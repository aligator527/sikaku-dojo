## 試験の特徴

E資格（JDLA Deep Learning for ENGINEER）は、ディープラーニングの理論を理解し、適切な手法を選択して実装する能力を認定する試験です。

| 項目 | 内容 |
| --- | --- |
| 受験資格 | JDLA認定プログラムを試験日の過去2年以内に修了していること |
| 試験方式 | 指定の試験会場（テストセンター）でのコンピュータ試験 |
| 試験時間 | 120分 |
| 出題形式 | 多肢選択式の知識問題、100問程度（2026年第2回は105問） |
| 実施時期 | 年2回（2027年は第1回が2月19日〜21日、第2回が8月27日〜29日） |

ソースコードを含む問題は Python で記述され、試験開始時に PyTorch か TensorFlow のどちらかを選びます。選択後は変更できません。試験中は画面上の一般電卓（関数電卓ではない）が使え、メモ用にホワイトノートとペンが貸与されます。

### 何が評価されるか

E資格は「知っている」だけでなく、次の3つの力を同時に求めます。

1. **理論を説明する力**：手法の目的・仕組み・長所と短所（例：なぜ残差接続で勾配消失が緩和されるのか）。
2. **計算する力**：出力サイズやパラメータ数、勾配、確率・情報量、評価指標などを手で計算する問題。
3. **コードを読む力**：NumPy やフレームワークのコードの空欄補充や、実行結果の推定。

JDLAの結果発表では、応用数学・機械学習・深層学習・開発環境の分野別の平均得点率が公表されています。2026年第2回はそれぞれ60.90%、60.07%、62.32%、70.00%でした。どの分野にも一定の得点が必要と考え、苦手分野を作らないことが大切です。

### シラバス（E2026#2〜）の要点

2026年8月試験（E2026#2）から新しいシラバスが適用されています。大項目は「数学的基礎」「機械学習」「深層学習の基礎」「深層学習の応用」「開発・運用環境」の5つです。シラバス2024からの主な変更点として、キーワードに**パープレキシティ**、**Shifted window**、**Next token prediction**、**RAG**、**自己回帰**、**Integrated Gradients** が追加され、**CAM**、**正則化項の係数**、**IoTデバイス** が削除されました。また小項目に「大規模言語モデル（LLM）」が追加されています。シラバスには出題対象外（オプション）の項目も示されているので、原本を確認してください。

## 重点テーマ

- **数学的基礎**：行列・テンソルの積と形状、固有値分解・特異値分解、確率分布、最尤推定・MAP推定、エントロピー・交差エントロピー・KLダイバージェンス。
- **機械学習**：線形回帰と正則化（Lasso・Ridge）、ロジスティック回帰、SVM、決定木とアンサンブル、主成分分析・t-SNE、k-means、性能指標（適合率・再現率・F値・ROC曲線・AUC・IoU・mAP）。
- **深層学習の基礎**：誤差逆伝播法、出力層と損失関数の組み合わせ、活性化関数、SGD・モメンタム・AdaGrad・RMSProp・Adam、初期化（Xavier・He）、正則化（重み減衰・ドロップアウト・早期終了）、CNN の出力サイズとパラメータ数、LSTM・GRU、Transformer の構成、正規化手法（Batch・Layer・Instance・Group）。
- **深層学習の応用**：ResNet・Vision Transformer、Faster R-CNN・YOLO・SSD・FCOS、FCN・U-Net、Word2vec、BERT・GPT、WaveNet・CTC、VAE・GAN・拡散モデル、DQN・A3C、転移学習・距離学習・メタ学習、Grad-CAM・LIME・SHAP。
- **開発・運用環境**：プルーニング・蒸留・量子化、データ並列とモデル並列、連合学習、SIMD・SIMT・GPU・TPU、Docker。

## つまずきやすいポイント

- **形状（shape）の取り違え**：行列の勾配で転置の位置を誤る、ソフトマックス関数の `dim`（`axis`）を誤るなど。コード問題では、各変数の形状を書き出してから考えます。
- **学習時と推論時の違い**：ドロップアウトやバッチ正規化は `train()` と `eval()` で挙動が変わります。
- **似た手法の混同**：Batch Normalization と Layer Normalization の正規化の軸、AdaGrad と RMSProp の違い、L1 と L2 正則化の性質、物体検出の1ステージと2ステージなど。比較表を自作して整理します。
- **電卓の制約**：画面上の電卓は関数電卓ではありません。$\log$ や $\exp$ を含む計算は、指数法則や $\log 2$ などの基本的な値を使って手で処理できるようにしておきます。

## 学習の進め方

### 教材

- **シラバス**：JDLA公式サイトで最新版（E2026#2〜）を入手し、学習の進捗管理表として使います。
- **書籍**：『ゼロから作るDeep Learning』（オライリー・ジャパン）で順伝播・逆伝播・最適化・CNN を自分で実装しながら理解し、『ゼロから作るDeep Learning ❷ 自然言語処理編』で RNN・LSTM・Attention を補います。理論の体系的な整理には『深層学習 改訂第2版』（岡谷貴之 著、講談社 機械学習プロフェッショナルシリーズ）が役立ちます。
- **無料のオンライン教材**：Dive into Deep Learning（d2l.ai、英語）はコードと数式が対応していて、Transformer や最適化手法まで網羅しています。フレームワークの使い方は PyTorch または TensorFlow の公式チュートリアルで確認します。
- **問題集**：市販の問題集を使う場合は、対応しているシラバスの版を確認してください。古い版のシラバスに基づく問題集では、新しいキーワードが扱われていないことがあります。

### 演習の方法

1. **キーワードごとに「一言説明・式・コード」をまとめる**：シラバスのキーワードを1つずつ、目的・仕組み・式（あれば）・フレームワークでの書き方の4点でノートにまとめます。
2. **計算問題は手で解く**：出力サイズ、パラメータ数、勾配、エントロピー、評価指標などは、電卓に頼らず手で計算できるようにします。
3. **コードは動かして確かめる**：`nn.Dropout` や `nn.BatchNorm2d` の挙動、`torch.triu` によるマスクなど、疑問に思ったら小さなコードを実行して確認します。
4. **間違いをシラバスの項目に戻す**：演習で間違えた問題は、どのキーワードの理解不足かを特定し、教材の該当箇所を読み直します。

## 本番のコツ

- **時間配分**：120分で100問程度なので、1問あたり1分強です。計算量の多い問題やコードの長い問題は後回しにし、全問に一度目を通すことを優先します。見直し用のマーク機能があれば活用します。
- **フレームワークの選択**：試験開始時に選んだフレームワークは変更できません。学習で使ってきた方を迷わず選びます。
- **計算用メモ**：ホワイトノートは1枚なので、計算は整理して書きます。足りなくなった場合は試験監督員に申し出る案内になっています。
- **当日の準備**：本人確認書類の要件や持ち込み禁止物は、受験案内（ピアソンVUE）の最新情報を事前に確認してください。CBT の操作は、公式に案内されているサンプル試験で事前に体験できます。
