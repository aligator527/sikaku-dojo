  キャッシュフロー計算書に関する次の記述 a〜d のうち，正しいものの組合せとして，最も適切なものはどれか。

キャッシュフロー計算書は、資金（現金及び現金同等物）の増減を営業活動・投資活動・財務活動の 3 つの区分に分けて示します。配当金の支払いは財務活動、固定資産の売却収入は投資活動に記載するので a と b は誤りで、c と d が正しい記述です。

### 各選択肢の検討

- **a（誤り）**：配当金の支払額は、株主への資金の返還として**財務活動**によるキャッシュフローの区分に記載します。なお、利息の受取・支払と配当金の受取については、営業活動の区分に記載する方法と、投資活動（受取）・財務活動（支払）の区分に記載する方法の選択が認められていますが、配当金の支払は常に財務活動です。
- **b（誤り）**：有形固定資産の取得による支出や売却による収入は、**投資活動**によるキャッシュフローの区分に記載します。
- **c（正しい）**：減価償却費は現金の支出を伴わない費用なので、間接法では税引前当期純利益に加算します。
- **d（正しい）**：現金同等物は、容易に換金でき、価値の変動について僅少なリスクしか負わない短期投資です。取得日から満期日または償還日までの期間が 3 か月以内の定期預金や譲渡性預金、コマーシャル・ペーパーなどが含まれます。

したがって、正しいものの組合せは「c と d」です。

### ポイント

| 区分 | 主な項目 |
| --- | --- |
| 営業活動 | 営業収入、商品の仕入による支出、人件費の支出、法人税等の支払額 |
| 投資活動 | 有形固定資産・有価証券の取得と売却、貸付けと回収 |
| 財務活動 | 借入れと返済、社債の発行と償還、株式の発行、自己株式の取得、配当金の支払 |

フリーキャッシュフローは、営業活動によるキャッシュフローと投資活動によるキャッシュフローの合計として簡便に計算されることがあります。
