a は改良保全の説明、b は時間基準保全の説明であり、いずれも用語との組合せが誤っています。c は $190 \div (190 + 10) = 0.95$ で正しいので、a 誤・b 誤・c 正のエが正解です。

### 各記述の検討

- **a（誤）**：既存設備の弱点を改良して故障を減らしたり、保全をしやすくしたりする活動は改良保全です。保全予防は、新しい設備の計画・設計の段階で、過去の保全の情報などを活かして、故障しにくく保全しやすい設備にする活動です。
- **b（誤）**：稼働時間や経過時間に基づいて周期的に保全するのは時間基準保全（定期保全）です。予知保全（状態基準保全）は、振動・温度・音などで設備の劣化状態を監視し、その状態に基づいて保全の時期を決める方式です。
- **c（正）**：固有アベイラビリティ（設備が使用可能な状態にある時間の割合）は次の式で求めます。

  $$
  \text{固有アベイラビリティ} = \frac{\text{MTBF}}{\text{MTBF} + \text{MTTR}} = \frac{190}{190 + 10} = 0.95
  $$

### ポイント

| 保全の種類 | 内容 |
| --- | --- |
| 予防保全（時間基準保全） | 周期を決めて定期的に点検・交換する |
| 予防保全（状態基準保全・予知保全） | 劣化の状態を監視し、状態に応じて保全する |
| 事後保全 | 故障してから修理する（影響の小さい設備では計画的に選ぶこともある） |
| 改良保全 | 既存設備を改良して故障を減らし、保全しやすくする |
| 保全予防 | 設計段階から故障しにくく保全しやすい設備にする |

- MTBF は信頼性（故障しにくさ）、MTTR は保全性（直しやすさ）の指標です。アベイラビリティを高めるには、MTBF を長くするか MTTR を短くします。
