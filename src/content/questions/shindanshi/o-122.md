間接法では、税引前当期純利益を出発点に、現金の支出を伴わない費用（減価償却費・引当金の増加）を加算し、投資活動に関する損益（固定資産売却益）を取り除き、運転資本の増減を調整したうえで、法人税等の支払額を差し引きます。本問の営業キャッシュフローは 390 万円です。

### 計算

| 項目 | 調整 | 金額（万円） |
| --- | --- | ---: |
| 税引前当期純利益 | 出発点 | 500 |
| 減価償却費 | 非資金費用なので加算 | +120 |
| 貸倒引当金の増加額 | 非資金費用なので加算 | +10 |
| 有形固定資産売却益 | 投資活動の区分で扱うので減算 | −20 |
| 売上債権の増加額 | 未回収の売上が増えたので減算 | −60 |
| 棚卸資産の減少額 | 在庫が現金化されたので加算 | +30 |
| 仕入債務の減少額 | 買掛金などの支払いが進んだので減算 | −40 |
| 小計 | | 540 |
| 法人税等の支払額 | 減算 | −150 |
| 営業活動によるキャッシュフロー | | 390 |

### よくある誤り

- **固定資産売却益をそのまま残す**：売却による収入（売却益を含む）は投資活動によるキャッシュフローに計上されるので、営業活動の区分では利益から売却益を差し引きます。残したままにすると 410 万円になります。
- **運転資本の増減の符号を逆にする**：資産（売上債権・棚卸資産）の増加は減算、減少は加算、負債（仕入債務）の増加は加算、減少は減算です。
- **引当金を無視する**：貸倒引当金の繰入は現金の支出を伴わない費用なので、増加額を加算します。

### ポイント

- 運転資本の調整は「資産の増加 → キャッシュの減少、負債の増加 → キャッシュの増加」と覚えます。
- 間接法と直接法で、営業活動によるキャッシュフローの金額は一致します。違うのは小計までの表示の仕方です。
