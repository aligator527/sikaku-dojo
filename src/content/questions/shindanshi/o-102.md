  2 つの財 X，Y を消費する消費者の効用関数が $u = xy$（$x$：X の消費量，$y$：Y の消費量）で表される。この消費者の所得は 1,200，X の価格は 20，Y の価格は 30 であり，所得はすべて X と Y の購入に充てるものとする。この消費者が効用を最大化するときの消費量の組合せとして，最も適切なものはどれか。
choices:

answer: 3

効用が最大になるのは、無差別曲線と予算制約線が接する点、つまり限界代替率（無差別曲線の傾き）が価格比に等しい点です。$u = xy$ では限界代替率が $y/x$ なので、$y/x = 20/30$ と予算制約を連立させて $x = 30$、$y = 20$ が得られます。

### 計算

限界効用は $MU_x = y$、$MU_y = x$ なので、効用最大化の条件は

$$
MRS = \frac{MU_x}{MU_y} = \frac{y}{x} = \frac{P_x}{P_y} = \frac{20}{30} \quad\Longrightarrow\quad 30y = 20x
$$

です。これを予算制約 $20x + 30y = 1{,}200$ に代入すると、$20x + 20x = 1{,}200$ より $x = 30$、$y = 20$ となります。X と Y への支出がどちらも 600 と、所得の半分ずつになっています。

### 各選択肢の検討

選択肢の組合せは、いずれも予算制約線 $20x + 30y = 1{,}200$ の上にあります。効用 $u = xy$ を比べると次のとおりです。

| 選択肢 | ア | イ | ウ | エ | オ |
| --- | ---: | ---: | ---: | ---: | ---: |
| $u = xy$ | 384 | 576 | 600 | 576 | 384 |

- **ア・オ**：予算は使い切っていますが、無差別曲線が予算制約線と交わる点で、効用はまだ高められます。
- **イ**：X と Y を同じ量ずつ買う組合せです。価格の安い X を増やし、高い Y を減らすと効用が上がります。
- **ウ（正解）**：限界代替率と価格比が一致し、効用が最大（600）になります。
- **エ**：イとは逆に X を買いすぎた組合せで、効用はイと同じ 576 にとどまります。

### ポイント

- 効用最大化の条件は「$MRS = P_x / P_y$」、言い換えると「1 円当たりの限界効用が等しい（$MU_x / P_x = MU_y / P_y$）」です。
- $u = x^{a}y^{b}$ 型（コブ＝ダグラス型）の効用関数では、各財への支出額が所得の $\dfrac{a}{a+b}$、$\dfrac{b}{a+b}$ に固定されます。本問は $a = b$ なので半分ずつです。
