EVM では、出来高（EV）を基準に、計画（PV）と比べてスケジュールを、実コスト（AC）と比べてコストを評価します。SPI $= EV / PV = 0.80$、CPI $= EV / AC \approx 0.89$ で、どちらも 1 を下回っているため、スケジュールは遅れ、コストは超過しています。現在のコスト効率が続くと、EAC $= BAC / CPI = 1{,}125$ 万円となるので、アが正解です。

### 計算

$$
\begin{aligned}
\text{SPI} &= \frac{EV}{PV} = \frac{400}{500} = 0.80 \\
\text{CPI} &= \frac{EV}{AC} = \frac{400}{450} \approx 0.89 \\
\text{EAC} &= \frac{BAC}{CPI} = \frac{1{,}000}{400 / 450} = 1{,}000 \times \frac{450}{400} = 1{,}125 \ \text{（万円）}
\end{aligned}
$$

スケジュール差異 $SV = EV - PV = -100$ 万円、コスト差異 $CV = EV - AC = -50$ 万円です。

### 各選択肢の検討

- **ア（正解）**：SPI 0.80、CPI 0.89、EAC 1,125 万円です。
- **イ**：$EAC = AC + (BAC - EV) = 450 + 600 = 1{,}050$ 万円は、残りの作業が**当初の計画どおりのコスト**で進むと仮定した場合の見積りです。問題文の「現時点までのコスト効率で進む」という仮定に合いません。
- **ウ**：分子と分母を逆にした値（$PV / EV$、$AC / EV$）です。この誤りをすると、効率が 1 を上回り、計画より順調であるかのように見えてしまいます。
- **エ**：SPI と CPI の値を取り違えています。
- **オ**：EAC を BAC ÷ SPI で計算した誤りです。コストの見積りにはコスト効率（CPI）を使います。

### ポイント

- SPI $= EV / PV$、CPI $= EV / AC$。1 未満なら遅延・超過、1 を超えれば前倒し・節約です。
- EAC は前提によって式が変わります。現在のコスト効率が続く場合は $BAC / CPI$、残作業は計画どおりと見込む場合は $AC + (BAC - EV)$ です。どちらの前提かを問題文で確認しましょう。
