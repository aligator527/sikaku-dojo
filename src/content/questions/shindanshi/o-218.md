  人事評価において評価者が陥りやすい誤り（評価エラー）に関する記述として，最も適切なものはどれか。

ハロー効果（光背効果）は、ある一つの際立った特徴が全体の印象を左右し、本来は独立しているはずのほかの評価項目まで高く（または低く）評価してしまう誤りです。アはその説明として正しいものです。

### 各選択肢の検討

- **ア（正解）**：ハロー効果の説明です。「営業成績が良いから協調性も高いだろう」と評価してしまう例が典型です。
- **イ**：評価を中央の段階に集中させるのは中心化傾向です。寛大化傾向は、評価が全体的に甘く（高く）なる傾向です。
- **ウ**：評価項目間の論理的な関連を思い込んで同じように評価するのは論理誤差です。対比誤差は、評価者が自分の能力や価値観を基準にして被評価者を評価してしまう誤りです。
- **エ**：期末誤差は、評価期間の終わり（評価の直前）に起きた出来事の印象が強く残り、期間全体の評価に影響を与える誤りです。
- **オ**：記述は、評価者自身を基準にする対比誤差の典型例です。

### ポイント

| 評価エラー | 内容 |
| --- | --- |
| ハロー効果 | 一つの際立った特徴に引きずられ、ほかの項目も同じ方向に評価する |
| 寛大化傾向／厳格化傾向 | 全体的に甘く／厳しく評価する |
| 中心化傾向 | 評価が中央に集まり、差がつかない |
| 論理誤差 | 関連があると思い込んだ項目を同じように評価する |
| 対比誤差 | 評価者自身を基準に評価する |
| 期末誤差 | 期末に近い出来事の影響を過大に受ける |

- 対策としては、評価基準の明確化と公開、評価者訓練、複数の評価者による評価（多面評価）、期間中の行動の記録などがあります。
