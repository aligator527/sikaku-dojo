  財の価格変化が需要量に与える効果（代替効果と所得効果）に関する次の記述 a〜d のうち，正しいものの組合せとして，最も適切なものはどれか。

  a　上級財（正常財）の価格が下落すると，代替効果と所得効果はともに，その財の需要量を増やす方向に働く。

  b　下級財の価格が下落すると，所得効果はその財の需要量を減らす方向に働くが，代替効果が必ず所得効果を上回るため，需要量は必ず増加する。

  c　ギッフェン財は下級財の一種であり，価格が上昇すると需要量が増加する。

  d　代替効果は，価格が上昇した財の需要量を増やす方向に働くことがある。
choices:
  - a と b
  - a と c
  - a と d
  - b と c
  - c と d
answer: 2

価格変化の効果は、効用水準を一定に保ったまま相対価格だけが変わる「代替効果」と、実質所得の変化による「所得効果」に分けられます（スルツキー分解）。代替効果は常に価格と逆方向に働き、所得効果の向きは上級財か下級財かで決まります。正しいのは a と c です。

### 各選択肢の検討

- **a（正しい）**：価格が下がると、代替効果で相対的に安くなったその財の需要が増えます。また実質所得が増えるので、上級財なら所得効果でも需要が増えます。両方の効果が同じ向きに働きます。
- **b（誤り）**：下級財では、価格の下落による実質所得の増加が需要を減らす方向に働きます。多くの下級財では代替効果の方が大きく需要量は増えますが、「必ず」ではありません。所得効果が代替効果を上回る財がギッフェン財です。
- **c（正しい）**：ギッフェン財は、下級財のうち所得効果が代替効果を上回る財です。価格が上昇すると、代替効果による需要減少よりも、実質所得の減少による需要増加（所得効果）が大きくなり、需要量が増加します。
- **d（誤り）**：代替効果は、効用水準を一定に保ったまま相対的に高くなった財を減らし、安くなった財を増やす効果なので、価格が上昇した財の需要量を増やす方向には働きません。

したがって、正しいものの組合せは「a と c」です。

### ポイント

| 財の種類 | 価格下落時の代替効果 | 価格下落時の所得効果 | 需要量（全部効果） |
| --- | --- | --- | --- |
| 上級財 | 増加 | 増加 | 増加 |
| 下級財（ギッフェン財以外） | 増加 | 減少 | 増加（代替効果 > 所得効果） |
| ギッフェン財 | 増加 | 減少 | 減少（代替効果 < 所得効果） |

ギッフェン財は必ず下級財ですが、下級財が必ずギッフェン財になるわけではありません。この包含関係を逆にした選択肢がよく出題されます。
