マネーストックとマネタリーベースの比率を貨幣乗数（信用乗数）といい、現金預金比率を $c$、準備預金比率を $r$ とすると $\dfrac{c + 1}{c + r}$ で表されます。本問の貨幣乗数は $\dfrac{1.2}{0.25} = 4.8$ なので、マネーストックは $5 \times 4.8 = 24$ 兆円増加します。

### 計算

$M = C + D$、$H = C + R$ の分子・分母を預金 $D$ で割ると、

$$
\frac{M}{H} = \frac{C/D + 1}{C/D + R/D} = \frac{0.2 + 1}{0.2 + 0.05} = \frac{1.2}{0.25} = 4.8
$$

$$
\Delta M = 4.8 \times 5 = 24 \ \text{（兆円）}
$$

### よくある誤り

- **分子の 1 を忘れる**：$\dfrac{0.2}{0.25} = 0.8$ とすると、マネーストックがマネタリーベースより増えないことになってしまいます。分子は $C/D + 1$（$M = C + D$ を $D$ で割ったもの）です。
- **準備預金比率だけで考える**：$\dfrac{1}{0.05} = 20$ 倍とするのは、現金の漏出がない（$c = 0$）場合の信用創造の倍率です。現金として手元に置かれる分は預金として銀行に戻らないので、乗数は小さくなります。

### ポイント

- 貨幣乗数は、現金預金比率 $c$ が高いほど、準備預金比率 $r$ が高いほど小さくなります。法定準備率の引下げは乗数を大きくする金融緩和策です。
- 現実には、マネタリーベースを増やしても銀行貸出が増えなければマネーストックはあまり増えず、乗数は安定しません。理論上の関係として理解しておきましょう。
