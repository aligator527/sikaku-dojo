政令による業種の特例は、ゴム製品製造業（資本金 3 億円以下又は従業員 900 人以下）、ソフトウェア業・情報処理サービス業（3 億円以下又は 300 人以下）、旅館業（5,000 万円以下又は 200 人以下）の三つです（中小企業信用保険法施行令第1条第2項）。旅館業は資本金 1 億円・従業員 250 人で、どちらの基準も超えるため中小企業者に該当しません。したがってイが正解です。

### 各選択肢の検討

| 業種 | 資本金基準 | 従業員基準 |
| --- | --- | --- |
| 製造業・建設業・運輸業その他 | 3 億円以下 | 300 人以下 |
| 卸売業 | 1 億円以下 | 100 人以下 |
| サービス業 | 5,000 万円以下 | 100 人以下 |
| 小売業 | 5,000 万円以下 | 50 人以下 |
| ゴム製品製造業（自動車・航空機用タイヤ・チューブ製造業、工業用ベルト製造業を除く）【政令】 | 3 億円以下 | 900 人以下 |
| ソフトウェア業・情報処理サービス業【政令】 | 3 億円以下 | 300 人以下 |
| 旅館業【政令】 | 5,000 万円以下 | 200 人以下 |

- **ア**：資本金 4 億円は基準を超えますが、従業員 800 人はゴム製品製造業の特例（900 人以下）を満たすので該当します。
- **イ（正解）**：旅館業の特例でも資本金 5,000 万円以下又は従業員 200 人以下が基準で、どちらも満たしません。サービス業の一般の基準（従業員 100 人以下）より広げられていても該当しない点に注意します。
- **ウ**：ソフトウェア業はサービス業ですが、特例により資本金 3 億円以下が基準になるので、資本金 2 億円で該当します。
- **エ**：経営コンサルタント業はサービス業（特例なし）で、資本金 1 億円は基準（5,000 万円以下）を超えますが、従業員 90 人は基準（100 人以下）を満たすので該当します。
- **オ**：自動車用タイヤ製造業はゴム製品製造業の特例から除かれていますが、一般の製造業として資本金 3 億円以下又は従業員 300 人以下で判定します。従業員 280 人なので該当します。

### ポイント

- 資本金基準と従業員基準は「又は」の関係で、どちらか一方を満たせば中小企業者です。
- 中小企業基本法の定義は「おおむね」の範囲であり、個別の法律が政令で業種ごとに範囲を変えています。小規模企業者についても、宿泊業と娯楽業は従業員 20 人以下とする特例があります（同施行令第1条の2）。
