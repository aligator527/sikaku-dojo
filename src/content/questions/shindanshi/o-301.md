stem: |
  地区 X に住む消費者の買物行動を，ハフモデルを用いて分析する。地区 X の消費者が利用する店舗は A，B，C の 3 店で，各店舗の売場面積と地区 X からの距離は次のとおりである。消費者がある店舗を選択する確率は，その店舗の売場面積に比例し，地区 X からの距離の 2 乗に反比例するものとする。

  | 店舗 | 売場面積 | 地区 X からの距離 |
  | --- | ---: | ---: |
  | A | 3,200 m² | 2 km |
  | B | 7,200 m² | 3 km |
  | C | 1,600 m² | 1 km |

  地区 X の消費者が店舗 B を選択する確率として，最も適切なものはどれか。
choices:
  - '8.2%'
  - '25.0%'
  - '42.9%'
  - '60.0%'
answer: 2

ハフモデルでは、店舗の魅力度を「売場面積 ÷ 距離の $\lambda$ 乗」で表し、その店舗の魅力度が全店舗の魅力度の合計に占める割合を選択確率とします。本問は $\lambda = 2$ なので、魅力度は A が 800、B が 800、C が 1,600 となり、B の選択確率は $800 \div 3{,}200 = 25.0\%$ です。

### 計算

$$
\begin{aligned}
\text{A} &: \frac{3{,}200}{2^2} = 800, \qquad \text{B} : \frac{7{,}200}{3^2} = 800, \qquad \text{C} : \frac{1{,}600}{1^2} = 1{,}600 \\
P_{XB} &= \frac{800}{800 + 800 + 1{,}600} = \frac{800}{3{,}200} = 0.25
\end{aligned}
$$

地区 X の消費者が 12,000 人いれば、店舗 B を選ぶ人数の期待値は $12{,}000 \times 0.25 = 3{,}000$ 人と見積もれます。

### 各選択肢の検討

- **ア（8.2%）**：売場面積を無視し、距離の 2 乗の逆数だけで計算した値（$\frac{1/9}{1/4 + 1/9 + 1/1}$）です。ハフモデルでは、売場面積（品ぞろえの豊富さ）が店舗の魅力度を高める要因になります。
- **イ（25.0%、正解）**：売場面積を距離の 2 乗で割った魅力度の比で求めた値です。
- **ウ（42.9%）**：距離の 1 乗で割った値（$\lambda = 1$）です。距離抵抗のパラメータを問題文の条件（2 乗）どおりに使っていません。
- **エ（60.0%）**：距離を無視し、売場面積の比（$7{,}200 \div 12{,}000$）だけで計算した値です。B は最も大きい店舗ですが、地区 X から遠いため選択確率は下がります。

### ポイント

- ハフモデル：$P_{ij} = \dfrac{S_j / T_{ij}^{\lambda}}{\sum_k S_k / T_{ik}^{\lambda}}$（$S_j$：店舗 $j$ の売場面積、$T_{ij}$：地区 $i$ から店舗 $j$ までの距離や時間、$\lambda$：距離抵抗パラメータ）。
- 旧通商産業省（現在の経済産業省）が用いた修正ハフモデルは、$\lambda = 2$ に固定したものです。本問の A と B のように、売場面積が 2.25 倍でも距離が 1.5 倍なら $2.25 \div 1.5^2 = 1$ で魅力度は同じになります。遠い大型店と近い中型店の比較で、距離の 2 乗の効果を確認しておきましょう。
