modelAnswer: |
  **[1]** $H_1$ のもと：$\hat{\mu}_1 = \bar{X}$、$\hat{\mu}_2 = \bar{Y}$、

  $$\hat{\sigma}^2 = \frac{1}{N}\left\{\sum(X_i - \bar{X})^2 + \sum(Y_j - \bar{Y})^2\right\} = \frac{N - 2}{N}s_p^2$$

  $H_0$ のもと（共通平均 $\mu$）：$\hat{\mu} = \dfrac{m\bar{X} + n\bar{Y}}{N}$、

  $$\hat{\sigma}_0^2 = \frac{1}{N}\left\{\sum(X_i - \hat{\mu})^2 + \sum(Y_j - \hat{\mu})^2\right\}$$

  **[2]** 正規分布の尤度に最尤推定量を代入すると、どちらのもとでも指数部分は $-N/2$ になるので、最大尤度は $(2\pi\hat{\sigma}^2)^{-N/2}e^{-N/2}$ の形となり

  $$\Lambda = \left(\frac{\hat{\sigma}^2}{\hat{\sigma}_0^2}\right)^{N/2}$$

  $\sum(X_i - \hat{\mu})^2 = \sum(X_i - \bar{X})^2 + m(\bar{X} - \hat{\mu})^2$ で、$\bar{X} - \hat{\mu} = \dfrac{n(\bar{X} - \bar{Y})}{N}$、$\bar{Y} - \hat{\mu} = -\dfrac{m(\bar{X} - \bar{Y})}{N}$ だから

  $$N\hat{\sigma}_0^2 = N\hat{\sigma}^2 + \frac{mn^2 + nm^2}{N^2}(\bar{X} - \bar{Y})^2 = N\hat{\sigma}^2 + \frac{mn}{N}(\bar{X} - \bar{Y})^2$$

  よって、$N\hat{\sigma}^2 = (N - 2)s_p^2$ と $\dfrac{mn}{N} = \dfrac{1}{1/m + 1/n}$ を用いて

  $$\frac{\hat{\sigma}_0^2}{\hat{\sigma}^2} = 1 + \frac{(\bar{X} - \bar{Y})^2}{(N - 2)s_p^2(1/m + 1/n)} = 1 + \frac{t^2}{N - 2}$$

  したがって $\Lambda = \left(1 + \dfrac{t^2}{N - 2}\right)^{-N/2}$。

  **[3]** $\Lambda$ は $|t|$ の狭義減少関数なので、棄却域 $\{\Lambda < k\}$ は $\{|t| > c\}$ と同値である。$H_0$ のもとで $t$ は自由度 $N - 2$ の $t$ 分布に従う（$\bar{X} - \bar{Y} \sim N(0,\ \sigma^2(1/m + 1/n))$、$(N - 2)s_p^2/\sigma^2 \sim \chi^2(N - 2)$ で両者は独立）ので、$c = t_{\alpha/2}(N - 2)$ とすれば大きさがちょうど $\alpha$ になる。したがって有意水準 $\alpha$ の尤度比検定は、通常の 2 標本 $t$ 検定（等分散）と一致する。

  **[4]** $t^2 = \dfrac{3.0^2}{2.5^2 \times (1/6 + 1/6)} = \dfrac{9}{2.0833} = 4.32$、$|t| = 2.078 < 2.228$ なので、$t$ 検定では有意水準 5% で $H_0$ は棄却されない。

  一方

  $$-2\log\Lambda = N\log\left(1 + \frac{t^2}{N - 2}\right) = 12\log 1.432 = 12 \times 0.3591 = 4.309 > 3.841$$

  なので、ウィルクスの近似では棄却される。ウィルクスの定理は $N \to \infty$ での近似であり、小標本では $-2\log\Lambda$ の分布が $\chi^2(1)$ より右に裾が重く、近似による検定は有意になりやすい（実際の第 1 種の過誤の確率が名目の 5% を上回る）。本問のように正確な分布（$t$ 分布）が分かる場合は、それを使うべきである。

尤度比検定は「大標本でカイ二乗近似を使う検定」と思われがちですが、正規分布モデルでは尤度比が $t$ 統計量や $F$ 統計量の単調関数になり、小標本でも正確な検定が得られます。本問は 2 標本 $t$ 検定が尤度比検定であることを示し、同じ尤度比に漸近近似を使うと結論が変わりうることを確認する問題です。

### 解答の流れ

1. 正規分布の最大尤度は $(2\pi\hat{\sigma}^2)^{-N/2}e^{-N/2}$ となるので、尤度比は分散の推定値の比だけで決まる。
2. 帰無仮説のもとでの平方和を、群内平方和と群間平方和に分解する。
3. 尤度比が $|t|$ の単調関数であることから、棄却域を $t$ で表す。
4. 正確な $t$ 検定と漸近近似を比較する。

### つまずきやすい点

- 最尤推定量の分散は除数が $N$（不偏分散の $N - 2$ ではない）です。$\Lambda$ を $s_p^2$ で書き直すときに係数の扱いを誤りやすいので注意します。
- [4] で $-2\log\Lambda$ を $t^2 = 4.32$ と同一視するのは誤りです。$N\log(1 + t^2/(N - 2))$ は $N \to \infty$ で $t^2$ に近づきますが、$N = 12$ では $4.31$ です。
- $t^2 = 4.32$ を $\chi^2_{0.05}(1) = 3.841$ と比べるのも、$t$ 分布の裾の重さを無視した誤りです（$t^2$ の正確な分布は $F(1, 10)$ で、上側 5% 点は $2.228^2 = 4.96$）。

### ポイント

- 一元配置分散分析の $F$ 検定も、同様に「平均がすべて等しい」という仮説に対する尤度比検定で、$\Lambda = \left(1 + \frac{a - 1}{N - a}F\right)^{-N/2}$ と表せます。
- ウィルクスの定理は正則条件のもとでの大標本近似です。小標本では、バートレット補正などで $-2\log\Lambda$ の期待値を自由度に合わせる工夫が使われます。
