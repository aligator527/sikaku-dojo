stem: |
  因子 $A$（$a$ 水準）と因子 $B$（$b$ 水準）の各組合せで $r$ 回ずつ繰り返し観測した二元配置データ $Y_{ijk}$（$i = 1, \ldots, a$；$j = 1, \ldots, b$；$k = 1, \ldots, r$）を、モデル

  $$Y_{ijk} = \mu + \alpha_i + \beta_j + (\alpha\beta)_{ij} + \varepsilon_{ijk},\qquad \varepsilon_{ijk} \sim N(0, \sigma^2)\ \text{（互いに独立）}$$

  で解析する。平方和を $S_A,\ S_B,\ S_{AB},\ S_E$、平均平方を $V_A = S_A/\phi_A$ などと書く（$\phi$ は自由度）。以下の各問に答えよ。

  [1] 各平方和の自由度 $\phi_A,\ \phi_B,\ \phi_{AB},\ \phi_E$ を求め、その和が総平方和の自由度に一致することを確かめよ。

  [2] 母数模型（$\sum_i\alpha_i = \sum_j\beta_j = 0$、$\sum_i(\alpha\beta)_{ij} = \sum_j(\alpha\beta)_{ij} = 0$）での $V_A,\ V_{AB},\ V_E$ の期待値は

  $$E[V_A] = \sigma^2 + \frac{br\sum_i\alpha_i^2}{a - 1},\quad E[V_{AB}] = \sigma^2 + \frac{r\sum_{i,j}(\alpha\beta)_{ij}^2}{(a - 1)(b - 1)},\quad E[V_E] = \sigma^2$$

  である。$A$ の主効果の検定に用いる $F$ 比を答え、その理由を説明せよ。

  [3] $A$ は母数因子のまま、$B$ を変量因子とする混合模型を考える。$\beta_j \sim N(0, \sigma_B^2)$、$(\alpha\beta)_{ij} \sim N(0, \sigma_{AB}^2)$ はすべて互いに独立で $\varepsilon_{ijk}$ とも独立とし、$\sum_i\alpha_i = 0$ とする（交互作用に和の制約を課さない模型）。このとき

  $$E[V_A] = \sigma^2 + r\sigma_{AB}^2 + \frac{br\sum_i\alpha_i^2}{a - 1},\quad E[V_{AB}] = \sigma^2 + r\sigma_{AB}^2$$

  となることを、$\bar{Y}_{i\cdot\cdot} - \bar{Y}_{\cdot\cdot\cdot}$ の分解を用いて説明し、$A$ の主効果の検定に用いる $F$ 比を答えよ。

  [4] $a = 3,\ b = 4,\ r = 2$ の実験で $S_A = 60,\ S_B = 45,\ S_{AB} = 36,\ S_E = 48$ であった。母数模型と [3] の混合模型のそれぞれで、$A$ の主効果を有意水準 5% で検定せよ。$F_{0.05}(2, 12) = 3.885$、$F_{0.05}(2, 6) = 5.143$ とする。
modelAnswer: |
  **[1]** $\phi_A = a - 1$、$\phi_B = b - 1$、$\phi_{AB} = (a - 1)(b - 1)$、$\phi_E = ab(r - 1)$。和は

  $$(a - 1) + (b - 1) + (a - 1)(b - 1) + ab(r - 1) = (ab - 1) + ab(r - 1) = abr - 1$$

  で、総平方和の自由度 $abr - 1$ に一致する。

  **[2]** $F_A = V_A/V_E$ を用いる。$H_0: \alpha_1 = \cdots = \alpha_a = 0$ のもとで $E[V_A] = E[V_E] = \sigma^2$ となり、$V_A$ と $V_E$ は独立で、それぞれ $\sigma^2\chi^2(\phi)/\phi$ に従う。よって $F_A \sim F(a - 1,\ ab(r - 1))$ で、$H_0$ が偽なら $E[V_A] > \sigma^2$ なので上側で棄却する。分母は「$H_0$ のもとで分子と同じ期待値をもち、$A$ の効果を含まない平均平方」でなければならず、母数模型ではそれが $V_E$ である。

  **[3]** $\bar{Y}_{i\cdot\cdot} - \bar{Y}_{\cdot\cdot\cdot}$ を分解すると、変量の $\beta_j$ は全水準 $i$ に共通なので打ち消し合い

  $$\bar{Y}_{i\cdot\cdot} - \bar{Y}_{\cdot\cdot\cdot} = \alpha_i + \left\{\overline{(\alpha\beta)}_{i\cdot} - \overline{(\alpha\beta)}_{\cdot\cdot}\right\} + (\bar{\varepsilon}_{i\cdot\cdot} - \bar{\varepsilon}_{\cdot\cdot\cdot})$$

  $\overline{(\alpha\beta)}_{i\cdot} = \frac{1}{b}\sum_j(\alpha\beta)_{ij}$ は分散 $\sigma_{AB}^2/b$ の独立な確率変数なので、$a$ 個の偏差平方和の期待値は $(a - 1)\sigma_{AB}^2/b$。同様に誤差部分は $(a - 1)\sigma^2/(br)$。$S_A = br\sum_i(\bar{Y}_{i\cdot\cdot} - \bar{Y}_{\cdot\cdot\cdot})^2$ で、各部分は独立・平均 0 なので

  $$E[S_A] = br\sum_i\alpha_i^2 + (a - 1)r\sigma_{AB}^2 + (a - 1)\sigma^2$$

  これを $a - 1$ で割って $E[V_A]$ が得られる。交互作用平方和は $(\alpha\beta)_{ij}$ と誤差の変動だけを含むので（$\beta_j$ も $\alpha_i$ も、交互作用の対比では消える）、$E[V_{AB}] = \sigma^2 + r\sigma_{AB}^2$。

  よって $H_0: \alpha_i = 0$ のもとで $E[V_A] = E[V_{AB}]$ となるので、$A$ の検定には $F_A = V_A/V_{AB}$（自由度 $(a - 1,\ (a - 1)(b - 1))$）を用いる。$V_E$ を分母にすると、$\sigma_{AB}^2 > 0$ のとき $A$ の効果がなくても $F$ が大きくなりやすく、有意水準を保てない。

  **[4]** 自由度は $\phi_A = 2,\ \phi_B = 3,\ \phi_{AB} = 6,\ \phi_E = 12$ で、$V_A = 30,\ V_B = 15,\ V_{AB} = 6,\ V_E = 4$。

  - 母数模型：$F_A = 30/4 = 7.50 > F_{0.05}(2, 12) = 3.885$ で、$A$ の主効果は有意。
  - 混合模型：$F_A = 30/6 = 5.00 < F_{0.05}(2, 6) = 5.143$ で、$A$ の主効果は有意でない。

  混合模型では、$B$ の水準を母集団から選んだとみなすため、$A$ の効果の大きさが $B$ の水準によって変わる変動（$\sigma_{AB}^2$）も「$A$ の効果の推定の不確かさ」に含まれる。そのため分母が大きく、自由度も小さくなり、結論が慎重になる。

二元配置分散分析では、「どの平均平方を分母にするか」が期待平均平方で決まります。母数模型では誤差の平均平方 $V_E$ が分母ですが、相手の因子が変量因子のときは交互作用の平均平方 $V_{AB}$ が分母になり、同じデータでも結論が変わることがあります。

### 解答の流れ

1. 自由度は「主効果 = 水準数 − 1」「交互作用 = 自由度の積」「誤差 = セル数 ×（繰り返し − 1）」。
2. 帰無仮説のもとで分子と同じ期待値をもつ平均平方を分母に選ぶ。
3. 混合模型では、群平均の差に交互作用の変量部分が残ることを分解で示す。
4. 分母と自由度を変えて 2 通りに判定する。

### つまずきやすい点

- 混合模型で $V_A/V_E$ を使う誤り。$\sigma_{AB}^2 > 0$ なら第 1 種の過誤の確率が名目より大きくなります。
- 交互作用に和の制約を課す模型（制約付き模型）では、$B$ の主効果の検定の分母が $V_E$ になるなど、変量因子側の期待平均平方が変わります。本問のように母数因子 $A$ の検定の分母は、どちらの模型でも $V_{AB}$ です。
- 分散成分の推定値は期待平均平方を逆に解いて求めます。ここでは $\hat{\sigma}_{AB}^2 = (V_{AB} - V_E)/r = (6 - 4)/2 = 1$ です。

### ポイント

- 交互作用が有意でないときに $S_{AB}$ を誤差にプールするかどうかは、事前に決めた方針に従います。プールすると誤差の自由度が増えますが、交互作用が実在する場合は検定が偏ります。
- 実験計画の段階で、どの因子を母数・変量とみなすかを決めておくことが、正しい分散分析表を作る前提になります。
