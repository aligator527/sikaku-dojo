$\bar{X}$ は完備十分統計量で、$E[\bar{X}^2] = \mu^2 + 1/n$ なので、$T = \bar{X}^2 - 1/n$ が一様最小分散不偏推定量です（レーマン・シェフェの定理）。$V[T] = V[\bar{X}^2] = \dfrac{4\mu^2}{n} + \dfrac{2}{n^2}$ で、$\mu = 2,\ n = 25$ では $0.64 + 0.0032 = 0.6432$ です。

### 計算

$\bar{X} = \mu + Z/\sqrt{n}$（$Z \sim N(0, 1)$）と書くと

$$\bar{X}^2 = \mu^2 + \frac{2\mu Z}{\sqrt{n}} + \frac{Z^2}{n}$$

$E[Z] = E[Z^3] = 0$ より $\mathrm{Cov}(Z, Z^2) = 0$、$V[Z^2] = 2$ なので

$$V[T] = V[\bar{X}^2] = \frac{4\mu^2}{n}V[Z] + \frac{1}{n^2}V[Z^2] = \frac{4\mu^2}{n} + \frac{2}{n^2}$$

$$\mu = 2,\ n = 25:\quad V[T] = \frac{16}{25} + \frac{2}{625} = 0.64 + 0.0032 = 0.6432$$

### クラーメル・ラオの下限との比較

$I_n(\mu) = n$、$\tau(\mu) = \mu^2$、$\tau'(\mu) = 2\mu$ より、下限は $\dfrac{(2\mu)^2}{n} = \dfrac{16}{25} = 0.64$ です。$V[T] = 0.6432$ はこれより $2/n^2 = 0.0032$ だけ大きく、一様最小分散不偏推定量でも下限は達成されません（$n \to \infty$ では比が 1 に近づきます）。

### ポイント

- よくある誤り：下限 $0.64$ を答える、または $T$ を $\bar{X}^2$（偏りが $1/n$）としたうえで $V[\bar{X}^2]$ を計算する。分散は同じ $0.6432$ だが、$\bar{X}^2$ は不偏推定量ではない。
- クラーメル・ラオの下限が達成されるのは $\tau(\mu)$ が $\mu$ の 1 次関数のときに限られる（正規分布の平均の場合）。$\mu^2$ のような非線形な関数では達成されない。
- $\mu = 0$ では $T = \bar{X}^2 - 1/n$ は確率 $P(\bar{X}^2 < 1/n) \approx 0.68$ で負になる。不偏性にこだわると、母数空間の外の値をとる推定量になりうる。
