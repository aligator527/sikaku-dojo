  対数賃金 $y$ が教育年数 $x_1$ と能力の指標 $x_2$ によって

  $$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + u,\qquad E[u \mid x_1, x_2] = 0$$

  と表され、$\beta_1 = 0.08$、$\beta_2 = 0.05$ であるとする。母集団で $V[x_1] = 6.25$、$V[x_2] = 1.00$、$\mathrm{Cov}(x_1, x_2) = 0.75$ である。$x_2$ が観測できないため $y$ を $x_1$ だけに単回帰したとき、$x_1$ の係数の最小二乗推定量の確率極限として正しいものを一つ選べ。

欠落変数があるとき、単回帰の係数の確率極限は $\beta_1 + \beta_2\,\mathrm{Cov}(x_1, x_2)/V[x_1]$ です。$\mathrm{Cov}(x_1, x_2)/V[x_1] = 0.75/6.25 = 0.12$ は「$x_2$ を $x_1$ に回帰したときの係数」で、確率極限は $0.08 + 0.05 \times 0.12 = 0.086$ です。

### 各選択肢の検討

- $0.074$：偏りの符号を逆にしている。$\beta_2 > 0$ かつ $\mathrm{Cov}(x_1, x_2) > 0$ なので、偏りは正。
- $0.080$：欠落変数バイアスを無視している。偏りは標本サイズを大きくしても消えない（一致性がない）。
- $0.086$：正しい。
- $0.095$：相関係数 $0.75/\sqrt{6.25 \times 1.00} = 0.30$ を回帰係数の代わりに使っている。
- $0.118$：$\mathrm{Cov}(x_1, x_2)/V[x_2] = 0.75$（$x_1$ を $x_2$ に回帰したときの係数）を使っている。$x_1$ の係数に混入するのは、$x_2$ のうち $x_1$ で説明される部分である。

### 計算

単回帰の係数は $\mathrm{Cov}(x_1, y)/V[x_1]$ に確率収束し

$$\frac{\mathrm{Cov}(x_1, y)}{V[x_1]} = \frac{\beta_1V[x_1] + \beta_2\mathrm{Cov}(x_1, x_2)}{V[x_1]} = 0.08 + 0.05 \times \frac{0.75}{6.25} = 0.086$$

教育の収益率を $0.6$ ポイント（相対的に 7.5%）過大に評価することになります。

### ポイント

- 欠落変数バイアスの符号は「欠落変数の係数 $\beta_2$ の符号」と「欠落変数と説明変数の相関の符号」の積で決まる。
- 対処法には、代理変数（能力の代わりに IQ テストの得点など）を加える、操作変数法を用いる、パネルデータで時間不変な能力を固定効果として除く、などがある。
