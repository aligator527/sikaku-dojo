クロンバックの $\alpha$ は $\alpha = \dfrac{k}{k - 1}\left(1 - \dfrac{\sum_j s_j^2}{s_X^2}\right)$ で、$s_j^2$ は各項目の分散、$s_X^2$ は合計得点の分散です。項目の分散の和は 5.5、合計得点の分散は行列の全成分の和 12.5 なので、$\alpha = \dfrac{5}{4}\left(1 - \dfrac{5.5}{12.5}\right) = 1.25 \times 0.56 = 0.700$ です。

### 計算

項目の分散（対角成分）の和：

$$\sum_{j=1}^{5}s_j^2 = 1.2 + 1.0 + 0.9 + 1.1 + 1.3 = 5.5$$

合計得点の分散は、すべての分散と共分散の和です。共分散（上三角）の和は

$$0.6 + 0.5 + 0.6 + 0.1 + 0.5 + 0.4 + 0.2 + 0.5 + 0.0 + 0.1 = 3.5$$

なので、$s_X^2 = 5.5 + 2 \times 3.5 = 12.5$。

$$\alpha = \frac{5}{5 - 1}\left(1 - \frac{5.5}{12.5}\right) = 1.25 \times 0.56 = 0.700$$

### 別の表し方

共分散の平均を $\bar{c} = 3.5/10 = 0.35$ とすると、$\alpha = \dfrac{k^2\bar{c}}{s_X^2} = \dfrac{25 \times 0.35}{12.5} = 0.700$ とも書けます。$\alpha$ は「項目間の共分散が合計得点の分散に占める割合」を項目数で補正したものです。

### ポイント

- よくある誤り：係数 $k/(k-1)$ を掛け忘れて $0.56$ とする、合計得点の分散を対角成分の和（5.5）や共分散を 1 回だけ足した値（9.0）とする。
- 項目間の共分散がすべて 0 なら $\alpha = 0$、すべての項目が完全に相関し分散が等しければ $\alpha = 1$ になる。
- この尺度では、項目 5 と他の項目との共分散が小さい（0.0〜0.2）。項目分析では、各項目を除いたときの $\alpha$ や項目と残りの合計との相関（I-T 相関）を確認する。
