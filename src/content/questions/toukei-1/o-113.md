modelAnswer: |
  **[1]** $x = \tan\theta$ は $(-\pi/2, \pi/2)$ から $\mathbb{R}$ への単調増加な 1 対 1 写像で、逆変換 $\theta = \arctan x$、$d\theta/dx = 1/(1 + x^2)$。$\Theta$ の密度は $1/\pi$ なので

  $$f(x) = \frac{1}{\pi}\cdot\frac{1}{1 + x^2}\qquad (-\infty < x < \infty)$$

  （標準コーシー分布）。

  **[2]**

  $$E[|X|] = \int_{-\infty}^{\infty}\frac{|x|}{\pi(1 + x^2)}\,dx = \frac{2}{\pi}\lim_{A\to\infty}\int_0^A\frac{x}{1 + x^2}\,dx = \frac{1}{\pi}\lim_{A\to\infty}\log(1 + A^2) = \infty$$

  よって $E[X]$ は（ルベーグ積分の意味で）存在しない。

  **[3]** 独立性より

  $$\phi_{\bar{X}_n}(t) = E\left[e^{i(t/n)\sum X_i}\right] = \left\{\phi\left(\frac{t}{n}\right)\right\}^n = \left(e^{-|t|/n}\right)^n = e^{-|t|}$$

  特性関数は分布を一意に定めるので、$\bar{X}_n$ は $X_1$ と同じ標準コーシー分布に従う。

  **[4]** [3] より $n$ によらず

  $$P(|\bar{X}_n| \leq 1) = P(|X_1| \leq 1) = P\left(-\frac{\pi}{4} \leq \Theta \leq \frac{\pi}{4}\right) = \frac{1}{2}$$

  となり、$n$ を大きくしても $\bar{X}_n$ は特定の定数の近くに集中しない（確率収束しない）。大数の法則（弱法則）は $E[|X_1|] < \infty$ を、中心極限定理は $V[X_1] < \infty$ を仮定しており、[2] よりコーシー分布はどちらの仮定も満たさないので、矛盾しない。

コーシー分布は、期待値が存在しないために大数の法則が成り立たない代表例です。変数変換で密度を導き、特性関数で「標本平均が 1 個の観測と同じ分布になる」ことを示す、確率分布と極限定理をつなぐ問題です。

### 解答の流れ

1. 単調な変換 $x = \tan\theta$ の逆関数の微分を掛けて密度を得る。
2. 期待値の存在は $E[|X|] < \infty$ で判定する。$|x|/(1 + x^2)$ は $1/|x|$ のように減衰するので積分が発散する。
3. 独立な和の特性関数は積になる。$\bar{X}_n$ では $t$ を $t/n$ に置き換える。

### つまずきやすい点

- 「密度が原点について対称なので $E[X] = 0$」とする誤り。$\lim_{A\to\infty}\int_{-A}^{A}$ は 0 になるが（主値）、期待値は $E[X^+]$ と $E[X^-]$ がともに有限のときにしか定義されない。
- 積率母関数 $E[e^{tX}]$ は $t \neq 0$ で存在しないので、特性関数を使う必要がある。
- 特性関数 $e^{-|t|}$ は $t = 0$ で微分できない。これも期待値が存在しないことに対応している。

### ポイント

- 位置 $\mu$、尺度 $\sigma$ のコーシー分布の特性関数は $e^{i\mu t - \sigma|t|}$。独立なコーシー変数の和もコーシー分布に従う（安定分布の一種）。
- $X$ と $Y$ が独立な標準正規分布に従うとき $X/Y$ は標準コーシー分布に従い、これは自由度 1 の $t$ 分布でもある。
- コーシー分布の位置母数の推定には、標本平均ではなく標本中央値（漸近分散 $\pi^2/(4n)$）や最尤推定量（漸近分散 $2/n$）を用いる。
