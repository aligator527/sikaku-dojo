「$X_{(3)} \leq 0.4$」は「5 個のうち少なくとも 3 個が $0.4$ 以下」と同じ事象です。$0.4$ 以下になる個数は二項分布 $\mathrm{Bin}(5,\ 0.4)$ に従うので、$P = \sum_{k=3}^{5}\binom{5}{k}0.4^k0.6^{5-k} = 0.31744$ です。

### 計算

$$P(X_{(3)} \leq 0.4) = \binom{5}{3}0.4^3 \times 0.6^2 + \binom{5}{4}0.4^4 \times 0.6 + 0.4^5$$

$$= 10 \times 0.064 \times 0.36 + 5 \times 0.0256 \times 0.6 + 0.01024 = 0.2304 + 0.0768 + 0.01024 = 0.31744$$

### 別解（密度から）

$X_{(k)}$ の密度は「1 個が $x$ に、$k - 1$ 個が $x$ より下に、$n - k$ 個が上に入る」ことから

$$f_{(k)}(x) = \frac{n!}{(k-1)!\,(n-k)!}x^{k-1}(1-x)^{n-k}$$

で、$X_{(3)} \sim \mathrm{Beta}(3, 3)$、密度 $30x^2(1-x)^2$ です。

$$\int_0^{0.4}30x^2(1-x)^2\,dx = \left[10x^3 - 15x^4 + 6x^5\right]_0^{0.4} = 0.64 - 0.384 + 0.06144 = 0.31744$$

### ポイント

- よくある誤り：「ちょうど 3 個が $0.4$ 以下」の確率 $0.2304$ だけを答える。$X_{(3)} \leq x$ は「$x$ 以下の個数が 3 以上」である。
- 一般に $P(X_{(k)} \leq x) = P(\mathrm{Bin}(n, F(x)) \geq k)$ で、任意の連続分布に使える。ベータ分布の分布関数と二項分布の上側確率の関係として覚えておくとよい。
