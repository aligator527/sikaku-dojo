stem: |
  ある物質の濃度の時間減衰を、非線形回帰モデル

  $$y_i = \theta_1\exp(-\theta_2x_i) + \varepsilon_i\qquad (i = 1, \ldots, n)$$

  で表す。$x_i$ は時刻、$\theta_1 > 0$、$\theta_2 > 0$ は未知母数、$\varepsilon_i$ は互いに独立に $N(0, \sigma^2)$ に従う。$f_i(\boldsymbol{\theta}) = \theta_1\exp(-\theta_2x_i)$ とする。以下の各問に答えよ。

  [1] 残差平方和 $S(\boldsymbol{\theta}) = \sum_i\{y_i - f_i(\boldsymbol{\theta})\}^2$ を最小にする条件（正規方程式）を書き、それが $\boldsymbol{\theta}$ について線形でないことを説明せよ。また、$\theta_2$ を固定したときの $\theta_1$ の最小化は陽に解けることを示せ。

  [2] $f_i(\boldsymbol{\theta})$ を現在の値 $\boldsymbol{\theta}^{(k)}$ のまわりで 1 次近似することにより、ガウス・ニュートン法の更新式を導け。ヤコビ行列 $F$ の成分を具体的に書き、最小二乗推定量の漸近分散共分散行列の推定量を述べよ。

  [3] 両辺の対数をとり $\log y_i$ を $x_i$ に線形回帰して $\log\theta_1$ と $\theta_2$ を推定する方法は、上のモデルの最小二乗推定量と一般に一致しない。その理由を誤差の構造の観点から説明し、どのような誤差の構造なら対数変換が適切か述べよ。

  [4] 推定の結果、$\hat{\theta}_2 = 0.231$（1/時間）、その漸近標準誤差 $0.012$ を得た。半減期 $t_{1/2} = (\log 2)/\theta_2$ の推定値と、デルタ法による標準誤差を求めよ。$\log 2 = 0.6931$ とする。
modelAnswer: |
  **[1]** $\partial f_i/\partial\theta_1 = e^{-\theta_2x_i}$、$\partial f_i/\partial\theta_2 = -\theta_1x_ie^{-\theta_2x_i}$ より、正規方程式は

  $$\sum_{i}\left(y_i - \theta_1e^{-\theta_2x_i}\right)e^{-\theta_2x_i} = 0,\qquad \sum_{i}\left(y_i - \theta_1e^{-\theta_2x_i}\right)\theta_1x_ie^{-\theta_2x_i} = 0$$

  $\theta_2$ が指数関数の中に入っているので、これは $\boldsymbol{\theta}$ の連立 1 次方程式にならず、一般に陽に解けない（反復計算が必要）。

  一方、$\theta_2$ を固定すると $f_i$ は $\theta_1$ について線形なので、第 1 式から

  $$\hat{\theta}_1(\theta_2) = \frac{\sum_i y_ie^{-\theta_2x_i}}{\sum_i e^{-2\theta_2x_i}}$$

  と陽に求まる。これを代入した $S(\hat{\theta}_1(\theta_2), \theta_2)$ を $\theta_2$ の 1 変数関数として最小化すればよい（条件付き線形性の利用）。

  **[2]** $f_i(\boldsymbol{\theta}) \approx f_i(\boldsymbol{\theta}^{(k)}) + \boldsymbol{F}_i^{\top}(\boldsymbol{\theta} - \boldsymbol{\theta}^{(k)})$（$\boldsymbol{F}_i^{\top}$ はヤコビ行列 $F$ の第 $i$ 行）と近似すると、残差平方和は

  $$S(\boldsymbol{\theta}) \approx \left\|\boldsymbol{r}^{(k)} - F\boldsymbol{\delta}\right\|^2,\qquad \boldsymbol{r}^{(k)} = \boldsymbol{y} - \boldsymbol{f}(\boldsymbol{\theta}^{(k)}),\quad \boldsymbol{\delta} = \boldsymbol{\theta} - \boldsymbol{\theta}^{(k)}$$

  となり、$\boldsymbol{\delta}$ についての線形最小二乗問題になる。その解から

  $$\boldsymbol{\theta}^{(k+1)} = \boldsymbol{\theta}^{(k)} + (F^{\top}F)^{-1}F^{\top}\left\{\boldsymbol{y} - \boldsymbol{f}(\boldsymbol{\theta}^{(k)})\right\}$$

  ここで $F$ は $\boldsymbol{\theta}^{(k)}$ で評価した $n \times 2$ 行列で

  $$F_{i1} = e^{-\theta_2x_i},\qquad F_{i2} = -\theta_1x_ie^{-\theta_2x_i}$$

  収束値 $\hat{\boldsymbol{\theta}}$ について、漸近分散共分散行列は線形回帰の $\sigma^2(X^{\top}X)^{-1}$ に対応して

  $$\hat{V}[\hat{\boldsymbol{\theta}}] = \hat{\sigma}^2(\hat{F}^{\top}\hat{F})^{-1},\qquad \hat{\sigma}^2 = \frac{S(\hat{\boldsymbol{\theta}})}{n - 2}$$

  で推定する（$\hat{F}$ は $\hat{\boldsymbol{\theta}}$ で評価したヤコビ行列）。

  **[3]** モデルの誤差は加法的なので

  $$\log y_i = \log\theta_1 - \theta_2x_i + \log\left(1 + \frac{\varepsilon_i}{f_i(\boldsymbol{\theta})}\right)$$

  となり、変換後の誤差項 $\log(1 + \varepsilon_i/f_i)$ は、分散が近似的に $\sigma^2/f_i^2$ で $x_i$ とともに増大し（$f_i$ が減衰するため）、期待値も近似的に $-\sigma^2/(2f_i^2)$ で 0 でない。したがって変換後のモデルは均一分散・平均 0 の仮定を満たさず、対数変換後の最小二乗推定は元のモデルの最小二乗推定と一致しない（濃度の低い後半の点を過大に重視する）。$y_i \leq 0$ となる観測があると変換自体ができない。

  対数変換が適切なのは、誤差が乗法的な $y_i = \theta_1e^{-\theta_2x_i}\eta_i$（$\log\eta_i \sim N(0, \tau^2)$）、すなわち相対誤差が一定の場合である。このとき $\log y_i = \log\theta_1 - \theta_2x_i + \log\eta_i$ は通常の線形回帰モデルになる。加法誤差のモデルでも、対数変換による推定値はガウス・ニュートン法の初期値として有用である。

  **[4]** 推定値は不変性より

  $$\hat{t}_{1/2} = \frac{0.6931}{0.231} = 3.00\ \text{時間}$$

  $g(\theta_2) = (\log 2)/\theta_2$ の導関数は $g'(\theta_2) = -(\log 2)/\theta_2^2$ なので、デルタ法により

  $$\mathrm{SE}(\hat{t}_{1/2}) \approx |g'(\hat{\theta}_2)|\,\mathrm{SE}(\hat{\theta}_2) = \frac{0.6931}{0.231^2} \times 0.012 = \frac{0.6931}{0.05336} \times 0.012 = 0.156\ \text{時間}$$

非線形回帰では、最小二乗推定量が陽に求まらず反復計算が必要になりますが、推測の理論は「ヤコビ行列 $F$ を線形回帰の計画行列 $X$ と見なす」ことで線形回帰と並行に組み立てられます。変数変換で線形化する方法の落とし穴も、典型的な論点です。

### 解答の流れ

1. 偏微分を計算して正規方程式を書く。$\theta_1$ についてだけ見れば線形であることに気づく。
2. テイラー展開の 1 次の項でモデルを線形化し、増分 $\boldsymbol{\delta}$ の最小二乗問題を解く。
3. 変換後の誤差項を書き下し、その平均と分散を近似する（$\log(1 + u) \approx u - u^2/2$）。
4. 関数 $g(\theta_2) = \log 2/\theta_2$ にデルタ法を適用する。

### つまずきやすい点

- ガウス・ニュートン法は初期値が悪いと発散することがある。ステップ幅を調整する方法や、$(F^{\top}F + \lambda I)$ を使うレーベンバーグ・マーカート法が用いられる。
- 非線形回帰の標準誤差は漸近近似であり、曲率が大きい（非線形性が強い）と精度が落ちる。母数の変換（例：$\log\theta_2$）で近似が改善することがある。
- [4] で $\mathrm{SE}(\hat{t}_{1/2}) = (\log 2)/\mathrm{SE}(\hat{\theta}_2)$ のように、関数を標準誤差に直接適用するのは誤り。

### ポイント

- 相対標準誤差で見ると、$\hat{\theta}_2$ は $0.012/0.231 = 5.2\%$、$\hat{t}_{1/2}$ も $0.156/3.00 = 5.2\%$ で等しい。$g(\theta) = c/\theta$ の形では、デルタ法による相対誤差が保存される。
