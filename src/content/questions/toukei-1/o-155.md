$Q = \sum(X_i - \bar{X})^2$ とすると $Q/\sigma^2 \sim \chi^2(n-1)$ で、$E[Q] = (n-1)\sigma^2$、$V[Q] = 2(n-1)\sigma^4$ です。平均二乗誤差は $\sigma^4\{c^2(n^2 - 1) - 2c(n - 1) + 1\}$ となり、$\sigma^4$ を除いた部分は $c$ だけの 2 次関数なので、$\sigma^2$ によらず $c = 1/(n+1)$ で最小になります。

### 計算

$E[Q^2] = V[Q] + E[Q]^2 = \sigma^4\{2(n-1) + (n-1)^2\} = \sigma^4(n-1)(n+1)$ より

$$\mathrm{MSE}(c) = c^2E[Q^2] - 2c\sigma^2E[Q] + \sigma^4 = \sigma^4\left\{c^2(n-1)(n+1) - 2c(n-1) + 1\right\}$$

$c$ で微分して 0 とおくと

$$2c(n-1)(n+1) - 2(n-1) = 0\ \Rightarrow\ c = \frac{1}{n+1}$$

### 各選択肢の検討

- $c = 1/(n+1)$：正しい。わずかな偏りを許して分散を減らすことで、平均二乗誤差が最小になる。
- $c = 1/(n-1)$：不偏推定量 $S^2$。偏りは 0 だが、平均二乗誤差は $2\sigma^4/(n-1)$ で最小ではない。「不偏推定量の中で分散最小」と「平均二乗誤差最小」を混同している。
- $c = 1/n$：最尤推定量。平均二乗誤差は $\dfrac{2n-1}{n^2}\sigma^4$ で、$S^2$ よりは小さいが最小ではない。$V[Q] = (n-1)\sigma^4$（カイ二乗分布の分散を自由度と同じとする誤り）で計算すると、この値が最小点になってしまう。
- $c = 1/(n+2)$：$\mu$ が既知で $\sum(X_i - \mu)^2$（自由度 $n$）を使う場合の最適値。$\bar{X}$ を引くことで自由度が 1 減ることを見落としている。
- $\sigma^2$ に依存する：$\mathrm{MSE}(c)$ は $\sigma^4 \times (c$ の関数$)$ なので、最小点は $\sigma^2$ によらない。

### ポイント

- 平均二乗誤差 = 分散 + 偏りの 2 乗。不偏性は平均二乗誤差の最小化を保証しない。
- 最小値は $\mathrm{MSE}(1/(n+1)) = \dfrac{2\sigma^4}{n+1}$ で、不偏推定量の $\dfrac{2\sigma^4}{n-1}$ と比べると、$n$ が小さいほど改善の割合が大きい。
