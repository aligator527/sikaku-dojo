最尤推定量は $\hat{p} = 1/\bar{X}$ で、1 観測あたりのフィッシャー情報量は $I(p) = \dfrac{1}{p^2(1 - p)}$ です。$\hat{p} = 0.25$ を代入すると、標準誤差は $\sqrt{p^2(1-p)/n} = \sqrt{0.0625 \times 0.75/50} = \sqrt{0.0009375} = 0.0306$ です。

### 計算

対数尤度は $\ell(p) = \left(\sum x_i - n\right)\log(1 - p) + n\log p$ なので

$$\ell'(p) = -\frac{\sum x_i - n}{1 - p} + \frac{n}{p} = 0\ \Rightarrow\ \hat{p} = \frac{n}{\sum x_i} = \frac{1}{\bar{X}} = 0.25$$

1 観測の対数確率の 2 階微分は $-\dfrac{k - 1}{(1 - p)^2} - \dfrac{1}{p^2}$ で、$E[X - 1] = (1 - p)/p$ より

$$I(p) = \frac{1 - p}{p(1 - p)^2} + \frac{1}{p^2} = \frac{1}{p(1 - p)} + \frac{1}{p^2} = \frac{1}{p^2(1 - p)}$$

$$\sqrt{\frac{1}{nI(\hat{p})}} = \sqrt{\frac{\hat{p}^2(1 - \hat{p})}{n}} = \sqrt{\frac{0.0625 \times 0.75}{50}} = \sqrt{0.0009375} = 0.03062$$

### ポイント

- デルタ法でも同じ結果になる：$V[X] = (1 - p)/p^2$、$g(x) = 1/x$、$g'(1/p) = -p^2$ より、$\hat{p} = 1/\bar{X}$ の漸近分散は $p^4 \cdot (1 - p)/(p^2n) = p^2(1 - p)/n$。
- よくある誤り：二項分布の公式 $\sqrt{\hat{p}(1 - \hat{p})/n} = 0.0612$ を流用する。幾何分布では 1 観測あたりの情報の量が異なる。
- $\hat{p} = 1/\bar{X}$ は不偏ではない（イェンセンの不等式より $E[1/\bar{X}] > 1/E[\bar{X}] = p$）。漸近標準誤差は大標本での近似であり、$n = 50$ では実際のばらつき（シミュレーションで約 0.031）とよく合う。
