  ある商品分野には 3 つのブランド A、B、C があり、消費者は毎週 1 つのブランドを購入する。第 $t$ 週に購入するブランドを $X_t$ とし、$\{X_t\}$ は推移確率行列

  $$P = \begin{pmatrix} 0.5 & 0.4 & 0.1 \\ 0.2 & 0.6 & 0.2 \\ 0.1 & 0.4 & 0.5 \end{pmatrix}$$

  をもつ斉時マルコフ連鎖であるとする（行・列の順に A、B、C。$(i, j)$ 成分は $P(X_{t+1} = j \mid X_t = i)$）。以下の各問に答えよ。

  [1] 第 0 週の購入者の割合が A、B、C の順に $(0.5,\ 0.3,\ 0.2)$ のとき、第 1 週と第 2 週の割合を求めよ。また、$P(X_2 = \mathrm{C} \mid X_0 = \mathrm{A})$ を求めよ。

  [2] 定常分布 $\boldsymbol{\pi}$ を求めよ。また、初期分布によらず $X_t$ の分布が $\boldsymbol{\pi}$ に収束する理由を述べよ。

  [3] A を購入した消費者が、次に再び A を購入するまでの平均週数（平均再帰時間）を求めよ。また、A を購入した消費者が初めて C を購入するまでの平均週数を求めよ。

  [4] この連鎖が詳細つり合い条件 $\pi_ip_{ij} = \pi_jp_{ji}$ を満たすか調べ、その意味を述べよ。
modelAnswer: |
  **[1]** 分布は行ベクトルに右から $P$ を掛けて更新する。

  $$(0.5,\ 0.3,\ 0.2)P = (0.25 + 0.06 + 0.02,\ 0.20 + 0.18 + 0.08,\ 0.05 + 0.06 + 0.10) = (0.33,\ 0.46,\ 0.21)$$

  $$(0.33,\ 0.46,\ 0.21)P = (0.278,\ 0.492,\ 0.230)$$

  2 段階の推移確率はチャップマン・コルモゴロフの式より $P^2$ の成分で

  $$P(X_2 = \mathrm{C} \mid X_0 = \mathrm{A}) = \sum_kp_{\mathrm{A}k}p_{k\mathrm{C}} = 0.5 \times 0.1 + 0.4 \times 0.2 + 0.1 \times 0.5 = 0.18$$

  **[2]** $\boldsymbol{\pi}P = \boldsymbol{\pi}$、$\pi_1 + \pi_2 + \pi_3 = 1$ を解く。第 1 列と第 3 列の式は

  $$\pi_1 = 0.5\pi_1 + 0.2\pi_2 + 0.1\pi_3,\qquad \pi_3 = 0.1\pi_1 + 0.2\pi_2 + 0.5\pi_3$$

  辺々引くと $\pi_1 - \pi_3 = 0.4(\pi_1 - \pi_3)$ より $\pi_1 = \pi_3$。第 1 式に代入して $0.4\pi_1 = 0.2\pi_2$、$\pi_2 = 2\pi_1$。よって

  $$\boldsymbol{\pi} = \left(\frac{1}{4},\ \frac{1}{2},\ \frac{1}{4}\right)$$

  すべての成分が正なので任意の状態から任意の状態へ 1 段階で移れ（既約）、$p_{ii} > 0$ なので周期は 1（非周期的）である。状態数が有限で既約かつ非周期的なマルコフ連鎖は定常分布がただ一つ存在し、任意の初期分布について $X_t$ の分布は $\boldsymbol{\pi}$ に収束する（エルゴード定理）。

  **[3]** 既約で正再帰な連鎖では平均再帰時間は $1/\pi_i$ なので、A の平均再帰時間は $1/\pi_1 = 4$ 週。

  初めて C に到達するまでの平均時間を $m_i$（$i$ = A、B から出発）とすると、1 段階目で場合分けして

  $$m_{\mathrm{A}} = 1 + 0.5m_{\mathrm{A}} + 0.4m_{\mathrm{B}},\qquad m_{\mathrm{B}} = 1 + 0.2m_{\mathrm{A}} + 0.6m_{\mathrm{B}}$$

  第 2 式より $m_{\mathrm{B}} = 2.5 + 0.5m_{\mathrm{A}}$。第 1 式に代入すると $0.5m_{\mathrm{A}} = 2 + 0.2m_{\mathrm{A}}$、よって $m_{\mathrm{A}} = 20/3 \approx 6.67$ 週（$m_{\mathrm{B}} = 35/6$）。

  **[4]** 

  $$\pi_1p_{12} = \frac{1}{4} \times 0.4 = 0.1 = \frac{1}{2} \times 0.2 = \pi_2p_{21},\quad \pi_1p_{13} = 0.025 = \pi_3p_{31},\quad \pi_2p_{23} = 0.1 = \pi_3p_{32}$$

  より、すべての組で詳細つり合い条件が成り立つ。したがってこの連鎖は可逆であり、定常状態では「$i$ から $j$ への流れ」と「$j$ から $i$ への流れ」が組ごとにつり合っている。時間を逆向きにたどった過程も同じ推移確率をもつマルコフ連鎖になり、ブランド間の乗り換えに一方向の循環（A → B → C → A のような偏った流れ）がないことを意味する。

マルコフ連鎖の基本である、分布の時間発展・定常分布・平均再帰時間・初到達時間・可逆性を一つの推移確率行列で確認する問題です。

### 解答の流れ

1. 分布は行ベクトル × 推移確率行列で更新する。$n$ 段階の推移確率は $P^n$ の成分。
2. 定常分布は $\boldsymbol{\pi}P = \boldsymbol{\pi}$ の解。有限・既約・非周期なら唯一で、極限分布になる。
3. 平均再帰時間は $1/\pi_i$。初到達時間の期待値は「1 段階目で条件付ける」連立方程式で求める（目的の状態では 0 とおく）。
4. 詳細つり合い条件は定常分布の十分条件であり、成り立てば可逆な連鎖である。

### つまずきやすい点

- $P$ を左から掛けて $P\boldsymbol{p}^\top$ とする誤り。この問題の $P$ は行和が 1 なので、分布は左から掛ける行ベクトルとして扱う。
- 初到達時間の連立方程式に C から出発する式を含めてしまう誤り。C に着いた時点で終わるので $m_{\mathrm{C}} = 0$ とする。C の平均再帰時間（$1 + 0.1m_{\mathrm{A}} + 0.4m_{\mathrm{B}} = 4 = 1/\pi_3$）と混同しない。

### ポイント

- 長期的な市場占有率は定常分布 $(25\%,\ 50\%,\ 25\%)$ で、現在の割合 $(50\%,\ 30\%,\ 20\%)$ にはよらない。
- $P$ の固有値は $1,\ 0.4,\ 0.2$ で、定常分布への収束の速さは 2 番目に大きい固有値の絶対値 0.4 で決まる（誤差は毎週およそ 0.4 倍に縮む）。
