  処置の有無を $T \in \{0, 1\}$、結果変数を $Y$、処置前に測定された共変量を $X$ とする。各個体には処置を受けた場合と受けなかった場合の潜在的な結果 $Y(1),\ Y(0)$ があり、観測されるのは $Y = TY(1) + (1 - T)Y(0)$ である。平均処置効果を $\tau = E[Y(1) - Y(0)]$ とする。以下の各問に答えよ。

  [1] 処置が無作為に割り付けられ、$T$ が $(Y(1), Y(0))$ と独立であるとき、$E[Y \mid T = 1] - E[Y \mid T = 0] = \tau$ となることを示せ。

  (b) $E\left[\dfrac{TY}{e(X)}\right] = E[Y(1)]$。

modelAnswer: |
  **[1]** $T = 1$ のとき $Y = Y(1)$ なので $E[Y \mid T = 1] = E[Y(1) \mid T = 1]$。独立性より $E[Y(1) \mid T = 1] = E[Y(1)]$。同様に $E[Y \mid T = 0] = E[Y(0)]$。よって

  $$E[Y \mid T = 1] - E[Y \mid T = 0] = E[Y(1)] - E[Y(0)] = \tau$$

  **[2]** (a) $T$ は 2 値なので、条件付き分布は $P(T = 1 \mid \cdot)$ で決まる。$e(X)$ は $X$ の関数なので、繰り返し期待値の性質より

  $$P(T = 1 \mid e(X)) = E\left[P(T = 1 \mid X) \mid e(X)\right] = E[e(X) \mid e(X)] = e(X) = P(T = 1 \mid X, e(X))$$

  したがって $e(X)$ を与えたとき、$T$ の分布はさらに $X$ を与えても変わらず、$T$ と $X$ は $e(X)$ を与えたとき条件付き独立である。すなわち、傾向スコアが等しい個体の間では、処置群と対照群で $X$ の分布がそろう。

  (b) $TY = TY(1)$ なので、$X$ で条件付けて

  $$E\left[\frac{TY}{e(X)}\right] = E\left[\frac{E[T \cdot Y(1) \mid X]}{e(X)}\right] = E\left[\frac{E[T \mid X]\,E[Y(1) \mid X]}{e(X)}\right] = E\big[E[Y(1) \mid X]\big] = E[Y(1)]$$

  2 つ目の等号で条件付き独立性を、3 つ目で $E[T \mid X] = e(X) > 0$ を用いた。

  **[3]** 平均処置効果は、条件付き効果を $X$ の分布で平均して

  $$\tau = 0.4 \times (50 - 40) + 0.6 \times (80 - 75) = 4 + 3 = 7$$

  単純な群間差：$P(T = 1) = 0.4 \times 0.8 + 0.6 \times 0.2 = 0.44$ で、処置群に占める重症者の割合は $0.32/0.44 = 0.727$、対照群では $0.08/0.56 = 0.143$。

  $$E[Y \mid T = 1] = 0.727 \times 50 + 0.273 \times 80 = 58.18,\qquad E[Y \mid T = 0] = 0.143 \times 40 + 0.857 \times 75 = 70.00$$

  差は $58.18 - 70.00 = -11.82$ で、処置は有害であるかのように見える。

  重症度 $X$ は処置の受けやすさ（重症者ほど処置される）と結果（重症者ほど結果が悪い）の両方に関係する交絡因子である。処置群には予後の悪い重症者が多く含まれるため、単純な群間差は処置効果と重症度の違いを混同し、符号まで逆転している。$X$ で層別して比べるか、傾向スコアによる重み付け（[2] (b)）で調整すれば、$\tau = 7$ を正しく推定できる。

観察研究で因果効果を推定する際の基本的な枠組み（潜在的結果モデル）の問題です。無作為化は処置と潜在的結果の独立性を保証するので、単純な群間差が平均処置効果になります。観察研究では、測定された共変量で条件付けたときの独立性（強く無視できる割り付け）を仮定し、傾向スコアで共変量の分布をそろえて調整します。

### 解答の流れ

1. 観測される $Y$ を潜在的結果で書き換え、独立性で条件を外す。
2. (a) 傾向スコアは $X$ の関数なので、$P(T = 1 \mid e(X))$ を $X$ で条件付けて計算する。(b) $X$ で条件付けて、条件付き独立性で期待値を分解する。
3. 層別に計算した効果を母集団の $X$ の分布で平均したものが $\tau$。群間差は、群ごとに異なる $X$ の分布で平均している。

### つまずきやすい点

- 強く無視できる割り付けは、観測データだけからは検証できない仮定です。測定されていない交絡因子があると、傾向スコアで調整しても偏りが残ります。
- [3] で層別の効果を処置群の $X$ の分布（$0.727 : 0.273$）で平均すると $0.727 \times 10 + 0.273 \times 5 = 8.64$ となり、これは処置群における平均処置効果（ATT）です。母集団全体の平均処置効果 $\tau = 7$ とは異なります。
- 傾向スコアが 0 や 1 に近い個体があると、逆確率重み付け推定量の分散が非常に大きくなります（正値性の条件の実質的な破れ）。

### ポイント

- 交絡の調整に使う共変量は処置より前に測定されたものに限ります。処置の結果として変わる中間変数で調整すると、効果の一部を取り除いてしまいます。
- 傾向スコアの使い方には、マッチング・層別・重み付け・共変量としての回帰調整があります。いずれもバランシング性が根拠です。
