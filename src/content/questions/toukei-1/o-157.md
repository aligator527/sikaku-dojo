正規分布の平均に正規事前分布を置くと、事後分布も正規分布になります。事後の精度（分散の逆数）は「事前の精度 + データの精度」$= 1 + 16/4 = 5$、事後平均は精度で重み付けた平均 $(1 \times 0 + 4 \times 1.0)/5 = 0.8$ です。上限は $0.8 + 1.96\sqrt{1/5} = 0.8 + 0.8765 = 1.677$ です。

### 計算

$\bar{X} \mid \mu \sim N(\mu,\ 4/16) = N(\mu,\ 0.25)$ で、データの精度は $1/0.25 = 4$ です。事後密度は

$$\pi(\mu \mid \bar{x}) \propto \exp\left(-\frac{\mu^2}{2}\right)\exp\left\{-\frac{(\bar{x} - \mu)^2}{2 \times 0.25}\right\} \propto \exp\left\{-\frac{5}{2}\left(\mu - \frac{4\bar{x}}{5}\right)^2\right\}$$

なので、$\mu \mid \bar{x} \sim N(0.8,\ 0.2)$ です。

$$\text{上限} = 0.8 + 1.96\sqrt{0.2} = 0.8 + 1.96 \times 0.4472 = 0.8 + 0.8765 = 1.6765 \approx 1.677$$

（下限は $0.8 - 0.8765 = -0.077$。）

### ポイント

- 事後平均 $0.8$ は標本平均 $1.0$ を事前平均 $0$ の方向へ縮小した値で、縮小の重みは精度の比（事前 1 : データ 4）で決まる。
- 頻度論の 95% 信頼区間 $\bar{x} \pm 1.96 \times 0.5 = [0.02,\ 1.98]$ と比べ、信用区間は事前情報の分だけ狭く、中心も 0 寄りになる。$n \to \infty$ では両者は一致する。
- よくある誤り：事後分散を $1/(1 + 16) $ や $4/16 + 1$ とする。精度（分散の逆数）を足すのが正しい。また、事後平均を $\bar{x} = 1.0$ のままにして上限を $1.0 + 0.8765 = 1.877$ とする。
