  ある政策への意見を、都市部と郡部の住民それぞれ 100 人に尋ね、次の分割表を得た。

  | | 賛成 | 反対 | わからない | 計 |
  | --- | --- | --- | --- | --- |
  | 都市部 | 30 | 50 | 20 | 100 |
  | 郡部 | 50 | 30 | 20 | 100 |
  | 計 | 80 | 80 | 40 | 200 |

  度数を $n_{ij}$、総数を $n$ とし、対応行列 $P = (p_{ij}) = (n_{ij}/n)$、行の周辺比率（行質量）$r_i = \sum_jp_{ij}$、列の周辺比率（列質量）$c_j = \sum_ip_{ij}$ とする。対応分析では、標準化残差行列

  $$S = (s_{ij}),\qquad s_{ij} = \frac{p_{ij} - r_ic_j}{\sqrt{r_ic_j}}$$

  の特異値分解を用いる。以下の各問に答えよ。

  [1] 総慣性 $\sum_{i,j}s_{ij}^2$ が、独立性の検定のピアソンのカイ二乗統計量 $\chi^2$ を用いて $\chi^2/n$ と表せることを示せ。

  [2] この表の $\chi^2$ と総慣性を求め、独立性を有意水準 5% で検定せよ。$\chi^2_{0.05}(2) = 5.991$ とする。

  [3] 行が 2 つの表では $S$ の階数が 1 になること（意味のある次元が 1 つしかないこと）を示せ。さらに、列の主座標が（符号を除いて）$g_j = \dfrac{p_{1|j} - r_1}{\sqrt{r_1r_2}}$（$p_{1|j} = p_{1j}/c_j$ は列 $j$ の中での第 1 行の割合）となることを用いて、3 つの列の主座標を求め、$\sum_jc_jg_j^2$ が総慣性に一致することを確かめよ。

  [4] 行の主座標 $f_i$ は、列の主座標の加重平均を特異値 $\sigma$ で割った $f_i = \dfrac{1}{\sigma}\sum_jp_{j|i}\,g_j$（$p_{j|i} = p_{ij}/r_i$）で与えられる（推移公式）。都市部と郡部の主座標を求め、対応分析の布置からこの表をどう解釈できるか述べよ。$\sqrt{0.05} = 0.2236$ とする。
modelAnswer: |
  **[1]** 独立のもとでの期待度数は $E_{ij} = nr_ic_j$ である。$p_{ij} - r_ic_j = (n_{ij} - E_{ij})/n$、$r_ic_j = E_{ij}/n$ なので

  $$\sum_{i,j}s_{ij}^2 = \sum_{i,j}\frac{(n_{ij} - E_{ij})^2/n^2}{E_{ij}/n} = \frac{1}{n}\sum_{i,j}\frac{(n_{ij} - E_{ij})^2}{E_{ij}} = \frac{\chi^2}{n}$$

  **[2]** 期待度数はどちらの行も $(40,\ 40,\ 20)$ なので

  $$\chi^2 = \frac{(30 - 40)^2}{40} + \frac{(50 - 40)^2}{40} + 0 + \frac{(50 - 40)^2}{40} + \frac{(30 - 40)^2}{40} + 0 = 4 \times 2.5 = 10.0$$

  総慣性は $10.0/200 = 0.05$。自由度 $(2 - 1)(3 - 1) = 2$ で $10.0 > 5.991$ なので、独立性の仮説は棄却され、地域と意見には関連がある。

  **[3]** 列和の条件 $p_{1j} + p_{2j} = c_j$ と $r_1 + r_2 = 1$ より

  $$p_{2j} - r_2c_j = c_j - p_{1j} - (1 - r_1)c_j = -(p_{1j} - r_1c_j)$$

  なので $s_{2j} = -\sqrt{r_1/r_2}\,s_{1j}$ がすべての $j$ で成り立ち、$S$ の 2 つの行は比例する。よって $S$ の階数は 1 で、非零の特異値は 1 つ（$\sigma^2 = $ 総慣性 $= 0.05$）だけである。一般に意味のある次元の数は $\min(I, J) - 1$ である。

  $r_1 = r_2 = 0.5$、$p_{1|j} = 30/80,\ 50/80,\ 20/40 = 0.375,\ 0.625,\ 0.5$ なので

  $$g_{\text{賛成}} = \frac{0.375 - 0.5}{0.5} = -0.25,\qquad g_{\text{反対}} = \frac{0.625 - 0.5}{0.5} = 0.25,\qquad g_{\text{わからない}} = 0$$

  $$\sum_jc_jg_j^2 = 0.4 \times 0.0625 + 0.4 \times 0.0625 + 0.2 \times 0 = 0.05$$

  で、総慣性（主慣性）に一致する。

  **[4]** $\sigma = \sqrt{0.05} = 0.2236$。

  $$f_{\text{都市部}} = \frac{0.3 \times (-0.25) + 0.5 \times 0.25 + 0.2 \times 0}{0.2236} = \frac{0.05}{0.2236} = 0.2236,\qquad f_{\text{郡部}} = \frac{0.5 \times (-0.25) + 0.3 \times 0.25}{0.2236} = -0.2236$$

  （確認：$\sum_ir_if_i^2 = 0.5 \times 0.05 \times 2 = 0.05$。）1 次元の布置では、都市部（$+0.224$）と「反対」（$+0.25$）が同じ側に、郡部（$-0.224$）と「賛成」（$-0.25$）が反対側に、「わからない」（0）が原点に置かれる。都市部は反対が、郡部は賛成が相対的に多く、「わからない」の割合は両地域で同じ（20%）で地域を区別しない、と読める。行と列の座標が近いことは、その行でその列の比率が平均より高いことを意味する。

対応分析の基本である標準化残差行列、総慣性とカイ二乗統計量の関係、次元の数、主座標と推移公式を、手計算できる 2×3 表で確認する問題です。

### 解答の流れ

1. 総慣性は、独立からのずれを表すピアソンのカイ二乗統計量を総数で割ったもの。
2. 期待度数との差からカイ二乗統計量を計算する。
3. 行が 2 つしかないと、第 2 行の残差は第 1 行の残差の定数倍になり、次元は 1 つだけになる。
4. 推移公式（行の座標は列の座標の加重平均を $\sigma$ で割ったもの）は、数量化 III 類の交互平均法と同じ考え方である。

### つまずきやすい点

- 総慣性を $\chi^2$ そのもの、あるいは $\chi^2/\{n(\min(I, J) - 1)\}$（クラメールの連関係数の 2 乗）と混同しない。$\chi^2/n$ は $\phi^2$ 係数とも呼ばれる。
- 主座標と標準座標の区別：標準座標は主座標を $\sigma$ で割ったもの（ここでは列が $\pm 1.118,\ 0$）で、$\sum_jc_j\gamma_j^2 = 1$ となるように基準化されている。推移公式は「一方の標準座標の加重平均が他方の主座標」とも書ける。

### ポイント

- 次元 $k$ の主慣性 $\sigma_k^2$ を総慣性で割った値が、その次元の寄与率である。この例は 1 次元で総慣性の 100% を説明する。
- 対応分析は、分割表の行と列を同じ空間に布置してカテゴリー間の関連を視覚化する方法で、多重対応分析は数量化 III 類と同等である。
