$2^2$ 要因計画では、交互作用の対比は「(A, B が同符号の条件の合計) − (異符号の条件の合計)」で、$(118 + 64) - (87 + 78) = 17$ です。平方和は $17^2/(4 \times 3) = 24.08$（自由度 1）、誤差平方和は各条件内の偏差平方和の合計 $23.33$（自由度 8）なので、$F = 24.08/(23.33/8) = 8.26$ です。

### 計算

交互作用の平方和（対比の 2 乗を「条件数 × 繰返し数」で割る）：

$$S_{AB} = \frac{(118 - 87 - 78 + 64)^2}{4 \times 3} = \frac{17^2}{12} = 24.083$$

誤差平方和は、各条件の平均 $21.33,\ 29,\ 26,\ 39.33$ からの偏差平方和の合計で

$$S_E = 4.667 + 6 + 8 + 4.667 = 23.333,\qquad V_E = \frac{23.333}{4(3 - 1)} = 2.917$$

$$F_{AB} = \frac{S_{AB}/1}{V_E} = \frac{24.083}{2.917} = 8.26$$

参考までに、主効果の平方和は $S_A = (87 + 118 - 64 - 78)^2/12 = 63^2/12 = 330.75$、$S_B = (78 + 118 - 64 - 87)^2/12 = 45^2/12 = 168.75$ です。$F(1, 8)$ の上側 5% 点 $5.318$ と比べると、交互作用も 5% 水準で有意です。

### ポイント

- 交互作用は「A の効果が B の水準によって異なること」。B が低水準のとき A の効果は $(87 - 64)/3 = 7.67$、高水準のとき $(118 - 78)/3 = 13.33$ で、その差の半分 $2.83$ が交互作用の効果（$17/6$）にあたる。
- よくある誤り：平方和を対比の 2 乗を 4 で割って $72.25$ とする（繰返し数 3 を忘れる）、誤差の自由度を $12 - 1 = 11$ や $12 - 3 = 9$ とする（正しくは $12 - 4 = 8$）。
- 交互作用が有意なときは、主効果だけで最適条件を決めず、A と B の組合せごとの平均で判断する。
