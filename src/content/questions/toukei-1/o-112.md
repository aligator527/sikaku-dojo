  非負整数値をとる確率変数 $X$ の確率母関数が

  $$G(s) = E\left[s^X\right] = \frac{s^2}{(2 - s)^2}\qquad (|s| < 2)$$

  で与えられている。$X$ の分散 $V[X]$ として正しいものを、次のうちから一つ選べ。
choices:
  - '$2$'
  - '$4$'
  - '$12$'
  - '$16$'
  - '$20$'
answer: 2

確率母関数の微分係数は階乗モーメントを与えます：$G'(1) = E[X]$、$G''(1) = E[X(X-1)]$。したがって $V[X] = G''(1) + G'(1) - \{G'(1)\}^2$ で、$G'(1) = 4$、$G''(1) = 16$ より $V[X] = 16 + 4 - 16 = 4$ です。

### 計算

$G(s) = s^2(2 - s)^{-2}$ を微分すると

$$G'(s) = 2s(2 - s)^{-2} + 2s^2(2 - s)^{-3},\qquad G'(1) = 2 + 2 = 4$$

$$G''(s) = 2(2 - s)^{-2} + 8s(2 - s)^{-3} + 6s^2(2 - s)^{-4},\qquad G''(1) = 2 + 8 + 6 = 16$$

$$V[X] = E[X(X-1)] + E[X] - E[X]^2 = 16 + 4 - 16 = 4$$

### 別解（分布の同定）

$\dfrac{1}{2 - s} = \dfrac{1/2}{1 - s/2}$ は $P(Y = k) = (1/2)^{k+1}\ (k = 0, 1, \ldots)$ の幾何分布（平均 1、分散 $q/p^2 = 2$）の確率母関数です。よって $X = 2 + Y_1 + Y_2$（$Y_1, Y_2$ は独立な幾何分布）と表せ、$E[X] = 4$、$V[X] = 2 + 2 = 4$ となります。

### 各選択肢の検討

- $2$：幾何分布 1 個分の分散。$G$ が 2 乗の形であること（2 個の和）を見落としている。
- $4$：正しい。
- $12$：$G''(1) - G'(1) = 16 - 4$ とした誤り。$E[X(X-1)] = E[X^2] - E[X]$ なので、$E[X]$ は引くのではなく足す。
- $16$：$G''(1)$ を $E[X^2]$ あるいは分散そのものと誤解している。
- $20$：$G''(1) + G'(1) = E[X^2]$ で止め、$E[X]^2$ を引き忘れている。

### ポイント

- 確率母関数では $G^{(k)}(1) = E[X(X-1)\cdots(X-k+1)]$（$k$ 次の階乗モーメント）、$G^{(k)}(0)/k! = P(X = k)$。ここでは $P(X = 2) = G''(0)/2 = 1/4$。
- 積率母関数 $M(t) = G(e^t)$ を使えば $V[X] = M''(0) - M'(0)^2$ と通常の公式になる。両者の公式を混同しないこと。
