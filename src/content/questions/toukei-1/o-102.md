$U_2$ の値で条件付けると $P(Z \leq z) = \int_0^1 P(U_1 \leq z/u)\,du$ となり、分布関数は $F_Z(z) = z - z\log z$（$0 < z < 1$）です。$z = 1/4$ を代入すると $\frac{1}{4}(1 + \log 4) = \frac{1}{4}(1 + 1.3862) \approx 0.597$ です。

### 計算

$U_2 = u$ を与えたとき $P(U_1 \leq z/u) = \min(1,\ z/u)$ なので

$$F_Z(z) = \int_0^z 1\,du + \int_z^1 \frac{z}{u}\,du = z + z(\log 1 - \log z) = z - z\log z$$

微分すると密度は $f_Z(z) = -\log z$（$0 < z < 1$）です。$z = 1/4$ では

$$F_Z\left(\tfrac{1}{4}\right) = \frac{1}{4} - \frac{1}{4}\log\frac{1}{4} = \frac{1}{4}(1 + 2\log 2) = \frac{1}{4}(1 + 1.3862) = 0.59655 \approx 0.597$$

### 別解（変数変換）

$(U_1, U_2) \mapsto (Z, W) = (U_1U_2,\ U_2)$ と変換すると、逆変換 $u_1 = z/w,\ u_2 = w$ のヤコビアンの絶対値は $1/w$、定義域は $0 < z < w < 1$ です。よって $f_Z(z) = \int_z^1 \frac{1}{w}\,dw = -\log z$ となり、同じ結果になります。

### ポイント

- よくある誤り：$\min(1, z/u)$ の場合分けを忘れて $\int_0^1 \frac{z}{u}\,du$（発散）としたり、$\int_z^1 \frac{z}{u}\,du = \frac{1}{4}\log 4 \approx 0.347$ だけを答えたりする。$u \leq z$ の範囲では確率は 1 である。
- 積 $Z$ は 0 の近くに集まる（密度 $-\log z$ は $z \to 0$ で発散する）。$-\log Z = (-\log U_1) + (-\log U_2)$ は独立な指数分布の和なので $Ga(2, 1)$ に従う、という見方でも $P(Z \leq z) = P(-\log Z \geq -\log z)$ から同じ結果が得られる。
