  大きさ $N$ の有限母集団の各単位に、補助変数 $x_i > 0$ と調査変数 $y_i$ が対応している。補助変数の母平均 $\bar{X}$ は既知とする。大きさ $n$ の非復元単純無作為抽出による標本平均を $\bar{x},\ \bar{y}$ とし、$\bar{Y}$ の比推定量を

  $$\bar{y}_R = \frac{\bar{y}}{\bar{x}}\bar{X}$$

  とする。$R = \bar{Y}/\bar{X}$、$f = n/N$ とし、$S_x^2,\ S_y^2,\ S_{xy}$ を母集団の分散・共分散（除数 $N - 1$）、$C_x = S_x/\bar{X}$、$C_y = S_y/\bar{Y}$ を変動係数、$\rho = S_{xy}/(S_xS_y)$ とする。以下の各問に答えよ。

  [1] $\bar{y}_R - \bar{Y} = \dfrac{\bar{X}}{\bar{x}}(\bar{y} - R\bar{x})$ を示し、$\bar{x}$ を $\bar{X}$ で近似する 1 次の近似（線形化）により、$\bar{y}_R$ の分散が近似的に

  $$V[\bar{y}_R] \approx \frac{1 - f}{n}\left(S_y^2 - 2RS_{xy} + R^2S_x^2\right)$$

  となることを示せ。

  [2] 2 次の項まで考えると、$\bar{y}_R$ の偏りは近似的に $\dfrac{1 - f}{n}\cdot\dfrac{RS_x^2 - S_{xy}}{\bar{X}}$ となる。この結果から、偏りが分散に比べて無視できる理由を述べよ。

modelAnswer: |
  **[1]** $\bar{y}_R - \bar{Y} = \dfrac{\bar{y}\bar{X}}{\bar{x}} - R\bar{X} = \dfrac{\bar{X}}{\bar{x}}(\bar{y} - R\bar{x})$。$\bar{x} \approx \bar{X}$ とすると $\bar{y}_R - \bar{Y} \approx \bar{y} - R\bar{x}$ で、これは $d_i = y_i - Rx_i$ の標本平均である。$d_i$ の母平均は $\bar{Y} - R\bar{X} = 0$、母分散は

  $$S_d^2 = \frac{1}{N - 1}\sum_i(y_i - Rx_i)^2 = S_y^2 - 2RS_{xy} + R^2S_x^2$$

  なので、非復元単純無作為抽出の標本平均の分散の公式から

  $$V[\bar{y}_R] \approx E[(\bar{y} - R\bar{x})^2] = \frac{1 - f}{n}S_d^2 = \frac{1 - f}{n}\left(S_y^2 - 2RS_{xy} + R^2S_x^2\right)$$

  **[2]** 偏りは $\dfrac{1 - f}{n}$ のオーダー、すなわち $O(1/n)$ である。一方、分散も $O(1/n)$ なので標準誤差は $O(1/\sqrt{n})$。偏りの標準誤差に対する比は $O(1/\sqrt{n})$ で、$n$ が大きければ平均二乗誤差 $= $ 分散 $+$（偏り）$^2$ に占める偏りの寄与は $O(1/n^2)$ となり、分散の $O(1/n)$ に比べて無視できる。また $S_{xy} = RS_x^2$（$y$ が $x$ に原点を通る直線で比例する傾向が強い場合など）なら偏りの主要項は 0 になる。

  **[3]** $V[\bar{y}] = \dfrac{1 - f}{n}S_y^2$ なので

  $$V[\bar{y}_R] < V[\bar{y}] \iff R^2S_x^2 - 2RS_{xy} < 0 \iff 2RS_{xy} > R^2S_x^2$$

  $R > 0$ のとき両辺を $2RS_xS_y$ で割り、$R = \bar{Y}/\bar{X}$ を用いると

  $$\rho > \frac{RS_x}{2S_y} = \frac{S_x/\bar{X}}{2S_y/\bar{Y}} = \frac{C_x}{2C_y}$$

  **[4]** $\hat{R} = \bar{y}/\bar{x} = 90/45 = 2.0$ より $\bar{y}_R = 2.0 \times 50 = 100$（kg）。分散の推定値は

  $$\hat{V}[\bar{y}_R] = \frac{1 - 0.1}{20}\left(32^2 - 2 \times 2.0 \times 420 + 2.0^2 \times 15^2\right) = 0.045 \times (1024 - 1680 + 900) = 0.045 \times 244 = 10.98$$

  標準誤差は $\sqrt{10.98} = 3.31$。単純な標本平均の標準誤差は $\sqrt{0.045 \times 1024} = \sqrt{46.08} = 6.79$ で、比推定量の分散は約 $1/4.2$ になる。実際、$r = 420/(15 \times 32) = 0.875$、$\hat{C}_x/(2\hat{C}_y) = (15/45)/(2 \times 32/90) = 0.469$ で、[3] の条件を満たしている。

比推定量は、調査変数 $y$ と強く比例する補助変数 $x$ の母平均が分かっているときに、標本での $x$ の「偶然の偏り」を補正して精度を上げる推定量です。線形化（デルタ法）により、分散は残差 $y_i - Rx_i$ の分散で決まることが分かり、$y$ と $x$ の相関が十分に高いときに標本平均より有利になります。

### 解答の流れ

1. 比推定量の誤差を、分母の $\bar{x}$ を $\bar{X}$ で近似して、線形な統計量 $\bar{y} - R\bar{x}$ の平均に帰着させる。
2. 偏りと標準誤差のオーダーを比べる。
3. 2 つの分散の差をとり、相関係数と変動係数で書き直す。
4. 標本の分散・共分散を代入して標準誤差を推定する。

### つまずきやすい点

- 比推定量は不偏ではありません（$E[\bar{y}/\bar{x}] \neq \bar{Y}/\bar{X}$）。偏りは $O(1/n)$ で、小標本や $\bar{x}$ の変動が大きい場合には注意が必要です。
- 条件 $\rho > C_x/(2C_y)$ は「相関が正であればよい」という意味ではありません。$C_x = C_y$ なら $\rho > 0.5$ が必要です。
- [4] の分散の推定で、$R$ にも推定値 $\hat{R}$ を代入します。$\bar{X} = 50$ と $\bar{x} = 45$ のずれを分散の式に入れる必要はありません（1 次の近似の範囲）。

### ポイント

- $y$ が $x$ に比例する（原点を通る回帰直線のまわりで、分散が $x$ に比例する）モデルのもとでは、比推定量は最良線形不偏推定量になります。
- 原点を通らない関係では、回帰推定量 $\bar{y} + b(\bar{X} - \bar{x})$ のほうが有利で、その近似分散は $\frac{1 - f}{n}S_y^2(1 - \rho^2)$ です。
