  $\alpha > 0,\ \beta > 0$ とし、$X$ は確率密度関数

  $$f(x) = \frac{\beta^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\beta x}\qquad (x > 0)$$

  のガンマ分布 $Ga(\alpha, \beta)$（形状母数 $\alpha$、率母数 $\beta$）に従うとする。以下の各問に答えよ。

  [1] $X$ の積率母関数 $M_X(t)$ を、存在する $t$ の範囲とともに求めよ。

  [2] キュムラント母関数 $K_X(t) = \log M_X(t)$ を用いて、$X$ の平均、分散、歪度 $\kappa_3/\kappa_2^{3/2}$ を求めよ（$\kappa_r$ は $r$ 次のキュムラント）。

  [3] $X_1 \sim Ga(\alpha_1, \beta)$、$X_2 \sim Ga(\alpha_2, \beta)$ が独立なとき、$X_1 + X_2$ の分布を求めよ。

  [4] $\beta$ を固定して $\alpha \to \infty$ とするとき、$Z_\alpha = \dfrac{X - \alpha/\beta}{\sqrt{\alpha}/\beta}$ が標準正規分布に分布収束することを、積率母関数を用いて示せ。
modelAnswer: |
  **[1]** $t < \beta$ のとき

  $$M_X(t) = \int_0^\infty e^{tx}\frac{\beta^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\beta x}\,dx = \frac{\beta^\alpha}{\Gamma(\alpha)}\cdot\frac{\Gamma(\alpha)}{(\beta - t)^\alpha} = \left(1 - \frac{t}{\beta}\right)^{-\alpha}$$

  $t \geq \beta$ では積分が発散するので、存在範囲は $t < \beta$ である。

  **[2]** $K_X(t) = -\alpha\log(1 - t/\beta)$ を展開すると

  $$K_X(t) = \alpha\sum_{r=1}^{\infty}\frac{1}{r}\left(\frac{t}{\beta}\right)^r = \sum_{r=1}^{\infty}\frac{\alpha(r-1)!}{\beta^r}\cdot\frac{t^r}{r!}$$

  よって $\kappa_r = \alpha(r-1)!/\beta^r$ で

  $$E[X] = \kappa_1 = \frac{\alpha}{\beta},\qquad V[X] = \kappa_2 = \frac{\alpha}{\beta^2},\qquad \text{歪度} = \frac{\kappa_3}{\kappa_2^{3/2}} = \frac{2\alpha/\beta^3}{\alpha^{3/2}/\beta^3} = \frac{2}{\sqrt{\alpha}}$$

  **[3]** 独立性より、$t < \beta$ で

  $$M_{X_1+X_2}(t) = \left(1 - \frac{t}{\beta}\right)^{-\alpha_1}\left(1 - \frac{t}{\beta}\right)^{-\alpha_2} = \left(1 - \frac{t}{\beta}\right)^{-(\alpha_1+\alpha_2)}$$

  積率母関数の一意性より $X_1 + X_2 \sim Ga(\alpha_1 + \alpha_2,\ \beta)$（再生性。率母数が共通であることが必要）。

  **[4]** $Z_\alpha = \dfrac{\beta X}{\sqrt{\alpha}} - \sqrt{\alpha}$ なので、$t < \sqrt{\alpha}$ で

  $$\log M_{Z_\alpha}(t) = -t\sqrt{\alpha} + K_X\left(\frac{\beta t}{\sqrt{\alpha}}\right) = -t\sqrt{\alpha} - \alpha\log\left(1 - \frac{t}{\sqrt{\alpha}}\right)$$

  $|t| < \sqrt{\alpha}$ で $-\log(1 - u) = u + \dfrac{u^2}{2} + \dfrac{u^3}{3} + \cdots$ と展開すると

  $$\log M_{Z_\alpha}(t) = -t\sqrt{\alpha} + \alpha\left(\frac{t}{\sqrt{\alpha}} + \frac{t^2}{2\alpha} + \frac{t^3}{3\alpha^{3/2}} + \cdots\right) = \frac{t^2}{2} + \frac{t^3}{3\sqrt{\alpha}} + O\left(\frac{1}{\alpha}\right) \to \frac{t^2}{2}$$

  任意の $t$ について（$\alpha$ が十分大きければ $|t| < \sqrt{\alpha}$）$M_{Z_\alpha}(t) \to e^{t^2/2}$ となり、これは標準正規分布の積率母関数なので、$Z_\alpha \xrightarrow{d} N(0, 1)$。

ガンマ分布の積率母関数とキュムラントから、モーメント・再生性・正規近似までを一続きで導く問題です。キュムラント母関数は対数をとるだけで高次のキュムラントが読み取れるので、歪度や尖度の計算に便利です。

### 解答の流れ

1. 積率母関数は、被積分関数をガンマ密度の形 $x^{\alpha-1}e^{-(\beta - t)x}$ にそろえて計算する。
2. $\log(1 - u)$ のテイラー展開から、すべてのキュムラントが一度に得られる。
3. 独立な和の積率母関数は積。形状母数だけが足し合わされる。
4. 標準化した変数のキュムラント母関数を展開し、2 次の項だけが残ることを示す。

### つまずきやすい点

- 母数の取り方：尺度母数 $\theta = 1/\beta$ で書く流儀では $M(t) = (1 - \theta t)^{-\alpha}$、平均 $\alpha\theta$、分散 $\alpha\theta^2$。どちらの表し方かを最初に確認する。
- [3] で率母数が異なる場合（$Ga(\alpha_1, \beta_1)$ と $Ga(\alpha_2, \beta_2)$、$\beta_1 \neq \beta_2$）は、和はガンマ分布にならない。
- [4] で歪度 $2/\sqrt{\alpha} \to 0$ が $t^3$ の項の係数 $1/(3\sqrt{\alpha})$ に対応している。正規近似の精度は形状母数が大きいほどよい。

### ポイント

- 指数分布（$\alpha = 1$）、カイ二乗分布（$\alpha = m/2,\ \beta = 1/2$）、アーラン分布（$\alpha$ が整数）はガンマ分布の特別な場合である。
- [4] は、$\alpha$ が整数のとき「$\alpha$ 個の独立な指数分布の和」に対する中心極限定理と同じ内容である。尖度（超過尖度）は $\kappa_4/\kappa_2^2 = 6/\alpha$。
