stem: |
  $X$ は二項分布 $\mathrm{Bin}(n, p)$（$0 < p < 1$）に従うとし、2 乗誤差損失 $L(p, a) = (p - a)^2$ のもとで $p$ を推定する。$p$ の事前分布をベータ分布 $\mathrm{Beta}(\alpha, \beta)$（密度 $\propto p^{\alpha-1}(1-p)^{\beta-1}$）とする。以下の各問に答えよ。

  [1] $p$ のベイズ推定量 $\delta_{\alpha,\beta}(X)$ を求めよ。

  [2] $\delta_{\alpha,\beta}$ のリスク（平均二乗誤差）$R(p) = E_p[(\delta_{\alpha,\beta}(X) - p)^2]$ を $p$ の関数として求めよ。

  [3] $R(p)$ が $p$ によらない定数となる $\alpha,\ \beta$ を求め、そのときの推定量がミニマックス推定量であることを説明せよ。

  [4] $n = 16$ のとき、[3] の推定量のリスクと最尤推定量 $X/n$ のリスクを比較し、最尤推定量の方がリスクが小さくなる $p$ の範囲を求めよ。
modelAnswer: |
  **[1]** 事後分布は $p^{X + \alpha - 1}(1 - p)^{n - X + \beta - 1}$ に比例するので $\mathrm{Beta}(X + \alpha,\ n - X + \beta)$。2 乗誤差損失のベイズ推定量は事後平均なので

  $$\delta_{\alpha,\beta}(X) = \frac{X + \alpha}{n + \alpha + \beta}$$

  **[2]** $N = n + \alpha + \beta$ とおく。$E[\delta] - p = \dfrac{np + \alpha - Np}{N} = \dfrac{\alpha - (\alpha + \beta)p}{N}$、$V[\delta] = \dfrac{np(1 - p)}{N^2}$ より

  $$R(p) = V[\delta] + (E[\delta] - p)^2 = \frac{np(1 - p) + \{\alpha - (\alpha + \beta)p\}^2}{(n + \alpha + \beta)^2}$$

  **[3]** 分子を展開すると

  $$\alpha^2 + \{n - 2\alpha(\alpha + \beta)\}p + \{(\alpha + \beta)^2 - n\}p^2$$

  これが $p$ によらないためには $(\alpha + \beta)^2 = n$ かつ $2\alpha(\alpha + \beta) = n$、すなわち $\alpha = \beta = \sqrt{n}/2$。このとき分子は $\alpha^2 = n/4$ で

  $$R(p) = \frac{n/4}{(n + \sqrt{n})^2} = \frac{1}{4(\sqrt{n} + 1)^2},\qquad \delta^*(X) = \frac{X + \sqrt{n}/2}{n + \sqrt{n}}$$

  $\delta^*$ が事前分布 $\pi = \mathrm{Beta}(\sqrt{n}/2, \sqrt{n}/2)$ に対するベイズ推定量で、リスクが定数 $r$ であるとする。任意の推定量 $\delta$ について

  $$\sup_p R(p, \delta) \geq \int R(p, \delta)\,\pi(p)\,dp \geq \int R(p, \delta^*)\,\pi(p)\,dp = r = \sup_p R(p, \delta^*)$$

  （2 番目の不等号はベイズ推定量がベイズリスクを最小にすることによる）。よって $\delta^*$ は最大リスクを最小にするミニマックス推定量である。

  **[4]** $n = 16$ では $R(p, \delta^*) = \dfrac{1}{4 \times 5^2} = 0.01$。最尤推定量のリスクは $\dfrac{p(1 - p)}{16}$（最大値は $p = 1/2$ で $1/64 = 0.015625$）。

  $$\frac{p(1 - p)}{16} < 0.01 \iff p^2 - p + 0.16 > 0 \iff (p - 0.2)(p - 0.8) > 0 \iff p < 0.2\ \text{または}\ p > 0.8$$

  よって $p$ が 0 または 1 に近い（$p < 0.2$ または $p > 0.8$）ときは最尤推定量の方がリスクが小さく、$0.2 < p < 0.8$ ではミニマックス推定量の方が小さい。

ベイズ推定量のリスクを計算し、リスクが一定になる事前分布を選ぶとミニマックス推定量が得られる、という決定理論の典型問題です。最尤推定量（不偏推定量）と縮小推定量の、母数の値に応じた優劣も確認できます。

### 解答の流れ

1. ベータ分布は二項分布の共役事前分布。事後平均が 2 乗誤差損失のベイズ推定量。
2. リスク = 分散 + 偏りの 2 乗。$p$ の 2 次式になる。
3. 2 次と 1 次の係数を 0 にすると、リスクが定数になる。
4. 「リスク一定のベイズ推定量はミニマックス」という定理を、ベイズリスクの不等式で示す。

### つまずきやすい点

- [3] で $\alpha = \beta$ だけを課して $\alpha$ の値を決めない誤り。対称性だけでは 2 次の係数 $(2\alpha)^2 - n$ が残る。
- ミニマックス推定量が「すべての $p$ で最尤推定量より良い」と考える誤り。[4] のとおり、端の $p$ では最尤推定量の方がリスクが小さい。ミニマックスは最悪の場合を最良にする基準である。
- [4] で最尤推定量のリスクを $p(1 - p)/n^2$ とする誤り（$V[X/n] = p(1-p)/n$）。

### ポイント

- ミニマックス推定量 $\dfrac{X + \sqrt{n}/2}{n + \sqrt{n}}$ は $X/n$ を $1/2$ の方向へ縮小した推定量で、縮小の重み $\sqrt{n}/(n + \sqrt{n})$ は $n$ が大きいほど小さくなる。大標本では最大リスクの比 $\dfrac{1/\{4(\sqrt{n}+1)^2\}}{1/(4n)} \to 1$ となり、差はなくなる。
- 正規分布の平均の推定では、標本平均がミニマックス（リスク一定、ベイズ推定量の極限）であり、3 次元以上ではスタインの縮小推定量に優越される。
