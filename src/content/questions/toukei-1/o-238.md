前後の合格率の差 $0.65 - 0.50 = 0.15$ は、合否が変わった人（不一致の対）だけで決まります。講習前に合格・後に不合格が $b = 10$ 人、前に不合格・後に合格が $c = 25$ 人なので、マクネマー統計量は $(b - c)^2/(b + c) = 225/35 = 6.43$ です。帰無仮説（周辺合格率が等しい）のもとで近似的に $\chi^2(1)$ に従い、$3.841$ を超えるので有意水準 5% で合格率は変化したと判断されます。

### 計算

$H_0$ のもとでは、不一致の対 $b + c = 35$ 人のうち $c$ は $\mathrm{Bin}(35,\ 1/2)$ に従います。正規近似で

$$\frac{(c - (b + c)/2)^2}{(b + c)/4} = \frac{(b - c)^2}{b + c} = \frac{(10 - 25)^2}{35} = \frac{225}{35} = 6.43$$

### 各選択肢の検討

- $2.25$：$(b - c)^2/n = 225/100$ と、分母に全体の人数を使った誤りです。分散を決めるのは不一致の対の数 $b + c$ だけです。
- $6.43$：正しい。
- $3.46$：一致した対 $(40 - 25)^2/(40 + 25)$ を使った誤りです。前後とも合格・前後とも不合格の人は、合格率の変化について情報をもちません。
- $9.89$：表を独立な 2 群の $2 \times 2$ 分割表とみなしたピアソンのカイ二乗統計量です。これは「講習前の合否と講習後の合否が関連しているか」を検定するもので、合格率の変化の検定ではありません。また、同じ人の前後の測定は独立な 2 標本ではありません。
- $5.60$：連続修正をした $(|b - c| - 1)^2/(b + c) = 196/35$ です。問題は連続修正なしの値を求めています。

### ポイント

- 対応のある 2 値データでは、合格率の差の推定値 $(c - b)/n$ の分散も $b,\ c$ で決まります。対応を無視して 2 標本の比率の差の検定を使うと、前後の合否に正の相関がある通常の場合は分散を過大に見積もり、検出力を失います。
- $b + c$ が小さいときは、$\mathrm{Bin}(b + c,\ 1/2)$ による正確な検定（符号検定と同じ）を使います。
