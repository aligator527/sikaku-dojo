項目 5 を除くと、項目の分散の和は $4.2$、4 項目の合計得点の分散は $4.2 + 2 \times 3.1 = 10.4$ となり、$\alpha = \dfrac{4}{3}\left(1 - \dfrac{4.2}{10.4}\right) = 0.795$ です。項目を減らしたのに $\alpha$ が上がるのは、項目 5 が他の項目とほとんど共変動していないためです。

### 計算

項目 1〜4 の分散の和は $1.2 + 1.0 + 0.9 + 1.1 = 4.2$、共分散の和（上三角）は $0.6 + 0.5 + 0.6 + 0.5 + 0.4 + 0.5 = 3.1$ なので

$$\alpha_{-5} = \frac{4}{3}\left(1 - \frac{4.2}{4.2 + 6.2}\right) = \frac{4}{3} \times 0.5962 = 0.795$$

同様に、ほかの項目を 1 つ除いたときの $\alpha$ は、項目 1：0.589、項目 2：0.593、項目 3：0.620、項目 4：0.618 で、いずれも 0.70 より小さくなります。

### 各選択肢の検討

- 信頼性係数の上限：誤り。古典的テスト理論の仮定（誤差が互いに無相関）のもとで、$\alpha$ は信頼性係数の**下限**を与える。$\alpha$ と信頼性係数が一致するのは、項目が本質的タウ等価な場合である。
- 項目 5 を除いた $\alpha$：正しい（上記）。
- 1 次元性：誤り。$\alpha$ は項目間の共分散の平均の大きさを反映するだけで、構造は見ていない。互いに無相関な 2 つの因子からなる項目群でも、項目数が多ければ $\alpha$ は高くなりうる。1 次元性は因子分析などで確かめる。
- 項目 5 の寄与：誤り。内的一貫性に寄与するのは項目の分散ではなく、他の項目との共分散である。項目 5 の分散 1.3 はほとんどが他と共有されない成分で、合計得点の誤差分散を増やしている。
- 項目数への依存：誤り。共分散の平均を $\bar{c}$、分散の平均を $\bar{v}$ とすると $\alpha = \dfrac{k\bar{c}}{\bar{v} + (k - 1)\bar{c}}$ で、同じ $\bar{c},\ \bar{v}$ のもとでも $k$ が増えるほど $\alpha$ は大きくなる（スピアマン・ブラウンの公式と同じ形）。

### ポイント

- 「項目を除いたときの $\alpha$」は項目分析の基本的な指標だが、$\alpha$ を上げることだけを目的に項目を削ると、測りたい概念の幅（内容的妥当性）を狭めることがある。
- 因子負荷量が項目ごとに異なる場合（同族測定）の信頼性の推定には、$\omega$ 係数も用いられる。
