テストの長さを $k$ 倍にしたときの信頼性係数は $\rho_k = k\rho/\{1 + (k - 1)\rho\}$ です。これを $k$ について解くと $k = \dfrac{\rho_k(1 - \rho)}{\rho(1 - \rho_k)} = \dfrac{0.85 \times 0.30}{0.70 \times 0.15} = 2.43$ 倍が必要で、項目数は $20 \times 2.43 = 48.6$、切り上げて 49 項目です。

### 計算

$\rho_k = \dfrac{k\rho}{1 + (k - 1)\rho} \geq 0.85$ を $k$ について解きます。$\rho_k$ は $k$ の増加関数なので

$$k \geq \frac{\rho_k(1 - \rho)}{\rho(1 - \rho_k)} = \frac{0.85 \times 0.30}{0.70 \times 0.15} = \frac{0.255}{0.105} = 2.4286$$

必要な項目数は $20k \geq 48.57$ なので、最小値は 49 項目です。

確認：49 項目では $k = 2.45$、$\rho_k = \dfrac{2.45 \times 0.70}{1 + 1.45 \times 0.70} = \dfrac{1.715}{2.015} = 0.851$。48 項目では $k = 2.4$、$\rho_k = \dfrac{1.68}{1.98} = 0.848$ で足りません。

### ポイント

- よくある誤り：48.57 を四捨五入して 48 項目とする。条件を満たす最小の整数なので切り上げる。
- 信頼性係数を上げるのに必要な項目数は急速に増える。0.70 から 0.85 には約 2.4 倍だが、0.95 にするには $\dfrac{0.95 \times 0.30}{0.70 \times 0.05} = 8.1$ 倍（約 163 項目）が必要になる。
- 公式は、追加する項目が元の項目と平行（真の得点と誤差分散が同じ）であることを前提とする。質の異なる項目を加えた場合には成り立たない。
