  確率変数列の収束について、以下の各問に答えよ。

  [1] $U$ を区間 $(0, 1)$ 上の一様分布に従う確率変数とし、$X_n = n\cdot\mathbf{1}\{U \leq 1/n\}$（$\mathbf{1}\{\cdot\}$ は指示関数）とする。$X_n$ が 0 に確率収束し、さらに概収束することを示せ。

  [2] [1] の $X_n$ について $E[X_n]$ と $E[X_n^2]$ を求め、$X_n$ が 0 に平均収束（$L^1$ 収束）も平均二乗収束もしないことを示せ。

  [3] $Z$ を標準正規分布に従う確率変数とし、すべての $n$ について $Y_n = -Z$ とおく。$Y_n$ は $Z$ に分布収束するが、確率収束はしないことを示せ。

  [4] 定数 $c$ について、$W_n \xrightarrow{d} c$ ならば $W_n \xrightarrow{p} c$ であることを示せ。
modelAnswer: |
  **[1]** 任意の $\varepsilon > 0$ について、$|X_n| > \varepsilon$ となるのは $U \leq 1/n$ のときに限られるので

  $$P(|X_n| > \varepsilon) \leq P(U \leq 1/n) = \frac{1}{n} \to 0$$

  よって $X_n \xrightarrow{p} 0$。また $U = u > 0$ を固定すると、$n > 1/u$ を満たすすべての $n$ で $X_n = 0$ となる。$P(U > 0) = 1$ なので、確率 1 で $X_n \to 0$、すなわち $X_n \xrightarrow{a.s.} 0$。

  **[2]**

  $$E[X_n] = n\cdot P(U \leq 1/n) = 1,\qquad E[X_n^2] = n^2\cdot\frac{1}{n} = n$$

  したがって $E[|X_n - 0|] = 1 \not\to 0$ で平均収束せず、$E[|X_n - 0|^2] = n \to \infty$ で平均二乗収束もしない。概収束・確率収束しても、期待値は極限の期待値 $0$ に収束しない（まれに非常に大きな値をとるため）。

  **[3]** $Z$ の分布は 0 について対称なので $-Z$ も $N(0, 1)$ に従う。したがって $Y_n$ の分布関数はすべての $n$ で $Z$ の分布関数 $\Phi$ に等しく、$Y_n \xrightarrow{d} Z$。一方、

  $$P(|Y_n - Z| > \varepsilon) = P(2|Z| > \varepsilon) = 2\left\{1 - \Phi\left(\frac{\varepsilon}{2}\right)\right\} > 0$$

  は $n$ によらない正の値で 0 に収束しないので、$Y_n$ は $Z$ に確率収束しない。分布収束は分布だけについての主張で、確率変数としての近さは意味しない。

  **[4]** $W_n$ の分布関数を $F_n$ とする。$c$ に退化した分布の分布関数は $x < c$ で 0、$x \geq c$ で 1 であり、$c$ 以外の点で連続である。$\varepsilon > 0$ に対し $c - \varepsilon$ と $c + \varepsilon/2$ は連続点なので

  $$P(|W_n - c| > \varepsilon) \leq P(W_n \leq c - \varepsilon) + P(W_n > c + \varepsilon/2) = F_n(c - \varepsilon) + 1 - F_n(c + \varepsilon/2) \to 0 + 1 - 1 = 0$$

  よって $W_n \xrightarrow{p} c$。

収束の 4 つの概念（概収束、平均収束、確率収束、分布収束）の関係を、反例と証明で確認する問題です。成り立つ関係は「概収束 ⇒ 確率収束 ⇒ 分布収束」「$L^2$ 収束 ⇒ $L^1$ 収束 ⇒ 確率収束」で、逆は一般には成り立ちません。

### 解答の流れ

1. 確率収束は $P(|X_n - X| > \varepsilon) \to 0$ を直接評価する。
2. 概収束は「標本点 $\omega$（ここでは $U$ の値）を固定したときの数列の収束」が確率 1 で起こることを示す。
3. 平均収束の反例は「確率は小さいが値が大きい」事象で作る。
4. 分布収束しても確率収束しない反例は、同じ分布をもつが互いに異なる確率変数で作る。

### つまずきやすい点

- [2] から「確率収束すれば期待値も収束する」は誤りと分かる。期待値の収束には一様可積分性（たとえば $\sup_n E[|X_n|^{1+\delta}] < \infty$）が必要である。
- [3] の分布収束は、極限の確率変数 $Z$ が $Y_n$ と同じ確率空間にある必要すらない概念である。確率収束を論じるには同じ確率空間で $|Y_n - Z|$ を考える。
- [4] の逆向き（確率収束 ⇒ 分布収束）は一般に成り立つが、「分布収束 ⇒ 確率収束」は極限が定数のときにのみ成り立つ。

### ポイント

- [4] はスルツキーの定理や、推定量の一致性（$\hat{\theta}_n \xrightarrow{p} \theta$）を分布収束から導くときに使われる。
- $X_n = n\cdot\mathbf{1}\{U \leq 1/n\}$ を独立な事象で作り直す（$P(X_n = n) = 1/n$ を独立に）と、ボレル・カンテリの第 2 補題により $X_n = n$ が無限回起こるので、確率収束はするが概収束しない例になる。
