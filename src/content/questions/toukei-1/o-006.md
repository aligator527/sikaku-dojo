stem: |
  所得 $X$ が支出 $Y$ に与える影響を、単回帰モデル

  $$Y_i = \alpha + \beta X_i + \varepsilon_i \qquad (i = 1, \ldots, n)$$

  で分析したい。ただし、真の所得 $X_i$ は観測できず、自己申告による $W_i = X_i + U_i$ のみが観測される。$X_i,\ U_i,\ \varepsilon_i$ は互いに独立で、$E[U_i] = E[\varepsilon_i] = 0$、$V[X_i] = \sigma_X^2 > 0$、$V[U_i] = \sigma_U^2$、$V[\varepsilon_i] = \sigma_\varepsilon^2$ とし、$(X_i, U_i, \varepsilon_i)$ は $i$ について独立同一分布に従うとする。以下の各問に答えよ。

  [1] $Y_i$ を $W_i$ に回帰したときの最小二乗推定量 $\hat{\beta}$ の確率極限を求め、$\hat{\beta}$ が $\beta$ の一致推定量にならないことを示せ。

  [2] $\beta = 2$、信頼性係数 $\sigma_X^2/(\sigma_X^2 + \sigma_U^2) = 0.8$ のとき、$\hat{\beta}$ の確率極限を求め、偏りの向きを述べよ。

  [3] 同じ個人について、$U_i$ とも $\varepsilon_i$ とも独立な誤差 $U_i'$ を含む 2 回目の測定 $W_i' = X_i + U_i'$ が得られるとする。$W_i'$ を操作変数として用いた推定量が $\beta$ の一致推定量となることを示せ。

  [4] 測定誤差が説明変数ではなく目的変数 $Y$ にだけ含まれる場合、$\hat{\beta}$ の一致性はどうなるか簡潔に述べよ。
modelAnswer: |
  **[1]** 最小二乗推定量は $\hat{\beta} = \dfrac{\sum (W_i - \bar{W})(Y_i - \bar{Y})}{\sum (W_i - \bar{W})^2}$。大数の法則より、分子・分母を $n$ で割ったものはそれぞれ $\mathrm{Cov}(W, Y)$、$V[W]$ に確率収束する。独立性より

  $$\mathrm{Cov}(W, Y) = \mathrm{Cov}(X + U,\ \alpha + \beta X + \varepsilon) = \beta\sigma_X^2,\qquad V[W] = \sigma_X^2 + \sigma_U^2$$

  よって（連続写像定理により）

  $$\operatorname*{plim}_{n\to\infty}\hat{\beta} = \beta\,\frac{\sigma_X^2}{\sigma_X^2 + \sigma_U^2}$$

  $\sigma_U^2 > 0$ かつ $\beta \neq 0$ なら、これは $\beta$ と異なるので $\hat{\beta}$ は一致推定量ではない。

  **[2]** $\operatorname{plim}\hat{\beta} = 2 \times 0.8 = 1.6$。$0 < \sigma_X^2/(\sigma_X^2 + \sigma_U^2) < 1$ なので、推定値は絶対値が小さくなる方向、すなわち 0 に向かって偏る（希薄化バイアス、減衰バイアス）。

  **[3]** 操作変数推定量 $\hat{\beta}_{IV} = \dfrac{\sum (W_i' - \bar{W}')(Y_i - \bar{Y})}{\sum (W_i' - \bar{W}')(W_i - \bar{W})}$ について

  $$\mathrm{Cov}(W', Y) = \mathrm{Cov}(X + U',\ \alpha + \beta X + \varepsilon) = \beta\sigma_X^2,\qquad \mathrm{Cov}(W', W) = \mathrm{Cov}(X + U',\ X + U) = \sigma_X^2$$

  したがって $\operatorname{plim}\hat{\beta}_{IV} = \beta\sigma_X^2/\sigma_X^2 = \beta$ で、一致推定量である。$W'$ は $W$ と相関をもち（$\sigma_X^2 > 0$）、誤差項 $\varepsilon_i - \beta U_i$（$Y_i = \alpha + \beta W_i + \varepsilon_i - \beta U_i$ と書いたときの誤差）とは無相関なので、操作変数の条件を満たす。

  **[4]** $Y_i^{*} = Y_i + V_i$（$V_i$ は他と独立、平均 0）が観測される場合、誤差項が $\varepsilon_i + V_i$ に変わるだけで説明変数との無相関性は保たれるので、$\hat{\beta}$ は一致推定量のままである。ただし誤差分散が大きくなるため、推定の精度は下がる（標準誤差が大きくなる）。

説明変数の測定誤差による「希薄化（減衰）バイアス」は、社会科学分野の計量経済モデル（内生性・操作変数法）や、人文科学分野のテストの信頼性と関連する重要な論点です。

### 解答の流れ

1. 最小二乗推定量を標本共分散 / 標本分散として書き、それぞれの確率極限を求める。
2. 確率極限が信頼性係数 $\lambda = \sigma_X^2/(\sigma_X^2 + \sigma_U^2)$ 倍に縮むことを示す。
3. 操作変数推定量では、分子・分母の両方に $\sigma_X^2$ が現れて打ち消し合う。

### つまずきやすい点

- $Y_i = \alpha + \beta W_i + (\varepsilon_i - \beta U_i)$ と書き直すと、誤差項が $W_i$ と相関する（$\mathrm{Cov}(W_i,\ \varepsilon_i - \beta U_i) = -\beta\sigma_U^2$）ことが、内生性として見えてくる。
- 「標本サイズを増やせば偏りは消える」は誤り。偏りは $n$ によらず残る（一致性の欠如）。
- 2 回目の測定誤差 $U'$ が $U$ と相関すると（同じ人が同じ方向に誤って申告するなど）、操作変数推定量も一致性を失う。

### ポイント

- 信頼性係数が分かっていれば $\hat{\beta}/\hat{\lambda}$ で補正できる。心理測定では再検査信頼性やクロンバックの $\alpha$ が $\lambda$ の推定に使われる。
- 重回帰では、測定誤差のある変数の係数が減衰するだけでなく、他の変数の係数にも偏りが波及しうる。
