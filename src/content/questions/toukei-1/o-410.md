パーシェ価格指数は比較時点の数量で重み付けた $\sum p_1 q_1/\sum p_0 q_1 = 28050/26000 \times 100 = 107.9$、フィッシャー価格指数はラスパイレスとパーシェの幾何平均 $\sqrt{110.4 \times 107.9} = 109.1$ です。

### 各選択肢の検討

- 選択肢 1：正しい。$\sum p_0 q_1 = 4800 + 8800 + 7000 + 5400 = 26000$、$\sum p_1 q_1 = 5760 + 9240 + 6300 + 6750 = 28050$ より $P_P = 107.885$、$F_P = \sqrt{1.104 \times 1.07885} \times 100 = 109.1$。
- 選択肢 2：$\sum p_1 q_1/\sum p_0 q_0 = 28050/25000 = 112.2$ は名目支出額の比（金額指数）であり、価格と数量の両方の変化を含む。パーシェ価格指数ではない。
- 選択肢 3：金額指数に一致するのは「ラスパイレス数量指数 × パーシェ価格指数」（$1.040 \times 1.07885 = 1.122$）または「ラスパイレス価格指数 × パーシェ数量指数」である。ラスパイレスどうしの積は $1.040 \times 1.104 = 1.148$ で一致しない。
- 選択肢 4：フィッシャー指数は時点逆転テスト $F_{01}F_{10} = 1$ を満たす（$L_{10} = 1/P_{01}$、$P_{10} = 1/L_{01}$ なので $F_{10} = 1/F_{01}$）。要素逆転テスト（価格指数 × 数量指数 = 金額指数）も満たす。
- 選択肢 5：逆である。価格比と数量比の間に**負**の相関がある（価格が上がった A、D は数量が減り、価格が下がった C は数量が増えた）ため、比較時点の数量で重み付けるパーシェ指数が小さくなる。

### ポイント

- ボルトケビッチの関係式：基準時点の支出額をウェイトとした価格比 $r_i = p_{1i}/p_{0i}$ と数量比 $s_i = q_{1i}/q_{0i}$ の加重共分散を $C$、加重平均を $\bar{r}$（$= L_P$）、$\bar{s}$（$= L_Q$）とすると $P_P/L_P - 1 = C/(\bar{r}\bar{s})$。本問では $C < 0$ なので $P_P < L_P$。
- 消費者は相対的に高くなった財を減らす（代替効果）ので、通常は $P_P < L_P$ となり、その間にあるフィッシャー指数が「理想算式」と呼ばれる。
