$\kappa = \dfrac{p_o - p_e}{1 - p_e}$ で、$p_o$ は観測された一致率、$p_e$ は 2 人が独立に（周辺分布どおりに）評定したときに偶然一致する確率です。$p_o = 0.73$、$p_e = 0.3475$ なので、$\kappa = 0.3825/0.6525 \approx 0.586$ です。

### 計算

観測された一致率（対角成分の割合）：

$$p_o = \frac{25 + 30 + 18}{100} = 0.73$$

偶然の一致率（周辺比率の積の和）：

$$p_e = 0.30 \times 0.35 + 0.45 \times 0.40 + 0.25 \times 0.25 = 0.105 + 0.180 + 0.0625 = 0.3475$$

$$\kappa = \frac{0.73 - 0.3475}{1 - 0.3475} = \frac{0.3825}{0.6525} = 0.5862$$

### ポイント

- $\kappa$ は「偶然の一致を除いたうえで、最大限の一致（$1 - p_e$）のうちどれだけを達成したか」を表す。$\kappa = 1$ は完全一致、$\kappa = 0$ は偶然と同程度の一致である。よく使われる目安では 0.41〜0.60 が「中程度」の一致にあたる。
- よくある誤り：一致率 $p_o = 0.73$ をそのまま答える、または $p_e$ を $1/3$（カテゴリー数の逆数）とする。偶然の一致率は各評定者の周辺分布に依存する。
- A、B、C が順序のある評価なので、A と C の不一致を A と B の不一致より重く扱う重み付き $\kappa$（線形・2 次の重み）を用いることも多い。2 次の重み付き $\kappa$ は級内相関係数に近い値になる。
- $\kappa$ は周辺分布の偏りに敏感で、あるカテゴリーがまれな場合には、一致率が高くても $\kappa$ が小さくなることがある（$\kappa$ のパラドックス）。
