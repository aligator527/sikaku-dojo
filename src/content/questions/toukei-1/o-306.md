  2 値の目的変数 $Y_i \in \{0, 1\}$ と 2 値の説明変数 $x_i \in \{0, 1\}$（$i = 1, \ldots, n$）について、$Y_i$ は互いに独立で

  $$P(Y_i = 1) = \pi_i,\qquad \log\frac{\pi_i}{1 - \pi_i} = \beta_0 + \beta_1x_i$$

  とするロジスティック回帰モデルを考える。データを集計したところ、次の分割表を得た。

  | | $Y = 1$ | $Y = 0$ | 計 |
  | --- | --- | --- | --- |
  | $x = 1$ | $a$ | $b$ | $a + b$ |
  | $x = 0$ | $c$ | $d$ | $c + d$ |

  以下の各問に答えよ。

  [1] 対数尤度 $\ell(\beta_0, \beta_1)$ を書き、尤度方程式を導け。

  [2] 最尤推定量が $\hat{\beta}_0 = \log(c/d)$、$\hat{\beta}_1 = \log\dfrac{ad}{bc}$ となることを示し、$e^{\beta_1}$ の意味を述べよ。

  [3] フィッシャー情報行列を求め、$\hat{\beta}_1$ の漸近分散の推定量が $\dfrac{1}{a} + \dfrac{1}{b} + \dfrac{1}{c} + \dfrac{1}{d}$ となることを示せ。

  [4] $a = 30,\ b = 20,\ c = 15,\ d = 35$ のとき、$e^{\beta_1}$ の推定値と、ワルド法による 95% 信頼区間を求めよ。必要なら $\log 3.5 = 1.2528$、$e^{0.4245} = 1.529$、$e^{2.0810} = 8.013$ を用いよ（$\log$ は自然対数）。標準正規分布の上側 2.5% 点は $1.96$ とする。
modelAnswer: |
  **[1]** $\eta_i = \beta_0 + \beta_1x_i$ とすると $\log\pi_i = \eta_i - \log(1 + e^{\eta_i})$、$\log(1 - \pi_i) = -\log(1 + e^{\eta_i})$ なので

  $$\ell(\beta_0, \beta_1) = \sum_{i=1}^{n}\left\{y_i\eta_i - \log(1 + e^{\eta_i})\right\}$$

  $\partial\log(1 + e^{\eta})/\partial\eta = \pi$ より、尤度方程式は

  $$\frac{\partial\ell}{\partial\beta_0} = \sum_{i}(y_i - \pi_i) = 0,\qquad \frac{\partial\ell}{\partial\beta_1} = \sum_{i}x_i(y_i - \pi_i) = 0$$

  **[2]** $x = 1$ の群の確率を $\pi_1 = \dfrac{e^{\beta_0 + \beta_1}}{1 + e^{\beta_0 + \beta_1}}$、$x = 0$ の群を $\pi_0 = \dfrac{e^{\beta_0}}{1 + e^{\beta_0}}$ とすると、尤度方程式は

  $$a - (a + b)\pi_1 = 0,\qquad (a + c) - (a + b)\pi_1 - (c + d)\pi_0 = 0$$

  となり、$\hat{\pi}_1 = a/(a + b)$、$\hat{\pi}_0 = c/(c + d)$。$(\beta_0, \beta_1)$ と $(\pi_0, \pi_1)$ は 1 対 1 に対応するので（最尤推定量の不変性）

  $$\hat{\beta}_0 = \log\frac{\hat{\pi}_0}{1 - \hat{\pi}_0} = \log\frac{c}{d},\qquad \hat{\beta}_1 = \log\frac{\hat{\pi}_1}{1 - \hat{\pi}_1} - \hat{\beta}_0 = \log\frac{a}{b} - \log\frac{c}{d} = \log\frac{ad}{bc}$$

  $e^{\beta_1} = \dfrac{\pi_1/(1 - \pi_1)}{\pi_0/(1 - \pi_0)}$ は、$x = 1$ の群の $x = 0$ の群に対する**オッズ比**である。

  **[3]** $\partial\pi_i/\partial\eta_i = \pi_i(1 - \pi_i)$ より、2 階微分の符号を変えたものは確率変数を含まず

  $$I(\boldsymbol{\beta}) = \sum_{i}\pi_i(1 - \pi_i)\begin{pmatrix} 1 & x_i \\ x_i & x_i^2 \end{pmatrix} = \begin{pmatrix} w_1 + w_0 & w_1 \\ w_1 & w_1 \end{pmatrix}$$

  ここで $w_1 = (a + b)\pi_1(1 - \pi_1)$、$w_0 = (c + d)\pi_0(1 - \pi_0)$。逆行列の $(2,2)$ 成分は

  $$\{I(\boldsymbol{\beta})^{-1}\}_{22} = \frac{w_1 + w_0}{(w_1 + w_0)w_1 - w_1^2} = \frac{1}{w_1} + \frac{1}{w_0}$$

  最尤推定値を代入すると $\hat{w}_1 = (a + b)\cdot\dfrac{a}{a + b}\cdot\dfrac{b}{a + b} = \dfrac{ab}{a + b}$ なので $1/\hat{w}_1 = 1/a + 1/b$、同様に $1/\hat{w}_0 = 1/c + 1/d$。よって

  $$\hat{V}[\hat{\beta}_1] = \frac{1}{a} + \frac{1}{b} + \frac{1}{c} + \frac{1}{d}$$

  **[4]** オッズ比の推定値は $\dfrac{30 \times 35}{20 \times 15} = 3.5$、$\hat{\beta}_1 = \log 3.5 = 1.2528$。

  $$\widehat{\mathrm{SE}} = \sqrt{\frac{1}{30} + \frac{1}{20} + \frac{1}{15} + \frac{1}{35}} = \sqrt{0.17857} = 0.4226$$

  $\beta_1$ の 95% 信頼区間は $1.2528 \pm 1.96 \times 0.4226 = [0.4245,\ 2.0810]$。指数変換して、オッズ比の 95% 信頼区間は $[1.529,\ 8.013]$。区間は 1 を含まないので、有意水準 5% でオッズ比 1（$\beta_1 = 0$）は棄却される（ワルド統計量 $z = 1.2528/0.4226 = 2.96$）。

説明変数が 2 値のロジスティック回帰は、2×2 分割表のオッズ比の推測と一致します。一般化線形モデルの尤度方程式・情報行列の計算を、閉じた形で確認できる典型問題です。

### 解答の流れ

1. ロジットリンクは二項分布の正準リンクなので、尤度方程式は $X^\top(\boldsymbol{y} - \boldsymbol{\pi}) = \boldsymbol{0}$ という簡単な形になる。
2. 説明変数が 2 値なら、各群の観測割合がそのまま最尤推定値になる（飽和モデル）。
3. 情報行列は $X^\top WX$（$W = \mathrm{diag}\{\pi_i(1 - \pi_i)\}$）。2×2 の逆行列を計算する。
4. 信頼区間は $\beta_1$ の尺度で正規近似を使って作り、指数変換する。

### つまずきやすい点

- オッズ比の信頼区間を $3.5 \pm 1.96 \times \mathrm{SE}$ のように元の尺度で作るのは誤り。対数オッズ比の方が正規分布に近く、指数変換した区間は 3.5 に関して非対称になる。
- $e^{\beta_1}$ は確率の比（リスク比）ではない。ここでのリスク比は $0.6/0.3 = 2.0$ で、オッズ比 3.5 とは異なる。事象がまれな場合にだけ両者は近くなる。

### ポイント

- 一般の説明変数では尤度方程式は閉じた形に解けず、ニュートン・ラフソン法（正準リンクではフィッシャーのスコア法と一致し、反復重み付き最小二乗法 IRLS として実装される）で解く。
- ロジスティック回帰の係数は、症例対照研究のように $Y$ で層別して標本を抽出しても（切片を除いて）一致推定できる。オッズ比が抽出方法に対して不変であることによる。
