ポアソン分布の再生性から $X + Y \sim Po(5)$ です。条件付き確率を計算すると $e^{-\lambda}$ と $k!$ の部分が打ち消し合い、$P(X = k \mid X + Y = 10) = \binom{10}{k}\left(\frac{2}{5}\right)^k\left(\frac{3}{5}\right)^{10-k}$ となるので、$\mathrm{Bin}(10,\ 2/5)$ が正解です。

### 計算

$k = 0, 1, \ldots, 10$ について

$$P(X = k \mid X + Y = 10) = \frac{P(X = k)\,P(Y = 10 - k)}{P(X + Y = 10)} = \frac{\dfrac{e^{-2}2^k}{k!}\cdot\dfrac{e^{-3}3^{10-k}}{(10-k)!}}{\dfrac{e^{-5}5^{10}}{10!}} = \binom{10}{k}\left(\frac{2}{5}\right)^k\left(\frac{3}{5}\right)^{10-k}$$

### 各選択肢の検討

- $\mathrm{Bin}(10,\ 2/3)$：成功確率を $\lambda_X/\lambda_Y = 2/3$ とした誤り。正しくは $\lambda_X/(\lambda_X + \lambda_Y) = 2/5$。
- $\mathrm{Bin}(10,\ 1/2)$：2 つの変数を対称に扱った誤り。平均の大きい $Y$ の側に多く割り振られるはずである。
- $Po(2)$：$X$ と $Y$ が独立なので条件を付けても $X$ の分布は変わらない、とする誤り。$X$ は和 $X + Y$ とは独立ではない。そもそも条件のもとで $X \leq 10$ なので、ポアソン分布にはなり得ない。
- $\mathrm{Bin}(10,\ 2/5)$：正しい。
- $Po(4)$：条件付き期待値 $E[X \mid X + Y = 10] = 4$ に合わせたポアソン分布。平均は一致するが、分散は $10 \times 0.4 \times 0.6 = 2.4$ で 4 ではなく、値の範囲も $0 \sim 10$ に限られる。

### ポイント

- 一般に $X_i \sim Po(\lambda_i)$ が独立なとき、$\sum X_i = n$ を与えた $(X_1, \ldots, X_k)$ の条件付き分布は多項分布 $\mathrm{Mult}(n;\ \lambda_1/\lambda, \ldots, \lambda_k/\lambda)$（$\lambda = \sum\lambda_i$）になる。分割表の検定で、総数を固定した条件付き推測が多項分布で行えるのはこの性質による。
- 条件付き期待値は $E[X \mid X + Y] = \frac{2}{5}(X + Y)$ と、和の一次関数になる。
