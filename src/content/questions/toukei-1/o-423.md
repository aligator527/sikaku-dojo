構成要素の信頼度を $R = e^{-\lambda t}$ とすると、システムの信頼度は「3 個とも正常」か「ちょうど 2 個正常」の確率で $R_s(t) = R^3 + 3R^2(1 - R) = 3e^{-2\lambda t} - 2e^{-3\lambda t}$ です。MTTF はこれを積分して $\dfrac{3}{2\lambda} - \dfrac{2}{3\lambda} = \dfrac{5}{6\lambda} = 833$ 時間となり、構成要素 1 個の平均寿命 1000 時間より**短く**なります。

### 各選択肢の検討

- $333$ 時間：直列系（3 個すべてが必要）の MTTF $1/(3\lambda)$。
- $833$ 時間：正しい。
- $1000$ 時間：構成要素 1 個の MTTF $1/\lambda$。冗長化すれば必ず長くなると考えた誤り。
- $1500$ 時間：故障が起きるたびの平均待ち時間を $1/(1 \cdot \lambda) + 1/(2\lambda)$ と、稼働台数を 1、2 台として足している。正しくは 3 台稼働中の $1/(3\lambda)$ と 2 台稼働中の $1/(2\lambda)$ の和。
- $1833$ 時間：並列系（1 個でも動けばよい）の MTTF $\dfrac{1}{\lambda}\left(1 + \dfrac{1}{2} + \dfrac{1}{3}\right) = \dfrac{11}{6\lambda}$。

### 計算

$$\mathrm{MTTF} = \int_0^{\infty}R_s(t)\,dt = \int_0^{\infty}\left(3e^{-2\lambda t} - 2e^{-3\lambda t}\right)dt = \frac{3}{2\lambda} - \frac{2}{3\lambda} = \frac{5}{6\lambda} = \frac{5}{6 \times 0.001} = 833.3$$

無記憶性を使うと、最初の故障までの時間は平均 $1/(3\lambda)$、その後 2 台のうち 1 台が故障するまでは平均 $1/(2\lambda)$ なので、$\dfrac{1}{3\lambda} + \dfrac{1}{2\lambda} = \dfrac{5}{6\lambda}$ と求めることもできます。

### ポイント

- 2-out-of-3 システムは、初期（$t$ が小さい）には $R_s(t) > R(t)$ で単体より信頼度が高いが、$R(t) < 1/2$（$t > \log 2/\lambda = 693$ 時間）では単体より低くなる。多数決冗長は、短い任務時間での信頼性向上や誤動作の防止に向いた方式である。
- 一般に $k$-out-of-$n$ システム（独立・同一の指数分布）の MTTF は $\dfrac{1}{\lambda}\sum_{i=k}^{n}\dfrac{1}{i}$。
