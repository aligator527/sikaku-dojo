$x_2$ の VIF は、$x_2$ を他の説明変数 $x_1,\ x_3$ に回帰したときの決定係数 $R_2^2$ を用いて $\mathrm{VIF}_2 = 1/(1 - R_2^2)$ です。2 変数の重相関の公式から $R_2^2 = 0.52/0.75 = 0.6933$ となり、$\mathrm{VIF}_2 = 1/0.3067 \approx 3.26$ です。

### 計算

$x_2$ を $x_1,\ x_3$ に回帰したときの決定係数は、相関係数 $r_{12} = 0.8,\ r_{23} = 0.6,\ r_{13} = 0.5$ を用いて

$$R_2^2 = \frac{r_{12}^2 + r_{23}^2 - 2r_{12}r_{23}r_{13}}{1 - r_{13}^2} = \frac{0.64 + 0.36 - 0.48}{1 - 0.25} = \frac{0.52}{0.75} = 0.6933$$

$$\mathrm{VIF}_2 = \frac{1}{1 - 0.6933} = \frac{1}{0.3067} = 3.261$$

### 別解（逆行列の対角成分）

VIF は相関行列の逆行列 $R^{-1}$ の対角成分に等しくなります。$\det R = 1 + 2(0.8)(0.5)(0.6) - 0.64 - 0.25 - 0.36 = 0.23$ で、$(2,2)$ 余因子は $1 - r_{13}^2 = 0.75$ なので

$$(R^{-1})_{22} = \frac{0.75}{0.23} = 3.261$$

同様に $\mathrm{VIF}_1 = (1 - 0.36)/0.23 = 2.78$、$\mathrm{VIF}_3 = (1 - 0.64)/0.23 = 1.57$ です。

### ポイント

- 説明変数を標本分散 1 に標準化して当てはめたとき、係数の推定量の分散は $V[\hat{\beta}_j] = \dfrac{\sigma^2}{n-1}(R^{-1})_{jj}$ で、説明変数が互いに無相関の場合（$(R^{-1})_{jj} = 1$）に比べて $\mathrm{VIF}_j$ 倍に拡大する。名前の由来はここにある。
- よくある誤り：対になった相関だけを見て $1/(1 - r_{12}^2) = 2.78$ とする。VIF は「他のすべての説明変数」との重相関で決まる。
- 目安として $\mathrm{VIF} > 10$（$R_j^2 > 0.9$）で強い多重共線性が疑われるが、VIF が大きくても予測そのものの精度が落ちるとは限らない。問題になるのは個々の係数の推定と解釈である。
