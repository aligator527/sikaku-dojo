stem: |
  2 つの時系列 $x_t,\ y_t$ が次のモデルに従うとする。

  $$x_t = x_{t-1} + u_t,\qquad y_t = \beta x_t + v_t,\qquad v_t = \rho v_{t-1} + e_t$$

  ここで $\beta \neq 0$、$|\rho| < 1$ で、$\{u_t\}$ と $\{e_t\}$ は互いに独立で、それぞれ平均 0、分散 $\sigma_u^2,\ \sigma_e^2$ の独立同一分布に従う系列とする（$\{v_t\}$ は定常 AR(1) 過程）。以下の各問に答えよ。

  [1] $x_t,\ y_t$ がともに 1 次の和分過程 I(1) であり、$y_t - \beta x_t$ が定常であることを示せ。このような関係を何と呼ぶか。

  [2] $\Delta y_t = y_t - y_{t-1}$ が

  $$\Delta y_t = \beta\Delta x_t + \gamma(y_{t-1} - \beta x_{t-1}) + e_t$$

  と表せることを示し、$\gamma$ を求めよ。また、この表現（誤差修正モデル）における $\gamma$ の符号と大きさの意味を説明せよ。

  [3] $\beta$ が未知のとき、エングル・グレンジャーの 2 段階法による分析の手順を説明せよ。その際、第 1 段階の最小二乗推定量の性質と、残差に対する単位根検定の注意点にふれよ。

  [4] $\rho = 0.8$ のとき、長期均衡 $y = \beta x$ からの乖離が半分になるまでの期間（半減期）を求めよ。また、$\rho = 1$ の場合に $y_t$ を $x_t$ に回帰すると何が起こるか述べよ。$\log 0.5 = -0.6931$、$\log 0.8 = -0.2231$ とする。
modelAnswer: |
  **[1]** $x_t = x_0 + \sum_{s=1}^{t}u_s$ はランダムウォークで、$V[x_t - x_0] = t\sigma_u^2$ が増大するので非定常、$\Delta x_t = u_t$ は定常。よって $x_t$ は I(1)。$y_t = \beta x_t + v_t$ は $\beta \neq 0$ なので $x_t$ の非定常性を受け継ぎ非定常であり、

  $$\Delta y_t = \beta u_t + v_t - v_{t-1}$$

  は定常な系列の和なので定常。よって $y_t$ も I(1)。一方 $y_t - \beta x_t = v_t$ は定常 AR(1) 過程である。I(1) の系列の線形結合が定常（I(0)）になる関係を**共和分**といい、$(1, -\beta)$ を共和分ベクトルという。

  **[2]** $\Delta y_t = \beta\Delta x_t + \Delta v_t$ で、$\Delta v_t = (\rho - 1)v_{t-1} + e_t$、$v_{t-1} = y_{t-1} - \beta x_{t-1}$ なので

  $$\Delta y_t = \beta\Delta x_t + (\rho - 1)(y_{t-1} - \beta x_{t-1}) + e_t,\qquad \gamma = \rho - 1$$

  $|\rho| < 1$ より $-2 < \gamma < 0$（$0 < \rho < 1$ なら $-1 < \gamma < 0$）。前期に $y$ が均衡値 $\beta x$ を上回っていれば（$y_{t-1} - \beta x_{t-1} > 0$）、今期の $y$ は下がる方向に調整される。$|\gamma|$ は 1 期あたりに均衡からの乖離が解消される割合（調整速度）を表す。$\gamma = 0$（$\rho = 1$）なら均衡へ戻る力がなく、共和分は成り立たない。

  **[3]** 第 1 段階：$y_t$ を $x_t$（必要なら定数項）に最小二乗回帰し、$\hat{\beta}$ と残差 $\hat{v}_t = y_t - \hat{\beta}x_t$ を得る。共和分があるとき、$\hat{\beta}$ は $n$ の速さで $\beta$ に収束する（超一致性）。$v_t$ と $x_t$ の相関があっても一致性は保たれるが、分布は非標準的なので、通常の $t$ 値で $\beta$ を検定することはできない。

  次に $\hat{v}_t$ に単位根検定（ADF 検定など）を行い、単位根が棄却されれば共和分ありと判断する。$\hat{v}_t$ は残差平方和を最小にするように推定された系列なので、真の $v_t$ より定常に見えやすい。そのため通常のディッキー・フラーの臨界値ではなく、より絶対値の大きいエングル・グレンジャー（マッキノン）の臨界値を用いる。

  第 2 段階：$\Delta y_t$ を $\Delta x_t$ と $\hat{v}_{t-1}$（および必要なら $\Delta y,\ \Delta x$ のラグ）に回帰して誤差修正モデルを推定する。すべての変数が I(0) なので、通常の推測が近似的に使える。

  **[4]** 誤差修正項 $v_t$ は外部ショックがなければ $v_{t+h} = 0.8^hv_t$ と減衰するので、$0.8^h = 0.5$ より

  $$h = \frac{\log 0.5}{\log 0.8} = \frac{-0.6931}{-0.2231} = 3.11$$

  約 3.1 期で乖離が半分になる。

  $\rho = 1$ では $v_t$ もランダムウォークとなり、$y_t - \beta x_t$ は定常でなく共和分は存在しない。このとき $y_t$ を $x_t$ に回帰すると、$\hat{\beta}$ は $\beta$ に収束せず、決定係数や $t$ 統計量は通常の分布に従わない（$t$ 統計量は $n$ とともに発散する）。とくに $\beta = 0$ でも「有意な関係」が見つかりやすい見せかけの回帰になる。残差の自己相関が強く（ダービン・ワトソン比が 0 に近い）、決定係数が高いのに残差が非定常、という特徴がみられる。

  - '[2] $\Delta v_t = (\rho - 1)v_{t-1} + e_t$ を用いて誤差修正表現を導き、$\gamma = \rho - 1 < 0$ を調整速度として解釈している'

共和分の定義、誤差修正モデルへの書き換え、エングル・グレンジャーの 2 段階法、見せかけの回帰との関係を一つのモデルで確認する問題です。

### 解答の流れ

1. 階差をとって定常になる系列が I(1)。2 つの I(1) 系列の線形結合が定常なら共和分。
2. $\Delta v_t$ を AR(1) の式で書き直すと、前期の均衡からの乖離が説明変数として現れる（グレンジャーの表現定理の最も簡単な例）。
3. 共和分ベクトルの推定は超一致的だが、残差の単位根検定では推定の影響を考えた臨界値を使う。
4. 均衡からの乖離は AR(1) として減衰するので、半減期は $\log 0.5/\log\rho$。

### つまずきやすい点

- I(1) の系列どうしの回帰では、有意な係数や高い決定係数が得られても、それだけで関係があるとはいえない。残差が定常かどうか（共和分の有無）を確認する必要がある。
- 共和分があるときに両方の系列を階差だけで分析すると、長期の均衡関係（誤差修正項）の情報が失われる。

### ポイント

- 多変量の場合は、ベクトル誤差修正モデル $\Delta\boldsymbol{y}_t = \Pi\boldsymbol{y}_{t-1} + \cdots$ の $\Pi$ の階数が共和分関係の数になり、ヨハンセン検定で調べる。
- この例では $y_t$ だけが均衡へ調整しているが、一般には複数の変数が調整に参加する（調整係数ベクトル）。
