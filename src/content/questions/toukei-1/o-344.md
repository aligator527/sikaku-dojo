ロジスティック部分を $L(\theta) = 1/[1 + \exp\{-Da(\theta - b)\}]$ とすると $P = c + (1 - c)L$、$P^{\prime} = (1 - c)DaL(1 - L)$ です。$\theta = b = 0$ では $L = 0.5$、$P = 0.6$、$P^{\prime} = 0.8 \times 1.7 \times 0.25 = 0.34$ なので、$I(0) = 0.34^2/(0.6 \times 0.4) = 0.1156/0.24 \approx 0.482$ です。

### 計算

$\theta = 0$ では $\exp\{-Da(0 - 0)\} = 1$ なので $L = 1/2$。

$$P(0) = 0.2 + 0.8 \times 0.5 = 0.6$$

$$P^{\prime}(0) = (1 - c)\,Da\,L(1 - L) = 0.8 \times 1.7 \times 1.0 \times 0.25 = 0.34$$

$$I(0) = \frac{0.34^2}{0.6 \times 0.4} = \frac{0.1156}{0.24} = 0.4817$$

### 一般形

$L = (P - c)/(1 - c)$、$1 - L = (1 - P)/(1 - c)$ を代入すると

$$I(\theta) = D^2a^2\cdot\frac{1 - P(\theta)}{P(\theta)}\left\{\frac{P(\theta) - c}{1 - c}\right\}^2$$

と書けます。$c = 0$ なら 2PL の $D^2a^2P(1 - P)$ に戻り、$\theta = b$ での値は $1.7^2/4 = 0.7225$ です。

### ポイント

- 当て推量があると、低い能力の受検者でも正答することがあるため、正答から得られる情報が減る。この例では情報量が 2PL の $0.4817/0.7225 = 67\%$ に下がる。
- 3PL の項目情報量が最大になるのは $\theta = b$ ではなく、それより少し高い $\theta^{*} = b + \dfrac{1}{Da}\log\dfrac{1 + \sqrt{1 + 8c}}{2}$ で、この項目では $\theta^{*} = 0.157$（最大値は約 0.492）である。
- よくある誤り：$P^{\prime}$ に係数 $(1 - c)$ を掛け忘れて $0.425$ とすると $I = 0.753$ となる。また $D = 1.7$ を落とすと値は $1/1.7^2$ 倍になる。
