modelAnswer: |
  **[1]** $X$ は独立なベルヌーイ変数（平均 $p$、分散 $p(1-p)$）$n$ 個の和と同じ分布なので、中心極限定理より

  $$\sqrt{n}(\hat{p} - p) \xrightarrow{d} N\big(0,\ p(1 - p)\big)$$

  **[2]** $g(p) = \log p - \log(1 - p)$ とおくと

  $$g'(p) = \frac{1}{p} + \frac{1}{1 - p} = \frac{1}{p(1 - p)} \neq 0$$

  デルタ法より

  $$\sqrt{n}(\hat{\psi} - \psi) \xrightarrow{d} N\left(0,\ g'(p)^2\,p(1 - p)\right) = N\left(0,\ \frac{1}{p(1 - p)}\right)$$

  **[3]** 大数の法則より $\hat{p} \xrightarrow{p} p$ で、$p(1-p)$ は連続関数なので $\hat{p}(1 - \hat{p}) \xrightarrow{p} p(1 - p)$。スルツキーの定理より

  $$\sqrt{n\hat{p}(1 - \hat{p})}\,(\hat{\psi} - \psi) \xrightarrow{d} N(0, 1)$$

  となり、漸近分散の $p$ を $\hat{p}$ で置き換えても極限分布は変わらない。よって $\psi$ の近似 95% 信頼区間は

  $$\hat{\psi} \pm \frac{1.96}{\sqrt{n\hat{p}(1 - \hat{p})}} = [L,\ U]$$

  $p = \dfrac{e^\psi}{1 + e^\psi}$ は $\psi$ の単調増加関数なので、$p$ の区間は $\left[\dfrac{e^L}{1 + e^L},\ \dfrac{e^U}{1 + e^U}\right]$ となる。

  **[4]** $\hat{p} = 0.2$、$\hat{\psi} = \log(0.2/0.8) = -\log 4 = -1.386$、$n\hat{p}(1 - \hat{p}) = 32$ なので、$\psi$ の区間は $-1.386 \pm 0.3465$。オッズ $e^\psi$ の区間は

  $$\left[0.25\,e^{-0.3465},\ 0.25\,e^{0.3465}\right] = \left[\frac{0.25}{1.414},\ 0.25 \times 1.414\right] = [0.1768,\ 0.3535]$$

  $p = \text{オッズ}/(1 + \text{オッズ})$ により

  $$\left[\frac{0.1768}{1.1768},\ \frac{0.3535}{1.3535}\right] = [0.150,\ 0.261]$$

  Wald 型は $0.2 \pm 1.96\sqrt{0.16/200} = 0.2 \pm 0.0554 = [0.145,\ 0.255]$。対数オッズによる区間は $\hat{p} = 0.2$ に関して右に長い非対称な区間で、端点が必ず $(0, 1)$ に入る。$\hat{p}$ が 0 や 1 に近いとき、Wald 型は負の下限などの不合理な区間を与えやすい。

デルタ法で変換後の推定量の漸近分布を求め、変換した尺度で信頼区間を作ってから元に戻す、という定番の手順の問題です。ロジスティック回帰の係数（対数オッズ比）の信頼区間も同じ考え方で作られます。

### 解答の流れ

1. $\hat{p}$ の漸近正規性（中心極限定理）を出発点にする。
2. デルタ法：$\sqrt{n}(g(\hat{p}) - g(p)) \xrightarrow{d} N(0,\ g'(p)^2\sigma^2)$。
3. 漸近分散の推定値を代入してよいことをスルツキーの定理で示す。
4. 単調変換の逆関数で区間の端点を変換する。

### つまずきやすい点

- デルタ法で $g'(p)$ を 2 乗し忘れて漸近分散を $1$ などとする誤り。$g'(p)^2 \cdot p(1-p) = 1/\{p(1-p)\}$。
- [4] で $1.96/\sqrt{32}$ ではなく $1.96/\sqrt{200 \times 0.2}$ のように $1 - \hat{p}$ を落とす誤り。
- $p$ の区間の端点を $\hat{p} \pm (\text{何か})$ の形で求めようとする誤り。変換後の対称な区間を逆変換すると、元の尺度では非対称になる。

### ポイント

- 対数オッズの漸近分散 $\dfrac{1}{np(1-p)} = \dfrac{1}{np} + \dfrac{1}{n(1-p)}$ は「成功数の逆数 + 失敗数の逆数」と読める。2×2 分割表の対数オッズ比の標準誤差 $\sqrt{1/a + 1/b + 1/c + 1/d}$ はこの拡張である。
