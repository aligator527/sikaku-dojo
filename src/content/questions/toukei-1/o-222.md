  $I \times J$ 分割表の度数 $n_{ij}$ が互いに独立にポアソン分布 $Po(\mu_{ij})$ に従うとし、対数線形モデル

  $$\log\mu_{ij} = \lambda + \lambda_i^{A} + \lambda_j^{B} + \lambda_{ij}^{AB}$$

  を考える。パラメータには和が 0 の制約 $\sum_i\lambda_i^{A} = \sum_j\lambda_j^{B} = 0$、$\sum_i\lambda_{ij}^{AB} = \sum_j\lambda_{ij}^{AB} = 0$ を課す。$n_{i+} = \sum_j n_{ij}$、$n_{+j} = \sum_i n_{ij}$、$n = \sum_{i,j}n_{ij}$ とする。以下の各問に答えよ。

  [1] $I = J = 2$ のとき、$\lambda_{11}^{AB} = \dfrac{1}{4}\log\dfrac{\mu_{11}\mu_{22}}{\mu_{12}\mu_{21}}$ を示し、独立性（$\lambda_{ij}^{AB} = 0$）がオッズ比 1 と同値であることを説明せよ。

  [2] 独立モデル $\log\mu_{ij} = \lambda + \lambda_i^{A} + \lambda_j^{B}$ のもとで、$\mu_{ij}$ の最尤推定値が $\hat{\mu}_{ij} = n_{i+}n_{+j}/n$ となることを示せ。

  [4] 次の $2 \times 3$ 分割表について、$G^2$ とピアソンのカイ二乗統計量 $X^2$ を求め、有意水準 5% で独立性を検定せよ。$\log 1.2 = 0.1823$、$\log 0.8 = -0.2231$、$\chi^2_{0.05}(2) = 5.991$ とする。

modelAnswer: |
  **[1]** $I = J = 2$ では制約より $\lambda_2^{A} = -\lambda_1^{A}$、$\lambda_2^{B} = -\lambda_1^{B}$、$\lambda_{12}^{AB} = \lambda_{21}^{AB} = -\lambda_{11}^{AB}$、$\lambda_{22}^{AB} = \lambda_{11}^{AB}$。対数オッズ比は

  $$\log\mu_{11} + \log\mu_{22} - \log\mu_{12} - \log\mu_{21} = \lambda_{11}^{AB} + \lambda_{22}^{AB} - \lambda_{12}^{AB} - \lambda_{21}^{AB} = 4\lambda_{11}^{AB}$$

  （$\lambda,\ \lambda^{A},\ \lambda^{B}$ の項は打ち消し合う）。よって $\lambda_{11}^{AB} = \frac{1}{4}\log\{\mu_{11}\mu_{22}/(\mu_{12}\mu_{21})\}$ で、$\lambda^{AB} = 0 \iff$ オッズ比 $= 1$。このとき $\mu_{ij} = e^{\lambda + \lambda_i^{A}}e^{\lambda_j^{B}}$ と行の因子と列の因子の積に分かれ、$\mu_{ij}/\mu_{++} = (\mu_{i+}/\mu_{++})(\mu_{+j}/\mu_{++})$（独立）となる。

  **[2]** 対数尤度（定数を除く）は

  $$\ell = \sum_{i,j}\left(n_{ij}\log\mu_{ij} - \mu_{ij}\right) = n\lambda + \sum_i n_{i+}\lambda_i^{A} + \sum_j n_{+j}\lambda_j^{B} - \sum_{i,j}\mu_{ij}$$

  $\lambda$、$\lambda_i^{A}$、$\lambda_j^{B}$ で微分して 0 とおくと（制約は、たとえば $\lambda_I^{A} = -\sum_{i<I}\lambda_i^{A}$ と消去して扱う）、尤度方程式は

  $$\hat{\mu}_{++} = n,\qquad \hat{\mu}_{i+} = n_{i+},\qquad \hat{\mu}_{+j} = n_{+j}$$

  となる（十分統計量である周辺度数を、期待度数の周辺和に一致させる）。独立モデルでは $\mu_{ij} = \mu_{i+}\mu_{+j}/\mu_{++}$ と書けるので、$\hat{\mu}_{ij} = n_{i+}n_{+j}/n$ がこれらの方程式を満たし、対数尤度は凹なのでこれが最尤推定値である。

  **[3]** 飽和モデルのパラメータ数は $IJ$、独立モデルは $1 + (I - 1) + (J - 1)$。差は

  $$IJ - 1 - (I - 1) - (J - 1) = (I - 1)(J - 1)$$

  で、$G^2$ は漸近的に $\chi^2((I - 1)(J - 1))$ に従う。

  ポアソンモデルでは $n$ は $Po(\mu_{++})$ に従い、$n$ を与えたときの $(n_{ij})$ の条件付き分布は多項分布 $\mathrm{Mult}(n;\ \mu_{ij}/\mu_{++})$ になる。対数尤度は「$n$ の周辺尤度（$\mu_{++}$ だけに依存）」と「多項分布の尤度（セル確率だけに依存）」の和に分かれ、どちらのモデルでも $\hat{\mu}_{++} = n$ となるので、$G^2$ の中で前者は打ち消し合う。よって、ポアソンモデルと多項分布モデルで同じ $\hat{\mu}_{ij}$ と同じ $G^2$ が得られる。

  **[4]** 期待度数は $\hat{\mu}_{ij} = 100 \times n_{+j}/200$ より、どちらの行も $(25,\ 50,\ 25)$。

  $$G^2 = 2\left[30\log\frac{30}{25} + 20\log\frac{20}{25} + 20\log\frac{20}{25} + 30\log\frac{30}{25}\right] = 2\left[60\log 1.2 + 40\log 0.8\right]$$

  $$= 2\left[60 \times 0.1823 - 40 \times 0.2231\right] = 2(10.938 - 8.924) = 4.03$$

  （中央の列は $\log(50/50) = 0$。）

  $$X^2 = \frac{5^2}{25} \times 4 + 0 = 4.00$$

  自由度は $(2 - 1)(3 - 1) = 2$ で、$G^2 = 4.03$、$X^2 = 4.00$ はいずれも $5.991$ より小さいので、有意水準 5% で独立性は棄却されない。

対数線形モデルは、分割表の度数の期待値の対数を「主効果」と「交互作用」に分解するモデルです。2 元表では交互作用パラメータがオッズ比と直接対応し、独立性の検定は「交互作用が 0 のモデル」の適合度検定として理解できます。

### 解答の流れ

1. 2×2 表で制約を使うと交互作用パラメータは 1 つだけ（$\pm\lambda_{11}^{AB}$）で、対数オッズ比の 1/4 になる。
2. ポアソン対数尤度を書くと、十分統計量は周辺度数。尤度方程式は「期待度数の周辺和 = 観測度数の周辺和」。
3. 自由度は飽和モデルとのパラメータ数の差。
4. 期待度数を計算し、$G^2$ と $X^2$ を求める。

### つまずきやすい点

- [1] で制約の付け方を変える（たとえば第 1 水準を 0 とする端点制約）と、$\lambda_{22}^{AB}$ がそのまま対数オッズ比になり、係数 $1/4$ は現れません。パラメータの値は制約に依存しますが、オッズ比や期待度数は依存しません。
- $G^2$ の計算では、観測度数と期待度数が等しいセル（$\log 1 = 0$）も忘れずに確認します。
- 多項分布モデルで総度数 $n$ を固定しても、さらに行和を固定した積二項（積多項）モデルでも、独立性（同質性）の検定は同じ $G^2$・$X^2$ と同じ自由度になります。

### ポイント

- $G^2$ と $X^2$ は漸近的に同等で、期待度数が十分大きいときは近い値になります。期待度数が小さいセルがあると近似が悪くなるので、フィッシャーの正確検定などを使います。
- 3 元以上の表では、$[AB][C]$（$C$ と $(A, B)$ の独立）、$[AC][BC]$（$C$ を与えたときの $A$ と $B$ の条件付き独立）など、交互作用項の組み合わせで多様な独立構造を表せます。
