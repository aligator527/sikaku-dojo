正規分布の事前分布と正規分布の尤度（分散既知）から、事後分布も正規分布になります。精度（分散の逆数）は足し算で、事前の精度 $1/0.5 = 2$ とデータの精度 $n/\sigma^2 = 32/16 = 2$ の和 $4$ が事後の精度です。事後平均は精度による加重平均 $(2 \times 0 + 2 \times 1.5)/4 = 0.75$、事後標準偏差は $\sqrt{1/4} = 0.5$ なので、$P(\theta > 0 \mid \boldsymbol{x}) = \Phi(0.75/0.5) = \Phi(1.50) = 0.933$ です。

### 計算

$\bar{X}$ は十分統計量で、$\bar{X} \mid \theta \sim N(\theta,\ 16/32) = N(\theta,\ 0.5)$ です。事前分布 $N(0,\ 0.5)$ と組み合わせると

$$\pi(\theta \mid \bar{x}) \propto \exp\left\{-\frac{(\bar{x} - \theta)^2}{2 \times 0.5}\right\}\exp\left\{-\frac{\theta^2}{2 \times 0.5}\right\} \propto \exp\left\{-\frac{4}{2}\left(\theta - \frac{\bar{x}}{2}\right)^2\right\}$$

より、事後分布は $N(\bar{x}/2,\ 1/4) = N(0.75,\ 0.25)$ です。

$$P(\theta > 0 \mid \boldsymbol{x}) = P\left(Z > \frac{0 - 0.75}{0.5}\right) = \Phi(1.50) = 0.9332 \approx 0.933$$

### ポイント

- 事後平均は $\bar{x} = 1.5$ を事前平均 0 の方向へ半分だけ縮めた値になります。データの精度と事前の精度が等しいためです。
- 頻度論の片側検定では $z = 1.5/\sqrt{0.5} = 2.12$、$p \approx 0.017$ で、$1 - p \approx 0.983$ は事後確率 $0.933$ より大きくなります。0 を中心とする事前分布が推定値を 0 に引き寄せるためで、$p$ 値を「$H_0$ が正しい確率」と解釈してはならない例でもあります。
- よくある誤り：事後分散をデータの分散 $0.5$ のままにする（$\Phi(1.06) \approx 0.855$）、または縮小を忘れて $\Phi(1.5/0.5) = \Phi(3.00)$ とする。
