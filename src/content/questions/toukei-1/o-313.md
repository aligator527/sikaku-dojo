最長距離法では、クラスター間の距離を「両クラスターに属する対象の組の距離の最大値」と定め、毎回その距離が最小のクラスター対を併合します。併合は A と E（距離 1）、B と C（距離 6）、{B, C} と D（距離 8）の順に起こるので、2 クラスターは {A, E} と {B, C, D}、3 回目の併合距離は 8 です。

### 計算

1 回目：最小の距離は A–E の 1 なので {A, E} を作る。新しいクラスターとの距離は最大値で更新する。

$$d(\mathrm{AE}, \mathrm{B}) = \max(13, 12) = 13,\quad d(\mathrm{AE}, \mathrm{C}) = \max(5, 15) = 15,\quad d(\mathrm{AE}, \mathrm{D}) = \max(9, 4) = 9$$

2 回目：残りの距離 $\{13, 15, 9,\ d(\mathrm{B},\mathrm{C}) = 6,\ d(\mathrm{B},\mathrm{D}) = 7,\ d(\mathrm{C},\mathrm{D}) = 8\}$ の最小は 6 なので {B, C} を作る。

$$d(\mathrm{BC}, \mathrm{AE}) = \max(13, 15) = 15,\qquad d(\mathrm{BC}, \mathrm{D}) = \max(7, 8) = 8$$

3 回目：$\{15,\ 8,\ d(\mathrm{AE}, \mathrm{D}) = 9\}$ の最小は 8 なので {B, C, D} を作る。ここで 2 クラスター {A, E}、{B, C, D} となる。

4 回目：$d(\mathrm{BCD}, \mathrm{AE}) = \max(15, 9) = 15$ で全体が 1 つになる。

### 各選択肢の検討

- {B} と {A, C, D, E}、距離 5：最短距離法（単連結法）の結果。距離を最小値で更新すると、A–E（1）、{A, E}–D（4）、{A, D, E}–C（5）と鎖のようにつながり、B だけが取り残される（連鎖効果）。
- {A, E} と {B, C, D}、距離 8：正しい。
- {B, C} と {A, D, E}、距離 6.5：群平均法の結果。$d(\mathrm{AE}, \mathrm{D}) = (9 + 4)/2 = 6.5$ が $d(\mathrm{BC}, \mathrm{D}) = (7 + 8)/2 = 7.5$ より小さいので、D は {A, E} 側に入る。
- 距離 15：分類は正しいが、15 は最後（4 回目）に全体が 1 つにまとまる距離である。
- 距離 7：分類は正しいが、{B, C} と D の距離を最小値 $\min(7, 8) = 7$ で更新している。最長距離法では最大値 8 を用いる。

### ポイント

- 同じ距離行列でも、クラスター間距離の定義（最短・最長・群平均・ウォード法など）によって分類が変わる。最短距離法は細長いクラスターを作りやすく、最長距離法はまとまりのよい（直径の小さい）クラスターを作りやすい。
- これらの更新はランス・ウィリアムズの漸化式 $d(k, i \cup j) = \alpha_id(k, i) + \alpha_jd(k, j) + \beta d(i, j) + \gamma|d(k, i) - d(k, j)|$ で統一的に書ける。最長距離法は $\alpha_i = \alpha_j = 1/2,\ \beta = 0,\ \gamma = 1/2$、最短距離法は $\gamma = -1/2$ である。
