全分散の公式 $V[X] = E\big[V[X \mid P]\big] + V\big[E[X \mid P]\big]$ を使います。$E[X \mid P] = 10P$、$V[X \mid P] = 10P(1-P)$ なので、ベータ分布の 1 次・2 次のモーメントから $V[X] = 10 \times 0.2 + 100 \times 0.04 = 6$ です。

### 計算

$\mathrm{Beta}(a, b)$ の平均と分散は $\dfrac{a}{a+b}$、$\dfrac{ab}{(a+b)^2(a+b+1)}$ なので、$a = 2,\ b = 3$ では

$$E[P] = \frac{2}{5} = 0.4,\qquad V[P] = \frac{6}{25 \times 6} = 0.04,\qquad E[P^2] = 0.04 + 0.16 = 0.2$$

よって

$$E\big[V[X \mid P]\big] = 10\,E[P - P^2] = 10(0.4 - 0.2) = 2,\qquad V\big[E[X \mid P]\big] = V[10P] = 100 \times 0.04 = 4$$

$$V[X] = 2 + 4 = 6$$

### 各項の意味と典型的な誤り

- $10 \times 0.4 \times 0.6 = 2.4$ とする誤り：$P$ を平均 $0.4$ に固定した二項分布の分散で、$P$ のばらつきを無視している。
- $E[V[X \mid P]] = 2$ だけ、または $V[E[X \mid P]] = 4$ だけを答える誤り：全分散の公式の一方の項を落としている。$E[V[X \mid P]]$ は $10 \times 0.4 \times 0.6 = 2.4$ ではなく $2$ になる（$E[P(1-P)] \neq E[P]\,(1 - E[P])$）ことにも注意する。

### ポイント

- この $X$ の周辺分布はベータ二項分布で、一般に $V[X] = \dfrac{nab(a+b+n)}{(a+b)^2(a+b+1)}$。$n = 10,\ a = 2,\ b = 3$ を代入すると $\dfrac{10 \times 6 \times 15}{25 \times 6} = 6$ となり一致する。
- 成功確率が個体ごとにばらつくと、分散は二項分布の $2.4$ より大きくなる（過分散）。ポアソン分布に対するガンマ分布の混合（負の二項分布）と並ぶ、過分散モデルの代表例である。
