  ある調査で、学習意欲 $X$、学習時間 $M$、試験成績 $Y$ を測定した。いずれも標準化した変数とし、次の構造方程式モデル（パス解析モデル）を考える。

  $$M = aX + e_M,\qquad Y = c^{\prime}X + bM + e_Y$$

  ここで $X,\ e_M,\ e_Y$ は互いに無相関とする。$n = 200$ の標本で、相関係数は $r_{XM} = 0.5$、$r_{XY} = 0.4$、$r_{MY} = 0.6$ であった。以下の各問に答えよ。

  [1] モデルが相関行列を完全に再現するとして、$r_{XM},\ r_{XY},\ r_{MY}$ をパス係数 $a,\ b,\ c^{\prime}$ で表し、$a,\ b,\ c^{\prime}$ と誤差分散 $V[e_M],\ V[e_Y]$ を求めよ。

  [2] $X$ から $Y$ への総合効果を、直接効果と $M$ を経由する間接効果に分解し、間接効果の割合を求めよ。

  [3] 観測変数の分散・共分散の数と自由な母数の数を数えて、このモデルの自由度を求めよ。次に、直接効果がない（$c^{\prime} = 0$、完全媒介）という制約をおいたモデルを最尤法で推定したところ、適合度のカイ二乗統計量は $4.19$ であった。このモデルの自由度と、モデルが再現する $r_{XY}$ の値を求め、有意水準 5% で完全媒介モデルを評価せよ。$\chi^2_{0.05}(1) = 3.841$ とする。

  [4] 標準化しない元の尺度で推定したところ、$\hat{a} = 0.50$（標準誤差 $0.06$）、$\hat{b} = 0.53$（標準誤差 $0.07$）であった。ソーベル検定（デルタ法）により間接効果 $ab$ の検定統計量を求めよ。また、この検定と、間接効果を因果的に解釈することについての注意点を述べよ。有意水準は 5%（両側）とし、必要なら $\sqrt{0.002236} = 0.04729$ を用いよ。標準正規分布の上側 2.5% 点は $1.96$ とする。
modelAnswer: |
  **[1]** 標準化されているので共分散が相関係数になる。$M = aX + e_M$ より $r_{XM} = a$。$Y = c^{\prime}X + bM + e_Y$ と $X$、$M$ の共分散をとると

  $$r_{XY} = c^{\prime} + br_{XM} = c^{\prime} + ab,\qquad r_{MY} = c^{\prime}r_{XM} + b = ac^{\prime} + b$$

  （$e_Y$ は $X$ とも $M = aX + e_M$ とも無相関）。$a = 0.5$ を代入して連立方程式を解くと

  $$c^{\prime} = \frac{r_{XY} - r_{XM}r_{MY}}{1 - r_{XM}^2} = \frac{0.4 - 0.3}{0.75} = 0.133,\qquad b = \frac{r_{MY} - r_{XM}r_{XY}}{1 - r_{XM}^2} = \frac{0.6 - 0.2}{0.75} = 0.533$$

  これは $Y$ を $X$、$M$ に回帰した標準化偏回帰係数に等しい。誤差分散は

  $$V[e_M] = 1 - a^2 = 0.75,\qquad V[e_Y] = 1 - (c^{\prime}r_{XY} + br_{MY}) = 1 - (0.0533 + 0.32) = 0.627$$

  **[2]** 総合効果は $c^{\prime} + ab = 0.133 + 0.5 \times 0.533 = 0.133 + 0.267 = 0.4$ で、$r_{XY}$ に一致する。直接効果 0.133、間接効果 0.267 で、間接効果の割合は $0.267/0.4 = 2/3 \approx 0.67$。

  **[3]** 3 変数の分散・共分散は $3 \times 4/2 = 6$ 個。母数は $V[X]$、$a$、$b$、$c^{\prime}$、$V[e_M]$、$V[e_Y]$ の 6 個なので、自由度は $6 - 6 = 0$（飽和モデル。どんなデータにも完全に当てはまり、適合度は検証できない）。

  $c^{\prime} = 0$ のモデルは母数が 5 個で自由度 1。このとき $a = r_{XM} = 0.5$、$b = r_{MY} = 0.6$ と推定され、モデルが再現する相関は $r_{XY} = ab = 0.5 \times 0.6 = 0.30$ で、観測値 0.40 より小さい。カイ二乗統計量 $4.19$ は $\chi^2_{0.05}(1) = 3.841$ を超えるので、有意水準 5% で完全媒介モデルは棄却され、$X$ から $Y$ への直接の経路も必要と判断される。（この統計量は $-(n - 1)\log(1 - r_{XY\cdot M}^2)$、$r_{XY\cdot M}$ は $M$ を除いた $X$ と $Y$ の偏相関、に等しく、$c^{\prime} = 0$ の尤度比検定になっている。）

  **[4]** デルタ法により $V[\hat{a}\hat{b}] \approx b^2V[\hat{a}] + a^2V[\hat{b}]$（$\hat{a}$ と $\hat{b}$ は漸近的に無相関）なので

  $$\mathrm{SE}(\hat{a}\hat{b}) \approx \sqrt{0.53^2 \times 0.06^2 + 0.50^2 \times 0.07^2} = \sqrt{0.001011 + 0.001225} = \sqrt{0.002236} = 0.0473$$

  $$z = \frac{0.50 \times 0.53}{0.0473} = \frac{0.265}{0.0473} = 5.60$$

  $|z| > 1.96$ なので、間接効果は有意水準 5% で有意である。

  注意点：(i) 積 $\hat{a}\hat{b}$ の分布は正規分布から外れて歪むことが多く、ソーベル検定は標本が小さいと検出力が低い。ブートストラップ法による信頼区間がよく用いられる。(ii) パス係数を因果効果と解釈するには、$X$ と $M$、$M$ と $Y$、$X$ と $Y$ の間に未測定の交絡がないこと、因果の向きが正しいことなどの仮定が必要である。横断調査のデータだけでは、$M \to Y$ と $Y \to M$ を区別できない。

媒介分析を題材に、構造方程式モデルの共分散構造、効果の分解、自由度と識別、入れ子モデルのカイ二乗検定、間接効果の検定を確認する問題です。

### 解答の流れ

1. 標準化したパス解析では、相関係数を「経路の係数の積の和」に分解できる（パス解析の追跡規則）。
2. 総合効果＝直接効果＋間接効果。逐次モデルでは総合効果は単回帰の係数（ここでは相関係数）に一致する。
3. 自由度は（分散・共分散の数）$-$（母数の数）。飽和モデルは検証できず、制約を加えたモデルとの比較で仮説を検定する。
4. 間接効果は積なので、デルタ法で標準誤差を近似する。

### つまずきやすい点

- $b$ を単相関 $r_{MY} = 0.6$ とする誤り。$X$ を統制した偏回帰係数でなければならない。$r_{MY}$ には、$X$ という共通の原因による相関 $ac^{\prime}$ が含まれている。
- 完全媒介モデルでは $r_{XY}$ を自由に再現できないことが、自由度 1 の意味である。観測された $r_{XY}$ と再現された値 $ab$ のずれが、適合度の悪さとして検出される。

### ポイント

- 構造方程式モデルでは、モデルが再現する共分散行列 $\Sigma(\boldsymbol{\vartheta})$ と標本共分散行列 $S$ のずれ $F = \log|\Sigma| - \log|S| + \operatorname{tr}(S\Sigma^{-1}) - p$ を最小化し、$(n - 1)\hat{F}$ を自由度 df のカイ二乗分布と比べる（ML 推定）。
- 適合度の評価には、カイ二乗検定に加えて RMSEA、CFI などの指標も併用する（カイ二乗検定は標本が大きいとわずかなずれでも棄却する）。
