  $n$ 個の観測値について、切片を含む重回帰モデル

  $$\boldsymbol{y} = X\boldsymbol{\beta} + \boldsymbol{\varepsilon},\qquad \boldsymbol{\varepsilon} \sim N_n(\boldsymbol{0},\ \sigma^2 I_n)$$

  を考える。$X$ は第 1 列がすべて 1 の $n \times (p+1)$ 行列で、階数は $p + 1$ とする。最小二乗推定量を $\hat{\boldsymbol{\beta}} = (X^\top X)^{-1}X^\top\boldsymbol{y}$、ハット行列を $H = X(X^\top X)^{-1}X^\top$、残差ベクトルを $\boldsymbol{e} = \boldsymbol{y} - X\hat{\boldsymbol{\beta}}$ とし、$H$ の第 $(i, i)$ 成分を $h_{ii}$ と書く。以下の各問に答えよ。

  [1] $H$ が対称かつべき等であり、$\operatorname{tr}H = p + 1$ であることを示せ。また、$E[\boldsymbol{e}] = \boldsymbol{0}$、$V[\boldsymbol{e}] = \sigma^2(I_n - H)$ を示せ。

  [2] 残差平方和 $S_e = \boldsymbol{e}^\top\boldsymbol{e}$ について $E[S_e] = (n - p - 1)\sigma^2$ を示し、$\sigma^2$ の不偏推定量を与えよ。

  [3] $1/n \leq h_{ii} \leq 1$ であること、および $h_{ii}$ の平均が $(p+1)/n$ であることを示せ。

  [4] $n = 30,\ p = 3$ のデータで、ある観測値 $i$ について $h_{ii} = 0.40$、残差 $e_i = 2.4$ であり、[2] の不偏推定量の平方根は $s = 2.0$ であった。標準化残差 $r_i = e_i/(s\sqrt{1 - h_{ii}})$ とクックの距離 $D_i = \dfrac{r_i^2}{p+1}\cdot\dfrac{h_{ii}}{1 - h_{ii}}$ を求め、この観測値について診断上どのようなことがいえるか述べよ。
modelAnswer: |
  **[1]** $(X^\top X)^{-1}$ は対称なので $H^\top = X(X^\top X)^{-1}X^\top = H$。また

  $$H^2 = X(X^\top X)^{-1}X^\top X(X^\top X)^{-1}X^\top = X(X^\top X)^{-1}X^\top = H$$

  トレースの巡回性より $\operatorname{tr}H = \operatorname{tr}\{(X^\top X)^{-1}X^\top X\} = \operatorname{tr}I_{p+1} = p + 1$。

  $\boldsymbol{e} = (I_n - H)\boldsymbol{y}$ であり、$HX = X$ より $(I_n - H)X = O$ なので $\boldsymbol{e} = (I_n - H)\boldsymbol{\varepsilon}$。よって $E[\boldsymbol{e}] = \boldsymbol{0}$、$I_n - H$ も対称・べき等なので

  $$V[\boldsymbol{e}] = (I_n - H)\,\sigma^2 I_n\,(I_n - H)^\top = \sigma^2(I_n - H)$$

  **[2]** $S_e = \boldsymbol{\varepsilon}^\top(I_n - H)\boldsymbol{\varepsilon}$ はスカラーなのでトレースをとって

  $$E[S_e] = E[\operatorname{tr}\{(I_n - H)\boldsymbol{\varepsilon}\boldsymbol{\varepsilon}^\top\}] = \operatorname{tr}\{(I_n - H)\sigma^2 I_n\} = \sigma^2(n - p - 1)$$

  よって $s^2 = S_e/(n - p - 1)$ が $\sigma^2$ の不偏推定量である。

  **[3]** $H = H^2 = H^\top H$ の $(i, i)$ 成分を比べると

  $$h_{ii} = \sum_{j=1}^{n}h_{ij}^2 = h_{ii}^2 + \sum_{j \neq i}h_{ij}^2 \geq h_{ii}^2$$

  なので $0 \leq h_{ii} \leq 1$。さらに $X$ の第 1 列が $\boldsymbol{1}$ なので $H\boldsymbol{1} = \boldsymbol{1}$ であり、$H_0 = \frac{1}{n}\boldsymbol{1}\boldsymbol{1}^\top$ とすると $HH_0 = H_0H = H_0$。このとき $H - H_0$ も対称・べき等になるので、同じ議論で $h_{ii} - \frac{1}{n} \geq 0$。よって $1/n \leq h_{ii} \leq 1$。平均は $\frac{1}{n}\sum_i h_{ii} = \frac{1}{n}\operatorname{tr}H = \frac{p+1}{n}$。

  **[4]**

  $$r_i^2 = \frac{e_i^2}{s^2(1 - h_{ii})} = \frac{5.76}{4.0 \times 0.60} = 2.4,\qquad r_i = \sqrt{2.4} \approx 1.55$$

  $$D_i = \frac{2.4}{4}\times\frac{0.40}{0.60} = 0.6 \times 0.667 = 0.40$$

  標準化残差は $|r_i| < 2$ で外れ値とはいえない。一方、てこ比 $h_{ii} = 0.40$ は平均 $(p+1)/n = 0.133$ の 3 倍で、目安 $2(p+1)/n = 0.267$ を超えるので、説明変数の空間で外れた位置にある高てこ比の点である。クックの距離 0.40 は目安の 1（あるいは $F_{0.5}(p+1, n-p-1) \approx 0.86$）よりは小さく、単独で推定結果を大きく変える点とまではいえないが、この点を除いた再推定などで影響を確認しておくべきである。

重回帰の診断の基礎となるハット行列の性質を、残差の分散・誤差分散の不偏推定・てこ比・クックの距離までつなげる問題です。どれも「$H$ は列空間への直交射影行列である」という一点から導けます。

### 解答の流れ

1. $H$ は $X$ の列空間への直交射影なので、対称・べき等で、トレース（＝階数）は $p+1$。
2. 残差は $(I - H)\boldsymbol{\varepsilon}$ と誤差だけで書けるので、期待値 0、分散 $\sigma^2(I - H)$。
3. 2 次形式の期待値はトレースで計算する：$E[\boldsymbol{\varepsilon}^\top A\boldsymbol{\varepsilon}] = \sigma^2\operatorname{tr}A$。
4. $h_{ii}$ は射影行列の対角成分なので 0 と 1 の間にある。切片があると下限は $1/n$。

### つまずきやすい点

- 残差の分散は各点で等しくなく、$V[e_i] = \sigma^2(1 - h_{ii})$ である。てこ比の大きい点ほど回帰直線（面）が引き寄せられて残差が小さくなるので、残差の大きさだけで外れ値を判断するのは危険である。標準化残差はこの違いを補正したもの。
- クックの距離は「残差の大きさ $r_i^2$」と「てこ比 $h_{ii}/(1-h_{ii})$」の積である。てこ比が大きくても残差が小さければ $D_i$ は大きくならない。

### ポイント

- 観測値 $i$ を除いて推定したときの予測誤差は $y_i - \hat{y}_{(i)} = e_i/(1 - h_{ii})$ で、再推定しなくても計算できる。
- 目安：$h_{ii} > 2(p+1)/n$ で高てこ比、$|r_i| > 2$〜$3$ で外れ値の疑い、$D_i > 1$（または $4/n$）で影響の大きい点。
