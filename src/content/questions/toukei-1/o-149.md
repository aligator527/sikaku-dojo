同時密度は $\theta^{-n}\exp\left\{-\dfrac{\sum x_i^2}{2\theta^2} + \dfrac{\sum x_i}{\theta}\right\} \times (\text{定数})$ なので、分解定理より $(\sum X_i, \sum X_i^2)$ は十分統計量で、さらに最小十分です。しかし $E\left[\dfrac{n}{n+1}\bar{X}^2 - S^2\right] = 0$ がすべての $\theta$ で成り立つのに、この関数は 0 ではないので、完備ではありません。

### 最小十分性

2 つの標本 $\boldsymbol{x},\ \boldsymbol{y}$ の尤度比は

$$\frac{L(\theta;\boldsymbol{x})}{L(\theta;\boldsymbol{y})} = \exp\left\{-\frac{\sum x_i^2 - \sum y_i^2}{2\theta^2} + \frac{\sum x_i - \sum y_i}{\theta}\right\}$$

で、これが $\theta$ によらないのは $\sum x_i = \sum y_i$ かつ $\sum x_i^2 = \sum y_i^2$ のときに限られます（$1/\theta$ と $1/\theta^2$ は 1 次独立な関数）。よって $(\sum X_i, \sum X_i^2)$ は最小十分統計量です。

### 完備でないこと

$E[\bar{X}^2] = V[\bar{X}] + E[\bar{X}]^2 = \dfrac{\theta^2}{n} + \theta^2 = \dfrac{n+1}{n}\theta^2$、$E[S^2] = \theta^2$ なので

$$g(T) = \frac{n}{n+1}\bar{X}^2 - S^2\quad \text{について}\quad E_\theta[g(T)] = 0\quad (\text{すべての } \theta > 0)$$

ですが、$g(T)$ は連続分布に従う確率変数で、$P(g(T) = 0) = 0$ です。

### 各選択肢の検討

- $\sum X_i$ だけで十分：誤り。尤度は $\sum x_i^2$ にも $\theta$ を通じて依存する。
- 最小十分だが完備でない：正しい。
- 最小十分で完備：誤り（上記の $g$ が反例）。母数が 1 次元なのに十分統計量が 2 次元である「曲がった指数型分布族」では、完備性が成り立たないことが多い。
- $\sum X_i^2$ だけで最小十分：誤り。$\sum x_i$ の情報も必要である。
- $\bar{X}/S$ が十分：誤り。$X_i = \theta Z_i$（$Z_i \sim N(1, 1)$）と書けるので、$\bar{X}/S = \bar{Z}/S_Z$ の分布は $\theta$ によらない（補助統計量）。$\theta$ についての情報をもたない。

### ポイント

- 完備性がないと、レーマン・シェフェの定理で一様最小分散不偏推定量を構成する議論が使えない。
- 補助統計量 $\bar{X}/S$ は最小十分統計量の関数であり、バスーの定理（完備十分統計量と補助統計量は独立）の前提が満たされない例にもなっている。
