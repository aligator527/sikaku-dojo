位置母数族 $f(x - \theta)$ が $X$ に関して単調尤度比をもつことは、$\log f$ が凹関数（$f$ が対数凹）であることと同値です。正規・ロジスティック・ラプラス分布の密度は対数凹ですが、コーシー分布は裾が重く対数凹ではありません。実際、コーシー分布の尤度比は $x \to \pm\infty$ でともに 1 に近づくので、単調にはなりません。

### 各選択肢の検討

- 正規分布：尤度比は $\exp\{(\theta_1 - \theta_0)x - (\theta_1^2 - \theta_0^2)/2\}$ で、$x$ の増加関数です。単調尤度比をもちます。
- ロジスティック分布：$\log f(x) = -x - 2\log(1 + e^{-x})$ の 2 階微分は $-2e^{-x}/(1 + e^{-x})^2 < 0$ で、狭義の対数凹です。よって尤度比は $x$ の増加関数で、単調尤度比をもちます。
- ラプラス分布：尤度比 $\exp(|x - \theta_0| - |x - \theta_1|)$ は、$x \leq \theta_0$ で $e^{-(\theta_1 - \theta_0)}$、$\theta_0 < x < \theta_1$ で $e^{2x - \theta_0 - \theta_1}$（増加）、$x \geq \theta_1$ で $e^{\theta_1 - \theta_0}$ となり、非減少です。単調尤度比をもちます（狭義ではない）。
- コーシー分布：正しい（単調尤度比をもたない）。$\theta_0 = 0,\ \theta_1 = 1$ とすると尤度比は $(1 + x^2)/\{1 + (x - 1)^2\}$ で、$x = (1 - \sqrt{5})/2 \approx -0.62$ で最小値約 $0.38$、$x = (1 + \sqrt{5})/2 \approx 1.62$ で最大値約 $2.62$ をとり、$x \to \pm\infty$ ではともに 1 に近づきます。増加したあと減少するので単調ではありません。
- 一様分布：$\theta_0 < \theta_1$ のとき尤度比は $0 < x < \theta_0$ で $\theta_0/\theta_1$、$\theta_0 \leq x < \theta_1$ で $+\infty$（分母が 0）となり、非減少です。単調尤度比をもちます（$X_{(n)}$ にもとづく片側検定が一様最強力になる根拠）。

### ポイント

- 単調尤度比をもつ分布族では、カーリン・ルビンの定理により片側検定 $H_0: \theta \leq \theta_0$ vs. $H_1: \theta > \theta_0$ の一様最強力検定が存在します（「$T > c$ なら棄却」）。
- 1 母数指数型分布族 $f(x;\theta) = h(x)\exp\{\eta(\theta)T(x) - A(\theta)\}$ は、$\eta$ が単調増加なら $T$ に関して単調尤度比をもちます。
- コーシー分布の位置母数については一様最強力検定が存在しないため、$\theta_0$ の近くで検出力の傾きを最大にする局所最強力検定（スコア検定）がよく使われます。
