stem: |
  $X_1, \ldots, X_n$ は互いに独立に、確率密度関数

  $$f(x;\theta) = \theta x^{\theta - 1}\qquad (0 < x < 1)$$

  のベータ分布 $\mathrm{Beta}(\theta, 1)$ に従うとする（$\theta > 0$ は未知母数）。以下の各問に答えよ。

  [1] $\theta$ のモーメント推定量 $\tilde{\theta}$ を求めよ。

  [2] $\theta$ の最尤推定量 $\hat{\theta}$ を求めよ。さらに $Y_i = -\log X_i$ の分布を求め、$E[\hat{\theta}]$ を計算せよ（$n \geq 2$）。

  [3] $\sqrt{n}(\tilde{\theta} - \theta)$ と $\sqrt{n}(\hat{\theta} - \theta)$ の極限分布をそれぞれ求めよ。

  [4] $\hat{\theta}$ に対する $\tilde{\theta}$ の漸近相対効率（漸近分散の比 $\mathrm{AV}(\hat{\theta})/\mathrm{AV}(\tilde{\theta})$）を求め、それが常に 1 未満であることを示せ。また $\theta = 1$ のときの値を求めよ。
modelAnswer: |
  **[1]** $E[X] = \int_0^1 \theta x^\theta\,dx = \dfrac{\theta}{\theta + 1}$。$\bar{X} = \tilde{\theta}/(\tilde{\theta} + 1)$ を解いて

  $$\tilde{\theta} = \frac{\bar{X}}{1 - \bar{X}}$$

  **[2]** 対数尤度 $\ell(\theta) = n\log\theta + (\theta - 1)\sum\log x_i$ より

  $$\ell'(\theta) = \frac{n}{\theta} + \sum_{i=1}^{n}\log x_i = 0\ \Rightarrow\ \hat{\theta} = -\frac{n}{\sum_{i=1}^{n}\log X_i}$$

  $\ell''(\theta) = -n/\theta^2 < 0$ なので最大値を与える。$Y_i = -\log X_i$ について $P(Y_i > y) = P(X_i < e^{-y}) = e^{-\theta y}$ なので、$Y_i$ は率 $\theta$ の指数分布に従い、$S = \sum Y_i \sim Ga(n, \theta)$。$\hat{\theta} = n/S$ で

  $$E\left[\frac{1}{S}\right] = \int_0^\infty\frac{1}{s}\cdot\frac{\theta^n s^{n-1}e^{-\theta s}}{\Gamma(n)}\,ds = \frac{\theta\,\Gamma(n-1)}{\Gamma(n)} = \frac{\theta}{n - 1}$$

  より $E[\hat{\theta}] = \dfrac{n\theta}{n - 1}$（偏りがあり、$(n-1)\hat{\theta}/n$ は不偏）。

  **[3]** **モーメント推定量.** $V[X] = E[X^2] - E[X]^2 = \dfrac{\theta}{\theta + 2} - \dfrac{\theta^2}{(\theta + 1)^2} = \dfrac{\theta}{(\theta + 1)^2(\theta + 2)}$。$g(m) = m/(1 - m)$ とすると $g'(m) = 1/(1 - m)^2$、$m = \theta/(\theta + 1)$ で $g'(m) = (\theta + 1)^2$。中心極限定理とデルタ法より

  $$\sqrt{n}(\tilde{\theta} - \theta) \xrightarrow{d} N\left(0,\ (\theta + 1)^4\cdot\frac{\theta}{(\theta + 1)^2(\theta + 2)}\right) = N\left(0,\ \frac{\theta(\theta + 1)^2}{\theta + 2}\right)$$

  **最尤推定量.** $I(\theta) = -E[\partial^2\log f/\partial\theta^2] = 1/\theta^2$ なので、最尤推定量の漸近正規性より

  $$\sqrt{n}(\hat{\theta} - \theta) \xrightarrow{d} N(0,\ \theta^2)$$

  （$\hat{\theta} = 1/\bar{Y}$ に中心極限定理とデルタ法を適用しても、$\bar{Y}$ の漸近分散 $1/\theta^2$ と $g'(1/\theta)^2 = \theta^4$ から同じ結果を得る。）

  **[4]**

  $$\mathrm{ARE} = \frac{\theta^2}{\theta(\theta + 1)^2/(\theta + 2)} = \frac{\theta(\theta + 2)}{(\theta + 1)^2} = 1 - \frac{1}{(\theta + 1)^2} < 1$$

  よって、すべての $\theta > 0$ でモーメント推定量は最尤推定量より漸近的に効率が悪い。$\theta = 1$（一様分布）では $\mathrm{ARE} = 3/4$。$\theta \to 0$ で 0、$\theta \to \infty$ で 1 に近づく。

  - '[2] 最尤推定量 $-n/\sum\log X_i$ を求め、$-\log X_i$ が率 $\theta$ の指数分布に従うことから $E[\hat{\theta}] = n\theta/(n-1)$ を導いている'
  - '[3] $V[X]$ を求め、デルタ法でモーメント推定量の漸近分散 $\theta(\theta+1)^2/(\theta+2)$ を得ている'
  - '[3] フィッシャー情報量 $1/\theta^2$ から最尤推定量の漸近分散 $\theta^2$ を得ている'
  - '[4] $\mathrm{ARE} = 1 - 1/(\theta+1)^2$ を示し、$\theta = 1$ で $3/4$ を得ている'
---
同じ母数をモーメント法と最尤法で推定し、デルタ法とフィッシャー情報量で漸近分散を比べる問題です。最尤推定量は正則条件のもとで漸近有効（漸近分散がクラーメル・ラオの下限 $1/I(\theta)$ に一致）なので、他の推定量の漸近相対効率は 1 以下になります。

### 解答の流れ

1. モーメント法は 1 次モーメントの方程式を $\theta$ について解く。
2. 最尤推定量は十分統計量 $\sum\log X_i$ の関数になる。$-\log X$ の分布を求めると、正確な期待値も計算できる。
3. モーメント推定量の漸近分散は「$\bar{X}$ の漸近分散 × $g'$ の 2 乗」（デルタ法）。
4. 漸近相対効率は漸近分散の逆数の比。

### つまずきやすい点

- [2] で $E[\hat{\theta}] = n/E[S] = \theta$ とする誤り。$E[1/S] \neq 1/E[S]$（イェンセンの不等式より $E[1/S] > 1/E[S]$）。
- [3] でデルタ法の $g'$ を $\bar{X}$ の値（標本）で評価したままにする誤り。漸近分散は真の値 $m = \theta/(\theta + 1)$ で評価する。
- 漸近相対効率の向き：「$\tilde{\theta}$ の $\hat{\theta}$ に対する効率」は $\mathrm{AV}(\hat{\theta})/\mathrm{AV}(\tilde{\theta})$。逆にすると 1 より大きな値になる。

### ポイント

- モーメント推定量は十分統計量 $\sum\log X_i$ ではなく $\sum X_i$ にもとづくため、情報を一部失う。指数型分布族では、十分統計量の期待値を合わせるモーメント法（$E[\log X] = -1/\theta$ を使う）が最尤法と一致する。
- 漸近相対効率 $3/4$ は「モーメント推定量で最尤推定量と同じ精度を得るには約 $4/3$ 倍の標本が必要」と解釈できる。
