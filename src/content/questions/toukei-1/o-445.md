層ごとに $a_kd_k/n_k$ と $b_kc_k/n_k$ を計算して足し合わせます。喫煙者の層（$n = 200$）は $13.5$ と $11.0$、非喫煙者の層（$n = 250$）は $6.8$ と $4.8$ なので、$\widehat{OR}_{MH} = (13.5 + 6.8)/(11.0 + 4.8) = 20.3/15.8 = 1.28$ です。

### 計算

| 層 | $n_k$ | $a_kd_k/n_k$ | $b_kc_k/n_k$ | 層別 $\widehat{OR}_k$ |
| --- | --- | --- | --- | --- |
| 喫煙者 | 200 | $45 \times 60/200 = 13.5$ | $55 \times 40/200 = 11.0$ | 1.23 |
| 非喫煙者 | 250 | $10 \times 170/250 = 6.8$ | $40 \times 30/250 = 4.8$ | 1.42 |
| 計 | | 20.3 | 15.8 | |

$$\widehat{OR}_{MH} = \frac{20.3}{15.8} = 1.2848 \approx 1.28$$

調整オッズ比 $1.28$ は 2 つの層別オッズ比の間にあり、重み $b_kc_k/n_k$（$11.0$ と $4.8$）による加重平均になっています。

### ポイント

- 層を無視して併合した粗オッズ比は $(55 \times 230)/(95 \times 70) = 1.90$ で、調整後の $1.28$ より大きい。喫煙者ほど曝露が多く、喫煙が肺がんの強い危険因子であるため、粗オッズ比が喫煙の影響を含んで過大になっている（交絡）。
- よくある誤り：各層の $n_k$ で割らずに $\sum a_kd_k/\sum b_kc_k = (2700 + 1700)/(2200 + 1200) = 1.29$ とする（本問では近い値になるが、層の大きさが大きく異なると結果が変わる）、層別オッズ比の単純平均 $(1.23 + 1.42)/2 = 1.32$ とする。
- マンテル・ヘンツェル推定量は、オッズ比が層間で均一であるという仮定のもとで共通オッズ比を推定する。均一性はブレスロー・デイ検定で確認できる（本問では $p \approx 0.77$ で、均一性は否定されない）。
