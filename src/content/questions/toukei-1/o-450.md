  **[1]** $V\left[\sum c_iy_i\right] = \sum c_i^2s_i^2 = \sum c_i^2/w_i$ を $\sum c_i = 1$ のもとで最小化する。コーシー・シュワルツの不等式より

  $$1 = \left(\sum c_i\right)^2 = \left(\sum\frac{c_i}{\sqrt{w_i}}\cdot\sqrt{w_i}\right)^2 \leq \left(\sum\frac{c_i^2}{w_i}\right)\left(\sum w_i\right)$$

  なので $\sum c_i^2/w_i \geq 1/\sum w_i$。等号は $c_i/\sqrt{w_i} \propto \sqrt{w_i}$、すなわち $c_i \propto w_i$ のとき成り立つ。したがって最適な重みは $c_i = w_i/\sum w_j$、最小分散は

  $$V[\hat{\theta}_F] = \frac{1}{\sum w_i}$$

  **[2]**

  $$Q = \sum w_iy_i^2 - \frac{\left(\sum w_iy_i\right)^2}{\sum w_i} = 14.65 - \frac{(-23.9)^2}{88.25} = 14.65 - 6.473 = 8.18$$

  $$I^2 = \frac{8.18 - 4}{8.18} = 0.51\quad(51\%)$$

  $Q = 8.18 < 9.488$ なので、有意水準 5% では「異質性なし」の帰無仮説は棄却されない。ただし $I^2 = 51\%$ は、総変動の約半分が試験間の真の効果の違いによることを示し、中程度の異質性がある。

  **[3]**

  $$\hat{\tau}^2 = \frac{8.18 - 4}{88.25 - 1801.06/88.25} = \frac{4.18}{88.25 - 20.41} = \frac{4.18}{67.84} = 0.0616$$

  $$\hat{\mu}_R = \frac{\sum w_i^{*}y_i}{\sum w_i^{*}} = \frac{-11.76}{40.32} = -0.292,\qquad \mathrm{SE}(\hat{\mu}_R) = \frac{1}{\sqrt{40.32}} = 0.157$$

  $$95\%\ \text{信頼区間：}\ -0.292 \pm 1.96 \times 0.157 = [-0.600,\ 0.017]$$

  **[4]** 固定効果モデルでは信頼区間が 0 を含まず、薬剤の効果は有意である。変量効果モデルでは区間が 0 を含み、有意ではない。変量効果モデルは試験間の真の効果のばらつき $\tau^2$ を誤差に加えるため、重みが均等に近づき（大きな試験の重みが相対的に下がり）、標準誤差が $0.106$ から $0.157$ に大きくなる。固定効果モデルは「すべての試験が同じ効果を推定している」という仮定のもとで、試験内の誤差だけを考慮した推論であり、異質性があればその精度を過大評価する。

  異質性の検定は、試験数が 5 と少ないため検出力が低く、「有意でない」ことは「異質性がない」ことを意味しない。$I^2 = 51\%$ や、試験 4 のように効果の向きが逆の試験があることを踏まえると、異質性を考慮した変量効果モデルの結果を重視し、効果の大きさは試験によって異なる可能性がある、と慎重に結論するのが妥当である。さらに、患者背景や用量などで異質性の原因を探る（サブグループ解析・メタ回帰）ことも考えられる。

メタアナリシスでは、固定効果モデルと変量効果モデルの違い、異質性の指標（$Q$、$I^2$、$\tau^2$）の計算と解釈が基本です。同じデータでも、モデルによって結論が変わりうることを数値で確認します。

### 解答の流れ

1. 加重平均の分散を最小化する。逆分散重みが最適であることは、[1] の不等式 1 本で示せる。
2. $Q$ は「平方和の分解」の形 $\sum w_iy_i^2 - (\sum w_iy_i)^2/\sum w_i$ で計算すると楽である。
3. $Q$ の期待値 $E[Q] = (k - 1) + \tau^2\left(\sum w_i - \sum w_i^2/\sum w_i\right)$ をモーメント法で解いたものがダーシモニアン・レアード推定量。
4. 2 つのモデルの信頼区間を比べ、違いの原因を重みと分散から説明する。

### つまずきやすい点

- $I^2$ は異質性の「割合」の指標で、$\tau^2$ は異質性の「大きさ」（効果の尺度での分散）の指標である。試験の精度が高いと、同じ $\tau^2$ でも $I^2$ は大きくなる。
- 変量効果モデルの $\mu$ は「試験ごとに異なる真の効果の平均」であり、固定効果モデルの $\theta$（共通の効果）とは推定の対象が異なる。
- 変量効果モデルでは小規模な試験の重みが相対的に大きくなるので、小規模試験ほど効果が大きく報告される傾向（出版バイアス）があると、結果がその影響を受けやすい。ファンネルプロットで確認する。

### ポイント

- 新しい試験で期待される効果の範囲を示す予測区間 $\hat{\mu}_R \pm t_{k-2}\sqrt{\hat{\tau}^2 + \mathrm{SE}^2}$ は、信頼区間よりさらに広い。
