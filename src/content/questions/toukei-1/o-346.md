  標準化された観測変数 $x_1, \ldots, x_p$ に、1 因子モデル

  $$x_j = \lambda_jf + e_j\qquad (j = 1, \ldots, p)$$

  を当てはめる。共通因子 $f$ は平均 0、分散 1、独自因子 $e_j$ は平均 0、分散 $\psi_j$ で、$f,\ e_1, \ldots, e_p$ は互いに無相関とする。以下の各問に答えよ。

  [1] $i \neq j$ のとき $\mathrm{Corr}(x_i, x_j) = \lambda_i\lambda_j$ となることを示し、共通性 $h_j^2$ と独自性 $\psi_j$ を $\lambda_j$ で表せ。

  [2] $p = 3$ で、観測された相関係数が $r_{12} = 0.48$、$r_{13} = 0.42$、$r_{23} = 0.56$ であった。モデルが相関行列を完全に再現するとして、因子負荷量 $\lambda_1,\ \lambda_2,\ \lambda_3$（すべて正とする）と独自性を求めよ。

  [3] 相関行列に 1 因子モデルを当てはめるときの自由度（相関係数の個数 $-$ 自由な母数の個数）を $p$ で表せ。$p = 3$ と $p = 4$ の場合について、モデルが相関行列に課す制約を述べよ。

  [4] $p = 3$ で $r_{12} = 0.6$、$r_{13} = 0.5$、$r_{23} = 0.25$ が観測された場合、[2] と同じ方法で解を求めると何が起こるか。このような解を何と呼ぶか、また考えられる原因を述べよ。
modelAnswer: |
  **[1]** $V[x_j] = \lambda_j^2V[f] + V[e_j] = \lambda_j^2 + \psi_j = 1$（標準化）。$i \neq j$ では無相関の仮定から

  $$\mathrm{Cov}(x_i, x_j) = \mathrm{Cov}(\lambda_if + e_i,\ \lambda_jf + e_j) = \lambda_i\lambda_jV[f] = \lambda_i\lambda_j$$

  分散が 1 なので $\mathrm{Corr}(x_i, x_j) = \lambda_i\lambda_j$。共通性（共通因子で説明される分散の割合）は $h_j^2 = \lambda_j^2$、独自性は $\psi_j = 1 - \lambda_j^2$。

  **[2]** $r_{12} = \lambda_1\lambda_2$、$r_{13} = \lambda_1\lambda_3$、$r_{23} = \lambda_2\lambda_3$ より

  $$\lambda_1^2 = \frac{r_{12}r_{13}}{r_{23}} = \frac{0.48 \times 0.42}{0.56} = 0.36,\quad \lambda_2^2 = \frac{r_{12}r_{23}}{r_{13}} = \frac{0.48 \times 0.56}{0.42} = 0.64,\quad \lambda_3^2 = \frac{r_{13}r_{23}}{r_{12}} = \frac{0.42 \times 0.56}{0.48} = 0.49$$

  よって $\lambda_1 = 0.6,\ \lambda_2 = 0.8,\ \lambda_3 = 0.7$、独自性は $\psi_1 = 0.64,\ \psi_2 = 0.36,\ \psi_3 = 0.51$。

  **[3]** 相関係数は $p(p-1)/2$ 個、母数は $\lambda_1, \ldots, \lambda_p$ の $p$ 個（$\psi_j = 1 - \lambda_j^2$ は従属して決まる）なので、自由度は

  $$\frac{p(p-1)}{2} - p = \frac{p(p-3)}{2}$$

  $p = 3$ では自由度 0 で、正の相関の組なら（[2] のように）常に完全に当てはまる（丁度識別）。モデルの適合を検証することはできない。$p = 4$ では自由度 2 で、6 個の相関が 4 個の負荷量で表されるので

  $$r_{12}r_{34} = r_{13}r_{24} = r_{14}r_{23}\ (= \lambda_1\lambda_2\lambda_3\lambda_4)$$

  という 2 つの独立な制約（テトラッド条件）が課され、データでこれを検証できる。

  **[4]** $\lambda_1^2 = \dfrac{0.6 \times 0.5}{0.25} = 1.2 > 1$ となり、独自性 $\psi_1 = 1 - 1.2 = -0.2$ が負になる。分散が負という解釈できない解であり、**不適解**（ヘイウッドケース）と呼ばれる。（$\lambda_2^2 = 0.6 \times 0.25/0.5 = 0.3$、$\lambda_3^2 = 0.5 \times 0.25/0.6 = 0.208$。）

  原因としては、標本サイズが小さく相関係数の標本変動が大きいこと、1 因子モデル自体が誤っている（$x_2$ と $x_3$ の相関 0.25 が 1 因子から予想されるより小さい、あるいは別の因子がある）こと、変数の数が少なく母数が不安定なこと、などが考えられる。対処として、$\psi_j \geq 0$ の制約をおいた推定、変数や因子数の見直し、標本の追加などを行う。

1 因子モデルの共分散構造、3 変数での解の陽な表現、自由度と識別、不適解という、因子分析の基本的な論点を手計算で確認できる問題です。

### 解答の流れ

1. 因子モデルでは、観測変数の相関はすべて共通因子を経由して生じる。1 因子なら相関は負荷量の積になる。
2. 3 つの式 $r_{ij} = \lambda_i\lambda_j$ を掛け合わせたり割ったりして、各負荷量の 2 乗を求める。
3. 自由度は「データが与える情報の数」から「推定する母数の数」を引いたもの。正なら適合度を検定できる。
4. 計算上の負荷量の 2 乗が 1 を超えると、独自性が負になる。

### つまずきやすい点

- [2] で $\lambda_j$ の符号は相関行列からは決まらない（すべての符号を同時に反転しても相関は同じ）。因子の向きを決める約束として、正の値を選んでいる。
- 1 因子モデルでは、負荷量の 2 乗が共通性であり、因子負荷量と観測変数の相関係数は一致する（直交因子の場合）。

### ポイント

- 一般の $m$ 因子モデル（直交、回転の自由度を除く）では、分散共分散行列に当てはめたときの自由度は $\dfrac{(p - m)^2 - (p + m)}{2}$ である。$m = 1$ では $p(p-3)/2$ となり、[3] と一致する。
- 1 因子モデルが成り立つとき、尺度得点の信頼性は $\omega = (\sum\lambda_j)^2/\{(\sum\lambda_j)^2 + \sum\psi_j\}$ で評価できる。[2] の 3 変数では $\omega = 2.1^2/(4.41 + 1.51) = 0.745$。
