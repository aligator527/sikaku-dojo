  $X_1, \ldots, X_n$ は互いに独立に、確率密度関数

  $$f(x;\theta) = \frac{1}{\theta}\exp\left(-\frac{x}{\theta}\right) \qquad (x > 0)$$

  をもつ指数分布に従うとする。ここで $\theta > 0$ は未知母数である。以下の各問に答えよ。

  [1] $\theta$ の最尤推定量 $\hat{\theta}$ を求めよ。

  [2] $\hat{\theta}$ が $\theta$ の不偏推定量であることを示し、その分散を求めよ。

  [3] $X_1, \ldots, X_n$ にもとづくフィッシャー情報量 $I_n(\theta)$ を求め、$\hat{\theta}$ の分散がクラーメル・ラオの下限に一致することを示せ。

  [4] $2n\bar{X}/\theta$ が自由度 $2n$ のカイ二乗分布に従うことを示し、これを用いて $\theta$ の 95% 信頼区間を構成せよ。さらに、$n = 10,\ \bar{x} = 5.0$ のときの区間を小数第 2 位まで求めよ。ただし、$\chi^2_{0.025}(20) = 34.17$、$\chi^2_{0.975}(20) = 9.591$ とする（$\chi^2_{\alpha}(m)$ は自由度 $m$ のカイ二乗分布の上側 $100\alpha\%$ 点）。
modelAnswer: |
  **[1]** 対数尤度は

  $$\ell(\theta) = -n\log\theta - \frac{1}{\theta}\sum_{i=1}^{n}x_i$$

  $$\ell'(\theta) = -\frac{n}{\theta} + \frac{\sum x_i}{\theta^2} = 0 \ \Rightarrow\ \hat{\theta} = \bar{X}$$

  $\ell''(\hat{\theta}) = \dfrac{n}{\bar{x}^2} - \dfrac{2n\bar{x}}{\bar{x}^3} = -\dfrac{n}{\bar{x}^2} < 0$ なので、これは最大値を与える。

  **[2]** $E[X_i] = \theta$、$V[X_i] = \theta^2$ より

  $$E[\hat{\theta}] = E[\bar{X}] = \theta,\qquad V[\hat{\theta}] = \frac{\theta^2}{n}$$

  **[3]** $\log f(x;\theta) = -\log\theta - x/\theta$ より

  $$\frac{\partial^2}{\partial\theta^2}\log f = \frac{1}{\theta^2} - \frac{2x}{\theta^3},\qquad I_1(\theta) = -E\left[\frac{1}{\theta^2} - \frac{2X}{\theta^3}\right] = -\frac{1}{\theta^2} + \frac{2}{\theta^2} = \frac{1}{\theta^2}$$

  よって $I_n(\theta) = n/\theta^2$。不偏推定量の分散の下限（クラーメル・ラオの下限）は $1/I_n(\theta) = \theta^2/n$ で、[2] の $V[\hat{\theta}]$ に一致する。したがって $\hat{\theta}$ は有効推定量（一様最小分散不偏推定量）である。

  **[4]** $X_i/\theta$ は平均 1 の指数分布に従うので、$Y_i = 2X_i/\theta$ の密度は $\frac{1}{2}e^{-y/2}$ であり、これは自由度 2 のカイ二乗分布である（モーメント母関数 $(1-2t)^{-1}$）。独立な $n$ 個の和は、モーメント母関数が $(1-2t)^{-n}$ となるので

  $$\frac{2n\bar{X}}{\theta} = \sum_{i=1}^{n}\frac{2X_i}{\theta} \sim \chi^2(2n)$$

  これは $\theta$ によらない分布をもつ枢軸量なので

  $$P\left(\chi^2_{0.975}(2n) \leq \frac{2n\bar{X}}{\theta} \leq \chi^2_{0.025}(2n)\right) = 0.95$$

  を $\theta$ について解くと、95% 信頼区間は

  $$\left[\frac{2n\bar{X}}{\chi^2_{0.025}(2n)},\ \frac{2n\bar{X}}{\chi^2_{0.975}(2n)}\right]$$

  $n = 10,\ \bar{x} = 5.0$ では $2n\bar{x} = 100$ なので

  $$\left[\frac{100}{34.17},\ \frac{100}{9.591}\right] = [2.93,\ 10.43]$$

指数分布は 1 級の推定論で最もよく使われる題材です。最尤推定量・不偏性・フィッシャー情報量・クラーメル・ラオの下限・枢軸量による正確な信頼区間という、推定論の基本的な流れを一つの分布で確認できます。

### 解答の流れ

1. 対数尤度を微分して最尤推定量 $\hat{\theta} = \bar{X}$ を得る。
2. 期待値と分散を計算する（指数分布の分散は平均の 2 乗）。
3. フィッシャー情報量は「スコアの分散」または「対数尤度の 2 階微分の期待値の符号を反転したもの」で計算する。
4. $2X_i/\theta \sim \chi^2(2)$ を使い、カイ二乗分布の再生性から枢軸量を作る。

### つまずきやすい点

- 母数の取り方：密度が $\lambda e^{-\lambda x}$（レート）の場合、最尤推定量は $1/\bar{X}$ となり、これは不偏ではない（$E[1/\bar{X}] = n\lambda/(n-1)$）。不偏性は母数の変換で保たれないが、最尤推定量は変換に対して不変（$\hat{\lambda} = 1/\hat{\theta}$）である。
- 信頼区間の向き：$2n\bar{X}/\theta$ が大きいほど $\theta$ は小さいので、下限には上側 2.5% 点（34.17）、上限には下側 2.5% 点（9.591）が対応する。
- 得られた区間 $[2.93,\ 10.43]$ は $\bar{x} = 5.0$ に関して非対称である。正規近似 $\bar{x} \pm 1.96\,\bar{x}/\sqrt{n} = [1.90,\ 8.10]$ との違いは、$n$ が小さいほど大きい。

### ポイント

- 有効推定量が存在するのは、スコア関数が $\hat{\theta} - \theta$ の定数倍で書ける場合（指数型分布族の自然な十分統計量）に限られる。ここでは $\ell'(\theta) = \dfrac{n}{\theta^2}(\bar{X} - \theta)$。
