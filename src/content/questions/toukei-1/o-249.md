修正項 $CT = 160^2/16 = 1600$ を用いて、総平方和 $50$、行平方和 $6$、列平方和 $6$、加工条件の平方和 $30$ を求めると、残差平方和は $50 - 6 - 6 - 30 = 8$ です。残差の自由度は $(4 - 1)(4 - 2) = 6$ なので、$F = (30/3)/(8/6) = 10/1.333 = 7.50$ となります。

### 計算

$$CT = \frac{160^2}{16} = 1600,\qquad S_T = 1650 - 1600 = 50$$

$$S_{\text{行}} = \frac{36^2 + 42^2 + 40^2 + 42^2}{4} - 1600 = \frac{6424}{4} - 1600 = 6$$

$$S_{\text{列}} = \frac{38^2 + 40^2 + 44^2 + 38^2}{4} - 1600 = \frac{6424}{4} - 1600 = 6$$

$$S_{\text{条件}} = \frac{32^2 + 38^2 + 46^2 + 44^2}{4} - 1600 = \frac{6520}{4} - 1600 = 30$$

$$S_E = 50 - 6 - 6 - 30 = 8$$

| 要因 | 平方和 | 自由度 | 平均平方 | $F$ |
| --- | --- | --- | --- | --- |
| 作業者（行） | 6 | 3 | 2.000 | |
| 作業日（列） | 6 | 3 | 2.000 | |
| 加工条件 | 30 | 3 | 10.000 | 7.50 |
| 残差 | 8 | 6 | 1.333 | |
| 計 | 50 | 15 | | |

$F = 7.50 > F_{0.05}(3, 6) = 4.757$ なので、有意水準 5% で加工条件の効果は有意です。

### ポイント

- $p \times p$ のラテン方格の残差の自由度は $(p^2 - 1) - 3(p - 1) = (p - 1)(p - 2)$ です。$p = 4$ では 6 しかないので、小さなラテン方格では検出力が低くなります（反復するか、ブロックを追加して自由度を確保します）。
- よくある誤り：残差の自由度を二元配置と同じ $(p - 1)^2 = 9$ とする（加工条件の自由度を引き忘れる）と、$F = 10/(8/9) = 11.25$ となります。
- ラテン方格は、行・列・処理の間に交互作用がないことを前提に、2 つのブロック因子を同時に除く計画です。交互作用があると残差に混入します。
