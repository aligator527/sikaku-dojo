stem: |
  中心化した目的変数 $\boldsymbol{y}$（$n \times 1$）と、各列を中心化・標準化した説明変数行列 $X$（$n \times p$、階数 $p$）について、切片のない線形モデル

  $$\boldsymbol{y} = X\boldsymbol{\beta} + \boldsymbol{\varepsilon},\qquad E[\boldsymbol{\varepsilon}] = \boldsymbol{0},\quad V[\boldsymbol{\varepsilon}] = \sigma^2 I_n$$

  を考える。$k \geq 0$ に対してリッジ推定量を $\hat{\boldsymbol{\beta}}(k) = (X^\top X + kI_p)^{-1}X^\top\boldsymbol{y}$ とする（$k = 0$ は最小二乗推定量）。$X^\top X = PDP^\top$（$P$ は直交行列、$D = \mathrm{diag}(d_1, \ldots, d_p)$、$d_j > 0$）とスペクトル分解し、$\boldsymbol{\alpha} = P^\top\boldsymbol{\beta} = (\alpha_1, \ldots, \alpha_p)^\top$ とおく。以下の各問に答えよ。

  [1] $\hat{\boldsymbol{\beta}}(k)$ が $\|\boldsymbol{y} - X\boldsymbol{\beta}\|^2 + k\|\boldsymbol{\beta}\|^2$ を最小にする $\boldsymbol{\beta}$ であることを示せ。

  [2] 平均二乗誤差 $\mathrm{MSE}(k) = E\left[\|\hat{\boldsymbol{\beta}}(k) - \boldsymbol{\beta}\|^2\right]$ が

  $$\mathrm{MSE}(k) = \sum_{j=1}^{p}\frac{\sigma^2 d_j + k^2\alpha_j^2}{(d_j + k)^2}$$

  となることを示せ。

  [3] $\mathrm{MSE}(k) < \mathrm{MSE}(0)$ となる $k > 0$ が必ず存在することを示せ。

  [4] $X^\top X = I_p$ の場合に $\mathrm{MSE}(k)$ を最小にする $k$ を $p,\ \sigma^2,\ \|\boldsymbol{\beta}\|^2$ で表せ。さらに $p = 4,\ \sigma^2 = 1,\ \|\boldsymbol{\beta}\|^2 = 2$ のとき、その $k$ と最小の $\mathrm{MSE}$ を求め、最小二乗推定量の $\mathrm{MSE}$ と比較せよ。
modelAnswer: |
  **[1]** $Q(\boldsymbol{\beta}) = (\boldsymbol{y} - X\boldsymbol{\beta})^\top(\boldsymbol{y} - X\boldsymbol{\beta}) + k\boldsymbol{\beta}^\top\boldsymbol{\beta}$ を微分して 0 とおくと

  $$\frac{\partial Q}{\partial\boldsymbol{\beta}} = -2X^\top(\boldsymbol{y} - X\boldsymbol{\beta}) + 2k\boldsymbol{\beta} = \boldsymbol{0} \iff (X^\top X + kI_p)\boldsymbol{\beta} = X^\top\boldsymbol{y}$$

  ヘッセ行列 $2(X^\top X + kI_p)$ は正定値なので $Q$ は狭義凸であり、解 $\hat{\boldsymbol{\beta}}(k) = (X^\top X + kI_p)^{-1}X^\top\boldsymbol{y}$ が唯一の最小点である（$k > 0$ なら $X^\top X$ が特異でも逆行列が存在する）。

  **[2]** $W_k = (X^\top X + kI_p)^{-1} = P\,\mathrm{diag}\left(\frac{1}{d_j + k}\right)P^\top$ とおく。$E[\boldsymbol{y}] = X\boldsymbol{\beta}$ より

  $$E[\hat{\boldsymbol{\beta}}(k)] = W_kX^\top X\boldsymbol{\beta} = W_k(X^\top X + kI_p - kI_p)\boldsymbol{\beta} = \boldsymbol{\beta} - kW_k\boldsymbol{\beta}$$

  なので偏りは $-kW_k\boldsymbol{\beta}$、分散共分散行列は $V[\hat{\boldsymbol{\beta}}(k)] = \sigma^2W_kX^\top XW_k$。MSE は「分散のトレース + 偏りの 2 乗ノルム」なので

  $$\mathrm{MSE}(k) = \sigma^2\operatorname{tr}(W_kX^\top XW_k) + k^2\boldsymbol{\beta}^\top W_k^2\boldsymbol{\beta} = \sigma^2\sum_{j=1}^{p}\frac{d_j}{(d_j + k)^2} + k^2\sum_{j=1}^{p}\frac{\alpha_j^2}{(d_j + k)^2}$$

  （$W_kX^\top XW_k = P\,\mathrm{diag}\left(\frac{d_j}{(d_j+k)^2}\right)P^\top$、$\boldsymbol{\beta}^\top W_k^2\boldsymbol{\beta} = \boldsymbol{\alpha}^\top\mathrm{diag}\left(\frac{1}{(d_j+k)^2}\right)\boldsymbol{\alpha}$ を用いた。）これは示すべき式である。

  **[3]** 第 $j$ 項を $k$ で微分すると

  $$\frac{d}{dk}\,\frac{\sigma^2 d_j + k^2\alpha_j^2}{(d_j + k)^2} = \frac{2k\alpha_j^2(d_j + k) - 2(\sigma^2 d_j + k^2\alpha_j^2)}{(d_j + k)^3} = \frac{2d_j(k\alpha_j^2 - \sigma^2)}{(d_j + k)^3}$$

  $\alpha_{\max}^2 = \max_j\alpha_j^2$ とすると、$0 < k < \sigma^2/\alpha_{\max}^2$（$\alpha_{\max} = 0$ なら任意の $k > 0$）ではすべての項の導関数が負なので、$\mathrm{MSE}(k)$ はこの区間で狭義減少する。したがってこの区間の $k$ について $\mathrm{MSE}(k) < \mathrm{MSE}(0) = \sigma^2\sum_j 1/d_j$ である。

  **[4]** $X^\top X = I_p$ では $d_j = 1$、$\sum_j\alpha_j^2 = \|\boldsymbol{\beta}\|^2$ なので

  $$\mathrm{MSE}(k) = \frac{p\sigma^2 + k^2\|\boldsymbol{\beta}\|^2}{(1 + k)^2},\qquad \frac{d}{dk}\mathrm{MSE}(k) = \frac{2(k\|\boldsymbol{\beta}\|^2 - p\sigma^2)}{(1 + k)^3}$$

  よって $k^{*} = p\sigma^2/\|\boldsymbol{\beta}\|^2$ で最小となり、代入すると $\mathrm{MSE}(k^{*}) = \dfrac{p\sigma^2\|\boldsymbol{\beta}\|^2}{\|\boldsymbol{\beta}\|^2 + p\sigma^2}$。

  $p = 4,\ \sigma^2 = 1,\ \|\boldsymbol{\beta}\|^2 = 2$ では $k^{*} = 2$、$\mathrm{MSE}(k^{*}) = \dfrac{4 \times 2}{2 + 4} = \dfrac{4}{3} \approx 1.33$。最小二乗推定量の $\mathrm{MSE}(0) = p\sigma^2 = 4$ の 3 分の 1 になる。分散は $4/9$ に減り、偏りの 2 乗 $8/9$ が加わるが、合計では大きく改善する。

リッジ回帰が最小二乗推定量より平均二乗誤差の意味で改善しうること（ホーエル・ケナードの定理）を、偏りと分散のトレードオフとして示す問題です。

### 解答の流れ

1. 罰則つき残差平方和を微分して正規方程式を得る。
2. 偏りは $-kW_k\boldsymbol{\beta}$、分散は $\sigma^2W_kX^\top XW_k$。$X^\top X$ の固有ベクトルで座標を回すと、すべてが成分ごとの和に分かれる。
3. $k = 0$ の近くでは、分散の減少（1 次の効果）が偏りの 2 乗の増加（2 次の効果）を上回る。
4. 正規直交計画では MSE が $k$ の 1 変数関数になり、最適な $k$ が陽に求まる。

### つまずきやすい点

- 偏りの計算で $W_kX^\top X = I - kW_k$ と変形すると見通しがよい。
- [3] で示すのは「ある $k > 0$ が存在する」ことであり、最適な $k$ は未知の $\boldsymbol{\beta}$ と $\sigma^2$ に依存する。実際には交差検証や、$k = p\hat{\sigma}^2/\|\hat{\boldsymbol{\beta}}\|^2$ のような推定値で選ぶ。
- 固有値 $d_j$ が小さい方向（多重共線性の方向）ほど最小二乗推定量の分散 $\sigma^2/d_j$ が大きく、リッジによる縮小の効果も大きい。

### ポイント

- リッジ推定量は、最小二乗推定量の主成分方向の成分を $d_j/(d_j + k)$ 倍に縮める推定量である。有効自由度は $\operatorname{tr}\{X(X^\top X + kI)^{-1}X^\top\} = \sum_j d_j/(d_j + k)$。
- ベイズ的には、事前分布 $\boldsymbol{\beta} \sim N(\boldsymbol{0},\ (\sigma^2/k)I)$ のもとでの事後平均（事後モード）に一致する。
