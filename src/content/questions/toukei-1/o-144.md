$\lambda$ についての情報量は $I(\lambda) = 1/\lambda$ で、母数変換では $I(\theta) = I(\lambda)\left(\dfrac{d\lambda}{d\theta}\right)^2$ となります。$\lambda = e^\theta$、$d\lambda/d\theta = e^\theta$ なので $I(\theta) = e^{-\theta}\cdot e^{2\theta} = e^{\theta}$ です。

### 計算

**$\lambda$ についての情報量.** $\log f(x;\lambda) = -\lambda + x\log\lambda - \log x!$ より

$$\frac{\partial^2}{\partial\lambda^2}\log f = -\frac{x}{\lambda^2},\qquad I(\lambda) = E\left[\frac{X}{\lambda^2}\right] = \frac{1}{\lambda}$$

**$\theta$ で直接計算.** $\log f = -e^\theta + x\theta - \log x!$ より

$$\frac{\partial}{\partial\theta}\log f = x - e^\theta,\qquad I(\theta) = V[X - e^\theta] = V[X] = \lambda = e^\theta$$

両者は一致します。

### 各選択肢の検討

- $e^{\theta}$：正しい。
- $e^{-\theta}$：$I(\lambda) = 1/\lambda$ に $\lambda = e^\theta$ を代入しただけで、ヤコビアン $(d\lambda/d\theta)^2$ を掛け忘れている。
- $e^{-3\theta}$：$I(\lambda)$ を $(d\lambda/d\theta)^2$ で割った誤り（掛けると割るの取り違え）。
- $e^{2\theta}$：$(d\lambda/d\theta)^2$ だけで、元の情報量 $I(\lambda)$ を掛け忘れている。
- $1/\theta$：$I(\lambda) = 1/\lambda$ の $\lambda$ を $\theta$ に書き換えただけの誤り。

### ポイント

- 情報量の変換則 $I(\theta) = I(\lambda)(d\lambda/d\theta)^2$ はスコアの連鎖律 $\partial_\theta\log f = (\partial_\lambda\log f)(d\lambda/d\theta)$ から得られる。$\theta$ の推定量の漸近分散 $1/I(\theta)$ は、$\lambda$ の推定量の漸近分散にデルタ法を適用した結果 $(d\theta/d\lambda)^2/I(\lambda)$ と一致する。
- $\theta = \log\lambda$ はポアソン分布の自然母数で、ポアソン回帰（対数線形モデル）の線形予測子にあたる。自然母数についての情報量は十分統計量の分散 $V[X]$ に等しい。
