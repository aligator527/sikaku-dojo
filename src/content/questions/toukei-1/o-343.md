  **[1]** $P_j = 1/(1 + e^{-a_j(\theta - b_j)})$ を微分すると $P_j^{\prime}(\theta) = a_jP_j(1 - P_j)$。よって

  $$I_j(\theta) = \frac{a_j^2P_j^2(1 - P_j)^2}{P_j(1 - P_j)} = a_j^2P_j(\theta)\{1 - P_j(\theta)\}$$

  $p(1 - p)$ は $p = 1/2$ で最大値 $1/4$ をとり、$P_j(\theta) = 1/2 \iff \theta = b_j$ なので、項目情報量は $\theta = b_j$ で最大値 $a_j^2/4$ をとる。

  **[2]** 局所独立性より

  $$\ell(\theta) = \sum_{j=1}^{J}\left[u_j\log P_j(\theta) + (1 - u_j)\log\{1 - P_j(\theta)\}\right]$$

  $\dfrac{d}{d\theta}\log P_j = a_j(1 - P_j)$、$\dfrac{d}{d\theta}\log(1 - P_j) = -a_jP_j$ より、尤度方程式は

  $$\ell^{\prime}(\theta) = \sum_{j=1}^{J}a_j\{u_j - P_j(\theta)\} = 0$$

  $-\ell^{\prime\prime}(\theta) = \sum_ja_j^2P_j(1 - P_j) = I(\theta)$ は $\boldsymbol{u}$ によらず、これがフィッシャー情報量（テスト情報量）である。項目数が多いとき $\hat{\theta}$ は近似的に $N(\theta,\ 1/I(\theta))$ に従い、標準誤差は $1/\sqrt{I(\hat{\theta})}$。

  **[3]** $a_j = a$ のとき $P_j = e^{a(\theta - b_j)}/(1 + e^{a(\theta - b_j)})$ なので、尤度は

  $$L(\theta) = \prod_j\frac{e^{a(\theta - b_j)u_j}}{1 + e^{a(\theta - b_j)}} = \exp(a\theta R)\cdot\exp\left(-a\sum_jb_ju_j\right)\cdot\prod_j\frac{1}{1 + e^{a(\theta - b_j)}}$$

  と、$\theta$ と $\boldsymbol{u}$ が $\exp(a\theta R)$ の形でしか結びつかない。因子分解定理より $R$ は $\theta$ の十分統計量である（ラッシュモデルの性質）。尤度方程式は $a\{R - \sum_jP_j(\theta)\} = 0$、すなわち $\sum_jP_j(\hat{\theta}) = R$ で、同じ正答数の受検者は同じ推定値をもつ。全問正答（$R = J$）では $\sum_jP_j(\theta) < J$ がすべての $\theta$ で成り立ち $\ell^{\prime}(\theta) > 0$ なので、尤度は $\theta$ について単調増加で、有限の最尤推定値は存在しない（$\hat{\theta} = +\infty$）。実際には事後分布の平均（EAP）や最頻値（MAP）などのベイズ推定を用いる。

  **[4]** $\theta = 0$ で

  $$P_1 = \frac{1}{1 + e^{-1}} = \frac{1}{1.3679} = 0.7311,\quad P_2 = 0.5,\quad P_3 = \frac{1}{1 + e^{2}} = \frac{e^{-2}}{1 + e^{-2}} = \frac{0.1353}{1.1353} = 0.1192$$

  $$I_1 = 1.0^2 \times 0.7311 \times 0.2689 = 0.1966,\quad I_2 = 1.5^2 \times 0.25 = 0.5625,\quad I_3 = 2.0^2 \times 0.1192 \times 0.8808 = 0.4199$$

  テスト情報量は $I(0) = 0.1966 + 0.5625 + 0.4199 = 1.179$、標準誤差は $1/\sqrt{1.179} = 1/1.086 = 0.921$。困難度 $b_2 = 0$ の項目 2 が最も多くの情報をもち、識別力の最も大きい項目 3 は、困難度が $\theta$ から離れているため情報量が項目 2 より小さい。

項目反応理論の 2 パラメタ・ロジスティックモデルについて、情報量、最尤推定、ラッシュモデルの十分統計量、具体的なテスト情報量の計算を一通り扱う問題です。

### 解答の流れ

1. ロジスティック関数の微分は $P(1 - P)$ の形になる。情報量は困難度の位置で最大になる。
2. 局所独立性により尤度は項目ごとの積になる。正準形なので、情報量は反応に依存しない。
3. 識別力が共通なら尤度が $\exp(a\theta R)$ を通してだけ $\theta$ に依存し、正答数が十分統計量になる。
4. テスト情報量は項目情報量の和で、標準誤差はその平方根の逆数。

### つまずきやすい点

- 識別力が大きい項目ほど、どの能力水準でも情報量が大きいとは限らない。情報量は $\theta = b_j$ の近くに集中し、離れた水準では識別力の小さい項目より小さくなることがある。
- 尤度方程式の重み $a_j$ を落として $\sum_j(u_j - P_j) = 0$ とするのは、識別力が共通な場合だけ正しい。2PL では、識別力の高い項目の正誤が推定値に大きく効く。

### ポイント

- 1.7 を掛けた $P_j = 1/[1 + \exp\{-1.7a_j(\theta - b_j)\}]$ の形（正規累積モデルへの近似）では、情報量は $(1.7a_j)^2P_j(1 - P_j)$ になる。
- テスト情報量関数を設計すると、測定したい能力の範囲で精度の高いテストを組める（項目プールからの組み合わせや、適応型テストでの項目選択）。
