  次の実数値関数 $\phi(t)\ (-\infty < t < \infty)$ のうち、どのような確率分布の特性関数 $E[e^{itX}]$ にもなり得ないものを一つ選べ。
choices:
  - '$\phi(t) = \cos t$'
  - '$\phi(t) = e^{-|t|}$'
  - '$\phi(t) = \dfrac{1}{1 + t^2}$'
  - '$\phi(t) = \max(1 - |t|,\ 0)$'
  - '$\phi(t) = e^{-t^4}$'
answer: 5

$\phi(t) = e^{-t^4}$ が特性関数だとすると、$\phi$ は 2 回微分可能で $\phi''(0) = 0$ です。特性関数が原点で 2 回微分可能なら $E[X^2] = -\phi''(0)$ が成り立つので $E[X^2] = 0$、すなわち $X = 0$（確率 1）となり、特性関数は恒等的に 1 でなければなりません。これは $e^{-t^4} \neq 1$ と矛盾します。他の 4 つは実際にある分布の特性関数です。

### 各選択肢の検討

- $\cos t$：$P(X = 1) = P(X = -1) = 1/2$ の分布の特性関数 $\frac{1}{2}(e^{it} + e^{-it}) = \cos t$。
- $e^{-|t|}$：標準コーシー分布（密度 $\frac{1}{\pi(1 + x^2)}$）の特性関数。原点で微分できないのは、期待値が存在しないことに対応する。
- $\dfrac{1}{1 + t^2}$：ラプラス分布（密度 $\frac{1}{2}e^{-|x|}$）の特性関数。$\int_{-\infty}^{\infty}\frac{1}{2}e^{-|x|}\cos(tx)\,dx = \int_0^\infty e^{-x}\cos(tx)\,dx = \frac{1}{1 + t^2}$。
- $\max(1 - |t|,\ 0)$：密度 $\dfrac{1 - \cos x}{\pi x^2}$ の分布の特性関数。偶関数で $(0, \infty)$ 上で凸、$\phi(0) = 1$、$t \to \infty$ で 0 に収束する関数は特性関数になる（ポリアの判定条件）。
- $e^{-t^4}$：特性関数になり得ない（上記）。

### ポイント

- 特性関数の基本性質：$\phi(0) = 1$、$|\phi(t)| \leq 1$、一様連続、$\phi(-t) = \overline{\phi(t)}$、非負定値（ボホナーの定理）。
- $e^{-|t|^\alpha}$ が特性関数になるのは $0 < \alpha \leq 2$ のとき（対称安定分布）に限られる。$\alpha = 2$ は正規分布 $N(0, 2)$、$\alpha = 1$ はコーシー分布である。
- 原点での微分可能性とモーメントの関係：$E[|X|^k] < \infty$ なら $\phi$ は $k$ 回微分可能で $\phi^{(k)}(0) = i^kE[X^k]$。偶数次については、$\phi^{(2m)}(0)$ が存在すれば $E[X^{2m}] < \infty$ となる。
