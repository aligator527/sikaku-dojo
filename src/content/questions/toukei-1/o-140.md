$P(M/\theta \leq u) = P(\text{すべての } X_i \leq u\theta) = u^n\ (0 \leq u \leq 1)$ なので、$M/\theta$ は枢軸量です。$P(a \leq M/\theta \leq 1) = 1 - a^n = 0.95$ より $a = 0.05^{1/n}$、上限は $4.5/0.7411 = 6.07$ です。

### 計算

$$1 - a^{10} = 0.95 \ \Rightarrow\ a = 0.05^{1/10} = 0.7411$$

$$a \leq \frac{M}{\theta} \leq 1 \iff M \leq \theta \leq \frac{M}{a}$$

なので、95% 信頼区間は $[M,\ M/0.05^{1/n}]$ です。$M = 4.5$ では

$$\left[4.5,\ \frac{4.5}{0.7411}\right] = [4.50,\ 6.07]$$

### ポイント

- この区間は、$P(a \leq M/\theta \leq b) = b^n - a^n = 0.95$ を満たす区間 $[M/b,\ M/a]$ の中で長さ $M(1/a - 1/b)$ が最短になるもの（$b = 1$）である。$M/\theta$ の密度 $nu^{n-1}$ は $u = 1$ に向かって増加するので、密度が大きい側（上端 1）を区間に含めるのが最短になる。
- よくある誤り：両側 2.5% ずつに分けて $a = 0.025^{1/10}$、$b = 0.975^{1/10}$ とする。これも 95% 区間だが長くなる（$[4.51,\ 6.51]$、長さ $2.00$ に対し本問の区間は $1.57$）。また、$P(M/\theta \leq a) = 0.05$ を $a = 0.05$（$n$ 乗根を取り忘れ）とすると上限 90 という不合理な値になる。
- 下限が $M$ になるのは、$\theta \geq M$ が確実に分かっているからである。
