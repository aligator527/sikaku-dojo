stem: |
  古典的テスト理論では、受検者の観測得点 $X$ を真の得点 $T$ と誤差 $E$ の和 $X = T + E$ で表し、$E[E] = 0$、$\mathrm{Cov}(T, E) = 0$ を仮定する。$\sigma_X^2 = V[X]$、$\sigma_T^2 = V[T]$、$\sigma_E^2 = V[E]$ とし、信頼性係数を $\rho = \sigma_T^2/\sigma_X^2$ で定義する。2 つのテスト $X = T + E$、$X^{\prime} = T + E^{\prime}$ が平行テストであるとは、真の得点が共通で、$\mathrm{Cov}(E, E^{\prime}) = \mathrm{Cov}(T, E^{\prime}) = 0$、$V[E] = V[E^{\prime}]$ を満たすことをいう。以下の各問に答えよ。

  [1] 平行テストの得点の相関係数 $\mathrm{Corr}(X, X^{\prime})$ が信頼性係数 $\rho$ に等しいことを示せ。また、$\mathrm{Corr}(X, T)$ を $\rho$ で表せ。

  [2] 互いに平行な $k$ 個のテストの合計得点の信頼性係数が

  $$\rho_k = \frac{k\rho}{1 + (k - 1)\rho}$$

  となること（スピアマン・ブラウンの公式）を示せ。ここで $\rho$ は 1 個のテストの信頼性係数で、各テストの誤差は互いに無相関とする。

  [3] あるテストの得点は、受検者集団で平均 50、標準偏差 $\sigma_X = 10$、信頼性係数 $\rho = 0.84$ である。測定の標準誤差 $\sigma_E$ を求めよ。観測得点が $X = 60$ の受検者について、(a) $X \pm 1.96\sigma_E$ による区間と、(b) 真の得点の回帰推定値（ケリーの推定値）$\hat{T} = 50 + \rho(X - 50)$ とその推定の標準誤差 $\sigma_X\sqrt{\rho(1 - \rho)}$ による区間 $\hat{T} \pm 1.96\sigma_X\sqrt{\rho(1-\rho)}$ を求め、両者の違いを説明せよ。必要なら $\sqrt{0.1344} = 0.3666$ を用いよ。
modelAnswer: |
  **[1]** 仮定より $\mathrm{Cov}(X, X^{\prime}) = \mathrm{Cov}(T + E,\ T + E^{\prime}) = V[T] = \sigma_T^2$。また $V[X^{\prime}] = \sigma_T^2 + V[E^{\prime}] = \sigma_T^2 + \sigma_E^2 = V[X]$ なので

  $$\mathrm{Corr}(X, X^{\prime}) = \frac{\sigma_T^2}{\sqrt{\sigma_X^2\sigma_X^2}} = \frac{\sigma_T^2}{\sigma_X^2} = \rho$$

  $\mathrm{Cov}(X, T) = \sigma_T^2$ より $\mathrm{Corr}(X, T) = \sigma_T^2/(\sigma_X\sigma_T) = \sigma_T/\sigma_X = \sqrt{\rho}$（信頼性指数）。

  **[2]** $k$ 個の平行テスト $X_j = T + E_j$ の合計は $S = kT + \sum_jE_j$ で、その真の得点は $kT$。誤差が互いに無相関なので

  $$V[kT] = k^2\sigma_T^2,\qquad V[S] = k^2\sigma_T^2 + k\sigma_E^2$$

  $\sigma_T^2 = \rho\sigma_X^2$、$\sigma_E^2 = (1 - \rho)\sigma_X^2$ を代入して

  $$\rho_k = \frac{k^2\rho\sigma_X^2}{k^2\rho\sigma_X^2 + k(1 - \rho)\sigma_X^2} = \frac{k\rho}{k\rho + 1 - \rho} = \frac{k\rho}{1 + (k - 1)\rho}$$

  真の得点の分散は $k^2$ 倍になるのに、誤差の分散は $k$ 倍にしかならないので、テストを長くすると信頼性が上がる。

  **[3]** $\sigma_E = \sigma_X\sqrt{1 - \rho} = 10\sqrt{0.16} = 4.0$。

  (a) $60 \pm 1.96 \times 4.0 = 60 \pm 7.84 = [52.16,\ 67.84]$。

  (b) $\hat{T} = 50 + 0.84 \times 10 = 58.4$、推定の標準誤差は $10\sqrt{0.84 \times 0.16} = 10 \times 0.3666 = 3.666$ なので

  $$58.4 \pm 1.96 \times 3.666 = 58.4 \pm 7.19 = [51.21,\ 65.59]$$

  (a) は「真の得点 $T$ を固定したとき $X$ が $T \pm 1.96\sigma_E$ に入る」ことを裏返した区間で、中心は観測得点そのものである。(b) は受検者集団から無作為に選ばれた受検者について、$X$ を与えたときの $T$ の（最良線形）予測で、平均の方向へ縮めた値 58.4 を中心とする。平均より高い得点をとった受検者には、正の誤差が乗っている可能性が高いことを反映しており（平均への回帰）、区間の幅も $\sqrt{\rho}$ 倍（$3.666 = 4.0 \times \sqrt{0.84}$）に狭くなる。

古典的テスト理論の基本（信頼性係数の意味、スピアマン・ブラウンの公式、測定の標準誤差、真の得点の推定）を確認する問題です。

### 解答の流れ

1. 平行テストの共分散は真の得点の分散だけになる。これが「再テストや平行テストの相関で信頼性を推定する」根拠である。
2. テストを $k$ 倍に延長すると、真の得点の分散は $k^2$ 倍、誤差分散は $k$ 倍になる。
3. 測定の標準誤差は $\sigma_X\sqrt{1 - \rho}$。真の得点の推定には、観測得点を中心とする区間と、平均への回帰を考慮した区間の 2 通りがある。

### つまずきやすい点

- 信頼性係数は観測得点の分散に占める真の得点の分散の割合であり、テストと真の得点の相関（$\sqrt{\rho}$）とは異なる。$\rho = 0.84$ なら $\mathrm{Corr}(X, T) = 0.917$ である。
- 信頼性係数は受検者集団に依存する。同じテストでも、得点のばらつきが小さい集団（選抜された集団など）では $\sigma_T^2$ が小さくなり、信頼性係数は低くなる。測定の標準誤差 $\sigma_E$ の方が集団の違いに対して安定している。

### ポイント

- スピアマン・ブラウンの公式で $\rho = 0.84$ のテストを 2 倍にすると $\rho_2 = 1.68/1.84 = 0.913$、半分にすると $\rho_{1/2} = 0.42/0.58 = 0.724$ になる。折半法では、半分のテストの相関を $k = 2$ で補正して全体の信頼性を推定する。
- 平行テストの仮定は強い。真の得点の尺度が定数だけずれることを許すのが本質的タウ等価、尺度の倍率も変わることを許すのが同族（コンジェネリック）測定である。
