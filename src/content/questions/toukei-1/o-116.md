  $X$ は区間 $(0, 1)$ 上の一様分布に従い、$X = x$ が与えられたとき $Y$ は区間 $(0, x)$ 上の一様分布に従うとする。以下の各問に答えよ。

  [1] $E[Y \mid X]$ と $E[Y]$ を求めよ。

  [2] 全分散の公式を用いて $V[Y]$ を求めよ。

  [3] $Y$ の周辺確率密度関数を求め、それを用いて [1]・[2] の結果を確かめよ。

  [4] $Y = y\ (0 < y < 1)$ が与えられたときの $X$ の条件付き期待値 $E[X \mid Y = y]$ を求めよ。また、$X$ の関数で $Y$ を予測するときの平均二乗誤差の最小値を求めよ。
modelAnswer: |
  **[1]** $Y \mid X = x \sim U(0, x)$ より $E[Y \mid X] = X/2$。全期待値の公式より

  $$E[Y] = E\big[E[Y \mid X]\big] = \frac{E[X]}{2} = \frac{1}{4}$$

  **[2]** $V[Y \mid X] = X^2/12$、$E[X^2] = 1/3$、$V[X] = 1/12$ なので

  $$V[Y] = E\big[V[Y \mid X]\big] + V\big[E[Y \mid X]\big] = \frac{1}{12}\cdot\frac{1}{3} + \frac{1}{4}\cdot\frac{1}{12} = \frac{1}{36} + \frac{1}{48} = \frac{7}{144}$$

  **[3]** 同時密度は $f(x, y) = 1 \cdot \dfrac{1}{x}\ (0 < y < x < 1)$ なので

  $$f_Y(y) = \int_y^1\frac{1}{x}\,dx = -\log y\qquad (0 < y < 1)$$

  部分積分 $\int_0^1 y^k(-\log y)\,dy = \dfrac{1}{(k+1)^2}$ より

  $$E[Y] = \frac{1}{4},\qquad E[Y^2] = \frac{1}{9},\qquad V[Y] = \frac{1}{9} - \frac{1}{16} = \frac{7}{144}$$

  となり、[1]・[2] と一致する。

  **[4]** $X \mid Y = y$ の条件付き密度は $\dfrac{f(x, y)}{f_Y(y)} = \dfrac{1/x}{-\log y}\ (y < x < 1)$ なので

  $$E[X \mid Y = y] = \int_y^1 x\cdot\frac{1/x}{-\log y}\,dx = \frac{1 - y}{-\log y}$$

  $X$ の関数 $g(X)$ による $Y$ の予測の平均二乗誤差 $E[(Y - g(X))^2]$ は $g(X) = E[Y \mid X]$ で最小になり、その値は

  $$E\big[(Y - E[Y \mid X])^2\big] = E\big[V[Y \mid X]\big] = \frac{1}{36}$$

  である（定数 $1/4$ で予測した場合の $V[Y] = 7/144$ に比べ、$V[E[Y \mid X]]/V[Y] = (1/48)/(7/144) = 3/7$ だけ減る）。

階層的に定義された確率変数について、全期待値・全分散の公式と、周辺密度・逆向きの条件付き分布の計算をひととおり確認する問題です。条件付き期待値が平均二乗誤差の意味で最良の予測であることもあわせて問うています。

### 解答の流れ

1. 内側の分布（$U(0, x)$）の平均と分散を書き、外側の分布で期待値をとる。
2. 同時密度 $f(x)f(y \mid x)$ の定義域 $0 < y < x < 1$ に注意して、$x$ について積分すると周辺密度になる。
3. 逆向きの条件付き分布は同時密度を周辺密度で割って求める（ベイズの定理）。

### つまずきやすい点

- [2] で $V[Y \mid X] = X^2/12$ の期待値を $E[X]^2/12 = 1/48$ とする誤り。$E[X^2] = 1/3$ を使う。
- [3] で積分範囲を $0 < x < y$ としたり、$\int_0^1 \frac{1}{x}dx$（発散）としたりする誤り。$y$ を固定すると $x$ は $y$ より大きい範囲を動く。
- [4] の $E[X \mid Y = y]$ は $y$ の一次関数ではない。条件付き期待値が線形になるのは、正規分布などの特別な場合に限られる。

### ポイント

- $V[Y] = E[V[Y \mid X]] + V[E[Y \mid X]]$ の第 1 項は「$X$ を知っても残るばらつき」（予測誤差）、第 2 項は「$X$ で説明できるばらつき」である。
- $-\log Y = (-\log X) + (-\log(Y/X))$ と書くと、$X$ と $Y/X$ は独立に $U(0, 1)$ に従うので $-\log Y \sim Ga(2, 1)$ となり、[3] の密度 $-\log y$ と一致する。
