$X_1/T$ は $\mathrm{Beta}(1,\ n - 1)$ に従い、$T$ と独立です。したがって $E[\mathbf{1}\{X_1 > c\} \mid T = t] = P(X_1/T > c/t) = (1 - c/t)^{n-1}$（$t > c$）となり、これが一様最小分散不偏推定量です（レーマン・シェフェの定理）。$n = 5,\ t = 20,\ c = 2$ では $(1 - 0.1)^4 = 0.9^4 = 0.6561$ です。

### 計算

**$X_1/T$ の分布.** $X_1$ と $T' = \sum_{i \geq 2}X_i \sim Ga(n - 1,\ \text{尺度 } \theta)$ は独立なので、独立なガンマ変数 $Y_1, Y_2$（尺度共通）について $Y_1/(Y_1 + Y_2)$ と $Y_1 + Y_2$ が独立でベータ分布に従うという性質より、$V = X_1/(X_1 + T')$ は $\mathrm{Beta}(1,\ n-1)$ に従い、$T = X_1 + T'$ と独立です。$V$ の分布は $\theta$ によらないので、バスーの定理（完備十分統計量と補助統計量は独立）からも独立性が分かります。

**条件付き期待値.** $t > c$ のとき

$$P(X_1 > c \mid T = t) = P\left(V > \frac{c}{t}\right) = \int_{c/t}^{1}(n - 1)(1 - v)^{n-2}\,dv = \left(1 - \frac{c}{t}\right)^{n-1}$$

（$t \leq c$ なら 0）。よって

$$\hat{R}(c) = \left(1 - \frac{c}{T}\right)^{n-1}\mathbf{1}\{T > c\},\qquad \hat{R}(2) = \left(1 - \frac{2}{20}\right)^{4} = 0.9^4 = 0.6561$$

### ポイント

- 最尤推定値は不変性より $e^{-c/\bar{x}} = e^{-2/4} = e^{-0.5} \approx 0.6065$ で、一様最小分散不偏推定値とは異なる。$n \to \infty$ では $(1 - c/T)^{n-1} \approx e^{-c(n-1)/T} \to e^{-c/\theta}$ となり、両者は一致する。
- よくある誤り：$(1 - c/t)^n$ とする（$\mathrm{Beta}(1, n-1)$ の指数 $n - 1$ を $n$ と取り違え）と $0.9^5 = 0.5905$。また、$e^{-c/\theta}$ に不偏推定量 $\bar{X}$ を代入しても不偏推定量にはならない。
- 同じ考え方で、ポアソン分布の $P(X = 0) = e^{-\lambda}$ の一様最小分散不偏推定量は $(1 - 1/n)^T$ となる。
