  **[1]** $H_0$ のもとで $D_i$ は 0 に関して対称なので、$D_i$ の符号 $\mathbf{1}\{D_i > 0\}$ と絶対値 $|D_i|$ は独立で、符号は確率 $1/2$ で正となる。各 $i$ について符号は互いに独立で、順位ベクトル $(R_1, \ldots, R_n)$（絶対値だけの関数）とも独立である。順位 $k$ をもつ観測値の符号を $B_k$ とおくと、$B_1, \ldots, B_n$ は独立に $\mathrm{Bin}(1, 1/2)$ に従い、$T^{+} = \sum_{k=1}^{n}kB_k$ と書ける。よって

  $$E[T^{+}] = \sum_{k=1}^{n}\frac{k}{2} = \frac{n(n + 1)}{4},\qquad V[T^{+}] = \sum_{k=1}^{n}\frac{k^2}{4} = \frac{n(n + 1)(2n + 1)}{24}$$

  **[2]** $T^{+}$ は「正の符号をもつ順位の集合」の要素の和で、$2^6 = 64$ 通りの集合が等確率で現れる。最大値は $1 + \cdots + 6 = 21$ なので、$T^{+} \geq 21 - s$ は「負の符号をもつ順位の和が $s$ 以下」と同値である。

  - 負の順位の和 $\leq 1$：$\varnothing,\ \{1\}$ の 2 通り → $P(T^{+} \geq 20) = 2/64 = 0.0313$
  - 負の順位の和 $\leq 2$：さらに $\{2\}$ → $P(T^{+} \geq 19) = 3/64 = 0.0469$
  - 負の順位の和 $\leq 3$：さらに $\{3\},\ \{1, 2\}$ → $P(T^{+} \geq 18) = 5/64 = 0.0781$

  有意水準 5% の片側検定の棄却域は $T^{+} \geq 19$ で、実際の大きさは $3/64 = 0.0469$。

  **[3]** $|D_i|$ を小さい順に並べると $0.4,\ 0.8,\ 1.2,\ 1.9,\ 2.5,\ 3.1$ で、負の差 $-0.4$ の順位は 1。よって $T^{+} = 21 - 1 = 20$。正確な片側 $p$ 値は $P(T^{+} \geq 20) = 2/64 = 0.0313$ で、$0.05$ 未満なので有意水準 5% で $H_0$ を棄却する（棄却域 $T^{+} \geq 19$ に入る）。

  **[4]** $E[T^{+}] = 6 \times 7/4 = 10.5$、$V[T^{+}] = 6 \times 7 \times 13/24 = 22.75$、標準偏差は $4.770$。

ウィルコクソンの符号付き順位検定は、正規性を仮定せずに対応のあるデータの位置を検定する方法です。帰無仮説のもとでは「各順位に独立に $\pm$ の符号がつく」という単純な構造になるため、正確な分布を数え上げで求められ、平均と分散も簡単に計算できます。

### 解答の流れ

1. 対称性から、符号と順位が独立で、符号が公平なコインと同じ分布になることを示す。
2. $T^{+}$ の上側確率は、補集合（負の符号の順位の和）が小さい場合を数えると速い。
3. データの絶対値に順位をつけ、正の差の順位を足す。
4. 平均・分散で標準化し、連続修正の有無で比べる。

### つまずきやすい点

- 順位は $D_i$ そのものではなく $|D_i|$ につけます。$D_i$ に順位をつけると $-0.4$ が最小になるのは同じですが、負の値が複数あると結果が変わります。
- 離散分布なので、大きさがちょうど 5% の（確率化しない）検定は作れません。棄却域 $T^{+} \geq 18$ では大きさが $0.0781$ となり、有意水準を超えます。
- 同じデータに符号検定を使うと、正の符号は 6 個中 5 個で、$p = P(\mathrm{Bin}(6, 1/2) \geq 5) = 7/64 = 0.109$ となり有意になりません。符号付き順位検定は差の大きさの情報も使うので、検出力が高くなります。

### ポイント

- 正規分布のもとでの、$t$ 検定に対する漸近相対効率は $3/\pi \approx 0.955$ で、正規性が成り立つ場合でも損失はわずかです。
- 同順位（タイ）や差が 0 の観測値がある場合は、平均順位を用い、分散を補正します。
