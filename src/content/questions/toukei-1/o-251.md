各抽出での $z_k = y_k/p_k = y_kX/x_k$ は $2600,\ 2750,\ 2400,\ 2900$ で、推定値はその平均 $\hat{Y}_{HH} = 2662.5$ です。偏差平方和は $136875$ なので、$\hat{V} = 136875/12 = 11406.25$、標準誤差は $\sqrt{11406.25} = 106.8$ となります。

### 計算

$$z_1 = \frac{52 \times 10000}{200} = 2600,\quad z_2 = \frac{110 \times 10000}{400} = 2750,\quad z_3 = \frac{24 \times 10000}{100} = 2400,\quad z_4 = \frac{87 \times 10000}{300} = 2900$$

$$\hat{Y}_{HH} = \frac{2600 + 2750 + 2400 + 2900}{4} = \frac{10650}{4} = 2662.5$$

$$\sum_k(z_k - \hat{Y}_{HH})^2 = (-62.5)^2 + 87.5^2 + (-262.5)^2 + 237.5^2 = 3906.25 + 7656.25 + 68906.25 + 56406.25 = 136875$$

$$\hat{V} = \frac{136875}{4 \times 3} = 11406.25,\qquad \sqrt{11406.25} = 106.80$$

### ポイント

- 復元抽出では $z_k$ が互いに独立に同一の分布に従い、$E[z_k] = \sum_i p_i \cdot y_i/p_i = Y$ です。$\hat{Y}_{HH}$ はその標本平均なので、分散推定は「$z_k$ の不偏分散 ÷ $n$」になります。
- 売上高が売場面積にほぼ比例するので、$y_i/p_i$ のばらつきが小さく、少ない標本でも精度よく推定できます（確率比例抽出の利点）。$y_i$ が $p_i$ に完全に比例すれば分散は 0 になります。
- よくある誤り：$n(n - 1)$ ではなく $n - 1$ で割る（$z_k$ の標準偏差 $213.6$ を答える）。これは推定量の標準誤差ではなく、1 回の抽出による推定値のばらつきです。
