modelAnswer: |
  **[1]** 判別領域を $R_1$（$\Pi_1$ と判別する領域）とすると、誤判別確率の和は

  $$\int_{R_1^c}f_1(\boldsymbol{x})\,d\boldsymbol{x} + \int_{R_1}f_2(\boldsymbol{x})\,d\boldsymbol{x} = 1 - \int_{R_1}\{f_1(\boldsymbol{x}) - f_2(\boldsymbol{x})\}\,d\boldsymbol{x}$$

  なので、$f_1(\boldsymbol{x}) > f_2(\boldsymbol{x})$ となる点をすべて $R_1$ に入れるとき最小になる。共通の $\Sigma$ のもとで対数密度比は、2 次の項 $\boldsymbol{x}^\top\Sigma^{-1}\boldsymbol{x}$ が打ち消し合って

  $$\log\frac{f_1(\boldsymbol{x})}{f_2(\boldsymbol{x})} = -\frac{1}{2}(\boldsymbol{x} - \boldsymbol{\mu}_1)^\top\Sigma^{-1}(\boldsymbol{x} - \boldsymbol{\mu}_1) + \frac{1}{2}(\boldsymbol{x} - \boldsymbol{\mu}_2)^\top\Sigma^{-1}(\boldsymbol{x} - \boldsymbol{\mu}_2) = \boldsymbol{\delta}^\top\Sigma^{-1}\boldsymbol{x} - \frac{1}{2}\boldsymbol{\delta}^\top\Sigma^{-1}(\boldsymbol{\mu}_1 + \boldsymbol{\mu}_2) = L(\boldsymbol{x})$$

  よって $f_1 > f_2 \iff L(\boldsymbol{x}) > 0$。

  **[2]** $\boldsymbol{x} \sim N_p(\boldsymbol{\mu}_1, \Sigma)$ のとき $L(\boldsymbol{x})$ は正規分布に従い

  $$E[L] = \boldsymbol{\delta}^\top\Sigma^{-1}\left(\boldsymbol{\mu}_1 - \frac{\boldsymbol{\mu}_1 + \boldsymbol{\mu}_2}{2}\right) = \frac{1}{2}\Delta^2,\qquad V[L] = \boldsymbol{\delta}^\top\Sigma^{-1}\Sigma\Sigma^{-1}\boldsymbol{\delta} = \Delta^2$$

  したがって

  $$P(L(\boldsymbol{x}) \leq 0 \mid \Pi_1) = P\left(Z \leq \frac{0 - \Delta^2/2}{\Delta}\right) = \Phi\left(-\frac{\Delta}{2}\right)$$

  対称性から $\Pi_2$ の個体を $\Pi_1$ と誤る確率も $\Phi(-\Delta/2)$ である。

  **[3]** $\boldsymbol{b} = \Sigma^{1/2}\boldsymbol{a}$ とおくと、コーシー・シュワルツの不等式より

  $$(\boldsymbol{a}^\top\boldsymbol{\delta})^2 = \left\{\boldsymbol{b}^\top\Sigma^{-1/2}\boldsymbol{\delta}\right\}^2 \leq (\boldsymbol{b}^\top\boldsymbol{b})(\boldsymbol{\delta}^\top\Sigma^{-1}\boldsymbol{\delta}) = (\boldsymbol{a}^\top\Sigma\boldsymbol{a})\,\Delta^2$$

  等号は $\boldsymbol{b} \propto \Sigma^{-1/2}\boldsymbol{\delta}$、すなわち $\boldsymbol{a} \propto \Sigma^{-1}\boldsymbol{\delta}$ のときに成り立ち、比の最大値は $\Delta^2$ である。これはフィッシャーの線形判別の方向であり、正規性を仮定しない「分離の度合いの最大化」からも、[1] のベイズ判別と同じ方向 $\Sigma^{-1}\boldsymbol{\delta}$ が得られる。

  **[4]** $\det\Sigma = 0.75$、$\Sigma^{-1} = \dfrac{1}{0.75}\begin{pmatrix} 1 & -0.5 \\ -0.5 & 1 \end{pmatrix}$、$\boldsymbol{\delta} = (2, 1)^\top$ より

  $$\Sigma^{-1}\boldsymbol{\delta} = \frac{1}{0.75}\begin{pmatrix} 2 - 0.5 \\ -1 + 1 \end{pmatrix} = \begin{pmatrix} 2 \\ 0 \end{pmatrix},\qquad \Delta^2 = (2, 1)\begin{pmatrix} 2 \\ 0 \end{pmatrix} = 4$$

  $\frac{1}{2}(\boldsymbol{\mu}_1 + \boldsymbol{\mu}_2) = (1, 0.5)^\top$ なので

  $$L(\boldsymbol{x}) = 2(x_1 - 1) + 0 \cdot (x_2 - 0.5) = 2x_1 - 2$$

  すなわち「$x_1 > 1$ なら $\Pi_1$」と判別する。$\Delta = 2$ より誤判別確率は $\Phi(-1) = 1 - 0.8413 = 0.1587$。

  $x_2$ の平均は群間で 1 だけ異なるのに、判別関数での係数は 0 になる。$x_2$ の平均の差 1 は、$x_1$ の差 2 と相関 0.5 から予想される差（回帰 $E[x_2 \mid x_1]$ の傾き 0.5 × 2 = 1）とちょうど一致しており、$x_1$ を知ったうえでは $x_2$ に判別の追加情報がないためである。各変数の平均差だけを見て変数を選ぶと、こうした構造を見落とす。

等分散の正規母集団における線形判別分析を、ベイズ判別・誤判別確率・フィッシャーの基準の 3 つの見方から導く問題です。

### 解答の流れ

1. 誤判別確率の和を最小にするには、密度の大きい方の群に判別する。共通の分散共分散行列のもとでは、対数密度比が $\boldsymbol{x}$ の 1 次式になる。
2. $L(\boldsymbol{x})$ は $\boldsymbol{x}$ の線形関数なので正規分布に従い、平均 $\pm\Delta^2/2$、分散 $\Delta^2$。
3. フィッシャーの基準の最大化はコーシー・シュワルツの不等式（または一般化固有値問題）で解ける。
4. 具体的な数値では $\Sigma^{-1}\boldsymbol{\delta}$ を計算するだけで判別関数が決まる。

### つまずきやすい点

- 誤判別確率を $\Phi(-\Delta)$ や $\Phi(-\Delta^2/2)$ とする誤り。判別の境界は 2 つの平均の中点にあり、そこまでの距離は標準偏差 $\Delta$ の単位で $\Delta/2$ である。
- 事前確率が $q_1,\ q_2$ と異なる場合、境界は $L(\boldsymbol{x}) > \log(q_2/q_1)$ に移る。誤判別の損失が異なる場合も同様に閾値が変わる。
- 分散共分散行列が群で異なると、2 次の項が打ち消されず 2 次判別関数になる。

### ポイント

- $\Delta^2$ は判別のしやすさの尺度で、誤判別確率 $\Phi(-\Delta/2)$ は $\Delta$ だけで決まる（$\Delta = 2$ で約 16%、$\Delta = 3$ で約 7%）。
- 実際には $\boldsymbol{\mu}_k$ と $\Sigma$ を標本平均とプールした分散共分散行列で置き換える。その誤判別率をそのまま学習データで評価すると楽観的になるので、交差検証で評価する。
