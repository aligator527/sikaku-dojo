対数尤度は $(2n_1 + n_2)\log\theta + (n_2 + 2n_3)\log(1 - \theta) + \text{定数}$ で、これは「$2n$ 個の対立遺伝子のうち A が $2n_1 + n_2$ 個」という二項分布の尤度と同じ形です。したがって $\hat{\theta} = (2n_1 + n_2)/(2n)$、$I_n(\theta) = 2n/\{\theta(1 - \theta)\}$ です。

### 計算

$$\ell(\theta) = 2n_1\log\theta + n_2\{\log 2 + \log\theta + \log(1 - \theta)\} + 2n_3\log(1 - \theta)$$

$$\ell'(\theta) = \frac{2n_1 + n_2}{\theta} - \frac{n_2 + 2n_3}{1 - \theta} = 0\ \Rightarrow\ \hat{\theta} = \frac{2n_1 + n_2}{2n}$$

$$-\ell''(\theta) = \frac{2N_1 + N_2}{\theta^2} + \frac{N_2 + 2N_3}{(1 - \theta)^2}$$

$E[2N_1 + N_2] = n\{2\theta^2 + 2\theta(1 - \theta)\} = 2n\theta$、$E[N_2 + 2N_3] = 2n(1 - \theta)$ より

$$I_n(\theta) = \frac{2n\theta}{\theta^2} + \frac{2n(1 - \theta)}{(1 - \theta)^2} = \frac{2n}{\theta} + \frac{2n}{1 - \theta} = \frac{2n}{\theta(1 - \theta)}$$

### 各選択肢の検討

- $I_n = n/\{\theta(1-\theta)\}$ の組：最尤推定量は正しいが、情報量を「$n$ 人の二項分布」として計算している。1 人から 2 個の対立遺伝子の情報が得られるので、情報量は $2n$ に比例する。
- $\hat{\theta} = (n_1 + n_2)/n$：A をもつ人の割合で、その期待値は $\theta^2 + 2\theta(1 - \theta) = 1 - (1 - \theta)^2 \neq \theta$。
- $\hat{\theta} = \sqrt{n_1/n}$：AA の度数だけを使ったモーメント推定量で、最尤推定量ではない（一致推定量ではあるが Aa、aa の情報を捨てている）。
- 正しい組：上記の計算のとおり。
- $I_n = \theta(1-\theta)/(2n)$：最尤推定量の漸近分散 $1/I_n(\theta)$ とフィッシャー情報量を取り違えている。

### ポイント

- $\hat{\theta}$ の漸近分散は $1/I_n(\theta) = \theta(1 - \theta)/(2n)$。たとえば $n = 100$、$(n_1, n_2, n_3) = (30, 50, 20)$ なら、A の個数は $2 \times 30 + 50 = 110$（全 200 個中）で $\hat{\theta} = 0.55$、標準誤差は $\sqrt{0.55 \times 0.45/200} \approx 0.035$ となる。
- ハーディ・ワインベルグ平衡の検定（適合度検定）では、母数を 1 個推定するので自由度は $3 - 1 - 1 = 1$ になる。
