stem: |
  $N$ 個の個体を $T$ 期間観測したパネルデータに対し、モデル

  $$y_{it} = \beta x_{it} + \alpha_i + \varepsilon_{it}\qquad (i = 1, \ldots, N;\ t = 1, \ldots, T)$$

  を考える。$\alpha_i$ は観測されない個体効果である。$\varepsilon_{it}$ は互いに独立に平均 0、分散 $\sigma_\varepsilon^2$ の分布に従い、すべての $x_{js}$ および $\alpha_j$ と独立とする。$\bar{y}_i = \frac{1}{T}\sum_{t=1}^{T}y_{it}$ などと書く。以下の各問に答えよ。

  [1] 個体内変換 $y_{it} - \bar{y}_i$、$x_{it} - \bar{x}_i$ を行ってから最小二乗法を適用した固定効果推定量 $\hat{\beta}_{FE}$ を式で表せ。また、$\alpha_i$ が $x_{it}$ と相関していても、$\hat{\beta}_{FE}$ が（$x$ を所与として）$\beta$ の不偏推定量であることを示せ。

  [2] 変量効果モデルでは、$\alpha_i$ はすべての $x$ と独立に平均 0、分散 $\sigma_\alpha^2$ の分布に従うとする。合成誤差 $v_{it} = \alpha_i + \varepsilon_{it}$ の同一個体内の相関係数 $\mathrm{Corr}(v_{it}, v_{is})$（$t \neq s$）を求めよ。さらに

  $$\theta = 1 - \sqrt{\frac{\sigma_\varepsilon^2}{\sigma_\varepsilon^2 + T\sigma_\alpha^2}}$$

  として準平均除去 $v_{it} - \theta\bar{v}_i$ を行うと、同一個体内で無相関かつ等分散になることを示せ。

  [3] 固定効果推定量 $\hat{\beta}_{FE}$ と変量効果推定量 $\hat{\beta}_{RE}$ を比べるハウスマン検定について、帰無仮説を述べ、帰無仮説のもとと対立仮説のもとでの 2 つの推定量の性質（一致性・有効性）を説明せよ。また、帰無仮説のもとで $V[\hat{\beta}_{FE} - \hat{\beta}_{RE}] = V[\hat{\beta}_{FE}] - V[\hat{\beta}_{RE}]$ が成り立つ理由を説明せよ。

  [4] $T = 5$、$\sigma_\varepsilon^2 = 0.80$、$\sigma_\alpha^2 = 0.60$ のとき、[2] の相関係数と $\theta$ を小数第 3 位まで求めよ。また、$\theta$ の値から、変量効果推定量がプーリング最小二乗推定量・固定効果推定量とどのような関係にあるかを述べよ。
modelAnswer: |
  **[1]** 個体ごとに時間平均を引くと $\alpha_i$ が消える。

  $$y_{it} - \bar{y}_i = \beta(x_{it} - \bar{x}_i) + (\varepsilon_{it} - \bar{\varepsilon}_i)$$

  これに最小二乗法を適用して

  $$\hat{\beta}_{FE} = \frac{\sum_{i}\sum_{t}(x_{it} - \bar{x}_i)(y_{it} - \bar{y}_i)}{\sum_{i}\sum_{t}(x_{it} - \bar{x}_i)^2} = \beta + \frac{\sum_{i}\sum_{t}(x_{it} - \bar{x}_i)\varepsilon_{it}}{\sum_{i}\sum_{t}(x_{it} - \bar{x}_i)^2}$$

  （$\sum_t(x_{it} - \bar{x}_i)\bar{\varepsilon}_i = 0$ を用いた。）$\varepsilon_{it}$ はすべての $x$ と $\alpha$ に独立で平均 0 なので、$x$ を所与とした第 2 項の期待値は 0 であり、$E[\hat{\beta}_{FE} \mid x] = \beta$。$\alpha_i$ は変換で消去されるので、$\alpha_i$ と $x_{it}$ の相関の有無は結果に影響しない。

  **[2]** $t \neq s$ のとき $\mathrm{Cov}(v_{it}, v_{is}) = V[\alpha_i] = \sigma_\alpha^2$、$V[v_{it}] = \sigma_\alpha^2 + \sigma_\varepsilon^2$ なので

  $$\mathrm{Corr}(v_{it}, v_{is}) = \frac{\sigma_\alpha^2}{\sigma_\alpha^2 + \sigma_\varepsilon^2}$$

  $v_{it} - \theta\bar{v}_i = (1 - \theta)\alpha_i + \varepsilon_{it} - \theta\bar{\varepsilon}_i$ であり、$\mathrm{Cov}(\varepsilon_{it}, \bar{\varepsilon}_i) = \sigma_\varepsilon^2/T$、$V[\bar{\varepsilon}_i] = \sigma_\varepsilon^2/T$ より、$t \neq s$ で

  $$\mathrm{Cov}(v_{it} - \theta\bar{v}_i,\ v_{is} - \theta\bar{v}_i) = (1 - \theta)^2\sigma_\alpha^2 - \frac{2\theta - \theta^2}{T}\sigma_\varepsilon^2$$

  $\lambda = 1 - \theta$ とおくと $2\theta - \theta^2 = 1 - \lambda^2$ なので、これは

  $$\frac{\lambda^2(T\sigma_\alpha^2 + \sigma_\varepsilon^2) - \sigma_\varepsilon^2}{T}$$

  となり、$\lambda^2 = \sigma_\varepsilon^2/(\sigma_\varepsilon^2 + T\sigma_\alpha^2)$ のとき 0 になる。分散は、上の共分散に $V[\varepsilon_{it}] = \sigma_\varepsilon^2$ を加えたものなので $\sigma_\varepsilon^2$ で、$t$ によらない。したがって準平均除去した変数に最小二乗法を適用したものが一般化最小二乗（GLS）推定量、すなわち変量効果推定量になる。

  **[3]** 帰無仮説は「個体効果 $\alpha_i$ が説明変数 $x_{it}$ と無相関である」。

  - 帰無仮説のもと：$\hat{\beta}_{FE}$、$\hat{\beta}_{RE}$ はともに一致推定量で、$\hat{\beta}_{RE}$ は GLS なので有効（漸近分散が小さい）。
  - 対立仮説のもと：$\hat{\beta}_{FE}$ は一致推定量のままだが、$\hat{\beta}_{RE}$ は $\alpha_i$ を誤差に含めるため一致性を失う。

  したがって両者の差が大きければ帰無仮説を棄却する。検定統計量は $H = (\hat{\beta}_{FE} - \hat{\beta}_{RE})^2/(\hat{V}[\hat{\beta}_{FE}] - \hat{V}[\hat{\beta}_{RE}])$ で、帰無仮説のもとで漸近的に $\chi^2(1)$ に従う。

  分散の式：$q = \hat{\beta}_{FE} - \hat{\beta}_{RE}$ とする。帰無仮説のもとで $\hat{\beta}_{RE}$ は有効なので $\mathrm{Cov}(\hat{\beta}_{RE}, q) = 0$ である。実際、もし $\mathrm{Cov}(\hat{\beta}_{RE}, q) = c_0 \neq 0$ なら、推定量 $\hat{\beta}_{RE} + cq$（これも一致推定量）の分散 $V[\hat{\beta}_{RE}] + 2cc_0 + c^2V[q]$ は、絶対値の小さい $c$ を $c_0$ と逆符号に取ると $V[\hat{\beta}_{RE}]$ より小さくなり、有効性に反する。よって

  $$V[\hat{\beta}_{FE}] = V[\hat{\beta}_{RE} + q] = V[\hat{\beta}_{RE}] + V[q]\ \Rightarrow\ V[q] = V[\hat{\beta}_{FE}] - V[\hat{\beta}_{RE}]$$

  **[4]**

  $$\mathrm{Corr}(v_{it}, v_{is}) = \frac{0.60}{0.60 + 0.80} = 0.429,\qquad \theta = 1 - \sqrt{\frac{0.80}{0.80 + 5 \times 0.60}} = 1 - \sqrt{0.2105} = 1 - 0.4588 = 0.541$$

  変量効果推定量は、$\theta = 0$ のプーリング最小二乗推定量（平均を引かない）と $\theta = 1$ の固定効果推定量（平均をすべて引く）の中間にあり、本問では個体平均の約 54% を除いた変数で推定している。$T$ が大きいほど、また $\sigma_\alpha^2/\sigma_\varepsilon^2$ が大きいほど $\theta \to 1$ となり、変量効果推定量は固定効果推定量に近づく。

パネルデータ分析の中心は、観測されない個体効果 $\alpha_i$ の扱いです。$\alpha_i$ を変換で消す固定効果モデルと、$\alpha_i$ を誤差の一部とみて GLS で効率よく推定する変量効果モデルの違い、その選択に使うハウスマン検定の論理をまとめて確認します。

### 解答の流れ

1. 個体内変換で $\alpha_i$ を消去し、残った誤差が説明変数と無相関であることから不偏性を示す。
2. 合成誤差の共分散構造（同一個体内で一定の相関）を書き、準平均除去で共分散が 0 になる $\theta$ を確かめる。
3. 「効率的だが仮定に依存する推定量」と「頑健だが効率の劣る推定量」の差を比べる、というハウスマン検定の一般的な構造を述べる。
4. 公式に数値を代入する。

### つまずきやすい点

- 固定効果推定量では、時間を通じて変化しない説明変数（性別、学歴など）の係数は推定できない。個体内変換で $\alpha_i$ と一緒に消えるからである。
- 固定効果推定量の不偏性には「強外生性」（$\varepsilon_{it}$ がすべての期の $x_{is}$ と無相関）が必要。$y_{i,t-1}$ を説明変数に含む動学的パネルでは、$\bar{\varepsilon}_i$ と $y_{i,t-1} - \bar{y}_{i,-1}$ が相関し、$T$ が小さいと偏る（ニッケル・バイアス）。
- ハウスマン統計量の分母は分散の**差**。和にすると統計量が小さくなり、帰無仮説を棄却しにくくなる。

### ポイント

- $T = 2$ のとき、固定効果推定量は 1 階差分 $\Delta y_i = \beta\Delta x_i + \Delta\varepsilon_i$ に最小二乗法を適用した推定量に一致する。
- 変量効果モデルの仮定が成り立つときでも、固定効果推定量は一致推定量であり続ける。迷ったときに固定効果モデルが選ばれやすいのはこのためである。
