$X^\top X = I_p$ のとき、最小二乗推定値 $\boldsymbol{b} = X^\top\boldsymbol{y}$ を用いると $\|\boldsymbol{y} - X\boldsymbol{\beta}\|^2 = \|\boldsymbol{y} - X\boldsymbol{b}\|^2 + \|\boldsymbol{b} - \boldsymbol{\beta}\|^2$ と分解できるので、LASSO の目的関数は成分ごとの $(b_j - \beta_j)^2 + \lambda|\beta_j|$ の和になります。これを各成分で最小にすると、閾値 $\lambda/2$ の軟閾値関数が得られます。

### 計算

$\beta_j > 0$ の範囲では $g(\beta_j) = (b_j - \beta_j)^2 + \lambda\beta_j$ の導関数 $-2(b_j - \beta_j) + \lambda = 0$ から $\beta_j = b_j - \lambda/2$ で、これが正となるのは $b_j > \lambda/2$ のときです。$\beta_j < 0$ も同様で、$|b_j| \leq \lambda/2$ のときは $\beta_j = 0$ で最小になります（0 での劣微分 $[-2b_j - \lambda,\ -2b_j + \lambda]$ が 0 を含む）。まとめると

$$\hat{\beta}_j^{\mathrm{LASSO}} = \mathrm{sign}(b_j)\max\left(|b_j| - \frac{\lambda}{2},\ 0\right),\qquad \hat{\beta}_j^{\mathrm{ridge}} = \frac{b_j}{1 + \lambda}$$

### 各選択肢の検討

- リッジの変数選択：誤り。上の式のとおり、リッジは $b_j$ を一律に $1/(1+\lambda)$ 倍に縮めるだけで、$b_j \neq 0$ なら推定値はちょうど 0 にはならない。ちょうど 0 になるのは、罰則 $|\beta_j|$ が 0 で微分できないことによる LASSO の性質である。
- 尺度への依存：誤り。$x_j$ を $c$ 倍すると対応する係数は $1/c$ 倍になり、罰則 $\lambda|\beta_j|$ の効き方が変わる。罰則つき推定は尺度に依存するので、通常は説明変数を標準化してから当てはめる。
- 正規直交計画での LASSO：正しい（上記）。
- 相関の強いグループ：誤り。LASSO はグループの中から 1 つだけを選び、他を 0 にする傾向がある（どれが選ばれるかはデータの揺らぎに左右される）。グループごと選ぶ性質（グループ化効果）をもつのは、L1 と L2 の罰則を組み合わせたエラスティックネットである。
- $p > n$ でのリッジ：誤り。$X^\top X$ は特異でも、$\lambda > 0$ なら $X^\top X + \lambda I_p$ は正定値で逆行列をもつので、リッジ推定量は一意に定まる。もともとリッジ回帰は、多重共線性で $X^\top X$ が特異に近い場合の対策として提案された。

### ポイント

- 目的関数の罰則を $\frac{1}{2}\|\boldsymbol{y} - X\boldsymbol{\beta}\|^2 + \lambda\sum|\beta_j|$ と書く流儀では閾値が $\lambda$ になる。定数倍の違いに注意する。
- $\lambda$ は交差検証で選ぶことが多い。選んだモデルの係数に通常の最小二乗の標準誤差や $t$ 検定をそのまま当てはめると、選択の影響を無視することになり、有意性を過大評価する。
