状態 $k$ から出発したときの停止までの期待時間を $D_k$ とすると、1 歩目で条件付けて $D_k = 1 + pD_{k+1} + qD_{k-1}$、$D_0 = D_6 = 0$ が成り立ちます。これを解くと $D_k = \dfrac{k}{q - p} - \dfrac{N}{q - p}\cdot\dfrac{1 - (q/p)^k}{1 - (q/p)^N}$（$N = 6$）となり、$D_3 = -15 + 30 \times \dfrac{27}{35} = \dfrac{57}{7} \approx 8.14$ です。

### 計算

差分方程式 $pD_{k+1} - D_k + qD_{k-1} = -1$ の一般解は、同次方程式の解 $A + B(q/p)^k$ と特殊解 $k/(q - p)$ の和です（$p \neq q$）。境界条件 $D_0 = 0$、$D_N = 0$ から

$$D_k = \frac{k}{q - p} - \frac{N}{q - p}\cdot\frac{1 - (q/p)^k}{1 - (q/p)^N}$$

$q/p = 2/3$、$q - p = -0.2$、$N = 6$、$k = 3$ を代入します。$\dfrac{1 - (2/3)^3}{1 - (2/3)^6} = \dfrac{1}{1 + (2/3)^3} = \dfrac{27}{35}$ なので

$$D_3 = \frac{3}{-0.2} - \frac{6}{-0.2}\times\frac{27}{35} = -15 + 30 \times \frac{27}{35} = -15 + \frac{162}{7} = \frac{57}{7} = 8.143$$

### 検算（連立方程式）

対称性はないので、$D_1, \ldots, D_5$ の連立方程式 $D_k = 1 + 0.6D_{k+1} + 0.4D_{k-1}$ を直接解いても $D_1 = 5.962,\ D_2 = 8.271,\ D_3 = 8.143,\ D_4 = 6.391,\ D_5 = 3.556$ となり、一致します。

### ポイント

- 6 に先に到達する確率は $\dfrac{1 - (q/p)^3}{1 - (q/p)^6} = \dfrac{27}{35} = 0.771$。上の式の第 2 項は、この確率を使って「6 に着く場合」と「0 に着く場合」の位置の期待値の差を補正している（ワルドの等式 $E[X_T - X_0] = (p - q)E[T]$ から $E[T] = \{6 \times \frac{27}{35} - 3\}/0.2 = 57/7$ と求めることもできる）。
- 対称な場合（$p = q = 1/2$）は $D_k = k(N - k)$ で、ここでは $9$ になる。偏りがある方が早く端に着く。
- よくある誤り：$3/(p - q) = 15$ と、片側の吸収壁だけを考えた（上側にだけ到達を待つ）期待時間を答える。下側の壁で止まる可能性を無視している。
