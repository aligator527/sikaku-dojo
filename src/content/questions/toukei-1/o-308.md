  計数データ $Y_i$（$i = 1, \ldots, n$）に、説明変数ベクトル $\boldsymbol{x}_i$ を用いたポアソン回帰モデル

  $$Y_i \sim Po(\mu_i),\qquad \log\mu_i = \boldsymbol{x}_i^\top\boldsymbol{\beta}$$

  を当てはめる（$Y_i$ は互いに独立、$\boldsymbol{x}_i$ は切片を含む $p$ 次元）。このモデルとその当てはめに関する記述として、正しいものを一つ選べ。

$\log\mu_i = \log t_i + \boldsymbol{x}_i^\top\boldsymbol{\beta}$ とすると $\log(\mu_i/t_i) = \boldsymbol{x}_i^\top\boldsymbol{\beta}$ となり、発生率の対数が説明変数の線形式で表されます。$\log t_i$ の係数は推定せず 1 に固定するので、これをオフセットと呼びます。ほかの記述はいずれも一般化線形モデルの性質を取り違えています。

### 各選択肢の検討

- 過分散と一致性：誤り。ポアソン回帰の尤度方程式 $\sum_i\boldsymbol{x}_i(Y_i - \mu_i) = \boldsymbol{0}$ は平均の構造 $E[Y_i] = \mu_i$ だけで期待値 0 になる推定方程式なので、分散の仮定が誤っていても推定量は一致性をもつ。崩れるのは標準誤差で、過分散があるとポアソンの公式は標準誤差を過小評価する（検定が有意になりすぎる）。
- 正準リンク：誤り。ポアソン分布を指数型分布族 $\exp\{y\theta - e^{\theta} - \log y!\}$ と書くと自然母数は $\theta = \log\mu$ なので、正準リンクは対数リンクである。恒等リンクは $\mu_i$ が負になりうるので扱いにくい。
- 逸脱度のカイ二乗近似：誤り。逸脱度 $D = 2\sum\{y_i\log(y_i/\hat{\mu}_i) - (y_i - \hat{\mu}_i)\}$ がカイ二乗分布で近似できるのは、各 $\hat{\mu}_i$ がある程度大きい場合に限られる。小さい計数が多いと近似は悪く、2 値データ（ベルヌーイ）では逸脱度は適合度の情報をほとんどもたない。異なるモデルの逸脱度の差（尤度比検定）の近似の方がはるかに頑健である。
- 準ポアソンの推定値：誤り。準尤度の推定方程式はポアソン回帰の尤度方程式と同じなので、推定値は一致する。違うのは標準誤差で、$\sqrt{\hat{\phi}}$ 倍になる（$\hat{\phi}$ はピアソン統計量を残差自由度で割ったもの）。
- オフセット：正しい（上記）。

### ポイント

- 指数型分布族 $f(y) = \exp\{(y\theta - b(\theta))/a(\phi) + c(y, \phi)\}$ では $E[Y] = b'(\theta)$、$V[Y] = a(\phi)b''(\theta)$。ポアソンでは $b(\theta) = e^{\theta}$ なので平均と分散がともに $\mu$ になる。
- 過分散への対処は、準ポアソン（分散を定数倍）、負の二項回帰（分散 $\mu + \mu^2/\theta$）、頑健な（サンドイッチ型）分散推定などがある。
