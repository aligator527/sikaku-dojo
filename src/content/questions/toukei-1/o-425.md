$\hat{\sigma} = 0.04652/2.326 = 0.0200$ です。$C_{pk}$ は、平均から近い方の規格限界までの距離を $3\hat{\sigma}$ で割ったもので、上限側が近いので $C_{pk} = (25.060 - 25.012)/(3 \times 0.0200) = 0.048/0.060 = 0.80$ です。

### 計算

$$C_{pk} = \min\left(\frac{S_U - \bar{\bar{x}}}{3\hat{\sigma}},\ \frac{\bar{\bar{x}} - S_L}{3\hat{\sigma}}\right) = \min\left(\frac{0.048}{0.060},\ \frac{0.072}{0.060}\right) = \min(0.80,\ 1.20) = 0.80$$

平均のかたよりを考えない工程能力指数は $C_p = (S_U - S_L)/(6\hat{\sigma}) = 0.120/0.120 = 1.00$ です。かたより度 $k = |25.012 - 25.000|/0.060 = 0.2$ を用いると、$C_{pk} = (1 - k)C_p = 0.80$ とも計算できます。

### ポイント

- 目安として $C_{pk} \geq 1.33$ なら工程能力は十分、$1.00 \leq C_{pk} < 1.33$ ならまずまず、$C_{pk} < 1.00$ なら不足とされる。本問の工程は、まず平均を規格の中心に合わせる（$C_{pk}$ を $C_p$ に近づける）ことが改善の第一歩である。
- $C_{pk} = 0.80$ は、近い側の規格限界が平均から $3 \times 0.80 = 2.4\sigma$ の位置にあることを意味し、その側の規格外れ率は $Q(2.40) \approx 0.82\%$。
- よくある誤り：$\sigma$ を $\bar{R}$ そのもので代用する（$C_{pk} = 0.34$）、$\sigma/\sqrt{n}$（$\bar{X}$ の標準偏差）を使う。工程能力は個々の製品のばらつきで評価する。
