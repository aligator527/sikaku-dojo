  $X_1, \ldots, X_m$ は互いに独立に平均 $\theta_1$ の指数分布（密度 $\theta_1^{-1}e^{-x/\theta_1},\ x > 0$）に、$Y_1, \ldots, Y_n$ は互いに独立に平均 $\theta_2$ の指数分布に従い、2 つの標本は互いに独立とする。

  $$H_0: \theta_1 = \theta_2 \quad \text{vs.} \quad H_1: \theta_1 \neq \theta_2$$

  を検定する。以下の各問に答えよ。

  [1] 尤度比 $\Lambda$ を求め、$T = \dfrac{m\bar{X}}{m\bar{X} + n\bar{Y}}$ の関数として表せ。また、棄却域 $\{\Lambda < k\}$ が $T$ についてどのような形になるか述べよ。

modelAnswer: |
  **[1]** 対数尤度は

  $$\ell(\theta_1, \theta_2) = -m\log\theta_1 - \frac{m\bar{X}}{\theta_1} - n\log\theta_2 - \frac{n\bar{Y}}{\theta_2}$$

  $H_1$ のもとでの最尤推定量は $\hat{\theta}_1 = \bar{X},\ \hat{\theta}_2 = \bar{Y}$、$H_0$ のもとでは $\hat{\theta} = \dfrac{m\bar{X} + n\bar{Y}}{m + n}$。指数の部分はどちらも $e^{-(m + n)}$ になるので

  $$\Lambda = \frac{\hat{\theta}^{-(m+n)}}{\bar{X}^{-m}\bar{Y}^{-n}} = \frac{\bar{X}^m\bar{Y}^n}{\hat{\theta}^{m+n}}$$

  $\bar{X} = T(m\bar{X} + n\bar{Y})/m$、$\bar{Y} = (1 - T)(m\bar{X} + n\bar{Y})/n$ を代入すると

  $$\Lambda = \frac{(m + n)^{m+n}}{m^m n^n}\,T^m(1 - T)^n$$

  $h(T) = T^m(1 - T)^n$ は $T = m/(m + n)$ で最大となる単峰の関数なので、$\{\Lambda < k\}$ は $\{T < c_1\} \cup \{T > c_2\}$（$h(c_1) = h(c_2)$、$c_1 < m/(m + n) < c_2$）の形になる。

  **[2]** $X_i/\theta_1$ は平均 1 の指数分布に従い、$2X_i/\theta_1 \sim \chi^2(2)$。再生性より $2m\bar{X}/\theta_1 \sim \chi^2(2m)$、同様に $2n\bar{Y}/\theta_2 \sim \chi^2(2n)$ で、両者は独立。よって

  $$\frac{\{2m\bar{X}/\theta_1\}/(2m)}{\{2n\bar{Y}/\theta_2\}/(2n)} = \frac{\bar{X}/\theta_1}{\bar{Y}/\theta_2} \sim F(2m, 2n)$$

  $H_0$（$\theta_1 = \theta_2$）のもとでは $F = \bar{X}/\bar{Y} \sim F(2m, 2n)$。

  **[3]** $m = n$ のとき $T = F/(1 + F)$ は $F$ の増加関数で、$h(T) = \{T(1 - T)\}^m$ は $T = 1/2$ について対称である。$T \mapsto 1 - T$ は $F \mapsto 1/F$ に対応するので、棄却域は $\{F < 1/c\} \cup \{F > c\}$（$c > 1$）の形になる。$H_0$ のもとで $F \sim F(2m, 2m)$ であり、$1/F$ も同じ分布 $F(2m, 2m)$ に従うので、$P(F > c) = P(F < 1/c)$。大きさを $\alpha$ にするには $P(F > c) = \alpha/2$、すなわち $c = F_{\alpha/2}(2m, 2m)$ であり、これは両側に $\alpha/2$ ずつとる検定にほかならない。

  **[4]** $F = 3.0/1.2 = 2.5$。棄却域は $\{F > 3.717\} \cup \{F < 1/3.717 = 0.269\}$ で、$F = 2.5$ はどちらにも入らないので、有意水準 5% で $H_0$ は棄却されない。

  $T = 2.5/3.5 = 5/7$、$4T(1 - T) = 4 \times \dfrac{5}{7} \times \dfrac{2}{7} = \dfrac{40}{49}$ なので

  $$\Lambda = 2^{10}\{T(1 - T)\}^5 = \left(\frac{40}{49}\right)^5,\qquad -2\log\Lambda = 10\log\frac{49}{40} = 2.029$$

  $2.029 < 3.841$ なので、ウィルクスの近似でも $H_0$ は棄却されない。

指数分布の 2 標本比較は、正規分布の分散比の検定と同じく $F$ 分布で正確に扱えます。尤度比が $T = m\bar{X}/(m\bar{X} + n\bar{Y})$ の単峰関数になること、$m = n$ のときは対称性によって等裾の $F$ 検定と一致することがポイントです。

### 解答の流れ

1. 両仮説のもとで最尤推定量を求めて代入すると、指数の部分が打ち消し合う。
2. 尤度比を $T$（ベータ分布 $\mathrm{Beta}(m, n)$ に従う統計量）で書き、単峰性から棄却域の形を決める。
3. $2X_i/\theta_1 \sim \chi^2(2)$ から $F$ 分布を導く。
4. $m = n$ の対称性で、棄却域の 2 つの端点が $c$ と $1/c$ になることを示す。

### つまずきやすい点

- $F$ 分布の自由度を $(m, n)$ とする誤り。指数分布 1 個が $\chi^2(2)$ に対応するので $(2m, 2n)$ です。
- 下側の棄却点を $F_{0.975}(10, 10)$ として表から探す必要はありません。$F_{0.975}(\nu_1, \nu_2) = 1/F_{0.025}(\nu_2, \nu_1)$ より $1/3.717 = 0.269$ です。
- $m \neq n$ のときは $h(c_1) = h(c_2)$ を満たす $c_1, c_2$ が等裾にならないので、尤度比検定と等裾の $F$ 検定はわずかに異なります。

### ポイント

- 正確な両側 $p$ 値は $2P(F(10, 10) > 2.5) \approx 0.16$ です。平均の比が 2.5 倍でも、各群 5 個の指数分布データでは差があるとはいえません。
- 2 つの検定統計量の関係 $T = mF/(mF + n)$ と $T \sim \mathrm{Beta}(m, n)$ は、ガンマ分布とベータ分布の関係（独立なガンマ変数の比）から導くこともできます。
