最小値と最大値の同時密度から範囲 $R$ の分布を導くと、$n$ 個の一様乱数について $P(R \leq r) = n r^{n-1} - (n-1) r^{n}$ となります。$n = 5,\ r = 0.5$ を代入すると $5 \times 0.5^4 - 4 \times 0.5^5 = 0.3125 - 0.125 = 0.1875 = 3/16$ です。

### 計算

$n$ 個の独立な $U(0,1)$ の最小値 $U_{(1)}$ と最大値 $U_{(n)}$ の同時密度は

$$f(u, v) = n(n-1)(v - u)^{n-2} \qquad (0 < u < v < 1)$$

です（$n$ 個のうち 1 個が $u$ に、1 個が $v$ に、残り $n - 2$ 個が $(u, v)$ に入る）。$R = V - U$ と $U$ に変数変換すると（ヤコビアンは 1）、$U$ の範囲は $0 < u < 1 - r$ なので

$$f_R(r) = \int_0^{1-r} n(n-1)r^{n-2}\,du = n(n-1)r^{n-2}(1 - r) \qquad (0 < r < 1)$$

これは $\mathrm{Beta}(n-1,\ 2)$ 分布です。分布関数は

$$P(R \leq r) = n(n-1)\left(\frac{r^{n-1}}{n-1} - \frac{r^{n}}{n}\right) = n r^{n-1} - (n-1) r^{n}$$

$n = 5,\ r = 0.5$ では

$$P(R \leq 0.5) = 5 \times \frac{1}{16} - 4 \times \frac{1}{32} = \frac{5}{16} - \frac{2}{16} = \frac{3}{16} = 0.1875$$

### 別解（直接の数え上げ）

「すべての点がある長さ 0.5 の区間に入る」事象を、最小値になる点で場合分けします。最小値が $U_i = u$ で、他の 4 点が $(u,\ u + 0.5)$ に入る確率を積分すると

$$5\left[\int_0^{0.5} 0.5^4\,du + \int_{0.5}^{1}(1 - u)^4\,du\right] = 5\left[0.5^5 + \frac{0.5^5}{5}\right] = 5 \times 0.03125 + 0.03125 = 0.1875$$

### ポイント

- 範囲の期待値は $E[R] = \dfrac{n-1}{n+1}$（ここでは $2/3$）。順序統計量 $U_{(k)} \sim \mathrm{Beta}(k,\ n-k+1)$ もあわせて覚える。
- よくある誤り：$P(U_{(5)} \leq 0.5) = 0.5^5 = 0.03125$ と「最大値」の確率で代用する（最小値の位置を考慮していない）。
