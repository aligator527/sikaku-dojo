  1 次の自己回帰モデル AR(1)

  $$y_t = c + \phi y_{t-1} + \varepsilon_t,\qquad |\phi| < 1$$

  を考える。$\{\varepsilon_t\}$ は互いに独立に $N(0, \sigma^2)$ に従い、$\varepsilon_t$ は $y_{t-1}, y_{t-2}, \ldots$ と独立とする。$\{y_t\}$ は弱定常であるとする。以下の各問に答えよ。

  [1] $y_t$ の平均 $\mu$、分散 $\gamma(0)$、自己相関関数 $\rho(h)$（$h = 0, 1, 2, \ldots$）を求めよ。

  [2] 長さ $n = 100$ の時系列から、標本平均 $\bar{y} = 10.0$、標本分散 $\hat{\gamma}(0) = 2.5$、ラグ 1 の標本自己相関係数 $r_1 = 0.6$ を得た。ユール・ウォーカー法により $\phi,\ \sigma^2,\ c$ を推定せよ。

  [3] $\hat{\phi}$ の漸近分布が $N(\phi,\ (1 - \phi^2)/n)$ であることを用いて、$\phi$ の近似 95% 信頼区間を求めよ。標準正規分布の上側 2.5% 点は $1.96$ とする。

  [4] 最終時点の観測値が $y_n = 12.0$ であった。[2] の推定値を真の値とみなして、1 期先と 2 期先の予測値 $\hat{y}_{n+1},\ \hat{y}_{n+2}$ と、それぞれの予測誤差の分散を求めよ。さらに $y_{n+1}$ の 95% 予測区間を求め、予測期間 $h \to \infty$ としたときの予測値と予測誤差の分散の極限を述べよ。必要なら $\sqrt{1.6} = 1.265$ を用いよ。
modelAnswer: |
  **[1]** 定常性より $E[y_t] = E[y_{t-1}] = \mu$ なので $\mu = c + \phi\mu$、$\mu = c/(1 - \phi)$。$\tilde{y}_t = y_t - \mu$ とおくと $\tilde{y}_t = \phi\tilde{y}_{t-1} + \varepsilon_t$。両辺の分散をとると、$\varepsilon_t$ と $\tilde{y}_{t-1}$ の独立性から

  $$\gamma(0) = \phi^2\gamma(0) + \sigma^2 \ \Rightarrow\ \gamma(0) = \frac{\sigma^2}{1 - \phi^2}$$

  $h \geq 1$ では両辺に $\tilde{y}_{t-h}$ を掛けて期待値をとると $\gamma(h) = \phi\gamma(h - 1)$（$\varepsilon_t$ は $\tilde{y}_{t-h}$ と独立）。よって $\gamma(h) = \phi^h\gamma(0)$、$\rho(h) = \phi^h$。

  **[2]** ユール・ウォーカー方程式 $\rho(1) = \phi$ に標本自己相関を代入して $\hat{\phi} = r_1 = 0.6$。

  $$\hat{\sigma}^2 = \hat{\gamma}(0)(1 - \hat{\phi}^2) = 2.5 \times 0.64 = 1.6,\qquad \hat{c} = \bar{y}(1 - \hat{\phi}) = 10.0 \times 0.4 = 4.0$$

  **[3]** 標準誤差は $\sqrt{(1 - 0.6^2)/100} = \sqrt{0.0064} = 0.08$ なので

  $$0.6 \pm 1.96 \times 0.08 = 0.6 \pm 0.157 = [0.443,\ 0.757]$$

  区間は 0 も 1 も含まず、正の自己相関をもつ定常な過程であることと整合的である（ただし単位根 $\phi = 1$ の近くではこの正規近似は成り立たないので、単位根の検定には別の方法を用いる）。

  **[4]** 予測値は条件付き期待値で、未来の誤差を 0 とおいて逐次計算する。

  $$\hat{y}_{n+1} = 4.0 + 0.6 \times 12.0 = 11.2,\qquad \hat{y}_{n+2} = 4.0 + 0.6 \times 11.2 = 10.72$$

  予測誤差は $y_{n+1} - \hat{y}_{n+1} = \varepsilon_{n+1}$、$y_{n+2} - \hat{y}_{n+2} = \varepsilon_{n+2} + \phi\varepsilon_{n+1}$ なので、分散は

  $$\sigma^2 = 1.6,\qquad \sigma^2(1 + \phi^2) = 1.6 \times 1.36 = 2.176$$

  $y_{n+1}$ の 95% 予測区間は $11.2 \pm 1.96 \times 1.265 = 11.2 \pm 2.48 = [8.72,\ 13.68]$。

  一般に $h$ 期先では $\hat{y}_{n+h} = \mu + \phi^h(y_n - \mu)$、予測誤差の分散は $\sigma^2(1 + \phi^2 + \cdots + \phi^{2(h-1)}) = \sigma^2\dfrac{1 - \phi^{2h}}{1 - \phi^2}$ である。$h \to \infty$ で予測値は平均 $\mu = 10.0$ に、予測誤差の分散は $\gamma(0) = 2.5$ に収束する。遠い将来については、現在の値は情報をもたず、定常分布そのものが予測分布になる。

AR(1) モデルのモーメント、ユール・ウォーカー推定、推定量の漸近分布、予測と予測誤差という、時系列解析の基本の流れを確認する問題です。

### 解答の流れ

1. 定常性（平均・分散が時点によらない）を使って、モデル式の両辺の平均・分散・共分散を比べる。
2. ユール・ウォーカー法は、理論自己相関を標本自己相関で置き換えて母数を解く方法。
3. AR(1) の $\hat{\phi}$ の漸近分散は $(1 - \phi^2)/n$。$\phi$ が 1 に近いほど推定は精密になる。
4. 予測は条件付き期待値。予測誤差は MA($\infty$) 表現 $y_t = \mu + \sum_{j \geq 0}\phi^j\varepsilon_{t-j}$ の未来の項から生じる。

### つまずきやすい点

- $\hat{c}$ を $\bar{y}$ そのもの（10.0）とする誤り。定数項 $c$ と平均 $\mu = c/(1-\phi)$ は異なる。
- 2 期先の予測誤差の分散を $2\sigma^2$ や $\sigma^2$ とする誤り。$\varepsilon_{n+1}$ が $\phi$ 倍されて $y_{n+2}$ に伝わるので $\sigma^2(1 + \phi^2)$ である。
- $\hat{\sigma}^2$ を $\hat{\gamma}(0) = 2.5$ とする誤り。$\gamma(0)$ は $y_t$ の分散で、誤差（イノベーション）の分散 $\sigma^2$ はその $1 - \phi^2$ 倍である。

### ポイント

- 予測区間は「母数が既知」という仮定のもとのものである。実際には推定誤差の分だけわずかに広くなる。
- AR(1) では偏自己相関はラグ 1 で $\phi$、ラグ 2 以降は 0 になる（自己相関は指数的に減衰する）。
