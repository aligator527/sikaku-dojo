  大きさ $N$ の有限母集団が $H$ 個の層に分かれ、第 $h$ 層の大きさを $N_h$、層の重みを $W_h = N_h/N$、層平均を $\bar{Y}_h$、層内分散を $S_h^2 = \frac{1}{N_h - 1}\sum_{j=1}^{N_h}(Y_{hj} - \bar{Y}_h)^2$ とする。各層から大きさ $n_h$ の非復元単純無作為抽出を互いに独立に行い、層別の標本平均 $\bar{y}_h$ から母平均 $\bar{Y}$ を層別推定量 $\bar{y}_{st} = \sum_h W_h\bar{y}_h$ で推定する。以下の各問に答えよ。

  [1] $\bar{y}_{st}$ が $\bar{Y}$ の不偏推定量であることを示し、その分散を求めよ。ただし、大きさ $N_h$ の母集団からの大きさ $n_h$ の非復元単純無作為抽出で $V[\bar{y}_h] = (1 - n_h/N_h)S_h^2/n_h$ となることは用いてよい。

  [2] 有限母集団修正を無視し（$n_h/N_h \approx 0$）、第 $h$ 層での 1 単位あたりの調査費用を $c_h$ として、総費用 $\sum_h c_hn_h = C$ のもとで $V[\bar{y}_{st}]$ を最小にする $n_h$ を求めよ。

  [3] 有限母集団修正を無視し、総標本サイズ $n = \sum_h n_h$ を固定する。比例割当（$n_h = nW_h$）とネイマン割当（$n_h \propto W_hS_h$）の分散の差が

  $$V_{\text{prop}} - V_{\text{Ney}} = \frac{1}{n}\sum_h W_h(S_h - \bar{S})^2,\qquad \bar{S} = \sum_h W_hS_h$$

  となることを示せ。

  [4] $H = 2$、$W_1 = 0.6,\ W_2 = 0.4$、$S_1 = 10,\ S_2 = 30$、$c_1 = 1,\ c_2 = 4$、$C = 500$ のとき、[2] の最適な $n_1,\ n_2$ と、そのときの $V[\bar{y}_{st}]$（有限母集団修正は無視）を求めよ。同じ費用で比例割当とした場合の分散とも比較せよ。
modelAnswer: |
  **[1]** 各層で $E[\bar{y}_h] = \bar{Y}_h$ なので

  $$E[\bar{y}_{st}] = \sum_h W_h\bar{Y}_h = \frac{1}{N}\sum_h N_h\bar{Y}_h = \bar{Y}$$

  層ごとの抽出は独立なので共分散は 0 で

  $$V[\bar{y}_{st}] = \sum_h W_h^2V[\bar{y}_h] = \sum_h W_h^2\left(1 - \frac{n_h}{N_h}\right)\frac{S_h^2}{n_h}$$

  **[2]** $V = \sum_h W_h^2S_h^2/n_h$ を、$\sum_h c_hn_h = C$ のもとで最小化する。コーシー・シュワルツの不等式より

  $$V \cdot C = \left(\sum_h\frac{W_h^2S_h^2}{n_h}\right)\left(\sum_h c_hn_h\right) \geq \left(\sum_h W_hS_h\sqrt{c_h}\right)^2$$

  で、等号は $\dfrac{W_hS_h/\sqrt{n_h}}{\sqrt{c_hn_h}}$ が $h$ によらず一定、すなわち $n_h \propto \dfrac{W_hS_h}{\sqrt{c_h}}$ のとき成り立つ。費用の制約から

  $$n_h = C\,\frac{W_hS_h/\sqrt{c_h}}{\sum_k W_kS_k\sqrt{c_k}},\qquad V_{\min} = \frac{\left(\sum_h W_hS_h\sqrt{c_h}\right)^2}{C}$$

  （ラグランジュの未定乗数法でも同じ結果を得る。）ばらつきの大きい層・大きな層からは多く、費用の高い層からは少なくとる。

  **[3]** 比例割当では $n_h = nW_h$ より $V_{\text{prop}} = \dfrac{1}{n}\sum_h W_hS_h^2$。ネイマン割当では $n_h = nW_hS_h/\bar{S}$ より $V_{\text{Ney}} = \sum_h\dfrac{W_h^2S_h^2\bar{S}}{nW_hS_h} = \dfrac{\bar{S}^2}{n}$。よって

  $$V_{\text{prop}} - V_{\text{Ney}} = \frac{1}{n}\left(\sum_h W_hS_h^2 - \bar{S}^2\right) = \frac{1}{n}\sum_h W_h(S_h - \bar{S})^2$$

  （$\sum W_h = 1$ より、右辺は $S_h$ の重み付き分散。）層内標準偏差が層によって異なるほど、ネイマン割当の利益が大きい。

  **[4]** $W_hS_h/\sqrt{c_h}$ は $6/1 = 6$、$12/2 = 6$、$\sum W_hS_h\sqrt{c_h} = 6 \times 1 + 12 \times 2 = 30$ なので

  $$n_1 = 500 \times \frac{6}{30} = 100,\qquad n_2 = 500 \times \frac{6}{30} = 100$$

  （費用 $100 \times 1 + 100 \times 4 = 500$）。分散は

  $$V = \frac{0.36 \times 100}{100} + \frac{0.16 \times 900}{100} = 0.36 + 1.44 = 1.80 \quad \left(= \frac{30^2}{500}\right)$$

  比例割当では $n_h = nW_h$ で費用は $n(0.6 \times 1 + 0.4 \times 4) = 2.2n = 500$ より $n = 227.3$、分散は $\dfrac{0.6 \times 100 + 0.4 \times 900}{227.3} = \dfrac{420}{227.3} = 1.85$。最適割当のほうが分散が小さい。

層別抽出は、層内が均質になるように層を作ると精度が上がる抽出法です。さらに、標本の割り当て方を工夫すると精度が上がります。最適割当（費用を考慮したネイマン割当）は「層が大きいほど、層内のばらつきが大きいほど多く、費用が高いほど少なく」とるという直感を、$n_h \propto W_hS_h/\sqrt{c_h}$ という式で表したものです。

### 解答の流れ

1. 層ごとの推定量の不偏性と分散を、独立性で足し合わせる。
2. 分散と費用の積をコーシー・シュワルツの不等式で下から抑える（積は $n_h$ のスケールによらない）。
3. 比例割当とネイマン割当の分散を具体的に書き、差を平方完成する。
4. 数値を代入する。比例割当は「同じ費用」で比べることに注意する。

### つまずきやすい点

- 費用を考慮した最適割当では $\sqrt{c_h}$ で割ります。$c_h$ で割る誤りが多く見られます。
- 費用が層によって違うとき、比例割当と比べるには「同じ総費用」にそろえる必要があります。総標本サイズ $n$ をそろえると比較の意味が変わります。
- [4] では層 2 のばらつきが 3 倍ですが費用が 4 倍なので、$S_h/\sqrt{c_h}$ の比は $10 : 15$ となり、層の重みを掛けると 2 層の配分が等しくなります。

### ポイント

- 有限母集団修正を無視すると、層別抽出（比例割当）と単純無作為抽出の分散の差はおよそ $\frac{1}{n}\sum_h W_h(\bar{Y}_h - \bar{Y})^2$ で、層平均の違いが大きいほど層別の効果が大きくなります。
- ネイマン割当で $n_h > N_h$ となる層が出たら、その層は全数調査とし、残りの層で割当をやり直します。
