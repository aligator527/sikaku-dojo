最強力検定は尤度比 $f_1(x)/f_0(x)$ が大きい点から棄却域に入れます。尤度比は $|x|$ の関数で、$|x| = 1$ で最小、$|x| = 0$ と $|x| \to \infty$ の両側で大きくなるので、棄却域は「中心付近」と「裾」の 2 つの部分からなります。$\alpha = 0.10$ では中心付近も棄却域に含まれます。

### 計算

$$r(x) = \frac{f_1(x)}{f_0(x)} = \sqrt{\frac{\pi}{2}}\exp\left(\frac{x^2}{2} - |x|\right)$$

$u = |x|$ として $g(u) = u^2/2 - u$ は $u = 1$ で最小値 $-1/2$ をとり、$0 \leq u < 1$ で減少、$u > 1$ で増加します。よって $\{r(x) > k\}$ は

- $k \geq r(0) = \sqrt{\pi/2}$ のとき $\{|x| > b\}$（$b \geq 2$）
- $r(1) < k < r(0)$ のとき $\{|x| < a\} \cup \{|x| > b\}$（$0 < a < 1 < b$）

となり、後者では $r(a) = r(b)$ から $a^2/2 - a = b^2/2 - b$、すなわち $(b - a)(a + b - 2) = 0$ より $a + b = 2$ です。

前者の形で達成できる大きさの最大値は $b = 2$ のときの $P(|Z| > 2) = 0.0455$ です。$\alpha = 0.10 > 0.0455$ なので後者の形になり、大きさの条件 $P(|Z| < a) + P(|Z| > 2 - a) = 0.10$ を数値的に解くと $a \approx 0.060$、$b \approx 1.940$ です。

### 各選択肢の検討

- $\{|x| < a\} \cup \{|x| > b\}$：正しい。
- $\{|x| > c\}$：「対立仮説の分布は裾が重いから、$|x|$ が大きいときに棄却」という直感による誤りです。この形が最強力になるのは $\alpha \leq 0.0455$ のときだけです。$\alpha = 0.10$ では、$c = 1.645$ とした検定の検出力 $0.193$ は、最強力検定の検出力 $0.202$ より小さくなります。
- $\{|x| < c\}$：ラプラス分布の密度が 0 で尖っていることだけに注目した誤りです。裾での尤度比の増加を無視しています。
- $\{a < |x| < b\}$：尤度比が最小になる $|x| = 1$ の付近を棄却域にしており、逆です。尤度比の小さい点を棄却域に入れると検出力は下がります。
- $\{x > c\}$：両分布とも 0 について対称なので、尤度比は $x$ の符号によりません。片側だけの棄却域は最強力になりません。

### ポイント

- ネイマン・ピアソンの補題では、棄却域の形は尤度比の等高線で決まり、「対立仮説の特徴」の直感とは一致しないことがあります。棄却域の形が $\alpha$ によって変わることもあります。
- 尤度比の単調性がないため、この問題の最強力検定は「$|X|$ が大きいほど $H_1$ らしい」という単純な順序をもちません。
