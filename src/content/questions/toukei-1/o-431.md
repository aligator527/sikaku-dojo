  原料のロット間のばらつきを調べるため、$a$ 個のロットを無作為に選び、各ロットから $n$ 個の試料をとって純度を測定する。測定値 $y_{ij}$（$i = 1, \ldots, a$；$j = 1, \ldots, n$）に変量模型

  $$y_{ij} = \mu + \alpha_i + \varepsilon_{ij},\qquad \alpha_i \sim N(0, \sigma_A^2),\quad \varepsilon_{ij} \sim N(0, \sigma^2)$$

  を仮定する（すべて互いに独立）。ロット間平方和を $S_A = n\sum_i(\bar{y}_{i\cdot} - \bar{y}_{\cdot\cdot})^2$、ロット内平方和を $S_E = \sum_i\sum_j(y_{ij} - \bar{y}_{i\cdot})^2$、平均平方を $V_A = S_A/(a - 1)$、$V_E = S_E/\{a(n - 1)\}$ とする。以下の各問に答えよ。

  [1] $E[V_E] = \sigma^2$、$E[V_A] = \sigma^2 + n\sigma_A^2$ を示せ。

  [2] $\sigma_A^2$ の不偏推定量を作り、それが負の値をとりうることを説明せよ。また、級内相関係数 $\rho = \sigma_A^2/(\sigma_A^2 + \sigma^2)$ の意味を述べよ。

  [3] $a = 6$、$n = 4$ で $S_A = 45.0$、$S_E = 36.0$ を得た。分散分析表を作り、有意水準 5% で $H_0: \sigma_A^2 = 0$ を検定せよ。また $\sigma_A^2$ と $\rho$ を推定せよ。$F_{0.05}(5, 18) = 2.773$ とする。

  [4] 総平均 $\bar{y}_{\cdot\cdot}$ の分散を求め、$\mu$ の 95% 信頼区間の半幅を [3] のデータについて求めよ。$t_{0.025}(5) = 2.571$ とする。また、$V_E$ と自由度 18 の $t$ 分布を使うのが誤りである理由を述べよ。
modelAnswer: |
  **[1]** ロット内では $y_{ij} - \bar{y}_{i\cdot} = \varepsilon_{ij} - \bar{\varepsilon}_{i\cdot}$ で $\alpha_i$ が消える。$\sum_j(\varepsilon_{ij} - \bar{\varepsilon}_{i\cdot})^2$ の期待値は $(n - 1)\sigma^2$（標本分散の不偏性）なので

  $$E[S_E] = a(n - 1)\sigma^2,\qquad E[V_E] = \sigma^2$$

  ロット平均は $\bar{y}_{i\cdot} = \mu + \alpha_i + \bar{\varepsilon}_{i\cdot}$ で、$i$ について独立に分散 $\sigma_A^2 + \sigma^2/n$ をもつ。よって

  $$E\left[\sum_i(\bar{y}_{i\cdot} - \bar{y}_{\cdot\cdot})^2\right] = (a - 1)\left(\sigma_A^2 + \frac{\sigma^2}{n}\right),\qquad E[V_A] = n\left(\sigma_A^2 + \frac{\sigma^2}{n}\right) = \sigma^2 + n\sigma_A^2$$

  **[2]** [1] より

  $$\hat{\sigma}_A^2 = \frac{V_A - V_E}{n}$$

  は不偏推定量である。$V_A$ と $V_E$ は独立な確率変数なので、$\sigma_A^2$ が小さいときには $V_A < V_E$ となる確率が無視できず、推定値が負になりうる（その場合は 0 と報告するのが普通である）。

  級内相関係数 $\rho$ は、同じロットの 2 つの測定値の相関係数 $\mathrm{Cov}(y_{ij}, y_{ij'})/V[y_{ij}] = \sigma_A^2/(\sigma_A^2 + \sigma^2)$ であり、全変動のうちロット間変動が占める割合を表す。

  **[3]**

  | 要因 | 平方和 | 自由度 | 平均平方 | $F$ |
  | --- | --- | --- | --- | --- |
  | ロット間 | 45.0 | 5 | 9.0 | 4.50 |
  | ロット内 | 36.0 | 18 | 2.0 | |
  | 計 | 81.0 | 23 | | |

  $H_0$ のもとで $F = V_A/V_E \sim F(5, 18)$ であり、$4.50 > 2.773$ なので $H_0$ を棄却し、ロット間にばらつきがあると判断する。

  $$\hat{\sigma}_A^2 = \frac{9.0 - 2.0}{4} = 1.75,\qquad \hat{\sigma}^2 = 2.0,\qquad \hat{\rho} = \frac{1.75}{1.75 + 2.0} = 0.467$$

  **[4]** $\bar{y}_{\cdot\cdot} = \mu + \bar{\alpha} + \bar{\varepsilon}_{\cdot\cdot}$ より

  $$V[\bar{y}_{\cdot\cdot}] = \frac{\sigma_A^2}{a} + \frac{\sigma^2}{an} = \frac{\sigma^2 + n\sigma_A^2}{an} = \frac{E[V_A]}{an}$$

  したがって $V_A/(an)$ が不偏推定量で、$(\bar{y}_{\cdot\cdot} - \mu)/\sqrt{V_A/(an)}$ は自由度 $a - 1 = 5$ の $t$ 分布に従う。95% 信頼区間の半幅は

  $$t_{0.025}(5)\sqrt{\frac{V_A}{an}} = 2.571 \times \sqrt{\frac{9.0}{24}} = 2.571 \times 0.612 = 1.57$$

  $V_E/(an)$ はロット内の変動しか含まず、ロット間の変動 $\sigma_A^2/a$ を無視しているので分散を過小評価する。母平均の推定の精度を決めるのはロットの数 $a$ であり、自由度も $a - 1$ である。誤って $t_{0.025}(18)\sqrt{V_E/24}$ を使うと半幅は約 0.61 となり、実際より狭すぎる区間になる。

変量模型（変量効果モデル）は、ロット間・装置間・測定者間のばらつきを分散成分として推定する方法で、品質管理や測定システムの評価（ゲージ R&R）の基礎になります。母数模型と同じ分散分析表を使いますが、期待平均平方と推測の対象が異なります。

### 解答の流れ

1. ロット内の偏差とロット平均のそれぞれについて、どの確率変数が残るかを確認して期待値を計算する。
2. 期待平均平方の差から分散成分の推定量を作る（モーメント法）。
3. 分散分析表を作り、$F$ 検定と分散成分の推定を行う。
4. 総平均の分散にロット間の成分が $1/a$ でしか減らない形で入ることを確認する。

### つまずきやすい点

- 変量模型の $F$ 検定の統計量は母数模型と同じ $V_A/V_E$ だが、帰無仮説は「効果がすべて 0」ではなく「$\sigma_A^2 = 0$」である。
- 総平均の標準誤差に $V_E$ を使うと、ロット間の変動を無視した過度に楽観的な精度評価になる。各ロットからの試料数 $n$ を増やしても、$\sigma_A^2/a$ の項は減らない。

### ポイント

- $\sigma_A^2$ の信頼区間は正確には求まらないが、$\sigma^2 + n\sigma_A^2$ については $(a - 1)V_A/(\sigma^2 + n\sigma_A^2) \sim \chi^2(a - 1)$ を使える。
- 測定システムの評価では、測定値の全変動を「部品間」「繰返し性」「再現性」の分散成分に分け、測定のばらつきが全体に占める割合で測定システムの適否を判断する。
