  確率変数 $W$ は確率密度関数

  $$g(w) = 4w\,e^{-2w}\qquad (w > 0)$$

正規分布の精度（分散の逆数）をガンマ分布で混合すると $t$ 分布が得られます。$W \sim Ga(\nu/2,\ \text{率 } \nu/2)$ のとき $X \sim t(\nu)$ で、ここでは $\nu/2 = 2$ より自由度 4 です。

### 計算

$X$ の周辺密度は

$$f(x) = \int_0^\infty \sqrt{\frac{w}{2\pi}}\,e^{-wx^2/2}\cdot 4we^{-2w}\,dw = \frac{4}{\sqrt{2\pi}}\int_0^\infty w^{3/2}\exp\left\{-w\left(2 + \frac{x^2}{2}\right)\right\}dw$$

ガンマ関数の積分 $\int_0^\infty w^{s-1}e^{-cw}\,dw = \Gamma(s)/c^s$ を $s = 5/2,\ c = 2 + x^2/2$ で用いると

$$f(x) = \frac{4\,\Gamma(5/2)}{\sqrt{2\pi}}\left(2 + \frac{x^2}{2}\right)^{-5/2} \propto \left(1 + \frac{x^2}{4}\right)^{-5/2}$$

これは自由度 $\nu = 4$ の $t$ 分布の密度 $\propto (1 + x^2/\nu)^{-(\nu+1)/2}$ の形です（定数も $\Gamma(5/2)/\{\sqrt{4\pi}\,\Gamma(2)\}$ に一致します）。

### 各選択肢の検討

- $N(0,\ 2)$：分散は $V[X] = E[V[X \mid W]] = E[1/W] = 2$ で一致するが、分散の異なる正規分布の混合は正規分布ではない（裾が重く、尖度が 3 より大きい）。
- 自由度 2 の $t$ 分布：ガンマ分布の形状母数 2 をそのまま自由度とした誤り。自由度は形状母数の 2 倍である。
- $N(0,\ 1)$：$W$ をその期待値 $E[W] = 1$ で置き換えた誤り。混合による裾の重さが失われる。
- 自由度 4 の $t$ 分布：正しい。
- 標準コーシー分布：自由度 1 の $t$ 分布で、$W \sim Ga(1/2,\ \text{率 } 1/2)$（$\chi^2(1)$）の場合に得られる。

### ポイント

- $Z \sim N(0, 1)$ と $V \sim \chi^2(\nu)$ が独立なとき $T = Z/\sqrt{V/\nu}$ は $t(\nu)$ に従う。$W = V/\nu \sim Ga(\nu/2,\ \text{率 } \nu/2)$ とすれば、$T \mid W \sim N(0,\ 1/W)$ であり、この問題はその書き換えである。
- ベイズ統計では、正規分布の精度にガンマ事前分布を置くと、平均の周辺事後分布が $t$ 分布になる。頑健な回帰モデル（$t$ 誤差）をこの階層表現で扱うこともある。
