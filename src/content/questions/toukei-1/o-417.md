  単回帰モデル $y_i = \beta_0 + \beta_1 x_i + u_i$（$i = 1, \ldots, n$）において、$u_i$ は互いに独立で $E[u_i \mid x] = 0$、$V[u_i \mid x] = \sigma_i^2$ とする（不均一分散）。以下の各問に答えよ。

  [1] 最小二乗推定量 $\hat{\beta}_1$ が（$x$ を所与として）不偏であることを示し、その分散を求めよ。また、通常の公式 $\sigma^2/\sum(x_i - \bar{x})^2$ が一般には正しくない理由と、ホワイトの不均一分散に頑健な分散推定量を述べよ。

  [2] 原点を通るモデル $y_i = \beta x_i + u_i$（$x_i > 0$）で $V[u_i \mid x] = \sigma^2x_i^2$ の場合を考える。両辺を $x_i$ で割る変換を用いて加重最小二乗推定量 $\tilde{\beta}$ を求め、これが最良線形不偏推定量である理由を説明せよ。

  [3] [2] のモデルで、最小二乗推定量 $\hat{\beta} = \sum x_iy_i/\sum x_i^2$ と $\tilde{\beta}$ の分散を求め、$V[\tilde{\beta}] \leq V[\hat{\beta}]$ を示せ。さらに $x_i = 1, 2, 3, 4$ のとき、相対効率 $V[\tilde{\beta}]/V[\hat{\beta}]$ を小数第 3 位まで求めよ。

  [4] $n = 200$ の回帰で、ブロイシュ・ペイガン検定の補助回帰（最小二乗残差の 2 乗 $\hat{u}_i^2$ を定数項と説明変数 1 個に回帰）の決定係数が $R^2 = 0.045$ であった。LM 統計量 $nR^2$ を求め、有意水準 5% で均一分散の仮説を検定せよ。自由度 1 のカイ二乗分布の上側 5% 点は $3.841$ とする。
modelAnswer: |
  **[1]** $S_{xx} = \sum(x_i - \bar{x})^2$ とすると

  $$\hat{\beta}_1 = \beta_1 + \frac{\sum_{i}(x_i - \bar{x})u_i}{S_{xx}}$$

  $E[u_i \mid x] = 0$ より $E[\hat{\beta}_1 \mid x] = \beta_1$（不偏性に分散の均一性は不要）。$u_i$ は独立なので

  $$V[\hat{\beta}_1 \mid x] = \frac{\sum_{i}(x_i - \bar{x})^2\sigma_i^2}{S_{xx}^2}$$

  これが $\sigma^2/S_{xx}$ に一致するのは $\sigma_i^2 = \sigma^2$（均一分散）の場合であり、一般には異なる。例えば $x$ の外れた値ほど分散が大きければ、通常の公式は真の分散を過小評価する。ホワイトの推定量は $\sigma_i^2$ を残差の 2 乗で置き換えた

  $$\hat{V}_{HC}[\hat{\beta}_1] = \frac{\sum_{i}(x_i - \bar{x})^2\hat{u}_i^2}{S_{xx}^2}$$

  で、分散の形を特定しなくても一致性をもつ（小標本では $n/(n - 2)$ を掛ける補正などが用いられる）。

  **[2]** 両辺を $x_i$ で割ると

  $$\frac{y_i}{x_i} = \beta + \frac{u_i}{x_i},\qquad V\left[\frac{u_i}{x_i}\,\middle|\,x\right] = \sigma^2$$

  となり、変換後の誤差は独立・等分散・平均 0 でガウス・マルコフの仮定を満たす。変換後のモデルは「定数 $\beta$ のまわりのばらつき」なので最小二乗推定量は標本平均で

  $$\tilde{\beta} = \frac{1}{n}\sum_{i=1}^{n}\frac{y_i}{x_i}$$

  これは $\sum(y_i - \beta x_i)^2/x_i^2$（重み $1/x_i^2$ の加重残差平方和）を最小にする加重最小二乗推定量である。ガウス・マルコフの定理により変換後のモデルで最良線形不偏であり、$y_i$ の線形推定量の集合は変換の前後で同じなので、元のモデルでも最良線形不偏推定量である。

  **[3]**

  $$V[\hat{\beta}] = \frac{\sum x_i^2\cdot\sigma^2x_i^2}{\left(\sum x_i^2\right)^2} = \frac{\sigma^2\sum x_i^4}{\left(\sum x_i^2\right)^2},\qquad V[\tilde{\beta}] = \frac{1}{n^2}\sum_{i}\frac{\sigma^2x_i^2}{x_i^2} = \frac{\sigma^2}{n}$$

  コーシー・シュワルツの不等式 $\left(\sum 1 \cdot x_i^2\right)^2 \leq n\sum x_i^4$ より $V[\hat{\beta}] \geq \sigma^2/n = V[\tilde{\beta}]$。等号は $x_i^2$ がすべて等しいときに限る。

  $x_i = 1, 2, 3, 4$ では $\sum x_i^2 = 30$、$\sum x_i^4 = 354$ なので

  $$\frac{V[\tilde{\beta}]}{V[\hat{\beta}]} = \frac{\sigma^2/4}{354\sigma^2/900} = \frac{900}{1416} = 0.636$$

  **[4]** $LM = nR^2 = 200 \times 0.045 = 9.0$。帰無仮説（均一分散）のもとで漸近的に $\chi^2(1)$ に従い、$9.0 > 3.841$ なので有意水準 5% で均一分散の仮説を棄却する。分散が説明変数とともに変化していると判断され、ホワイトの頑健な標準誤差を用いるか、分散の構造をモデル化して加重最小二乗法を用いる。

不均一分散は、クロスセクションデータ（世帯・企業）で最も頻繁に現れる問題です。最小二乗推定量は不偏のままですが、通常の標準誤差が誤り、効率も最良ではなくなります。

### 解答の流れ

1. 推定誤差を $\sum(x_i - \bar{x})u_i/S_{xx}$ と書き、独立性から分散を計算する（交差項が消える）。
2. 誤差の標準偏差 $\sigma x_i$ で割れば等分散になる。
3. 2 つの分散を比べる。分母と分子の形から、コーシー・シュワルツの不等式が使える。
4. 補助回帰の $nR^2$ を自由度（補助回帰の説明変数の数）1 のカイ二乗分布と比べる。

### つまずきやすい点

- 不均一分散のもとでも最小二乗推定量は**不偏かつ一致**である。失われるのは有効性（BLUE であること）と、通常の分散公式の正しさ。
- 加重最小二乗法の重みは分散の**逆数** $1/\sigma_i^2 = 1/(\sigma^2x_i^2)$。標準偏差の逆数ではない。
- 分散の構造を誤って指定した加重最小二乗法は、最小二乗法より非効率になることもある。その場合でも頑健な標準誤差を使えば推測は妥当である。

### ポイント

- ホワイト検定は、補助回帰に説明変数の 2 乗と交差項も含め、分散の形を特定せずに不均一分散を検定する。
- 対数変換 $\log y$ で不均一分散が緩和されることも多い（分散が平均の 2 乗に比例する場合）。
