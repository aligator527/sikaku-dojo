  大きさ $N$ の有限母集団が $H$ 個の層に分かれており、第 $h$ 層の大きさを $N_h$、層内の母平均を $\bar{Y}_h$、層内の母分散（除数 $N_h - 1$）を $S_h^2$、$W_h = N_h/N$ とする。各層から互いに独立に $n_h$ 個を非復元単純無作為抽出し、層別平均 $\bar{y}_{st} = \sum_{h=1}^{H}W_h\bar{y}_h$（$\bar{y}_h$ は第 $h$ 層の標本平均）で母平均 $\bar{Y} = \sum_h W_h\bar{Y}_h$ を推定する。以下の各問に答えよ。

  [1] $\bar{y}_{st}$ が $\bar{Y}$ の不偏推定量であることを示し、その分散を求めよ。ただし、非復元単純無作為抽出の標本平均の分散が $(1 - n_h/N_h)S_h^2/n_h$ であることは用いてよい。

  [2] 以下では有限母集団修正を無視する（$n_h/N_h \approx 0$）。第 $h$ 層の 1 単位あたりの調査費用を $c_h$ とし、総費用 $\sum_h c_h n_h = C$ が一定のもとで $V[\bar{y}_{st}]$ を最小にする配分が $n_h \propto W_h S_h/\sqrt{c_h}$ であることを示し、そのときの最小分散を求めよ。

  [3] 3 つの層について、$N_h = 2000,\ 5000,\ 3000$、$S_h = 40,\ 8,\ 20$、$c_h = 4,\ 1,\ 4$、予算 $C = 960$ のとき、[2] の最適配分 $n_h$ と $V[\bar{y}_{st}]$ を求めよ。

  [4] 同じ予算で比例配分（$n_h \propto N_h$）を用いたときの $V[\bar{y}_{st}]$ を求め、[3] と比較せよ。
modelAnswer: |
  **[1]** 各層の標本平均は層内平均の不偏推定量なので

  $$E[\bar{y}_{st}] = \sum_h W_h E[\bar{y}_h] = \sum_h W_h\bar{Y}_h = \bar{Y}$$

  層ごとの抽出は独立なので共分散の項は 0 で

  $$V[\bar{y}_{st}] = \sum_{h=1}^{H}W_h^2\left(1 - \frac{n_h}{N_h}\right)\frac{S_h^2}{n_h}$$

  **[2]** 最小化する量は $V = \sum_h W_h^2S_h^2/n_h$。コーシー・シュワルツの不等式より

  $$V \cdot C = \left(\sum_h\frac{W_h^2S_h^2}{n_h}\right)\left(\sum_h c_h n_h\right) \geq \left(\sum_h\frac{W_hS_h}{\sqrt{n_h}}\cdot\sqrt{c_h n_h}\right)^2 = \left(\sum_h W_hS_h\sqrt{c_h}\right)^2$$

  右辺は配分によらない定数であり、等号は $\dfrac{W_hS_h/\sqrt{n_h}}{\sqrt{c_hn_h}}$ が $h$ によらず一定、すなわち $n_h \propto W_hS_h/\sqrt{c_h}$ のときに成り立つ。したがって最適配分は

  $$n_h = C\,\frac{W_hS_h/\sqrt{c_h}}{\sum_k W_kS_k\sqrt{c_k}},\qquad V_{\min} = \frac{\left(\sum_h W_hS_h\sqrt{c_h}\right)^2}{C}$$

  （ラグランジュの未定乗数法で $-W_h^2S_h^2/n_h^2 + \lambda c_h = 0$ を解いてもよい。）費用が全層で等しいときは、ネイマン配分 $n_h \propto N_hS_h$ になる。

  **[3]** $W_h = 0.2,\ 0.5,\ 0.3$、$W_hS_h = 8,\ 4,\ 6$、$W_hS_h/\sqrt{c_h} = 4,\ 4,\ 3$ なので $n_h = (4k, 4k, 3k)$ とおくと、費用は $4 \cdot 4k + 1 \cdot 4k + 4 \cdot 3k = 32k = 960$ より $k = 30$。

  $$n_h = 120,\ 120,\ 90$$

  $$V[\bar{y}_{st}] = \frac{(8 \times 2 + 4 \times 1 + 6 \times 2)^2}{960} = \frac{32^2}{960} = 1.067$$

  （直接計算しても $\dfrac{0.04 \times 1600}{120} + \dfrac{0.25 \times 64}{120} + \dfrac{0.09 \times 400}{90} = 0.533 + 0.133 + 0.400 = 1.067$。）

  **[4]** 比例配分 $n_h = nW_h$ の費用は $n\sum_h W_hc_h = n(0.8 + 0.5 + 1.2) = 2.5n = 960$ より $n = 384$（$n_h = 76.8,\ 192,\ 115.2$）。分散は

  $$V[\bar{y}_{st}] = \sum_h W_h^2\frac{S_h^2}{nW_h} = \frac{\sum_h W_hS_h^2}{n} = \frac{0.2 \times 1600 + 0.5 \times 64 + 0.3 \times 400}{384} = \frac{472}{384} = 1.229$$

  最適配分の分散 $1.067$ は比例配分の約 87%（$1.067/1.229 = 0.868$）である。比例配分は層内のばらつきが小さく費用の安い第 2 層に標本を多く割き、ばらつきの大きい第 1 層の標本が不足するため効率が劣る。

層別抽出の配分問題は、標本調査法で最もよく出る論点です。費用を考えた最適配分は「ばらつきが大きく、層が大きく、調査費用が安い層ほど多く抽出する」という直感的な結論を、不等式 1 本で導けます。

### 解答の流れ

1. 層別平均の期待値と分散を、層間の独立性を使って計算する。
2. 分散と費用の積にコーシー・シュワルツの不等式を当て、下限と等号条件を求める。
3. 比 $W_hS_h/\sqrt{c_h}$ を求め、費用の制約から定数倍を決める。
4. 比例配分の総標本サイズを費用制約から決め、分散を計算する。

### つまずきやすい点

- 費用の制約は標本サイズの合計ではなく $\sum c_hn_h = C$。費用を無視したネイマン配分（$n_h \propto N_hS_h$）を同じ予算で使うと、$n_h = 128,\ 64,\ 96$ で分散は $1.125$ となり、最適配分より劣る。
- 配分の比は $S_h$ に比例し、$S_h^2$ に比例するのではない。
- 実際の配分では $n_h$ を整数に丸め、$n_h \leq N_h$ を確認する（最適配分が $N_h$ を超える層は全数調査にして、残りを再配分する）。

### ポイント

- 層別抽出は層間の変動を誤差から取り除くので、比例配分でも単純無作為抽出より分散が小さくなる（$N_h$ が大きく有限母集団修正を無視できるとき、差は近似的に $\frac{1}{n}\sum W_h(\bar{Y}_h - \bar{Y})^2$）。
- 層内の分散が小さくなるように層を作ることが、層別の効果を大きくする鍵である。
