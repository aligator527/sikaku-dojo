  時系列データの回帰モデル

  $$y_t = \beta_0 + \beta_1 x_t + u_t\qquad (t = 1, \ldots, T)$$

  で、誤差項が定常な 1 次の自己回帰過程 $u_t = \rho u_{t-1} + e_t$（$|\rho| < 1$）に従うとする。$e_t$ は互いに独立に平均 0、分散 $\sigma_e^2$ の分布に従い、すべての $x_s$ と独立である。以下の各問に答えよ。

  [1] $\sigma_u^2 = V[u_t]$ と $\mathrm{Cov}(u_t, u_{t-s})$（$s \geq 1$）を求めよ。

  [2] 最小二乗推定量 $\hat{\beta}_1$ が（$x$ を所与として）不偏であることを示せ。さらに、説明変数が $\sum_{t}(x_t - \bar{x})(x_{t+k} - \bar{x}) \approx \phi^{k}\sum_{t}(x_t - \bar{x})^2$（$k \geq 1$、$|\phi| < 1$）を満たすとき、$T$ が大きければ

  $$V[\hat{\beta}_1] \approx \frac{\sigma_u^2}{\sum_{t}(x_t - \bar{x})^2}\cdot\frac{1 + \rho\phi}{1 - \rho\phi}$$

  となることを示し、通常の最小二乗法の標準誤差を用いた $t$ 検定の問題点を説明せよ。

  [3] $\rho$ が既知のとき、変換 $y_t - \rho y_{t-1}$ を用いて $(\beta_0, \beta_1)$ の最良線形不偏推定量を得る方法を説明せよ。$\rho$ が未知のときの方法も述べよ。

  [4] $T = 40$ のデータで、最小二乗残差 $\hat{u}_t$ から計算したダービン・ワトソン比は $DW = 0.84$ であった。$DW$ と残差の 1 次の自己相関係数 $r_1 = \sum_{t=2}^{T}\hat{u}_t\hat{u}_{t-1}/\sum_{t=1}^{T}\hat{u}_t^2$ の近似的な関係を導き、$r_1$ の値を推定せよ。また、有意水準 5% の下限 $d_L = 1.44$、上限 $d_U = 1.54$ を用いて、正の系列相関の有無を判定せよ。
modelAnswer: |
  **[1]** 定常性より $V[u_t] = V[u_{t-1}]$ で、$u_{t-1}$ と $e_t$ は独立なので $\sigma_u^2 = \rho^2\sigma_u^2 + \sigma_e^2$、すなわち

  $$\sigma_u^2 = \frac{\sigma_e^2}{1 - \rho^2}$$

  $u_t = \rho^{s}u_{t-s} + \sum_{j=0}^{s-1}\rho^{j}e_{t-j}$ と書け、第 2 項は $u_{t-s}$ と独立なので

  $$\mathrm{Cov}(u_t, u_{t-s}) = \rho^{s}\sigma_u^2 = \frac{\rho^{s}\sigma_e^2}{1 - \rho^2}$$

  **[2]** $S_{xx} = \sum_t(x_t - \bar{x})^2$ とすると

  $$\hat{\beta}_1 = \beta_1 + \frac{\sum_{t}(x_t - \bar{x})u_t}{S_{xx}}$$

  $E[u_t \mid x] = 0$ なので $E[\hat{\beta}_1 \mid x] = \beta_1$（系列相関があっても不偏性は保たれる）。分散は

  $$V[\hat{\beta}_1 \mid x] = \frac{1}{S_{xx}^2}\sum_{t}\sum_{s}(x_t - \bar{x})(x_s - \bar{x})\rho^{|t-s|}\sigma_u^2 = \frac{\sigma_u^2}{S_{xx}^2}\left\{S_{xx} + 2\sum_{k\geq 1}\rho^{k}\sum_{t}(x_t - \bar{x})(x_{t+k} - \bar{x})\right\}$$

  仮定の近似を代入すると

  $$V[\hat{\beta}_1] \approx \frac{\sigma_u^2}{S_{xx}}\left\{1 + 2\sum_{k=1}^{\infty}(\rho\phi)^{k}\right\} = \frac{\sigma_u^2}{S_{xx}}\left(1 + \frac{2\rho\phi}{1 - \rho\phi}\right) = \frac{\sigma_u^2}{S_{xx}}\cdot\frac{1 + \rho\phi}{1 - \rho\phi}$$

  通常の公式 $\sigma_u^2/S_{xx}$ は係数 $(1 + \rho\phi)/(1 - \rho\phi)$ を無視している。経済の時系列では $\rho > 0$、$\phi > 0$ が多く、例えば $\rho = \phi = 0.7$ なら係数は $1.49/0.51 = 2.92$ で、真の標準誤差は通常の標準誤差の約 $\sqrt{2.92} = 1.71$ 倍になる。通常の標準誤差は過小となり、$t$ 値が過大になって、実際には効果がないのに有意と判定しやすくなる（見せかけの有意性）。

  **[3]** $t \geq 2$ について $y_t - \rho y_{t-1}$ を計算すると

  $$y_t - \rho y_{t-1} = \beta_0(1 - \rho) + \beta_1(x_t - \rho x_{t-1}) + e_t$$

  となり、誤差 $e_t$ は独立・等分散である。$t = 1$ については $\sqrt{1 - \rho^2}\,y_1 = \beta_0\sqrt{1 - \rho^2} + \beta_1\sqrt{1 - \rho^2}\,x_1 + \sqrt{1 - \rho^2}\,u_1$ とすれば誤差の分散が $\sigma_e^2$ になる（プレイス・ウィンステン変換）。変換後のモデルはガウス・マルコフの仮定を満たすので、これに最小二乗法を適用した推定量（一般化最小二乗推定量）が最良線形不偏推定量である。

  $\rho$ が未知の場合は、まず最小二乗残差から $\hat{\rho} = \sum\hat{u}_t\hat{u}_{t-1}/\sum\hat{u}_{t-1}^2$ を推定して変換し、得られた係数から残差を再計算して $\hat{\rho}$ を更新することを収束するまで繰り返す（コクラン・オーカット法、実行可能な GLS）。あるいは最小二乗推定量をそのまま使い、標準誤差だけをニューウィー・ウエストの HAC 推定量に置き換える。

  **[4]**

  $$DW = \frac{\sum_{t=2}^{T}(\hat{u}_t - \hat{u}_{t-1})^2}{\sum_{t=1}^{T}\hat{u}_t^2} = \frac{\sum_{t=2}^{T}\hat{u}_t^2 + \sum_{t=2}^{T}\hat{u}_{t-1}^2 - 2\sum_{t=2}^{T}\hat{u}_t\hat{u}_{t-1}}{\sum_{t=1}^{T}\hat{u}_t^2}$$

  $T$ が大きければ分子の最初の 2 項はいずれも $\sum_{t=1}^{T}\hat{u}_t^2$ にほぼ等しいので、$DW \approx 2(1 - r_1)$。よって

  $$r_1 \approx 1 - \frac{DW}{2} = 1 - \frac{0.84}{2} = 0.58$$

  $DW = 0.84 < d_L = 1.44$ なので、有意水準 5% で「系列相関なし（$\rho = 0$）」を棄却し、正の系列相関があると判定する。（$d_L \leq DW \leq d_U$ なら判定保留、$DW > d_U$ なら棄却しない。）

誤差項の系列相関は、時系列データを使う計量経済分析で最初に確認すべき問題です。最小二乗推定量の不偏性は保たれますが、分散の公式が成り立たなくなり、検定の結論が誤る危険があります。

### 解答の流れ

1. AR(1) 過程の定常分散と自己共分散を求める（$u_t$ を過去の $e$ で展開する）。
2. 推定誤差を $\sum(x_t - \bar{x})u_t/S_{xx}$ と書き、分散を二重和で計算する。$x$ の自己相関と $u$ の自己相関の積が効いてくる。
3. 変換で誤差を「ホワイトノイズ」にすれば、ガウス・マルコフの定理が使える。
4. DW 比の分子を展開し、$\sum\hat{u}_t^2$ と $\sum\hat{u}_t\hat{u}_{t-1}$ で表す。

### つまずきやすい点

- 系列相関で失われるのは不偏性ではなく、有効性と分散の公式の正しさである。ただし、説明変数にラグ付きの目的変数 $y_{t-1}$ を含む場合は、$y_{t-1}$ が $u_{t-1}$ を通じて $u_t$ と相関するため、最小二乗推定量は一致性も失う。
- DW 検定はラグ付き目的変数を含むモデルには使えない（2 に偏る）。その場合はダービンの $h$ 検定やブロイシュ・ゴドフリー検定を用いる。
- $x_t$ に自己相関がない（$\phi = 0$）なら、$u_t$ に系列相関があっても通常の分散公式は漸近的に正しい。

### ポイント

- $DW$ は 0〜4 の値をとり、2 付近なら系列相関なし、0 に近いほど正、4 に近いほど負の系列相関を示す。
- 判定保留域があるのは、$DW$ の分布が説明変数の値に依存するためで、$d_L$ と $d_U$ はその下限と上限にあたる。
