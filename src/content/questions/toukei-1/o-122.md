$E[X] = 40$、$V[X] = 100 \times 0.4 \times 0.6 = 24$ です。$X$ は整数値なので、$P(X \leq 35) = P(X < 35.5)$ と考えて 35.5 で標準化すると $z = (35.5 - 40)/4.899 = -0.92$ となり、$\Phi(-0.92) = 1 - 0.8212 = 0.1788 \approx 0.179$ です。

### 計算

$$z = \frac{35.5 - 40}{\sqrt{24}} = \frac{-4.5}{4.899} = -0.9186 \approx -0.92$$

$$P(X \leq 35) \approx \Phi(-0.92) = 1 - \Phi(0.92) = 1 - 0.8212 = 0.1788$$

### ポイント

- 正確な値は $0.1795$ で、連続修正をした近似はよく合っている。連続修正をしないと $z = -5/4.899 = -1.02$、$\Phi(-1.02) \approx 0.154$ となり、誤差が大きい。
- 連続修正の向き：$P(X \leq k)$ は $k + 0.5$、$P(X < k) = P(X \leq k - 1)$ は $k - 0.5$、$P(X \geq k)$ は $k - 0.5$ で標準化する。各整数 $j$ の確率を区間 $[j - 0.5,\ j + 0.5]$ 上の面積で近似する、と考えると覚えやすい。
- 二項分布の正規近似は $np$ と $n(1-p)$ がともに十分大きい（目安として 5〜10 以上）ときに使う。$p$ が 0 や 1 に近いと分布が歪み、近似が悪くなる（その場合はポアソン近似を検討する）。
