modelAnswer: |
  **[1]** 同時確率関数は

  $$\prod_{i=1}^{n}\frac{e^{-\lambda}\lambda^{x_i}}{x_i!} = \underbrace{e^{-n\lambda}\lambda^{t}}_{g(t;\,\lambda)}\cdot\underbrace{\prod_i\frac{1}{x_i!}}_{h(\boldsymbol{x})}\qquad (t = \textstyle\sum x_i)$$

  なので、分解定理より $T$ は十分統計量である。$T \sim Po(n\lambda)$ で、$E_\lambda[g(T)] = 0$ がすべての $\lambda > 0$ で成り立つとすると

  $$e^{-n\lambda}\sum_{t=0}^{\infty}g(t)\frac{(n\lambda)^t}{t!} = 0 \iff \sum_{t=0}^{\infty}\frac{g(t)n^t}{t!}\lambda^t = 0\quad (\lambda > 0)$$

  べき級数が区間上で恒等的に 0 なら係数はすべて 0 なので $g(t) = 0\ (t = 0, 1, \ldots)$。よって $T$ は完備である。

  **[2]** $X_1$ と $\sum_{i \geq 2}X_i \sim Po((n-1)\lambda)$ は独立なので、$T = t$ のもとで

  $$P(X_1 = k \mid T = t) = \frac{\dfrac{e^{-\lambda}\lambda^k}{k!}\cdot\dfrac{e^{-(n-1)\lambda}\{(n-1)\lambda\}^{t-k}}{(t-k)!}}{\dfrac{e^{-n\lambda}(n\lambda)^t}{t!}} = \binom{t}{k}\left(\frac{1}{n}\right)^k\left(1 - \frac{1}{n}\right)^{t-k}$$

  すなわち $X_1 \mid T = t \sim \mathrm{Bin}(t,\ 1/n)$。よって

  $$E[W \mid T] = P(X_1 = 0 \mid T) = \left(1 - \frac{1}{n}\right)^T$$

  これは $T$ の関数で不偏（ラオ・ブラックウェルの定理より $E[E[W \mid T]] = E[W] = e^{-\lambda}$）であり、$T$ は完備十分統計量なので、レーマン・シェフェの定理より $\hat{\tau} = (1 - 1/n)^T$ が一様最小分散不偏推定量である。

  **[3]** $T \sim Po(n\lambda)$ の確率母関数 $E[s^T] = e^{n\lambda(s-1)}$ を $s = (1 - 1/n)^2$ で用いると

  $$E[\hat{\tau}^2] = \exp\left\{n\lambda\left(1 - \frac{2}{n} + \frac{1}{n^2} - 1\right)\right\} = e^{-2\lambda + \lambda/n}$$

  $$V[\hat{\tau}] = e^{-2\lambda + \lambda/n} - e^{-2\lambda} = e^{-2\lambda}\left(e^{\lambda/n} - 1\right)$$

  一方、$I_n(\lambda) = n/\lambda$、$\tau'(\lambda) = -e^{-\lambda}$ より、クラーメル・ラオの下限は

  $$\frac{\tau'(\lambda)^2}{I_n(\lambda)} = \frac{\lambda e^{-2\lambda}}{n}$$

  $e^x - 1 > x\ (x > 0)$ より $V[\hat{\tau}] > \lambda e^{-2\lambda}/n$ で、一様最小分散不偏推定量であっても下限は達成されない（$n \to \infty$ では比が 1 に近づく）。

  **[4]** $\hat{\tau} = (1 - 1/20)^{30} = 0.95^{30} = 0.2146$。最尤推定値は $\bar{x} = 1.5$ より $e^{-1.5} = 0.2231$。

「不偏推定量を完備十分統計量で条件付ける」ことで一様最小分散不偏推定量を作る、ラオ・ブラックウェル化とレーマン・シェフェの定理の典型問題です。あわせて、一様最小分散不偏推定量がクラーメル・ラオの下限を達成するとは限らないことを確認します。

### 解答の流れ

1. ポアソン分布は指数型分布族で、$T = \sum X_i$ が完備十分統計量。
2. 粗い不偏推定量 $\mathbf{1}\{X_1 = 0\}$ を $T$ で条件付ける。和を与えたポアソン変数の条件付き分布は二項分布。
3. 分散は $T$ の確率母関数で計算する。$(1 - 1/n)^T$ は $s^T$ の形なので計算しやすい。

### つまずきやすい点

- 最尤推定量 $e^{-\bar{X}}$ は不偏ではない。$E[e^{-\bar{X}}] = \exp\{n\lambda(e^{-1/n} - 1)\} \neq e^{-\lambda}$。
- 標本の 0 の割合 $\frac{1}{n}\sum\mathbf{1}\{X_i = 0\}$ も不偏だが、$T$ の関数ではないので一様最小分散不偏推定量ではない。
- クラーメル・ラオの下限は、$\tau(\lambda)$ を推定するときは $\tau'(\lambda)^2/I_n(\lambda)$ になる。$1/I_n(\lambda) = \lambda/n$ のままにしない。

### ポイント

- 下限が達成されるのは、推定したい関数が指数型分布族の十分統計量の期待値の 1 次関数（ここでは $\lambda$ の 1 次式）である場合に限られる。$e^{-\lambda}$ はそうでないので達成されない。
- 同様の手順で、たとえば $\lambda^2$ の一様最小分散不偏推定量は $T(T-1)/n^2$ と求められる（$E[T(T-1)] = (n\lambda)^2$）。
