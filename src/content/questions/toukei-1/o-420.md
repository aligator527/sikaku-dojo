stem: |
  ある電子部品の寿命 $T$ が、分布関数

  $$F(t) = 1 - \exp\left\{-\left(\frac{t}{\eta}\right)^{m}\right\}\qquad (t \geq 0)$$

  をもつワイブル分布に従うとする（$m > 0$ は形状母数、$\eta > 0$ は尺度母数）。以下の各問に答えよ。

  [1] ハザード関数（故障率関数）$h(t)$ を求め、$m < 1$、$m = 1$、$m > 1$ のそれぞれについて故障率の時間変化と、対応する故障の型を述べよ。

  [2] 平均寿命（MTTF）$E[T]$ をガンマ関数を用いて表せ。

  [3] 故障時間データからワイブル確率紙（ワイブルプロット）で $m$ と $\eta$ を推定する原理を、$F(t)$ の変換を用いて説明せよ。

  [4] $m = 2$ が既知であるとして、5 個の部品を 800 時間まで試験したところ、300、500、700 時間に 1 個ずつ故障し、2 個は 800 時間の時点で故障していなかった（定時打切り）。$\eta$ の最尤推定量を導き、その推定値と MTTF の推定値を求めよ。必要なら $\Gamma(1.5) = \sqrt{\pi}/2 = 0.8862$ を用いよ。
modelAnswer: |
  **[1]** 密度は $f(t) = F'(t) = \dfrac{m}{\eta}\left(\dfrac{t}{\eta}\right)^{m-1}\exp\left\{-\left(\dfrac{t}{\eta}\right)^{m}\right\}$、信頼度は $R(t) = 1 - F(t)$ なので

  $$h(t) = \frac{f(t)}{R(t)} = \frac{m}{\eta}\left(\frac{t}{\eta}\right)^{m-1}$$

  - $m < 1$：$h(t)$ は単調減少（DFR）。初期故障型（製造上の欠陥品が早く故障し、残ったものは故障しにくい）。
  - $m = 1$：$h(t) = 1/\eta$ で一定（CFR）。指数分布であり、偶発故障型。
  - $m > 1$：$h(t)$ は単調増加（IFR）。摩耗故障型（劣化が進むほど故障しやすい）。

  これらはバスタブ曲線の 3 つの期間に対応する。

  **[2]** $u = (t/\eta)^{m}$ と置換すると $t = \eta u^{1/m}$、$f(t)\,dt = e^{-u}\,du$ なので

  $$E[T] = \int_0^{\infty}\eta u^{1/m}e^{-u}\,du = \eta\,\Gamma\left(1 + \frac{1}{m}\right)$$

  **[3]** $1 - F(t) = \exp\{-(t/\eta)^{m}\}$ の対数を 2 回とると

  $$\log\log\frac{1}{1 - F(t)} = m\log t - m\log\eta$$

  となり、$x = \log t$、$y = \log\log\{1/(1 - F)\}$ は直線関係にある。故障時間を小さい順に並べ、各時刻の $F$ をメディアンランク $(i - 0.3)/(n + 0.4)$ などで推定して $(x, y)$ を打点し、当てはめた直線の傾きから $\hat{m}$、$y = 0$（$F = 1 - e^{-1} \approx 0.632$）となる $t$ から $\hat{\eta}$ を読み取る。点が直線に乗らなければワイブル分布の当てはまりが悪いと判断できる。

  **[4]** 故障した部品は密度 $f(t_i)$、打ち切られた部品は信頼度 $R(c_j)$ で尤度に寄与する。$m = 2$ のとき、故障数を $r$ として

  $$L(\eta) = \prod_{i=1}^{r}\frac{2t_i}{\eta^{2}}\exp\left\{-\left(\frac{t_i}{\eta}\right)^{2}\right\}\prod_{j}\exp\left\{-\left(\frac{c_j}{\eta}\right)^{2}\right\}$$

  $$\log L = \text{const} - 2r\log\eta - \frac{1}{\eta^{2}}\sum_{\text{全数}}t_k^{2}$$

  （$\sum_{\text{全数}}$ は故障時間と打切り時間のすべてについての和。）$\eta$ で微分して 0 とおくと

  $$-\frac{2r}{\eta} + \frac{2}{\eta^{3}}\sum t_k^{2} = 0\ \Rightarrow\ \hat{\eta} = \left(\frac{\sum t_k^{2}}{r}\right)^{1/2}$$

  データでは $\sum t_k^{2} = 300^2 + 500^2 + 700^2 + 2 \times 800^2 = 2110000$、$r = 3$ なので

  $$\hat{\eta} = \sqrt{\frac{2110000}{3}} = \sqrt{703333} = 838.6\ \text{時間}$$

  MTTF の推定値は最尤推定量の不変性より

  $$\hat{\eta}\,\Gamma(1.5) = 838.6 \times 0.8862 = 743.2\ \text{時間}$$

ワイブル分布は信頼性工学の中心的な寿命分布です。形状母数 $m$ が故障率の増減を決め、指数分布（$m = 1$）を特別な場合として含みます。打切りのある寿命試験データの最尤推定は、理工学分野で繰り返し出題されます。

### 解答の流れ

1. ハザード関数は $f(t)/R(t)$。ワイブル分布では $R(t)$ が簡単な形なので、$h(t) = -\dfrac{d}{dt}\log R(t)$ から求めてもよい。
2. $u = (t/\eta)^{m}$ の置換でガンマ関数に帰着させる。
3. 分布関数を「二重対数」で変換すると $\log t$ の 1 次式になる。
4. 打切りデータは「その時点まで故障しなかった」という情報として $R(c)$ で尤度に入れる。

### つまずきやすい点

- 打ち切られた 2 個を捨てて故障した 3 個だけで推定すると、$\hat{\eta} = \sqrt{830000/3} = 526$ 時間となり、寿命を大きく過小評価する。
- 尤度方程式の分母 $r$ は**故障数**（3）であり、試験個数（5）ではない。一方、分子の和は打切りを含む**全数**についてとる。
- $m$ が既知なら $T^{m}$ は平均 $\eta^{m}$ の指数分布に従うので、本問は「$T^2$ の総試験時間 / 故障数」という指数分布の推定と同じ形になる。

### ポイント

- 信頼度 $R(t)$ が $p$ となる時間（$B_{100(1-p)}$ ライフ）は $t = \eta(-\log p)^{1/m}$。
- 平均寿命は $m$ によって $\eta$ との比が変わり、$m = 1$ で $\eta$、$m = 2$ で $0.886\eta$、$m$ が大きいほど $\eta$ に近づく。
