合計得点 $\sum_jx_j = (\sum_j\lambda_j)f + \sum_je_j$ のうち、共通因子による部分の分散は $(\sum\lambda_j)^2 = 2.6^2 = 6.76$、独自因子による部分の分散は $\sum\psi_j = 4 - 1.74 = 2.26$ です。よって $\omega = 6.76/(6.76 + 2.26) = 6.76/9.02 \approx 0.749$ です。

### 計算

$$\sum_j\lambda_j = 0.7 + 0.6 + 0.8 + 0.5 = 2.6,\qquad \left(\sum_j\lambda_j\right)^2 = 6.76$$

$$\sum_j\psi_j = (1 - 0.49) + (1 - 0.36) + (1 - 0.64) + (1 - 0.25) = 0.51 + 0.64 + 0.36 + 0.75 = 2.26$$

$$\omega = \frac{6.76}{6.76 + 2.26} = \frac{6.76}{9.02} = 0.7494$$

### α 係数との比較

モデルが再現する相関行列（非対角成分 $\lambda_i\lambda_j$）からクロンバックの $\alpha$ を計算すると、相関の和（上三角）は $(6.76 - 1.74)/2 = 2.51$、合計得点の分散は $4 + 2 \times 2.51 = 9.02$ なので

$$\alpha = \frac{4}{3}\left(1 - \frac{4}{9.02}\right) = 0.742$$

となり、$\omega$ より小さくなります。負荷量が項目ごとに異なる（タウ等価でない）とき、$\alpha$ は信頼性を過小評価します。負荷量がすべて等しければ両者は一致します。

### ポイント

- $\omega$ の分母 $(\sum\lambda_j)^2 + \sum\psi_j$ は、モデルのもとでの合計得点の分散そのものである。$\omega$ は「合計得点の分散のうち共通因子が説明する割合」で、古典的テスト理論の信頼性係数 $\sigma_T^2/\sigma_X^2$ にあたる。
- よくある誤り：分子を負荷量の 2 乗和 $\sum\lambda_j^2 = 1.74$ として $1.74/(1.74 + 2.26) = 0.435$ とする。これは項目の平均的な共通性であり、合計得点の信頼性ではない。
