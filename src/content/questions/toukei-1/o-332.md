$nV[\bar{y}]$ は自己共分散の総和 $\sum_{h=-\infty}^{\infty}\gamma(h) = 2\pi f(0)$（長期分散）に収束します。ARMA(1, 1) では長期分散は $\sigma^2(1 + \theta)^2/(1 - \phi)^2 = 4\sigma^2$、分散は $\gamma(0) = 1.25\sigma^2$ なので、$n_{\mathrm{eff}} = n\gamma(0)/(4\sigma^2) = 200 \times 1.25/4 = 62.5$ です。

### 計算

$\phi = 0.6,\ \theta = -0.2$ とします。

**分散**：ARMA(1, 1) の分散の公式より

$$\gamma(0) = \frac{1 + 2\phi\theta + \theta^2}{1 - \phi^2}\sigma^2 = \frac{1 - 0.24 + 0.04}{1 - 0.36}\sigma^2 = \frac{0.80}{0.64}\sigma^2 = 1.25\sigma^2$$

**標本平均の分散**：

$$nV[\bar{y}] = \sum_{|h| < n}\left(1 - \frac{|h|}{n}\right)\gamma(h) \ \longrightarrow\ \sum_{h=-\infty}^{\infty}\gamma(h) = 2\pi f(0)$$

スペクトル密度 $f(\lambda) = \dfrac{\sigma^2}{2\pi}\dfrac{|1 + \theta e^{-i\lambda}|^2}{|1 - \phi e^{-i\lambda}|^2}$ の $\lambda = 0$ での値から

$$\sum_h\gamma(h) = \sigma^2\frac{(1 + \theta)^2}{(1 - \phi)^2} = \sigma^2\frac{0.8^2}{0.4^2} = 4\sigma^2$$

（MA($\infty$) 表現 $y_t - \mu = \sum_j\psi_j\varepsilon_{t-j}$ で $\sum_j\psi_j = \dfrac{1 + \theta}{1 - \phi}$ となることからも得られます。）

**有効標本サイズ**：

$$n_{\mathrm{eff}} = \frac{\gamma(0)}{V[\bar{y}]} \approx \frac{n\gamma(0)}{\sum_h\gamma(h)} = \frac{200 \times 1.25\sigma^2}{4\sigma^2} = 62.5$$

### ポイント

- 正の自己相関があると、200 個の観測値の平均は、独立な約 63 個の平均と同じ精度しかもたない。$\bar{y}$ の標準誤差を $\sqrt{\hat{\gamma}(0)/n}$ で計算すると、精度を過大評価する（この例では標準誤差を $\sqrt{200/62.5} \approx 1.8$ 分の 1 に見誤る）。
- よくある誤り：長期分散を $\sigma^2$ や $\gamma(0)$ とする、または AR 部分だけを見て $\sigma^2/(1 - \phi)^2 = 6.25\sigma^2$ とする。MA 係数が負なので、MA 部分は長期分散を $(1 + \theta)^2 = 0.64$ 倍に減らしている。
- 自己相関のある時系列の平均や回帰係数の標準誤差には、長期分散の推定（ニューイ・ウェスト推定量など）が使われる。
