  $a$ 種類の処理を比較するため、$b$ 個のブロック（実験の場所・日・ロットなど）のそれぞれで、$a$ 個の実験単位に処理を無作為に 1 つずつ割り付けた（乱塊法）。観測値 $y_{ij}$（処理 $i$、ブロック $j$）のモデルを

  $$y_{ij} = \mu + \tau_i + \beta_j + \varepsilon_{ij},\qquad \sum_i\tau_i = \sum_j\beta_j = 0,\qquad \varepsilon_{ij} \sim N(0, \sigma^2)\ \text{（互いに独立）}$$

  とする。以下の各問に答えよ。

  [1] 総平方和を処理平方和 $S_A$、ブロック平方和 $S_B$、残差平方和 $S_E$ に分解し、それぞれの自由度を答えよ。

  [3] 同じ $ab$ 個の実験単位を、ブロックを考えずに完全無作為化法で実験したとすれば、誤差分散は

  **[1]** $\bar{y}_{i\cdot},\ \bar{y}_{\cdot j},\ \bar{y}_{\cdot\cdot}$ を処理平均・ブロック平均・総平均として

  $$y_{ij} - \bar{y}_{\cdot\cdot} = (\bar{y}_{i\cdot} - \bar{y}_{\cdot\cdot}) + (\bar{y}_{\cdot j} - \bar{y}_{\cdot\cdot}) + (y_{ij} - \bar{y}_{i\cdot} - \bar{y}_{\cdot j} + \bar{y}_{\cdot\cdot})$$

  の 2 乗和をとると、交差項はすべて 0 になり

  $$S_T = S_A + S_B + S_E,\quad S_A = b\sum_i(\bar{y}_{i\cdot} - \bar{y}_{\cdot\cdot})^2,\quad S_B = a\sum_j(\bar{y}_{\cdot j} - \bar{y}_{\cdot\cdot})^2$$

  自由度は $S_A$ が $a - 1$、$S_B$ が $b - 1$、$S_E$ が $(a - 1)(b - 1)$ で、和は $ab - 1$。

  **[2]** $H_0: \tau_1 = \cdots = \tau_a = 0$ のもとで $V_A = S_A/(a - 1)$ と $V_E = S_E/\{(a - 1)(b - 1)\}$ はともに $\sigma^2$ を期待値とし、独立で、$F = V_A/V_E \sim F(a - 1,\ (a - 1)(b - 1))$。$H_0$ が偽なら $E[V_A] > \sigma^2$ なので、$F > F_{\alpha}(a - 1, (a - 1)(b - 1))$ のとき棄却する。ブロック間の変動 $\beta_j$ は $S_B$ に分離され、$V_E$ にも $V_A$ にも入らない。

  交互作用がないとは、処理の効果の差 $\tau_i - \tau_{i'}$ がどのブロックでも同じ（効果が加法的）ということである。各ブロック・処理の組合せで観測が 1 回しかないので、交互作用があればそれは $S_E$ に含まれ、$V_E$ の期待値が $\sigma^2$ より大きくなる。その結果 $F$ 比は小さくなり、検定は保守的（検出力が低い）になる。

  **[3]** 完全無作為化法の誤差には、ブロック間の変動も含まれる。もし処理効果がなかったとすれば、$ab$ 個の観測値の全変動の平均平方が、完全無作為化法の誤差分散の推定値となる。乱塊法の分散分析で処理の平方和を「処理効果がないときの値」すなわち自由度 $a - 1$ の誤差 $(a - 1)V_E$ に置き換えると、全平方和は

  $$(b - 1)V_B + (a - 1)V_E + (a - 1)(b - 1)V_E = (b - 1)V_B + b(a - 1)V_E$$

  となり、これを自由度 $ab - 1$ で割ったものが $\hat{\sigma}^2_{CR}$ である。

  **[4]** $F = 18/5 = 3.60 > F_{0.05}(3, 12) = 3.490$ なので、有意水準 5% で処理効果は有意である。

  $$\hat{\sigma}^2_{CR} = \frac{4 \times 30 + 5 \times 3 \times 5}{19} = \frac{195}{19} = 10.26,\qquad \frac{\hat{\sigma}^2_{CR}}{V_E} = \frac{10.26}{5} = 2.05$$

  ブロックを設けたことで誤差分散が約半分になり、完全無作為化法なら約 2 倍の繰り返しが必要だった精度を達成している。

乱塊法（ランダム化ブロック計画）は、実験単位のばらつきの原因（場所・日・ロットなど）をブロックとしてまとめ、その変動を誤差から取り除く計画です。フィッシャーの 3 原則（反復・無作為化・局所管理）のうち、局所管理を実現する最も基本的な方法です。

### 解答の流れ

1. 偏差を処理・ブロック・残差の 3 つに分けて 2 乗和をとる。
2. 期待平均平方を比べて $F$ 比を作る。繰り返しがないので、交互作用は誤差と分離できない。
3. 処理効果がない「均一性試験」を想定して、完全無作為化法の誤差分散を推定する。
4. 数値を代入して検定し、相対効率を求める。

### つまずきやすい点

- 残差の自由度を $ab - a = a(b - 1)$（完全無作為化法の誤差の自由度）とする誤り。ブロックの自由度 $b - 1$ を差し引いた $(a - 1)(b - 1)$ が正しい値です。
- 相対効率の式で、$V_B$ と $V_E$ の重みを自由度ではなく単純平均で合わせてしまう誤り。
- ブロック内での処理の割り付けを無作為化しないと、ブロック内の系統的な違い（位置の効果など）が処理効果と交絡します。

### ポイント

- 誤差の自由度の違いを考慮して、相対効率に $\dfrac{(f_1 + 1)(f_2 + 3)}{(f_2 + 1)(f_1 + 3)}$（$f_1 = (a - 1)(b - 1)$、$f_2 = a(b - 1)$）を掛ける補正もあります。ここでは $f_1 = 12,\ f_2 = 16$ で、補正後は約 $1.99$ です。
- ブロック因子は検定の対象ではありません。$V_B$ が $V_E$ より十分大きいことは、ブロックを設けた効果があったことを示しますが、$V_B/V_E$ の $F$ 検定は通常行いません。
