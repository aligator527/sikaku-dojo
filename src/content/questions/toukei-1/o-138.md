大数の弱法則は $E[|X_1|] < \infty$ だけで成り立ち（ヒンチンの定理）、通常の中心極限定理は $E[X_1^2] < \infty$ を必要とします。自由度 $\nu$ の $t$ 分布は裾が $|x|^{-(\nu+1)}$ の速さで減衰するので、$k < \nu$ 次のモーメントだけが有限です。自由度 2 では平均は存在するが分散は無限大なので、これが条件に合います。

### 各選択肢の検討

- 標準コーシー分布：$E[|X|] = \infty$ で平均が存在せず、大数の法則も成り立たない（$\bar{X}_n$ は $n$ によらず標準コーシー分布に従う）。
- 自由度 2 の $t$ 分布：正しい。密度は $\propto (1 + x^2/2)^{-3/2}$ で裾が $|x|^{-3}$ なので、$\int|x|\cdot|x|^{-3}dx < \infty$、$\int x^2\cdot|x|^{-3}dx = \infty$。
- 自由度 3 の $t$ 分布：分散 $\nu/(\nu - 2) = 3$ が有限なので、大数の法則も中心極限定理も成り立つ。
- 平均 1 の指数分布：すべての次数のモーメントが有限で、両方とも成り立つ。
- パレート分布 $3x^{-4}$：$E[X] = \int_1^\infty 3x^{-3}dx = 3/2$、$E[X^2] = \int_1^\infty 3x^{-2}dx = 3$ で分散 $3/4$ は有限。両方とも成り立つ（分散が無限大になるのは $f(x) = \alpha x^{-\alpha-1}$ で $\alpha \leq 2$ のとき）。

### ポイント

- 自由度 2 の $t$ 分布では、$\sqrt{n}(\bar{X}_n - \mu)$ は正規分布に収束せず、$\sqrt{n\log n}$ 程度の正規化が必要になる（このように正規化すれば正規分布に収束する）。裾がさらに重く $P(|X| > x)$ が $x^{-\alpha}\ (0 < \alpha < 2)$ の速さで減衰する場合は、極限分布は正規分布ではない安定分布になる。
- 標本平均の性質を議論するときは、まず「平均は存在するか」「分散は有限か」を裾の減衰の速さから確認する。$\int^\infty x^k\cdot x^{-a}dx$ が収束するのは $k - a < -1$ のときである。
