stem: |
  ある意識調査の 3 つの 2 値項目（賛成 $= 1$、反対 $= 0$）への反応 $\boldsymbol{U} = (U_1, U_2, U_3)$ を、2 つの潜在クラスをもつ潜在クラスモデルで分析する。回答者はクラス 1（確率 $\pi_1$）またはクラス 2（確率 $\pi_2 = 1 - \pi_1$）に属し、クラス $c$ の中では 3 項目への反応は互いに独立（局所独立）で、$P(U_j = 1 \mid c) = p_{cj}$ とする。推定の結果

  $$\pi_1 = 0.6,\qquad (p_{11}, p_{12}, p_{13}) = (0.9,\ 0.8,\ 0.7),\qquad (p_{21}, p_{22}, p_{23}) = (0.2,\ 0.3,\ 0.1)$$

  を得た。以下の各問に答えよ。

  [1] 反応パターン $\boldsymbol{u} = (u_1, u_2, u_3)$ の確率 $P(\boldsymbol{U} = \boldsymbol{u})$ を母数で表し、$P(\boldsymbol{U} = (1, 1, 1))$ と $P(\boldsymbol{U} = (0, 0, 0))$ を求めよ。

  [2] 反応パターン $(1, 1, 0)$ の回答者がクラス 1 に属する事後確率を求め、事後確率が最大のクラスに割り当てる規則でどちらのクラスに分類されるか答えよ。

  [3] $U_1$ と $U_2$ の共分散が $\pi_1\pi_2(p_{11} - p_{21})(p_{12} - p_{22})$ となることを示し、その値と相関係数を求めよ。局所独立であるのに項目間に相関が生じる理由を述べよ。必要なら $\sqrt{0.056544} = 0.2378$ を用いよ。

  [4] $J$ 個の 2 値項目に $C$ クラスの潜在クラスモデルを当てはめるとき、反応パターンの度数にもとづく適合度検定の自由度を $J$ と $C$ で表せ。$J = 3,\ C = 2$ と $J = 4,\ C = 2$ の場合の値を求め、その意味を述べよ。
modelAnswer: |
  **[1]** クラスで条件付けると局所独立より各項目の確率の積になるので

  $$P(\boldsymbol{U} = \boldsymbol{u}) = \sum_{c=1}^{2}\pi_c\prod_{j=1}^{3}p_{cj}^{u_j}(1 - p_{cj})^{1 - u_j}$$

  $$P(1, 1, 1) = 0.6 \times 0.9 \times 0.8 \times 0.7 + 0.4 \times 0.2 \times 0.3 \times 0.1 = 0.3024 + 0.0024 = 0.3048$$

  $$P(0, 0, 0) = 0.6 \times 0.1 \times 0.2 \times 0.3 + 0.4 \times 0.8 \times 0.7 \times 0.9 = 0.0036 + 0.2016 = 0.2052$$

  **[2]** 各クラスでのパターン $(1, 1, 0)$ の確率は、クラス 1：$0.9 \times 0.8 \times 0.3 = 0.216$、クラス 2：$0.2 \times 0.3 \times 0.9 = 0.054$。ベイズの定理より

  $$P(c = 1 \mid \boldsymbol{u}) = \frac{0.6 \times 0.216}{0.6 \times 0.216 + 0.4 \times 0.054} = \frac{0.1296}{0.1512} = 0.857$$

  0.5 を超えるので、クラス 1 に分類される。

  **[3]** $E[U_1U_2] = \sum_c\pi_cp_{c1}p_{c2}$、$E[U_j] = \sum_c\pi_cp_{cj}$ なので、$\pi_1 + \pi_2 = 1$ を用いて

  $$\mathrm{Cov}(U_1, U_2) = \sum_c\pi_cp_{c1}p_{c2} - \left(\sum_c\pi_cp_{c1}\right)\left(\sum_c\pi_cp_{c2}\right) = \pi_1\pi_2(p_{11} - p_{21})(p_{12} - p_{22})$$

  （右辺を展開すると $\pi_1\pi_2(p_{11}p_{12} + p_{21}p_{22} - p_{11}p_{22} - p_{21}p_{12})$ となり、左辺の $\pi_1p_{11}p_{12}(1 - \pi_1) + \pi_2p_{21}p_{22}(1 - \pi_2) - \pi_1\pi_2(p_{11}p_{22} + p_{21}p_{12})$ と一致する。）

  $$\mathrm{Cov}(U_1, U_2) = 0.6 \times 0.4 \times 0.7 \times 0.5 = 0.084$$

  $E[U_1] = 0.54 + 0.08 = 0.62$、$E[U_2] = 0.48 + 0.12 = 0.60$ より、相関係数は

  $$\frac{0.084}{\sqrt{0.62 \times 0.38 \times 0.60 \times 0.40}} = \frac{0.084}{\sqrt{0.056544}} = \frac{0.084}{0.2378} = 0.353$$

  クラスの中では反応は独立だが、賛成しやすいクラスと反対しやすいクラスが混ざっているため、全体では「一方の項目に賛成する人は他方にも賛成しやすい」という相関が生じる。潜在クラスモデルは、観測された項目間の連関を、潜在的な（カテゴリカルな）変数の違いで説明するモデルである。

  **[4]** 反応パターンは $2^J$ 通りで、総数を固定すると自由な確率は $2^J - 1$ 個。母数はクラスの割合 $C - 1$ 個と、反応確率 $CJ$ 個なので

  $$\mathrm{df} = 2^J - 1 - (C - 1) - CJ$$

  $J = 3,\ C = 2$ では $7 - 1 - 6 = 0$ で、モデルはデータに完全に当てはまり（丁度識別）、適合度を検証できない。$J = 4,\ C = 2$ では $15 - 1 - 8 = 6$ で、局所独立の仮定とクラス数の妥当性を、尤度比統計量 $G^2$ を自由度 6 のカイ二乗分布と比べて検証できる。（自由度が負になるモデルは識別されない。）

潜在クラス分析は、質問紙調査などのカテゴリカルな反応を、観測されない「類型」の混合として説明する方法です。因子分析が連続的な潜在変数を仮定するのに対し、潜在クラスモデルはカテゴリカルな潜在変数を仮定します。

### 解答の流れ

1. クラスを与えたときの局所独立と、全確率の公式から、パターンの確率は「クラスごとの積の加重和」になる。
2. 分類にはベイズの定理による事後確率を用いる。
3. 混合分布では、条件付き独立でも周辺では相関が生じる。共分散は 2 クラスの反応確率の差の積に比例する。
4. 自由度は（パターンの確率の自由な個数）$-$（母数の個数）。

### つまずきやすい点

- [2] でクラスの事前の割合 $\pi_c$ を掛け忘れると、$0.216/(0.216 + 0.054) = 0.8$ となる。
- [3] で局所独立を「項目どうしが無相関」と取り違えると、共分散 0 と答えてしまう。局所独立はクラス（潜在変数）を与えたときの条件付き独立である。
- [4] でクラスの割合の制約（和が 1）や、パターン確率の和が 1 であることを数え忘れる。

### ポイント

- 母数の推定には EM アルゴリズムがよく用いられる。E ステップで各回答者の事後確率（[2] の計算）を求め、M ステップでそれを重みとしてクラスの割合と反応確率を更新する。
- クラス数の選択には、$G^2$ による適合度検定（自由度が正の場合）のほか、AIC・BIC などの情報量規準を用いる。項目反応理論が連続的な能力を、潜在クラス分析が離散的な類型を仮定するという違いは、データの背後にどのような構造を想定するかの違いである。
