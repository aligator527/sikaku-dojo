$\partial\log f/\partial\theta = 2(x - \theta)/\{1 + (x - \theta)^2\}$ なので、$U = \sum 2X_i/(1 + X_i^2)$ の観測値は $8.4$ です。コーシー分布の位置母数のフィッシャー情報量は 1 個あたり $1/2$ で、$I_{50}(0) = 25$ です。よって $Z = 8.4/\sqrt{25} = 1.68$ となります。

### 計算

$$\frac{\partial}{\partial\theta}\log f(x;\theta) = \frac{2(x - \theta)}{1 + (x - \theta)^2}$$

1 個あたりのフィッシャー情報量は（位置母数なので $\theta$ によらない）

$$I_1 = E\left[\left(\frac{2X}{1 + X^2}\right)^2\right] = \frac{4}{\pi}\int_{-\infty}^{\infty}\frac{x^2}{(1 + x^2)^3}\,dx$$

$x = \tan t$ と置換すると $dx = \sec^2 t\,dt$、$1 + x^2 = \sec^2 t$ より

$$\int_{-\infty}^{\infty}\frac{x^2}{(1 + x^2)^3}\,dx = \int_{-\pi/2}^{\pi/2}\sin^2 t\cos^2 t\,dt = \int_{-\pi/2}^{\pi/2}\frac{\sin^2 2t}{4}\,dt = \frac{\pi}{8}$$

よって $I_1 = \dfrac{4}{\pi} \cdot \dfrac{\pi}{8} = \dfrac{1}{2}$、$I_{50}(0) = 50 \times \dfrac{1}{2} = 25$ です。

$$Z = \frac{8.4}{\sqrt{25}} = 1.68$$

$H_0$ のもとで $E[U] = 0$、$V[U] = 25$ で、中心極限定理により $Z$ は近似的に $N(0, 1)$ に従います。$1.68 > 1.645$ なので、有意水準 5% で棄却されます。

### ポイント

- コーシー分布は平均も分散ももたないので $\bar{X}$ にもとづく検定は使えませんが、スコア関数 $2x/(1 + x^2)$ は有界（$|2x/(1 + x^2)| \leq 1$）なので、その和には中心極限定理が使えます。
- よくある誤り：情報量を $1$（正規分布の場合）として $Z = 8.4/\sqrt{50} = 1.19$ とする、または $I_1 = 1/2$ を分散ではなく標準偏差と取り違える。
- スコア検定は、$\theta_0$ の近傍で検出力関数の傾き $\beta'(\theta_0)$ を最大にする局所最強力検定です。一様最強力検定が存在しない（単調尤度比をもたない）コーシー分布で特に有用です。
