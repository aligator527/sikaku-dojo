$C$ を与えたときの $A$ と $B$ の条件付き独立は、$A$–$B$ を直接結ぶ交互作用項（$\lambda^{AB}$ と $\lambda^{ABC}$）を含まず、$A$–$C$ と $B$–$C$ の交互作用を含むモデル $[AC][BC]$ で表されます。自由度は「各 $C$ の層での $2 \times 3$ 表の独立性の自由度 $(2 - 1)(3 - 1) = 2$」を層の数 4 だけ足し合わせた $8$ です。

### 計算

$I = 2,\ J = 3,\ K = 4$ で、セル数は $IJK = 24$。$[AC][BC]$ のパラメータ数は

$$1 + (I - 1) + (J - 1) + (K - 1) + (I - 1)(K - 1) + (J - 1)(K - 1) = 1 + 1 + 2 + 3 + 3 + 6 = 16$$

なので、自由度は $24 - 16 = 8 = K(I - 1)(J - 1)$ です。このモデルでは $\mu_{ijk} = \mu_{i+k}\mu_{+jk}/\mu_{++k}$ となり、最尤推定値は $\hat{\mu}_{ijk} = n_{i+k}n_{+jk}/n_{++k}$ です。

### 各選択肢の検討

- $[AB][C]$、自由度 15：$(A, B)$ の組と $C$ が独立というモデルです（自由度 $(IJ - 1)(K - 1) = 15$ は正しい）が、条件付き独立のモデルではありません。
- $[AC][BC]$、自由度 8：正しい。
- $[AC][BC]$、自由度 2：モデルは正しいものの、自由度を 1 つの層の $2 \times 3$ 表の分だけで数えています。条件付き独立は $C$ のすべての層で成り立つ必要があるので、層の数 $K = 4$ 倍になります。
- $[AB][AC][BC]$、自由度 6：3 因子交互作用だけがないモデル（均一連関モデル）です。$C$ のどの層でも $A$–$B$ のオッズ比が等しいことを表しますが、そのオッズ比が 1 である（条件付き独立）とは限りません。自由度 $(I - 1)(J - 1)(K - 1) = 6$ は正しい値です。
- $[A][B][C]$、自由度 17：3 変数が互いに独立（完全独立）というモデルです。条件付き独立よりも強い制約で、$A$–$C$、$B$–$C$ の関連も認めません。

### ポイント

- 対数線形モデルの階層的な表記 $[AC][BC]$ は「含まれる最高次の交互作用項」を並べたもので、低次の項はすべて含みます。
- 条件付き独立 $A \perp B \mid C$ が成り立っても、$C$ について合計した 2 元表では $A$ と $B$ が関連していることがあります（シンプソンのパラドックスと同じ構造）。周辺表と層別表の結論は必ずしも一致しません。
