「はい」と答える確率は $\lambda = p\pi + (1 - p)(1 - \pi)$ なので、$\hat{\pi} = \{\hat{\lambda} - (1 - p)\}/(2p - 1) = (0.38 - 0.3)/0.4 = 0.20$ です。$\hat{\lambda}$ は二項分布の標本比率なので $V[\hat{\pi}] = \lambda(1 - \lambda)/\{n(2p - 1)^2\}$ となり、標準誤差は $0.0543$、上限は $0.20 + 1.96 \times 0.0543 = 0.306$ です。

### 計算

$$\hat{\lambda} = \frac{190}{500} = 0.38,\qquad \hat{\pi} = \frac{0.38 - 0.3}{2 \times 0.7 - 1} = \frac{0.08}{0.4} = 0.20$$

$$\widehat{V}[\hat{\pi}] = \frac{\hat{\lambda}(1 - \hat{\lambda})}{n(2p - 1)^2} = \frac{0.38 \times 0.62}{500 \times 0.16} = \frac{0.2356}{80} = 0.002945,\qquad \mathrm{SE} = 0.05427$$

$$\hat{\pi} + 1.96 \times \mathrm{SE} = 0.20 + 0.1064 = 0.306$$

近似 95% 信頼区間は $[0.094,\ 0.306]$ です。

### ポイント

- 分散は $V[\hat{\pi}] = \dfrac{\pi(1 - \pi)}{n} + \dfrac{p(1 - p)}{n(2p - 1)^2}$ と分解できる。第 1 項は直接質問した場合の分散、第 2 項は回答を無作為化したことによる分散の増加で、プライバシーを守る代償である。本問では $0.00032 + 0.002625$ で、分散は直接質問の約 9 倍になる。
- $p$ が $1/2$ に近いほど回答者のプライバシーは守られるが、$2p - 1$ が 0 に近づいて分散が急増する（$p = 1/2$ では推定不能）。
- よくある誤り：$\sqrt{\hat{\pi}(1 - \hat{\pi})/n} = 0.0179$ を標準誤差とする（上限 $0.235$）、または $(2p - 1)^2$ で割り忘れる（上限 $0.243$）。
- 回答者が正直に答えるという仮定は、直接質問よりは成り立ちやすいと考えられるが、検証はできない。
