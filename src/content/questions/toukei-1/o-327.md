  **[1]** $\Phi(z) = 1 - \phi_1z - \phi_2z^2$ とおき、$\phi_2 \neq 0$ とする（$\phi_2 = 0$ は AR(1) で $|\phi_1| < 1$ と同値）。2 根を $z_1,\ z_2$ とすると、逆数 $w_j = 1/z_j$ は $w^2 - \phi_1w - \phi_2 = 0$ の根であり、条件は $|w_1|,\ |w_2| < 1$ と同値である。$g(w) = w^2 - \phi_1w - \phi_2$ は下に凸の 2 次関数なので、実根がともに $(-1, 1)$ にある条件は

  $$g(1) = 1 - \phi_1 - \phi_2 > 0,\qquad g(-1) = 1 + \phi_1 - \phi_2 > 0,\qquad -1 < \frac{\phi_1}{2} < 1$$

  である。最初の 2 つが $\phi_1 + \phi_2 < 1$、$\phi_2 - \phi_1 < 1$。また根と係数の関係から $w_1w_2 = -\phi_2$ で、$|w_1|, |w_2| < 1$ なら $|\phi_2| < 1$。逆に 3 条件が成り立てば、$g(\pm 1) > 0$ と $|\phi_2| < 1$ から軸 $\phi_1/2$ が $(-1, 1)$ に入ることが従い（$|\phi_1| < 1 - \phi_2 < 2$）、2 根は $(-1, 1)$ にある。

  **[2]** 両辺に $y_{t-h}$（$h \geq 1$）を掛けて期待値をとると、$E[\varepsilon_ty_{t-h}] = 0$ より

  $$\gamma(h) = \phi_1\gamma(h - 1) + \phi_2\gamma(h - 2)$$

  $\gamma(0)$ で割って $\rho(h) = \phi_1\rho(h-1) + \phi_2\rho(h-2)$。$h = 1$ では $\rho(-1) = \rho(1)$ より $\rho(1) = \phi_1 + \phi_2\rho(1)$、よって $\rho(1) = \phi_1/(1 - \phi_2)$。

  $$\rho(h) = A\left(\frac{1}{\sqrt{2}}\right)^h\cos\left(\frac{\pi}{4}h + B\right)$$

  の形の減衰振動となり、振幅は 1 期ごとに $0.707$ 倍に減り、周期は $2\pi/(\pi/4) = 8$ 期である。

  **[4]** 分母を展開すると

  $$|1 - \phi_1e^{-i\lambda} - \phi_2e^{-2i\lambda}|^2 = 1 + \phi_1^2 + \phi_2^2 - 2\phi_1(1 - \phi_2)\cos\lambda - 2\phi_2\cos 2\lambda$$

  $c = \cos\lambda$、$\cos 2\lambda = 2c^2 - 1$ とおくと、$\phi_1 = 1,\ \phi_2 = -0.5$ では分母は $2.25 - 3c + (2c^2 - 1) = 2c^2 - 3c + 1.25$ で、$c = 3/4$ で最小になる（$c \in [-1, 1]$ の内部）。よって

AR(2) モデルの定常条件、ユール・ウォーカー方程式、複素根による擬似周期、スペクトルのピークを関連づける問題です。景気循環のような周期的な変動を AR(2) で表すときの基本になります。

### 解答の流れ

1. 定常条件は「特性方程式の根が単位円の外」、言い換えると「逆数の根が単位円の内」。実根の場合は 2 次関数の符号で調べる。
2. 自己共分散は AR の係数と同じ差分方程式を満たす（ユール・ウォーカー方程式）。
3. 特性根が複素数なら、自己相関は減衰振動になる。減衰率は根の逆数の絶対値、周期は偏角から決まる。
4. スペクトル密度は $\cos\lambda$ の関数として最小化・最大化できる。

### つまずきやすい点

- 定常条件を「$|\phi_1| < 1$ かつ $|\phi_2| < 1$」とする誤り。たとえば $\phi_1 = 1.0,\ \phi_2 = -0.5$ は $|\phi_1| = 1$ だが定常であり、$\phi_1 = 0.6,\ \phi_2 = 0.6$ は両方 1 未満だが $\phi_1 + \phi_2 > 1$ で非定常である。
- [4] のピーク周波数 $\cos\lambda^{*} = \dfrac{\phi_1(\phi_2 - 1)}{4\phi_2}$ は、根の偏角 $\theta$（$\cos\theta = \dfrac{\phi_1}{2\sqrt{-\phi_2}}$）と一致しない。前者は $0.75$、後者は $1/\sqrt{2} = 0.707$ である。

### ポイント

- 分散は $\gamma(0) = \dfrac{(1 - \phi_2)\sigma^2}{(1 + \phi_2)\{(1 - \phi_2)^2 - \phi_1^2\}}$。この例では $\dfrac{1.5\sigma^2}{0.5 \times 1.25} = 2.4\sigma^2$。
- AR(2) の偏自己相関はラグ 2 で $\phi_2$ になり、ラグ 3 以降は 0 である。自己相関の減衰振動と偏自己相関の切断の組合せが、AR(2) を見分ける手がかりになる。
