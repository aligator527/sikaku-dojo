  $N$ はポアソン分布 $Po(\lambda)$ に従う確率変数、$X_1, X_2, \ldots$ は $N$ と独立で、互いに独立に同一の分布に従う確率変数とする。$X_i$ の平均を $\mu$、分散を $\sigma^2$、積率母関数を $M_X(t)$（$0$ の近傍で存在するとする）とし、

  $$S = \sum_{i=1}^{N} X_i \qquad (N = 0 \text{ のときは } S = 0)$$

  とおく（複合ポアソン分布）。以下の各問に答えよ。

  [1] 条件付き期待値と条件付き分散を用いて、$E[S]$ と $V[S]$ を $\lambda,\ \mu,\ \sigma^2$ で表せ。

  [2] $S$ の積率母関数 $M_S(t)$ を $\lambda$ と $M_X(t)$ で表せ。

  [3] $X_i$ が成功確率 $p$ のベルヌーイ分布に従うとき、$S$ の分布を求めよ。

  [4] ある保険の 1 年間の請求件数が $Po(50)$ に従い、1 件あたりの請求額（万円）が平均 20、標準偏差 10 の分布に従うとする（件数と請求額、請求額どうしは独立）。1 年間の請求総額 $S$ を正規分布で近似し、$P(S > c) \approx 0.05$ となる $c$ を小数第 1 位まで求めよ。標準正規分布の上側 5% 点は $1.645$ とする。
modelAnswer: |
  **[1]** $N = n$ を与えたとき、$S$ は独立な $n$ 個の和なので $E[S \mid N] = N\mu$、$V[S \mid N] = N\sigma^2$。全期待値の公式と全分散の公式より

  $$E[S] = E\big[E[S \mid N]\big] = \mu E[N] = \lambda\mu$$

  $$V[S] = E\big[V[S \mid N]\big] + V\big[E[S \mid N]\big] = \sigma^2E[N] + \mu^2V[N] = \lambda(\sigma^2 + \mu^2) = \lambda E[X_1^2]$$

  **[2]** $E[e^{tS} \mid N = n] = M_X(t)^n$ なので、ポアソン分布の確率母関数 $E[s^N] = e^{\lambda(s-1)}$ を用いて

  $$M_S(t) = E\big[M_X(t)^N\big] = \sum_{n=0}^{\infty}\frac{e^{-\lambda}\lambda^n}{n!}M_X(t)^n = \exp\big\{\lambda\big(M_X(t) - 1\big)\big\}$$

  （検算：$K_S(t) = \log M_S(t) = \lambda(M_X(t) - 1)$ より $K_S'(0) = \lambda M_X'(0) = \lambda\mu$、$K_S''(0) = \lambda M_X''(0) = \lambda E[X^2]$ で [1] と一致する。）

  **[3]** $M_X(t) = 1 - p + pe^t$ を [2] に代入すると

  $$M_S(t) = \exp\{\lambda(1 - p + pe^t - 1)\} = \exp\{\lambda p(e^t - 1)\}$$

  これは $Po(\lambda p)$ の積率母関数であり、積率母関数は分布を一意に定めるので $S \sim Po(\lambda p)$（ポアソン分布の間引き）。

  **[4]** [1] より

  $$E[S] = 50 \times 20 = 1000,\qquad V[S] = 50 \times (10^2 + 20^2) = 25000,\qquad \sqrt{V[S]} = 158.11$$

  $\lambda = 50$ が大きいので $S$ は近似的に $N(1000,\ 25000)$ に従う（[2] の $K_S(t)$ を標準化すると、$\lambda \to \infty$ で $t^2/2$ に収束することからも分かる）。よって

  $$c \approx 1000 + 1.645 \times 158.11 = 1260.1\ \text{（万円）}$$

  なお $S$ は右に裾の長い分布なので、正規近似は上側の裾確率をやや過小評価する（$c$ を小さめに見積もる）傾向がある。

複合ポアソン分布は、件数と 1 件あたりの大きさがともにランダムな「ランダム和」の代表例です。条件付き期待値・条件付き分散（全分散の公式）と、条件付けによる母関数の計算という、確率論の 2 つの基本技法を使います。

### 解答の流れ

1. 件数 $N$ で条件付けると、$S$ は固定個数の独立な和になる。
2. 全分散の公式で「件数のばらつき」と「1 件ごとのばらつき」の寄与を足す。
3. 母関数は $E[e^{tS}] = E[E[e^{tS} \mid N]]$ として、$N$ の確率母関数に $M_X(t)$ を代入する。

### つまずきやすい点

- $V[S] = \lambda\sigma^2$ とする誤り（[4] では $50 \times 100 = 5000$）。件数のばらつきによる項 $\mu^2 V[N] = \lambda\mu^2$ を落としている。ポアソンの場合は $E[N] = V[N]$ なので、まとめて $\lambda E[X^2]$ となる。
- $S$ を「$N$ 倍の $X$」と考えて $V[S] = V[NX_1]$ とする誤り。$X_i$ は件ごとに独立なので、$S$ と $NX_1$ は分布が異なる。
- [4] で $\sqrt{25000}$ を $\sqrt{50} \times 10$ などと計算を誤りやすい。$\sqrt{25000} = 50\sqrt{10} \approx 158.11$。

### ポイント

- ランダム和の一般公式：$E[S] = E[N]\mu$、$V[S] = E[N]\sigma^2 + V[N]\mu^2$。
- 複合ポアソン過程は保険数理のリスクモデル（クラメール・ルンドバーグモデル）の基本であり、キュムラント $\kappa_r(S) = \lambda E[X^r]$ という単純な形をもつ。
