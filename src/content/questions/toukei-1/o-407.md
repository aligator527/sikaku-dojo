  2 値の目的変数 $y_i \in \{0, 1\}$ と説明変数ベクトル $\boldsymbol{x}_i$（第 1 成分は定数 1）について、ロジットモデル

  $$P(y_i = 1 \mid \boldsymbol{x}_i) = \Lambda(\boldsymbol{x}_i^{\top}\boldsymbol{\beta}),\qquad \Lambda(s) = \frac{e^{s}}{1 + e^{s}}$$

  を考える。観測 $(y_i, \boldsymbol{x}_i)$（$i = 1, \ldots, n$）は互いに独立とする。以下の各問に答えよ。

  [1] 対数尤度 $\ell(\boldsymbol{\beta})$ を書き、尤度方程式が $\sum_{i=1}^{n}\{y_i - \Lambda(\boldsymbol{x}_i^{\top}\boldsymbol{\beta})\}\boldsymbol{x}_i = \boldsymbol{0}$ となることを示せ。また、最尤推定値 $\hat{\boldsymbol{\beta}}$ のもとで $\sum_{i}\Lambda(\boldsymbol{x}_i^{\top}\hat{\boldsymbol{\beta}}) = \sum_{i}y_i$ が成り立つことを示せ。

  [2] $\ell(\boldsymbol{\beta})$ のヘッセ行列を求め、$\ell(\boldsymbol{\beta})$ が $\boldsymbol{\beta}$ の凹関数であることを示せ。また、$\hat{\boldsymbol{\beta}}$ の漸近分散共分散行列の推定量を述べよ。

  [3] 連続な説明変数 $x_{ik}$ の限界効果 $\partial P(y_i = 1 \mid \boldsymbol{x}_i)/\partial x_{ik}$ を求め、その絶対値が $|\beta_k|/4$ 以下であることを示せ。また、$e^{\beta_k}$ の意味を説明せよ。

  [4] 既婚女性の就業（就業 $= 1$）を教育年数 $x$ で説明するロジットモデルを推定し、$\hat{\beta}_0 = -3.2$、$\hat{\beta}_1 = 0.25$ を得た。$x = 12$ における就業確率の推定値と、$x$ の限界効果の推定値を小数第 3 位まで求めよ。また、教育年数が 1 年長いことに対応するオッズ比を求めよ。必要なら $e^{0.2} = 1.2214$、$e^{0.25} = 1.2840$ を用いよ。
modelAnswer: |
  **[1]** $\Lambda_i = \Lambda(\boldsymbol{x}_i^{\top}\boldsymbol{\beta})$ と書く。$\log\Lambda_i = \boldsymbol{x}_i^{\top}\boldsymbol{\beta} - \log(1 + e^{\boldsymbol{x}_i^{\top}\boldsymbol{\beta}})$、$\log(1 - \Lambda_i) = -\log(1 + e^{\boldsymbol{x}_i^{\top}\boldsymbol{\beta}})$ なので

  $$\ell(\boldsymbol{\beta}) = \sum_{i=1}^{n}\{y_i\log\Lambda_i + (1 - y_i)\log(1 - \Lambda_i)\} = \sum_{i=1}^{n}\left\{y_i\boldsymbol{x}_i^{\top}\boldsymbol{\beta} - \log\left(1 + e^{\boldsymbol{x}_i^{\top}\boldsymbol{\beta}}\right)\right\}$$

  $\dfrac{\partial}{\partial\boldsymbol{\beta}}\log(1 + e^{\boldsymbol{x}_i^{\top}\boldsymbol{\beta}}) = \Lambda_i\boldsymbol{x}_i$ より

  $$\frac{\partial\ell}{\partial\boldsymbol{\beta}} = \sum_{i=1}^{n}(y_i - \Lambda_i)\boldsymbol{x}_i = \boldsymbol{0}$$

  $\boldsymbol{x}_i$ の第 1 成分は 1 なので、尤度方程式の第 1 成分から $\sum_i(y_i - \hat{\Lambda}_i) = 0$、すなわち予測確率の合計は観測された 1 の個数に等しい。

  **[2]** $\Lambda'(s) = \Lambda(s)\{1 - \Lambda(s)\}$ より

  $$\frac{\partial^2\ell}{\partial\boldsymbol{\beta}\,\partial\boldsymbol{\beta}^{\top}} = -\sum_{i=1}^{n}\Lambda_i(1 - \Lambda_i)\,\boldsymbol{x}_i\boldsymbol{x}_i^{\top}$$

  任意の $\boldsymbol{a}$ について $\boldsymbol{a}^{\top}(\cdot)\boldsymbol{a} = -\sum_i\Lambda_i(1 - \Lambda_i)(\boldsymbol{a}^{\top}\boldsymbol{x}_i)^2 \leq 0$ なので、ヘッセ行列は半負定値であり $\ell$ は凹関数である（説明変数の行列が列フルランクなら狭義凹で、最尤推定値は存在すれば一意）。ヘッセ行列が $y$ を含まないので、これはフィッシャー情報行列の符号を反転したものに等しく、漸近分散共分散行列は

  $$\hat{V}[\hat{\boldsymbol{\beta}}] = \left\{\sum_{i=1}^{n}\hat{\Lambda}_i(1 - \hat{\Lambda}_i)\,\boldsymbol{x}_i\boldsymbol{x}_i^{\top}\right\}^{-1}$$

  で推定される。

  **[3]**

  $$\frac{\partial\Lambda_i}{\partial x_{ik}} = \Lambda_i(1 - \Lambda_i)\,\beta_k$$

  $\Lambda_i(1 - \Lambda_i)$ は $\Lambda_i = 1/2$ で最大値 $1/4$ をとるので、$|\partial\Lambda_i/\partial x_{ik}| \leq |\beta_k|/4$。

  オッズは $\Lambda_i/(1 - \Lambda_i) = e^{\boldsymbol{x}_i^{\top}\boldsymbol{\beta}}$ なので、他の変数を固定して $x_{ik}$ を 1 増やすとオッズは $e^{\beta_k}$ 倍になる。$e^{\beta_k}$ は $x_{ik}$ の 1 単位の違いに対応するオッズ比であり、確率の差と違って $\boldsymbol{x}_i$ の値によらない。

  **[4]** $x = 12$ のとき $\hat{\beta}_0 + 12\hat{\beta}_1 = -3.2 + 3.0 = -0.2$ なので

  $$\hat{P} = \frac{e^{-0.2}}{1 + e^{-0.2}} = \frac{1}{1 + e^{0.2}} = \frac{1}{2.2214} = 0.450$$

  $$\text{限界効果} = \hat{P}(1 - \hat{P})\hat{\beta}_1 = 0.4502 \times 0.5498 \times 0.25 = 0.062$$

  教育年数が 1 年長いと、就業確率は約 6.2 パーセントポイント高くなる（$x = 12$ の近傍で）。オッズ比は $e^{0.25} = 1.284$ で、教育年数 1 年あたり就業のオッズが約 1.28 倍になる。

ロジットモデルは、離散選択モデルの中で最尤推定の性質（スコア・ヘッセ行列・凹性）が最もきれいに出るモデルです。係数そのものではなく、限界効果やオッズ比に翻訳して解釈できることが求められます。

### 解答の流れ

1. ベルヌーイ分布の対数尤度に $\Lambda$ を代入し、$\Lambda' = \Lambda(1 - \Lambda)$ を使って微分する。
2. 2 階微分が $y$ を含まず、各項が半負定値の行列 $\boldsymbol{x}_i\boldsymbol{x}_i^{\top}$ の負の重み付き和であることから凹性を示す。
3. 限界効果は確率の微分。$\Lambda(1 - \Lambda) \leq 1/4$ を使う。
4. 線形予測子 $-0.2$ を計算し、$\Lambda(-0.2) = 1/(1 + e^{0.2})$ と変形して与えられた値を使う。

### つまずきやすい点

- 係数 $\hat{\beta}_1 = 0.25$ をそのまま「確率が 0.25 上がる」と読むのは誤り。確率への効果は $\hat{P}(1 - \hat{P})$ 倍に縮み、$\boldsymbol{x}$ の値によって変わる。
- 限界効果の評価点には、平均的な個人の $\bar{\boldsymbol{x}}$ で評価する方法（平均での限界効果）と、個人ごとの限界効果を平均する方法（平均限界効果）があり、一般に値が異なる。
- ある説明変数の値で $y$ が完全に分離される（$x > c$ なら必ず $y = 1$ など）と、対数尤度は上に有界でも最大値をとらず、最尤推定値が存在しない（係数が発散する）。

### ポイント

- 線形確率モデル（$y$ を $\boldsymbol{x}$ に最小二乗回帰）は解釈が容易だが、予測値が $[0, 1]$ の外に出ること、誤差の分散 $p_i(1 - p_i)$ が不均一であることが欠点。
- プロビットモデルとの係数の比較では、ロジスティック分布の標準偏差が $\pi/\sqrt{3} \approx 1.81$ であることから、ロジットの係数はプロビットの係数のおよそ 1.6〜1.8 倍になる。限界効果どうしで比べるとほぼ一致する。
