stem: |
  平均 0 の弱定常過程 $\{y_t\}$ の自己共分散関数を $\gamma(h)$ とし、$\sum_h|\gamma(h)| < \infty$ とする。スペクトル密度関数を

  $$f(\lambda) = \frac{1}{2\pi}\sum_{h=-\infty}^{\infty}\gamma(h)e^{-ih\lambda}\qquad (-\pi \leq \lambda \leq \pi)$$

  で定義する。以下の各問に答えよ。

  [1] $f(\lambda)$ が実数値の偶関数で $f(\lambda) = \dfrac{1}{2\pi}\left\{\gamma(0) + 2\sum_{h=1}^{\infty}\gamma(h)\cos h\lambda\right\}$ と書けること、および $\gamma(h) = \displaystyle\int_{-\pi}^{\pi}e^{ih\lambda}f(\lambda)\,d\lambda$ が成り立つことを示せ。これより $V[y_t]$ と $f$ の関係を述べよ。

  [2] MA(1) 過程 $y_t = \varepsilon_t + \theta\varepsilon_{t-1}$（$\{\varepsilon_t\}$ は分散 $\sigma^2$ のホワイトノイズ）のスペクトル密度を求めよ。$\theta = 0.5$ のとき $f(0)/f(\pi)$ を求め、この過程の見た目の特徴を述べよ。

  [3] 有限個の係数による線形フィルター $x_t = \sum_{j=0}^{m}a_jy_{t-j}$ について、$x_t$ のスペクトル密度が $f_x(\lambda) = |A(e^{-i\lambda})|^2f_y(\lambda)$（$A(z) = \sum_{j=0}^{m}a_jz^j$）となることを示せ。これを用いて、1 階の階差 $x_t = y_t - y_{t-1}$ と季節階差 $x_t = y_t - y_{t-12}$（月次データ）がそれぞれどの周波数の変動を取り除くかを説明せよ。

  [4] 長さ $n$ の観測値から作るピリオドグラム $I(\lambda) = \dfrac{1}{2\pi n}\left|\sum_{t=1}^{n}y_te^{-it\lambda}\right|^2$ は、$f(\lambda)$ の推定量としてどのような性質をもつか。$n$ を大きくしたときの期待値と分散の振る舞いにふれて説明し、実際にスペクトルを推定するときの対処法を述べよ。
modelAnswer: |
  **[1]** 定常過程では $\gamma(-h) = \gamma(h)$ なので、$h$ と $-h$ の項をまとめると $e^{-ih\lambda} + e^{ih\lambda} = 2\cos h\lambda$ より

  $$f(\lambda) = \frac{1}{2\pi}\left\{\gamma(0) + 2\sum_{h=1}^{\infty}\gamma(h)\cos h\lambda\right\}$$

  これは実数値で、$\cos h\lambda$ が偶関数なので $f$ も偶関数である。また $\sum|\gamma(h)| < \infty$ より項別積分ができ、$\int_{-\pi}^{\pi}e^{i(h-k)\lambda}\,d\lambda = 2\pi\,\mathbf{1}\{h = k\}$ を用いると

  $$\int_{-\pi}^{\pi}e^{ih\lambda}f(\lambda)\,d\lambda = \frac{1}{2\pi}\sum_k\gamma(k)\int_{-\pi}^{\pi}e^{i(h-k)\lambda}\,d\lambda = \gamma(h)$$

  $h = 0$ とおくと $V[y_t] = \gamma(0) = \int_{-\pi}^{\pi}f(\lambda)\,d\lambda$。すなわち $f(\lambda)\,d\lambda$ は、分散のうち周波数 $\lambda$ 付近の周期成分が担う部分を表す（分散の周波数分解）。

  **[2]** $\gamma(0) = (1 + \theta^2)\sigma^2$、$\gamma(\pm 1) = \theta\sigma^2$、それ以外は 0 なので

  $$f(\lambda) = \frac{\sigma^2}{2\pi}(1 + \theta^2 + 2\theta\cos\lambda) = \frac{\sigma^2}{2\pi}|1 + \theta e^{-i\lambda}|^2$$

  $\theta = 0.5$ では $f(0) = \dfrac{2.25\sigma^2}{2\pi}$、$f(\pi) = \dfrac{0.25\sigma^2}{2\pi}$ で、$f(0)/f(\pi) = 9$。スペクトルが低い周波数に偏っているので、隣り合う値が似た値をとりやすい、ホワイトノイズより滑らかな動きの系列になる（$\theta < 0$ なら逆に高周波が卓越し、ジグザグした系列になる）。

  **[3]** $x_t$ の自己共分散は

  $$\gamma_x(h) = E[x_{t+h}x_t] = \sum_{j=0}^{m}\sum_{k=0}^{m}a_ja_k\gamma_y(h - j + k)$$

  なので

  $$f_x(\lambda) = \frac{1}{2\pi}\sum_h\sum_{j,k}a_ja_k\gamma_y(h - j + k)e^{-ih\lambda} = \sum_ja_je^{-ij\lambda}\sum_ka_ke^{ik\lambda}\cdot\frac{1}{2\pi}\sum_l\gamma_y(l)e^{-il\lambda} = |A(e^{-i\lambda})|^2f_y(\lambda)$$

  （$l = h - j + k$ と置き換えた。）1 階の階差では $A(z) = 1 - z$ で

  $$|1 - e^{-i\lambda}|^2 = 2(1 - \cos\lambda)$$

  これは $\lambda = 0$ で 0、$\lambda = \pi$ で最大 4 になるので、階差はトレンドのような低周波の変動を取り除き、高周波の変動を強調する。季節階差では $|1 - e^{-12i\lambda}|^2 = 2(1 - \cos 12\lambda)$ で、$\lambda = 2\pi k/12$（$k = 0, 1, \ldots, 6$）、すなわち周期 12、6、4、3、2.4、2 か月の季節変動と周波数 0 のトレンドをすべて取り除く。

  **[4]** フーリエ周波数 $\lambda_j = 2\pi j/n$（$0 < \lambda_j < \pi$）で、$n \to \infty$ のとき $E[I(\lambda_j)] \to f(\lambda_j)$ と漸近不偏だが、分散は $V[I(\lambda_j)] \to f(\lambda_j)^2$ で 0 に近づかない。したがってピリオドグラムは一致推定量ではなく、$n$ を増やしても細かく激しく上下する。近似的には $I(\lambda_j) \approx f(\lambda_j)\chi^2_2/2$ で、異なるフーリエ周波数では漸近的に独立である。そこで、近くの周波数のピリオドグラムを平均する（ダニエル窓などの平滑化）、自己共分散にラグ窓をかけてから変換する、AR モデルを当てはめてそのスペクトルを用いる、などの方法で分散を減らして推定する。平滑化の幅を広げるほど分散は減るが、ピークがならされて偏りが増える。

スペクトル密度の定義と反転公式、MA(1) のスペクトル、線形フィルターのゲイン、ピリオドグラムの性質という、周波数領域での時系列解析の基本をまとめた問題です。

### 解答の流れ

1. 自己共分散の対称性で複素指数の和を余弦の和に直し、三角関数の直交性で反転する。
2. MA(1) は自己共分散がラグ 1 までしかないので、スペクトルは $\cos\lambda$ の 1 次式になる。
3. フィルターの効果は周波数ごとに $|A(e^{-i\lambda})|^2$ 倍の掛け算になる（時間領域の畳み込みが周波数領域の積になる）。
4. ピリオドグラムは各周波数でほぼ自由度 2 のカイ二乗分布に比例し、データを増やしても分散が減らない。

### つまずきやすい点

- [1] の係数 $1/(2\pi)$ の位置は流儀によって異なる（周波数を $[-1/2, 1/2]$ で測る場合など）。どの定義でも、スペクトルの積分が分散になるように係数が決まる。
- [3] でホワイトノイズに階差をとると $|1 - e^{-i\lambda}|^2\sigma^2/(2\pi)$ となり、$\lambda = 0$ でスペクトルが 0 になる。これは MA 係数 $-1$ の反転不可能な MA(1) であり、定常な系列に不必要な階差をとる（過剰階差）と生じる。

### ポイント

- ARMA 過程 $\Phi(B)y_t = \Theta(B)\varepsilon_t$ のスペクトルは、[3] の結果から $f(\lambda) = \dfrac{\sigma^2}{2\pi}\dfrac{|\Theta(e^{-i\lambda})|^2}{|\Phi(e^{-i\lambda})|^2}$ となる。
- $2\pi f(0) = \sum_h\gamma(h)$ は長期分散と呼ばれ、標本平均の分散 $V[\bar{y}] \approx 2\pi f(0)/n$ を与える。
