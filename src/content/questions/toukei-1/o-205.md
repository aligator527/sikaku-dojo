対立仮説のもとでは各工場の発生率を別々に、帰無仮説のもとでは共通の発生率を推定し、最大対数尤度の差を 2 倍します。共通の発生率の最尤推定値は $(36 + 24)/(1200 + 400) = 0.0375$ で、期待件数は工場 A が 45 件、工場 B が 15 件です。$-2\log\Lambda = 2\sum(\text{観測}) \log(\text{観測}/\text{期待}) = 2(36\log 0.8 + 24\log 1.6) = 6.49$ となります。

### 計算

対数尤度（定数を除く）は、$t_A = 1200,\ t_B = 400$ として

$$\ell(\lambda_A, \lambda_B) = -t_A\lambda_A + x\log\lambda_A - t_B\lambda_B + y\log\lambda_B$$

- $H_1$ のもと：$\hat{\lambda}_A = x/t_A = 0.03$、$\hat{\lambda}_B = y/t_B = 0.06$
- $H_0$ のもと：$\hat{\lambda} = (x + y)/(t_A + t_B) = 60/1600 = 0.0375$

どちらのもとでも $-t_A\hat{\lambda}_A - t_B\hat{\lambda}_B = -(x + y)$ となって打ち消し合うので

$$-2\log\Lambda = 2\left[x\log\frac{\hat{\lambda}_A}{\hat{\lambda}} + y\log\frac{\hat{\lambda}_B}{\hat{\lambda}}\right] = 2\left[36\log\frac{36}{45} + 24\log\frac{24}{15}\right]$$

$$= 2\left[36 \times (-0.2231) + 24 \times 0.4700\right] = 2(-8.0316 + 11.2800) = 6.497$$

対数の値を丸めずに計算すると $6.494$ で、いずれも $6.49$〜$6.50$ です。

### 判定

自由度は「対立仮説の母数の数 2 − 帰無仮説の母数の数 1 = 1」で、ウィルクスの定理より $-2\log\Lambda$ は近似的に $\chi^2(1)$ に従います。$6.49 > \chi^2_{0.05}(1) = 3.841$ なので、有意水準 5% で発生率に差があると判断されます（$p \approx 0.011$）。

### ポイント

- 同じデータのピアソンのカイ二乗統計量は $(36 - 45)^2/45 + (24 - 15)^2/15 = 1.8 + 5.4 = 7.2$ で、尤度比統計量 $G^2$ と漸近的に同等です。
- $x + y = 60$ を与えたときの $Y$ の条件付き分布は二項分布 $\mathrm{Bin}(60,\ t_B\lambda_B/(t_A\lambda_A + t_B\lambda_B))$ で、$H_0$ のもとでは成功確率 $400/1600 = 0.25$ です。これを使えば正確な検定もできます。
- よくある誤り：延べ時間を無視して件数 36 と 24 をそのまま比べる（共通平均 30 を期待値とする）。曝露量が異なるときは、期待件数を曝露量に比例して配分します。
