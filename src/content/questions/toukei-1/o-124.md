$X_i/2$ は標準指数分布に従うので、$M/2 - \log 1000$ は近似的にガンベル分布に従います。$G(x) = 0.95$ を解くと $x = -\log(-\log 0.95) = 2.970$ なので、$c/2 = 6.908 + 2.970 = 9.878$、$c = 19.756 \approx 19.76$ 秒です。

### 計算

まず極限分布を確認します。標準指数分布の最大値について

$$P(M_n - \log n \leq x) = \left(1 - e^{-(x + \log n)}\right)^n = \left(1 - \frac{e^{-x}}{n}\right)^n \to \exp(-e^{-x})$$

$M = 2M_n$（$M_n$ は $X_i/2$ の最大値）なので

$$P(M \leq c) = P\left(M_n - \log n \leq \frac{c}{2} - \log n\right) \approx \exp\left\{-e^{-(c/2 - \log n)}\right\} = 0.95$$

両辺の対数を 2 回とると $-(c/2 - \log n) = \log(-\log 0.95) = -2.970$ なので

$$c = 2(\log 1000 + 2.970) = 2(6.908 + 2.970) = 19.756 \approx 19.76$$

### ポイント

- 正確な値は $(1 - e^{-c/2})^{1000} = 0.95$ を解いた $c = 19.756$ で、ガンベル近似はほぼ一致する。
- よくある誤り：平均 2 の尺度を忘れて $c = 9.88$ とする、または中心極限定理と混同して最大値を正規近似する。最大値の分布は正規分布ではなく、右に裾の長いガンベル分布に近づく。
- $n$ が 10 倍になっても、最大値の目安は $2\log 10 \approx 4.6$ 秒しか増えない（$\log n$ の増え方）。指数分布のように裾が指数関数的に減衰する分布の最大値はガンベル分布の吸引域に入る。
