stem: |
  分析装置の検量線を作るため、濃度 $x$ が既知の標準試料 $x = 0, 2, 4, 6, 8, 10$（各 1 回）を測定し、装置の応答 $y$ について単回帰モデル $y = \beta_0 + \beta_1x + \varepsilon$（$\varepsilon \sim N(0, \sigma^2)$、独立）を当てはめた。結果は

  $$\hat{\beta}_0 = 0.40,\qquad \hat{\beta}_1 = 2.00,\qquad s^2 = 0.0400\ (\text{残差分散、自由度 } 4)$$

  であった（$\bar{x} = 5$、$S_{xx} = \sum(x_i - \bar{x})^2 = 70$）。次に、濃度が未知の試料を $m = 3$ 回測定し、応答の平均 $\bar{y}_0 = 13.40$ を得た。この測定の誤差も同じモデルに従い、検量線のデータとは独立とする。以下の各問に答えよ。

  [1] 未知試料の濃度 $x_0$ の推定値 $\hat{x}_0$ を求めよ。

  [2] デルタ法（1 次の近似）により、$\hat{x}_0$ の分散が

  $$V[\hat{x}_0] \approx \frac{\sigma^2}{\beta_1^2}\left\{\frac{1}{m} + \frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}\right\}\qquad (n = 6)$$

  となることを示し、標準誤差の推定値を求めよ。

  [3] [2] を用いて $x_0$ の近似 95% 信頼区間を求めよ。$t_{0.025}(4) = 2.776$ とする。

  [4] 統計量 $\bar{y}_0 - \hat{\beta}_0 - \hat{\beta}_1x_0$ にもとづくフィラーの方法による $x_0$ の信頼区間の考え方を説明せよ。また、この方法で信頼区間が有界にならないのはどのような場合か述べよ。
modelAnswer: |
  **[1]** 検量線を逆に解いて

  $$\hat{x}_0 = \frac{\bar{y}_0 - \hat{\beta}_0}{\hat{\beta}_1} = \frac{13.40 - 0.40}{2.00} = 6.50$$

  **[2]** $\hat{x}_0 = g(\bar{y}_0, \hat{\beta}_0, \hat{\beta}_1)$ と見る。$\hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x}$ を代入すると

  $$\hat{x}_0 = \bar{x} + \frac{\bar{y}_0 - \bar{y}}{\hat{\beta}_1}$$

  ここで $\bar{y}_0$、$\bar{y}$、$\hat{\beta}_1$ は互いに独立で、$V[\bar{y}_0] = \sigma^2/m$、$V[\bar{y}] = \sigma^2/n$、$V[\hat{\beta}_1] = \sigma^2/S_{xx}$。真値のまわりで 1 次近似すると、$\bar{y}_0 - \bar{y} \approx \beta_1(x_0 - \bar{x})$ より

  $$\hat{x}_0 - x_0 \approx \frac{(\bar{y}_0 - E\bar{y}_0) - (\bar{y} - E\bar{y})}{\beta_1} - \frac{x_0 - \bar{x}}{\beta_1}(\hat{\beta}_1 - \beta_1)$$

  よって

  $$V[\hat{x}_0] \approx \frac{1}{\beta_1^2}\left\{\frac{\sigma^2}{m} + \frac{\sigma^2}{n} + (x_0 - \bar{x})^2\frac{\sigma^2}{S_{xx}}\right\} = \frac{\sigma^2}{\beta_1^2}\left\{\frac{1}{m} + \frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}\right\}$$

  推定値を代入すると

  $$\hat{V}[\hat{x}_0] = \frac{0.0400}{4.00}\left\{\frac{1}{3} + \frac{1}{6} + \frac{1.5^2}{70}\right\} = 0.0100 \times 0.5321 = 0.005321,\qquad \mathrm{SE} = 0.0729$$

  **[3]** $\sigma^2$ を自由度 4 の $s^2$ で推定しているので $t$ 分布の点を用いて

  $$6.50 \pm 2.776 \times 0.0729 = 6.50 \pm 0.20 \ \Rightarrow\ [6.30,\ 6.70]$$

  **[4]** $W = \bar{y}_0 - \hat{\beta}_0 - \hat{\beta}_1x_0$ は真の $x_0$ のもとで平均 0、分散 $\sigma^2\{1/m + 1/n + (x_0 - \bar{x})^2/S_{xx}\}$ の正規分布に従う。したがって

  $$T(x_0) = \frac{\bar{y}_0 - \hat{\beta}_0 - \hat{\beta}_1x_0}{s\sqrt{\dfrac{1}{m} + \dfrac{1}{n} + \dfrac{(x_0 - \bar{x})^2}{S_{xx}}}} \sim t(n - 2)$$

  が正確に成り立つ（近似ではない）。$|T(x_0)| \leq t_{0.025}(n - 2)$ を満たす $x_0$ の集合が 95% 信頼集合であり、これは $x_0$ の 2 次不等式を解いて得られる（本問では $[6.30,\ 6.70]$ でほぼ同じ）。

  2 次の係数は $\hat{\beta}_1^2 - t^2s^2/S_{xx}$ に比例するので、$g = t^2s^2/(\hat{\beta}_1^2S_{xx})$ とおくと、$g < 1$（傾きが 5% 水準で有意）なら有界な区間になる。$g \geq 1$、すなわち傾き $\beta_1 = 0$ の検定で帰無仮説を棄却できない場合は、信頼集合が有界にならない（実数全体や 2 つの半直線の和になる）。本問では $g = 2.776^2 \times 0.04/(4 \times 70) = 0.0011$ と非常に小さいので、デルタ法の区間とフィラーの区間はほとんど一致する。

検量線による逆推定（キャリブレーション）は、理工学の線形推測で頻出の題材です。推定量 $\hat{x}_0$ は推定値の比なので、分散はデルタ法で近似するか、フィラーの方法で正確な信頼区間を作ります。

### 解答の流れ

1. 検量線の式を $x$ について解く。
2. $\hat{\beta}_0$ を $\bar{y} - \hat{\beta}_1\bar{x}$ に書き換えると、互いに独立な 3 つの量 $\bar{y}_0$、$\bar{y}$、$\hat{\beta}_1$ の関数になり、分散の計算が簡単になる。
3. $\sigma^2$ を推定しているので、正規分布ではなく $t$ 分布の点を使う。
4. $x_0$ を含む $t$ 統計量を作り、それを $x_0$ について反転する。

### つまずきやすい点

- $\hat{\beta}_0$ と $\hat{\beta}_1$ は独立ではない（$\bar{x} \neq 0$ なら相関がある）ので、$V[\hat{\beta}_0]$ と $V[\hat{\beta}_1]$ を単純に足すと誤る。$\bar{y}$ と $\hat{\beta}_1$ は独立であることを使う。
- 分散の式の $1/m$ は未知試料の測定回数による項で、$m$ を増やすと小さくなるが、$1/n$ と $(x_0 - \bar{x})^2/S_{xx}$ は検量線の精度で決まり、$m$ を増やしても減らない。
- 未知試料の濃度が標準試料の範囲の中心 $\bar{x}$ から離れるほど精度は悪くなる。範囲外への外挿は避ける。

### ポイント

- フィラーの方法は、比 $\theta = a/b$ の信頼区間を「$a - \theta b$ の分布」を反転して作る一般的な方法で、半数致死量（LD50）や相対力価の推定にも用いられる。
