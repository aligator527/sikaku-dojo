  $X_1, \ldots, X_n\ (n \geq 2)$ は互いに独立に、確率密度関数

  $$f(x;\mu, \sigma) = \frac{1}{\sigma}\exp\left(-\frac{x - \mu}{\sigma}\right)\qquad (x \geq \mu)$$

  の 2 母数指数分布に従うとする（$\mu$ は位置母数、$\sigma > 0$ は尺度母数で、ともに未知）。$X_{(1)} = \min_i X_i$、$S = \sum_{i=1}^{n}(X_i - X_{(1)})$ とする。標準指数分布（$\mu = 0,\ \sigma = 1$）の順序統計量について、$D_k = (n - k + 1)(X_{(k)} - X_{(k-1)})\ (k = 1, \ldots, n,\ X_{(0)} = 0)$ が互いに独立に標準指数分布に従うことを用いてよい。以下の各問に答えよ。

  [1] $n(X_{(1)} - \mu)/\sigma$ が標準指数分布に従うことを示せ。

  [2] $2S/\sigma$ が自由度 $2n - 2$ のカイ二乗分布に従い、$X_{(1)}$ と独立であることを示せ。

  [3] $\mu$ についての枢軸量で、$F$ 分布に従うものを作れ。

  [4] $n = 10$、$x_{(1)} = 3.2$、$S = 18.0$ のとき、[3] を用いて $\mu$ の 95% 信頼区間を、$\mu \leq X_{(1)}$ であることを考慮した片側の形 $[L,\ X_{(1)}]$ で求めよ。自由度 $(2, 18)$ の $F$ 分布の上側 5% 点を $3.555$ とする。
modelAnswer: |
  **[1]** $Z_i = (X_i - \mu)/\sigma$ は標準指数分布に従い、$X_{(1)} = \mu + \sigma Z_{(1)}$。

  $$P\left(\frac{n(X_{(1)} - \mu)}{\sigma} > z\right) = P\left(Z_{(1)} > \frac{z}{n}\right) = \left(e^{-z/n}\right)^n = e^{-z}\qquad (z > 0)$$

  よって $n(X_{(1)} - \mu)/\sigma = nZ_{(1)} = D_1$ は標準指数分布に従う。

  **[2]** $X_i - X_{(1)} = \sigma(Z_i - Z_{(1)})$ なので $S/\sigma = \sum_i(Z_{(k)} - Z_{(1)})$（順序統計量で書き直した和）。$Z_{(k)} - Z_{(1)} = \sum_{j=2}^{k}D_j/(n - j + 1)$ を代入して和の順序を入れ替えると

  $$\frac{S}{\sigma} = \sum_{k=2}^{n}\sum_{j=2}^{k}\frac{D_j}{n - j + 1} = \sum_{j=2}^{n}\frac{(n - j + 1)D_j}{n - j + 1} = \sum_{j=2}^{n}D_j$$

  （$D_j$ を含む $k$ は $k = j, \ldots, n$ の $n - j + 1$ 個）。$D_2, \ldots, D_n$ は独立な標準指数分布、すなわち $2D_j \sim \chi^2(2)$ なので、再生性より $2S/\sigma \sim \chi^2(2n - 2)$。また $X_{(1)}$ は $D_1$ だけの関数で、$S$ は $D_2, \ldots, D_n$ の関数なので、両者は独立である。

  **[3]** [1] より $2n(X_{(1)} - \mu)/\sigma = 2D_1 \sim \chi^2(2)$ で、[2] の $2S/\sigma$ と独立。よって

  $$F = \frac{2n(X_{(1)} - \mu)/\sigma\,\big/\,2}{2S/\sigma\,\big/\,(2n - 2)} = \frac{n(n - 1)(X_{(1)} - \mu)}{S} \sim F(2,\ 2n - 2)$$

  は $\sigma$ を含まず、分布が母数によらない $\mu$ の枢軸量である。

  **[4]** $F \geq 0$（$\mu \leq X_{(1)}$）なので、$P(0 \leq F \leq F_{0.05}(2, 2n-2)) = 0.95$ を $\mu$ について解くと

  $$X_{(1)} - F_{0.05}(2,\ 2n - 2)\frac{S}{n(n - 1)} \leq \mu \leq X_{(1)}$$

  $n = 10$ では $n(n - 1) = 90$ で

  $$L = 3.2 - 3.555 \times \frac{18.0}{90} = 3.2 - 0.711 = 2.489$$

  よって 95% 信頼区間は $[2.489,\ 3.2]$。

2 母数指数分布は、位置母数の推定に順序統計量（最小値）が現れる非正則なモデルです。指数分布の順序統計量の間隔が独立になるというレーニの表現を使うと、正規分布の $t$ 統計量と同じように、尺度母数を消去した枢軸量（ここでは $F$ 分布）が作れます。

### 解答の流れ

1. 標準化 $Z_i = (X_i - \mu)/\sigma$ で、位置・尺度を取り除いた標準指数分布の問題に帰着させる。
2. $S$ を間隔 $D_j$ の和で表すと、$D_1$ を含まないので $X_{(1)}$ と独立になる。
3. 独立な $\chi^2(2)$ と $\chi^2(2n - 2)$ をそれぞれの自由度で割った比は $F(2,\ 2n - 2)$。
4. $X_{(1)} - \mu \geq 0$ なので、区間は上側だけを切った片側の形が自然である。

### つまずきやすい点

- [2] で $S$ を $\sum_{i=1}^{n}(X_i - X_{(1)})$ のまま $n$ 個の独立な和として扱い、$\chi^2(2n)$ とする誤り。$X_{(1)}$ を引くことで自由度が 2 減る。
- [3] で $\sigma$ を含んだまま区間を作ろうとする誤り。$\sigma$ が未知なので、比をとって消去する。
- [4] で両側の点（$F$ 分布の上側 2.5% 点と下側 2.5% 点）を使うと、$\mu \leq X_{(1)}$ という情報を生かせず、区間が不必要に広くなる。

### ポイント

- 最尤推定量は $\hat{\mu} = X_{(1)}$、$\hat{\sigma} = S/n$ で、$\sigma$ の不偏推定量は $S/(n - 1)$。$E[X_{(1)}] = \mu + \sigma/n$ なので、$\mu$ の不偏推定量は $X_{(1)} - S/\{n(n - 1)\}$。
- $F(2, m)$ の上側 $\alpha$ 点は $\dfrac{m}{2}\left(\alpha^{-2/m} - 1\right)$ と閉じた形で書ける（$m = 18,\ \alpha = 0.05$ で $3.555$）。
