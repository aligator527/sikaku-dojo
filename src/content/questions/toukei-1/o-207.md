  $X$ は二項分布 $\mathrm{Bin}(n, p)$ に従うとし、$\hat{p} = X/n$ とする。$0 < p_0 < 1$ を既知として、$H_0: p = p_0$ vs. $H_1: p \neq p_0$ を検定する。以下の各問に答えよ。

  [1] 対数尤度 $\ell(p)$、スコア関数 $U(p) = \ell'(p)$、フィッシャー情報量 $I(p)$ を求め、ワルド検定統計量 $W$、スコア検定統計量 $S$、尤度比検定統計量 $LR = 2\{\ell(\hat{p}) - \ell(p_0)\}$ を $n,\ \hat{p},\ p_0$ で表せ。ただし $W$ では情報量を $\hat{p}$ で、$S$ では $p_0$ で評価するものとする。

  [2] $n = 100,\ X = 62,\ p_0 = 0.5$ のとき、$W,\ S,\ LR$ の値を小数第 2 位まで求め、有意水準 5% で判定せよ。$\chi^2_{0.05}(1) = 3.841$、$\log 1.24 = 0.2151$、$\log 0.76 = -0.2744$ とする。

  [3] $H_0$ のもとで、$LR - W \xrightarrow{p} 0$ が成り立つことを、$\ell(p_0)$ の $\hat{p}$ のまわりのテイラー展開を用いて示せ。

  [4] 母数を対数オッズ $\psi = \log\{p/(1 - p)\}$ に変換して $H_0: \psi = \psi_0$ を検定するとき、3 つの統計量のうち値が変わるものはどれか。[2] のデータで、$\psi$ についてのワルド統計量の値を求めて確かめよ。$\log(0.62/0.38) = 0.4895$ とする。
modelAnswer: |
  **[1]** 定数を除いて

  $$\ell(p) = X\log p + (n - X)\log(1 - p),\qquad U(p) = \frac{X}{p} - \frac{n - X}{1 - p} = \frac{n(\hat{p} - p)}{p(1 - p)}$$

  $$I(p) = E\left[-\ell''(p)\right] = E\left[\frac{X}{p^2} + \frac{n - X}{(1 - p)^2}\right] = \frac{n}{p(1 - p)}$$

  最尤推定量は $\hat{p} = X/n$ なので

  $$W = (\hat{p} - p_0)^2 I(\hat{p}) = \frac{n(\hat{p} - p_0)^2}{\hat{p}(1 - \hat{p})},\qquad S = \frac{U(p_0)^2}{I(p_0)} = \frac{n(\hat{p} - p_0)^2}{p_0(1 - p_0)}$$

  $$LR = 2n\left[\hat{p}\log\frac{\hat{p}}{p_0} + (1 - \hat{p})\log\frac{1 - \hat{p}}{1 - p_0}\right]$$

  **[2]** $\hat{p} = 0.62$、$(\hat{p} - p_0)^2 = 0.0144$ より

  $$W = \frac{100 \times 0.0144}{0.62 \times 0.38} = \frac{1.44}{0.2356} = 6.11,\qquad S = \frac{1.44}{0.25} = 5.76$$

  $$LR = 2\left[62 \times 0.2151 + 38 \times (-0.2744)\right] = 2(13.336 - 10.427) = 5.82$$

  いずれも $3.841$ を超えるので、有意水準 5% で $H_0$ は棄却される。この例では $S < LR < W$ である。

  **[3]** $\ell'(\hat{p}) = 0$ なので、$\hat{p}$ と $p_0$ の間の点 $\tilde{p}$ を用いて

  $$\ell(p_0) = \ell(\hat{p}) + \frac{1}{2}\ell''(\tilde{p})(p_0 - \hat{p})^2$$

  よって $LR = -\ell''(\tilde{p})(\hat{p} - p_0)^2$。一方 $W = I(\hat{p})(\hat{p} - p_0)^2$ なので

  $$LR - W = \left\{\frac{-\ell''(\tilde{p})}{n} - \frac{I(\hat{p})}{n}\right\} \cdot n(\hat{p} - p_0)^2$$

  $H_0$ のもとで $\hat{p} \xrightarrow{p} p_0$、$\tilde{p} \xrightarrow{p} p_0$ であり、$-\ell''(p)/n = \hat{p}/p^2 + (1 - \hat{p})/(1 - p)^2$ と $I(p)/n = 1/\{p(1 - p)\}$ は連続なので、中括弧はともに $1/\{p_0(1 - p_0)\}$ に確率収束し、その差は $0$ に確率収束する。また中心極限定理より $n(\hat{p} - p_0)^2$ は分布収束する（確率有界）ので、積は $0$ に確率収束する。よって $LR - W \xrightarrow{p} 0$（同様に $S - W \xrightarrow{p} 0$）で、3 つとも漸近的に $\chi^2(1)$ に従う。

  **[4]** 尤度比統計量は最大尤度の比で決まり、スコア統計量も $U^2/I$ が母数変換のヤコビアンで打ち消し合うので、どちらも変換で値が変わらない。値が変わるのはワルド統計量である。

  $\psi$ のフィッシャー情報量は $I_\psi(\psi) = I(p)\left(\dfrac{dp}{d\psi}\right)^2 = \dfrac{n}{p(1 - p)}\{p(1 - p)\}^2 = np(1 - p)$。$\hat{\psi} = 0.4895$、$\psi_0 = 0$ より

  $$W_\psi = (\hat{\psi} - \psi_0)^2\, n\hat{p}(1 - \hat{p}) = 0.4895^2 \times 23.56 = 5.65$$

  で、$p$ についての $W = 6.11$ と異なる。

ワルド検定・スコア検定・尤度比検定は「漸近的に同等な 3 つの検定」としてまとめて問われます。対数尤度の曲線を、最尤推定値での放物線近似（ワルド）、帰無仮説の値での傾き（スコア）、2 点の高さの差（尤度比）で評価していると理解すると、性質の違いを整理しやすくなります。

### 解答の流れ

1. スコア関数とフィッシャー情報量を求め、$W = (\hat{p} - p_0)^2 I(\hat{p})$、$S = U(p_0)^2/I(p_0)$、$LR = 2\{\ell(\hat{p}) - \ell(p_0)\}$ に代入する。
2. 数値を代入する。$S$ は帰無仮説の値で分散を評価するので、最尤推定値を求めなくても計算できる。
3. $\ell'(\hat{p}) = 0$ を使って最尤推定値のまわりで 2 次まで展開すると、$LR$ はワルド型の 2 次形式に近づく。
4. 母数変換に対する不変性を比較する。

### つまずきやすい点

- $S$ の分母を $\hat{p}(1 - \hat{p})$ にしてしまう（それはワルド統計量）。スコア検定では帰無仮説のもとでの情報量を使います。
- 対数尤度の定数項 $\log\binom{n}{X}$ は、差をとると消えるので気にしなくてかまいません。
- [3] で「$\hat{p} \to p_0$ だから差は 0」とだけ書くのは不十分です。$n(\hat{p} - p_0)^2 = O_p(1)$ であることと、係数の差が $o_p(1)$ であることの両方が必要です。

### ポイント

- スコア統計量 $S$ は、2 群比較ならピアソンのカイ二乗統計量に一致するなど、よく知られた検定の多くがスコア検定として導けます。
- ワルド検定は母数の取り方に依存し、$\hat{p}$ が 0 や 1 に近いと分散の推定が不安定になります。信頼区間を作る場合も、ワルド型の区間 $\hat{p} \pm 1.96\sqrt{\hat{p}(1 - \hat{p})/n}$ より、スコア検定を反転したウィルソンの区間のほうが被覆確率が名目値に近くなります。
