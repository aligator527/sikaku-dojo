stem: |
  一元配置モデル

  $$Y_{ij} = \mu + \alpha_i + \varepsilon_{ij}\qquad (i = 1, \ldots, a;\ j = 1, \ldots, n_i),\qquad \sum_{i=1}^{a}n_i\alpha_i = 0$$

  を考える。$\varepsilon_{ij}$ は互いに独立に $N(0, \sigma^2)$ に従う。$N = \sum_i n_i$、群平均を $\bar{Y}_{i\cdot}$、全平均を $\bar{Y}_{\cdot\cdot}$ とし、

  $$S_T = \sum_{i,j}(Y_{ij} - \bar{Y}_{\cdot\cdot})^2,\quad S_A = \sum_{i}n_i(\bar{Y}_{i\cdot} - \bar{Y}_{\cdot\cdot})^2,\quad S_E = \sum_{i,j}(Y_{ij} - \bar{Y}_{i\cdot})^2$$

  とおく。以下の各問に答えよ。

  [1] $S_T = S_A + S_E$ が成り立つことを示せ。

  [2] $E[S_E] = (N - a)\sigma^2$、$E[S_A] = (a - 1)\sigma^2 + \sum_i n_i\alpha_i^2$ を示せ。

  [3] $H_0: \alpha_1 = \cdots = \alpha_a = 0$ のもとで、$F = \dfrac{S_A/(a - 1)}{S_E/(N - a)}$ が自由度 $(a - 1, N - a)$ の $F$ 分布に従う理由を説明せよ。また [2] の結果から、$F$ が大きいときに $H_0$ を棄却する理由を述べよ。

  [4] $a = 2$ のとき、$F$ が等分散を仮定した 2 標本 $t$ 統計量の 2 乗に等しいことを示せ。
modelAnswer: |
  **[1]** $Y_{ij} - \bar{Y}_{\cdot\cdot} = (Y_{ij} - \bar{Y}_{i\cdot}) + (\bar{Y}_{i\cdot} - \bar{Y}_{\cdot\cdot})$ を 2 乗して和をとると、交差項は

  $$2\sum_{i}(\bar{Y}_{i\cdot} - \bar{Y}_{\cdot\cdot})\sum_{j}(Y_{ij} - \bar{Y}_{i\cdot}) = 0$$

  （各群内で偏差の和が 0）となるので、$S_T = S_E + S_A$。

  **[2]** 群 $i$ の不偏分散は $\sigma^2$ の不偏推定量なので $E\left[\sum_j(Y_{ij} - \bar{Y}_{i\cdot})^2\right] = (n_i - 1)\sigma^2$。$i$ について和をとって $E[S_E] = (N - a)\sigma^2$。

  $\bar{\varepsilon}_{i\cdot},\ \bar{\varepsilon}_{\cdot\cdot}$ を誤差の群平均・全平均とすると、$\sum n_i\alpha_i = 0$ より $\bar{Y}_{i\cdot} - \bar{Y}_{\cdot\cdot} = \alpha_i + (\bar{\varepsilon}_{i\cdot} - \bar{\varepsilon}_{\cdot\cdot})$。$E[\bar{\varepsilon}_{i\cdot} - \bar{\varepsilon}_{\cdot\cdot}] = 0$ で、$\mathrm{Cov}(\bar{\varepsilon}_{i\cdot}, \bar{\varepsilon}_{\cdot\cdot}) = \dfrac{n_i}{N}\cdot\dfrac{\sigma^2}{n_i} = \dfrac{\sigma^2}{N}$ より

  $$V[\bar{\varepsilon}_{i\cdot} - \bar{\varepsilon}_{\cdot\cdot}] = \frac{\sigma^2}{n_i} - \frac{2\sigma^2}{N} + \frac{\sigma^2}{N} = \sigma^2\left(\frac{1}{n_i} - \frac{1}{N}\right)$$

  よって

  $$E[S_A] = \sum_i n_i\left\{\alpha_i^2 + \sigma^2\left(\frac{1}{n_i} - \frac{1}{N}\right)\right\} = \sum_i n_i\alpha_i^2 + (a - 1)\sigma^2$$

  **[3]** 群内の偏差 $(Y_{ij} - \bar{Y}_{i\cdot})_j$ と群平均 $\bar{Y}_{i\cdot}$ は、正規標本の標本平均と偏差なので独立である。群どうしも独立だから、$S_E$（偏差だけの関数）と $S_A$（群平均だけの関数）は独立。$S_E/\sigma^2 = \sum_i\{\sum_j(Y_{ij} - \bar{Y}_{i\cdot})^2/\sigma^2\}$ は独立な $\chi^2(n_i - 1)$ の和なので $\chi^2(N - a)$。$H_0$ のもとでは $Y_{ij}$ はすべて $N(\mu, \sigma^2)$ に従うので、$S_T/\sigma^2 \sim \chi^2(N - 1)$ であり、$S_T = S_A + S_E$ と独立性（コクランの定理、あるいはモーメント母関数の比較）から $S_A/\sigma^2 \sim \chi^2(a - 1)$。したがって

  $$F = \frac{\{S_A/\sigma^2\}/(a - 1)}{\{S_E/\sigma^2\}/(N - a)} \sim F(a - 1,\ N - a)$$

  [2] より $E[S_E/(N - a)] = \sigma^2$ は $H_0$ の真偽によらないが、$E[S_A/(a - 1)] = \sigma^2 + \sum n_i\alpha_i^2/(a - 1)$ は $H_0$ が偽のとき $\sigma^2$ より大きい。よって $F$ が大きいことは $H_0$ に反する証拠であり、上側の棄却域 $F > F_{\alpha}(a - 1, N - a)$ を用いる。

  **[4]** $a = 2$ では $\bar{Y}_{\cdot\cdot} = (n_1\bar{Y}_{1\cdot} + n_2\bar{Y}_{2\cdot})/N$ より $\bar{Y}_{1\cdot} - \bar{Y}_{\cdot\cdot} = \dfrac{n_2}{N}(\bar{Y}_{1\cdot} - \bar{Y}_{2\cdot})$、$\bar{Y}_{2\cdot} - \bar{Y}_{\cdot\cdot} = -\dfrac{n_1}{N}(\bar{Y}_{1\cdot} - \bar{Y}_{2\cdot})$ なので

  $$S_A = \frac{n_1n_2^2 + n_2n_1^2}{N^2}(\bar{Y}_{1\cdot} - \bar{Y}_{2\cdot})^2 = \frac{(\bar{Y}_{1\cdot} - \bar{Y}_{2\cdot})^2}{1/n_1 + 1/n_2}$$

  $S_E/(N - 2) = s_p^2$（プールした分散）だから

  $$F = \frac{(\bar{Y}_{1\cdot} - \bar{Y}_{2\cdot})^2}{s_p^2(1/n_1 + 1/n_2)} = t^2$$

  自由度も $F(1, N - 2)$ と $t(N - 2)$ で対応し、$F$ 検定と両側 $t$ 検定は同じ結論を与える。

  - '[2] $E[S_E]$ を群ごとの不偏分散から導き、$E[S_A]$ を $\bar{\varepsilon}_{i\cdot} - \bar{\varepsilon}_{\cdot\cdot}$ の分散 $\sigma^2(1/n_i - 1/N)$ を用いて導いている'
  - '[3] $S_A$ と $S_E$ の独立性、それぞれのカイ二乗分布と自由度を説明し、期待平均平方の違いから上側棄却の理由を述べている'
  - '[4] $S_A = (\bar{Y}_{1\cdot} - \bar{Y}_{2\cdot})^2/(1/n_1 + 1/n_2)$ を示し、$F = t^2$ を導いている'
---
一元配置分散分析の数理の基本は、平方和の分解・期待平均平方・$F$ 分布の導出の 3 点です。期待平均平方を正しく計算できると、どの平均平方を分母にとれば帰無仮説のもとで比の期待値が 1 に近くなるかが分かり、二元配置や変量模型の検定にもそのまま応用できます。

### 解答の流れ

1. 偏差を「群内」と「群間」に分け、交差項が消えることを示す。
2. $S_E$ は群ごとの不偏分散から、$S_A$ は群平均の偏差の期待値と分散から期待値を計算する。
3. 正規標本で標本平均と偏差が独立であることから $S_A$ と $S_E$ の独立性を導き、カイ二乗分布の比として $F$ 分布を得る。
4. $a = 2$ で $S_A$ を書き直し、$t^2$ に一致させる。

### つまずきやすい点

- $E[S_A]$ の計算で、$\bar{\varepsilon}_{i\cdot}$ と $\bar{\varepsilon}_{\cdot\cdot}$ が独立でない（$\bar{\varepsilon}_{\cdot\cdot}$ は $\bar{\varepsilon}_{i\cdot}$ を含む）ことを見落とすと、自由度が $a$ になってしまいます。
- 制約 $\sum n_i\alpha_i = 0$（重み付きの和）を使っているので、$E[S_A]$ の非心部分は $\sum n_i\alpha_i^2$ です。制約を $\sum\alpha_i = 0$ にした場合は $\sum n_i(\alpha_i - \bar{\alpha}_w)^2$（$\bar{\alpha}_w$ は重み付き平均）になります。

### ポイント

- $H_0$ が偽のとき、$S_A/\sigma^2$ は非心度 $\lambda = \sum n_i\alpha_i^2/\sigma^2$ の非心カイ二乗分布に従い、検出力は非心 $F$ 分布で計算できます。
- 分散分析表の「期待平均平方」の列は、検定の分母の選び方と分散成分の推定（変量模型）の両方の基礎になります。
