事後分布は $Ga(\alpha + T,\ \beta + n)$ です。事後期待損失 $E\left[\dfrac{(\lambda - a)^2}{\lambda}\,\middle|\,\boldsymbol{x}\right] = E[\lambda \mid \boldsymbol{x}] - 2a + a^2E[1/\lambda \mid \boldsymbol{x}]$ は $a$ の 2 次関数で、$a = 1/E[1/\lambda \mid \boldsymbol{x}]$ で最小になります。$Ga(A, B)$ では $E[1/\lambda] = B/(A - 1)$ なので、ベイズ推定量は $(\alpha + T - 1)/(\beta + n)$ です。

### 計算

$A = \alpha + T,\ B = \beta + n$ とおくと、$A > 1$ のとき

$$E\left[\frac{1}{\lambda}\,\middle|\,\boldsymbol{x}\right] = \int_0^\infty\frac{1}{\lambda}\cdot\frac{B^A\lambda^{A-1}e^{-B\lambda}}{\Gamma(A)}\,d\lambda = \frac{B^A}{\Gamma(A)}\cdot\frac{\Gamma(A - 1)}{B^{A-1}} = \frac{B}{A - 1}$$

$\dfrac{d}{da}\left(E[\lambda] - 2a + a^2E[1/\lambda]\right) = -2 + 2aE[1/\lambda] = 0$ より

$$a^* = \frac{1}{E[1/\lambda \mid \boldsymbol{x}]} = \frac{A - 1}{B} = \frac{\alpha + T - 1}{\beta + n}$$

### 各選択肢の検討

- $(\alpha + T)/(\beta + n)$：事後平均。重みのない 2 乗誤差損失 $(\lambda - a)^2$ のベイズ推定量である。
- $(\alpha + T + 1)/(\beta + n)$：$E[\lambda^2]/E[\lambda]$ で、損失 $\lambda(\lambda - a)^2$（重みが $1/\lambda$ でなく $\lambda$）のベイズ推定量にあたる。重みの向きを取り違えている。
- $(\alpha + T - 1)/(\beta + n)$：正しい。
- $T/n$：最尤推定量。事前分布の情報を使っていない（$\alpha = 1,\ \beta \to 0$ の極限でベイズ推定量はこれに近づく）。
- 事後中央値：絶対誤差損失 $|\lambda - a|$ のベイズ推定量である。

### ポイント

- 重み付き 2 乗誤差損失 $w(\lambda)(\lambda - a)^2$ のベイズ推定量は $E[w(\lambda)\lambda \mid \boldsymbol{x}]/E[w(\lambda) \mid \boldsymbol{x}]$。$w = 1/\lambda$ では $1/E[1/\lambda \mid \boldsymbol{x}]$ になる。
- この推定量はたまたま事後分布の最頻値 $(A - 1)/B$ に一致する。損失 $(\lambda - a)^2/\lambda$ は、$\lambda$ が小さいところの誤差を重く評価する（ポアソン分布の分散 $\lambda$ で誤差を基準化した損失）。
