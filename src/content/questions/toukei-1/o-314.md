  $$\begin{pmatrix} R_{11} & R_{12} \\ R_{21} & R_{22} \end{pmatrix},\qquad R_{11} = V[\boldsymbol{X}],\ R_{22} = V[\boldsymbol{Y}],\ R_{12} = \mathrm{Cov}(\boldsymbol{X}, \boldsymbol{Y}) = R_{21}^\top$$

  **[1]** $L = \boldsymbol{a}^\top R_{12}\boldsymbol{b} - \frac{\lambda}{2}(\boldsymbol{a}^\top R_{11}\boldsymbol{a} - 1) - \frac{\mu}{2}(\boldsymbol{b}^\top R_{22}\boldsymbol{b} - 1)$ を微分して 0 とおくと

  $$R_{12}\boldsymbol{b} = \lambda R_{11}\boldsymbol{a},\qquad R_{21}\boldsymbol{a} = \mu R_{22}\boldsymbol{b}$$

  第 1 式に左から $\boldsymbol{a}^\top$、第 2 式に $\boldsymbol{b}^\top$ を掛けると、制約より $\lambda = \mu = \boldsymbol{a}^\top R_{12}\boldsymbol{b} = \rho$。第 2 式から $\boldsymbol{b} = \rho^{-1}R_{22}^{-1}R_{21}\boldsymbol{a}$ を第 1 式に代入すると

  $$R_{12}R_{22}^{-1}R_{21}\boldsymbol{a} = \rho^2R_{11}\boldsymbol{a} \iff R_{11}^{-1}R_{12}R_{22}^{-1}R_{21}\boldsymbol{a} = \rho^2\boldsymbol{a}$$

  停留点での目的関数の値は $\rho$ なので、最大値は最大固有値の平方根である。2 番目以降の固有値は、前の正準変量と無相関という制約のもとでの最大値（第 2 正準相関係数など）を与える。

  （確認：$\mathrm{Cov}(X_1 + X_2,\ Y_1 + Y_2) = 0.5 + 0.4 + 0.4 + 0.5 = 1.8$、$1.8/3 = 0.6$。）第 2 正準変量は $U_2 = X_1 - X_2$、$V_2 = Y_1 - Y_2$（分散 1、共分散 $0.5 - 0.4 - 0.4 + 0.5 = 0.2$）。

正準相関分析の固有値問題の導出、重相関係数との関係、具体的な相関行列での計算、正準相関の個数の検定を一通り扱う問題です。

### 解答の流れ

1. 2 つの分散制約に対するラグランジュ乗数は、どちらも相関係数 $\rho$ に等しくなる。これを使って $\boldsymbol{b}$ を消去すると固有値問題になる。
2. $q = 1$ では行列の階数が 1 になり、固有値は 2 次形式 $\boldsymbol{r}^\top R_{11}^{-1}\boldsymbol{r}$ で書ける。
3. 対称な構造をもつ相関行列では、和と差の方向が共通の固有ベクトルになる。和の方向では相関が $0.9/1.5$、差の方向では $0.1/0.5$。
4. バートレットの近似で、大きい方から順に正準相関が 0 かどうかを検定する。

### つまずきやすい点

- 第 2 正準相関 $0.2$ を、和の方向と差の方向を混同して $0.1$（$R_{12}$ の固有値そのもの）とする誤り。差 $X_1 - X_2$ の分散は $2 - 2 \times 0.5 = 1$ で、正規化が必要である。
- 正準相関は、元の変数の各組の相関（ここでは最大 0.5）よりも必ず大きいか等しい。$\boldsymbol{a},\ \boldsymbol{b}$ に単位ベクトルを選べば個々の相関が得られるからである。

### ポイント

- 正準相関係数は、$\boldsymbol{X}$ と $\boldsymbol{Y}$ のそれぞれに正則な線形変換を施しても変わらない。
- 正準相関係数の 2 乗は、$R_{11}^{-1/2}R_{12}R_{22}^{-1/2}$ の特異値の 2 乗としても求められる。
