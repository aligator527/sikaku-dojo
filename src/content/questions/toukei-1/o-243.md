  [1] $A, B, C$ の 8 通りの組合せに対して $D$ の水準を定め、実施する 8 個の処理の組合せを列挙せよ。

  [4] 生成元を $D = AB$ とした $2^{4-1}$ 型計画と比べ、[1] の計画が優れている点を述べよ。
modelAnswer: |
  **[1]** $D$ の水準は $A, B, C$ の水準の積で定める。

  | $A$ | $B$ | $C$ | $D = ABC$ | 処理 |
  | --- | --- | --- | --- | --- |
  | $-$ | $-$ | $-$ | $-$ | $(1)$ |
  | $+$ | $-$ | $-$ | $+$ | $ad$ |
  | $-$ | $+$ | $-$ | $+$ | $bd$ |
  | $+$ | $+$ | $-$ | $-$ | $ab$ |
  | $-$ | $-$ | $+$ | $+$ | $cd$ |
  | $+$ | $-$ | $+$ | $-$ | $ac$ |
  | $-$ | $+$ | $+$ | $-$ | $bc$ |
  | $+$ | $+$ | $+$ | $+$ | $abcd$ |

  **[2]** $D = ABC$ の両辺に $D$ を掛けると $D^2 = I$ より、定義関係は $I = ABCD$。各効果に $ABCD$ を掛けて（2 乗は $I$）別名を得る。

  - 主効果：$A = BCD$、$B = ACD$、$C = ABD$、$D = ABC$
  - 2 因子交互作用：$AB = CD$、$AC = BD$、$AD = BC$

  定義関係の語の最小の長さが 4 なので分解能は IV である。主効果はほかの主効果とも 2 因子交互作用とも交絡せず（3 因子交互作用とだけ交絡する）、2 因子交互作用どうしは互いに交絡する。3 因子以上の交互作用が無視できれば、主効果は偏りなく推定できる。

  **[3]** $A$ が高水準の処理は $ad, ab, ac, abcd$ で応答の和は $31 + 27 + 30 + 37 = 125$、低水準は $(1), bd, cd, bc$ で $20 + 22 + 25 + 24 = 91$。

  $$\hat{A} = \frac{125}{4} - \frac{91}{4} = \frac{34}{4} = 8.5$$

  $AD$ の符号は $A$ と $D$ の符号の積で、$+$ となるのは $(1), ad, bc, abcd$（$A$ と $D$ が同じ水準）、$-$ となるのは $bd, ab, cd, ac$。

  $$\widehat{AD + BC} = \frac{20 + 31 + 24 + 37}{4} - \frac{22 + 27 + 25 + 30}{4} = \frac{112 - 104}{4} = 2.0$$

  （$BC$ の符号も同じ列になることから、この対比は $AD$ と $BC$ の和を推定している。）

  **[4]** 生成元 $D = AB$ では定義関係が $I = ABD$（長さ 3）となり、分解能は III である。このとき $D = AB$、$A = BD$、$B = AD$ のように主効果が 2 因子交互作用と交絡するため、2 因子交互作用が存在すると主効果の推定に偏りが生じる。[1] の計画（分解能 IV）では主効果は 3 因子交互作用とだけ交絡するので、通常無視できると考えられる高次の交互作用を除けば、主効果を偏りなく推定できる。$2^{4-1}$ 型では、$D = ABC$ とする計画が最大の分解能をもつ。

一部実施要因計画は、高次の交互作用が無視できるという前提（効果の希薄性）のもとで、実験回数を減らして主効果と低次の交互作用を推定する計画です。どの効果がどの効果と区別できなくなるか（別名関係）は定義関係から機械的に求まり、その最短の語の長さが分解能になります。

### 解答の流れ

1. 生成元 $D = ABC$ に従って、$2^3$ 型の 8 行に $D$ の列を加える。
2. 定義関係 $I = ABCD$ を各効果に掛けて別名を求める（文字の 2 乗は消える）。
3. 効果の推定値は「符号 $+$ の応答の平均 − 符号 $-$ の応答の平均」。交互作用の符号は主効果の符号の積。
4. 分解能を比較する。

### つまずきやすい点

- 一部実施では、推定値は 1 つの効果ではなく別名の和（ここでは $A + BCD$、$AD + BC$）を推定しています。$BC$ が無視できるという根拠がなければ、$2.0$ を $AD$ の推定値と断定できません。
- 処理の組合せの表記で、$D$ を高水準にした行に $d$ を付け忘れる誤り。[1] では $ad,\ bd,\ cd,\ abcd$ に $d$ が付きます。
- 効果の定義（平均の差）では $4$ で割ります。$8$ で割ると回帰係数（効果の半分）になります。

### ポイント

- この計画のほかの効果の推定値は $\hat{B} = 1.0$、$\hat{C} = 4.0$、$\hat{D} = 3.5$、$\widehat{AB + CD} = \widehat{AC + BD} = 0.5$ です。$AD + BC$ が残りの交互作用より大きいので、残りの半分（定義関係 $I = -ABCD$ の 8 回）を追加で実施して完全な $2^4$ 型とし、$AD$ と $BC$ を分離することが考えられます。
- 分解能 III の計画は主効果のスクリーニングに、分解能 IV は主効果の偏りのない推定に、分解能 V 以上は 2 因子交互作用の推定にも使えます。
