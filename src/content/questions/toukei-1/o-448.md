stem: |
  ある疾患の診断に用いる検査 1 は感度 0.80、特異度 0.90、検査 2 は感度 0.90、特異度 0.85 である。以下の各問に答えよ。

  [1] 検査 1 の陽性尤度比 $LR_{+}$ と陰性尤度比 $LR_{-}$ を求め、それぞれの意味を説明せよ。

  [2] 検査前確率（有病率）が 0.10 の患者に検査 1 を行ったとき、陽性の場合と陰性の場合の検査後確率を、オッズと尤度比を用いて求めよ。

  [3] 疾患の有無を条件として 2 つの検査の結果が独立であると仮定する。「両方とも陽性なら陽性」とする直列検査と、「どちらか一方でも陽性なら陽性」とする並列検査について、それぞれの感度と特異度を求めよ。さらに、検査前確率 0.10 のとき直列検査の陽性的中率を求めよ。

  [4] [3] の「条件付き独立」の仮定が成り立たないのはどのような場合か、また、その場合に直列検査の感度・特異度の計算結果がどちらの方向にずれるかを述べよ。
modelAnswer: |
  **[1]**

  $$LR_{+} = \frac{\text{感度}}{1 - \text{特異度}} = \frac{0.80}{0.10} = 8.0,\qquad LR_{-} = \frac{1 - \text{感度}}{\text{特異度}} = \frac{0.20}{0.90} = 0.222$$

  $LR_{+}$ は「陽性という結果が、疾患のある人では疾患のない人の何倍起こりやすいか」を表し、大きいほど陽性結果が診断の確定に役立つ。$LR_{-}$ は陰性結果の起こりやすさの比で、小さいほど陰性結果が疾患の除外に役立つ。尤度比は感度・特異度だけで決まり、有病率によらない。

  **[2]** ベイズの定理をオッズで書くと「検査後オッズ = 検査前オッズ × 尤度比」。検査前オッズは $0.10/0.90 = 1/9$ なので

  - 陽性：検査後オッズ $= \dfrac{1}{9} \times 8 = \dfrac{8}{9}$、検査後確率 $= \dfrac{8/9}{1 + 8/9} = \dfrac{8}{17} = 0.471$
  - 陰性：検査後オッズ $= \dfrac{1}{9} \times \dfrac{2}{9} = \dfrac{2}{81}$、検査後確率 $= \dfrac{2/81}{1 + 2/81} = \dfrac{2}{83} = 0.024$

  **[3]** 条件付き独立のもとで

  - 直列検査：感度 $= 0.80 \times 0.90 = 0.72$、特異度 $= 1 - (1 - 0.90)(1 - 0.85) = 1 - 0.015 = 0.985$
  - 並列検査：感度 $= 1 - (1 - 0.80)(1 - 0.90) = 1 - 0.02 = 0.98$、特異度 $= 0.90 \times 0.85 = 0.765$

  直列検査の陽性的中率は

  $$\frac{0.72 \times 0.10}{0.72 \times 0.10 + 0.015 \times 0.90} = \frac{0.072}{0.072 + 0.0135} = \frac{0.072}{0.0855} = 0.842$$

  直列検査は特異度を高めて確定診断に、並列検査は感度を高めて見逃しの防止（除外診断）に向く。

  **[4]** 2 つの検査が同じ生物学的な現象（同じ抗原、同じ画像所見など）を測っている場合や、病期・重症度によって両方の検査が同時に陽性になりやすい場合には、疾患の有無を条件としても結果が正の相関をもち、条件付き独立は成り立たない。

  正の相関があると、疾患のある人で 2 つの検査が同時に陽性になる確率は積 $0.72$ より大きく、疾患のない人で同時に陽性（偽陽性）になる確率も積 $0.015$ より大きくなる。したがって、独立を仮定した計算は、直列検査の感度を**過小**に、特異度を**過大**に評価する（並列検査では逆に、感度を過大、特異度を過小に評価する）。

診断検査の評価では、感度・特異度という検査固有の性質と、有病率によって変わる的中率を区別し、尤度比を使って検査前確率から検査後確率を求める流れを理解することが大切です。

### 解答の流れ

1. 尤度比の定義に代入する。
2. 確率をオッズに直してから尤度比を掛け、確率に戻す。
3. 直列検査は「疾患ありで両方陽性」「疾患なしでどちらか陰性」、並列検査は「疾患ありでどちらか陽性」「疾患なしで両方陰性」の確率を、条件付き独立のもとで積として計算する。
4. 条件付きの相関が積の計算にどう影響するかを考える。

### つまずきやすい点

- 尤度比をそのまま確率に掛けて「$0.10 \times 8 = 0.80$」としない。尤度比が掛かるのはオッズである。
- 直列検査の特異度は「両方陰性」ではなく「少なくとも一方が陰性」の確率。

### ポイント

- 検査を順に行う場合、1 回目の検査後確率が 2 回目の検査前確率になる。条件付き独立なら、尤度比を掛け合わせればよい（直列検査で両方陽性の尤度比は $8.0 \times 6.0 = 48$）。
- 感度・特異度も、対象集団の重症度の分布によって変わることがある（スペクトラム・バイアス）。
