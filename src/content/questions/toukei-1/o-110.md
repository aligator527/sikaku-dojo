modelAnswer: |
  **[1]** $X = x$ のもとで $Y = \rho x + \sqrt{1 - \rho^2}\,Z$ であり、$Z$ は $X$ と独立に $N(0, 1)$ に従うので

  $$Y \mid X = x \ \sim\ N\left(\rho x,\ 1 - \rho^2\right)$$

  **[2]** [1] より $E[Y^2 \mid X] = V[Y \mid X] + E[Y \mid X]^2 = 1 - \rho^2 + \rho^2X^2$。標準正規分布の 4 次モーメント $E[X^4] = 3$ を用いて

  $$E[X^2Y^2] = E\big[X^2E[Y^2 \mid X]\big] = (1 - \rho^2)E[X^2] + \rho^2E[X^4] = 1 - \rho^2 + 3\rho^2 = 1 + 2\rho^2$$

  $E[X^2] = E[Y^2] = 1$ なので $\mathrm{Cov}(X^2, Y^2) = 1 + 2\rho^2 - 1 = 2\rho^2$（相関係数は $\rho^2$）。

  **[3]** $X, Z$ は独立な標準正規分布に従うので、同時密度 $\frac{1}{2\pi}e^{-(x^2+z^2)/2}$ を極座標に変換すると（ヤコビアン $r$）、$R$ と $\Theta$ は独立で $\Theta \sim U(-\pi,\ \pi)$ となる。

  $\varphi = \arcsin\rho\ (-\pi/2 < \varphi < \pi/2)$ とおくと $\rho = \sin\varphi,\ \sqrt{1 - \rho^2} = \cos\varphi$ なので

  $$Y = R(\sin\varphi\cos\Theta + \cos\varphi\sin\Theta) = R\sin(\Theta + \varphi)$$

  $R > 0$ なので（確率 1）

  - $X > 0 \iff \cos\Theta > 0 \iff -\pi/2 < \Theta < \pi/2$
  - $-\pi/2 < \Theta < \pi/2$ のとき $\Theta + \varphi \in (-\pi,\ \pi)$ なので、$Y > 0 \iff \sin(\Theta + \varphi) > 0 \iff 0 < \Theta + \varphi < \pi \iff -\varphi < \Theta < \pi - \varphi$

  $-\pi/2 < -\varphi$ かつ $\pi/2 < \pi - \varphi$ なので、$X > 0$ かつ $Y > 0$ となる範囲は $-\varphi < \Theta < \pi/2$、長さ $\pi/2 + \varphi$。$\Theta$ は一様分布なので

  $$P(X > 0,\ Y > 0) = \frac{\pi/2 + \varphi}{2\pi} = \frac{1}{4} + \frac{1}{2\pi}\arcsin\rho$$

  $$P(XY > 0) = 2\left(\frac{1}{4} + \frac{\pi/6}{2\pi}\right) = 2\left(\frac{1}{4} + \frac{1}{12}\right) = \frac{2}{3}$$

2 変量正規分布の象限確率 $\frac{1}{4} + \frac{1}{2\pi}\arcsin\rho$ は、ケンドールの順位相関係数と相関係数の関係などで現れる重要な公式です。独立な標準正規変数への分解と極座標変換（$\Theta$ が一様になること）を組み合わせて導きます。

### 解答の流れ

1. $Y = \rho X + \sqrt{1 - \rho^2}Z$ の表現で、条件付き分布も高次モーメントも計算できる。
2. $E[X^2Y^2]$ は、$X$ で条件付けて $E[Y^2 \mid X]$ を代入する（全期待値の公式）。
3. 象限確率は、独立な 2 つの標準正規変数の偏角が一様分布になることを使って、角度の長さの比に帰着させる。

### つまずきやすい点

- [2] で「$X^2$ と $Y^2$ はそれぞれ $\chi^2(1)$ なので $E[X^2Y^2] = 1$」とする誤り。$X$ と $Y$ は相関しているので積の期待値は積にならない。
- [3] で角度の範囲を $(0, 2\pi)$ と $(-\pi, \pi)$ で混同し、共通部分を取り違えやすい。$\rho = 0$ のとき $1/4$、$\rho \to 1$ のとき $1/2$ になることで検算できる。

### ポイント

- 符号が一致する確率は $\frac{1}{2} + \frac{1}{\pi}\arcsin\rho$ なので、ケンドールの $\tau$（一致確率 − 不一致確率）は 2 変量正規分布のもとで $\tau = \frac{2}{\pi}\arcsin\rho$ となる。$\rho = 1/2$ では $\tau = 1/3$。
- $\mathrm{Cov}(X^2, Y^2) = 2\rho^2$ は、正規分布のイッサーリスの定理 $E[X^2Y^2] = E[X^2]E[Y^2] + 2E[XY]^2$ の特別な場合である。
