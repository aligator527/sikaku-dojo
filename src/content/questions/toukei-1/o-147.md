  $X_1, \ldots, X_n$ は互いに独立に正規分布 $N(\mu, \sigma^2)$（$\mu > 0,\ \sigma^2 > 0$ はともに未知）に従うとする。変動係数 $\gamma = \sigma/\mu$ を推定したい。以下の各問に答えよ。

  [1] $(\mu, \sigma^2)$ の最尤推定量 $(\hat{\mu}, \hat{\sigma}^2)$ と、1 観測あたりのフィッシャー情報行列 $I(\mu, \sigma^2)$ を求めよ。

  [2] $\gamma$ の最尤推定量 $\hat{\gamma}$ を求め、多変量のデルタ法を用いて $\sqrt{n}(\hat{\gamma} - \gamma)$ の極限分布を $\gamma$ だけで表せ。

  [3] $n = 200$ の標本で $\bar{x} = 50$、$\hat{\sigma} = 10$ であった。[2] にもとづく $\gamma$ の近似 95% 信頼区間を小数第 3 位まで求めよ。標準正規分布の上側 2.5% 点は $1.96$、$\sqrt{0.000108} = 0.01039$ とする。
modelAnswer: |
  **[1]** 対数尤度は $\ell(\mu, \sigma^2) = -\dfrac{n}{2}\log(2\pi\sigma^2) - \dfrac{1}{2\sigma^2}\sum(x_i - \mu)^2$。

  $$\frac{\partial\ell}{\partial\mu} = \frac{1}{\sigma^2}\sum(x_i - \mu) = 0,\qquad \frac{\partial\ell}{\partial\sigma^2} = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4}\sum(x_i - \mu)^2 = 0$$

  より $\hat{\mu} = \bar{X}$、$\hat{\sigma}^2 = \dfrac{1}{n}\sum(X_i - \bar{X})^2$。1 観測の対数密度の 2 階微分は

  $$\frac{\partial^2}{\partial\mu^2} = -\frac{1}{\sigma^2},\qquad \frac{\partial^2}{\partial\mu\,\partial\sigma^2} = -\frac{x - \mu}{\sigma^4},\qquad \frac{\partial^2}{\partial(\sigma^2)^2} = \frac{1}{2\sigma^4} - \frac{(x - \mu)^2}{\sigma^6}$$

  で、符号を反転して期待値をとると

  $$I(\mu, \sigma^2) = \begin{pmatrix} 1/\sigma^2 & 0 \\ 0 & 1/(2\sigma^4) \end{pmatrix}$$

  **[2]** 最尤推定量の不変性より $\hat{\gamma} = \hat{\sigma}/\hat{\mu} = \sqrt{\hat{\sigma}^2}/\bar{X}$。最尤推定量の漸近正規性より

  $$\sqrt{n}\begin{pmatrix}\hat{\mu} - \mu \\ \hat{\sigma}^2 - \sigma^2\end{pmatrix} \xrightarrow{d} N_2\left(\mathbf{0},\ I^{-1}\right),\qquad I^{-1} = \begin{pmatrix}\sigma^2 & 0 \\ 0 & 2\sigma^4\end{pmatrix}$$

  $h(\mu, \sigma^2) = (\sigma^2)^{1/2}/\mu$ の勾配は

  $$\frac{\partial h}{\partial\mu} = -\frac{\sigma}{\mu^2},\qquad \frac{\partial h}{\partial\sigma^2} = \frac{1}{2\sigma\mu}$$

  デルタ法より、漸近分散は

  $$\frac{\sigma^2}{\mu^4}\cdot\sigma^2 + \frac{1}{4\sigma^2\mu^2}\cdot 2\sigma^4 = \frac{\sigma^4}{\mu^4} + \frac{\sigma^2}{2\mu^2} = \gamma^4 + \frac{\gamma^2}{2}$$

  よって

  $$\sqrt{n}(\hat{\gamma} - \gamma) \xrightarrow{d} N\left(0,\ \gamma^2\left(\gamma^2 + \frac{1}{2}\right)\right)$$

  **[3]** $\hat{\gamma} = 10/50 = 0.2$。漸近分散の推定値は $0.04 \times (0.04 + 0.5) = 0.0216$ で、標準誤差は $\sqrt{0.0216/200} = \sqrt{0.000108} = 0.01039$。

  $$0.2 \pm 1.96 \times 0.01039 = 0.2 \pm 0.0204 = [0.180,\ 0.220]$$

2 母数モデルで、最尤推定量の漸近分布（フィッシャー情報行列の逆行列）と多変量デルタ法を組み合わせ、母数の関数の漸近分散を求める問題です。最尤推定量の不変性により、$\gamma$ の最尤推定量は $\hat{\sigma}/\hat{\mu}$ で与えられます。

### 解答の流れ

1. 正規分布の対数尤度から最尤推定量とフィッシャー情報行列を求める。$\mu$ と $\sigma^2$ の交差項は期待値が 0 になる。
2. $(\hat{\mu}, \hat{\sigma}^2)$ の漸近共分散行列 $I^{-1}/n$ に、$h$ の勾配を両側から掛ける。
3. 漸近分散の $\gamma$ に推定値を代入し（スルツキーの定理）、Wald 型の区間を作る。

### つまずきやすい点

- フィッシャー情報行列を $\sigma$ について計算した場合は $I_{\sigma\sigma} = 2/\sigma^2$ となる。どの母数で微分しているかをそろえること（どちらで計算しても最終結果は同じ）。
- 勾配の $\partial h/\partial\sigma^2$ を $1/\mu$（$\sigma$ についての微分）とする誤り。$\sigma = (\sigma^2)^{1/2}$ なので $\partial\sigma/\partial\sigma^2 = 1/(2\sigma)$。
- $\gamma$ が小さいとき漸近分散は $\gamma^2/2$ が主要項で、「$\sigma$ の推定の誤差」が支配的になる。$\gamma^4$ の項は「$\mu$ の推定の誤差」による。

### ポイント

- $\hat{\mu}$ と $\hat{\sigma}^2$ が漸近的に（正規分布では正確に）独立であることが、漸近分散が 2 項の和に分かれる理由である。
- 多変量デルタ法：$\sqrt{n}(\hat{\boldsymbol{\theta}} - \boldsymbol{\theta}) \xrightarrow{d} N(\mathbf{0}, \Sigma)$ なら $\sqrt{n}(h(\hat{\boldsymbol{\theta}}) - h(\boldsymbol{\theta})) \xrightarrow{d} N(0,\ \nabla h^\top\Sigma\nabla h)$。
