stem: |
  ある農産物の市場について、時点 $t$（$t = 1, \ldots, T$）の取引量 $Q_t$ と価格 $P_t$ が次の需要関数と供給関数の交点で決まるとする。

  $$\text{需要：}\ Q_t = \alpha_1 + \alpha_2 P_t + u_t,\qquad \text{供給：}\ Q_t = \beta_1 + \beta_2 P_t + \beta_3 W_t + v_t$$

  ここで $\alpha_2 < 0 < \beta_2$、$\beta_3 \neq 0$ であり、$W_t$ は生産費用を表す外生変数である。$W_t,\ u_t,\ v_t$ は互いに独立で、$E[u_t] = E[v_t] = 0$、$V[W_t] = \sigma_W^2 > 0$、$V[u_t] = \sigma_u^2$、$V[v_t] = \sigma_v^2$ とし、$(W_t, u_t, v_t)$ は $t$ について独立同一分布に従うとする。以下の各問に答えよ。

  [1] 価格 $P_t$ を $W_t$、$u_t$、$v_t$ で表す誘導形を求めよ。

  [2] 需要関数の $Q_t$ を $P_t$ に単回帰したときの最小二乗推定量 $\hat{\alpha}_2$ の確率極限を求め、$\hat{\alpha}_2$ が $\alpha_2$ の一致推定量にならないことを示せ。偏りの向きも述べよ。

  [3] 需要関数と供給関数のそれぞれについて、識別されるかどうかを次数条件にもとづいて判定し、その理由を説明せよ。

  [4] $W_t$ を操作変数とする $\alpha_2$ の推定量が一致推定量であることを示せ。さらに、標本共分散・標本分散が

  $$s_{WW} = 4.0,\quad s_{WP} = 1.6,\quad s_{WQ} = -2.4,\quad s_{PP} = 2.0,\quad s_{PQ} = -0.4$$

  であったとき、操作変数推定値と最小二乗推定値を求めて比較せよ。
modelAnswer: |
  **[1]** 需要と供給を等しいとおくと $\alpha_1 + \alpha_2 P_t + u_t = \beta_1 + \beta_2 P_t + \beta_3 W_t + v_t$ なので

  $$P_t = \frac{\beta_1 - \alpha_1}{\alpha_2 - \beta_2} + \frac{\beta_3}{\alpha_2 - \beta_2}\,W_t + \frac{v_t - u_t}{\alpha_2 - \beta_2}$$

  $P_t$ は $u_t$ を含むので、需要関数の説明変数 $P_t$ は誤差項 $u_t$ と相関する（同時性）。

  **[2]** $\hat{\alpha}_2 = s_{PQ}/s_{PP}$ であり、大数の法則と連続写像定理より $\operatorname{plim}\hat{\alpha}_2 = \mathrm{Cov}(P, Q)/V[P]$。$Q_t = \alpha_1 + \alpha_2 P_t + u_t$ を代入すると

  $$\operatorname*{plim}_{T\to\infty}\hat{\alpha}_2 = \alpha_2 + \frac{\mathrm{Cov}(P_t, u_t)}{V[P_t]}$$

  [1] より

  $$\mathrm{Cov}(P_t, u_t) = \frac{-\sigma_u^2}{\alpha_2 - \beta_2} = \frac{\sigma_u^2}{\beta_2 - \alpha_2},\qquad V[P_t] = \frac{\beta_3^2\sigma_W^2 + \sigma_u^2 + \sigma_v^2}{(\beta_2 - \alpha_2)^2}$$

  したがって

  $$\operatorname*{plim}_{T\to\infty}\hat{\alpha}_2 = \alpha_2 + \frac{(\beta_2 - \alpha_2)\,\sigma_u^2}{\beta_3^2\sigma_W^2 + \sigma_u^2 + \sigma_v^2}$$

  $\beta_2 - \alpha_2 > 0$ なので、$\sigma_u^2 > 0$ であれば第 2 項は正であり、$\hat{\alpha}_2$ は一致推定量ではない。偏りは正の向き（負の傾き $\alpha_2$ を 0 の側へ、場合によっては正の値まで）である。観測される $(P_t, Q_t)$ は需要曲線と供給曲線の両方が動いた結果の交点であり、最小二乗法はその「混ざった」傾きを推定してしまう。

  **[3]** 体系全体の外生変数は $W_t$ の 1 個である。

  - 需要関数：右辺の内生変数は $P_t$ の 1 個、式から除外された外生変数は $W_t$ の 1 個。除外された外生変数の数（1）が右辺の内生変数の数（1）以上なので次数条件を満たし、ちょうど識別される。$W_t$ が供給曲線だけを動かすので、交点は需要曲線の上を動き、需要曲線がなぞられる。
  - 供給関数：右辺の内生変数は $P_t$ の 1 個だが、除外された外生変数は 0 個なので次数条件を満たさず、識別されない。需要曲線を動かす外生変数がないため、供給曲線をなぞる変動が得られない。

  （$\beta_3 \neq 0$ は、需要関数の階数条件に相当する。）

  **[4]** 操作変数推定量は $\hat{\alpha}_2^{IV} = s_{WQ}/s_{WP}$。$W_t$ は $u_t$ と独立なので

  $$\mathrm{Cov}(W_t, Q_t) = \alpha_2\,\mathrm{Cov}(W_t, P_t) + \mathrm{Cov}(W_t, u_t) = \alpha_2\,\mathrm{Cov}(W_t, P_t)$$

  また $\mathrm{Cov}(W_t, P_t) = \beta_3\sigma_W^2/(\alpha_2 - \beta_2) \neq 0$ なので

  $$\operatorname*{plim}_{T\to\infty}\hat{\alpha}_2^{IV} = \frac{\alpha_2\,\mathrm{Cov}(W_t, P_t)}{\mathrm{Cov}(W_t, P_t)} = \alpha_2$$

  となり一致推定量である。これは、誘導形 $P_t = \pi_{10} + \pi_{11}W_t + \cdots$、$Q_t = \pi_{20} + \pi_{21}W_t + \cdots$ の係数の比 $\pi_{21}/\pi_{11}$（間接最小二乗法）とも一致する。

  数値では

  $$\hat{\alpha}_2^{IV} = \frac{s_{WQ}}{s_{WP}} = \frac{-2.4}{1.6} = -1.5,\qquad \hat{\alpha}_2^{OLS} = \frac{s_{PQ}}{s_{PP}} = \frac{-0.4}{2.0} = -0.2$$

  最小二乗推定値は [2] で示した正の偏りのために 0 に近く、需要が価格に反応する大きさ（傾きの絶対値）を過小に評価している。

需要と供給の連立方程式モデルは、内生性（同時性バイアス）と識別の問題を同時に扱える、社会科学分野の代表的な題材です。価格は需要の誤差項にも反応して決まるため、需要関数の説明変数として外生的ではありません。

### 解答の流れ

1. 均衡条件を価格について解き、誘導形を得る。誘導形には両方の式の誤差項が入る。
2. 最小二乗推定量の確率極限を「真の値 + 共分散 / 分散」の形に書き、誘導形から共分散と分散を計算する。
3. 次数条件は「式から除外された外生変数の数 $\geq$ 右辺の内生変数の数」。
4. 需要関数から除外された外生変数 $W_t$ が、そのまま需要関数の操作変数になる。

### つまずきやすい点

- 識別の判定を逆にしやすい。**供給側を動かす変数**（費用 $W_t$）があると**需要曲線**が識別される。供給曲線を識別するには、需要だけを動かす外生変数（所得など）が必要。
- 偏りの符号：$\beta_2 - \alpha_2 > 0$ なので偏りは正。需要の傾きは負なので、「絶対値が小さく推定される」と表現してもよい。
- $\beta_3 = 0$ だと $W_t$ が $P_t$ と相関せず、操作変数推定量の分母の確率極限が 0 になって識別できない（階数条件の破れ）。

### ポイント

- 操作変数推定量 $s_{WQ}/s_{WP}$ は、ちょうど識別の場合、間接最小二乗法・2 段階最小二乗法（2SLS）と一致する。過剰識別（除外された外生変数が多い）の場合は 2SLS で全ての操作変数を使う。
- 本問の数値では誘導形の係数は $\hat{\pi}_{11} = 1.6/4.0 = 0.4$、$\hat{\pi}_{21} = -2.4/4.0 = -0.6$ で、比 $-0.6/0.4 = -1.5$ が操作変数推定値に等しい。
