  [1] $(X_{(1)}, \ldots, X_{(n)})$ の同時確率密度関数を書き、$X_{(1)}$ の分布を求めよ。

  [2] $D_k = (n - k + 1)\left(X_{(k)} - X_{(k-1)}\right)\ (k = 1, \ldots, n)$ とおく。変数変換により、$D_1, \ldots, D_n$ が互いに独立に $f(x) = e^{-x}$ の指数分布に従うことを示せ。

  [3] [2] を用いて、$E[X_{(k)}]$ と $V[X_{(k)}]$ を求めよ。

  [4] 平均寿命 1（単位時間）の指数分布に従う 5 個の部品を同時に試験し、3 個目が故障した時点で試験を打ち切る。打ち切り時刻の期待値と分散を既約分数で求めよ。
modelAnswer: |
  **[1]** $n$ 個の値の並べ方が $n!$ 通りあるので

  $$g(y_1, \ldots, y_n) = n!\,\exp\left(-\sum_{k=1}^{n}y_k\right)\qquad (0 < y_1 < y_2 < \cdots < y_n)$$

  $X_{(1)}$ については $P(X_{(1)} > x) = P(\text{すべての } X_i > x) = e^{-nx}$ なので、$X_{(1)}$ は密度 $ne^{-nx}$ の指数分布（平均 $1/n$）に従う。

  **[2]** $d_k = (n - k + 1)(y_k - y_{k-1})$（$y_0 = 0$）とおくと、領域 $0 < y_1 < \cdots < y_n$ は $d_k > 0\ (k = 1, \ldots, n)$ に 1 対 1 に移る。逆変換は

  $$y_k = \sum_{j=1}^{k}\frac{d_j}{n - j + 1}$$

  で、$\partial y_k/\partial d_j$ は下三角行列、対角成分は $1/(n - k + 1)$ なので、ヤコビアンは $\prod_{k=1}^{n}\dfrac{1}{n-k+1} = \dfrac{1}{n!}$。また、和の順序を入れ替えると

  $$\sum_{k=1}^{n}d_k = \sum_{k=1}^{n}(n - k + 1)(y_k - y_{k-1}) = \sum_{k=1}^{n}y_k$$

  （$y_k$ の係数は $(n - k + 1) - (n - k) = 1$）。よって $(D_1, \ldots, D_n)$ の同時密度は

  $$n!\,e^{-\sum d_k}\cdot\frac{1}{n!} = \prod_{k=1}^{n}e^{-d_k}\qquad (d_k > 0)$$

  となり、$D_1, \ldots, D_n$ は独立に平均 1 の指数分布に従う。

  **[3]** $X_{(k)} = \displaystyle\sum_{j=1}^{k}\frac{D_j}{n - j + 1}$ と、$D_j$ の独立性・$E[D_j] = V[D_j] = 1$ より

  $$E[X_{(k)}] = \sum_{j=1}^{k}\frac{1}{n - j + 1},\qquad V[X_{(k)}] = \sum_{j=1}^{k}\frac{1}{(n - j + 1)^2}$$

  **[4]** $n = 5,\ k = 3$ で

  $$E[X_{(3)}] = \frac{1}{5} + \frac{1}{4} + \frac{1}{3} = \frac{47}{60},\qquad V[X_{(3)}] = \frac{1}{25} + \frac{1}{16} + \frac{1}{9} = \frac{769}{3600}$$

指数分布の順序統計量の「間隔」を重み付けすると独立な指数分布になるという性質（レーニの表現）は、寿命試験・打ち切りデータの理論の基礎です。指数分布の無記憶性を、変数変換とヤコビアンで厳密に示す問題です。

### 解答の流れ

1. 順序統計量の同時密度は「元の同時密度 × $n!$」（並べ替えの数）で、定義域は $y_1 < \cdots < y_n$。
2. 間隔の変換は線形で、ヤコビアンは三角行列の対角成分の積になる。
3. 期待値・分散は独立な和の公式で求める。

### つまずきやすい点

- 重み $n - k + 1$ を付け忘れると、間隔 $X_{(k)} - X_{(k-1)}$ は平均 $1/(n - k + 1)$ の指数分布であり、同一分布にはならない。
- ヤコビアンを $\partial d/\partial y$（行列式 $n!$）で計算した場合は、その逆数を掛ける。
- [4] の分散を $\left(\frac{1}{5} + \frac{1}{4} + \frac{1}{3}\right)^2$ などとする誤り。独立な和の分散は、各項の係数の 2 乗の和になる。

### ポイント

- 直感的には、$k - 1$ 個が故障した時点で残りは $n - k + 1$ 個であり、無記憶性によって次の故障までの時間は平均 $1/(n - k + 1)$ の指数分布になる。
- 最大値の期待値は $E[X_{(n)}] = 1 + \frac{1}{2} + \cdots + \frac{1}{n} \approx \log n + 0.5772$ で、これは極値分布（ガンベル分布）への収束と対応する。
- 定数打ち切り（第 II 種打ち切り）の寿命試験では、総試験時間 $\sum_{k=1}^{r}X_{(k)} + (n - r)X_{(r)} = \sum_{k=1}^{r}D_k$ が $Ga(r, 1)$ に従うことが、この結果から直ちに分かる。
