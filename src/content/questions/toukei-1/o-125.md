  独立同一分布に従う確率変数の最大値 $M_n = \max(X_1, \ldots, X_n)$ の極限分布について、以下の各問に答えよ。

  [1] $X_i$ が区間 $(0, \theta)$ 上の一様分布に従うとき、$n(\theta - M_n)/\theta$ の極限分布を求めよ。

  [2] [1] から $\sqrt{n}(M_n - \theta) \xrightarrow{p} 0$ が成り立つことを示し、$\theta$ の最尤推定量 $M_n$ が通常の「$\sqrt{n}$ の速さの漸近正規性」をもたない理由を、最尤推定量の漸近正規性の正則条件と関連付けて述べよ。

  [3] $X_i$ が分布関数 $F(x) = 1 - x^{-\alpha}\ (x \geq 1,\ \alpha > 0)$ のパレート分布に従うとき、$M_n/n^{1/\alpha}$ の極限分布を求めよ。

  [4] [3] で $\alpha = 2,\ n = 10000$ のとき、極限分布を用いて $P(M_n > 200)$ を近似せよ。$e^{-0.25} = 0.7788$ とする。
modelAnswer: |
  **[1]** $0 \leq x \leq n$ について

  $$P\left(\frac{n(\theta - M_n)}{\theta} > x\right) = P\left(M_n < \theta\left(1 - \frac{x}{n}\right)\right) = \left(1 - \frac{x}{n}\right)^n \to e^{-x}$$

  よって $n(\theta - M_n)/\theta \xrightarrow{d} \mathrm{Exp}(1)$（平均 1 の指数分布）。

  **[2]** $T_n = n(\theta - M_n)/\theta$ とおくと $\sqrt{n}(M_n - \theta) = -\theta T_n/\sqrt{n}$。$T_n$ は分布収束するので確率的に有界であり、$1/\sqrt{n} \to 0$ との積はスルツキーの定理により 0 に分布収束、したがって（極限が定数なので）確率収束する。すなわち $M_n$ の誤差は $O_p(1/n)$ で、$\sqrt{n}$ で拡大しても 0 に縮退し、非退化の正規分布には収束しない（$n$ で拡大した極限は正規分布でなく指数分布）。

  最尤推定量の漸近正規性 $\sqrt{n}(\hat{\theta} - \theta) \xrightarrow{d} N(0, 1/I(\theta))$ は、台 $\{x : f(x;\theta) > 0\}$ が $\theta$ に依存しないこと、対数尤度が $\theta$ について微分可能でスコアの期待値が 0 になることなどの正則条件のもとで成り立つ。一様分布 $U(0, \theta)$ では台が $\theta$ に依存し、尤度 $\theta^{-n}\mathbf{1}\{M_n \leq \theta\}$ は $\theta = M_n$ で不連続なので、この条件を満たさない。

  **[3]** $x > 0$ について、$n$ が十分大きく $n^{1/\alpha}x \geq 1$ のとき

  $$P\left(\frac{M_n}{n^{1/\alpha}} \leq x\right) = F(n^{1/\alpha}x)^n = \left(1 - \frac{x^{-\alpha}}{n}\right)^n \to \exp\left(-x^{-\alpha}\right)$$

  よって極限分布は分布関数 $\exp(-x^{-\alpha})\ (x > 0)$ のフレシェ分布である。

  **[4]** $n^{1/\alpha} = 10000^{1/2} = 100$ なので

  $$P(M_n > 200) = 1 - P\left(\frac{M_n}{100} \leq 2\right) \approx 1 - \exp(-2^{-2}) = 1 - e^{-0.25} = 1 - 0.7788 = 0.2212$$

最大値の極限分布は、裾の重さによってワイブル型（台の上端が有限）、ガンベル型（指数的な裾）、フレシェ型（べき乗の裾）の 3 つに分かれます（フィッシャー・ティペットの定理）。この問題では有限の上端をもつ一様分布と、べき乗の裾をもつパレート分布を扱います。

### 解答の流れ

1. 最大値の分布関数は $F(x)^n$。正規化した変数の分布関数を書き、$(1 + a/n)^n \to e^a$ を使う。
2. 正規化の速さは分布の上端付近の振る舞いで決まる。一様分布では $n$、パレート分布では $n^{1/\alpha}$。
3. 母数推定の観点では、台の端点を推定する問題は $\sqrt{n}$ より速い速さ（超効率）で推定できる「非正則」な問題である。

### つまずきやすい点

- [1] で $P(M_n \leq x) = (x/\theta)^n$ から直接極限をとると、$x < \theta$ では 0、$x \geq \theta$ では 1 となり、退化した分布しか得られない。適切に正規化する必要がある。
- [2] で「最尤推定量は常に漸近正規」と答える誤り。正則条件を確認すること。$U(0, \theta)$ では $n(\theta - M_n)/\theta$ の極限は指数分布であり、正規分布ではない。
- [3] で正規化定数を $n^\alpha$ や $\log n$ とする誤り。$F(a_nx)^n$ の極限が非退化になるように $n\{1 - F(a_n)\} \to 1$ となる $a_n$ を選ぶ。

### ポイント

- ガンベル型の例：標準指数分布では $M_n - \log n \xrightarrow{d} \exp(-e^{-x})$。
- [1] の結果を使うと、$U(0, \theta)$ の $\theta$ について、$M_n/\theta$ を枢軸量とする正確な信頼区間 $[M_n,\ M_n/0.05^{1/n}]$ も作れる。
- パレート分布の $\alpha$ が小さい（裾が重い）ほど、最大値は $n^{1/\alpha}$ の速さで急激に大きくなる。保険の巨大損害や金融リスクの評価では、この裾の重さが重要になる。
