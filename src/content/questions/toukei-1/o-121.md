  同じ確率空間上の確率変数列 $X_n,\ Y_n$ と確率変数 $X,\ Y$ について、次の記述のうち常に正しいものを一つ選べ。
choices:
  - '$X_n$ が $X$ に確率収束するならば、$X_n$ は $X$ に概収束する。'
  - '$X_n$ が $X$ に分布収束するならば、$X_n$ は $X$ に確率収束する。'
  - '$X_n$ が $X$ に確率収束するならば、$E[X_n] \to E[X]$ である。'
  - '$X_n$ が $X$ に平均二乗収束（$E[(X_n - X)^2] \to 0$）するならば、$X_n$ は $X$ に確率収束する。'
  - '$X_n$ が $X$ に、$Y_n$ が $Y$ にそれぞれ分布収束するならば、$X_n + Y_n$ は $X + Y$ に分布収束する。'
answer: 4

チェビシェフ（マルコフ）の不等式 $P(|X_n - X| > \varepsilon) \leq E[(X_n - X)^2]/\varepsilon^2$ より、平均二乗収束すれば右辺が 0 に収束するので、確率収束します。ほかの記述には反例があります。

### 各選択肢の検討

- 確率収束 ⇒ 概収束：誤り。独立な事象 $A_n$（$P(A_n) = 1/n$）について $X_n = \mathbf{1}_{A_n}$ とすると、$P(|X_n| > \varepsilon) = 1/n \to 0$ だが、$\sum 1/n = \infty$ なのでボレル・カンテリの補題により $A_n$ は確率 1 で無限回起こり、$X_n$ は 0 に概収束しない。
- 分布収束 ⇒ 確率収束：誤り。$X \sim N(0, 1)$、$X_n = -X$ とすると分布はすべて等しいが、$|X_n - X| = 2|X|$ は 0 に近づかない。極限が定数の場合に限り成り立つ。
- 確率収束 ⇒ 期待値の収束：誤り。$U \sim U(0, 1)$、$X_n = n\cdot\mathbf{1}\{U \leq 1/n\}$ は 0 に確率収束するが $E[X_n] = 1$。一様可積分性が必要である。
- 平均二乗収束 ⇒ 確率収束：正しい（上記）。
- 和の分布収束：誤り。$X \sim N(0, 1)$、$X_n = X$、$Y_n = -X$、$Y = X$ とすると、$X_n + Y_n = 0$ だが $X + Y = 2X \sim N(0, 4)$。分布収束は各変数の周辺分布しか規定しないので、同時分布が定まらない。一方が定数に収束する場合はスルツキーの定理により成り立つ。

### ポイント

- 収束の強さの関係：概収束 ⇒ 確率収束 ⇒ 分布収束、$L^p$ 収束 ⇒ $L^q$ 収束（$p > q \geq 1$）⇒ 確率収束。
- 推定量の一致性の証明では、「$E[(\hat{\theta}_n - \theta)^2] = (\text{偏り})^2 + \text{分散} \to 0$ を示して確率収束を得る」という形でこの関係がよく使われる。
