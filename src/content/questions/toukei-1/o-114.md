$S$ の分布関数は、$1 \leq x \leq 2$ で $F(x) = \dfrac{x^3 - 3(x - 1)^3}{6}$ です。$x = 1.2$ を代入すると $(1.728 - 0.024)/6 = 0.284$ になります。

### 計算（幾何学的な考え方）

$P(S \leq x)$ は、単位立方体 $[0, 1]^3$ のうち $u_1 + u_2 + u_3 \leq x$ を満たす部分の体積です。

- 立方体の制約を無視すると、$u_i \geq 0,\ \sum u_i \leq x$ の部分は体積 $x^3/6$ の四面体。
- $1 < x \leq 2$ では、この四面体が立方体からはみ出す。$u_1 > 1$ となる部分は $v_1 = u_1 - 1$ とおくと $v_1 + u_2 + u_3 \leq x - 1$ の四面体で、体積 $(x - 1)^3/6$。$u_2 > 1$、$u_3 > 1$ も同様で、2 つ以上が 1 を超える部分は $x \leq 2$ では存在しない。

よって

$$P(S \leq x) = \frac{x^3 - 3(x - 1)^3}{6}\qquad (1 \leq x \leq 2)$$

$$P(S \leq 1.2) = \frac{1.728 - 3 \times 0.008}{6} = \frac{1.704}{6} = 0.284$$

### 別解（たたみ込み）

$U_1 + U_2$ の密度は三角分布 $g(y) = y\ (0 < y < 1)$、$2 - y\ (1 \leq y < 2)$ です。$S \leq 1.2$ は $U_3 \leq 1.2 - y$ と同値で、

$$P(S \leq 1.2) = \int_0^{0.2}y \cdot 1\,dy + \int_{0.2}^{1}y(1.2 - y)\,dy + \int_{1}^{1.2}(2 - y)(1.2 - y)\,dy$$

$$= 0.02 + 0.245333 + 0.018667 = 0.284$$

（$y < 0.2$ では $1.2 - y > 1$ なので $P(U_3 \leq 1.2 - y) = 1$ です。）

### ポイント

- よくある誤り：はみ出し部分を引き忘れて $1.2^3/6 = 0.288$ とする。$0 \leq x \leq 1$ の式 $x^3/6$ をそのまま使えるのは $x \leq 1$ のときだけである。
- 中心極限定理による正規近似（$E[S] = 1.5$、$V[S] = 3/12 = 0.25$）では $\Phi\big((1.2 - 1.5)/0.5\big) = \Phi(-0.6) \approx 0.274$ となる。$n = 3$ でもかなり近いが、正確な値とは差がある。
- 一般に $n$ 個の一様分布の和（アーウィン・ホール分布）の分布関数は $\dfrac{1}{n!}\sum_{k=0}^{\lfloor x\rfloor}(-1)^k\binom{n}{k}(x - k)^n$ で、包除原理から得られる。
