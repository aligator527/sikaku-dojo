  ある窓口への客の到着は、強度 $\lambda = 3$（人/時）のポアソン過程 $\{N(t),\ t \geq 0\}$ に従うとする。$N(t)$ は時刻 $0$ から $t$（時間）までの到着数である。以下の各問に答えよ。必要なら $e^{-1.2} = 0.3012$、$e^{-1.5} = 0.2231$ を用いよ。

  [1] 到着間隔 $T_1, T_2, \ldots$（$T_1$ は最初の到着時刻、$T_k$ は $k - 1$ 番目と $k$ 番目の到着の間隔）が互いに独立に平均 $1/\lambda$ の指数分布に従うことを、ポアソン過程の性質を用いて説明せよ。

  [2] 最初の 1 時間にちょうど 4 人が到着したことがわかっているとき、最初の 15 分間の到着数の条件付き分布を求め、最初の 15 分間に少なくとも 1 人到着している条件付き確率を求めよ。

  [3] 各客は、他の客と独立に確率 $0.4$ で窓口 A、確率 $0.6$ で窓口 B の手続きを希望する。窓口 A を希望する客の到着過程と窓口 B を希望する客の到着過程は、それぞれ強度 $1.2$、$1.8$ の互いに独立なポアソン過程になることを、時刻 $t$ までの到着数について示せ。また、1 時間に窓口 A の希望者が 1 人も来ない確率を求めよ。

  [4] 3 人目の客の到着時刻 $S_3 = T_1 + T_2 + T_3$ の分布と期待値を述べ、$P(S_3 \leq 0.5)$ を求めよ。
modelAnswer: |
  **[1]** $P(T_1 > t) = P(N(t) = 0) = e^{-\lambda t}$ なので、$T_1$ は平均 $1/\lambda$ の指数分布に従う。次に $T_1 = s$ を与えたとき、$T_2 > t$ は区間 $(s, s + t]$ に到着がないことと同値であり、ポアソン過程の独立増分性より、この事象は $(0, s]$ での出来事と独立で、定常増分性よりその確率は $P(N(t) = 0) = e^{-\lambda t}$。よって $T_2$ は $T_1$ と独立に同じ指数分布に従う。同様の議論をくり返すと、$T_1, T_2, \ldots$ は互いに独立に平均 $1/\lambda = 1/3$ 時間（20 分）の指数分布に従う。

  **[2]** $N(1/4)$ と $N(1) - N(1/4)$ は独立で、それぞれ $Po(3/4)$、$Po(9/4)$ に従うので、$k = 0, \ldots, 4$ について

  $$P\left(N(\tfrac{1}{4}) = k \,\middle|\, N(1) = 4\right) = \frac{\dfrac{e^{-3/4}(3/4)^k}{k!}\cdot\dfrac{e^{-9/4}(9/4)^{4-k}}{(4-k)!}}{\dfrac{e^{-3}3^4}{4!}} = \binom{4}{k}\left(\frac{1}{4}\right)^k\left(\frac{3}{4}\right)^{4-k}$$

  すなわち二項分布 $\mathrm{Bin}(4,\ 1/4)$ である（4 人の到着時刻が $(0, 1)$ 上の一様分布に独立に従うことに対応する）。よって

  $$P\left(N(\tfrac{1}{4}) \geq 1 \,\middle|\, N(1) = 4\right) = 1 - \left(\frac{3}{4}\right)^4 = 1 - \frac{81}{256} = \frac{175}{256} = 0.684$$

  **[3]** 時刻 $t$ までの A 希望者数を $N_A(t)$、B 希望者数を $N_B(t)$ とする。$N(t) = a + b$ を与えたとき、$N_A(t)$ は $\mathrm{Bin}(a + b,\ 0.4)$ に従うので

  $$P(N_A(t) = a,\ N_B(t) = b) = \frac{e^{-3t}(3t)^{a+b}}{(a+b)!}\binom{a + b}{a}0.4^a0.6^b = \frac{e^{-1.2t}(1.2t)^a}{a!}\cdot\frac{e^{-1.8t}(1.8t)^b}{b!}$$

  同時確率関数が $Po(1.2t)$ と $Po(1.8t)$ の確率関数の積に分解するので、$N_A(t)$ と $N_B(t)$ は独立にそれぞれ $Po(1.2t)$、$Po(1.8t)$ に従う（異なる区間の増分の独立性も元の過程から引き継がれる）。1 時間に A の希望者が 0 人である確率は $P(N_A(1) = 0) = e^{-1.2} = 0.301$。

  **[4]** 独立な指数分布 3 個の和なので、$S_3$ は形状母数 3、尺度母数 $1/\lambda = 1/3$ のガンマ分布（アーラン分布）に従い、$E[S_3] = 3/\lambda = 1$ 時間。$S_3 \leq 0.5$ は「0.5 時間までに 3 人以上到着する」ことと同値なので、$N(0.5) \sim Po(1.5)$ より

  $$P(S_3 \leq 0.5) = 1 - e^{-1.5}\left(1 + 1.5 + \frac{1.5^2}{2}\right) = 1 - 0.2231 \times 3.625 = 1 - 0.8087 = 0.191$$

ポアソン過程の基本性質（指数分布の到着間隔、到着数を与えたときの一様性、間引き、到着時刻のガンマ分布）を一通り確認する問題です。

### 解答の流れ

1. 「時刻 $t$ までに到着がない」と「最初の到着が $t$ より後」は同じ事象である。
2. 到着総数を与えると、各到着は区間上に一様に独立に散らばる。部分区間に入る数は二項分布になる。
3. 各到着を独立に振り分けると（間引き）、それぞれが独立なポアソン過程になる。
4. 「$k$ 番目の到着時刻が $t$ 以下」は「時刻 $t$ までの到着数が $k$ 以上」と同じ事象である。

### つまずきやすい点

- [2] で条件を無視して $P(N(1/4) \geq 1) = 1 - e^{-0.75}$ とする誤り。条件 $N(1) = 4$ のもとでは、到着数は強度 $\lambda$ によらない二項分布になる。
- [3] で、A と B の到着数は $N(t)$ を共有しているので従属すると考えるのは誤り。ポアソン分布の総数を二項分布で振り分けると、結果は独立になる（総数が固定されている場合には従属する）。
- [4] で $P(S_3 \leq 0.5)$ を $P(N(0.5) = 3)$ とする誤り。「3 人以上」である。

### ポイント

- 独立なポアソン過程の重ね合わせ（強度の和）と間引き（強度に確率を掛ける）は、どちらもポアソン過程になる。
- 指数分布の無記憶性 $P(T > s + t \mid T > s) = P(T > t)$ は、ポアソン過程の独立増分性の言い換えである。
