modelAnswer: |
  **[1]** 尤度関数は

  $$L(\theta) = \prod_{i=1}^{n}\frac{1}{\theta}\mathbf{1}\{0 < x_i < \theta\} = \underbrace{\theta^{-n}\mathbf{1}\{\max_i x_i < \theta\}}_{g(M;\,\theta)}\cdot\underbrace{\mathbf{1}\{\min_i x_i > 0\}}_{h(\boldsymbol{x})}$$

  と $\theta$ を含む部分が $M$ だけの関数となるので、分解定理より $M$ は十分統計量である。$L(\theta)$ は $\theta \leq M$ で 0、$\theta > M$ で減少関数 $\theta^{-n}$ なので、最大化する値は $\theta = M$（上限）であり、最尤推定量は $\hat{\theta} = M$ である（密度を閉区間 $[0, \theta]$ 上で定義すれば最大値として達成される）。

  **[2]** $P(M \leq t) = (t/\theta)^n\ (0 \leq t \leq \theta)$ より密度は $f_M(t) = nt^{n-1}/\theta^n$。

  $$E[M] = \int_0^\theta t\cdot\frac{nt^{n-1}}{\theta^n}\,dt = \frac{n}{n+1}\theta,\qquad E[M^2] = \frac{n}{n+2}\theta^2$$

  よって $T = \dfrac{n+1}{n}M$ が不偏推定量で、$V[M] = \dfrac{n\theta^2}{(n+1)^2(n+2)}$ より

  $$V[T] = \left(\frac{n+1}{n}\right)^2V[M] = \frac{\theta^2}{n(n+2)}$$

  **[3]** 関数 $g$ がすべての $\theta > 0$ について $E_\theta[g(M)] = 0$ を満たすとすると

  $$\int_0^\theta g(t)\,nt^{n-1}\,dt = 0\qquad (\text{すべての } \theta > 0)$$

  両辺を $\theta$ で微分すると $g(\theta)\,n\theta^{n-1} = 0$（ほとんどすべての $\theta$）、よって $g = 0$（ほとんど至るところ）であり、$P_\theta(g(M) = 0) = 1$。したがって $M$ は完備十分統計量である。$T$ は $M$ の関数で不偏なので、レーマン・シェフェの定理により $T$ は一様最小分散不偏推定量である。

  **[4]** $V[X_i] = \theta^2/12$ より $V[2\bar{X}] = \dfrac{4}{n}\cdot\dfrac{\theta^2}{12} = \dfrac{\theta^2}{3n}$。

  $$\frac{V[T]}{V[2\bar{X}]} = \frac{\theta^2/\{n(n+2)\}}{\theta^2/(3n)} = \frac{3}{n+2}$$

  $n = 1$ で等しく、$n \geq 2$ では $T$ の方が分散が小さい。$V[T]$ は $O(1/n^2)$ で、$O(1/n)$ の $2\bar{X}$ より速く 0 に近づく。

  クラーメル・ラオの不等式は、台 $\{x : f(x;\theta) > 0\}$ が $\theta$ に依存せず、$\int f\,dx$ の微分と積分の順序交換ができることを前提とする。$U(0, \theta)$ では台 $(0, \theta)$ が $\theta$ に依存するのでこの正則条件が成り立たず、実際 $V[T]$ は形式的な「下限」$\theta^2/n$ より小さくなる。

一様分布 $U(0, \theta)$ は、十分統計量・完備性・一様最小分散不偏推定量の典型例であると同時に、クラーメル・ラオの不等式の正則条件が成り立たない「非正則な」モデルの代表例です。

### 解答の流れ

1. 尤度は指示関数 $\mathbf{1}\{M < \theta\}$ を含む。これを落とさずに書くことが十分性と最尤推定の鍵になる。
2. 最大値の分布 $(t/\theta)^n$ からモーメントを計算し、偏りを補正する。
3. 完備性は「$E_\theta[g(M)] = 0$ がすべての $\theta$ で成り立つなら $g = 0$」を、積分の上端についての微分で示す。
4. レーマン・シェフェの定理：完備十分統計量の関数である不偏推定量は一様最小分散不偏推定量。

### つまずきやすい点

- 尤度方程式 $\partial\log L/\partial\theta = -n/\theta = 0$ を解こうとする誤り。解はなく、最大値は境界（$\theta = M$）で達成される。
- $M$ は $\theta$ を下回るので偏りは常に負である。$E[M] = n\theta/(n+1)$ を $\theta$ と取り違えないこと。
- [4] で $V[T]$ がクラーメル・ラオの下限を下回ることを「矛盾」と考える誤り。正則条件が成り立たないので、下限は適用できない。

### ポイント

- 平均二乗誤差の意味では、$cM$ の形の推定量の中で $c = (n+2)/(n+1)$ が最良であり、不偏推定量 $T$ よりわずかに平均二乗誤差が小さい。
- $M/\theta$ は $\theta$ によらない分布（分布関数 $u^n$）をもつ枢軸量なので、これを用いて正確な信頼区間が作れる。
