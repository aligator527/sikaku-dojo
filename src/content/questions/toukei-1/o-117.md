稼働の有無を表す潜在変数 $B$（稼働なら 1）で条件付けると、全分散の公式から $V[X] = E[V[X \mid B]] + V[E[X \mid B]] = 0.8 \times 3 + 9 \times 0.16 = 2.4 + 1.44 = 3.84$ です。平均 $E[X] = 2.4$ より大きく、過分散になっています。

### 計算

$B \sim$ ベルヌーイ分布（成功確率 $0.8$）とすると、$X \mid B = 1 \sim Po(3)$、$X \mid B = 0$ は 0 に退化した分布です。

$$E[X \mid B] = 3B,\qquad V[X \mid B] = 3B$$

$$E[X] = 3 \times 0.8 = 2.4$$

$$V[X] = E[3B] + V[3B] = 3 \times 0.8 + 9 \times 0.8 \times 0.2 = 2.4 + 1.44 = 3.84$$

### 別解（モーメントの直接計算）

$E[X^2] = 0.8 \times E[Y^2]$（$Y \sim Po(3)$）$= 0.8 \times (3 + 9) = 9.6$ なので、$V[X] = 9.6 - 2.4^2 = 9.6 - 5.76 = 3.84$。

### ポイント

- 一般に、確率 $\pi$ で 0、確率 $1 - \pi$ で $Po(\lambda)$ のとき、$E[X] = (1-\pi)\lambda$、$V[X] = (1-\pi)\lambda(1 + \pi\lambda)$。$\pi > 0$ なら常に $V[X] > E[X]$ となる。
- よくある誤り：ポアソン分布の性質から $V[X] = E[X] = 2.4$ とする、または $V[X] = 0.8 \times 3 = 2.4$ と「稼働日の分散 × 稼働確率」だけを答える。稼働の有無による平均の違い（$V[E[X \mid B]] = 1.44$）が抜けている。
- 0 の度数が多すぎるデータに通常のポアソン分布を当てはめると、分散を過小評価し、検定や区間推定が楽観的になる。
