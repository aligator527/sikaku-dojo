  **[1]** 予測：$\mu_t = \mu_{t-1} + \eta_t$ で $\eta_t$ は $Y_{t-1}$ と独立なので

  $$a_{t|t-1} = a_{t-1|t-1},\qquad P_{t|t-1} = P_{t-1|t-1} + \sigma_\eta^2$$

  更新：$Y_{t-1}$ を与えたとき、$(\mu_t, y_t)$ は 2 変量正規分布に従い

  $$E[y_t \mid Y_{t-1}] = a_{t|t-1},\quad V[y_t \mid Y_{t-1}] = P_{t|t-1} + \sigma_\varepsilon^2,\quad \mathrm{Cov}(\mu_t, y_t \mid Y_{t-1}) = P_{t|t-1}$$

  正規分布の条件付き分布の公式 $E[X \mid Y] = E[X] + \dfrac{\mathrm{Cov}(X, Y)}{V[Y]}(Y - E[Y])$、$V[X \mid Y] = V[X] - \dfrac{\mathrm{Cov}(X, Y)^2}{V[Y]}$ を適用すると

  $$a_{t|t} = a_{t|t-1} + \frac{P_{t|t-1}}{P_{t|t-1} + \sigma_\varepsilon^2}(y_t - a_{t|t-1}),\qquad P_{t|t} = P_{t|t-1} - \frac{P_{t|t-1}^2}{P_{t|t-1} + \sigma_\varepsilon^2} = (1 - K_t)P_{t|t-1}$$

  $$\bar{P}^2 - \sigma_\eta^2\bar{P} - \sigma_\eta^2\sigma_\varepsilon^2 = 0$$

  $$\bar{P} = \frac{\sigma_\eta^2 + \sqrt{\sigma_\eta^4 + 4\sigma_\eta^2\sigma_\varepsilon^2}}{2} = \sigma_\varepsilon^2\cdot\frac{q + \sqrt{q^2 + 4q}}{2},\qquad \bar{K} = \frac{\bar{P}}{\bar{P} + \sigma_\varepsilon^2}$$

  **[3]** $q = 0.5$ では $\sqrt{0.25 + 2} = 1.5$ なので $\bar{P}/\sigma_\varepsilon^2 = (0.5 + 1.5)/2 = 1$、$\bar{K} = 1/(1 + 1) = 0.5$。定常状態では $a_{t|t-1} = a_{t-1|t-1}$ より

  これは平滑化定数 $\alpha = \bar{K} = 0.5$ の指数平滑法 $S_t = \alpha y_t + (1 - \alpha)S_{t-1}$ である。また 1 期先予測 $E[y_{t+1} \mid Y_t] = a_{t|t}$ も指数平滑値に一致する。

状態空間モデルとカルマンフィルタの最も簡単な例であるローカルレベルモデルについて、フィルタの導出、定常ゲイン、指数平滑法・ARIMA(0, 1, 1) との同値性をまとめて確認する問題です。

### 解答の流れ

1. 予測では状態方程式で平均を進め、分散に $\sigma_\eta^2$ を加える。更新は正規分布の条件付き分布の公式そのものである。
2. 予測誤差分散の漸化式（リカッチ方程式）の不動点を求める。
3. 定常ゲインのもとでフィルタは指数平滑法になる。信号対雑音比 $q$ が大きいほど $\bar{K}$ は 1 に近く、新しい観測値を重視する。
4. 階差をとると状態の非定常性が消え、2 つのノイズの和として MA(1) が現れる。

### つまずきやすい点

- $K_t$ の分母を $\sigma_\varepsilon^2$ だけにする誤り。分母は 1 期先予測誤差 $y_t - a_{t|t-1}$ の分散 $P_{t|t-1} + \sigma_\varepsilon^2$ である。
- [4] で $\theta = -2$ を選ぶ誤り。同じ自己相関を与える MA(1) 表現は 2 つあるが、観測値からイノベーション $u_t$ を復元できる（反転可能な）のは $|\theta| < 1$ の方である。

### ポイント

- カルマンフィルタは、線形・正規の状態空間モデルで、条件付き分布（平均と分散）を逐次的に正確に計算する。正規性がなくても線形推定量の中で平均二乗誤差を最小にする。
- 予測誤差 $v_t = y_t - a_{t|t-1}$ とその分散 $F_t = P_{t|t-1} + \sigma_\varepsilon^2$ から、対数尤度 $-\frac{1}{2}\sum_t\{\log(2\pi F_t) + v_t^2/F_t\}$ が計算でき（予測誤差分解）、$\sigma_\varepsilon^2,\ \sigma_\eta^2$ を最尤推定できる。
