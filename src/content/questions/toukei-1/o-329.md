ARMA(1, 1) の自己相関は、ラグ 1 だけが MA 部分の影響を受け、ラグ 2 以降は $\rho(h) = \phi\rho(h-1)$ で減衰します。$\rho(1) = \dfrac{(1 + \phi\theta)(\phi + \theta)}{1 + 2\phi\theta + \theta^2} = \dfrac{1.2 \times 0.9}{1.56} = 0.6923$ なので、$\rho(2) = 0.5 \times 0.6923 \approx 0.346$ です。

### 計算

$\phi = 0.5,\ \theta = 0.4$ とします。$y_t$ に $\varepsilon_t,\ \varepsilon_{t-1}$ を掛けて期待値をとると、$E[y_t\varepsilon_t] = \sigma^2$、$E[y_t\varepsilon_{t-1}] = (\phi + \theta)\sigma^2 = 0.9\sigma^2$。これを使って

$$\gamma(0) = \phi\gamma(1) + \sigma^2 + \theta(\phi + \theta)\sigma^2,\qquad \gamma(1) = \phi\gamma(0) + \theta\sigma^2$$

を解くと

$$\gamma(0) = \frac{1 + 2\phi\theta + \theta^2}{1 - \phi^2}\sigma^2 = \frac{1.56}{0.75}\sigma^2 = 2.08\sigma^2,\qquad \gamma(1) = \frac{(1 + \phi\theta)(\phi + \theta)}{1 - \phi^2}\sigma^2 = \frac{1.08}{0.75}\sigma^2 = 1.44\sigma^2$$

$$\rho(1) = \frac{1.44}{2.08} = 0.6923,\qquad \rho(2) = \phi\rho(1) = 0.3462$$

（$h \geq 2$ では $y_{t-h}$ が $\varepsilon_t,\ \varepsilon_{t-1}$ と無相関なので、$\gamma(h) = \phi\gamma(h-1)$ が成り立ちます。）

### ポイント

- よくある誤り：AR(1) とみなして $\rho(2) = \phi^2 = 0.25$ とする、または $\rho(1) = \phi + \theta = 0.9$ として $\rho(2) = 0.45$ とする。MA 項はラグ 1 の自己相関を押し上げるが、その後の減衰率は AR 係数 $\phi$ で決まる。
- ARMA($p$, $q$) の自己相関は、ラグ $q$ を超えると AR 部分の差分方程式 $\rho(h) = \phi_1\rho(h-1) + \cdots + \phi_p\rho(h-p)$ に従う。自己相関・偏自己相関がどちらも切断されずに減衰することが、ARMA を識別する手がかりになる。
