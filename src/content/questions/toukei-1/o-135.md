modelAnswer: |
  **[1]** 各試行で第 $j$ カテゴリに入るかを表す指示変数を $\delta_{lj}\ (l = 1, \ldots, n)$ とすると $N_j = \sum_l \delta_{lj}$。同じ試行では $\delta_{li}\delta_{lj} = 0\ (i \neq j)$、異なる試行は独立なので

  $$E[\hat{p}_j] = p_j,\qquad V[\hat{p}_j] = \frac{p_j(1 - p_j)}{n},\qquad \mathrm{Cov}(\hat{p}_i, \hat{p}_j) = \frac{1}{n}(0 - p_ip_j) = -\frac{p_ip_j}{n}$$

  **[2]** $N_2 - np_2 = (n - N_1) - n(1 - p_1) = -(N_1 - np_1)$ なので

  $$X^2 = (N_1 - np_1)^2\left(\frac{1}{np_1} + \frac{1}{np_2}\right) = \frac{(N_1 - np_1)^2}{np_1p_2} = \left\{\frac{\sqrt{n}(\hat{p}_1 - p_1)}{\sqrt{p_1(1 - p_1)}}\right\}^2$$

  中心極限定理より中括弧内は $N(0, 1)$ に分布収束し、連続写像定理（$x \mapsto x^2$）より $X^2 \xrightarrow{d} \chi^2(1)$。

  **[3]** $\sqrt{n}(\hat{\boldsymbol{p}} - \boldsymbol{p})$ は独立同一分布のベクトル $(\delta_{l1}, \ldots, \delta_{lk})$ の和を標準化したものなので、多変量中心極限定理と [1] より

  $$\sqrt{n}(\hat{\boldsymbol{p}} - \boldsymbol{p}) \xrightarrow{d} N_k\big(\mathbf{0},\ \mathrm{diag}(\boldsymbol{p}) - \boldsymbol{p}\boldsymbol{p}^\top\big)$$

  $\boldsymbol{Y} = D\sqrt{n}(\hat{\boldsymbol{p}} - \boldsymbol{p})$、$D = \mathrm{diag}(1/\sqrt{p_1}, \ldots, 1/\sqrt{p_k})$ なので

  $$\boldsymbol{Y} \xrightarrow{d} N_k(\mathbf{0},\ A),\qquad A = D\big(\mathrm{diag}(\boldsymbol{p}) - \boldsymbol{p}\boldsymbol{p}^\top\big)D = I_k - \boldsymbol{q}\boldsymbol{q}^\top$$

  $\boldsymbol{q}^\top\boldsymbol{q} = \sum p_j = 1$ より $A^2 = I - 2\boldsymbol{q}\boldsymbol{q}^\top + \boldsymbol{q}(\boldsymbol{q}^\top\boldsymbol{q})\boldsymbol{q}^\top = A$ でべき等、階数は $\mathrm{tr}\,A = k - \boldsymbol{q}^\top\boldsymbol{q} = k - 1$（べき等行列の階数はトレースに等しい）。$X^2 = \boldsymbol{Y}^\top\boldsymbol{Y}$ で $\boldsymbol{y} \mapsto \boldsymbol{y}^\top\boldsymbol{y}$ は連続なので、連続写像定理と与えられた事実より

  $$X^2 \xrightarrow{d} \chi^2(k - 1)$$

適合度検定や分割表の検定で使うピアソンのカイ二乗統計量が、なぜ自由度 $k - 1$ のカイ二乗分布に近づくのかを示す問題です。$k$ 個の度数には「合計が $n$」という 1 本の制約があり、それが極限の分散共分散行列の階数を 1 つ下げます。

### 解答の流れ

1. 多項分布を「独立な試行ごとの指示ベクトルの和」とみて、平均・分散共分散を計算する。
2. $k = 2$ では、2 つの度数の偏差が符号違いで等しいことから、二項分布の標準化の 2 乗になる。
3. 一般の $k$ では、多変量中心極限定理で極限の正規分布を求め、その共分散行列が射影行列 $I - \boldsymbol{q}\boldsymbol{q}^\top$ であることを使う。

### つまずきやすい点

- 共分散の符号：1 回の試行で 2 つのカテゴリに同時に入ることはないので、$N_i$ と $N_j$ は負の相関をもつ。
- $Y_j$ を独立な $N(0, 1)$ と誤解して $\chi^2(k)$ とする誤り。$\sum_j\sqrt{p_j}Y_j = \sum_j(N_j - np_j)/\sqrt{n} = 0$ という線形制約があるので、自由度は 1 減る。
- 多変量正規分布の共分散行列 $\mathrm{diag}(\boldsymbol{p}) - \boldsymbol{p}\boldsymbol{p}^\top$ は特異（$\mathbf{1}$ 方向の分散が 0）であり、逆行列をとる議論はそのままではできない。

### ポイント

- 母数を $s$ 個推定してから期待度数を計算する場合、極限分布は $\chi^2(k - 1 - s)$ になる（最尤推定量などの効率的な推定量を用いる場合）。分割表の独立性の検定の自由度 $(r - 1)(c - 1)$ はこれから得られる。
- 尤度比統計量 $G^2 = 2\sum N_j\log\{N_j/(np_j)\}$ も $X^2$ と漸近的に同等であり、同じ $\chi^2(k-1)$ に分布収束する。
