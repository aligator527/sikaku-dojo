ルービンのルールでは、全分散を「代入内分散の平均 $\bar{U}$」と「代入間分散 $B$ に $(1 + 1/m)$ を掛けたもの」の和 $T = \bar{U} + (1 + 1/m)B$ とします。$\bar{U} = 0.40$、$B = 0.125$ より $T = 0.40 + 1.2 \times 0.125 = 0.55$、標準誤差は $\sqrt{0.55} = 0.742$ です。

### 計算

$$\bar{Q} = \frac{10.2 + 10.8 + 9.9 + 10.5 + 10.6}{5} = \frac{52.0}{5} = 10.4$$

$$\bar{U} = \frac{0.40 + 0.42 + 0.38 + 0.41 + 0.39}{5} = 0.40$$

$$B = \frac{1}{m - 1}\sum_{l=1}^{5}(\hat{Q}_l - \bar{Q})^2 = \frac{0.04 + 0.16 + 0.25 + 0.01 + 0.04}{4} = \frac{0.50}{4} = 0.125$$

$$T = \bar{U} + \left(1 + \frac{1}{m}\right)B = 0.40 + 1.2 \times 0.125 = 0.55,\qquad \sqrt{T} = 0.7416 \approx 0.742$$

### ポイント

- $B$ は欠測による不確かさ（代入値が一意に決まらないこと）を表します。$\bar{U}$ だけを使うと標準誤差は $\sqrt{0.40} = 0.632$ となり、不確かさを過小評価します。
- $(1 + 1/m)$ は、代入の回数 $m$ が有限であることによる $\bar{Q}$ のばらつきの補正です。省くと $\sqrt{0.525} = 0.725$ となります。
- 欠測による情報の損失の割合は $(1 + 1/m)B/T = 0.15/0.55 \approx 0.27$ と見積もれます。信頼区間には自由度 $\nu = (m - 1)\{1 + \bar{U}/((1 + 1/m)B)\}^2$ の $t$ 分布を用います。
