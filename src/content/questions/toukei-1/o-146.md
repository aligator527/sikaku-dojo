事後分布は事前分布と尤度の積に比例し、$\lambda^{\alpha + T - 1}e^{-(\beta + n)\lambda}$ の形なので $Ga(\alpha + T,\ \beta + n) = Ga(20,\ 6)$ です。2 乗誤差損失のベイズ推定量は事後平均で、$20/6 = 3.333$ です。

### 計算

$$\pi(\lambda \mid \boldsymbol{x}) \propto \lambda^{\alpha-1}e^{-\beta\lambda}\cdot\prod_{i=1}^{n}e^{-\lambda}\lambda^{x_i} = \lambda^{\alpha + T - 1}e^{-(\beta + n)\lambda}$$

$$E[\lambda \mid \boldsymbol{x}] = \frac{\alpha + T}{\beta + n} = \frac{3 + 17}{1 + 5} = \frac{20}{6} = 3.333$$

### 縮小推定としての解釈

事後平均は、事前平均 $\alpha/\beta = 3$ と標本平均 $\bar{x} = 3.4$ の重み付き平均です。

$$\frac{\alpha + T}{\beta + n} = \frac{\beta}{\beta + n}\cdot\frac{\alpha}{\beta} + \frac{n}{\beta + n}\cdot\bar{x} = \frac{1}{6} \times 3 + \frac{5}{6} \times 3.4 = 3.333$$

$n$ が大きいほど標本平均の重みが大きくなります。

### ポイント

- ガンマ分布はポアソン分布の共役事前分布であり、事後分布も同じ族に入る。$\beta$ は「事前に観測した期間の数」、$\alpha$ は「その間の総件数」と解釈できる。
- よくある誤り：事後分布の最頻値 $(\alpha + T - 1)/(\beta + n) = 19/6 = 3.167$ を答える（これは 0-1 損失の極限に対応する）。または率母数と尺度母数を取り違えて $(\alpha + T)(\beta + n)$ などとする。
