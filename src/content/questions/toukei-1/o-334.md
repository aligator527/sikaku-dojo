カルマンフィルタの「更新 → 予測 → 更新」を 1 回ずつ行います。$t = 1$ ではゲイン $K_1 = 4/(4 + 4) = 0.5$ で $a_{1|1} = 11$、$P_{1|1} = 2$。予測で $P_{2|1} = 2 + 1 = 3$ となり、$t = 2$ のゲインは $K_2 = 3/7$、$a_{2|2} = 11 + \frac{3}{7}(9 - 11) = 71/7 \approx 10.14$ です。

### 計算

**$t = 1$ の更新**

$$K_1 = \frac{P_{1|0}}{P_{1|0} + \sigma_\varepsilon^2} = \frac{4}{8} = 0.5,\qquad a_{1|1} = 10 + 0.5 \times (12 - 10) = 11,\qquad P_{1|1} = (1 - 0.5) \times 4 = 2$$

**$t = 2$ の予測**

$$a_{2|1} = a_{1|1} = 11,\qquad P_{2|1} = P_{1|1} + \sigma_\eta^2 = 2 + 1 = 3$$

**$t = 2$ の更新**

$$K_2 = \frac{3}{3 + 4} = \frac{3}{7} = 0.4286,\qquad a_{2|2} = 11 + \frac{3}{7}(9 - 11) = 11 - \frac{6}{7} = \frac{71}{7} = 10.143$$

$$P_{2|2} = \left(1 - \frac{3}{7}\right) \times 3 = \frac{12}{7} = 1.714$$

### ポイント

- よくある誤り：予測のステップで $\sigma_\eta^2$ を加え忘れて $P_{2|1} = 2$ とすると、$K_2 = 1/3$、$a_{2|2} = 10.33$ となる。水準がランダムウォークで動く分だけ、前期の推定値の不確かさは増える。
- この設定（$q = \sigma_\eta^2/\sigma_\varepsilon^2 = 0.25$）の定常ゲインは $\bar{K} = 0.390$ で、ゲインは $0.5 \to 0.429 \to \cdots$ と定常値に近づいていく。初期の不確かさ $P_{1|0}$ が大きいほど、最初の観測値を強く信頼する。
- 次期の予測値 $E[y_3 \mid Y_2] = a_{2|2} = 10.14$、その予測誤差分散は $P_{2|2} + \sigma_\eta^2 + \sigma_\varepsilon^2 = 1.714 + 1 + 4 = 6.714$ である。
