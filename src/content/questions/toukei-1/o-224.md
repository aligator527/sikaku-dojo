  $\lambda$ が与えられたとき、$X_1, \ldots, X_n$ は互いに独立にポアソン分布 $Po(\lambda)$ に従うとする。$\lambda$ の事前分布をガンマ分布 $Ga(\alpha, \beta)$（密度 $\dfrac{\beta^{\alpha}}{\Gamma(\alpha)}\lambda^{\alpha - 1}e^{-\beta\lambda},\ \lambda > 0$；$\alpha, \beta > 0$ は既知）とする。$S = \sum_{i=1}^{n}X_i$ とおく。以下の各問に答えよ。

  [1] $\lambda$ の事後分布を求めよ。

  [2] 2 乗誤差損失のもとでのベイズ推定量を求め、それが標本平均 $\bar{X}$ と事前平均 $\alpha/\beta$ の加重平均として表せることを示せ。$n \to \infty$ のときの重みの変化についても述べよ。

  [3] 次の観測値 $X_{n+1}$（$\lambda$ が与えられたとき $X_1, \ldots, X_n$ と独立に $Po(\lambda)$ に従う）の事後予測分布 $P(X_{n+1} = k \mid X_1, \ldots, X_n)$ を求めよ。また、その平均と分散を求めよ。

  [4] $\alpha = 2,\ \beta = 1$ とし、$n = 4$ 日間の観測値の合計が $S = 10$ であった。$\lambda$ の事後平均と事後分散、および翌日の観測値が 0 となる事後予測確率を小数第 4 位まで求めよ。$(5/6)^{12} = 0.1122$ とする。
modelAnswer: |
  **[1]** 尤度は $\prod_i e^{-\lambda}\lambda^{x_i}/x_i! \propto \lambda^{S}e^{-n\lambda}$ なので

  $$\pi(\lambda \mid \boldsymbol{x}) \propto \lambda^{S}e^{-n\lambda}\cdot\lambda^{\alpha - 1}e^{-\beta\lambda} = \lambda^{\alpha + S - 1}e^{-(\beta + n)\lambda}$$

  これはガンマ分布 $Ga(\alpha + S,\ \beta + n)$ の核であり、事後分布は $Ga(\alpha + S,\ \beta + n)$ である（ガンマ分布はポアソン分布の共役事前分布）。

  **[2]** 2 乗誤差損失のベイズ推定量は事後平均なので

  $$\hat{\lambda}_B = \frac{\alpha + S}{\beta + n} = \frac{n}{\beta + n}\bar{X} + \frac{\beta}{\beta + n}\cdot\frac{\alpha}{\beta}$$

  重み $w = n/(\beta + n)$ は $n \to \infty$ で 1 に近づき、ベイズ推定量は最尤推定量 $\bar{X}$ に近づく（データが増えるほど事前分布の影響が小さくなる）。$\beta$ は「事前分布が何日分の観測に相当するか」を表す。

  **[3]** $\alpha' = \alpha + S,\ \beta' = \beta + n$ とすると

  $$P(X_{n+1} = k \mid \boldsymbol{x}) = \int_0^{\infty}\frac{e^{-\lambda}\lambda^{k}}{k!}\cdot\frac{\beta'^{\alpha'}}{\Gamma(\alpha')}\lambda^{\alpha' - 1}e^{-\beta'\lambda}\,d\lambda = \frac{\Gamma(\alpha' + k)}{\Gamma(\alpha')\,k!}\cdot\frac{\beta'^{\alpha'}}{(\beta' + 1)^{\alpha' + k}}$$

  $$= \frac{\Gamma(\alpha' + k)}{\Gamma(\alpha')\,k!}\left(\frac{\beta'}{\beta' + 1}\right)^{\alpha'}\left(\frac{1}{\beta' + 1}\right)^{k}\qquad (k = 0, 1, 2, \ldots)$$

  で、これは負の二項分布である。平均と分散は、繰り返し期待値と全分散の公式から

  $$E[X_{n+1} \mid \boldsymbol{x}] = E[\lambda \mid \boldsymbol{x}] = \frac{\alpha'}{\beta'}$$

  $$V[X_{n+1} \mid \boldsymbol{x}] = E[\lambda \mid \boldsymbol{x}] + V[\lambda \mid \boldsymbol{x}] = \frac{\alpha'}{\beta'} + \frac{\alpha'}{\beta'^2}$$

  **[4]** 事後分布は $Ga(2 + 10,\ 1 + 4) = Ga(12, 5)$。

  $$E[\lambda \mid \boldsymbol{x}] = \frac{12}{5} = 2.4,\qquad V[\lambda \mid \boldsymbol{x}] = \frac{12}{25} = 0.48$$

  （$\bar{x} = 2.5$ と事前平均 $2$ を重み $0.8 : 0.2$ で平均した値が $2.4$。）事後予測確率は

  $$P(X_5 = 0 \mid \boldsymbol{x}) = \left(\frac{5}{6}\right)^{12} = 0.1122$$

ポアソン・ガンマモデルは、共役事前分布によるベイズ推定の代表例です。事後平均が「データの平均」と「事前の平均」の加重平均になること（縮小推定）と、事後予測分布が $\lambda$ の不確かさを反映して負の二項分布（ポアソン分布より分散が大きい）になることがポイントです。

### 解答の流れ

1. 尤度を $\lambda$ の関数として書き、事前密度と掛けてガンマ分布の核を見つける。
2. 事後平均を変形して加重平均の形にする。
3. 事後予測分布は、ポアソン確率を事後分布で積分する。積分はガンマ関数の定義で計算できる。
4. 数値を代入する。$k = 0$ のとき予測確率は $(\beta'/(\beta' + 1))^{\alpha'}$ と簡単になる。

### つまずきやすい点

- 事後予測確率を、事後平均を代入したポアソン確率 $e^{-2.4} \approx 0.0907$ で代用する誤り。$\lambda$ の不確かさを無視しているため、0 となる確率を過小評価します。
- ガンマ分布の母数の取り方（率母数 $\beta$ か尺度母数 $1/\beta$ か）を取り違えると、事後平均が $(\alpha + S)\beta/(1 + n\beta)$ のように変わります。問題文の密度の形で確認します。
- 予測分布の分散は $E[\lambda \mid \boldsymbol{x}]$ だけではありません。全分散の公式で $V[\lambda \mid \boldsymbol{x}]$ が加わり、[4] では $2.4 + 0.48 = 2.88$ になります。

### ポイント

- 共役事前分布の母数は「仮想的なデータ」と解釈できます。$Ga(\alpha, \beta)$ は「$\beta$ 日間に合計 $\alpha$ 件観測した」情報に相当します。
- 2 乗誤差損失では事後平均、絶対誤差損失では事後中央値、0–1 損失（の極限）では事後最頻値がベイズ推定量になります。
