打切りのある指数分布の最尤推定量は $\hat{\lambda} = d/T$（イベント数 / 総観察時間）で、$\log\hat{\lambda}$ の漸近分散は $1/d$ です。ハザード比の推定値は $(30/600)/(45/500) = 0.05/0.09 = 5/9$、$\log(5/9) = -0.5878$、標準誤差は $\sqrt{1/30 + 1/45} = 0.2357$ なので、$Z = -0.5878/0.2357 = -2.49$ です。

### 計算

各患者の観察時間を $t_i$、イベントの有無を $\delta_i$ とすると、1 群の対数尤度は

$$\ell(\lambda) = \sum_i\{\delta_i\log\lambda - \lambda t_i\} = d\log\lambda - \lambda T$$

（イベントは密度 $\lambda e^{-\lambda t}$、打切りは生存関数 $e^{-\lambda t}$ で寄与）。$\ell'(\lambda) = d/\lambda - T = 0$ より $\hat{\lambda} = d/T$、観測情報量は $d/\lambda^2$ なので $\hat{V}[\hat{\lambda}] = \hat{\lambda}^2/d$、デルタ法より $\hat{V}[\log\hat{\lambda}] = 1/d$ です。2 群は独立なので

$$\widehat{\mathrm{SE}}\left[\log\frac{\hat{\lambda}_1}{\hat{\lambda}_0}\right] = \sqrt{\frac{1}{30} + \frac{1}{45}} = \sqrt{0.05556} = 0.2357$$

$$\log\frac{5}{9} = \log 5 - 2\log 3 = 1.6094 - 2.1972 = -0.5878,\qquad Z = \frac{-0.5878}{0.2357} = -2.49$$

$|Z| = 2.49 > 1.96$ なので、有意水準 5%（両側）でハザード比 1 の帰無仮説は棄却されます。

### ポイント

- 標準誤差を決めるのは症例数ではなくイベント数。生存時間解析の検出力がイベント数で決まる（シェーンフェルトの式など）のはこのためである。
- よくある誤り：$\hat{\lambda}$ を「イベント数 / 患者数」とする（観察時間の違いと打切りを無視）、$\log$ をとらずにハザード比 $0.556$ の標準誤差を $1/d$ から作る。
- 95% 信頼区間は $\exp(-0.5878 \pm 1.96 \times 0.2357)$ で $[0.35,\ 0.88]$ となり、対数尺度で対称、元の尺度では非対称になる。
