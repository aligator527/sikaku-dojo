  $a > 0,\ b > 0$ とする。確率変数 $X,\ Y$ は互いに独立で、それぞれ確率密度関数

modelAnswer: |
  **[1]** 逆変換は $x = uv,\ y = u(1 - v)$（$u > 0,\ 0 < v < 1$）である。

  $$\frac{\partial(x, y)}{\partial(u, v)} = \det\begin{pmatrix} v & u \\ 1 - v & -u \end{pmatrix} = -uv - u(1 - v) = -u$$

  よってヤコビアンの絶対値は $u$ で、

  $$f_{U,V}(u, v) = f_X(uv)\,f_Y(u(1-v))\cdot u = \frac{u^{a+b-1}e^{-u}\,v^{a-1}(1-v)^{b-1}}{\Gamma(a)\Gamma(b)}\qquad (u > 0,\ 0 < v < 1)$$

  **[2]** 同時密度は $u$ だけの関数と $v$ だけの関数の積に分解でき、定義域も直積 $(0, \infty) \times (0, 1)$ なので $U$ と $V$ は独立である。定数を整理すると

  $$f_{U,V}(u, v) = \underbrace{\frac{u^{a+b-1}e^{-u}}{\Gamma(a+b)}}_{Ga(a+b,\,1)}\cdot\underbrace{\frac{\Gamma(a+b)}{\Gamma(a)\Gamma(b)}v^{a-1}(1-v)^{b-1}}_{\mathrm{Beta}(a,\,b)}$$

  したがって $U \sim Ga(a + b, 1)$、$V \sim \mathrm{Beta}(a, b)$ である。

  **[3]** $X = UV$ で $U$ と $V$ は独立なので、$E[X^k] = E[U^k]E[V^k]$。ガンマ分布のモーメント $E[X^k] = \Gamma(a+k)/\Gamma(a)$ を用いると

  $$E[V] = \frac{E[X]}{E[U]} = \frac{a}{a+b},\qquad E[V^2] = \frac{E[X^2]}{E[U^2]} = \frac{a(a+1)}{(a+b)(a+b+1)}$$

  よって

  $$V[V] = \frac{a(a+1)}{(a+b)(a+b+1)} - \frac{a^2}{(a+b)^2} = \frac{ab}{(a+b)^2(a+b+1)}$$

  **[4]** $X = 2X',\ Y = 2Y'$（$X' \sim Ga(m/2, 1)$、$Y' \sim Ga(n/2, 1)$、独立）と書ける。$X$ と $Y$ は独立なので

  $$E[F] = \frac{n}{m}E[X]\,E\left[\frac{1}{Y}\right]$$

  $E[X] = m$ であり、$n > 2$ のとき

  $$E\left[\frac{1}{Y'}\right] = \int_0^\infty \frac{y^{n/2-2}e^{-y}}{\Gamma(n/2)}\,dy = \frac{\Gamma(n/2 - 1)}{\Gamma(n/2)} = \frac{1}{n/2 - 1}$$

  より $E[1/Y] = \dfrac{1}{2}\cdot\dfrac{2}{n-2} = \dfrac{1}{n-2}$。したがって $E[F] = \dfrac{n}{m}\cdot m\cdot\dfrac{1}{n-2} = \dfrac{n}{n-2}$。

  （補足）$V = X/(X + Y) = \dfrac{mF}{mF + n}$ は尺度に依存しないので $V \sim \mathrm{Beta}(m/2,\ n/2)$ であり、$F$ 分布とベータ分布はこの単調変換で結ばれる。

ガンマ分布に従う独立な 2 変数の和と比が独立になることは、ベータ分布・$F$ 分布・ディリクレ分布を導く基本的な道具です。変数変換では、逆変換を書いてからヤコビアンを計算し、定義域の対応を確認するのが手順です。

### 解答の流れ

1. 逆変換 $x = uv,\ y = u(1-v)$ を求め、$\partial(x, y)/\partial(u, v)$ の行列式の絶対値を掛ける。
2. 同時密度が「$u$ の関数 × $v$ の関数」かつ定義域が直積になることから独立性を結論する。
3. $X = UV$ と独立性から、$V$ のモーメントを $X$ と $U$ のモーメントの比として求める。

### つまずきやすい点

- ヤコビアンを $\partial(u, v)/\partial(x, y)$ で計算した場合は、その逆数を掛ける必要がある。ここでは $\partial(u, v)/\partial(x, y) = -1/u$ なので、掛けるのは $u$ である。
- 独立性の判定では、密度の積への分解に加えて、定義域が直積であることの確認が必要である（たとえば $0 < y < x$ のような定義域では独立にならない）。
- 「$E[X/(X+Y)] = E[X]/E[X+Y]$」は一般には成り立たない。ここでは $X+Y$ と $X/(X+Y)$ が独立なので成り立つ（ガンマ分布の特別な性質）。

### ポイント

- $X_i \sim Ga(a_i, 1)$ が独立なとき、$(X_1, \ldots, X_k)/\sum X_i$ はディリクレ分布に従い、$\sum X_i$ と独立である。
- 尺度母数が共通であれば同じ議論が成り立つので、$\chi^2$ 分布の比（$F$ 分布）にもそのまま使える。
