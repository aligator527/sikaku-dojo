  確率関数が

  $$f(y;\theta, \phi) = \exp\left\{\frac{y\theta - b(\theta)}{a(\phi)} + c(y, \phi)\right\}$$

  の形に書ける分布族（指数型分布族）にもとづく一般化線形モデルを考える。以下の各問に答えよ。

  [1] ポアソン分布 $Po(\mu)$ をこの形に書き、$\theta,\ b(\theta),\ a(\phi)$ を求めよ。また、一般に $E[Y] = b'(\theta)$、$V[Y] = a(\phi)b''(\theta)$ が成り立つことを用いて、ポアソン分布の平均と分散を確かめ、正準リンク関数を答えよ。

  [2] 互いに独立な $Y_i \sim Po(\mu_i)$、$\log\mu_i = \boldsymbol{x}_i^\top\boldsymbol{\beta}$（$i = 1, \ldots, n$、$\boldsymbol{x}_i$ は第 1 成分が 1 の $p$ 次元ベクトル）とする。尤度方程式を導き、最尤推定値による当てはめ値 $\hat{\mu}_i$ について $\sum_i\hat{\mu}_i = \sum_iy_i$ が成り立つことを示せ。

  [3] 飽和モデル（$\hat{\mu}_i = y_i$）との対数尤度の差の 2 倍として定義される逸脱度 $D$ を求めよ。また、[2] の性質を用いて $D$ が簡単になることを示せ。

  [4] $n = 40,\ p = 3$ のポアソン回帰を当てはめたところ、ピアソンのカイ二乗統計量 $X^2 = \sum_i(y_i - \hat{\mu}_i)^2/\hat{\mu}_i$ は $74.0$ であった。分散を $\phi\mu_i$ とする準ポアソンモデルの考え方で $\phi$ を推定し、ポアソン回帰で $0.12$ と報告されたある係数の標準誤差を補正せよ。必要なら $\sqrt{2} = 1.414$ を用いよ。また、この補正が必要となる理由を述べよ。
modelAnswer: |
  **[1]** $f(y;\mu) = e^{-\mu}\mu^y/y! = \exp\{y\log\mu - \mu - \log y!\}$ なので

  $$\theta = \log\mu,\qquad b(\theta) = e^{\theta},\qquad a(\phi) = 1,\qquad c(y, \phi) = -\log y!$$

  $E[Y] = b'(\theta) = e^{\theta} = \mu$、$V[Y] = b''(\theta) = e^{\theta} = \mu$ となり、平均と分散がともに $\mu$ であることが確かめられる。自然母数 $\theta$ を線形予測子に等しくおくリンク $g(\mu) = \log\mu$（対数リンク）が正準リンクである。

  **[2]** 対数尤度は $\ell(\boldsymbol{\beta}) = \sum_i\{y_i\boldsymbol{x}_i^\top\boldsymbol{\beta} - e^{\boldsymbol{x}_i^\top\boldsymbol{\beta}} - \log y_i!\}$ なので

  $$\frac{\partial\ell}{\partial\boldsymbol{\beta}} = \sum_{i=1}^{n}\boldsymbol{x}_i(y_i - \mu_i) = \boldsymbol{0}$$

  が尤度方程式である。$\boldsymbol{x}_i$ の第 1 成分が 1 なので、第 1 成分の式は $\sum_i(y_i - \hat{\mu}_i) = 0$、すなわち $\sum_i\hat{\mu}_i = \sum_iy_i$。

  **[3]** 1 個の観測の対数尤度 $y\log\mu - \mu - \log y!$ について、飽和モデル（$\mu = y$）と当てはめたモデルの差をとり 2 倍すると

  $$D = 2\sum_{i=1}^{n}\left\{y_i\log\frac{y_i}{\hat{\mu}_i} - (y_i - \hat{\mu}_i)\right\}$$

  （$y_i = 0$ の項は $y_i\log y_i = 0$ とする）。切片を含むモデルでは [2] より $\sum_i(y_i - \hat{\mu}_i) = 0$ なので

  $$D = 2\sum_{i=1}^{n}y_i\log\frac{y_i}{\hat{\mu}_i}$$

  **[4]** $\hat{\phi} = X^2/(n - p) = 74.0/37 = 2.0$。準ポアソンモデルの推定値はポアソン回帰と同じで、分散共分散行列は $\phi$ 倍になるので、標準誤差は $\sqrt{\hat{\phi}}$ 倍に補正する。

  $$0.12 \times \sqrt{2.0} = 0.12 \times 1.414 = 0.170$$

  ポアソン分布は分散が平均に等しいという強い制約をもつが、実際の計数データでは個体差（観測されない異質性）や事象の集積によって分散が平均を上回る（過分散）ことが多い。$\hat{\phi} = 2$ は分散が仮定の約 2 倍であることを示す。そのままポアソン回帰の標準誤差を使うと過小評価になり、検定が有意になりすぎ、信頼区間が狭くなりすぎる。

一般化線形モデルの骨格（指数型分布族・正準リンク・尤度方程式・逸脱度・過分散）をポアソン回帰で確認する問題です。

### 解答の流れ

1. ポアソン分布の確率関数の対数をとり、$y$ と母数の積の項から自然母数 $\theta = \log\mu$ を読み取る。
2. 正準リンクでは尤度方程式が $X^\top(\boldsymbol{y} - \hat{\boldsymbol{\mu}}) = \boldsymbol{0}$ という形になり、切片があれば当てはめ値の総和が観測値の総和に一致する。
3. 逸脱度は飽和モデルとの対数尤度比である。
4. 過分散パラメータはピアソン統計量を残差自由度で割って推定し、標準誤差を $\sqrt{\hat{\phi}}$ 倍する。

### つまずきやすい点

- 標準誤差を $\hat{\phi}$ 倍（$0.24$）にする誤り。分散が $\phi$ 倍なので、標準誤差は $\sqrt{\phi}$ 倍である。
- $\hat{\phi}$ を $X^2/n$ とする誤り。$p$ 個の係数を推定しているので、残差自由度 $n - p$ で割る。
- 準ポアソンモデルにしても、係数の推定値は変わらない（推定方程式が同じ）。

### ポイント

- 正準リンクのもとでは、$X^\top\boldsymbol{y}$ が十分統計量になり、観測情報行列とフィッシャー情報行列が一致する。そのためニュートン・ラフソン法とフィッシャーのスコア法が同じ反復になる。
- 逸脱度や $X^2$ を自由度と比べる適合度の判断は、各 $\hat{\mu}_i$ がある程度大きい（目安 5 以上）ときに限って有効である。
