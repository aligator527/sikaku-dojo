  目的変数 $y$ と 2 つの説明変数 $x_1,\ x_2$ の間の相関係数が

  $$r_{y1} = 0.3,\qquad r_{y2} = 0.6,\qquad r_{12} = 0.7$$

  であった。$y$ を $x_1,\ x_2$ に回帰したときの標準化偏回帰係数 $(b_1^{*},\ b_2^{*})$ と決定係数 $R^2$ の組として正しいものを、次のうちから一つ選べ（値は小数第 4 位を四捨五入したもの）。
choices:
  - '$b_1^{*} = 0.300,\ b_2^{*} = 0.600,\ R^2 = 0.450$'
  - '$b_1^{*} = 0.588,\ b_2^{*} = 1.176,\ R^2 = 0.882$'
  - '$b_1^{*} = -0.120,\ b_2^{*} = 0.390,\ R^2 = 0.198$'
  - '$b_1^{*} = -0.235,\ b_2^{*} = 0.765,\ R^2 = 0.388$'
  - '$b_1^{*} = 0.235,\ b_2^{*} = 0.765,\ R^2 = 0.529$'
answer: 4

標準化偏回帰係数は正規方程式 $\begin{pmatrix} 1 & r_{12} \\ r_{12} & 1 \end{pmatrix}\begin{pmatrix} b_1^{*} \\ b_2^{*} \end{pmatrix} = \begin{pmatrix} r_{y1} \\ r_{y2} \end{pmatrix}$ の解で、$b_1^{*} = (0.3 - 0.6 \times 0.7)/(1 - 0.49) = -0.235$、$b_2^{*} = (0.6 - 0.3 \times 0.7)/0.51 = 0.765$ です。決定係数は $R^2 = b_1^{*}r_{y1} + b_2^{*}r_{y2} = 0.388$ となります。

### 計算

$$b_1^{*} = \frac{r_{y1} - r_{y2}r_{12}}{1 - r_{12}^2} = \frac{0.3 - 0.42}{0.51} = -0.2353,\qquad b_2^{*} = \frac{r_{y2} - r_{y1}r_{12}}{1 - r_{12}^2} = \frac{0.6 - 0.21}{0.51} = 0.7647$$

$$R^2 = b_1^{*}r_{y1} + b_2^{*}r_{y2} = -0.0706 + 0.4588 = 0.3882$$

（相関行列の行列式は $1 + 2(0.3)(0.6)(0.7) - 0.09 - 0.36 - 0.49 = 0.312 > 0$ で、この相関の組は実現可能です。）

### 各選択肢の検討

- $(0.300,\ 0.600,\ 0.450)$：説明変数が無相関（$r_{12} = 0$）とみなして、単相関をそのまま係数とし、$R^2 = r_{y1}^2 + r_{y2}^2$ とした誤り。
- $(0.588,\ 1.176,\ 0.882)$：公式の分子で $r_{y2}r_{12}$（または $r_{y1}r_{12}$）を引き忘れ、単相関を $1 - r_{12}^2$ で割っただけの誤り。$R^2$ が過大になる。
- $(-0.120,\ 0.390,\ 0.198)$：分子だけを計算し、$1 - r_{12}^2$ で割り忘れた誤り。
- $(-0.235,\ 0.765,\ 0.388)$：正しい。
- $(0.235,\ 0.765,\ 0.529)$：$b_1^{*}$ の分子の引き算の順序を逆にした符号の誤り。$y$ と正の相関をもつ $x_1$ の係数は正のはず、という思い込みでも起こる。

### ポイント

- $x_1$ は $y$ と正の相関（0.3）をもつのに、偏回帰係数は負になる。$x_1$ と $y$ の相関は $x_2$ との強い相関（0.7）を経由した見かけのもので、$x_2$ を一定にすると $x_1$ はむしろ $y$ と負の関係にある（偏相関 $r_{y1\cdot2} = -0.210$）。このように、それ自体は $y$ との相関が弱いのに、加えることで他の変数の係数を大きくし $R^2$ を高める変数を**抑制変数**という。
- $x_2$ だけの回帰では $R^2 = 0.36$。$x_1$ を加えると $0.388$ に増え、$b_2^{*}$ は単相関 0.6 より大きい 0.765 になる。
- 偏回帰係数の符号は、他の説明変数を含めるかどうかで変わりうる。単相関の符号だけで解釈しない。
