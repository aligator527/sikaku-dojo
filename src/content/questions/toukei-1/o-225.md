stem: |
  ある調査で、共変量 $X$ はすべての対象者で観測されるが、目的変数 $Y$ は一部の対象者で欠測する。$Y$ が観測されたとき $R = 1$、欠測したとき $R = 0$ とする。$(X_i, Y_i, R_i)\ (i = 1, \ldots, n)$ は互いに独立に同一の分布に従う。以下の各問に答えよ。

  [1] 欠測のメカニズム MCAR（完全にランダムな欠測）、MAR（ランダムな欠測）、MNAR（ランダムでない欠測）を、$P(R = 1 \mid X, Y)$ を用いて定義せよ。

  [2] 欠測が MAR のとき、$Y$ が観測された対象者だけで求めた $Y$ の平均（完全ケース平均）は、一般に $E[Y]$ の一致推定量にならない。一方、$X$ を与えたときの $Y$ の条件付き分布は、完全ケースだけから偏りなく推定できる。後者が成り立つ理由を示せ。

  [3] $X$ は 2 値（$X = 0, 1$ をそれぞれ確率 $0.5$ でとる）で、$E[Y \mid X = 0] = 10$、$E[Y \mid X = 1] = 20$、$P(R = 1 \mid X = 0, Y) = 0.8$、$P(R = 1 \mid X = 1, Y) = 0.4$ とする。完全ケース平均の確率極限を小数第 2 位まで求めよ。また、[2] の性質を用いて $E[Y]$ の一致推定量を構成せよ。

  [4] 母数 $\theta$ をもつ $(X, Y)$ の分布と、母数 $\psi$ をもつ欠測メカニズムを考える。MAR のもとで $\theta$ と $\psi$ が互いに関係しない（分離可能な）とき、観測データの尤度にもとづく $\theta$ の推測では欠測メカニズムを無視してよいことを示せ。
modelAnswer: |
  **[1]**

  - MCAR：$P(R = 1 \mid X, Y) = P(R = 1)$。欠測が $X$ にも $Y$ にも依存しない。
  - MAR：$P(R = 1 \mid X, Y) = P(R = 1 \mid X)$。欠測は観測されている $X$ を通じてのみ依存し、$X$ を与えれば $Y$ の値に依存しない。
  - MNAR：MAR が成り立たない。$X$ を与えても、欠測が $Y$ の値（観測されない値）に依存する。

  **[2]** ベイズの定理より、$Y$ の条件付き密度を $f(y \mid x)$ とすると

  $$f(y \mid x, R = 1) = \frac{P(R = 1 \mid x, y)f(y \mid x)}{P(R = 1 \mid x)} = \frac{P(R = 1 \mid x)f(y \mid x)}{P(R = 1 \mid x)} = f(y \mid x)$$

  （2 つ目の等号で MAR を用いた）。よって完全ケースにおける $Y$ の $X$ への条件付き分布は、母集団での条件付き分布と一致し、完全ケースによる回帰分析などは偏りなく $f(y \mid x)$ を推定できる。一方、完全ケースでの $X$ の分布は $P(R = 1 \mid x)$ によって母集団の分布から歪むので、$Y$ の周辺平均は一般に偏る。

  **[3]** $P(R = 1) = 0.5 \times 0.8 + 0.5 \times 0.4 = 0.6$。完全ケースでの $X$ の分布は $P(X = 0 \mid R = 1) = 0.4/0.6 = 2/3$、$P(X = 1 \mid R = 1) = 1/3$ なので、完全ケース平均は大数の法則により

  $$E[Y \mid R = 1] = \frac{2}{3} \times 10 + \frac{1}{3} \times 20 = 13.33$$

  に確率収束し、$E[Y] = 0.5 \times 10 + 0.5 \times 20 = 15$ より小さい。

  一致推定量：[2] より、完全ケースの $X = x$ の群での $Y$ の平均 $\bar{y}_x^{(1)}$ は $E[Y \mid X = x]$ の一致推定量である。全員について観測されている $X$ の割合 $\hat{p}_x$ で重み付けた

  $$\hat{\mu} = \hat{p}_0\,\bar{y}_0^{(1)} + \hat{p}_1\,\bar{y}_1^{(1)}$$

  は $0.5 \times 10 + 0.5 \times 20 = 15 = E[Y]$ に確率収束する（回帰による補完、または $1/P(R = 1 \mid X)$ による逆確率重み付けと同じ考え方）。

  **[4]** 観測データ $(x, y_{\text{obs}}, r)$ の尤度は、欠測した $y$ について積分して

  $$L(\theta, \psi) = \prod_{i: r_i = 1}f(x_i, y_i;\theta)P(R = 1 \mid x_i, y_i;\psi)\prod_{i: r_i = 0}\int f(x_i, y;\theta)P(R = 0 \mid x_i, y;\psi)\,dy$$

  MAR では $P(R = r \mid x, y;\psi) = P(R = r \mid x;\psi)$ なので、欠測メカニズムの因子を積分の外に出せて

  $$L(\theta, \psi) = \underbrace{\prod_{i: r_i = 1}f(x_i, y_i;\theta)\prod_{i: r_i = 0}f(x_i;\theta)}_{L_1(\theta)}\cdot\underbrace{\prod_{i}P(R = r_i \mid x_i;\psi)}_{L_2(\psi)}$$

  と分解できる（$f(x;\theta) = \int f(x, y;\theta)\,dy$）。$\theta$ と $\psi$ が分離可能なら、$\theta$ の最尤推定やベイズ推測（事前分布も独立なとき）は $L_1(\theta)$ だけで行え、欠測メカニズムをモデル化する必要はない（無視可能な欠測）。

欠測データの扱いでは、欠測の起こり方（メカニズム）によって、どの解析が妥当かが決まります。MAR は「観測された変数を条件にすれば欠測はランダム」という仮定で、このもとでは完全ケースの単純平均は偏りますが、条件付き分布の推定や尤度にもとづく推測は欠測メカニズムを無視して行えます。

### 解答の流れ

1. 欠測確率が何に依存するかで 3 つのメカニズムを定義する。
2. ベイズの定理で、完全ケースの条件付き分布が母集団と一致することを示す。
3. 完全ケースでは回答率の高い $X = 0$ の群が過大に代表されることを数値で確かめ、$X$ の分布で重み付け直す。
4. 観測データの尤度を書き、MAR で因子分解する。

### つまずきやすい点

- MAR は「欠測がランダム（何にも依存しない）」という意味ではありません。それは MCAR です。MAR では欠測が $X$ に依存してよく、そのため完全ケースの周辺平均は偏ります。
- MAR と MNAR は観測データだけからは区別できません（欠測した $Y$ の値は見えないため）。MNAR の可能性がある場合は、選択モデル・パターン混合モデルによる感度分析を行います。
- [4] の分解には、MAR に加えて母数の分離可能性が必要です。

### ポイント

- 多重代入法や EM アルゴリズムも、MAR のもとで観測データの尤度 $L_1(\theta)$ にもとづく推測を実行する方法です。
- 逆確率重み付け推定量 $\frac{1}{n}\sum_i R_iY_i/\hat{P}(R = 1 \mid X_i)$ も、MAR と欠測確率のモデルが正しければ $E[Y]$ の一致推定量になります。
