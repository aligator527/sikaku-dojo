最小二乗法は、各点の $y$ 方向のずれ（残差）$y_i - (a + bx_i)$ の 2 乗和を最小にする $a, b$ を求める方法です。$a$ と $b$ で偏微分して 0 とおいた正規方程式を解くと、$b = S_{xy}/S_{xx}$、$a = \bar{y} - b\bar{x}$ が得られます。

### 計算

$Q(a, b) = \sum (y_i - a - bx_i)^2$ とおきます。

$$\frac{\partial Q}{\partial a} = -2\sum (y_i - a - bx_i) = 0 \quad\Longrightarrow\quad a = \bar{y} - b\bar{x}$$

これを代入すると $Q = \sum \{(y_i - \bar{y}) - b(x_i - \bar{x})\}^2 = S_{yy} - 2bS_{xy} + b^2 S_{xx}$ となり、$b$ の 2 次関数として

$$b = \frac{S_{xy}}{S_{xx}}$$

で最小になります。

### 各選択肢の検討

- ①：絶対値の和を最小にする方法（最小絶対偏差法）は外れ値に強い方法ですが、最小二乗法ではありません。また、その解は一般に $S_{xy}/S_{xx}$ になりません。
- ②：残差の和は、$(\bar{x}, \bar{y})$ を通るどの直線でも 0 になり、正負が打ち消し合うので、最小化の基準になりません（いくらでも小さくできます）。
- ③：分母が誤りです。$S_{xy}/S_{yy}$ は $x$ を目的変数、$y$ を説明変数としたときの傾きです。
- ④：$y$ 方向のずれではなく直線までの距離を使う方法（直交回帰と呼ばれる別の方法）であり、目的変数 $y$ を予測する最小二乗法とは異なります。また $S_{xy}/\sqrt{S_{xx}S_{yy}}$ は相関係数です。
- ⑤：正しい。

### ポイント

- 最小二乗法は「$y$ の予測誤差の 2 乗和」を最小にする。$x$ と $y$ の役割を入れ替えると別の直線になる。
- $b = \dfrac{S_{xy}}{S_{xx}} = r\dfrac{s_y}{s_x}$、$a = \bar{y} - b\bar{x}$ はそのまま覚えて使えるようにする。
