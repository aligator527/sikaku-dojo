区間 $[a, b]$ 上の一様分布の分散は $(b-a)^2/12$ なので、$100/12 \approx 8.33$ です。確率密度は区間上で一定の $1/10$ なので、確率は区間の長さに比例し、$P(X > 7) = (10 - 7)/10 = 0.3$ となります。

### 計算

確率密度関数は $f(x) = \dfrac{1}{10}\ (0 \leq x \leq 10)$ です。

$$E[X] = \frac{0 + 10}{2} = 5,\qquad E[X^2] = \int_0^{10} \frac{x^2}{10}\,dx = \frac{100}{3}$$

$$V[X] = \frac{100}{3} - 5^2 = \frac{25}{3} \approx 8.33 \quad \left(= \frac{(10-0)^2}{12}\right)$$

$$P(X > 7) = \int_7^{10} \frac{1}{10}\,dx = 0.3$$

### 各選択肢の検討

- ①：$\sqrt{25/3} \approx 2.89$ は標準偏差です。
- ②：$0.7$ は $P(X \leq 7)$ です。「7 分を超える」のは区間 $(7, 10]$ です。
- ③：$E[X^2] = 100/3 \approx 33.3$ をそのまま分散としています。$(E[X])^2 = 25$ を引き忘れています。
- ④：正しい。
- ⑤：$(b-a)/12 = 10/12$ と、区間の長さを 2 乗し忘れています。

### ポイント

- 一様分布 $U(a, b)$：$E[X] = \dfrac{a+b}{2}$、$V[X] = \dfrac{(b-a)^2}{12}$。
- 連続型確率変数では、確率は確率密度関数の面積（積分）で求める。一点の確率は 0 なので、$P(X > 7)$ と $P(X \geq 7)$ は等しい。
