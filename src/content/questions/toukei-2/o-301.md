  離散型確率変数 $X$ の確率分布が次の表で与えられている。ただし、$a$ は定数である。

  | $x$ | 0 | 1 | 2 | 3 |
  | --- | --- | --- | --- | --- |
  | $P(X = x)$ | 0.2 | 0.3 | $a$ | 0.1 |

  $X$ の期待値 $E[X]$ と分散 $V[X]$ の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - '$E[X] = 1.5,\ V[X] = 1.25$'
  - '$E[X] = 1.4,\ V[X] = 2.80$'
  - '$E[X] = 1.4,\ V[X] = 1.40$'
  - '$E[X] = 1.4,\ V[X] = 0.84$'
  - '$E[X] = 1.4,\ V[X] = 0.92$'
answer: 4

確率の合計は 1 なので $a = 1 - (0.2 + 0.3 + 0.1) = 0.4$ です。期待値は「値 × 確率」の和で $1.4$、分散は $V[X] = E[X^2] - (E[X])^2$ を使うと $2.8 - 1.96 = 0.84$ になります。

### 計算

$$E[X] = 0 \times 0.2 + 1 \times 0.3 + 2 \times 0.4 + 3 \times 0.1 = 1.4$$

$$E[X^2] = 0^2 \times 0.2 + 1^2 \times 0.3 + 2^2 \times 0.4 + 3^2 \times 0.1 = 0.3 + 1.6 + 0.9 = 2.8$$

$$V[X] = E[X^2] - (E[X])^2 = 2.8 - 1.4^2 = 2.8 - 1.96 = 0.84$$

定義どおり $\sum (x - 1.4)^2 P(X = x)$ で計算しても $1.96 \times 0.2 + 0.16 \times 0.3 + 0.36 \times 0.4 + 2.56 \times 0.1 = 0.84$ となり、一致します。

### 各選択肢の検討

- ①：確率を無視して、4 つの値 $0, 1, 2, 3$ の単純な平均（$1.5$）と分散（$1.25$）を求めています。値ごとに確率が違うので、確率で重み付けする必要があります。
- ②：$E[X^2] = 2.8$ をそのまま分散としています。$(E[X])^2$ を引き忘れています。
- ③：$E[X^2] - E[X] = 2.8 - 1.4$ と、期待値を 2 乗せずに引いています。
- ④：正しい。
- ⑤：$\sqrt{0.84} \approx 0.92$ は標準偏差です。

### ポイント

- 離散型確率変数では $E[X] = \sum x\,P(X = x)$、$V[X] = E[X^2] - (E[X])^2$。
- 未知の定数は「確率の総和 ＝ 1」から決める。求めた確率が 0 以上 1 以下であることも確認する。
