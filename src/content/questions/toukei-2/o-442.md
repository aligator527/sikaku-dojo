  重回帰分析における決定係数 $R^2$ と自由度調整済み決定係数 $R^{*2}$ について、次の I〜III の記述を考える。ただし、$n$ を観測値の数、$p$ を説明変数の数として、$R^{*2} = 1 - \dfrac{(1 - R^2)(n - 1)}{n - p - 1}$ である。

  I. 説明変数を追加すると、$R^2$ は減少することはない（増加するか、変わらない）。

  II. 説明変数を追加すると、$R^{*2}$ は減少することがある。

  III. $R^{*2}$ は常に 0 以上 1 以下の値をとる。

  記述 I〜III の正誤について、正しいものを次のうちから一つ選べ。
choices:

  - 'I と II のみ正しい'
  - 'I と III のみ正しい'
  - 'I と II と III はすべて正しい'
answer: 3

$R^2$ は残差平方和だけで決まり、説明変数を追加しても残差平方和は増えないので、$R^2$ は減りません。自由度調整済み決定係数は、説明変数の数に応じた罰則を含むので、役に立たない変数を加えると減少することがあり、負の値にもなりえます。正しいのは I と II です。

### 各記述の検討

- I：正しい。最小二乗法では、変数を追加したモデルは、追加した変数の係数を 0 とすれば元のモデルと同じ当てはまりを再現できます。したがって残差平方和は増えず、$R^2 = 1 - (\text{残差平方和})/(\text{全平方和})$ は減りません。
- II：正しい。$p$ が増えると $\dfrac{n-1}{n-p-1}$ が大きくなるので、$R^2$ の増加がわずかなら $R^{*2}$ は減少します。
- III：誤り。$R^2$ が小さく説明変数が多いと負になります。たとえば $n = 20,\ p = 5,\ R^2 = 0.05$ なら $R^{*2} = 1 - 0.95 \times 19/14 \approx -0.29$ です。

### ポイント

- $R^{*2} = 1 - \dfrac{\text{残差平方和}/(n - p - 1)}{\text{全平方和}/(n - 1)}$。分子・分母とも「平方和 ÷ 自由度」の形になっている。
- 説明変数の数が異なるモデルを比べるときは、$R^2$ ではなく $R^{*2}$（や AIC など）を使う。
