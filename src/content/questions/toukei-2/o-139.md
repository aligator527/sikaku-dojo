  ある工場で、機械の稼働時間 $x$（時間）と製品の生産量 $y$（個）の関係を調べたところ、次の値が得られた。

  $$\bar{x} = 20,\quad \bar{y} = 50,\quad s_x = 4,\quad s_y = 10,\quad r_{xy} = 0.8$$

  ただし、$s_x, s_y$ は標準偏差、$r_{xy}$ は相関係数である。$y$ を目的変数、$x$ を説明変数とする最小二乗法による回帰直線として、正しいものを次のうちから一つ選べ。
choices:

  - '$\hat{y} = -50 + 5.0x$'
answer: 4

最小二乗法による回帰直線の傾きは $b = r_{xy}\,\dfrac{s_y}{s_x}$、切片は $a = \bar{y} - b\bar{x}$ です。$b = 0.8 \times 10/4 = 2.0$、$a = 50 - 2.0 \times 20 = 10$ なので、回帰直線は $\hat{y} = 10 + 2.0x$ です。

### 計算

$$b = r_{xy}\frac{s_y}{s_x} = 0.8 \times \frac{10}{4} = 2.0$$

$$a = \bar{y} - b\bar{x} = 50 - 2.0 \times 20 = 10$$

検算：回帰直線は点 $(\bar{x}, \bar{y}) = (20, 50)$ を通ります。$10 + 2.0 \times 20 = 50$ で一致します。

### 各選択肢の検討

- ①：相関係数 $0.8$ をそのまま傾きにしています。傾きが相関係数と一致するのは $s_x = s_y$ のときだけです。
- ②：標準偏差の比を逆にして $b = 0.8 \times 4/10 = 0.32$ としています。
- ③：切片を $\bar{y}$ としています。切片は $x = 0$ のときの予測値で、$\bar{y} - b\bar{x}$ です。
- ④：正しい。
- ⑤：標準偏差ではなく分散の比を使い、$b = 0.8 \times 100/16 = 5.0$ としています。

### ポイント

- $b = \dfrac{S_{xy}}{S_{xx}} = \dfrac{s_{xy}}{s_x^2} = r_{xy}\dfrac{s_y}{s_x}$。3 つの形はどれも同じで、与えられた情報に合わせて使い分ける。
- 傾きの符号は相関係数の符号と一致する。
