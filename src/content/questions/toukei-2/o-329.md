2 つの標本平均はそれぞれ $\bar{X}_A \sim N(72,\ 9^2/36)$、$\bar{X}_B \sim N(70,\ 8^2/16)$ に従い、独立です。差 $D = \bar{X}_A - \bar{X}_B$ は平均 2、分散 $2.25 + 4 = 6.25$（標準偏差 2.5）の正規分布に従うので、$P(D < 0) = P(Z < -0.80) = 0.2119$ です。

### 計算

$$V[\bar{X}_A] = \frac{9^2}{36} = 2.25,\qquad V[\bar{X}_B] = \frac{8^2}{16} = 4$$

$$D = \bar{X}_A - \bar{X}_B \sim N(72 - 70,\ 2.25 + 4) = N(2,\ 2.5^2)$$

$$P(\bar{X}_A < \bar{X}_B) = P(D < 0) = P\!\left(Z < \frac{0 - 2}{2.5}\right) = P(Z < -0.80) = P(Z > 0.80) = 0.2119$$

### ポイント

- 独立な 2 標本の平均の差：$\bar{X}_A - \bar{X}_B \sim N\!\left(\mu_A - \mu_B,\ \dfrac{\sigma_A^2}{n_A} + \dfrac{\sigma_B^2}{n_B}\right)$。母平均の差の区間推定・検定の土台になる。
- よくある誤り：標準誤差を足して $1.5 + 2 = 3.5$ とする（$z = 0.57$、確率 $0.2843$）。足すのは分散である。
- 母平均では A の方が高くても、標本平均では約 21% の確率で逆転する。標本の大きさが小さいほど逆転は起こりやすい。
