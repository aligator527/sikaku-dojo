2 個のサイコロの目を $D_1, D_2$ とすると $X = D_1 + D_2$ で、$D_1$ と $D_2$ は独立です。独立な確率変数の和の分散は、それぞれの分散の和になるので、1 個のサイコロの分散 $35/12$ を 2 倍して $35/6 \approx 5.83$ です。

### 計算

1 個のサイコロの目 $D$ について、

$$E[D] = \frac{1 + 2 + \cdots + 6}{6} = \frac{7}{2},\qquad E[D^2] = \frac{1 + 4 + 9 + 16 + 25 + 36}{6} = \frac{91}{6}$$

$$V[D] = \frac{91}{6} - \left(\frac{7}{2}\right)^2 = \frac{182 - 147}{12} = \frac{35}{12}$$

$D_1$ と $D_2$ は独立なので、

$$V[X] = V[D_1] + V[D_2] = 2 \times \frac{35}{12} = \frac{35}{6} \approx 5.833$$

和 $X$ の分布（2〜12 の 11 通り）を書き出して直接計算しても同じ値になりますが、独立性を使う方がはるかに速く計算できます。

### ポイント

- 独立なら $V[X + Y] = V[X] + V[Y]$。独立でないときは $2\,\mathrm{Cov}(X, Y)$ が加わる。
- 期待値の和の性質 $E[X + Y] = E[X] + E[Y]$ は独立でなくても成り立つが、分散の和の性質は独立（無相関）のときだけ成り立つ。
- よく出る誤り：$V[2D] = 4V[D] = 35/3$ と計算してしまう。$2D$ は「1 個のサイコロの目を 2 倍したもの」で、2 個の和 $D_1 + D_2$ とは別物である。
