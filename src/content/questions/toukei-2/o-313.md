  同じ駅から同じ職場へ向かう 2 人が同時に出発し、1 人は経路 A を、もう 1 人は経路 B を使う。経路 A と経路 B の所要時間（分）をそれぞれ $X_A$、$X_B$ とすると、$X_A$ は正規分布 $N(50,\ 3^2)$、$X_B$ は正規分布 $N(52,\ 4^2)$ に従い、$X_A$ と $X_B$ は互いに独立である。

  経路 A を使った人の方が先に職場に着く確率 $P(X_A < X_B)$ として、最も適切なものを次のうちから一つ選べ。

  必要なら、標準正規分布に従う確率変数 $Z$ について次の値を用いよ。

  $P(Z > 0.08) = 0.4681,\quad P(Z > 0.29) = 0.3859,\quad P(Z > 0.40) = 0.3446,\quad P(Z > 0.76) = 0.2236$
choices:
  - '$0.3446$'
  - '$0.5319$'
  - '$0.6141$'
  - '$0.6554$'
  - '$0.7764$'
answer: 4

差 $D = X_B - X_A$ を考えます。独立な正規分布に従う確率変数の差も正規分布に従い、平均は $52 - 50 = 2$、分散は「引き算でも足し算」の $3^2 + 4^2 = 25$ です。求める確率は $P(D > 0) = P(Z > -0.40) = 0.6554$ です。

### 計算

$$D = X_B - X_A \sim N(52 - 50,\ 3^2 + 4^2) = N(2,\ 5^2)$$

$$P(X_A < X_B) = P(D > 0) = P\!\left(Z > \frac{0 - 2}{5}\right) = P(Z > -0.40) = 1 - 0.3446 = 0.6554$$

### 各選択肢の検討

- ①：$P(Z > 0.40) = P(D < 0)$、つまり経路 B の人が先に着く確率です。
- ②：分散 25 で割って $z = -2/25 = -0.08$ とした誤りです。標準化には標準偏差 5 を使います。
- ③：差の標準偏差を $3 + 4 = 7$ として $z = -2/7 \approx -0.29$ とした誤りです。標準偏差は足し算できず、足すのは分散です。
- ④：正しい。
- ⑤：差の分散を $4^2 - 3^2 = 7$ と引き算して $z = -2/\sqrt{7} \approx -0.76$ とした誤りです。$V[X_B - X_A] = V[X_B] + (-1)^2 V[X_A]$ なので分散は足し算になります。

### ポイント

- 独立な正規確率変数の 1 次結合は正規分布に従う（再生性）：$aX + bY \sim N(a\mu_X + b\mu_Y,\ a^2\sigma_X^2 + b^2\sigma_Y^2)$。
- 「どちらが大きいか」の確率は、差をとって「差が 0 より大きい確率」に言い換える。
