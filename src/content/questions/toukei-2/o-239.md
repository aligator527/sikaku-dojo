  事象 $A$、$B$ について、$P(A) = 0.5$、$P(B) = 0.4$、$P(A \cap B) = 0.1$ である。$A$ または $B$ が起こる確率 $P(A \cup B)$ と、$A$ も $B$ も起こらない確率 $P(\bar{A} \cap \bar{B})$ の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - '$P(A \cup B) = 0.9,\ P(\bar{A} \cap \bar{B}) = 0.1$'
  - '$P(A \cup B) = 0.8,\ P(\bar{A} \cap \bar{B}) = 0.2$'
  - '$P(A \cup B) = 0.8,\ P(\bar{A} \cap \bar{B}) = 0.9$'
  - '$P(A \cup B) = 0.8,\ P(\bar{A} \cap \bar{B}) = 0.3$'
  - '$P(A \cup B) = 0.7,\ P(\bar{A} \cap \bar{B}) = 0.3$'
answer: 2

加法定理 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ より $P(A \cup B) = 0.5 + 0.4 - 0.1 = 0.8$ です。「$A$ も $B$ も起こらない」は「$A$ または $B$ が起こる」の余事象なので（ド・モルガンの法則 $\bar{A} \cap \bar{B} = \overline{A \cup B}$）、その確率は $1 - 0.8 = 0.2$ です。

### 計算

$$P(A \cup B) = 0.5 + 0.4 - 0.1 = 0.8$$

$$P(\bar{A} \cap \bar{B}) = P(\overline{A \cup B}) = 1 - P(A \cup B) = 0.2$$

### 各選択肢の検討

- ①：$P(A) + P(B) = 0.9$ で、$A \cap B$ を 2 回数えています。
- ②：正しい。
- ③：$1 - P(A \cap B) = 0.9$ は「$A$ と $B$ が同時には起こらない」確率 $P(\bar{A} \cup \bar{B})$ です。$\bar{A} \cap \bar{B}$ とは異なります。
- ④：$P(\bar{A} \cap \bar{B})$ を $P(\bar{A})P(\bar{B}) = 0.5 \times 0.6$ と計算しています。これは $A$ と $B$ が独立な場合に限られます。ここでは $P(A)P(B) = 0.2 \neq 0.1 = P(A \cap B)$ なので独立ではありません。
- ⑤：独立を仮定して $P(A \cap B) = 0.2$ とした値です。与えられた $P(A \cap B) = 0.1$ を使います。

### ポイント

- 加法定理：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$。排反なら $P(A \cap B) = 0$。
- ド・モルガンの法則：$\overline{A \cup B} = \bar{A} \cap \bar{B}$、$\overline{A \cap B} = \bar{A} \cup \bar{B}$。「どちらも起こらない」は余事象で考える。
