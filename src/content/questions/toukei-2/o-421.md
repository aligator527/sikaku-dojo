独立性の仮説のもとでの期待度数は（行の合計）×（列の合計）÷（総数）で求めます。「20 代・和食」は $80 \times 150/400 = 30.0$ で、観測度数 18 との差は $-12$ なので、寄与は $(-12)^2/30 = 4.80$ です。

### 計算

$$E = \frac{80 \times 150}{400} = 30.0,\qquad \frac{(O - E)^2}{E} = \frac{(18 - 30)^2}{30} = \frac{144}{30} = 4.80$$

参考までに、すべてのセルについて寄与を合計するとカイ二乗統計量は約 11.93 となり、自由度 $(3-1)(3-1) = 4$ の上側 5% 点 9.488 を超えます。

### 各選択肢の検討

- ①：$|O - E|/E = 12/30$ で、差を 2 乗し忘れています。
- ②：正しい。
- ③：観測度数 $O = 18$ で割っています（$144/18 = 8.00$）。分母は期待度数です。
- ④：20 代の合計 80 を 3 つのメニューに均等に割り振った値 $80/3$ です。列の合計（メニューごとの人気の違い）を無視しています。
- ⑤：和食の合計 150 を 3 つの年代に均等に割り振った値 $150/3$ です。行の合計（年代ごとの人数の違い）を無視しています。

### ポイント

- 行 $i$ のカテゴリーを $A_i$、列 $j$ のカテゴリーを $B_j$ とすると、独立なら $P(A_i \cap B_j) = P(A_i)P(B_j)$ なので、期待度数は $E_{ij} = N \times \dfrac{R_i}{N} \times \dfrac{C_j}{N} = \dfrac{R_i C_j}{N}$（$R_i$ は行の合計、$C_j$ は列の合計）。
- 期待度数の行和・列和は、観測度数の行和・列和と一致する。検算に使える。
