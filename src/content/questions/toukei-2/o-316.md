  連続型確率変数 $X$ の確率密度関数が、定数 $c$ を用いて

  $$f(x) = \begin{cases} cx & (0 \leq x \leq 3) \\ 0 & (\text{それ以外}) \end{cases}$$

  で与えられている。定数 $c$ の値と $X$ の期待値 $E[X]$ の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - '$c = \dfrac{1}{3},\ E[X] = 1.5$'
  - '$c = \dfrac{1}{9},\ E[X] = 1$'
  - '$c = \dfrac{2}{9},\ E[X] = 1.5$'
  - '$c = \dfrac{2}{9},\ E[X] = 4.5$'
  - '$c = \dfrac{2}{9},\ E[X] = 2$'
answer: 5

確率密度関数は全区間で積分すると 1 になるので、$\int_0^3 cx\,dx = \dfrac{9}{2}c = 1$ から $c = \dfrac{2}{9}$ です。期待値は $\int x f(x)\,dx$ で、$\dfrac{2}{9} \times \dfrac{3^3}{3} = 2$ になります。密度が右上がりなので、期待値は区間の中点 $1.5$ より大きくなります。

### 計算

$$\int_0^3 cx\,dx = c\left[\frac{x^2}{2}\right]_0^3 = \frac{9}{2}c = 1 \iff c = \frac{2}{9}$$

$$E[X] = \int_0^3 x \cdot \frac{2}{9}x\,dx = \frac{2}{9}\left[\frac{x^3}{3}\right]_0^3 = \frac{2}{9} \times 9 = 2$$

参考までに、$E[X^2] = \dfrac{2}{9}\left[\dfrac{x^4}{4}\right]_0^3 = 4.5$ なので $V[X] = 4.5 - 2^2 = 0.5$ です。

### 各選択肢の検討

- ①：一様分布 $U(0, 3)$ の密度 $1/3$ と期待値 $1.5$ です。密度が $x$ に比例していることを無視しています。
- ②：$\int_0^3 cx\,dx = 9c$ と、積分の $1/2$ を落として $c = 1/9$ としています（このとき期待値も $1$ と誤ります）。
- ③：$c$ は正しいですが、期待値を区間の中点としています。
- ④：$E[X^2] = 4.5$ を期待値としています。
- ⑤：正しい。

### ポイント

- 確率密度関数の条件：$f(x) \geq 0$、$\int_{-\infty}^{\infty} f(x)\,dx = 1$。
- $E[X] = \int x f(x)\,dx$、$V[X] = \int x^2 f(x)\,dx - (E[X])^2$。
- 分布関数 $F(x) = P(X \leq x) = x^2/9$ を使えば、たとえば $P(X \leq 1) = 1/9$ もすぐに求まる。
