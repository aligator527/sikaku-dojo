  ある工場で、組立作業の手順を旧方式から新方式に変えた効果を調べるため、作業員 25 人の 1 台あたりの作業時間 $y$（分）を測定した。旧方式で作業した 10 人の平均は $42.0$ 分、新方式で作業した 15 人の平均は $35.5$ 分であった。

  新方式なら $x = 1$、旧方式なら $x = 0$ とする変数 $x$ を説明変数、$y$ を目的変数として、25 人のデータに最小二乗法で回帰直線 $\hat{y} = a + bx$ を当てはめた。得られる回帰直線として正しいものを次のうちから一つ選べ。
choices:
  - '$\hat{y} = 35.5 + 6.5x$'
  - '$\hat{y} = 38.1 - 6.5x$'
  - '$\hat{y} = 48.5 - 6.5x$'
  - '$\hat{y} = 42.0 - 6.5x$'
  - '$\hat{y} = 42.0 + 6.5x$'
answer: 4

説明変数が 0 と 1 だけをとるとき、最小二乗法による予測値は各グループの平均値になります。$x = 0$（旧方式）の予測値 $a$ は旧方式の平均 $42.0$、$x = 1$（新方式）の予測値 $a + b$ は新方式の平均 $35.5$ なので、$b = 35.5 - 42.0 = -6.5$ です。

### 計算

$x$ は 0 か 1 なので、残差平方和は

$$\sum_{\text{旧}} (y_i - a)^2 + \sum_{\text{新}} (y_i - a - b)^2$$

と 2 つの部分に分かれます。第 1 項は $a = \bar{y}_{\text{旧}}$ で、第 2 項は $a + b = \bar{y}_{\text{新}}$ で最小になり、両方を同時に満たすことができます。

$$a = 42.0,\qquad b = 35.5 - 42.0 = -6.5$$

公式で確かめると、$\bar{x} = 15/25 = 0.6$、全体の平均 $\bar{y} = (10 \times 42.0 + 15 \times 35.5)/25 = 38.1$ で、

$$S_{xx} = 25 \times 0.6 \times 0.4 = 6,\qquad S_{xy} = \sum_{\text{新}} (1 - 0.6)(y_i - \bar{y}) + \sum_{\text{旧}} (0 - 0.6)(y_i - \bar{y}) = 15 \times 0.4 \times (35.5 - 38.1) - 10 \times 0.6 \times (42.0 - 38.1) = -39$$

$$b = \frac{-39}{6} = -6.5,\qquad a = 38.1 - (-6.5) \times 0.6 = 42.0$$

### 各選択肢の検討

- ①：新方式を基準（$x = 0$）にした場合の式です。問題では旧方式が $x = 0$ です。
- ②：切片を全体の平均 $38.1$ としています。切片は $x = 0$ のグループ（旧方式）の平均です。
- ③：$42.0 + 6.5$ を切片にしています。$x = 1$ を代入すると $42.0$ になり、新方式の平均と合いません。
- ④：正しい。
- ⑤：傾きの符号が逆です。新方式の方が作業時間が短いので、傾きは負です。

### ポイント

- 0/1 の変数（ダミー変数）を説明変数にした回帰では、切片 ＝ 基準グループ（$x = 0$）の平均、傾き ＝ 2 グループの平均の差。
- 傾きの t 検定は、等分散を仮定した 2 標本 t 検定と一致する。重回帰でダミー変数を使うときも、係数は「他の変数をそろえたときのグループ間の差」と解釈する。
