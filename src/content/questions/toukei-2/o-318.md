  ある試験は国語と数学の 2 科目からなる。受験者の国語の得点 $X$ と数学の得点 $Y$ はどちらも標準偏差 10 点で、$X$ と $Y$ の相関係数は $0.28$ である。

  2 科目の合計点 $T = X + Y$ と国語の得点 $X$ の相関係数として、正しいものを次のうちから一つ選べ。
choices:

共分散の双線形性から $\mathrm{Cov}(X, X + Y) = V[X] + \mathrm{Cov}(X, Y)$ です。合計点の分散にも共分散の項が入ることに注意して計算すると、$\mathrm{Cov}(X, T) = 128$、$D[T] = 16$ となり、相関係数は $128/(10 \times 16) = 0.8$ です。

### 計算

$$\mathrm{Cov}(X, Y) = 0.28 \times 10 \times 10 = 28$$

$$V[T] = V[X] + V[Y] + 2\,\mathrm{Cov}(X, Y) = 100 + 100 + 56 = 256,\qquad D[T] = 16$$

$$\mathrm{Cov}(X, T) = \mathrm{Cov}(X, X) + \mathrm{Cov}(X, Y) = 100 + 28 = 128$$

$$r_{XT} = \frac{\mathrm{Cov}(X, T)}{D[X]\,D[T]} = \frac{128}{10 \times 16} = 0.8$$

### 各選択肢の検討

- ①：$X$ と $Y$ の相関係数そのものです。合計点 $T$ には $X$ 自身が含まれるので、$X$ と $T$ の相関はずっと強くなります。
- ②：$\mathrm{Cov}(X, T) = V[X] = 100$ として $\mathrm{Cov}(X, Y)$ を落とした値 $100/160 = 0.625$ です。
- ③：$X$ と $Y$ が無相関の場合の値 $100/(10\sqrt{200}) = 1/\sqrt{2}$ です。
- ④：正しい。
- ⑤：$V[T] = 200$ として合計点の分散の共分散の項を落とした値 $128/(10\sqrt{200}) \approx 0.905$ です。

### ポイント

- 共分散の性質：$\mathrm{Cov}(X, Y + Z) = \mathrm{Cov}(X, Y) + \mathrm{Cov}(X, Z)$、$\mathrm{Cov}(X, X) = V[X]$。
- 標準偏差が等しい 2 変数の場合、$r_{X, X+Y} = \sqrt{(1 + r_{XY})/2}$ となる（ここでは $\sqrt{0.64} = 0.8$）。合計点と各科目の相関は、科目間の相関が 0 でも $0.707$ あり、見かけ上大きくなりやすい。
