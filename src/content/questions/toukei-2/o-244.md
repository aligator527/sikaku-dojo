不良品になる経路は「A の製品で不良」「B の製品で不良」「C の製品で不良」の 3 通りで、これらは排反なので確率を足し合わせます（全確率の公式）。不良品である確率は $0.019$ です。そのうち C を経由する部分 $0.008$ の割合が、ベイズの定理による事後確率 $P(C \mid \text{不良}) = 0.008/0.019 \approx 0.421$ です。

### 計算

不良品であることを $F$ で表します。

$$P(F) = 0.5 \times 0.01 + 0.3 \times 0.02 + 0.2 \times 0.04 = 0.005 + 0.006 + 0.008 = 0.019$$

$$P(C \mid F) = \frac{P(F \mid C)P(C)}{P(F)} = \frac{0.008}{0.019} = \frac{8}{19} \approx 0.421$$

C の生産割合は 20% ですが、不良率が高いため、不良品の中では約 42% を占めます。

### 各選択肢の検討

- ①：正しい。
- ②：$P(F \mid C) = 0.04$ で、条件が逆です。
- ③：C の生産割合（事前確率）$P(C) = 0.2$ で、不良品であるという情報が反映されていません。
- ④：$P(C \cap F) = 0.008$（同時確率）で、$P(F)$ で割っていません。
- ⑤：不良率を生産割合で重みづけせずに $0.01 + 0.02 + 0.04 = 0.07$ と足し、$0.04/0.07$ としています。

### ポイント

- 全確率の公式：$P(F) = \sum_i P(F \mid H_i)P(H_i)$（$H_1, H_2, \dots$ は互いに排反で、合わせると全体になる事象）。
- ベイズの定理：$P(H_j \mid F) = \dfrac{P(F \mid H_j)P(H_j)}{\sum_i P(F \mid H_i)P(H_i)}$。分子は分母の各項のうちの 1 つ。
