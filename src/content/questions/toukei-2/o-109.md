偏差平方和は $\sum x_i^2 - n\bar{x}^2$ で計算できます。平均値は $96/8 = 12$ なので、偏差平方和は $1250 - 8 \times 12^2 = 98$、これを $n - 1 = 7$ で割って分散は $14$ です。

### 計算

$$\bar{x} = \frac{96}{8} = 12$$

$$S = \sum_{i=1}^{8}(x_i - \bar{x})^2 = \sum x_i^2 - n\bar{x}^2 = 1250 - 8 \times 144 = 98$$

$$s^2 = \frac{S}{n-1} = \frac{98}{7} = 14$$

なお、$\sum x_i^2 - \dfrac{(\sum x_i)^2}{n} = 1250 - \dfrac{96^2}{8} = 1250 - 1152 = 98$ と計算しても同じです。

### ポイント

- 偏差平方和の計算公式 $\sum(x_i - \bar{x})^2 = \sum x_i^2 - n\bar{x}^2$ は、合計値だけが与えられた問題で必須。
- よくある誤り：$n = 8$ で割る（$12.25$）、$\sum x_i^2/n$ から $\bar{x}$ を引く（2 乗のし忘れ）、$1250/7$ のように平均を引き忘れる。
- 単位が「十人」なので、人数に直すと分散は $14 \times 10^2 = 1400$（人$^2$）、標準偏差は約 $37.4$ 人になる。
