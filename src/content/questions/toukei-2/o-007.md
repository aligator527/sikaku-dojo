  確率変数 $X$ は二項分布 $B(20,\ 0.3)$ に、確率変数 $Y$ は平均 4 のポアソン分布に従い、$X$ と $Y$ は互いに独立であるとする。

  $W = 2X - Y$ の期待値 $E[W]$ と分散 $V[W]$ の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - '$E[W] = 8,\ V[W] = 12.8$'
  - '$E[W] = 8,\ V[W] = 20.8$'
  - '$E[W] = 8,\ V[W] = 12.4$'
  - '$E[W] = 16,\ V[W] = 20.8$'
  - '$E[W] = 8,\ V[W] = 8.2$'
answer: 2

期待値は線形なので $E[W] = 2E[X] - E[Y]$ です。分散は、独立な確率変数については $V[aX + bY] = a^2V[X] + b^2V[Y]$ となり、係数が 2 乗されるため、引き算でも分散は足し算になります。

### 計算

二項分布 $B(n, p)$ の期待値は $np$、分散は $np(1-p)$、ポアソン分布の期待値と分散はどちらも $\lambda$ です。

$$E[X] = 20 \times 0.3 = 6,\quad V[X] = 20 \times 0.3 \times 0.7 = 4.2,\quad E[Y] = V[Y] = 4$$

$$E[W] = 2 \times 6 - 4 = 8$$

$$V[W] = 2^2 \times 4.2 + (-1)^2 \times 4 = 16.8 + 4 = 20.8$$

### 各選択肢の検討

- ①：$4V[X] - V[Y]$ と、分散も引き算にした誤りです。
- ③：$2V[X] + V[Y]$ と、係数を 2 乗し忘れた誤りです。
- ④：期待値を $2E[X] + E[Y]$ と足してしまっています。
- ⑤：$V[X] + V[Y]$ と、係数を無視しています。

### ポイント

- $E[aX + bY] = aE[X] + bE[Y]$（独立でなくても成り立つ）。
- $V[aX + bY] = a^2V[X] + b^2V[Y] + 2ab\,\mathrm{Cov}(X, Y)$。独立なら共分散の項は 0。
- 代表的な分布の期待値・分散（二項・ポアソン・幾何・一様・指数・正規）は即答できるようにしておく。
