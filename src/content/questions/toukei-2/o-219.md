  互いに独立で、いずれも期待値 0、分散 $\sigma^2$ の確率変数の列 $\varepsilon_t$（$t = 0, \pm 1, \pm 2, \dots$）がある。この系列に 3 項移動平均を施して

  $$y_t = \frac{\varepsilon_{t-1} + \varepsilon_t + \varepsilon_{t+1}}{3}$$

  をつくる。$y_t$ と $y_{t+k}$ の相関係数を $\rho_k$ とするとき、$(\rho_1,\ \rho_2,\ \rho_3)$ の組合せとして正しいものを次のうちから一つ選べ。

元の $\varepsilon_t$ は互いに独立ですが、移動平均をとると、近い時点の $y_t$ どうしが共通の $\varepsilon$ を含むようになり、相関が生じます。$y_t$ と $y_{t+1}$ は 2 個、$y_t$ と $y_{t+2}$ は 1 個の $\varepsilon$ を共有し、$y_t$ と $y_{t+3}$ は共有しません。したがって $\rho_1 = 2/3$、$\rho_2 = 1/3$、$\rho_3 = 0$ です。

### 計算

独立性より、異なる $\varepsilon$ どうしの共分散は 0、同じ $\varepsilon$ どうしの共分散は $\sigma^2$ です。

$$V[y_t] = \frac{1}{9}\left(\sigma^2 + \sigma^2 + \sigma^2\right) = \frac{\sigma^2}{3}$$

$$\mathrm{Cov}(y_t,\ y_{t+1}) = \frac{1}{9}\mathrm{Cov}(\varepsilon_{t-1} + \varepsilon_t + \varepsilon_{t+1},\ \varepsilon_t + \varepsilon_{t+1} + \varepsilon_{t+2}) = \frac{2\sigma^2}{9}$$

$$\mathrm{Cov}(y_t,\ y_{t+2}) = \frac{1}{9}\mathrm{Cov}(\varepsilon_{t-1} + \varepsilon_t + \varepsilon_{t+1},\ \varepsilon_{t+1} + \varepsilon_{t+2} + \varepsilon_{t+3}) = \frac{\sigma^2}{9}$$

$y_t$ と $y_{t+3}$ は共通の $\varepsilon$ を含まないので共分散は 0 です。共分散を分散 $\sigma^2/3$ で割って

$$\rho_1 = \frac{2\sigma^2/9}{\sigma^2/3} = \frac{2}{3},\qquad \rho_2 = \frac{\sigma^2/9}{\sigma^2/3} = \frac{1}{3},\qquad \rho_3 = 0$$

### 各選択肢の検討

- ①：正しい。
- ②：$\varepsilon_t$ が独立であることから $y_t$ も無相関と考えた誤りです。移動平均をとると共通の項を通じて相関が生じます。
- ③：共分散（$\sigma^2 = 1$ の場合）をそのまま答えており、$V[y_t] = \sigma^2/3$ で割って相関係数にしていません。
- ④：ラグ 3 でも相関が残ると考えた誤りです。$y_t$ と $y_{t+3}$ には共通の $\varepsilon$ がないので、相関は 0 です。
- ⑤：$\rho_k = \rho_1^k$ のように、ラグとともに等比的に減ると考えた誤りです。これは 1 次の自己回帰モデルの性質で、移動平均の系列では一定のラグで自己相関が 0 になります。

### ポイント

- 独立な系列でも、移動平均をとると見かけの自己相関や周期的な動きが現れることがある（スルツキー効果）。移動平均した系列のコレログラムを解釈するときは注意する。
- 一般に $m$ 項の単純移動平均では $\rho_k = (m-k)/m$（$k < m$）、$\rho_k = 0$（$k \geq m$）。
