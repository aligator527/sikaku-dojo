  $P(A) > 0$、$P(B) > 0$ である事象 $A$、$B$ に関する次の記述 I〜III について、正誤の組合せとして正しいものを次のうちから一つ選べ。

  I. $A$ と $B$ が互いに排反ならば、$A$ と $B$ は独立ではない。

  II. $A$ と $B$ が独立ならば、$\bar{A}$ と $B$ も独立である。

  III. $A$ と $B$ が独立ならば、$P(A \cup B) = P(A) + P(B)$ が成り立つ。

排反は「同時には起こらない」こと（$P(A \cap B) = 0$）、独立は「一方が起こるかどうかが他方の確率に影響しない」こと（$P(A \cap B) = P(A)P(B)$）で、別の概念です。$P(A) > 0$、$P(B) > 0$ のとき、排反なら $P(A \cap B) = 0 \neq P(A)P(B)$ なので独立ではありません。

### 各記述の検討

- I：正しい。排反なら $A$ が起こると $B$ は決して起こらないので、$A$ の情報は $B$ の確率を $P(B)$ から 0 に変えてしまいます。式では $P(A \cap B) = 0 < P(A)P(B)$ です。
- II：正しい。$P(\bar{A} \cap B) = P(B) - P(A \cap B) = P(B) - P(A)P(B) = \{1 - P(A)\}P(B) = P(\bar{A})P(B)$ となります。
- III：誤り。独立なら $P(A \cup B) = P(A) + P(B) - P(A)P(B)$ で、$P(A)P(B) > 0$ だけ $P(A) + P(B)$ より小さくなります。$P(A \cup B) = P(A) + P(B)$ が成り立つのは排反の場合です。

### ポイント

- 排反：$P(A \cap B) = 0$、加法定理が単純な足し算になる。
- 独立：$P(A \cap B) = P(A)P(B)$、乗法定理が単純な掛け算になる。$A$ と $B$ が独立なら、$\bar{A}$ と $B$、$A$ と $\bar{B}$、$\bar{A}$ と $\bar{B}$ もすべて独立。
