帰無仮説のもとでの標本比率 $\hat{p}$ の標準偏差 $\sqrt{p_0(1-p_0)/n} = \sqrt{0.25/400} = 0.025$ を使って標準化します。$\hat{p} = 0.57$ なので $z = 0.07/0.025 = 2.80$ で、上側 1% 点 2.326 を超えるため、有意水準 1% でも帰無仮説は棄却されます。

### 計算

$$\hat{p} = \frac{228}{400} = 0.57$$

$$z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}} = \frac{0.57 - 0.5}{\sqrt{0.5 \times 0.5 / 400}} = \frac{0.07}{0.025} = 2.80$$

人数で考えても同じで、$z = \dfrac{228 - 400 \times 0.5}{\sqrt{400 \times 0.5 \times 0.5}} = \dfrac{28}{10} = 2.80$ です。片側 P 値は $P(Z \geq 2.80) = 0.0026$ です。

### 各選択肢の検討

- ①：正しい。
- ②：$2.80 > 2.326$ なので、有意水準 1% でも棄却されます。
- ③：賛成者数の分散を $np_0(1-p_0) = 100$ ではなく $np_0 = 200$ とした誤りです（$28/\sqrt{200} \approx 1.98$）。
- ④：分母を $p_0(1-p_0) = 0.25$ とし、$n$ で割ることも平方根をとることも忘れています（$0.07/0.25 = 0.28$）。
- ⑤：検定で結論できるのは「$p > 0.5$」までです。$0.57$ は点推定値であり、母比率が 0.57 以上であることは示されていません。

### ポイント

- 母比率の検定（正規近似）：$z = \dfrac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}}$。分母には帰無仮説の値 $p_0$ を使う。
- 正規近似の目安は、$np_0$ と $n(1-p_0)$ がともに十分大きい（5 以上など）こと。ここではどちらも 200 である。
