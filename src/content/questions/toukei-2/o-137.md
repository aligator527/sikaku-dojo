合計点には筆記試験の得点そのものが含まれているので、$x$ と $x + y$ の相関は $x$ と $y$ の相関よりかなり強くなります。共分散は $\mathrm{Cov}(x, x + y) = s_x^2 + s_{xy} = 45.6$、合計点の標準偏差は約 $10.92$ なので、相関係数は $45.6/(6 \times 10.92) \approx 0.70$ です。

### 計算

$$s_{xy} = r\,s_x s_y = 0.2 \times 6 \times 8 = 9.6$$

$$\mathrm{Cov}(x,\ x + y) = s_x^2 + s_{xy} = 36 + 9.6 = 45.6$$

$$s_{x+y}^2 = s_x^2 + s_y^2 + 2s_{xy} = 36 + 64 + 19.2 = 119.2, \qquad s_{x+y} \approx 10.92$$

$$r_{x,\,x+y} = \frac{45.6}{6 \times 10.92} \approx 0.70$$

### 各選択肢の検討

- ①：$x$ と $y$ の相関係数をそのまま答えています。合計点は $x$ を含むので、相関はこれより強くなります。
- ②：$45.6/119.2 \approx 0.38$ で、共分散を合計点の分散で割っています（合計点から $x$ を予測する回帰直線の傾きにあたる値）。相関係数は 2 つの標準偏差の積で割ります。
- ③：合計点の標準偏差を $6 + 8 = 14$ として $45.6/(6 \times 14) \approx 0.54$ としています。標準偏差は足し算できません。
- ④：$x$ と $y$ を無相関とみなし、共分散を $36$、合計点の標準偏差を $\sqrt{100} = 10$ として $36/60 = 0.60$ としています。
- ⑤：正しい。

### ポイント

- 共分散の性質：$\mathrm{Cov}(x,\ x + y) = \mathrm{Var}(x) + \mathrm{Cov}(x, y)$。共分散は各変数について線形に分解できる。
- 部分（各科目）と全体（合計点）の相関は、部分どうしが無相関でも正になる。標準偏差の大きい科目ほど合計点との相関が強くなり、合計点への影響が大きい。
