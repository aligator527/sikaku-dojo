0 と 1 だけをとる変数でも、相関係数の定義どおりに計算できます。$x$ の平均は $0.3$、$y$ の平均は $0.48$、$xy$ の平均は $0.06$ なので、共分散は $0.06 - 0.3 \times 0.48 = -0.084$ です。これを標準偏差の積 $\sqrt{0.21 \times 0.2496} \approx 0.229$ で割ると、相関係数は約 $-0.37$ になります。

### 計算

$x$ も $y$ も 0 か 1 なので、$x^2 = x$、$y^2 = y$ であり、$xy = 1$ となるのは「喫煙あり・運動あり」の 6 人だけです。

$$\bar{x} = \frac{30}{100} = 0.3,\quad \bar{y} = \frac{48}{100} = 0.48,\quad \overline{xy} = \frac{6}{100} = 0.06$$

$$s_{xy} = \overline{xy} - \bar{x}\bar{y} = 0.06 - 0.144 = -0.084$$

$$s_x^2 = \bar{x}(1 - \bar{x}) = 0.21,\qquad s_y^2 = \bar{y}(1 - \bar{y}) = 0.2496$$

$$r = \frac{-0.084}{\sqrt{0.21 \times 0.2496}} \approx \frac{-0.084}{0.2290} \approx -0.37$$

2×2 表のセルを $a = 6,\ b = 24,\ c = 42,\ d = 28$ とすると、同じ値は次の式でも求められます。

$$r = \frac{ad - bc}{\sqrt{(a+b)(c+d)(a+c)(b+d)}} = \frac{168 - 1008}{\sqrt{30 \times 70 \times 48 \times 52}} \approx -0.37$$

### 各選択肢の検討

- ①：符号を誤っています。喫煙ありの人は運動習慣ありの割合が低い（20%）ので、相関は負です。
- ②：共分散の値で、標準偏差で割っていません。
- ③：運動習慣ありの割合の差（$6/30 - 42/70 = 0.2 - 0.6 = -0.40$）です。関連の向きは同じですが、相関係数とは別の指標です。
- ④：正しい。
- ⑤：相関係数の 2 乗（$0.37^2 \approx 0.13$）です。

### ポイント

- 2 値変数どうしの相関係数は $\phi$ 係数（ファイ係数）とも呼ばれ、$\dfrac{ad - bc}{\sqrt{(a+b)(c+d)(a+c)(b+d)}}$ で計算できる。$ad = bc$ のとき 0 で、これは 2 つの変数が独立のときの度数の関係にあたる。
- 総数を $N$ とすると $N r^2$ は、2×2 表の独立性の検定のカイ二乗統計量（連続修正なし）に等しい。
