$\bar{X}$ の標準偏差は $8/\sqrt{16} = 2$ です。$\alpha$ は帰無仮説 $\mu = 50$ が正しいときに $\bar{X} \geq 54$ となる確率で $P(Z \geq 2.00) = 0.0228$、$\beta$ は $\mu = 55$ のときに棄却域に入らない（$\bar{X} < 54$ となる）確率で $P(Z < -0.50) = 0.3085$ です。

### 計算

$$\alpha = P(\bar{X} \geq 54 \mid \mu = 50) = P\left(Z \geq \frac{54 - 50}{2}\right) = P(Z \geq 2.00) = 0.0228$$

$$\beta = P(\bar{X} < 54 \mid \mu = 55) = P\left(Z < \frac{54 - 55}{2}\right) = P(Z < -0.50) = P(Z > 0.50) = 0.3085$$

このときの検出力は $1 - \beta = 0.6915$ です。

### 各選択肢の検討

- ①：$0.6915$ は検出力 $1 - \beta$ です。
- ②：$0.0455 = 2 \times 0.0228$ は両側の確率です。棄却域は $\bar{X} \geq 54$ の片側だけです。
- ③：$\alpha$ と $\beta$ を入れ替えています。
- ④：正しい。
- ⑤：どちらも余事象の確率です。$0.9772$ は帰無仮説が正しいときに正しく棄却しない確率、$0.6915$ は検出力です。

### ポイント

- $\alpha$ は帰無仮説の値のもとでの分布で、$\beta$ は真の値（対立仮説の値）のもとでの分布で計算する。
- 棄却域を $\bar{X} \geq c$ とすると、$c$ を大きくするほど $\alpha$ は小さくなり、$\beta$ は大きくなる。
