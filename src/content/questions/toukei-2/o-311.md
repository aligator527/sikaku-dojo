  ある種類の電球の寿命 $X$（時間）は、確率密度関数

  $$f(x) = \frac{1}{1000}\,e^{-x/1000}\quad (x \geq 0)$$

  の指数分布に従うとする。$X$ に関する次の記述 I〜III について、正しいものの組合せを次のうちから一つ選べ。

  I. $X$ の分散は $1000$ である。

  II. 寿命が 2000 時間を超える確率は $e^{-2}$ である。

この指数分布の平均は 1000 時間で、分散は平均の 2 乗の $1000^2 = 10^6$ です（I は誤り）。生存確率は $P(X > x) = e^{-x/1000}$ なので II は正しく、指数分布の無記憶性から III も正しい記述です。

### 各選択肢の検討

- I：誤り。パラメータ $\lambda = 1/1000$ の指数分布の期待値は $1/\lambda = 1000$、分散は $1/\lambda^2 = 1000^2 = 1{,}000{,}000$ です。「期待値と分散が等しい」のはポアソン分布の性質で、指数分布では「期待値と標準偏差が等しい」になります。
- II：正しい。

  $$P(X > 2000) = \int_{2000}^{\infty} \frac{1}{1000}e^{-x/1000}\,dx = e^{-2000/1000} = e^{-2}$$

- III：正しい。

  $$P(X > 1500 \mid X > 500) = \frac{P(X > 1500)}{P(X > 500)} = \frac{e^{-1.5}}{e^{-0.5}} = e^{-1} = P(X > 1000)$$

  すでに使用した時間に関係なく、その後の寿命の分布は新品と同じです（無記憶性）。

以上より、正しいのは II と III のみです。

### ポイント

- 指数分布 $f(x) = \lambda e^{-\lambda x}$：$E[X] = 1/\lambda$、$V[X] = 1/\lambda^2$、$P(X > x) = e^{-\lambda x}$。
- 中央値は $P(X > m) = 1/2$ を解いて $m = (\log 2)/\lambda \approx 0.693/\lambda$ で、期待値より小さい（右に裾の長い分布）。
- 単位時間あたりの発生回数がポアソン分布に従うとき、発生間隔は指数分布に従う。
