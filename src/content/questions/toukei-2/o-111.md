データを $y = ax + b$ と 1 次変換すると、平均値は $a\bar{x} + b$ に、標準偏差は $|a|$ 倍になります。定数 $b$ を足しても散らばりは変わりません。平均値は $1.8 \times 15.0 + 32 = 59.0$ ℉、標準偏差は $1.8 \times 5.0 = 9.0$ ℉ です。

### 計算

$$\bar{F} = 1.8\,\bar{C} + 32 = 1.8 \times 15.0 + 32 = 59.0$$

$$s_F = |1.8| \times s_C = 1.8 \times 5.0 = 9.0$$

分散で考えると $s_F^2 = 1.8^2 \times 25 = 81$ で、その平方根が $9.0$ です。

### 各選択肢の検討

- ①：標準偏差にも $+32$ を加えています（$1.8 \times 5.0 + 32 = 41.0$）。全体を平行移動しても散らばりは変わりません。
- ②：平均値の計算で $+32$ を忘れています。
- ③：標準偏差が変換で変わらないと考えた誤りです。目盛りの間隔が 1.8 倍になるので標準偏差も 1.8 倍になります。
- ④：標準偏差に $1.8^2$ を掛けています。$1.8^2$ 倍になるのは分散です。
- ⑤：正しい。

### ポイント

- $y = ax + b$ のとき：$\bar{y} = a\bar{x} + b$、$s_y^2 = a^2 s_x^2$、$s_y = |a|\,s_x$。
- 中央値・四分位数は平均値と同じように変換され、範囲・四分位範囲は標準偏差と同じく $|a|$ 倍になる。
- 変動係数（標準偏差 ÷ 平均値）は、$b \neq 0$ の変換では変わってしまう（ここでは $5.0/15.0 \approx 0.33$ が $9.0/59.0 \approx 0.15$ になる）。原点に意味のある比例尺度のデータで使う指標である。
