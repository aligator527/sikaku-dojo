  2 つの離散型確率変数 $X$ と $Y$ の同時確率分布が次の表で与えられている。

  | | $Y = 0$ | $Y = 1$ |
  | --- | --- | --- |
  | $X = -1$ | 0.1 | 0.2 |
  | $X = 0$ | 0.3 | 0.1 |
  | $X = 1$ | 0.1 | 0.2 |

  $X$ と $Y$ に関する次の記述 I〜III について、正しいものの組合せを次のうちから一つ選べ。

  I. $X$ と $Y$ の相関係数は 0 である。

  II. $X$ と $Y$ は互いに独立である。

  III. $X = 0$ であるときの $Y = 1$ となる条件付き確率 $P(Y = 1 \mid X = 0)$ は $0.25$ である。
choices:
  - 'I のみ正しい'
  - 'II のみ正しい'
  - 'I と II のみ正しい'
  - 'I と III のみ正しい'
  - 'II と III のみ正しい'
answer: 4

周辺分布を求めると $E[X] = 0$ かつ $E[XY] = 0$ なので共分散は 0、相関係数も 0 です（I は正しい）。しかし $P(X = 0, Y = 0) = 0.3$ は $P(X = 0)P(Y = 0) = 0.4 \times 0.5 = 0.2$ と一致しないので、独立ではありません（II は誤り）。III は $0.1/0.4 = 0.25$ で正しい記述です。

### 計算

周辺分布は次のとおりです。

| $x$ | $-1$ | $0$ | $1$ |
| --- | --- | --- | --- |
| $P(X = x)$ | 0.3 | 0.4 | 0.3 |

$$P(Y = 0) = 0.5,\qquad P(Y = 1) = 0.5$$

$$E[X] = -0.3 + 0 + 0.3 = 0,\qquad E[Y] = 0.5$$

$XY$ が 0 でないのは $(X, Y) = (-1, 1),\ (1, 1)$ のときだけなので、

$$E[XY] = (-1) \times 1 \times 0.2 + 1 \times 1 \times 0.2 = 0$$

$$\mathrm{Cov}(X, Y) = E[XY] - E[X]E[Y] = 0 - 0 \times 0.5 = 0$$

### 各選択肢の検討

- I：正しい。共分散が 0 なので相関係数も 0 です。
- II：誤り。独立であるためには、すべての $(x, y)$ について $P(X = x, Y = y) = P(X = x)P(Y = y)$ が必要です。$(0, 0)$ では $0.3 \neq 0.2$ です。
- III：正しい。$P(Y = 1 \mid X = 0) = \dfrac{P(X = 0, Y = 1)}{P(X = 0)} = \dfrac{0.1}{0.4} = 0.25$ です。一方 $P(Y = 1 \mid X = 1) = 0.2/0.3 = 2/3$ で、$X$ の値によって $Y$ の条件付き分布が変わることからも、独立でないことが分かります。

以上より、正しいのは I と III のみです。

### ポイント

- 独立 ⇒ 無相関（共分散 0）は成り立つが、逆は成り立たない。相関係数は直線的な関係の強さしか測らない。
- この例では $|X|$ が大きいほど $Y = 1$ になりやすいという、$X = 0$ を中心に左右対称な（直線的でない）関係がある。
