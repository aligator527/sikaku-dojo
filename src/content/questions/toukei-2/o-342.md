尤度関数は、観測された結果が得られる確率を母数 $p$ の関数とみたものです。独立な試行なので確率は積になり、成功 3 回・失敗 7 回なら $L(p) = p^3(1-p)^7$ です。これを最大にする $p$ は、対数尤度を微分して 0 とおくと $\hat{p} = 3/10 = 0.3$（標本比率）になります。

### 計算

$$\log L(p) = 3\log p + 7\log(1-p)$$

$$\frac{d}{dp}\log L(p) = \frac{3}{p} - \frac{7}{1-p} = 0 \iff 3(1-p) = 7p \iff p = \frac{3}{10}$$

$0 < p < 0.3$ では導関数が正、$0.3 < p < 1$ では負なので、$p = 0.3$ で最大になります。

### 各選択肢の検討

- ①：正しい。
- ②：成功と失敗を取り違えています。
- ③：尤度関数は正しいですが、最大になる点を誤っています。$L(0.5) = 0.5^{10} \approx 0.00098$ に対して $L(0.3) = 0.3^3 \times 0.7^7 \approx 0.00222$ で、$p = 0.3$ の方が大きくなります。
- ④：$3/7$ は成功回数と失敗回数の比（オッズ）です。
- ⑤：独立な事象が同時に起こる確率は積で、和ではありません。

### ポイント

- 最尤法：観測データの同時確率（密度）を母数の関数とみた尤度 $L(\theta)$ を最大にする $\theta$ を推定値とする。積の最大化は対数をとって和にすると計算しやすい。
- 二項分布の $p$ の最尤推定量は標本比率 $X/n$、ポアソン分布の $\lambda$ と正規分布の $\mu$ の最尤推定量は標本平均になる。
