全変動 $S_{yy}$ は、回帰によって説明される変動 $S_R$ と残差平方和 $S_e$ に分解されます。$S_R = S_{xy}^2/S_{xx} = 3600/40 = 90$ なので、残差平方和は $S_e = 125 - 90 = 35$ です。

### 計算

傾きは $b = S_{xy}/S_{xx} = 60/40 = 1.5$ です。回帰による変動（回帰平方和）は

$$S_R = \sum (\hat{y}_i - \bar{y})^2 = b^2 S_{xx} = \frac{S_{xy}^2}{S_{xx}} = \frac{3600}{40} = 90$$

$$S_e = S_{yy} - S_R = 125 - 90 = 35$$

決定係数は $R^2 = S_R/S_{yy} = 90/125 = 0.72$ で、相関係数の 2 乗 $\dfrac{S_{xy}^2}{S_{xx}S_{yy}} = \dfrac{3600}{5000} = 0.72$ と一致します。

### ポイント

- 変動の分解：$S_{yy} = S_R + S_e$。$S_R = S_{xy}^2/S_{xx}$、$S_e = S_{yy}(1 - r^2)$。
- 残差の分散（誤差分散）の推定値は $S_e/(n - 2) = 35/10 = 3.5$ で、回帰の標準誤差は $\sqrt{3.5} \approx 1.87$ になる。
- よくある誤り：$S_R$ を $b S_{xx}$ や $S_{xy}$（いずれも $60$）として残差平方和を $65$ とする、残差平方和ではなく $S_R = 90$ を答えてしまう。
