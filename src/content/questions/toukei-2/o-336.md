$W = (n-1)S^2/\sigma^2 = 8S^2/6$ は自由度 8 のカイ二乗分布に従うので、$V[W] = 16$ です。$S^2 = \dfrac{6}{8}W$ と $W$ の定数倍で表せるので、$V[S^2] = \left(\dfrac{6}{8}\right)^2 \times 16 = 9$ になります。

### 計算

$$W = \frac{(n-1)S^2}{\sigma^2} = \frac{8S^2}{6} \sim \chi^2(8),\qquad E[W] = 8,\qquad V[W] = 16$$

$$S^2 = \frac{\sigma^2}{n-1}W = \frac{6}{8}W$$

$$V[S^2] = \left(\frac{6}{8}\right)^2 V[W] = \frac{36}{64} \times 16 = 9$$

一般に $V[S^2] = \left(\dfrac{\sigma^2}{n-1}\right)^2 \times 2(n-1) = \dfrac{2\sigma^4}{n-1}$ で、$\dfrac{2 \times 36}{8} = 9$ と一致します。期待値の方は $E[S^2] = \dfrac{6}{8} \times 8 = 6 = \sigma^2$ で、$S^2$ が不偏推定量であることも確かめられます。

### ポイント

- 定数倍の分散は係数の 2 乗倍：$V[cW] = c^2 V[W]$。係数を 2 乗し忘れると $\dfrac{6}{8} \times 16 = 12$ と誤る。
- $V[S^2] = \dfrac{2\sigma^4}{n-1}$ は $n \to \infty$ で 0 に近づく。不偏分散は母分散の不偏推定量であるだけでなく、一致推定量でもある。
- この性質は母集団が正規分布であることを前提にしている。
