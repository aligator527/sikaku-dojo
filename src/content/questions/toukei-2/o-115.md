  データ $x_1, \ldots, x_n$ の平均値を $\bar{x}$、偏差平方和を $n$ で割った分散の正の平方根を $s$ とし、歪度と尖度を次のように定める。

  $$\text{歪度} = \frac{1}{n}\sum_{i=1}^{n}\left(\frac{x_i - \bar{x}}{s}\right)^3, \qquad \text{尖度} = \frac{1}{n}\sum_{i=1}^{n}\left(\frac{x_i - \bar{x}}{s}\right)^4 - 3$$

  この定義では、正規分布に従う大きなデータの歪度と尖度はともに 0 に近くなる。次の記述 I〜III について、正誤の組合せとして正しいものを次のうちから一つ選べ。

  I. 右に裾が長い分布のデータでは、歪度は正の値になる。

  II. 平均値に関して左右対称な分布のデータでは、尖度は 0 になる。

  III. ヒストグラムが山のない平らな形（一様分布に近い形）のデータの尖度は、正規分布に近いデータの尖度より大きい。
choices:
  - 'I：正　II：正　III：誤'
  - 'I：正　II：誤　III：正'
  - 'I：正　II：誤　III：誤'
  - 'I：誤　II：正　III：誤'
  - 'I：誤　II：誤　III：正'
answer: 3

歪度は偏差の 3 乗の平均なので、右側に大きく離れた値があると正の値になります。尖度は偏差の 4 乗の平均から 3 を引いたもので、分布の裾の重さ・とがり具合を表します。左右対称であることは歪度が 0 になることを保証しますが、尖度の値は決まりません。一様分布に近い平らな分布の尖度は負になります。I のみが正しい記述です。

### 各選択肢の検討

- I（正）：右に長い裾の値は標準化すると大きな正の値になり、3 乗するとその影響が強く出るため、歪度は正になります。
- II（誤）：左右対称なら偏差の 3 乗が打ち消し合って歪度は 0 になりますが、尖度は分布によって異なります。たとえば一様分布は対称ですが、尖度は約 $-1.2$ です。
- III（誤）：一様分布は正規分布より裾が軽く山も平らなので、尖度は負（約 $-1.2$）です。正規分布の 0 より小さくなります。逆に、中心がとがって裾が重い分布（t 分布など）の尖度は正になります。

したがって「I：正　II：誤　III：誤」の③が正解です。

### ポイント

- 歪度 > 0：右に裾が長い、歪度 < 0：左に裾が長い、歪度 = 0：左右対称（逆は必ずしも成り立たない）。
- 尖度は定義に「$-3$」を含める流儀と含めない流儀がある。含めない定義では正規分布の尖度は 3 になるので、問題文の定義を確認する。
