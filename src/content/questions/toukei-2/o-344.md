  $X_1, \ldots, X_n$ $(n \geq 2)$ を平均 $\mu$、分散 $\sigma^2$ の母集団からの無作為標本とし、$\bar{X} = \dfrac{1}{n}\displaystyle\sum_{i=1}^{n} X_i$ とする。推定量の不偏性に関する次の記述 I〜III について、正しいものの組合せを次のうちから一つ選べ。

  I. $\bar{X}$ は $\mu$ の不偏推定量である。

  II. $\dfrac{1}{n}\displaystyle\sum_{i=1}^{n}(X_i - \bar{X})^2$ は $\sigma^2$ の不偏推定量である。

  III. 不偏分散 $S^2 = \dfrac{1}{n-1}\displaystyle\sum_{i=1}^{n}(X_i - \bar{X})^2$ の正の平方根 $S$ は、$\sigma$ の不偏推定量である。

  - 'I と III のみ正しい'

推定量 $T$ が母数 $\theta$ の不偏推定量であるとは $E[T] = \theta$ が成り立つことです。$E[\bar{X}] = \mu$ なので I は正しい記述です。$n$ で割った標本分散の期待値は $\frac{n-1}{n}\sigma^2$ で $\sigma^2$ より小さく（II は誤り）、$S^2$ は $\sigma^2$ の不偏推定量ですが、平方根をとった $S$ は $\sigma$ の不偏推定量になりません（III は誤り）。

### 各選択肢の検討

- I：正しい。$E[\bar{X}] = \dfrac{1}{n}\sum E[X_i] = \mu$ です。
- II：誤り。$E\!\left[\sum (X_i - \bar{X})^2\right] = (n-1)\sigma^2$ なので、

  $$E\!\left[\frac{1}{n}\sum_{i=1}^{n}(X_i - \bar{X})^2\right] = \frac{n-1}{n}\sigma^2 < \sigma^2$$

  となり、平均的に母分散を過小評価します。
- III：誤り。$E[S^2] = \sigma^2$ ですが、

  $$V[S] = E[S^2] - (E[S])^2 = \sigma^2 - (E[S])^2 > 0$$

  なので（$S$ が定数でない限り分散は正）、$E[S] < \sigma$ となります。不偏性は平方根のような非線形な変換では保たれません。

以上より、正しいのは I のみです。

### ポイント

- 不偏分散 $S^2$ が $n - 1$ で割るのは、$\bar{X}$ のまわりの偏差平方和が $\mu$ のまわりの偏差平方和より平均的に小さくなる分を補正するため。
- 期待値は 1 次変換とは交換できる（$E[aT + b] = aE[T] + b$）が、2 乗や平方根とは交換できない。
