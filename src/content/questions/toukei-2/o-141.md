  $n$ 組のデータ $(x_i, y_i)$ に対して、最小二乗法により切片を含む回帰直線 $\hat{y} = a + bx$ を求めた。残差を $e_i = y_i - (a + bx_i)$ とする（残差がすべて 0 になる場合は考えない）。次の記述 I〜III のうち、正しいものだけをすべて挙げたものを、次のうちから一つ選べ。

  I. 回帰直線は、点 $(\bar{x}, \bar{y})$ を通る。

  II. 観測値 $y_i$ のちょうど半数は回帰直線より上にあり、残りの半数は下にある。

  III. 残差 $e_1, \ldots, e_n$ と説明変数 $x_1, \ldots, x_n$ の相関係数は 0 である。

最小二乗法の解は、残差平方和を $a$ と $b$ で偏微分して 0 とおいた正規方程式

$$\sum e_i = 0, \qquad \sum x_i e_i = 0$$

を満たします。1 つ目から回帰直線は $(\bar{x}, \bar{y})$ を通り、2 つ目と合わせると残差と $x$ の共分散が 0 になります。「残差の和が 0」は「正の残差と負の残差の個数が等しい」こととは違うので、II は誤りです。I と III が正しい記述です。

### 各選択肢の検討

- I（正）：$\sum e_i = \sum (y_i - a - bx_i) = 0$ を $n$ で割ると $\bar{y} = a + b\bar{x}$ となり、直線は $(\bar{x}, \bar{y})$ を通ります。
- II（誤）：残差の「和」が 0 なので、大きな正の残差が 1 つあれば、小さな負の残差が多数ある、ということも起こります。正負の個数が等しいとは限りません。
- III（正）：$\sum e_i = 0$ より $\bar{e} = 0$ なので、残差と $x$ の偏差積和は $\sum (x_i - \bar{x})e_i = \sum x_i e_i = 0$ です。したがって相関係数は 0 です。

### ポイント

- 正規方程式から導かれる性質：①残差の和は 0、②残差と $x$ は無相関、③残差と予測値 $\hat{y}$ も無相関、④回帰直線は $(\bar{x}, \bar{y})$ を通る。
- ③から、全変動の分解 $\sum (y_i - \bar{y})^2 = \sum (\hat{y}_i - \bar{y})^2 + \sum e_i^2$ が成り立つ。
