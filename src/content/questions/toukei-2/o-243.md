  大小 2 個のさいころを同時に投げる。次の事象を考える。

  - $A$：大きいさいころの目が偶数である。
  - $B$：2 個の目の和が偶数である。
  - $C$：2 個の目の和が 8 である。
  - $D$：2 個の目の和が 7 である。
  - $E$：小さいさいころの目が 4 である。

  次の記述 I〜III について、正しいものの組合せを次のうちから一つ選べ。

  I. $A$ と $B$ は独立である。

  II. $A$ と $C$ は独立である。

  III. $D$ と $E$ は独立である。
choices:
  - 'I のみ正しい'
  - 'II のみ正しい'
  - 'III のみ正しい'
  - 'I と II のみ正しい'
  - 'I と III のみ正しい'
answer: 5

独立かどうかは、$P(X \cap Y) = P(X)P(Y)$ が成り立つかどうかで判定します。目の出方 36 通りは同様に確からしいので、それぞれの事象に含まれる場合の数を数えます。I と III は等式が成り立ち、II は成り立ちません。

### 各記述の検討

- I：正しい。$P(A) = 1/2$、$P(B) = 1/2$ です。$A \cap B$ は「大きい目が偶数で和も偶数」、つまり 2 個とも偶数の場合で $9$ 通りなので、$P(A \cap B) = 9/36 = 1/4 = P(A)P(B)$ です。
- II：誤り。$P(C) = 5/36$（$(2,6), (3,5), (4,4), (5,3), (6,2)$）です。$A \cap C$ は大きい目が偶数の $(2,6), (4,4), (6,2)$ の 3 通りなので、$P(A \cap C) = 3/36 = 1/12$ ですが、$P(A)P(C) = 5/72$ で一致しません。和が 8 であることが分かると、大きい目が偶数である確率は $3/5$ に上がります。
- III：正しい。$P(D) = 6/36 = 1/6$、$P(E) = 1/6$ です。$D \cap E$ は $(3,4)$ の 1 通りで、$P(D \cap E) = 1/36 = P(D)P(E)$ です。小さい目が何であっても、和が 7 になる大きい目はちょうど 1 つあるので、和が 7 になる確率は小さい目によらず $1/6$ です。

（$(x, y)$ は大きいさいころの目が $x$、小さいさいころの目が $y$ であることを表します。）

### ポイント

- 独立の定義：$P(X \cap Y) = P(X)P(Y)$、同値な言い方で $P(X \mid Y) = P(X)$。直感ではなく定義で確かめる。
- 「和が 7」はどちらか一方の目の値と独立になる特別な事象である。「和が 8」ではそうならない。
