  ある資格試験の得点 $X$ は、平均 50 点、標準偏差 10 点の正規分布 $N(50,\ 10^2)$ に従うとする。得点が 40 点より高く 65 点より低い受験者の割合 $P(40 < X < 65)$ として、最も適切なものを次のうちから一つ選べ。

  必要なら、標準正規分布に従う確率変数 $Z$ について次の値を用いよ。

  $P(Z > 0.10) = 0.4602,\quad P(Z > 0.15) = 0.4404,\quad P(Z > 1.00) = 0.1587,\quad P(Z > 1.50) = 0.0668$
choices:

answer: 5

$Z = (X - 50)/10$ と標準化すると、40 点は $z = -1.00$、65 点は $z = 1.50$ に対応します。標準正規分布の対称性を使うと、求める確率は「全体 1 から、両側にはみ出す部分 $P(Z < -1.00) = 0.1587$ と $P(Z > 1.50) = 0.0668$ を引いた値」で、$0.7745$ です。

### 計算

$$P(40 < X < 65) = P\!\left(\frac{40-50}{10} < Z < \frac{65-50}{10}\right) = P(-1.00 < Z < 1.50)$$

対称性より $P(Z < -1.00) = P(Z > 1.00) = 0.1587$ なので、

$$P(-1.00 < Z < 1.50) = 1 - 0.1587 - 0.0668 = 0.7745$$

### 各選択肢の検討

- ①：$P(1.00 < Z < 1.50) = 0.1587 - 0.0668$ です。40 点に対応する $z$ を $-1.00$ ではなく $+1.00$ としています。
- ②：分散 $10^2 = 100$ で割って $z = -0.10,\ 0.15$ とした誤りです。標準化には標準偏差を使います。
- ③：$1 - 0.7745$、つまり区間の外側の確率です。
- ④：$(0.5 - 0.1587) + 0.0668$ で、$1.50$ 側に $P(0 < Z < 1.50)$ ではなく上側確率 $P(Z > 1.50)$ を足しています。
- ⑤：正しい。

### ポイント

- 正規分布の確率は、標準化 $Z = (X - \mu)/\sigma$ してから標準正規分布表で求める。
- 表が上側確率 $P(Z > z)$ の形のときは、$P(Z < -z) = P(Z > z)$（対称性）と $P(Z \leq z) = 1 - P(Z > z)$ を組み合わせる。図を描いて面積を確認すると取り違えを防げる。
