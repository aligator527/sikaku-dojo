全部原価計算の営業利益は、直接原価計算の営業利益に「期末の仕掛品・製品に含まれる固定加工費」を加え、「期首の仕掛品・製品に含まれる固定加工費」を差し引いて求められます（固定費調整）。先入先出法なので、固定加工費も変動費と同じように仕掛品・製品のボックス図で順に追いかけます（ころがし計算法）。

### 計算

固定加工費のボックス図（仕掛品、先入先出法）

| 固定加工費 | 換算量 | 金額 |
| --- | ---: | ---: |
| 期首仕掛品 | 100個 | 140,000 |
| 当期投入 | 5,050個 | 7,575,000 |
| 完成品 | 5,000個 | 7,490,000 |
| 期末仕掛品 | 150個 | 225,000 |

1. 当期投入の単価：7,575,000 ÷ 5,050 ＝ 1,500円 → 期末仕掛品 150 × 1,500 ＝ 225,000円
2. 完成品の固定加工費：140,000 ＋ 4,900 × 1,500 ＝ 7,490,000円（1個当たり 7,490,000 ÷ 5,000 ＝ 1,498円）
3. 期末製品の固定加工費（当期完成品から）：600 × 1,498 ＝ 898,800円

固定費調整

| 項目 | 金額 |
| --- | ---: |
| 直接原価計算の営業利益 | 7,185,000 |
| ＋ 期末仕掛品の固定加工費 | 225,000 |
| ＋ 期末製品の固定加工費 | 898,800 |
| − 期首仕掛品の固定加工費 | 140,000 |
| − 期首製品の固定加工費 | 560,000 |
| 全部原価計算の営業利益 | **7,608,800** |

検算：全部原価計算の売上原価は、変動部分 9,600,000 ＋ 固定部分 (560,000 ＋ 4,400 × 1,498) ＝ 16,751,200円。営業利益は 28,800,000 − 16,751,200 − 1,440,000 − 3,000,000 ＝ 7,608,800円 です。

### ポイント

- 期末製品の固定加工費を当期の単価 1,500円 で計算し、仕掛品の調整を省くと 7,525,000円 となり誤りです。先入先出法では、完成品の単位原価に期首仕掛品の原価が混ざる点に注意します。
- 期末在庫に含まれる固定費が期首より多い（在庫が増えた）ので、全部原価計算の利益のほうが 423,800円 大きくなります。
- 原価計算基準30は、総合原価計算で直接原価計算を行う場合、会計年度末に当期の固定費を期末の仕掛品・製品と当年度の売上品に配賦するとしています。直接原価計算を採用しても、外部報告用の利益は固定費調整によって全部原価計算の利益に直します。
