不利差異は実際原価が標準原価を上回った分なので、差異勘定の **借方** に振り替えます。有利差異は差異勘定の **貸方** です。仕掛品勘定には、差異の合計額（不利の純額）が貸借差額として残っており、これを貸方に記入して消します。

### 計算

1. 不利差異の合計：15,000 ＋ 8,000 ＋ 12,000 ＋ 9,000 ＋ 21,000 ＝ 65,000円
2. 有利差異の合計：6,000 ＋ 4,000 ＝ 10,000円
3. 仕掛品勘定の差額：65,000 − 10,000 ＝ 55,000円（借方残高＝不利の純額）

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 材料価格差異 | 15,000 | 仕掛品 | 55,000 |
| 賃率差異 | 8,000 | 材料数量差異 | 6,000 |
| 作業時間差異 | 12,000 | 予算差異 | 4,000 |
| 能率差異 | 9,000 | | |
| 操業度差異 | 21,000 | | |

### ポイント

- パーシャル・プランでは、価格差異（材料価格差異・賃率差異）も含めて、すべての差異が仕掛品勘定で把握されます。修正パーシャル・プランやシングル・プランでは価格差異は材料・賃金勘定で把握されるので、仕掛品勘定から振り替えることはありません。
- 不利差異を貸方に書く誤りは、差異勘定の残高の意味（借方残高 ＝ 原価の超過 ＝ 費用の追加）を考えると防げます。
- 原価計算基準47（二）により、これらの差異は異常な状態によるものを除き、会計年度末に原則として売上原価に賦課します。
