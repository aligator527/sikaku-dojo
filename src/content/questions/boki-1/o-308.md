部門別の予定配賦率は、補助部門費を配賦した **後** の製造部門費予算を、その部門の基準操業度で割って求めます。予定配賦額は「予定配賦率 × 実際操業度」で計算し、製造部門費勘定の貸方から仕掛品勘定の借方へ振り替えます。

### 計算

| 予算 | 第1製造部 | 第2製造部 |
| --- | ---: | ---: |
| 第1次集計費 | 30,000,000 | 18,000,000 |
| 動力部費 6,000,000（70：30） | 4,200,000 | 1,800,000 |
| 工場事務部費 4,000,000（40：60） | 1,600,000 | 2,400,000 |
| 製造部門費予算 | 35,800,000 | 22,200,000 |
| 基準操業度 | 40,000時間 | 30,000時間 |
| 予定配賦率 | 895円/時間 | 740円/時間 |
| 当月の予定配賦額 | 895 × 3,200 ＝ 2,864,000 | 740 × 2,600 ＝ 1,924,000 |

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 仕掛品 | 4,788,000 | 第1製造部門費 | 2,864,000 |
| | | 第2製造部門費 | 1,924,000 |

### ポイント

- 補助部門費は製品に直接配賦しません。動力部費・工場事務部費を配賦する前の第1次集計費だけで予定配賦率を計算すると、第1製造部 750円、第2製造部 600円 となり誤りです。
- 予定配賦の段階では配賦差異の仕訳は生じません。月末に実際発生額を集計した後、予定配賦額との差額を製造部門費配賦差異勘定に振り替えます。
- 原価計算基準33は、個別原価計算における間接費を原則として部門間接費として予定配賦率で各指図書に配賦するとしています。
