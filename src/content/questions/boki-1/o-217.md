自己株式処分差損と自己株式の消却は、いずれもその他資本剰余金を減額します。その結果、その他資本剰余金の残高が負の値になった場合は、会計期間末にその他資本剰余金をゼロとし、負の値をその他利益剰余金（繰越利益剰余金）から減額します（自己株式及び準備金の額の減少等に関する会計基準）。

### 計算

1. 自己株式処分差損：(520 − 600) × 500株 ＝ △40,000円
2. 自己株式の消却：600 × 1,000株 ＝ 600,000円（その他資本剰余金から減額）
3. 期末のその他資本剰余金（補填前）：300,000 − 40,000 − 600,000 ＝ △340,000円
4. 補填：その他資本剰余金をゼロにし、繰越利益剰余金から 340,000円 を減額
5. 期末の繰越利益剰余金：5,000,000 − 800,000 − 80,000 ＋ 1,800,000 − 340,000 ＝ **5,580,000円**

| 繰越利益剰余金の増減 | 金額 |
| --- | ---: |
| 期首残高 | 5,000,000 |
| 剰余金の配当 | △800,000 |
| 利益準備金の積立て | △80,000 |
| 当期純利益 | 1,800,000 |
| その他資本剰余金の負の残高の補填 | △340,000 |
| 期末残高 | 5,580,000 |

なお、期末に残る自己株式は 500株、600 × 500 ＝ 300,000円 で、純資産の部の株主資本から控除して表示します。

### ポイント

- 自己株式の取得に要した手数料などの付随費用は、取得原価に含めず営業外費用とします。取得原価を 1株当たり 606円 とすると処分差損・消却額がずれます。
- その他資本剰余金の負の残高は、取引のつどではなく **会計期間末** に繰越利益剰余金で補填します。
- 補填を忘れて 5,920,000円 とする誤り、その他資本剰余金の期首残高を考えずに 640,000円 を減額する誤りに注意します。
