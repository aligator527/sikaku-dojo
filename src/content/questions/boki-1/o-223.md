非支配株主持分は、評価差額を含む子会社の資本に非支配株主の持分比率を掛けて求めます。X3年3月31日の追加取得（10％）によってP社の持分は70％になるので、同日の非支配株主持分は30％分です。

### 計算

1. X3年3月31日のS社の資本（評価差額を含む）

| 項目 | 金額 |
| --- | ---: |
| 資本金 | 3,000,000 |
| 利益剰余金：1,400,000 ＋ 600,000 − 200,000 | 1,800,000 |
| 評価差額 | 350,000 |
| 合計 | 5,150,000 |

2. 追加取得前の非支配株主持分（40％）：5,150,000 × 40％ ＝ 2,060,000円
3. 追加取得による減少額（10％）：5,150,000 × 10％ ＝ 515,000円
4. 追加取得後の非支配株主持分（30％）：5,150,000 × 30％ ＝ **1,545,000円**

追加取得の連結修正仕訳（参考）

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 非支配株主持分 | 515,000 | S社株式 | 560,000 |
| 資本剰余金 | 45,000 | | |

### ポイント

- 評価差額 350,000円 を子会社の資本に含め忘れると、1,440,000円 と答えてしまいます。
- 追加取得の取得原価 560,000円 と減少する非支配株主持分 515,000円 との差額は、のれんではなく資本剰余金で処理します（支配獲得後の親会社と非支配株主との取引）。
- 非支配株主持分にはのれんを含めません（日本の基準は購入のれん方式）。
