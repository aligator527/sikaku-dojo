最小自乗法は、すべての実績データからの距離（残差）の2乗和が最小になるように原価の直線 $y = a + bx$ を求める方法です。平均からの偏差を使うと計算が簡単になります。

### 計算

1. 平均：$\bar{x} = 7{,}000 \div 5 = 1{,}400$時間、$\bar{y} = 14{,}200{,}000 \div 5 = 2{,}840{,}000$円

| 月 | $x - \bar{x}$ | $y - \bar{y}$ | $(x - \bar{x})^2$ | $(x - \bar{x})(y - \bar{y})$ |
| --- | ---: | ---: | ---: | ---: |
| 1月 | −400 | −238,000 | 160,000 | 95,200,000 |
| 2月 | −200 | −124,000 | 40,000 | 24,800,000 |
| 3月 | 0 | 4,000 | 0 | 0 |
| 4月 | 200 | 116,000 | 40,000 | 23,200,000 |
| 5月 | 400 | 242,000 | 160,000 | 96,800,000 |
| 合計 | | | 400,000 | 240,000,000 |

2. 変動費率：$b = 240{,}000{,}000 \div 400{,}000 = 600$円/時間
3. 固定費：$a = \bar{y} - b\bar{x} = 2{,}840{,}000 - 600 \times 1{,}400 =$ **2,000,000円**

正規方程式 $\sum y = na + b\sum x$、$\sum xy = a\sum x + b\sum x^2$ に $\sum x = 7{,}000$、$\sum y = 14{,}200{,}000$、$\sum xy = 20{,}120{,}000{,}000$、$\sum x^2 = 10{,}200{,}000$ を代入して解いても同じ結果になります。

### ポイント

- 同じデータを高低点法で分解すると、変動費率 (3,082,000 − 2,602,000) ÷ 800 ＝ 600円、固定費 2,002,000円 となり、最小自乗法の結果とずれます。高低点法は両端の2点の残差の影響をそのまま受けるためです。
- 最小自乗法の前提として、データは正常操業圏内のものに限り、異常値は除いておきます。
- 求めた原価関数は、正常操業圏内の予測にだけ使います。圏外への外挿は信頼性が低くなります。
