部分純資産直入法では、時価が取得原価を上回る銘柄の評価差額は純資産の部（その他有価証券評価差額金）に計上し、下回る銘柄の評価差額は当期の損失とします。これとは別に、時価や実質価額が著しく下落した銘柄は減損処理を行い、評価差額を当期の損失とします。

### 計算

| 銘柄 | 判定 | 処理 | 投資有価証券評価損 |
| --- | --- | --- | ---: |
| A社株式 | 時価 ＞ 取得原価 | 評価差益 150,000 → その他有価証券評価差額金 | 0 |
| B社株式 | 時価 ＜ 取得原価（下落率10％） | 部分純資産直入法による評価損 | 80,000 |
| C社株式 | 下落率 (2,000,000 − 900,000) ÷ 2,000,000 ＝ 55％ | 時価の著しい下落 → 減損処理 | 1,100,000 |
| D社株式 | 実質価額 5,000,000 × 5％ ＝ 250,000、低下率 約58％ | 実質価額の著しい低下 → 減損処理 | 350,000 |
| 合計 | | | **1,530,000** |

### ポイント

- 「金融商品に関する会計基準」では、時価のある有価証券の時価が著しく下落したときは、回復する見込みがあると認められる場合を除き、時価で評価して評価差額を当期の損失とします。市場価格のない株式等は、発行会社の財政状態の悪化により実質価額が著しく低下したときに相当の減額を行います。実務上、おおむね50％程度以上の下落・低下が「著しい」の目安です。
- 部分純資産直入法でも、評価益と評価損を相殺しません。A社株式の評価益 150,000円 を差し引いて 1,380,000円 とするのは誤りです。
- 部分純資産直入法による評価損（B社株式）は翌期首に振り戻しますが、減損処理（C社株式・D社株式）は切放しで、減損後の金額が翌期以降の取得原価になります。
- 時価算定会計基準の適用以後、その他有価証券の期末評価に「期末前1か月の市場価格の平均」を使う方法は認められていません。市場価格のない株式等は取得原価で評価します。
