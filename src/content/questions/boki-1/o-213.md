株式交換では、完全親会社は子会社の資産・負債を直接受け入れず、子会社株式を取得します。個別財務諸表上の子会社株式の取得原価は、交付した株式の時価に、取得に直接要した支出額（取得の対価性が認められるもの）を加えた金額です。

### 計算

1. 交付した株式の時価：3,000株 × 1,800 ＝ 5,400,000円
2. 子会社株式の取得原価：5,400,000 ＋ 200,000 ＝ 5,600,000円
3. 増加する資本：資本金 3,000,000円、その他資本剰余金 5,400,000 − 3,000,000 ＝ 2,400,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 子会社株式 | 5,600,000 | 資本金 | 3,000,000 |
| | | その他資本剰余金 | 2,400,000 |
| | | 当座預金 | 200,000 |

### ポイント

- 増加する資本は交付した株式の時価 5,400,000円 が基礎です。アドバイザー報酬 200,000円 は資本の増加には含めません。
- **個別財務諸表** では、取得に直接要した支出額を子会社株式の取得原価に含めます。一方、**連結財務諸表** では取得関連費用として発生時の費用に組み替えます。
- 吸収合併の場合は、取得関連費用を個別財務諸表でも費用処理します。株式交換との違いが正誤問題でもよく問われます。
- 株式交換では子会社の資産・負債を受け入れないので、個別財務諸表にのれんは生じません。のれんは連結財務諸表の作成時に資本連結で算定します。
