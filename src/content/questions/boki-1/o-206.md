（分類3）は、臨時的な原因により業績が大きく変動する企業です。将来の合理的な見積可能期間（おおむね5年）以内の一時差異等加減算前課税所得の見積額にもとづいて一時差異をスケジューリングし、その範囲で回収が見込まれる分だけ繰延税金資産を計上します。

### 計算

5年間（X3年3月期〜X7年3月期）について、各年度の解消見込額と課税所得の見積額を比べます。

| 年度 | 解消見込額 | 課税所得の見積額 | 回収可能額 |
| --- | ---: | ---: | ---: |
| X3/3期 | 1,200,000 ＋ 400,000 ＋ 600,000 ＝ 2,200,000 | 2,500,000 | 2,200,000 |
| X4/3期 | 600,000 | 900,000 | 600,000 |
| X5/3期 | 500,000 | 700,000 | 500,000 |
| X6/3期 | 500,000 | 600,000 | 500,000 |
| X7/3期 | 400,000 | 300,000 | 300,000 |
| 合計 | | | 4,100,000 |

1. X7年3月期は課税所得 300,000円 を超える 100,000円 が税務上の欠損金になります。これを繰り越しても、見積可能期間内にはもう課税所得がないので回収できません。
2. X8年3月期・X9年3月期に解消する 600,000円 は見積可能期間を超えるので回収可能性なし。
3. スケジューリング不能な土地の減損損失 2,000,000円 も回収可能性なし。
4. 繰延税金資産：4,100,000 × 30％ ＝ **1,230,000円**

### ポイント

- 各年度の課税所得に余裕があっても（X3年3月期の 300,000円 など）、その余裕で後の年度の解消額を回収することはできません。後の年度に生じた欠損金は、それより後の年度の課税所得とだけ相殺できます。
- 機械の減価償却限度超過額 3,200,000円 を全額回収可能とすると（分類2）の答え 1,440,000円 になります。
- 退職給付引当金や建物の減価償却超過額のように解消見込年度が長期にわたるものは、（分類3）でも最終解消見込年度までに解消が見込まれれば回収可能性があるとする特則があります。機械には適用されません。
- （分類4）なら、翌期（X3年3月期）の課税所得 2,500,000円 の範囲で翌期に解消する 2,200,000円 だけが対象になり、繰延税金資産は 660,000円 です。
