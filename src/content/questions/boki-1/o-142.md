個別財務諸表では、未認識数理計算上の差異を貸借対照表に計上しないので、退職給付引当金は「退職給付債務 − 年金資産 ∓ 未認識数理計算上の差異」です。期首の引当金に退職給付費用を加え、掛金拠出と一時金支払を差し引く方法でも同じ金額になります。

### 計算

1. 期首の退職給付引当金：60,000,000 − 42,000,000 − 2,700,000 ＝ 15,300,000円
2. 退職給付費用：3,200,000 ＋ 600,000 − 840,000 ＋ 300,000 ＋ 100,000 ＝ 3,360,000円
3. 引当金の増減

| 項目 | 金額 |
| --- | ---: |
| 期首の退職給付引当金 | 15,300,000 |
| ＋ 退職給付費用 | 3,360,000 |
| − 年金掛金の拠出 | △2,500,000 |
| − 退職一時金の支払 | △800,000 |
| 期末の退職給付引当金 | **15,360,000** |

検算（期末の積立状況から）

| 項目 | 金額 |
| --- | ---: |
| 退職給付債務（実際額） | 61,800,000 |
| − 年金資産（時価） | △43,140,000 |
| − 未認識数理計算上の差異 | △3,300,000 |
| 退職給付引当金 | 15,360,000 |

未認識数理計算上の差異：前期発生分 (3,000,000 − 300,000 × 2年) ＋ 当期発生分 (1,000,000 − 100,000) ＝ 2,400,000 ＋ 900,000 ＝ 3,300,000円

### ポイント

- 年金基金からの年金支払 1,600,000円 は、退職給付債務と年金資産が同額減るだけなので、引当金に影響しません。これを差し引いてしまう誤りに注意します。
- 未認識の借方差異は、将来費用になる「まだ費用処理していない不利差異」なので、積立不足額（18,660,000円）から控除します。
- 連結財務諸表では、未認識数理計算上の差異も含めた積立状況（18,660,000円）を退職給付に係る負債として計上します。
