在外子会社の貸借対照表は、資産・負債を決算日の為替相場、資本を発生時の為替相場で換算するので、その差額が為替換算調整勘定になります。子会社の為替換算調整勘定は持分比率で非支配株主持分に配分し、さらに外貨で把握したのれんの換算差額（親会社持分のみ）を加えます。

### 計算

1. S社の純資産（ドル）：資本金 50,000 ＋ 利益剰余金 (30,000 ＋ 12,000 − 4,000) ＋ 評価差額 10,000 ＝ 98,000ドル
2. S社の資本の換算

| 項目 | ドル | 為替相場 | 円 |
| --- | ---: | ---: | ---: |
| 資本金 | 50,000 | 140 | 7,000,000 |
| 利益剰余金（取得時） | 30,000 | 140 | 4,200,000 |
| 当期純利益 | 12,000 | 145 | 1,740,000 |
| 剰余金の配当 | △4,000 | 144 | △576,000 |
| 評価差額 | 10,000 | 140 | 1,400,000 |
| 小計 | | | 13,764,000 |
| 純資産（決算日の為替相場） | 98,000 | 150 | 14,700,000 |
| 為替換算調整勘定 | | | 936,000 |

3. S社の為替換算調整勘定の配分：非支配株主持分へ 936,000 × 30％ ＝ 280,800円、P社持分 655,200円
4. のれん（外貨）：70,000 − (50,000 ＋ 30,000 ＋ 10,000) × 70％ ＝ 7,000ドル
   - 期首（取得時）：7,000 × 140 ＝ 980,000円
   - 償却額：700ドル × 145 ＝ 101,500円
   - 期末残高：6,300ドル × 150 ＝ 945,000円
   - のれんの換算差額：945,000 − (980,000 − 101,500) ＝ 66,500円
5. 連結貸借対照表の為替換算調整勘定：655,200 ＋ 66,500 ＝ **721,700円**

### ポイント

- のれんは支配獲得時に外国通貨で把握し、期末残高は決算日の為替相場、償却額は期中平均相場で換算します。その差額も為替換算調整勘定になり、親会社持分だけに帰属します。
- 評価差額は資本項目なので、支配獲得時の為替相場で換算します。決算日の為替相場で換算すると為替換算調整勘定がずれます。
- S社の為替換算調整勘定 936,000円 をそのまま答える誤り、非支配株主持分への配分を忘れて 1,002,500円 とする誤りに注意します。
- 在外子会社の為替換算調整勘定は、連結貸借対照表ではその他の包括利益累計額に表示します。在外支店（テンポラル法）の換算差額は為替差損益として当期の損益になる点と区別します。
