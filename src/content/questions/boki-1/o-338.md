事業部長の業績は、事業部長が責任を負える範囲、つまり **管理可能な** 利益と投下資本で評価します。残余利益は、利益から投下資本に資本コスト率を掛けた資本コストを差し引いた額です。

### 計算

| 項目 | 金額 |
| --- | ---: |
| 売上高 | 80,000,000 |
| 変動費 | 48,000,000 |
| 貢献利益 | 32,000,000 |
| 管理可能固定費 | 12,000,000 |
| 管理可能利益 | 20,000,000 |
| 管理可能投下資本の資本コスト 50,000,000 × 8％ | 4,000,000 |
| 事業部長の業績評価のための残余利益 | **16,000,000** |

### ポイント

- 事業部そのもの（投資の対象としての事業部）の業績は、事業部長が管理できない固定費も差し引いた事業部貢献利益（14,000,000円）と、投下資本の総額で評価します。この場合の残余利益は 14,000,000 − 70,000,000 × 8％ ＝ 8,400,000円 です。評価の目的によって使う利益と投下資本を区別します。
- 本社費・共通費の配賦額は事業部長にも事業部にも管理できず、配賦基準によって金額が変わるので、どちらの評価にも含めないのが原則です。
- 投資利益率（ROI）で評価すると、事業部長は資本コストを上回る投資案でも自部門のROIを下げる案を見送るおそれがあります（部分最適）。残余利益は額で評価するので、この問題が起きにくくなります。
