連結財務諸表では、未認識数理計算上の差異を即時に認識し、退職給付債務と年金資産の差額（積立状況）をそのまま退職給付に係る負債とします。未認識だった借方差異は、税効果を控除したうえで、その他の包括利益累計額の「退職給付に係る調整累計額」（借方 ＝ 純資産の減少）とします。

### 計算

1. 期末の積立状況：61,800,000 − 43,140,000 ＝ 18,660,000円（退職給付に係る負債）
2. 個別上の退職給付引当金：15,360,000円
3. 期末の未認識数理計算上の差異：2,400,000（前期発生分）＋ 900,000（当期発生分）＝ 3,300,000円（借方差異）
4. 税効果：3,300,000 × 30％ ＝ 990,000円（繰延税金資産）
5. 退職給付に係る調整累計額：3,300,000 − 990,000 ＝ 2,310,000円（借方）

| 退職給付引当金 | 15,360,000 | 退職給付に係る負債 | 18,660,000 |
| 退職給付に係る調整累計額 | 2,310,000 | | |
| 繰延税金資産 | 990,000 | | |

### ポイント

- 「退職給付に関する会計基準」では、連結貸借対照表上、未認識数理計算上の差異と未認識過去勤務費用を税効果を調整のうえ、純資産の部のその他の包括利益累計額に計上します。個別財務諸表では、当面の間、この処理を行いません。
- 実際の連結手続では、期首残高分（2,700,000円）を開始仕訳で、当期の増減分（費用処理による減少 400,000円、当期発生 1,000,000円）を「退職給付に係る調整額」（その他の包括利益）として処理します。合計すると本問の仕訳と同じ残高になります。
- 税効果を考慮せずに調整累計額を 3,300,000円 とする誤り、借方差異を貸方に計上する（純資産を増やす）誤りが典型的です。
