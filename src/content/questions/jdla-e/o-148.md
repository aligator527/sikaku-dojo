平均の分布は $M = \left(\tfrac14, \tfrac12, \tfrac14\right)$ です。$D_{\mathrm{KL}}(P \parallel M) = \tfrac12\log_2 2 + \tfrac12\log_2 1 = 0.5$、対称性から $D_{\mathrm{KL}}(Q \parallel M) = 0.5$ なので、$D_{\mathrm{JS}} = \tfrac12(0.5 + 0.5) = 0.5$ ビットです。

### 計算

$$D_{\mathrm{KL}}(P \parallel M) = \frac12\log_2\frac{1/2}{1/4} + \frac12\log_2\frac{1/2}{1/2} + 0 = \frac12 \times 1 + 0 = 0.5$$

$P$ が 0 の第 3 成分は $0\log 0 = 0$ として扱います。$D_{\mathrm{KL}}(Q \parallel M)$ も同様に $0.5$ です。

$$D_{\mathrm{JS}}(P \parallel Q) = \frac12 \times 0.5 + \frac12 \times 0.5 = 0.5$$

### ポイント

- この $P, Q$ では、第 1 成分で $P$ が $\tfrac12$、$Q$ が $0$ なので、$D_{\mathrm{KL}}(P \parallel Q)$ は無限大です。JS ダイバージェンスは平均の分布 $M$ と比べるため、台が一部しか重ならなくても有限の値になります。
- 底 2 の JS ダイバージェンスは 0 以上 1 以下で、台がまったく重ならないとき 1（自然対数なら $\log 2$）になります。この例は「半分だけ重なる」ので、ちょうど中間の 0.5 です。自然対数では $0.5\log 2 \approx 0.347$ ナットです。
- GAN の元の定式化では、最適な識別器のもとで生成器が最小化する量が JS ダイバージェンス（の定数倍と定数の和）になります。
