L$p$ ノルムは $\|\boldsymbol x\|_p = \left(\sum_i |x_i|^p\right)^{1/p}$ で、$p = 1$ は絶対値の和、$p = 2$ は二乗和の平方根、$p \to \infty$ の極限は絶対値の最大値です。$\|\boldsymbol x\|_1 = 3 + 4 + 0 + 12 = 19$、$\|\boldsymbol x\|_2 = \sqrt{9 + 16 + 0 + 144} = 13$、$\|\boldsymbol x\|_\infty = 12$ です。

### 各選択肢の検討

- **A** 平方根をとり忘れています。$169$ は $\|\boldsymbol x\|_2^2$ です。
- **B** 絶対値をとらずに和を計算しています（$3 - 4 + 0 + 12 = 11$）。
- **C（正解）** 定義どおりの値です。
- **D** $3$ は 0 でない成分の個数で、いわゆる L0「ノルム」です。L∞ ノルムは成分の絶対値の最大値です。

### ポイント

- 常に $\|\boldsymbol x\|_\infty \le \|\boldsymbol x\|_2 \le \|\boldsymbol x\|_1$ が成り立ちます（$12 \le 13 \le 19$）。
- 正則化では L1 ノルム（Lasso）が重みをちょうど 0 にしてスパースにし、L2 ノルムの 2 乗（Ridge、weight decay）は重みを全体的に小さくします。
- 勾配クリッピング（ノルムによるクリッピング）では、勾配ベクトルの L2 ノルムが閾値を超えたときに、向きを保ったまま閾値の長さまで縮めます。
- シラバス 2026（E2026#2〜）では、線形代数は「オプション（出題対象外）」の項目で、直接は出題されない前提知識の扱いです。
