  3 つの値をとる離散確率変数について、2 つの確率分布

  $$p = \left(\tfrac12,\ \tfrac14,\ \tfrac14\right),\qquad q = \left(\tfrac14,\ \tfrac14,\ \tfrac12\right)$$

  を考える。対数の底を 2 としたとき、エントロピー $H(p)$、交差エントロピー $H(p, q) = -\sum_i p_i \log_2 q_i$、KL ダイバージェンス $D_{\mathrm{KL}}(p \parallel q)$ の値の組み合わせとして正しいものを選べ（単位はいずれもビット）。
choices:

  - '$H(p) \approx 1.04,\ H(p,q) \approx 1.21,\ D_{\mathrm{KL}}(p \parallel q) \approx 0.17$'
  - '$H(p) = 1.5,\ H(p,q) = 1.75,\ D_{\mathrm{KL}}(p \parallel q) = 0.25$'

交差エントロピーはエントロピーと KL ダイバージェンスの和 $H(p, q) = H(p) + D_{\mathrm{KL}}(p \parallel q)$ に分解できます。$H(p) = 1.5$、$H(p,q) = 1.75$ なので $D_{\mathrm{KL}}(p\parallel q) = 0.25$ です。

### 計算

$\log_2 \tfrac12 = -1$、$\log_2 \tfrac14 = -2$ を使います。

$$H(p) = -\left(\tfrac12\cdot(-1) + \tfrac14\cdot(-2) + \tfrac14\cdot(-2)\right) = 0.5 + 0.5 + 0.5 = 1.5$$

$$H(p, q) = -\left(\tfrac12\cdot(-2) + \tfrac14\cdot(-2) + \tfrac14\cdot(-1)\right) = 1 + 0.5 + 0.25 = 1.75$$

$$D_{\mathrm{KL}}(p\parallel q) = \sum_i p_i \log_2\frac{p_i}{q_i} = \tfrac12\log_2 2 + \tfrac14\log_2 1 + \tfrac14\log_2\tfrac12 = 0.5 + 0 - 0.25 = 0.25$$

### 各選択肢の検討

- **A** KL ダイバージェンスは常に 0 以上です（ギブスの不等式）。負の値にはなりません。
- **B** $H(p)$ と $H(p, q)$ を取り違えています。$H(p, q) \ge H(p)$ が常に成り立ちます。
- **C** 自然対数で計算した値（単位はナット）です。問題では底を 2 と指定しているので誤りです。
- **D（正解）** $1.75 = 1.5 + 0.25$ と分解の関係も満たしています。

### ポイント

- 分類問題で交差エントロピー誤差を最小化することは、正解分布 $p$ が固定されているので $H(p)$ が定数となり、$D_{\mathrm{KL}}(p\parallel q)$ を最小化することと同じです。
- KL ダイバージェンスは一般に非対称で、$D_{\mathrm{KL}}(p\parallel q) \ne D_{\mathrm{KL}}(q\parallel p)$ です（この例ではたまたま等しくなります）。対称化したものの一つが JS ダイバージェンスです。
- 底を $e$ にすると単位はナットになり、ビットの値に $\log 2 \approx 0.693$ を掛けた値になります。
