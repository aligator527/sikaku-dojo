順伝播で $\boldsymbol u = (-1, 0.5)$ となり、1 番目の隠れユニットは ReLU で 0 に切られます。逆伝播では、このユニットを通る勾配も 0 になるので、$x_1$ への勾配は 2 番目のユニットを経由する分だけで、$4.5 \times W_{21} = 4.5 \times 0.5 = 2.25$ です。

### 計算

**順伝播**

$$u_1 = 1\cdot1 + (-1)\cdot2 + 0 = -1,\qquad u_2 = 0.5\cdot1 + 0.5\cdot2 - 1 = 0.5$$

$$\boldsymbol h = (0,\ 0.5),\qquad y = 2\cdot0 + (-3)\cdot0.5 + 1 = -0.5,\qquad L = \tfrac12(-0.5 - 1)^2 = 1.125$$

**逆伝播**

$$\frac{\partial L}{\partial y} = y - t = -1.5,\qquad \frac{\partial L}{\partial \boldsymbol h} = \boldsymbol v\,\frac{\partial L}{\partial y} = (-3,\ 4.5)$$

ReLU の微分は $u_1 < 0$ で $0$、$u_2 > 0$ で $1$ なので

$$\frac{\partial L}{\partial \boldsymbol u} = (-3 \times 0,\ 4.5 \times 1) = (0,\ 4.5).$$

$\boldsymbol u = W\boldsymbol x + \boldsymbol b$ より $\dfrac{\partial L}{\partial \boldsymbol x} = W^{\mathsf T}\dfrac{\partial L}{\partial \boldsymbol u}$ なので

$$\frac{\partial L}{\partial x_1} = W_{11}\cdot 0 + W_{21}\cdot 4.5 = 1 \times 0 + 0.5 \times 4.5 = 2.25.$$

### ポイント

- ReLU のマスクを忘れると $\partial L/\partial x_1 = 1\times(-3) + 0.5 \times 4.5 = -0.75$、$W^{\mathsf T}$ ではなく $W$ を掛けると $1 \times 0 + (-1) \times 4.5 = -4.5$ となり、どちらも誤りです。入力 $x_j$ への勾配は、$x_j$ が影響するすべてのユニット $i$ について $W_{ij}\,\partial L/\partial u_i$ を足し合わせます。
- 同じ途中結果から重みの勾配も求められます。$\partial L/\partial W = (\partial L/\partial \boldsymbol u)\,\boldsymbol x^{\mathsf T}$ なので、1 行目（停止したユニット）は $(0, 0)$、2 行目は $(4.5, 9)$ です。
- 逆伝播では、順伝播で計算した $\boldsymbol u$（または ReLU のマスク）と $\boldsymbol h$ を保存しておき再利用します。
