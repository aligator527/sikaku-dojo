重みは全位置で共有されているので、$\partial L/\partial w_k$ は各出力位置からの寄与の和で、入力と上流の勾配の相互相関になります。入力 $x_j$ は複数の出力に使われるので、$\partial L/\partial x_j$ も関係する出力すべてからの寄与の和で、上流の勾配と（反転した）カーネルとの畳み込みになります。

### 計算

上流の勾配を $g_i = \partial L/\partial y_i$ とすると、$g = (1, 0, -2)$ です。

**重みの勾配** $y_i$ に $w_1$ は $x_i$ を、$w_2$ は $x_{i+1}$ を掛けて寄与するので

$$\frac{\partial L}{\partial w_1} = \sum_i g_i x_i = 1\cdot1 + 0\cdot2 + (-2)\cdot(-1) = 3,\qquad \frac{\partial L}{\partial w_2} = \sum_i g_i x_{i+1} = 1\cdot2 + 0\cdot(-1) + (-2)\cdot3 = -4.$$

**入力の勾配** $x_j$ は $y_j$（係数 $w_1$）と $y_{j-1}$（係数 $w_2$）に寄与するので、$\partial L/\partial x_j = g_j w_1 + g_{j-1} w_2$（範囲外の $g$ は 0）です。

$$\frac{\partial L}{\partial \boldsymbol x} = (1\cdot2,\ \ 1\cdot(-1) + 0\cdot2,\ \ 0\cdot(-1) + (-2)\cdot2,\ \ (-2)\cdot(-1)) = (2,\ -1,\ -4,\ 2)$$

### 各選択肢の検討

- **A** $\partial L/\partial \boldsymbol x$ を、0 でパディングした $g$ とカーネル $\boldsymbol w$ を反転せずに相互相関させて求めた結果です。入力の勾配はカーネルを反転させた演算（数学的な畳み込み）になります。
- **B（正解）** 重みの勾配・入力の勾配ともに正しい値です。
- **C** $\partial L/\partial \boldsymbol w$ の成分の順序が逆です。$w_1$ は各窓の左側の入力 $x_i$ に掛かります。
- **D** 最初の出力 $y_1$ からの寄与だけを使った値（$\partial L/\partial \boldsymbol w = g_1(x_1, x_2)$、$\partial L/\partial \boldsymbol x = g_1(w_1, w_2, 0, 0)$）です。重みと入力はいずれも複数の出力に使われているので、すべての出力位置からの寄与を足し合わせる必要があります。

### ポイント

- 畳み込み層の逆伝播は、重みの勾配が「入力と上流の勾配の相互相関」、入力の勾配が「上流の勾配を 0 パディングして反転カーネルと相互相関（＝転置畳み込み）」になります。
- バイアスがある場合、その勾配は上流の勾配を全位置について足し合わせたもの（この例では $1 + 0 - 2 = -1$）です。
- 2 次元でも考え方は同じで、im2col を使う実装では行列積の逆伝播として $\partial L/\partial W = \text{col}^{\mathsf T}\, dY$ を計算します。
