$\operatorname{Cov}(X, Y) = E[XY] - E[X]E[Y] = E[X^3] - 0 = 0$ なので無相関です。一方、$P(X = 0, Y = 1) = 0$ ですが $P(X = 0)P(Y = 1) = \tfrac13 \times \tfrac23 = \tfrac29$ で、同時確率が周辺確率の積に一致しないため独立ではありません。

### 計算

$$E[X] = \tfrac13(-1 + 0 + 1) = 0,\qquad E[Y] = E[X^2] = \tfrac13(1 + 0 + 1) = \tfrac23$$

$$E[XY] = E[X^3] = \tfrac13(-1 + 0 + 1) = 0,\qquad \operatorname{Cov}(X, Y) = 0 - 0 \times \tfrac23 = 0$$

独立であれば、すべての $(x, y)$ で $P(X = x, Y = y) = P(X = x)P(Y = y)$ が成り立つ必要があります。$(x, y) = (0, 1)$ では左辺 $0$、右辺 $\tfrac29$ で成り立ちません。

### 各選択肢の検討

- **A** $E[XY]$ を $E[X^2] = \tfrac23$ と計算した誤りです。$XY = X^3$ です。
- **B** 「独立 ⇒ 無相関」は成り立ちますが、逆は一般には成り立ちません。共分散は**線形**な関係しか測らないためです（例外として、同時分布が多変量正規分布なら無相関と独立は同値です）。
- **C（正解）** 無相関であっても独立とは限りません。
- **D** $Y$ は $X$ で完全に決まりますが、関係が非線形（$X$ の符号を区別しない）なので、線形の関係の強さを表す相関係数は 0 です。

### ポイント

- 非線形な依存関係も捉える指標が相互情報量 $I(X; Y)$ で、$I(X; Y) = 0$ は独立と同値です。この例では $I(X; Y) = H(Y) > 0$ です。
- 共分散の性質：$\operatorname{Cov}(X, X) = V[X]$、$\operatorname{Cov}(aX + b, Y) = a\operatorname{Cov}(X, Y)$。
- シラバス 2026（E2026#2〜）では、確率・統計のうち「一般的な確率分布」（同時確率・周辺確率・共分散など）は「オプション（出題対象外）」の項目で、直接は出題されない前提知識の扱いです。
