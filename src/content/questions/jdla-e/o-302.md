  モメンタム付きの確率的勾配降下法で、1 次元のパラメータ $w$ を次の式で更新する。

  $$v_t = \alpha v_{t-1} - \eta\, g_t,\qquad w_t = w_{t-1} + v_t$$

  ここで $g_t$ は $w_{t-1}$ における損失の勾配である。$w_0 = 1.0$、$v_0 = 0$、モメンタム係数 $\alpha = 0.9$、学習率 $\eta = 0.1$ とし、1 回目と 2 回目の更新で得られた勾配がそれぞれ $g_1 = 0.5$、$g_2 = 0.3$ であったとき、2 回更新した後の $w_2$ を求めよ。

速度 $v$ には前回の速度が $\alpha$ 倍で残るので、2 回目の更新量は「今回の勾配による $-\eta g_2$」に「前回の速度の 0.9 倍」を加えたものになります。$v_1 = -0.05$、$v_2 = 0.9 \times (-0.05) - 0.1 \times 0.3 = -0.075$ より、$w_2 = 0.95 - 0.075 = 0.875$ です。

### 計算

$$v_1 = 0.9 \times 0 - 0.1 \times 0.5 = -0.05,\qquad w_1 = 1.0 - 0.05 = 0.95$$

$$v_2 = 0.9 \times (-0.05) - 0.1 \times 0.3 = -0.045 - 0.03 = -0.075,\qquad w_2 = 0.95 - 0.075 = 0.875$$

### ポイント

- モメンタムなしの SGD では $w_2 = 1.0 - 0.05 - 0.03 = 0.92$ です。同じ向きの勾配が続くと、モメンタムによって更新が加速されます。
- $w_2 = w_0 + v_2 = 0.925$ とするのは誤りです。1 回目の移動 $v_1$ も積み重なるので $w_2 = w_0 + v_1 + v_2$ です。
- $v_t = \beta v_{t-1} + (1-\beta) g_t$、$w_t = w_{t-1} - \eta v_t$ という指数移動平均の形で書く流儀もあります。この形では同じ $\eta$ でも更新量がおよそ $(1-\beta)$ 倍になり、本問の数値なら $w_2 = 0.9875$ です。式の定義を必ず確認します。
