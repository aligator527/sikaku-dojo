事前分布の負の対数をとると、ガウス分布 $\mathcal N(0, \sigma^2)$ からは $\dfrac{w^2}{2\sigma^2}$、ラプラス分布（尺度 $b$）からは $\dfrac{|w|}{b}$ が出てきます。それぞれ係数 $1/\sigma^2$ の L2 正則化、係数 $1/b$ の L1 正則化です。分散（$\sigma^2$ や $2b^2$）が小さいほど係数が大きくなり、重みを 0 付近に強く押しとどめます。

### 計算

$$-\log \mathcal N(w \mid 0, \sigma^2) = \frac{w^2}{2\sigma^2} + \frac12\log(2\pi\sigma^2)$$

$$-\log \mathrm{Laplace}(w \mid 0, b) = -\log\left(\frac{1}{2b}e^{-|w|/b}\right) = \frac{|w|}{b} + \log(2b)$$

第 2 項は $w$ によらない定数なので、最適化には影響しません。

### 各選択肢の検討

- **A** 対応が入れ替わっています。$w^2$ が出てくるのはガウス分布、$|w|$ が出てくるのはラプラス分布です。
- **B（正解）** 対応関係と、分散と正則化の強さの関係がどちらも正しい記述です。
- **C** 向きが逆です。分散を大きくすると事前分布が平らになり、正則化は弱くなります。分散を無限大にした極限は正則化なしの最尤推定です。
- **D** 一様分布の密度は区間内で一定なので、$-\log p(w)$ は区間内で定数になり、ペナルティは生じません。MAP 推定は（区間内では）最尤推定と同じになります。

### ポイント

- 正則化係数は「事前分布の分散の逆数」と対応します。データが少ないときほど事前分布（正則化）の影響が相対的に大きくなります。
- ラプラス分布は原点で尖った形をしているので、MAP 推定値がちょうど 0 になりやすく、L1 正則化のスパース性と対応しています。
