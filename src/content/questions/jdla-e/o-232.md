誤差（予測値 − 実際の値）は $1, -2, 0, 3, -1$ です。2 乗の平均（MSE）は $(1 + 4 + 0 + 9 + 1)/5 = 3$ なので、RMSE は $\sqrt3 \approx 1.73$ です。

### 計算

$$\text{MSE} = \frac{1}{5}\sum_{i=1}^{5}(\hat y_i - y_i)^2 = \frac{1 + 4 + 0 + 9 + 1}{5} = \frac{15}{5} = 3$$

$$\text{RMSE} = \sqrt{\text{MSE}} = \sqrt3 \approx 1.732$$

参考までに、MAE（平均絶対誤差）は $(1 + 2 + 0 + 3 + 1)/5 = 1.4$ です。

### ポイント

- RMSE は誤差を 2 乗してから平均するので、大きな誤差（ここではデータ 4 の $3$）の影響を強く受けます。MAE は誤差の絶対値の平均で、外れ値の影響を受けにくい指標です。
- RMSE と MAE は、どちらも目的変数と同じ単位を持ちます。MSE は単位が 2 乗になります。
- 平方根をとり忘れる（$3$）、和の平方根をとる（$\sqrt{15} \approx 3.87$）、MAE と取り違える（$1.4$）といった誤りに注意します。
