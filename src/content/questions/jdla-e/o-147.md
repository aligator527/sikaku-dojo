相互情報量は「一方を知ることで他方の不確かさがどれだけ減るか」で、$I(X; Y) = H(X) - H(X \mid Y)$ と書けます（A）。同時分布が独立な場合の分布 $p(x)p(y)$ からどれだけ離れているかを KL ダイバージェンスで測った量とも解釈できます（D）。KL ダイバージェンスは非負なので $I(X; Y) \ge 0$、すなわち $H(X \mid Y) \le H(X)$ です。

### 各選択肢の検討

- **A（正しい）** 連鎖律 $H(X, Y) = H(Y) + H(X \mid Y) = H(X) + H(Y \mid X)$ と $I(X; Y) = H(X) + H(Y) - H(X, Y)$ から導かれます。
- **B（誤り）** 相関係数は線形の関係しか測りません。$X$ が $-1, 0, 1$ を等確率でとり $Y = X^2$ のとき、相関係数は 0 ですが $I(X; Y) = H(Y) > 0$ です。$I(X; Y) = 0$ と同値なのは独立性です。
- **C（誤り）** $H(X) - H(X \mid Y) = I(X; Y) \ge 0$ なので、平均としての条件付きエントロピーが元のエントロピーを上回ることはありません。特定の値 $y$ についての $H(X \mid Y = y)$ が $H(X)$ より大きくなることはありますが、$Y$ について平均すると必ず $H(X)$ 以下になります。
- **D（正しい）** $D_{\mathrm{KL}}(p(x, y) \parallel p(x)p(y)) = \sum_{x, y}p(x, y)\log\dfrac{p(x, y)}{p(x)p(y)}$ は相互情報量の定義そのものです。
- **E（誤り）** $I(X; Y) = H(X) + H(Y) - H(X, Y)$ で、ベン図では $H(X)$ と $H(Y)$ の重なりの部分です。結合エントロピーは和集合の部分にあたります。

### ポイント

- ベン図で整理すると覚えやすくなります：$H(X, Y)$ が全体、$H(X \mid Y)$ と $H(Y \mid X)$ が重ならない部分、$I(X; Y)$ が重なり。
- $I(X; X) = H(X)$ で、自分自身との相互情報量はエントロピーに一致します。
- 表現学習では、入力と表現の相互情報量を大きくすることを目標にする手法があり、対照学習の InfoNCE 損失は相互情報量の下界を最大化していると解釈されます。
