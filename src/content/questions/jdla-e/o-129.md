まず $E[X]$ と $E[X^2]$ から $V[X] = E[X^2] - (E[X])^2 = 1.24$ を求めます。定数倍は 2 乗で効き、定数の加算は分散を変えないので、$V[2X + 1] = 2^2 V[X] = 4.96$ です。

### 計算

$$E[X] = 0 \times 0.2 + 1 \times 0.5 + 3 \times 0.3 = 1.4$$

$$E[X^2] = 0^2 \times 0.2 + 1^2 \times 0.5 + 3^2 \times 0.3 = 0.5 + 2.7 = 3.2$$

$$V[X] = 3.2 - 1.4^2 = 3.2 - 1.96 = 1.24,\qquad V[Y] = 4 \times 1.24 = 4.96$$

### ポイント

- $E[aX + b] = aE[X] + b$、$V[aX + b] = a^2V[X]$ です。$V[2X + 1] = 2V[X] + 1 = 3.48$ や $4V[X] + 1 = 5.96$ とするのは典型的な誤りです。
- $V[X] = E[X^2] - (E[X])^2$ で、$E[X^2]$ を $(E[X])^2$ と混同しないようにします。
- 独立な確率変数の和では $V[X + Y] = V[X] + V[Y]$、一般には $V[X + Y] = V[X] + V[Y] + 2\operatorname{Cov}(X, Y)$ です。重みの初期化（Xavier / He）は、この分散の計算から各層の出力の分散が一定に保たれるように設計されています。
- シラバス 2026（E2026#2〜）では、確率・統計のうち「一般的な確率分布」（確率の基礎・期待値・分散など）は「オプション（出題対象外）」の項目で、直接は出題されない前提知識の扱いです。最尤推定など出題対象の項目を理解する土台になります。
