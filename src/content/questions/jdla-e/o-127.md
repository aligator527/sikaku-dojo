  線形回帰モデル $y_i = \boldsymbol w^{\mathsf T}\boldsymbol x_i + \varepsilon_i$（$\varepsilon_i \sim \mathcal N(0, \sigma^2)$ は独立）の重み $\boldsymbol w$ に、事前分布 $\boldsymbol w \sim \mathcal N(\boldsymbol 0, \tau^2 I)$ をおいて MAP 推定する。$\sigma^2$ と $\tau^2$ は既知の定数とする。この MAP 推定は、目的関数

  $$E(\boldsymbol w) = \sum_{i=1}^{n}(y_i - \boldsymbol w^{\mathsf T}\boldsymbol x_i)^2 + \lambda\|\boldsymbol w\|_2^2$$

  の最小化（L2 正則化付きの最小二乗法、リッジ回帰）と等価である。このときの正則化係数 $\lambda$ として正しいものを選べ。
choices:

  - '$\lambda = \dfrac{\tau^2}{\sigma^2}$'
  - '$\lambda = \dfrac{1}{2\tau^2}$'
  - '$\lambda = \dfrac{\sigma^2}{\tau^2}$'
answer: 4

負の対数事後分布は、定数を除いて $\dfrac{1}{2\sigma^2}\sum_i(y_i - \boldsymbol w^{\mathsf T}\boldsymbol x_i)^2 + \dfrac{1}{2\tau^2}\|\boldsymbol w\|_2^2$ です。二乗誤差の項の係数が 1 になるよう全体に $2\sigma^2$ を掛けて問題の形にそろえると、$\lambda = \sigma^2/\tau^2$ です。

### 計算

$$-\log p(\boldsymbol w \mid D) = -\sum_{i}\log\mathcal N(y_i \mid \boldsymbol w^{\mathsf T}\boldsymbol x_i, \sigma^2) - \log\mathcal N(\boldsymbol w \mid \boldsymbol 0, \tau^2 I) + \text{const}$$

$$= \frac{1}{2\sigma^2}\sum_{i}(y_i - \boldsymbol w^{\mathsf T}\boldsymbol x_i)^2 + \frac{1}{2\tau^2}\|\boldsymbol w\|_2^2 + \text{const}$$

正の定数 $2\sigma^2$ を掛けても最小点は変わらないので

$$\sum_{i}(y_i - \boldsymbol w^{\mathsf T}\boldsymbol x_i)^2 + \frac{\sigma^2}{\tau^2}\|\boldsymbol w\|_2^2.$$

### 各選択肢の検討

- **A** 全体に $\sigma^2$ だけを掛けた値です。このとき二乗誤差の項の係数は $\tfrac12$ になり、問題の目的関数（係数 1）とは形が異なります。係数 1 にそろえると $\lambda$ は 2 倍の $\sigma^2/\tau^2$ です。
- **B** 比が逆です。事前分布の分散 $\tau^2$ が小さい（重みは 0 に近いという信念が強い）ほど、正則化は強く（$\lambda$ は大きく）なるはずです。
- **C** 負の対数事後分布の正則化項の係数 $\tfrac{1}{2\tau^2}$ をそのまま読み取っています。二乗誤差の項の係数は $\tfrac{1}{2\sigma^2}$ で 1 ではないので、両方の項の比で考える必要があります。
- **D（正解）** 二乗誤差の係数を 1 にそろえたときの正則化項の係数です。

### ポイント

- 対応関係：ガウス分布のノイズ ↔ 二乗誤差、ガウス分布の事前分布 ↔ L2 正則化（weight decay）、ラプラス分布の事前分布 ↔ L1 正則化。
- ノイズが大きい（$\sigma^2$ が大きい）ほどデータを信用できないので、$\lambda$ が大きくなり事前分布を重視します。
- 事前分布をおかない最尤推定は、$\lambda = 0$ の通常の最小二乗法です。
