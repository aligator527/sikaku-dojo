スコアは内積を $\sqrt{d_k} = 2$ で割った $\boldsymbol q^{\mathsf T}\boldsymbol k_i/\sqrt{d_k}$ で、$(4/2,\ 0/2,\ 0/2) = (2, 0, 0)$ です。ソフトマックス関数を適用すると、$\boldsymbol k_1$ の重みは $\dfrac{e^2}{e^2 + e^0 + e^0} = \dfrac{7.39}{9.39} \approx 0.79$ です。

### 計算

**内積**

$$\boldsymbol q^{\mathsf T}\boldsymbol k_1 = 2 + 0 + 2 + 0 = 4,\qquad \boldsymbol q^{\mathsf T}\boldsymbol k_2 = 1 + 0 - 1 + 0 = 0,\qquad \boldsymbol q^{\mathsf T}\boldsymbol k_3 = 0$$

**スケーリング** $\sqrt{d_k} = \sqrt4 = 2$ で割って $(2, 0, 0)$。

**ソフトマックス**

$$a_1 = \frac{e^2}{e^2 + 1 + 1} \approx \frac{7.39}{9.39} \approx 0.787,\qquad a_2 = a_3 = \frac{1}{9.39} \approx 0.106$$

### ポイント

- $\sqrt{d_k}$ で割り忘れると、スコアが $(4, 0, 0)$ となって $a_1 = e^4/(e^4 + 2) \approx 0.96$ になり、重みが 1 つのキーに偏ります。
- $\sqrt{d_k}$ ではなく $d_k$ で割ると、スコアが $(1, 0, 0)$ となって $a_1 = e/(e + 2) \approx 0.58$ になります。
- 出力は値ベクトルの重み付き和 $\sum_i a_i \boldsymbol v_i$ です。行列でまとめると $\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(QK^{\mathsf T}/\sqrt{d_k}\right)V$ で、ソフトマックス関数はキーの方向（行ごと）に適用します。
