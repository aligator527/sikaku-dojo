ベイズ則 $P(S \mid W) = \dfrac{P(W \mid S)P(S)}{P(W)}$ を使います。分母の $P(W)$ は、迷惑メールとそれ以外の両方から「当選」を含むメールが生じる確率の和（周辺化）です。$P(S \mid W) = 0.18/0.25 = 0.72$ です。

### 計算

$S$ を「迷惑メールである」、$W$ を「当選を含む」とします。

$$P(W) = P(W \mid S)P(S) + P(W \mid \bar S)P(\bar S) = 0.6 \times 0.3 + 0.1 \times 0.7 = 0.18 + 0.07 = 0.25$$

$$P(S \mid W) = \frac{0.18}{0.25} = 0.72$$

### ポイント

- 尤度 $P(W \mid S) = 0.6$ と事後確率 $P(S \mid W) = 0.72$ を混同しないようにします。事前確率 $P(S) = 0.3$ が「当選」という証拠によって $0.72$ に更新された、と読みます。
- 分母は $P(W \mid S)P(S)$ を $S$ のすべての値について足した正規化定数です。分母を $P(W \mid S)$ だけにしたり、$P(\bar S)$ を掛け忘れたりする誤りが典型的です。
- 複数の単語を使うときに「クラスが与えられたもとで単語の出現は互いに独立」と仮定して尤度を積で表すのが、ナイーブベイズ分類器です。
