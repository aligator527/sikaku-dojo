990 件の陰性はすべて正しく予測されるので、正解率は $990/1000 = 0.99$ です。しかし陽性 10 件を 1 件も検出できないので、再現率は $0/10 = 0$ です。陽性がまれな不均衡データでは、何も検出しないモデルでも正解率が高く見えます。

### 計算

混同行列は $TP = 0$、$FN = 10$、$FP = 0$、$TN = 990$ です。

$$\text{Accuracy} = \frac{0 + 990}{1000} = 0.99,\qquad \text{Recall} = \frac{0}{0 + 10} = 0,\qquad \text{特異度} = \frac{990}{990 + 0} = 1$$

### 各選択肢の検討

- **A** 再現率の分母は実際の陽性数 $10$ で、分子の $TP$ は $0$ です。
- **B** 正解率の分子には、正しく陰性と予測した $TN = 990$ 件も含まれます。
- **C** 特異度（陰性を陰性と予測できた割合）は $990/990 = 1$ です。このモデルは陰性に対しては完璧です。
- **D（正解）** 正解率と再現率が大きく食い違う典型例です。

### ポイント

- 陽性と予測した件数が $0$ なので、適合率は $0/0$ で定義できません（ライブラリでは 0 として警告を出すことが多い）。F 値も実質的に $0$ と評価されます。
- 不均衡データの評価には、陽性クラスの適合率・再現率・F 値、PR 曲線、クラスごとの指標の macro 平均などを使います。
- 学習の段階では、少数クラスの重みを大きくする、オーバーサンプリング・アンダーサンプリングを行う、などの対策があります。
