目的関数は成分ごとに分かれるので、1 成分ずつ最小化します。L1 正則化では $w_i = \mathrm{sign}(a_i)\max(|a_i| - \lambda,\ 0)$（ソフトしきい値処理）となり、$|a_i| \le \lambda$ の成分はちょうど 0 になります。L2 正則化では $w_i = a_i/(1+\lambda)$ と、すべての成分が同じ比率で縮みます。

### 計算

**L1 正則化** $\frac12(w - a)^2 + \lambda|w|$ を考えます。$w > 0$ なら微分して $w - a + \lambda = 0$ より $w = a - \lambda$ で、これは $a > \lambda$ のときだけ $w > 0$ を満たします。$w < 0$ も同様で、$|a| \le \lambda$ なら $w = 0$ が最小です。

- $a_1 = 1.2$：$1.2 - 0.5 = 0.7$
- $a_2 = -0.3$：$|{-0.3}| \le 0.5$ なので $0$
- $a_3 = 0.6$：$0.6 - 0.5 = 0.1$

**L2 正則化** $\frac12(w - a)^2 + \frac{\lambda}{2}w^2$ を微分して $w - a + \lambda w = 0$ より $w = a/1.5$ です。

$$\left(\frac{1.2}{1.5},\ \frac{-0.3}{1.5},\ \frac{0.6}{1.5}\right) = (0.8,\ -0.2,\ 0.4)$$

### 各選択肢の検討

- **A（正解）** L1 はソフトしきい値処理、L2 は一様な縮小です。
- **B** L1 と L2 の結果が入れ替わっています。
- **C** L1 で、すべての成分から一律に $\lambda\,\mathrm{sign}(a_i)$ を引いています。$a_2 = -0.3$ から $-0.5$ を引くと $0.2$ になり符号が反転しますが、$w > 0$ では $\lambda|w|$ の勾配は $+\lambda$ なので停留点の条件を満たしません。0 で止まるのが正しい解です。
- **D** L2 の正則化項 $\frac{\lambda}{2}w^2$ の微分を $\frac{\lambda}{2}w$ として、$a/1.25$ と計算しています。

### ポイント

- L1 正則化は小さな成分を 0 に「切り捨て」、L2 正則化は全成分を同じ比率で「縮める」と覚えると、スパース性の違いがすぐにわかります。
- ソフトしきい値処理は、L1 正則化を含む目的関数を解く近接勾配法（ISTA など）の基本的な操作です。
