  1 つのユニットに学習時の Batch Normalization を適用する。ミニバッチの入力を $x_1, \ldots, x_N$、その平均を $\mu$、分散を $\sigma^2$（$N$ で割る）として

  $$\hat x_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \varepsilon}},\qquad y_i = \gamma\,\hat x_i + \beta$$

  とする。$x_i$ はすべて等しいわけではないとする。損失 $L$ の出力に関する勾配が、すべてのサンプルで等しく $\dfrac{\partial L}{\partial y_i} = c\ (c \ne 0)$ であったとき、$\dfrac{\partial L}{\partial x_i}$、$\dfrac{\partial L}{\partial \gamma}$、$\dfrac{\partial L}{\partial \beta}$ の組み合わせとして正しいものを選べ。

すべての出力を同じだけ動かしたいという勾配は、BN の入力をどう変えても実現できません。入力全体に定数を足しても平均が同じだけずれて打ち消されるからです。そのため $\partial L/\partial x_i = 0$ になり、この勾配はシフト $\beta$ だけが受け取ります（$\partial L/\partial\beta = Nc$）。$\hat x_i$ の和は 0 なので $\partial L/\partial\gamma = c\sum_i \hat x_i = 0$ です。

### 計算

$\gamma$ と $\beta$ については

$$\frac{\partial L}{\partial \beta} = \sum_{i=1}^{N}\frac{\partial L}{\partial y_i} = Nc,\qquad \frac{\partial L}{\partial \gamma} = \sum_{i=1}^{N}\frac{\partial L}{\partial y_i}\hat x_i = c\sum_{i=1}^{N}\hat x_i = 0$$

入力についての勾配は、$\mu$ と $\sigma^2$ も $x_i$ の関数であることを考慮すると

$$\frac{\partial L}{\partial x_i} = \frac{\gamma}{N\sqrt{\sigma^2 + \varepsilon}}\left(N\frac{\partial L}{\partial y_i} - \sum_{j}\frac{\partial L}{\partial y_j} - \hat x_i\sum_{j}\frac{\partial L}{\partial y_j}\hat x_j\right)$$

です。$\partial L/\partial y_j = c$ を代入すると、括弧の中は $Nc - Nc - \hat x_i \cdot c\sum_j \hat x_j = 0$ になります。

### 各選択肢の検討

- **A（正解）** 上の計算のとおりです。
- **B** $\mu$ と $\sigma^2$ を定数とみなし、$\partial y_i/\partial x_i = \gamma/\sqrt{\sigma^2+\varepsilon}$ だけで計算しています。平均と分散を通じて他のサンプルの入力にも依存する経路を見落としています。
- **C** $\partial L/\partial \gamma$ を $\sum_i \partial L/\partial y_i$ としています。$y_i = \gamma\hat x_i + \beta$ なので、$\gamma$ の勾配には $\hat x_i$ が掛かります。
- **D** ミニバッチ内の和をとっておらず、平均と分散の依存関係も無視しています。

### ポイント

- 一般の勾配でも $\sum_i \partial L/\partial x_i = 0$ が成り立ちます（BN の出力は入力の平行移動に不変だからです）。実装の検算に使えます。
- BN の逆伝播は、平均と分散の計算をそれぞれ計算グラフのノードとして扱い、連鎖律で順にたどると導けます。
