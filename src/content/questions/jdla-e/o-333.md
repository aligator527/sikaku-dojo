交差エントロピー $-\sum_k t_k\log y_k$ は、出力分布 $\boldsymbol y$ が目標分布 $\boldsymbol t$ に一致したときに最小になります（ギブスの不等式）。$t_1 = 0.91$、$t_k = 0.01\ (k \ne 1)$ なので、$y_1/y_k = e^{z_1 - z_k} = 91$ となり、$z_1 - z_k = \log 91 = \log 7 + \log 13 \approx 4.51$ です。

### 計算

$$t_1 = 0.9 + \frac{0.1}{10} = 0.91,\qquad t_k = \frac{0.1}{10} = 0.01\quad (k \ne 1)$$

$L = H(\boldsymbol t) + D_{\mathrm{KL}}(\boldsymbol t \parallel \boldsymbol y)$ と分解でき、$D_{\mathrm{KL}} \ge 0$ で等号は $\boldsymbol y = \boldsymbol t$ のときだけなので、最小点では $y_k = t_k$ です。ソフトマックス関数では $y_1/y_k = e^{z_1 - z_k}$ なので

$$z_1 - z_k = \log\frac{0.91}{0.01} = \log 91 = \log 7 + \log 13 \approx 1.946 + 2.565 = 4.511$$

です。ロジット全体に定数を足しても出力は変わらないので、最小にするロジットそのものは一意ではありませんが、差は一意に決まります。

### ポイント

- 平滑化しない one-hot の目標では、損失は $y_1 \to 1$ で 0 に近づくだけで最小値に到達せず、ロジットの差を限りなく大きくし続けようとします。ラベル平滑化では目標とすべきロジットの差が有限の値（本問では約 4.51）になるので、過度に確信した出力や、ロジットの際限ない増大を防ぎます。
- 他のクラスに $\varepsilon/(K-1)$、正解クラスに $1 - \varepsilon$ を割り振る定義では、差は $\log\dfrac{0.9}{0.1/9} = \log 81 \approx 4.39$ になります。PyTorch の `nn.CrossEntropyLoss(label_smoothing=0.1)` は本問と同じく、全クラスに $\varepsilon/K$ を足す定義です。
- ラベル平滑化は 2026 年版の E資格シラバスのキーワードには含まれていませんが、画像分類や Transformer の学習で広く使われる正則化です。
