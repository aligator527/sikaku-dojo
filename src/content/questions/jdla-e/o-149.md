  GAN の価値関数

  $$V(D, G) = E_{\boldsymbol x \sim p_{\mathrm{data}}}[\log D(\boldsymbol x)] + E_{\boldsymbol x \sim p_g}[\log(1 - D(\boldsymbol x))]$$

各点 $\boldsymbol x$ で $a\log D + b\log(1 - D)$（$a = p_{\mathrm{data}}(\boldsymbol x)$、$b = p_g(\boldsymbol x)$）を $D$ について最大化すると $D^* = \dfrac{a}{a + b}$ です。これを代入して整理すると $C(G) = -\log 4 + 2D_{\mathrm{JS}}(p_{\mathrm{data}} \parallel p_g)$ となり、生成器の最適解は $p_g = p_{\mathrm{data}}$（このとき $D^* = \tfrac12$、$C(G) = -\log 4$）です。

### 計算

$$\frac{d}{dD}\{a\log D + b\log(1 - D)\} = \frac aD - \frac{b}{1 - D} = 0 \iff D^* = \frac{a}{a + b}$$

$m = \tfrac12(p_{\mathrm{data}} + p_g)$ とおくと $D^* = \dfrac{p_{\mathrm{data}}}{2m}$、$1 - D^* = \dfrac{p_g}{2m}$ なので

$$C(G) = E_{p_{\mathrm{data}}}\left[\log\frac{p_{\mathrm{data}}}{m}\right] + E_{p_g}\left[\log\frac{p_g}{m}\right] - 2\log 2 = D_{\mathrm{KL}}(p_{\mathrm{data}} \parallel m) + D_{\mathrm{KL}}(p_g \parallel m) - \log 4.$$

JS ダイバージェンスの定義 $D_{\mathrm{JS}} = \tfrac12D_{\mathrm{KL}}(p_{\mathrm{data}} \parallel m) + \tfrac12D_{\mathrm{KL}}(p_g \parallel m)$ より $C(G) = -\log 4 + 2D_{\mathrm{JS}}$ です。

### 各選択肢の検討

- **A** 符号が逆です。$D_{\mathrm{JS}} \ge 0$ なので、$C(G)$ は $p_g = p_{\mathrm{data}}$ で最小値 $-\log 4$ をとり、生成器はこれを最小化します。
- **B** $D$ は本物である確率なので、分子は $p_{\mathrm{data}}$ です。$p_g$ を分子にすると、偽物である確率になります。
- **C** 平均の分布 $m$ と比べる形になるので、現れるのは KL ダイバージェンスではなく JS ダイバージェンスです。
- **D（正解）** 識別器は「本物の密度の割合」を出力するのが最適です。

### ポイント

- $C(G) = -\log 4 + 2D_{\mathrm{JS}}$ と $0 \le D_{\mathrm{JS}} \le \log 2$ から、$-\log 4 \le C(G) \le 0$ です。
- 学習初期は $p_g$ と $p_{\mathrm{data}}$ の台がほとんど重ならず、$D_{\mathrm{JS}}$ が $\log 2$ 付近で飽和して生成器の勾配が小さくなります。実装では $\log(1 - D(G(\boldsymbol z)))$ の最小化の代わりに $-\log D(G(\boldsymbol z))$ を最小化する（non-saturating loss）のが一般的です。
