適合率の分母は「陽性と予測した件数」$TP + FP$、再現率の分母は「実際に陽性である件数」$TP + FN$ です。それぞれ `np.sum(y_pred == 1)` と `np.sum(y_true == 1)` で求められます。このデータでは $TP = 3$、陽性と予測した件数 $5$、実際の陽性 $4$ なので、適合率 $0.6$、再現率 $0.75$、F 値 $2/3 \approx 0.667$ です。

### 各選択肢の検討

- **A** 分母が逆で、適合率と再現率を取り違えています。このコードでは適合率が $0.75$、再現率が $0.6$ と入れ替わって出力されます（F 値は 2 つの対称な式なので、たまたま同じ値になります）。
- **B** 再現率の分母を全件数にしています。$3/10 = 0.3$ となり、再現率ではありません。
- **C** `np.sum(y_pred == y_true)` は正しく予測できた件数（$TP + TN = 7$）で、正解率の分子です。適合率の分母ではありません。
- **D（正解）** `np.sum(y_pred == 1)` $= TP + FP = 5$、`np.sum(y_true == 1)` $= TP + FN = 4$ です。

### ポイント

- `(y_pred == 1) & (y_true == 1)` のように、比較の結果（真偽値の配列）を `&` でつなぐときは、演算子の優先順位のため各比較を括弧で囲みます。
- 陽性と予測した件数が 0 のときは適合率が $0/0$ になるので、実用のコードではゼロ除算の扱いを決めておきます。
- F 値は $2TP/(2TP + FP + FN)$ と書けるので、$TP$・$FP$・$FN$ を数えれば適合率と再現率を経由せずに計算できます。
