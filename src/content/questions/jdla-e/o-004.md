  ```python
  import torch
  import torch.nn as nn

  conv = nn.Conv2d(in_channels=3, out_channels=16,

  x = torch.randn(8, 3, 32, 32)   # (N, C, H, W)

  n_params = sum(p.numel() for p in conv.parameters())
  ```

出力サイズは $\left\lfloor \dfrac{H + 2P - K}{S} \right\rfloor + 1$ で求めます。$\lfloor (32 + 4 - 5)/2 \rfloor + 1 = 15 + 1 = 16$ なので出力は `(8, 16, 16, 16)` です。パラメータ数は「カーネルの大きさ × 入力チャネル数 × 出力チャネル数 ＋ バイアス」で $5\times5\times3\times16 + 16 = 1216$ です。

### 計算

- **出力サイズ** $H_{\text{out}} = \left\lfloor \dfrac{32 + 2\cdot 2 - 5}{2} \right\rfloor + 1 = \lfloor 15.5 \rfloor + 1 = 16$。幅も同様に $16$ です。チャネル数は `out_channels` の $16$、バッチサイズ $8$ はそのままです。
- **重み** 1 枚のフィルタは全入力チャネルにまたがるので形状は $(3, 5, 5)$、これが $16$ 枚で $16 \times 3 \times 5 \times 5 = 1200$。
- **バイアス** 出力チャネルごとに 1 個で $16$。合計 $1216$ です。

### 各選択肢の検討

- **A** パディングを無視して $\lfloor (32 - 5)/2 \rfloor + 1 = 14$ と計算しています。
- **B** 入力チャネル数 $3$ を掛け忘れて $5\times5\times16 + 16 = 416$ としています。
- **C** ストライドを無視し（`padding=2` は $5\times5$ カーネルでサイズを保つ "same" 相当）、さらにバイアスを数えていません。
- **D（正解）** 出力サイズ・パラメータ数ともに正しい組み合わせです。

### ポイント

- 出力サイズの公式に dilation $d$ がある場合は $K$ を実効カーネルサイズ $d(K-1)+1$ に置き換えます。
- 畳み込み層のパラメータ数は入力画像の縦横サイズに依存しません。全結合層との大きな違いです。
- depth-wise 畳み込み（`groups=in_channels`）では、重みが $K\times K\times C$ になり、パラメータ数が大きく減ります。
