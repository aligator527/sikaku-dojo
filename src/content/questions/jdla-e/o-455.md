エンコーダの各層は、トークン間で情報をやり取りする Multi-Head Self-Attention と、各トークンの表現を個別に変換する Position-wise Feed-Forward Network の 2 つのサブレイヤーからなります。各サブレイヤーの出力は $\mathrm{LayerNorm}(\boldsymbol x + \mathrm{Sublayer}(\boldsymbol x))$ の形で、残差接続と Layer Normalization を通ります。

### 各選択肢の検討

- **A** デコーダの層の構成です。デコーダは未来の位置を隠す Masked Self-Attention、エンコーダの出力を参照する Source-Target Attention、Feed-Forward Network の 3 つのサブレイヤーを持ちます。
- **B** Feed-Forward Network は各位置のベクトル（$d_{\text{model}}$ 次元）に同じ重みで別々に適用されます（$1\times1$ 畳み込みと同じ）。全トークンを連結すると、系列長によってパラメータの形が変わってしまいます。
- **C（正解）** エンコーダ層の 2 つのサブレイヤーと、残差接続・正規化の配置を正しく述べています。
- **D** 正規化には Layer Normalization を使います。系列長が可変でパディングを含む入力では、ミニバッチ方向の統計量を使う Batch Normalization は扱いにくいためです。

### ポイント

- Position-wise Feed-Forward Network は $\mathrm{FFN}(\boldsymbol x) = \max(0,\ \boldsymbol x W_1 + \boldsymbol b_1)W_2 + \boldsymbol b_2$ で、原論文では $d_{\text{model}} = 512$、中間層の次元 $d_{\text{ff}} = 2048$ です。
- 原論文のエンコーダはこの層を 6 層重ねています。トークン間の情報の混合は Self-Attention だけが担い、Feed-Forward Network はトークンごとの非線形変換を担うという役割分担になっています。
