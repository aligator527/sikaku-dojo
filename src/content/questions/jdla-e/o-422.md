重み $w$ は全時刻で共有されているので、$\partial L/\partial w$ は各時刻で $w$ が使われた箇所からの寄与の和になります。時刻 $t$ の隠れ状態に関する勾配を $\delta_t = \partial L/\partial h_t$ とすると $\dfrac{\partial L}{\partial w} = \sum_t \delta_t h_{t-1}$ で、$2\times2.5 + 1\times1 + 0.5\times0 = 6$ です。

### 計算

**順伝播**

$$h_1 = 0.5\times0 + 1 = 1,\quad h_2 = 0.5\times1 + 2 = 2.5,\quad h_3 = 0.5\times2.5 + 3 = 4.25$$

**逆伝播（時刻を遡る）**

$$\delta_3 = h_3 - 2.25 = 2,\qquad \delta_2 = \delta_3\, w = 1,\qquad \delta_1 = \delta_2\, w = 0.5$$

**重みの勾配** 時刻 $t$ では $w$ に $h_{t-1}$ が掛かっているので

$$\frac{\partial L}{\partial w} = \delta_3 h_2 + \delta_2 h_1 + \delta_1 h_0 = 2\times2.5 + 1\times1 + 0.5\times0 = 6$$

同じ結果は $h_3 = w^2 x_1 + w x_2 + x_3$ を直接微分して $\dfrac{\partial h_3}{\partial w} = 2w x_1 + x_2 = 3$、$\dfrac{\partial L}{\partial w} = (h_3 - 2.25)\times 3 = 6$ としても得られます。

### ポイント

- 最後の時刻の寄与 $\delta_3 h_2 = 5$ だけを答えるのは、時間を遡る経路を無視した誤りです（1 ステップで打ち切った truncated BPTT に相当します）。
- 時刻を 1 つ遡るごとに $\delta$ に $w$（一般には $W_h^{\mathsf T}$ と活性化関数の微分）が掛かります。$|w| < 1$ なら遠い過去ほど寄与が指数的に小さくなり（勾配消失）、$|w| > 1$ なら大きくなります（勾配爆発）。
- 共有パラメータの勾配は「各時刻を別々のパラメータとみなして求めた勾配の和」と覚えておくと、BPTT の計算を整理しやすくなります。
