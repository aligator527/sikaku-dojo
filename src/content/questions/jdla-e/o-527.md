Reparameterization Trick では、乱数 $\boldsymbol\epsilon \sim \mathcal N(\boldsymbol 0, I)$ を外から与えて $\boldsymbol z = \boldsymbol\mu + \boldsymbol\sigma \odot \boldsymbol\epsilon$ とします。$\boldsymbol\sigma = \exp\left(\tfrac12 \log\boldsymbol\sigma^2\right)$ なので（あ）は `mu + torch.exp(0.5 * logvar) * eps` です。2 つのガウス分布の KL ダイバージェンスは閉じた式で書け、（い）は $-\tfrac12\sum(1 + \log\sigma^2 - \mu^2 - \sigma^2)$ です。

### 計算

1 次元あたりの KL ダイバージェンスは

$$D_{\mathrm{KL}}\left(\mathcal N(\mu, \sigma^2) \parallel \mathcal N(0, 1)\right) = \frac12\left(\mu^2 + \sigma^2 - \log\sigma^2 - 1\right) = -\frac12\left(1 + \log\sigma^2 - \mu^2 - \sigma^2\right)$$

で、これを全次元・全サンプルで足します。たとえば $\boldsymbol\mu = (1, 0)$、$\log\boldsymbol\sigma^2 = (0, -1)$ なら、$\tfrac12(1 + 1 - 0 - 1) + \tfrac12(0 + e^{-1} + 1 - 1) \approx 0.5 + 0.184 = 0.684$ です。

### 各選択肢の検討

- **A** `torch.exp(logvar)` は分散 $\sigma^2$ で、標準偏差ではありません。たとえば $\sigma^2 = 4$ のとき、標準偏差 2 ではなく 4 でサンプリングしてしまいます。
- **B（正解）** サンプリングと KL ダイバージェンスの両方が正しい組み合わせです。
- **C** 符号が逆で、KL ダイバージェンスが負の値になります。KL ダイバージェンスは常に 0 以上で、これを損失に加えて最小化すると、逆に事前分布から遠ざける方向に学習してしまいます。
- **D** `detach()` で計算グラフから切り離しているため、デコーダ側の再構成誤差の勾配が `mu` と `logvar` に伝わりません。サンプリングを微分可能にするという Reparameterization Trick の目的が失われます。

### ポイント

- VAE は、対数尤度の下界である変分下限（ELBO）$\mathbb E_{q(\boldsymbol z \mid \boldsymbol x)}[\log p(\boldsymbol x \mid \boldsymbol z)] - D_{\mathrm{KL}}\left(q(\boldsymbol z \mid \boldsymbol x) \parallel p(\boldsymbol z)\right)$ を最大化します。損失は「再構成誤差 ＋ KL 項」です。
- $\boldsymbol z$ を $q$ から直接サンプリングすると、サンプリングの操作を $\boldsymbol\mu, \boldsymbol\sigma$ で微分できません。乱数を $\boldsymbol\epsilon$ に押し出すことで、$\boldsymbol z$ が $\boldsymbol\mu, \boldsymbol\sigma$ の微分可能な関数になります。
- $\log\boldsymbol\sigma^2$ を出力させるのは、ネットワークの出力が負の値でも分散が必ず正になり、数値的にも安定するためです。
