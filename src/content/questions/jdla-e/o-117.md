  次の関数は、行列 `A`（形状 `(m, n)`）のムーア・ペンローズの擬似逆行列 $A^{+}$ を特異値分解で計算する。`A` はランク落ちしていることがあり、ほぼ 0 の特異値は逆数をとらずに 0 とする。空欄（あ）に入るものとして正しいものを選べ。

  ```python
  import numpy as np

  def pinv_svd(A, rcond=1e-15):
      U, s, Vt = np.linalg.svd(A, full_matrices=False)
      s_inv = np.where(s > rcond * s.max(), 1.0 / s, 0.0)
      return （あ）

  A = np.random.randn(5, 2) @ np.random.randn(2, 3)   # 形状 (5, 3)、ランク 2
  w = pinv_svd(A) @ np.random.randn(5)                 # 最小二乗解
  ```

$A = U\Sigma V^{\mathsf T}$ のとき、擬似逆行列は $A^{+} = V\Sigma^{+}U^{\mathsf T}$ です。$\Sigma^{+}$ は 0 でない特異値だけを逆数にした対角行列です。`Vt` は $V^{\mathsf T}$ なので $V$ は `Vt.T` で、（あ）は `Vt.T @ np.diag(s_inv) @ U.T` です。形状は $(3, 3)(3, 3)(3, 5) = (3, 5)$ で、$A^{\mathsf T}$ と同じ $(n, m)$ になります。

### 計算

$A^{+} = V\Sigma^{+}U^{\mathsf T}$ を $A = U\Sigma V^{\mathsf T}$ に掛けると

$$A^{+}A = V\Sigma^{+}U^{\mathsf T}U\Sigma V^{\mathsf T} = V(\Sigma^{+}\Sigma)V^{\mathsf T}$$

となり、ランク $r$ の部分では単位行列として働きます（$A$ が列フルランクなら $A^{+}A = I$）。$\boldsymbol w = A^{+}\boldsymbol y$ は $\|A\boldsymbol w - \boldsymbol y\|_2$ を最小にする解のうち、$\|\boldsymbol w\|_2$ が最小のものです。

### 各選択肢の検討

- **A** 特異値の逆数をとっていません。$V\Sigma U^{\mathsf T}$ は $A^{\mathsf T}$ そのものです。
- **B** $U\Sigma^{+}V^{\mathsf T}$ で、形状が $(5, 3)$ になり $A^{\mathsf T}$ の形 $(3, 5)$ と合いません。順序と転置を逆にしています。
- **C** `Vt`（$V^{\mathsf T}$）を $V$ と取り違えています。形状は $(3, 5)$ になりエラーは出ませんが、値は誤りです。
- **D（正解）** $V\Sigma^{+}U^{\mathsf T}$ です。`np.linalg.pinv(A)` と一致します。

### ポイント

- $A$ が列フルランクなら $A^{+} = (A^{\mathsf T}A)^{-1}A^{\mathsf T}$ で、線形回帰の正規方程式の解 $\hat{\boldsymbol w} = (X^{\mathsf T}X)^{-1}X^{\mathsf T}\boldsymbol y$ と一致します。ランク落ち（多重共線性）していても SVD なら解を計算できます。
- 小さい特異値の逆数は非常に大きくなるため、閾値以下を 0 にしないと数値的に不安定になります。この例では 3 番目の特異値が丸め誤差程度（約 $10^{-16}$）になり、そのまま逆数をとると $10^{15}$ 程度の巨大な成分が現れます。
- 実装では `np.linalg.pinv`（内部は SVD）や `np.linalg.lstsq` を使います。
- シラバス 2026（E2026#2〜）では、線形代数は「オプション（出題対象外）」の項目で、直接は出題されない前提知識の扱いです。
