混合分布は「確率 $\pi_k$ で成分 $k$ を選び、その成分の正規分布から $x$ を生成する」と考えます。$V[X] = E[X^2] - (E[X])^2$ を、各成分の $E[X^2 \mid k] = \sigma_k^2 + \mu_k^2$ の混合として計算すると $V[X] = 12.2 - 2.8^2 = 4.36$ です。

### 計算

$$E[X] = \sum_k\pi_k\mu_k = 0.3 \times 0 + 0.7 \times 4 = 2.8$$

$$E[X^2] = \sum_k\pi_k(\sigma_k^2 + \mu_k^2) = 0.3 \times (1 + 0) + 0.7 \times (1 + 16) = 0.3 + 11.9 = 12.2$$

$$V[X] = 12.2 - 2.8^2 = 12.2 - 7.84 = 4.36$$

全分散の公式（成分の番号を $Z$ とする）でも同じ値になります。

$$V[X] = \underbrace{E[V[X \mid Z]]}_{=1} + \underbrace{V[E[X \mid Z]]}_{=0.3 \times 0.7 \times 4^2 = 3.36} = 4.36$$

### ポイント

- 各成分の分散の加重平均 $0.3 \times 1 + 0.7 \times 1 = 1$ だけを答えるのは誤りです。成分の平均どうしが離れていることによる散らばり（成分間の分散）が加わります。
- 混合分布は、独立な確率変数の和 $0.3X_1 + 0.7X_2$ とは別物です。和の分散 $0.3^2 + 0.7^2 = 0.58$ とするのも典型的な誤りです。
- 混合ガウス分布のパラメータは、潜在変数 $Z$ を補って EM アルゴリズムで推定するのが一般的です。
- シラバス 2026（E2026#2〜）では、確率・統計のうち「一般的な確率分布」（混合ガウス分布など）は「オプション（出題対象外）」の項目で、直接は出題されない前提知識の扱いです。
