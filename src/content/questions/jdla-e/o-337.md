混ぜた目標は $\tilde{\boldsymbol t} = 0.7\,(1, 0, 0) + 0.3\,(0, 0, 1) = (0.7,\ 0,\ 0.3)$ です。交差エントロピー誤差は $L = -(0.7\log 0.5 + 0.3\log 0.3) = 0.7 \times 0.693 + 0.3 \times 1.204 \approx 0.85$ です。

### 計算

$$L = -\left(0.7 \times \log 0.5 + 0 \times \log 0.2 + 0.3 \times \log 0.3\right) = 0.4851 + 0.3612 = 0.8463$$

小数第 3 位を四捨五入して $0.85$ です。

### ポイント

- 交差エントロピー誤差は目標について線形なので、$L = \lambda\,\mathrm{CE}(\boldsymbol y, \boldsymbol t_i) + (1-\lambda)\,\mathrm{CE}(\boldsymbol y, \boldsymbol t_j)$ と、2 つの正解ラベルに対する損失を同じ比で混ぜたものに等しくなります。実装ではこの形で計算することが多いです。
- $\lambda$ と $1-\lambda$ を取り違えると $0.3 \times 0.693 + 0.7 \times 1.204 \approx 1.05$ になります。入力とラベルは同じ比で混ぜます。
- MixUp の混合比は、ベータ分布 $\mathrm{Beta}(\alpha, \alpha)$ からサンプリングするのが一般的です。異なるクラスの間を滑らかにつなぐ学習をさせることで、決定境界付近で過度に確信した予測を抑えます。
- 自然言語処理では単語埋め込みや文の表現のレベルで、音声ではスペクトログラムなどで MixUp が使われます。
