L1 正則化は、制約領域 $\sum_i |w_i| \le C$ がひし形（高次元では角の多い多面体）になり、損失の等高線が座標軸上の角で接しやすいので、多くの重みがちょうど 0 になります。L2 正則化の制約領域 $\sum_i w_i^2 \le C$ は円（球）で角がなく、重みは 0 に近づくもののちょうど 0 にはなりにくい、という違いがあります。

### 各選択肢の検討

- **A** L1 と L2 の性質が入れ替わっています。円には角がないので、接点が座標軸上に来るのは特別な場合だけです。
- **B** $\lambda w_i$ は L2 正則化項 $\frac{\lambda}{2}\sum_i w_i^2$ の勾配です。L1 正則化項の勾配（劣勾配）は $\lambda\,\mathrm{sign}(w_i)$ で、重みの大きさによらず一定の強さで 0 に引き寄せるので、小さな重みはちょうど 0 になります。
- **C** L2 正則化を加えた線形回帰は Ridge 回帰です。L1 正則化を加えたものが Lasso 回帰です。
- **D（正解）** L1 正則化がスパースな解を与える理由の、幾何学的な説明です。

### ポイント

- 勾配で比べると、L2 は「大きな重みほど強く縮める」、L1 は「どの重みも同じ強さで 0 に近づける」働きをします。
- L1 正則化は、不要な特徴量の重みを 0 にする特徴選択として使えます。
- L1 と L2 を組み合わせた正則化は Elastic Net と呼ばれます。
