  次の NumPy のコードは、全結合層の順伝播 $Y = XW + \boldsymbol b$ を計算している。上流から損失 $L$ の勾配 `dY`（$\partial L/\partial Y$）が渡されたとき、`dW`（$\partial L/\partial W$）、`db`（$\partial L/\partial \boldsymbol b$）、`dX`（$\partial L/\partial X$）を正しく計算するものを選べ。

  ```python
  import numpy as np

  N, D, H = 32, 100, 50
  X = np.random.randn(N, D)   # ミニバッチ入力
  W = np.random.randn(D, H)
  b = np.zeros(H)

  Y = X @ W + b               # 形状 (N, H)。b はブロードキャストされる
  dY = np.random.randn(N, H)  # 上流から渡された勾配
  ```

  - '`dW = X.T @ dY`、`db = dY.sum(axis=0)`、`dX = W.T @ dY`'

勾配は「元の変数と同じ形状になる」ことを手がかりにすると、行列積の順序と転置の位置が決まります。`dW` は $(D, H)$、`db` は $(H,)$、`dX` は $(N, D)$ でなければならず、これを満たすのは $X^{\mathsf T}\,dY$、`dY.sum(axis=0)`、$dY\,W^{\mathsf T}$ の組み合わせです。

### 各選択肢の検討

- **A** `dY.T @ X` は $(H, N)(N, D) = (H, D)$ となり、`W` の形状 $(D, H)$ と一致しません。正しい勾配の転置になっています。
- **B（正解）** `X.T @ dY` は $(D, N)(N, H) = (D, H)$。バイアスはミニバッチの全サンプルにブロードキャストされて加算されているので、勾配はサンプル方向（`axis=0`）の和で $(H,)$ になります。`dY @ W.T` は $(N, H)(H, D) = (N, D)$ です。
- **C** `dY.sum(axis=1)` は形状 $(N,)$ になり、ユニットごとではなくサンプルごとの和になってしまいます。
- **D** `W.T @ dY` は $(H, D)$ と $(N, H)$ の積で、$D \ne N$ のため形状が合わず計算できません。

### ポイント

- $Y = XW + \boldsymbol b$ に対して $\dfrac{\partial L}{\partial W} = X^{\mathsf T}\dfrac{\partial L}{\partial Y}$、$\dfrac{\partial L}{\partial X} = \dfrac{\partial L}{\partial Y}W^{\mathsf T}$、$\dfrac{\partial L}{\partial \boldsymbol b} = \sum_{n}\dfrac{\partial L}{\partial Y_{n,:}}$ です。
- 順伝播でブロードキャストされた変数の勾配は、ブロードキャストされた軸について和をとります。平均（`mean`）にするのは誤りです（損失側ですでに平均をとっているなら、その係数は `dY` に含まれています）。
- 迷ったら形状を書き出して確認するのが、試験でも実装でも最も確実です。
