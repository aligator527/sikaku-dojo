正規分布の対数尤度を $\mu$ と $\sigma^2$ で偏微分して 0 とおくと、$\hat\mu = \bar x$、$\hat\sigma^2 = \tfrac1n\sum_i(x_i - \bar x)^2$ が得られます。$\bar x = 5$、偏差平方和は $32$ なので $\hat\sigma^2 = 32/8 = 4$ です。この推定量の期待値は $\tfrac{n-1}{n}\sigma^2$ で、$\sigma^2$ より小さくなります。

### 計算

$$\ell(\mu, \sigma^2) = -\frac n2\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^{n}(x_i - \mu)^2$$

$$\frac{\partial\ell}{\partial\mu} = 0 \Rightarrow \hat\mu = \bar x = \frac{40}{8} = 5,\qquad \frac{\partial\ell}{\partial\sigma^2} = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4}\sum_i(x_i - \mu)^2 = 0 \Rightarrow \hat\sigma^2 = \frac1n\sum_i(x_i - \bar x)^2$$

偏差は $-3, -1, -1, -1, 0, 0, 2, 4$、偏差平方和は $9 + 1 + 1 + 1 + 0 + 0 + 4 + 16 = 32$ なので $\hat\sigma^2 = 32/8 = 4$ です。期待値は $E[\hat\sigma^2] = \tfrac{n-1}{n}\sigma^2 = \tfrac78\sigma^2$ です。

### 各選択肢の検討

- **A** $32/7$ は不偏分散で、最尤推定値ではありません。
- **B** 不偏推定量は $n - 1$ で割った不偏分散 $s^2 = 32/7$ です。最尤推定量は不偏ではありません。
- **C（正解）** 最尤推定量は $n$ で割るため、平均的に $\sigma^2$ を過小に推定します。
- **D** $2$ は標準偏差の最尤推定値 $\hat\sigma = \sqrt4$ です。分散ではありません。

### ポイント

- 偏りの原因は、真の平均 $\mu$ の代わりにデータから求めた $\bar x$ を使うことです。$\bar x$ はデータに最も近い点なので、偏差平方和が小さめに出ます。
- $n$ が大きければ $\tfrac{n-1}{n} \to 1$ となり、偏りは無視できます（最尤推定量は一致推定量です）。
- 最尤推定量は変数変換に対して不変で、$\sigma$ の最尤推定値は $\sqrt{\hat\sigma^2} = 2$ です。
- NumPy の `np.var` は既定で $n$ で割り（`ddof=0`、最尤推定値）、`np.var(x, ddof=1)` で不偏分散になります。PyTorch の `torch.var` は既定で不偏分散です。
