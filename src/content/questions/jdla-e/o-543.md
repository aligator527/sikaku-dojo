非対称（アフィン）量子化では $q = \mathrm{clip}\left(\mathrm{round}(x / s) + z,\ 0,\ 255\right)$、逆量子化では $\hat x = (q - z)\,s$ とします。ゼロ点 $z$ は「実数の 0 に対応する整数」なので、量子化では足し、逆量子化では引いてから $s$ を掛けます。

### 計算

例として $x_{\min} = -0.51$、$x_{\max} = 2.04$ とすると、$s = 2.55 / 255 = 0.01$、$z = \mathrm{round}(0.51 / 0.01) = 51$ です。

| $x$ | $-0.51$ | $0$ | $1.234$ | $3.0$ |
| --- | --- | --- | --- | --- |
| $q$ | $0$ | $51$ | $\mathrm{round}(123.4) + 51 = 174$ | $\mathrm{clip}(351) = 255$ |
| $\hat x = (q - 51) \times 0.01$ | $-0.51$ | $0$ | $1.23$ | $2.04$ |

範囲内の値は誤差 $s/2 = 0.005$ 以内で復元され、範囲外の $3.0$ は $x_{\max} = 2.04$ に切り詰められます。

### 各選択肢の検討

- **A（正解）** 量子化と逆量子化が互いに逆の操作になっています。
- **B** 逆量子化で、整数の世界の値であるゼロ点 $z$ を、$s$ を掛けた後の実数から引いています。$q = 174$ は $1.74 - 51 = -49.26$ になってしまいます。
- **C** ゼロ点の符号が逆です。表せる範囲が $[z\,s,\ (255 + z)\,s] = [0.51,\ 3.06]$ にずれ、$0.51$ 未満の値（負の値や 0 を含む）がすべて $0.51$ になります。
- **D** 量子化で $s$ を掛けており、逆数の関係が逆です。$x \times 0.01$ はほぼ 0 になり、ほとんどの値が同じ $q = 51$ に潰れてしまいます。

### ポイント

- `q.astype(np.float32)` で実数に変換してから引くのは、`uint8` の配列から整数を引くと、負になるはずの値が 256 を法として巻き戻る（たとえば $0 - 51$ が $205$ になる）のを防ぐためです。
- ゼロ点を使うことで実数の 0 がちょうど整数で表せ、ゼロパディングや ReLU の出力の 0 を誤差なく扱えます。値の分布が 0 を中心に対称な重みでは、ゼロ点を 0 に固定する対称量子化（$s = \max|x| / 127$）もよく使われます。
- $x_{\min}, x_{\max}$ を広くとると切り詰めは減りますが、$s$ が大きくなって丸め誤差が増えます。範囲を決めることを校正（キャリブレーション）と呼びます。
