  表が出る確率 $\theta$ が未知のコインを 10 回投げたところ、表が 7 回出た。$\theta$ の事前分布としてベータ分布

  $$p(\theta) = \frac{\theta^{a-1}(1 - \theta)^{b-1}}{B(a, b)},\qquad a = 3,\ b = 3$$

  を用いるとき、$\theta$ の MAP 推定値として正しいものを選べ。
choices:
  - '$\dfrac{9}{14}$'
  - '$\dfrac{5}{8}$'
  - '$\dfrac{7}{10}$'
  - '$\dfrac{5}{7}$'
answer: 1

事後分布は「尤度 × 事前分布」に比例し、$\theta^{7}(1-\theta)^{3} \times \theta^{2}(1-\theta)^{2} = \theta^{9}(1-\theta)^{5}$、つまりベータ分布 $\mathrm{Beta}(10, 6)$ になります。MAP 推定値はこの密度を最大にする $\theta$（最頻値）で、$\dfrac{10 - 1}{10 + 6 - 2} = \dfrac{9}{14} \approx 0.643$ です。

### 計算

対数事後分布（定数を除く）は

$$\log p(\theta \mid D) = 9\log\theta + 5\log(1 - \theta) + \text{const}.$$

$$\frac{d}{d\theta}\log p(\theta \mid D) = \frac{9}{\theta} - \frac{5}{1 - \theta} = 0 \iff \hat\theta_{\mathrm{MAP}} = \frac{9}{14}$$

一般に、$n$ 回中 $k$ 回成功で事前分布が $\mathrm{Beta}(a, b)$ のとき、$\hat\theta_{\mathrm{MAP}} = \dfrac{k + a - 1}{n + a + b - 2}$ です。

### 各選択肢の検討

- **A（正解）** 事後分布 $\mathrm{Beta}(10, 6)$ の最頻値です。
- **B** 事後分布の平均 $\dfrac{k + a}{n + a + b} = \dfrac{10}{16}$ です。これは二乗誤差の期待値を最小にするベイズ推定値で、MAP 推定値（最頻値）とは異なります。
- **C** 事前分布を使わない最尤推定値 $k/n$ です。
- **D** 分子の $-1$ を忘れて $\dfrac{k + a}{n + a + b - 2} = \dfrac{10}{14}$ としています。

### ポイント

- ベータ分布はベルヌーイ分布（二項分布）の共役事前分布で、事後分布もベータ分布になります。$a - 1$ 回の表と $b - 1$ 回の裏を「仮想的に観測済み」とみなすと、MAP 推定値の式を覚えやすくなります。
- 事前分布 $\mathrm{Beta}(3, 3)$ は $\theta = 0.5$ の付近を重視するので、推定値は最尤推定値 $0.7$ から $0.5$ の側に引き寄せられます（$0.7 > 0.643 > 0.5$）。データ数が増えると、この影響は小さくなります。
- $a = b = 1$（一様分布）なら MAP 推定値は最尤推定値と一致します。
