Nesterov の方法では、現在の位置ではなく、慣性だけで進んだ先の「先読み位置」$w_{t-1} + \alpha v_{t-1}$ で勾配を評価します。先読み位置は $1.0 + 0.9 \times (-0.2) = 0.82$、そこでの勾配は $2 \times 0.82 = 1.64$ なので、$v_t = -0.18 - 0.164 = -0.344$、$w_t = 1.0 - 0.344 = 0.656$ です。

### 計算

$$\tilde w = w_{t-1} + \alpha v_{t-1} = 1.0 - 0.18 = 0.82,\qquad \nabla L(\tilde w) = 2 \times 0.82 = 1.64$$

$$v_t = 0.9 \times (-0.2) - 0.1 \times 1.64 = -0.344,\qquad w_t = 1.0 - 0.344 = 0.656$$

### ポイント

- 通常のモメンタム法なら勾配を現在の位置で評価するので $\nabla L(1.0) = 2$、$v_t = -0.18 - 0.2 = -0.38$、$w_t = 0.62$ になります。
- 最小点に近づくと先読み位置での勾配が小さくなるため、Nesterov の方法では「行き過ぎる前にブレーキがかかる」形になり、モメンタム法より振動しにくくなります。
- 先読み位置で勾配を評価したのに慣性項 $\alpha v_{t-1}$ を加え忘れると、$w_t = 1.0 - 0.164 = 0.836$ という誤った値になります。
