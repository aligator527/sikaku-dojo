2 つの区間の共通部分は「右端の小さいほう − 左端の大きいほう」で、重ならないときはこの値が負になるので `max(0, ...)` で 0 にします。IoU の分母は和集合の面積で、2 つの面積の和から二重に数えた共通部分を 1 回引いた `area_a + area_b - inter` です。

### 各選択肢の検討

- **A** 分母が `area_a + area_b` で、共通部分を二重に数えています。完全に一致する 2 つのボックスでも IoU が $0.5$ にしかならず、本来の $1$ になりません。
- **B** 0 への切り上げがありません。たとえば `a = (0, 0, 2, 2)`、`b = (3, 3, 5, 5)` のように斜めに離れたボックスでは、幅と高さがともに $-1$ になり、積が $+1$ になって IoU が $1/(4 + 4 - 1) \approx 0.14$ と誤って正の値になります。
- **C（正解）** たとえば `a = (10, 10, 50, 50)`、`b = (30, 20, 70, 60)` では共通部分が $20 \times 30 = 600$、和集合が $1600 + 1600 - 600 = 2600$ で、IoU は約 $0.23$ です。離れたボックスでは `inter` が 0 になり、IoU も 0 です。
- **D** 「左端の小さいほうから右端の大きいほうまで」は、2 つのボックスを囲む最小の矩形（GIoU で使う外接矩形）の幅です。共通部分ではないため、上の例では $60 \times 50 = 3000$ となり、IoU が $3000/(3200 - 3000) = 15$ と 1 を超えてしまいます。

### ポイント

- 共通部分：$\max\bigl(0, \min(x_2^a, x_2^b) - \max(x_1^a, x_1^b)\bigr) \times \max\bigl(0, \min(y_2^a, y_2^b) - \max(y_1^a, y_1^b)\bigr)$ と覚えます。
- 和集合：$|A \cup B| = |A| + |B| - |A \cap B|$（包除原理）。
- NumPy で多数のボックスとの IoU をまとめて計算するときは、`np.maximum`・`np.minimum` と `np.clip(..., 0, None)` を使って同じ式をベクトル化します。
