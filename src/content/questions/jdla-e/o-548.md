第 1 層のフィルタを 32 枚取り除くと、第 1 層の出力は 32 チャネルになり、それを受け取る第 2 層の入力チャネルも 64 から 32 に減ります。第 1 層は $3 \times 3 \times 3 \times 32 + 32 = 896$、第 2 層は $3 \times 3 \times 32 \times 128 + 128 = 36{,}992$ で、合計 $37{,}888$ です。

### 計算

| | プルーニング前 | プルーニング後 |
| --- | --- | --- |
| 第 1 層 | $3 \times 3 \times 3 \times 64 + 64 = 1{,}792$ | $3 \times 3 \times 3 \times 32 + 32 = 896$ |
| 第 2 層 | $3 \times 3 \times 64 \times 128 + 128 = 73{,}856$ | $3 \times 3 \times 32 \times 128 + 128 = 36{,}992$ |
| 合計 | $75{,}648$ | $37{,}888$ |

第 1 層のフィルタを半分にしただけで、全体のパラメータ数もほぼ半分になります。

### ポイント

- 第 2 層の入力チャネルを減らし忘れると $896 + 73{,}856 = 74{,}752$ となり、削減はわずか約 1% にとどまります。実際には第 2 層の重みの形が第 1 層の出力と合わず、ネットワークは動きません。構造化プルーニングでは、取り除いたフィルタに対応する**次の層の入力チャネル**の重みも一緒に取り除きます。
- 第 1 層の直後に Batch Normalization がある場合は、そのチャネルの $\gamma$・$\beta$ と移動平均も取り除きます。
- 計算量（積和演算の回数）も、第 2 層では入力チャネルに比例して半分になります。層の形が小さくなるので、特別なハードウェアがなくても高速化できるのが構造化プルーニングの利点です。
