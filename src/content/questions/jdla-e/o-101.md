  次の PyTorch のコードを実行したときの `c.shape` として正しいものを選べ。

  ```python
  import torch

  a = torch.randn(8, 1, 3, 4)
  b = torch.randn(5, 4, 2)
  c = torch.matmul(a, b)   # a @ b と同じ
  ```
choices:
  - '`(40, 3, 2)`'
  - '`(8, 1, 3, 2)`'
  - '`(8, 5, 3, 2)`'
  - 'バッチ次元の大きさ（1 と 5）が一致しないため、エラーになる'

`torch.matmul` は 3 次元以上のテンソルに対して、**最後の 2 軸を行列とみなして行列積**をとり、それより前の軸（バッチ次元）はブロードキャストの規則でそろえます。行列部分は $(3, 4)(4, 2) \to (3, 2)$、バッチ部分は `(8, 1)` と `(5,)` をブロードキャストして `(8, 5)` になるので、結果は `(8, 5, 3, 2)` です。

### 計算

1. **行列部分** `a` の最後の 2 軸は $(3, 4)$、`b` の最後の 2 軸は $(4, 2)$ です。内側の次元 $4$ が一致するので、積は $(3, 2)$ です。
2. **バッチ部分** `a` は `(8, 1)`、`b` は `(5,)` です。次元数をそろえるため `b` の左に 1 を補って `(1, 5)` とし、各軸で大きさ 1 の側を相手に合わせて引き伸ばすと `(8, 5)` になります。
3. 合わせて `(8, 5, 3, 2)` です。$8 \times 5 = 40$ 通りの組み合わせそれぞれで、$(3, 4)$ と $(4, 2)$ の行列積を計算しています。

### 各選択肢の検討

- **A** 40 個の行列が並ぶ点は正しいものの、`matmul` がバッチ次元を 1 つに平坦化することはありません。`c.reshape(40, 3, 2)` と明示したときの形状です。
- **B** `b` のバッチ次元 5 を無視しています。大きさ 1 の軸は、相手の大きさ（5）に引き伸ばされます。
- **C（正解）** 上の計算どおりです。
- **D** ブロードキャストでは、大きさが等しいか、どちらかが 1 であれば軸をそろえられます。1 と 5 は一致しなくてもエラーになりません。

### ポイント

- ブロードキャストは「右端の軸から順に比べ、大きさが等しいか一方が 1 なら可。足りない軸は左に 1 を補う」と覚えます。
- `a * b` はアダマール積（要素ごとの積）で、このコードでは最後の軸が 4 と 2 で一致しないためエラーになります。`*` と `@` の違いは頻出です。
- `torch.mm`（2 次元同士）や `torch.bmm`（3 次元のバッチ同士）はブロードキャストしません。Attention のスコア `q @ k.transpose(-2, -1)` も、この「最後の 2 軸で行列積」の規則で計算されています。
- シラバス 2026（E2026#2〜）では、線形代数は「オプション（出題対象外）」の項目で、直接は出題されない前提知識の扱いです。ただしテンソルの形状の扱いは、実装問題を読み解く前提として欠かせません。
