  次の PyTorch のコードを実行したときの `output.shape` と `h_n.shape` の組み合わせとして正しいものを選べ。

  ```python
  import torch
  import torch.nn as nn

  lstm = nn.LSTM(input_size=10, hidden_size=20, num_layers=2,
                 batch_first=True, bidirectional=True)
  x = torch.randn(3, 7, 10)        # (batch, 系列長, 特徴量)
  output, (h_n, c_n) = lstm(x)
  ```
choices:
  - '`output.shape` は `(3, 7, 20)`、`h_n.shape` は `(2, 3, 20)`'
  - '`output.shape` は `(3, 7, 40)`、`h_n.shape` は `(3, 4, 20)`'
  - '`output.shape` は `(3, 7, 40)`、`h_n.shape` は `(4, 3, 20)`'
  - '`output.shape` は `(3, 7, 40)`、`h_n.shape` は `(2, 3, 40)`'
answer: 3
---
`output` は最上位の層の全時刻の隠れ状態で、双方向なので順方向と逆方向の隠れ状態（各 20 次元）を連結した 40 次元になり、`(3, 7, 40)` です。`h_n` は各層・各方向の最終時刻の隠れ状態を並べたもので、形状は `(num_layers × 方向数, batch, hidden_size)` $= (4, 3, 20)$ です。`batch_first=True` は `h_n` と `c_n` には適用されません。

### 各選択肢の検討

- **A** 双方向であることを無視した形状です（単方向の 2 層 LSTM なら正しい）。
- **B** `h_n` にも `batch_first=True` が効くと考えた誤りです。`h_n` と `c_n` は常に `(層数 × 方向数, batch, hidden)` の並びです。
- **C（正解）** `output` と `h_n` の形状がともに正しい組み合わせです。
- **D** `h_n` で 2 方向の隠れ状態が連結されていると考えた誤りです。`h_n` では方向は第 0 軸に並び、`h_n.view(2, 2, 3, 20)`（層, 方向, batch, hidden）のように分けて取り出せます。

### ポイント

- 2 層目の LSTM には、1 層目の順方向と逆方向の出力を連結した 40 次元のベクトルが入力されます。
- 逆方向の RNN の最終状態は、系列の**先頭**（時刻 1）を処理し終えたときの状態です。`output[:, -1, 20:]` は逆方向については時刻 7 だけを見た状態なので、`h_n` の逆方向の成分とは一致しません。
- 系列の分類で双方向 RNN を使う場合は、最上位の層の順方向と逆方向の最終状態（`h_n[-2]` と `h_n[-1]`）を連結して使うのが一般的です。
