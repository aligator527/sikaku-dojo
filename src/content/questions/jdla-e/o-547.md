プルーニングは、推論への影響が小さい重みやチャネルを取り除いてモデルを軽量化する手法です。重みの絶対値などで重要度を測り、不規則に重みを消す非構造化プルーニングと、チャネルやフィルタのようなまとまりで消す構造化プルーニングに分けられます。

### 各選択肢の検討

- **A（誤り）** 取り除く割合が大きいほど精度は下がりやすくなります。プルーニングの後にファインチューニングで残った重みを調整し、精度を回復させるのが一般的で、「少しずつ枝刈り → 再学習」を繰り返す反復的なプルーニングもよく使われます。
- **B（正しい）** magnitude-based pruning と呼ばれる最も基本的な方法です。
- **C（正しい）** 不規則な位置に 0 があっても、密な行列として計算すれば計算量は変わりません。圧縮後の保存容量は減らせますが、高速化には疎行列の演算への対応が必要です。
- **D（誤り）** 畳み込み層の重みも、個々の重み単位でも、フィルタ（出力チャネル）単位でも取り除けます。
- **E（正しい）** 例えば出力チャネルを半分にすると、その層の出力と、次の層の入力チャネルがともに半分になり、通常の GPU や CPU の演算でもそのまま速くなります。

### ポイント

- NVIDIA の Ampere 世代以降の GPU は、連続する 4 つの重みのうち 2 つを 0 にする 2:4 の細粒度な構造化スパース性を演算器で扱え、高速化に利用できます。
- 大きなネットワークの中に、初期値に戻して単独で学習しても同程度の精度に達する小さな部分ネットワーク（当たりくじ）が含まれる、という宝くじ仮説（lottery ticket hypothesis）も知られています。
- プルーニングは量子化・蒸留と組み合わせて使うことができます。
