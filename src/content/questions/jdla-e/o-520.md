  Faster R-CNN では、アンカーボックス（中心 $(x_a, y_a)$、幅 $w_a$、高さ $h_a$）に対して、予測するボックス（中心 $(x, y)$、幅 $w$、高さ $h$）を次のオフセットで表し、ネットワークに $(t_x, t_y, t_w, t_h)$ を回帰させる。

  $$t_x = \frac{x - x_a}{w_a},\quad t_y = \frac{y - y_a}{h_a},\quad t_w = \log\frac{w}{w_a},\quad t_h = \log\frac{h}{h_a}$$

  アンカーが $(x_a, y_a, w_a, h_a) = (100,\ 80,\ 64,\ 32)$ で、ネットワークの出力が $(t_x, t_y, t_w, t_h) = (0.25,\ -0.5,\ \log 2,\ 0)$ であったとき、予測ボックスの $(x, y, w, h)$ として正しいものを選べ。ただし $\log$ は自然対数とする。
choices:

  - '$(100.25,\ 79.5,\ 64.69,\ 32)$'
  - '$(116,\ 64,\ 44.36,\ 32)$'
  - '$(132,\ 64,\ 128,\ 32)$'
answer: 1

式を逆に解くと $x = x_a + t_x w_a$、$y = y_a + t_y h_a$、$w = w_a e^{t_w}$、$h = h_a e^{t_h}$ です。値を代入すると $x = 100 + 0.25 \times 64 = 116$、$y = 80 - 0.5 \times 32 = 64$、$w = 64 \times e^{\log 2} = 128$、$h = 32 \times e^0 = 32$ になります。

### 計算

$$x = 100 + 0.25 \times 64 = 116,\qquad y = 80 + (-0.5) \times 32 = 64$$

$$w = 64 \times e^{\log 2} = 64 \times 2 = 128,\qquad h = 32 \times e^{0} = 32$$

### 各選択肢の検討

- **A（正解）** オフセットをアンカーの大きさで戻し、幅と高さには指数関数を適用しています。
- **B** オフセットをアンカーの座標や大きさにそのまま足しています（$64 + \log 2 \approx 64.69$）。中心のオフセットはアンカーの幅・高さで正規化された値です。
- **C** 幅を $w_a \times t_w = 64 \times \log 2 \approx 44.36$ としています。$t_w$ は比の対数なので、指数関数で戻す必要があります。
- **D** 中心の $x$ を、予測した幅 $w = 128$ を使って $100 + 0.25 \times 128 = 132$ としています。正規化に使うのはアンカーの幅 $w_a$ です。

### ポイント

- 中心のずれをアンカーの大きさで割ることで、大きな物体と小さな物体で回帰の目標値の大きさがそろいます。幅と高さを比の対数で表すと、拡大と縮小が対称に扱え（2 倍は $\log 2$、半分は $-\log 2$）、指数関数で戻すため予測した幅と高さは必ず正になります。
- 学習の損失には、$(t_x, t_y, t_w, t_h)$ と正解ボックスから計算した目標値との Smooth L1 損失を使います。実装では目標値を標準偏差（例：$0.1, 0.1, 0.2, 0.2$）で割って正規化することもあります。
- RPN（アンカー → 候補領域）と検出ヘッド（候補領域 → 最終的なボックス）の両方で、同じ形のオフセットを回帰します。
