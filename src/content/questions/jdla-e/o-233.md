誤差を $e_i$ とすると、RMSE $= \sqrt{\tfrac1n\sum e_i^2}$、MAE $= \tfrac1n\sum|e_i|$ です。2 乗平均の平方根は絶対値の平均以上になる（$\tfrac1n\sum|e_i|^2 \ge \left(\tfrac1n\sum|e_i|\right)^2$）ので、RMSE $\ge$ MAE が常に成り立ちます。等号は $|e_i|$ がすべて等しいときです。

### 各選択肢の検討

- **A** 逆です。$\sum(y_i - c)^2$ を最小にするのは平均値、$\sum|y_i - c|$ を最小にするのは中央値です。MAE で学習・評価すると外れ値に強い（中央値的な）予測になります。
- **B** 逆です。2 乗すると大きな誤差がより大きく効くので、RMSE のほうが外れ値の影響を強く受けます。
- **C（正解）** $\tfrac1n\sum|e_i|^2 - \left(\tfrac1n\sum|e_i|\right)^2$ は $|e_i|$ の分散で、0 以上です。RMSE と MAE の差が大きいほど、誤差の大きさにばらつきがある（一部に大きな誤差がある）ことを示します。
- **D** RMSE は MSE の平方根をとるので、目的変数と同じ単位に戻ります。単位が 2 乗になるのは MSE です。

### ポイント

- 例えば誤差が $(1, 1, 1, 1)$ なら RMSE と MAE はどちらも $1$ ですが、$(0, 0, 0, 4)$ なら MAE は $1$ のまま、RMSE は $2$ になります。
- 損失関数として使う場合、MSE は誤差が正規分布に従うと仮定した最尤推定、MAE はラプラス分布を仮定した最尤推定に対応します。
- 外れ値の影響を抑えつつ 0 付近で滑らかな損失として、Huber 損失もよく使われます。
