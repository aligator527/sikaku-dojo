  次の PyTorch のコードは、ImageNet で事前学習した ResNet-18 を、10 クラスの画像分類に転移学習する準備をしている。ResNet-18 の最終層 `model.fc` は、512 次元の特徴を 1000 クラスのスコアに変換する全結合層（バイアスあり）である。このコードを実行した後の `n_trainable` の値を求めよ。

  ```python
  import torch.nn as nn
  from torchvision import models

  model = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1)
  for p in model.parameters():
      p.requires_grad = False

  model.fc = nn.Linear(512, 10)

  n_trainable = sum(p.numel() for p in model.parameters() if p.requires_grad)
  ```

すべてのパラメータを `requires_grad = False` で固定した**後**に、最終層を新しい `nn.Linear(512, 10)` に置き換えています。新しく作った層のパラメータは既定で `requires_grad = True` なので、学習対象はこの層だけで、重み $512 \times 10 = 5120$ とバイアス $10$ の合計 $5130$ です。

### 計算

$$512 \times 10 + 10 = 5130$$

### ポイント

- 最終層を置き換えてから全体を固定すると、新しい層まで固定されて `n_trainable` は 0 になり、何も学習できません。順序に注意が必要です。
- 元の最終層のパラメータ数 $512 \times 1000 + 1000 = 513{,}000$ や、バイアスを数え忘れた $5120$ も典型的な誤りです。
- このように事前学習済みの部分を固定して特徴抽出器として使い、出力層だけを学習する方法は、データが少ないときに有効です。データが十分にあるときは、固定を外して全体を小さな学習率でファインチューニングすると、精度がさらに上がることが多くなります。
- `requires_grad = False` にしても、`model.train()` のままだと Batch Normalization の `running_mean` と `running_var`（学習可能なパラメータではなくバッファ）は更新されます。完全に固定したい場合は、該当する層を `eval()` にします。
- 事前学習のデータと目標タスクのデータの分布が異なること（ドメインシフト）が大きいほど、固定したままの特徴は適合しにくくなります。分布の違いを埋めて目標のドメインでも機能させる手法をドメイン適応と呼びます。
