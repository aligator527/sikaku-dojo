Q 学習の更新式は $Q(s, a) \leftarrow Q(s, a) + \alpha\left\{r + \gamma\max_{a'}Q(s', a') - Q(s, a)\right\}$ です。遷移先で実際に選んだ行動にかかわらず、最大の Q 値 $3.0$ を使うので、$2.0 + 0.1 \times (1 + 0.9 \times 3.0 - 2.0) = 2.17$ です。

### 計算

$$\text{TD 目標} = r + \gamma \max_{a'} Q(s', a') = 1 + 0.9 \times 3.0 = 3.7$$

$$\text{TD 誤差} = 3.7 - 2.0 = 1.7,\qquad Q(s, a) \leftarrow 2.0 + 0.1 \times 1.7 = 2.17$$

### ポイント

- 実際に選んだ行動 $a_2$ の Q 値を使うのは SARSA で、その場合は $2.0 + 0.1 \times (1 + 0.9 \times 1.0 - 2.0) = 1.99$ になります。Q 学習は行動を選ぶ方策（$\varepsilon$-greedy）と、学習する方策（greedy）が異なる **方策オフ型**、SARSA は実際に従う方策の価値を学習する **方策オン型** です。
- 学習率を掛け忘れると TD 目標そのものの $3.7$、割引率を掛け忘れると $2.0 + 0.1 \times 2.0 = 2.2$ になります。
- 状態や行動が多いと Q 値を表で持てないため、ニューラルネットワークで $Q(s, a)$ を近似したのが DQN です。
