転置畳み込みでは、入力の各要素がカーネル全体を自分の値で拡大して出力に「書き込み」、書き込み位置は入力が 1 つ進むごとにストライド分（2）ずれます。重なった位置は足し合わせます。出力の長さは $(2 - 1)\times 2 + 3 = 5$ で、$(1, 2, 3, 0, 0) + (0, 0, 2, 4, 6) = (1, 2, 5, 4, 6)$ です。

### 計算

- $x_1 = 1$ の寄与：位置 1〜3 に $1 \times (1, 2, 3) = (1, 2, 3)$
- $x_2 = 2$ の寄与：位置 3〜5 に $2 \times (1, 2, 3) = (2, 4, 6)$
- 位置 3 では両者が重なり $3 + 2 = 5$

よって $\boldsymbol y = (1,\ 2,\ 5,\ 4,\ 6)$ です。

同じことは、入力の間に $S - 1 = 1$ 個の 0 を挿入し、両端に $K - 1 = 2$ 個ずつ 0 を補った $(0, 0, 1, 0, 2, 0, 0)$ に、反転したカーネル $(3, 2, 1)$ をストライド 1 の相互相関（カーネルを反転させない演算）で適用することでも求められます。

### 各選択肢の検討

- **A** ストライド 1 で計算した結果です（長さ $(2-1)\times1 + 3 = 4$）。
- **B** 0 を挿入した系列に、カーネルを反転させずに $(1, 2, 3)$ を適用した結果です。転置畳み込みを「0 挿入＋通常の畳み込み」として計算するときは、カーネルを反転させる必要があります。
- **C** 各入力の寄与を重ねずに並べた結果です。ストライド 2 はカーネルサイズ 3 より小さいので、書き込み範囲は重なります。
- **D（正解）** 長さ・値ともに正しい結果です。

### ポイント

- 出力サイズは $(H_{\text{in}} - 1)S - 2P + K$ です。
- この例のように、カーネルサイズがストライドで割り切れないと、出力の位置によって重なる回数が異なり（位置 3 だけ 2 回）、生成画像に格子状のノイズ（チェッカーボードアーティファクト）が出る原因になります。対策として、カーネルサイズをストライドで割り切れる値にする、または最近傍補間などで拡大してから通常の畳み込みを行う方法があります。
- セマンティックセグメンテーション（FCN、U-Net）や GAN の生成器で、特徴マップを拡大する層として使われます。
