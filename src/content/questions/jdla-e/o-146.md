  確率変数 $X$ は $0$ と $1$ をそれぞれ確率 $\tfrac12$ でとる。$X = 0$ のとき $Y$ は $\{a, b, c, d\}$ の 4 つの値を等確率でとり、$X = 1$ のとき $Y$ は必ず $a$ になる。対数の底を 2 としたときの条件付きエントロピー $H(Y \mid X)$ と結合エントロピー $H(X, Y)$ の組み合わせとして正しいものを選べ（単位はビット）。
choices:
  - '$H(Y \mid X) = 2,\ H(X, Y) = 3$'
  - '$H(Y \mid X) = 1,\ H(X, Y) = 2$'
  - '$H(Y \mid X) = 1,\ H(X, Y) \approx 2.55$'
  - '$H(Y \mid X) \approx 0.45,\ H(X, Y) = 2$'
answer: 2

条件付きエントロピーは、$X$ の各値での $Y$ のエントロピーを $X$ の確率で平均したものです。$H(Y \mid X = 0) = \log_2 4 = 2$、$H(Y \mid X = 1) = 0$ なので $H(Y \mid X) = \tfrac12 \times 2 + \tfrac12 \times 0 = 1$ です。連鎖律 $H(X, Y) = H(X) + H(Y \mid X) = 1 + 1 = 2$ ビットです。

### 計算

$$H(Y \mid X) = \sum_x P(x)\,H(Y \mid X = x) = \tfrac12 \cdot 2 + \tfrac12 \cdot 0 = 1$$

同時分布は $(0, a), (0, b), (0, c), (0, d)$ がそれぞれ $\tfrac18$、$(1, a)$ が $\tfrac12$ なので、直接計算しても

$$H(X, Y) = 4 \times \tfrac18 \times 3 + \tfrac12 \times 1 = 1.5 + 0.5 = 2$$

となります。

### 各選択肢の検討

- **A** $H(Y \mid X = 0) = 2$ だけを条件付きエントロピーとしています。$X = 1$ の場合（エントロピー 0）との平均をとる必要があります。
- **B（正解）** 平均をとった条件付きエントロピーと、連鎖律による結合エントロピーです。
- **C** $H(X, Y)$ を $H(X) + H(Y)$ と計算しています。$Y$ の周辺分布は $\left(\tfrac58, \tfrac18, \tfrac18, \tfrac18\right)$ で $H(Y) \approx 1.55$ なので $1 + 1.55 = 2.55$ ですが、$X$ と $Y$ は独立ではないので誤りです。
- **D** $0.45$ は逆向きの条件付きエントロピー $H(X \mid Y) = H(X, Y) - H(Y) \approx 2 - 1.55$ です。

### ポイント

- 連鎖律：$H(X, Y) = H(X) + H(Y \mid X) = H(Y) + H(X \mid Y)$。
- 条件付けるとエントロピーは平均的に減ります（$H(Y \mid X) \le H(Y)$、ここでは $1 \le 1.55$）。その差が相互情報量 $I(X; Y) = H(Y) - H(Y \mid X) \approx 0.55$ ビットです。
- 決定木の情報利得は、分割に使う特徴 $X$ と目的変数 $Y$ の相互情報量 $H(Y) - H(Y \mid X)$ にあたります。
