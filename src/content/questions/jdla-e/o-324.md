`self.mask` は各要素が確率 $1 - p$ で `True`（残す）になります。残した要素を $1/(1-p)$ 倍すると、出力の期待値は $(1-p)\cdot\dfrac{x}{1-p} + p \cdot 0 = x$ となり、推論時に何もしなくても学習時と期待値がそろいます。順伝播が $y = x \cdot \mathrm{mask}/(1-p)$ なので、逆伝播も同じマスクと係数を掛けて $\partial L/\partial x = \mathrm{dout}\cdot\mathrm{mask}/(1-p)$ です。

### 各選択肢の検討

- **A（正解）** 順伝播と逆伝播で同じ係数 $1/(1-p)$ を掛けています。
- **B** 順伝播は正しいものの、逆伝播で $1/(1-p)$ を掛け忘れています。順伝播で掛けた定数は、連鎖律により逆伝播でもそのまま掛かります。勾配が $(1-p)$ 倍に小さくなります。
- **C** スケーリングの向きが逆です。期待値が $(1-p)^2 x$ に下がり、推論時（`x` をそのまま返す）と食い違います。
- **D** `p` を「残す確率」と取り違えています。このコードでは残す確率は $1 - p$ なので、$p = 0.2$ なら期待値は $0.8 \times x/0.2 = 4x$ になってしまいます。

### ポイント

- inverted dropout は学習時にスケーリングし、推論時には何もしません。元の論文の方式は、学習時はスケーリングせず、推論時に出力（または重み）を $1-p$ 倍します。どちらも期待値をそろえるという目的は同じです。
- 逆伝播では、順伝播で 0 にしたユニットには勾配が流れません。順伝播で作ったマスクを保存しておき、同じものを使う必要があります。
- PyTorch の `nn.Dropout(p)` や Keras の `Dropout(rate)` も inverted dropout で、引数は 0 にする確率です。
