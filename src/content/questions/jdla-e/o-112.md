元の重みは $1024 \times 512$ 個、置き換え後は $1024k + 512k = 1536k$ 個です。$1536k \le \tfrac14 \times 524288 = 131072$ を解くと $k \le 85.33\ldots$ なので、最大の整数は $k = 85$ です。

### 計算

$$1024 \times 512 = 524288,\qquad \frac{524288}{4} = 131072$$

$$k(1024 + 512) \le 131072 \iff k \le \frac{131072}{1536} = 85.33\ldots$$

確認すると $85 \times 1536 = 130560 \le 131072$、$86 \times 1536 = 132096 > 131072$ です。

### ポイント

- $m \times n$ 行列をランク $k$ の 2 つの行列に分けると、パラメータ数は $mn$ から $k(m + n)$ になります。$k < \dfrac{mn}{m + n}$（この例では約 341）でなければ、かえってパラメータが増えます。
- 入力 1 件あたりの積和演算の回数も同じく $mn$ から $k(m + n)$ に減ります。
- 切り詰め SVD はランク $k$ の近似の中で $\|W - \hat W\|_F$ を最小にします（エッカート・ヤングの定理）が、近似誤差で精度は落ちるため、通常は分解後に再学習（ファインチューニング）して精度を戻します。
- シラバス 2026（E2026#2〜）では、線形代数は「オプション（出題対象外）」の項目で、直接は出題されない前提知識の扱いです。低ランク近似の考え方は、軽量化の手法を理解する土台になります。
