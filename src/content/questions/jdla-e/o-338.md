  次のコードは、画像中のランダムな矩形領域をランダムな画素値で塗りつぶすデータ拡張（Random Erasing）を NumPy で実装したものである。消去する領域の面積を `S_e`、縦横比（高さ ÷ 幅）を `r_e` としたとき、領域の高さ `h` と幅 `w` を求める空欄（あ）に入るものとして正しいものを選べ。

  ```python
  import numpy as np

  def random_erasing(img, rng, s_l=0.02, s_h=0.4, r_1=0.3):
      H, W = img.shape[:2]
      S_e = rng.uniform(s_l, s_h) * H * W     # 消去する領域の面積
      r_e = rng.uniform(r_1, 1 / r_1)         # 消去する領域の縦横比（高さ / 幅）
      （あ）
      if h < H and w < W:
          y = rng.integers(0, H - h + 1)
          x = rng.integers(0, W - w + 1)
          img = img.copy()
          img[y:y + h, x:x + w] = rng.uniform(0, 255, size=img[y:y + h, x:x + w].shape)
      return img
  ```

高さ $h$ と幅 $w$ は、$hw = S_e$（面積）と $h/w = r_e$（縦横比）を満たす必要があります。2 式を掛けると $h^2 = S_e r_e$、割ると $w^2 = S_e/r_e$ なので、$h = \sqrt{S_e r_e}$、$w = \sqrt{S_e / r_e}$ です。

### 各選択肢の検討

- **A（正解）** $hw = \sqrt{S_e r_e}\sqrt{S_e/r_e} = S_e$、$h/w = r_e$ となり、両方の条件を満たします（`int` による切り捨ての誤差を除く）。
- **B** 面積は $S_e$ になりますが、$h/w = 1/r_e$ と縦横比が逆数になっています。
- **C** 面積が $hw = S_e^2$ となり、単位からして誤りです。$S_e$ は画像の面積の 2〜40% なので、$S_e^2$ はたいてい画像全体の面積 $HW$ を超えてしまい、`h < H and w < W` をほとんど満たさず何も消去されません。
- **D** 縦横比は $r_e$ になりますが、面積が $S_e r_e$ になってしまいます。

### ポイント

- Random Erasing は、物体の一部が隠れた（オクルージョンのある）画像に対する頑健性を高める拡張です。Cutout も、矩形領域を 0 などの固定値で塗りつぶす同様の手法です。
- 元の手法では、実際には適用するかどうかを確率 $p$ で決め、領域がはみ出す場合は面積と縦横比を引き直します。
- 拡張は訓練データにだけ適用し、検証データとテストデータには適用しません。
