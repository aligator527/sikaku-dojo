  $$H(p) = -p\log_2 p - (1 - p)\log_2(1 - p)\qquad(0 \le p \le 1,\ 0\log_2 0 = 0)$$

2 値エントロピー関数は、結果が最も予測しにくい $p = \tfrac12$ で最大値 $H(\tfrac12) = 1$ ビットをとり、結果が確定する $p = 0, 1$ で 0 になります。式は $p$ と $1 - p$ を入れ替えても変わらないので、$p = \tfrac12$ について左右対称です。

### 計算

$$\frac{dH}{dp} = -\log_2 p + \log_2(1 - p) = \log_2\frac{1 - p}{p} = 0 \iff p = \frac12,\qquad H\left(\tfrac12\right) = -2 \times \tfrac12\log_2\tfrac12 = 1$$

2 階微分は $\dfrac{d^2H}{dp^2} = -\dfrac{1}{p(1 - p)\log 2} < 0$ なので、$H(p)$ は上に凸（凹関数）です。例えば $H(0.1) = H(0.9) \approx 0.469$、$H(0.25) \approx 0.811$ ビットです。

### 各選択肢の検討

- **A** 最大値は $\log_2 2 = 1$ ビットです。自然対数で測れば $\log 2 \approx 0.693$ ナットになります。
- **B** $p = 1$ では結果が常に「成功」と確定しているので、エントロピーは 0 です。
- **C（正解）** 最大値と対称性の両方が正しい記述です。
- **D** 2 階微分が負なので上に凸で、$p = \tfrac12$ は最大点です。

### ポイント

- 2 値分類でモデルの予測確率が $0.5$ に近いデータは予測のエントロピーが大きく、「自信がない」データとみなせます（能動学習の不確実性サンプリングなど）。
- $K$ 値の場合も、エントロピーは一様分布のとき最大値 $\log_2 K$ ビットをとります。
