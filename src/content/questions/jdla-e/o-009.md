F 値は適合率（Precision）と再現率（Recall）の調和平均です。適合率 $= 30/(30+10) = 0.75$、再現率 $= 30/(30+30) = 0.5$ なので、$F_1 = \dfrac{2 \times 0.75 \times 0.5}{0.75 + 0.5} = 0.6$ です。

### 計算

表から $TP = 30$、$FN = 30$、$FP = 10$、$TN = 130$ です。

$$\text{Precision} = \frac{TP}{TP+FP} = \frac{30}{40} = 0.75,\qquad \text{Recall} = \frac{TP}{TP+FN} = \frac{30}{60} = 0.5$$

$$F_1 = \frac{2PR}{P+R} = \frac{2TP}{2TP + FP + FN} = \frac{60}{100} = 0.6$$

### 各選択肢の検討

- **0.75** 適合率です。
- **0.60（正解）** F 値（適合率と再現率の調和平均）です。
- **0.63** 適合率と再現率の算術平均 $(0.75 + 0.5)/2 = 0.625$ です。F 値は調和平均なので、算術平均より小さくなります。
- **0.80** 正解率（Accuracy）$= (30 + 130)/200$ です。陰性が多い不均衡データでは、正解率は陽性の検出性能を過大に見せます。

### ポイント

- $F_1 = 2TP/(2TP + FP + FN)$ の形で覚えると、適合率と再現率を経由せずに計算できます。TN は F 値に影響しません。
- 調和平均は小さい方の値に引きずられます。適合率と再現率の一方が極端に低いと F 値も低くなります。
- 多クラス分類では、クラスごとの指標を平均する macro 平均と、全クラスの TP・FP・FN を合算してから計算する micro 平均を区別します。
