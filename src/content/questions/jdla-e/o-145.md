$I(X; Y) = H(X) + H(Y) - H(X, Y)$ を使うと、周辺分布と同時分布のエントロピーだけで計算できます。$H(X) \approx 0.811$、$H(Y) = 1$、$H(X, Y) = 1.5$ なので、$I(X; Y) \approx 0.811 + 1 - 1.5 = 0.311$ ビットです。

### 計算

周辺分布は $P(X) = \left(\tfrac34, \tfrac14\right)$、$P(Y) = \left(\tfrac12, \tfrac12\right)$ です。

$$H(X) = -\tfrac34\log_2\tfrac34 - \tfrac14\log_2\tfrac14 = \tfrac34(2 - \log_2 3) + \tfrac14 \cdot 2 = 2 - \tfrac34\log_2 3 \approx 0.811$$

$$H(Y) = 1,\qquad H(X, Y) = -\tfrac12\log_2\tfrac12 - 2 \times \tfrac14\log_2\tfrac14 = 0.5 + 1 = 1.5\quad(0\log 0 = 0)$$

$$I(X; Y) = H(X) + H(Y) - H(X, Y) = 2 - \tfrac34\log_2 3 + 1 - 1.5 = 1.5 - \tfrac34\log_2 3 \approx 0.311$$

定義 $I(X; Y) = \sum_{x, y}p(x, y)\log_2\dfrac{p(x, y)}{p(x)p(y)}$ から直接計算しても同じ値になります。

### ポイント

- 条件付きエントロピーは $H(Y \mid X) = H(X, Y) - H(X) \approx 0.689$、$H(X \mid Y) = H(X, Y) - H(Y) = 0.5$ で、$I(X; Y) = H(Y) - H(Y \mid X) = H(X) - H(X \mid Y)$ も成り立ちます。
- 相互情報量は「$Y$ を知ることで $X$ の不確かさがどれだけ減るか」を表します。$X$ と $Y$ が独立なら 0 です。
- $H(X, Y) = H(X) + H(Y)$ と計算するのは、独立を仮定したときだけ正しい誤りです。
