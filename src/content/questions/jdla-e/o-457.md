まず重みに関する勾配 $g_j = \dfrac{\partial L}{\partial a_j} = \dfrac{\partial L}{\partial \boldsymbol o}\cdot \boldsymbol v_j$ を求めると $\boldsymbol g = (1, 3, -1)$ です。ソフトマックス関数のヤコビ行列 $\dfrac{\partial a_j}{\partial s_i} = a_j(\delta_{ij} - a_i)$ を通すと $\dfrac{\partial L}{\partial s_i} = a_i\left(g_i - \sum_j a_j g_j\right)$ となり、$\sum_j a_j g_j = 1$ なので $\dfrac{\partial L}{\partial \boldsymbol s} = \left(\tfrac12\cdot 0,\ \tfrac14\cdot 2,\ \tfrac14\cdot(-2)\right) = (0,\ 0.5,\ -0.5)$ です。

### 計算

**重みに関する勾配** $\boldsymbol o = \sum_j a_j \boldsymbol v_j$ より $\partial L/\partial a_j = (1, 1)\cdot\boldsymbol v_j$ なので

$$g_1 = 1,\qquad g_2 = 1 + 2 = 3,\qquad g_3 = -1$$

**加重平均** $\bar g = \sum_j a_j g_j = \tfrac12\cdot1 + \tfrac14\cdot3 + \tfrac14\cdot(-1) = 1$

**スコアに関する勾配**

$$\frac{\partial L}{\partial s_i} = \sum_j \frac{\partial L}{\partial a_j}\frac{\partial a_j}{\partial s_i} = \sum_j g_j\, a_j(\delta_{ij} - a_i) = a_i(g_i - \bar g)$$

$$\frac{\partial L}{\partial \boldsymbol s} = \left(\tfrac12(1 - 1),\ \tfrac14(3 - 1),\ \tfrac14(-1 - 1)\right) = (0,\ 0.5,\ -0.5)$$

### 各選択肢の検討

- **A** $a_i g_i$ で、ソフトマックス関数の正規化（分母）による項 $-a_i\bar g$ を無視しています。
- **B** $g_i - \bar g$ で、$a_i$ を掛け忘れています。
- **C** ヤコビ行列の対角成分 $a_i(1 - a_i)$ だけを使い、非対角成分 $-a_i a_j$ を無視しています。ソフトマックス関数の出力は互いに依存する（和が 1）ので、1 つのスコアを変えると全ての重みが変わります。
- **D（正解）** 成分の和が $0$ になっていることも確認できます（スコアに一定値を足しても重みは変わらないため）。

### ポイント

- $\partial L/\partial s_i = a_i(g_i - \bar g)$ は、「値ベクトルとの相性 $g_i$ が平均より良いキーのスコアを上げる（勾配降下では $-\partial L/\partial s_i$ の方向に動く）」という形をしています。
- マスクで $a_i = 0$ になった位置では、この勾配も 0 になり、隠した位置のスコアには勾配が流れません。
- 行列でまとめると、$dS = A \odot \left(dA - \mathrm{rowsum}(dA \odot A)\right)$、$dA = dO\,V^{\mathsf T}$ です。
