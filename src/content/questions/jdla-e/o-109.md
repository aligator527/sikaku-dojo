  NumPy で行列 `X`（形状 `(100, 20)`）を特異値分解し、特異値の大きい方から `k` 個だけを使って、フロベニウスノルムの意味で `X` に最も近いランク `k` の行列 `X_k` を作りたい。空欄（あ）に入るものとして正しいものを選べ。

  ```python
  import numpy as np

  X = np.random.randn(100, 20)
  U, s, Vt = np.linalg.svd(X, full_matrices=False)
  # U: (100, 20), s: (20,), Vt: (20, 20)
  k = 5
  X_k = （あ）
  ```

`np.linalg.svd` は $X = U\,\mathrm{diag}(\boldsymbol s)\,V^{\mathsf T}$ の $U$、特異値 `s`（**降順**）、そして $V$ ではなく **$V^{\mathsf T}$**（`Vt`、各**行**が右特異ベクトル）を返します。上位 $k$ 個の成分は、`U` の先頭 $k$ 列、`s` の先頭 $k$ 個、`Vt` の先頭 $k$ 行です。

### 計算

$$X_k = \sum_{i=1}^{k} s_i\,\boldsymbol u_i\boldsymbol v_i^{\mathsf T} = U_{:, 1:k}\,\mathrm{diag}(s_1, \dots, s_k)\,(V^{\mathsf T})_{1:k, :}$$

形状は $(100, 5)(5, 5)(5, 20) = (100, 20)$ で、`X` と同じです。エッカート・ヤングの定理により、これがランク $k$ の行列の中で $\|X - X_k\|_F$ を最小にし、その誤差は $\sqrt{s_{k+1}^2 + \cdots + s_{20}^2}$ です。

### 各選択肢の検討

- **A** `Vt` を $V$ と取り違えています。`Vt[:, :k].T` は「すべての右特異ベクトルの先頭 $k$ 成分」で、右特異ベクトルではありません。形状は $(5, 20)$ になるためエラーにならず、誤った行列が黙って得られる点が厄介です。
- **B（正解）** 上の式どおりです。
- **C** 特異値の小さい方から $k$ 個を使っています。`np.linalg.svd` の特異値は降順なので、これは最も情報の少ない成分による近似になります（固有値を昇順で返す `np.linalg.eigh` との混同）。
- **D** `U[:k, :]` は形状 $(5, 20)$ で、$(5, 5)$ の `np.diag(s[:k])` と内側の次元が合わず、エラーになります。

### ポイント

- `full_matrices=False` にすると、`U` は $(m, r)$、`Vt` は $(r, n)$（$r = \min(m, n)$）の経済型 SVD になります。既定の `True` では `U` が $(100, 100)$ の正方行列になります。
- `(U[:, :k] * s[:k]) @ Vt[:k]` のように、ブロードキャストで `U` の各列に特異値を掛けても同じ結果になります（`np.diag` を作らない分、効率的です）。
- PyTorch では `torch.linalg.svd(X, full_matrices=False)` が同じく `U, S, Vh` を返します。
- シラバス 2026（E2026#2〜）では、線形代数は「オプション（出題対象外）」の項目で、直接は出題されない前提知識の扱いです。
