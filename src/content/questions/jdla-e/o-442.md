Multi-Head Attention が $4 \times (256^2 + 256) = 263{,}168$、Feed-Forward Network が $(256 \times 1024 + 1024) + (1024 \times 256 + 256) = 525{,}568$、Layer Normalization が $2 \times 2 \times 256 = 1024$ で、合計 $789{,}760$ です。PyTorch の `nn.TransformerEncoderLayer(d_model=256, nhead=4, dim_feedforward=1024)` のパラメータ数とも一致します。

### 計算

**Multi-Head Attention** 全ヘッド分の $W^Q$ は $h$ 個の $d_{\text{model}} \times d_k$ 行列を並べたもので、合わせて $d_{\text{model}} \times h d_k = 256 \times 256$ です。$W^K, W^V, W^O$ も同じ大きさなので

$$4 \times (256 \times 256 + 256) = 4 \times 65{,}792 = 263{,}168$$

**Feed-Forward Network**

$$(256 \times 1024 + 1024) + (1024 \times 256 + 256) = 263{,}168 + 262{,}400 = 525{,}568$$

**Layer Normalization** $\gamma, \beta$ がそれぞれ $d_{\text{model}}$ 個で、2 つあるので $2 \times 2 \times 256 = 1024$。

**合計** $263{,}168 + 525{,}568 + 1024 = 789{,}760$

### ポイント

- Multi-Head Attention のパラメータ数は、$d_k = d_{\text{model}}/h$ である限りヘッド数 $h$ によらず $4(d_{\text{model}}^2 + d_{\text{model}})$ です。ヘッドごとに $d_{\text{model}} \times d_{\text{model}}$ の射影を持つと考えて $h$ 倍すると過大になります。
- Layer Normalization を数え忘れると $788{,}736$、バイアスを数え忘れると $787{,}456$ になります。
- $d_{\text{ff}} = 4 d_{\text{model}}$ のとき、Feed-Forward Network のパラメータ（約 $8 d_{\text{model}}^2$）は Multi-Head Attention（約 $4 d_{\text{model}}^2$）の約 2 倍で、層のパラメータの約 3 分の 2 を占めます。
