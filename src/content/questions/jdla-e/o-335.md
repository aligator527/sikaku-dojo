L1 ペナルティを重みにかけるとパラメータがスパースになり、隠れ層の出力（活性）にかけると表現がスパースになります。スパース表現では、入力ごとに少数のユニットだけが 0 でない値をとり、各ユニットが特定の特徴に選択的に反応するようになります。

### 各選択肢の検討

- **A（正解）** 表現のスパース性と、パラメータのスパース性の違いを正しく述べています。
- **B** 罰則の対象（活性か重みか）も、ノルムの種類（L1 か L2 か）も異なります。活性は入力ごとに変わるので、重みのペナルティとは一般に一致しません。
- **C** 表現がスパースでも、重み行列の要素はほとんど 0 でないことがあり、パラメータ数は変わりません。どのユニットが 0 になるかは入力ごとに異なります。
- **D** 逆です。ReLU は負の入力に対してちょうど 0 を出力するので、スパースな表現を作りやすい活性化関数です。シグモイド関数の出力はちょうど 0 にはなりません。

### ポイント

- シラバスでは「パラメータノルムペナルティ」の項目に、L1 正則化と並んでスパース表現が挙げられています。「何に」L1 ペナルティをかけるかで意味が変わる点を押さえておきます。
- スパース表現は、オートエンコーダの隠れ層に L1 ペナルティを加えるスパースオートエンコーダなどで使われます。
