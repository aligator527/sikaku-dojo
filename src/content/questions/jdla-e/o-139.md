  区間 $[0, \theta]$ 上の一様分布 $U(0, \theta)$（$\theta > 0$ は未知）に独立に従う 5 個のデータ

  $$0.8,\ 2.1,\ 1.5,\ 3.4,\ 2.7$$

  を得た。$\theta$ の最尤推定値として正しいものを選べ。
choices:
  - '$3.4$'
  - '$4.2$'
  - '$4.08$'
  - '$2.1$'
answer: 1

一様分布の密度は $0 \le x \le \theta$ で $1/\theta$、それ以外で 0 です。尤度は、すべてのデータが $[0, \theta]$ に入る（$\theta \ge \max_i x_i$）ときだけ $\theta^{-5}$ で、それ以外は 0 です。$\theta^{-5}$ は $\theta$ について減少関数なので、条件を満たす最小の $\theta$、つまり最大値 $3.4$ で尤度が最大になります。

### 計算

$$L(\theta) = \prod_{i=1}^{5}\frac{1}{\theta}\,\mathbb 1[0 \le x_i \le \theta] = \begin{cases} \theta^{-5} & (\theta \ge 3.4) \\ 0 & (\theta < 3.4) \end{cases}$$

$L(\theta)$ は $\theta = 3.4$ で不連続に立ち上がり、その後は単調に減少するので $\hat\theta = \max_i x_i = 3.4$ です。微分して 0 とおく方法では求まらない点に注意します（$d\ell/d\theta = -5/\theta$ は 0 になりません）。

### 各選択肢の検討

- **A（正解）** 標本の最大値です。
- **B** $E[X] = \theta/2$ を使ったモーメント法の推定値 $2\bar x = 2 \times 2.1$ です。最尤推定値とは異なり、この値では観測値の最大 3.4 は区間に入りますが、尤度 $4.2^{-5}$ は $3.4^{-5}$ より小さくなります。
- **C** 最尤推定量の偏りを補正した不偏推定量 $\dfrac{n+1}{n}\max_i x_i = 1.2 \times 3.4$ です。最尤推定値は常に真の $\theta$ 以下になるため、平均的に過小推定します。
- **D** 標本平均で、区間の上端ではなく中央の推定値です。$\theta = 2.1$ では $3.4$ などが区間の外になり、尤度は 0 です。

### ポイント

- 尤度を最大にする点が、微分が 0 になる点とは限りません。パラメータによって台（密度が正の範囲）が変わる分布では、尤度を直接グラフで考えます。
- 最尤推定量は必ずしも不偏ではありません（正規分布の分散の最尤推定量 $\tfrac1n\sum(x_i - \bar x)^2$ も同様です）。ただしデータ数が増えると真の値に近づきます（一致性）。
