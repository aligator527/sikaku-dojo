  2 変数の損失関数

  $$L(w_1, w_2) = \frac12\left(10\,w_1^2 + w_2^2\right)$$

  を、固定の学習率 $\eta > 0$ の勾配降下法 $\boldsymbol w \leftarrow \boldsymbol w - \eta \nabla L(\boldsymbol w)$ で最小化する。任意の初期値から最小点 $(0, 0)$ に収束するための、$\eta$ についての必要十分条件として正しいものを選べ。
choices:
  - '$0 < \eta < 0.1$'
  - '$0 < \eta < 0.2$'
  - '$0 < \eta < 1$'
  - '$0 < \eta < 2$'
answer: 2

勾配は $\nabla L = (10 w_1,\ w_2)$ なので、各座標は独立に $w_1 \leftarrow (1 - 10\eta) w_1$、$w_2 \leftarrow (1-\eta) w_2$ と更新されます。両方が 0 に収束するには $|1-10\eta| < 1$ かつ $|1-\eta| < 1$、すなわち $0 < \eta < 0.2$ が必要十分です。上限は最も急な方向の曲率（ヘッセ行列の最大固有値 10）で決まり、$2/\lambda_{\max}$ です。

### 計算

$t$ 回更新すると $w_1^{(t)} = (1 - 10\eta)^t w_1^{(0)}$、$w_2^{(t)} = (1 - \eta)^t w_2^{(0)}$ です。

$$|1 - 10\eta| < 1 \iff 0 < \eta < 0.2,\qquad |1 - \eta| < 1 \iff 0 < \eta < 2$$

両方を満たすのは $0 < \eta < 0.2$ です。$\eta = 0.2$ ちょうどでは $w_1$ の係数が $-1$ となり、符号を変えながら同じ大きさで振動し続けます。

### 各選択肢の検討

- **A** $\eta < 0.1$ は $1 - 10\eta > 0$、つまり $w_1$ が符号を変えずに単調に 0 へ近づく条件です。$\eta = 0.1$ なら $w_1$ は 1 回で 0 になり、$0.1 < \eta < 0.2$ でも $w_1$ は符号を交互に変えながら収束するので、必要条件ではありません。
- **B（正解）** 両方向の係数の絶対値が 1 未満になる範囲です。
- **C** 緩やかな方向の曲率 $\lambda_{\min} = 1$ の逆数で、この範囲の $\eta = 0.5$ では $w_1$ の係数が $1 - 5 = -4$ となり発散します。
- **D** $w_2$ だけを考えた条件 $2/\lambda_{\min}$ です。急な方向 $w_1$ が先に発散します。

### ポイント

- ヘッセ行列が $H$ の 2 次関数に対する勾配降下法は、$0 < \eta < 2/\lambda_{\max}(H)$ のときに収束します。
- 収束の速さは最も遅い方向で決まります。$\eta$ を上限近くにとっても $w_2$ の係数は $1 - \eta \approx 0.8$ 程度にしかなりません。条件数 $\kappa = \lambda_{\max}/\lambda_{\min}$ が大きいほど収束が遅くなるのが pathological curvature の問題で、モメンタムや適応的な学習率の手法はこれを和らげるために使われます。
