  確率的勾配降下法で、ステップ $t = 1, 2, \ldots$ の学習率 $\eta_t$ をスケジュールに従って変化させる。確率的勾配降下法が収束するための十分条件としてよく知られる

  $$\sum_{t=1}^{\infty}\eta_t = \infty,\qquad \sum_{t=1}^{\infty}\eta_t^2 < \infty$$

  の両方を満たす学習率のスケジュールとして、正しいものを選べ。
choices:

$\sum 1/t$（調和級数）は発散し、$\sum 1/t^2$ は収束するので、$\eta_t = 0.1/t$ は両方の条件を満たします。第 1 の条件は「最適解までどれだけ遠くても到達できるだけの距離を進める」こと、第 2 の条件は「勾配のノイズによる揺れが最終的に収まる」ことを表しています。

### 計算

$$\sum_{t=1}^{\infty}\frac{0.1}{t} = \infty,\qquad \sum_{t=1}^{\infty}\left(\frac{0.1}{t}\right)^2 = 0.01 \times \frac{\pi^2}{6} \approx 0.0164 < \infty$$

### 各選択肢の検討

- **A** $\sum\eta_t = \infty$ は満たしますが、$\sum\eta_t^2 = \sum 0.01 = \infty$ です。学習率が一定だと、最小点の近くでもミニバッチ勾配のノイズによる揺れが残り、最小点のまわりをさまよい続けます。
- **B（正解）** 両方の条件を満たします。
- **C** $\sum\eta_t^2 < \infty$ は満たしますが、$\sum\eta_t = 0.1 \times \pi^2/6 \approx 0.164$ と有限です。学習率が早く小さくなりすぎて、最小点に着く前に止まってしまうおそれがあります。
- **D** $\sum\eta_t = \infty$ は満たしますが、$\sum\eta_t^2 = \sum 0.01/t = \infty$ です。

### ポイント

- 最急降下法（全データの勾配）では最小点で勾配が 0 になるので、学習率が一定でも収束できます。SGD ではミニバッチ勾配が最小点でも 0 にならないので、学習率を徐々に下げる必要があります。
- 実際の深層学習では $1/t$ のような減衰は遅すぎることが多く、ステップ減衰、線形減衰、コサイン減衰などで、学習の終盤に初期値の数％程度まで下げるスケジュールがよく使われます。
