  メモリーセルが 1 次元の LSTM で、メモリーセルは

  $$c_t = f_t\, c_{t-1} + i_t\, g_t$$

  で更新される（$f_t$：忘却ゲート、$i_t$：入力ゲート、$g_t$：セル候補）。$c_0 = 1.0$ とし、各時刻のゲートとセル候補の値が次の表のとおりであったとき、$c_2$ の値を求めよ。

  | 時刻 $t$ | $f_t$ | $i_t$ | $g_t$ |
  | --- | --- | --- | --- |
  | 1 | 0.9 | 0.5 | 0.8 |
  | 2 | 0.8 | 0.5 | 0.4 |

メモリーセルの更新式を時刻順に 2 回適用します。$c_1 = 0.9\times1.0 + 0.5\times0.8 = 1.3$、$c_2 = 0.8\times1.3 + 0.5\times0.4 = 1.24$ です。

### 計算

$$c_1 = f_1 c_0 + i_1 g_1 = 0.9\times1.0 + 0.5\times0.8 = 0.9 + 0.4 = 1.3$$

$$c_2 = f_2 c_1 + i_2 g_2 = 0.8\times1.3 + 0.5\times0.4 = 1.04 + 0.2 = 1.24$$

### ポイント

- 忘却ゲートと入力ゲートを取り違えて $c_t = i_t c_{t-1} + f_t g_t$ とすると $c_1 = 1.22$、$c_2 = 0.61 + 0.32 = 0.93$ になります。
- メモリーセルは $\tanh$ などで押しつぶされずに足し算で更新されるので、値が 1 を超えることもあります。隠れ状態は $h_t = o_t \tanh(c_t)$ で $(-1, 1)$ に収められます。
- $c_0$ から $c_2$ への直接の経路の勾配は $\dfrac{\partial c_2}{\partial c_0} = f_1 f_2 = 0.72$ です。忘却ゲートが 1 に近いほど、勾配は過去へ減衰せずに伝わります。
