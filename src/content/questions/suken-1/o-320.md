$f(x) = x^3 - 2$ に対するニュートン法の反復式は $x_{n+1} = x_n - \dfrac{x_n^3 - 2}{3x_n^2} = \dfrac{2x_n^3 + 2}{3x_n^2}$ です。$x_1 = \tfrac43$、$x_2 = \tfrac{91}{72}$ となります。

### 計算

反復式を整理すると

$$x_{n+1} = x_n - \frac{x_n^3 - 2}{3x_n^2} = \frac{2x_n^3 + 2}{3x_n^2} = \frac23\left(x_n + \frac{1}{x_n^2}\right).$$

$x_0 = 1$ のとき

$$x_1 = \frac23\,(1 + 1) = \frac43.$$

$x_1 = \tfrac43$ のとき $\dfrac{1}{x_1^2} = \dfrac{9}{16}$ なので

$$x_2 = \frac23\left(\frac43 + \frac{9}{16}\right) = \frac23\cdot\frac{64 + 27}{48} = \frac{91}{72}.$$

$\tfrac{91}{72} = 1.2638\cdots$ で、真の値 $\sqrt[3]{2} = 1.2599\cdots$ との差は約 $0.004$ です。

### ポイント

- ニュートン法は $x_{n+1} = x_n - \dfrac{f(x_n)}{f'(x_n)}$ で、接線の $x$ 切片を次の近似値とします。単根の近くでは誤差がほぼ 2 乗ずつ小さくなります（2 次収束）。
- $x_0 = 1$ からの誤差は $0.26 \to 0.074 \to 0.004$ と減ります。次の $x_3$ では誤差は約 $10^{-5}$ になります。
- $f'(x) = 3x^2$ を $2x$ などと誤ると、収束はしても速さが落ちたり別の値に向かったりします。
