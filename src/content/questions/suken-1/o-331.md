ロジスティック方程式の解は $P(t) = \dfrac{1000}{1 + Ae^{-rt}}$ の形です。初期条件から $A = 9$、$P(1) = 250$ から $e^{-r} = \tfrac13$ が決まり、$P(t) = 900$ は $9\cdot 3^{-t} = \tfrac19$、すなわち $t = 4$ のときです。

### 計算

変数分離して部分分数に分けると

$$\int\left(\frac1P + \frac{1}{1000 - P}\right)dP = \int r\,dt \quad\Longrightarrow\quad \log\frac{P}{1000 - P} = rt + C.$$

よって $\dfrac{1000 - P}{P} = Ae^{-rt}$、すなわち

$$P(t) = \frac{1000}{1 + Ae^{-rt}}.$$

- $P(0) = 100$：$1 + A = 10$ より $A = 9$。
- $P(1) = 250$：$1 + 9e^{-r} = 4$ より $e^{-r} = \tfrac13$。

したがって $P(t) = \dfrac{1000}{1 + 9\cdot 3^{-t}}$ です。$P(t) = 900$ とすると

$$1 + 9\cdot 3^{-t} = \frac{10}{9} \quad\Longrightarrow\quad 3^{-t} = \frac{1}{81} = 3^{-4} \quad\Longrightarrow\quad t = 4.$$

### ポイント

- $\dfrac{1000 - P}{P}$（環境収容力までの「残り」と現在の比）が指数関数的に減少する、と覚えると計算が速くなります。ここでは $9 \to 3 \to 1 \to \tfrac13 \to \tfrac19$ と毎時刻 $\tfrac13$ 倍で、$t = 4$ で $\tfrac19$（$P = 900$）です。
- 増加が最も速い（変曲点）のは $P = 500$ のときで、この問題では $t = 2$ です。$P = 100$ と $P = 900$ の時刻が変曲点について対称になっていることも確かめられます。
- 初期の増加を指数関数 $100\cdot 2.5^t$ で近似すると、$P = 900$ に達する時刻を過小に見積もります。
