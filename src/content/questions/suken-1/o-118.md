stem: |
  $e$ を自然対数の底とする。

  (1) テイラーの定理を用いて、各自然数 $n$ に対し

  $$e = \sum_{k=0}^{n} \frac{1}{k!} + \frac{e^{\theta}}{(n+1)!}$$

  を満たす $\theta$（$0 < \theta < 1$）が存在することを示せ。

  (2) $2 < e < 3$ であることを示せ。

  (3) $e$ は無理数であることを証明せよ。
modelAnswer: |
  **(1)** $f(x) = e^x$ は何回でも微分でき、$f^{(k)}(x) = e^x$、$f^{(k)}(0) = 1$ である。ラグランジュの剰余項をもつテイラーの定理を $0$ と $1$ の間に適用すると、ある $\theta$（$0 < \theta < 1$）が存在して

  $$f(1) = \sum_{k=0}^{n}\frac{f^{(k)}(0)}{k!} + \frac{f^{(n+1)}(\theta)}{(n+1)!}, \quad\text{すなわち}\quad e = \sum_{k=0}^{n} \frac{1}{k!} + \frac{e^{\theta}}{(n+1)!}.$$

  **(2)** (1) で $n = 1$ とすると $e = 2 + \dfrac{e^\theta}{2} > 2$。

  また $e^\theta < e$ だから、(1) より任意の $n$ で

  $$e < \sum_{k=0}^{n}\frac{1}{k!} + \frac{e}{(n+1)!}.$$

  $n = 2$ とすると $\displaystyle\sum_{k=0}^{2}\frac{1}{k!} = \frac52$ だから

  $$e < \frac52 + \frac{e}{6} \quad\Longrightarrow\quad \frac56 e < \frac52 \quad\Longrightarrow\quad e < 3.$$

  **(3)** $e$ が有理数であると仮定し、$e = \dfrac{p}{q}$（$p, q$ は自然数）とおく。(2) より $e$ は整数でないから $q \ge 2$ である。(1) で $n = q$ とし、両辺に $q!$ を掛けると

  $$q!\,e - \sum_{k=0}^{q}\frac{q!}{k!} = \frac{e^{\theta}}{q+1}.$$

  左辺について、$q!\,e = (q-1)!\,p$ は整数であり、$k \le q$ のとき $\dfrac{q!}{k!}$ も整数だから、左辺は整数である。

  一方、右辺は $0 < \theta < 1$ と (2) より

  $$0 < \frac{e^{\theta}}{q+1} < \frac{e}{q+1} < \frac{3}{3} = 1 \quad (q \ge 2).$$

  $0$ と $1$ の間に整数は存在しないから矛盾である。したがって $e$ は無理数である。（証明終）

テイラーの定理の剰余項評価を使う、有名な無理数性の証明です。$e$ を $\sum_{k\le n} 1/k!$ で近似したときの誤差が $\dfrac{1}{(n+1)!}$ 程度と非常に小さいことを利用し、「$q!\,e$ が整数なら、誤差を $q!$ 倍したものが $0$ と $1$ の間の整数になってしまう」という矛盾を導きます。

### 証明の組み立て

1. **剰余項つきの展開** $e^x$ はすべての導関数が $e^x$ なので、剰余項が $\dfrac{e^\theta}{(n+1)!}$ と具体的に書けます。$\theta$ が $0$ と $1$ の **間**（端点を含まない）にあることが、後で右辺が正であることの根拠になります。
2. **$e$ の大きさの評価** (3) で右辺を $1$ 未満に抑えるために $e < 3$ が必要です。「$e = 2.718\ldots$ だから」と書くだけでは証明になりません。
3. **整数性の矛盾** 分母 $q$ に合わせて $n = q$ と選ぶのが要点です。$n$ を $q$ より小さくとると、$q!\,e$ の展開部分が整数にならないことがあります。

### ポイント

- 同様の議論で $e^{-1}$ や $\cosh 1$ の無理数性も示せます。一方、$\pi$ の無理数性はこの方法では示せず、積分を使う別の証明（ニーベンの証明など）が必要です。
- テイラーの定理の剰余項には、ラグランジュ形 $\dfrac{f^{(n+1)}(\theta)}{(n+1)!}x^{n+1}$ と積分形 $\displaystyle\int_0^x\frac{(x-t)^n}{n!}f^{(n+1)}(t)\,dt$ があります。どちらを使っても (1) は示せます。
- (3) で「右辺は正」の根拠を落とすと、$0$ が整数であることとの区別がつかず、証明が不完全になります。
