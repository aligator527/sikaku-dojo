直方体の頂点の 1 つを第 1 象限の $(x, y, z)$ とすると体積は $V = 8xyz$ で、条件は $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} + \dfrac{z^2}{c^2} = 1$ です。3 つの項に相加・相乗平均の不等式を使うと、各項が $\tfrac13$ のとき最大で、$V_{\max} = \dfrac{8abc}{3\sqrt3}$ です。

### 計算

体積を最大にするには頂点を楕円体の表面上にとればよく、$x, y, z > 0$ として

$$\frac13 = \frac13\left(\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2}\right) \ge \left(\frac{x^2y^2z^2}{a^2b^2c^2}\right)^{1/3}.$$

両辺を $\tfrac32$ 乗すると $\dfrac{xyz}{abc} \le \left(\dfrac13\right)^{3/2} = \dfrac{1}{3\sqrt3}$ なので

$$V = 8xyz \le \frac{8abc}{3\sqrt3}.$$

等号は $\dfrac{x^2}{a^2} = \dfrac{y^2}{b^2} = \dfrac{z^2}{c^2} = \dfrac13$、すなわち $(x, y, z) = \left(\dfrac{a}{\sqrt3}, \dfrac{b}{\sqrt3}, \dfrac{c}{\sqrt3}\right)$ のとき成り立ちます。

**別解（ラグランジュの未定乗数法）** $\nabla(xyz) = \lambda\nabla\left(\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2}\right)$ から $yz = \frac{2\lambda x}{a^2}$ などが得られ、各式に $x, y, z$ を掛けて比べると $\frac{x^2}{a^2} = \frac{y^2}{b^2} = \frac{z^2}{c^2}$ となります。

### 各選択肢の検討

1. 誤り。条件を平面 $\frac xa + \frac yb + \frac zc = 1$ と取り違え、$\frac xa = \frac yb = \frac zc = \frac13$ とした値です（または不等式の両辺の 2 乗をはずし忘れた値）。
2. 正しい。
3. 誤り。$xyz$ の最大値で、直方体の辺の長さが $2x, 2y, 2z$ であること（係数 $8$）を忘れています。
4. 誤り。対称性から最大になるのは立方体（$x = y = z$）だと思い込んだ場合の値です。$a, b, c$ が異なると立方体は最適ではありません。

### ポイント

- 変数変換 $X = \frac xa,\ Y = \frac yb,\ Z = \frac zc$ で単位球に内接する直方体の問題（最大は立方体、体積 $\frac{8}{3\sqrt3}$）に帰着し、体積は $abc$ 倍になります。
- $a = b = c = r$（球）のとき $\dfrac{8r^3}{3\sqrt3}$ で、球の体積 $\frac43\pi r^3$ の約 $37\%$ です。
