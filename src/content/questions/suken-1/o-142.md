右辺の積分は $\sin t$ と $y(t)$ のたたみ込みなので、ラプラス変換すると代数方程式になります。$Y(s) = \dfrac{1}{s^2} + \dfrac{1}{s^4}$ から $y(t) = t + \dfrac{t^3}{6}$ で、$y(6) = 6 + 36 = 42$ です。

### 計算

**ラプラス変換による解法** $\mathcal{L}[y] = Y(s)$ とすると、たたみ込みの変換は積になるので

$$Y(s) = \frac{1}{s^{2}} + \frac{1}{s^{2} + 1}\,Y(s).$$

$Y$ について解くと

$$Y(s)\cdot\frac{s^{2}}{s^{2} + 1} = \frac{1}{s^{2}} \quad\Longrightarrow\quad Y(s) = \frac{s^{2} + 1}{s^{4}} = \frac{1}{s^{2}} + \frac{1}{s^{4}}.$$

$\mathcal{L}[t^n] = \dfrac{n!}{s^{n+1}}$ より逆変換して

$$y(t) = t + \frac{t^{3}}{6}.$$

**別解（微分方程式に直す）** 両辺を $t$ で微分すると（積分の上端と被積分関数の両方に $t$ があることに注意して）

$$y'(t) = 1 + \sin 0\cdot y(t) + \int_0^t\cos(t - s)\,y(s)\,ds = 1 + \int_0^t\cos(t-s)\,y(s)\,ds,$$

$$y''(t) = \cos 0\cdot y(t) - \int_0^t\sin(t-s)\,y(s)\,ds = y(t) - \bigl(y(t) - t\bigr) = t.$$

初期条件は元の式と $y'$ の式に $t = 0$ を代入して $y(0) = 0,\ y'(0) = 1$。よって $y = \dfrac{t^3}{6} + t$ で、同じ結果です。

$$y(6) = 6 + \frac{216}{6} = 6 + 36 = 42.$$

### ポイント

- $\displaystyle\int_0^t f(t-s)g(s)\,ds$ の形（たたみ込み）を見たら、ラプラス変換 $\mathcal{L}[f * g] = F(s)G(s)$ を考えます。$\mathcal{L}[\sin t] = \dfrac{1}{s^2+1}$ です。
- 積分方程式を微分方程式に直す場合は、初期条件を元の方程式から読み取ることを忘れないようにします。$y'(0) = 1$ を見落として $y'(0) = 0$ とすると、$y = \dfrac{t^3}{6}$、$y(6) = 36$ と誤答します。
- 求めた解を元の式に代入して確かめることもできます：$\displaystyle\int_0^t\sin(t-s)\left(s + \frac{s^3}{6}\right)ds = \frac{t^3}{6}$。
