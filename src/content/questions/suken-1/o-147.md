  微分方程式

  $$y'' - 2xy' - 2y = 0 \qquad (\ast)$$

  について、次の問いに答えよ。

  (1) $(\ast)$ がべき級数解 $y = \displaystyle\sum_{n=0}^{\infty} a_n x^n$ をもつとき、係数 $a_n$ が満たす漸化式を求めよ。

  (2) 初期条件 $y(0) = 1,\ y'(0) = 0$ を満たす $(\ast)$ の解を、初等関数で表せ。

  (3) $y = e^{x^{2}}v$ とおくことにより、初期条件 $y(0) = 0,\ y'(0) = 1$ を満たす $(\ast)$ の解が

  $$y = e^{x^{2}}\int_0^x e^{-t^{2}}\,dt$$

  であることを示せ。また、この解のべき級数展開を (1) を用いて求めよ。
modelAnswer: |
  **(1)** $y = \sum a_n x^n$ を項別微分して代入すると

  $$y'' = \sum_{n=0}^{\infty}(n+2)(n+1)a_{n+2}x^{n},\qquad 2xy' = \sum_{n=0}^{\infty}2n\,a_n x^{n},\qquad 2y = \sum_{n=0}^{\infty}2a_n x^n.$$

  $x^n$ の係数を比較して $(n+2)(n+1)a_{n+2} - 2(n+1)a_n = 0$、すなわち

  $$a_{n+2} = \frac{2}{n+2}\,a_n \qquad (n = 0, 1, 2, \ldots).$$

  **(2)** $a_0 = y(0) = 1,\ a_1 = y'(0) = 0$ である。漸化式より奇数番目はすべて $0$、偶数番目は

  $$a_{2k} = \frac{2}{2k}a_{2k-2} = \frac1k a_{2k-2} = \cdots = \frac{1}{k!}.$$

  よって $y = \displaystyle\sum_{k=0}^{\infty}\frac{x^{2k}}{k!} = e^{x^{2}}$（収束半径は $\infty$ なので、項別微分・代入はすべての $x$ で正当化される）。実際、$y = e^{x^2}$ のとき $y' = 2xe^{x^2}$、$y'' = (2 + 4x^2)e^{x^2}$ で $y'' - 2xy' - 2y = 0$ を満たす。

  **(3)** $y = e^{x^2}v$ とおくと

  $$y' = e^{x^2}(v' + 2xv),\qquad y'' = e^{x^2}\left\{v'' + 4xv' + (2 + 4x^{2})v\right\}.$$

  $(\ast)$ に代入すると

  $$e^{x^2}\left\{v'' + 4xv' + (2 + 4x^2)v - 2xv' - 4x^2v - 2v\right\} = e^{x^2}(v'' + 2xv') = 0.$$

  よって $(e^{x^2}v')' = e^{x^2}(v'' + 2xv') = 0$ で、$v' = Ce^{-x^2}$。初期条件は $v(0) = y(0) = 0$、$v'(0) = y'(0) - 0 = 1$ なので $C = 1$、$v = \displaystyle\int_0^x e^{-t^2}\,dt$。したがって

  $$y = e^{x^{2}}\int_0^x e^{-t^{2}}\,dt$$

  は $(\ast)$ の解で、$y(0) = 0$、$y'(0) = 1$ を満たす。線形微分方程式の初期値問題の解は一意なので、これが求める解である。

  **べき級数展開** $a_0 = 0,\ a_1 = 1$ として (1) を使うと、偶数番目はすべて $0$、奇数番目は

  $$a_{2k+1} = \frac{2}{2k+1}a_{2k-1} = \cdots = \frac{2^{k}}{3\cdot5\cdots(2k+1)} = \frac{2^k\cdot 2^k k!}{(2k+1)!} = \frac{4^{k}\,k!}{(2k+1)!}.$$

  （$3\cdot5\cdots(2k+1) = \dfrac{(2k+1)!}{2\cdot4\cdots(2k)} = \dfrac{(2k+1)!}{2^k k!}$ を用いた。）この級数も収束半径 $\infty$ で $(\ast)$ の解となり、同じ初期条件を満たすから、一意性より

  $$e^{x^{2}}\int_0^x e^{-t^{2}}\,dt = \sum_{k=0}^{\infty}\frac{4^{k}\,k!}{(2k+1)!}x^{2k+1} = x + \frac23x^{3} + \frac{4}{15}x^{5} + \frac{8}{105}x^{7} + \cdots.$$
rubric:
  - (1) でべき級数を代入して添字をそろえ、漸化式 $a_{n+2} = 2a_n/(n+2)$ を導いている
  - (2) で $a_{2k} = 1/k!$ を求め、解が $e^{x^2}$ であることを示している
  - (3) で $y = e^{x^2}v$ の代入から $v'' + 2xv' = 0$ を導き、初期条件から $v = \int_0^x e^{-t^2}dt$ を得ている
  - 奇数次の係数 $a_{2k+1} = 4^k k!/(2k+1)!$ を求め、初期値問題の解の一意性に触れてべき級数展開と結びつけている

係数に $x$ を含む 2 階線形方程式を、べき級数と階数低下法の 2 通りで解く問題です。偶数次の解は $e^{x^2}$ と閉じた形になり、それを使って $y = e^{x^2}v$ とおくと、もう 1 つの解が誤差関数型の積分 $e^{x^2}\displaystyle\int_0^x e^{-t^2}dt$ で表されます。

### 解答の組み立て

1. **漸化式** $y''$ の級数は添字を 2 ずらして $x^n$ の係数にそろえます。$2xy'$ は $x$ を掛けるので添字がそのまま $n$ になります。$(n+1)$ で約分できることに気付くと漸化式が簡単になります。
2. **閉じた形の解** $a_{2k} = \dfrac{1}{k!}$ から $e^{x^2}$ の展開であると見抜きます。
3. **階数低下法** 1 つの解 $y_1$ が分かれば、$y = y_1v$ とおくと $v'$ についての 1 階方程式になります。一般に $v' = \dfrac{C}{y_1^2}\exp\left(-\displaystyle\int p\,dx\right)$（$p = -2x$ は $y'$ の係数）で、ここでは $v' = Ce^{-2x^2}\cdot e^{x^2} = Ce^{-x^2}$ です。

### ポイント

- 解の一意性（初期値問題）を使うと、「同じ方程式・同じ初期条件を満たす 2 つの表示は等しい」という形で恒等式が得られます。ここでは $e^{x^2}\displaystyle\int_0^x e^{-t^2}dt$ のべき級数展開が得られました。
- $(\ast)$ は $y = e^{x^2}$ のような急増加する解をもつので、$x \to \infty$ での挙動を議論するときは解の組み合わせに注意します。
- 漸化式で $a_{n+2}$ と $a_n$ を結ぶとき、偶数番目と奇数番目が独立に決まり、$a_0 = y(0)$、$a_1 = y'(0)$ が 2 つの任意定数の役割を果たします。
