$f(x) = \dfrac1x$ の 2 階導関数 $f''(x) = \dfrac{2}{x^3}$ の最大値は $x = 1$ での $2$ です。評価式は $\dfrac{1}{6n^2} \le 10^{-4}$ となり、$n^2 \ge 1666.6\cdots$ から最小の $n$ は $41$ です。

### 計算

$a = 1,\ b = 2$ より $b - a = 1,\ h = \dfrac1n$。$1 \le x \le 2$ で $|f''(x)| = \dfrac{2}{x^3} \le 2$（$x = 1$ で最大）なので

$$|E| \le \frac{1\cdot h^2}{12}\cdot 2 = \frac{1}{6n^2}.$$

$\dfrac{1}{6n^2} \le 10^{-4} \iff n^2 \ge \dfrac{10^4}{6} = 1666.6\cdots$ です。$40^2 = 1600 < 1666.6\cdots < 1681 = 41^2$ なので、最小の $n$ は $41$ です。

### ポイント

- 複合台形公式の誤差は $E = -\dfrac{(b-a)h^2}{12}f''(\eta)$（$a \le \eta \le b$）と表され、評価式はこれから得られます。$h$ を半分にすると誤差は約 $\tfrac14$ になります。
- 評価式は「最悪の場合」の上界です。実際の誤差は $n = 41$ で約 $3.7 \times 10^{-5}$ で、$n = 25$ ですでに $10^{-4}$ をわずかに下回ります。
- $\max|f''|$ を区間の右端 $x = 2$ でとる（$\tfrac14$）と、上界にならない値を使うことになり誤りです。
