$y^2$ を含むベルヌーイ型の方程式なので、$u = \dfrac1y$ とおくと 1 階線形方程式 $u' + u = -e^{x}$ になります。解は $y = \dfrac{2}{5e^{-x} - e^{x}}$ で、$y(\log 2) = \dfrac{2}{\frac52 - 2} = 4$ です。

### 計算

$y \neq 0$ として $u = y^{-1}$ とおくと $u' = -\dfrac{y'}{y^2}$。方程式の両辺を $-y^2$ で割ると

$$-\frac{y'}{y^{2}} + \frac1y = -e^{x} \quad\Longrightarrow\quad u' + u = -e^{x}.$$

両辺に積分因子 $e^{x}$ を掛けると $(e^{x}u)' = -e^{2x}$ なので

$$e^{x}u = -\frac{e^{2x}}{2} + C,\qquad u = Ce^{-x} - \frac{e^{x}}{2}.$$

$u(0) = \dfrac{1}{y(0)} = 2$ より $C - \dfrac12 = 2$、$C = \dfrac52$。よって

$$y(x) = \frac{1}{u} = \frac{2}{5e^{-x} - e^{x}}.$$

$e^{\log 2} = 2,\ e^{-\log 2} = \dfrac12$ なので

$$y(\log 2) = \frac{2}{\frac52 - 2} = \frac{2}{\frac12} = 4.$$

（この解は分母が $0$ になる $x = \dfrac12\log 5 \approx 0.805$ で発散します。$\log 2 \approx 0.693$ はその手前なので、解は $[0, \log 2]$ で定義されています。）

### ポイント

- ベルヌーイ型 $y' + P(x)y = Q(x)y^{n}$ は、$u = y^{1-n}$ とおくと $u' + (1-n)P(x)u = (1-n)Q(x)$ という線形方程式になります。ここでは $n = 2$ なので $u = y^{-1}$ です。
- 置き換えたあと右辺の符号（$1 - n = -1$ 倍）を落として $u' + u = e^{x}$ とすると、$u = \dfrac{3}{2}e^{-x} + \dfrac{e^x}{2}$ となり答えが $\dfrac{4}{7}$ にずれます。
- 非線形の方程式の解は、初期値によって有限の $x$ で発散（爆発）することがあります。値を求める点が解の存在区間に入っているかを確認します。
