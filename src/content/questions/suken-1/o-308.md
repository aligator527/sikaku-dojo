stem: |
  確率変数 $X, Y$ は独立で、それぞれパラメータ $\lambda, \mu$（$\lambda > 0,\ \mu > 0$）のポアソン分布に従う。次の問いに答えよ。

  (1) $X + Y$ はパラメータ $\lambda + \mu$ のポアソン分布に従うことを示せ。

  (2) $0$ 以上の整数 $n$ に対して、$X + Y = n$ という条件のもとでの $X$ の条件付き分布を求めよ。また、条件付き期待値 $E[X \mid X + Y = n]$ を求めよ。
modelAnswer: |
  **(1)** $0$ 以上の整数 $n$ に対して、$X, Y$ の独立性から

  $$P(X + Y = n) = \sum_{k=0}^{n} P(X = k)\,P(Y = n-k) = \sum_{k=0}^{n} e^{-\lambda}\frac{\lambda^k}{k!}\cdot e^{-\mu}\frac{\mu^{n-k}}{(n-k)!}.$$

  $\dfrac{1}{k!\,(n-k)!} = \dfrac{1}{n!}\dbinom{n}{k}$ と二項定理を使うと

  $$P(X + Y = n) = \frac{e^{-(\lambda+\mu)}}{n!}\sum_{k=0}^{n}\binom{n}{k}\lambda^k\mu^{n-k} = e^{-(\lambda+\mu)}\frac{(\lambda+\mu)^n}{n!}.$$

  これはパラメータ $\lambda + \mu$ のポアソン分布の確率関数である。

  **(2)** $k = 0, 1, \dots, n$ に対して、事象 $\{X = k,\ X + Y = n\}$ は $\{X = k,\ Y = n - k\}$ と同じなので、独立性と (1) より

  $$P(X = k \mid X + Y = n) = \frac{P(X = k)\,P(Y = n-k)}{P(X + Y = n)} = \frac{e^{-\lambda}\dfrac{\lambda^k}{k!}\cdot e^{-\mu}\dfrac{\mu^{n-k}}{(n-k)!}}{e^{-(\lambda+\mu)}\dfrac{(\lambda+\mu)^n}{n!}} = \binom{n}{k}\left(\frac{\lambda}{\lambda+\mu}\right)^{k}\left(\frac{\mu}{\lambda+\mu}\right)^{n-k}.$$

  $k > n$ のときは条件付き確率は $0$ である。よって、$X + Y = n$ のもとで $X$ は二項分布 $B\!\left(n, \dfrac{\lambda}{\lambda+\mu}\right)$ に従う。二項分布の期待値の公式より

  $$E[X \mid X + Y = n] = \frac{n\lambda}{\lambda + \mu}.$$

  - '(2) 条件付き確率の定義に従い、分母に (1) の結果を用いている'

ポアソン分布の再生性と、和で条件付けると二項分布が現れるという、ポアソン分布の 2 つの基本性質を示す問題です。どちらも、独立性から同時確率を積に分け、二項係数の形に整理するのが鍵です。

### 証明の組み立て

1. **(1) 畳み込み** 和が $n$ になる組 $(k, n-k)$ について確率を足し合わせます。$\dfrac{n!}{k!(n-k)!}$ を作るために $n!$ を掛けて割るのがポイントです。
2. **別解（確率母関数）** $G_X(s) = E[s^X] = e^{\lambda(s-1)}$ なので、独立性から $G_{X+Y}(s) = G_X(s)G_Y(s) = e^{(\lambda+\mu)(s-1)}$ となり、確率母関数が分布を決めることから (1) が従います。
3. **(2) 条件付き分布** 分子の事象を $\{X = k, Y = n-k\}$ と書き直すと独立性が使えます。$e^{-\lambda}e^{-\mu}$ が分母と打ち消し合い、二項分布の形が残ります。

### ポイント

- ポアソン過程の言葉では「2 種類の到着を合わせた総数が $n$ のとき、そのうち一方の種類の数は $B\bigl(n, \frac{\lambda}{\lambda+\mu}\bigr)$」という意味になります。逆に、ポアソン分布に従う個数を確率 $p$ で振り分けると、独立なポアソン分布 $\mathrm{Po}(\lambda p)$ と $\mathrm{Po}(\lambda(1-p))$ に分かれます。
- 条件付き分布を求める問題では、分母 $P(X+Y=n)$ を (1) の結果で書けることを利用します。分母を求めずに比だけで議論すると、確率の和が $1$ になる確認が抜けやすくなります。
- 再生性は二項分布（同じ $p$）、正規分布、ガンマ分布（同じ尺度）でも成り立ちます。
