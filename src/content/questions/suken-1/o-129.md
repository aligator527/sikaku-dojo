stem: |
  $p > 0,\ q > 0$ に対してベータ関数を $B(p, q) = \displaystyle\int_0^1 t^{p-1}(1-t)^{q-1}\,dt$ で定める。次の 2 つの公式は証明なしに用いてよい。

  $$B(p, q) = \frac{\Gamma(p)\,\Gamma(q)}{\Gamma(p+q)},\qquad \Gamma(s)\,\Gamma(1-s) = \frac{\pi}{\sin \pi s} \quad (0 < s < 1)$$

  (1) $B(p, q) = 2\displaystyle\int_0^{\frac{\pi}{2}} \sin^{2p-1}\theta\,\cos^{2q-1}\theta\,d\theta$ を示せ。

  (2) 広義積分 $\displaystyle\int_0^{\frac{\pi}{2}} \sqrt{\tan\theta}\,d\theta$ の値を求めよ。

  (3) 広義積分 $\displaystyle\int_0^{\infty} \frac{\sqrt{x}}{1 + x^{2}}\,dx$ の値を求めよ。
modelAnswer: |
  **(1)** $t = \sin^2\theta$（$0 \le \theta \le \tfrac{\pi}{2}$）と置換すると、$1 - t = \cos^2\theta$、$dt = 2\sin\theta\cos\theta\,d\theta$ で、$t: 0 \to 1$ に $\theta: 0 \to \tfrac{\pi}{2}$ が対応する。よって

  $$B(p, q) = \int_0^{\pi/2}\sin^{2p-2}\theta\,\cos^{2q-2}\theta\cdot 2\sin\theta\cos\theta\,d\theta = 2\int_0^{\pi/2}\sin^{2p-1}\theta\,\cos^{2q-1}\theta\,d\theta.$$

  （$p, q > 0$ なので両辺の広義積分はともに収束する。）

  **(2)** $\sqrt{\tan\theta} = \sin^{1/2}\theta\,\cos^{-1/2}\theta$ である。$2p - 1 = \tfrac12,\ 2q - 1 = -\tfrac12$ より $p = \tfrac34,\ q = \tfrac14$（ともに正なので収束する）。(1) と与えられた公式、$\Gamma(1) = 1$ より

  $$\int_0^{\pi/2}\sqrt{\tan\theta}\,d\theta = \frac12 B\!\left(\frac34, \frac14\right) = \frac12\cdot\frac{\Gamma(\frac34)\Gamma(\frac14)}{\Gamma(1)} = \frac12\cdot\frac{\pi}{\sin\frac{\pi}{4}} = \frac12\cdot\frac{\pi}{\frac{\sqrt2}{2}} = \frac{\pi}{\sqrt2}.$$

  **(3)** $x = \tan\theta$（$0 \le \theta < \tfrac{\pi}{2}$）と置換すると $dx = \dfrac{d\theta}{\cos^2\theta}$、$1 + x^2 = \dfrac{1}{\cos^2\theta}$ だから $\dfrac{dx}{1+x^2} = d\theta$ であり

  $$\int_0^{\infty}\frac{\sqrt{x}}{1 + x^{2}}\,dx = \int_0^{\pi/2}\sqrt{\tan\theta}\,d\theta = \frac{\pi}{\sqrt2} = \frac{\sqrt2}{2}\pi \ (\approx 2.2214).$$
rubric:

$\sqrt{\tan\theta}$ は $\sin$ と $\cos$ のべきの積なので、ベータ関数の三角関数表示 (1) が使えます。$p + q = 1$ となるため $\Gamma(p+q) = 1$ となり、相補公式で $\Gamma(\tfrac34)\Gamma(\tfrac14) = \sqrt2\,\pi$ と計算できます。値は $\dfrac{\pi}{\sqrt2}$ です。

### 解答の組み立て

1. **三角関数表示** $t = \sin^2\theta$ の置換で、$t^{p-1}(1-t)^{q-1}$ が $\sin^{2p-2}\theta\cos^{2q-2}\theta$ に、$dt$ が $2\sin\theta\cos\theta\,d\theta$ になり、指数が 1 ずつ上がります。
2. **パラメータの読み取り** 指数 $\tfrac12 = 2p - 1$、$-\tfrac12 = 2q - 1$ から $p, q$ を求めます。係数 $\tfrac12$（(1) の右辺の $2$ の逆数）を忘れないことが大切です。
3. **相補公式** $\Gamma(\tfrac34)$ や $\Gamma(\tfrac14)$ は単独では簡単な値になりませんが、積は $\dfrac{\pi}{\sin(\pi/4)}$ と求まります。

### ポイント

- 一般に $\displaystyle\int_0^{\pi/2}\tan^{a}\theta\,d\theta = \frac{\pi}{2\cos(\pi a/2)}$（$-1 < a < 1$）です。$a = \tfrac12$ で $\dfrac{\pi}{2\cdot\frac{\sqrt2}{2}} = \dfrac{\pi}{\sqrt2}$ となり、検算に使えます。
- (3) はさらに $x = u^2$ とおくと $2\displaystyle\int_0^\infty\frac{u^2}{1+u^4}\,du$ となり、留数定理でも同じ値が得られます。
- $\theta \to \tfrac{\pi}{2}$ で $\sqrt{\tan\theta} \to \infty$ となる広義積分ですが、$\cos^{-1/2}\theta$ 程度の発散なので収束します（$q = \tfrac14 > 0$ に対応）。
