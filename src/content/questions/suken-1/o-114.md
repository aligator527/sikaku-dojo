媒介変数表示の曲率の公式 $\kappa = \dfrac{|\dot x\ddot y - \dot y\ddot x|}{(\dot x^2 + \dot y^2)^{3/2}}$ を使います。サイクロイドの曲率半径は $4\sin\dfrac t2$ と簡単な形になり、$t = \dfrac{\pi}{3}$ では $4\sin\dfrac{\pi}{6} = 2$ です。

### 計算

$$\dot x = 1 - \cos t,\quad \dot y = \sin t,\quad \ddot x = \sin t,\quad \ddot y = \cos t.$$

分子は

$$\dot x\ddot y - \dot y\ddot x = (1 - \cos t)\cos t - \sin^2 t = \cos t - 1.$$

分母は、$\dot x^2 + \dot y^2 = 2 - 2\cos t = 4\sin^2\dfrac t2$ より

$$(\dot x^2 + \dot y^2)^{3/2} = 8\sin^3\frac t2 \quad (0 < t < 2\pi \text{ で } \sin\tfrac t2 > 0).$$

$|\cos t - 1| = 2\sin^2\dfrac t2$ なので

$$\kappa = \frac{2\sin^2(t/2)}{8\sin^3(t/2)} = \frac{1}{4\sin(t/2)},\qquad R = \frac{1}{\kappa} = 4\sin\frac t2.$$

$t = \dfrac{\pi}{3}$ のとき $R = 4\sin\dfrac{\pi}{6} = 2$ です。

### ポイント

- 曲率の公式の分母は $(\dot x^2 + \dot y^2)^{3/2}$ です。指数を $\tfrac12$ や $1$ にしてしまう誤りがよく見られます。
- $y = f(x)$ の形なら $\kappa = \dfrac{|f''|}{(1 + f'^2)^{3/2}}$ です。媒介変数表示の公式から $x = t$ とおけば導けます。
- サイクロイドの曲率半径 $4\sin\dfrac t2$ は、頂点（$t = \pi$）で最大値 $4$ をとり、円の直径 $2$ の 2 倍になります。
