$y$ の $x$ への回帰係数 $b_{y\cdot x} = r\dfrac{s_y}{s_x}$ と、$x$ の $y$ への回帰係数 $b_{x\cdot y} = r\dfrac{s_x}{s_y}$ の積は $r^2$ です。$r^2 \le 1$ という条件から 2 直線の役割が決まり、$r^2 = 0.49$、傾きが正なので $r = 0.7$ です。

### 計算

**割り当て A**：$7x - 5y + 15 = 0$ を $y$ の $x$ への回帰直線とすると $y = \tfrac75 x + 3$ で $b_{y\cdot x} = \tfrac75$。もう一方を $x$ について解くと $x = \tfrac{7}{20}y + \tfrac32$ で $b_{x\cdot y} = \tfrac{7}{20}$。

$$r^2 = b_{y\cdot x}\,b_{x\cdot y} = \frac75\cdot\frac{7}{20} = \frac{49}{100} \le 1.$$

**割り当て B**：逆に $20x - 7y - 30 = 0$ を $y$ の $x$ への回帰直線とすると $b_{y\cdot x} = \tfrac{20}{7}$、$7x - 5y + 15 = 0$ から $b_{x\cdot y} = \tfrac57$ となり、積は $\tfrac{100}{49} > 1$ です。$r^2 \le 1$ に反するので、この割り当てはありえません。

よって割り当て A が正しく、$r^2 = 0.49$。2 つの回帰係数はともに正なので $r > 0$ で、$r = 0.7$ です。

（参考：2 直線の交点 $(5, 10)$ が平均 $(\bar x, \bar y)$ で、$\dfrac{s_y}{s_x} = \dfrac{b_{y\cdot x}}{r} = 2$ です。）

### ポイント

- $b_{y\cdot x} = \dfrac{S_{xy}}{S_{xx}}$、$b_{x\cdot y} = \dfrac{S_{xy}}{S_{yy}}$ なので、$b_{y\cdot x}\,b_{x\cdot y} = \dfrac{S_{xy}^2}{S_{xx}S_{yy}} = r^2$ です。
- $r$ の符号は回帰係数の符号と一致します。$r^2$ から平方根をとるときに符号を決める根拠を示します。
- $x$ の $y$ への回帰係数は「$x$ について解いたときの $y$ の係数」です。$xy$ 平面上での傾き（$\tfrac{20}{7}$）をそのまま使うと $r^2 = \tfrac75\cdot\tfrac{20}{7} = 4$ となり、明らかに誤りです。
