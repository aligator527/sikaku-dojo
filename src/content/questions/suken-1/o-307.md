指数分布には「すでに $a$ だけ待ったという条件のもとで、残りの待ち時間はまた同じ指数分布に従う」という無記憶性があります。したがって $X \mid X > a$ は $a + (\text{平均 } \tfrac1\lambda \text{ の指数分布})$ と同じ分布で、期待値は $a + \dfrac1\lambda$ です。

### 計算

$P(X > a) = e^{-\lambda a}$ です。部分積分により

$$E[X;\ X > a] = \int_a^\infty x\,\lambda e^{-\lambda x}\,dx = \Bigl[-x e^{-\lambda x}\Bigr]_a^\infty + \int_a^\infty e^{-\lambda x}\,dx = a e^{-\lambda a} + \frac{1}{\lambda}e^{-\lambda a}.$$

条件付き期待値はこれを $P(X > a)$ で割ったものなので

$$E[X \mid X > a] = \frac{\left(a + \frac1\lambda\right)e^{-\lambda a}}{e^{-\lambda a}} = a + \frac1\lambda.$$

### 各選択肢の検討

1. 誤り。「残りの待ち時間」$X - a$ の条件付き期待値です。すでに待った $a$ を足していません。
2. 正しい。
3. 誤り。密度 $\lambda e^{-\lambda x}$ の平均を $\lambda$ と取り違えています。平均は $\tfrac1\lambda$ です。
4. 誤り。$E[X;\ X > a] = \int_a^\infty x f(x)\,dx$ の値で、条件付き期待値にするための $P(X > a)$ による割り算を忘れています。

### ポイント

- 無記憶性 $P(X > a + t \mid X > a) = P(X > t)$ を満たす連続分布は指数分布だけです（離散では幾何分布）。
- 条件付き期待値は $E[X \mid A] = \dfrac{E[X;\,A]}{P(A)}$ です。分母を忘れる誤りに注意します。
