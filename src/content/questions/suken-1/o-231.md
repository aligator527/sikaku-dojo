元の問題の最適解は、原料 A と原料 B の制約がともに等号となる $(x, y) = (2, 6)$（利益 36000 円）です。この 2 つの制約が等号のままという構造は在庫を 15 kg にしても変わらず、最大利益の増加量は原料 A の双対変数（シャドウプライス）$2250$ 円に等しくなります。

### 計算

P を $x$ 個、Q を $y$ 個とすると、問題は

$$\text{最大化 } 3000x + 5000y,\quad x + 2y \le 14,\ \ 3x + 2y \le 18,\ \ x \le 5,\ \ x, y \ge 0.$$

**元の最適解** 頂点 $(0, 7)$、$(2, 6)$、$\left(5, \tfrac32\right)$、$(5, 0)$、$(0, 0)$ での利益はそれぞれ $35000$、$36000$、$22500$、$15000$、$0$ 円で、最適解は $x + 2y = 14$ と $3x + 2y = 18$ の交点 $(2, 6)$、最大利益は $36000$ 円です。

**双対変数** 等号となる 2 つの制約の双対変数 $u_A, u_B$ は

$$u_A + 3u_B = 3000,\qquad 2u_A + 2u_B = 5000$$

を満たし、$u_A = 2250$、$u_B = 250$ です（ともに正なので双対実行可能）。

**在庫を 15 kg にした場合** $x + 2y = 15$ と $3x + 2y = 18$ の交点は $(x, y) = \left(\tfrac32, \tfrac{27}{4}\right)$ で、$x \le 5$ も満たします。新しい頂点 $\left(0, \tfrac{15}{2}\right)$ の利益 $37500$ 円よりも大きく、

$$3000\cdot\frac32 + 5000\cdot\frac{27}{4} = 4500 + 33750 = 38250\ \text{円}.$$

増加量は $38250 - 36000 = 2250$ 円で、$u_A$ と一致します。

### ポイント

- 最適基底（等号となる制約の組）が変わらない範囲では、右辺 $b_i$ を $1$ 増やしたときの最適値の増加量は双対変数 $u_i$ に等しくなります。これが「原料 A を 1 kg あたり 2250 円までなら追加購入してよい」という経済的な意味です。
- 右辺を大きく変えると最適な頂点の構造が変わり、増加率も変わります。ここでは $x = \tfrac32 \ge 0$ なので、構造は保たれています（在庫 A が 18 kg を超えると $x < 0$ となり、構造が変わります）。
- 余裕のある制約（ここでは $x \le 5$）の双対変数は $0$ です（相補性条件）。
