  2 変量 $x, y$ のデータについて、$y$ の $x$ への回帰直線の傾きを $b\ (b \neq 0)$ とする。各データを

  $$u = -2x + 3,\qquad v = 3y - 1$$

回帰直線の傾きは「共分散 $\div$ 説明変数の分散」です。1 次変換で共分散は係数の積 $(-2)\cdot 3 = -6$ 倍、$u$ の分散は $(-2)^2 = 4$ 倍になるので、傾きは $-\tfrac64 b = -\tfrac32 b$ です。

### 計算

定数項 $+3,\ -1$ は偏差に影響しないので

$$s_{uv} = (-2)\cdot 3\cdot s_{xy} = -6s_{xy},\qquad s_u^2 = (-2)^2 s_x^2 = 4s_x^2.$$

よって

$$\frac{s_{uv}}{s_u^2} = \frac{-6s_{xy}}{4s_x^2} = -\frac32\cdot\frac{s_{xy}}{s_x^2} = -\frac32 b.$$

### 各選択肢の検討

1. 誤り。比が逆です（$u$ の係数 $-2$ を $v$ の係数 $3$ で割った値）。傾きは「$v$ 方向の倍率 $\div$ $u$ 方向の倍率」で $\tfrac{3}{-2}$ 倍になります。
2. 誤り。$u$ の係数 $-2$ の符号を落としています。$x$ と $u$ の大小が逆転するので、傾きの符号も反転します。
3. 誤り。共分散の変化（$-6$ 倍）だけを考え、分母の分散が $4$ 倍になることを忘れています。
4. 正しい。

### ポイント

- 一般に $u = px + q,\ v = ry + s$ のとき、$v$ の $u$ への回帰係数は $\dfrac{r}{p}b$ です。
- 相関係数は $r_{uv} = \operatorname{sgn}(pr)\,r_{xy}$ で、大きさは変わりません。回帰係数と相関係数で変換の影響が異なる点を区別します。
