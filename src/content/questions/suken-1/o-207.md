modelAnswer: |
  **分枝と関数** $z = re^{i\theta}\ (r > 0,\ 0 < \theta < 2\pi)$ に対して $z^{1/2} = \sqrt{r}\,e^{i\theta/2}$ と定める。これは正の実軸を除いた領域で正則である。

  $$f(z) = \frac{z^{1/2}}{(z+1)^{2}}$$

  とおく。

  **積分路** $0 < \varepsilon < 1 < R$ として、次の 4 つをつないだ閉曲線（鍵穴型の積分路）$\Gamma$ をとる。

  - $L_{+}$：正の実軸の上側を $\varepsilon$ から $R$ へ（$\theta = 0$ 側）
  - $C_{R}$：円 $|z| = R$ を正の向きに 1 周
  - $L_{-}$：正の実軸の下側を $R$ から $\varepsilon$ へ（$\theta = 2\pi$ 側）
  - $C_{\varepsilon}$：円 $|z| = \varepsilon$ を負の向きに 1 周

  **留数** $\Gamma$ の内部にある特異点は $z = -1 = e^{i\pi}$ だけで、2 位の極である。

  $$\operatorname*{Res}_{z=-1} f = \left.\frac{d}{dz}z^{1/2}\right|_{z=e^{i\pi}} = \frac12\left(e^{i\pi}\right)^{-1/2} = \frac12 e^{-i\pi/2} = -\frac{i}{2}.$$

  **実軸上の積分** $L_{+}$ 上では $z^{1/2} = \sqrt{x}$、$L_{-}$ 上では $z^{1/2} = \sqrt{x}\,e^{i\pi} = -\sqrt{x}$ だから

  $$\int_{L_{+}} f\,dz + \int_{L_{-}} f\,dz = \int_{\varepsilon}^{R}\frac{\sqrt{x}}{(x+1)^{2}}\,dx + \int_{R}^{\varepsilon}\frac{-\sqrt{x}}{(x+1)^{2}}\,dx = 2\int_{\varepsilon}^{R}\frac{\sqrt{x}}{(x+1)^{2}}\,dx.$$

  **円周上の評価** $|z| = R$ では $|z+1| \ge R - 1$、$|z| = \varepsilon$ では $|z+1| \ge 1 - \varepsilon$ なので

  $$\left|\int_{C_{R}} f\,dz\right| \le 2\pi R\cdot\frac{R^{1/2}}{(R-1)^{2}} \to 0\ (R\to\infty),\qquad \left|\int_{C_{\varepsilon}} f\,dz\right| \le 2\pi\varepsilon\cdot\frac{\varepsilon^{1/2}}{(1-\varepsilon)^{2}} \to 0\ (\varepsilon\to 0).$$

  **結論** 留数定理より

  $$2\int_{\varepsilon}^{R}\frac{\sqrt{x}}{(x+1)^{2}}\,dx + \int_{C_{R}} f\,dz + \int_{C_{\varepsilon}} f\,dz = 2\pi i\cdot\left(-\frac{i}{2}\right) = \pi.$$

  $\varepsilon \to 0,\ R \to \infty$ として $2I = \pi$、すなわち

  $$I = \frac{\pi}{2}.$$

多価関数 $\sqrt z$ を含む積分は、正の実軸に沿って切れ目（分枝切断）を入れた鍵穴型の積分路で扱うのが定石です。切れ目の上下で $\sqrt z$ の値が符号だけ異なるので、上下の積分が打ち消し合わずに $2I$ として残り、$I = \dfrac{\pi}{2}$ が得られます。

### 計算の要点

- **偏角の扱い** 留数を計算するとき、$-1$ を $e^{i\pi}$ と表すのは分枝を $0 < \theta < 2\pi$ と定めたからです。$-1 = e^{-i\pi}$ とすると $(-1)^{-1/2} = e^{i\pi/2} = i$ となり、符号が逆になって $I = -\dfrac{\pi}{2}$ という矛盾した値（正の関数の積分が負）が出ます。
- **2 位の極** $(z+1)^{2} f(z) = z^{1/2}$ を 1 回微分するだけで留数が求まります。
- **上下の辺** 下側では偏角が $2\pi$ なので $e^{i\cdot 2\pi/2} = -1$ 倍になり、さらに向きが逆なので、符号が 2 回反転して上側と同じ積分になります。

### 検算

$x = t^{2}$ と置換すると $I = \displaystyle\int_0^{\infty}\frac{2t^{2}}{(t^{2}+1)^{2}}\,dt$ となり、部分積分で $\left[-\dfrac{t}{t^2+1}\right]_0^\infty + \displaystyle\int_0^\infty\frac{dt}{t^2+1} = \frac{\pi}{2}$ と一致します。ベータ関数を使えば $I = B\left(\tfrac32, \tfrac12\right) = \dfrac{\Gamma(\frac32)\Gamma(\frac12)}{\Gamma(2)} = \dfrac{\pi}{2}$ です。

### ポイント

- 一般に $0 < a < 2$ のとき $\displaystyle\int_0^\infty \frac{x^{a-1}}{(x+1)^{2}}\,dx = \frac{(1-a)\pi}{\sin \pi a}$ で、$a = \tfrac32$ とすると $\dfrac{\pi}{2}$ になります。
- 小さい円 $C_\varepsilon$ の評価を省略する答案が多いので、$z = 0$ の近くで被積分関数が $|z|^{1/2}$ 程度に抑えられることを必ず書きます。
- 半円の積分路では切れ目の上下が作れないため、$\sqrt z$ を含む積分には使えません。
