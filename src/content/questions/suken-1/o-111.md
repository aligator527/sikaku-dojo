$e^{x}\sin x = \operatorname{Im} e^{(1+i)x}$ と見ると、$n$ 回微分は $(1+i)^n$ を掛ける操作になります。$(1+i)^{10} = (\sqrt2)^{10}e^{10\pi i/4} = 32i$ なので $f^{(10)}(0) = 32$ です。

### 計算

$1 + i = \sqrt2\,e^{i\pi/4}$ より

$$f^{(n)}(x) = \operatorname{Im}\left[(1+i)^n e^{(1+i)x}\right] = 2^{n/2}e^{x}\sin\left(x + \frac{n\pi}{4}\right).$$

$n = 10$、$x = 0$ を代入すると

$$f^{(10)}(0) = 2^{5}\sin\frac{10\pi}{4} = 32\sin\frac{5\pi}{2} = 32.$$

**別解（実数の範囲で）** $f'(x) = e^x(\sin x + \cos x) = \sqrt2\,e^x\sin\left(x + \dfrac{\pi}{4}\right)$ なので、1 回微分するごとに「$\sqrt2$ 倍して位相を $\dfrac{\pi}{4}$ 進める」ことになります。10 回で $(\sqrt2)^{10} = 32$ 倍、位相は $\dfrac{10\pi}{4} = 2\pi + \dfrac{\pi}{2}$ 進みます。

### ポイント

- $e^{ax}\sin bx$、$e^{ax}\cos bx$ の高次導関数は、$a + bi = re^{i\varphi}$ として $r^n e^{ax}\sin(bx + n\varphi)$ の形になります。
- ライプニッツの公式で $\sum \binom{10}{k}\sin^{(k)}(0)$ を計算しても $\binom{10}{1} - \binom{10}{3} + \binom{10}{5} - \binom{10}{7} + \binom{10}{9} = 10 - 120 + 252 - 120 + 10 = 32$ となり、検算できます。
- 位相 $\dfrac{n\pi}{4}$ を $\dfrac{n\pi}{2}$ と取り違える（$\sin$ 単独の導関数の公式と混同する）誤りに注意します。
