  $a > 0$ とする。球 $x^{2} + y^{2} + z^{2} \le a^{2}$ のうち、円柱 $x^{2} + y^{2} \le ax$ の内部にある部分の体積 $V$ を求めよ。
modelAnswer: |
  円柱の底面にあたる領域を $D = \{(x, y) \mid x^{2} + y^{2} \le ax\}$ とする。$D$ の各点で球の内部は $|z| \le \sqrt{a^2 - x^2 - y^2}$ なので（$D$ は円板 $x^2 + y^2 \le a^2$ に含まれる）、

  $$V = \iint_D 2\sqrt{a^{2} - x^{2} - y^{2}}\,dx\,dy.$$

  極座標 $x = r\cos\theta,\ y = r\sin\theta$ に変換すると、$x^2 + y^2 \le ax$ は $r \le a\cos\theta$ となり、$D$ は

  $$-\frac{\pi}{2} \le \theta \le \frac{\pi}{2},\qquad 0 \le r \le a\cos\theta$$

  に対応する。$dx\,dy = r\,dr\,d\theta$ より

  $$V = 2\int_{-\pi/2}^{\pi/2}\int_0^{a\cos\theta}\sqrt{a^{2} - r^{2}}\;r\,dr\,d\theta.$$

  内側の積分は

  $$\int_0^{a\cos\theta}\sqrt{a^{2} - r^{2}}\;r\,dr = \Bigl[-\frac13(a^{2} - r^{2})^{3/2}\Bigr]_0^{a\cos\theta} = \frac13\left\{a^{3} - (a^{2}\sin^{2}\theta)^{3/2}\right\} = \frac{a^{3}}{3}\left(1 - |\sin\theta|^{3}\right).$$

  被積分関数は $\theta$ について偶関数なので

  $$V = \frac{2a^{3}}{3}\int_{-\pi/2}^{\pi/2}\left(1 - |\sin\theta|^{3}\right)d\theta = \frac{4a^{3}}{3}\int_0^{\pi/2}\left(1 - \sin^{3}\theta\right)d\theta.$$

  $\displaystyle\int_0^{\pi/2}\sin^3\theta\,d\theta = \frac23$ だから

  $$V = \frac{4a^{3}}{3}\left(\frac{\pi}{2} - \frac23\right) = \frac{2}{9}(3\pi - 4)\,a^{3} \ (\approx 1.2055\,a^{3}).$$
rubric:
  - 体積を $D$ 上の $2\sqrt{a^2 - x^2 - y^2}$ の重積分として正しく立式している
  - 極座標で $D$ を $-\pi/2 \le \theta \le \pi/2$、$0 \le r \le a\cos\theta$ と表し、ヤコビアン $r$ を付けている
  - $(a^2\sin^2\theta)^{3/2} = a^3|\sin\theta|^3$ と絶対値を正しく扱っている

円柱 $x^2 + y^2 \le ax$ は、中心 $\left(\dfrac a2, 0\right)$、半径 $\dfrac a2$ の円を底面とする円柱で、球の中心を通って球面に内接しています（ヴィヴィアーニの問題）。極座標で $r \le a\cos\theta$ と表すと積分が計算でき、$V = \dfrac29(3\pi - 4)a^3$ です。

### 計算の要点

- **立式** 上下対称なので、上半分 $z \ge 0$ の体積の 2 倍として $2\sqrt{a^2 - x^2 - y^2}$ を積分します。
- **積分領域** $r^2 \le ar\cos\theta$ から $r \le a\cos\theta$ で、$\cos\theta \ge 0$ となる $-\dfrac{\pi}{2} \le \theta \le \dfrac{\pi}{2}$ が範囲です。
- **絶対値** $(a^2 - a^2\cos^2\theta)^{3/2} = (a^2\sin^2\theta)^{3/2} = a^3|\sin\theta|^3$ です。絶対値を外して $\sin^3\theta$ のまま $-\dfrac\pi2$ から $\dfrac\pi2$ まで積分すると、奇関数の積分が $0$ になって $V = \dfrac{2\pi}{3}a^3$（半球の体積）という誤った値になります。

### ポイント

- 対称性を使って $0 \le \theta \le \dfrac{\pi}{2}$ の部分を 2 倍すれば、絶対値の扱いを避けられます。
- 答えの妥当性は、球の体積 $\dfrac43\pi a^3 \approx 4.19a^3$ や円柱部分（高さ $2a$ 以下、底面積 $\dfrac{\pi a^2}{4}$）の体積 $\dfrac{\pi}{2}a^3 \approx 1.57a^3$ より小さいことで確かめられます。
- 球から 2 つの円柱 $x^2 + y^2 \le \pm ax$ の部分をくり抜いた残りの体積は $\dfrac43\pi a^3 - 2V = \dfrac{16}{9}a^3$ となり、$\pi$ を含まない値になることが知られています。
