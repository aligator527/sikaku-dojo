右辺の $\sin 2x$ は同次方程式の解そのもの（共鳴）なので、特殊解は $x(A\cos 2x + B\sin 2x)$ とおきます。解は $y = \sin 2x - 2x\cos 2x$ で、$y\!\left(\dfrac{\pi}{2}\right) = 0 - \pi\cdot(-1) = \pi \approx 3.142$ です。

### 計算

**同次方程式** 特性方程式 $\lambda^2 + 4 = 0$ より $\lambda = \pm 2i$。一般解は $C_1\cos 2x + C_2\sin 2x$ です。

**特殊解** 右辺 $8\sin 2x$ の $2i$ は特性根なので、$y_p = x(A\cos 2x + B\sin 2x)$ とおきます。

$$y_p'' = 2(-2A\sin 2x + 2B\cos 2x) + x(-4A\cos 2x - 4B\sin 2x)$$

なので

$$y_p'' + 4y_p = -4A\sin 2x + 4B\cos 2x = 8\sin 2x \quad\Longrightarrow\quad A = -2,\ B = 0.$$

よって $y_p = -2x\cos 2x$ です。

**初期条件** $y = C_1\cos 2x + C_2\sin 2x - 2x\cos 2x$ に対し

$$y(0) = C_1 = 0,\qquad y'(0) = 2C_2 - 2 = 0 \quad\Longrightarrow\quad C_2 = 1.$$

よって $y(x) = \sin 2x - 2x\cos 2x$。$x = \dfrac{\pi}{2}$ では $\sin\pi = 0$、$\cos\pi = -1$ なので

$$y\!\left(\frac{\pi}{2}\right) = 0 - 2\cdot\frac{\pi}{2}\cdot(-1) = \pi = 3.14159\cdots.$$

小数第4位を四捨五入して $3.142$ です。

### ポイント

- 共鳴の場合に $y_p = A\cos 2x + B\sin 2x$ とおくと、左辺が $0$ になって係数が決まりません。$x$ を掛けた形にします。
- 共鳴解 $-2x\cos 2x$ は振幅が $x$ に比例して増大します。外力の振動数が固有振動数と一致すると振幅が際限なく大きくなる、という物理的な共鳴現象に対応します。
- 複素数を使って $y'' + 4y = 8e^{2ix}$ の特殊解 $\dfrac{8}{4i}xe^{2ix} = -2ix\,e^{2ix}$ を求め、虚部 $-2x\cos 2x$ をとっても同じ結果が得られます。
