曲面 $F(x, y, z) = 0$ の点 $\mathrm{P}$ における接平面の法線ベクトルは、勾配 $\nabla F(\mathrm{P})$ です。接平面は $x + 2y + 3z = 6$ となり、3 つの切片は $6, 3, 2$ なので、体積は $\dfrac16\cdot6\cdot3\cdot2 = 6$ です。

### 計算

$F(x, y, z) = x^2 + 2y^2 + 3z^2 - 6$ とおくと

$$\nabla F = (2x,\ 4y,\ 6z),\qquad \nabla F(1, 1, 1) = (2,\ 4,\ 6).$$

点 $(1, 1, 1)$ における接平面は

$$2(x - 1) + 4(y - 1) + 6(z - 1) = 0 \iff x + 2y + 3z = 6.$$

座標軸との交点は $\mathrm{A}(6, 0, 0)$、$\mathrm{B}(0, 3, 0)$、$\mathrm{C}(0, 0, 2)$ です。$\mathrm{OA}, \mathrm{OB}, \mathrm{OC}$ は互いに直交するので

$$V = \frac13\cdot\left(\frac12\cdot 6\cdot 3\right)\cdot 2 = 6.$$

### ポイント

- 2 次曲面 $ax^2 + by^2 + cz^2 = d$ 上の点 $(x_0, y_0, z_0)$ における接平面は $ax_0x + by_0y + cz_0z = d$ です（$x^2 \to x_0x$ と置き換える）。
- $z = f(x, y)$ の形に解いてから $z - z_0 = f_x(x - x_0) + f_y(y - y_0)$ を使うこともできますが、陰関数のまま勾配を使う方が計算が短く済みます。
- 四面体の体積は $\dfrac16 abc$（$a, b, c$ は切片）です。$\dfrac13$ や $\dfrac12$ と取り違えないようにします。
