相関のある正規分布を独立な標準正規分布 $Z_1, Z_2$ で表すと、$(Z_1, Z_2)$ の分布は原点のまわりの回転で変わらないので、確率は「条件を満たす偏角の範囲 $\div\ 2\pi$」で求まります。範囲は $120^\circ$ なので答えは $\tfrac13$ です。

### 計算

$Z_1, Z_2$ を独立な標準正規分布とし

$$X = Z_1,\qquad Y = \frac12 Z_1 + \frac{\sqrt3}{2} Z_2$$

とおくと、$V[Y] = \tfrac14 + \tfrac34 = 1$、$\mathrm{Cov}(X, Y) = \tfrac12$ で、$(X, Y)$ は問題の 2 変量正規分布に従います。

$(Z_1, Z_2) = (R\cos\Theta, R\sin\Theta)$ と極座標で表すと、$(Z_1, Z_2)$ の密度 $\frac{1}{2\pi}e^{-(z_1^2+z_2^2)/2}$ は回転で不変なので、$\Theta$ は $[0, 2\pi)$ 上の一様分布に従います（$R$ と独立）。

- $X > 0 \iff \cos\Theta > 0 \iff -90^\circ < \Theta < 90^\circ$
- $Y = R\left(\tfrac12\cos\Theta + \tfrac{\sqrt3}{2}\sin\Theta\right) = R\cos(\Theta - 60^\circ) > 0 \iff -30^\circ < \Theta < 150^\circ$

共通部分は $-30^\circ < \Theta < 90^\circ$ の $120^\circ$ なので

$$P(X > 0,\ Y > 0) = \frac{120^\circ}{360^\circ} = \frac13.$$

### ポイント

- 一般に、相関係数 $\rho$ の標準 2 変量正規分布では $P(X > 0, Y > 0) = \dfrac14 + \dfrac{\arcsin\rho}{2\pi}$ です。$\rho = \tfrac12$ なら $\dfrac14 + \dfrac{\pi/6}{2\pi} = \dfrac13$ です。
- $\rho = 0$（独立）なら $\tfrac14$、$\rho \to 1$ なら $\tfrac12$ に近づきます。独立と思い込んで $\tfrac14$ と答える誤りが典型です。
- 「独立な標準正規分布の組は回転対称」という性質は、比 $X/Y$ の分布や $X^2 + Y^2$ の分布を求めるときにも使えます。
