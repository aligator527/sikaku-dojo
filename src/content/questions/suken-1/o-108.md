  $$S_p = \sum_{n=2}^{\infty} \frac{1}{n(\log n)^{p}}$$

modelAnswer: |
  $f(x) = \dfrac{1}{x(\log x)^p}$（$x \ge 2$）とおく。$f(x) > 0$ であり

  $$f'(x) = -\frac{(\log x)^{p} + p(\log x)^{p-1}}{x^2(\log x)^{2p}} = -\frac{\log x + p}{x^{2}(\log x)^{p+1}} < 0$$

  だから、$f$ は $[2, \infty)$ で正の値をとる狭義単調減少関数である。よって $k \ge 2$ に対し、$k \le x \le k+1$ で $f(k+1) \le f(x) \le f(k)$（等号は端点のみ）が成り立ち、積分すると

  $$f(k+1) < \int_{k}^{k+1} f(x)\,dx < f(k). \qquad (\ast)$$

  **(1)** $(\ast)$ を $k = 2, \ldots, N-1$ について加えると

  $$\sum_{n=3}^{N} f(n) < \int_2^{N} f(x)\,dx < \sum_{n=2}^{N-1} f(n). \qquad (\ast\ast)$$

  $t = \log x$ と置換すると $dt = dx/x$ なので

  $$\int_2^{N} f(x)\,dx = \int_{\log 2}^{\log N} \frac{dt}{t^{p}} = \begin{cases} \dfrac{(\log 2)^{1-p} - (\log N)^{1-p}}{p-1} & (p \neq 1) \\[2mm] \log(\log N) - \log(\log 2) & (p = 1). \end{cases}$$

  - $p > 1$ のとき：$(\log N)^{1-p} \to 0$ なので積分は $\dfrac{(\log 2)^{1-p}}{p-1}$ に収束する。$(\ast\ast)$ の左の不等式より、正項級数の部分和 $\sum_{n=2}^{N} f(n)$ は $f(2) + \dfrac{(\log 2)^{1-p}}{p-1}$ で上から押さえられ、単調増加かつ有界だから収束する。
  - $p = 1$ のとき：$\log(\log N) \to \infty$。
  - $0 < p < 1$ のとき：$(\log N)^{1-p} \to \infty$ なので積分は $+\infty$ に発散する。

  $p \le 1$ のときは $(\ast\ast)$ の右の不等式より $\sum_{n=2}^{N-1} f(n) \to \infty$ となり、級数は発散する。

  以上より、**$S_p$ が収束するための必要十分条件は $p > 1$** である。

  **(2)** $p = 2$ のとき $\displaystyle\int_{a}^{\infty} f(x)\,dx = \Bigl[-\frac{1}{\log x}\Bigr]_a^{\infty} = \frac{1}{\log a}$ である。$(\ast)$ を $k = 2, 3, \ldots$ について加えると（各項の不等式は狭義なので、和でも狭義のまま）

  $$\sum_{n=3}^{\infty} f(n) < \int_2^{\infty} f(x)\,dx = \frac{1}{\log 2}.$$

  また $(\ast)$ の右の不等式を $k = 3, 4, \ldots$ について加えると

  $$\sum_{n=3}^{\infty} f(n) > \int_3^{\infty} f(x)\,dx = \frac{1}{\log 3}.$$

  $S_2 = f(2) + \sum_{n=3}^{\infty} f(n)$、$f(2) = \dfrac{1}{2(\log 2)^2}$ だから

  $$\frac{1}{2(\log 2)^{2}} + \frac{1}{\log 3} < S_2 < \frac{1}{2(\log 2)^{2}} + \frac{1}{\log 2}. \qquad \text{（証明終）}$$

  （数値では $1.951 < S_2 < 2.483$ であり、実際の値は $S_2 \approx 2.110$ である。）

積分判定法の典型問題です。$f(x) = \dfrac{1}{x(\log x)^p}$ は単調減少なので、級数の部分和は広義積分 $\displaystyle\int_2^\infty f(x)\,dx$ と同時に収束・発散します。置換 $t = \log x$ により積分は $\displaystyle\int \frac{dt}{t^p}$ となり、収束条件は $p > 1$ です。

### 証明の組み立て

1. **単調性の確認** 積分判定法は単調減少の正値関数にしか使えません。まず $f' < 0$ を示します。
2. **区間ごとの比較** $f(k+1) < \displaystyle\int_k^{k+1} f < f(k)$ を足し合わせると、部分和と積分が互いに挟み合う不等式が得られます。左側（$\sum_{n\ge3}$）は収束の証明に、右側（$\sum_{n\le N-1}$）は発散の証明に使います。
3. **積分の計算** $\dfrac{dx}{x} = d(\log x)$ に気付けば、$p$ 級数の積分 $\displaystyle\int t^{-p}\,dt$ と同じ場合分けになります。
4. **(2) の評価** 第 1 項 $f(2)$ を別にして、残りの和を $\displaystyle\int_3^\infty f$ と $\displaystyle\int_2^\infty f$ で挟みます。第 1 項まで含めて積分で挟むと、下からの評価が $\displaystyle\int_2^\infty f$ になり、問題の不等式とは異なる形になります。

### ポイント

- $\sum \dfrac{1}{n^p}$ と同じく、$\sum \dfrac{1}{n(\log n)^p}$ も $p > 1$ で収束、$p \le 1$ で発散します。$p = 1$ の $\sum \dfrac{1}{n\log n}$ は、$\sum \dfrac1n$ よりさらにゆっくり発散する例として有名です。
- 積分判定法で得られる不等式は、和の近似値の誤差評価にもそのまま使えます（2 次では電卓を使って数値を確かめられます）。
- $p = 1$ の場合を $(\log N)^{1-p}/(1-p)$ の式に含めてしまう誤り（分母が 0）に注意し、必ず別に扱います。
