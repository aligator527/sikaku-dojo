$x$ を固定した断面を考えると、$|y| \le \sqrt{1-x^2}$、$|z| \le \sqrt{1-x^2}$ の正方形になります。断面積 $4(1 - x^2)$ を $-1 \le x \le 1$ で積分して、体積は $\dfrac{16}{3}$ です。

### 計算

$-1 \le x \le 1$ を固定すると、断面は

$$\{(y, z) \mid |y| \le \sqrt{1 - x^2},\ |z| \le \sqrt{1 - x^2}\}$$

で、1 辺 $2\sqrt{1-x^2}$ の正方形です。断面積は $S(x) = 4(1 - x^2)$ なので

$$\mathrm{Vol}(V) = \int_{-1}^{1} 4(1 - x^{2})\,dx = 4\left[x - \frac{x^3}{3}\right]_{-1}^{1} = 4\cdot\frac43 = \frac{16}{3}.$$

**別解（重積分）** $D = \{x^2 + y^2 \le 1\}$ 上で、$z$ の範囲は $|z| \le \sqrt{1-x^2}$ なので

$$\mathrm{Vol}(V) = \iint_D 2\sqrt{1 - x^2}\,dx\,dy = \int_{-1}^{1} 2\sqrt{1-x^2}\cdot 2\sqrt{1-x^2}\,dx = \frac{16}{3}.$$

### ポイント

- 2 つの円柱がともに $x$ を含む式なので、$x$ で切ると断面が単純な正方形になります。どの変数で切るかを最初に見極めるのが重要です。
- 断面を円と誤解して $\pi(1 - x^2)$ を積分すると、球の体積 $\dfrac43\pi$ になってしまいます。共通部分の体積は球より大きく、外接する立方体（体積 $8$）より小さいことで検算できます。
- この立体（シュタインメッツの立体）の表面積は $16$ です。
