$z = e^{i\theta}$ とおいて単位円上の複素積分に直し、留数定理を使います。$\cos 2\theta$ を $e^{2i\theta}$ の実部として扱うと、内部の極は $z = \tfrac13$ の 1 つだけになり、積分の値は $\dfrac{\pi}{18}$、すなわち $k = \dfrac{1}{18}$ です。

### 計算

$\cos 2\theta = \operatorname{Re} e^{2i\theta}$ なので $I = \operatorname{Re} J$、$J = \displaystyle\int_0^{2\pi}\frac{e^{2i\theta}}{5 - 3\cos\theta}\,d\theta$ とします。

$z = e^{i\theta}$ とすると $\cos\theta = \dfrac12\left(z + \dfrac1z\right)$、$d\theta = \dfrac{dz}{iz}$ で、

$$5 - 3\cos\theta = \frac{10z - 3z^{2} - 3}{2z} = -\frac{(3z-1)(z-3)}{2z}.$$

したがって

$$J = \oint_{|z|=1} z^{2}\cdot\frac{-2z}{(3z-1)(z-3)}\cdot\frac{dz}{iz} = \oint_{|z|=1}\frac{2i\,z^{2}}{(3z-1)(z-3)}\,dz.$$

単位円の内部にある極は $z = \tfrac13$（1 位）だけで、

$$\operatorname*{Res}_{z=1/3} = \frac{2i\cdot\frac19}{3\left(\frac13 - 3\right)} = \frac{\frac{2i}{9}}{-8} = -\frac{i}{36}.$$

よって $J = 2\pi i\cdot\left(-\dfrac{i}{36}\right) = \dfrac{\pi}{18}$。これは実数なので $I = \operatorname{Re}J = \dfrac{\pi}{18}$（虚部 $\displaystyle\int_0^{2\pi}\frac{\sin 2\theta}{5-3\cos\theta}\,d\theta$ は $\theta \mapsto 2\pi - \theta$ の対称性から $0$）。

### ポイント

- $\cos 2\theta = \dfrac12\left(z^{2} + z^{-2}\right)$ と直接置き換えると、$z = 0$ に 3 位の極が現れて計算が重くなります。$e^{2i\theta}$ の実部をとる方法が速く確実です。
- 一般に $0 < a < 1$ のとき $\displaystyle\int_0^{2\pi}\frac{\cos n\theta}{1 - 2a\cos\theta + a^{2}}\,d\theta = \frac{2\pi a^{n}}{1-a^{2}}$ です。$5 - 3\cos\theta = \dfrac92\left(1 - \dfrac23\cos\theta + \dfrac19\right)$（$a = \tfrac13$）と変形すると検算できます。
- 2 つの根 $\tfrac13$ と $3$ のうち、単位円の内部にあるのはどちらかを必ず確認します。$z = 3$ の留数を使うと符号も値も合いません。
