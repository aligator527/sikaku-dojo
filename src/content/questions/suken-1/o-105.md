$n^3$ を階乗冪 $n(n-1)(n-2),\ n(n-1),\ n$ の 1 次結合で表すと、各項が $n!$ と約分できて $e$ の級数 $\sum 1/m!$ に帰着します。和は $(1 + 3 + 1)e = 5e$ なので $k = 5$ です。

### 計算

$$n^3 = n(n-1)(n-2) + 3n(n-1) + n$$

が成り立ちます（$n = 1, 2, 3$ を代入すると $1, 8, 27$ となり確かめられます）。$\sum_{m=0}^{\infty} \dfrac{1}{m!} = e$ を使うと

$$\sum_{n=3}^{\infty}\frac{n(n-1)(n-2)}{n!} = \sum_{n=3}^{\infty}\frac{1}{(n-3)!} = e,\qquad \sum_{n=2}^{\infty}\frac{n(n-1)}{n!} = \sum_{n=2}^{\infty}\frac{1}{(n-2)!} = e,\qquad \sum_{n=1}^{\infty}\frac{n}{n!} = e.$$

（$n(n-1)(n-2)$ は $n = 1, 2$ で、$n(n-1)$ は $n = 1$ で $0$ なので、和の始まりをずらしても値は変わりません。）

$$\sum_{n=1}^{\infty} \frac{n^{3}}{n!} = e + 3e + e = 5e.$$

**別解（微分作用素）** $\displaystyle\sum_{n=0}^{\infty}\frac{n^3}{n!}x^n = \left(x\frac{d}{dx}\right)^{3} e^{x} = (x^3 + 3x^2 + x)e^x$ に $x = 1$ を代入しても $5e$ です。

### ポイント

- $\sum n^k/n!$ は $e$ の整数倍で、その係数はベル数 $B_k$（$B_1 = 1,\ B_2 = 2,\ B_3 = 5,\ B_4 = 15$）です。
- $n^3 = n(n-1)(n-2) + 3n(n-1) + n$ の係数 $1, 3, 1$ は第 2 種スターリング数です。係数を $1, 2, 1$ などと誤ると答えが変わるので、小さい $n$ を代入して確かめます。
- $\dfrac{n}{n!} = \dfrac{1}{(n-1)!}$ のような約分は $n \ge 1$ でしか成り立ちません。和の下端に注意します。
