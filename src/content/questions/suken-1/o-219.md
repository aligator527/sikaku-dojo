固有多項式を因数分解すると $A$ の固有値は $1, -1, 2$ です。多項式 $f(\lambda) = \lambda^2 - \lambda + 2$ に対して $f(A)$ の固有値は $f(1), f(-1), f(2)$ なので、行列式はその積 $2\cdot4\cdot4 = 32$ です。

### 計算

$$\lambda^{3} - 2\lambda^{2} - \lambda + 2 = \lambda^{2}(\lambda - 2) - (\lambda - 2) = (\lambda - 1)(\lambda + 1)(\lambda - 2)$$

より、$A$ の固有値は $1, -1, 2$ です。$A$ は相異なる 3 つの固有値をもつので対角化でき、$A = P\,\mathrm{diag}(1, -1, 2)\,P^{-1}$ と書けます。すると

$$A^{2} - A + 2I = P\,\mathrm{diag}\bigl(f(1), f(-1), f(2)\bigr)\,P^{-1},\qquad f(\lambda) = \lambda^{2} - \lambda + 2.$$

$f(1) = 2$、$f(-1) = 4$、$f(2) = 4$ なので

$$\det\left(A^{2} - A + 2I\right) = 2\cdot 4\cdot 4 = 32.$$

### ポイント

- 一般に $A$ の固有値が $\lambda_1, \dots, \lambda_n$（重複を込めて）なら、多項式 $f$ について $f(A)$ の固有値は $f(\lambda_1), \dots, f(\lambda_n)$ です。対角化できない場合も三角化によって成り立ちます。
- 別解：$f(\lambda) = (\lambda - \alpha)(\lambda - \beta)$ と分解すると、$\varphi(\lambda) = \det(\lambda I - A)$ に対して $\det f(A) = \det(A - \alpha I)\det(A - \beta I) = \varphi(\alpha)\varphi(\beta)$ です（3 次なので符号 $(-1)^3$ が 2 回出て打ち消し合います）。
- $\det(A^2) - \det A + 2\det I$ のように、行列式を項ごとに分けて計算することはできません。
