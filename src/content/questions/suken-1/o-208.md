stem: |
  複素平面全体で正則な関数（整関数）について、次の (1)、(2) を証明せよ。

  (1)（リウヴィルの定理）有界な整関数は定数関数である。

  (2) 整関数 $f(z)$ に対して、ある実数 $M$ が存在し、すべての $z$ について $\operatorname{Re} f(z) \le M$ が成り立つならば、$f(z)$ は定数関数である。
modelAnswer: |
  **(1)** $f$ を整関数とし、すべての $z$ で $|f(z)| \le K$ とする。任意の点 $a$ と任意の $R > 0$ に対して、コーシーの積分公式（導関数版）より

  $$f'(a) = \frac{1}{2\pi i}\oint_{|z-a|=R}\frac{f(z)}{(z-a)^{2}}\,dz.$$

  円周 $|z - a| = R$ の長さは $2\pi R$、その上で $\left|\dfrac{f(z)}{(z-a)^{2}}\right| \le \dfrac{K}{R^{2}}$ だから

  $$|f'(a)| \le \frac{1}{2\pi}\cdot 2\pi R\cdot\frac{K}{R^{2}} = \frac{K}{R}.$$

  $R$ はいくらでも大きくとれるので $f'(a) = 0$。$a$ は任意だから $f' \equiv 0$ である。このとき任意の $z$ について、$0$ と $z$ を結ぶ線分に沿って

  $$f(z) - f(0) = \int_{0}^{z} f'(\zeta)\,d\zeta = 0$$

  となり、$f$ は定数関数である。

  **(2)** $g(z) = e^{f(z)}$ とおくと、$g$ は整関数（正則関数の合成）であり、

  $$|g(z)| = \left|e^{\operatorname{Re} f(z)}\,e^{i\operatorname{Im} f(z)}\right| = e^{\operatorname{Re} f(z)} \le e^{M}.$$

  よって $g$ は有界な整関数であり、(1) より定数である。したがって

  $$0 = g'(z) = f'(z)\,e^{f(z)}$$

  がすべての $z$ で成り立つ。$e^{f(z)} \neq 0$ なので $f'(z) = 0$ となり、(1) の後半と同じ議論で $f$ は定数関数である。（証明終）
rubric:
  - (1) でコーシーの積分公式から |f'(a)| ≤ K/R を導き、R → ∞ として f' = 0 を示している
  - f' ≡ 0 から f が定数であることを、複素平面が連結であること（線分に沿った積分など）で結論している
  - (2) で e^f（または 1/(f − M − 1) など）を考え、それが有界な整関数であることを示している
  - '$|e^{w}| = e^{\operatorname{Re} w}$ と $e^{w} \neq 0$ を正しく使い、f 自身が定数であることまで導いている'
---
リウヴィルの定理は「コーシーの評価式」から直接導けます。(2) は $\operatorname{Re} f$ の上界を $|e^{f}|$ の上界に変換して (1) に帰着させるのが鍵で、整関数に関する 2 次試験の典型的な論法です。

### 証明の組み立て

1. **(1)** 導関数のコーシーの積分公式に、円の半径 $R$ を自由に選べることを組み合わせます。評価 $|f'(a)| \le K/R$ の右辺が $R \to \infty$ で $0$ になるのは、$f$ が「全平面で」正則だからです。
2. **(2)** $\operatorname{Re} f \le M$ だけでは $|f|$ の有界性は分かりません。指数関数を通すと $|e^{f}| = e^{\operatorname{Re} f} \le e^{M}$ となり、有界性に変わります。
3. $e^{f}$ が定数であることから $f$ が定数であることを言う段階では、$e^{w} \neq 0$ を使って $f' = 0$ を導きます（$e^{f}$ が定数でも、$f$ の値は $2\pi i$ の整数倍だけ動く可能性があるので、連続性か微分による議論が必要です）。

### 別解（(2)）

$h(z) = \dfrac{1}{f(z) - (M+1)}$ とおくと、$\operatorname{Re}\bigl(f(z) - (M+1)\bigr) \le -1$ より $|f(z) - (M+1)| \ge 1$ なので、$h$ は整関数で $|h| \le 1$。(1) より $h$ は定数、したがって $f$ も定数です。

### ポイント

- リウヴィルの定理から代数学の基本定理（定数でない多項式 $p$ は零点をもつ。もたなければ $1/p$ が有界な整関数になる）も導けます。
- 「実部が上に有界」「値が直線の片側にある」「値がある円板を避ける」などの条件は、指数関数や一次分数変換で有界性に変換してリウヴィルの定理に帰着させます。
- $f' \equiv 0 \Rightarrow f$ は定数、の部分は領域が連結であることを使います。答案では一言触れておきます。
