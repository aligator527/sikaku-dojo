  $A$ を $m \times n$ 実行列、$\boldsymbol b \in \mathbb{R}^{m}$、$\boldsymbol c \in \mathbb{R}^{n}$ とし、次の 2 つの線形計画問題を考える（ベクトルの不等号は成分ごと）。

  $$(\mathrm{P})\quad \text{最大化 } \boldsymbol c^{\mathsf T}\boldsymbol x \quad \text{制約 } A\boldsymbol x \le \boldsymbol b,\ \boldsymbol x \ge \boldsymbol 0$$

  $$(\mathrm{D})\quad \text{最小化 } \boldsymbol b^{\mathsf T}\boldsymbol y \quad \text{制約 } A^{\mathsf T}\boldsymbol y \ge \boldsymbol c,\ \boldsymbol y \ge \boldsymbol 0$$

  (1) $\boldsymbol x$ が (P) の実行可能解、$\boldsymbol y$ が (D) の実行可能解ならば、$\boldsymbol c^{\mathsf T}\boldsymbol x \le \boldsymbol b^{\mathsf T}\boldsymbol y$ が成り立つことを証明せよ。

  (2) (P) の実行可能解 $\boldsymbol x^{*}$ と (D) の実行可能解 $\boldsymbol y^{*}$ が $\boldsymbol c^{\mathsf T}\boldsymbol x^{*} = \boldsymbol b^{\mathsf T}\boldsymbol y^{*}$ を満たすならば、$\boldsymbol x^{*}$、$\boldsymbol y^{*}$ はそれぞれ (P)、(D) の最適解であることを証明せよ。

  (3) 次の問題について、$\boldsymbol x^{*} = (1, 3, 0)$ が最適解であることを (2) を用いて示し、最適値を求めよ。

  $$\text{最大化 } 3x_1 + 2x_2 + 4x_3 \quad \text{制約 } x_1 + x_2 + 2x_3 \le 4,\ \ 2x_1 + x_2 + 3x_3 \le 5,\ \ x_1, x_2, x_3 \ge 0$$
modelAnswer: |
  **(1)** $\boldsymbol x \ge \boldsymbol 0$ と $A^{\mathsf T}\boldsymbol y - \boldsymbol c \ge \boldsymbol 0$ より、成分ごとの積の和は非負なので $(A^{\mathsf T}\boldsymbol y - \boldsymbol c)^{\mathsf T}\boldsymbol x \ge 0$、すなわち

  $$\boldsymbol c^{\mathsf T}\boldsymbol x \le (A^{\mathsf T}\boldsymbol y)^{\mathsf T}\boldsymbol x = \boldsymbol y^{\mathsf T}A\boldsymbol x.$$

  同様に $\boldsymbol y \ge \boldsymbol 0$ と $\boldsymbol b - A\boldsymbol x \ge \boldsymbol 0$ より $\boldsymbol y^{\mathsf T}(\boldsymbol b - A\boldsymbol x) \ge 0$、すなわち $\boldsymbol y^{\mathsf T}A\boldsymbol x \le \boldsymbol y^{\mathsf T}\boldsymbol b = \boldsymbol b^{\mathsf T}\boldsymbol y$。2 つを合わせて

  $$\boldsymbol c^{\mathsf T}\boldsymbol x \le \boldsymbol y^{\mathsf T}A\boldsymbol x \le \boldsymbol b^{\mathsf T}\boldsymbol y.$$

  **(2)** (P) の任意の実行可能解 $\boldsymbol x$ について、(1) を $\boldsymbol x$ と $\boldsymbol y^{*}$ に適用すると

  $$\boldsymbol c^{\mathsf T}\boldsymbol x \le \boldsymbol b^{\mathsf T}\boldsymbol y^{*} = \boldsymbol c^{\mathsf T}\boldsymbol x^{*}.$$

  よって $\boldsymbol x^{*}$ は (P) の最適解である。同様に (D) の任意の実行可能解 $\boldsymbol y$ について $\boldsymbol b^{\mathsf T}\boldsymbol y \ge \boldsymbol c^{\mathsf T}\boldsymbol x^{*} = \boldsymbol b^{\mathsf T}\boldsymbol y^{*}$ なので、$\boldsymbol y^{*}$ は (D) の最適解である。

  **(3)** **主問題の実行可能性** $\boldsymbol x^{*} = (1, 3, 0) \ge \boldsymbol 0$ で、

  $$1 + 3 + 0 = 4 \le 4,\qquad 2 + 3 + 0 = 5 \le 5.$$

  目的関数の値は $3 + 6 + 0 = 9$。

  **双対解の構成** 双対問題は「最小化 $4y_1 + 5y_2$、制約 $y_1 + 2y_2 \ge 3$、$y_1 + y_2 \ge 2$、$2y_1 + 3y_2 \ge 4$、$y_1, y_2 \ge 0$」である。(1) の 2 つの不等式がともに等号になるように、$x_1^{*}, x_2^{*} > 0$ に対応する双対制約を等号にとって

  $$y_1 + 2y_2 = 3,\qquad y_1 + y_2 = 2$$

  を解くと $\boldsymbol y^{*} = (1, 1)$。これは $\boldsymbol y^{*} \ge \boldsymbol 0$、第 3 制約 $2 + 3 = 5 \ge 4$ を満たすので双対実行可能であり、

  $$\boldsymbol b^{\mathsf T}\boldsymbol y^{*} = 4 + 5 = 9 = \boldsymbol c^{\mathsf T}\boldsymbol x^{*}.$$

  (2) より $\boldsymbol x^{*} = (1, 3, 0)$ は最適解であり、最適値は $9$ である。

線形計画法の弱双対定理と、それを最適性の判定に使う方法を問う問題です。(1) の 2 段の不等式は、主問題・双対問題の制約と非負条件をそれぞれ 1 回ずつ使うだけで示せます。(3) では、相補性条件をヒントに双対解 $\boldsymbol y^{*} = (1, 1)$ を見つけ、目的関数値が一致することから $\boldsymbol x^{*}$ の最適性（最適値 $9$）を結論します。

### 証明の組み立て

1. **(1)** 「非負ベクトル同士の内積は非負」を 2 回使います。どの非負性をどの不等式と組み合わせるかを明示するのが答案のポイントです。
2. **(2)** 弱双対定理から、(P) の値は常に (D) の値以下です。値が一致する組があれば、それ以上よい解は存在しません。
3. **(3)** 双対解の見つけ方として相補性条件を使います。(1) の不等式が等号になる条件は
   - $x_j > 0$ なら双対の第 $j$ 制約が等号
   - $y_i > 0$ なら主問題の第 $i$ 制約が等号

   です。$x_1^{*}, x_2^{*} > 0$ から双対の第 1、第 2 制約を等号にとりました。

### ポイント

- 強双対定理（一方に最適解があれば他方にもあり、最適値が一致する）は (1)、(2) より深い結果で、証明には単体法やファルカスの補題が必要です。2 次試験では弱双対定理とその応用がよく問われます。
- 双対解は「最適性の証明書」です。単体法の計算を見せなくても、双対実行可能解を 1 つ示して値の一致を確かめれば最適性が示せます。
- 不等式の向きを誤り、$\boldsymbol c^{\mathsf T}\boldsymbol x \ge \boldsymbol y^{\mathsf T}A\boldsymbol x$ のように書く誤りが典型です。$\boldsymbol x \ge \boldsymbol 0$ を使う場所を必ず確認します。
