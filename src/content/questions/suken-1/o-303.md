$\max\{X, Y\} + \min\{X, Y\} = X + Y$ を使うと、最大値の期待値は最小値の期待値から求められます。独立な指数分布の最小値は、率を足し合わせた指数分布に従うので $E[\min] = \tfrac13$ となり、答えは $1 + \tfrac12 - \tfrac13 = \tfrac76$ です。

### 計算

$X$ は率 $1$、$Y$ は率 $2$ の指数分布に従うので、$E[X] = 1$、$E[Y] = \tfrac12$ です。

**最小値** $t > 0$ に対して、独立性から

$$P(\min\{X, Y\} > t) = P(X > t)\,P(Y > t) = e^{-t}\cdot e^{-2t} = e^{-3t}.$$

よって $\min\{X, Y\}$ は率 $3$ の指数分布に従い、$E[\min\{X, Y\}] = \tfrac13$ です。

**最大値** $\max + \min = X + Y$ より

$$E[\max\{X, Y\}] = E[X] + E[Y] - E[\min\{X, Y\}] = 1 + \frac12 - \frac13 = \frac76.$$

**別解（分布関数から）** $P(\max \le t) = (1 - e^{-t})(1 - e^{-2t})$ なので、非負の確率変数の期待値の公式 $E[M] = \int_0^\infty P(M > t)\,dt$ を使うと

$$E[\max] = \int_0^\infty \left(e^{-t} + e^{-2t} - e^{-3t}\right)dt = 1 + \frac12 - \frac13 = \frac76.$$

### ポイント

- 独立な指数分布の最小値は指数分布で、率は和になります（$\mathrm{Exp}(\lambda)$ と $\mathrm{Exp}(\mu)$ の最小値は $\mathrm{Exp}(\lambda+\mu)$）。
- 最大値は指数分布ではありません。分布関数の積 $F_X(t)F_Y(t)$ から求めるか、$\max = X + Y - \min$ を使います。
- 密度 $2e^{-2y}$ の平均は $2$ ではなく $\tfrac12$ です。率と平均を取り違えると答えが大きくずれます。
