不動点反復 $x_{n+1} = g(x_n)$ の誤差は、1 回の反復でほぼ $|g'(\alpha)|$ 倍になります（1 次収束）。$g(x) = 1 + \dfrac1x$ では $|g'(\alpha)| = \dfrac{1}{\alpha^2} = \dfrac{3 - \sqrt5}{2} = 0.3819\cdots$ なので、答えは $0.382$ です。

### 計算

$\alpha = 1 + \dfrac1\alpha$（$\alpha^2 = \alpha + 1$）なので、誤差 $e_n = x_n - \alpha$ について

$$e_{n+1} = \left(1 + \frac{1}{x_n}\right) - \left(1 + \frac1\alpha\right) = \frac{\alpha - x_n}{\alpha x_n} = -\frac{e_n}{\alpha x_n}.$$

$x_n$ はすべて有理数なので $e_n \neq 0$ で、$x_n \to \alpha$ より

$$\lim_{n\to\infty}\frac{|e_{n+1}|}{|e_n|} = \lim_{n\to\infty}\frac{1}{\alpha x_n} = \frac{1}{\alpha^2}.$$

$\alpha^2 = \alpha + 1 = \dfrac{3 + \sqrt5}{2}$ より

$$\frac{1}{\alpha^2} = \frac{2}{3 + \sqrt5} = \frac{2(3 - \sqrt5)}{9 - 5} = \frac{3 - \sqrt5}{2} = \frac{3 - 2.2360\cdots}{2} = 0.3819\cdots.$$

小数第 4 位を四捨五入して $0.382$ です。

### ポイント

- 一般に $g$ が $C^1$ 級で $0 < |g'(\alpha)| < 1$ なら、$\alpha$ の近くから始めた反復は 1 次収束し、誤差の比は $|g'(\alpha)|$ に近づきます。$g'(\alpha) = 0$ のときは 2 次以上の収束になります（ニュートン法）。
- ここでは $g'(\alpha) = -\dfrac{1}{\alpha^2} < 0$ なので、$x_n$ は $\alpha$ の両側を交互に行き来しながら収束します（$x_n$ は隣り合うフィボナッチ数の比 $F_{n+1}/F_n$）。
- $\dfrac1\alpha = \alpha - 1 = 0.618\cdots$ と取り違える誤りに注意します。誤差の比は $\dfrac{1}{\alpha^2}$ で、$\dfrac1\alpha$ の 2 乗です。
