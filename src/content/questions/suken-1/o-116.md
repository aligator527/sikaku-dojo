$u = \sin x = x - \dfrac{x^3}{6} + O(x^5)$ を $e^u = 1 + u + \dfrac{u^2}{2} + \dfrac{u^3}{6} + \dfrac{u^4}{24} + \cdots$ に代入し、$x^4$ までの項を集めます。$x^3$ の項は $u$ と $\dfrac{u^3}{6}$ からの寄与が打ち消し合って $0$ になり、$x^4$ の係数は $-\dfrac16 + \dfrac{1}{24} = -\dfrac18$ です。

### 計算

$x^4$ までで

$$u = x - \frac{x^3}{6},\qquad u^2 = x^2 - \frac{x^4}{3},\qquad u^3 = x^3,\qquad u^4 = x^4$$

なので

$$e^{\sin x} = 1 + \left(x - \frac{x^3}{6}\right) + \frac12\left(x^2 - \frac{x^4}{3}\right) + \frac{x^3}{6} + \frac{x^4}{24} + O(x^5) = 1 + x + \frac{x^2}{2} - \frac{x^4}{8} + O(x^5).$$

**検算（微分係数）** $f = e^{\sin x}$ とすると $f' = f\cos x$、$f'' = f(\cos^2 x - \sin x)$、$f''' = f(\cos^3 x - 3\sin x\cos x - \cos x)$ で、$f'''(0) = 1 - 0 - 1 = 0$ となり $x^3$ の係数が $0$ であることと合います。

### 各選択肢の検討

1. 誤り。$e^x$ の展開そのものです。$\sin x$ の $-\dfrac{x^3}{6}$ の項を無視しています。
2. 正しい。
3. 誤り。$\dfrac{u^3}{6}$ の項を落としたため、$x^3$ の係数 $-\dfrac16$ が残っています。
4. 誤り。$\dfrac{u^4}{24}$ の項を落としたため、$x^4$ の係数が $-\dfrac16$ になっています。

### ポイント

- 合成関数の展開では、外側の展開の **どの次数の項まで** 必要かを最初に決めます。内側が $x$ から始まるなら、$x^4$ までには $u^4$ まで必要です。
- $u^2$ の展開の交差項 $2\cdot x\cdot\left(-\dfrac{x^3}{6}\right) = -\dfrac{x^4}{3}$ を忘れないようにします。
- 偶関数・奇関数のような対称性がない関数なので、すべての次数の係数を確認する必要があります。
