内側の $\displaystyle\int e^{x^3}\,dx$ は初等関数で表せないので、積分順序を交換します。積分領域は $0 \le y \le x^2,\ 0 \le x \le 1$ と書き直せ、値は $\displaystyle\int_0^1 x^2e^{x^3}\,dx = \frac{e-1}{3} \approx 0.5728$ です。

### 計算

積分領域は

$$D = \{(x, y) \mid 0 \le y \le 1,\ \sqrt{y} \le x \le 1\}$$

です。$\sqrt{y} \le x$ は（$x, y \ge 0$ で）$y \le x^2$ と同値なので、$x$ を外側にとると

$$D = \{(x, y) \mid 0 \le x \le 1,\ 0 \le y \le x^{2}\}.$$

被積分関数は $D$ 上で連続なので、順序を交換できます。

$$\int_{0}^{1}\!\!\int_{\sqrt{y}}^{1} e^{x^{3}}\,dx\,dy = \int_0^1\!\!\int_0^{x^2} e^{x^3}\,dy\,dx = \int_0^1 x^{2}e^{x^{3}}\,dx = \Bigl[\frac{e^{x^3}}{3}\Bigr]_0^1 = \frac{e - 1}{3}.$$

$\dfrac{e-1}{3} = \dfrac{1.71828\cdots}{3} = 0.57276\cdots$ なので、小数第4位を四捨五入して $0.573$ です。

### ポイント

- 内側の積分が計算できないときは、まず積分領域を図示して順序の交換を考えます。交換後に $x^2$ のような因子が現れ、ちょうど $e^{x^3}$ の原始関数が作れるように問題が作られていることがよくあります。
- 領域の境界 $x = \sqrt y$ を $y = x^2$ と書き直すとき、上下関係を取り違えて $\displaystyle\int_0^1\!\!\int_{x^2}^{1}$ としてしまう誤りに注意します（その場合は計算できない積分が残ります）。
