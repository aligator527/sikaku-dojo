stem: |
  $0$ 以上の整数 $n$ に対して

  $$I_n = \int_{0}^{\frac{\pi}{2}} \sin^{n} x\,dx$$

  とおく。

  (1) $n \ge 2$ のとき $I_n = \dfrac{n-1}{n}\,I_{n-2}$ が成り立つことを示せ。

  (2) $n \ge 1$ のとき $n\,I_n I_{n-1} = \dfrac{\pi}{2}$ が成り立つことを示せ。

  (3) 極限値 $\displaystyle\lim_{n\to\infty}\sqrt{n}\,I_n$ を求めよ。
modelAnswer: |
  **(1)** $n \ge 2$ のとき、$\sin^{n}x = \sin^{n-1}x\cdot\sin x$ として部分積分すると

  $$I_n = \Bigl[-\sin^{n-1}x\cos x\Bigr]_0^{\pi/2} + (n-1)\int_0^{\pi/2}\sin^{n-2}x\cos^{2}x\,dx = (n-1)\int_0^{\pi/2}\sin^{n-2}x\,(1 - \sin^{2}x)\,dx.$$

  （境界項は $x = 0$ で $\sin^{n-1}0 = 0$、$x = \pi/2$ で $\cos\frac{\pi}{2} = 0$ より $0$。）よって $I_n = (n-1)(I_{n-2} - I_n)$、すなわち

  $$I_n = \frac{n-1}{n}\,I_{n-2}.$$

  **(2)** $n$ に関する帰納法。$I_0 = \dfrac{\pi}{2}$、$I_1 = \displaystyle\int_0^{\pi/2}\sin x\,dx = 1$ より、$n = 1$ のとき $1\cdot I_1 I_0 = \dfrac{\pi}{2}$ で成り立つ。$n - 1$（$n \ge 2$）で成り立つとすると、(1) より

  $$n\,I_n I_{n-1} = n\cdot\frac{n-1}{n}I_{n-2}\cdot I_{n-1} = (n-1)\,I_{n-1}I_{n-2} = \frac{\pi}{2}.$$

  よってすべての $n \ge 1$ で成り立つ。

  **(3)** $0 \le x \le \dfrac{\pi}{2}$ で $0 \le \sin x \le 1$ だから $\sin^{n+1}x \le \sin^{n}x \le \sin^{n-1}x$ であり、積分して

  $$I_{n+1} \le I_n \le I_{n-1}. \qquad (\ast)$$

  また $I_n > 0$ である。$n \ge 1$ とすると、(2) と $(\ast)$ の右の不等式より

  $$n I_n^{2} \le n I_n I_{n-1} = \frac{\pi}{2}.$$

  (2) で $n$ を $n+1$ に置き換えた $(n+1)I_{n+1}I_n = \dfrac{\pi}{2}$ と $(\ast)$ の左の不等式より

  $$n I_n^{2} \ge n I_n I_{n+1} = \frac{n}{n+1}\cdot\frac{\pi}{2}.$$

  よって $\dfrac{n}{n+1}\cdot\dfrac{\pi}{2} \le n I_n^{2} \le \dfrac{\pi}{2}$。はさみうちの原理より $n I_n^2 \to \dfrac{\pi}{2}$ であり、$I_n > 0$ だから

  $$\lim_{n\to\infty}\sqrt{n}\,I_n = \sqrt{\frac{\pi}{2}}.$$
rubric:
  - (1) で部分積分を行い、境界項が 0 になることを確認して漸化式を導いている
  - (2) で $I_0 = \pi/2$、$I_1 = 1$ を初期値として帰納法を正しく進めている
  - (3) で $\sin x$ の範囲から $I_{n+1} \le I_n \le I_{n-1}$ を導いている
  - (2) を $n$ と $n+1$ の 2 通りに使い、$n I_n^2$ を上下から挟んでいる
  - 極限値 $\sqrt{\pi/2}$ を得ている

ウォリス積分の漸化式と単調性から、$I_n$ の漸近的な大きさ $I_n \approx \sqrt{\dfrac{\pi}{2n}}$ を導く問題です。(2) の「隣どうしの積が $\dfrac{\pi}{2n}$ に等しい」という関係と、$I_n$ が単調減少であることを組み合わせるのが鍵です。

### 証明の組み立て

1. **漸化式** $\sin^{n}x$ を $\sin^{n-1}x\cdot\sin x$ と分け、$\sin x$ の側を積分します。$\cos^2 x = 1 - \sin^2 x$ で元の積分 $I_n$ が右辺に現れるので、移項して解きます。
2. **積の不変量** $n I_n I_{n-1}$ は (1) によって $n$ を 1 つ下げても値が変わらないので、$n = 1$ の値 $\dfrac{\pi}{2}$ に等しくなります。
3. **はさみうち** $I_n$ を $I_{n-1}$ や $I_{n+1}$ と比べて $I_n^2$ を評価します。単調性だけでは極限は求まらず、(2) の等式と組み合わせて初めて上下の評価が一致します。

### ポイント

- (1) を繰り返すと $I_{2m} = \dfrac{(2m-1)!!}{(2m)!!}\cdot\dfrac{\pi}{2}$、$I_{2m+1} = \dfrac{(2m)!!}{(2m+1)!!}$ です。(3) からウォリスの公式 $\displaystyle\lim_{m\to\infty}\frac{1}{\sqrt m}\cdot\frac{(2m)!!}{(2m-1)!!} = \sqrt\pi$ が得られ、スターリングの公式の定数 $\sqrt{2\pi}$ の決定にも使われます。
- 数値で確かめると、$n = 10000$ で $\sqrt{n}\,I_n \approx 1.25328$、$\sqrt{\pi/2} \approx 1.25331$ です。
- (3) で極限の存在を仮定して $n I_n^2 \to L$ とおく議論は不十分です。はさみうちで存在と値を同時に示します。
