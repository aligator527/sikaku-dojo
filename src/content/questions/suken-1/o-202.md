極 $\pm i,\ \pm 2i$ はすべて $|z| < 3$ の内部にあるので、求める値は 4 つの留数の和です。これは「無限遠点での留数」の符号を変えたもの、すなわち $|z| > 2$ でのローラン展開の $z^{-1}$ の係数に等しく、値は $21$ です。

### 計算

**無限遠点での展開を使う方法** $|z| > 2$ では

$$\frac{z^{7}}{(z^{2}+1)(z^{2}+4)} = \frac{z^{7}}{z^{4}\left(1 + \dfrac{5}{z^{2}} + \dfrac{4}{z^{4}}\right)} = z^{3}\left(1 + \frac{5}{z^{2}} + \frac{4}{z^{4}}\right)^{-1}.$$

$(1+w)^{-1} = 1 - w + w^{2} - \cdots$ で $w = 5z^{-2} + 4z^{-4}$ とし、$z^{-4}$ の項まで残すと

$$\left(1 + 5z^{-2} + 4z^{-4}\right)^{-1} = 1 - 5z^{-2} + (25 - 4)z^{-4} + \cdots = 1 - 5z^{-2} + 21z^{-4} + \cdots.$$

よって $f(z) = z^{3} - 5z + \dfrac{21}{z} + \cdots$ で、$z^{-1}$ の係数は $21$ です。積分路の外側に特異点はないので、求める値は $21$ です。

**検算（各極の留数）** いずれも 1 位の極です。

$$\operatorname*{Res}_{z=\pm i} f = \frac{(\pm i)^{7}}{(\pm 2i)\cdot 3} = \frac{(\pm i)^{6}}{6} = -\frac16,\qquad \operatorname*{Res}_{z=\pm 2i} f = \frac{(\pm 2i)^{7}}{(-3)\cdot(\pm 4i)} = \frac{(\pm 2i)^{6}}{-6} = \frac{-64}{-6} = \frac{32}{3}.$$

和は $-\dfrac13 + \dfrac{64}{3} = 21$ で一致します。

### ポイント

- 有界な領域の外に特異点がないとき、内部の留数の和 $=$ （$|z|$ が大きい所でのローラン展開の $z^{-1}$ の係数）です。極が多い・高次のときに計算量を大きく減らせます。
- 無限遠点での留数は $\operatorname*{Res}_{z=\infty} f = -c_{-1}$ と符号が逆になります。符号を取り違えて $-21$ と答えないようにします。
- 1 位の極の留数は $\dfrac{p(a)}{q'(a)}$ で計算でき、$a^{2} = -1$ などの関係を使うと簡単になります。
