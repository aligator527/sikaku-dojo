  表と裏がそれぞれ確率 $\tfrac12$ で出るコインを繰り返し投げ、初めて表が 2 回続けて出た時点で投げるのをやめる。投げた回数を $N$ とする。

  (2) $N$ の期待値 $E[N]$ と分散 $V[N]$ を求めよ。
modelAnswer: |
  **(1)** 最初の 1 回または 2 回の結果で場合分けする。

  - 1 回目が裏（確率 $\tfrac12$）：その後は最初からやり直すのと同じなので、残りの回数 $N'$ は $N$ と同じ分布に従い、$N = 1 + N'$。
  - 1 回目が表、2 回目が裏（確率 $\tfrac14$）：同様に $N = 2 + N''$（$N''$ は $N$ と同じ分布）。
  - 1 回目、2 回目とも表（確率 $\tfrac14$）：$N = 2$。

  やり直した後の試行は最初の結果と独立なので、$0 \le s \le 1$ に対して

  $$G(s) = \frac12 s\,G(s) + \frac14 s^2 G(s) + \frac14 s^2.$$

  $0 \le s \le 1$ では $1 - \frac12 s - \frac14 s^2 \ge \frac14 > 0$ なので

  $$G(s) = \frac{s^2/4}{1 - \frac{s}{2} - \frac{s^2}{4}} = \frac{s^2}{4 - 2s - s^2}.$$

  右辺は分母の零点 $s = -1 \pm \sqrt5$ の外側、特に $|s| < \sqrt5 - 1\ (\approx 1.236)$ で $s$ のべき級数に展開でき、その係数が $P(N = n)$ を与える。

  **(2)** 収束半径が $1$ より大きいので、$E[N] = G'(1)$、$E[N(N-1)] = G''(1)$ が成り立つ。$D(s) = 4 - 2s - s^2$ とおくと $D(1) = 1,\ D'(s) = -2 - 2s,\ D'(1) = -4$ である。

  $$G'(s) = \frac{2s\,D(s) - s^2 D'(s)}{D(s)^2} = \frac{8s - 2s^2}{D(s)^2}$$

  より $G'(1) = 6$。さらに

  $$G''(s) = \frac{(8 - 4s)D(s) - 2(8s - 2s^2)D'(s)}{D(s)^3}$$

  より $G''(1) = 4 \cdot 1 - 2\cdot 6\cdot(-4) = 52$。したがって

  $$E[N] = G'(1) = 6,\qquad V[N] = G''(1) + G'(1) - \bigl(G'(1)\bigr)^2 = 52 + 6 - 36 = 22.$$

「最初の数回の結果で場合分けし、やり直しになる場合は同じ分布が再び現れる」という初手分析（first-step analysis）で、確率母関数の方程式を立てます。答えは $G(s) = \dfrac{s^2}{4 - 2s - s^2}$、$E[N] = 6$、$V[N] = 22$ です。

### 計算の要点

- **方程式の立て方** 裏が出た時点で「連続した表の数」は $0$ に戻るので、それまでに投げた回数を $s^k$ として掛ければ済みます。表が 1 回出た後に裏が出た場合も同じくやり直しです。
- **期待値だけなら** $m = E[N]$ として $m = \frac12(1 + m) + \frac14(2 + m) + \frac14\cdot 2$ を解いても $m = 6$ が得られます。分散まで求めるときは母関数が便利です。
- **分散の公式** $V[N] = E[N(N-1)] + E[N] - (E[N])^2 = G''(1) + G'(1) - G'(1)^2$ です。$G''(1)$ は $E[N^2]$ ではなく $E[N(N-1)]$ である点に注意します。

### ポイント

- 展開すると $G(s) = \tfrac14 s^2 + \tfrac18 s^3 + \tfrac18 s^4 + \tfrac{3}{32}s^5 + \cdots$ で、一般に $P(N = n) = \dfrac{F_{n-1}}{2^n}$（$F_k$ はフィボナッチ数、$F_1 = F_2 = 1$）となります。分母 $4 - 2s - s^2$ がフィボナッチ数の漸化式に対応しています。
- 「表が 2 回出るまで」（連続でなくてよい）なら負の二項分布で $E = 4$ です。「連続して」の条件を落とすと答えが変わります。
- 同じ方法で「表裏」が初めて出るまでの回数は $E = 4$ となり、同じ 2 文字のパターンでも期待値が異なります。
