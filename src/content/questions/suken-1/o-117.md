合成関数の微分で、対数の中身の導関数 $1 + \dfrac{x}{\sqrt{x^2+1}} = \dfrac{x + \sqrt{x^2+1}}{\sqrt{x^2+1}}$ が中身そのものと約分でき、$y' = \dfrac{1}{\sqrt{x^2+1}}$ となります。

### 計算

$$y' = \frac{1}{x + \sqrt{x^2+1}}\cdot\left(1 + \frac{x}{\sqrt{x^2+1}}\right) = \frac{1}{x + \sqrt{x^2+1}}\cdot\frac{\sqrt{x^2+1} + x}{\sqrt{x^2+1}} = \frac{1}{\sqrt{x^2+1}}.$$

この関数は双曲線正弦の逆関数 $\sinh^{-1}x$ です（$x = \sinh y = \dfrac{e^y - e^{-y}}{2}$ を $e^y$ について解くと得られます）。逆関数の微分 $\dfrac{dy}{dx} = \dfrac{1}{\cosh y} = \dfrac{1}{\sqrt{1 + \sinh^2 y}}$ からも同じ結果が出ます。

### 各選択肢の検討

1. 誤り。$\log$ の微分だけをして、中身の導関数を掛け忘れています。
2. 誤り。$\sqrt{x^2+1}$ の導関数です。$\log$ の微分を忘れています。
3. 誤り。$\cosh^{-1}x = \log\left(x + \sqrt{x^2-1}\right)$ の導関数です。
4. 誤り。$\tan^{-1}x$ の導関数です。
5. 正しい。

### ポイント

- $\dfrac{d}{dx}\log\left(x + \sqrt{x^2 + A}\right) = \dfrac{1}{\sqrt{x^2 + A}}$ は、逆に $\displaystyle\int\frac{dx}{\sqrt{x^2+A}}$ の公式として積分の問題で頻繁に使います。
- $\sinh^{-1}$ と $\cosh^{-1}$、$\tan^{-1}$ の導関数は形が似ているので、符号と根号の有無で区別して覚えます。
