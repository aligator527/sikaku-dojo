行列式は積を積に移し（$\det(XY) = \det X\det Y$）、スカラー倍は $n$ 乗で効きます。各因子の行列式を求めて掛け合わせると $2^3\cdot\dfrac12\cdot(-3)\cdot 4 = -48$ です。

### 計算

各因子の行列式は次のとおりです（$n = 3$）。

- $\det(2X) = 2^{3}\det X = 8\det X$
- $\det A^{-1} = \dfrac{1}{\det A} = \dfrac12$
- $\det B^{\mathsf T} = \det B = -3$
- $A\tilde{A} = (\det A)I$ の両辺の行列式をとると $\det A\cdot\det\tilde{A} = (\det A)^{3}$。$\det A \neq 0$ なので $\det\tilde{A} = (\det A)^{2} = 4$

したがって

$$\det\left(2A^{-1}B^{\mathsf T}\tilde{A}\right) = 2^{3}\cdot\frac12\cdot(-3)\cdot 4 = -48.$$

### ポイント

- $n$ 次正方行列では $\det(cA) = c^{n}\det A$ です。$\det(2X) = 2\det X$ とすると $-12$ になってしまいます。
- 余因子行列の行列式は $\det\tilde{A} = (\det A)^{n-1}$ です。$\det\tilde{A} = \det A$ と混同すると $-24$ になります。
- $\tilde{A} = (\det A)A^{-1}$ と書き直して $\det(2A^{-1}B^{\mathsf T}\tilde A) = \det\bigl(4A^{-1}B^{\mathsf T}A^{-1}\bigr) = 4^{3}\cdot\dfrac12\cdot(-3)\cdot\dfrac12 = -48$ と検算することもできます。
