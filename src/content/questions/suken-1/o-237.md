求める個数はオイラー関数の値 $\varphi(1350)$ です。$1350 = 2\cdot3^{3}\cdot5^{2}$ と素因数分解し、公式 $\varphi(n) = n\prod_{p\mid n}\left(1 - \frac1p\right)$ を使うと $360$ です。

### 計算

$$1350 = 2\cdot 675 = 2\cdot 3^{3}\cdot 5^{2}.$$

$$\varphi(1350) = 1350\left(1 - \frac12\right)\left(1 - \frac13\right)\left(1 - \frac15\right) = 1350\cdot\frac12\cdot\frac23\cdot\frac45 = 360.$$

**別の計算** $\varphi$ は乗法的関数で、素数べきでは $\varphi(p^{k}) = p^{k} - p^{k-1}$ なので

$$\varphi(1350) = \varphi(2)\,\varphi(3^{3})\,\varphi(5^{2}) = 1\cdot(27 - 9)\cdot(25 - 5) = 1\cdot 18\cdot 20 = 360.$$

### ポイント

- $\varphi(p^{k}) = p^{k-1}(p - 1)$ です。$\varphi(p^{k}) = p^{k} - 1$ と素数の場合の式を流用すると $1\cdot 26\cdot 24 = 624$ と誤ります。
- 乗法性 $\varphi(mn) = \varphi(m)\varphi(n)$ は $m, n$ が互いに素のときだけ成り立ちます。$\varphi(1350) = \varphi(2)\varphi(675)$ は使えますが、$\varphi(1350) = \varphi(30)\varphi(45)$ は誤りです。
- 包除原理で「2、3、5 のいずれかで割り切れる数」を除いても同じ結果になり、検算に使えます：$1350 - (675 + 450 + 270) + (225 + 135 + 90) - 45 = 360$。
