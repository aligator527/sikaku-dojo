  $X_1, \dots, X_n\ (n \ge 2)$ は互いに独立に、区間 $[0, \theta]$ 上の一様分布に従う。ただし $\theta > 0$ は未知の母数である。$\bar X = \dfrac1n\displaystyle\sum_{i=1}^n X_i$、$M = \max\{X_1, \dots, X_n\}$ とする。

  (1) $T_1 = 2\bar X$ は $\theta$ の不偏推定量であることを示し、分散 $V[T_1]$ を求めよ。

  (2) $T_2 = cM$ が $\theta$ の不偏推定量となるように定数 $c$ を定め、分散 $V[T_2]$ を求めよ。

  (3) $V[T_2] < V[T_1]$ であることを示せ。
modelAnswer: |
  **(1)** $X_i$ の平均は $\dfrac\theta2$、分散は $\dfrac{\theta^2}{12}$ である。よって

  $$E[T_1] = 2E[\bar X] = 2\cdot\frac\theta2 = \theta$$

  であり、$T_1$ は不偏推定量である。独立性より $V[\bar X] = \dfrac1n\cdot\dfrac{\theta^2}{12}$ なので

  $$V[T_1] = 4V[\bar X] = \frac{\theta^2}{3n}.$$

  **(2)** $0 \le m \le \theta$ に対して、独立性から

  $$P(M \le m) = \prod_{i=1}^n P(X_i \le m) = \left(\frac m\theta\right)^n$$

  なので、$M$ の密度関数は $f_M(m) = \dfrac{n m^{n-1}}{\theta^n}\ (0 \le m \le \theta)$ である。

  $$E[M] = \int_0^\theta m\cdot\frac{nm^{n-1}}{\theta^n}\,dm = \frac{n}{n+1}\theta,\qquad E[M^2] = \int_0^\theta m^2\cdot\frac{nm^{n-1}}{\theta^n}\,dm = \frac{n}{n+2}\theta^2.$$

  $E[cM] = \theta$ がすべての $\theta > 0$ で成り立つ条件は $c\cdot\dfrac{n}{n+1} = 1$、すなわち $c = \dfrac{n+1}{n}$ である。また

  $$V[M] = \frac{n}{n+2}\theta^2 - \frac{n^2}{(n+1)^2}\theta^2 = \frac{n(n+1)^2 - n^2(n+2)}{(n+1)^2(n+2)}\theta^2 = \frac{n}{(n+1)^2(n+2)}\theta^2$$

  より

  $$V[T_2] = \left(\frac{n+1}{n}\right)^2 V[M] = \frac{\theta^2}{n(n+2)}.$$

  **(3)** $n \ge 2$ のとき $n + 2 > 3$ なので $n(n+2) > 3n > 0$。よって

  $$V[T_2] = \frac{\theta^2}{n(n+2)} < \frac{\theta^2}{3n} = V[T_1].$$

同じ母数 $\theta$ に対する 2 つの不偏推定量の分散を比べる問題です。標本平均に基づく $T_1$ の分散は $\dfrac{\theta^2}{3n}$（$n$ に反比例）、最大値に基づく $T_2$ の分散は $\dfrac{\theta^2}{n(n+2)}$（$n^2$ に反比例）で、$n \ge 2$ では $T_2$ の方が精度が高くなります。

### 計算の要点

- **最大値の分布** 「最大値が $m$ 以下 $\iff$ すべてが $m$ 以下」から分布関数を求めるのが定石です。$\theta = 1$ のときは $\mathrm{Beta}(n, 1)$ 分布です。
- **分散の計算** $V[M]$ の分子は $n(n+1)^2 - n^2(n+2) = n$ と簡単になります。ここで計算を誤りやすいので、$n = 1$ で $V[M] = \theta^2/12$（一様分布の分散）になることで検算できます。
- **比較** $n = 1$ のときは $T_1 = T_2 = 2X_1$ で分散は等しくなります。$n \ge 2$ という条件はここで使います。

### ポイント

- $M$ は $\theta$ の十分統計量で、$T_2 = \frac{n+1}{n}M$ は一様最小分散不偏推定量（UMVUE）です。$\bar X$ はデータの情報を十分に使っていません。
- $M$ 自身は $E[M] = \frac{n}{n+1}\theta < \theta$ で、$\theta$ を過小に見積もる偏りをもちます（最尤推定量は $M$）。
- 一様分布の母数は分布の台の端を決めるので、通常の正則条件が成り立たず、分散が $1/n$ より速く $0$ に近づきます。
