右辺 $\dfrac{e^x}{x}$ は未定係数法の対象外なので、定数変化法（ロンスキアンを使う公式）で特殊解を求めます。特殊解は $xe^{x}\log x - xe^{x}$ となり、$-xe^x$ は同次解に吸収されるので、一般解は $y = e^{x}(C_1 + C_2x + x\log x)$ です。

### 計算

**同次方程式** 特性方程式 $\lambda^2 - 2\lambda + 1 = (\lambda - 1)^2 = 0$ は重根 $\lambda = 1$ をもち、基本解は $y_1 = e^{x},\ y_2 = xe^{x}$ です。ロンスキアンは

$$W = y_1y_2' - y_1'y_2 = e^{x}(1 + x)e^{x} - e^{x}\cdot xe^{x} = e^{2x}.$$

**特殊解** $f(x) = \dfrac{e^x}{x}$ として

$$y_p = -y_1\int\frac{y_2 f}{W}\,dx + y_2\int\frac{y_1 f}{W}\,dx = -e^{x}\int 1\,dx + xe^{x}\int\frac{dx}{x} = -xe^{x} + xe^{x}\log x.$$

$-xe^x$ は同次解なので、一般解は

$$y = e^{x}\left(C_1 + C_2x + x\log x\right).$$

**別解** $y = e^{x}u$ とおくと $y'' - 2y' + y = e^{x}u''$ なので、方程式は $u'' = \dfrac1x$ となります。2 回積分して $u = x\log x - x + C_2'x + C_1$ となり、同じ結果を得ます。

### 各選択肢の検討

1. 誤り。特殊解を $e^{x}\log x$ としていますが、代入すると $y'' - 2y' + y = -\dfrac{e^x}{x^2}$ となり、右辺に一致しません。
2. 正しい。
3. 誤り。符号が逆です。代入すると左辺は $-\dfrac{e^x}{x}$ になります。
4. 誤り。同次方程式の基本解を誤っています。$e^{-x}$ は $y'' - 2y' + y = 0$ の解ではありません（特性根は重根 $1$ です）。

### ポイント

- 重根 $\lambda$ をもつ定数係数の方程式では、$y = e^{\lambda x}u$ とおくと $u''$ だけの式になり、定数変化法より速く解けることがあります。
- 定数変化法の公式は $y_p = -y_1\displaystyle\int\frac{y_2f}{W} + y_2\int\frac{y_1f}{W}$ です。符号と $y_1, y_2$ の位置を取り違えないようにします。
- 選択肢の検討では、特殊解の候補を実際に代入するのが確実です。
