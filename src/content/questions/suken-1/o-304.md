個数 $N$ が確率的に変わる和（ランダム和）の分散は、$N$ で条件付けて「全分散の公式」で求めます。$N$ を固定したときのばらつきと、$N$ 自体のばらつきの両方を足し、$V[S] = \tfrac13 + 1 = \tfrac43$ です。

### 計算

$U(0,1)$ の平均は $\tfrac12$、分散は $\tfrac{1}{12}$ です。$N = n$ のもとでは $S$ は $n$ 個の独立な一様分布の和なので

$$E[S \mid N] = \frac{N}{2},\qquad V[S \mid N] = \frac{N}{12}.$$

ポアソン分布では $E[N] = V[N] = 4$ です。全分散の公式 $V[S] = E\bigl[V[S \mid N]\bigr] + V\bigl[E[S \mid N]\bigr]$ より

$$V[S] = E\left[\frac{N}{12}\right] + V\left[\frac{N}{2}\right] = \frac{4}{12} + \frac{4}{4} = \frac13 + 1 = \frac43.$$

**別解（積率母関数）** $X_i$ の積率母関数を $M_X(t)$ とすると $M_S(t) = E\bigl[M_X(t)^N\bigr] = e^{4(M_X(t) - 1)}$ です。$K(t) = \log M_S(t) = 4(M_X(t) - 1)$ を 2 回微分して $t = 0$ とおくと $V[S] = K''(0) = 4E[X^2] = 4\cdot\tfrac13 = \tfrac43$ となります。

### ポイント

- 一般に $V\Bigl[\sum_{i=1}^N X_i\Bigr] = E[N]\,V[X] + V[N]\,(E[X])^2$ です。$N$ がポアソン分布なら $E[N]\,E[X^2]$ にまとまります。
- 第 2 項 $V\bigl[E[S\mid N]\bigr]$ を落として $\tfrac13$ と答える、あるいは $N = 4$ に固定して同じく $\tfrac13$ とする誤りが典型です。
- $E[S] = E[N]E[X] = 2$ は期待値の積で済みますが、分散は積にならない点に注意します。
