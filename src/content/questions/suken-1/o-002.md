$t = x^2$ と置換するとガンマ関数 $\Gamma(4)$ の定義式に帰着し、値は $\tfrac12\Gamma(4) = \tfrac12\cdot 3! = 3$ です。

### 計算

$t = x^2$ とおくと $dt = 2x\,dx$、$x: 0 \to \infty$ のとき $t: 0 \to \infty$ です。$x^7\,dx = x^6\cdot x\,dx = t^3\cdot\dfrac{dt}{2}$ なので

$$\int_0^{\infty} x^7 e^{-x^2}\,dx = \frac12\int_0^{\infty} t^{3} e^{-t}\,dt = \frac12\,\Gamma(4) = \frac12\cdot 3! = 3.$$

ここで $\Gamma(s) = \displaystyle\int_0^{\infty} t^{s-1}e^{-t}\,dt$、自然数 $n$ に対して $\Gamma(n+1) = n!$ を使いました。

**別解（部分積分）** $I_n = \displaystyle\int_0^\infty x^{2n+1}e^{-x^2}dx$ とおくと、部分積分により $I_n = n I_{n-1}$、$I_0 = \tfrac12$ が成り立ちます。よって $I_3 = 3\cdot2\cdot1\cdot\tfrac12 = 3$ です。

### ポイント

- 一般に $\displaystyle\int_0^\infty x^{2n+1}e^{-x^2}\,dx = \frac{n!}{2}$、$\displaystyle\int_0^\infty x^{2n}e^{-x^2}\,dx = \frac{(2n-1)!!}{2^{n+1}}\sqrt{\pi}$ です。
- 置換で $dx = \dfrac{dt}{2\sqrt t}$ の係数 $\tfrac12$ を落として $\Gamma(4) = 6$ と答える誤りが典型的です。
- $\Gamma(s)$ の指数は $s-1$ です。$t^3$ に対応するのは $\Gamma(4)$ であって $\Gamma(3)$ ではありません。
