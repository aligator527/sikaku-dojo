一般二項展開 $(1+x)^{1/2} = \sum_k \dbinom{1/2}{k}x^k$ の 3 次の係数が誤差の主要項の係数です。$\dbinom{1/2}{3} = \dfrac{\frac12\cdot\left(-\frac12\right)\cdot\left(-\frac32\right)}{3!} = \dfrac{1}{16}$ なので、主要項は $\dfrac{x^3}{16}$ です。

### 計算

$$\binom{1/2}{1} = \frac12,\qquad \binom{1/2}{2} = \frac{\frac12\cdot\left(-\frac12\right)}{2!} = -\frac18,\qquad \binom{1/2}{3} = \frac{\frac12\cdot\left(-\frac12\right)\cdot\left(-\frac32\right)}{3!} = \frac{3/8}{6} = \frac{1}{16}$$

より

$$\sqrt{1+x} = 1 + \frac x2 - \frac{x^2}{8} + \frac{x^3}{16} - \frac{5x^4}{128} + \cdots \qquad (|x| < 1).$$

したがって誤差の主要項は $\dfrac{x^3}{16}$ です。

（例：$\sqrt{1.02} \approx 1 + 0.01 - 0.00005 = 1.00995$ の誤差は約 $\dfrac{0.02^3}{16} = 5\times10^{-7}$ です。）

### 各選択肢の検討

1. 誤り。符号の誤りです。$\left(-\tfrac12\right)\left(-\tfrac32\right) > 0$ なので 3 次の係数は正です。
2. 正しい。
3. 誤り。分子を $\left(\tfrac12\right)^3$ とし、$\tfrac12, -\tfrac12, -\tfrac32$ と 1 ずつ減らしていく一般二項係数の形を使っていません。
4. 誤り。分子 $\tfrac38$ を $3! = 6$ で割り忘れています。

### ポイント

- テイラーの定理（ラグランジュの剰余）を使うと、誤差は $\dfrac{f'''(\xi)}{3!}x^3 = \dfrac{1}{16}(1+\xi)^{-5/2}x^3$（$\xi$ は $0$ と $x$ の間）と正確に表せ、$x > 0$ なら誤差は正で $\dfrac{x^3}{16}$ 以下と評価できます。
- 近似式の精度を問われたら「打ち切った次の項」を見積もるのが基本です。
