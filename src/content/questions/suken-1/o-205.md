部分分数に分解し、$1 < |z| < 2$ で収束する形に項ごとに展開します。$\dfrac{1}{z+1}$ は $\left|\dfrac1z\right| < 1$ を使って負べきに、$\dfrac{1}{z-2}$ は $\left|\dfrac z2\right| < 1$ を使って正べきに展開するので、正しいのは 3 です。

### 計算

$$f(z) = \frac{z}{(z+1)(z-2)} = \frac{1/3}{z+1} + \frac{2/3}{z-2}$$

（$z = -1$ で $\dfrac{-1}{-3} = \dfrac13$、$z = 2$ で $\dfrac{2}{3}$）。

$|z| > 1$ では

$$\frac{1}{z+1} = \frac{1}{z}\cdot\frac{1}{1 + \frac1z} = \sum_{n=0}^{\infty}\frac{(-1)^{n}}{z^{n+1}} = \sum_{n=1}^{\infty}\frac{(-1)^{n-1}}{z^{n}}.$$

$|z| < 2$ では

$$\frac{1}{z-2} = -\frac12\cdot\frac{1}{1 - \frac z2} = -\frac12\sum_{n=0}^{\infty}\frac{z^{n}}{2^{n}}.$$

よって

$$f(z) = \frac13\sum_{n=1}^{\infty}\frac{(-1)^{n-1}}{z^{n}} - \frac13\sum_{n=0}^{\infty}\frac{z^{n}}{2^{n}}\qquad (1 < |z| < 2).$$

### 各選択肢の検討

1. 誤り。両方の項を正べきに展開したもので、$|z| < 1$ でのテイラー展開です。$1 < |z|$ では $\sum (-1)^n z^n$ が発散します。
2. 誤り。$\dfrac{1}{1 + 1/z}$ を $\dfrac{1}{1 - 1/z}$ と取り違え、符号の交代 $(-1)^{n-1}$ が消えています。
3. 正しい。上の計算のとおりです。
4. 誤り。両方の項を負べきに展開したもので、$|z| > 2$ での展開です。
5. 誤り。$\dfrac{1}{z-2} = -\dfrac12\cdot\dfrac{1}{1 - z/2}$ の係数 $-\dfrac12$ のうち $\dfrac12$ を掛け忘れ、正べきの部分が 2 倍になっています。

### ポイント

- ローラン展開は領域ごとに異なります。各項について「$|z|$ より小さい定数」なら $\dfrac{1}{z}$ でくくって負べき、「大きい定数」なら定数でくくって正べき、と判断します。
- 展開の検算には、$z^{-1}$ の係数 $= \dfrac{1}{2\pi i}\displaystyle\oint_{|z|=r} f\,dz$（$1<r<2$）が使えます。円の内部の極は $z=-1$ だけで留数は $\dfrac13$ なので、3 の $z^{-1}$ の係数 $\dfrac13$ と一致します。
