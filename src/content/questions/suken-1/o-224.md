ケーリー・ハミルトンの定理 $\varphi(A) = O$ により、$\lambda^5$ を $\varphi(\lambda)$ で割った余り $r(\lambda)$ に $A$ を代入したものが $A^5$ です。$\varphi$ の根 $1, -2, 3$ で $r(\lambda) = \lambda^5$ となるように $r$ を決めると $r(\lambda) = 22\lambda^2 + 33\lambda - 54$ で、正しいのは 1 です。

### 計算

$\varphi(\lambda) = (\lambda - 1)(\lambda + 2)(\lambda - 3)$ です。$\lambda^{5} = \varphi(\lambda)q(\lambda) + r(\lambda)$、$r(\lambda) = a\lambda^{2} + b\lambda + c$ とおき、根を代入すると

$$\begin{cases} a + b + c = 1 \\ 4a - 2b + c = -32 \\ 9a + 3b + c = 243 \end{cases}$$

第 2 式 − 第 1 式から $a - b = -11$、第 3 式 − 第 1 式から $4a + b = 121$。よって $a = 22,\ b = 33,\ c = -54$ です。ケーリー・ハミルトンの定理より $\varphi(A) = O$ なので

$$A^{5} = \varphi(A)q(A) + r(A) = 22A^{2} + 33A - 54I.$$

**別解（次数下げ）** $A^{3} = 2A^{2} + 5A - 6I$ を繰り返し使うと

$$A^{4} = 2A^{3} + 5A^{2} - 6A = 9A^{2} + 4A - 12I,\qquad A^{5} = 9A^{3} + 4A^{2} - 12A = 22A^{2} + 33A - 54I.$$

### 各選択肢の検討

1. 正しい。上の計算のとおりです。
2. 誤り。$A^{4}$ の表示です。次数下げの回数を 1 回少なく数えています。
3. 誤り。固有値を $-1, 2, -3$ と符号を逆にして（$\varphi(-\lambda)$ の根で）連立方程式を立てると、この式になります。
4. 誤り。定数項の符号を誤っています。$\lambda = 1$ を代入すると $22 + 33 + 54 = 109 \neq 1^{5}$ で、すぐに誤りと分かります。

### ポイント

- $A^{n}$ や $A$ の高次多項式は、$\varphi(\lambda)$ で割った余りに帰着させます。根が相異なるときは、余りを根での値から決める方法（ラグランジュ補間）が速いです。
- $A$ の固有値は相異なるので最小多項式は $\varphi$ 自身で、$I, A, A^{2}$ は一次独立です。したがって $A^{5} = aA^2 + bA + cI$ の表し方は一通りに決まります。
- 重根がある場合は、余りの導関数の値も条件に加えます（例：$\varphi = (\lambda - 2)^2(\lambda - 1)$ なら $r(2) = 2^5$、$r'(2) = 5\cdot 2^4$、$r(1) = 1$）。
