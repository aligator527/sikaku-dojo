最大値の分布は「すべてが $m$ 以下」という事象から分布関数を求めるのが定石です。$M$ の分布関数は $m^3$、密度関数は $3m^2$ となり、$E[M] = \tfrac34$、$E[M^2] = \tfrac35$ から $V[M] = \tfrac35 - \tfrac{9}{16} = \tfrac{3}{80} = 0.0375$ です。

### 計算

$0 \le m \le 1$ のとき、独立性から

$$P(M \le m) = P(X_1 \le m)\,P(X_2 \le m)\,P(X_3 \le m) = m^3.$$

微分して密度関数は $f_M(m) = 3m^2\ (0 \le m \le 1)$ です。

$$E[M] = \int_0^1 m\cdot 3m^2\,dm = \frac34,\qquad E[M^2] = \int_0^1 m^2\cdot 3m^2\,dm = \frac35.$$

$$V[M] = E[M^2] - (E[M])^2 = \frac35 - \frac{9}{16} = \frac{48 - 45}{80} = \frac{3}{80} = 0.0375.$$

### ポイント

- $n$ 個の独立な $U(0,1)$ の最大値はベータ分布 $\mathrm{Beta}(n, 1)$ に従い、$E[M] = \dfrac{n}{n+1}$、$V[M] = \dfrac{n}{(n+1)^2(n+2)}$ です（$n=3$ で $\tfrac{3}{80}$）。
- 最小値は $P(\min > m) = (1-m)^n$ から求めます。最大値と最小値で「以下」「より大きい」を取り違えないようにします。
- $V[M] = E[M^2] - (E[M])^2$ の第 2 項を $E[M^2]$ から引き忘れたり、$E[M]^2$ を $E[M^2]$ と混同したりする誤りが典型です。
