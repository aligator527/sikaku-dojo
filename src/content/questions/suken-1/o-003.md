$A^5$ を直接計算する必要はありません。$A$ の固有値を $\lambda_1,\lambda_2,\lambda_3$ とすると $A^5$ の固有値は $\lambda_i^5$ で、トレースは固有値の和なので $\operatorname{tr}(A^5) = \sum \lambda_i^5$ です。$A$ の固有値は $4, 1, 1$ なので答えは $4^5 + 1 + 1 = 1026$ です。

### 計算

すべての成分が $1$ の行列を $J$ とすると $A = I + J$ です。$J$ は階数 $1$ で、$J\boldsymbol{1} = 3\boldsymbol{1}$（$\boldsymbol 1 = (1,1,1)^{\mathsf T}$）なので固有値は $3, 0, 0$ です。したがって $A$ の固有値は $1$ を足した

$$4,\ 1,\ 1$$

です。検算として、$\operatorname{tr}A = 4+1+1 = 6$（対角成分の和 $2+2+2$ と一致）、$\det A = 4\cdot1\cdot1 = 4$ も直接計算と一致します。

$A$ は実対称行列なので直交行列 $P$ で $A = P\,\mathrm{diag}(4,1,1)\,P^{\mathsf T}$ と対角化でき、

$$\operatorname{tr}(A^5) = \operatorname{tr}\bigl(P\,\mathrm{diag}(4^5,1,1)\,P^{\mathsf T}\bigr) = 4^5 + 1^5 + 1^5 = 1024 + 2 = 1026.$$

### ポイント

- $\operatorname{tr}(A^k) = \sum_i \lambda_i^k$、$\det A = \prod_i \lambda_i$ は対角化できない行列でも（ジョルダン標準形・三角化により）成り立ちます。
- $(\operatorname{tr}A)^5 = 6^5 = 7776$ と混同する誤りや、重複固有値 $1$ を 1 回しか数えない誤り（$1025$）に注意します。
- 「単位行列＋階数 1 の行列」の形は固有値がすぐに分かる典型です。
