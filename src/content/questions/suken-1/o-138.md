  $F(x, y) = x^{3} + y^{3} - 3xy$ とおくと

  $$F_x = 3x^{2} - 3y,\qquad F_y = 3y^{2} - 3x,\qquad F_{xx} = 6x.$$

  **(1)** $F = 0$ かつ $F_y = 0$ となる実数の点を求める。$F_y = 0$ より $x = y^2$。$F = 0$ に代入すると

  $$y^{6} + y^{3} - 3y^{3} = y^{3}(y^{3} - 2) = 0$$

  より $y = 0$ または $y = \sqrt[3]{2}$。よって求める点は

  $$(0, 0),\qquad \left(\sqrt[3]{4},\ \sqrt[3]{2}\right).$$

  **(2)** $F_y \neq 0$ となる点の近くでは、陰関数定理により $y = \varphi(x)$ と表され

  $$\varphi'(x) = -\frac{F_x}{F_y} = -\frac{x^{2} - y}{y^{2} - x}.$$

  $\varphi'(x_0) = 0$ となるのは $F_x(x_0, y_0) = 0$、すなわち $y_0 = x_0^2$ のときである。$F = 0$ に代入すると

  $$x_0^{3} + x_0^{6} - 3x_0^{3} = x_0^{3}(x_0^{3} - 2) = 0$$

  より $x_0 = 0$ または $x_0 = \sqrt[3]{2}$。$x_0 = 0$ のとき点は $(0, 0)$ で、(1) より $F_y = 0$ となり陰関数として表せないので除く。

  $x_0 = \sqrt[3]{2}$ のとき $y_0 = \sqrt[3]{4}$ であり、$F_y = 3\left(\sqrt[3]{16} - \sqrt[3]{2}\right) = 3\left(2\sqrt[3]{2} - \sqrt[3]{2}\right) = 3\sqrt[3]{2} \neq 0$。

  恒等式 $F_x + F_y\varphi' = 0$ を $x$ で微分すると

  $$F_{xx} + 2F_{xy}\varphi' + F_{yy}(\varphi')^{2} + F_y\varphi'' = 0.$$

  この点では $\varphi' = 0$ なので

  $$\varphi''(x_0) = -\frac{F_{xx}}{F_y} = -\frac{6\sqrt[3]{2}}{3\sqrt[3]{2}} = -2 < 0.$$

  よって $\varphi$ は $x = \sqrt[3]{2}$ で極大となり、極大値は $y_0 = \sqrt[3]{4}$ である。極値をとる点はこの 1 点のみである。

デカルトの正葉線 $x^3 + y^3 = 3xy$ の陰関数の極値問題です。陰関数 $y = \varphi(x)$ の極値の候補は $F = 0,\ F_x = 0,\ F_y \neq 0$ を満たす点で、ここでは $\left(\sqrt[3]{2}, \sqrt[3]{4}\right)$ だけです。$\varphi'' = -F_{xx}/F_y = -2 < 0$ から極大値 $\sqrt[3]{4}$ をとります。

### 解答の組み立て

1. **陰関数定理の条件** $F_y \neq 0$ の点の近くでのみ $y = \varphi(x)$ と表せます。(1) の 2 点のうち、原点は曲線が自分自身と交わる結節点（特異点、$F_x = F_y = 0$）、$\left(\sqrt[3]{4}, \sqrt[3]{2}\right)$ は接線が $y$ 軸に平行になる点です。
2. **極値の候補** $\varphi' = 0 \iff F_x = 0$（$F_y \neq 0$ のもとで）です。$F = 0$ と連立して候補を求めます。
3. **2 階微分** $\varphi' = 0$ の点では $\varphi'' = -F_{xx}/F_y$ と簡単になります。符号で極大・極小を判定します。

### ポイント

- 曲線は $y = x$ に関して対称なので、(1) の点 $\left(\sqrt[3]{4}, \sqrt[3]{2}\right)$ と (2) の点 $\left(\sqrt[3]{2}, \sqrt[3]{4}\right)$ は互いに $x$ と $y$ を入れ替えた関係にあります。検算に使えます。
- 原点も $F_x = 0$ を満たしますが、$F_y = 0$ なので陰関数定理が使えません。候補から除く理由を答案に書く必要があります。
- 数値で確かめると、$x = \sqrt[3]{2} \pm 0.05$ での $y$ の値（曲線の上側の枝）はどちらも $\sqrt[3]{4} \approx 1.5874$ より小さく、極大であることが確認できます。
