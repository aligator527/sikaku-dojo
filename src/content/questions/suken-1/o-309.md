modelAnswer: |
  **設定** 選んだ 2 点を $U, V$ とし、小さい方を $S$、大きい方を $T$ とする（$U = V$ となる確率は $0$ なので無視する）。3 本の長さは

  $$a = S,\qquad b = T - S,\qquad c = 1 - T$$

  である。$(U, V)$ は単位正方形上の一様分布に従うので、$(S, T)$ は $\{0 < s < t < 1\}$ 上で密度 $2$ をもつ。$(s, t) \mapsto (a, b) = (s,\ t - s)$ はヤコビアンが $1$ の 1 対 1 の写像なので、$(a, b)$ は三角形

  $$\Delta = \{(a, b) \mid a > 0,\ b > 0,\ a + b < 1\}$$

  上で密度 $2$ の一様分布に従う。したがって、$\Delta$ 内の領域 $E$ に対して $P\bigl((a, b) \in E\bigr) = 2 \times (E \text{ の面積})$ である。

  **(1)** 3 本で三角形ができる条件は $a < b + c,\ b < c + a,\ c < a + b$ である。$a + b + c = 1$ より、$a < b + c \iff a < \tfrac12$ などとなるから、条件は

  $$a < \tfrac12,\qquad b < \tfrac12,\qquad c = 1 - a - b < \tfrac12 \iff a + b > \tfrac12.$$

  これは 3 点 $(\tfrac12, 0),\ (0, \tfrac12),\ (\tfrac12, \tfrac12)$ を頂点とする直角二等辺三角形で、面積は $\tfrac18$。よって求める確率は $2 \cdot \tfrac18 = \dfrac14$ である。

  **(2)** (1) の領域（三角形ができる場合）を $D$ とする。$D$ の中で、長さ $c$ の辺の対角が直角または鈍角になる条件は

  $$c^2 \ge a^2 + b^2 \iff (1 - a - b)^2 \ge a^2 + b^2 \iff 1 - 2a - 2b + 2ab \ge 0 \iff (1-a)(1-b) \ge \tfrac12.$$

  $u = 1 - a,\ v = 1 - b$ とおくと（面積を変えない変換）、$D$ は $u > \tfrac12,\ v > \tfrac12,\ u + v < \tfrac32$ となり、この中で $uv \ge \tfrac12$ を満たす領域を $O_c$ とする。双曲線 $uv = \tfrac12$ と直線 $u + v = \tfrac32$ は $(1, \tfrac12),\ (\tfrac12, 1)$ で交わり、$\tfrac12 \le u \le 1$ で $\dfrac{1}{2u} \le \dfrac32 - u$ が成り立つ（$(2u-1)(u-1) \le 0$ と同値）。よって

  $$|O_c| = \int_{1/2}^{1}\left(\frac32 - u - \frac{1}{2u}\right)du = \left[\frac32 u - \frac{u^2}{2} - \frac12\log u\right]_{1/2}^{1} = 1 - \left(\frac58 + \frac12\log 2\right) = \frac38 - \frac12\log 2.$$

  $(a, b, c)$ の分布は $a, b, c$ の入れ替えで不変である（たとえば $(a, b) \mapsto (c, b) = (1 - a - b,\ b)$ は $\Delta$ を $\Delta$ に移すヤコビアン $-1$ の写像）。したがって、長さ $a$ の辺、長さ $b$ の辺の対角が直角以上になる領域 $O_a,\ O_b$ も面積は $|O_c|$ に等しい。また三角形の内角のうち 2 つ以上が $90^\circ$ 以上になることはないので、$O_a, O_b, O_c$ は互いに重ならない（境界は面積 $0$）。

  よって鋭角三角形になる領域の面積は

  $$\frac18 - 3\left(\frac38 - \frac12\log 2\right) = \frac32\log 2 - 1$$

  であり、求める確率は

  $$2\left(\frac32\log 2 - 1\right) = 3\log 2 - 2\ (\approx 0.0794).$$

幾何確率の代表的な問題です。3 本の長さの組を「正三角形状の領域（単体）上の一様分布」として扱えれば、三角形・鋭角三角形の条件はすべて領域の面積の計算になります。答えは (1) $\tfrac14$、(2) $3\log 2 - 2 \approx 0.079$ です。

### 計算の要点

- **一様性の確認** 2 点を小さい順に並べると密度は $2$ になります。この係数 $2$ を忘れると、確率がすべて半分になります。
- **三角形の条件** 「最長辺が他の 2 辺の和より短い」は、周の長さが $1$ なので「どの辺も $\tfrac12$ 未満」と同値です。
- **鈍角の条件** 余弦定理から、辺 $c$ の対角が鈍角 $\iff c^2 > a^2 + b^2$ です。$c = 1 - a - b$ を代入すると $a, b$ の 2 次の項が消え、双曲線 $(1-a)(1-b) = \tfrac12$ が境界になります。
- **対称性** 3 辺のどれが最長辺になるかで 3 つの場合に分かれますが、分布が対称なので 1 つ計算して 3 倍すれば済みます。

### ポイント

- 鋭角三角形になる確率は約 $8\%$ で、三角形ができる場合（$25\%$）の約 $3$ 割にすぎません。結果の大きさで検算できます。
- 「1 点目で切った後、長い方の棒をさらに切る」など切り方を変えると確率も変わります。問題文の設定（2 点を独立に一様に選ぶ）を正確に式にすることが大切です。
- $\log$ の積分区間を取り違えて $\tfrac38 + \tfrac12\log 2$ とすると、確率が負になります。符号の確認を忘れないようにします。
