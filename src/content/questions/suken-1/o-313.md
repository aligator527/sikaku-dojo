残差平方和 $Q(a, b, c) = \sum (y_i - a - bx_i - cx_i^2)^2$ を $a, b, c$ で偏微分して $0$ とおくと、3 元連立 1 次方程式（正規方程式）が得られます。$x$ が $0$ について対称なので奇数乗の和が消え、$a = 0,\ b = -0.4,\ c = 2$ がすぐに求まります。$x = 3$ での値は $16.8$ です。

### 計算

正規方程式は

$$\begin{aligned}
na + b\textstyle\sum x_i + c\sum x_i^2 &= \textstyle\sum y_i,\\
a\textstyle\sum x_i + b\sum x_i^2 + c\sum x_i^3 &= \textstyle\sum x_iy_i,\\
a\textstyle\sum x_i^2 + b\sum x_i^3 + c\sum x_i^4 &= \textstyle\sum x_i^2y_i.
\end{aligned}$$

データから $n = 5$、$\sum x_i = \sum x_i^3 = 0$、$\sum x_i^2 = 10$、$\sum x_i^4 = 34$、

$$\textstyle\sum y_i = 20,\quad \sum x_iy_i = -18 - 2 + 0 + 2 + 14 = -4,\quad \sum x_i^2y_i = 36 + 2 + 0 + 2 + 28 = 68.$$

よって

$$5a + 10c = 20,\qquad 10b = -4,\qquad 10a + 34c = 68.$$

第 2 式から $b = -0.4$。第 1 式から $a = 4 - 2c$ を第 3 式に代入して $40 + 14c = 68$、$c = 2$、$a = 0$。

当てはめた 2 次式は $y = -0.4x + 2x^2$ で、$x = 3$ のとき

$$y = -1.2 + 18 = 16.8.$$

（参考：当てはめ値は $8.8,\ 2.4,\ 0,\ 1.6,\ 7.2$、残差平方和は $0.4$ です。）

### ポイント

- 多項式回帰も、係数について 1 次なので「線形」最小二乗法です。正規方程式は $X^{\mathsf T}X\boldsymbol\beta = X^{\mathsf T}\boldsymbol y$ と書けます。
- $x$ の値が $0$ について対称だと $\sum x_i = \sum x_i^3 = 0$ となり、1 次の係数 $b$ だけが分離されます。計算の前に対称性を確認すると楽になります。
- 直線 $y = a + bx$ を当てはめた場合（$y = 4 - 0.4x$、$x = 3$ で $2.8$）とは値が大きく異なります。モデルの次数を取り違えないようにします。
