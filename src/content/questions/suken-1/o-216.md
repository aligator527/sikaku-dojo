  $A$ を $n$ 次の実交代行列（$A^{\mathsf T} = -A$ を満たす実正方行列）とし、$I$ を $n$ 次の単位行列とする。次の (1)〜(3) を証明せよ。

  (1) $n$ が奇数ならば $\det A = 0$ である。

  (2) $I + A$ は正則である。

  (3) $Q = (I - A)(I + A)^{-1}$ は直交行列である。
modelAnswer: |
  **(1)** 転置しても行列式は変わらず、$n$ 次正方行列では $\det(-A) = (-1)^{n}\det A$ だから

  $$\det A = \det A^{\mathsf T} = \det(-A) = (-1)^{n}\det A = -\det A\qquad (n \text{ は奇数}).$$

  よって $2\det A = 0$、すなわち $\det A = 0$ である。

  **(2)** 実ベクトル $\boldsymbol x$ が $(I + A)\boldsymbol x = \boldsymbol 0$ を満たすとする。左から $\boldsymbol x^{\mathsf T}$ を掛けると

  $$\boldsymbol x^{\mathsf T}\boldsymbol x + \boldsymbol x^{\mathsf T}A\boldsymbol x = 0.$$

  ここで $\boldsymbol x^{\mathsf T}A\boldsymbol x$ は $1\times 1$ 行列（実数）なので転置しても等しく、

  $$\boldsymbol x^{\mathsf T}A\boldsymbol x = \left(\boldsymbol x^{\mathsf T}A\boldsymbol x\right)^{\mathsf T} = \boldsymbol x^{\mathsf T}A^{\mathsf T}\boldsymbol x = -\boldsymbol x^{\mathsf T}A\boldsymbol x$$

  より $\boldsymbol x^{\mathsf T}A\boldsymbol x = 0$。したがって $\|\boldsymbol x\|^{2} = \boldsymbol x^{\mathsf T}\boldsymbol x = 0$、$\boldsymbol x = \boldsymbol 0$ である。$(I + A)\boldsymbol x = \boldsymbol 0$ が自明な解しかもたないので、$I + A$ は正則である。

  **(3)** $-A$ も実交代行列なので、(2) より $I - A$ も正則である。また

  $$(I - A)(I + A) = I - A^{2} = (I + A)(I - A)$$

  だから、この式の左右から $(I+A)^{-1}$ を掛けて $(I+A)^{-1}(I - A) = (I - A)(I + A)^{-1}$ を得る。すなわち $Q = (I+A)^{-1}(I-A)$ とも書ける。

  転置について $(I + A)^{\mathsf T} = I - A$、$(I - A)^{\mathsf T} = I + A$、$\bigl(X^{-1}\bigr)^{\mathsf T} = \bigl(X^{\mathsf T}\bigr)^{-1}$ を使うと

  $$Q^{\mathsf T} = \bigl((I+A)^{-1}\bigr)^{\mathsf T}(I - A)^{\mathsf T} = (I - A)^{-1}(I + A).$$

  よって

  $$Q^{\mathsf T}Q = (I - A)^{-1}(I + A)\cdot(I + A)^{-1}(I - A) = (I - A)^{-1}(I - A) = I.$$

  したがって $Q$ は直交行列である。（証明終）

実交代行列の基本性質を順に示す問題です。(1) は行列式の性質だけ、(2) は二次形式 $\boldsymbol x^{\mathsf T}A\boldsymbol x$ が常に $0$ になることが鍵です。(3) の $Q$ はケーリー変換と呼ばれ、交代行列から直交行列を作る標準的な方法です。

### 証明の組み立て

1. **(1)** 「$\det A^{\mathsf T} = \det A$」と「$-1$ 倍で $(-1)^n$ 倍」の 2 つを組み合わせるだけです。
2. **(2)** 正則性は「$(I+A)\boldsymbol x = \boldsymbol 0 \Rightarrow \boldsymbol x = \boldsymbol 0$」で示すのが簡潔です。固有値を使う方法（実交代行列の固有値は純虚数なので $-1$ は固有値でない）もありますが、その場合は純虚数であることの証明も必要になります。
3. **(3)** $Q^{\mathsf T}Q$ を計算するとき、$(I+A)$ と $(I+A)^{-1}$ を隣に並べるために、$I - A$ と $(I + A)^{-1}$ が可換であることを先に示しておきます。

### ポイント

- $n$ が偶数のときは $\det A = 0$ とは限りません。例えば $A = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$ では $\det A = 1$ です。
- (2) は実行列であることを使っています。複素の交代行列では $\boldsymbol x^{\mathsf T}\boldsymbol x = 0$ となる非零ベクトルがあり、同じ議論は成り立ちません。
- ケーリー変換で得られる直交行列 $Q$ は $-1$ を固有値にもちません。逆に、そのような直交行列 $Q$ は $A = (I - Q)(I + Q)^{-1}$ によって交代行列から得られます。
