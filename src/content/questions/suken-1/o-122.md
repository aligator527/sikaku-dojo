パラメータ $a$ を含む積分 $I(a) = \displaystyle\int_0^\infty e^{-x^2}\cos ax\,dx$ を考え、$a$ で微分して部分積分すると $I'(a) = -\dfrac a2 I(a)$ という微分方程式が得られます。$I(0) = \dfrac{\sqrt\pi}{2}$ から $I(a) = \dfrac{\sqrt\pi}{2}e^{-a^2/4}$ で、$a = 2$ のとき $\dfrac{\sqrt\pi}{2e} \approx 0.3260$ です。

### 計算

$\left|\dfrac{\partial}{\partial a}\left(e^{-x^2}\cos ax\right)\right| = |x|e^{-x^2}|\sin ax| \le xe^{-x^2}$ で、右辺は $[0, \infty)$ で積分可能なので、積分記号下で微分できます。

$$I'(a) = -\int_0^\infty x e^{-x^2}\sin ax\,dx.$$

$xe^{-x^2} = \dfrac{d}{dx}\left(-\dfrac12 e^{-x^2}\right)$ として部分積分すると

$$I'(a) = \Bigl[\frac12 e^{-x^2}\sin ax\Bigr]_0^\infty - \frac{a}{2}\int_0^\infty e^{-x^2}\cos ax\,dx = -\frac a2 I(a).$$

これを解くと $I(a) = I(0)\,e^{-a^2/4} = \dfrac{\sqrt\pi}{2}e^{-a^2/4}$。$a = 2$ とすると

$$\int_{0}^{\infty} e^{-x^{2}}\cos 2x\,dx = \frac{\sqrt\pi}{2}e^{-1} = \frac{1.77245\cdots}{2\times 2.71828\cdots} = 0.32602\cdots.$$

小数第4位を四捨五入して $0.326$ です。

**別解（複素数で平方完成）** $\displaystyle\int_{-\infty}^{\infty} e^{-x^2 + 2ix}\,dx = e^{-1}\int_{-\infty}^{\infty} e^{-(x-i)^2}\,dx = e^{-1}\sqrt\pi$（積分路を実軸に平行移動できることはコーシーの積分定理で示せる）の実部の半分としても求められます。

### ポイント

- ガウス関数のフーリエ変換は再びガウス関数になります：$\displaystyle\int_{-\infty}^\infty e^{-x^2}\cos ax\,dx = \sqrt\pi\,e^{-a^2/4}$。
- 指数を $-a^2/2$ や $-a^2$ と誤ると、答えが $\dfrac{\sqrt\pi}{2}e^{-2}\ (\approx 0.120)$ や $\dfrac{\sqrt\pi}{2}e^{-4}$ になります。微分方程式 $I' = -\dfrac a2 I$ から解き直して確かめます。
- 積分記号下の微分には、$a$ によらない可積分な優関数が必要です。2 次ではこの確認も答案に書きます。
