  $a > 0$ とする。

  (1) 方程式 $x^2 - a = 0$ にニュートン法を適用すると、漸化式

  $$x_{n+1} = \frac12\left(x_n + \frac{a}{x_n}\right)$$

  が得られることを示せ。

  (2) $x_0 > 0$ を任意にとる。$n \ge 1$ のとき $x_n \ge \sqrt a$ であり、数列 $\{x_n\}_{n \ge 1}$ は単調に減少して $\sqrt a$ に収束することを示せ。

  (3) $a = 2,\ x_0 = 1$ のとき、$0 < x_3 - \sqrt2 < 10^{-5}$ であることを示せ。ただし $1.414 < \sqrt2 < 1.415$ を用いてよい。
modelAnswer: |
  **(1)** $f(x) = x^2 - a$ とすると $f'(x) = 2x$。点 $(x_n, f(x_n))$ における接線 $y = f(x_n) + 2x_n(x - x_n)$ と $x$ 軸の交点を $x_{n+1}$ とすると

  $$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} = x_n - \frac{x_n^2 - a}{2x_n} = \frac{x_n^2 + a}{2x_n} = \frac12\left(x_n + \frac{a}{x_n}\right).$$

  **(2)** $x_n > 0$ ならば $x_{n+1} > 0$ なので、帰納的にすべての $n$ で $x_n > 0$ である。漸化式から

  $$x_{n+1} - \sqrt a = \frac{x_n^2 - 2\sqrt a\,x_n + a}{2x_n} = \frac{(x_n - \sqrt a)^2}{2x_n} \ge 0 \qquad (\ast)$$

  なので、$n \ge 1$ で $x_n \ge \sqrt a$。このとき

  $$x_{n+1} - x_n = \frac{a - x_n^2}{2x_n} \le 0$$

  だから、$\{x_n\}_{n\ge1}$ は単調減少で、$\sqrt a$ で下に有界である。よって極限 $L\ (\ge \sqrt a > 0)$ が存在し、漸化式で $n \to \infty$ とすると $L = \frac12\left(L + \frac aL\right)$、すなわち $L^2 = a$。$L > 0$ より $L = \sqrt a$ である。

  **(3)** $e_n = x_n - \sqrt2$ とおく。$x_0 = 1$ から $x_1 = \frac12(1 + 2) = \frac32$ で、$x_1 \neq \sqrt2$。$(\ast)$ より $e_n \ne 0$ ならば $e_{n+1} > 0$ であり、$x_n$ はすべて有理数なので $e_n \neq 0$ が保たれる。よって $n \ge 1$ で $e_n > 0$、$x_n > \sqrt2$ であり、$(\ast)$ から

  $$0 < e_{n+1} = \frac{e_n^2}{2x_n} < \frac{e_n^2}{2\sqrt2} < \frac{e_n^2}{2.828}.$$

  $\sqrt2 > 1.414$ より $e_1 = 1.5 - \sqrt2 < 0.086$。したがって

  $$e_2 < \frac{0.086^2}{2.828} = \frac{0.007396}{2.828} < 0.0027,\qquad e_3 < \frac{0.0027^2}{2.828} = \frac{0.00000729}{2.828} < 2.6\times10^{-6} < 10^{-5}.$$

  以上より $0 < x_3 - \sqrt2 < 10^{-5}$ である。

平方根を求めるニュートン法（バビロニアの方法）の収束を、恒等式 $x_{n+1} - \sqrt a = \dfrac{(x_n - \sqrt a)^2}{2x_n}$ を軸にして示す問題です。この 1 本の式から、1 回目以降は真の値より大きいこと、単調に減ること、誤差が 2 乗のオーダーで減ること（2 次収束）がすべて読み取れます。

### 証明の組み立て

1. **(1)** $f(x) = x^2 - a$ の接線の $x$ 切片を計算します。
2. **(2)** 恒等式 $(\ast)$ で $x_n \ge \sqrt a$ を示し、増減は $x_{n+1} - x_n$ の符号で調べます。極限の存在（単調有界）を言ってから、漸化式で極限をとって値を決めます。
3. **(3)** $(\ast)$ から $e_{n+1} < \dfrac{e_n^2}{2\sqrt a}$ を作り、具体的な数値で 2 回評価します。分母の $x_n$ を $\sqrt2$ で下から押さえるので、不等号の向きに注意します。

### ポイント

- 実際の値は $x_1 = 1.5,\ x_2 = 1.41666\cdots,\ x_3 = 1.4142156\cdots$ で、誤差は $8.6\times10^{-2} \to 2.5\times10^{-3} \to 2.1\times10^{-6}$ と、正しい桁数がほぼ倍々に増えます。
- 初期値 $x_0$ が $\sqrt a$ より小さくても、$x_1$ 以降は必ず $\sqrt a$ 以上になります。単調性を $n \ge 0$ から主張するのは誤りです。
- 極限を求める前に、極限が存在することを示す必要があります。「$L = \frac12(L + a/L)$ を解く」だけでは収束の証明になりません。
