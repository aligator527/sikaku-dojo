$x = e^{-t}$ と置換すると $\log x = -t$、$x^m\,dx = -e^{-(m+1)t}\,dt$ となり、ガンマ関数 $\Gamma(n+1) = n!$ の形に帰着します。値は $\dfrac{(-1)^n\,n!}{(m+1)^{n+1}}$ です。

### 計算

$x = e^{-t}$ とおくと、$x: 0 \to 1$ のとき $t: \infty \to 0$、$dx = -e^{-t}\,dt$ なので

$$\int_{0}^{1} x^{m}(\log x)^{n}\,dx = \int_{\infty}^{0} e^{-mt}(-t)^{n}\left(-e^{-t}\right)dt = (-1)^n\int_0^\infty t^{n}e^{-(m+1)t}\,dt.$$

さらに $u = (m+1)t$（$m + 1 > 0$）とおくと

$$(-1)^n\int_0^\infty \frac{u^{n}}{(m+1)^{n}}e^{-u}\,\frac{du}{m+1} = \frac{(-1)^n}{(m+1)^{n+1}}\,\Gamma(n+1) = \frac{(-1)^n\,n!}{(m+1)^{n+1}}.$$

例えば $m = 0,\ n = 1$ なら $\displaystyle\int_0^1\log x\,dx = -1$ で、公式の値 $\dfrac{-1}{1^2} = -1$ と一致します。

### 各選択肢の検討

1. 正しい。
2. 誤り。$u = (m+1)t$ の置換で $dt = \dfrac{du}{m+1}$ から出る因子 $\dfrac{1}{m+1}$ を落としています。
3. 誤り。$0 < x < 1$ では $\log x < 0$ なので、$n$ が奇数のとき積分は負になります。符号 $(-1)^n$ が必要です。
4. 誤り。$dx = -e^{-t}\,dt$ の $e^{-t}$ を落として、指数を $m$ のままにしています。$m = 0$ では値が定義できなくなり、$\displaystyle\int_0^1(\log x)^n\,dx = (-1)^n n!$ とも合いません。

### ポイント

- $\log x$ を含む $[0, 1]$ 上の積分は、$x = e^{-t}$ で $[0, \infty)$ 上のガンマ関数型の積分に直すのが定石です。
- $m > -1$ は、$x = 0$ の近くで積分が収束するための条件（置換後の $e^{-(m+1)t}$ が減衰する条件）です。
- 別解として、$\displaystyle\int_0^1 x^m\,dx = \frac{1}{m+1}$ の両辺を $m$ で $n$ 回微分しても同じ結果が得られます（$\dfrac{\partial}{\partial m}x^m = x^m\log x$）。
