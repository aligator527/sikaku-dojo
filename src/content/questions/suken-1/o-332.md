右辺に $\sqrt k$ を含むベルヌーイ型の微分方程式です。$u = \sqrt k$ と置き換えると $u$ についての 1 階線形微分方程式 $u' = 0.15 - 0.05u$ になり、$u(t) = 3 - 2e^{-t/20}$ と解けます。$t = 40\log 2$ では $u = 2.5$、$k = 6.25$ です。

### 計算

$u = \sqrt k\ (> 0)$ とおくと $k = u^2$、$\dfrac{dk}{dt} = 2u\dfrac{du}{dt}$ なので

$$2u\frac{du}{dt} = 0.3u - 0.1u^2 \quad\Longrightarrow\quad \frac{du}{dt} = 0.15 - 0.05u = -0.05\,(u - 3).$$

$u(0) = \sqrt{k(0)} = 1$ より

$$u(t) - 3 = (1 - 3)e^{-0.05t},\qquad u(t) = 3 - 2e^{-t/20}.$$

$t = 40\log 2$ のとき $e^{-t/20} = e^{-2\log 2} = \tfrac14$ なので

$$u = 3 - \frac24 = \frac52,\qquad k = u^2 = \frac{25}{4} = 6.25.$$

### ポイント

- $y' = P(t)y + Q(t)y^n$ の形（ベルヌーイ型）は $u = y^{1-n}$ で線形化できます。ここでは $n = \tfrac12$ なので $u = k^{1/2}$ です。
- $t \to \infty$ で $u \to 3$、$k \to 9$ となります。これは $0.3\sqrt k = 0.1k$ を満たす定常状態 $k^* = \left(\frac{0.3}{0.1}\right)^2$ で、貯蓄（投資）と資本の減耗がつり合う水準です。
- $u$ の式から $k$ に戻すときに 2 乗を忘れて $2.5$ と答える誤りに注意します。
