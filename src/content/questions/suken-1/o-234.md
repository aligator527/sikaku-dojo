modelAnswer: |
  A を $x$ 個、B を $y$ 個生産するとすると、問題は

  $$\text{最大化 } z = 4x + 3y,\qquad 2x + y \le 40,\quad x + y \le 24,\quad x + 3y \le 60,\quad x \ge 0,\ y \ge 0.$$

  **(1)** 実行可能領域は凸多角形で、その頂点は

  - $(0, 0)$
  - $(20, 0)$：$2x + y = 40$ と $y = 0$
  - $(16, 8)$：$2x + y = 40$ と $x + y = 24$（$x + 3y = 40 \le 60$）
  - $(6, 18)$：$x + y = 24$ と $x + 3y = 60$（$2x + y = 30 \le 40$）
  - $(0, 20)$：$x + 3y = 60$ と $x = 0$

  である。各頂点での $z$ は $0,\ 80,\ 88,\ 78,\ 60$ なので、最大値は $(16, 8)$ での $88$ である。

  **最大であることの根拠** 機械の制約に $1$、作業の制約に $2$ を掛けて足すと、任意の実行可能解について

  $$4x + 3y = 1\cdot(2x + y) + 2\cdot(x + y) \le 1\cdot 40 + 2\cdot 24 = 88.$$

  $(16, 8)$ で等号が成り立つので、最大値は $88$ である。

  よって、**A を 16 個、B を 8 個** 生産するとき、利益は最大の **88 万円** となる。

  **(2)** 目的関数を $z = px + 3y$ とする。$(16, 8)$ で等号となる制約は機械 $2x + y \le 40$ と作業 $x + y \le 24$ である。$(16, 8)$ が最適であるための条件は、目的関数の係数ベクトル $(p, 3)$ が、これらの制約の係数ベクトル $(2, 1)$、$(1, 1)$ の非負結合で表されること、すなわち

  $$(p, 3) = \alpha(2, 1) + \beta(1, 1),\qquad \alpha \ge 0,\ \beta \ge 0$$

  を満たす $\alpha, \beta$ が存在することである（このとき (1) と同様に $px + 3y \le 40\alpha + 24\beta$ が示せる。逆に条件が崩れると、隣の頂点へ移ると $z$ が増える）。$\alpha + \beta = 3$、$2\alpha + \beta = p$ を解くと

  $$\alpha = p - 3,\qquad \beta = 6 - p.$$

  $\alpha \ge 0,\ \beta \ge 0$ より、求める範囲は

  $$3 \le p \le 6.$$

  （$p = 3$ のときは $(6, 18)$ と $(16, 8)$ を結ぶ辺全体、$p = 6$ のときは $(16, 8)$ と $(20, 0)$ を結ぶ辺全体が最適解となり、$(16, 8)$ はその一つとして最適である。）

2 変数の生産計画問題を定式化して図解法で解き、さらに利益係数の変化に対する感度分析を行う問題です。最適解は機械と作業の制約がともに等号となる $(16, 8)$ で、利益は 88 万円です。A の利益が 3 万円以上 6 万円以下の範囲なら、この生産計画は最適のままです。

### 解き方の要点

- **頂点の列挙** 直線どうしの交点を求めたら、残りの制約を満たすかを必ず確かめます。例えば $2x + y = 40$ と $x + 3y = 60$ の交点 $(12, 16)$ は $x + y = 28 > 24$ で実行不可能です。
- **根拠の示し方** 頂点の値を比べるのは「凸多角形上の 1 次関数は頂点で最大」という事実に基づく方法です。答案では、それに加えて制約の非負結合 $1\cdot(\text{機械}) + 2\cdot(\text{作業})$ で上界 $88$ を示すと、短く厳密になります。この係数 $(1, 2, 0)$ は双対問題の最適解です。
- **(2) の別の見方** 等高線 $px + 3y = k$ の傾き $-\tfrac{p}{3}$ が、機械の直線の傾き $-2$ と作業の直線の傾き $-1$ の間にあればよく、$-2 \le -\tfrac p3 \le -1$ から $3 \le p \le 6$ が得られます。

### ポイント

- 感度分析では「最適な頂点で等号となる制約の組（最適基底）」が変わらない範囲を求めます。係数を変えるときは目的関数の傾き、右辺を変えるときは頂点の位置の変化を調べます。
- $p$ が範囲の外に出ると、$p < 3$ では $(6, 18)$、$p > 6$ では $(20, 0)$ が新たな最適解になります。
- 生産量を整数に限ると整数計画問題になり、一般には線形計画の解を丸めただけでは最適になりません（この問題では最適解がたまたま整数です）。
