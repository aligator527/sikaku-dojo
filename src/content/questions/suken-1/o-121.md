ベータ関数 $B(p, q) = \displaystyle\int_0^1 x^{p-1}(1-x)^{q-1}\,dx = \frac{\Gamma(p)\Gamma(q)}{\Gamma(p+q)}$ の $p = 4,\ q = 5$ の場合です。$I = \dfrac{3!\,4!}{8!} = \dfrac{1}{280}$ なので $\dfrac1I = 280$ です。

### 計算

自然数 $m, n$ に対して

$$\int_0^1 x^{m}(1-x)^{n}\,dx = B(m+1, n+1) = \frac{m!\,n!}{(m+n+1)!}.$$

$m = 3,\ n = 4$ を代入すると

$$I = \frac{3!\cdot 4!}{8!} = \frac{6\cdot 24}{40320} = \frac{144}{40320} = \frac{1}{280}.$$

**別解（展開）** $(1-x)^4 = 1 - 4x + 6x^2 - 4x^3 + x^4$ より

$$I = \int_0^1 (x^3 - 4x^4 + 6x^5 - 4x^6 + x^7)\,dx = \frac14 - \frac45 + 1 - \frac47 + \frac18 = \frac{70 - 224 + 280 - 160 + 35}{280} = \frac{1}{280}.$$

### ポイント

- ベータ関数の引数は指数に $1$ を足したもの（$x^{p-1}$ に対して $p$）です。$B(3, 4) = \dfrac{2!\,3!}{6!} = \dfrac{1}{60}$ と取り違えないようにします。
- 分母の階乗は $(m + n + 1)!$ です。$(m+n)!$ とすると $\dfrac{1}{35}$ になってしまいます。
- 部分積分を $n$ 回繰り返す方法でも同じ公式が得られます（$x^m$ を積分、$(1-x)^n$ を微分する側にとる）。
