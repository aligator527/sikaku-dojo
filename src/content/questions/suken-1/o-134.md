1 変数の展開 $e^x = 1 + x + \dfrac{x^2}{2} + \cdots$ と $\log(1+y) = y - \dfrac{y^2}{2} + \cdots$ を掛け合わせ、2 次以下の項を残します。結果は $y + xy - \dfrac{y^2}{2}$ です。

### 計算

$$e^{x}\log(1+y) = \left(1 + x + \frac{x^2}{2} + \cdots\right)\left(y - \frac{y^2}{2} + \cdots\right) = y + xy - \frac{y^{2}}{2} + (\text{3 次以上の項}).$$

**検算（偏微分係数による公式）** $f(0, 0) = 0$ で

$$f_x = e^x\log(1+y),\quad f_y = \frac{e^x}{1+y},\quad f_{xx} = e^x\log(1+y),\quad f_{xy} = \frac{e^x}{1+y},\quad f_{yy} = -\frac{e^x}{(1+y)^2}$$

より、原点で $f_x = 0,\ f_y = 1,\ f_{xx} = 0,\ f_{xy} = 1,\ f_{yy} = -1$。2 次までのテイラー展開

$$f(0,0) + f_x x + f_y y + \frac12\left(f_{xx}x^2 + 2f_{xy}xy + f_{yy}y^2\right) = y + xy - \frac{y^2}{2}$$

と一致します。

### 各選択肢の検討

1. 誤り。$\log(1+y)$ の 2 次の項の符号を誤っています（$\log(1+y) = y - \dfrac{y^2}{2} + \cdots$）。
2. 誤り。$\log(1+y)$ を $1 + y - \cdots$ のように定数項から始めています。$f(0, 0) = \log 1 = 0$ なので定数項は $0$ です。
3. 誤り。2 次の項の係数 $\dfrac12$ を落としています（$f_{xx}x^2 + 2f_{xy}xy + f_{yy}y^2$ をそのまま足した形）。
4. 正しい。

### ポイント

- 積の形の関数は、1 変数の展開の積をとるのが最も速い方法です。
- 公式を使う場合は、2 次の項が $\dfrac{1}{2!}\left(f_{xx}x^2 + 2f_{xy}xy + f_{yy}y^2\right)$ であること（$xy$ の係数は $f_{xy}$ そのもの）に注意します。
