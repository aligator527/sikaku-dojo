求める積分を $I$ とおき、$1\cdot\sqrt{x^2+1}$ と見て部分積分すると、右辺に再び $I$ が現れます。$\displaystyle\int\frac{dx}{\sqrt{x^2+1}} = \log\left(x + \sqrt{x^2+1}\right)$ を使って $I$ について解くと、$I = \dfrac12\left\{x\sqrt{x^2+1} + \log\left(x + \sqrt{x^2+1}\right)\right\} + C$ です。

### 計算

$$I = x\sqrt{x^2+1} - \int x\cdot\frac{x}{\sqrt{x^2+1}}\,dx = x\sqrt{x^2+1} - \int\frac{(x^2 + 1) - 1}{\sqrt{x^2+1}}\,dx = x\sqrt{x^2+1} - I + \int\frac{dx}{\sqrt{x^2+1}}.$$

$\dfrac{d}{dx}\log\left(x + \sqrt{x^2+1}\right) = \dfrac{1}{\sqrt{x^2+1}}$ なので

$$2I = x\sqrt{x^2+1} + \log\left(x + \sqrt{x^2+1}\right) + C' \quad\Longrightarrow\quad I = \frac12\left\{x\sqrt{x^2+1} + \log\left(x + \sqrt{x^2+1}\right)\right\} + C.$$

**検算** 右辺を微分すると $\dfrac12\left\{\sqrt{x^2+1} + \dfrac{x^2}{\sqrt{x^2+1}} + \dfrac{1}{\sqrt{x^2+1}}\right\} = \dfrac12\cdot\dfrac{2(x^2+1)}{\sqrt{x^2+1}} = \sqrt{x^2+1}$ となります。

### 各選択肢の検討

1. 誤り。対数の項の符号が逆です。これは $\displaystyle\int\sqrt{x^2-1}\,dx = \frac12\left\{x\sqrt{x^2-1} - \log\left|x + \sqrt{x^2-1}\right|\right\} + C$ の形と混同したものです。
2. 誤り。$(x^2+1)^{1/2}$ を「べきを 1 上げて、中身の導関数 $2x$ で割る」と処理していますが、中身が 1 次式でないときこの方法は使えません。微分しても $\sqrt{x^2+1}$ に戻りません。
3. 正しい。
4. 誤り。部分積分で $I$ を移項したあと、$2$ で割るのを忘れています。微分すると $2\sqrt{x^2+1}$ になります。

### ポイント

- $\sqrt{x^2 + A}$ の積分は「部分積分して同じ積分を移項する」か、$x = \sinh t$（$A = 1$ の場合）と置換して $\displaystyle\int\cosh^2 t\,dt$ に直すのが定番です。
- 一般形 $\displaystyle\int\sqrt{x^2+A}\,dx = \frac12\left(x\sqrt{x^2+A} + A\log\left|x + \sqrt{x^2+A}\right|\right) + C$ は覚えておくと速いですが、選択式でも微分して検算するのが確実です。
