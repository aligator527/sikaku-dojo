コーシー・リーマンの関係式 $u_x = v_y,\ u_y = -v_x$ を順に積分して $v$ を決めます。結果は $v = 3x^2y - y^3 + 2x$ で、$f(z) = z^{3} + 2iz$ となります。

### 計算

$u_x = 3x^{2} - 3y^{2}$、$u_y = -6xy - 2$ です（$u_{xx} + u_{yy} = 6x - 6x = 0$ なので $u$ は調和関数）。

$v_y = u_x = 3x^{2} - 3y^{2}$ を $y$ で積分すると

$$v = 3x^{2}y - y^{3} + \varphi(x).$$

$v_x = 6xy + \varphi'(x)$ が $-u_y = 6xy + 2$ に等しいので $\varphi'(x) = 2$、$\varphi(x) = 2x + C$。$v(0,0) = 0$ より $C = 0$ で

$$v(x, y) = 3x^{2}y - y^{3} + 2x.$$

検算として $(x+iy)^{3} = x^{3} - 3xy^{2} + i(3x^{2}y - y^{3})$、$2i(x+iy) = -2y + 2ix$ なので、$f(z) = z^{3} + 2iz$ の実部が $u$、虚部が $v$ に一致します。

### 各選択肢の検討

1. 正しい。上の計算のとおりです。
2. 誤り。2 つ目の関係式 $v_x = -u_y$ の定数項の符号を落とすと $\varphi'(x) = -2$ となり、この式になります。このとき $v_x = 6xy - 2$ は $-u_y = 6xy + 2$ と一致せず、コーシー・リーマンの関係式を満たしません。
3. 誤り。符号がすべて逆で、$-v$ に当たります。「$u$ が $v$ の共役調和関数」と向きを取り違え、$w + iu$ が正則となる $w$ を求めるとこの式（$w = -v$）になります。$u - iv = \overline{f}$ は正則ではありません。
4. 誤り。$v_y = u_x$ の積分で $-3y^{2}$ を $+3y^2$ と写し、$y^3$ の符号を誤っています。この $v$ は調和関数になりません（$v_{xx} + v_{yy} = 12y \neq 0$）。

### ポイント

- 共役調和関数は「$v_y = u_x$ を $y$ で積分 → $v_x = -u_y$ で積分定数を決める」の 2 段階で求めます。
- $f'(z) = u_x - i u_y$ を使うと $f'(z) = 3x^2 - 3y^2 + i(6xy + 2)$ で、$y = 0$ とおいた $3x^2 + 2i$ の $x$ を $z$ に置き換えれば $f'(z) = 3z^2 + 2i$ がすぐに分かります（ミルン・トムソンの方法）。
- 答えの $v$ が調和関数であることを確かめると、符号の誤りを見つけられます。
