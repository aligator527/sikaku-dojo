$x = \tan\theta$ と置換すると $\dfrac{dx}{1+x^2} = d\theta$、$\log(1 + x^2) = -2\log\cos\theta$ となり、有名な積分 $\displaystyle\int_0^{\pi/2}\log\cos\theta\,d\theta = -\frac{\pi}{2}\log 2$ に帰着します。値は $\pi\log 2 \approx 2.1776$ です。

### 計算

$x = \tan\theta$（$0 \le \theta < \tfrac{\pi}{2}$）とおくと $dx = \dfrac{d\theta}{\cos^2\theta}$、$1 + x^2 = \dfrac{1}{\cos^2\theta}$ なので

$$\int_{0}^{\infty} \frac{\log(1 + x^{2})}{1 + x^{2}}\,dx = \int_0^{\pi/2}\log\frac{1}{\cos^2\theta}\,d\theta = -2\int_0^{\pi/2}\log\cos\theta\,d\theta.$$

**$J = \displaystyle\int_0^{\pi/2}\log\cos\theta\,d\theta$ の計算** $\theta \mapsto \dfrac{\pi}{2} - \theta$ により $J = \displaystyle\int_0^{\pi/2}\log\sin\theta\,d\theta$ でもあるので

$$2J = \int_0^{\pi/2}\log(\sin\theta\cos\theta)\,d\theta = \int_0^{\pi/2}\log\frac{\sin 2\theta}{2}\,d\theta = -\frac{\pi}{2}\log 2 + \int_0^{\pi/2}\log\sin 2\theta\,d\theta.$$

最後の積分は $\varphi = 2\theta$ とおくと $\dfrac12\displaystyle\int_0^{\pi}\log\sin\varphi\,d\varphi = \int_0^{\pi/2}\log\sin\varphi\,d\varphi = J$（$\sin\varphi$ は $\varphi = \tfrac\pi2$ に関して対称）です。よって $2J = -\dfrac{\pi}{2}\log 2 + J$ より

$$J = -\frac{\pi}{2}\log 2.$$

したがって

$$\int_{0}^{\infty} \frac{\log(1 + x^{2})}{1 + x^{2}}\,dx = -2J = \pi\log 2 = 3.14159\cdots\times 0.69315\cdots = 2.17759\cdots.$$

小数第4位を四捨五入して $2.178$ です。

### ポイント

- $\displaystyle\int_0^{\pi/2}\log\sin\theta\,d\theta = \int_0^{\pi/2}\log\cos\theta\,d\theta = -\frac{\pi}{2}\log 2$ は 1 級で何度も使う値です。導き方（2 倍角と対称性）ごと覚えておきます。
- $J$ 自体も $\theta = \tfrac\pi2$（あるいは $\theta = 0$）で被積分関数が $-\infty$ になる広義積分ですが、$\log$ の発散は弱いので収束します。
- 置換後に係数 $-2$ を落として $\dfrac{\pi}{2}\log 2$ と答える誤りや、$\log\dfrac{1}{\cos^2\theta}$ の符号を誤る（負の値になる）誤りに注意します。被積分関数は正なので答えは正です。
