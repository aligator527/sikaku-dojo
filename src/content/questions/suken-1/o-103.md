通分すると $\dfrac{x^2 - \sin^2 x}{x^2\sin^2 x}$ という $\dfrac00$ 型の不定形になります。分子・分母をテイラー展開して $x^4$ の係数を比べると、極限値は $\dfrac13$ です。

### 計算

$\sin x = x - \dfrac{x^3}{6} + O(x^5)$ より

$$\sin^2 x = x^2 - \frac{x^4}{3} + O(x^6).$$

したがって

$$x^2 - \sin^2 x = \frac{x^4}{3} + O(x^6),\qquad x^2\sin^2 x = x^4 + O(x^6).$$

よって

$$\frac{1}{\sin^{2} x} - \frac{1}{x^{2}} = \frac{x^2 - \sin^2 x}{x^2\sin^2 x} = \frac{\tfrac13 + O(x^2)}{1 + O(x^2)} \longrightarrow \frac13 \quad (x \to 0).$$

**別解（因数分解）** $x^2 - \sin^2 x = (x - \sin x)(x + \sin x)$ と分けると

$$\frac{x - \sin x}{x^3}\cdot\frac{x + \sin x}{x}\cdot\frac{x^2}{\sin^2 x} \longrightarrow \frac16 \cdot 2 \cdot 1 = \frac13.$$

### ポイント

- $\sin^2 x$ の展開は $x^2 - \dfrac{x^4}{3}$ です。$\left(x - \dfrac{x^3}{6}\right)^2$ の交差項 $2\cdot x\cdot\left(-\dfrac{x^3}{6}\right)$ を $-\dfrac{x^4}{6}$ としてしまうと、答えが $\dfrac16$ にずれます。
- 「$\infty - \infty$」型は、通分して $\dfrac00$ 型に直してから展開するのが基本です。
- 展開を一段進めると $\dfrac{1}{\sin^2 x} = \dfrac{1}{x^2} + \dfrac13 + \dfrac{x^2}{15} + \cdots$ となり、検算に使えます。
