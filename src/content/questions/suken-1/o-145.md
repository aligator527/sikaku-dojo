  $x > 0,\ y > 0$ における微分方程式

  $$y' = \frac{x^{2} + y^{2}}{xy}$$

  の一般解として正しいものを選べ。ただし $C$ は任意定数、$\log$ は自然対数とする。
choices:
  - '$y^{2} = x^{2}\left(\log x + C\right)$'
  - '$y^{2} = 2x^{2}\log x + C$'

  - '$y^{2} = x^{2}\left(2\log x + C\right)$'
answer: 4

右辺は $\dfrac{x}{y} + \dfrac{y}{x}$ と $\dfrac yx$ だけで書ける同次形です。$y = xu$ とおくと変数分離形 $xu' = \dfrac1u$ になり、$\dfrac{u^2}{2} = \log x + C'$ から $y^2 = x^2(2\log x + C)$ が得られます。

### 計算

$y = xu$ とおくと $y' = u + xu'$。右辺は $\dfrac{x^2 + x^2u^2}{x\cdot xu} = \dfrac{1 + u^2}{u} = \dfrac1u + u$ なので

$$u + xu' = \frac1u + u \quad\Longrightarrow\quad xu' = \frac1u \quad\Longrightarrow\quad u\,du = \frac{dx}{x}.$$

積分すると

$$\frac{u^{2}}{2} = \log x + C' \quad\Longrightarrow\quad \frac{y^{2}}{x^{2}} = 2\log x + C \quad (C = 2C').$$

よって $y^{2} = x^{2}(2\log x + C)$ です。

**検算** $y^2 = x^2(2\log x + C)$ を微分すると $2yy' = 2x(2\log x + C) + 2x = \dfrac{2y^2}{x} + 2x$ より $y' = \dfrac{y}{x} + \dfrac{x}{y} = \dfrac{x^2 + y^2}{xy}$ となり、元の方程式を満たします。

### 各選択肢の検討

1. 誤り。$\dfrac{u^2}{2}$ の $\dfrac12$ を処理するときに $\log x$ を 2 倍し忘れています。
2. 誤り。$\dfrac{y^2}{x^2} = 2\log x + C$ の両辺に $x^2$ を掛けるとき、定数 $C$ にも $x^2$ を掛ける必要があります。微分して代入すると方程式を満たしません。
3. 誤り。$xu' = \dfrac1u$ の $\dfrac1u$ を $1$ と誤って $u = \log x + C$ としています。
4. 正しい。

### ポイント

- 右辺が $\dfrac yx$ の関数 $f\!\left(\dfrac yx\right)$ で表されるとき（同次形）、$y = xu$ とおけば必ず変数分離形 $xu' = f(u) - u$ になります。
- 任意定数を含む式を変形するときは、定数を掛けたり足したりする操作が $x$ を含むかどうかに注意します。$C$ に $x^2$ が掛かるかどうかで解の形が変わります。
