各ルジャンドル記号を平方剰余の相互法則と第 1・第 2 補充法則で計算します。$103 \equiv 3 \pmod 4$、$103 \equiv 7 \pmod 8$ に注意すると、$\left(\frac{7}{103}\right) = 1$ で、他はすべて $-1$ なので、正しいのは 3 です。

### 計算

$\left(\frac{a}{p}\right) = 1$ のとき、かつそのときに限り $x^{2} \equiv a \pmod p$ は解をもちます（$p \nmid a$）。$p = 103$ について

- $103 \equiv 3 \pmod 4$、$103 \equiv 7 \pmod 8$
- $103 = 3\cdot 34 + 1$、$103 = 5\cdot 20 + 3$、$103 = 7\cdot 14 + 5$

です。

$$\left(\frac{7}{103}\right) = -\left(\frac{103}{7}\right) = -\left(\frac{5}{7}\right) = -\left(\frac{7}{5}\right) = -\left(\frac{2}{5}\right) = -(-1) = 1.$$

1 つ目の等号は $7 \equiv 103 \equiv 3 \pmod 4$ なので相互法則で符号が反転し、3 つ目は $5 \equiv 1 \pmod 4$ なので反転しません。$\left(\frac25\right) = -1$ は $5 \equiv 5 \pmod 8$ からです。実際 $25^{2} = 625 = 6\cdot 103 + 7$ なので $x \equiv \pm 25$ が解です。

### 各選択肢の検討

1. 誤り。第 1 補充法則 $\left(\frac{-1}{p}\right) = (-1)^{(p-1)/2} = (-1)^{51} = -1$。$p \equiv 3 \pmod 4$ では $-1$ は平方非剰余です。
2. 誤り。$\left(\frac{3}{103}\right) = -\left(\frac{103}{3}\right) = -\left(\frac13\right) = -1$。$3$ と $103$ はともに $4$ で割って $3$ 余るので符号が反転します（反転を忘れると $+1$ と誤ります）。
3. 正しい。上の計算のとおりです。
4. 誤り。$\left(\frac{5}{103}\right) = \left(\frac{103}{5}\right) = \left(\frac35\right) = -1$（$\bmod 5$ の平方剰余は $1, 4$ だけ）。
5. 誤り。$\left(\frac{10}{103}\right) = \left(\frac{2}{103}\right)\left(\frac{5}{103}\right) = 1\cdot(-1) = -1$。第 2 補充法則で $103 \equiv 7 \pmod 8$ なら $\left(\frac{2}{103}\right) = 1$ です。

### ポイント

- 相互法則：奇素数 $p \neq q$ について $\left(\frac pq\right)\left(\frac qp\right) = (-1)^{\frac{p-1}{2}\cdot\frac{q-1}{2}}$。符号が反転するのは $p \equiv q \equiv 3 \pmod 4$ のときだけです。
- 補充法則：$\left(\frac{-1}{p}\right) = (-1)^{(p-1)/2}$、$\left(\frac{2}{p}\right) = (-1)^{(p^{2}-1)/8}$（$p \equiv \pm1 \pmod 8$ で $1$、$p \equiv \pm 3 \pmod 8$ で $-1$）。
- ルジャンドル記号は分子について乗法的です。合成数の分子は素因数に分けて計算します。
