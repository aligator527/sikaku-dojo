実行可能領域は凸多角形で、1 次式の最大値はその頂点のどれかでとられます。頂点を列挙して目的関数を比べると、$x + y = 5$ と $2x + y = 8$ の交点 $(3, 2)$ で最大値 $23$ をとります。

### 計算

実行可能領域の頂点は、境界の直線どうしの交点のうち、すべての制約を満たすものです。

| 頂点 | 求め方 | $5x + 4y$ |
| --- | --- | --- |
| $(0, 0)$ | 原点 | $0$ |
| $(4, 0)$ | $2x + y = 8$ と $y = 0$ | $20$ |
| $(3, 2)$ | $x + y = 5$ と $2x + y = 8$ | $23$ |
| $\left(\tfrac32, \tfrac72\right)$ | $x + y = 5$ と $x + 3y = 12$ | $21.5$ |
| $(0, 4)$ | $x + 3y = 12$ と $x = 0$ | $16$ |

例えば $(3, 2)$ では $x + 3y = 9 \le 12$、$\left(\tfrac32, \tfrac72\right)$ では $2x + y = 6.5 \le 8$ と、残りの制約も満たしています。最大値は $(x, y) = (3, 2)$ のときの $23$ です。

### ポイント

- 目的関数の等高線 $5x + 4y = k$ の傾き $-\tfrac54$ は、$x + y = 5$ の傾き $-1$ と $2x + y = 8$ の傾き $-2$ の間にあります。したがって最適な頂点はこの 2 直線の交点です（図を描かなくても判定できます）。
- 直線の交点を求めただけでは頂点とは限りません。例えば $2x + y = 8$ と $x + 3y = 12$ の交点 $\left(\tfrac{12}{5}, \tfrac{16}{5}\right)$ は $x + y = 5.6 > 5$ で実行不可能です。必ずすべての制約を確かめます。
