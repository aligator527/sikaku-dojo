  留数定理を用いて、次の広義積分の値を求めよ。途中の議論（積分路の設定、留数の計算、半円上の積分の評価）も示すこと。

  $$I = \int_{0}^{\infty} \frac{dx}{x^{4} + 1}$$
modelAnswer: |
  被積分関数は偶関数なので $I = \dfrac12\displaystyle\int_{-\infty}^{\infty}\frac{dx}{x^4+1}$ である。

  **積分路** $f(z) = \dfrac{1}{z^4+1}$ とし、$R > 1$ に対して実軸上の線分 $[-R, R]$ と上半円 $C_R: z = Re^{i\theta}\ (0 \le \theta \le \pi)$ からなる閉曲線を正の向きに一周する。

  **極と留数** $z^4 = -1$ の解は $z = e^{i\pi/4}, e^{3i\pi/4}, e^{5i\pi/4}, e^{7i\pi/4}$ で、すべて 1 位の極である。積分路の内部にあるのは $z_1 = e^{i\pi/4},\ z_2 = e^{3i\pi/4}$。1 位の極 $z_k$ での留数は

  $$\operatorname{Res}_{z=z_k} f = \frac{1}{4z_k^{3}} = \frac{z_k}{4z_k^{4}} = -\frac{z_k}{4}$$

  であり、$z_1 + z_2 = \left(\tfrac{\sqrt2}{2} + \tfrac{\sqrt2}{2}i\right) + \left(-\tfrac{\sqrt2}{2} + \tfrac{\sqrt2}{2}i\right) = \sqrt2\,i$ だから、留数の和は $-\dfrac{\sqrt2}{4}i$ となる。

  **留数定理** より

  $$\int_{-R}^{R}\frac{dx}{x^4+1} + \int_{C_R} f(z)\,dz = 2\pi i\cdot\left(-\frac{\sqrt2}{4}i\right) = \frac{\sqrt2}{2}\pi.$$

  **半円上の評価** $|z| = R$ のとき $|z^4 + 1| \ge R^4 - 1$ なので

  $$\left|\int_{C_R} f(z)\,dz\right| \le \frac{\pi R}{R^4 - 1} \longrightarrow 0 \quad (R \to \infty).$$

  **結論** $R \to \infty$ として $\displaystyle\int_{-\infty}^{\infty}\frac{dx}{x^4+1} = \frac{\sqrt2}{2}\pi$。したがって

  $$I = \frac{\sqrt2}{4}\pi = \frac{\pi}{2\sqrt2}\ (\approx 1.1107).$$

有理関数の実軸上の積分を、上半平面の半円を使った閉曲線の積分に置き換える定番の手法です。上半平面にある 2 つの極の留数の和を $2\pi i$ 倍し、半円部分が消えることを確認すれば、$I = \dfrac{\sqrt2}{4}\pi$ が得られます。

### 計算の要点

- **留数の計算** $f = 1/g$（$g(z) = z^4+1$）で $g(z_k) = 0,\ g'(z_k) \neq 0$ のとき、$\operatorname{Res}_{z=z_k} f = 1/g'(z_k) = 1/(4z_k^3)$ です。さらに $z_k^4 = -1$ を使うと $-z_k/4$ と簡単になります。
- **留数の和** $-\dfrac{1}{4}(z_1 + z_2) = -\dfrac{\sqrt2}{4}i$。$2\pi i$ を掛けると $i^2 = -1$ により実数 $\dfrac{\sqrt2}{2}\pi$ になります。結果が実数にならない場合は計算ミスを疑います。
- **半円の評価** 分母の次数が分子より 2 以上大きいので、$\pi R \cdot \dfrac{1}{R^4 - 1}$ の形で 0 に収束します。

### ポイント

- 一般に $\displaystyle\int_0^\infty \frac{dx}{x^n+1} = \frac{\pi/n}{\sin(\pi/n)}$ です。$n = 4$ で $\dfrac{\pi/4}{\sqrt2/2} = \dfrac{\pi}{2\sqrt2}$ となり、検算に使えます。
- 下半平面の極を含めてしまう、または実軸全体の積分の値を半分にし忘れる（$\tfrac{\sqrt2}{2}\pi$ と答える）誤りが典型です。
- 2 次試験では答えだけでなく、積分路・留数・評価の 3 点を順序立てて書くことが求められます。
