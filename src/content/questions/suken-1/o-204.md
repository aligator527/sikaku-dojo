$\cos 2x = \operatorname{Re} e^{2ix}$ とし、$f(z) = \dfrac{e^{2iz}}{(z^{2}+1)^{2}}$ を上半平面の半円で積分します。上半平面の極は $z = i$（2 位）だけで、その留数 $-\dfrac{3i}{4e^{2}}$ を $2\pi i$ 倍すると積分の値は $\dfrac{3\pi}{2e^{2}}$、すなわち $a = \dfrac32$ です。

### 計算

**留数** $z = i$ は 2 位の極なので

$$\operatorname*{Res}_{z=i} f = \frac{d}{dz}\left[\frac{e^{2iz}}{(z+i)^{2}}\right]_{z=i} = \left[e^{2iz}\left(\frac{2i}{(z+i)^{2}} - \frac{2}{(z+i)^{3}}\right)\right]_{z=i}.$$

$z = i$ で $e^{2iz} = e^{-2}$、$(z+i)^{2} = (2i)^{2} = -4$、$(z+i)^{3} = (2i)^{3} = -8i$ だから

$$\operatorname*{Res}_{z=i} f = e^{-2}\left(\frac{2i}{-4} - \frac{2}{-8i}\right) = e^{-2}\left(-\frac{i}{2} - \frac{i}{4}\right) = -\frac{3i}{4}e^{-2}.$$

**半円上の積分** $z = Re^{i\theta}\ (0\le\theta\le\pi)$ では $|e^{2iz}| = e^{-2R\sin\theta} \le 1$ なので

$$\left|\int_{C_R} f(z)\,dz\right| \le \frac{\pi R}{(R^{2}-1)^{2}} \longrightarrow 0\quad (R\to\infty).$$

**結論** 留数定理から

$$\int_{-\infty}^{\infty}\frac{e^{2ix}}{(x^{2}+1)^{2}}\,dx = 2\pi i\cdot\left(-\frac{3i}{4}e^{-2}\right) = \frac{3\pi}{2}e^{-2}.$$

実部をとって $\displaystyle\int_{-\infty}^{\infty}\frac{\cos 2x}{(x^{2}+1)^{2}}\,dx = \frac{3\pi}{2e^{2}}\ (\approx 0.6378)$。よって $a = \dfrac32$ です。

### ポイント

- $\cos 2z$ そのものは上半平面で有界でないため、$e^{2iz}$ に置き換えてから半円で閉じます。上半平面では $|e^{2iz}| \le 1$ が成り立ちます。
- 一般に $\displaystyle\int_{-\infty}^{\infty}\frac{\cos mx}{(x^{2}+1)^{2}}\,dx = \frac{\pi(1+m)}{2}e^{-m}\ (m \ge 0)$ です。$m = 0$ で $\dfrac{\pi}{2}$ となり検算に使えます。
- 2 位の極で積の微分の一方（$e^{2iz}$ の微分から出る $2i$）を落とすと $a = \dfrac12$ になります。指数関数の微分を忘れる誤りが典型です。
