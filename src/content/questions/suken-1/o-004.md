定数係数の 2 階線形微分方程式なので、「同次方程式の一般解 ＋ 特殊解」で一般解を作り、初期条件で定数を決めます。解は $y = e^x - 2e^{2x} + e^{3x} = e^x(e^x-1)^2$ となり、$y(\log 3) = 3\cdot 2^2 = 12$ です。

### 計算

**同次方程式** 特性方程式 $\lambda^2 - 3\lambda + 2 = (\lambda-1)(\lambda-2) = 0$ より $\lambda = 1, 2$。一般解は $C_1e^{x} + C_2e^{2x}$ です。

**特殊解** 右辺 $2e^{3x}$ の $3$ は特性根ではないので $y_p = Ae^{3x}$ とおけます。代入すると

$$(9 - 9 + 2)Ae^{3x} = 2e^{3x} \quad\Longrightarrow\quad A = 1.$$

**初期条件** $y = C_1e^x + C_2e^{2x} + e^{3x}$ に対して

$$y(0) = C_1 + C_2 + 1 = 0,\qquad y'(0) = C_1 + 2C_2 + 3 = 0.$$

これを解くと $C_2 = -2,\ C_1 = 1$。よって

$$y(x) = e^{x} - 2e^{2x} + e^{3x} = e^{x}\left(e^{x}-1\right)^2.$$

$e^{\log 3} = 3$ なので $y(\log 3) = 3\cdot(3-1)^2 = 12$ です。

### ポイント

- 未定係数法では、右辺の指数 $e^{\alpha x}$ の $\alpha$ が特性根と一致するとき（共鳴）、$Axe^{\alpha x}$（重根なら $Ax^2e^{\alpha x}$）とおき直す必要があります。
- 特殊解の係数は特性多項式 $p(\lambda) = \lambda^2 - 3\lambda + 2$ を使って $A = 2/p(3)$ とすぐに求められます。
- 初期条件は特殊解を含めた一般解に適用します。同次解だけに初期条件を当てはめるのはよくある誤りです。
