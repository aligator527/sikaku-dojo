modelAnswer: |
  **準備** 整数 $n$ について、$n \equiv 0, \pm 1 \pmod 3$ に応じて $n^{2} \equiv 0, 1, 1 \pmod 3$ である。したがって

  $$x^{2} + y^{2} \equiv 0 \pmod 3 \implies x \equiv y \equiv 0 \pmod 3 \qquad (\ast)$$

  が成り立つ（$x^2, y^2$ の余りの組 $(0,0), (0,1), (1,0), (1,1)$ のうち、和が $3$ の倍数になるのは $(0, 0)$ だけ）。

  **(1)** $(0, 0, 0)$ でない整数解が存在すると仮定する。そのような解のうち、$|x| + |y| + |z|$（正の整数）が最小のものを $(x, y, z)$ とする。

  $x^{2} + y^{2} = 3z^{2}$ は $3$ の倍数なので、$(\ast)$ より $x = 3x_1,\ y = 3y_1$（$x_1, y_1$ は整数）と書ける。代入すると

  $$9(x_1^{2} + y_1^{2}) = 3z^{2} \implies z^{2} = 3(x_1^{2} + y_1^{2}).$$

  $z^{2}$ が $3$ の倍数で $3$ は素数だから $3 \mid z$、$z = 3z_1$ と書ける。代入して $9z_1^{2} = 3(x_1^{2} + y_1^{2})$、すなわち

  $$x_1^{2} + y_1^{2} = 3z_1^{2}.$$

  よって $(x_1, y_1, z_1)$ も整数解であり、

  $$|x_1| + |y_1| + |z_1| = \frac{|x| + |y| + |z|}{3}$$

  は正の整数で、$|x| + |y| + |z|$ より小さい。$(x_1, y_1, z_1) \neq (0, 0, 0)$ でもあるから、最小性に矛盾する。したがって整数解は $(0, 0, 0)$ に限る。

  **(2)** 有理数の点 $(x, y)$ が円 $x^{2} + y^{2} = 3$ 上にあると仮定する。分母を払うため、正の整数 $c$ と整数 $a, b$ を用いて $x = \dfrac ac,\ y = \dfrac bc$ と書く（$c$ は $x, y$ の分母の公倍数）。代入して $c^{2}$ を掛けると

  $$a^{2} + b^{2} = 3c^{2}.$$

  $c \ge 1$ なので $(a, b, c) \neq (0, 0, 0)$ であり、これは (1) に矛盾する。よって、そのような点は存在しない。（証明終）

「$3$ の倍数であることが何度でも繰り返せる」ことを使う、フェルマーの無限降下法の典型問題です。$\bmod 3$ の平方剰余が $0, 1$ だけであることから $x, y, z$ がすべて $3$ で割り切れ、$3$ で割った組もまた解になるので、自明でない解は存在しません。

### 証明の組み立て

1. **$\bmod 3$ の観察** 平方数の余りは $0$ か $1$ なので、$x^2 + y^2 \equiv 0$ になるのは $x \equiv y \equiv 0$ のときだけです。これが降下の原動力です。
2. **降下** $x, y$ が $3$ の倍数 → $z^2 = 3(\cdots)$ → $z$ も $3$ の倍数、と進みます。$z^{2}$ が $3$ の倍数なら $z$ が $3$ の倍数であることには、$3$ が素数であること（または $(\ast)$ と同じ余りの議論）を使います。
3. **矛盾の形** 「最小の解をとる」形で書くと、無限降下法の論理（正の整数の無限減少列は存在しない）が明確になります。$(x_1, y_1, z_1)$ が再び $(0,0,0)$ でないことも確認しておきます。

### ポイント

- 同じ方法で、$x^{2} + y^{2} = 7z^{2}$ が自明な解しかもたないことや、$4^{k}(8m+7)$ の形の整数が 3 つの平方数の和で表せないことも示せます。$\bmod 4$ や $\bmod 8$ の平方剰余を使う問題も多いので、小さい法での平方剰余の表は覚えておきます。
- 対照的に $x^{2} + y^{2} = 2z^{2}$ は $(1, 1, 1)$ のような非自明解をもち、円 $x^{2} + y^{2} = 2$ には有理点 $(1, 1)$ があります。1 つでも有理点があれば、そこを通る有理数の傾きの直線で有理点を無数に作れます。
- (2) で $c$ を「$x, y$ の分母の最小公倍数」としておけば、$a, b, c$ がすべて整数であることが明確になります。
