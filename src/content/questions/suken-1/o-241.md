$720 = 2^{4}\cdot3^{2}\cdot5$ なので、中国剰余定理により解の個数は $\bmod 16$、$\bmod 9$、$\bmod 5$ での解の個数の積になります。それぞれ $4, 2, 2$ 個なので、答えは $4\cdot2\cdot2 = 16$ 個です。

### 計算

**$\bmod 16$** $x^{2} \equiv 1$ なら $x$ は奇数です。奇数 $x = 1, 3, 5, \dots, 15$ の 2 乗を $\bmod 16$ で計算すると

$$1^{2} = 1,\ 3^{2} = 9,\ 5^{2} = 25 \equiv 9,\ 7^{2} = 49 \equiv 1,\ 9^{2} = 81 \equiv 1,\ 11^{2} = 121 \equiv 9,\ 13^{2} = 169 \equiv 9,\ 15^{2} = 225 \equiv 1$$

なので、解は $x \equiv 1, 7, 9, 15$ の **4 個** です。

**$\bmod 9$** $(x - 1)(x + 1) \equiv 0 \pmod 9$。$x - 1$ と $x + 1$ の差は $2$ なので両方が $3$ で割り切れることはなく、どちらか一方が $9$ で割り切れます。解は $x \equiv \pm1$ の **2 個** です。

**$\bmod 5$** $5$ は素数なので $x \equiv \pm 1$ の **2 個** です。

**組み合わせ** 中国剰余定理により、$\bmod 16$、$\bmod 9$、$\bmod 5$ の解の組 1 つごとに $\bmod 720$ の解がちょうど 1 つ対応します。よって

$$4\cdot 2\cdot 2 = 16\ \text{個}.$$

（具体的には $x = 1, 71, 89, 161, 199, 271, 289, 359, 361, 431, 449, 521, 559, 631, 649, 719$ です。）

### ポイント

- 奇素数 $p$ について $x^{2} \equiv 1 \pmod{p^{k}}$ の解は $\pm 1$ の 2 個ですが、$2^{k}$ では $k = 1$ で 1 個、$k = 2$ で 2 個、$k \ge 3$ で 4 個（$\pm1,\ 2^{k-1}\pm1$）になります。「素因数 3 種類なので $2^3 = 8$ 個」とする誤りが典型です。
- 解の個数は、$(\mathbb{Z}/720\mathbb{Z})^{\times}$ の中の位数 2 以下の元の個数とも言えます。
- 解は $x$ と $720 - x$ の対になるので、個数は必ず偶数です（$x = 360$ のような自己対応は $x^2 \equiv 1$ を満たしません）。
