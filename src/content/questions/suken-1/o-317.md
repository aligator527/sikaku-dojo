stem: |
  $n$ 組のデータ $(x_1, y_1), \dots, (x_n, y_n)$ があり、$x_1, \dots, x_n$ のすべてが等しいわけではないとする。$\bar x, \bar y$ を平均とし、

  $$S_{xx} = \sum_{i=1}^n (x_i - \bar x)^2,\quad S_{xy} = \sum_{i=1}^n (x_i - \bar x)(y_i - \bar y),\quad S_{yy} = \sum_{i=1}^n (y_i - \bar y)^2$$

  とおく。

  (1) $Q(a, b) = \displaystyle\sum_{i=1}^n (y_i - a - bx_i)^2$ を最小にする $(a, b)$ は

  $$\hat b = \frac{S_{xy}}{S_{xx}},\qquad \hat a = \bar y - \hat b\,\bar x$$

  のただ 1 組であることを示せ。

  (2) 残差を $e_i = y_i - \hat a - \hat b x_i$ とする。$\displaystyle\sum_{i=1}^n e_i = 0$、$\displaystyle\sum_{i=1}^n x_i e_i = 0$ を示し、$Q$ の最小値が $S_{yy} - \dfrac{S_{xy}^2}{S_{xx}}$ に等しいことを示せ。
modelAnswer: |
  仮定より $S_{xx} > 0$ である。

  **(1)** $d = \bar y - a - b\bar x$ とおくと、$y_i - a - bx_i = \bigl\{(y_i - \bar y) - b(x_i - \bar x)\bigr\} + d$ と書ける。$\sum(x_i - \bar x) = \sum(y_i - \bar y) = 0$ より交差項が消えて

  $$Q(a, b) = \sum_{i=1}^n\bigl\{(y_i - \bar y) - b(x_i - \bar x)\bigr\}^2 + nd^2 = S_{yy} - 2bS_{xy} + b^2S_{xx} + nd^2.$$

  $b$ について平方完成すると

  $$Q(a, b) = S_{xx}\left(b - \frac{S_{xy}}{S_{xx}}\right)^2 + n\left(\bar y - a - b\bar x\right)^2 + S_{yy} - \frac{S_{xy}^2}{S_{xx}}.$$

  $S_{xx} > 0,\ n > 0$ なので、右辺の第 1 項・第 2 項はともに $0$ 以上であり、

  $$Q(a, b) \ge S_{yy} - \frac{S_{xy}^2}{S_{xx}}.$$

  等号が成り立つのは $b = \dfrac{S_{xy}}{S_{xx}} = \hat b$ かつ $a = \bar y - \hat b\bar x = \hat a$ のときに限る。よって $Q$ を最小にする $(a, b)$ は $(\hat a, \hat b)$ のただ 1 組である。

  **(2)** $\hat a = \bar y - \hat b\bar x$ より $e_i = (y_i - \bar y) - \hat b(x_i - \bar x)$ なので

  $$\sum_{i=1}^n e_i = 0 - \hat b\cdot 0 = 0.$$

  また

  $$\sum_{i=1}^n (x_i - \bar x)e_i = S_{xy} - \hat b S_{xx} = 0$$

  であるから、$\displaystyle\sum_{i=1}^n x_ie_i = \sum_{i=1}^n (x_i - \bar x)e_i + \bar x\sum_{i=1}^n e_i = 0$。

  最小値は (1) の不等式の等号の場合として $Q(\hat a, \hat b) = S_{yy} - \dfrac{S_{xy}^2}{S_{xx}}$ である。残差の性質からも、$\sum e_i = 0$ と $\sum (x_i - \bar x)e_i = 0$ を使って

  $$Q(\hat a, \hat b) = \sum_{i=1}^n e_i^2 = \sum_{i=1}^n e_i\bigl\{(y_i - \bar y) - \hat b(x_i - \bar x)\bigr\} = \sum_{i=1}^n e_i(y_i - \bar y) = S_{yy} - \hat b S_{xy} = S_{yy} - \frac{S_{xy}^2}{S_{xx}}$$

  と確かめられる。

最小二乗法の基本定理を自分の手で導く問題です。偏微分で正規方程式を立ててもよいのですが、平方完成すると「最小点であること」「ただ 1 つであること」「最小値」が一度に示せます。

### 証明の組み立て

1. **平均のまわりに書き直す** $y_i - a - bx_i$ を「偏差の部分」と「定数のずれ $d$」に分けると、偏差の和が $0$ であることから交差項が消えます。
2. **平方完成** $b$ の 2 次式 $S_{xx}b^2 - 2S_{xy}b + S_{yy}$ を平方完成します。$S_{xx} > 0$（$x_i$ がすべて等しくはない）という仮定はここで使います。
3. **残差の性質** $e_i$ を偏差で表せば、$\sum e_i = 0$ と $\sum (x_i - \bar x)e_i = 0$ はほぼ定義から従います。これは正規方程式 $\partial Q/\partial a = 0,\ \partial Q/\partial b = 0$ と同じ内容です。

**別解（偏微分）** $\dfrac{\partial Q}{\partial a} = -2\sum e_i = 0$、$\dfrac{\partial Q}{\partial b} = -2\sum x_ie_i = 0$ を解くと $(\hat a, \hat b)$ が得られます。この場合は、ヘッセ行列 $\begin{pmatrix} 2n & 2\sum x_i \\ 2\sum x_i & 2\sum x_i^2 \end{pmatrix}$ の行列式が $4nS_{xx} > 0$ で正定値であること（$Q$ が狭義凸であること）を示して、最小であることを確認します。

### ポイント

- 最小値は $S_{yy}(1 - r^2)$（$r$ は相関係数）とも書けます。決定係数 $R^2 = 1 - \dfrac{Q_{\min}}{S_{yy}}$ が単回帰では $r^2$ に等しいのはこのためです。
- 偏微分が $0$ になる点を求めただけでは「最小」とは言えません。2 次試験では最小であることの根拠まで書きます。
