投げる回数を「新しい目が出るまでの待ち時間」の和に分解すると、それぞれが幾何分布に従います。期待値の線形性から、答えは $6\left(1 + \tfrac12 + \tfrac13 + \tfrac14 + \tfrac15 + \tfrac16\right) = \tfrac{147}{10} = 14.7$ です。

### 計算

すでに $k-1$ 種類の目が出ている状態から、$k$ 種類目の目が出るまでに投げる回数を $W_k$ とします（$k = 1, 2, \dots, 6$）。1 回投げるごとに新しい目が出る確率は $p_k = \dfrac{6-(k-1)}{6}$ で一定なので、$W_k$ は成功確率 $p_k$ の幾何分布に従い

$$E[W_k] = \frac{1}{p_k} = \frac{6}{7-k}.$$

投げる回数の合計は $N = W_1 + W_2 + \dots + W_6$ なので

$$E[N] = \sum_{k=1}^{6} \frac{6}{7-k} = 6\left(1 + \frac12 + \frac13 + \frac14 + \frac15 + \frac16\right) = 6\cdot\frac{49}{20} = \frac{147}{10} = 14.7.$$

### ポイント

- 成功確率 $p$ の幾何分布（初めて成功するまでの回数、値は $1, 2, \dots$）の期待値は $\dfrac1p$、分散は $\dfrac{1-p}{p^2}$ です。
- 期待値の線形性は $W_k$ が独立でなくても使えます（この問題では実際に独立です）。
- 一般に $n$ 種類をそろえる回数の期待値は $nH_n$（$H_n = \sum_{k=1}^n \frac1k$）で、$n$ が大きいとき約 $n\log n$ です。
- 各 $W_k$ の期待値を $6$ と考えて $36$ と答える、あるいは最初の 1 回（$W_1 = 1$）を数え忘れて $13.7$ とする誤りに注意します。
