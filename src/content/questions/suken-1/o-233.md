目的関数 $2x + 4y = 2(x + 2y)$ は第 1 制約の左辺の 2 倍なので、実行可能領域で $2x + 4y \le 16$ が成り立ちます。等号は第 1 制約の境界のうち領域に含まれる部分、すなわち $(0, 4)$ と $(4, 2)$ を結ぶ線分上で成り立つので、正しいのは 5 です。

### 計算

実行可能領域の頂点は $(0, 0)$、$(6, 0)$、$(4, 2)$、$(0, 4)$ です（$(4, 2)$ は $x + 2y = 8$ と $x + y = 6$ の交点）。各頂点での目的関数の値は

$$0,\quad 12,\quad 16,\quad 16$$

で、最大値 $16$ をとる頂点が 2 つあります。

任意の実行可能解について $2x + 4y = 2(x + 2y) \le 16$ であり、等号は $x + 2y = 8$ のとき、かつそのときに限ります。直線 $x + 2y = 8$ のうち実行可能領域に含まれるのは、$x + y \le 6$、$x \ge 0$、$y \ge 0$ から $0 \le x \le 4$ の部分、すなわち $(0, 4)$ と $(4, 2)$ を結ぶ線分です。

### 各選択肢の検討

1. 誤り。$(4, 2)$ は最適解の 1 つですが、最適解はこれだけではありません。
2. 誤り。$(0, 4)$ も最適解の 1 つにすぎません。
3. 誤り。実行可能領域は有界（四角形）なので、最適解は必ず存在します。
4. 誤り。$(6, 0)$ での値は $12 < 16$ です。$x + y = 6$ の辺上では最適になりません。
5. 正しい。上の計算のとおりです。

### ポイント

- 目的関数の等高線が実行可能領域の辺と平行になると、その辺全体が最適解になります。線形計画問題の最適解の集合は、常に凸集合（点・線分・面など）です。
- 単体法では、最終表で非基底変数の被約費用が $0$ になることで、最適解が一意でないことが分かります。
- 「頂点で最適になる」のは「最適解の中に頂点がある」という意味で、「最適解は頂点だけ」という意味ではありません。
