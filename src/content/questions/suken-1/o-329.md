modelAnswer: |
  **(1)** $I_0 = \displaystyle\int_0^1 e^{x-1}\,dx = \Bigl[e^{x-1}\Bigr]_0^1 = 1 - \frac1e$。$n \ge 1$ のとき部分積分により

  $$I_n = \Bigl[x^n e^{x-1}\Bigr]_0^1 - n\int_0^1 x^{n-1}e^{x-1}\,dx = 1 - nI_{n-1}.$$

  **(2)** $0 < x < 1$ で $\dfrac1e < e^{x-1} < 1$ なので、$x^n > 0$ を掛けて積分すると

  $$\frac1e\int_0^1 x^n\,dx < I_n < \int_0^1 x^n\,dx,\qquad\text{すなわち}\qquad \frac{1}{e(n+1)} < I_n < \frac{1}{n+1}.$$

  **(3)** $d_n = \tilde I_n - I_n$ とおくと、2 つの漸化式の差から $d_n = -n\,d_{n-1}$、$d_0 = \varepsilon$。よって

  $$\tilde I_n - I_n = (-1)^n\,n!\,\varepsilon.$$

  $n = 20$ では $20! \approx 2.43\times10^{18}$ なので、$|\varepsilon| = 10^{-8}$ でも誤差の絶対値は約 $2.4\times10^{10}$ になる。一方、(2) より真の値は $0 < I_{20} < \dfrac{1}{21}$ であり、誤差が真の値をはるかに上回るので、得られた値には意味のある桁が 1 つも残らない。初期値の誤差が 1 段ごとに $n$ 倍に拡大される（不安定な）計算であることが原因である。

  **(4)** 近似値を $J_n$ とし、$J_{30} = 0$、$J_{n-1} = \dfrac{1 - J_n}{n}$ とする。$\delta_n = J_n - I_n$ とおくと $\delta_{n-1} = -\dfrac{\delta_n}{n}$ なので

  $$|\delta_{20}| = \frac{|\delta_{30}|}{30\cdot 29\cdots 21} = \frac{20!}{30!}\,|\delta_{30}|.$$

  (2) より $|\delta_{30}| = I_{30} < \dfrac{1}{31}$。また $30\cdot29\cdots21$ を両端から組にすると、$j = 0, \dots, 4$ に対して $(21 + j)(30 - j) \ge 21\cdot 30 = 630$ なので

  $$\frac{30!}{20!} = \prod_{j=0}^{4}(21+j)(30-j) \ge 630^5 > 9.9\times10^{13}.$$

  よって

  $$|\delta_{20}| < \frac{1}{31\times 9.9\times10^{13}} < \frac{1}{3\times10^{15}} < 10^{-15}.$$

漸化式による計算の「安定性」を扱う問題です。同じ漸化式でも、前向きに使うと初期値の誤差が $n!$ 倍に拡大し、後ろ向きに使うと誤差が $\dfrac{1}{n}$ 倍ずつ縮小します。数学的には等価な計算でも、数値計算としての性質がまったく異なることを示しています。

### 証明の組み立て

1. **(1)** $x^n$ を微分する側、$e^{x-1}$ を積分する側にして部分積分します。$x = 1$ での境界項がちょうど $1$ になるように $e^{x-1}$ としてあります。
2. **(2)** 被積分関数の一部を定数で挟む、積分の基本的な評価です。$I_n \to 0$ が分かり、(3) で計算結果が「明らかにおかしい」と判断する根拠になります。
3. **(3)** 漸化式が 1 次（線形）なので、誤差もまったく同じ形の同次漸化式に従います。
4. **(4)** 後ろ向きでは $\delta_{n-1} = -\delta_n/n$ となり、初期値 $J_{30} = 0$ の大きな誤差（最大で $\tfrac{1}{31}$）も 10 段で $10^{-15}$ 以下に縮みます。$30!/20!$ は組にして下から評価すると手計算で扱えます（実際の値は約 $1.09\times10^{14}$）。

### ポイント

- 計算機で前向きに計算すると、倍精度の丸め誤差（約 $10^{-16}$）からでも $I_{20}$ 付近で結果が破綻し、負の値や $1$ を超える値が現れます。(2) の不等式に反する値は誤りのサインです。
- 後ろ向きの計算では、出発点 $N$ を大きくとるほど精度が上がります。必要な精度から $N$ を決める考え方は、ベッセル関数などの計算（ミラーの方法）でも使われます。
- 誤差が拡大するか縮小するかは、誤差の漸化式の係数（ここでは $-n$ と $-\tfrac1n$）の絶対値で判断します。
