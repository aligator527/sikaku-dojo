  $x > 0$ で定義された関数 $f(x) = x^{\frac{1}{x}}$ について、次の問いに答えよ。ただし $e$ は自然対数の底、$\log$ は自然対数とする。

  (1) $f(x)$ の増減を調べ、最大値とそのときの $x$ の値を求めよ。

  (2) 極限 $\displaystyle\lim_{x\to+0} f(x)$ および $\displaystyle\lim_{x\to\infty} f(x)$ を求めよ。

  (3) $e^{\pi}$ と $\pi^{e}$ の大小を、数値計算に頼らずに判定せよ（$e < \pi$ は用いてよい）。
modelAnswer: |
  $f(x) > 0$ なので $g(x) = \log f(x) = \dfrac{\log x}{x}$ を調べる。$\log$ は単調増加だから、$f$ と $g$ の増減は一致する。

  **(1)**

  $$g'(x) = \frac{\frac1x\cdot x - \log x}{x^{2}} = \frac{1 - \log x}{x^{2}}.$$

  $0 < x < e$ で $g'(x) > 0$、$x > e$ で $g'(x) < 0$ だから、$f$ は $0 < x \le e$ で単調増加、$x \ge e$ で単調減少である。よって $f$ は $x = e$ で最大となり、最大値は

  $$f(e) = e^{\frac1e}.$$

  **(2)** $x \to +0$ のとき $\log x \to -\infty$、$\dfrac1x \to +\infty$ だから $g(x) = \dfrac1x\cdot\log x \to -\infty$。よって $f(x) = e^{g(x)} \to 0$。

  $x \to \infty$ のとき、ロピタルの定理（または $\log x$ が $x$ より遅く増大すること）により $g(x) = \dfrac{\log x}{x} \to 0$。よって $f(x) \to e^0 = 1$。

  $$\lim_{x\to+0} f(x) = 0,\qquad \lim_{x\to\infty} f(x) = 1.$$

  **(3)** (1) より $g$ は $x \ge e$ で狭義単調減少であり、$e < \pi$ だから $g(\pi) < g(e)$、すなわち

  $$\frac{\log\pi}{\pi} < \frac{\log e}{e} = \frac1e.$$

  両辺に $e\pi\ (> 0)$ を掛けて $e\log\pi < \pi$、すなわち $\log \pi^{e} < \log e^{\pi}$。$\log$ は単調増加だから

  $$\pi^{e} < e^{\pi}.$$

$x^{1/x}$ のような「変数の変数乗」は、対数をとって $\dfrac{\log x}{x}$ の増減に直すのが定石です。$\dfrac{\log x}{x}$ は $x = e$ で最大になるので、$f$ の最大値は $e^{1/e} \approx 1.4447$ です。$e$ より大きい範囲で減少することから、$e^\pi$ と $\pi^e$ の大小（$\pi^e < e^\pi$）も同時に判定できます。

### 解答の組み立て

1. **対数をとる** $f(x) = e^{(\log x)/x}$ と書けるので、$f$ の増減・極限はすべて $g(x) = \dfrac{\log x}{x}$ の増減・極限から決まります。
2. **増減** $g'(x) = \dfrac{1 - \log x}{x^2}$ の符号は分子だけで決まり、$x = e$ を境に正から負に変わります。
3. **大小比較** $e^\pi$ と $\pi^e$ の対数をとって $e\pi$ で割ると、$\dfrac{\log e}{e}$ と $\dfrac{\log\pi}{\pi}$ の比較になり、(1) の結果がそのまま使えます。

（参考）$e^\pi \approx 23.14$、$\pi^e \approx 22.46$ で、両者はかなり近い値です。

### ポイント

- 一般に $e \le a < b$ ならば $a^b > b^a$ です（$2^4 = 4^2$ のように、$a < e$ の場合は大小が入れ替わったり等しくなったりします）。
- $f'(x)$ を直接求めるときは $f'(x) = f(x)\,g'(x) = x^{1/x}\cdot\dfrac{1 - \log x}{x^2}$ です（対数微分法）。$x^{1/x}$ を $x^n$ のように扱って $\dfrac1x\cdot x^{1/x - 1}$ と微分するのは誤りです。
- $\lim_{x\to+0}$ では $x^{1/x}$ が「$0^{\infty}$ 型」で不定形ではなく、$0$ に収束します。$\lim_{x\to+0} x^x = 1$（$0^0$ 型）と混同しないようにします。
