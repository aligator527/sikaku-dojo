$f$ が満たす微分方程式 $(1 - x^2)f'' - xf' = 0$ を $n$ 回微分して $x = 0$ を代入すると、漸化式 $f^{(n+2)}(0) = n^2 f^{(n)}(0)$ が得られます。$f'(0) = 1$ から $f^{(7)}(0) = 5^2\cdot 3^2\cdot 1^2 = 225$ です。

### 計算

$f'(x) = \dfrac{1}{\sqrt{1-x^2}}$ より $(1 - x^2)\{f'(x)\}^2 = 1$。両辺を微分して $2f'$ で割ると

$$(1 - x^{2})f''(x) - x f'(x) = 0.$$

ライプニッツの公式で両辺を $n$ 回微分すると

$$(1 - x^{2})f^{(n+2)} - 2nx f^{(n+1)} - n(n-1)f^{(n)} - x f^{(n+1)} - n f^{(n)} = 0.$$

$x = 0$ を代入すると $f^{(n+2)}(0) = \{n(n-1) + n\}f^{(n)}(0) = n^{2}f^{(n)}(0)$。$f'(0) = 1$ から

$$f'''(0) = 1^2\cdot 1 = 1,\qquad f^{(5)}(0) = 3^2\cdot 1 = 9,\qquad f^{(7)}(0) = 5^2\cdot 9 = 225.$$

**別解（級数）** $\dfrac{1}{\sqrt{1-x^2}} = \displaystyle\sum_{k=0}^{\infty}\frac{(2k-1)!!}{(2k)!!}x^{2k}$ を項別積分すると

$$\sin^{-1}x = x + \frac{1}{2}\cdot\frac{x^3}{3} + \frac{1\cdot3}{2\cdot4}\cdot\frac{x^5}{5} + \frac{1\cdot3\cdot5}{2\cdot4\cdot6}\cdot\frac{x^7}{7} + \cdots.$$

$x^7$ の係数は $\dfrac{15}{48}\cdot\dfrac17 = \dfrac{5}{112}$ なので、$f^{(7)}(0) = 7!\cdot\dfrac{5}{112} = 225$ です。

### ポイント

- テイラー係数 $a_n$ と高次微分係数は $f^{(n)}(0) = n!\,a_n$ の関係です。係数 $\dfrac{5}{112}$ をそのまま答えたり、$n!$ を掛け忘れたりしないようにします。
- 逆三角関数・$\sqrt{\ }$ を含む関数の高次微分は、「簡単な微分方程式を作ってライプニッツの公式で $n$ 回微分」が定石です。
- 同じ方法で $\tan^{-1}x$ なら $(1+x^2)f' = 1$ から $f^{(2m+1)}(0) = (-1)^m(2m)!$ が得られます。
