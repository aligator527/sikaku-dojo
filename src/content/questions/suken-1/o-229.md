P を $x$ 単位、Q を $y$ 単位とると、$3x + y \ge 12,\ x + y \ge 8,\ x + 3y \ge 12$ のもとで $50x + 30y$ を最小化する問題になります。実行可能領域は非有界ですが、目的関数の係数が正なので最小値は頂点でとられ、$(x, y) = (2, 6)$ で $280$ 円です。

### 計算

実行可能領域の頂点（境界の交点のうち全制約を満たすもの）を求めます。

| 頂点 | 求め方 | $50x + 30y$ |
| --- | --- | --- |
| $(0, 12)$ | $3x + y = 12$ と $x = 0$ | $360$ |
| $(2, 6)$ | $3x + y = 12$ と $x + y = 8$ | $280$ |
| $(6, 2)$ | $x + y = 8$ と $x + 3y = 12$ | $360$ |
| $(12, 0)$ | $x + 3y = 12$ と $y = 0$ | $600$ |

$(2, 6)$ では $x + 3y = 20 \ge 12$、$(6, 2)$ では $3x + y = 20 \ge 12$ で、残りの制約も満たします。

領域は右上に無限に広がっていますが、$x, y$ を増やすと費用は増えるだけなので、最小値は頂点のどれかでとられます。最小値は $(2, 6)$ での $280$ 円です。

**最適性の確認（双対）** 制約 $3x + y \ge 12$ に $u_1 = 10$、$x + y \ge 8$ に $u_2 = 20$ を掛けて足すと

$$50x + 30y = 10(3x + y) + 20(x + y) \ge 10\cdot 12 + 20\cdot 8 = 280$$

となり、すべての実行可能解で費用が $280$ 以上であることが直接示せます。

### ポイント

- 等高線 $50x + 30y = k$ の傾き $-\tfrac53$ は、$3x + y = 12$ の傾き $-3$ と $x + y = 8$ の傾き $-1$ の間にあるので、最適解はこの 2 直線の交点です。
- 最小化問題で実行可能領域が非有界でも、目的関数が下に有界なら最適解は頂点に現れます。最大化問題と取り違えて「最小値なし」としないようにします。
- 上の $u_1, u_2$ は双対問題の最適解です。主問題と双対問題の最適値が一致すること（強双対性）が、最適性の証明書になります。
