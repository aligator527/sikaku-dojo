  平均 $0$、分散 $\sigma^2$ のホワイトノイズ $\varepsilon_t$ を用いた MA(1) モデル

  $$X_t = \varepsilon_t + 0.5\varepsilon_{t-1}$$

choices:

MA(1) $X_t = \varepsilon_t + \theta\varepsilon_{t-1}$ の自己共分散は $\gamma(0) = (1 + \theta^2)\sigma^2$、$\gamma(1) = \theta\sigma^2$ で、ラグ 2 以上は $0$ です。$\theta = 0.5$ なので $\rho(1) = 0.5/(1 + 0.25) = 0.4$、$\rho(2) = 0$ となります。

### 計算

$$\gamma(0) = V[\varepsilon_t + 0.5\varepsilon_{t-1}] = (1 + 0.5^2)\sigma^2 = 1.25\sigma^2$$

$$\gamma(1) = \mathrm{Cov}(\varepsilon_t + 0.5\varepsilon_{t-1},\ \varepsilon_{t-1} + 0.5\varepsilon_{t-2}) = 0.5\sigma^2$$

$X_t$ と $X_{t-2}$ は共通のノイズを含まないので $\gamma(2) = 0$ です。

$$\rho(1) = \frac{0.5\sigma^2}{1.25\sigma^2} = 0.4,\qquad \rho(2) = 0$$

### 各選択肢の検討

- ①：係数 $0.5$ の AR(1) の自己相関 $\rho(h) = 0.5^h$ と取り違えています。
- ②：正しい。
- ③：$\gamma(1)$ を $X_t$ の分散ではなくノイズの分散 $\sigma^2$ で割っています。
- ④：自己相関が等比的に減衰すると考えていますが、MA(1) ではラグ 2 以降で 0 に切断されます。
- ⑤：分母を $1 + \theta^2$ ではなく $1 + \theta$ としています。

### ポイント

- MA($q$) の自己相関はラグ $q$ の後で 0 になり（切断）、偏自己相関は減衰する。AR($p$) はその逆。
- $\theta$ と $1/\theta$ は同じ自己相関を与える（$\theta = 2$ でも $\rho(1) = 2/5 = 0.4$）。識別のため、通常は反転可能性 $|\theta| < 1$ を満たす方を採用する。
- MA(1) では常に $|\rho(1)| \leq 0.5$ が成り立つ。
