  Web サイトの 1 日あたりの真の訪問者水準 $\mu_t$（千人）を、次のローカルレベルモデル（状態空間モデル）で推定している。

  $$\text{観測方程式：}\ y_t = \mu_t + \varepsilon_t,\qquad \varepsilon_t \sim N(0,\ 4)$$

  $$\text{状態方程式：}\ \mu_t = \mu_{t-1} + \eta_t,\qquad \eta_t \sim N(0,\ 3)$$

  $\varepsilon_t$ と $\eta_t$ は互いに独立で、時点についても独立である。時点 $t - 1$ までの観測にもとづく状態の分布（フィルタ分布）が $N(100,\ 5)$ であり、時点 $t$ に $y_t = 110$ が観測された。

カルマンフィルタは「予測」と「更新（フィルタリング）」を交互に行います。予測ステップで状態の分散が $5 + 3 = 8$ に広がり、カルマンゲインは $K = 8/(8 + 4) = 2/3$ です。更新後の推定値は予測値 $100$ を観測との差 $10$ の $2/3$ だけ観測側に寄せた $106.67$ です。

### 計算

**予測ステップ**：状態方程式から

$$\mu_{t \mid t-1} = 100,\qquad P_{t \mid t-1} = 5 + 3 = 8$$

**更新ステップ**：観測の予測誤差（イノベーション）は $y_t - \mu_{t \mid t-1} = 10$、その分散は $P_{t \mid t-1} + \sigma_\varepsilon^2 = 8 + 4 = 12$ です。

$$K_t = \frac{P_{t \mid t-1}}{P_{t \mid t-1} + \sigma_\varepsilon^2} = \frac{8}{12} = \frac{2}{3}$$

$$\mu_{t \mid t} = 100 + \frac{2}{3} \times 10 \approx 106.67,\qquad P_{t \mid t} = (1 - K_t)P_{t \mid t-1} = \frac{8}{3} \approx 2.67$$

### よくある誤り

- 予測ステップで状態ノイズの分散 3 を加え忘れると、$K = 5/9$ となり $105.56$ になります。
- ゲインを $\sigma_\varepsilon^2/(P_{t \mid t-1} + \sigma_\varepsilon^2) = 1/3$ と逆にすると $103.33$ になります。観測ノイズが小さいほど観測を信用する（$K$ が 1 に近づく）のが正しい向きです。

### ポイント

- 更新後の推定値は、予測値と観測値を精度（分散の逆数）で重み付けした平均と同じになる：$(100/8 + 110/4)/(1/8 + 1/4) = 106.67$。
- ローカルレベルモデルは ARIMA(0, 1, 1) と同等で、定常状態のカルマンフィルタは単純指数平滑法に一致する。
- 状態空間モデルでは、トレンド・季節・回帰の成分を状態として組み合わせ、季節調整や欠測値の補完、全時点のデータを使った平滑化（カルマンスムーザー）も同じ枠組みで扱える。
