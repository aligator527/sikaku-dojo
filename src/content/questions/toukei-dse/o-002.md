直交計画では目的関数が係数ごとに分離し、lasso は最小二乗推定値に「ソフト閾値処理」$\operatorname{sign}(z)(|z| - \lambda)_+$ を、リッジ回帰は「一律の縮小」$z/(1 + \lambda)$ を施したものになります。lasso では絶対値が $\lambda = 1$ 以下の係数がちょうど 0 になり、リッジでは 0 にならず半分に縮みます。

### 計算

$X^{\top}X = I$ のとき、$z = X^{\top}y = \hat{\beta}^{\mathrm{OLS}}$ とおくと

$$\frac{1}{2}\|y - X\beta\|^2 = \frac{1}{2}\|y\|^2 - z^{\top}\beta + \frac{1}{2}\|\beta\|^2 = \text{定数} + \frac{1}{2}\sum_j(\beta_j - z_j)^2$$

と書けるので、係数ごとの 1 変数の最小化問題になります。

- lasso：$\frac{1}{2}(\beta_j - z_j)^2 + \lambda|\beta_j|$ の最小化（劣微分が 0 を含む条件）から

  $$\hat{\beta}_j^{\mathrm{L}} = \operatorname{sign}(z_j)\max(|z_j| - \lambda,\ 0)$$

  $z = (3.0, -0.8, 0.4)$、$\lambda = 1$ より $(2.0,\ 0,\ 0)$。

- リッジ：$\frac{1}{2}(\beta_j - z_j)^2 + \frac{\lambda}{2}\beta_j^2$ を微分して 0 とおくと $\hat{\beta}_j^{\mathrm{R}} = z_j/(1 + \lambda)$。よって $(1.5,\ -0.4,\ 0.2)$。

### 各選択肢の検討

- ①：符号を考えずに一律に $\lambda$ を引き、0 で打ち切っていません。
- ②：lasso とリッジを取り違えています。
- ③：閾値以下を 0 にするだけで、残った係数を縮めない「ハード閾値処理」です（最良部分集合選択に対応）。
- ⑤：リッジの縮小率を $1/(1 + 2\lambda)$ としています。罰則項の係数 $\lambda/2$ と微分で出る 2 が打ち消し合うことに注意します。

### ポイント

- L1 罰則は係数をちょうど 0 にでき（スパース推定・変数選択）、L2 罰則は係数を連続的に縮めるが 0 にはしない。
- $\lambda$ を大きくするとバイアスは増え、バリアンスは減る。$\lambda$ は訓練誤差ではなく交差検証などで選ぶ（訓練誤差は $\lambda = 0$ で最小）。
- 罰則は係数の大きさに依存するので、説明変数は事前に標準化しておくのが普通。
