  ある国の硬貨は 1 円・4 円・6 円の 3 種類である。指定した金額をできるだけ少ない枚数の硬貨で支払うため、金額の大きい硬貨から順に使えるだけ使う、次の関数を作った。

  ```python
  def greedy_coins(amount, coins=(6, 4, 1)):
      count = 0
      for c in coins:
          count += amount // c
          amount %= c
      return count

  print(greedy_coins(8))
  ```

`greedy_coins(8)` は、6 円を $8 // 6 = 1$ 枚使って残り 2 円、4 円は $2 // 4 = 0$ 枚、1 円を 2 枚使うので、$1 + 0 + 2 = 3$ を返します。しかし 4 円を 2 枚使えば 2 枚で支払えるので、貪欲法の答えは最適ではありません。その場で最もよく見える選択（大きい硬貨）が、全体として最適とは限らない例です。

### 計算

| 硬貨 | 使う枚数 `amount // c` | 残りの金額 `amount % c` |
| --- | --- | --- |
| 6 円 | 1 | 2 |
| 4 円 | 0 | 2 |
| 1 円 | 2 | 0 |

最小枚数は動的計画法 $\mathrm{dp}(a) = \min_{c \leq a}\{\mathrm{dp}(a - c)\} + 1$（$\mathrm{dp}(0) = 0$）で求められ、$\mathrm{dp}(8) = \mathrm{dp}(4) + 1 = 2$ です。この硬貨の組では、金額 8、9、14、15、20 などで貪欲法が最適解を逃します（例：9 円は貪欲法で 6 + 1 + 1 + 1 の 4 枚、最小は 4 + 4 + 1 の 3 枚）。

### 各選択肢の検討

- ①：正しい。
- ②：関数の出力は 3 です。また、貪欲法が常に最適になるのは、日本の硬貨（1・5・10・50・100・500 円）のように特別な性質をもつ組の場合に限られます。
- ③：3 は最小枚数ではありません。
- ④：`//` は切り捨ての割り算（商）で、余りは `%` です。
- ⑤：動的計画法では金額 $0, 1, \ldots, A$ のそれぞれについて硬貨の種類数 $k$ 通りを調べるだけなので、計算時間は $O(kA)$ です。指数時間になるのは、すべての組合せを調べ上げる場合です。

### ポイント

- 貪欲法は計算が速く実装も簡単だが、最適解が得られる保証は問題の構造（マトロイドなど）に依存する。最小全域木のクラスカル法・プリム法、区間スケジューリング、ハフマン符号は貪欲法で最適解が得られる代表例。
- 最適性が保証されない場合でも、貪欲法の解は局所探索やメタヒューリスティクスの初期解として使われる。
