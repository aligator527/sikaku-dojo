  RGB の 3 チャネル、縦横 32 × 32 画素の画像を分類するため、次の PyTorch のモデルを定義した。

  ```python
  import torch.nn as nn

  model = nn.Sequential(
      nn.Conv2d(in_channels=3, out_channels=32, kernel_size=3, padding=1),   # 層A
      nn.ReLU(),
      nn.MaxPool2d(kernel_size=2),
      nn.Conv2d(in_channels=32, out_channels=64, kernel_size=3, padding=1),  # 層B
      nn.ReLU(),
  )
  ```

  `nn.Conv2d` は既定でバイアス項をもつ（`bias=True`）。層 B の学習可能なパラメータ（重みとバイアス）の個数を求めよ。

畳み込み層のパラメータ数は「（カーネルの縦 × 横 × 入力チャネル数 + 1）× 出力チャネル数」です。層 B のフィルタ 1 枚は $3 \times 3$ の窓を入力の 32 チャネルすべてにわたってもち、それが出力チャネルの数（64 枚）だけあります。各フィルタにバイアスが 1 つずつ付くので、$(3 \times 3 \times 32 + 1) \times 64 = 18496$ 個です。

### 計算

$$\underbrace{3 \times 3 \times 32 \times 64}_{\text{重み}} + \underbrace{64}_{\text{バイアス}} = 18432 + 64 = 18496$$

参考までに、ほかの層は次のとおりです。

- 層 A：$(3 \times 3 \times 3 + 1) \times 32 = 896$ 個
- ReLU と最大プーリング：学習するパラメータはない（0 個）

### ポイント

- 畳み込み層のパラメータ数は、入力画像の縦横の大きさ（ここでは 32 × 32）によらない。同じフィルタを画像のすべての位置で使い回す（重み共有）ためである。
- 比較のため、層 B の入力（$16 \times 16 \times 32$ 次元）を出力（$16 \times 16 \times 64$ 次元）へ全結合層で写すと、パラメータは $8192 \times 16384 + 16384 = 134234112$ 個（約 1.3 億個）になる。局所的な結合と重み共有によって、CNN はパラメータを大幅に減らしている。
- 典型的な誤り：入力チャネル数を掛け忘れる（$3 \times 3 \times 64 + 64 = 640$）、バイアスを数え忘れる（$18432$）、画像の大きさを掛けてしまう。
