  次の Python の関数 `f(n)` について、`count` に加算される回数（計算時間）のオーダーとして正しいものを、次のうちから一つ選べ。$n$ は 2 以上の整数とする。

  ```python
  def f(n):
      count = 0
      for i in range(n):
          j = 1
          while j < n:
              j *= 2
              count += 1
      return count
  ```
choices:
  - '$O(n \log n)$'
  - '$O(\log n)$'
  - '$O(n)$'
  - '$O(n^2)$'
  - '$O(2^n)$'
answer: 1
---
外側の `for` 文は $n$ 回繰り返されます。内側の `while` 文では `j` が $1, 2, 4, 8, \ldots$ と 2 倍ずつ増え、$n$ 以上になったところで終わるので、繰り返しは $\lceil\log_2 n\rceil$ 回です。全体では $n \times \lceil\log_2 n\rceil$ 回となり、オーダーは $O(n \log n)$ です。

### 計算

内側のループで `j` が $2^k \geq n$ となる最小の $k$ が繰り返し回数なので、$k = \lceil\log_2 n\rceil$ です。たとえば $n = 1000$ なら $2^9 = 512 < 1000 \leq 2^{10}$ より内側は 10 回、全体で $1000 \times 10 = 10000$ 回です。

### 各選択肢の検討

- ①：正しい。
- ②：内側のループだけの回数です。外側の $n$ 回の繰り返しを掛け忘れています。
- ③：内側のループの回数を定数とみなしています。
- ④：内側のループが `j += 1` のように 1 ずつ増える場合です。2 倍ずつ増えると $\log n$ 回で終わります。
- ⑤：指数時間になるのは、再帰呼び出しが毎回 2 つに分かれる（素朴なフィボナッチ数の計算など）ような場合です。

### ポイント

- 「毎回 2 倍（または半分）」になる繰り返しは $O(\log n)$。二分探索、二分木の高さ、繰り返し二乗法などで現れる。
- 入れ子のループは回数を掛け算する。$O(n\log n)$ は、比較によるソート（マージソート、ヒープソート）の計算量でもある。
- オーダー記法では、対数の底や定数倍は区別しない（$\log_2 n$ と $\log_{10} n$ は定数倍の違い）。
