  広告枠の予算配分を 0-1 ナップサック問題として解く。$n$ 個の候補 $i$ にはそれぞれ費用 `weights[i]`（正の整数）と効果 `values[i]` があり、各候補は 1 回までしか選べない。費用の合計が予算 `W` 以下になる選び方のうち、効果の合計の最大値を、次の動的計画法の関数で求めたい。`dp[c]` は「ここまでに調べた候補だけを使い、費用の合計が `c` 以下のときの効果の合計の最大値」を表す。

  ```python
  def knapsack(weights, values, W):
      dp = [0] * (W + 1)
      for w_i, v_i in zip(weights, values):
          for c in （あ）:
              dp[c] = max(dp[c], dp[c - w_i] + v_i)
      return dp[W]
  ```

  たとえば `knapsack([1, 3, 4], [15, 20, 30], 4)` は、費用 1 と 3 の候補を選んだときの 35 を返さなければならない。空欄（あ）に入るものとして正しいものを次のうちから一つ選べ。
choices:
  - '`range(w_i, W + 1)`'
  - '`range(W, w_i, -1)`'
  - '`range(W, w_i - 1, -1)`'
  - '`range(W + 1)`'
  - '`range(w_i, W)`'
answer: 3

1 次元の配列 `dp` を使い回す場合、`dp[c - w_i]` は「候補 $i$ をまだ使っていない」状態の値でなければなりません。`c` を大きい方から小さい方へ動かすと、`dp[c]` を更新する時点で `dp[c - w_i]`（`c` より小さい添字）はまだ更新されておらず、前の候補までの値が残っています。また、`c` は `w_i` 以上の範囲だけを調べればよい（`c < w_i` では候補 $i$ を入れられない）ので、`range(W, w_i - 1, -1)`（`W` から `w_i` まで 1 ずつ減らす）が正解です。

### 各選択肢の検討

例の `knapsack([1, 3, 4], [15, 20, 30], 4)` を各選択肢で実行すると次のようになります（正しい値は 35）。

| 選択肢 | 返す値 | 理由 |
| --- | --- | --- |
| ① `range(w_i, W + 1)` | 60 | 小さい方から更新すると、同じ候補を何度でも使える |
| ② `range(W, w_i, -1)` | 20 | `c = w_i` が抜ける |
| ③ `range(W, w_i - 1, -1)` | 35 | 正しい |
| ④ `range(W + 1)` | 140 | `c < w_i` で負の添字になる |
| ⑤ `range(w_i, W)` | 0 | `dp[W]` が更新されない |

- ①：`c` を小さい方から動かすと、`dp[c - w_i]` がすでに候補 $i$ を入れた値に更新されていることがあり、同じ候補を複数回使ってしまいます。例では費用 1・効果 15 の候補を 4 回使って 60 になります。これは各候補を何個でも使える「個数制限なしナップサック問題」の解き方です。
- ②：`range` の終点は含まれないので、`c = w_i` の場合が調べられません。例では費用 1 の候補を `dp[1]` に入れられず、正しい値が得られません。
- ③：正しい。
- ④：`c < w_i` のとき `c - w_i` が負になります。Python では負の添字はリストの末尾からの要素を指すのでエラーにならず、誤った値が紛れ込みます。
- ⑤：終点 `W` が含まれないので、答えを入れる `dp[W]` が一度も更新されず 0 のままです。

### ポイント

- 0-1 ナップサック問題の動的計画法：$\mathrm{dp}_i(c) = \max\{\mathrm{dp}_{i-1}(c),\ \mathrm{dp}_{i-1}(c - w_i) + v_i\}$。2 次元の表を 1 次元に詰めるときは、容量の大きい方から更新する。
- 計算量は $O(nW)$。$W$ の値そのもの（入力の桁数ではない）に比例するので擬似多項式時間と呼ばれ、$W$ が非常に大きいと現実的でなくなる。ナップサック問題自体は NP 困難である。
- 効果と費用の比が大きい順に詰める貪欲法は、0-1 ナップサック問題では最適解を与えるとは限らない。たとえば費用 $(3, 2, 2)$、効果 $(5, 3, 3)$、予算 4 では、比が最大の費用 3 の候補を先に選ぶと合計 5 で止まるが、費用 2 の候補を 2 つ選べば 6 になる。
