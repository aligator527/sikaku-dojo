  ある EC サイトの日次注文数から曜日効果とトレンドを除いた系列 $X_t$ が、平均 $0$ の定常な AR(1) モデル

  $$X_t = 0.6X_{t-1} + \varepsilon_t$$

定常 AR(1) の分散は $\gamma(0) = \sigma^2/(1 - \phi^2) = 4/0.64 = 6.25$ で、自己共分散はラグが 1 増えるごとに $\phi$ 倍になります（$\gamma(h) = \phi^h\gamma(0)$）。したがって $\gamma(2) = 0.6^2 \times 6.25 = 2.25$ です。

### 計算

両辺の分散をとると、$\varepsilon_t$ と $X_{t-1}$ が無相関で、定常性から $V[X_t] = V[X_{t-1}] = \gamma(0)$ なので

$$\gamma(0) = \phi^2\gamma(0) + \sigma^2 \quad\Rightarrow\quad \gamma(0) = \frac{\sigma^2}{1 - \phi^2} = \frac{4}{1 - 0.36} = 6.25$$

次に、モデルの両辺に $X_{t-h}$（$h \geq 1$）を掛けて期待値をとると、$E[\varepsilon_t X_{t-h}] = 0$ より

$$\gamma(h) = \phi\,\gamma(h - 1) \quad\Rightarrow\quad \gamma(h) = \phi^h\gamma(0)$$

よって

$$\gamma(2) = 0.6^2 \times 6.25 = 0.36 \times 6.25 = 2.25$$

### ポイント

- 自己相関係数は $\rho(h) = \gamma(h)/\gamma(0) = \phi^h$ で、$\rho(2) = 0.36$。問われているのが自己共分散か自己相関かを区別する。
- $\phi^2\sigma^2 = 1.44$ とするのは、$X_t$ の分散ではなくノイズの分散を使った誤り。AR 過程の分散はノイズの分散より大きい（過去のノイズが蓄積する）。
- AR(1) の自己相関はラグとともに指数的に減衰し、偏自己相関はラグ 1 の後で 0 になる（切断）。モデル同定の手がかりになる。
