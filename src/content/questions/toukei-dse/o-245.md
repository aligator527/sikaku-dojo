  ウェブサイトのページ間のリンク構造を有向グラフで表し、トップページ A から各ページに何回のクリックでたどり着けるかを調べる。次の Python のコードを実行する。

  ```python
  from collections import deque

  graph = {'A': ['B', 'C'], 'B': ['D'], 'C': ['F'],
           'D': ['E'], 'E': ['F'], 'F': []}

  def search(start):
      dist = {start: 0}
      order = []
      q = deque([start])
      while q:
          v = q.popleft()
          order.append(v)
          for w in graph[v]:
              if w not in dist:
                  dist[w] = dist[v] + 1
                  q.append(w)
      return order, dist

  order, dist = search('A')
  print(order)
  print(dist['F'])
  ```

  出力される `order` と `dist['F']` の組合せとして、正しいものを次のうちから一つ選べ。
choices:

  - '`[''A'', ''B'', ''C'', ''D'', ''F'', ''E'']` と `2`'
  - '`[''A'', ''C'', ''F'', ''B'', ''D'', ''E'']` と `2`'
  - '`[''A'', ''B'', ''C'', ''D'', ''E'', ''F'']` と `2`'
  - '`[''A'', ''B'', ''C'', ''D'', ''F'', ''E'']` と `4`'
answer: 2
---
`deque` の `popleft()` で先に入れたものから取り出す（キュー、先入れ先出し）ので、これは幅優先探索です。A からの距離が近い順に、距離 0 の A、距離 1 の B、C、距離 2 の D、F、距離 3 の E と訪問します。F には A → C → F の 2 回のクリックで到達するので `dist['F']` は 2 です。

### 実行の流れ

| 取り出す頂点 | 新たに見つけてキューに入れる頂点（距離） | キューの中身 |
| --- | --- | --- |
| A | B（1）、C（1） | B, C |
| B | D（2） | C, D |
| C | F（2） | D, F |
| D | E（3） | F, E |
| F | なし | E |
| E | なし（F は発見済み） | 空 |

### 各選択肢の検討

- ①：再帰による深さ優先探索で訪問した順と、そのとき A → B → D → E → F の経路の長さ 4 を距離としたものです。深さ優先探索で見つかる経路は最短とは限りません。
- ②：正しい。
- ③：`popleft()` を `pop()`（後に入れたものから取り出すスタック）に変えた場合の訪問順です。
- ④：頂点名の順に並べています。E は距離 3、F は距離 2 なので、幅優先探索では F が先に訪問されます。
- ⑤：訪問順は正しいですが、距離を最長の経路で数えています。幅優先探索では、最初に見つけたときの距離が最短距離になります。

### ポイント

- 幅優先探索（BFS）はキュー、深さ優先探索（DFS）はスタック（または再帰）で実装する。どちらも計算量は $O(V + E)$（頂点数 + 辺数）。
- 辺に重みがないグラフでは、BFS で最初に発見したときの距離が最短距離（最小の辺数）になる。重みがある場合はダイクストラ法などを使う。
- 発見済みかどうかの判定に辞書や集合を使うと、判定は平均 $O(1)$ でできる。リストで判定すると $O(V)$ かかる。
