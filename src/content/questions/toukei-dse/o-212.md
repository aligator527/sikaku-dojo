被積分関数 $\theta^3(1 - \theta)^2$ は $\theta^{a-1}(1 - \theta)^{b-1}$ で $a = 4,\ b = 3$ とした形なので、$m = B(4, 3) = \dfrac{\Gamma(4)\Gamma(3)}{\Gamma(7)} = \dfrac{3! \times 2!}{6!} = \dfrac{12}{720} = \dfrac{1}{60}$ です。

### 計算

$$m = B(4, 3) = \frac{\Gamma(4)\,\Gamma(3)}{\Gamma(7)} = \frac{3!\ 2!}{6!} = \frac{6 \times 2}{720} = \frac{1}{60}$$

展開して直接積分しても確かめられます。

$$\int_0^1 \theta^3(1 - 2\theta + \theta^2)\,d\theta = \frac{1}{4} - \frac{2}{5} + \frac{1}{6} = \frac{15 - 24 + 10}{60} = \frac{1}{60}$$

### 各選択肢の検討

- ①：指数 3 と 2 をそのまま母数にして $B(3, 2) = \dfrac{2!\ 1!}{4!} = \dfrac{1}{12}$ としています。$\theta^{a-1}$ の「$-1$」に注意します。また、$\int_0^1\theta^3\,d\theta \times \int_0^1(1 - \theta)^2\,d\theta = \dfrac{1}{4} \times \dfrac{1}{3}$ と積を分けて積分しても同じ誤った値になります（積の積分は積分の積ではありません）。
- ②：正しい。
- ③：分母を $\Gamma(a + b) = \Gamma(7) = 6!$ ではなく $5!$ としています（$\dfrac{3!\ 2!}{5!}$）。
- ④：$\Gamma(n) = n!$ と取り違えています（$\dfrac{4!\ 3!}{7!} = \dfrac{144}{5040}$）。
- ⑤：分母を $\Gamma(a + b + 1) = 7!$ としています（$\dfrac{3!\ 2!}{7!}$）。

### ポイント

- 事後分布は $\mathrm{Beta}(4, 3)$ で、その正規化定数がちょうど周辺尤度 $m$ になる。
- 周辺尤度は、モデル（事前分布）どうしを比べるベイズファクター $m_1/m_2$ の計算に使う。たとえば「$\theta = 0.5$ に固定したモデル」の周辺尤度は $0.5^5 = 1/32$ で、ベイズファクターは $(1/60)/(1/32) \approx 0.53$。
- ガンマ関数の性質：$\Gamma(n) = (n - 1)!$、$\Gamma(x + 1) = x\Gamma(x)$、$\Gamma(1/2) = \sqrt{\pi}$。
