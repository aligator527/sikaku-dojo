両方が購入したのは野菜・乳製品・飲料の 3 カテゴリー、少なくとも一方が購入したのは冷凍食品以外の 5 カテゴリーなので、ジャカード係数は $3/5 = 0.6$ です。単純一致係数は、両方とも購入しなかった冷凍食品も「一致」と数えるので $(3 + 1)/6 \approx 0.667$ になります。

### 計算

$a$ = 両方 1 の数、$b$ = A だけ 1、$c$ = B だけ 1、$d$ = 両方 0 とすると、$a = 3$（野菜・乳製品・飲料）、$b = 1$（鮮魚）、$c = 1$（菓子）、$d = 1$（冷凍食品）です。

$$\text{ジャカード係数} = \frac{a}{a + b + c} = \frac{3}{5} = 0.6,\qquad \text{単純一致係数} = \frac{a + d}{a + b + c + d} = \frac{4}{6} \approx 0.667$$

### 各選択肢の検討

- ①：2 つの値を取り違えています。
- ②：単純一致係数で、両方 0 の一致（冷凍食品）を数えていません（$3/6$）。
- ③：正しい。
- ④：ジャカード係数の分母を、顧客 A が購入したカテゴリー数 $a + b = 4$ にしています。
- ⑤：ジャカード係数の分母を全カテゴリー数 6 にしています（$3/6$）。

### ポイント

- 購買データのように 0 が大多数を占める疎なデータでは、「両方とも買わなかった」一致を数える単純一致係数は、ほとんど何も買わない顧客どうしを「よく似ている」と評価してしまう。ジャカード係数やコサイン類似度（ここでは $a/\sqrt{(a + b)(a + c)} = 3/4$）は 0–0 の一致を無視する。
- 一方、性別や「はい／いいえ」の質問のように 0 と 1 が対等な 2 値変数では、0–0 の一致にも意味があるので単純一致係数が適する。
- 非類似度として $1 - \text{ジャカード係数}$（ジャカード距離）を使い、階層的クラスタリングなどに入力できる。
