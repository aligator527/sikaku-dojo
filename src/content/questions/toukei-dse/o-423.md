stem: |
  2 つの文書を、語彙（AI, 統計, 学習, 試験）の出現回数を並べた BoW ベクトルで表したところ、

  $$\boldsymbol{a} = (2,\ 1,\ 0,\ 1),\qquad \boldsymbol{b} = (1,\ 1,\ 1,\ 0)$$

  となった。$\boldsymbol{a}$ と $\boldsymbol{b}$ のコサイン類似度に最も近い値を次のうちから一つ選べ。
choices:
  - '$0.50$'
  - '$0.67$'
  - '$0.71$'
  - '$1.73$'
  - '$3.00$'
answer: 3

コサイン類似度は、内積を 2 つのベクトルの長さの積で割ったもので、ベクトルのなす角の余弦です。内積は $2 + 1 + 0 + 0 = 3$、長さは $\|\boldsymbol{a}\| = \sqrt{6}$、$\|\boldsymbol{b}\| = \sqrt{3}$ なので、$3/\sqrt{18} = 1/\sqrt{2} \approx 0.71$ です。

### 計算

$$\cos(\boldsymbol{a}, \boldsymbol{b}) = \frac{\boldsymbol{a}^{\top}\boldsymbol{b}}{\|\boldsymbol{a}\|\,\|\boldsymbol{b}\|} = \frac{2 \cdot 1 + 1 \cdot 1 + 0 \cdot 1 + 1 \cdot 0}{\sqrt{4 + 1 + 0 + 1}\,\sqrt{1 + 1 + 1 + 0}} = \frac{3}{\sqrt{18}} \approx 0.707$$

### 各選択肢の検討

- ①：出現の有無だけを見た集合 $\{\text{AI, 統計, 試験}\}$ と $\{\text{AI, 統計, 学習}\}$ のジャッカード係数 $2/4$ です。
- ②：同じ集合のダイス係数 $2 \times 2/(3 + 3)$ です。
- ③：正しい。
- ④：ユークリッド距離 $\|\boldsymbol{a} - \boldsymbol{b}\| = \sqrt{1 + 0 + 1 + 1} = \sqrt{3}$ です。距離は小さいほど似ていることを表し、類似度とは向きが逆です。
- ⑤：内積です。長さで割らないと、長い文書ほど値が大きくなります。

### ポイント

- 出現回数は非負なので、BoW のコサイン類似度は 0 以上 1 以下。文書の長さ（ベクトルの大きさ）の影響を受けない。
- L2 正規化したベクトルどうしでは $\|\boldsymbol{a} - \boldsymbol{b}\|^2 = 2(1 - \cos)$ が成り立ち、ユークリッド距離による順位とコサイン類似度による順位が一致する。
