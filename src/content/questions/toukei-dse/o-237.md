ハフマン符号は、出現確率の小さい 2 つを繰り返しまとめて木を作り、根から各記号までの深さを符号長とする方法です。木を作ると符号長は A が 2 ビット、B と C が 2 ビット、D と E が 3 ビット（同点の扱いによっては A が 1 ビット、C が 2 ビット、B が 3 ビット、D と E が 4 ビット）となり、どちらの場合も平均符号長は 2.2 ビットです。

### 計算

1. 最小の D（0.1）と E（0.1）をまとめる → DE（0.2）。残り：A 0.4、B 0.2、C 0.2、DE 0.2
2. 0.2 の 3 つのうち 2 つ、たとえば B と C をまとめる → BC（0.4）。残り：A 0.4、BC 0.4、DE 0.2
3. 最小の DE（0.2）と、0.4 の一方（A）をまとめる → A·DE（0.6）。残り：BC 0.4、A·DE 0.6
4. 最後の 2 つをまとめて根とする。

各記号の深さ（符号長）は A：2、B：2、C：2、D：3、E：3 で

$$\bar{L} = 0.4 \times 2 + 0.2 \times 2 + 0.2 \times 2 + 0.1 \times 3 + 0.1 \times 3 = 2.2$$

手順 2 で DE と B をまとめ、手順 3 で BDE（0.4）と C（0.2）をまとめると、符号長は A：1、B：3、C：2、D：4、E：4 となり、$0.4 + 0.6 + 0.4 + 0.4 + 0.4 = 2.2$ で平均は同じです（ハフマン符号は同点の扱いによって形が変わるが、平均符号長はどれも最小値に等しい）。

### ポイント

- 5 種類を固定長で表すには 3 ビット必要なので、ハフマン符号で平均 2.2 ビットに縮み、約 27% 小さくなる。
- 情報源のエントロピー $H = -\sum_i p_i\log_2 p_i \approx 2.122$ ビットは、どんな可逆な符号化でも平均符号長の下限になる。ハフマン符号の平均符号長 $\bar{L}$ は $H \leq \bar{L} < H + 1$ を満たす。
- ハフマン符号は語頭符号（どの符号語も他の符号語の先頭部分にならない）なので、区切り記号なしで一意に復号できる。ZIP（Deflate）や JPEG などの圧縮方式の一部に使われている。
