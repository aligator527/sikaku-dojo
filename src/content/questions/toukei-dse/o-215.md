  2 つの施策に配分する予算 $x_1,\ x_2$（単位：百万円）を、目標値 $(2, 1)$ にできるだけ近づけたい。ただし予算の合計は 2 以下でなければならない。この問題を

  $$\min_{x_1, x_2}\ f(x) = (x_1 - 2)^2 + (x_2 - 1)^2 \quad \text{s.t.}\quad g(x) = x_1 + x_2 - 2 \leq 0$$

  と定式化し、ラグランジュ関数 $\mathcal{L}(x, \lambda) = f(x) + \lambda g(x)$（$\lambda \geq 0$）に対するカルーシュ・キューン・タッカー（KKT）条件を用いて解く。最適解 $x^{*}$ と、それに対応する乗数 $\lambda^{*}$ の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - '$x^{*} = (2,\ 1),\ \lambda^{*} = 0$'
  - '$x^{*} = (1.5,\ 0.5),\ \lambda^{*} = -1$'
  - '$x^{*} = (1,\ 1),\ \lambda^{*} = 2$'
  - '$x^{*} = (1.5,\ 0.5),\ \lambda^{*} = 0.5$'
  - '$x^{*} = (1.5,\ 0.5),\ \lambda^{*} = 1$'
answer: 5

制約を無視した最小点 $(2, 1)$ は $x_1 + x_2 = 3 > 2$ で制約を満たさないので、最適解では制約が等号で成り立ちます（有効制約）。停留条件 $2(x_1 - 2) + \lambda = 0$、$2(x_2 - 1) + \lambda = 0$ と $x_1 + x_2 = 2$ を連立すると、$\lambda^{*} = 1 \geq 0$、$x^{*} = (1.5,\ 0.5)$ が得られます。これは点 $(2, 1)$ から直線 $x_1 + x_2 = 2$ への垂線の足（射影）です。

### KKT 条件

1. 停留条件：$\nabla f(x) + \lambda\nabla g(x) = 0$
2. 主実行可能性：$g(x) \leq 0$
3. 双対実行可能性：$\lambda \geq 0$
4. 相補性条件：$\lambda\,g(x) = 0$

### 計算

相補性条件から「$\lambda = 0$」か「$g(x) = 0$」のどちらかです。

- $\lambda = 0$ の場合：停留条件から $x = (2, 1)$ ですが、$g(2, 1) = 1 > 0$ で主実行可能性を満たしません。
- $g(x) = 0$ の場合：停留条件から $x_1 = 2 - \lambda/2,\ x_2 = 1 - \lambda/2$。これを $x_1 + x_2 = 2$ に代入して $3 - \lambda = 2$、よって $\lambda = 1 \geq 0$、$x = (1.5,\ 0.5)$。

$f$ は凸関数、制約も線形（凸）なので、KKT 条件を満たす点は大域的な最適解です。最小値は $f(x^{*}) = 0.25 + 0.25 = 0.5$ です。

### 各選択肢の検討

- ①：制約を無視した解で、予算の合計が 3 となり制約を満たしません。
- ②：$\lambda \geq 0$（双対実行可能性）に反します。$\mathcal{L} = f + \lambda g$ と $g \leq 0$ の組では、有効な制約の乗数は 0 以上になります。
- ③：$(1, 1)$ は制約の境界上の点ですが、$\nabla f(1, 1) = (-2,\ 0)$ と $\nabla g = (1,\ 1)$ は平行でなく、停留条件 $(-2 + \lambda,\ \lambda) = (0, 0)$ を満たす $\lambda$ は存在しません。
- ④：$f$ の勾配を $(x_1 - 2,\ x_2 - 1)$ と係数 2 を落として計算した値です。$x^{*}$ は同じになりますが、乗数の値が変わります。
- ⑤：正しい。

### ポイント

- 不等式制約は、最適解で等号が成り立つ（有効）か、成り立たず乗数が 0 になるか（相補性）のどちらか。場合分けで解く。
- 乗数 $\lambda^{*} = 1$ は、予算の上限 2 を少し増やしたときの最小値の減少率を表す。上限を $c$ とすると最小値は $(3 - c)^2/2$ で、$c = 2$ での微分は $-1$。
- サポートベクターマシンの双対問題やスパース推定（lasso の制約形式）も、KKT 条件で特徴づけられる。
