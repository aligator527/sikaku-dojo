個体処置効果 $Y(1) - Y(0)$ は順に $4, 2, 1, 2, 3, 3$ で、その平均が ATE です。合計は 15 なので、ATE は $15/6 = 2.5$（千円）です。

### 計算

$$\mathrm{ATE} = \frac{1}{6}\{(14 - 10) + (10 - 8) + (7 - 6) + (6 - 4) + (12 - 9) + (6 - 3)\} = \frac{15}{6} = 2.5$$

### 観測データでの単純比較との違い

現実には、各会員について実際に受けた処置の結果しか観測できません（因果推論の根本問題）。観測できる値だけで群の平均を比べると

$$\underbrace{\frac{14 + 10 + 12}{3}}_{\text{配布群の } Y(1)} - \underbrace{\frac{6 + 4 + 3}{3}}_{\text{非配布群の } Y(0)} = 12 - 4.33 = 7.67$$

となり、ATE の 3 倍以上に見えます。配布群は、クーポンがなくても購入額の多い会員（$Y(0)$ の平均 9）に偏っているためです。

$$\text{単純比較の差} = \underbrace{E[Y(1) - Y(0) \mid T = 1]}_{\mathrm{ATT} = 3} + \underbrace{E[Y(0) \mid T = 1] - E[Y(0) \mid T = 0]}_{\text{選択バイアス} = 9 - 4.33 = 4.67}$$

### ポイント

- ATE は集団全体、ATT（処置群における平均処置効果）は実際に処置を受けた人についての平均で、一般に異なる（ここでは ATT $= (4 + 2 + 3)/3 = 3$）。
- 処置を無作為に割り付ければ、$T$ と $(Y(1), Y(0))$ が独立になり、選択バイアスの項が 0 になるので、群の平均の差が ATE の不偏推定量になる。
