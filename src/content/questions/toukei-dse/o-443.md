総合効果は、$X$ から $Y$ へ向かうすべての有向経路について、経路上のパス係数の積を合計したものです。経路は 4 本あり、$0.1 + 0.5 \times 0.2 + 0.3 \times 0.5 + 0.5 \times 0.4 \times 0.5 = 0.1 + 0.1 + 0.15 + 0.1 = 0.45$ です。

### 計算

| 経路 | 効果 |
| --- | --- |
| $X \to Y$（直接効果） | $0.1$ |
| $X \to M_1 \to Y$ | $0.5 \times 0.2 = 0.10$ |
| $X \to M_2 \to Y$ | $0.3 \times 0.5 = 0.15$ |
| $X \to M_1 \to M_2 \to Y$ | $0.5 \times 0.4 \times 0.5 = 0.10$ |
| 合計（総合効果） | $0.45$ |

構造方程式を順に代入しても同じ結果になります。

$$M_2 = 0.3X + 0.4(0.5X + e_1) + e_2 = 0.5X + 0.4e_1 + e_2$$

$$Y = 0.1X + 0.2(0.5X + e_1) + 0.5(0.5X + 0.4e_1 + e_2) + e_3 = 0.45X + (\text{誤差項})$$

### よくある誤り

- 直接効果 $0.1$ だけを答えると、媒介変数を通じた効果（間接効果 $0.35$）が抜けます。
- $M_1 \to M_2$ の経路を見落とすと $0.35$ になります。

### ポイント

- この例では $X$ と誤差項が独立なので、$Y$ を $X$ だけに回帰したときの係数は総合効果 $0.45$ に一致する。$X, M_1, M_2$ をすべて説明変数に入れて回帰すると、$X$ の係数は直接効果 $0.1$ になる。
- 間接効果を因果効果として解釈するには、媒介変数と結果の間に未観測の交絡がないことが必要（媒介分析の仮定）。
- 構造方程式モデリングでは、観測変数の背後に潜在変数（構成概念）をおき、測定方程式と構造方程式を同時に推定することも多い。
