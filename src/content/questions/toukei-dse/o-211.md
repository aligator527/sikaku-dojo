シンプソン法は、3 点を通る 2 次式で被積分関数を近似して積分する方法で、$\int_{a}^{a+2h} f(x)\,dx \approx \dfrac{h}{3}\left\{f(a) + 4f(a + h) + f(a + 2h)\right\}$ です。$f(0) = 1,\ f(0.5) = 2/3,\ f(1) = 1/2$ を代入すると $\dfrac{0.5}{3}\left(1 + \dfrac{8}{3} + \dfrac{1}{2}\right) = \dfrac{25}{36} \approx 0.694$ です。

### 計算

$$S = \frac{h}{3}\left\{f(0) + 4f(0.5) + f(1)\right\} = \frac{1}{6}\left(1 + 4 \times \frac{2}{3} + \frac{1}{2}\right) = \frac{1}{6} \times \frac{25}{6} = \frac{25}{36} = 0.6944\cdots$$

真の値は $I = \log 2 = 0.6931\cdots$ で、誤差は約 0.0013 です。

同じ 3 点を使う台形則では

$$T = \frac{h}{2}\left\{f(0) + 2f(0.5) + f(1)\right\} = 0.25 \times \left(1 + \frac{4}{3} + \frac{1}{2}\right) = 0.7083\cdots$$

となり、誤差は約 0.015 とシンプソン法より 1 桁大きくなります。

### ポイント

- 台形則は 1 次式、シンプソン法は 2 次式による近似。誤差は小区間の幅 $h$ に対して、台形則が $O(h^2)$、シンプソン法が $O(h^4)$（いずれも区間全体の誤差）。シンプソン法は 3 次式まで厳密に積分できる。
- シンプソン法の係数は $1, 4, 1$（小区間が $2m$ 個のときは $1, 4, 2, 4, \ldots, 2, 4, 1$）で、全体に $h/3$ を掛ける。$h/2$ や $h/6$ と取り違える誤りが多い。
- 台形則の値 $T(h)$ と $T(h/2)$ から $\{4T(h/2) - T(h)\}/3$ を作ると、刻み $h/2$ のシンプソン法と一致する（リチャードソン補外）。本問なら $T(1) = 0.75$ と $T(0.5) = 0.7083$ から $(4 \times 0.7083 - 0.75)/3 \approx 0.694$。
