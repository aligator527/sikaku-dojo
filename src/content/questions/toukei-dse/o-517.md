Q 学習の更新式は $Q(s, a) \leftarrow Q(s, a) + \alpha\left\{r + \gamma\max_{a'}Q(s', a') - Q(s, a)\right\}$ です。次の状態で実際に選んだ行動（左）にかかわらず、$s_2$ での最大の行動価値 $\max\{2.0,\ 4.0\} = 4.0$ を使うのが Q 学習の特徴です。TD 誤差は $-1 + 0.9 \times 4.0 - 1.0 = 1.6$ なので、$Q(s_1, \text{右}) = 1.0 + 0.2 \times 1.6 = 1.32$ です。

### 計算

$$\text{TD ターゲット} = r + \gamma\max_{a'}Q(s_2, a') = -1 + 0.9 \times 4.0 = 2.6$$

$$\text{TD 誤差} = 2.6 - Q(s_1, \text{右}) = 2.6 - 1.0 = 1.6$$

$$Q(s_1, \text{右}) \leftarrow 1.0 + 0.2 \times 1.6 = 1.32$$

### ポイント

- Q 学習は、行動を選ぶ方策（ε-greedy など探索を含む方策）と、更新で評価する方策（greedy 方策）が異なる **方策オフ型（off-policy）** の手法である。
- 同じ遷移で、次に実際に選んだ行動の価値を使う SARSA（**方策オン型（on-policy）**）なら、ターゲットは $-1 + 0.9 \times Q(s_2, \text{左}) = 0.8$、更新後は $1.0 + 0.2 \times (0.8 - 1.0) = 0.96$ になる。
- 典型的な誤り：SARSA の更新をしてしまう（$0.96$）、割引率を掛け忘れる（$1.4$）、学習率を掛けずに TD ターゲットで置き換える（$2.6$）。
- 状態や行動が多い場合は、Q テーブルの代わりにニューラルネットワークで $Q(s, a)$ を近似する（DQN）。
