  ある Web API の応答時間 $X$（ミリ秒）について、過去のログから平均が $200$、標準偏差が $20$ であることがわかっている。ただし、$X$ の分布の形（正規分布かどうかなど）はわからない。

チェビシェフの不等式は、分布の形によらず平均と分散だけから「平均から $k$ 標準偏差以上離れる確率は $1/k^2$ 以下」と保証します。区間 $160 < X < 240$ は平均 $\pm 40$、すなわち $\pm 2\sigma$ なので、外側にはみ出す確率は $1/4$ 以下、内側に入る確率は $1 - 1/4 = 0.75$ 以上です。

### 計算

チェビシェフの不等式：任意の $k > 0$ に対して

$$P(|X - \mu| \geq k\sigma) \leq \frac{1}{k^2}$$

$\mu = 200$、$\sigma = 20$、$k = 40/20 = 2$ とすると

$$P(160 < X < 240) = P(|X - 200| < 40) = 1 - P(|X - 200| \geq 40) \geq 1 - \frac{1}{4} = 0.75$$

### 各選択肢の検討

- ①：$1/k^2 = 0.25$ は区間の外に出る確率の上限で、区間に入る確率の下限ではありません。
- ②：$1 - 1/k$ としています。不等式の右辺は $1/k$ ではなく $1/k^2$ です。
- ③：正しい。
- ④：$1 - 1/3^2 \approx 0.89$ は $k = 3$（$\pm 60$ ミリ秒）の場合です。
- ⑤：正規分布を仮定したときの $P(|Z| < 2) \approx 0.954$ です。分布の形がわからないので、この値は保証されません。

### ポイント

- 下限 $1 - 1/k^2$ はこれ以上改善できない（等号を達成する分布がある）。例えば $X$ が $\mu - 2\sigma$、$\mu$、$\mu + 2\sigma$ をそれぞれ確率 $1/8$、$3/4$、$1/8$ でとる分布は平均 $\mu$・分散 $\sigma^2$ で、$P(|X - \mu| < 2\sigma) = 0.75$ ちょうどになる。
- チェビシェフの不等式はマルコフの不等式 $P(Y \geq a) \leq E[Y]/a$ を $Y = (X - \mu)^2$ に適用して導ける。大数の弱法則（標本平均の確率収束）の証明にも使われる。
- 監視の閾値を「平均 $\pm 3\sigma$」とするとき、正規分布なら外れる確率は約 0.3% だが、分布の仮定がなければ保証できるのは $1/9 \approx 11\%$ 以下までである。
