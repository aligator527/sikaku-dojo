$\frac{1}{n}\mathbf{1}\mathbf{1}^{\top}x = \bar{x}\mathbf{1}$ なので、$Cx = x - \bar{x}\mathbf{1}$ は偏差ベクトルです。$P = \frac{1}{n}\mathbf{1}\mathbf{1}^{\top}$ は $\mathbf{1}$ 方向への直交射影行列で、$C = I - P$ はその直交補空間（成分の和が 0 のベクトル全体、$n - 1$ 次元）への直交射影行列です。

### 各選択肢の検討

- ①：正しい。$\mathbf{1}^{\top}\mathbf{1} = n$ より $P^2 = \frac{1}{n^2}\mathbf{1}(\mathbf{1}^{\top}\mathbf{1})\mathbf{1}^{\top} = P$、よって $C^2 = I - 2P + P^2 = C$ です。$C^{\top} = C$ も明らかです。射影行列のランクはトレースに等しく、$n - 1$ です。
- ②：$C\mathbf{1} = \mathbf{1} - \frac{1}{n}\mathbf{1}(\mathbf{1}^{\top}\mathbf{1}) = \mathbf{0}$ です。定数ベクトルの偏差は 0 です。
- ③：$(Cx)^{\top}(Cy)/n = \frac{1}{n}\sum_i(x_i - \bar{x})(y_i - \bar{y})$ は共分散です。相関係数は、偏差ベクトルどうしのなす角の余弦 $\dfrac{(Cx)^{\top}(Cy)}{\|Cx\|\,\|Cy\|}$ です。
- ④：$C\mathbf{1} = \mathbf{0}$ なので、$C$ は固有値 0 をもち、正則ではありません。
- ⑤：$\operatorname{tr}(C) = n - \frac{1}{n}\operatorname{tr}(\mathbf{1}\mathbf{1}^{\top}) = n - 1$ です。

### ポイント

- 偏差平方和は $\sum_i(x_i - \bar{x})^2 = x^{\top}Cx$ と二次形式で書ける。$\operatorname{rank}(C) = n - 1$ が、不偏分散の分母 $n - 1$（自由度）に対応する。
- データ行列 $X$（$n \times p$）の分散共分散行列（分母 $n$）は、$C^{\top}C = C$ を使って $\frac{1}{n}X^{\top}CX$ と表せる。
