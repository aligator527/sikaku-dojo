  2 変数関数

  $$f(w_1, w_2) = (w_1 - 1)^2 + 4(w_2 + 2)^2$$

  を、最急降下法（勾配降下法）$w^{(k+1)} = w^{(k)} - \eta\,\nabla f(w^{(k)})$ で最小化する。初期値を $w^{(0)} = (0,\ 0)$、学習率を $\eta = 0.1$ としたときの 1 回更新後の点 $w^{(1)}$ と、任意の初期値から最小点に収束するための学習率 $\eta > 0$ の条件の組合せとして、正しいものを次のうちから一つ選べ。
choices:

  - '$w^{(1)} = (0.2,\ -1.6)$、条件は $0 < \eta < 1$'
  - '$w^{(1)} = (0.2,\ -1.6)$、条件は $0 < \eta < 0.125$'
  - '$w^{(1)} = (0.1,\ -0.8)$、条件は $0 < \eta < 0.25$'
answer: 2

勾配は $\nabla f = (2(w_1 - 1),\ 8(w_2 + 2))$ で、原点では $(-2,\ 16)$ です。勾配と逆向きに $\eta = 0.1$ 倍進むので $w^{(1)} = (0.2,\ -1.6)$ となります。二次関数ではヘッセ行列の最大固有値 $L = 8$ に対して $0 < \eta < 2/L = 0.25$ が収束の必要十分条件です。

### 計算

$$\nabla f(0, 0) = \left(2(0 - 1),\ 8(0 + 2)\right) = (-2,\ 16)$$

$$w^{(1)} = (0, 0) - 0.1 \times (-2,\ 16) = (0.2,\ -1.6)$$

収束条件：最小点 $w^{*} = (1, -2)$ からのずれは、成分ごとに

$$w_1^{(k+1)} - 1 = (1 - 2\eta)(w_1^{(k)} - 1),\qquad w_2^{(k+1)} + 2 = (1 - 8\eta)(w_2^{(k)} + 2)$$

と更新されます。両方の成分が 0 に収束する条件は $|1 - 2\eta| < 1$ かつ $|1 - 8\eta| < 1$、すなわち $0 < \eta < 1$ かつ $0 < \eta < 0.25$ なので、$0 < \eta < 0.25$ です。$\eta = 0.25$ では $w_2$ 方向が $\pm$ に振動し続けて収束しません。

### 各選択肢の検討

- ①：勾配の向きに進んでいます（最急上昇）。
- ③：ヘッセ行列の最小固有値 2 で $2/2 = 1$ としています。曲率の大きい方向（$w_2$）が先に発散します。
- ④：$1/L$ は勾配が $L$-リプシッツな関数で目的関数の単調減少が保証される標準的な学習率で、収束する範囲の上限ではありません。
- ⑤：勾配の係数 2 を落としています（$\nabla(w_1 - 1)^2 = 2(w_1 - 1)$）。

### ポイント

- 収束の速さは条件数 $\lambda_{\max}/\lambda_{\min}$（ここでは 4）に依存し、条件数が大きいとジグザグに進んで遅くなる。
- ニュートン法 $w - (\nabla^2 f)^{-1}\nabla f$ なら、二次関数は 1 回で最小点 $(1, -2)$ に到達する。
- 深層学習で使う確率的勾配降下法（SGD）やモーメンタム・Adam も、この更新式の変形である。
