商談化しなかった架電の数 $X = Y - 3$ は負の二項分布に従い、$Y$ は $X$ を定数 3 だけずらしたものなので分散は同じです。$X$ は「1 件目の商談までの失敗数」「2 件目までの失敗数」「3 件目までの失敗数」という 3 個の独立な幾何分布の和で、それぞれの分散は $(1 - p)/p^2 = 20$ なので、$V[Y] = 3 \times 20 = 60$ です。

### 計算

成功確率 $p$ の試行で、最初の成功までの失敗数 $G$ は幾何分布 $P(G = k) = (1 - p)^k p$（$k = 0, 1, \dots$）に従い

$$E[G] = \frac{1 - p}{p} = 4,\qquad V[G] = \frac{1 - p}{p^2} = \frac{0.8}{0.04} = 20$$

$r = 3$ 件目の成功までの失敗数 $X = G_1 + G_2 + G_3$（独立）は負の二項分布

$$P(X = k) = \binom{k + r - 1}{k}p^r(1 - p)^k\qquad (k = 0, 1, \dots)$$

に従い、$E[X] = r(1 - p)/p = 12$、$V[X] = r(1 - p)/p^2 = 60$ です。$Y = X + 3$ より

$$E[Y] = 15,\qquad V[Y] = V[X] = 60$$

### よくある誤り

- 二項分布の分散 $np(1 - p)$ を流用する（$15 \times 0.2 \times 0.8 = 2.4$ など）：ここでは成功数（3 件）が固定で、試行回数のほうが確率変数です。
- 定数 3 を足した分だけ分散も増えると考えて 63 とする：定数を足しても分散は変わりません。
- 期待値 $r(1 - p)/p = 12$ を分散と取り違える。

### ポイント

- 負の二項分布の分散 $r(1 - p)/p^2$ は平均 $r(1 - p)/p$ の $1/p$ 倍で、平均より大きい。ポアソン分布より散らばりの大きい（過分散の）カウントデータのモデルとしても使われ、ポアソン分布の平均 $\lambda$ がガンマ分布に従う混合分布として導ける。
- $r = 1$ のとき幾何分布になる。幾何分布は離散分布で唯一の無記憶性 $P(G \geq s + t \mid G \geq s) = P(G \geq t)$ をもつ。
