  あるウェブサイトへの 100 件のアクセスを端末の種類で分類したところ、PC が 50 件、スマートフォンが 30 件、タブレットが 20 件であった。各アクセスが独立に確率 $p_1, p_2, p_3$（$p_1 + p_2 + p_3 = 1$）で各端末から来るという多項分布モデルを考え、対数尤度

  $$\ell(p) = 50\log p_1 + 30\log p_2 + 20\log p_3$$

  を制約 $p_1 + p_2 + p_3 = 1$ のもとで最大化する。ラグランジュ関数を

  $$\mathcal{L}(p, \lambda) = \ell(p) - \lambda\,(p_1 + p_2 + p_3 - 1)$$

  と定めてラグランジュの未定乗数法を用いるとき、最適解における乗数 $\lambda$ の値と最尤推定値 $(\hat{p}_1,\ \hat{p}_2,\ \hat{p}_3)$ の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - '$\lambda = 100,\ (\hat{p}_1, \hat{p}_2, \hat{p}_3) = (0.5,\ 0.3,\ 0.2)$'
  - '$\lambda = 1,\ (\hat{p}_1, \hat{p}_2, \hat{p}_3) = (0.5,\ 0.3,\ 0.2)$'
  - '$\lambda = -100,\ (\hat{p}_1, \hat{p}_2, \hat{p}_3) = (0.5,\ 0.3,\ 0.2)$'
  - '$\lambda = 100,\ (\hat{p}_1, \hat{p}_2, \hat{p}_3) = (1/3,\ 1/3,\ 1/3)$'
  - '$\lambda = 0,\ (\hat{p}_1, \hat{p}_2, \hat{p}_3) = (0.5,\ 0.3,\ 0.2)$'
answer: 1

$\mathcal{L}$ を $p_k$ で偏微分して 0 とおくと $n_k/p_k - \lambda = 0$、すなわち $p_k = n_k/\lambda$ です。これを制約式に代入すると $(50 + 30 + 20)/\lambda = 1$ から $\lambda = 100$（総数 $n$）となり、$\hat{p}_k = n_k/n = (0.5,\ 0.3,\ 0.2)$ が得られます。

### 計算

$$\frac{\partial \mathcal{L}}{\partial p_k} = \frac{n_k}{p_k} - \lambda = 0 \quad\Longrightarrow\quad p_k = \frac{n_k}{\lambda}\qquad (n_1, n_2, n_3) = (50, 30, 20)$$

$$\sum_{k} p_k = \frac{100}{\lambda} = 1 \quad\Longrightarrow\quad \lambda = 100,\qquad \hat{p} = \left(\frac{50}{100},\ \frac{30}{100},\ \frac{20}{100}\right)$$

$\ell$ は各 $p_k$ について凹関数（$\log$ の和）で、制約は線形なので、この停留点が最大点です。

### 各選択肢の検討

- ①：正しい。
- ②：乗数を「確率の和 1」と混同しています。$\lambda = 1$ なら $p_k = n_k$ となり制約を満たしません。
- ③：ラグランジュ関数を $\ell + \lambda(\sum p_k - 1)$ と定めた場合の値です。本問は $-\lambda$ と定めているので $\lambda = 100$ です。乗数の符号は定め方に依存します。
- ④：データを使わない一様な確率です。$p = (1/3, 1/3, 1/3)$ では $50/p_1 = 150 \neq 30/p_2 = 90$ となり停留条件を満たしません。
- ⑤：制約付き最適化では、最適解で目的関数の勾配が 0 になるとは限りません。ここでは $\partial\ell/\partial p_k = n_k/p_k > 0$ で、勾配は制約面の法線 $(1, 1, 1)$ に平行（$\nabla\ell = \lambda(1, 1, 1)^{\top}$）になります。

### ポイント

- ラグランジュの未定乗数法の条件：$\nabla f(x^{*}) = \lambda\nabla g(x^{*})$ と $g(x^{*}) = 0$。最適点で目的関数の等高線と制約面が接する。
- 乗数 $\lambda$ は「制約の右辺を 1 単位緩めたときの最適値の増加率」（シャドウプライス）と解釈できる。ここで右辺を $c$ にすると最適値は $100\log c + \text{定数}$ となり、$c = 1$ での微分は 100 で $\lambda$ と一致する。
- 多項分布・二項分布の最尤推定値は標本比率 $n_k/n$ になる。
