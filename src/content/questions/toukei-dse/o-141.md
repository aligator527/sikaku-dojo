$x$ 方向への直交射影は $\hat{y} = \dfrac{x^{\top}y}{x^{\top}x}x$ です。$x^{\top}y = 3 + 6 + 12 = 21$、$x^{\top}x = 1 + 4 + 4 = 9$ なので $\hat{\beta} = 7/3$ で、ピタゴラスの定理から残差平方和は $\|y\|^2 - \|\hat{y}\|^2 = 54 - 21^2/9 = 54 - 49 = 5$ です。

### 計算

$$\hat{\beta} = \frac{x^{\top}y}{x^{\top}x} = \frac{21}{9} = \frac{7}{3},\qquad \hat{y} = \frac{7}{3}(1,\ 2,\ 2)^{\top} = \left(\frac{7}{3},\ \frac{14}{3},\ \frac{14}{3}\right)^{\top}$$

$$e = y - \hat{y} = \left(\frac{2}{3},\ -\frac{5}{3},\ \frac{4}{3}\right)^{\top},\qquad \|e\|^2 = \frac{4 + 25 + 16}{9} = 5$$

確認：$x^{\top}e = \frac{2}{3} - \frac{10}{3} + \frac{8}{3} = 0$ で、残差は $x$ と直交しています。

### よくある誤り

- $\hat{\beta}$ を $x^{\top}y/\|x\| = 21/3 = 7$ とする：射影の係数は $\|x\|$ ではなく $\|x\|^2$ で割ります。$x^{\top}y/\|x\| = 7$ は射影 $\hat{y}$ の長さです。
- 残差平方和を $\|y\|^2 - x^{\top}y = 54 - 21 = 33$ とする：引くのは $\|\hat{y}\|^2 = (x^{\top}y)^2/x^{\top}x = 49$ です。

### ポイント

- 直交射影では $y = \hat{y} + e$、$\hat{y} \perp e$ なので、$\|y\|^2 = \|\hat{y}\|^2 + \|e\|^2$（ピタゴラスの定理）が成り立つ。
- 1 本のベクトルへの射影行列は $P = \dfrac{xx^{\top}}{x^{\top}x}$（ランク 1）で、一般の計画行列 $X$ では $H = X(X^{\top}X)^{-1}X^{\top}$ になる。
