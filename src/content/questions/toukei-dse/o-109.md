  ある Web 広告をクリックした 400 人のうち 80 人が商品を購入した。購入確率 $p$ の推定値 $\hat{p} = 0.2$ から、対数オッズ $\operatorname{logit}(p) = \log\dfrac{p}{1 - p}$ を推定する（$\log$ は自然対数）。

  $\operatorname{logit}(\hat{p})$ の標準誤差をデルタ法で近似した値として、最も適切なものを次のうちから一つ選べ。ただし、$\hat{p}$ の分散 $p(1 - p)/n$ は $p$ を $\hat{p}$ で置き換えて評価する。

デルタ法では、滑らかな関数 $g$ について $V[g(\hat{p})] \approx g'(p)^2 V[\hat{p}]$ と近似します。$g(p) = \log\{p/(1 - p)\}$ の導関数は $g'(p) = \dfrac{1}{p(1 - p)}$ なので、$V[g(\hat{p})] \approx \dfrac{1}{p^2(1 - p)^2}\cdot\dfrac{p(1 - p)}{n} = \dfrac{1}{np(1 - p)} = \dfrac{1}{64}$、標準誤差は $1/8 = 0.125$ です。

### 計算

$$g'(p) = \frac{1}{p} + \frac{1}{1 - p} = \frac{1}{p(1 - p)} = \frac{1}{0.16} = 6.25$$

$$\mathrm{SE}[\hat{p}] = \sqrt{\frac{0.2 \times 0.8}{400}} = 0.02,\qquad \mathrm{SE}[g(\hat{p})] \approx |g'(\hat{p})|\,\mathrm{SE}[\hat{p}] = 6.25 \times 0.02 = 0.125$$

購入数 $a = 80$、非購入数 $b = 320$ を使った公式 $\sqrt{1/a + 1/b} = \sqrt{0.0125 + 0.003125} = \sqrt{0.015625} = 0.125$ と一致します。

### 各選択肢の検討

- ①：$\hat{p}$ 自体の標準誤差です。変換の傾き $g'(p)$ を掛けていません。
- ②：$\log\hat{p}$（対数比率）の標準誤差 $\sqrt{(1 - p)/(np)} = 0.1$ です。
- ③：分散 $1/64 \approx 0.0156$ です。標準誤差はその平方根です。
- ④：正しい。
- ⑤：$1/\sqrt{80} + 1/\sqrt{320} \approx 0.168$ と、標準誤差どうしを足しています。足すのは分散（$1/a + 1/b$）です。

### ポイント

- デルタ法：$\sqrt{n}(\hat{\theta} - \theta)$ が $N(0, \sigma^2)$ に分布収束するなら、$\sqrt{n}\{g(\hat{\theta}) - g(\theta)\}$ は $N(0,\ g'(\theta)^2\sigma^2)$ に分布収束する（$g'(\theta) \neq 0$）。
- 対数オッズ上で信頼区間 $\operatorname{logit}(\hat{p}) \pm 1.96 \times 0.125$ を作り、逆変換して $p$ の区間に戻すと、区間が $[0,\ 1]$ からはみ出さない。ロジスティック回帰の係数（対数オッズ比）の標準誤差も同じ考え方で理解できる。
