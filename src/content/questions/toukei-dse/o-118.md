差の真値を $\delta = 0.02$、標準誤差を $\mathrm{SE} = \sqrt{V/n}$（$V = p_A(1 - p_A) + p_B(1 - p_B)$）とすると、検出力は $P(Z \geq 1.96 - \delta/\mathrm{SE})$ です。これが 0.80 となるのは $1.96 - \delta/\mathrm{SE} = -0.84$、すなわち $\delta/\mathrm{SE} = 1.96 + 0.84 = 2.80$ のときなので、$n = 2.80^2 V/\delta^2 = 7.84 \times 0.1956/0.0004 = 3833.76$、切り上げて 3834 人です。

### 計算

$$V = 0.10 \times 0.90 + 0.12 \times 0.88 = 0.09 + 0.1056 = 0.1956$$

両側 5% の検定は $|\hat{p}_B - \hat{p}_A|/\mathrm{SE} \geq 1.96$ で棄却します。対立仮説のもとで $(\hat{p}_B - \hat{p}_A - \delta)/\mathrm{SE}$ は近似的に標準正規分布に従うので

$$\text{検出力} \approx P\left(\frac{\hat{p}_B - \hat{p}_A}{\mathrm{SE}} \geq 1.96\right) = P\left(Z \geq 1.96 - \frac{\delta}{\mathrm{SE}}\right) = 0.80$$

$P(Z \geq -0.84) = 0.80$ より $1.96 - \delta/\mathrm{SE} = -0.84$ です。

$$\frac{\delta}{\sqrt{V/n}} = 2.80 \iff n = \frac{(1.96 + 0.84)^2 V}{\delta^2} = \frac{7.84 \times 0.1956}{0.02^2} = 3833.76$$

人数は整数で、検出力を 80% 以上にするので切り上げて $n = 3834$ です（両群合わせて 7668 人）。

### よくある誤り

- 検出力に対応する $0.84$ を足し忘れる（$n = 1.96^2 V/\delta^2 \approx 1879$）：このときの検出力は約 50% にしかなりません。
- 片側 5% 点 1.645 を使う（$n \approx 3020$）：問題は両側検定です。
- 差 $\delta$ を相対的な改善率 20% と取り違える：$\delta$ は購入率の差 $0.12 - 0.10 = 0.02$ です。

### ポイント

- 必要な人数は $\delta^2$ に反比例する。検出したい差を半分（0.01）にすると約 4 倍の人数が必要になる。
- 検出力を 90%（上側 10% 点 1.28）に上げると、$(1.96 + 1.28)^2/(1.96 + 0.84)^2 \approx 1.34$ 倍の人数が必要になる。
- 実際の検定では、帰無仮説のもとでプールした比率で標準誤差を計算することが多く、その場合は必要人数がわずかに変わる。
