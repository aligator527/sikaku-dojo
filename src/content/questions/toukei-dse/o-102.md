対数変換は単調増加なので、中央値は $\log X$ の中央値 $\mu$ を戻した $e^{\mu} = 4000$ 円です。平均は正規分布の積率母関数から $E[X] = e^{\mu + \sigma^2/2} = 4000 \times e^{0.125} \approx 4532$ 円、最頻値は密度を微分して $e^{\mu - \sigma^2} = 4000 \times e^{-0.25} \approx 3115$ 円です。右に裾が長いので、最頻値 < 中央値 < 平均 の順に並びます。

### 計算

$Y = \log X \sim N(\mu, \sigma^2)$ とします。

- 中央値：$P(X \leq m) = P(Y \leq \log m) = 1/2$ より $\log m = \mu$、$m = e^{\mu} = 4000$。
- 平均：$Y$ の積率母関数 $E[e^{tY}] = \exp(\mu t + \sigma^2 t^2/2)$ に $t = 1$ を代入して

  $$E[X] = E[e^{Y}] = e^{\mu + \sigma^2/2} = 4000 \times 1.1331 \approx 4532$$

- 最頻値：密度 $f(x) = \dfrac{1}{x\sigma\sqrt{2\pi}}\exp\left\{-\dfrac{(\log x - \mu)^2}{2\sigma^2}\right\}$ の対数 $-\log x - (\log x - \mu)^2/(2\sigma^2)$ を $x$ で微分して 0 とおくと

  $$-\frac{1}{x} - \frac{\log x - \mu}{\sigma^2 x} = 0 \iff \log x = \mu - \sigma^2$$

  よって最頻値は $e^{\mu - \sigma^2} = 4000 \times 0.7788 \approx 3115$。

### 各選択肢の検討

- ①：正規分布のように左右対称と考えています。対数正規分布は右に歪んでいます。
- ②：正しい。
- ③：中央値と平均を取り違えています。$E[\log X] = \mu$ ですが、$E[X] \neq e^{\mu}$ です（$e^{\mu}$ は中央値）。
- ④：平均を $e^{\mu + \sigma^2}$ としています。正しくは $e^{\mu + \sigma^2/2}$ です。
- ⑤：最頻値を $e^{\mu - \sigma^2/2}$ としています。正しくは $e^{\mu - \sigma^2}$ です。

### ポイント

- 対数正規分布の分散は $V[X] = e^{2\mu + \sigma^2}(e^{\sigma^2} - 1)$。
- $e^{\mu}$ は幾何平均（ここでは中央値）であり、算術平均より小さい。売上を対数変換して回帰し、予測値を $e^{\hat{y}}$ と戻すと平均を過小評価する（平均の予測には $e^{\hat{\sigma}^2/2}$ を掛けて補正する）。
