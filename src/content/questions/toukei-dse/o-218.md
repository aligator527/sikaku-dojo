$(X, Y)$ の同時密度は $e^{-x}e^{-y} = e^{-(x + y)}$（$x, y > 0$）です。$x = uv,\ y = u(1 - v)$ のヤコビ行列の行列式は $-u$ なので、$(U, V)$ の同時密度は $e^{-u} \times u = u\,e^{-u}$（$u > 0,\ 0 < v < 1$）です。これは $u$ だけの関数 $u\,e^{-u}$ と $v$ だけの関数 $1$ の積なので、$U$ と $V$ は独立で、$U \sim \mathrm{Ga}(2, 1)$、$V \sim U(0, 1)$ です。

### 計算

$$\frac{\partial(x, y)}{\partial(u, v)} = \det\begin{pmatrix} \partial x/\partial u & \partial x/\partial v \\ \partial y/\partial u & \partial y/\partial v \end{pmatrix} = \det\begin{pmatrix} v & u \\ 1 - v & -u \end{pmatrix} = -uv - u(1 - v) = -u$$

$$f_{U,V}(u, v) = f_{X,Y}\bigl(uv,\ u(1 - v)\bigr)\left|\frac{\partial(x, y)}{\partial(u, v)}\right| = e^{-u} \cdot u\qquad (u > 0,\ 0 < v < 1)$$

周辺密度は $f_U(u) = \int_0^1 u\,e^{-u}\,dv = u\,e^{-u}$（形状母数 2 のガンマ分布、平均 2・分散 2）、$f_V(v) = \int_0^{\infty}u\,e^{-u}\,du = \Gamma(2) = 1$（一様分布）です。

### 各選択肢の検討

- ①：ヤコビアンを掛け忘れています。$e^{-u}$ も $u > 0,\ 0 < v < 1$ 上で積分すると 1 になるので密度に見えますが、$U = X + Y$ の平均が $E[X] + E[Y] = 2$ であることと矛盾します。
- ②：逆変換 $(x, y) \mapsto (u, v)$ のヤコビアン $\partial(u, v)/\partial(x, y) = -1/u$ を使っています。$x, y$ の密度を $u, v$ の密度に直すときは、$(u, v) \mapsto (x, y)$ の方向のヤコビアンを掛けます。また $e^{-u}/u$ は $u \to 0$ で積分が発散し、密度になりません。
- ③：$V$ の定義に $X + Y$ が含まれていても、独立になることはあります。同時密度が $u$ の関数と $v$ の関数の積に分解できるかどうかで判断します。
- ④：独立な指数分布の和は指数分布ではなくガンマ分布です。密度 $u\,e^{-u}$ は $u = 0$ で 0 となり、$u = 1$ で最大になります。
- ⑤：正しい。

### ポイント

- 変数変換の公式：$f_{U,V}(u, v) = f_{X,Y}(x(u, v),\ y(u, v))\left|\dfrac{\partial(x, y)}{\partial(u, v)}\right|$。逆変換のヤコビアンとは互いに逆数の関係にある。
- 一般に $X \sim \mathrm{Ga}(a, 1)$、$Y \sim \mathrm{Ga}(b, 1)$ が独立なら、$X + Y \sim \mathrm{Ga}(a + b, 1)$ と $X/(X + Y) \sim \mathrm{Beta}(a, b)$ は独立（本問は $a = b = 1$）。ベータ分布やディリクレ分布の乱数生成に使われる。
