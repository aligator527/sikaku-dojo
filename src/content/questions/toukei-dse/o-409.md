各月の誤差を実績値で割った割合の絶対値は $10\%,\ 5\%,\ 5\%,\ 10\%$ なので、その平均は $7.5\%$ です。

### 計算

$$\mathrm{MAPE} = \frac{100}{n}\sum_{t=1}^{n}\left|\frac{y_t - \hat{y}_t}{y_t}\right|$$

| 月 | 誤差 $y_t - \hat{y}_t$ | $\lvert$誤差$\rvert / y_t$ |
| --- | --- | --- |
| 1 | $10$ | $10/100 = 0.10$ |
| 2 | $-4$ | $4/80 = 0.05$ |
| 3 | $-6$ | $6/120 = 0.05$ |
| 4 | $-5$ | $5/50 = 0.10$ |

$$\mathrm{MAPE} = \frac{100}{4}(0.10 + 0.05 + 0.05 + 0.10) = 7.5\ (\%)$$

### ポイント

- 同じデータで MAE は $(10 + 4 + 6 + 5)/4 = 6.25$、RMSE は $\sqrt{(100 + 16 + 36 + 25)/4} = \sqrt{44.25} \approx 6.65$。RMSE は大きな誤差を重く評価し、常に RMSE $\geq$ MAE。
- MAPE は単位に依存しないので異なる商品間で比較しやすいが、実績値が 0 に近い期間があると発散する。また、過大予測と過小予測で罰則が非対称になる。
- 時系列の予測モデルは、時間順に学習期間と評価期間を分けて（ローリング・オリジンなど）評価する。ランダムに分割すると未来の情報が学習に混入する。
