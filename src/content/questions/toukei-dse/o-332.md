  標本サイズ $n$、バンド幅 $h$ のカーネル密度推定量 $\hat{f}$ の漸近的な平均積分二乗誤差（AMISE）は、2 次のカーネル $K$ と十分滑らかな真の密度 $f$ について

  $$\mathrm{AMISE}(h) = \frac{h^4}{4}\mu_2(K)^2R(f'') + \frac{R(K)}{nh}$$

  と表される。ここで $\mu_2(K) = \int u^2K(u)\,du$、$R(g) = \int g(u)^2\,du$ であり、第 1 項は 2 乗バイアス、第 2 項は分散に由来する。

  データを集め直して標本サイズを 32 倍にしたとき、AMISE を最小にするバンド幅 $h^*$ と、そのときの AMISE の最小値は、それぞれもとの何倍になるか。組合せとして正しいものを次のうちから一つ選べ。
choices:
  - '$h^*$ は $1/2$ 倍、AMISE の最小値は $1/32$ 倍'
  - '$h^*$ は $1/32$ 倍、AMISE の最小値は $1/32$ 倍'
  - '$h^*$ は $1/2$ 倍、AMISE の最小値は $1/16$ 倍'
  - '$h^*$ は $1/4$ 倍、AMISE の最小値は $1/16$ 倍'
  - '$h^*$ は変わらず、AMISE の最小値は $1/32$ 倍'
answer: 3

AMISE を $h$ で微分して 0 とおくと $h^* \propto n^{-1/5}$ となり、これを代入すると最小値は $n^{-4/5}$ に比例します。$32 = 2^5$ なので、$h^*$ は $32^{-1/5} = 1/2$ 倍、AMISE の最小値は $32^{-4/5} = 2^{-4} = 1/16$ 倍です。

### 計算

$A = \mu_2(K)^2R(f'')$、$B = R(K)$ とおくと

$$\frac{d}{dh}\mathrm{AMISE} = A h^3 - \frac{B}{nh^2} = 0 \quad\Longrightarrow\quad h^* = \left(\frac{B}{An}\right)^{1/5} \propto n^{-1/5}$$

このとき 2 つの項はどちらも $n^{-4/5}$ に比例します。

$$\frac{(h^*)^4}{4}A \propto n^{-4/5},\qquad \frac{B}{nh^*} \propto \frac{1}{n \cdot n^{-1/5}} = n^{-4/5}$$

よって $n$ を 32 倍にすると、$h^*$ は $32^{-1/5} = 1/2$ 倍、最小 AMISE は $32^{-4/5} = 1/16$ 倍です。

### 各選択肢の検討

- ①：AMISE が $1/n$ に比例すると考えています。$1/n$ の速さはパラメトリックなモデル（正しい分布族の最尤推定など）の速さで、ノンパラメトリックな密度推定はそれより遅い $n^{-4/5}$ です。
- ②：$h^* \propto 1/n$ としています。$h$ を $n$ と同じ速さで小さくすると分散項 $B/(nh)$ が減りません。
- ③：正しい。
- ④：$h^* \propto n^{-2/5}$ としています。
- ⑤：$h$ を変えなければ分散項は $1/32$ 倍になりますが、バイアス項は変わらないので、AMISE は $1/32$ 倍にはなりません。

### ポイント

- バイアスは $h^2$ に、分散は $1/(nh)$ に比例する。$h$ を小さくするとバイアスが減って分散が増えるトレードオフがあり、最適な $h$ は $n$ が増えるにつれてゆっくり（$n^{-1/5}$ で）小さくなる。
- 最適な $h^*$ は未知の $R(f'')$ を含むので、正規分布を仮定した目安（シルバーマンの方法）や、交差検証・プラグイン法で推定する。
- $d$ 次元の密度推定では最適な誤差の速さは $n^{-4/(4 + d)}$ となり、次元が上がるほど急に遅くなる（次元の呪い）。
