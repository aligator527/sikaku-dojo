ダイクストラ法では、暫定距離が最小の未確定の頂点を 1 つずつ確定し、その頂点から出る辺で隣の頂点の暫定距離を更新します。S から B（1）を確定すると、B 経由で A への距離が $1 + 2 = 3$ に改善されます。A（3）を確定すると C が $3 + 1 = 4$、C（4）を確定すると T が $4 + 2 = 6$ となり、最短経路は S → B → A → C → T、所要時間は 6 分です。

### 計算

| 確定する頂点 | A | B | C | T |
| --- | --- | --- | --- | --- |
| 初期（S = 0 を確定） | 4 | **1** | ∞ | ∞ |
| B（1） | **3**（$1 + 2$） | 確定 | 6（$1 + 5$） | ∞ |
| A（3） | 確定 | | **4**（$3 + 1$） | 9（$3 + 6$） |
| C（4） | | | 確定 | **6**（$4 + 2$） |
| T（6） | | | | 確定 |

S から T への経路をすべて調べても次のとおりで、最小は 6 分です。

| 経路 | 所要時間 |
| --- | --- |
| S → A → T | 10 |
| S → A → C → T | 7 |
| S → B → A → T | 9 |
| S → B → A → C → T | 6 |
| S → B → C → T | 8 |

### ポイント

- 経由する区間の数が最も少ない S → A → T（10 分）や、S から直接つながる A を経由する S → A → C → T（7 分）は最短ではない。区間数の最短は幅優先探索で、所要時間の最短はダイクストラ法で求める。
- ダイクストラ法は辺の重みが非負であることが前提。負の重みがある場合はベルマン・フォード法を使う。
- 優先度付きキュー（二分ヒープ）を使うと計算量は $O((V + E)\log V)$。
