指数分布の無記憶性より、10 分を超えた視聴時間は「10 + 平均 $\theta$ の指数分布」と表せるので、$E[X \mid X > 10] = 10 + \theta^{(t)}$ です。$\theta^{(0)} = 5$ のとき打ち切られた値を 15 で補い、$\theta^{(1)} = (2 + 3 + 5 + 15 + 15)/5 = 8$ です。更新式 $\theta^{(t+1)} = \{10 + 2(10 + \theta^{(t)})\}/5$ の不動点を解くと $\theta = 10$ で、これは打ち切りを考慮した最尤推定値に一致します。

### 計算

更新式は

$$\theta^{(t+1)} = \frac{(2 + 3 + 5) + 2(10 + \theta^{(t)})}{5} = \frac{30 + 2\theta^{(t)}}{5}$$

で、$\theta^{(0)} = 5 \Rightarrow \theta^{(1)} = 40/5 = 8 \Rightarrow \theta^{(2)} = 46/5 = 9.2 \Rightarrow \cdots$ と増えていき、不動点は $5\theta = 30 + 2\theta$ より $\theta = 10$ です。

打ち切りを含む観測データの対数尤度は、打ち切られた観測が $\log P(X > 10) = -10/\theta$ を寄与するので

$$\ell(\theta) = \sum_{\text{観測}}\left(-\log\theta - \frac{x_i}{\theta}\right) + \sum_{\text{打ち切り}}\left(-\frac{10}{\theta}\right) = -3\log\theta - \frac{30}{\theta}$$

で、最尤推定値は $\hat{\theta} = (\text{総観測時間 } 30)/(\text{打ち切られていない件数 } 3) = 10$ です。EM アルゴリズムはこの値に収束します。

### 各選択肢の検討

- ①：打ち切り値 10 をそのまま観測値として平均しています（$30/5 = 6$）。視聴時間を過小評価します。
- ②：$\theta^{(1)}$ は正しいですが、EM アルゴリズムは 1 回の更新では収束せず、更新を繰り返す必要があります。
- ③：正しい。
- ④：打ち切られた 2 回を除き、観測できた 3 回だけで平均しています。長い視聴ほど除かれるので、さらに過小評価します。
- ⑤：無記憶性を使わずに $E[X \mid X > 10] = \theta^{(t)}$ としています。打ち切られた値は 10 より大きいはずなので誤りです。

### ポイント

- EM アルゴリズムは、E ステップ（完全データの対数尤度の条件付き期待値の計算）と M ステップ（その最大化）を繰り返す。指数分布では完全データの対数尤度が $x$ について線形なので、欠測値を条件付き期待値で置き換えることが E ステップそのものになる。各反復で観測データの尤度は減少しない（単調性）。
- 収束は一次収束で、欠測の割合が大きいほど遅い。局所最適解に収束することもあるので、初期値を変えて複数回実行する。
- 打ち切りのように欠測が値そのものに依存する場合は、欠測の仕組み（ここでは「10 分を超えた」という情報）を尤度に組み込む必要がある。
