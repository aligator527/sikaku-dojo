再帰の木で考えます。(a) は深さ $\log_2 n$ の各段で合計 $n$ の仕事をするので $O(n\log n)$、(b) は 1 段に 1 回の仕事が $\log_2 n$ 段続くので $O(\log n)$、(c) は葉の数 $n$ に比例する $1 + 2 + 4 + \cdots + n = 2n - 1$ 回の仕事なので $O(n)$ です。

### 計算

$n = 2^k$ として漸化式を展開します。

- (a)：$T(n) = 2T(n/2) + n = 4T(n/4) + 2n = \cdots = nT(1) + kn = O(n\log n)$
- (b)：$T(n) = T(n/2) + 1 = T(n/4) + 2 = \cdots = T(1) + k = O(\log n)$
- (c)：$T(n) = 2T(n/2) + 1 = 4T(n/4) + 2 + 1 = \cdots = nT(1) + (2^k - 1) = O(n)$

マスター定理 $T(n) = aT(n/b) + O(n^d)$ に当てはめると、(a) は $a = 2, b = 2, d = 1$ で $d = \log_b a$ の場合（$O(n^d\log n)$）、(b) は $a = 1, b = 2, d = 0$ で $d = \log_b a$ の場合（$O(\log n)$）、(c) は $a = 2, b = 2, d = 0$ で $d < \log_b a$ の場合（$O(n^{\log_b a}) = O(n)$）です。

### 各選択肢の検討

- ①：(c) を (b) と同じとみなしています。(c) は左右の両方を再帰的に調べるので、すべての要素を 1 回ずつ見ることになり $O(n)$ です。
- ②：正しい。
- ③：(a) と (c) を取り違えています。
- ④：(a) を単純なソート（バブルソートなど）の計算量、(b) を線形探索の計算量としています。
- ⑤：(b) は片側だけを調べるので、段ごとの仕事は 1 回です。

### ポイント

- 分割統治法の計算量は、分割数 $a$、縮小率 $b$、1 段あたりの分割・統合の手間 $O(n^d)$ で決まる。$d > \log_b a$ なら $O(n^d)$、$d = \log_b a$ なら $O(n^d\log n)$、$d < \log_b a$ なら $O(n^{\log_b a})$。
- 最大値は単純な 1 回の走査でも $O(n)$ で求まり、分割統治にしてもオーダーは変わらない。一方、整数の掛け算のカラツバ法 $T(n) = 3T(n/2) + O(n)$ は $O(n^{\log_2 3}) \approx O(n^{1.585})$ で、素朴な方法の $O(n^2)$ より速い。
