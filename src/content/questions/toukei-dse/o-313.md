線形分離可能なとき、最大マージンは 2 つのクラスの凸包どうしの距離に等しく、分離超平面はその最短距離を結ぶ線分の垂直二等分線になります。この例では、$y = -1$ の凸包の辺 $(1, 0)$–$(0, 2)$ と $y = +1$ の凸包の辺 $(3, 1)$–$(2, 3)$ が平行（方向 $(-1, 2)$）に向かい合っており、その距離 $\sqrt{5}$ がマージン幅です。

### 計算

向かい合う 2 辺はそれぞれ直線 $2x_1 + x_2 = 2$ と $2x_1 + x_2 = 7$ 上にあります。2 直線の距離は

$$\frac{|7 - 2|}{\sqrt{2^2 + 1^2}} = \frac{5}{\sqrt{5}} = \sqrt{5} \approx 2.24$$

分離超平面は中間の $2x_1 + x_2 = 4.5$ です。サポートベクトルで $y_i(w^{\top}x_i + b) = 1$ となるように尺度をそろえると $w = (0.8,\ 0.4)$、$b = -1.8$ で、

- $(1, 0)$：$0.8 - 1.8 = -1$、$(0, 2)$：$0.8 - 1.8 = -1$
- $(3, 1)$：$2.4 + 0.4 - 1.8 = 1$、$(2, 3)$：$1.6 + 1.2 - 1.8 = 1$
- 残りの $(0, 0)$ と $(4, 3)$ は $y_i(w^{\top}x_i + b)$ がそれぞれ $1.8$、$2.6$ でマージンの外側

$\|w\| = \sqrt{0.64 + 0.16} = \sqrt{0.8}$ より $2/\|w\| = 2/\sqrt{0.8} = \sqrt{5}$ と確かめられます。

### 各選択肢の検討

- ①：$x_1 + x_2 = 3$ でも分離できますが、$x_1 + x_2$ の値は $y = -1$ で最大 2、$y = +1$ で最小 4 なので、マージン幅は $(4 - 2)/\sqrt{2} = \sqrt{2} \approx 1.41$ で最大ではありません。
- ②：正しい。
- ③：分離超平面から最も近い点までの距離 $1/\|w\| = \sqrt{5}/2$ です。問題では 2 本のマージン境界の間の距離を問うています。
- ④：$x_1$ の値は $y = -1$ で最大 1、$y = +1$ で最小 2 なのでマージン幅は 1 です。
- ⑤：直線の式の定数の差 $7 - 2 = 5$ を、法線ベクトルの長さ $\sqrt{5}$ で割っていません。

### ポイント

- ハードマージン SVM：$\min \frac{1}{2}\|w\|^2$ s.t. $y_i(w^{\top}x_i + b) \geq 1$。解は $w = \sum_i \alpha_i y_i x_i$ と書け、$\alpha_i > 0$ となるのはマージン境界上の点（サポートベクトル）だけである。
- マージン境界の外側にある点は、外側にとどまる範囲で動かしたり、取り除いたりしても解が変わらない。
- 線形分離できないデータには、スラック変数を入れたソフトマージン SVM やカーネル法を使う。
