ベクトルによる微分の公式 $\dfrac{\partial}{\partial\beta}(a^{\top}\beta) = a$、$\dfrac{\partial}{\partial\beta}(\beta^{\top}A\beta) = (A + A^{\top})\beta$ を使います。$f(\beta) = y^{\top}y - 2y^{\top}X\beta + \beta^{\top}X^{\top}X\beta + \lambda\beta^{\top}\beta$ と展開すると、勾配は $-2X^{\top}y + 2X^{\top}X\beta + 2\lambda\beta$ で、これを 0 とおくと $(X^{\top}X + \lambda I_p)\beta = X^{\top}y$ が得られます。

### 計算

$$\nabla f(\beta) = -2X^{\top}y + 2X^{\top}X\beta + 2\lambda\beta = -2X^{\top}(y - X\beta) + 2\lambda\beta$$

$X^{\top}X$ は半正定値、$\lambda I_p$ は正定値なので、$X^{\top}X + \lambda I_p$ は正定値で正則です。$f$ のヘッセ行列 $2(X^{\top}X + \lambda I_p)$ も正定値なので $f$ は狭義凸関数で、勾配が 0 となる点がただ 1 つの最小点です。

$$\hat{\beta} = (X^{\top}X + \lambda I_p)^{-1}X^{\top}y$$

### 各選択肢の検討

- ①：直交計画 $X^{\top}X = I_p$ のときにだけ成り立つ式です。一般には $X^{\top}X$ に $\lambda I_p$ を足してから逆行列をとります。
- ②：$X$ は $n \times p$、$y - X\beta$ は $n$ 次元なので、$X(y - X\beta)$ は（$n \neq p$ のとき）定義されません。$\hat{\beta}$ の式も行列の大きさが合いません。
- ③：$\lambda\beta^{\top}\beta$ の勾配を $\lambda\beta$ としています。$\beta^{\top}\beta$ の勾配は $2\beta$ です。
- ④：罰則項の符号が逆です。$-\lambda I_p$ を足した行列は正則とは限らず、推定値を縮小するのではなく拡大してしまいます。
- ⑤：正しい。

### ポイント

- $\lambda > 0$ なら、$X^{\top}X$ が特異（$p > n$ や完全な多重共線性）でも解が一意に定まる。
- 特異値分解 $X = UDV^{\top}$ を使うと $X\hat{\beta} = \sum_j u_j\dfrac{d_j^2}{d_j^2 + \lambda}u_j^{\top}y$ と書け、特異値 $d_j$ の小さい方向ほど強く縮小されることがわかる。
