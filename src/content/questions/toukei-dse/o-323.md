高さ 2.5 で切ると、高さ 2.5 以下で起きた段階 1〜3 の併合だけが反映され、$\{P2, P5, P3\}$、$\{P1, P4\}$、まだどこにも併合されていない $\{P6\}$ の 3 つのクラスターになります。P5 は段階 1 で P2 と、そのクラスターが段階 3 で P3 と併合されるので、P3 と P5 のコーフェン距離は段階 3 の高さ 1.9 です。

### 各選択肢の検討

- ①：P6 が P1・P4 のクラスターに加わるのは高さ 3.1 で、2.5 より上です。
- ②：正しい。
- ③：段階 3（高さ 1.9）の併合を反映していません。また、0.8 は P2 と P5 が併合された高さで、P3 とは関係ありません。
- ④：クラスターは正しいですが、コーフェン距離を P5 が最初に併合された高さ 0.8 としています。P3 と同じクラスターになるのは段階 3 です。
- ⑤：5.4 はすべての顧客が 1 つにまとまる高さで、$\{P1, P4, P6\}$ の顧客と $\{P2, P3, P5\}$ の顧客の組のコーフェン距離です。

### ポイント

- 樹形図を高さ $h$ で切ると、高さ $h$ 以下の併合だけを行った状態のクラスターが得られる。切る高さを上げるほどクラスター数は減る。併合の高さが大きく跳ねる段階（ここでは 3.1 から 5.4）の手前で切ると、まとまりのよい分割になりやすい。
- コーフェン距離は「2 点を含む最小のクラスターができた高さ」で、超距離（$d(x, z) \leq \max\{d(x, y), d(y, z)\}$）を満たす。元の距離とコーフェン距離の相関（コーフェン相関係数）は、樹形図が元の距離をどれだけ保っているかの目安になる。
- 最短距離法・最長距離法・群平均法・ウォード法では併合の高さが単調に増加するが、重心法・メディアン法では高さが逆転することがある。
