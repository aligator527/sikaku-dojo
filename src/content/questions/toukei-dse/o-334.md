  3 つのセンサーの値（正常時の平均を引いて中心化したもの）$z = (z_1, z_2, z_3)^{\top}$ を監視する。正常時のデータの分散共分散行列に主成分分析を行い、固有値 $\lambda_1 = 3.0$、$\lambda_2 = 1.0$、$\lambda_3 = 0.2$ と、第 1・第 2 主成分の固有ベクトル

  $$v_1 = \left(\frac{2}{3},\ \frac{2}{3},\ \frac{1}{3}\right)^{\top},\qquad v_2 = \left(\frac{1}{\sqrt{2}},\ -\frac{1}{\sqrt{2}},\ 0\right)^{\top}$$

主成分得点は $t_k = v_k^{\top}z$ で、再構成値は $\hat{z} = t_1v_1 + t_2v_2$ です。$v_1, v_2$ は正規直交なので、ピタゴラスの定理から $\mathrm{SPE} = \|z\|^2 - t_1^2 - t_2^2$ と計算でき、$2.16 - 0.36 - 0.18 = 1.62$ になります。

### 計算

$$t_1 = \frac{2}{3}(1.0) + \frac{2}{3}(0.4) + \frac{1}{3}(-1.0) = \frac{2 + 0.8 - 1}{3} = 0.6$$

$$t_2 = \frac{1.0 - 0.4}{\sqrt{2}} = \frac{0.6}{\sqrt{2}},\qquad t_2^2 = 0.18$$

$$\|z\|^2 = 1.0^2 + 0.4^2 + (-1.0)^2 = 2.16$$

$$\mathrm{SPE} = 2.16 - 0.36 - 0.18 = 1.62$$

直接計算しても、$\hat{z} = 0.6\,v_1 + 0.6/\sqrt{2}\,v_2 = (0.4, 0.4, 0.2) + (0.3, -0.3, 0) = (0.7,\ 0.1,\ 0.2)$、$z - \hat{z} = (0.3,\ 0.3,\ -1.2)$ で、$0.09 + 0.09 + 1.44 = 1.62$ です。

### よくある誤り

- 第 1 主成分だけで再構成する：$2.16 - 0.36 = 1.80$。
- 主成分得点の 2 乗和 $t_1^2 + t_2^2 = 0.54$ を答える：これは部分空間の「中」での大きさで、部分空間からのずれではありません。
- ホテリングの $T^2 = t_1^2/\lambda_1 + t_2^2/\lambda_2 = 0.12 + 0.18 = 0.30$ と取り違える。

### ポイント

- 主成分分析による異常検知では 2 つの指標を併用する。$T^2$ 統計量は「正常時の変動の方向に沿って、どれだけ大きく動いたか」、SPE（$Q$ 統計量）は「正常時には現れない方向に、どれだけはみ出したか」を測る。
- この観測値は $T^2$ が小さい（主成分の方向にはふつうの大きさ）のに、SPE は第 3 主成分の分散 $\lambda_3 = 0.2$ に比べてはるかに大きい。変数間の相関関係が崩れたことを示す典型的なパターンである。
- 閾値は正常時のデータでの SPE の分布（経験分位点や近似分布）から決める。
