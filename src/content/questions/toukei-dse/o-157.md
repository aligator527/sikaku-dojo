  対称行列

  $$A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$$

  の絶対値最大の固有値（$A$ の固有値は 3 と 1）を、べき乗法で求める。初期ベクトルを $x^{(0)} = (1,\ 0)^{\top}$ とし、$x^{(k+1)} = Ax^{(k)}$ を繰り返す（正規化はベクトルの向きに影響しないので省略する）。$k$ 回目の固有値の推定値をレイリー商 $r_k = \dfrac{x^{(k)\top}Ax^{(k)}}{x^{(k)\top}x^{(k)}}$ で与える。

$x^{(1)} = (2, 1)^{\top}$、$x^{(2)} = (5, 4)^{\top}$ で、$Ax^{(2)} = (14, 13)^{\top}$ から $r_2 = \dfrac{5 \times 14 + 4 \times 13}{5^2 + 4^2} = \dfrac{122}{41} \approx 2.976$ です。初期ベクトルを固有ベクトル $q_1 = (1, 1)^{\top}/\sqrt{2}$、$q_2 = (1, -1)^{\top}/\sqrt{2}$ で $x^{(0)} = c_1q_1 + c_2q_2$ と展開すると $x^{(k)} = c_1 3^k q_1 + c_2 1^k q_2$ なので、$\tan\theta_k = |c_2|/(|c_1|3^k)$ は 1 回の反復ごとに $|\lambda_2/\lambda_1| = 1/3$ 倍になります。

### 計算

$x^{(0)} = (1, 0)^{\top} = \frac{1}{\sqrt{2}}q_1 + \frac{1}{\sqrt{2}}q_2$ より

$$x^{(k)} = A^k x^{(0)} = \frac{3^k}{\sqrt{2}}q_1 + \frac{1}{\sqrt{2}}q_2,\qquad \tan\theta_k = \frac{1}{3^k}$$

実際、$x^{(2)} = (5, 4)^{\top} = \frac{9}{\sqrt{2}}q_1 + \frac{1}{\sqrt{2}}q_2$ で、$\tan\theta_2 = 1/9$ です。レイリー商は

$$r_k = \frac{3 \cdot 9^k + 1}{9^k + 1},\qquad 3 - r_k = \frac{2}{9^k + 1}$$

で、$k = 2$ では $r_2 = 244/82 = 122/41$ です。

### 各選択肢の検討

- ①：比を $1 - |\lambda_2/\lambda_1| = 2/3$ としています。誤差に毎回掛かる比は $|\lambda_2/\lambda_1|$ そのものです。
- ②：有限回の反復では $q_2$ の成分が残るので、$r_k$ は 3 にちょうど一致しません（$3 - r_k = 2/(9^k + 1) > 0$）。
- ③：$1/9 = (\lambda_2/\lambda_1)^2$ は、対称行列でレイリー商の誤差 $3 - r_k$ が 1 回の反復でおよそ何倍になるかを表す比です。ベクトルの向きの誤差 $\tan\theta_k$ の比は $1/3$ です。
- ④：正しい。
- ⑤：1 回目のレイリー商 $r_1 = \dfrac{2 \times 5 + 1 \times 4}{2^2 + 1^2} = 2.8$ です。

### ポイント

- べき乗法は行列とベクトルの積だけで計算でき、大規模な疎行列（Web のリンク構造から PageRank を求める場合など）に向く。収束の速さは $|\lambda_2/\lambda_1|$ で決まり、この比が 1 に近いと遅い。
- 初期ベクトルが最大固有値の固有ベクトルと直交している（$c_1 = 0$）と、理論上はその固有値に収束しない。
- 実際には各反復で $x^{(k)}$ を正規化して、桁あふれを防ぐ。
