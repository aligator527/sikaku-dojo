  二次関数

  $$f(w) = \frac{1}{2}w^{\top}Aw - b^{\top}w,\qquad A = \begin{pmatrix} 5 & 4 \\ 4 & 5 \end{pmatrix}$$

  を、一定の学習率 $\eta > 0$ の勾配降下法 $w^{(k+1)} = w^{(k)} - \eta\nabla f(w^{(k)})$ で最小化する。最小点を $w^{*}$ とし、1 回の更新で誤差 $\|w^{(k)} - w^{*}\|$ が最悪の場合に何倍になるか（収束率）を $\rho(\eta)$ とする。$\rho(\eta)$ を最小にする学習率 $\eta$ と、そのときの $\rho$ の値の組合せとして、正しいものを次のうちから一つ選べ。

$\nabla f(w) = Aw - b$、$Aw^{*} = b$ より、誤差 $e^{(k)} = w^{(k)} - w^{*}$ は $e^{(k+1)} = (I - \eta A)e^{(k)}$ と更新されます。$A$ の固有値は $\mu = 1,\ L = 9$ なので、$\rho(\eta) = \max(|1 - \eta|,\ |1 - 9\eta|)$ です。これは 2 つの値が等しくなる $1 - \eta = 9\eta - 1$、すなわち $\eta = 2/(\mu + L) = 0.2$ で最小となり、$\rho = 0.8$ です。

### 計算

$A$ の固有値：$\det(A - tI) = (5 - t)^2 - 16 = 0$ より $t = 1,\ 9$（固有ベクトルは $(1, -1)/\sqrt{2}$ と $(1, 1)/\sqrt{2}$）。

$I - \eta A$ は対称行列で、固有値は $1 - \eta$ と $1 - 9\eta$ です。最悪の場合の縮小率はその絶対値の大きい方なので

$$\rho(\eta) = \max\left(|1 - \eta|,\ |1 - 9\eta|\right)$$

$\eta$ を増やすと $|1 - \eta|$ は小さくなり、$\eta > 1/9$ では $|1 - 9\eta| = 9\eta - 1$ が大きくなります。両者が等しくなる点が最適で

$$1 - \eta = 9\eta - 1 \quad\Longrightarrow\quad \eta = \frac{2}{1 + 9} = 0.2,\qquad \rho = 1 - 0.2 = 0.8 = \frac{\kappa - 1}{\kappa + 1}\ \ (\kappa = 9)$$

### 各選択肢の検討

- ①：$\eta = 1/L$ の場合です。$\rho(1/9) = \max(8/9,\ 0) = 8/9$ で収束はしますが、$\eta = 0.2$ より遅くなります。
- ②：正しい。
- ③：$\eta = 1/(\mu + L)$ と係数 2 を落としています。$\rho(0.1) = \max(0.9,\ 0.1) = 0.9$ です。
- ④：0.5 は $(\sqrt{\kappa} - 1)/(\sqrt{\kappa} + 1) = 2/4$ で、モーメンタム（重球法）を最適に調整した場合の収束率です。一定学習率の勾配降下法では達成できません。
- ⑤：$\eta = 1/\mu$ とすると、$\mu = 1$ の方向の誤差は 1 回で消えますが、$L = 9$ の方向では $|1 - 9| = 8$ 倍に拡大し発散します（$\rho(1) = 8$）。

### ポイント

- 二次関数に対する一定学習率の勾配降下法：収束する条件は $0 < \eta < 2/L$、最適な学習率は $\eta = 2/(\mu + L)$、そのときの収束率は $(\kappa - 1)/(\kappa + 1)$（$\kappa = L/\mu$ は条件数）。
- 条件数が大きいほど収束率は 1 に近づき、収束が遅くなる。誤差を $10^{-6}$ 倍にするのに必要な反復回数は、$\rho = 0.8$ なら約 62 回。
- 説明変数の標準化や前処理で条件数を小さくすると、勾配法が速くなる。
