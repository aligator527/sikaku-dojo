  次のバブルソートの関数で、リスト `[3, 7, 1, 8, 2, 5]` を昇順に並べ替える。

  ```python
  def bubble_sort(a):
      a = list(a)
      swaps = 0
      n = len(a)
      for i in range(n - 1):
          for j in range(n - 1 - i):
              if a[j] > a[j + 1]:
                  a[j], a[j + 1] = a[j + 1], a[j]
                  swaps += 1
      return a, swaps

  print(bubble_sort([3, 7, 1, 8, 2, 5]))
  ```

  出力される `swaps`（隣り合う要素を交換した回数）の値を求めよ。

バブルソートでは、1 回の交換で「大小が逆になっている要素の組」（転倒）がちょうど 1 つ減り、整列が終わると転倒数は 0 になります。したがって交換回数は、元のリストの転倒数に等しくなります。`[3, 7, 1, 8, 2, 5]` の転倒は (3,1)、(3,2)、(7,1)、(7,2)、(7,5)、(8,2)、(8,5) の 7 組なので、交換回数は 7 回です。

### 計算

各要素について、それより右にある小さい要素の数を数えます。

| 要素 | 3 | 7 | 1 | 8 | 2 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 右にある小さい要素 | 1, 2 | 1, 2, 5 | なし | 2, 5 | なし | なし |
| 個数 | 2 | 3 | 0 | 2 | 0 | 0 |

合計 $2 + 3 + 0 + 2 + 0 + 0 = 7$ です。

実際に追うと、1 巡目で `[3, 1, 7, 2, 5, 8]`（交換 3 回）、2 巡目で `[1, 3, 2, 5, 7, 8]`（3 回）、3 巡目で `[1, 2, 3, 5, 7, 8]`（1 回）となり、以降は交換が起こりません。合計 7 回です。

### ポイント

- バブルソートの比較回数は入力によらず $n(n - 1)/2$ 回（ここでは 15 回）、交換回数は転倒数で、最悪（逆順）のとき $n(n - 1)/2$ 回。計算量は $O(n^2)$。
- 1 巡のあいだに交換が 1 回も起きなければ打ち切る工夫を入れると、整列済みの入力では $O(n)$ で終わる。
- バブルソートは等しい要素の順序を保つ安定なソートである（`>` で比べ、等しいときは交換しないため）。
