行列による微分の公式 $\partial\log\det\Theta/\partial\Theta = \Theta^{-1}$（$\Theta$ は対称正定値）と $\partial\operatorname{tr}(S\Theta)/\partial\Theta = S^{\top} = S$ から、$\partial\ell/\partial\Theta = \frac{n}{2}(\Theta^{-1} - S)$ です。これを 0 とおくと $\Theta^{-1} = S$、すなわち $\hat{\Sigma} = S$（$n$ で割った標本分散共分散行列）、$\hat{\Theta} = S^{-1}$ が得られます。

### 計算

- $\operatorname{tr}(S\Theta) = \sum_{i,j}s_{ij}\theta_{ji}$ なので $\partial\operatorname{tr}(S\Theta)/\partial\theta_{ji} = s_{ij}$ で、行列にまとめると $S^{\top} = S$ です。
- $\det\Theta$ を $\theta_{ij}$ について余因子展開すると、$\partial\det\Theta/\partial\theta_{ij}$ は $(i, j)$ 余因子に等しく、$\partial\log\det\Theta/\partial\theta_{ij} = (\Theta^{-1})_{ji}$ です。行列にまとめると $(\Theta^{-1})^{\top} = \Theta^{-1}$ です。

$\Theta$ の対称性を考慮して微分しても、停留条件は $\Theta^{-1} = S$ で同じです。$\log\det\Theta$ は正定値行列の集合上で凹関数、$\operatorname{tr}(S\Theta)$ は線形なので、$\ell$ は凹関数で、停留点が最大点になります。

### 各選択肢の検討

- ①：$S$ は $\Sigma$ の最尤推定量です。精度行列の最尤推定量はその逆行列です。
- ②：正しい。
- ③：$\ell$ は凸関数ではなく凹関数なので、勾配が 0 となる点は最大点です。
- ④：精度行列の非対角成分が 0 であることは、ほかの変数（$X_3, \dots, X_p$）を与えたもとでの条件付き独立、すなわち偏相関係数 $-\theta_{12}/\sqrt{\theta_{11}\theta_{22}}$ が 0 であることを意味し、（周辺の）相関係数が 0 であることとは異なります。
- ⑤：$S$ のランクは $n - 1$ 以下なので、$n \leq p$ のとき $S$ は特異で、逆行列が存在しません。このような場合は $L_1$ 罰則を加えたグラフィカル lasso などを使います。

### ポイント

- 行列微分の基本公式：$\partial(a^{\top}Xb)/\partial X = ab^{\top}$、$\partial\operatorname{tr}(AX)/\partial X = A^{\top}$、$\partial\log\det X/\partial X = (X^{-1})^{\top}$、$\partial\operatorname{tr}(X^{-1}A)/\partial X = -(X^{-1}AX^{-1})^{\top}$。
- 精度行列の非ゼロのパターンは、ガウシアングラフィカルモデル（無向グラフ）の辺に対応する。
