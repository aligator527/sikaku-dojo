直交基底 $\{\mathbf{1},\ \tilde{x}\}$ への射影は、それぞれの方向への射影の和なので、$\hat{y} = \bar{y}\mathbf{1} + \dfrac{\tilde{x}^{\top}y}{\tilde{x}^{\top}\tilde{x}}\tilde{x}$ です。$\tilde{x} = (-2, -1, 0, 1, 2)^{\top}$、$\tilde{x}^{\top}y = 6$、$\tilde{x}^{\top}\tilde{x} = 10$ より $\hat{\beta}_1 = 0.6$ です。$y$ の偏差平方和 6 のうち $\hat{\beta}_1^2\|\tilde{x}\|^2 = 3.6$ が回帰で説明され、残差平方和は $6 - 3.6 = 2.4$、$R^2 = 3.6/6 = 0.6$ です。

### 計算

$\bar{x} = 3$、$\bar{y} = 4$ です。

$$\tilde{x}^{\top}y = (-2) \cdot 2 + (-1) \cdot 4 + 0 \cdot 5 + 1 \cdot 4 + 2 \cdot 5 = 6,\qquad \|\tilde{x}\|^2 = 4 + 1 + 0 + 1 + 4 = 10$$

$$\hat{y} = 4\cdot\mathbf{1} + 0.6\,\tilde{x} = (2.8,\ 3.4,\ 4.0,\ 4.6,\ 5.2)^{\top},\qquad e = (-0.8,\ 0.6,\ 1.0,\ -0.6,\ -0.2)^{\top}$$

$$\|e\|^2 = 0.64 + 0.36 + 1.00 + 0.36 + 0.04 = 2.4,\qquad \|y - \bar{y}\mathbf{1}\|^2 = 4 + 0 + 1 + 0 + 1 = 6$$

$$R^2 = 1 - \frac{2.4}{6} = 0.6$$

切片は $\hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x} = 4 - 1.8 = 2.2$ です。

### 各選択肢の検討

- ①：回帰で説明される平方和 3.6 を、残差平方和と取り違えています。
- ②：正しい。
- ③：中心化せずに $x^{\top}y/x^{\top}x = 66/55 = 1.2$ としています。$\mathbf{1}$ と $x$ は直交しないので、$x$ 方向への射影は切片の分まで含んでしまいます（これは原点を通る回帰の傾きで、そのときの残差平方和が 6.8）。
- ④：$\|e\|^2/\|y - \bar{y}\mathbf{1}\|^2 = 0.4$ を $R^2$ としています。これは $1 - R^2$ です。
- ⑤：中心化しない $\|y\|^2 = 86$ を使い、$1 - 2.4/86 \approx 0.97$ としています。切片を含むモデルの決定係数は、中心化した平方和で定義します。

### ポイント

- 切片を含む回帰では、平方和の分解 $\|y - \bar{y}\mathbf{1}\|^2 = \|\hat{y} - \bar{y}\mathbf{1}\|^2 + \|e\|^2$（総平方和 = 回帰平方和 + 残差平方和）が成り立つ。
- 単回帰の $R^2$ は、$x$ と $y$ の偏差ベクトルのなす角の余弦（相関係数）の 2 乗に等しい：$r = 6/\sqrt{10 \times 6} \approx 0.775$、$r^2 = 0.6$。
- 説明変数が多いときも、グラム・シュミットの直交化で列を順に直交化すれば、同じ考え方で射影を計算できる（QR 分解）。
