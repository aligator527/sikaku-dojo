連鎖律により $\dfrac{\partial L}{\partial w} = \dfrac{\partial L}{\partial \hat{y}} \cdot \dfrac{\partial \hat{y}}{\partial z} \cdot \dfrac{\partial z}{\partial w}$（$z = wx + b$）と分解します。$z = 3 - 3 = 0$ なので $\hat{y} = \sigma(0) = 0.5$、$\sigma'(0) = 0.5 \times 0.5 = 0.25$ となり、$\dfrac{\partial L}{\partial w} = 2(0.5 - 1) \times 0.25 \times 3 = -0.75$ です。

### 計算

$$z = wx + b = 1 \times 3 + (-3) = 0,\qquad \hat{y} = \sigma(0) = \frac{1}{1 + 1} = 0.5$$

各因子は

$$\frac{\partial L}{\partial \hat{y}} = 2(\hat{y} - y) = -1,\qquad \frac{\partial \hat{y}}{\partial z} = \sigma(z)\{1 - \sigma(z)\} = 0.25,\qquad \frac{\partial z}{\partial w} = x = 3$$

なので

$$\frac{\partial L}{\partial w} = (-1) \times 0.25 \times 3 = -0.75$$

微分係数が負なので、勾配降下法では $w$ を増やす方向に更新されます（$\hat{y}$ を $y = 1$ に近づける向き）。同様に $\dfrac{\partial L}{\partial b} = (-1) \times 0.25 \times 1 = -0.25$ です。

### ポイント

- シグモイド関数の導関数は $\sigma'(z) = \sigma(z)\{1 - \sigma(z)\}$。最大値は $z = 0$ での 0.25 で、$|z|$ が大きいと 0 に近づく（勾配消失の原因）。
- 誤差逆伝播法は、この連鎖律を出力側から順に適用し、途中の微分係数を再利用して全パラメータの勾配を効率よく求める方法である。
- 典型的な誤り：$\partial z/\partial w = x$ を掛け忘れる（$-0.25$）、二乗の微分の 2 を落とす（$-0.375$）、$\sigma'(z)$ を掛け忘れる（$-3$）。
