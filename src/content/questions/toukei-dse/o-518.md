状態価値は、ベルマン方程式「今期の報酬 + 割引率 × 次期の状態価値の期待値」を満たします。2 つの状態について連立方程式を立てて解くと $V^{\pi}(\text{A}) = 5,\ V^{\pi}(\text{B}) = 1$ です。

### 計算

ベルマン方程式は

$$V(\text{A}) = 3 + 0.5\left\{0.75\,V(\text{A}) + 0.25\,V(\text{B})\right\}$$

$$V(\text{B}) = 0 + 0.5\left\{0.25\,V(\text{A}) + 0.75\,V(\text{B})\right\}$$

です。2 つ目の式から $0.625\,V(\text{B}) = 0.125\,V(\text{A})$、すなわち $V(\text{A}) = 5V(\text{B})$。これを 1 つ目の式 $0.625\,V(\text{A}) - 0.125\,V(\text{B}) = 3$ に代入すると

$$3.125\,V(\text{B}) - 0.125\,V(\text{B}) = 3\quad\Longrightarrow\quad V(\text{B}) = 1,\quad V(\text{A}) = 5$$

検算：$3 + 0.5(0.75 \times 5 + 0.25 \times 1) = 3 + 2 = 5$、$0.5(0.25 \times 5 + 0.75 \times 1) = 1$ で、どちらも成り立ちます。行列で書けば $V = r + \gamma PV$ より $V = (I - \gamma P)^{-1}r$ です。

### 各選択肢の検討

- ①：今期の報酬だけで、将来の報酬を含めていません。
- ②：正しい。
- ③：$3/(1 - 0.5) = 6$ と、同じ状態にずっと留まり続ける場合の値を計算しています。実際には A から B へ移る可能性があり、B からも A に戻れます。
- ④：$V = 0$ から始めて $V \leftarrow r + \gamma PV$ を 2 回だけ反復した途中の値です。この反復は真の値に収束しますが、2 回では収束していません。
- ⑤：推移確率を取り違えています（A から A へ 0.25、A から B へ 0.75 として解いた値）。

### ポイント

- 状態価値関数のベルマン方程式：$V^{\pi}(s) = \sum_a \pi(a \mid s)\left\{r(s, a) + \gamma\sum_{s'}P(s' \mid s, a)V^{\pi}(s')\right\}$。行動価値関数 $Q^{\pi}(s, a)$ にも同様の式がある。
- 最適な方策の価値は、期待値の代わりに行動について最大値をとるベルマン最適方程式 $V^{*}(s) = \max_a\left\{r(s, a) + \gamma\sum_{s'}P(s' \mid s, a)V^{*}(s')\right\}$ を満たす。Q 学習はその標本版である。
- 割引率 $\gamma$ が 1 に近いほど遠い将来の報酬を重視する。$0 \leq \gamma < 1$ なら、報酬が有界である限り割引報酬和は有限になる。
