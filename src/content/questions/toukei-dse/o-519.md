推定行動価値が最大の行動は、確率 $1 - \varepsilon = 0.8$ の「活用」で必ず選ばれるうえ、確率 $\varepsilon = 0.2$ の「探索」でも $1/4$ の確率で選ばれます。よって $P = 0.8 + 0.2 \times 1/4 = 0.85$ です。割引報酬和は $k$ 期先の報酬に $\gamma^{k}$ を掛けて足し、$G_1 = 1 + 0.9 \times 0 + 0.9^2 \times 2 = 2.62$ です。

### 計算

$$P = (1 - \varepsilon) + \frac{\varepsilon}{4} = 0.8 + 0.05 = 0.85$$

$$G_1 = r_1 + \gamma r_2 + \gamma^2 r_3 = 1 + 0.9 \times 0 + 0.81 \times 2 = 2.62$$

それ以外の 3 つの行動は、それぞれ $\varepsilon/4 = 0.05$ の確率で選ばれます（合計 $0.85 + 3 \times 0.05 = 1$）。

### 各選択肢の検討

- ①：探索のときにも最大の行動が選ばれうることを忘れ、$P = 1 - \varepsilon$ としています。
- ②：割引をせずに報酬を単純に合計しています。
- ③：正しい。
- ④：$P = 1 - \varepsilon/4$ としています。これは「最大以外の特定の 1 つの行動が選ばれない確率」です。
- ⑤：時刻 3 の報酬に $\gamma^2$ ではなく $\gamma$ を掛けています。

### ポイント

- 強化学習では、今の知識で最善の行動をとる「活用」と、知らない行動を試す「探索」のバランスが重要になる（探索と活用のジレンマ）。ε-greedy では、学習が進むにつれて $\varepsilon$ を小さくしていくことが多い。
- 収益（割引報酬和）$G_t = \sum_{k=0}^{\infty}\gamma^{k}r_{t+k}$ は、$G_t = r_t + \gamma G_{t+1}$ と再帰的に書ける。この関係がベルマン方程式の出発点になる。
- 毎期一定の報酬 $r$ がずっと続くなら $G = r/(1 - \gamma)$。$\gamma = 0.9$ なら $10r$ で、およそ $1/(1 - \gamma) = 10$ 期先までの報酬を考慮していると解釈できる。
