尤度は $\theta \geq X_{(n)}$ のとき $L(\theta) = \theta^{-n}$、$\theta < X_{(n)}$ のとき $0$ で、$\theta \geq X_{(n)}$ の範囲では単調減少なので、最尤推定量は境界の $X_{(n)}$ です。$X_{(n)}$ は必ず $\theta$ 以下なので平均的には過小（$E[X_{(n)}] = \frac{n}{n+1}\theta$）ですが、$n \to \infty$ で $\theta$ に確率収束します（一致性）。

### 計算

$X_{(n)}$ の分布関数は $P(X_{(n)} \leq x) = (x/\theta)^n$（$0 \leq x \leq \theta$）、密度は $nx^{n-1}/\theta^n$ なので

$$E[X_{(n)}] = \int_0^{\theta} x \cdot \frac{nx^{n-1}}{\theta^n}dx = \frac{n}{n+1}\theta$$

よって $\frac{n+1}{n}X_{(n)}$ は不偏です。また、任意の $0 < \varepsilon < \theta$ について

$$P(|X_{(n)} - \theta| > \varepsilon) = P(X_{(n)} < \theta - \varepsilon) = \left(1 - \frac{\varepsilon}{\theta}\right)^n \to 0\quad (n \to \infty)$$

なので一致推定量です。

### 各選択肢の検討

- ①：$2\bar{X}$ は $E[X] = \theta/2$ にもとづくモーメント法の推定量で、最尤推定量ではありません。
- ②：$E[X_{(n)}] = \frac{n}{n+1}\theta < \theta$ なので、下向きの偏りがあります。
- ③：$2\bar{X}$ は不偏で、分散 $V[2\bar{X}] = 4 \cdot \dfrac{\theta^2}{12n} = \dfrac{\theta^2}{3n} \to 0$ なので一致推定量でもあります。
- ④：正しい。
- ⑤：$L(\theta)$ は $\theta = X_{(n)}$ で 0 から $X_{(n)}^{-n}$ へ不連続に跳び、$\theta > X_{(n)}$ では単調減少するので、尤度方程式（$-n/\theta = 0$）は解をもちません。データのとりうる範囲（台）が母数に依存するため、微分による通常の議論が使えない例です。

### ポイント

- 不偏推定量どうしの比較：$V\left[\frac{n+1}{n}X_{(n)}\right] = \dfrac{\theta^2}{n(n+2)}$ は $V[2\bar{X}] = \dfrac{\theta^2}{3n}$ 以下で、$n \geq 2$ では真に小さい（より有効）。分散が $1/n^2$ の速さで減るのは台が母数に依存する非正則な場合の特徴で、クラメール・ラオの不等式の前提も成り立たない。
- 最尤推定量は一般に不偏とは限らないが、正則条件のもとで一致性・漸近正規性・漸近有効性をもつ。
