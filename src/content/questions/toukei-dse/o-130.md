  待ち時間のシミュレーションで、指数分布（分布関数 $F(x) = 1 - e^{-\lambda x}$、$x \geq 0$、平均 $1/\lambda$）に従う乱数を、区間 $(0, 1)$ の一様乱数 $u$ から逆変換法 $x = F^{-1}(u)$ で生成する。$\lambda = 2$ とし、一様乱数の値が $u = 0.75$ であったとき、生成される値 $x$ として正しいものを次のうちから一つ選べ。必要なら $\log 2 = 0.693$、$\log 4 = 1.386$、$\log 0.75 = -0.288$、$e^{-1.5} = 0.223$ を用いよ（$\log$ は自然対数）。

$u = F(x) = 1 - e^{-\lambda x}$ を $x$ について解くと $x = F^{-1}(u) = -\log(1 - u)/\lambda$ です。$u = 0.75$、$\lambda = 2$ を代入すると $x = -\log 0.25/2 = \log 4/2 = 1.386/2 = 0.693$ となります。

### 計算

$$1 - e^{-2x} = 0.75 \iff e^{-2x} = 0.25 \iff x = \frac{\log 4}{2} = 0.693$$

$U \sim U(0, 1)$ のとき $P(F^{-1}(U) \leq x) = P(U \leq F(x)) = F(x)$ なので、$F^{-1}(U)$ は分布関数 $F$ に従います（逆変換法の原理）。

### 各選択肢の検討

- ①：$x = -\lambda\log(1 - u) = 2 \times 1.386$ としています。$\lambda$ は比率（rate）で、平均は $1/\lambda = 0.5$ です。
- ②：逆関数ではなく、分布関数そのものの値 $F(0.75) = 1 - e^{-1.5} = 0.777$ を計算しています。
- ③：正しい。
- ④：符号を誤っています。指数分布の値は負になりません。
- ⑤：$x = -\log u/\lambda = 0.288/2 = 0.144$ です。$1 - U$ も一様分布に従うので $-\log U/\lambda$ でも同じ分布の乱数が作れますが、$u = 0.75$ に対する $F^{-1}(u)$ の値ではありません。

### ポイント

- 逆変換法は、分布関数の逆関数が陽に書けるとき（指数分布・ワイブル分布・ロジスティック分布・コーシー分布など）に便利。離散分布では、累積確率が初めて $u$ 以上となる値を返す。
- 分布関数の逆関数が陽に書けない正規分布では、ボックス・ミュラー法 $Z = \sqrt{-2\log U_1}\cos(2\pi U_2)$ などを使う。
- 一様乱数そのものは、線形合同法やメルセンヌ・ツイスタなどの擬似乱数生成器で作る。シード（初期値）を固定すると同じ乱数列を再現できる。
