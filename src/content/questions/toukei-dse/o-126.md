二乗誤差損失の事後期待値 $E[(\theta - d)^2 \mid x]$ は $d = E[\theta \mid x]$ で最小になるので、ベイズ推定値は事後平均 $3/(3 + 7) = 0.3$ です。MAP 推定値は事後密度の最頻値 $(a - 1)/(a + b - 2) = 2/8 = 0.25$ です。

### 計算

$$E[(\theta - d)^2 \mid x] = V[\theta \mid x] + (E[\theta \mid x] - d)^2$$

は $d = E[\theta \mid x] = \dfrac{a}{a + b} = 0.3$ で最小になります。MAP 推定値は、対数密度 $2\log\theta + 6\log(1 - \theta)$ を微分して 0 とおき

$$\frac{2}{\theta} - \frac{6}{1 - \theta} = 0 \iff \theta = \frac{2}{8} = 0.25$$

### 各選択肢の検討

- ①：平均と最頻値を取り違えています。
- ②：$0.286$ は事後中央値で、絶対誤差損失 $|\theta - d|$ のもとでのベイズ推定値です。
- ③：事後分布が左右対称なら平均と最頻値は一致しますが、$\mathrm{Beta}(3, 7)$ は右に裾が長く、一致しません。
- ④：正しい。
- ⑤：最頻値を $(a - 1)/(a + b) = 0.2$ としています。分母は $a + b - 2$ です。

### ポイント

- 損失関数とベイズ推定値の対応：二乗誤差 → 事後平均、絶対誤差 → 事後中央値、0-1 損失（の極限）→ 事後最頻値（MAP 推定値）。
- 事前分布が一様のとき、MAP 推定値は最尤推定値に一致する。正則化付きの最尤推定（リッジ回帰など）は、ある事前分布のもとでの MAP 推定と解釈できる。
