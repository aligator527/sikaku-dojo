  API エコノミーの事例として，適切なものはどれか。

API エコノミーは、企業が自社のサービスやデータを API として外部に公開し、他の企業がそれを自社のサービスに組み込むことで、企業の枠を越えて新しい価値やビジネスが生まれる経済圏のことです。ホテル事業者が他社の公開しているタクシー配車の API を自社アプリに組み込み、宿泊客にサービスとして提供する例は、API を介した企業間の連携によって新たな顧客価値を生んでおり、API エコノミーの典型例です。

### 各選択肢の検討

- **ア**：EAI ツールで学内データベースと業務システムを連携させるのは、組織内部のシステム統合です。外部への公開や企業間の価値創出はありません。
- **イ**：自部門の API を自社内の他部署に提供するだけでは、社内での利用にとどまります。外部の事業者を巻き込んだ経済圏にはなっていません。
- **ウ**：BI ツールの API を使って自社の顧客データを可視化するのは、自社内のデータ分析の効率化です。他社と連携して新たなサービスを提供しているわけではありません。
- **エ（正解）**：他社が公開する API を組み込んで自社のサービスとして提供しており、API を通じた企業間の連携で価値を生み出す API エコノミーの事例です。

### ポイント

- API エコノミーの鍵は「外部に公開された API」と「それを組み合わせた新しいサービスの提供」です。社内連携やツールの単なる利用は該当しません。
- API を公開する側は利用料や自社サービスの利用拡大を、利用する側は開発期間の短縮やサービスの充実を得られ、双方に利益があります。
