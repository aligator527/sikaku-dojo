エンタープライズアーキテクチャ（EA）の参照モデルは、組織が EA を作るときのひな形として、業務・サービス・データ・技術などの階層ごとに標準的な分類や記述を提供するものです。BRM（業務参照モデル）は、そのうち**最も業務に近い階層**であり、業務分類に沿った業務体系・システム体系や各種の業務モデルを提供します。

### 各選択肢の検討

- **ア**：アプリケーションサービスを機能の観点から分類・体系化したサービスコンポーネントは、SRM（Service Component Reference Model：サービス参照モデル）です。
- **イ**：サービスコンポーネントを活用するためのプラットフォームやテクノロジの標準仕様は、TRM（Technical Reference Model：技術参照モデル）です。
- **ウ（正解）**：最も業務に近い階層として、業務分類に従った業務体系・システム体系と業務モデルを提供するのが BRM です。
- **エ**：組織間で共有される可能性の高い情報の名称・定義・属性を記述したモデルは、DRM（Data Reference Model：データ参照モデル）です。

### ポイント

- 参照モデルは、業務に近い順に「BRM（業務）→ SRM（サービスコンポーネント）→ DRM（データ）→ TRM（技術）」と整理できます。成果を測る PRM（Performance Reference Model）が加わることもあります。
- EA の四つのアーキテクチャ（ビジネス・データ・アプリケーション・テクノロジ）と、参照モデルの対応を合わせて押さえておきましょう。
