組み込み型金融（エンベデッドファイナンス）は、**金融以外の事業者**が自社のサービスの中に、決済・融資・保険などの金融サービスを**組み込んで**提供する形態です。金融機関などのサービスと API などで裏側で接続し、顧客は金融機関を意識することなく、事業者のサービスの流れの中で金融機能を利用します。

### 各選択肢の検討

- **ア**：銀行が自行のサイトで振込サービスを提供するのは、金融事業者による本来の金融サービスです。非金融事業者のサービスに組み込まれているわけではありません。
- **イ**：損害保険会社が自社サイトで保険の契約を受け付けるのも、金融事業者自身のサービス提供です。
- **ウ**：自動車メーカーが他社サービスに接続せずに見積りを出すだけでは、金融サービスが組み込まれていません。たとえば購入時にその場で自動車ローンを申し込める仕組みであれば、組み込み型金融の例になります。
- **エ（正解）**：非金融事業者である百貨店が、自社の販売サイトの購入手続の中でクレジットカード会社の決済サービスを利用者に意識させずに呼び出しています。組み込み型金融の典型例です。

### ポイント

- 判定の鍵は「非金融事業者が主体であること」と「金融サービスが自社サービスの中に組み込まれていること」の二つです。
- 組み込み型金融を金融機関側から支える仕組みを BaaS（Banking as a Service）と呼びます。金融機関が機能を API で提供し、非金融事業者がそれを組み込むという役割分担を押さえておきましょう。
