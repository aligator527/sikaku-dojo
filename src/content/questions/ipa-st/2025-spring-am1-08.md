SVG（Scalable Vector Graphics）は、W3C が策定したベクタ形式の画像フォーマットです。矩形・円・直線・パス・文字列などの図形を XML のタグで記述するので、拡大・縮小しても画質が劣化せず、テキストとして編集・検索でき、HTML に直接埋め込んで CSS や JavaScript から操作することもできます。

### 各選択肢の検討

- **ア**：OpenGL は、2D・3D グラフィックスを描画するための API（プログラミングインタフェース）の仕様で、Khronos Group が管理しています。画像フォーマットではありません。
- **イ**：PNG も W3C 勧告として仕様が公開されていますが、画像を画素（ピクセル）の集まりで表すラスタ形式です。可逆圧縮と透過に対応しますが、図形を XML で記述するものではありません。
- **ウ（正解）**：図形オブジェクトを XML で記述する、W3C 策定のベクタ画像形式です。
- **エ**：TIFF は、タグによって解像度や色数などの属性を記述できるラスタ形式の画像フォーマットで、スキャナや印刷・DTP の分野で使われます。

### ポイント

- 画像形式は、図形の情報を記述する**ベクタ形式**（SVG など）と、画素の並びで表す**ラスタ形式**（PNG、JPEG、GIF、TIFF、BMP など）に分けて整理しましょう。
- ベクタ形式は拡大に強く、図やアイコン向き、ラスタ形式は写真のような連続した色調の表現向きです。
