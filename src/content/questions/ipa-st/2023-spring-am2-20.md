stem: |
  表の事業計画案に対して，新規設備投資に伴う減価償却費（固定費）の増加1,000万円を織り込み，かつ，売上総利益を3,000万円とするようにしたい。変動費率に変化がないとすると，売上高の増加を何万円にすればよいか。

  （単位　万円）

  | 項目 |  | 金額 |
  | --- | --- | ---: |
  | 売上高 |  | 20,000 |
  | 売上原価 | 変動費 | 10,000 |
  |  | 固定費 | 8,000 |
  |  | 計 | 18,000 |
  | 売上総利益 |  | 2,000 |
  | ⋮ |  | ⋮ |
choices:
  - '2,000'
  - '3,000'
  - '4,000'
  - '5,000'
answer: 3
---
変動費率は $10{,}000 \div 20{,}000 = 0.5$ です。減価償却費の増加によって固定費は $8{,}000 + 1{,}000 = 9{,}000$ 万円になります。売上総利益を 3,000 万円にするには、「売上高 − 変動費 − 固定費 = 3,000」となる売上高を求めます。

### 計算

売上高を $S$ とすると、

$$
S - 0.5S - 9{,}000 = 3{,}000 \quad\Rightarrow\quad 0.5S = 12{,}000 \quad\Rightarrow\quad S = 24{,}000
$$

現在の売上高は 20,000 万円なので、増加額は $24{,}000 - 20{,}000 = 4{,}000$ 万円です。

### 各選択肢の検討

各選択肢の増加額を当てはめると、売上総利益は次のようになります。

| 売上高の増加 | 売上高 | 変動費 | 固定費 | 売上総利益 |
| ---: | ---: | ---: | ---: | ---: |
| 2,000 | 22,000 | 11,000 | 9,000 | 2,000 |
| 3,000 | 23,000 | 11,500 | 9,000 | 2,500 |
| 4,000 | 24,000 | 12,000 | 9,000 | 3,000 |
| 5,000 | 25,000 | 12,500 | 9,000 | 3,500 |

- **ア**：2,000 万円は、固定費の増加を無視し、売上総利益の増加分 1,000 万円を変動費率から逆算した場合（$1{,}000 \div 0.5$）の値です。実際には売上総利益は 2,000 万円のまま増えません。
- **イ**：売上総利益は 2,500 万円にとどまります。
- **ウ（正解）**：売上総利益がちょうど 3,000 万円になります。
- **エ**：売上総利益は 3,500 万円となり、目標を超えます。

### ポイント

- 売上高の増加で増えるのは、増加額に限界利益率（$1 - \text{変動費率}$）を掛けた分だけです。ここでは、固定費の増加 1,000 万円と利益の増加 1,000 万円の合計 2,000 万円を限界利益率 0.5 で割ると、必要な売上高の増加 4,000 万円が直接求められます。
- 変動費率が変わらないという条件は、「売上高が増えれば変動費も同じ割合で増える」という意味です。変動費を据え置いて計算しないように注意しましょう。
