stem: |
  ある会社の生産計画部では，毎月25日に次の手続で翌月分の計画生産量を決定している。8月分の計画生産量を求める式はどれか。

  〔手続〕

  (1)　当月末の予想在庫量を，前月末の実在庫量と当月分の計画生産量と予想販売量から求める。

  (2)　当月末の予想在庫量と翌月分の予想販売量を基に，翌月末の予想在庫量が翌々月から3か月間の予想販売量と等しくなるように翌月分の計画生産量を決定する。

  | 記号 | 内容 |
  | :---: | --- |
  | I6 | 6月末実在庫量 |
  | I7 | 7月末予想在庫量 |
  | I8 | 8月末予想在庫量 |
  | P7 | 7月分計画生産量 |
  | **P8** | **8月分計画生産量** |
  | S7 | 7月分予想販売量 |
  | S8 | 8月分予想販売量 |
  | S9 | 9月分予想販売量 |
  | S10 | 10月分予想販売量 |
  | S11 | 11月分予想販売量 |

  I$n$：$n$ 月の月末在庫量　P$n$：$n$ 月分の生産量　S$n$：$n$ 月分の販売量
choices:
  - '$\mathrm{I6} + \mathrm{P7} - \mathrm{S7} + \mathrm{S8}$'
  - '$\mathrm{S8} + \mathrm{S9} + \mathrm{S10} + \mathrm{S11} - \mathrm{I7}$'
  - '$\mathrm{S8} + \mathrm{S9} + \mathrm{S10} + \mathrm{S11} - \mathrm{I8}$'
  - '$\mathrm{S9} + \mathrm{S10} + \mathrm{S11} - \mathrm{I7}$'
answer: 2

月末在庫量は「前月末の在庫量 ＋ 当月の生産量 − 当月の販売量」で決まります。8 月分の計画生産量 P8 は、8 月末の予想在庫量 I8 が 9〜11 月の 3 か月間の予想販売量と等しくなるように決めるので、在庫の関係式を P8 について解きます。

### 計算

手続 (2) の条件から、8 月末の予想在庫量は

$$
\mathrm{I8} = \mathrm{S9} + \mathrm{S10} + \mathrm{S11}
$$

一方、在庫の関係から

$$
\mathrm{I8} = \mathrm{I7} + \mathrm{P8} - \mathrm{S8}
$$

この 2 式から

$$
\mathrm{P8} = \mathrm{S8} + \mathrm{S9} + \mathrm{S10} + \mathrm{S11} - \mathrm{I7}
$$

なお、7 月末の予想在庫量 I7 は、手続 (1) により $\mathrm{I7} = \mathrm{I6} + \mathrm{P7} - \mathrm{S7}$ として求めます。計画を決める 7 月 25 日の時点では、7 月末の在庫はまだ確定していないためです。

### 各選択肢の検討

- **ア**：$\mathrm{I6} + \mathrm{P7} - \mathrm{S7}$ は 7 月末の予想在庫量 I7 です。これに S8 を足しても、8 月末に 3 か月分の在庫を残す条件が反映されていません。
- **イ（正解）**：8 月の販売分（S8）と 8 月末に残すべき 3 か月分の在庫（S9＋S10＋S11）の合計から、7 月末の予想在庫量（I7）を差し引いた量です。
- **ウ**：差し引くべきなのは 8 月の期首在庫に当たる I7 であり、求めたい 8 月末の在庫 I8 ではありません。
- **エ**：8 月分の販売量 S8 が含まれていません。これでは 8 月中に販売した分だけ、8 月末の在庫が不足します。

### ポイント

- 「必要な生産量 ＝ 当期の販売量 ＋ 期末に残したい在庫量 − 期首在庫量」は、生産計画や発注量の計算で繰り返し使う基本の式です。
- 期首在庫（前月末在庫）と期末在庫（当月末在庫）のどちらを使うかを取り違えないよう、時点を整理してから式を立てましょう。
