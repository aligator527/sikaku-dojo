格納型 XSS は、攻撃者が掲示板やコメント欄などに攻撃用スクリプトを含む書込みを行い、それを Web サイトのデータベースなどに**格納（保存）させておく**攻撃です。その後、ページを閲覧した利用者のブラウザで、保存されたスクリプトが実行されます。罠のリンクをクリックさせる必要がなく、ページを開いただけの多数の利用者が被害に遭う点が特徴です。

### 各選択肢の検討

- **ア（正解）**：掲示板にスクリプトを含む書込みを保存させ、後から閲覧した利用者のブラウザで実行させており、格納型 XSS に該当します。
- **イ**：スクリプトを含むリクエストを送信する罠のリンクを利用者にクリックさせ、その応答にスクリプトが埋め込まれて実行されるのは、反射型 XSS（Reflected XSS）です。スクリプトはサーバに保存されません。
- **ウ**：乗っ取った多数の PC（ボットネット）から大量のリクエストを送り付けてサービスを停止させるのは、DDoS 攻撃です。
- **エ**：送信元 IP アドレスを攻撃対象に偽装した DNS の問合せを多数の DNS サーバに送り、大量の応答を攻撃対象に集中させるのは、DNS リフレクション攻撃（DNS アンプ攻撃）です。

### ポイント

- XSS には、格納型（サーバに保存される）、反射型（リクエストに含まれたスクリプトがそのまま応答に返る）、DOM ベース（ブラウザ上の JavaScript の処理だけで発生する）の 3 種類があります。
- 対策の基本は、出力時のエスケープ処理（HTML の特殊文字の置換）です。Cookie に HttpOnly 属性を付ける、CSP（Content Security Policy）を設定するなどの対策も併用します。
