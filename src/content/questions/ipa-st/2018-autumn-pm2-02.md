stem: |
  **新しい情報技術や情報機器と業務システムを連携させた新サービスの企画について**

  近年，IT ストラテジストは，事業戦略を実現するために，オープン API やタブレット端末などの新しい情報技術や情報機器（以下，新技術という）と業務システムを連携させ，顧客満足度や生産性などを向上させた新サービスを企画することがある。

  銀行業では，“フィンテックを活用して顧客満足度と収益の向上を図る”という事業戦略を実現するために，フィンテック企業が提供するスマートフォン向けアプリケーションソフトウェア，オープン API と銀行のシステムを連携させたビジネスモデルを検討し，顧客がいつでも入出金の確認や送金ができる新サービスを企画した。

  航空業では，“高品質かつ効率的な整備作業によって，安全かつ安定した運航を実現する”という事業戦略を実現するために，タブレット端末と整備管理システムを連携させた整備作業のビジネスプロセスを検討し，整備士が作業場所で，整備計画や図面の確認，点検箇所の撮影と作業報告などができる新サービスを企画した。

  IT ストラテジストは，新技術と業務システムを連携させた新サービスを企画する際には，事業戦略を実現するために，ビジネスモデル又はビジネスプロセスを検討し，どのような利用者にどのような便益を提供するのかを定義する。そして，投資効果を算出した上で，新サービスを企画する。

  さらに，新サービスの導入では，新サービスの有効性，信頼性，安全性などを検証する必要があり，試験的な導入，機能や範囲を限定した段階的な導入などの対応策も立案した上で，経営層に提案し，承認を得ることが必要である。

  あなたの経験と考えに基づいて，設問ア〜ウに従って論述せよ。

  - **設問ア**　あなたが携わった新技術と業務システムを連携させた新サービスの企画において，企画の背景にある，事業概要，事業特性，事業戦略，新技術を採用した必要性について，800 字以内で述べよ。
  - **設問イ**　設問アで述べた事業戦略を実現するために，新技術と業務システムを連携させて，どのような新サービスを企画し，どのような利用者に提供することを検討したか。検討したビジネスモデル又はビジネスプロセス，利用者の便益，投資効果を明確にして，800 字以上 1,600 字以内で具体的に述べよ。
  - **設問ウ**　設問イで述べた新サービスにおいて，新サービスの導入でどのようなことを検証するためにどのような対応策を立案し，経営層に提案したか。対応策の評価と評価を受けて改善したこととともに，600 字以上 1,200 字以内で具体的に述べよ。

  以下は論述の骨子（設計メモ）の例です。本番では各設問の字数を満たすよう、数値と自分の判断の理由を加えて文章にします。

  **設問ア（目安 700 字）事業概要・事業特性・事業戦略・新技術の必要性**

  - 事業概要：建設機械のレンタル会社 B 社（売上高約 300 億円、全国 80 営業所）。私は経営企画室の IT ストラテジストとして新サービスの企画を担当した。
  - 事業特性：顧客は中小ゼネコンや専門工事業者の現場監督で、建機の手配・返却は電話と FAX が中心。レンタル料の値下げ競争が激しく、営業所間の建機の回送費が利益を圧迫している。
  - 事業戦略：「現場の稼働率向上を支援するサービスで顧客を囲い込み、価格競争から脱する」。
  - 新技術の必要性：建機の稼働状況を顧客と共有するには、建機に搭載する GPS・稼働センサと、現場で使えるスマートフォンアプリが不可欠だった。

  **設問イ（目安 1,400 字）新サービス・利用者・ビジネスモデル・便益・投資効果**

  - 新サービス：稼働センサのデータをレンタル基幹システム（契約・在庫・請求）と連携し、現場監督がスマートフォンで建機の稼働状況の確認、追加手配、返却予約をできるようにする。
  - 利用者：複数の現場を掛け持ちする現場監督と、その会社の工事部門。
  - ビジネスモデル：基本レンタル料に、月次の稼働レポートと返却予約を含む「現場支援プラン」（1 台当たり月額 3,000 円）を上乗せする。顧客の工程管理システムとはオープン API で連携する。
  - 利用者の便益：手配・返却の連絡時間の削減、遊休建機の早期返却によるレンタル費の削減。
  - 投資効果：投資 5 億円に対し、プラン収入年 2 億円、回送費削減年 0.5 億円を見込み、3 年で回収する。前提とした加入率（対象顧客の 25%）の根拠を顧客アンケートで示した。

  **設問ウ（目安 1,000 字）検証事項・対応策・経営層の評価と改善**

  - 検証事項：有効性（現場監督が実際に使うか）、信頼性（山間部の現場での通信）、安全性（位置情報の取扱い）。
  - 対応策：2 営業所・3 か月の試験導入と、機能を稼働確認と返却予約に限定した段階的な導入を提案した。
  - 評価：試験導入の計画は評価されたが、「早期返却が増えると自社のレンタル収入が減るのではないか」と指摘された。
  - 改善：返却された建機を他の現場へ早く再貸出しすることで保有建機の稼働率が上がる効果を試算に加え、保有建機の稼働率を KPI に追加して承認を得た。

新技術（オープン API、タブレット端末など）と既存の業務システムを連携させた新サービスを、事業戦略の実現手段として企画できるかが問われています。設問イで「誰に・どんな便益を・どれだけの投資効果で」提供するのかを定義し、設問ウで導入時の検証と対応策を経営層に提案する流れになっています。

### 出題のねらい

IPA の出題趣旨では、新サービスの利用者、検討したビジネスモデル又はビジネスプロセス、利用者の便益、投資効果、導入時の検証内容と対応策を明確にした論述を求め、構想力・企画力・行動力をみるとされています。

### 答案の組み立て

- **設問ア**：事業戦略を一文で示し、その戦略を実現するうえで既存の業務システムだけでは足りない理由を「新技術を採用した必要性」として書きます。
- **設問イ**：新サービスの説明は機能の一覧ではなく、利用者の行動がどう変わるかで書きます。ビジネスモデル（収益の仕組み）かビジネスプロセス（業務の流れ）のどちらを検討したかを明示し、投資効果は投資額・効果額・前提条件・回収期間をそろえます。
- **設問ウ**：検証したいこと（有効性・信頼性・安全性など）と対応策（試験導入、機能や範囲を限定した段階導入）を一対一で対応させ、経営層の評価と改善につなげます。

### 採点講評に見る失敗パターン

IPA の採点講評では、次のような答案が見られたと指摘されています（要旨）。

- どのようなビジネスモデル又はビジネスプロセスを検討したかを書かず、システム機能の説明に終始している。
- 投資効果について、前提条件・算出根拠・実現可能性が具体的・定量的に書かれていない。
- ビジネスモデルとビジネスプロセスを混同している。
- 論述の対象の概要（答案用紙の質問項目）と本文が整合していない。

### ポイント

- 投資効果は「効果額 ÷ 投資額」だけでなく、加入率や利用率などの前提をどう見積もったかまで書くと説得力が増します。
- 設問ウの「対応策の評価」は経営層からの評価です。自己評価と混同しないようにしましょう。
- 採点の観点（rubric）は、IPA が公表した出題趣旨と採点講評を資格道場が要約し、言い換えたものです。
