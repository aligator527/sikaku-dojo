  図は，シックスシグマの基本となる日常業務の効率や品質の向上を目指す継続的改善サイクルである。このサイクルの c に該当するフェーズはどれか。ここで，ア〜エは a〜d のいずれかに対応する。

  $$
  \boxed{\text{定義}} \rightarrow \boxed{\ \text{a}\ } \rightarrow \boxed{\ \text{b}\ } \rightarrow \boxed{\ \textbf{c}\ } \rightarrow \boxed{\ \text{d}\ } \rightarrow \text{（a に戻る）}
  $$

  - 測定

  - 分析

シックスシグマの改善サイクルは、各フェーズの頭文字を取って DMAIC と呼ばれ、Define（定義）→ Measure（測定）→ Analyze（分析）→ Improve（改善）→ Control（定着・管理）の順に進みます。図の a〜d には測定・分析・改善・定着が順に入るので、c は「改善」です。定着の後は再び測定に戻り、改善を継続します。

### 各選択肢の検討

- **ア（正解）**：改善（Improve）は、分析で特定した真の原因に対して解決策を立案・実施する、c のフェーズです。
- **イ**：測定（Measure）は、現状のプロセスの能力や不良の発生状況をデータで把握するフェーズで、a に当たります。
- **ウ**：定着（Control）は、改善の成果が元に戻らないように、管理の仕組みを整えて標準化するフェーズで、d に当たります。
- **エ**：分析（Analyze）は、測定したデータから問題の真の原因を突き止めるフェーズで、b に当たります。

### ポイント

- DMAIC の順序は「定義 → 測定 → 分析 → 改善 → 定着」です。「測ってから分析し、原因が分かってから改善する」というデータに基づく流れで覚えましょう。
- シックスシグマは、プロセスのばらつきを抑え、不良の発生を 100 万回当たり 3.4 回以下に抑えることを目標とする品質改善の手法です。
