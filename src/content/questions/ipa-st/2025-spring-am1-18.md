  EVM を使用してマネジメントをしているプロジェクトで，進捗に関する指標値は次のとおりであった。このプロジェクトに対する適切な評価と対策はどれか。

  CPI（コスト効率指数）：0.9

  SPI（スケジュール効率指数）：1.1

  BAC（完成時総予算）に基づく TCPI（残作業効率指数）：1.2

三つの指標を順に読み取ります。

- $\mathrm{CPI} = \mathrm{EV} / \mathrm{AC} = 0.9 < 1$：出来高に対して実コストが多く、**コストは予算を超過**しています。
- $\mathrm{SPI} = \mathrm{EV} / \mathrm{PV} = 1.1 > 1$：計画以上に作業が進んでおり、**スケジュールには余裕**があります。
- $\mathrm{TCPI} = (\mathrm{BAC} - \mathrm{EV}) / (\mathrm{BAC} - \mathrm{AC}) = 1.2 > 1$：完成時総予算（BAC）内に収めるには、残作業を計画より 2 割高いコスト効率で進める必要があります。

したがって、BAC を超過するおそれがあり、残作業のコスト効率を上げる対策か、コンティンジェンシー予備費の使用を検討するという評価と対策が適切です。

### 各選択肢の検討

- **ア**：TCPI が 1.2 なので、BAC 内に収めるには残作業のコスト効率を計画より上げる必要があります。「上げる必要はない」という評価は誤りです。
- **イ（正解）**：CPI からコスト超過、SPI からスケジュールの余裕、TCPI から BAC 超過のおそれを読み取った、適切な評価と対策です。
- **ウ**：CPI が 0.9 なのでコストに余裕はなく、SPI が 1.1 なのでスケジュールも遅れていません。評価が逆です。
- **エ**：コストに余裕があるという評価も、スケジュールが遅れているという評価も誤りです。

### ポイント

- CPI と SPI は 1 より大きいほど良好、TCPI は 1 より大きいほど残作業に計画以上の効率が求められる（厳しい）と読みます。
- 現在のコスト効率が続くと仮定した完成時総コスト見積り（EAC）は $\mathrm{BAC} / \mathrm{CPI}$ です。CPI が 0.9 なら、EAC は BAC の約 1.11 倍になります。
