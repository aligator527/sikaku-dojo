stem: |
  A，B，C の順序で入力されるデータがある。各データについてスタックへの挿入と取出しを 1 回ずつ行うことができる場合，データの出力順序は何通りあるか。

  〔図〕入力（A，B，C の順）→ スタック → 出力
choices:
  - '3'
  - '4'
  - '5'
  - '6'
answer: 3
---
スタックは後入れ先出し（LIFO）のデータ構造です。A、B、C をこの順に挿入する途中で、任意のタイミングで取出しを挟めるので、実現できる出力順序を数え上げます。

### 計算

| 操作の順序（入＝挿入、出＝取出し） | 出力順序 |
| --- | :---: |
| A入 → A出 → B入 → B出 → C入 → C出 | ABC |
| A入 → A出 → B入 → C入 → C出 → B出 | ACB |
| A入 → B入 → B出 → A出 → C入 → C出 | BAC |
| A入 → B入 → B出 → C入 → C出 → A出 | BCA |
| A入 → B入 → C入 → C出 → B出 → A出 | CBA |

3 個の並べ方は全部で $3! = 6$ 通りですが、**CAB** だけは実現できません。C を最初に出力するには、その時点で A と B がスタックに入っていて B が A の上にあるため、C の次には B しか取り出せないからです。したがって 5 通りです。

### 各選択肢の検討

- **ア**：3 通りでは、上の表の順序の一部を数え漏らしています。
- **イ**：4 通りでも数え漏れがあります。表の 5 通りはすべて実現できます。
- **ウ（正解）**：実現できる出力順序は 5 通りです。
- **エ**：6 通りは 3 個のデータの順列の総数 $3!$ です。スタックでは CAB の順に出力できないので、1 通り少なくなります。

### ポイント

- $n$ 個のデータをスタックに通して得られる出力順序の数はカタラン数 $C_n = \dfrac{1}{n+1}\dbinom{2n}{n}$ で、$n = 3$ のとき 5、$n = 4$ のとき 14 です。
- 全順列から「実現できない順序」を見つけて引くと速く解けます。後から入れたデータを先に出したら、それより前に入れたデータは逆順でしか出せない、という性質を使います。
