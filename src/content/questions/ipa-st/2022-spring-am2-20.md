stem: |
  キャッシュフロー計算書における，営業活動によるキャッシュフローは何万円か。

  （単位　万円）

  | 項目 | 金額 |
  | --- | ---: |
  | 税金等調整前当期純利益 | 108 |
  | 減価償却費 | 42 |
  | 売上債権の増加額 | 60 |
  | 棚卸資産の減少額 | 30 |
  | 仕入債務の増加額 | 40 |
  | 法人税等の支払額 | 62 |
choices:
  - '14'
  - '74'
  - '98'
  - '158'
answer: 3

間接法による営業活動によるキャッシュフローは、税金等調整前当期純利益を出発点に、現金の支出を伴わない費用を足し戻し、運転資本の増減と法人税等の支払額を調整して求めます。各項目が現金を増やすのか減らすのかを考えると、$108 + 42 - 60 + 30 + 40 - 62 = 98$ 万円となります。

### 計算

| 項目 | 調整 | 理由 |
| --- | ---: | --- |
| 税金等調整前当期純利益 | ＋108 | 出発点 |
| 減価償却費 | ＋42 | 費用だが現金の支出を伴わないので足し戻す |
| 売上債権の増加額 | −60 | 売上のうち未回収分が増え、その分の現金が入っていない |
| 棚卸資産の減少額 | ＋30 | 在庫が減った分、仕入に現金を使わずに済んだ |
| 仕入債務の増加額 | ＋40 | 支払を先送りした分、現金が手元に残る |
| 法人税等の支払額 | −62 | 実際に現金で支払った税金 |
| 合計 | 98 | |

### 各選択肢の検討

- **ア**：14 万円は、減価償却費を足し戻さずに差し引いた場合の値です（$108 - 42 - 60 + 30 + 40 - 62$）。
- **イ**：74 万円は、減価償却費を差し引き、さらに売上債権の増加額を調整しなかった場合の値です（$108 - 42 + 30 + 40 - 62$）。
- **ウ（正解）**：各項目を正しい符号で調整した 98 万円です。
- **エ**：158 万円は、売上債権の増加額を差し引かなかった場合の値です（$108 + 42 + 30 + 40 - 62$）。

### ポイント

- 資産（売上債権・棚卸資産）の**増加**はキャッシュの減少、負債（仕入債務）の**増加**はキャッシュの増加として調整します。減少の場合はそれぞれ逆になります。
- 減価償却費は「費用だが現金が出ていない」ので必ず加算します。符号を取り違えた値が誤答の選択肢として並ぶのが典型です。
