  DNS 水責め攻撃（ランダムサブドメイン攻撃）はどれか。

DNS 水責め攻撃は、「ランダムな文字列.example.jp」のような**存在しないサブドメイン名**を大量に生成して問い合わせる DoS 攻撃です。存在しない名前はキャッシュに載らないため、問合せのたびに DNS キャッシュサーバから**標的ドメインの権威 DNS サーバ**へ問合せが転送され、権威 DNS サーバ（や途中のキャッシュサーバ）が過負荷になってサービスを提供できなくなります。

### 各選択肢の検討

- **ア**：キャッシュサーバに偽の DNS 情報を注入するのは、DNS キャッシュポイズニングの説明です。目的はサービス妨害ではなく、利用者を偽のサイトへ誘導することです。
- **イ（正解）**：権威 DNS サーバに、ランダムに生成した存在しないサブドメイン名を大量に問い合わせる、DNS 水責め攻撃の説明です。
- **ウ**：標的に大量の DNS レスポンスを送り付けるのは、送信元を詐称した問合せの応答を標的に集中させる DNS リフレクション攻撃に近い説明です。水責め攻撃は問合せを使って権威 DNS サーバに負荷をかける点が異なります。
- **エ**：データサイズの大きい DNS レスポンスを標的に送り付けるのは、小さな問合せから大きな応答を生み出して攻撃量を増幅する DNS アンプ攻撃（DNS amp）の説明です。

### ポイント

- 水責め攻撃は「存在しないサブドメイン」「権威 DNS サーバへの問合せ」が、キャッシュポイズニングは「偽情報の注入」が、DNS アンプ攻撃は「送信元詐称と応答の増幅」がキーワードです。
- 水責め攻撃への対策として、キャッシュサーバ側で問合せ元を制限する（オープンリゾルバにしない）、問合せの頻度を制限するなどの方法があります。
