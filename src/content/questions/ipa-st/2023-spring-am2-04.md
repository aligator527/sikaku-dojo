stem: |
  スマートフォン向けのアプリケーションプログラムの開発プロジェクト a〜d において，2年間の投資効果を NPV で評価する場合，投資効果が最大となるプロジェクトはどれか。ここで，割引率は10%とする。

  （単位　百万円）

  | プロジェクト | 初期投資額 | 1年目キャッシュフロー | 2年目キャッシュフロー |
  | :---: | ---: | ---: | ---: |
  | a | 7.9 | 4.40 | 4.84 |
  | b | 5.5 | 3.30 | 3.63 |
  | c | 4.3 | 3.30 | 2.42 |
  | d | 6.1 | 2.20 | 3.63 |
choices:
  - a
  - b
  - c
  - d
answer: 3
---
NPV（正味現在価値）は、将来のキャッシュフローを割引率で現在価値に割り戻して合計し、そこから初期投資額を差し引いた値です。割引率が10%なので、1年目は $1.1$、2年目は $1.1^2 = 1.21$ で割ります。NPV が最も大きい c が、投資効果が最大のプロジェクトです。

### 計算

$$
\text{NPV} = -\text{初期投資額} + \frac{\text{1年目CF}}{1.1} + \frac{\text{2年目CF}}{1.21}
$$

| プロジェクト | 1年目の現在価値 | 2年目の現在価値 | NPV |
| :---: | ---: | ---: | ---: |
| a | $4.40 \div 1.1 = 4.0$ | $4.84 \div 1.21 = 4.0$ | $-7.9 + 4.0 + 4.0 = 0.1$ |
| b | $3.30 \div 1.1 = 3.0$ | $3.63 \div 1.21 = 3.0$ | $-5.5 + 3.0 + 3.0 = 0.5$ |
| c | $3.30 \div 1.1 = 3.0$ | $2.42 \div 1.21 = 2.0$ | $-4.3 + 3.0 + 2.0 = 0.7$ |
| d | $2.20 \div 1.1 = 2.0$ | $3.63 \div 1.21 = 3.0$ | $-6.1 + 2.0 + 3.0 = -1.1$ |

### 各選択肢の検討

- **ア**：プロジェクト a は、キャッシュフローの合計が最も大きいものの、初期投資額も大きく、NPV は 0.1 百万円にとどまります。
- **イ**：プロジェクト b の NPV は 0.5 百万円です。
- **ウ（正解）**：プロジェクト c の NPV は 0.7 百万円で、四つの中で最大です。
- **エ**：プロジェクト d の NPV は −1.1 百万円で、投資額を回収できません。

### ポイント

- 割り引かずにキャッシュフローの合計から投資額を引くと、a が 1.34、b が 1.43、c が 1.42、d が −0.27 となり、b が最大に見えてしまいます。NPV では必ず年数に応じて割り引きます。
- NPV がプラスであれば、その投資は割引率（資本コスト）を上回る価値を生むと判断できます。
