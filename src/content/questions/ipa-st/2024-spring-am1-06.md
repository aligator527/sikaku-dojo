stem: |
  三つの資源 X〜Z を占有して処理を行う四つのプロセス A〜D がある。各プロセスは処理の進行に伴い，表中の数値の順に資源を占有し，実行終了時に三つの資源を一括して解放する。プロセス A と同時にもう一つプロセスを動かした場合に，デッドロックを起こす可能性があるプロセスはどれか。

  資源の占有順序

  | プロセス | 資源 X | 資源 Y | 資源 Z |
  | :---: | :---: | :---: | :---: |
  | A | 1 | 2 | 3 |
  | B | 1 | 2 | 3 |
  | C | 2 | 3 | 1 |
  | D | 3 | 2 | 1 |
choices:
  - B，C，D
  - C，D
  - C だけ
  - D だけ
answer: 2

表の数値を資源の占有順に読み替えると、A と B は X → Y → Z、C は Z → X → Y、D は Z → Y → X です。デッドロックは、二つのプロセスが互いに相手の占有している資源を待つ状態で、資源を**異なる順序**で占有するプロセスどうしで起こり得ます。

### 各プロセスとの組合せ

- **A と B**：同じ順序（X → Y → Z）で占有します。先に X を確保した側だけが先に進み、もう一方は X の解放を待つだけなので、デッドロックは起きません。
- **A と C**：A が X を、C が Z を確保した後、C は X（A が占有中）を、A は Y を確保して次に Z（C が占有中）を待つと、互いに相手の解放を待ち続けます。デッドロックが起こり得ます。
- **A と D**：A が X を、D が Z と Y を確保した後、A は Y（D が占有中）を、D は X（A が占有中）を待つと、デッドロックになります。

デッドロックを起こす可能性があるのは C と D です。

### 各選択肢の検討

- **ア**：B は A と同じ順序で資源を占有するので、デッドロックは起きません。
- **イ（正解）**：A と異なる順序で資源を占有する C と D で、デッドロックが起こり得ます。
- **ウ**：D も、A と逆の順序で X と Y を占有するので、デッドロックが起こり得ます。
- **エ**：C も、A が X を、C が Z を先に確保した場合にデッドロックが起こり得ます。

### ポイント

- デッドロックは、相互排除・占有と待ち・横取り不可・循環待ちの四つの条件がそろうと発生します。
- すべてのプロセスで資源を確保する順序を統一すると、循環待ちが起きなくなり、デッドロックを防止できます。
