直接原価計算では、固定製造原価を製品原価に含めず、発生した期間の費用（期間原価）として全額を差し引きます。そのため営業利益は販売量だけで決まり、生産量の影響を受けません。

### 計算

| 項目 | 計算 | 金額 |
| --- | --- | ---: |
| 売上高 | 1,800個 × 5,000 | 9,000,000 |
| 変動売上原価 | 1,800個 × 2,000 | 3,600,000 |
| 変動販売費 | 1,800個 × 300 | 540,000 |
| 貢献利益 | | 4,860,000 |
| 固定製造原価 | | 1,600,000 |
| 固定販売費及び一般管理費 | | 900,000 |
| 営業利益 | | **2,360,000** |

参考：全部原価計算の営業利益

- 製品単位原価：2,000 ＋ 1,600,000 ÷ 2,000個 ＝ 2,800円
- 営業利益：9,000,000 − 1,800個 × 2,800 − (540,000 ＋ 900,000) ＝ 2,520,000円
- 差額 160,000円 ＝ 期末製品 200個 × 固定製造原価 800円（全部原価計算では次期に繰り越される固定費）

### ポイント

- 変動販売費は販売量（1,800個）に掛けます。生産量（2,000個）に掛ける誤りに注意します。
- 固定費調整：全部原価計算の営業利益 ＝ 直接原価計算の営業利益 ＋ 期末棚卸資産に含まれる固定製造原価 − 期首棚卸資産に含まれる固定製造原価。
- 生産量が販売量を上回ると、全部原価計算の利益のほうが大きくなります。
