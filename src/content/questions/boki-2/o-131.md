建物が火災で焼失し、受け取る保険金の額がまだ確定していない場合は、焼失時の帳簿価額を未決算勘定に振り替えておきます。期中に焼失したので、当期首から焼失日までの減価償却費を月割で計上してから帳簿価額を求めます。

### 計算

1. 年間の減価償却費：9,000,000 ÷ 30年 ＝ 300,000円
2. 当期分（4月1日〜8月31日の5か月）：300,000 × 5/12 ＝ 125,000円
3. 焼失時の帳簿価額：9,000,000 − 3,600,000 − 125,000 ＝ 5,275,000円
4. 保険金額（6,000,000円）が帳簿価額を上回るので、帳簿価額の全額を未決算とします。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 建物減価償却累計額 | 3,600,000 | 建物 | 9,000,000 |
| 減価償却費 | 125,000 | | |
| 未決算 | 5,275,000 | | |

### ポイント

- 未決算に振り替えるのは保険金額ではなく焼失時の **帳簿価額** です。保険金額が帳簿価額より小さいときは、保険金額を限度として未決算とし、差額をその時点で火災損失とするのが一般的です。
- 保険金の額が確定したら、未決算との差額を保険差益（確定額が多い場合）または火災損失（少ない場合）とします。例：保険金 5,500,000円 の支払いが決定 →（借）未収入金 5,500,000 （貸）未決算 5,275,000・保険差益 225,000
- 当期分の減価償却費を忘れると、未決算が 5,400,000円 となり誤りです。
