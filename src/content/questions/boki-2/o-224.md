繰越利益剰余金は、繰越利益剰余金を財源とする配当とそれに伴う利益準備金の積立て、別途積立金の積立てで減少し、当期純利益で増加します。その他資本剰余金を財源とする配当や、新株の発行・合併は繰越利益剰余金に影響しません。

### 計算

1. 準備金の積立額：配当総額 5,000,000円 の10分の1 ＝ 500,000円（上限 4,700,000円 の範囲内）
   - 利益準備金：4,000,000 × 10分の1 ＝ 400,000円
2. 繰越利益剰余金の増減

| 事由 | 繰越利益剰余金 |
| --- | ---: |
| 当期首残高 | 8,600,000 |
| 剰余金の配当（配当金） | △4,000,000 |
| 剰余金の配当（利益準備金の積立て） | △400,000 |
| 別途積立金の積立て | △600,000 |
| 当期純利益 | 5,200,000 |
| 当期末残高 | **8,800,000** |

株主総会での剰余金の配当・処分の仕訳は次のとおりです。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| その他資本剰余金 | 1,100,000 | 未払配当金 | 5,000,000 |
| 繰越利益剰余金 | 5,000,000 | 資本準備金 | 100,000 |
| | | 利益準備金 | 400,000 |
| | | 別途積立金 | 600,000 |

### ポイント

- 配当総額の10分の1（500,000円）をすべて繰越利益剰余金から差し引くと 8,700,000円 となり誤答です。その他資本剰余金の配当分に対応する 100,000円 は、その他資本剰余金から積み立てます。
- その他資本剰余金の配当 1,000,000円 まで繰越利益剰余金から差し引く誤りにも注意します。
- その他有価証券の評価差額は純資産に直接計上され、当期純利益にも繰越利益剰余金にも影響しません。
