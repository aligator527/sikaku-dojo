全部純資産直入法による評価差額は、翌期首に振り戻して帳簿価額を取得原価に戻します（洗替法）。振戻しの仕訳は、前期末の評価替えの仕訳の貸借を逆にしたものです。前期末は時価が取得原価を下回っていたので、評価差損に対する繰延税金資産を計上していました。

### 計算

**前期末の評価替え**

- 評価差額：1,260,000 − 1,500,000 ＝ △240,000円（評価差損）
- 繰延税金資産：240,000 × 30％ ＝ 72,000円
- その他有価証券評価差額金（借方）：240,000 − 72,000 ＝ 168,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 繰延税金資産 | 72,000 | その他有価証券 | 240,000 |
| その他有価証券評価差額金 | 168,000 | | |

**当期首の振戻し（解答）**

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| その他有価証券 | 240,000 | 繰延税金資産 | 72,000 |
| | | その他有価証券評価差額金 | 168,000 |

借方・貸方の合計はともに 240,000円 です。

### ポイント

- その他有価証券の税効果は純資産（評価差額金）から直接控除するので、法人税等調整額は使いません。振戻しでも同じです。
- 評価差損を「有価証券評価損」として損益に計上するのは誤りです。2級の範囲では全部純資産直入法なので、評価差益・評価差損のどちらも評価差額金で処理します。
- 振戻し後のその他有価証券の帳簿価額は取得原価の 1,500,000円 に戻ります。
