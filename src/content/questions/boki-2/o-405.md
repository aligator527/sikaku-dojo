子会社から親会社への販売（アップストリーム）では、子会社の利益に含まれる未実現利益を消去し、その40%（非支配株主の持分割合）を非支配株主に負担させます。商品の未実現利益だけでなく、子会社が計上した土地の売却益も同じ扱いです。また、子会社の土地は支配獲得日の時価に評価替えしてから資本連結を行います。

### 計算

**1. 開始仕訳**

| 内容 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 評価差額 | 土地 | 500,000 | 評価差額 | 500,000 |
| 資本連結 | 資本金 | 3,000,000 | S社株式 | 4,500,000 |
| | 利益剰余金 | 1,500,000 | 非支配株主持分 | 2,000,000 |
| | 評価差額 | 500,000 | | |
| | のれん | 1,500,000 | | |
| 前期の利益・配当・償却 | 利益剰余金 | 350,000 | のれん | 150,000 |
| | | | 非支配株主持分 | 200,000 |
| 期首の未実現利益 | 利益剰余金 | 72,000 | 商品 | 120,000 |
| | 非支配株主持分 | 48,000 | | |

- 時価による S社の資本：$3{,}000{,}000 + 1{,}500{,}000 + 500{,}000 = 5{,}000{,}000$円 → のれん $4{,}500{,}000 - 5{,}000{,}000 \times 60\% = 1{,}500{,}000$円（年 150,000円）
- 前期分：のれん償却 150,000円、利益の配分 $800{,}000 \times 40\% = 320{,}000$円、配当の非支配株主分 $300{,}000 \times 40\% = 120{,}000$円
- 期首の未実現利益：$400{,}000 \times 30\% = 120{,}000$円（うち非支配株主の負担 48,000円）

- 土地：$5{,}000{,}000 + 2{,}000{,}000 + 500{,}000 - 200{,}000 = 7{,}300{,}000$円

**3. 純資産**

- 利益剰余金の当期首残高：$4{,}000{,}000 + 2{,}000{,}000 - 1{,}500{,}000 - 350{,}000 - 72{,}000 = 4{,}078{,}000$円
- 非支配株主持分：当期首 $2{,}000{,}000 + 200{,}000 - 48{,}000 = 2{,}152{,}000$円、当期末 $(3{,}000{,}000 + 2{,}600{,}000 + 500{,}000) \times 40\% - (150{,}000 + 200{,}000) \times 40\% = 2{,}300{,}000$円

### ポイント

- アップストリームの未実現利益は全額を消去したうえで、非支配株主の持分割合だけ「非支配株主持分」と「非支配株主に帰属する当期純利益」を減らします。ダウンストリームと取り違えないようにします。
- 評価差額は資本連結で消去されるので、連結貸借対照表には現れません。土地の金額に 500,000円を加えるのを忘れないようにします。
- 固定資産売却益は S社の 200,000円だけで、全額が消去されるため連結損益計算書には計上されません。
