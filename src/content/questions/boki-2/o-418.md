本支店合併財務諸表を作るときは、まず未達事項を処理して支店勘定と本店勘定の残高を一致させ、両者を相殺消去します。そのうえで本店・支店それぞれの決算整理を行い、同じ科目を合算します。本店から支店への商品の送付は会社内部の移動なので、合算すれば内部の振替は消え、外部からの仕入高だけが残ります。

### 計算

**1. 未達事項の処理**

| 未達事項 | 処理する側 | 仕訳 |
| --- | --- | --- |
| 1. 商品の未達 | 支店 | （借）仕入 300,000（貸）本店 300,000 |
| 2. 送金の未達 | 本店 | （借）現金預金 200,000（貸）支店 200,000 |
| 3. 売掛金の回収 | 支店 | （借）本店 150,000（貸）売掛金 150,000 |
| 4. 広告宣伝費の立替え | 本店 | （借）広告宣伝費 50,000（貸）支店 50,000 |

- 本店の支店勘定：$2{,}610{,}000 - 200{,}000 - 50{,}000 = 2{,}360{,}000$円
- 支店の本店勘定：$2{,}210{,}000 + 300{,}000 - 150{,}000 = 2{,}360{,}000$円（一致するので相殺消去できる）

**2. 決算整理**

| 項目 | 本店 | 支店 | 合計 |
| --- | ---: | ---: | ---: |
| 期首商品棚卸高 | 1,500,000 | 600,000 | 2,100,000 |
| 当期商品仕入高 | 17,200,000 | 7,500,000 | 24,700,000 |
| 期末商品棚卸高 | 1,700,000 | 1,050,000 | 2,750,000 |
| 貸倒引当金繰入 | 3,600,000 × 2% − 30,000 ＝ 42,000 | 1,650,000 × 2% − 12,000 ＝ 21,000 | 63,000 |
| 減価償却費 | (2,000,000 − 720,000) × 20% ＝ 256,000 | (800,000 − 288,000) × 20% ＝ 102,400 | 358,400 |
| 給料 | 3,200,000 ＋ 60,000 | 1,400,000 | 4,660,000 |
| 支払リース料 | 600,000 | 480,000 − 80,000 | 1,000,000 |
| 広告宣伝費 | 420,000 ＋ 50,000 | 180,000 | 650,000 |

- 支店の仕入高には未達の商品 300,000円を加え、期末商品にも 300,000円を加えます（$750{,}000 + 300{,}000 = 1{,}050{,}000$円）。
- 支店の売掛金は未達事項3.で 150,000円減るので、貸倒引当金は 1,650,000円にもとづいて計算します。
- 売上原価：$2{,}100{,}000 + 24{,}700{,}000 - 2{,}750{,}000 = 24{,}050{,}000$円

**3. 利益**

合併後の当期純利益は 2,488,600円です。内訳は、本店 1,142,000円、支店 1,346,600円で、合計すると会社全体の利益に一致します。合併貸借対照表の売掛金は $3{,}600{,}000 + 1{,}650{,}000 = 5{,}250{,}000$円、貸倒引当金は $72{,}000 + 33{,}000 = 105{,}000$円、商品は 2,750,000円です。

### ポイント

- 未達事項は「連絡を受けていない側」だけが仕訳を追加します。本店が自分で発送した商品（1.）を本店側で処理し直すと、二重計上になります。
- 本店から支店への送付分は、本店では仕入の減少、支店では仕入の増加として記帳されているので、合算すると打ち消し合います。当期商品仕入高に未達分を加え忘れると、期末商品の加算と整合しなくなります。
- 支店勘定・本店勘定は合併財務諸表には表示されません。
