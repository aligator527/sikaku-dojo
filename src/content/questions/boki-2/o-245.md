個別の売上原価を合計し、連結会社間の売上高との相殺、期首商品の未実現利益の実現、期末商品の未実現利益の消去を反映します。期首分は売上原価を減らし、期末分は売上原価を増やします。

### 計算

| 項目 | 金額 |
| --- | ---: |
| P社の売上原価 ＋ S社の売上原価 | 12,600,000 |
| 連結会社間の取引高の相殺 | △2,400,000 |
| 期首商品の未実現利益の実現（240,000 × 20 ÷ 120） | △40,000 |
| 期末商品の未実現利益の消去（360,000 × 20 ÷ 120） | ＋60,000 |
| 連結損益計算書の売上原価 | **10,220,000** |

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 売上高 | 2,400,000 | 売上原価 | 2,400,000 |
| 商品 | 40,000 | 売上原価 | 40,000 |
| 売上原価 | 60,000 | 商品 | 60,000 |

### ポイント

- 期首商品の未実現利益の実現を忘れると 10,260,000円 となり誤答です。前期末に消去した利益は、当期にその商品が外部に販売されたときに実現します。
- 土地の売却益の消去は固定資産売却益で行うので、売上原価には影響しません。
- 連結損益計算書の売上高は 18,000,000 − 2,400,000 ＝ 15,600,000円 です。
