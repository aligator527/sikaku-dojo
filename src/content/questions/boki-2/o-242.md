非支配株主持分は「子会社の純資産 × 非支配株主の持分割合（30％）」が基本で、子会社の利益で増え、子会社の配当で減ります。さらに、子会社が親会社に土地を売却した（アップストリーム）ことによる未実現利益は、その30％を非支配株主にも負担させるので、非支配株主持分を減らします。商品の売買は親会社からの販売（ダウンストリーム）なので、非支配株主持分には影響しません。

### 計算

| 内容 | 計算 | 非支配株主持分 |
| --- | --- | ---: |
| 支配獲得時 | 3,600,000 × 30％ | 1,080,000 |
| 前期の当期純利益 | 500,000 × 30％ | ＋150,000 |
| 前期の配当 | 200,000 × 30％ | △60,000 |
| 当期首残高（開始仕訳） | | 1,170,000 |
| 当期の当期純利益 | 600,000 × 30％ | ＋180,000 |
| 当期の配当 | 300,000 × 30％ | △90,000 |
| 土地の未実現利益（アップストリーム） | 200,000 × 30％ | △60,000 |
| 当期末残高 | | **1,200,000** |

検算：当期末のS社の純資産 (2,000,000 ＋ 400,000 ＋ 1,800,000) × 30％ ＝ 1,260,000円 から、土地の未実現利益の非支配株主負担分 60,000円 を差し引くと 1,200,000円 です。

土地の未実現利益に関する連結修正仕訳は次のとおりです。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 固定資産売却益 | 200,000 | 土地 | 200,000 |
| 非支配株主持分 | 60,000 | 非支配株主に帰属する当期純利益 | 60,000 |

### ポイント

- 土地の未実現利益の負担を忘れると 1,260,000円 となり誤答です。アップストリームかダウンストリームかを、売り手がどちらかで判断します。
- 商品の未実現利益はP社が販売したもの（ダウンストリーム）なので、全額を親会社が負担します。ここで非支配株主持分を減らすのは誤りです。
- 非支配株主持分は、連結貸借対照表の純資産の部に表示します。
