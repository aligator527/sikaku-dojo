決算整理仕訳を書いてから、収益・費用の勘定を損益計算書の区分（売上原価、販売費及び一般管理費、営業外収益・費用）に振り分けます。前期の売掛金の貸倒れと、期中に借り入れた借入金の利息の見越しが計算の要所です。

### 計算

| 決算整理事項 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 1. 売上原価 | 仕入 | 1,380,000 | 繰越商品 | 1,380,000 |
| | 繰越商品 | 1,520,000 | 仕入 | 1,520,000 |
| | 棚卸減耗損 | 40,000 | 繰越商品 | 114,000 |
| | 商品評価損 | 74,000 | | |
| 2. 貸倒れ | 貸倒引当金 | 52,000 | 売掛金 | 200,000 |
| | 貸倒損失 | 148,000 | | |
| 3. 貸倒引当金 | 貸倒引当金繰入 | 116,000 | 貸倒引当金 | 116,000 |
| 4. 有価証券 | 有価証券評価損 | 70,000 | 売買目的有価証券 | 70,000 |
| 5. 減価償却 | 減価償却費 | 976,000 | 建物減価償却累計額 | 400,000 |
| | | | 備品減価償却累計額 | 576,000 |
| 6. 退職給付 | 退職給付費用 | 480,000 | 退職給付引当金 | 480,000 |
| 7. 保険料 | 前払保険料 | 120,000 | 保険料 | 120,000 |
| 8. 利息 | 支払利息 | 96,000 | 未払利息 | 96,000 |

- 期末商品：帳簿 $760 \times 2{,}000 = 1{,}520{,}000$円、棚卸減耗損 $(760 - 740) \times 2{,}000 = 40{,}000$円、商品評価損 $740 \times (2{,}000 - 1{,}900) = 74{,}000$円
- 貸倒れ：前期の債権なので、まず貸倒引当金 52,000円を取り崩し、不足の 148,000円を貸倒損失とします。
- 貸倒引当金：$(4{,}000{,}000 + 1{,}800{,}000) \times 2\% = 116{,}000$円。取崩し後の残高はゼロなので、全額を繰り入れます。
- 減価償却：建物 $12{,}000{,}000 \div 30 = 400{,}000$円、備品 $(2{,}400{,}000 - 960{,}000) \times 0.4 = 576{,}000$円
- 保険料：12か月分のうち4月〜7月の4か月分 $360{,}000 \times 4/12 = 120{,}000$円が次期分です。
- 支払利息：8月〜3月の8か月分 $4{,}800{,}000 \times 3\% \times 8/12 = 96{,}000$円
- 売上原価：$28{,}460{,}000 + 40{,}000 + 74{,}000 = 28{,}574{,}000$円

税引前当期純利益は 2,713,000円、法人税、住民税及び事業税は $2{,}713{,}000 \times 30\% = 813{,}900$円で、当期純利益は 1,899,100円です（仮払法人税等 420,000円との差額 393,900円は未払法人税等）。

### ポイント

- 前期に発生した売掛金の貸倒れは、貸倒引当金を先に使います。引当金を超える部分だけが貸倒損失です（当期に発生した売掛金なら全額が貸倒損失）。
- 商品評価損は実地棚卸数量に単価の下落額を掛けます。帳簿棚卸数量（760個）で計算すると 76,000円となり誤りです。
- 有価証券評価損は営業外費用です。販売費及び一般管理費に含めると営業利益がずれます。
