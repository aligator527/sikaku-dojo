製造原価報告書は、当月に発生した製造原価を直接材料費・直接労務費・直接経費・製造間接費に分けて集計し、仕掛品の増減を調整して当月製品製造原価を求める書類です。製造間接費を予定配賦している場合、当月総製造費用には **予定配賦額** が入るので、実際発生額に配賦差異を加減して修正します。

### 計算

**1. 製造直接費**

- 直接材料費：250,000 ＋ 2,400,000 − 300,000（帳簿棚卸高）＝ 2,350,000円
- 直接労務費：1,500,000 − 300,000 ＋ 320,000 ＝ 1,520,000円
- 直接経費：外注加工賃 130,000円

**2. 製造間接費（実際発生額）**

- 間接材料費：40,000 ＋ 180,000 − 30,000 ＝ 190,000円
- 間接労務費：400,000 − 70,000 ＋ 80,000 ＝ 410,000円
- 間接経費：減価償却費 220,000 ＋ 電力料 95,000 ＋ 棚卸減耗損（300,000 − 292,000 ＝ 8,000）＝ 323,000円
- 実際発生額合計：190,000 ＋ 410,000 ＋ 323,000 ＝ 923,000円
- 予定配賦額：1,900時間 × 500円 ＝ 950,000円
- 製造間接費配賦差異：950,000 − 923,000 ＝ ＋27,000円（有利差異。報告書では実際発生額に加算）

**3. 製造原価報告書**

| 項目 | 金額 |
| --- | ---: |
| 直接材料費 | 2,350,000 |
| 直接労務費 | 1,520,000 |
| 直接経費 | 130,000 |
| 製造間接費（実際発生額） | 923,000 |
| 製造間接費配賦差異 | ＋27,000 |
| 当月総製造費用 | 4,950,000 |
| 月初仕掛品棚卸高 | 480,000 |
| 合計 | 5,430,000 |
| 月末仕掛品棚卸高 | 520,000 |
| 当月製品製造原価 | **4,910,000** |

### ポイント

- 製造間接費を実際発生額 923,000円 のまま集計すると 4,883,000円 となり誤りです。予定配賦をしているときは、配賦差異を加減して予定配賦額にそろえます（有利差異は加算、不利差異は減算）。
- 直接材料費は帳簿棚卸高で計算し、正常な棚卸減耗損 8,000円 は間接経費として製造間接費に含めます。実地棚卸高で直接材料費を計算すると、減耗分が直接材料費に混ざります。
- 賃金は支払高ではなく「支払高 − 月初未払高 ＋ 月末未払高」で当月の消費額を求めます。
