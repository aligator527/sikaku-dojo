売上原価対立法では、商品を販売するたびに原価を売上原価勘定に振り替えているので、試算表の売上原価がそのまま当期の売上原価になります（期首・期末の棚卸高による計算は不要）。決算では棚卸減耗損と商品評価損を加えるだけです。

### 計算

| 決算整理事項 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 1. ファクタリング | 普通預金（現金預金） | 490,000 | 売掛金 | 500,000 |
| | 債権売却損 | 10,000 | | |
| 2. 減耗・評価損 | 売上原価 | 100,000 | 商品 | 100,000 |
| 3. 貸倒引当金 | 貸倒引当金繰入 | 70,000 | 貸倒引当金 | 70,000 |
| 4. 建物への振替 | 建物 | 4,800,000 | 建設仮勘定 | 4,800,000 |
| 5. 圧縮記帳 | 固定資産圧縮損 | 1,000,000 | 機械装置 | 1,000,000 |
| 6. 減価償却 | 減価償却費 | 790,000 | 建物減価償却累計額 | 640,000 |
| | | | 機械装置減価償却累計額 | 150,000 |
| 7. 修繕引当金 | 修繕引当金 | 300,000 | 修繕費 | 300,000 |
| | 修繕引当金繰入 | 400,000 | 修繕引当金 | 400,000 |
| 8. 商品保証引当金 | 商品保証引当金繰入 | 104,000 | 商品保証引当金 | 104,000 |
| 9. 未払利息 | 支払利息 | 24,000 | 未払利息 | 24,000 |

- 商品：棚卸減耗損 $2{,}860{,}000 - 2{,}820{,}000 = 40{,}000$円、商品評価損 $2{,}820{,}000 - 2{,}760{,}000 = 60{,}000$円。売上原価は $30{,}240{,}000 + 100{,}000 = 30{,}340{,}000$円です。
- 貸倒引当金：$(5{,}600{,}000 - 500{,}000 + 1{,}400{,}000) \times 2\% = 130{,}000$円。譲渡した売掛金は引当金の対象から外します。
- 建物：既存分 $18{,}000{,}000 \div 30 = 600{,}000$円、新店舗 $4{,}800{,}000 \div 30 \times 3/12 = 40{,}000$円
- 機械装置：$(2{,}500{,}000 - 1{,}000{,}000) \div 5 \times 6/12 = 150{,}000$円
- 修繕費：$680{,}000 - 300{,}000 = 380{,}000$円。修繕引当金は $500{,}000 - 300{,}000 + 400{,}000 = 600{,}000$円になります。
- 商品保証引当金：$44{,}800{,}000 \times 0.5\% = 224{,}000$円、繰入 $224{,}000 - 120{,}000 = 104{,}000$円
- 支払利息：2月〜3月の2か月分 $6{,}000{,}000 \times 2.4\% \times 2/12 = 24{,}000$円を加えて 144,000円（1年分）

税引前当期純利益は 4,708,000円、法人税等は $4{,}708{,}000 \times 30\% = 1{,}412{,}400$円、当期純利益は 3,295,600円です。未払法人税等は仮払法人税等 380,000円を差し引いた 1,032,400円です。

### ポイント

- 国庫補助金受贈益（特別利益）と固定資産圧縮損（特別損失）は同額で、損益計算書には両方を表示します。減価償却は圧縮後の取得原価 1,500,000円にもとづきます。
- 建設仮勘定は使用を開始した日から建物として償却します。完成前の期間（4月〜12月）は償却しません。
- ファクタリングの手数料は債権売却損（営業外費用）です。支払手数料（販売費及び一般管理費）としないように注意します。
