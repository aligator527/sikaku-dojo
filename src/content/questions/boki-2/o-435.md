この形式では、まず材料費・労務費・経費を **実際発生額** のまま集計して当期製造費用とし、そのあとで製造間接費配賦差異を加減して、仕掛品勘定に入った金額（予定配賦額ベース）の当期総製造費用にそろえます。差異の額を知るために、製造間接費の実際発生額を先に計算します。

### 製造間接費の集計

| 項目 | 計算 | 金額 |
| --- | --- | ---: |
| 材料費 | $260{,}000 + 3{,}840{,}000 - 300{,}000$ | 3,800,000 |
| 間接材料費 | $3{,}800{,}000 - 3{,}380{,}000$ | 420,000 |
| 賃金 | $4{,}150{,}000 - 350{,}000 + 390{,}000$ | 4,190,000 |
| 労務費 | $4{,}190{,}000 + 720{,}000 + 210{,}000$ | 5,120,000 |
| 間接労務費 | $5{,}120{,}000 - 3{,}450{,}000$ | 1,670,000 |
| 間接経費 | 経費 2,820,000 − 外注加工賃 480,000 | 2,340,000 |
| 実際発生額 | $420{,}000 + 1{,}670{,}000 + 2{,}340{,}000$ | 4,430,000 |
| 予定配賦額 | $1{,}500 \times 3{,}000$ | 4,500,000 |

予定配賦額が実際発生額を 70,000円 上回る **配賦超過**（有利差異）です。仕掛品には実際より 70,000円 多く配賦されているので、製造原価報告書では当期製造費用に **加算** します。

### 製造原価報告書

- 当期製造費用：$3{,}800{,}000 + 5{,}120{,}000 + 2{,}820{,}000 = 11{,}740{,}000$円
- 当期総製造費用：$11{,}740{,}000 + 70{,}000 = 11{,}810{,}000$円
- 当期製品製造原価：$11{,}810{,}000 + 720{,}000 - 830{,}000 = 11{,}700{,}000$円

検算として、直接費と予定配賦額を足すと $3{,}380{,}000 + 3{,}450{,}000 + 480{,}000 + 4{,}500{,}000 = 11{,}810{,}000$円 となり、当期総製造費用と一致します。

### ポイント

- 形態別の報告書では、配賦差異は当期製造費用の後で加減します。有利差異は加算、不利差異は減算です。
- 外注加工賃は経費に含めて表示しますが、製造間接費（間接経費）ではなく直接経費です。
- 賃金は当期支払高ではなく、未払高を調整した消費額（支払高 − 期首未払高 ＋ 期末未払高）を記入します。
