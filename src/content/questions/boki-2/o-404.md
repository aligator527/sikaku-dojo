支配獲得後2年目なので、前期までの連結修正を「開始仕訳」として利益剰余金当期首残高・非支配株主持分当期首残高に反映させてから、当期の修正を行います。期首商品の未実現利益と前期末の貸倒引当金の修正も、開始仕訳で引き継ぎます。

### 計算

**1. 開始仕訳（前期までの修正）**

| 内容 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 資本連結 | 資本金 | 5,000,000 | S社株式 | 7,000,000 |
| | 利益剰余金 | 3,200,000 | 非支配株主持分 | 1,740,000 |
| | のれん | 540,000 | | |
| 期首の未実現利益 | 利益剰余金 | 90,000 | 商品 | 90,000 |
| 前期末の貸倒引当金 | 貸倒引当金 | 8,000 | 利益剰余金 | 8,000 |

- のれん：$7{,}000{,}000 - 8{,}000{,}000 \times 80\% = 600{,}000$円（年 60,000円の償却。前期の償却後 540,000円）
- 利益剰余金（資本連結分）：支配獲得時 3,000,000 ＋ 前期のれん償却 60,000 ＋ 前期の非支配株主への利益配分 240,000 − 前期配当の非支配株主分 100,000 ＝ 3,200,000円
- 非支配株主持分（当期首）：$(5{,}000{,}000 + 3{,}700{,}000) \times 20\% = 1{,}740{,}000$円
- 期首の未実現利益：$360{,}000 \times 25\% = 90{,}000$円、前期末の貸倒引当金：$400{,}000 \times 2\% = 8{,}000$円

**2. 当期の修正**

| 内容 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| のれん償却 | のれん償却 | 60,000 | のれん | 60,000 |
| 利益の配分 | 非支配株主に帰属する当期純利益 | 300,000 | 非支配株主持分 | 300,000 |
| 配当 | 受取配当金 | 480,000 | 利益剰余金（配当） | 600,000 |
| | 非支配株主持分 | 120,000 | | |
| 内部取引 | 売上高 | 4,800,000 | 売上原価 | 4,800,000 |
| 期首の未実現利益の実現 | 商品 | 90,000 | 売上原価 | 90,000 |
| 期末の未実現利益 | 売上原価 | 120,000 | 商品 | 120,000 |
| 債権債務 | 買掛金 | 500,000 | 売掛金 | 500,000 |
| 貸倒引当金 | 貸倒引当金 | 2,000 | 貸倒引当金繰入 | 2,000 |
| 土地 | 固定資産売却益 | 600,000 | 土地 | 600,000 |

- 売上原価：$21{,}000{,}000 + 9{,}800{,}000 - 4{,}800{,}000 - 90{,}000 + 120{,}000 = 26{,}030{,}000$円
- 貸倒引当金：期末の修正額 10,000円のうち 8,000円は開始仕訳で済んでいるので、当期は差額 2,000円だけ繰入を減らします。連結 B/S の貸倒引当金は $120{,}000 + 50{,}000 - 10{,}000 = 160{,}000$円です。
- 土地：$9{,}000{,}000 + 5{,}600{,}000 - 600{,}000 = 14{,}000{,}000$円、のれん：$540{,}000 - 60{,}000 = 480{,}000$円

**3. 利益剰余金と非支配株主持分**

- 利益剰余金の当期首残高：$8{,}000{,}000 + 3{,}700{,}000 - 3{,}200{,}000 - 90{,}000 + 8{,}000 = 8{,}418{,}000$円
- 当期末残高：$8{,}418{,}000 - 1{,}500{,}000 + 4{,}942{,}000 = 11{,}860{,}000$円
- 非支配株主持分：$1{,}740{,}000 + 300{,}000 - 120{,}000 = 1{,}920{,}000$円（＝ S社の資本 9,600,000円 × 20%）

### ポイント

- ダウンストリーム（親会社から子会社への販売）の未実現利益と貸倒引当金の修正は、全額を親会社が負担します。非支配株主持分は動きません。
- 期首商品の未実現利益は、開始仕訳で利益剰余金を減らし、当期に売上原価を減らして実現させます。
- 親会社から子会社への土地の売却益は、子会社が土地を保有している限り全額を消去します。
