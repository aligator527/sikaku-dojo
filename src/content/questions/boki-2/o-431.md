予定価格・予定賃率・予定配賦率で計算した消費額（配賦額）を仕掛品・製造間接費へ振り替え、実際額との差を差異の勘定へ振り替えます。差異が借方・貸方のどちらに出るかは、各勘定の貸借の差額で判断します。

### 材料

予定消費額は $3{,}700\text{kg} \times 600 = 2{,}220{,}000$円（直接 $3{,}300 \times 600 = 1{,}980{,}000$円、間接 $400 \times 600 = 240{,}000$円）です。実際消費額は先入先出法で、月初分 500kg と当月購入分 3,200kg を払い出します。

$$500 \times 600 + 3{,}200 \times 610 = 2{,}252{,}000\text{円}$$

実際が予定より 32,000円 多いので不利差異です。仕訳は「（借）材料消費価格差異 32,000 ／（貸）材料 32,000」で、材料勘定の **貸方** に記入します。月末有高は $800\text{kg} \times 610 = 488{,}000$円 です。

### 賃金

実際消費額（要支払額）は $2{,}700{,}000 - 380{,}000 + 410{,}000 = 2{,}730{,}000$円、予定消費額は $(1{,}650 + 180) \times 1{,}500 = 2{,}745{,}000$円 です。予定のほうが 15,000円 多い有利差異なので、「（借）賃金 15,000 ／（貸）賃率差異 15,000」となり、賃金勘定の **借方** に記入します。前月の未払額は貸方の前月繰越、当月の未払額は借方の次月繰越です。

### 製造間接費

| 項目 | 金額 |
| --- | ---: |
| 予定配賦率 | $40{,}800{,}000 \div 20{,}400 = 2{,}000$円/時間 |
| 予定配賦額 | $1{,}650 \times 2{,}000 = 3{,}300{,}000$円 |
| 実際発生額 | $240{,}000 + 270{,}000 + 610{,}000 + 2{,}230{,}000 = 3{,}350{,}000$円 |
| 配賦差異 | 50,000円（不利） |

配賦不足なので「（借）製造間接費配賦差異 50,000 ／（貸）製造間接費 50,000」で、製造間接費勘定の **貸方** に記入します。間接作業分の賃金 270,000円 は製造間接費に入ります。

### 仕掛品

借方合計は $520{,}000 + 1{,}980{,}000 + 2{,}475{,}000 + 3{,}300{,}000 = 8{,}275{,}000$円 で、月末有高 640,000円 を差し引いた 7,635,000円 が完成品原価（製品へ振替）です。

### ポイント

- 不利差異（実際 ＞ 予定）は各勘定の **貸方**、有利差異（実際 ＜ 予定）は **借方** に出ます。この問題では材料と製造間接費が不利、賃金が有利です。向きは勘定の種類ではなく、予定額と実際額のどちらが大きいかで決まります。
- 仕掛品勘定に入るのは予定額（直接材料費 1,980,000円、直接労務費 2,475,000円、予定配賦額 3,300,000円）で、実際額ではありません。
- 間接材料・間接作業の消費額は、予定価格・予定賃率で製造間接費に振り替えます。
