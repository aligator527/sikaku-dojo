組別総合原価計算では、各組（製品の種類）に直接集計できる組直接費は各組の仕掛品勘定に直接記入し、複数の組に共通して発生する組間接費は、適切な配賦基準で各組に配賦します。配賦額は組間接費勘定の貸方から、各組の仕掛品勘定の借方へ振り替えます。

### 計算

| 組 | 直接作業時間 | 配賦額 |
| --- | ---: | ---: |
| A組 | 1,200時間 | 840,000 × 1,200 / 2,100 ＝ 480,000円 |
| B組 | 900時間 | 840,000 × 900 / 2,100 ＝ 360,000円 |
| 合計 | 2,100時間 | 840,000円 |

配賦率で計算すると、840,000円 ÷ 2,100時間 ＝ 400円/時間 です。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| A組仕掛品 | 480,000 | 組間接費 | 840,000 |
| B組仕掛品 | 360,000 | | |

### ポイント

- 組別総合原価計算では、組間接費を各組に配賦した後は、各組ごとに単純総合原価計算と同じ手順（月末仕掛品の評価）で完成品原価を求めます。組間接費は加工費として扱います。
- 組間接費は「組」に配賦するので、借方は製品勘定ではなく各組の仕掛品勘定です。
- 配賦基準（直接作業時間・機械作業時間など）は問題文の指示に従います。
