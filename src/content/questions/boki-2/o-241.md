のれんは、支配獲得日に子会社株式の取得原価と、子会社の純資産のうち親会社の持分との差額として生じます。支配獲得の翌年度から償却するので、当期末までに前期と当期の2年分を償却しています。

### 計算

1. 支配獲得日のS社の純資産：2,000,000 ＋ 400,000 ＋ 1,200,000 ＝ 3,600,000円
2. のれん：2,800,000 − 3,600,000 × 70％ ＝ 2,800,000 − 2,520,000 ＝ 280,000円
3. 1年分の償却額：280,000 ÷ 10年 ＝ 28,000円
4. 当期末ののれん：280,000 − 28,000 × 2年 ＝ **224,000円**

支配獲得日の投資と資本の相殺消去は次のとおりです。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 資本金 | 2,000,000 | 子会社株式 | 2,800,000 |
| 資本剰余金 | 400,000 | 非支配株主持分 | 1,080,000 |
| 利益剰余金 | 1,200,000 | | |
| のれん | 280,000 | | |

### ポイント

- 前期の償却を忘れて当期分だけ差し引くと 252,000円 となり誤答です。前期の償却は開始仕訳（のれん 28,000円 の減少と利益剰余金の減少）で引き継ぎます。
- のれんの計算に使うのは **支配獲得日** の純資産です。当期末のS社の純資産（4,200,000円）を使わないようにします。
- 当期の連結損益計算書に計上されるのれん償却は 28,000円 です。残高と償却額を取り違えないようにします。
