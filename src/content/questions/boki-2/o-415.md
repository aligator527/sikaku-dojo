貸借対照表の問題でも、決算整理仕訳を書いて当期純利益を求めないと繰越利益剰余金が決まりません。資産・負債の各科目を整理した後、収益・費用から当期純利益を計算し、試算表の繰越利益剰余金に加えます。

### 計算

| 3. 貸倒引当金 | 貸倒引当金繰入 | 99,000 | 貸倒引当金 | 99,000 |

| | | | 備品減価償却累計額 | 450,000 |
| 8. 保険料 | 前払保険料 | 320,000 | 保険料 | 320,000 |

（売上原価の仕訳は省略）

- 現金預金：$305{,}000 + (3{,}860{,}000 + 150{,}000 - 200{,}000) = 4{,}115{,}000$円
- 貸倒引当金：売掛金 $5{,}050{,}000 \times 2\% = 101{,}000$円、電子記録債権 $2{,}300{,}000 \times 2\% = 46{,}000$円（繰入 $147{,}000 - 48{,}000 = 99{,}000$円）
- 商品：$2{,}650{,}000 - 50{,}000 - 40{,}000 = 2{,}560{,}000$円
- 満期保有目的債券：償却額 $(3{,}000{,}000 - 2{,}925{,}000) \div 5 = 15{,}000$円 → $2{,}955{,}000 + 15{,}000 = 2{,}970{,}000$円（満期まで1年超なので投資有価証券）
- 建物：$20{,}000{,}000 \times 0.9 \div 30 = 600{,}000$円 → 累計額 8,400,000円
- 備品：$(3{,}200{,}000 - 1{,}400{,}000) \times 0.25 = 450{,}000$円 → 累計額 1,850,000円
- 前払保険料：12か月のうち4月〜11月の8か月分 $480{,}000 \times 8/12 = 320{,}000$円（前払費用）

**当期純利益と繰越利益剰余金**

税引前当期純利益は 5,271,000円、法人税等は $5{,}271{,}000 \times 30\% = 1{,}581{,}300$円（未払法人税等 $1{,}581{,}300 - 560{,}000 = 1{,}021{,}300$円）、当期純利益は 3,689,700円です。繰越利益剰余金は $2{,}297{,}000 + 3{,}689{,}700 = 5{,}986{,}700$円となり、資産合計と負債純資産合計はともに 39,818,000円で一致します。

### ポイント

- 売買目的有価証券は「有価証券」（流動資産）、満期日まで1年を超える満期保有目的債券は「投資有価証券」（固定資産）に表示します。
- 未払給料は「未払費用」、前払保険料は「前払費用」としてまとめて表示します。
- 当座預金の未記帳のうち、売掛金の入金は売掛金を減らすので、貸倒引当金の計算も修正後の売掛金 5,050,000円で行います。
