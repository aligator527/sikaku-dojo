製造業の財務諸表では、工場で発生した原価（製造原価）と本社で発生した費用（販売費及び一般管理費）を分けることが出発点です。製造原価は製造原価報告書で集計して当期製品製造原価を求め、それを損益計算書の売上原価の計算に引き継ぎます。

### 計算

**1. 製造間接費と配賦差異**

| 項目 | 金額 |
| --- | ---: |
| 間接材料費（6,740,000 − 6,200,000） | 540,000 |
| 間接労務費（賃金） | 1,100,000 |
| 間接労務費（退職給付費用・工場） | 360,000 |
| 間接経費（減価償却費・工場） | 1,200,000 |
| 間接経費（電力料・保険料） | 700,000 |
| 間接経費（棚卸減耗損） | 10,000 |
| 実際発生額 | 3,910,000 |
| 予定配賦額（4,300時間 × 900円） | 3,870,000 |
| 配賦差異 | △40,000（不利差異） |

材料消費高は $420{,}000 + 6{,}800{,}000 - 480{,}000 = 6{,}740{,}000$円、棚卸減耗損は $480{,}000 - 470{,}000 = 10{,}000$円です。

**2. 製造原価報告書**

- 材料費 6,740,000円、労務費 $4{,}300{,}000 + 1{,}100{,}000 + 360{,}000 = 5{,}760{,}000$円、経費 $680{,}000 + 1{,}200{,}000 + 520{,}000 + 180{,}000 + 10{,}000 = 2{,}590{,}000$円
- 実際発生額の合計 15,090,000円から不利差異 40,000円を差し引いた 15,050,000円が当期総製造費用（予定配賦による製造原価）です。検算：直接材料費 6,200,000 ＋ 直接労務費 4,300,000 ＋ 直接経費 680,000 ＋ 予定配賦額 3,870,000 ＝ 15,050,000円
- 当期製品製造原価：$860{,}000 + 15{,}050{,}000 - 940{,}000 = 14{,}970{,}000$円

**3. 損益計算書**

- 売上原価：$1{,}200{,}000 + 14{,}970{,}000 - 1{,}350{,}000 = 14{,}820{,}000$円に不利差異 40,000円を加えて 14,860,000円
- 販売費及び一般管理費：本社の給料・広告宣伝費・貸倒引当金繰入と、本社分の減価償却費 400,000円・退職給付費用 240,000円の合計 4,090,000円
- 営業利益：$22{,}500{,}000 - 14{,}860{,}000 - 4{,}090{,}000 = 3{,}550{,}000$円

### ポイント

- 減価償却費と退職給付費用は、工場分を製造原価、本社分を販売費及び一般管理費に分けます。全額を一方に入れると、製造原価と営業費用の両方がずれます。
- 不利差異（実際 ＞ 予定）は、製造原価報告書では実際発生額から差し引いて予定配賦額に直し、損益計算書では売上原価に加算します。有利差異なら符号が逆になります。
- 正常な材料の棚卸減耗損は製造間接費（経費）です。
