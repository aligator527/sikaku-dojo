個別原価計算の仕損費は、仕損の程度と対応のしかたによって計算のもとになる原価が変わります。製品がすべて仕損となり代品を製作する場合は、**旧製造指図書（#301）に集計された原価** から仕損品の評価額を差し引いた額が仕損費です。#301 の原価は仕掛品勘定から取り除き、評価額は仕損品勘定（資産）、残りを仕損費勘定に振り替えます。

### 計算

- 旧製造指図書 #301 の原価：360,000円
- 仕損品の評価額：45,000円
- 仕損費：360,000 − 45,000 ＝ 315,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 仕損品 | 45,000 | 仕掛品 | 360,000 |
| 仕損費 | 315,000 | | |

この仕損費は、その後、代品の製造指図書 #301-2 に直接経費として賦課する（仕掛品へ振り替える）か、製造間接費として各製品に配賦します。

### ポイント

| 仕損の状況 | 仕損費の計算 |
| --- | --- |
| 一部仕損で補修する | 補修指図書に集計された原価 |
| 一部仕損で代品を製作する | 代品の製造指図書に集計された原価 − 仕損品評価額 |
| すべて仕損で代品を製作する | 旧製造指図書に集計された原価 − 仕損品評価額 |

- 本問はすべて仕損なので、代品の見込原価 350,000円 は使いません。これを使うと仕損費 305,000円 となり誤りです。
- 仕損品の評価額を差し引き忘れて仕損費を 360,000円 とすると、売却できる価値まで損失にしてしまいます。
