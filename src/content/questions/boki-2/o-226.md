期首の繰越利益剰余金はマイナス（借方残高）の 900,000円 です。その他資本剰余金による欠損の填補と、別途積立金・新築積立金の取崩しで増加し、配当と利益準備金の積立てで減少し、最後に当期純利益が加わります。資本準備金の資本金への組入れは、繰越利益剰余金に影響しません。

### 計算

1. 利益準備金の積立額
   - 配当額の10分の1：500,000 × 10分の1 ＝ 50,000円
   - 上限：30,000,000 × 4分の1 − (4,000,000 ＋ 2,000,000) ＝ 1,500,000円 → 50,000円
2. 繰越利益剰余金の増減

| 事由 | 繰越利益剰余金 |
| --- | ---: |
| 当期首残高 | △900,000 |
| 欠損の填補（その他資本剰余金から） | ＋900,000 |
| 別途積立金の取崩し | ＋800,000 |
| 剰余金の配当（配当金） | △500,000 |
| 剰余金の配当（利益準備金の積立て） | △50,000 |
| 新築積立金の取崩し | ＋2,500,000 |
| 当期純利益 | ＋1,600,000 |
| 当期末残高 | **4,350,000** |

欠損の填補と積立金の取崩しの仕訳は次のとおりです。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| その他資本剰余金 | 900,000 | 繰越利益剰余金 | 900,000 |
| 別途積立金 | 800,000 | 繰越利益剰余金 | 800,000 |
| 新築積立金 | 2,500,000 | 繰越利益剰余金 | 2,500,000 |

### ポイント

- 期首残高を ＋900,000円 として計算すると、当期末残高が 6,150,000円 となり誤答です。借方残高の繰越利益剰余金はマイナスとして扱います。
- 新築積立金の取崩しは、純資産の内部で新築積立金から繰越利益剰余金へ振り替えるだけです。建物の取得原価や純資産の合計額には影響しません。
- その他資本剰余金による欠損の填補や準備金の資本金への組入れは「株主資本の計数の変動」で、株主資本の合計額は変わりません。
