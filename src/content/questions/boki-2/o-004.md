利払日の途中で社債を売却すると、次の利払日に買主が半年分の利息を全額受け取ります。そこで売主は、前回の利払日の翌日から売却日までの利息（端数利息）を売却代金とともに買主から受け取り、有価証券利息（収益）として計上します。

### 計算

1. 売却価額：2,000,000 × 99.20/100 ＝ 1,984,000円
2. 売却損益：1,984,000 − 1,960,000 ＝ 24,000円（売却益）
3. 端数利息の日数：7月1日〜9月15日 ＝ 31日 ＋ 31日 ＋ 15日 ＝ 77日
4. 端数利息：2,000,000 × 1.46％ × 77/365 ＝ 6,160円
5. 入金額：1,984,000 ＋ 6,160 ＝ 1,990,160円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 普通預金 | 1,990,160 | 売買目的有価証券 | 1,960,000 |
| | | 有価証券売却益 | 24,000 |
| | | 有価証券利息 | 6,160 |

### ポイント

- 端数利息は売却損益に含めず、**有価証券利息** として区別します。
- 日数は「前回利払日の **翌日** から売却日 **当日** まで」で数えます。6月30日を含めたり9月15日を除いたりすると1日ずれます。
- 買主側では、支払った端数利息を有価証券利息の借方に記入し、次の利払日に受け取る利息と相殺します。
