支出を資本的支出と収益的支出に分けて考えます。耐用年数を延長させる改良（資本的支出）は建物の取得原価に加え、定期修繕（収益的支出）はまず修繕引当金を取り崩し、引当金を超える部分を当期の修繕費とします。

### 計算

| 区分 | 金額 | 処理 |
| --- | ---: | --- |
| 資本的支出（改良） | 400,000 | 建物の帳簿価額に加算 |
| 収益的支出（定期修繕） | 1,100,000 | 修繕引当金 900,000 を取り崩し、超過分 200,000 は修繕費 |

- 収益的支出：1,500,000 − 400,000 ＝ 1,100,000円
- 修繕費：1,100,000 − 900,000 ＝ 200,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 建物 | 400,000 | 普通預金 | 1,500,000 |
| 修繕引当金 | 900,000 | | |
| 修繕費 | 200,000 | | |

借方・貸方の合計はともに 1,500,000円 です。

### ポイント

- 修繕引当金は収益的支出（定期修繕）のために設定したものです。資本的支出まで含めて「修繕引当金 900,000／修繕費 600,000」とする誤りや、改良分を修繕費にする誤りに注意します。
- 修繕引当金繰入は、決算で引当金を設定するときの費用科目です。修繕を実施したときには使いません。
- 数年ごとに行う大規模な修繕（船舶のドック入りなど）に備える引当金は、特別修繕引当金として区別します。
