個別の当期純利益を合計し、当期の損益に影響する連結修正（のれん償却、配当の相殺、未実現利益の消去・実現）を加減して当期純利益を求め、そこから非支配株主に帰属する当期純利益を差し引きます。売上高と売上原価の相殺、債権と債務の相殺は損益に影響しません。

### 計算

| 項目 | 金額 |
| --- | ---: |
| P社の当期純利益 ＋ S社の当期純利益 | 1,750,000 |
| のれん償却（280,000 ÷ 10年） | △28,000 |
| 受取配当金の相殺（300,000 × 70％） | △210,000 |
| 期首商品の未実現利益の実現（240,000 × 20 ÷ 120） | ＋40,000 |
| 期末商品の未実現利益の消去（360,000 × 20 ÷ 120） | △60,000 |
| 土地の未実現利益の消去 | △200,000 |
| 当期純利益 | 1,292,000 |
| 非支配株主に帰属する当期純利益（(600,000 − 200,000) × 30％） | △120,000 |
| 親会社株主に帰属する当期純利益 | **1,172,000** |

当期の損益に関係する連結修正仕訳は次のとおりです。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| のれん償却 | 28,000 | のれん | 28,000 |
| 非支配株主に帰属する当期純利益 | 180,000 | 非支配株主持分 | 180,000 |
| 受取配当金 | 210,000 | 剰余金の配当 | 300,000 |
| 非支配株主持分 | 90,000 | | |
| 商品 | 40,000 | 売上原価 | 40,000 |
| 売上原価 | 60,000 | 商品 | 60,000 |
| 固定資産売却益 | 200,000 | 土地 | 200,000 |
| 非支配株主持分 | 60,000 | 非支配株主に帰属する当期純利益 | 60,000 |

（期首商品の未実現利益は、開始仕訳「（借）利益剰余金 40,000（貸）商品 40,000」を引き継いだうえで、当期に実現したものとして売上原価を減らします。）

### ポイント

- 土地の未実現利益の非支配株主負担分を忘れて非支配株主に帰属する当期純利益を 180,000円 とすると、1,112,000円 となり誤答です。
- 受取配当金の相殺を忘れると 1,382,000円 になってしまいます。子会社からの配当は企業集団の内部取引です。
- 期首商品の未実現利益は当期に実現するので、当期の利益を **増やす** 方向に働きます。期首分も差し引くと誤ります。
