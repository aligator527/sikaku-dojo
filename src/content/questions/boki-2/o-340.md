全部原価計算と直接原価計算の営業利益の差は、棚卸資産（製品）に含まれて期間をまたぐ固定製造原価の分だけです。直接原価計算の営業利益を求めてから **固定費調整**（期末製品の固定製造原価を加え、期首製品の固定製造原価を差し引く）を行うと効率よく計算できます。

### 計算

**1. 直接原価計算の営業利益**

| 項目 | 計算 | 金額 |
| --- | --- | ---: |
| 売上高 | 3,800個 × 4,000円 | 15,200,000 |
| 変動売上原価 | 3,800個 × 1,500円 | 5,700,000 |
| 変動販売費 | 3,800個 × 200円 | 760,000 |
| 貢献利益 | | 8,740,000 |
| 固定製造原価 | | 2,400,000 |
| 固定販売費及び一般管理費 | | 2,000,000 |
| 営業利益 | | 4,340,000 |

**2. 固定費調整**

- 当期の製品1個当たり固定製造原価：2,400,000 ÷ 4,000個 ＝ 600円
- 期末製品に含まれる固定製造原価：500個 × 600円 ＝ 300,000円（すべて当期生産分）
- 期首製品に含まれる固定製造原価：150,000円
- 全部原価計算の営業利益：4,340,000 ＋ 300,000 − 150,000 ＝ **4,490,000円**

**3. 検算（全部原価計算で直接計算）**

- 売上原価：期首製品 600,000 ＋ 当期生産分 3,500個 × (1,500 ＋ 600) ＝ 600,000 ＋ 7,350,000 ＝ 7,950,000円
- 営業利益：15,200,000 − 7,950,000 − 760,000 − 2,000,000 ＝ 4,490,000円

### ポイント

- 固定費調整の式：全部原価計算の営業利益 ＝ 直接原価計算の営業利益 ＋ 期末棚卸資産の固定製造原価 − 期首棚卸資産の固定製造原価。
- 期首製品の固定製造原価は前期の単価（1個当たり 500円）で含まれています。当期の単価 600円 で 180,000円 と計算すると、営業利益が 4,460,000円 となり誤答です。
- 生産量と販売量の差（200個）× 600円 ＝ 120,000円 を足すだけの計算（4,460,000円）では、期首と期末で単価が違うことを反映できません。
