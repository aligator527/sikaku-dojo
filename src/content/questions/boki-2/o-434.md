製造原価報告書は「直接材料費 → 直接労務費 → 直接経費 → 製造間接費」の順に当期総製造費用を集計し、仕掛品の増減を加減して当期製品製造原価を求めます。予定配賦をしている場合、製造間接費は実際発生額を集計したうえで配賦差異を加減し、**予定配賦額** にそろえます。

### 計算

| 項目 | 計算 | 金額 |
| --- | --- | ---: |
| 直接材料費 | $320{,}000 + 4{,}680{,}000 - 380{,}000$ | 4,620,000 |
| 直接工の消費賃金 | $3{,}920{,}000 - 280{,}000 + 320{,}000$ | 3,960,000 |
| 直接労務費 | $3{,}960{,}000 - 330{,}000$ | 3,630,000 |
| 間接材料費 | $45{,}000 + 610{,}000 - 52{,}000$ | 603,000 |
| 間接労務費 | $330{,}000 + 1{,}240{,}000 + 860{,}000$ | 2,430,000 |
| 間接経費 | $1{,}200{,}000 + 690{,}000 + 280{,}000 + 150{,}000$ | 2,320,000 |
| 製造間接費（実際） | $603{,}000 + 2{,}430{,}000 + 2{,}320{,}000$ | 5,353,000 |
| 予定配賦額 | $1{,}600 \times 3{,}300$ | 5,280,000 |

実際 5,353,000円 に対して予定配賦額は 5,280,000円 なので、73,000円 の配賦不足（不利差異）です。製造原価報告書では実際額から △73,000円 を差し引いて 5,280,000円 とします。外注加工賃は製品ごとに直接把握できる直接経費です。

- 当期総製造費用：$4{,}620{,}000 + 3{,}630{,}000 + 540{,}000 + 5{,}280{,}000 = 14{,}070{,}000$円
- 当期製品製造原価：$14{,}070{,}000 + 860{,}000 - 940{,}000 = 13{,}990{,}000$円

### 損益計算書

製品の増減を加減した 13,800,000円 に、不利差異 73,000円 を **加算** して売上原価 13,873,000円 とします。売上総利益は $21{,}500{,}000 - 13{,}873{,}000 = 7{,}627{,}000$円 です。

### ポイント

- 不利差異（配賦不足）は、製造原価報告書では減算、売上原価では加算します。仕掛品・製品には予定配賦額しか入っていないので、足りない分を売上原価で補うと考えます。
- 直接工の賃金のうち間接作業分は間接労務費です。直接労務費に含めないようにします。
- 当期製品製造原価は損益計算書の「当期製品製造原価」にそのまま写します。
