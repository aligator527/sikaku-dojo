剰余金の配当を行うときは、資本準備金と利益準備金の合計額が資本金の4分の1に達するまで、配当額の10分の1を準備金として積み立てます。2つの基準のうち **小さいほう** が積立額になります。

### 計算

1. 配当額の10分の1：3,000,000 × 10分の1 ＝ 300,000円
2. 積立ての上限：40,000,000 × 4分の1 − (6,500,000 ＋ 3,300,000) ＝ 10,000,000 − 9,800,000 ＝ 200,000円
3. 利益準備金の積立額：300,000円 と 200,000円 の小さいほう ＝ 200,000円
4. 繰越利益剰余金の減少額：3,000,000 ＋ 200,000 ＋ 500,000 ＝ 3,700,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 繰越利益剰余金 | 3,700,000 | 未払配当金 | 3,000,000 |
| | | 利益準備金 | 200,000 |
| | | 別途積立金 | 500,000 |

### ポイント

- 上限を確かめずに配当額の10分の1（300,000円）を積み立てるのが典型的な誤りです。上限の計算では、利益準備金だけでなく資本準備金も合計します。
- 配当金は株主総会の決議時点ではまだ支払っていないので、未払配当金（負債）とします。支払ったときに「（借）未払配当金（貸）普通預金」と処理します。
- 繰越利益剰余金を財源とする配当で積み立てるのは利益準備金、その他資本剰余金を財源とする配当で積み立てるのは資本準備金です。
