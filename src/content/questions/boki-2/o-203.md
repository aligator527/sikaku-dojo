退職一時金は、在職中に退職給付引当金として積み上げてきた負債の支払いなので、支給額の全額について退職給付引当金を取り崩します。一方、企業年金基金からの年金は、基金が積み立てた年金資産から支払われるもので、当社のお金は動かないため仕訳は不要です。

### 計算

| 支払の内容 | 当社の処理 |
| --- | --- |
| 退職一時金 4,200,000円（当社が支払う） | 退職給付引当金を 4,200,000円 取り崩す |
| 企業年金 1,500,000円（基金が支払う） | 仕訳なし |

- 所得税預り金：210,000円
- 普通預金からの支払額：4,200,000 − 210,000 ＝ 3,990,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 退職給付引当金 | 4,200,000 | 所得税預り金 | 210,000 |
| | | 普通預金 | 3,990,000 |

借方・貸方の合計はともに 4,200,000円 です。

### ポイント

- 基金からの年金 1,500,000円 まで退職給付引当金の取崩しに含めると、当社が支払っていない金額を減らすことになり誤りです。年金資産と退職給付債務が同額ずつ減るだけなので、当社の帳簿上の退職給付引当金は変わりません。
- 当社が企業年金基金に掛金を拠出したときは、「（借）退職給付引当金（貸）普通預金など」と処理します。拠出と基金からの支給を混同しないようにします。
- 退職一時金の支払いを退職給付費用とする誤りにも注意します。退職給付費用は、決算などで引当金を繰り入れるときの費用科目です。
