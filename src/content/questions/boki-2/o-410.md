利子抜き法では、リース料総額から利息相当額を除いた金額で使用権資産とリース負債を計上し、リース料を支払うたびに「リース負債の返済」と「支払利息」に分けます。利息相当額は定額法なので、毎年同じ額を配分します。

### 計算

**リースA**（前期首に開始、5年）

- 利息相当額：$600{,}000 \times 5 - 2{,}700{,}000 = 300{,}000$円 → 年 60,000円
- 1回の返済額：$600{,}000 - 60{,}000 = 540{,}000$円
- 期首のリース負債：$2{,}700{,}000 - 540{,}000 = 2{,}160{,}000$円（前期に1回支払済み）
- 減価償却費：$2{,}700{,}000 \div 5 = 540{,}000$円（期首の累計額も1年分の 540,000円）

**リースB**（当期の10月に開始、4年）

- 利息相当額：$360{,}000 \times 4 - 1{,}320{,}000 = 120{,}000$円 → 年 30,000円
- 当期の未払利息（10月〜3月）：$30{,}000 \times 6/12 = 15{,}000$円
- 減価償却費：$1{,}320{,}000 \div 4 \times 6/12 = 165{,}000$円

**仕訳**

| 日付 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 10/1 | 使用権資産 | 1,320,000 | リース負債 | 1,320,000 |
| 3/31 | リース負債 | 540,000 | 普通預金 | 600,000 |
| | 支払利息 | 60,000 | | |
| 3/31 | 支払利息 | 15,000 | 未払利息 | 15,000 |
| 3/31 | 減価償却費 | 705,000 | 使用権資産減価償却累計額 | 705,000 |

- リース負債の次期繰越：$2{,}160{,}000 + 1{,}320{,}000 - 540{,}000 = 2{,}940{,}000$円
- 累計額の次期繰越：$540{,}000 + 705{,}000 = 1{,}245{,}000$円
- 支払利息の損益への振替：$60{,}000 + 15{,}000 = 75{,}000$円

### ポイント

- 未払利息はリース負債に加えず、未払利息（未払費用）で計上します。リース負債が減るのはリース料を支払ったときだけです。
- 3/31 の支払いの仕訳は貸方が普通預金だけなので、リース負債勘定と支払利息勘定の摘要はどちらも「普通預金」です。
- 短期リースの賃借料は支払リース料で処理するので、ここに示した4つの勘定には記入しません。
