直接配賦法は、補助部門どうしのサービスのやり取りを無視し、補助部門費を **製造部門だけ** に配賦する方法です。配賦基準の数値も製造部門の分だけを使って配賦割合を計算します。

### 計算

| 補助部門 | 配賦基準（製造部門分） | 切削部へ | 組立部へ |
| --- | --- | ---: | ---: |
| 動力部 360,000円 | 6,000kWh : 3,000kWh | 240,000円 | 120,000円 |
| 修繕部 240,000円 | 120時間 : 80時間 | 144,000円 | 96,000円 |
| 工場事務部 180,000円 | 30人 : 45人 | 72,000円 | 108,000円 |
| 合計 780,000円 | | 456,000円 | 324,000円 |

- 動力部：360,000 × 6,000 / 9,000 ＝ 240,000円、360,000 × 3,000 / 9,000 ＝ 120,000円
- 修繕部：240,000 × 120 / 200 ＝ 144,000円、240,000 × 80 / 200 ＝ 96,000円
- 工場事務部：180,000 × 30 / 75 ＝ 72,000円、180,000 × 45 / 75 ＝ 108,000円

| --- | ---: | --- | ---: |
| 切削部門費 | 456,000 | 動力部門費 | 360,000 |
| 組立部門費 | 324,000 | 修繕部門費 | 240,000 |
| | | 工場事務部門費 | 180,000 |

### ポイント

- 直接配賦法では、修繕部の動力消費量 1,000kWh や動力部の修繕時間 50時間 は使いません。分母に含めると（動力部なら 10,000kWh で割ると）補助部門費が配賦しきれずに残ってしまいます。
- 配賦後、補助部門費の各勘定の残高はゼロになります。貸方の合計（780,000円）と借方の合計が一致するかで検算できます。
- 補助部門間の配賦も考慮する方法が相互配賦法です。2級の相互配賦法は、第1次配賦で補助部門間にも配賦し、第2次配賦は直接配賦法で行う簡便な方法です。
