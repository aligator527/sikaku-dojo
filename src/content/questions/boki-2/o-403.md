連結修正仕訳を先に書き出し、精算表の修正・消去欄に転記してから、行ごとに「P社 ＋ S社 ± 修正・消去」で連結の金額を求めます。損益計算書の利益と株主資本等変動計算書の期末残高は、上の行から順に集計して、貸借対照表の純資産の行に移します。

### 計算

| 連結修正仕訳 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 1. 開始仕訳（資本連結） | 資本金当期首残高 | 4,000,000 | S社株式 | 5,600,000 |
| | 利益剰余金当期首残高 | 2,000,000 | 非支配株主持分当期首残高 | 1,800,000 |
| | のれん | 1,400,000 | | |
| 2. のれんの償却 | のれん償却 | 140,000 | のれん | 140,000 |
| 3. 子会社の利益の配分 | 非支配株主に帰属する当期純利益 | 300,000 | 非支配株主持分当期変動額 | 300,000 |
| 4. 子会社の配当 | 受取配当金 | 280,000 | 配当金 | 400,000 |
| | 非支配株主持分当期変動額 | 120,000 | | |
| 5. 内部取引 | 売上高 | 3,000,000 | 売上原価 | 3,000,000 |
| 6. 未実現利益 | 売上原価 | 120,000 | 商品 | 120,000 |
| 7. 債権債務 | 買掛金 | 500,000 | 売掛金 | 500,000 |
| 8. 貸付金と利息 | 借入金 | 1,000,000 | 貸付金 | 1,000,000 |
| | 受取利息 | 20,000 | 支払利息 | 20,000 |

- 非支配株主持分（当期首）：$6{,}000{,}000 \times 30\% = 1{,}800{,}000$円
- のれん：$5{,}600{,}000 - 6{,}000{,}000 \times 70\% = 1{,}400{,}000$円、償却 $1{,}400{,}000 \div 10 = 140{,}000$円
- 非支配株主に帰属する当期純利益：$1{,}000{,}000 \times 30\% = 300{,}000$円
- 未実現利益：$600{,}000 \times \frac{0.25}{1.25} = 120{,}000$円（ダウンストリームなので全額を親会社が負担）

連結上の当期純利益は 1,960,000円、そのうち非支配株主に帰属する 300,000円を引いた 1,660,000円が親会社株主に帰属する当期純利益です。検算として、P社の利益 1,500,000円から受取配当金 280,000円を除き、S社の利益の70%（700,000円）を加え、のれん償却 140,000円と未実現利益 120,000円を引いても 1,660,000円になります。

利益剰余金の当期末残高は $5{,}480{,}000 - 800{,}000 + 1{,}660{,}000 = 6{,}340{,}000$円、非支配株主持分は $1{,}800{,}000 + 300{,}000 - 120{,}000 = 1{,}980{,}000$円で、資産合計と負債純資産合計はともに 26,270,000円で一致します。

### ポイント

- 原価に25%を加算した販売価格に含まれる利益は「売価 × 0.25 ÷ 1.25」です。600,000 × 25% ＝ 150,000円とするのは誤りです。
- S社の配当のうち親会社分は受取配当金と相殺し、非支配株主分は非支配株主持分を減らします。連結の配当金は P社の 800,000円だけが残ります。
- S社株式と受取配当金（S社からの分）は、連結財務諸表には残りません。
