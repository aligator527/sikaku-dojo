部門別計算では、製造部門ごとに予定配賦率を設定し、それぞれの部門の配賦基準（切削部は機械作業時間、組立部は直接作業時間）で製造指図書に配賦します。配賦額は各製造部門費勘定の貸方から仕掛品勘定の借方へ振り替えます。

### 計算

1. 切削部の予定配賦率：14,400,000円 ÷ 18,000時間 ＝ 800円/時間
2. 組立部の予定配賦率：12,960,000円 ÷ 21,600時間 ＝ 600円/時間
3. 当月の予定配賦額

| 部門 | 実際操業度（#501 ＋ #502 ＋ #503） | 予定配賦額 |
| --- | --- | ---: |
| 切削部 | 700 ＋ 500 ＋ 300 ＝ 1,500時間 × 800円 | 1,200,000円 |
| 組立部 | 800 ＋ 600 ＋ 400 ＝ 1,800時間 × 600円 | 1,080,000円 |
| 合計 | | 2,280,000円 |

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 仕掛品 | 2,280,000 | 切削部門費 | 1,200,000 |
| | | 組立部門費 | 1,080,000 |

### ポイント

- 部門別に予定配賦するときは、貸方は製造間接費ではなく **各製造部門費** の勘定です。
- 補助部門（動力部など）の費用はすでに製造部門費の予算に含まれているので、補助部門費を直接製品に配賦することはありません。
- 製造指図書別の配賦額（#501 は 700 × 800 ＋ 800 × 600 ＝ 1,040,000円 など）を合計しても同じ金額になります。
