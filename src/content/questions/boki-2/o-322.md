正常仕損が工程の終点で発生しているので、月末仕掛品（進捗度 50％）は仕損の発生点を通過していません。したがって正常仕損費は **完成品のみ** が負担します。度外視法では、仕損品を完成品と同じように扱って月末仕掛品を評価し、残りの原価（仕損費を含む）を完成品原価とします。仕損品の評価額は完成品原価から差し引きます。

### 計算

**直接材料費**（先入先出法、始点投入）

| 借方 | 数量 | 金額 | 貸方 | 数量 | 金額 |
| --- | ---: | ---: | --- | ---: | ---: |
| 月初仕掛品 | 400個 | 190,000 | 完成品 | 2,900個 | 1,438,000 |
| 当月投入 | 3,000個 | 1,440,000 | 正常仕損 | 100個 | （完成品に含める） |
| | | | 月末仕掛品 | 400個 | 192,000 |
| 合計 | 3,400個 | 1,630,000 | 合計 | 3,400個 | 1,630,000 |

- 当月投入分の単価：1,440,000 ÷ 3,000個 ＝ 480円
- 月末仕掛品：400個 × 480円 ＝ 192,000円

**加工費**

| 借方 | 換算量 | 金額 | 貸方 | 換算量 | 金額 |
| --- | ---: | ---: | --- | ---: | ---: |
| 月初仕掛品 | 240個 | 145,000 | 完成品 | 2,900個 | 2,215,000 |
| 当月投入 | 2,960個 | 2,220,000 | 正常仕損 | 100個 | （完成品に含める） |
| | | | 月末仕掛品 | 200個 | 150,000 |
| 合計 | 3,200個 | 2,365,000 | 合計 | 3,200個 | 2,365,000 |

- 当月投入の換算量：完成品 2,900 ＋ 正常仕損 100 ＋ 月末 200 − 月初 240 ＝ 2,960個
- 当月投入分の単価：2,220,000 ÷ 2,960個 ＝ 750円
- 月末仕掛品：200個 × 750円 ＝ 150,000円

**完成品総合原価**

- 正常仕損費を含む完成品原価：1,438,000 ＋ 2,215,000 ＝ 3,653,000円
- 仕損品評価額の控除：3,653,000 − 20,000 ＝ **3,633,000円**

### ポイント

- 仕損の発生点（終点）が月末仕掛品の進捗度（50％）より後なので、完成品のみ負担です。仕損の発生点が月末仕掛品の進捗度以前なら、両者負担になります。
- 先入先出法の当月投入量には正常仕損の数量も含めます。仕損 100個 を除いて 2,900個 で割ると単価がずれます。
- 仕損品の評価額を差し引き忘れると 3,653,000円 となり誤答です。
