200%定率法では、期首の帳簿価額（取得原価 − 減価償却累計額）に償却率を掛けて減価償却費を求めます。まず期首までの累計額を年度ごとに計算し、次に売却・取得の仕訳を考えて、相手勘定を摘要に書きます。

### 計算

**期首までの減価償却累計額**

| 備品 | 1年目 | 2年目 | 期首の累計額 | 期首の帳簿価額 |
| --- | ---: | ---: | ---: | ---: |
| A（X1年4月） | 1,500,000 × 0.4 ＝ 600,000 | 900,000 × 0.4 ＝ 360,000 | 960,000 | 540,000 |
| B（X2年10月） | 800,000 × 0.4 × 6/12 ＝ 160,000 | ― | 160,000 | 640,000 |

期首の累計額は $960{,}000 + 160{,}000 = 1{,}120{,}000$円です。調整前償却額は、いずれも償却保証額（A：$1{,}500{,}000 \times 0.108 = 162{,}000$円、B：86,400円）を上回るので、償却率 0.400 のまま計算します。

**7/31 備品A の売却**

- 当期の減価償却費（4か月）：$540{,}000 \times 0.4 \times 4/12 = 72{,}000$円
- 売却時の帳簿価額：$540{,}000 - 72{,}000 = 468{,}000$円 → 売却損 $468{,}000 - 300{,}000 = 168{,}000$円

| 借方 | | 貸方 | |
| --- | ---: | --- | ---: |
| 備品減価償却累計額 | 960,000 | 備品 | 1,500,000 |
| 減価償却費 | 72,000 | | |
| 普通預金 | 300,000 | | |
| 固定資産売却損 | 168,000 | | |

備品勘定の貸方は相手勘定が複数なので「諸口」、累計額勘定と減価償却費勘定の借方は相手勘定が備品だけなので「備品」と書きます。

**3/31 決算の減価償却**

- 備品B：$640{,}000 \times 0.4 = 256{,}000$円
- 備品C：$1{,}200{,}000 \times 0.4 \times 4/12 = 160{,}000$円（12月〜3月）
- 合計 416,000円 →「（借）減価償却費 416,000 ／（貸）備品減価償却累計額 416,000」

**締切り**

- 備品の次期繰越：$800{,}000 + 1{,}200{,}000 = 2{,}000{,}000$円
- 累計額の次期繰越：$1{,}120{,}000 - 960{,}000 + 416{,}000 = 576{,}000$円
- 減価償却費の損益への振替：$72{,}000 + 416{,}000 = 488{,}000$円

### ポイント

- 定率法は「期首の帳簿価額 × 償却率」です。取得原価に償却率を掛けるのは初年度だけです。
- 売却した備品の当期分の減価償却費（72,000円）も減価償却費勘定に記入し、損益へ振り替える金額に含めます。
- 期中取得の備品C は、使用を開始した月から決算月までの4か月分だけ償却します。
