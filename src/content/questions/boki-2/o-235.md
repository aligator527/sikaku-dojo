営業利益は「売上総利益 − 販売費及び一般管理費」です。棚卸減耗損と商品評価損は指示により売上原価に含め、使用権資産の減価償却費は他の有形固定資産と同じく販売費及び一般管理費に含めます。リース料に含まれる利息（支払利息）は営業外費用なので、営業利益には影響しません。

### 計算

1. 売上原価
   - 1,200,000 ＋ 18,500,000 − 1,350,000 ＝ 18,350,000円
   - 棚卸減耗損：1,350,000 − 1,320,000 ＝ 30,000円
   - 商品評価損：1,320,000 − 1,275,000 ＝ 45,000円
   - 売上原価：18,350,000 ＋ 30,000 ＋ 45,000 ＝ 18,425,000円
2. 売上総利益：28,000,000 − 18,425,000 ＝ 9,575,000円
3. 販売費及び一般管理費

| 科目 | 計算 | 金額 |
| --- | --- | ---: |
| 給料 | | 4,200,000 |
| 支払リース料 | 短期リースの賃借料 | 960,000 |
| 保険料 | 480,000 − 120,000 | 360,000 |
| 水道光熱費 | | 545,000 |
| 貸倒引当金繰入 | (2,600,000 ＋ 1,400,000) × 1％ − 30,000 | 10,000 |
| 減価償却費 | 建物 400,000 ＋ 備品 450,000 ＋ 使用権資産 360,000 | 1,210,000 |
| 退職給付費用 | | 350,000 |
| 合計 | | 7,635,000 |

- 建物：12,000,000 ÷ 30年 ＝ 400,000円
- 備品：(2,400,000 − 600,000) × 25％ ＝ 450,000円
- 使用権資産：1,800,000 ÷ 5年 ＝ 360,000円

4. 営業利益：9,575,000 − 7,635,000 ＝ **1,940,000円**

リース料の支払い（仮払金）の整理は次のとおりで、支払利息 40,000円 は営業外費用です。

| --- | ---: | --- | ---: |
| リース負債 | 360,000 | 仮払金 | 400,000 |

### ポイント

- 使用権資産の減価償却を忘れると 2,300,000円、備品の定率法を取得原価に掛けると 1,790,000円 となり誤答です。
- 2027年度適用の出題区分表では、借手のリースは企業会計基準第34号にもとづき **使用権資産・リース負債** で計上します（従来のリース資産・リース債務に代わる科目）。利子抜き法では、リース料 400,000円 を利息 40,000円（200,000 ÷ 5年）とリース負債の返済 360,000円 に分けます。
- 短期リース・少額リースは賃貸借処理が認められ、2級では不動産の賃借料も支払家賃ではなく支払リース料で処理します。
