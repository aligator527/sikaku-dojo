  ある店の会員の 1 か月の来店回数 $N$ について、会員ごとに来店のしやすさ $\Lambda$ が異なると考え、次の階層モデルをおく。

  - $\Lambda = \lambda$ が与えられたとき、$N$ の条件付き分布はポアソン分布 $Po(\lambda)$
  - $\Lambda$ は形状母数 2、尺度母数 1.5 のガンマ分布（確率密度関数 $f(\lambda) = \dfrac{\lambda e^{-\lambda/1.5}}{1.5^2}$、$\lambda > 0$）に従う

  $N$ の周辺分布と分散 $V[N]$ について、正しいものを次のうちから一つ選べ。
choices:

  - '負の二項分布に従い、$V[N] = 3$'
  - '負の二項分布に従い、$V[N] = 4.5$'
  - '負の二項分布に従い、$V[N] = 7.5$'
  - '負の二項分布に従い、$V[N] = 16.5$'

ポアソン分布の平均がガンマ分布に従ってばらつくと、周辺分布は負の二項分布になります。分散は全分散の公式から $V[N] = E[\Lambda] + V[\Lambda] = 3 + 4.5 = 7.5$ で、平均 3 より大きくなります（過分散）。

### 計算

ガンマ分布（形状 $k = 2$、尺度 $\theta = 1.5$）より $E[\Lambda] = k\theta = 3$、$V[\Lambda] = k\theta^2 = 4.5$ です。

$$E[N] = E\left[E[N \mid \Lambda]\right] = E[\Lambda] = 3$$

$$V[N] = E\left[V[N \mid \Lambda]\right] + V\left[E[N \mid \Lambda]\right] = E[\Lambda] + V[\Lambda] = 3 + 4.5 = 7.5$$

周辺確率関数は、$1 + 1/1.5 = 1/0.6$ に注意して

$$P(N = n) = \int_0^\infty \frac{e^{-\lambda}\lambda^n}{n!}\cdot\frac{\lambda e^{-\lambda/1.5}}{1.5^2}\,d\lambda = \frac{1}{n!\,1.5^2}\int_0^\infty \lambda^{n+1}e^{-\lambda/0.6}\,d\lambda = \frac{(n+1)!\,0.6^{n+2}}{n!\,1.5^2}$$

$$= (n+1) \times 0.4^2 \times 0.6^n\qquad (n = 0, 1, 2, \ldots)$$

これは「成功確率 0.4 の試行で 2 回目の成功までの失敗回数」の負の二項分布で、平均 $2 \times 0.6/0.4 = 3$、分散 $2 \times 0.6/0.4^2 = 7.5$ と一致します。

### 各選択肢の検討

- ①：$\Lambda$ を平均 3 に固定した場合の分布です。会員間のばらつき $V[\Lambda]$ を無視しています。
- ②：分布は正しいものの、分散を $E\left[V[N \mid \Lambda]\right] = 3$ だけにしています。
- ③：$V\left[E[N \mid \Lambda]\right] = V[\Lambda] = 4.5$ だけで、ポアソン分布自体のばらつきを落としています。
- ④：正しい。
- ⑤：$V[\Lambda]$ の代わりに $E[\Lambda^2] = 4.5 + 9 = 13.5$ を足しています。

### ポイント

- ポアソン・ガンマ混合は負の二項分布。カウントデータで分散が平均より明らかに大きいとき、ポアソン回帰の代わりに負の二項回帰を使う根拠になる。
- $P(N = 0) = E[e^{-\Lambda}] = (1 + \theta)^{-k} = 2.5^{-2} = 0.16$（ガンマ分布の積率母関数を $t = -1$ で評価）。
- ベイズ的には、ガンマ分布はポアソン分布の共役事前分布で、$N = n$ を観測した後の $\Lambda$ の事後分布は形状 $2 + n$、尺度 $0.6$ のガンマ分布。
