最短距離法はクラスター間の最も近い対象どうしの距離で併合するので、近い対象が鎖のようにつながると 1 つのクラスターに次々と取り込みます（連鎖効果）。この例では A–B–C–D–E が 2.0〜2.7 の間隔で並んでいるため、最後に E だけが残ります。最長距離法は最も遠い対象どうしの距離を使うので、まとまりのよい $\{A, B\}$ と $\{C, D, E\}$ に分かれます。

### 計算

**最短距離法**

1. 最小の距離 2.0 で A と B を併合。
2. $d(\{A,B\}, C) = \min(4.2,\ 2.2) = 2.2$ が最小なので、C を併合。
3. $d(\{A,B,C\}, D) = \min(6.6,\ 4.6,\ 2.4) = 2.4$ で D を併合。
4. 最後に E を距離 2.7 で併合。2 クラスターの段階は $\{A, B, C, D\}, \{E\}$。

**最長距離法**

1. 2.0 で A と B を併合。
2. $d(\{A,B\}, C) = \max(4.2,\ 2.2) = 4.2$ より $d(C, D) = 2.4$ が小さいので、C と D を併合。
3. $d(\{C,D\}, E) = \max(5.1,\ 2.7) = 5.1$、$d(\{A,B\}, \{C,D\}) = \max(4.2,\ 6.6,\ 2.2,\ 4.6) = 6.6$、$d(\{A,B\}, E) = 9.3$ なので、$\{C, D\}$ と E を 5.1 で併合。
4. 2 クラスターの段階は $\{A, B\}, \{C, D, E\}$。

### 各選択肢の検討

- ①：2 つの方法の結果を入れ替えています。
- ②・④：2 つの方法は併合の基準が異なり、この例では異なる分割になります。
- ③：正しい。
- ⑤：どちらの方法でも、$\{A, B, C\}$ と $\{D, E\}$ に分かれる段階は現れません。

### ポイント

- 最短距離法は連鎖効果で細長いクラスターを作りやすい。最長距離法はコンパクトなクラスターを作りやすい。
- 群平均法でも $d(\{C,D\}, E) = (5.1 + 2.7)/2 = 3.9 < d(\{A,B\}, \{C,D\}) = 4.4$ となり、最長距離法と同じ分割になる。
