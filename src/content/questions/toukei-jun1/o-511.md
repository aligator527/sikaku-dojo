まず密度を積分して累積分布関数 $F(x) = 1 - (1 + x)^{-2}$ を求め、$F(x) = u$ を $x$ について解きます。$x = (1 - u)^{-1/2} - 1$ なので、$u = 0.84$ では $x = 1/\sqrt{0.16} - 1 = 2.5 - 1 = 1.5$ です。

### 計算

$$F(x) = \int_0^x \frac{2}{(1 + t)^3}\,dt = \left[-\frac{1}{(1 + t)^2}\right]_0^x = 1 - \frac{1}{(1 + x)^2}$$

$F(x) = u$ を解くと

$$(1 + x)^2 = \frac{1}{1 - u} \;\Rightarrow\; x = \frac{1}{\sqrt{1 - u}} - 1$$

$$u = 0.84:\quad x = \frac{1}{\sqrt{0.16}} - 1 = \frac{1}{0.4} - 1 = 1.5$$

検算：$F(1.5) = 1 - 1/2.5^2 = 1 - 0.16 = 0.84$。

### 逆関数法が正しい理由

$U \sim U(0, 1)$ のとき、$F$ が狭義単調増加なら

$$P\!\left(F^{-1}(U) \leq x\right) = P\!\left(U \leq F(x)\right) = F(x)$$

なので、$X = F^{-1}(U)$ は累積分布関数 $F$ をもちます。

### ポイント

- $1 - U$ も一様分布に従うので、$X = U^{-1/2} - 1$ としても同じ分布の乱数が得られる。ただし、この問題のように「$x = F^{-1}(u)$」と指定された場合は $u = 0.84$ から $1.5$ が得られる（$U^{-1/2} - 1$ なら約 $0.091$）。
- よくある誤り：密度 $f(x) = u$ を解く、$F$ の計算で $(1 + x)^{-2}$ の係数を誤る、$\sqrt{1 - u}$ の平方根を忘れて $1/0.16 - 1 = 5.25$ とする。
- 指数分布 $F(x) = 1 - e^{-\lambda x}$ なら $X = -\log(1 - U)/\lambda$。累積分布関数の逆関数が陽に書けない正規分布などには、ボックス・ミュラー法や採択・棄却法を使う。
