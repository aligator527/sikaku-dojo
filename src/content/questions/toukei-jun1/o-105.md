$N = n$ を与えたときの $Y$ の条件付き分布は二項分布 $B(n,\ 0.3)$ ですが、$N$ について平均すると $Y$ の周辺分布はポアソン分布 $Po(10 \times 0.3) = Po(3)$ になります（ポアソン分布の間引き）。共分散は $\mathrm{Cov}(N,\ Y) = 0.3\,V[N] = 3$ なので、相関係数は $3/\sqrt{10 \times 3} = \sqrt{0.3} \approx 0.548$ です。

### 計算

**$Y$ の分布**：確率母関数を使います。$E[s^Y \mid N] = (0.7 + 0.3s)^N$ なので

$$G_Y(s) = E\left[(0.7 + 0.3s)^N\right] = G_N(0.7 + 0.3s) = e^{10\{(0.7 + 0.3s) - 1\}} = e^{3(s - 1)}$$

これは $Po(3)$ の確率母関数です。

**共分散**：条件付き期待値 $E[Y \mid N] = 0.3N$ を使うと

$$E[NY] = E\left[N\,E[Y \mid N]\right] = 0.3\,E[N^2]$$

$$\mathrm{Cov}(N,\ Y) = 0.3\,E[N^2] - E[N] \times 0.3\,E[N] = 0.3\,V[N] = 0.3 \times 10 = 3$$

**相関係数**：$V[N] = 10$、$V[Y] = 3$ なので

$$\rho = \frac{3}{\sqrt{10 \times 3}} = \sqrt{0.3} \approx 0.548$$

### 各選択肢の検討

- ①：独立になるのは購入者数 $Y$ と非購入者数 $N - Y$ です（ポアソン分布の分解）。$N$ と $Y$ は、$N$ が多い日ほど $Y$ も多くなるので正の相関をもちます。実際 $\mathrm{Cov}(N,\ Y) = \mathrm{Cov}(Y + (N - Y),\ Y) = V[Y] = 3$ です。
- ②：購入確率 $0.3$ を相関係数としています。$0.3$ は $Y$ を $N$ に回帰したときの傾き $\mathrm{Cov}(N, Y)/V[N]$ で、相関係数ではありません。
- ③：正しい。
- ④・⑤：$B(10,\ 0.3)$ は客数がちょうど 10 人の日の条件付き分布です。客数自体がばらつくので、周辺分布はポアソン分布になります（$B(10,\ 0.3)$ の分散は $2.1$ ですが、実際の $V[Y]$ は $3$ です）。

### ポイント

- 間引き：$N \sim Po(\lambda)$ の各個体を独立に確率 $p$ で選ぶと、選ばれた数は $Po(\lambda p)$、選ばれなかった数は $Po(\lambda(1-p))$ に従い、両者は独立。
- $\mathrm{Cov}(X,\ Y) = \mathrm{Cov}(X,\ E[Y \mid X])$。条件付き期待値が $X$ の 1 次式なら共分散はすぐに求まる。
