操作変数が 2 値のときの推定量（ワルド推定量）は「$Z$ が $Y$ に与える効果」を「$Z$ が $T$ に与える効果」で割ったもので、単調性などの仮定のもとで complier における平均因果効果（LATE）を推定します。$(71.2 - 68.4)/(0.65 - 0.15) = 2.8/0.5 = 5.6$ です。

### 計算

$$\text{ITT（案内状の効果）} = E[Y \mid Z = 1] - E[Y \mid Z = 0] = 71.2 - 68.4 = 2.8$$

$$\text{参加率の差（complier の割合）} = P(T = 1 \mid Z = 1) - P(T = 1 \mid Z = 0) = 0.65 - 0.15 = 0.50$$

$$\widehat{\mathrm{LATE}} = \frac{2.8}{0.50} = 5.6$$

### なぜ割り算になるのか

住民を、案内状の有無で参加行動が変わる complier（全体の 50%）、常に参加する always-taker（15%）、常に参加しない never-taker（35%）に分けます（単調性により、案内状で参加をやめる defier はいない）。除外制約（案内状は参加を通じてのみ $Y$ に影響する）のもとでは、always-taker と never-taker の $Y$ は $Z$ によって変わりません。したがって ITT の 2.8 はすべて complier から生じ、$2.8 = 0.50 \times (\text{complier での効果})$ となります。

### ポイント

- 操作変数の条件：(1) $Z$ が $T$ に影響する（関連性）、(2) $Z$ は $T$ を通じてのみ $Y$ に影響する（除外制約）、(3) $Z$ と $Y$ の間に共通原因がない（ここでは無作為化で保証）。
- よくある誤り：ITT の 2.8 を処置効果とする（参加しない人を含むので薄まる）、参加者と非参加者を直接比べる（自ら参加する人は健康意識が高いなど、交絡がある）。
- 参加率の差（第 1 段階）が小さいと推定値が不安定になる（弱い操作変数の問題）。
