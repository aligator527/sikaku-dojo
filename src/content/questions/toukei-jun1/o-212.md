  $X_1, \ldots, X_9$ を正規分布 $N(\mu, \sigma^2)$（$\mu,\ \sigma^2$ ともに未知）からの無作為標本とし、偏差平方和を $Q = \sum_{i=1}^{9}(X_i - \bar X)^2$ とする。$\sigma^2$ の推定量として、$T_c = Q/c$（$c > 0$ は定数）の形のものを考える。

  平均二乗誤差 $E[(T_c - \sigma^2)^2]$ を最小にする $c$ と、そのときの平均二乗誤差の組合せとして、正しいものを次のうちから一つ選べ。

$Q/\sigma^2 \sim \chi^2(n - 1)$ を使うと、$T_c$ のバイアスと分散がともに $c$ の式で書けます。平均二乗誤差 $=$ 分散 $+$ バイアス$^2$ を $c$ について最小化すると $c = n + 1 = 10$ となり、そのときの値は $2\sigma^4/(n + 1) = 0.2\sigma^4$ です。不偏分散（$c = n - 1$）は、平均二乗誤差の意味では最良ではありません。

### 計算

$n = 9$ で $Q/\sigma^2 \sim \chi^2(8)$ より、$E[Q] = 8\sigma^2$、$V[Q] = 16\sigma^4$ です。$a = 1/c$ とおくと

$$\mathrm{MSE}(a) = V[aQ] + (E[aQ] - \sigma^2)^2 = \sigma^4\left\{16a^2 + (8a - 1)^2\right\}$$

$$\frac{d}{da}\mathrm{MSE} = \sigma^4\left\{32a + 16(8a - 1)\right\} = 0 \ \Rightarrow\ 160a = 16 \ \Rightarrow\ a = \frac{1}{10}$$

一般には $a = 1/(n + 1)$ です。このとき

$$\mathrm{MSE} = \sigma^4\left\{\frac{16}{100} + \left(\frac{8}{10} - 1\right)^2\right\} = \sigma^4(0.16 + 0.04) = 0.200\sigma^4$$

ほかの $c$ と比べると次のとおりです。

| $c$ | 分散 | バイアス$^2$ | 平均二乗誤差 |
| --- | --- | --- | --- |
| 8（不偏分散） | $0.250\sigma^4$ | $0$ | $0.250\sigma^4$ |
| 9（最尤推定量） | $0.198\sigma^4$ | $0.012\sigma^4$ | $0.210\sigma^4$ |
| 10 | $0.160\sigma^4$ | $0.040\sigma^4$ | $0.200\sigma^4$ |
| 11 | $0.132\sigma^4$ | $0.074\sigma^4$ | $0.207\sigma^4$ |

### 各選択肢の検討

- ①：不偏分散 $S^2 = Q/8$ です。バイアスは 0 ですが分散が大きく、平均二乗誤差は最小になりません。
- ②：最尤推定量 $Q/9$ です。$c = 10$ より平均二乗誤差がわずかに大きくなります。
- ③：正しい。
- ④：$0.160\sigma^4$ は $c = 10$ のときの分散だけで、バイアスの 2 乗 $0.04\sigma^4$ を足し忘れています。
- ⑤：$c$ を大きくしすぎると、分散の減少よりバイアスの増加が上回ります。

### ポイント

- バイアス・バリアンス分解：$\mathrm{MSE} = V[T] + (E[T] - \theta)^2$。少しバイアスを許して分散を減らすと、平均二乗誤差が小さくなることがある（縮小推定。リッジ回帰と同じ考え方）。
- 正規分布の分散の推定では、平均二乗誤差を最小にする除数は $n + 1$、最尤推定は $n$、不偏推定は $n - 1$。
