stem: |
  中心化した説明変数の行列 $X$（$n \times p$）と目的変数 $y$ について、切片のない線形回帰モデル

  $$y = X\beta + \varepsilon,\qquad \varepsilon \sim N(0,\ \sigma^2 I_n)$$

  を考える。$\sigma^2$ は既知とし、回帰係数に事前分布 $\beta \sim N(0,\ \tau^2 I_p)$ を置く。このとき $\beta$ の事後分布の最頻値（MAP 推定値）は、リッジ回帰の推定値

  $$\hat{\beta}_{\lambda} = \operatorname*{arg\,min}_{\beta}\left\{\sum_{i=1}^{n}(y_i - x_i^{\top}\beta)^2 + \lambda\sum_{j=1}^{p}\beta_j^2\right\}$$

  とある $\lambda$ について一致する。その $\lambda$ として正しいものを次のうちから一つ選べ。
choices:
  - '$\lambda = \dfrac{\tau^2}{\sigma^2}$'
  - '$\lambda = \dfrac{1}{\tau^2}$'
  - '$\lambda = \dfrac{\sigma^2}{2\tau^2}$'
  - '$\lambda = \dfrac{\sigma}{\tau}$'
  - '$\lambda = \dfrac{\sigma^2}{\tau^2}$'
answer: 5

事後分布は「尤度 × 事前分布」に比例するので、その対数をとって符号を反転すると「残差平方和 $/(2\sigma^2)$ + $\|\beta\|^2/(2\tau^2)$」になります。全体を $2\sigma^2$ 倍すると、罰則の係数が $\lambda = \sigma^2/\tau^2$ のリッジ回帰の目的関数に一致します。

### 計算

$$\log \pi(\beta \mid y) = -\frac{1}{2\sigma^2}\|y - X\beta\|^2 - \frac{1}{2\tau^2}\|\beta\|^2 + (\beta \text{ によらない定数})$$

これを最大化することは

$$\|y - X\beta\|^2 + \frac{\sigma^2}{\tau^2}\|\beta\|^2$$

を最小化することと同じです。解は

$$\hat{\beta} = \left(X^{\top}X + \frac{\sigma^2}{\tau^2}I_p\right)^{-1}X^{\top}y$$

事後分布は正規分布なので、この MAP 推定値は事後平均でもあります。

### 各選択肢の検討

- ①：比が逆です。これでは事前分布が強いほど罰則が弱くなってしまいます。
- ②：尤度側の $1/(2\sigma^2)$ を考えずに、事前分布の項だけを見ています。$\sigma^2$ を掛けてそろえる必要があります。
- ③：$\tfrac{1}{2}$ の扱いを誤っています。残差平方和の項と罰則の項にはどちらも $\tfrac{1}{2}$ が付くので、比をとると消えます。
- ④：分散ではなく標準偏差の比です。
- ⑤：正しい。事前分布の分散 $\tau^2$ が小さい（係数が 0 に近いという信念が強い）ほど、$\lambda$ が大きく縮小が強くなります。

### ポイント

- L2 正則化（リッジ）は正規事前分布、L1 正則化（ラッソ）はラプラス分布（両側指数分布）の事前分布の MAP 推定値に対応する。ラプラス事前分布の事後分布の最頻値は 0 になりうるが、事後平均はちょうど 0 にはならない。
- $\tau^2 \to \infty$（無情報に近い事前分布）では $\lambda \to 0$ となり、最小二乗推定量に戻る。
- 正則化の強さを事前分布の分散として解釈すると、$\lambda$ の選択をクロスバリデーションだけでなく階層モデル（$\tau^2$ にも事前分布を置く）で行う考え方につながる。
