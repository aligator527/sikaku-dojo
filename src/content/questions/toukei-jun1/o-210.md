  $X_1, \ldots, X_n$ を正規分布 $N(\mu, \sigma^2)$ からの無作為標本とし、$\bar X$ を標本平均とする。推定量の性質に関する次の記述 I〜III を考える。

  I. $X_1$（最初の 1 個の観測値）は $\mu$ の不偏推定量であるが、$\mu$ の一致推定量ではない。

  II. $\hat\sigma^2 = \dfrac{1}{n}\displaystyle\sum_{i=1}^{n}(X_i - \bar X)^2$ は $E[\hat\sigma^2] = \dfrac{n-1}{n}\sigma^2$ なので $\sigma^2$ の不偏推定量ではないが、$\sigma^2$ の一致推定量である。

  III. $\bar X$ は $\mu$ の不偏推定量なので、$\bar X^2$ は $\mu^2$ の不偏推定量である。

  記述 I〜III の正誤の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - 'I のみ正しい'
  - 'II のみ正しい'
  - 'I と II のみ正しい'
  - 'II と III のみ正しい'
  - 'I と II と III はすべて正しい'
answer: 3

I と II は正しく、III は誤りです。不偏性は「期待値が真の値に等しい」という有限標本での性質、一致性は「$n \to \infty$ で真の値に確率収束する」という漸近的な性質で、互いに別の概念です。また、不偏性は非線形な変換では保たれません。

### 各記述の検討

- I：正しい。$E[X_1] = \mu$ ですが、$X_1$ の分布は $n$ によらず $N(\mu, \sigma^2)$ のままなので、$\mu$ に確率収束しません。
- II：正しい。$E[\hat\sigma^2] = \frac{n-1}{n}\sigma^2$ でバイアスは $-\sigma^2/n$ です。一方、$V[\hat\sigma^2] = \frac{2(n-1)}{n^2}\sigma^4 \to 0$ で、バイアスも 0 に収束するので、平均二乗誤差が 0 に収束し、一致推定量になります。
- III：誤り。$E[\bar X^2] = V[\bar X] + (E[\bar X])^2 = \mu^2 + \sigma^2/n$ なので、$\sigma^2/n$ だけ上に偏ります。$\mu^2$ の不偏推定量は $\bar X^2 - S^2/n$（$S^2$ は不偏分散）です。

### ポイント

- 平均二乗誤差 $=$ バイアス$^2$ $+$ 分散 が 0 に収束すれば一致推定量である（十分条件）。
- 不偏性は線形変換では保たれるが、2 乗・平方根・逆数などでは一般に保たれない。例えば不偏分散 $S^2$ の平方根 $S$ は $\sigma$ の不偏推定量ではない。
