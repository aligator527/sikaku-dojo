  ある新しい教材の効果を調べるため、受講者 25 人の得点の伸び（後 − 前）について、母平均 $\mu$ の 1 標本 t 検定を行った。統計ソフトウェアの出力は次のとおりであった。

  | 項目 | 値 |
  | --- | --- |
  | 標本平均 | 2.4 |
  | $t$ 値（$H_0: \mu = 0$） | 2.36 |
  | 両側 P 値 | 0.027 |
  | $\mu$ の 95% 信頼区間 | $[0.3,\ 4.5]$ |

  次の記述 I〜III を考える。

  I. 有意水準 5% の両側検定で $H_0: \mu = 0$ は棄却され、これは 95% 信頼区間が 0 を含まないことと対応している。

  II. 有意水準 5% の両側検定で $H_0: \mu = 4$ を検定すると、帰無仮説は棄却される。

  III. P 値が 0.027 であることから、帰無仮説 $H_0: \mu = 0$ が正しい確率は 2.7% である。

  記述 I〜III の正誤の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - 'I のみ正しい'
  - 'II のみ正しい'
  - 'I と II のみ正しい'
  - 'I と III のみ正しい'
  - 'I と II と III はすべて正しい'
answer: 1

I だけが正しい記述です。両側検定と信頼区間には「有意水準 $\alpha$ の両側検定で $H_0: \mu = \mu_0$ が棄却されない $\iff$ $\mu_0$ が $100(1 - \alpha)\%$ 信頼区間に含まれる」という対応（双対性）があります。また、P 値は帰無仮説が正しいと仮定したときの確率で、帰無仮説が正しい確率ではありません。

### 各記述の検討

- I：正しい。P 値 0.027 < 0.05 で棄却され、95% 信頼区間 $[0.3,\ 4.5]$ は 0 を含みません。
- II：誤り。4 は 95% 信頼区間 $[0.3,\ 4.5]$ に含まれるので、有意水準 5% の両側検定では棄却されません。実際、標準誤差は $2.4/2.36 \approx 1.02$ なので $t = (2.4 - 4)/1.02 \approx -1.57$ で、$|t| < t_{0.025}(24) = 2.064$ です。
- III：誤り。P 値は「$H_0$ が正しいとき、観測された値以上に極端な $t$ 値が得られる確率」です。$H_0$ が正しい確率を述べるには、ベイズ的に事前確率を置く必要があります。

### ポイント

- 信頼区間は「棄却されない $\mu_0$ の集合」と解釈できる。区間の幅から効果の大きさと推定の精度も読み取れるので、P 値だけでなく信頼区間も報告するのがよい。
- 「有意でない」ことは「帰無仮説が正しい」ことの証明ではない。このデータは $\mu = 0.3$ から $\mu = 4.5$ までの幅広い値と両立している。
