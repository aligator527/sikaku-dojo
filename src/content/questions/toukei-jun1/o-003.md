ポアソン分布の最尤推定量は標本平均 $\hat{\lambda} = \bar{X}$ で、1 観測あたりのフィッシャー情報量は $I(\lambda) = 1/\lambda$ です。したがって $\hat{\lambda}$ の漸近分散は $\lambda/n$ で、近似 95% 信頼区間は $\hat{\lambda} \pm 1.96\sqrt{\hat{\lambda}/n}$ となります。上限は約 $3.70$ です。

### 計算

対数尤度は

$$\ell(\lambda) = \sum_{i=1}^{n}\left(x_i\log\lambda - \lambda - \log x_i!\right)$$

$$\ell'(\lambda) = \frac{\sum x_i}{\lambda} - n = 0 \ \Rightarrow\ \hat{\lambda} = \bar{x} = \frac{160}{50} = 3.2$$

フィッシャー情報量（1 観測あたり）は

$$I(\lambda) = -E\left[\frac{\partial^2}{\partial\lambda^2}\log f(X;\lambda)\right] = E\left[\frac{X}{\lambda^2}\right] = \frac{1}{\lambda}$$

なので、$\hat{\lambda}$ の漸近分散は $\dfrac{1}{nI(\lambda)} = \dfrac{\lambda}{n}$ です。$\lambda$ に $\hat{\lambda} = 3.2$ を代入すると

$$\text{標準誤差} = \sqrt{\frac{3.2}{50}} = \sqrt{0.064} \approx 0.2530$$

$$\text{上限} = 3.2 + 1.96 \times 0.2530 \approx 3.2 + 0.4958 = 3.6958 \approx 3.70$$

（下限は約 $2.70$）

### ポイント

- ポアソン分布では「期待値＝分散＝$\lambda$」なので、標本平均の分散は $\lambda/n$。これはクラーメル・ラオの下限 $1/(nI(\lambda))$ に一致し、$\bar{X}$ は有効推定量である。
- よくある誤り：日数 $n = 50$ ではなく総件数 160 で割る、標準誤差を $\sqrt{\hat{\lambda}}$ とする（1 日の件数の標準偏差と標本平均の標準誤差の混同）。
- 平方根変換 $2\sqrt{\bar{X}}$ を用いた分散安定化による区間もある（1 級レベル）。
