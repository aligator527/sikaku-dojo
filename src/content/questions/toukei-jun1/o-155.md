独立増分を使い、$X = B(1)$、$Y = B(2) - B(1)$ とおくと、$X$ と $Y$ は独立に $N(0,\ 1)$ に従い、$B(2) = X + Y$ です。$(X,\ Y)$ の分布は原点のまわりの回転で変わらないので、確率は角度の割合で求められます。$P(X > 0,\ X + Y > 0) = 135°/360° = 3/8$ となり、条件付き確率は $(3/8)/(1/2) = 3/4$ です。

### 計算

$(X,\ Y)$ 平面で、$x > 0$ は偏角 $-90°$ から $90°$ の半平面、$x + y > 0$ は偏角 $-45°$ から $135°$ の半平面です。共通部分は偏角 $-45°$ から $90°$ の扇形（中心角 $135°$）で

$$P(B(1) > 0,\ B(2) > 0) = \frac{135}{360} = \frac{3}{8}$$

$$P(B(2) > 0 \mid B(1) > 0) = \frac{3/8}{1/2} = \frac{3}{4}$$

**別解**：$B(1)$ と $B(2)$ の相関係数は $\rho = \dfrac{\min(1,\ 2)}{\sqrt{1 \times 2}} = \dfrac{1}{\sqrt{2}}$ です。2 変量標準正規分布の象限確率の公式 $P(U > 0,\ V > 0) = \dfrac14 + \dfrac{\arcsin\rho}{2\pi}$ から $\dfrac14 + \dfrac{\pi/4}{2\pi} = \dfrac38$ となります。

### 各選択肢の検討

- ①：同時確率 $P(B(1) > 0,\ B(2) > 0)$ で、条件 $P(B(1) > 0) = 1/2$ で割っていません。
- ②：$B(2)$ と $B(1)$ を独立とみなしています。$B(2)$ は $B(1)$ を含むので正の相関があります。
- ③：相関係数 $1/\sqrt{2}$ を確率と混同しています。
- ④：正しい。
- ⑤：「$B(1) > 0$」という条件を「$B(1) = 1$」に置き換えて $P(Y > -1) = \Phi(1)$ としています。条件は値が正であることで、特定の値ではありません。

### ポイント

- ブラウン運動の計算は、独立な正規増分に分解するのが基本。$\mathrm{Corr}(B(s),\ B(t)) = \sqrt{s/t}$（$s < t$）。
- 2 変量標準正規分布の象限確率 $\dfrac14 + \dfrac{\arcsin\rho}{2\pi}$ は、$\rho = 0$ で $1/4$、$\rho \to 1$ で $1/2$ となる。
