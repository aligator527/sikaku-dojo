  デルタ法を用いて $\hat{\lambda}$ の標準誤差を近似し、その推定値（未知のパラメータに推定値を代入した値）を求めよ。

$\mu = 1/\lambda$ とおくと $V[\bar{X}] = \mu^2/n$ です。$g(\mu) = 1/\mu$ の微分は $g'(\mu) = -1/\mu^2$ なので、デルタ法により $V[\hat{\lambda}] \approx g'(\mu)^2\,\mu^2/n = \lambda^2/n$ となります。標準誤差の推定値は $\hat{\lambda}/\sqrt{n} = 0.4/8 = 0.050$ です。

### 計算

$$\mu = E[X] = \frac{1}{\lambda},\qquad V[\bar{X}] = \frac{V[X]}{n} = \frac{1}{n\lambda^2} = \frac{\mu^2}{n}$$

$$g(\mu) = \frac{1}{\mu},\qquad g'(\mu) = -\frac{1}{\mu^2}$$

$$V[\hat{\lambda}] \approx g'(\mu)^2\,V[\bar{X}] = \frac{1}{\mu^4}\cdot\frac{\mu^2}{n} = \frac{1}{n\mu^2} = \frac{\lambda^2}{n}$$

$$\mathrm{SE}(\hat{\lambda}) \approx \frac{\hat{\lambda}}{\sqrt{n}} = \frac{1/2.5}{\sqrt{64}} = \frac{0.4}{8} = 0.050$$

### ポイント

- 同じ結果は、最尤推定量の漸近分散 $1/\{nI(\lambda)\}$（フィッシャー情報量 $I(\lambda) = 1/\lambda^2$）からも得られる。
- よくある誤り：$\bar{X}$ の標準誤差 $\bar{x}/\sqrt{n} = 0.3125$ をそのまま使う、標準誤差に $g'(\mu)^2$ を掛けて $0.16^2 \times 0.3125 = 0.008$ とする（標準誤差に掛けるのは $|g'(\mu)| = 0.16$、分散に掛けるのが $g'(\mu)^2$）。
- $1/\bar{X}$ には偏りがあり、$E[1/\bar{X}] = \dfrac{n}{n-1}\lambda$。不偏推定量は $\dfrac{n-1}{n\bar{X}}$。
