  説明変数 1 個、切片なしの回帰モデル $y_i = \beta x_i + \varepsilon_i$（$i = 1, \ldots, n$）を考える。$\varepsilon_i$ は互いに独立に $N(0, \sigma^2)$ に従い、$x_i$ は固定された値で $\sum_{i=1}^{n}x_i^2 = n$ を満たす。リッジ推定量

  $$\hat\beta_\lambda = \arg\min_\beta\left\{\sum_{i=1}^{n}(y_i - \beta x_i)^2 + \lambda\beta^2\right\} = \frac{\sum x_iy_i}{n + \lambda}$$

  の平均二乗誤差 $E[(\hat\beta_\lambda - \beta)^2]$ を考える。$n = 50$、$\sigma^2 = 4$、$\beta = 0.5$ のとき、平均二乗誤差を最小にする $\lambda \ (\ge 0)$ の値として正しいものを、次のうちから一つ選べ。
choices:

  - '$16$'
  - '$800$'
answer: 4

$\hat\beta_\lambda$ の期待値は $n\beta/(n + \lambda)$、分散は $n\sigma^2/(n + \lambda)^2$ なので、平均二乗誤差は $(n\sigma^2 + \lambda^2\beta^2)/(n + \lambda)^2$ です。これを $\lambda$ で微分すると、$\lambda^* = \sigma^2/\beta^2 = 4/0.25 = 16$ で最小になります（$n$ によりません）。

### 計算

$\sum x_iy_i = \beta\sum x_i^2 + \sum x_i\varepsilon_i = n\beta + \sum x_i\varepsilon_i$ より

$$E[\hat\beta_\lambda] = \frac{n\beta}{n + \lambda},\qquad \text{バイアス} = -\frac{\lambda\beta}{n + \lambda},\qquad V[\hat\beta_\lambda] = \frac{n\sigma^2}{(n + \lambda)^2}$$

$$\mathrm{MSE}(\lambda) = \frac{n\sigma^2 + \lambda^2\beta^2}{(n + \lambda)^2}$$

$$\frac{d}{d\lambda}\mathrm{MSE}(\lambda) = \frac{2\lambda\beta^2(n + \lambda) - 2(n\sigma^2 + \lambda^2\beta^2)}{(n + \lambda)^3} = \frac{2n(\lambda\beta^2 - \sigma^2)}{(n + \lambda)^3}$$

$\lambda < \sigma^2/\beta^2$ で負、$\lambda > \sigma^2/\beta^2$ で正なので、$\lambda^* = \sigma^2/\beta^2 = 16$ で最小になります。このとき $\mathrm{MSE}(16) = (200 + 64)/66^2 \approx 0.0606$ で、最小二乗推定量（$\lambda = 0$）の $\sigma^2/n = 0.08$ より約 24% 小さくなります。

### 各選択肢の検討

- ①：最小二乗推定量は不偏ですが、$\mathrm{MSE}'(0) = -2\sigma^2/n^2 < 0$ なので、$\lambda$ を 0 から少し大きくすると平均二乗誤差は必ず減ります。
- ②：$\beta^2/\sigma^2$ と、逆数をとっています。
- ③：2 乗せずに $\sigma/\beta$ としています。
- ④：正しい。
- ⑤：$n\sigma^2/\beta^2$ としています。この設定では $\lambda^*$ は $n$ によりません。

### ポイント

- 少しバイアスを入れて分散を減らすと、平均二乗誤差が小さくなる。真の係数 $|\beta|$ が小さいほど、またノイズ $\sigma^2$ が大きいほど、強い縮小が最適になる。
- ただし $\lambda^*$ は未知の $\beta$ と $\sigma^2$ に依存するので、実際には交差検証などで $\lambda$ を選ぶ。
