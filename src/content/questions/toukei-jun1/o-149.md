グラフ上のランダムウォークでは、定常分布は各地点の次数（出ている道の本数）に比例し、$\pi_i = d_i/(2|E|)$（$|E|$ は道の本数）です。A の次数は 3、次数の合計は $2 \times 5 = 10$ なので、$\pi_A = 3/10 = 0.300$ です。

### 計算

次数は $d_A = 3$、$d_B = 2$、$d_C = 2$、$d_D = 2$、$d_E = 1$ で、合計は 10 です。

隣り合う地点 $i,\ j$ について $p_{ij} = 1/d_i$ なので、$\pi_i = d_i/10$ とおくと

$$\pi_i\,p_{ij} = \frac{d_i}{10}\cdot\frac{1}{d_i} = \frac{1}{10} = \pi_j\,p_{ji}$$

と詳細つり合い条件が成り立ち、$\pi = (0.3,\ 0.2,\ 0.2,\ 0.2,\ 0.1)$ は定常分布です。例えば A について $\pi_B/2 + \pi_C/2 + \pi_D/2 = 0.1 + 0.1 + 0.1 = 0.3$ と確かめられます。

この連鎖は既約で、A–B–C の三角形（長さ 3 の閉路）があるので非周期的でもあり、長期的な滞在割合は初期地点によらず定常分布に一致します。

### 各選択肢の検討

- ①：定常確率を次数の逆数に比例させた値 $\dfrac{1/3}{1/3 + 1/2 + 1/2 + 1/2 + 1} \approx 0.118$ です。比例関係が逆です。
- ②：5 地点を等確率としています。
- ③：正しい。
- ④：$1/d_A$ は A から特定の隣の地点へ移る確率です。
- ⑤：$d_A$ を道の本数 5 で割っています。各道は両端の 2 地点で数えられるので、分母は $2 \times 5 = 10$ です。

### ポイント

- 詳細つり合い条件 $\pi_ip_{ij} = \pi_jp_{ji}$ を満たす分布は定常分布（可逆なマルコフ連鎖）。MCMC のメトロポリス・ヘイスティングス法もこの条件を満たすように設計される。
- A から出発して A に戻るまでの平均ステップ数は $1/\pi_A = 10/3$。
