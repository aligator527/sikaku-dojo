  確率変数 $X$ のモーメント母関数（積率母関数）が

  $$M_X(t) = E\left[e^{tX}\right] = (1 - 2t)^{-3} \qquad \left(t < \tfrac{1}{2}\right)$$

  で与えられている。$X$ の期待値 $E[X]$ と分散 $V[X]$ の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - '$E[X] = 3,\ V[X] = 6$'
  - '$E[X] = 6,\ V[X] = 24$'
  - '$E[X] = 1.5,\ V[X] = 0.75$'
  - '$E[X] = 6,\ V[X] = 12$'
  - '$E[X] = 6,\ V[X] = 36$'
answer: 4

$(1 - \theta t)^{-k}$ は形状母数 $k$、尺度母数 $\theta$ のガンマ分布のモーメント母関数です。ここでは $k = 3,\ \theta = 2$ なので、$E[X] = k\theta = 6$、$V[X] = k\theta^2 = 12$ です。これは自由度 6 のカイ二乗分布でもあります。

### 計算

母関数を直接微分しても確認できます。

$$M_X'(t) = 6(1 - 2t)^{-4},\qquad M_X''(t) = 48(1 - 2t)^{-5}$$

$$E[X] = M_X'(0) = 6,\qquad E[X^2] = M_X''(0) = 48$$

$$V[X] = 48 - 6^2 = 12$$

キュムラント母関数 $K(t) = \log M_X(t) = -3\log(1 - 2t)$ を使うと、$K'(0) = 6$、$K''(0) = 12$ がそのまま期待値と分散になり、計算が速くなります。

### 各選択肢の検討

- ①：$E[X] = k$、$V[X] = 2k$ と、自由度 3 のカイ二乗分布と取り違えています。自由度 $m$ のカイ二乗分布のモーメント母関数は $(1 - 2t)^{-m/2}$ なので、ここでは $m = 6$ です。
- ②：分散を $2k\theta^2$ と余分に 2 倍した値です。カイ二乗分布の分散「自由度の 2 倍」とガンマ分布の分散 $k\theta^2$ を混同すると出やすい誤りです。正しくは $V[X] = 48 - 36 = 12$ です。
- ③：2 を「レート（尺度母数の逆数）」と取り違え、$E[X] = k/\lambda = 1.5$ としています。$(1 - t/\lambda)^{-k}$ の形のときのレートが $\lambda$ です。
- ⑤：$E[X^2]$ ではなく $E[X]^2$ を分散としています。

### ポイント

- 正規分布 $e^{\mu t + \sigma^2 t^2/2}$、ポアソン分布 $e^{\lambda(e^t - 1)}$、ガンマ分布 $(1 - \theta t)^{-k}$、二項分布 $(1 - p + pe^t)^n$ などの母関数は形で見分けられるようにする。
- 独立な確率変数の和のモーメント母関数は積になる。$(1 - 2t)^{-3}$ は「自由度 2 のカイ二乗分布（平均 2 の指数分布）3 個の和」とも読める。
