  $X_1, \ldots, X_{10}$ を一様分布 $U(0, \theta)$ からの無作為標本とし、$\theta$ の 2 つの推定量

  を考える。どちらも $\theta$ の不偏推定量である。分散の比 $V[T_1]/V[T_2]$ の値として、正しいものを次のうちから一つ選べ。

$V[T_1] = 4 \cdot \dfrac{\theta^2}{12n} = \dfrac{\theta^2}{3n}$ です。$X_{(n)}$ の分布関数は $(x/\theta)^n$ なので $V[X_{(n)}] = \dfrac{n\theta^2}{(n+1)^2(n+2)}$、$V[T_2] = \dfrac{\theta^2}{n(n+2)}$ となります。比は $(n + 2)/3$ で、$n = 10$ では $4$ です。

### 計算

$V[X_i] = \theta^2/12$ より

$$V[T_1] = 4V[\bar X] = \frac{4}{n}\cdot\frac{\theta^2}{12} = \frac{\theta^2}{3n} = \frac{\theta^2}{30}$$

$X_{(n)}$ の確率密度関数は $g(x) = nx^{n-1}/\theta^n\ (0 < x < \theta)$ なので

$$E[X_{(n)}] = \frac{n}{n+1}\theta,\qquad E[X_{(n)}^2] = \frac{n}{n+2}\theta^2$$

$$V[X_{(n)}] = \frac{n}{n+2}\theta^2 - \frac{n^2}{(n+1)^2}\theta^2 = \frac{n\theta^2}{(n+1)^2(n+2)}$$

$$V[T_2] = \frac{(n+1)^2}{n^2}V[X_{(n)}] = \frac{\theta^2}{n(n+2)} = \frac{\theta^2}{120}$$

$$\frac{V[T_1]}{V[T_2]} = \frac{n(n+2)}{3n} = \frac{n+2}{3} = \frac{12}{3} = 4$$

$T_2$ は $T_1$ の 4 倍効率がよく、$T_1$ で同じ精度を得るには約 4 倍の標本が必要です。

### 各選択肢の検討

- ①：比を逆にとっています。
- ②：「どちらも不偏なので分散も等しい」と考えた誤り、または $V[T_1]$ の係数 4 を落として $\theta^2/(12n)$ とした誤りです（このとき比は $(n+2)/12 = 1$）。
- ③：標準偏差の比 $\sqrt 4 = 2$ です。
- ④：正しい。
- ⑤：$T_2$ ではなく、係数 $(n+1)^2/n^2$ を掛ける前の $X_{(n)}$ の分散と比べた値 $\frac{121 \times 12}{300} = 4.84$ です。

### ポイント

- $V[T_2]$ は $1/n^2$ のオーダーで減少し、$1/n$ のオーダーの $T_1$ よりはるかに速い。台が $\theta$ に依存する分布は正則条件を満たさないので、クラーメル・ラオの下限（$1/n$ のオーダー）は適用されない。
- $X_{(n)}$ は十分統計量で、$T_2$ はその関数になっている。十分統計量の関数になっていない $T_1$ は、データの情報の一部を捨てている。
