  ある工程で作られる製品ロットの歩留まり率 $X$（$0 < X < 1$）は、互いに独立に確率密度関数

  をもつ分布に従うとする。10 ロットの歩留まり率 $x_1, \ldots, x_{10}$ を観測したところ、$\sum_{i=1}^{10}\log x_i = -4.0$（自然対数）であった。

まず $\theta$ の最尤推定量を求め、次に最尤推定量の不変性（$g(\theta)$ の最尤推定量は $g(\hat\theta)$）を使います。対数尤度を微分すると $\hat\theta = -n/\sum\log x_i = 2.5$ となり、これを $E[X] = \theta/(\theta + 1)$ に代入して $2.5/3.5 \approx 0.714$ です。

### 計算

対数尤度は

$$\ell(\theta) = n\log\theta + (\theta - 1)\sum_{i=1}^{n}\log x_i$$

$$\ell'(\theta) = \frac{n}{\theta} + \sum_{i=1}^{n}\log x_i = 0 \ \Rightarrow\ \hat\theta = -\frac{n}{\sum\log x_i} = -\frac{10}{-4.0} = 2.5$$

$\ell''(\theta) = -n/\theta^2 < 0$ なので、これは最大値です。期待値は

$$E[X] = \int_0^1 x\cdot\theta x^{\theta - 1}\,dx = \frac{\theta}{\theta + 1}$$

なので、不変性より

$$\widehat{E[X]} = \frac{\hat\theta}{\hat\theta + 1} = \frac{2.5}{3.5} \approx 0.714$$

### ポイント

- 最尤推定量の不変性：$\theta$ の最尤推定量が $\hat\theta$ なら、関数 $g(\theta)$ の最尤推定量は $g(\hat\theta)$。微分し直す必要はない。
- よくある誤り：逆数をとり忘れて $\hat\theta = -\sum\log x_i/n = 0.4$ とする（このとき $0.4/1.4 \approx 0.29$）。
- 最尤推定量は一般に不偏ではない。$-\log X_i$ は平均 $1/\theta$ の指数分布に従うので、$E[\hat\theta] = n\theta/(n-1)$ となり、$\hat\theta$ はわずかに上に偏る。
