定常な AR(1) モデル $X_t = \phi X_{t-1} + \varepsilon_t$（$|\phi| < 1$）では、分散は $\gamma_0 = \sigma^2/(1 - \phi^2)$、ラグ $h$ の自己相関は $\rho_h = \phi^h$ です。したがって $\gamma_2 = \phi^2\gamma_0 = 0.36 \times 4.0 = 1.44$ です。

### 計算

両辺の分散をとると、定常性（$V[X_t] = V[X_{t-1}] = \gamma_0$）と無相関性から

$$\gamma_0 = \phi^2\gamma_0 + \sigma^2 \ \Rightarrow\ \gamma_0 = \frac{2.56}{1 - 0.36} = \frac{2.56}{0.64} = 4.0$$

$X_t = \phi X_{t-1} + \varepsilon_t$ の両辺に $X_{t-h}$（$h \geq 1$）を掛けて期待値をとると、$\gamma_h = \phi\gamma_{h-1}$ が成り立つので

$$\gamma_1 = 0.6 \times 4.0 = 2.4,\qquad \gamma_2 = 0.6 \times 2.4 = 1.44$$

### ポイント

- よくある誤り：自己相関 $\rho_2 = 0.36$ を自己共分散と取り違える、$\gamma_0$ をホワイトノイズの分散 2.56 のままにする（$0.36 \times 2.56 = 0.92$）。
- AR(1) の自己相関はラグとともに指数的に減衰し、偏自己相関はラグ 2 以降で 0 になる。MA(1) では逆に自己相関がラグ 2 以降で 0 になる。
- 定常条件は特性方程式 $1 - \phi z = 0$ の根の絶対値が 1 より大きいこと（$|\phi| < 1$）。
