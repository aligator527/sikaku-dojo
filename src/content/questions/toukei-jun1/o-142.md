定常分布では「稼働 → 故障」と「故障 → 稼働」の確率の流れがつり合うので、故障の割合は $0.1/(0.1 + 0.4) = 0.2$ です。エルゴード的なマルコフ連鎖では、状態 $i$ の平均再帰時間は定常確率の逆数 $1/\pi_i$ なので、$1/0.2 = 5$ 日です。

### 計算

定常分布を $(\pi_1,\ \pi_2)$（1 = 稼働、2 = 故障）とすると

$$0.1\,\pi_1 = 0.4\,\pi_2,\qquad \pi_1 + \pi_2 = 1 \quad\Rightarrow\quad \pi_2 = \frac{0.1}{0.1 + 0.4} = 0.2$$

平均再帰時間を直接求めると、故障の日の翌日も故障なら（確率 0.6）1 日、稼働に戻ったら（確率 0.4）1 日に「稼働から故障までの平均日数 $1/0.1 = 10$ 日」を足して

$$m_2 = 0.6 \times 1 + 0.4 \times (1 + 10) = 0.6 + 4.4 = 5 = \frac{1}{\pi_2}$$

### 各選択肢の検討

- ①：$1/0.4 = 2.5$ は、故障が続く日数（修理期間）の平均です。
- ②：正しい。
- ③：$1/0.1 = 10$ は、稼働している日から故障するまでの平均日数です。
- ④：推移確率の比 $0.1/0.4 = 0.25$ は故障と稼働の割合の比（$\pi_2/\pi_1$）で、故障の割合ではありません。
- ⑤：稼働の割合 $0.8$ と、稼働状態の平均再帰時間 $1/0.8$ です。

### ポイント

- 2 状態連鎖（$1 \to 2$ の確率 $a$、$2 \to 1$ の確率 $b$）の定常分布は $\left(\dfrac{b}{a+b},\ \dfrac{a}{a+b}\right)$。$P^n$ は $(1 - a - b)^n = 0.5^n$ の速さで定常分布に近づく。
- 平均再帰時間 $= 1/\pi_i$（カッツの定理）。定常確率の大きい状態ほど早く戻ってくる。
