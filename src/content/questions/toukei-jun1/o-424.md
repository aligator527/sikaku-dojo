まずユール・ウォーカー方程式から自己相関 $\rho(1) = 5/7$、$\rho(2) = 23/35$ を求め、次にモデル式の両辺に $X_t$ を掛けて期待値をとった $\gamma(0) = \phi_1\gamma(1) + \phi_2\gamma(2) + \sigma^2$ を使います。$\gamma(0) = 1/(1 - \phi_1\rho(1) - \phi_2\rho(2)) = 175/78 \approx 2.24$ です。

### 計算

モデル式の両辺に $X_{t-h}$（$h = 1, 2$）を掛けて期待値をとり、$\gamma(0)$ で割ると（ユール・ウォーカー方程式）

$$\rho(1) = \phi_1 + \phi_2\rho(1) \ \Rightarrow\ \rho(1) = \frac{\phi_1}{1 - \phi_2} = \frac{0.5}{0.7} = \frac{5}{7} \approx 0.7143$$

$$\rho(2) = \phi_1\rho(1) + \phi_2 = \frac{5}{14} + 0.3 = \frac{23}{35} \approx 0.6571$$

両辺に $X_t$ を掛けて期待値をとると、$E[X_t\varepsilon_t] = \sigma^2$ より

$$\gamma(0) = \phi_1\gamma(1) + \phi_2\gamma(2) + \sigma^2 = \gamma(0)\{\phi_1\rho(1) + \phi_2\rho(2)\} + \sigma^2$$

$$\gamma(0) = \frac{\sigma^2}{1 - 0.5 \times 0.7143 - 0.3 \times 0.6571} = \frac{1}{1 - 0.3571 - 0.1971} = \frac{1}{0.4457} \approx 2.244$$

閉じた形の公式 $\gamma(0) = \dfrac{(1 - \phi_2)\sigma^2}{(1 + \phi_2)\{(1 - \phi_2)^2 - \phi_1^2\}} = \dfrac{0.7}{1.3 \times 0.24} \approx 2.244$ でも同じ値になります。

### ポイント

- AR($p$) の分散は $\gamma(0) = \sigma^2/(1 - \sum_j\phi_j\rho(j))$。自己相関を先に求めるのが計算の近道。
- よくある誤り：AR(1) の公式を拡張して $1/(1 - \phi_1^2 - \phi_2^2) \approx 1.52$ とする、$1/(1 - \phi_1 - \phi_2) = 5$ とする、$\phi_2\rho(2)$ の項を落として $1/(1 - \phi_1\rho(1)) \approx 1.56$ とする。
- $\phi_1 + \phi_2 = 0.8$ と 1 に近いほど、分散は $\sigma^2$ に比べて大きくなる（単位根に近づくと発散する）。
