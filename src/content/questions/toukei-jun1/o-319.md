説明変数が直交していると、残差平方和は $\mathrm{RSS}(\boldsymbol{\beta}) = \mathrm{RSS}(\hat{\boldsymbol{\beta}}) + 50\sum_j(\beta_j - \hat{\beta}_j)^2$ と成分ごとに分かれるので、各係数を別々に最小化できます。リッジは全係数を一律に $50/(50 + 25) = 2/3$ 倍に縮め、ラッソは各係数の絶対値から $50/(2 \times 50) = 0.5$ を引いて 0 で打ち切ります（軟閾値処理）。

### 計算

**リッジ**：$50(\beta_j - \hat{\beta}_j)^2 + 25\beta_j^2$ を $\beta_j$ で微分して 0 とおくと

$$100(\beta_j - \hat{\beta}_j) + 50\beta_j = 0 \ \Rightarrow\ \beta_j = \frac{50}{50 + 25}\hat{\beta}_j = \frac{2}{3}\hat{\beta}_j$$

行列で書けば $(X^\top X + 25I)^{-1}X^\top\boldsymbol{y} = \frac{50}{75}\hat{\boldsymbol{\beta}}$ で、$(1.333,\ -0.400,\ 0.200)$ です。

**ラッソ**：$50(\beta_j - \hat{\beta}_j)^2 + 50|\beta_j|$ を最小にします。$\beta_j > 0$ の範囲では微分して $100(\beta_j - \hat{\beta}_j) + 50 = 0$、つまり $\beta_j = \hat{\beta}_j - 0.5$ です。まとめると

$$\beta_j = \operatorname{sign}(\hat{\beta}_j)\max\left(|\hat{\beta}_j| - 0.5,\ 0\right)$$

$2.0 \to 1.5$、$-0.6 \to -0.1$、$0.3 \to 0$（$|0.3| < 0.5$ なので 0）となり、$(1.50,\ -0.10,\ 0)$ です。

### 各選択肢の検討

- ①：ラッソの閾値を $50/50 = 1$ としています。罰則の微分 $50$ と残差平方和の微分 $2 \times 50(\beta_j - \hat{\beta}_j)$ を比べるので、閾値は $50/(2 \times 50) = 0.5$ です。
- ②：リッジの罰則を半分（$12.5$）として $50/62.5 = 0.8$ 倍にしています。
- ③：リッジとラッソの性質が逆です。係数をちょうど 0 にするのはラッソで、リッジは比例的に縮めるだけで 0 にはしません。
- ④：ラッソを「一律に半分に縮める」としています。ラッソは比例縮小ではなく、一定量を引く縮小です。
- ⑤：正しい。

### ポイント

- リッジ（L2 正則化）：$\hat{\boldsymbol{\beta}}_{\text{ridge}} = (X^\top X + \lambda I)^{-1}X^\top\boldsymbol{y}$。多重共線性で $X^\top X$ が特異に近くても安定に計算でき、偏りと引き換えに分散を減らす。
- ラッソ（L1 正則化）：一部の係数をちょうど 0 にするので、変数選択を兼ねる。
- 罰則は説明変数の尺度に依存するので、通常は説明変数を標準化してから当てはめる。L2 正則化法は 2027 年 1 月 1 日以降の出題範囲表で明記された。
