一様分布 $U(0,\ 1)$ から大きさ $n$ の標本をとったとき、$k$ 番目に小さい値はベータ分布 $Be(k,\ n - k + 1)$ に従います。ここでは $Be(2,\ 3)$ なので、期待値は $2/5 = 0.4$、分散は $\dfrac{2 \times 3}{5^2 \times 6} = 0.04$ です。

### 計算

$X_{(2)}$ が $x$ の近くにあるのは「4 個のうち 1 個が $x$ より小さく、1 個が $x$ の近くにあり、残り 2 個が $x$ より大きい」場合で、その並べ方は $\dfrac{4!}{1!\,1!\,2!} = 12$ 通りです。よって密度関数は

$$f(x) = 12\,x\,(1 - x)^2\qquad (0 < x < 1)$$

で、これは $Be(2,\ 3)$ の密度関数です。

$$E[X_{(2)}] = \int_0^1 12x^2(1-x)^2\,dx = 12 \times \frac{1}{30} = 0.4$$

$$E[X_{(2)}^2] = \int_0^1 12x^3(1-x)^2\,dx = 12 \times \frac{1}{60} = 0.2,\qquad V[X_{(2)}] = 0.2 - 0.4^2 = 0.04$$

（$\int_0^1 x^{a-1}(1-x)^{b-1}dx = \dfrac{(a-1)!\,(b-1)!}{(a+b-1)!}$ を使いました。）

### 各選択肢の検討

- ①：$Be(k,\ n - k) = Be(2,\ 2)$ と母数を取り違えています。正しくは $Be(k,\ n - k + 1)$ です。
- ②：正しい。
- ③：分散を標本比率のように $0.4 \times 0.6/4 = 0.06$ としています。
- ④：大きい方から 2 番目の $X_{(3)} \sim Be(3,\ 2)$ の値です。分散は同じですが、期待値は $0.6$ になります。
- ⑤：ベータ分布 $Be(a,\ b)$ の分散 $\dfrac{ab}{(a+b)^2(a+b+1)}$ の $(a+b+1)$ を落としています。

### ポイント

- $U(0,\ 1)$ の $k$ 番目の順序統計量は $Be(k,\ n - k + 1)$ で、$E[X_{(k)}] = \dfrac{k}{n+1}$。$n$ 個の点は区間を平均的に $n + 1$ 等分する。
- 一般の連続分布 $F$ でも、確率積分変換により $F(X_{(k)}) \sim Be(k,\ n - k + 1)$ となる。
- 最大値の分布関数は $F(x)^n$、最小値の分布関数は $1 - \{1 - F(x)\}^n$。
