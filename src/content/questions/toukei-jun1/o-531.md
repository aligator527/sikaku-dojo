DiD は処置群の前後の変化から対照群の前後の変化を引くので、時間によらない群間の水準差は打ち消されます。必要なのは「処置がなければ両群は同じだけ変化した」という平行トレンドの仮定で、水準が等しいことは必要ありません。

### 各選択肢の検討

- ①：誤り。水準の違いを取り除けることが、単純な事後比較に対する DiD の利点です。
- ②：誤り。導入後の処置群について処置がなかった場合の結果（反実仮想）は観測できないので、仮定そのものは検証できません。導入前の複数時点で両群の推移が平行だったかを確認する（事前トレンドの確認、イベントスタディ）ことで、仮定のもっともらしさを点検します。
- ③：誤り。処置群だけに同時に起きた別の変化は、政策の効果と区別できず、DiD 推定量に混入します。
- ④：誤り。平行トレンドは尺度に依存します。たとえば処置がなかった場合の結果が処置群で 10 → 12、対照群で 20 → 22 と変化するなら差では平行ですが、比では 1.2 倍と 1.1 倍で平行ではありません。
- ⑤：正しい。$E[Y_{\text{後}}(0) - Y_{\text{前}}(0) \mid \text{処置群}] = E[Y_{\text{後}}(0) - Y_{\text{前}}(0) \mid \text{対照群}]$ が仮定の中身です。

### ポイント

- DiD の推定値は回帰 $Y = \beta_0 + \beta_1 D + \beta_2 P + \beta_3 (D \times P) + \varepsilon$ の $\beta_3$ として得られ、共変量を加えた調整もできる。
- 同じ個体を繰り返し観測するデータでは、誤差の系列相関を考慮した標準誤差（クラスター頑健標準誤差など）を使う。
