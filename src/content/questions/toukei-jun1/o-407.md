直交回転のもとでは、因子負荷量の 2 乗を行方向に足すと各変数の共通性、列方向に足すと各因子の寄与になります。因子 1 の寄与は $0.64 + 0.5625 + 0.49 + 0.0225 + 0.04 = 1.755$ で、標準化した 5 変数の分散の合計 5 の $1.755/5 \approx 35\%$ です。

### 計算

| 変数  | 共通性 $l_{i1}^2 + l_{i2}^2$ | 独自分散 |
| ----- | ---------------------------- | -------- |
| $x_1$ | 0.6500                       | 0.3500   |
| $x_2$ | 0.6025                       | 0.3975   |
| $x_3$ | 0.4925                       | 0.5075   |
| $x_4$ | 0.7450                       | 0.2550   |
| $x_5$ | 0.4000                       | 0.6000   |

因子 1 の寄与は 1.755、因子 2 の寄与は $0.01 + 0.04 + 0.0025 + 0.7225 + 0.36 = 1.135$ で、合計 2.89 は共通性の合計に一致します。

### 各選択肢の検討

- ①：正しい。
- ②：独自分散は $1 - (0.15^2 + 0.85^2) = 1 - 0.745 = 0.255$ です。負荷量を 2 乗せず、もう一方の因子も無視しています。
- ③：共通性は負荷量の 2 乗和 $0.04 + 0.36 = 0.40$ です。
- ④：直交回転 $\Lambda T$（$T$ は直交行列）では $\Lambda T T^\top \Lambda^\top = \Lambda\Lambda^\top$ なので、共通性は変わりません。変わるのは因子ごとの寄与の配分です。
- ⑤：バリマックス回転は直交回転なので、回転後の因子は無相関（相関係数 0）のままです。因子間の相関を許すのはプロマックス回転などの斜交回転です。

### ポイント

- 行方向の 2 乗和 = 共通性、列方向の 2 乗和 = 因子の寄与（直交解の場合）。
- 回転の目的は解釈しやすさ（単純構造）で、モデルの当てはまり（再現される相関行列）は回転によって変わらない。
