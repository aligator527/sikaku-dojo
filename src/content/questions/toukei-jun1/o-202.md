$wT_1 + (1 - w)T_2$ はどの $w$ でも不偏なので、分散 $w^2\sigma_1^2 + (1 - w)^2\sigma_2^2$ を最小にする $w$ を選びます。最適な重みは分散の逆数に比例し、$w = \sigma_2^2/(\sigma_1^2 + \sigma_2^2) = 0.16/0.25 = 0.64$ です。したがって $\hat\mu = 0.64 \times 10.2 + 0.36 \times 10.8 = 10.416$ です。

### 計算

$$V[\hat\mu] = w^2\sigma_1^2 + (1 - w)^2\sigma_2^2$$

$$\frac{d}{dw}V[\hat\mu] = 2w\sigma_1^2 - 2(1 - w)\sigma_2^2 = 0 \ \Rightarrow\ w = \frac{\sigma_2^2}{\sigma_1^2 + \sigma_2^2} = \frac{1/\sigma_1^2}{1/\sigma_1^2 + 1/\sigma_2^2}$$

$\sigma_1^2 = 0.09$、$\sigma_2^2 = 0.16$ より $w = 0.16/0.25 = 0.64$ です。

$$\hat\mu = 0.64 \times 10.2 + 0.36 \times 10.8 = 6.528 + 3.888 = 10.416 \approx 10.42$$

このときの分散は

$$V[\hat\mu] = \frac{1}{1/0.09 + 1/0.16} = \frac{0.09 \times 0.16}{0.25} = 0.0576$$

で、標準誤差は $0.24$ です。どちらの研究所単独の標準誤差（0.3、0.4）よりも小さくなります。

### ポイント

- 独立な不偏推定量の最良の線形結合は「分散の逆数で重み付けた平均」（逆分散重み付け）。メタアナリシスの固定効果モデルと同じ考え方である。
- よくある誤り：単純平均 $10.5$ を使う（分散 $(0.09 + 0.16)/4 = 0.0625$ で、最適な場合より大きい）、重みを標準誤差の逆数に比例させる（$w \approx 0.571$、$\hat\mu \approx 10.46$）、重みを逆に付ける（$w = 0.36$、$\hat\mu \approx 10.58$）。
