  $X_1, \ldots, X_{10}$ を正規分布 $N(\mu, \sigma^2)$（$\mu,\ \sigma^2$ ともに未知）からの無作為標本とする。$S^2 = \frac{1}{n-1}\sum(X_i - \bar X)^2$ を不偏分散、$\hat\sigma^2 = \frac{1}{n}\sum(X_i - \bar X)^2$ を最尤推定量とする（$n = 10$）。$\sigma^2$ の推定に関する次の記述 I〜III を考える。

  I. $S^2$ の分散は、$\sigma^2$ の不偏推定量の分散に対するクラーメル・ラオの下限に一致するので、$S^2$ は $\sigma^2$ の有効推定量である。

  II. 1 個の観測値がもつ $\sigma^2$ についてのフィッシャー情報量は $1/(2\sigma^4)$ であり、クラーメル・ラオの下限は $0.2\sigma^4$ である。$V[S^2] = 2\sigma^4/9$ なので、$S^2$ の効率（下限 / 分散）は $0.9$ である。

  III. $V[\hat\sigma^2] = 0.18\sigma^4$ はクラーメル・ラオの下限 $0.2\sigma^4$ を下回るが、$\hat\sigma^2$ は不偏推定量ではないので、クラーメル・ラオの不等式とは矛盾しない。

  記述 I〜III の正誤の組合せとして、正しいものを次のうちから一つ選べ。
choices:

II と III が正しく、I は誤りです。$\sigma^2$ についてのクラーメル・ラオの下限は $2\sigma^4/n$ ですが、$S^2$ の分散は $2\sigma^4/(n - 1)$ で下限よりわずかに大きく、有限標本では下限に到達しません（$n \to \infty$ で比が 1 に近づくので、漸近的には有効です）。

### 各記述の検討

$v = \sigma^2$ とおくと、1 個の観測値の対数確率密度は

$$\log f(x;\mu, v) = -\frac{1}{2}\log(2\pi v) - \frac{(x - \mu)^2}{2v}$$

$$\frac{\partial^2}{\partial v^2}\log f = \frac{1}{2v^2} - \frac{(x - \mu)^2}{v^3},\qquad I(v) = -E\left[\frac{1}{2v^2} - \frac{(X - \mu)^2}{v^3}\right] = \frac{1}{2v^2} = \frac{1}{2\sigma^4}$$

です。$(\mu, \sigma^2)$ のフィッシャー情報行列は対角行列なので、$\mu$ が未知でもこの成分だけで下限が決まり、下限は $1/(nI) = 2\sigma^4/n = 0.2\sigma^4$ です。また、$(n - 1)S^2/\sigma^2 \sim \chi^2(n - 1)$ より

$$V[S^2] = \frac{\sigma^4}{(n-1)^2}\cdot 2(n - 1) = \frac{2\sigma^4}{n - 1} = \frac{2\sigma^4}{9} \approx 0.222\sigma^4$$

- I：誤り。$V[S^2] \approx 0.222\sigma^4 > 0.2\sigma^4$ なので、下限に一致しません。
- II：正しい。効率は $0.2/0.222 = (n - 1)/n = 0.9$ です。
- III：正しい。$V[\hat\sigma^2] = \left(\frac{n-1}{n}\right)^2V[S^2] = \frac{2(n-1)}{n^2}\sigma^4 = 0.18\sigma^4$ です。下限 $1/(nI)$ は不偏推定量に対するもので、バイアス $b(\theta)$ をもつ推定量では下限が $\{1 + b'(\theta)\}^2/(nI)$ に変わります。ここでは $b(\sigma^2) = -\sigma^2/n$ より下限は $(1 - 1/n)^2 \times 0.2\sigma^4 = 0.162\sigma^4$ となり、$0.18\sigma^4$ はこれを上回っています。

### ポイント

- クラーメル・ラオの不等式：不偏推定量 $T$ について $V[T] \ge 1/\{nI(\theta)\}$。等号が成り立つ（有効推定量が存在する）のは、スコア関数が $T - \theta$ に比例する場合に限られる。
- $\mu$ が既知なら、$\frac{1}{n}\sum(X_i - \mu)^2$ は不偏で分散 $2\sigma^4/n$ となり、下限に到達する。
