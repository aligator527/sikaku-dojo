$W$ は自由度 $k = 4$、非心度 $\lambda = \sum\mu_i^2 = 1 + 1 + 4 + 0 = 6$ の非心カイ二乗分布に従います。期待値は $k + \lambda = 10$、分散は $2k + 4\lambda = 32$ です。公式を覚えていなくても、各項を $X_i = \mu_i + Z_i$（$Z_i \sim N(0,\ 1)$）と分解すれば計算できます。

### 計算

$X_i^2 = \mu_i^2 + 2\mu_i Z_i + Z_i^2$ で、$E[Z_i] = E[Z_i^3] = 0$、$E[Z_i^2] = 1$、$E[Z_i^4] = 3$ を使います。

$$E[X_i^2] = \mu_i^2 + 1$$

$$V[X_i^2] = V[2\mu_i Z_i + Z_i^2] = 4\mu_i^2 V[Z_i] + V[Z_i^2] + 4\mu_i\,\mathrm{Cov}(Z_i,\ Z_i^2) = 4\mu_i^2 + 2 + 0$$

（$V[Z_i^2] = 3 - 1 = 2$、$\mathrm{Cov}(Z_i,\ Z_i^2) = E[Z_i^3] = 0$）

$X_i$ は独立なので

$$E[W] = \sum_{i=1}^{4}(\mu_i^2 + 1) = 6 + 4 = 10,\qquad V[W] = \sum_{i=1}^{4}(4\mu_i^2 + 2) = 24 + 8 = 32$$

### 各選択肢の検討

- ①：中心カイ二乗分布 $\chi^2(4)$ の期待値と分散です。平均 $\mu_i$ がずれていることを無視しています。
- ②：期待値は正しいものの、分散が非心度に依存しないと考えています。
- ③：分散を $2(k + \lambda)$ としています。非心度の寄与は $4\lambda$ です。
- ④：正しい。
- ⑤：非心度を $\sum\mu_i^2/2$ で定義する流儀の公式 $E = k + 2\lambda$ に、$\sum\mu_i^2 = 6$ をそのまま代入しています。

### ポイント

- 非心カイ二乗分布 $\chi^2(k,\ \lambda)$（$\lambda = \sum\mu_i^2$）：$E = k + \lambda$、$V = 2(k + 2\lambda)$。非心度を $\sum\mu_i^2/2$ とする教科書もあるので定義を確認する。
- 対立仮説のもとでのカイ二乗検定統計量の分布として現れ、検出力の計算に使う（$F$ 検定では非心 $F$ 分布、$t$ 検定では非心 $t$ 分布）。
- 積率母関数は $(1 - 2t)^{-k/2}\exp\left(\dfrac{\lambda t}{1 - 2t}\right)$。
