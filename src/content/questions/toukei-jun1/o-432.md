ラグ 2 の偏自己相関係数は、$X_{t-1}$ の影響を取り除いたうえでの $X_t$ と $X_{t-2}$ の相関で、$\hat{\phi}_{22} = \dfrac{r(2) - r(1)^2}{1 - r(1)^2}$ と表せます。$(0.5 - 0.36)/(1 - 0.36) = 0.14/0.64 \approx 0.22$ です。

### 計算

AR(2) のユール・ウォーカー方程式

$$r(1) = \phi_1 + \phi_2 r(1),\qquad r(2) = \phi_1 r(1) + \phi_2$$

を $\phi_1, \phi_2$ について解くと

$$\hat{\phi}_2 = \frac{r(2) - r(1)^2}{1 - r(1)^2} = \frac{0.5 - 0.36}{1 - 0.36} = \frac{0.14}{0.64} = 0.21875$$

$$\hat{\phi}_1 = \frac{r(1)\{1 - r(2)\}}{1 - r(1)^2} = \frac{0.6 \times 0.5}{0.64} = 0.46875$$

偏自己相関係数 $\hat{\phi}_{22}$ は $\hat{\phi}_2$ に等しいので、約 $0.22$ です。

### ポイント

- AR(1) が正しければ $\rho(2) = \rho(1)^2$ なので $\phi_{22} = 0$。この例では $r(2) = 0.5$ が $r(1)^2 = 0.36$ より大きく、その差が偏自己相関として現れる。
- 偏自己相関は、レビンソン・ダービンの漸化式で $\phi_{11}, \phi_{22}, \phi_{33}, \ldots$ と順に計算できる。
- よくある誤り：分子だけの $r(2) - r(1)^2 = 0.14$ を答える、$r(2)$ そのもの 0.5 を答える。
