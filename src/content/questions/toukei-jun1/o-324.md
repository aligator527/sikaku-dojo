  ある資格試験の合否 $Y$（1：合格、0：不合格）を学習時間 $x$（時間）で説明するロジスティック回帰モデル

  $$\log\frac{P(Y = 1 \mid x)}{1 - P(Y = 1 \mid x)} = \beta_0 + \beta_1 x$$

確率 0.8 を対数オッズに直すと $\log(0.8/0.2) = \log 4 = 2\log 2 = 1.386$ です。これを線形予測子と等しいとおいて $-4.2 + 0.08x = 1.386$ を解くと、$x = 5.586/0.08 \approx 69.8$ 時間です。

### 計算

$$\log\frac{0.8}{1 - 0.8} = \log 4 = 2 \times 0.693 = 1.386$$

$$-4.2 + 0.08x = 1.386 \ \Rightarrow\ x = \frac{1.386 + 4.2}{0.08} = \frac{5.586}{0.08} \approx 69.8$$

### ポイント

- 確率 $p$ に対応する $x$ は $x = \{\operatorname{logit}(p) - \beta_0\}/\beta_1$。合格確率 0.5 となるのは $\operatorname{logit}(0.5) = 0$ より $x = 4.2/0.08 = 52.5$ 時間（用量反応の分野では 50% 有効量 ED50 とよぶ）。
- よくある誤り：0.8 をそのまま対数オッズとおいて $(0.8 + 4.2)/0.08 = 62.5$ とする。$\log 0.8$ を使って $(-0.223 + 4.2)/0.08 \approx 49.7$ とする（オッズではなく確率の対数をとっている）。
- 確率は $x$ の線形関数ではないので、52.5 時間で 0.5 だから、と比例計算で求めることはできない。
