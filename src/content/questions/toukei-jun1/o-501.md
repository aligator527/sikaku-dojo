ベータ分布は二項分布（ベルヌーイ試行）の成功確率の共役事前分布です。事前分布 $\mathrm{Beta}(a, b)$ に $n$ 回中 $k$ 回の成功を観測すると、事後分布は $\mathrm{Beta}(a + k,\ b + n - k)$ になります。ここでは $\mathrm{Beta}(8,\ 22)$ となり、事後平均は $8/30 \approx 0.267$ です。

### 計算

事後分布の密度は「尤度 × 事前密度」に比例します。

$$\pi(p \mid \text{データ}) \propto \underbrace{p^{6}(1-p)^{14}}_{\text{尤度}} \times \underbrace{p^{1}(1-p)^{7}}_{\text{事前分布}} = p^{7}(1-p)^{21}$$

これは $\mathrm{Beta}(8,\ 22)$ の密度の形なので

$$E[p \mid \text{データ}] = \frac{8}{8 + 22} = \frac{8}{30} \approx 0.2667$$

事後平均は、事前平均 $2/10 = 0.2$ と標本比率 $6/20 = 0.3$ の重み付き平均としても書けます。

$$\frac{a + k}{a + b + n} = \frac{a + b}{a + b + n}\cdot\frac{a}{a + b} + \frac{n}{a + b + n}\cdot\frac{k}{n} = \frac{10}{30} \times 0.2 + \frac{20}{30} \times 0.3 \approx 0.267$$

事前分布は「成功 2 回・失敗 8 回ぶんの仮想的なデータ」に相当し、その重み $10$ と実データの重み $20$ の比で平均が決まります。

### ポイント

- 共役事前分布の組合せ：ベルヌーイ・二項分布とベータ分布、ポアソン分布とガンマ分布、正規分布（分散既知）の平均と正規分布。
- よくある誤り：事後分布を $\mathrm{Beta}(2 + 14,\ 8 + 6)$ と成功・失敗を逆に足す、標本比率 $0.3$（最尤推定値）をそのまま答える、事後モード $(a + k - 1)/(a + b + n - 2) = 7/28 = 0.25$ と取り違える。
- データが増えるほど標本比率の重みが大きくなり、事後平均は最尤推定値に近づく。
