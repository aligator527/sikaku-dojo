  確率変数 $X$ がポアソン分布 $Po(\lambda)$ に従うとき、標準化した $Z = (X - \lambda)/\sqrt{\lambda}$ の積率母関数の対数は

  $$\log M_Z(t) = \lambda\left(e^{t/\sqrt{\lambda}} - 1\right) - t\sqrt{\lambda}$$

  である。これを $\lambda$ が大きいとして $1/\sqrt{\lambda}$ のべきで展開したとき、0 でない最初の 2 項として正しいものを、次のうちから一つ選べ。
choices:

  - '$\dfrac{t^2}{2} + \dfrac{t^3}{3\sqrt{\lambda}}$'
  - '$\dfrac{t^2}{2} + \dfrac{t^3}{6\lambda}$'
answer: 3

$e^u = 1 + u + u^2/2 + u^3/6 + \cdots$ に $u = t/\sqrt{\lambda}$ を代入すると、$t$ の 1 次の項 $t\sqrt{\lambda}$ が標準化の $-t\sqrt{\lambda}$ と打ち消し合い、$\dfrac{t^2}{2} + \dfrac{t^3}{6\sqrt{\lambda}} + \cdots$ が残ります。$\lambda \to \infty$ で $M_Z(t) \to e^{t^2/2}$（標準正規分布の積率母関数）となるので、ポアソン分布は正規分布で近似できます。

### 計算

$$\lambda\left(e^{t/\sqrt{\lambda}} - 1\right) = \lambda\left(\frac{t}{\sqrt{\lambda}} + \frac{t^2}{2\lambda} + \frac{t^3}{6\lambda^{3/2}} + \frac{t^4}{24\lambda^2} + \cdots\right) = t\sqrt{\lambda} + \frac{t^2}{2} + \frac{t^3}{6\sqrt{\lambda}} + \frac{t^4}{24\lambda} + \cdots$$

$$\log M_Z(t) = \frac{t^2}{2} + \frac{t^3}{6\sqrt{\lambda}} + \frac{t^4}{24\lambda} + \cdots \to \frac{t^2}{2}\qquad (\lambda \to \infty)$$

### 各選択肢の検討

- ①：標準化で引く $-t\sqrt{\lambda}$ を忘れています。この項は $\lambda \to \infty$ で発散します。
- ②：符号の誤りです。ポアソン分布は右に歪んでいる（歪度が正）ので、$t^3$ の項は正になります。
- ③：正しい。
- ④：$e^u$ の展開で $u^3$ の係数を $1/3!$ ではなく $1/3$ としています。
- ⑤：$\lambda \times \lambda^{-3/2} = \lambda^{-1/2}$ のべきの計算を誤っています。

### ポイント

- 連続性定理：積率母関数（または特性関数）が 0 の近くで極限の母関数に収束すれば、分布収束が成り立つ。中心極限定理の標準的な証明もこの方法による。
- $t^3$ の係数は（標準化した 3 次キュムラント）$/3!$ で、ポアソン分布の歪度 $1/\sqrt{\lambda}$ に対応する。正規近似の誤差はおおむね $1/\sqrt{\lambda}$ の大きさで、$\lambda = 100$ なら歪度は $0.1$。
