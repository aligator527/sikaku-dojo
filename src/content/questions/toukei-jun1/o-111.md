多変量正規分布に従うベクトルの 1 次結合の組 $(\boldsymbol{a}^\top\boldsymbol{X},\ \boldsymbol{b}^\top\boldsymbol{X})$ は 2 変量正規分布に従うので、共分散 $\boldsymbol{a}^\top\Sigma\boldsymbol{b}$ が 0 であれば独立です。各組の共分散を計算すると、0 になるのは $X_1 - X_2$ と $X_3$ の組だけです。

### 計算

$\mathrm{Cov}(\boldsymbol{a}^\top\boldsymbol{X},\ \boldsymbol{b}^\top\boldsymbol{X}) = \sum_i\sum_j a_i b_j \sigma_{ij}$ を使います（$\sigma_{ij}$ は $\Sigma$ の $(i, j)$ 成分）。

| 組 | 共分散 |
| --- | --- |
| $X_1$ と $X_2 - X_3$ | $\sigma_{12} - \sigma_{13} = 2 - 1 = 1$ |
| $X_1 + X_2$ と $X_1 - X_2$ | $\sigma_{11} - \sigma_{22} = 4 - 3 = 1$ |
| $X_1 - X_2$ と $X_3$ | $\sigma_{13} - \sigma_{23} = 1 - 1 = 0$ |
| $X_1 - X_3$ と $X_2$ | $\sigma_{12} - \sigma_{23} = 2 - 1 = 1$ |
| $X_1 - 2X_2$ と $X_3$ | $\sigma_{13} - 2\sigma_{23} = 1 - 2 = -1$ |

### 各選択肢の検討

- ①：共分散が 1 で、独立ではありません。
- ②：$\mathrm{Cov}(X_1 + X_2,\ X_1 - X_2) = V[X_1] - V[X_2]$ で、共分散 $\sigma_{12}$ の項は打ち消し合いますが、分散が等しくないので 0 になりません。
- ③：正しい。共分散が 0 で、同時分布が 2 変量正規分布なので独立です。
- ④：共分散が 1 です。
- ⑤：共分散が $-1$ です。

### ポイント

- 「無相関ならば独立」は、同時分布が多変量正規分布のときに成り立つ。周辺分布がそれぞれ正規分布でも、同時に正規分布でなければ成り立たない（例：$Z \sim N(0,\ 1)$ と、独立な符号 $\pm 1$ を掛けた $SZ$ は無相関だが独立でない）。
- $A\boldsymbol{X} \sim N(A\boldsymbol{\mu},\ A\Sigma A^\top)$。共分散行列の非対角成分が 0 のブロックどうしは独立。
