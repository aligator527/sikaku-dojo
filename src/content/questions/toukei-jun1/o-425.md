  長さ $n = 400$ の定常な時系列データについて、標本自己相関係数と標本偏自己相関係数を求めたところ、次のとおりであった。

  | ---------------- | ---- | ---- | ---- | ------- | ---- | ------- |
  | 標本自己相関係数   | 0.66 | 0.57 | 0.47 | 0.36    | 0.29 | 0.22    |

  ホワイトノイズのもとでの目安として、絶対値が $2/\sqrt{n} = 0.10$ を超える値を 0 でないとみなす。

自己相関係数はラグとともにゆっくり減衰し（裾を引き）、偏自己相関係数はラグ 2 までが目安の 0.10 を超え、ラグ 3 以降はほぼ 0 です（打ち切り）。偏自己相関がラグ $p$ で打ち切られるのは AR($p$) の特徴なので、AR(2) が適切です。

### 各選択肢の検討

- ①：AR(1) なら偏自己相関はラグ 2 以降で 0 になります。ラグ 2 の 0.24 は目安 0.10 を大きく超えています。
- ②・③：MA($q$) なら自己相関がラグ $q + 1$ 以降で 0 になり、偏自己相関が裾を引きます。この表では逆のパターンです。
- ④：正しい。
- ⑤：ホワイトノイズなら、すべてのラグで自己相関がほぼ 0 になります。

### ポイント

| モデル     | 自己相関           | 偏自己相関         |
| ---------- | ------------------ | ------------------ |
| AR($p$)    | 減衰（裾を引く）   | ラグ $p$ で打ち切り |
| MA($q$)    | ラグ $q$ で打ち切り | 減衰（裾を引く）   |
| ARMA($p, q$) | 減衰             | 減衰               |

- 偏自己相関係数 $\phi_{kk}$ は、AR($k$) を当てはめたときの最後の係数に等しい。この例では $\phi_{22} \approx 0.24$ から $\phi_2 \approx 0.24$ が見込まれる。
- 両方が裾を引く場合は ARMA を考え、候補のモデルを AIC などで比較する。
