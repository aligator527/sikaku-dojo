ブートストラップ法では、「元データ $\to$ 再標本」の関係を「母集団 $\to$ データ」の関係の代わりに使います。パーセンタイル法は $\hat{\theta}^{*}$ の分位点をそのまま区間の端点にし、基本ブートストラップ法は $\hat{\theta}^{*} - \hat{\theta}$ の分布で $\hat{\theta} - \theta$ の分布を近似して $[2\hat{\theta} - q_{0.975},\ 2\hat{\theta} - q_{0.025}] = [3.0,\ 5.9]$ とします。この 2 つの区間を正しく述べた記述が正解です。

### 計算

- バイアスの推定値：$\overline{\hat{\theta}^{*}} - \hat{\theta} = 5.4 - 5.0 = 0.4$
- バイアス補正した推定値：$\hat{\theta} - 0.4 = 2\hat{\theta} - \overline{\hat{\theta}^{*}} = 4.6$
- 標準誤差の推定値：$\hat{\theta}^{*}$ の標準偏差 $0.8$
- パーセンタイル法：$[q_{0.025},\ q_{0.975}] = [4.1,\ 7.0]$
- 基本ブートストラップ法：$\hat{\theta}^{*} - \hat{\theta}$ の 2.5% 点と 97.5% 点は $-0.9$ と $2.0$。$\hat{\theta} - \theta$ も同じ分布に従うとみなすと、$-0.9 \leq \hat{\theta} - \theta \leq 2.0$ から

$$\hat{\theta} - 2.0 \leq \theta \leq \hat{\theta} + 0.9 \;\Rightarrow\; [3.0,\ 5.9]$$

### 各選択肢の検討

- ①：正しい。$\hat{\theta}^{*}$ の分布が右に歪んでいるため、2 つの方法で区間がかなり異なります。
- ②：誤り。バイアスは $E[\hat{\theta}] - \theta$ に対応する $\overline{\hat{\theta}^{*}} - \hat{\theta} = +0.4$ です。補正は推定量を逆方向に動かし、$4.6$ になります。
- ③：誤り。$\hat{\theta}$ の標準誤差の推定値は $\hat{\theta}^{*}$ の標準偏差 $0.8$ そのものです。$\sqrt{B}$ で割った $0.018$ は、ブートストラップ分布の平均 $5.4$ のモンテカルロ誤差の目安です。
- ④：誤り。正規近似の区間は $\hat{\theta}$ を中心に $5.0 \pm 1.96 \times 0.8$（バイアス補正するなら $4.6 \pm 1.96 \times 0.8$）とします。$\hat{\theta}^{*}$ の平均を中心にするとバイアスを 2 倍にする方向にずれます。
- ⑤：誤り。$B$ を増やして減るのは再標本抽出によるモンテカルロ誤差だけです。区間の幅は元データの大きさ $n$ で決まり、$n$ を増やさない限りほぼ変わりません。

### ポイント

- ブートストラップの 2 つの近似：経験分布で母集団を近似すること（誤差は $n$ で決まる）と、すべての再標本の代わりに $B$ 個で近似すること（誤差は $B$ で決まる）。
- ブートストラップ分布が歪んでいるときは、パーセンタイル法と基本法の区間が大きく異なる。偏りと歪みを補正する BCa 法などもある。
