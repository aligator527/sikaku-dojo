正の側から戻る道は、1 歩目が $+1$、6 歩目が $-1$ で、その間の 4 歩が 1 を下回らずに 1 から 1 に戻る道です。そのような 4 歩は 2 通り（$++--$ と $+-+-$）しかなく、負の側も同様なので、$2^6 = 64$ 通りのうち 4 通り、確率は $1/16 = 0.0625$ です。

### 計算

正の側の道は、$\xi_1 = +1$、$\xi_6 = -1$ で、$S_1 = 1$ から $S_5 = 1$ まで $S_2, S_3, S_4 \geq 1$ を保つ必要があります。

- $\xi_2\xi_3\xi_4\xi_5 = (+, +, -, -)$：$S = 1, 2, 3, 2, 1$
- $\xi_2\xi_3\xi_4\xi_5 = (+, -, +, -)$：$S = 1, 2, 1, 2, 1$

の 2 通りです。負の側も対称に 2 通りあるので

$$f_6 = \frac{4}{2^6} = \frac{1}{16} = 0.0625$$

公式 $f_{2n} = \dfrac{u_{2n}}{2n - 1}$（$u_{2n} = P(S_{2n} = 0) = {}_{2n}\mathrm{C}_n/2^{2n}$）を使っても

$$f_6 = \frac{1}{5}\times\frac{{}_6\mathrm{C}_3}{2^6} = \frac{1}{5}\times\frac{20}{64} = \frac{1}{16}$$

となります。

### ポイント

- 初めて戻る確率は $f_2 = 1/2$、$f_4 = 1/8$、$f_6 = 1/16$、…。$\sum f_{2n} = 1$ なので 1 次元の対称ランダムウォークは再帰的だが、戻るまでの時間の期待値は無限大になる。
- よくある誤り：$P(S_6 = 0) = 20/64 = 0.3125$ を答える。これは途中で原点に戻る道も含む。
- 途中で 0 を通る道を数えるには反射原理が便利。
