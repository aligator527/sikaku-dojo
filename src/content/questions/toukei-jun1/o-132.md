コーシー分布には期待値も分散もないので、大数の法則も中心極限定理も使えません。特性関数で調べると、独立な標準コーシー分布の標本平均は、$n$ によらず再び標準コーシー分布に従います。したがって $P(|\bar{X}| \leq 1) = P(|X_1| \leq 1) = 0.5$ です。

### 計算

標準コーシー分布の特性関数は $\varphi(t) = E[e^{itX}] = e^{-|t|}$ です（積率母関数は $t \neq 0$ で存在しないので、特性関数を使います）。独立性より

$$\varphi_{\bar{X}}(t) = \left\{\varphi\left(\frac{t}{n}\right)\right\}^n = \left(e^{-|t|/n}\right)^n = e^{-|t|}$$

で、$\bar{X}$ も標準コーシー分布に従います。

$$P(|\bar{X}| \leq 1) = \int_{-1}^{1}\frac{dx}{\pi(1 + x^2)} = \frac{1}{\pi}\Big[\arctan x\Big]_{-1}^{1} = \frac{1}{\pi}\left(\frac{\pi}{4} + \frac{\pi}{4}\right) = 0.5$$

### 各選択肢の検討

- ①：大数の法則には $E[|X|] < \infty$ が必要ですが、$\displaystyle\int_{-\infty}^{\infty}\frac{|x|}{\pi(1+x^2)}dx = \infty$ です。標本平均はどこにも収束しません。
- ②：中心極限定理には分散の有限性が必要です。$0.68$ は $N(0,\ 1)$ の $P(|Z| \leq 1)$ です。
- ③：正しい。$n = 1$ でも $n = 100$ でも同じ値です。
- ④：$\bar{X}$ の尺度が $1/\sqrt{100}$ 倍に縮むと考えた値 $\frac{2}{\pi}\arctan 10 \approx 0.94$ です。実際には尺度は変わりません。
- ⑤：$\bar{X}$ の分布は $n$ によらず同じで、広がりも縮みもしません。

### ポイント

- コーシー分布の位置母数は、標本平均ではなく標本中央値で推定する。標本中央値 $\tilde{X}$ は一致推定量で、$\sqrt{n}\,\tilde{X} \xrightarrow{d} N(0,\ \pi^2/4)$。
- 標準コーシー分布は自由度 1 の $t$ 分布であり、独立な 2 つの標準正規分布の比 $Z_1/Z_2$ の分布でもある。
- 外れ値の影響を強く受ける裾の重い分布では、平均にもとづく方法が破綻しうる。
