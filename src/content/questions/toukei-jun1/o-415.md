併合による群内平方和の増加量は、重心間の距離の 2 乗に $n_P n_Q/(n_P + n_Q)$ を掛けたものです。P の重心は $(1, 1)$、Q の重心は $(5, 5)$ で、距離の 2 乗は 32 なので、増加量は $\frac{3 \times 2}{5} \times 32 = 38.4$ です。

### 計算

重心：$\bar{\boldsymbol{x}}_P = (1, 1)$、$\bar{\boldsymbol{x}}_Q = (5, 5)$、$\lVert\bar{\boldsymbol{x}}_P - \bar{\boldsymbol{x}}_Q\rVert^2 = 4^2 + 4^2 = 32$

$$\Delta = \frac{n_P n_Q}{n_P + n_Q}\lVert\bar{\boldsymbol{x}}_P - \bar{\boldsymbol{x}}_Q\rVert^2 = \frac{6}{5} \times 32 = 38.4$$

直接計算による検算：

- P の群内平方和：$(1^2 + 1^2) + (1^2 + 1^2) + (0^2 + 2^2) = 8$
- Q の群内平方和：$(1^2 + 1^2) + (1^2 + 1^2) = 4$
- 併合後の重心 $(13/5,\ 13/5) = (2.6,\ 2.6)$ のまわりの平方和：$13.52 + 7.12 + 2.72 + 3.92 + 23.12 = 50.4$

$$\Delta = 50.4 - (8 + 4) = 38.4$$

### ポイント

- ウォード法は、各段階で群内平方和の増加が最小になる 2 つのクラスターを併合する。大きさのそろった球状のクラスターを作りやすい。
- よくある誤り：重心間の距離の 2 乗 32（重心法の基準）を答える、併合後の群内平方和 50.4 そのものを答える。
- ソフトウェアによっては、デンドログラムの高さとして増加量そのものではなく $\sqrt{2\Delta}$ などを表示する。
