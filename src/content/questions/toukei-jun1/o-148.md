子の数の確率母関数を $G(s) = 0.2 + 0.3s + 0.5s^2$ とすると、1 個体から始めた系統の絶滅確率 $q$ は方程式 $s = G(s)$ の $[0,\ 1]$ における最小の解です。$q = 0.4$ で、3 個体の系統はそれぞれ独立に絶滅するので、求める確率は $0.4^3 = 0.064$ です。

### 計算

$$s = 0.2 + 0.3s + 0.5s^2 \iff 0.5s^2 - 0.7s + 0.2 = 0 \iff (s - 1)(0.5s - 0.2) = 0$$

解は $s = 1$ と $s = 0.4$ です。子の数の平均は $\mu = G'(1) = 0.3 + 2 \times 0.5 = 1.3 > 1$ なので、絶滅確率は 1 未満の解 $q = 0.4$ になります。

最小の解をとる理由：第 $n$ 世代までに絶滅している確率 $q_n = P(Z_n = 0)$ は $q_n = G(q_{n-1})$、$q_0 = 0$ を満たし、$q_1 = 0.2$、$q_2 = G(0.2) = 0.28$、$q_3 = G(0.28) \approx 0.323$、… と増加して、最小の不動点 $0.4$ に収束します。

3 個体から始めたときの絶滅確率は

$$q^3 = 0.4^3 = 0.064$$

です。

### ポイント

- 子の数の平均 $\mu \leq 1$ なら（子の数が常に 1 である場合を除き）確実に絶滅し、$\mu > 1$ なら絶滅確率は 1 未満。
- $k$ 個体から始めると、各個体の子孫の系統は独立なので絶滅確率は $q^k$。
- よくある誤り：1 個体の絶滅確率 $0.4$ のまま答える、$s = 1$ も解であることから絶滅確率を 1 とする、第 1 世代で全滅する確率 $0.2^3 = 0.008$ と混同する。
- 分枝過程は出題範囲表（2027 年 1 月 1 日以降のものを含む）に項目として明記されていないが、確率母関数の応用の典型例である。
