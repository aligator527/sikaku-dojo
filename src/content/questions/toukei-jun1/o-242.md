$X^\top X$ の固有値を $d_j$ とすると、$\operatorname{tr}(H_\lambda) = \operatorname{tr}\{(X^\top X + \lambda I)^{-1}X^\top X\} = \sum_j d_j/(d_j + \lambda)$ です。$\lambda = 3$ では $12/15 + 6/9 + 2/5 = 0.8 + 0.667 + 0.4 \approx 1.87$ です。$\lambda = 0$（最小二乗法）なら自由度は 3 で、罰則によって実質的なパラメータ数が減ります。

### 計算

トレースの性質 $\operatorname{tr}(AB) = \operatorname{tr}(BA)$ より

$$\operatorname{tr}(H_\lambda) = \operatorname{tr}\left\{X(X^\top X + \lambda I)^{-1}X^\top\right\} = \operatorname{tr}\left\{(X^\top X + \lambda I)^{-1}X^\top X\right\}$$

$X^\top X = VDV^\top$（$D = \mathrm{diag}(d_1, d_2, d_3)$、$V$ は直交行列）と固有値分解すると、$(X^\top X + \lambda I)^{-1}X^\top X = V\,\mathrm{diag}\left(\dfrac{d_j}{d_j + \lambda}\right)V^\top$ なので

$$\mathrm{df}(\lambda) = \sum_{j=1}^{3}\frac{d_j}{d_j + \lambda} = \frac{12}{15} + \frac{6}{9} + \frac{2}{5} = 0.800 + 0.667 + 0.400 = 1.867$$

### ポイント

- 固有値の小さい方向（説明変数どうしの相関のため情報の少ない方向）ほど強く縮小される。$d_j = 2$ の主成分方向の係数は $2/5$ 倍に、$d_j = 12$ の方向は $12/15$ 倍に縮む。
- $\mathrm{df}(\lambda)$ は $\lambda = 0$ で $p$、$\lambda \to \infty$ で 0 に向かって単調に減少する。$C_p$ や AIC をリッジ回帰に適用するときは、パラメータ数の代わりにこの有効自由度を使う。
- よくある誤り：縮小された分 $\sum\lambda/(d_j + \lambda) \approx 1.13$ を答える、$p/(1 + \lambda) = 0.75$ とする（$X^\top X = I$ の場合の式）。
- L2 正則化（リッジ回帰）は、2027 年 1 月 1 日以降の出題範囲表に明記されている。
