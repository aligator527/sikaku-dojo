  多数の学校で同じ学力テストを行い、学校 $j$ の平均点 $y_j$ を次の階層モデルで分析する。

  $$y_j \mid \theta_j \sim N(\theta_j,\ \sigma_j^2),\qquad \theta_j \sim N(\mu,\ \tau^2)$$

  ここで $\theta_j$ は学校 $j$ の真の平均点、$\sigma_j$ は $y_j$ の標準誤差（受験者数で決まり既知）である。学校全体のデータから $\mu = 60$、$\tau = 5$ と推定され、以下ではこれらを既知として扱う。

  学校 A は受験者が少なく $y_A = 75,\ \sigma_A = 10$、学校 B は受験者が多く $y_B = 70,\ \sigma_B = 2.5$ であった。$\theta_A$ と $\theta_B$ の事後平均の組合せとして正しいものを次のうちから一つ選べ。
choices:
  - '$\theta_A$：$72$、$\theta_B$：$62$'
  - '$\theta_A$：$65$、$\theta_B$：$66.7$'
  - '$\theta_A$：$75$、$\theta_B$：$70$'
  - '$\theta_A$：$63$、$\theta_B$：$68$'
  - '$\theta_A$：$67.5$、$\theta_B$：$65$'
answer: 4
---
$\theta_j$ の事後分布は、事前分布 $N(\mu, \tau^2)$ と観測 $y_j$ を精度（分散の逆数）で重み付けした正規分布です。事後平均は $\mu$ の方向へ $B_j = \sigma_j^2/(\sigma_j^2 + \tau^2)$ の割合だけ縮小され、A は $B_A = 0.8$ で $63$、B は $B_B = 0.2$ で $68$ です。標準誤差が大きい（情報が少ない）学校ほど全体平均へ強く引き寄せられます。

### 計算

$$E[\theta_j \mid y_j] = \frac{y_j/\sigma_j^2 + \mu/\tau^2}{1/\sigma_j^2 + 1/\tau^2} = B_j\,\mu + (1 - B_j)\,y_j,\qquad B_j = \frac{\sigma_j^2}{\sigma_j^2 + \tau^2}$$

学校 A：

$$B_A = \frac{100}{100 + 25} = 0.8,\qquad E[\theta_A \mid y_A] = 0.8 \times 60 + 0.2 \times 75 = 63$$

学校 B：

$$B_B = \frac{6.25}{6.25 + 25} = 0.2,\qquad E[\theta_B \mid y_B] = 0.2 \times 60 + 0.8 \times 70 = 68$$

観測値は A の方が高いのに、事後平均は B の方が高くなります。

### 各選択肢の検討

- ①：重みを逆にし、$y_j$ に $B_j$ を掛けています。精度が低い観測ほど重みは小さくなります。
- ②：分散ではなく標準偏差の比 $\sigma_j/(\sigma_j + \tau)$ を重みにしています。
- ③：縮小を行わず観測値をそのまま使っています（学校ごとに別々に推定した場合）。
- ④：正しい。
- ⑤：$\mu$ と $y_j$ を単純に平均しています。重みは各学校の精度で変わります。

### ポイント

- 階層ベイズモデルでは、各グループの母数が共通の分布から生じると仮定することで、情報を「借りて」小さなグループの推定を安定させる（縮小推定、partial pooling）。
- $\mu, \tau$ をデータから推定して代入するのが経験ベイズ法、$\mu, \tau$ にも事前分布を置いて MCMC などで同時に推論するのが階層ベイズ法。
- $\tau \to 0$ ではすべての学校が $\mu$ に一致し（完全な併合）、$\tau \to \infty$ では観測値そのもの（併合なし）になる。
