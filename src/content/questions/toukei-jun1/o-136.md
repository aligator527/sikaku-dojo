$g(x) = x^2$ は $g'(0) = 0$ なので、通常のデルタ法では漸近分散が 0 になり、極限分布の情報が得られません。この場合は $\sqrt{n}\,\bar{X}_n \xrightarrow{d} N(0,\ 4)$ と連続写像定理を直接使い、$n\bar{X}_n^2 = (\sqrt{n}\,\bar{X}_n)^2 \xrightarrow{d} 4Z^2$（$Z^2 \sim \chi^2(1)$）となります。

### 計算

中心極限定理より $\sqrt{n}\,\bar{X}_n \xrightarrow{d} N(0,\ 4)$、すなわち $2Z$（$Z \sim N(0,\ 1)$）の分布に収束します。$h(x) = x^2$ は連続なので

$$n\bar{X}_n^2 = \left(\sqrt{n}\,\bar{X}_n\right)^2 \xrightarrow{d} (2Z)^2 = 4Z^2,\qquad Z^2 \sim \chi^2(1)$$

比較のため $\mu \neq 0$ の場合は、$g'(\mu) = 2\mu \neq 0$ なのでデルタ法が使え、$\sqrt{n}(\bar{X}_n^2 - \mu^2) \xrightarrow{d} N(0,\ 4\mu^2\sigma^2) = N(0,\ 16\mu^2)$ です。$\mu = 0$ ではこの分散が 0 になり、$\sqrt{n}$ 倍では足りず、$n$ 倍して初めて非退化の極限が現れます。

### 各選択肢の検討

- ①：$\sqrt{n}\,\bar{X}_n^2$ なら 0 に確率収束しますが、$n\bar{X}_n^2$ は $E[n\bar{X}_n^2] = \sigma^2 = 4$ のまま 0 に近づきません。デルタ法の漸近分散 $4\mu^2\sigma^2 = 0$ を、$n$ 倍のスケールにそのまま当てはめた誤りです。
- ②：$4\chi^2(1)$ と同じ平均 4、分散 $2 \times 4^2 = 32$ をもつ正規分布ですが、極限分布は非負で右に歪んだ分布です。
- ③：倍率 $\sigma^2 = 4$ を落としています。$n\bar{X}_n^2/\sigma^2$ なら $\chi^2(1)$ に収束します。
- ④：正しい。
- ⑤：倍率を $\sigma^4 = 16$ としています。$(\sqrt{n}\,\bar{X}_n)^2$ の倍率は分散 $\sigma^2$ です。

### ポイント

- 2 次のデルタ法：$g'(\theta) = 0$、$g''(\theta) \neq 0$ のとき $n\{g(T_n) - g(\theta)\} \xrightarrow{d} \dfrac{g''(\theta)}{2}\sigma^2\chi^2(1)$。
- 同じ状況は、ベルヌーイ分布の分散の推定量 $\hat{p}(1 - \hat{p})$ の $p = 1/2$ での振る舞いなどでも現れる。
- $E[\bar{X}_n^2] = \mu^2 + \sigma^2/n$ なので $\bar{X}_n^2$ は $\mu^2$ の偏りのある推定量だが、一致推定量である。
