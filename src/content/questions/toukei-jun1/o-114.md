同時密度 $f_{X,Y}(x, y) = 1/x$（$0 < y < x < 1$）を $x$ について積分すると、$Y$ の周辺密度は $f_Y(y) = -\log y$ です。これを $0$ から $1/4$ まで積分して $\dfrac14 + \dfrac14\log 4 \approx 0.597$ となります。

### 計算

$$f_{X,Y}(x, y) = f_X(x)\,f_{Y \mid X}(y \mid x) = 1 \times \frac{1}{x}\qquad (0 < y < x < 1)$$

$$f_Y(y) = \int_y^1 \frac{1}{x}\,dx = -\log y\qquad (0 < y < 1)$$

$$P\left(Y \leq \frac14\right) = \int_0^{1/4}(-\log y)\,dy = \Big[\,y - y\log y\,\Big]_0^{1/4} = \frac14 - \frac14\log\frac14 = \frac14 + \frac{2\log 2}{4}$$

$$= 0.25 + 0.5 \times 0.6931 = 0.25 + 0.3466 \approx 0.597$$

（$y \to 0$ のとき $y\log y \to 0$ です。）

**別解**：条件付き確率を $X$ について平均します。$P(Y \leq 1/4 \mid X = x) = \min\{1,\ 1/(4x)\}$ なので

$$P\left(Y \leq \frac14\right) = \int_0^{1/4} 1\,dx + \int_{1/4}^{1}\frac{1}{4x}\,dx = \frac14 + \frac14\log 4$$

### ポイント

- 階層的に定義された分布は、同時密度 $f_X(x)f_{Y \mid X}(y \mid x)$ を積分して周辺分布を求めるか、条件付き確率の期待値（全確率の公式）で計算する。
- $E[Y] = E\left[E[Y \mid X]\right] = E[X/2] = 1/4$、$V[Y] = E\left[V[Y \mid X]\right] + V\left[E[Y \mid X]\right] = \dfrac{1}{36} + \dfrac{1}{48} = \dfrac{7}{144}$。
- よくある誤り：「$E[Y] = 1/4$ なので $P(Y \leq 1/4) = 1/2$」とする。$Y$ の分布は 0 の近くに偏っていて、中央値（約 0.187）は平均より小さい。
