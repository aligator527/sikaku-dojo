ポアソン分布 $Po(\lambda)$ のキュムラント母関数は $K(t) = \log M_X(t) = \lambda(e^t - 1)$ で、すべての次数のキュムラントが $\kappa_r = \lambda$ になります。歪度は $\kappa_3/\kappa_2^{3/2} = 1/\sqrt{\lambda} = 0.5$、尖度は $\kappa_4/\kappa_2^2 = 1/\lambda = 0.25$ です。

### 計算

$$K(t) = \lambda(e^t - 1) = \lambda\left(t + \frac{t^2}{2!} + \frac{t^3}{3!} + \frac{t^4}{4!} + \cdots\right)$$

$t^r/r!$ の係数が $r$ 次のキュムラント $\kappa_r$ なので、$\kappa_1 = \kappa_2 = \kappa_3 = \kappa_4 = \lambda = 4$ です。キュムラントと中心モーメントの関係は

$$\kappa_2 = \sigma^2,\qquad \kappa_3 = E[(X - \mu)^3],\qquad \kappa_4 = E[(X - \mu)^4] - 3\sigma^4$$

$$\text{歪度} = \frac{\kappa_3}{\kappa_2^{3/2}} = \frac{4}{8} = 0.5,\qquad \text{尖度} = \frac{\kappa_4}{\kappa_2^2} = \frac{4}{16} = 0.25$$

検算：$E[(X - \mu)^4] = \kappa_4 + 3\kappa_2^2 = 4 + 48 = 52$ で、$52/16 - 3 = 0.25$ です。

### 各選択肢の検討

- ①：歪度を $1/\lambda$ としています。$\sigma^3 = \lambda^{3/2}$ で割るので $1/\sqrt{\lambda}$ です。
- ②：正しい。
- ③：$E[(X - \mu)^4]/\sigma^4 = 3.25$ から 3 を引いていません。問題文の尖度は正規分布で 0 となる定義です。
- ④：$\kappa_3/\kappa_2$、$\kappa_4/\kappa_2$ と、標準偏差のべきで割る部分を誤っています。
- ⑤：$\kappa_3 = 4$ を $\sigma = 2$ で 1 回割っただけの値（2）と、$\kappa_4 = 4$ をそのままにした値です。

### ポイント

- $\lambda \to \infty$ で歪度・尖度はともに 0 に近づく。ポアソン分布の正規近似が $\lambda$ の大きいときに有効な理由の一つ。
- 独立な確率変数の和のキュムラントは各キュムラントの和になる。そのため $n$ 個の独立同分布の平均の歪度は $1/\sqrt{n}$ 倍、尖度は $1/n$ 倍になる。
- 指数分布の歪度は 2、尖度は 6。ガンマ分布（形状母数 $k$）では $2/\sqrt{k}$、$6/k$。
