$X_t = X_0 + 0.5t + (\varepsilon_1 + \cdots + \varepsilon_t)$ と書けるので、$E[X_t] = 10 + 0.5t$、$V[X_t] = 4t$ です。$t = 10$ では期待値 15、分散 40 になります。期待値も分散も $t$ に依存するので、定常ではありません。

### 各選択肢の検討

- ①：正しい。
- ②：期待値が $10 + 0.5t$、分散が $4t$ と時点とともに増えるので、定常ではありません。
- ③：独立な誤差が 10 個累積するので、分散は $10 \times 4 = 40$ です。
- ④：$\Delta X_t = 0.5 + \varepsilon_t$ は平均 0.5 の独立な系列（ホワイトノイズに定数を加えたもの）なので、自己相関はすべてのラグで 0 です。$X_t$ はドリフト付きの ARIMA(0,1,0) です。
- ⑤：$X_{n+h} = X_n + 0.5h + \varepsilon_{n+1} + \cdots + \varepsilon_{n+h}$ なので、$h$ 期先予測は $X_n + 0.5h$、誤差分散は $4h$ と $h$ に比例して大きくなります。

### ポイント

- ランダムウォークは単位根過程の代表例。差分をとると定常になる（和分過程、I(1)）。
- ドリフト $\delta$ があると期待値は直線的に増える。トレンド定常過程（$X_t = a + bt + $ 定常過程）とは、予測誤差の分散が $h$ とともに増え続ける点が異なる。
