残差平方和の期待値は $E[\mathrm{RSS}] = (n - p)\sigma^2$ なので、学習誤差の期待値は $\sigma^2(1 - p/n) = 3.6$ です。一方、新しい観測値 $y_i^*$ は $\hat y_i$ と独立なので $E[(y_i^* - \hat y_i)^2] = \sigma^2 + V[\hat y_i]$ で、$\sum_i V[\hat y_i] = \sigma^2\operatorname{tr}(H) = p\sigma^2$ より、予測誤差の期待値は $\sigma^2(1 + p/n) = 4.4$ です。差は $2p\sigma^2/n = 0.80$ です。

### 計算

ハット行列 $H = X(X^\top X)^{-1}X^\top$ は、$\operatorname{tr}(H) = p$ を満たす射影行列です。

$$E\left[\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat y_i)^2\right] = \frac{(n - p)\sigma^2}{n} = \frac{45 \times 4}{50} = 3.6$$

$\hat{\boldsymbol y} = H\boldsymbol y$ の分散共分散行列は $\sigma^2H$ なので、$\sum_i V[\hat y_i] = \sigma^2\operatorname{tr}(H) = p\sigma^2$ です。モデルが正しいので $E[\hat y_i] = E[y_i^*]$ であり、$y_i^*$ と $\hat y_i$ の独立性から

$$E\left[\frac{1}{n}\sum_{i=1}^{n}(y_i^* - \hat y_i)^2\right] = \sigma^2 + \frac{p\sigma^2}{n} = 4 + \frac{5 \times 4}{50} = 4.4$$

$$\text{差} = \frac{2p\sigma^2}{n} = \frac{2 \times 5 \times 4}{50} = 0.80$$

### ポイント

- 学習誤差は予測誤差を平均 $2p\sigma^2/n$ だけ過小評価する（楽観度、optimism）。パラメータが多いほど差は大きい。
- マローズの $C_p$ や AIC は、この差を罰則として学習誤差に加えることで予測誤差を推定する。$C_p$ の罰則 $2p$ や AIC の罰則 $2k$ はここから来ている。
- よくある誤り：片方の偏り $p\sigma^2/n = 0.4$ だけを答える、予測誤差には削減できない誤差 $\sigma^2$ も含まれることを忘れて両者を混同する。
