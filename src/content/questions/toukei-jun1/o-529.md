  次の線形構造方程式モデルを考える。

  $$X = Z + U + \varepsilon_1,\qquad Y = 2X + 3U + \varepsilon_2$$

  ここで $Z, U, \varepsilon_1, \varepsilon_2$ は互いに独立で、いずれも平均 0、分散 1 とする。$U$ は観測されない。

  標本サイズが十分大きいとき、(a) $Y$ を $X$ に単回帰した最小二乗推定量の傾きと、(b) $Z$ を操作変数とした操作変数推定量 $\widehat{\mathrm{Cov}}(Z, Y)/\widehat{\mathrm{Cov}}(Z, X)$ は、それぞれどの値に確率収束するか。正しい組合せを次のうちから一つ選べ。
choices:

  - '(a) $2$、(b) $2$'
  - '(a) $5$、(b) $2$'
  - '(a) $3$、(b) $3$'
  - '(a) $3.5$、(b) $2$'
answer: 1

最小二乗推定量の傾きは $\mathrm{Cov}(X, Y)/V[X]$ に収束します。$X$ と $Y$ には共通原因 $U$ があるため、傾きは $X$ の因果効果 2 に交絡バイアス $3\,\mathrm{Cov}(X, U)/V[X] = 1$ が加わった 3 になります。$Z$ は $X$ に影響し、$U$ とも $\varepsilon_2$ とも独立なので操作変数の条件を満たし、操作変数推定量は因果効果 2 に収束します。

### 計算

$$V[X] = V[Z] + V[U] + V[\varepsilon_1] = 3,\qquad \mathrm{Cov}(X, U) = V[U] = 1$$

$$\mathrm{Cov}(X, Y) = 2V[X] + 3\,\mathrm{Cov}(X, U) = 6 + 3 = 9$$

$$\text{(a)}\quad \frac{\mathrm{Cov}(X, Y)}{V[X]} = \frac{9}{3} = 3$$

$$\mathrm{Cov}(Z, X) = V[Z] = 1,\qquad \mathrm{Cov}(Z, Y) = 2\,\mathrm{Cov}(Z, X) + 3\,\mathrm{Cov}(Z, U) = 2$$

$$\text{(b)}\quad \frac{\mathrm{Cov}(Z, Y)}{\mathrm{Cov}(Z, X)} = \frac{2}{1} = 2$$

標本共分散・標本分散はそれぞれ母共分散・母分散に確率収束するので、連続写像定理により推定量は上の値に収束します。

### 各選択肢の検討

- ①：正しい。
- ②：最小二乗推定量にも交絡バイアスがないと考えています。誤差項 $3U + \varepsilon_2$ と $X$ が相関するため、最小二乗推定量は一致性をもちません。
- ③：$U$ の係数 3 をそのまま足しています。バイアスは $3 \times \mathrm{Cov}(X, U)/V[X] = 3 \times 1/3 = 1$ です。
- ④：操作変数推定量にもバイアスがあると考えています。$\mathrm{Cov}(Z, U) = 0$ なので、操作変数推定量は一致推定量です。
- ⑤：$V[X]$ の計算で $\varepsilon_1$ を落とし $V[X] = 2$ として、$2 + 3 \times 1/2 = 3.5$ としています。

### ポイント

- 欠落変数バイアス：$Y = \beta X + \gamma U + \varepsilon$ で $U$ を落とすと、傾きは $\beta + \gamma\,\mathrm{Cov}(X, U)/V[X]$ に収束する。
- 操作変数推定量は $X$ の変動のうち $Z$ による部分（$U$ と無関係な部分）だけを使って効果を測る。$\mathrm{Cov}(Z, X)$ が小さい（弱い操作変数）と分散が大きくなる。
- $X$ と $Z$ の両方を説明変数に入れた重回帰をしても、$U$ による交絡は除けない。
