MA($q$) モデル $X_t = \varepsilon_t + \theta_1\varepsilon_{t-1} + \cdots + \theta_q\varepsilon_{t-q}$ の自己共分散は、共通に含まれる $\varepsilon$ の係数の積の和で求まります。ラグ 1 では $\varepsilon_{t-1}$ と $\varepsilon_{t-2}$ が共通なので $\gamma(1) = (\theta_1 + \theta_1\theta_2)\sigma^2 = 0.42\sigma^2$、分散は $1.45\sigma^2$ で、$\rho(1) = 0.42/1.45 \approx 0.29$ です。

### 計算

$\theta_0 = 1,\ \theta_1 = 0.6,\ \theta_2 = -0.3$ とすると、$\gamma(h) = \sigma^2\sum_{j}\theta_j\theta_{j+h}$ です。

$$\gamma(0) = (1 + 0.36 + 0.09)\sigma^2 = 1.45\sigma^2$$

$$\gamma(1) = (\theta_0\theta_1 + \theta_1\theta_2)\sigma^2 = (0.6 - 0.18)\sigma^2 = 0.42\sigma^2$$

$$\rho(1) = \frac{0.42}{1.45} \approx 0.2897$$

参考：$\rho(2) = \theta_2/1.45 = -0.3/1.45 \approx -0.207$、$h \geq 3$ では $\rho(h) = 0$ です。

### ポイント

- MA($q$) の自己相関は、ラグ $q$ までは一般に 0 でなく、ラグ $q + 1$ 以降で 0 になる（打ち切り）。次数の同定に使う。
- よくある誤り：MA(1) の公式 $\theta_1/(1 + \theta_1^2) = 0.6/1.36 \approx 0.44$ を使う、$\theta_1\theta_2$ の項を落として $0.6/1.45 \approx 0.41$ とする、符号を誤って $(0.6 + 0.18)/1.45 \approx 0.54$ とする。
