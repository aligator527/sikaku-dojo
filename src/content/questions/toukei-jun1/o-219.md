  確率密度関数

  $$f(x;\mu, b) = \frac{1}{2b}\exp\left(-\frac{|x - \mu|}{b}\right) \qquad (-\infty < x < \infty,\ b > 0)$$

  をもつラプラス分布（両側指数分布）から、次の 7 個のデータを得た。

  $$2,\ 3,\ 5,\ 6,\ 8,\ 11,\ 14$$

choices:

対数尤度は $-n\log(2b) - \frac{1}{b}\sum|x_i - \mu|$ なので、$\mu$ については絶対偏差の和 $\sum|x_i - \mu|$ を最小にする値、つまり標本中央値 $\hat\mu = 6$ が最尤推定値です。$b$ については微分して $\hat b = \frac{1}{n}\sum|x_i - \hat\mu| = 23/7 \approx 3.29$ を得ます。

### 計算

$$\ell(\mu, b) = -n\log(2b) - \frac{1}{b}\sum_{i=1}^{n}|x_i - \mu|$$

どの $b > 0$ に対しても、$\ell$ を最大にする $\mu$ は $\sum|x_i - \mu|$ を最小にする値で、$n = 7$（奇数）なので中央値 $x_{(4)} = 6$ です。次に

$$\frac{\partial\ell}{\partial b} = -\frac{n}{b} + \frac{1}{b^2}\sum|x_i - \hat\mu| = 0 \ \Rightarrow\ \hat b = \frac{1}{n}\sum|x_i - \hat\mu|$$

$|x_i - 6|$ は $4,\ 3,\ 1,\ 0,\ 2,\ 5,\ 8$ で合計 23 なので、$\hat b = 23/7 \approx 3.29$ です。

### 各選択肢の検討

- ①：平均 $\bar x = 7$ を $\mu$ の推定値とし、平均からの絶対偏差の平均 $24/7 \approx 3.43$ を使っています。平均は正規分布の場合の最尤推定値です。
- ②：$\hat\mu$ は正しいが、絶対偏差の和を $n - 1 = 6$ で割っています。
- ③：正規分布と同じように、$\bar x$ と標準偏差（除数 $n$）$\sqrt{112/7} = 4$ を使っています。
- ④：モーメント法の推定値です。ラプラス分布の分散は $2b^2$ なので、$\bar x = 7$ と標本分散 16 から $b = \sqrt{16/2} \approx 2.83$ となります。
- ⑤：正しい。

### ポイント

- $\sum|x_i - \mu|$ を最小にするのは中央値、$\sum(x_i - \mu)^2$ を最小にするのは平均。ラプラス分布の位置の最尤推定は、L1 回帰（最小絶対偏差回帰）につながる。
- $\ell$ は $\mu$ について、データ点で微分できない。微分して 0 とおく代わりに、$\mu$ の左右にあるデータの個数（傾きの符号）から最小点を探す。$n$ が偶数のときは、中央の 2 点の間のどの値も最尤推定値になる。
