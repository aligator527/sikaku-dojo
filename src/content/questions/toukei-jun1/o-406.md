  標準化された 3 つの変数 $x_1, x_2, x_3$ に、1 因子モデル

  $$x_i = l_i f + e_i \qquad (i = 1, 2, 3)$$

1 因子モデルでは、異なる変数の相関係数は因子負荷量の積 $r_{ij} = l_i l_j$ になります。3 つの式から $l_1^2 = r_{12}r_{13}/r_{23} = 0.64$ が求まり、$l_1 = 0.8$、$l_2 = 0.7$、$l_3 = 0.6$ です。標準化した変数の分散は 1 なので、独自分散は $1 - l_2^2 = 0.51$ です。

### 計算

$x_i$ と $x_j$（$i \neq j$）の共分散は、$f$ と $e_i$ の無相関性から $\mathrm{Cov}(x_i, x_j) = l_i l_j V[f] = l_i l_j$ です。

$$l_1^2 = \frac{(l_1 l_2)(l_1 l_3)}{l_2 l_3} = \frac{r_{12}\,r_{13}}{r_{23}} = \frac{0.56 \times 0.48}{0.42} = 0.64 \quad\Rightarrow\quad l_1 = 0.8$$

$$l_2 = \frac{r_{12}}{l_1} = \frac{0.56}{0.8} = 0.7,\qquad l_3 = \frac{r_{13}}{l_1} = \frac{0.48}{0.8} = 0.6$$

（検算：$l_2 l_3 = 0.42 = r_{23}$）

$x_2$ の分散は $1 = l_2^2 + V[e_2]$ と共通性と独自分散に分かれるので

$$V[e_2] = 1 - 0.7^2 = 0.51$$

### ポイント

- 共通性 $h_i^2 = l_i^2$（1 因子の場合）と独自分散 $\psi_i = 1 - h_i^2$ の和が 1（標準化した変数の分散）になる。
- よくある誤り：共通性 $0.49$ を答える、$1 - l_2 = 0.3$ と 2 乗し忘れる、$1 - r_{12} = 0.44$ とする。
- 3 変数・1 因子のモデルは、推定するパラメータ（負荷量 3 個）と相関係数の個数（3 個）が等しく、自由度 0 でちょうど識別される。$r_{12}r_{13} > r_{23}$ だと $l_1^2 > 1$ となり、独自分散が負になる不適解（ヘイウッドケース）が生じる。
