  ある疾患の治療成功の有無 $Y$（1：成功）を、治療法 $T$（1：新薬、0：従来薬）と重症度 $G$（1：重症、0：軽症）で説明するロジスティック回帰モデル

  $$\log\frac{P(Y = 1)}{1 - P(Y = 1)} = \beta_0 + \beta_1 T + \beta_2 G + \beta_3 T G$$

  を当てはめ、次の推定値を得た。

  | 項 | 切片 | $T$ | $G$ | $T G$ |
  | --- | --- | --- | --- | --- |
  | 推定値 | $-0.40$ | $0.90$ | $-1.10$ | $-0.60$ |

  重症患者における、新薬の従来薬に対するオッズ比の推定値として、正しいものを次のうちから一つ選べ。必要なら $e^{0.3} = 1.350$、$e^{0.9} = 2.460$、$e^{-0.6} = 0.549$、$e^{-0.8} = 0.449$、$e^{-1.7} = 0.183$ を用いよ。
choices:

answer: 4

交互作用項があるとき、治療法の効果は重症度によって変わります。重症（$G = 1$）の患者では、新薬と従来薬の対数オッズの差は $\beta_1 + \beta_3 = 0.90 - 0.60 = 0.30$ なので、オッズ比は $e^{0.3} \approx 1.35$ です。

### 計算

重症患者の対数オッズは

- 新薬（$T = 1,\ G = 1$）：$\beta_0 + \beta_1 + \beta_2 + \beta_3 = -0.40 + 0.90 - 1.10 - 0.60 = -1.20$
- 従来薬（$T = 0,\ G = 1$）：$\beta_0 + \beta_2 = -0.40 - 1.10 = -1.50$

差は $0.30$、オッズ比は $e^{0.30} \approx 1.35$ です。軽症患者では差は $\beta_1 = 0.90$、オッズ比は $e^{0.9} \approx 2.46$ で、新薬の効果は重症患者で小さくなっています。

### 各選択肢の検討

- ①：$e^{\beta_2 + \beta_3} = e^{-1.7}$ で、新薬を使う患者どうしで重症と軽症を比べたオッズ比です。
- ②：$e^{\beta_1 + \beta_2 + \beta_3} = e^{-0.8}$ で、「重症・新薬」と「軽症・従来薬」を比べています。重症度もそろっていない比較です。
- ③：交互作用の係数だけを指数変換した $e^{\beta_3}$ です。これは「重症でのオッズ比」と「軽症でのオッズ比」の比（$1.35/2.46$）にあたります。
- ④：正しい。
- ⑤：$e^{\beta_1}$ は $G = 0$（軽症）でのオッズ比です。交互作用があるので、重症患者には当てはまりません。

### ポイント

- 交互作用のあるモデルでは、主効果の係数は「相手の変数が 0 のときの効果」を表す。
- 0/1 の 2 変数とその交互作用からなるこのモデルは 4 つのセルの確率を自由に表せる（飽和モデル）ので、推定されたオッズ比は各重症度での $2 \times 2$ 表の標本オッズ比に一致する。
