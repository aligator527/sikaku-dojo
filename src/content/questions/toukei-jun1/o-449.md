飽和モデルでは $\hat{\mu}_{ij} = n_{ij}$ です。和が 0 の制約のもとでは $\lambda_{11}^{AB} = -\lambda_{12}^{AB} = -\lambda_{21}^{AB} = \lambda_{22}^{AB}$ となるので、対数オッズ比 $\log\dfrac{\mu_{11}\mu_{22}}{\mu_{12}\mu_{21}} = 4\lambda_{11}^{AB}$ が成り立ちます。オッズ比は $(40 \times 30)/(10 \times 20) = 6$ なので、$\hat{\lambda}_{11}^{AB} = \log 6/4 = 0.448$ です。

### 計算

対数オッズ比をモデルの母数で表すと、$\lambda,\ \lambda_i^A,\ \lambda_j^B$ は打ち消し合って

$$\log\frac{\mu_{11}\mu_{22}}{\mu_{12}\mu_{21}} = \lambda_{11}^{AB} - \lambda_{12}^{AB} - \lambda_{21}^{AB} + \lambda_{22}^{AB}$$

制約から $\lambda_{12}^{AB} = \lambda_{21}^{AB} = -\lambda_{11}^{AB}$、$\lambda_{22}^{AB} = \lambda_{11}^{AB}$ なので、右辺は $4\lambda_{11}^{AB}$ です。

$$\hat{\lambda}_{11}^{AB} = \frac{1}{4}\log\frac{40 \times 30}{10 \times 20} = \frac{\log 6}{4} = \frac{1.792}{4} = 0.448$$

### 各選択肢の検討

- ①：符号が逆です。$A_1$ と $B_1$ の組合せは独立の場合より多く観測されているので、$\lambda_{11}^{AB} > 0$ です。
- ②：独立モデル（交互作用項なし）を当てはめた場合の値です。飽和モデルでは交互作用項も推定します。
- ③：正しい。
- ④：$\log 6/2$ で、係数の関係を 2 倍と取り違えています。
- ⑤：対数オッズ比そのものです。第 1 水準を基準（$\lambda_{1j}^{AB} = \lambda_{i1}^{AB} = 0$）にする端点制約なら、$\lambda_{22}^{AB} = \log 6$ になりますが、この問題の制約とは異なります。

### ポイント

- 対数線形モデルの交互作用項はオッズ比と直接対応する。独立性の検定は「$\lambda_{ij}^{AB} = 0$」の検定と同じ。
- 母数の値は制約（和が 0 か、基準カテゴリーを 0 とするか）によって変わるが、オッズ比などの解釈できる量は制約によらない。
- 対数線形モデルは、セル度数をポアソン分布とみなした一般化線形モデル（対数リンク）として推定できる。
