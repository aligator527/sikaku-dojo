間接効果は「$X \to M$ のパス係数」×「$M \to Y$ のパス係数」です。$X \to M$ は単回帰なので相関係数 $0.6$ そのもの、$M \to Y$ は $X$ と $M$ を説明変数とする重回帰の標準偏回帰係数 $(0.6 - 0.5 \times 0.6)/(1 - 0.6^2) = 0.46875$ です。積は $0.6 \times 0.46875 \approx 0.281$ です。

### 計算

標準化した 2 変数の重回帰の標準偏回帰係数は、相関係数から次のように求まります。

$$c' = \frac{r_{XY} - r_{XM}\,r_{MY}}{1 - r_{XM}^2} = \frac{0.5 - 0.36}{0.64} = 0.21875 \quad (X \to Y\text{、直接効果})$$

$$b = \frac{r_{MY} - r_{XY}\,r_{XM}}{1 - r_{XM}^2} = \frac{0.6 - 0.30}{0.64} = 0.46875 \quad (M \to Y)$$

$$a = r_{XM} = 0.6 \quad (X \to M)$$

$$\text{間接効果} = a \times b = 0.6 \times 0.46875 = 0.28125 \approx 0.281$$

$$\text{総合効果} = c' + ab = 0.21875 + 0.28125 = 0.5 = r_{XY}$$

交絡がないので、総合効果は $Y$ を $X$ だけに回帰したときの係数（ここでは相関係数）に一致します。

### 各選択肢の検討

- ①：$c'$ の分子 $r_{XY} - r_{XM}r_{MY} = 0.14$ だけを計算し、$1 - r_{XM}^2$ で割り忘れています（しかもこれは直接効果側の量です）。
- ②：直接効果 $c'$ です。
- ③：正しい。
- ④：$M \to Y$ のパス係数として、$X$ を調整しない相関係数 $r_{MY} = 0.6$ を使い、$0.6 \times 0.6$ としています。$r_{MY}$ には $M \leftarrow X \to Y$ を通じた見かけの関連が含まれます。
- ⑤：総合効果です。

### ポイント

- 線形の構造方程式モデルでは、ある変数から別の変数への効果は「経路上のパス係数の積」を全経路で足したものになる（総合効果 = 直接効果 + 間接効果）。
- 間接効果を因果的に解釈するには、$X$–$M$、$M$–$Y$、$X$–$Y$ のそれぞれに未観測の交絡がないことが必要。とくに $M$ と $Y$ の交絡は、$X$ を無作為化しても取り除けない。
