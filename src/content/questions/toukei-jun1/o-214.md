ジャックナイフ法では、除去推定値の平均 $\bar\theta_{(\cdot)}$ を使ってバイアスを $(n - 1)(\bar\theta_{(\cdot)} - \hat\theta)$ と推定し、これを $\hat\theta$ から引きます。$\bar\theta_{(\cdot)} = 10.875$ なので、バイアスの推定値は $4 \times (10.875 - 11.6) = -2.9$、補正後の推定値は $11.6 + 2.9 = 14.5$ です。これは不偏分散 $58/4 = 14.5$ に一致します。

### 計算

$$\bar\theta_{(\cdot)} = \frac{9.5 + 13.25 + 14.1875 + 14.1875 + 3.25}{5} = \frac{54.375}{5} = 10.875$$

$$\widehat{\text{バイアス}} = (n - 1)(\bar\theta_{(\cdot)} - \hat\theta) = 4 \times (10.875 - 11.6) = -2.9$$

$$\hat\theta_J = \hat\theta - \widehat{\text{バイアス}} = n\hat\theta - (n - 1)\bar\theta_{(\cdot)} = 58 - 43.5 = 14.5$$

$\bar x = 6$ で偏差平方和は $16 + 4 + 1 + 1 + 36 = 58$ なので、不偏分散は $58/4 = 14.5$ となり、ジャックナイフ補正後の値と一致します。

### 各選択肢の検討

- ①：バイアス推定値 $-2.9$ を引くべきところで足しています（$11.6 - 2.9$）。
- ②：除去推定値の平均そのものです。補正では $n\hat\theta - (n - 1)\bar\theta_{(\cdot)}$ のように外挿します。
- ③：係数 $n - 1$ を掛け忘れ、バイアスを $10.875 - 11.6 = -0.725$ としています。
- ④：正しい。
- ⑤：係数を $n - 1$ ではなく $n$ としています（$11.6 + 5 \times 0.725$）。

### ポイント

- ジャックナイフのバイアス補正は、$E[\hat\theta] = \theta + a/n + O(1/n^2)$ の形のバイアスのうち $1/n$ の項を消す。$\frac{1}{n}\sum(x_i - \bar x)^2$ のバイアスはちょうど $-\sigma^2/n$ なので、補正後は厳密に不偏な $S^2$ になる。
- ジャックナイフ標準誤差は $\sqrt{\frac{n-1}{n}\sum_i(\hat\theta_{(i)} - \bar\theta_{(\cdot)})^2}$。ブートストラップと同様、解析的に分散を求めにくい統計量で使う。
