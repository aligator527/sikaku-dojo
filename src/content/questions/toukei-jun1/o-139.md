$n$ か月後のシェアは、今月のシェアを表す行ベクトル $\pi^{(0)}$ に推移確率行列を $n$ 回右から掛けた $\pi^{(0)}P^n$ です。1 か月後は $(0.42,\ 0.38,\ 0.20)$、2 か月後の A のシェアは $0.372$ です。

### 計算

1 か月後：$\pi^{(1)} = \pi^{(0)}P$

$$\pi^{(1)}_A = 0.5 \times 0.7 + 0.3 \times 0.1 + 0.2 \times 0.2 = 0.42$$

$$\pi^{(1)}_B = 0.5 \times 0.2 + 0.3 \times 0.8 + 0.2 \times 0.2 = 0.38,\qquad \pi^{(1)}_C = 0.5 \times 0.1 + 0.3 \times 0.1 + 0.2 \times 0.6 = 0.20$$

2 か月後：

$$\pi^{(2)}_A = 0.42 \times 0.7 + 0.38 \times 0.1 + 0.20 \times 0.2 = 0.294 + 0.038 + 0.040 = 0.372$$

先に $P^2$ の A 列 $(0.53,\ 0.17,\ 0.28)^\top$ を求めて $0.5 \times 0.53 + 0.3 \times 0.17 + 0.2 \times 0.28 = 0.372$ としても同じです。

### ポイント

- チャップマン・コルモゴロフの等式：$P^{(m+n)} = P^{(m)}P^{(n)}$。$n$ ステップ後の分布は $\pi^{(n)} = \pi^{(0)}P^n$（行ベクトルを左から掛ける）。
- よくある誤り：$P^2$ の $(A,\ A)$ 成分 $0.53$（全員が A から始めた場合）を答える、1 か月後の $0.42$ で止める、シェアに行 A の成分を掛けて $0.5 \times 0.7 + 0.3 \times 0.2 + 0.2 \times 0.1 = 0.43$ とする。
- この連鎖の定常分布は $(0.3,\ 0.5,\ 0.2)$ で、A のシェアは長期的に 0.3 に近づく。
