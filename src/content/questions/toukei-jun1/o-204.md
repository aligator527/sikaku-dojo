対数尤度から $\hat p = 1/\bar x = 40/160 = 0.25$ を得ます。1 回の観測のフィッシャー情報量は $I(p) = 1/\{p^2(1 - p)\}$ なので、$\hat p$ の漸近分散は $p^2(1 - p)/n$ です。$p = 0.25$ を代入すると、標準誤差は $\sqrt{0.0625 \times 0.75/40} \approx 0.0342$ です。

### 計算

$$\ell(p) = n\log p + \left(\sum x_i - n\right)\log(1 - p)$$

$$\ell'(p) = \frac{n}{p} - \frac{\sum x_i - n}{1 - p} = 0 \ \Rightarrow\ \hat p = \frac{n}{\sum x_i} = \frac{40}{160} = 0.25$$

2 階微分は

$$\ell''(p) = -\frac{n}{p^2} - \frac{\sum x_i - n}{(1 - p)^2}$$

です。$E[X] = 1/p$ より $E\left[\sum X_i - n\right] = n(1 - p)/p$ なので、標本全体のフィッシャー情報量は

$$I_n(p) = \frac{n}{p^2} + \frac{n(1 - p)/p}{(1 - p)^2} = \frac{n}{p^2} + \frac{n}{p(1 - p)} = \frac{n}{p^2(1 - p)}$$

したがって

$$\mathrm{SE}(\hat p) \approx \sqrt{\frac{\hat p^2(1 - \hat p)}{n}} = \sqrt{\frac{0.0625 \times 0.75}{40}} = \sqrt{0.001172} \approx 0.0342$$

観測情報量 $-\ell''(\hat p) = 40/0.0625 + 120/0.5625 = 640 + 213.3 = 853.3$ を使っても同じ値になります（$1/\sqrt{853.3} \approx 0.0342$）。

### ポイント

- 最尤推定量の漸近分散は $1/I_n(\theta)$（クラーメル・ラオの下限と同じ形）。未知の $\theta$ には最尤推定値を代入する。
- よくある誤り：二項分布の式 $\sqrt{\hat p(1 - \hat p)/n} \approx 0.068$ を使う（「40 回の試行のうちの成功数」ではなく「成功までの回数」のデータであることを見落とす）、標準誤差ではなく分散 $0.0012$ を答える。
