$M$ は $X$ から $Y$ への道をすべて仲介し、$X \to M$ にはバックドアパスがなく、$M \to Y$ のバックドアパス $M \leftarrow X \leftarrow U \to Y$ は $X$ で遮断できるので、$M$ はフロントドア基準を満たします。フロントドア調整公式で計算すると $P(Y = 1 \mid do(X = 1)) = 0.257$、$P(Y = 1 \mid do(X = 0)) = 0.166$ で、因果効果は $0.091$ です。

### 計算

フロントドア調整公式：

$$P(y \mid do(x)) = \sum_{m} P(m \mid x)\sum_{x'} P(y \mid x', m)\,P(x')$$

まず、$M$ を $m$ に固定したときの $Y$ への効果（$X$ で調整したバックドア調整）を求めます。

$$\sum_{x'} P(Y = 1 \mid x', M = 1)P(x') = 0.30 \times 0.4 + 0.25 \times 0.6 = 0.27$$

$$\sum_{x'} P(Y = 1 \mid x', M = 0)P(x') = 0.20 \times 0.4 + 0.10 \times 0.6 = 0.14$$

次に、$X$ から $M$ への効果（交絡がないので条件付き確率そのもの）で重み付けます。

$$P(Y = 1 \mid do(X = 1)) = 0.9 \times 0.27 + 0.1 \times 0.14 = 0.257$$

$$P(Y = 1 \mid do(X = 0)) = 0.2 \times 0.27 + 0.8 \times 0.14 = 0.166$$

$$\text{因果効果} = 0.257 - 0.166 = 0.091$$

（2 値の場合は $\{P(M = 1 \mid X = 1) - P(M = 1 \mid X = 0)\} \times (0.27 - 0.14) = 0.7 \times 0.13 = 0.091$ と、2 段階の効果の積にもなります。）

### ポイント

- 単純な比較 $P(Y = 1 \mid X = 1) - P(Y = 1 \mid X = 0) = 0.29 - 0.13 = 0.16$ は、$U$ による交絡を含むので因果効果を過大評価する。
- よくある誤り：内側の和で $P(x')$ の代わりに $P(x' \mid m)$ や $X = x$ の値だけを使う（それでは $X$ による調整にならない）、$M$ をバックドア調整の変数として $\sum_m P(y \mid x, m)P(m)$ とする（$M$ は $X$ の子孫なのでバックドア基準を満たさない）。
- フロントドア基準は、交絡因子が観測できなくても、交絡のない仲介変数があれば因果効果を識別できることを示す。2027 年の準1級範囲表に明記された項目の一つ。
