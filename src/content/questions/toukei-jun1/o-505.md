提案分布が対称でないので、メトロポリス・ヘイスティングス法の採択確率には提案分布の比（ヘイスティングス補正）が入ります。

$$\alpha(\theta \to \theta') = \min\left\{1,\ \frac{\pi(\theta')\,q(\theta \mid \theta')}{\pi(\theta)\,q(\theta' \mid \theta)}\right\}$$

独立型の提案では $q(\theta' \mid \theta) = q(\theta')$ なので、比は $\dfrac{\pi(\theta')/q(\theta')}{\pi(\theta)/q(\theta)} = \dfrac{\theta'^2}{\theta^2} = \dfrac{1}{4}$ です。

### 計算

$$\frac{\pi(\theta')}{\pi(\theta)} = \frac{1^2 e^{-1}}{2^2 e^{-2}} = \frac{e}{4},\qquad \frac{q(\theta)}{q(\theta')} = \frac{e^{-2}}{e^{-1}} = e^{-1}$$

$$\alpha = \min\left\{1,\ \frac{e}{4} \times e^{-1}\right\} = \frac{1}{4}$$

目標分布の正規化定数 $1/\Gamma(3) = 1/2$ は比をとると消えるので、計算に必要ありません。

### 各選択肢の検討

- ①：密度の $\theta^{2}$ を $\theta^{3}$（形状母数の 3 をそのまま指数にした）と誤り、$(1/2)^3$ としています。ガンマ分布の密度は $\theta^{k-1}e^{-\theta}$ に比例します。
- ②：正しい。
- ③：指数を 1 として $\theta'/\theta$ を計算しています（形状母数 2 のガンマ分布と取り違えた）。
- ④：提案分布の比を掛け忘れ、対称な提案（ランダムウォーク型）のメトロポリス法の採択確率 $\min\{1,\ \pi(\theta')/\pi(\theta)\}$ を使っています。
- ⑤：比の分子と分母を逆にして $4$ を得たか、提案分布の比を $q(\theta')/q(\theta)$ と逆に掛けて $e^2/4 > 1$ を得たときの値です。

### ポイント

- 独立型の提案では、重み $w(\theta) = \pi(\theta)/q(\theta)$ を使って $\alpha = \min\{1,\ w(\theta')/w(\theta)\}$ と書ける。ここでは $w(\theta) \propto \theta^2$ なので、値が小さくなる方向への移動は採択されにくい。
- ヘイスティングス補正により、詳細つり合い条件 $\pi(\theta)\,q(\theta' \mid \theta)\,\alpha(\theta \to \theta') = \pi(\theta')\,q(\theta \mid \theta')\,\alpha(\theta' \to \theta)$ が成り立ち、目標分布が連鎖の定常分布になる。
- 独立型の提案分布は、目標分布より裾が重い（$w$ が有界になる）ものを選ぶのが望ましい。
