多項分布の対数尤度は $(2n_1 + n_2)\log\theta + (n_2 + 2n_3)\log(1 - \theta)$ + 定数 となり、$\hat\theta = (2n_1 + n_2)/(2n) = 180/300 = 0.6$ です（A 遺伝子の個数の割合と同じ）。フィッシャー情報量は $I_n(\theta) = 2n/\{\theta(1 - \theta)\}$ なので、標準誤差は $\sqrt{0.24/300} \approx 0.0283$、上限は $0.6 + 1.96 \times 0.0283 \approx 0.655$ です。

### 計算

遺伝子型の人数を $n_1 = 50,\ n_2 = 80,\ n_3 = 20$ とすると

$$\ell(\theta) = n_1\log\theta^2 + n_2\log\{2\theta(1 - \theta)\} + n_3\log(1 - \theta)^2 = (2n_1 + n_2)\log\theta + (n_2 + 2n_3)\log(1 - \theta) + \text{定数}$$

$$\ell'(\theta) = \frac{2n_1 + n_2}{\theta} - \frac{n_2 + 2n_3}{1 - \theta} = 0 \ \Rightarrow\ \hat\theta = \frac{2n_1 + n_2}{2n} = \frac{100 + 80}{300} = 0.6$$

$E[2n_1 + n_2] = 2n\theta$、$E[n_2 + 2n_3] = 2n(1 - \theta)$ より

$$I_n(\theta) = E\left[\frac{2n_1 + n_2}{\theta^2} + \frac{n_2 + 2n_3}{(1 - \theta)^2}\right] = \frac{2n}{\theta} + \frac{2n}{1 - \theta} = \frac{2n}{\theta(1 - \theta)}$$

$$\mathrm{SE}(\hat\theta) \approx \sqrt{\frac{\hat\theta(1 - \hat\theta)}{2n}} = \sqrt{\frac{0.24}{300}} = \sqrt{0.0008} \approx 0.02828$$

$$\text{上限} = 0.6 + 1.96 \times 0.02828 \approx 0.6 + 0.0554 = 0.6554 \approx 0.655$$

（下限は約 $0.545$）

### ポイント

- 各人は遺伝子を 2 個もつので、実質的に $2n = 300$ 個の遺伝子についての二項分布と同じ情報をもつ。標準誤差の分母が $n$ ではなく $2n$ になる。
- よくある誤り：$\sqrt{\hat\theta(1 - \hat\theta)/n} = 0.04$ を使って上限を $0.678$ とする、AA の割合 $50/150$ だけから $\theta = \sqrt{1/3} \approx 0.577$ と推定する（情報の一部しか使っていない）。
- 平衡の仮定そのものは、期待度数 $150 \times (0.36,\ 0.48,\ 0.16) = (54,\ 72,\ 24)$ との適合度検定（自由度 $3 - 1 - 1 = 1$）で確かめられる。
