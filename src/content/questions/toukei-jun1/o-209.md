$E[X] = \theta/2$ なので、標本平均と等置するとモーメント推定値は $2\bar x = 2 \times 2.44 = 4.88$ です。一方、尤度は $\theta \ge \max x_i$ の範囲で $\theta^{-5}$ となり、$\theta$ について単調減少なので、最尤推定値は最大値 $x_{(5)} = 4.10$ です。

### 計算

$\bar x = (1.2 + 3.5 + 0.8 + 2.6 + 4.1)/5 = 12.2/5 = 2.44$ より、$\hat\theta_{\mathrm{MM}} = 2\bar x = 4.88$ です。

尤度は

$$L(\theta) = \prod_{i=1}^{5}\frac{1}{\theta}\mathbf{1}(0 \le x_i \le \theta) = \begin{cases}\theta^{-5} & (\theta \ge x_{(5)})\\ 0 & (\theta < x_{(5)})\end{cases}$$

です。$\theta^{-5}$ は減少関数なので、$\theta$ がとりうる最小の値 $x_{(5)} = 4.1$ のとき最大になります。微分して 0 とおく方法は使えません。

### 各選択肢の検討

- ①：$E[X] = \theta/2$ の 2 倍を忘れ、$\bar x$ をそのまま推定値にしています。
- ②：正しい。
- ③：$4.92 = \frac{6}{5}x_{(5)}$ は、最尤推定量のバイアスを補正した不偏推定量 $\frac{n+1}{n}X_{(n)}$ の値で、最尤推定値ではありません。
- ④：2 つの推定値を取り違えています。
- ⑤：「最尤推定量はモーメント推定量と一致する」と考えた誤りです。正規分布やポアソン分布の平均では一致しますが、一様分布では一致しません。

### ポイント

- 台（値をとる範囲）がパラメータに依存する分布では、尤度は微分ではなく単調性から最大化する。
- $E[X_{(n)}] = \frac{n}{n+1}\theta$ なので、最尤推定量 $X_{(n)}$ は過小推定のバイアスをもつ。また、モーメント推定値 $2\bar x$ は観測された最大値より小さくなることがあり、その場合はデータと矛盾する値になる。
