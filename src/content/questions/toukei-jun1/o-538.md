入院は A と B の両方の結果である合流点（$A \to S \leftarrow B$）なので、入院患者だけで分析すると、母集団では独立な A と B の間に見かけの負の関連が生じます（バークソンのバイアス）。入院患者における各セルの割合を計算すると、オッズ比は $\dfrac{0.048 \times 0.028}{0.056 \times 0.120} = 0.2$ となります。

### 計算

入院を $S = 1$ とし、$P(A = a, B = b, S = 1) = P(A = a)P(B = b)P(S = 1 \mid a, b)$ を計算します。

| | B あり | B なし |
| --- | --- | --- |
| A あり | $0.2 \times 0.3 \times 0.80 = 0.048$ | $0.2 \times 0.7 \times 0.40 = 0.056$ |
| A なし | $0.8 \times 0.3 \times 0.50 = 0.120$ | $0.8 \times 0.7 \times 0.05 = 0.028$ |

$$\mathrm{OR} = \frac{0.048 \times 0.028}{0.056 \times 0.120} = \frac{0.001344}{0.00672} = 0.2$$

A と B が独立なので有病割合の部分は打ち消し合い、オッズ比は入院確率だけで決まります。

$$\mathrm{OR} = \frac{P(S \mid 1, 1)\,P(S \mid 0, 0)}{P(S \mid 1, 0)\,P(S \mid 0, 1)} = \frac{0.80 \times 0.05}{0.40 \times 0.50} = 0.2$$

条件付き確率で見ると、入院患者のうち B ありの人で A ありの割合は $0.048/0.168 \approx 0.286$、B なしの人では $0.056/0.084 \approx 0.667$ で、「B があると A が少ない」ように見えます。

### ポイント

- 母集団でのオッズ比は 1（独立）。合流点（ここでは入院）で選択・層別すると、原因どうしに見かけの関連が生じる。入院確率が乗法的（$P(S \mid 1, 1)P(S \mid 0, 0) = P(S \mid 1, 0)P(S \mid 0, 1)$）なら偏りは生じない。
- よくある誤り：有病割合 0.2 と 0.3 から関連を計算しようとする、入院患者に占める割合ではなく入院確率の表をそのまま分割表として扱う。
- 病院・登録データ・志願者など「選ばれた集団」だけを分析するときに起こる選択バイアスの典型例。
