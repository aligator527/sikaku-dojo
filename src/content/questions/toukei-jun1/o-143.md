所持金 $k$ 万円から 6 万円に達する確率を $h_k$ とし、1 回目の賭けの結果で場合分けすると $h_k = 0.6h_{k+1} + 0.4h_{k-1}$ が成り立ちます。境界条件 $h_0 = 0$、$h_6 = 1$ のもとで解くと $h_k = \dfrac{1 - (2/3)^k}{1 - (2/3)^6}$ で、$h_3 = 27/35 \approx 0.771$ です（ギャンブラーの破産問題）。

### 計算

$$h_k = 0.6\,h_{k+1} + 0.4\,h_{k-1}\quad (1 \leq k \leq 5),\qquad h_0 = 0,\quad h_6 = 1$$

特性方程式 $0.6x^2 - x + 0.4 = 0$ の解は $x = 1,\ 2/3$ なので、一般解は $h_k = A + B(2/3)^k$ です。境界条件から

$$h_k = \frac{1 - r^k}{1 - r^6},\qquad r = \frac{q}{p} = \frac{0.4}{0.6} = \frac{2}{3}$$

$$h_3 = \frac{1 - r^3}{1 - r^6} = \frac{1}{1 + r^3} = \frac{1}{1 + 8/27} = \frac{27}{35} \approx 0.771$$

（$1 - r^6 = (1 - r^3)(1 + r^3)$ を使いました。）

### ポイント

- 公平な賭け（$p = 1/2$）なら $h_k = k/N$ で、ここでは $0.5$。1 回あたりわずかに有利なだけで $0.771$ まで上がる。
- 上限をなくす（$N \to \infty$）と、$p > 1/2$ のとき破産確率は $r^k = (2/3)^3 \approx 0.296$ に収束する。
- よくある誤り：$r = p/q = 1.5$ と逆にして $\dfrac{1 - 1.5^3}{1 - 1.5^6} \approx 0.229$（これは破産する確率）とする。
