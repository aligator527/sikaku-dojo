説明変数が 0/1 の 1 つだけなので、2 つのパラメータで 2 群の購入確率を自由に表せます（飽和モデル）。このとき最尤推定値は観測割合を再現し、$\Phi(\hat{\beta}_0) = 0.2$、$\Phi(\hat{\beta}_0 + \hat{\beta}_1) = 0.7$ となります。$\hat{\beta}_0 = -0.842$、$\hat{\beta}_0 + \hat{\beta}_1 = 0.524$ より $\hat{\beta}_1 = 1.366 \approx 1.37$ です。

### 計算

$p_0 = \Phi(\beta_0)$、$p_1 = \Phi(\beta_0 + \beta_1)$ とおくと、対数尤度は

$$\ell = 40\log p_0 + 160\log(1 - p_0) + 140\log p_1 + 60\log(1 - p_1)$$

$(\beta_0, \beta_1)$ と $(p_0, p_1)$ は 1 対 1 に対応するので、$p_0, p_1$ について最大化すればよく、$\hat{p}_0 = 40/200 = 0.2$、$\hat{p}_1 = 140/200 = 0.7$ です。したがって

$$\hat{\beta}_0 = \Phi^{-1}(0.2) = -0.842,\qquad \hat{\beta}_0 + \hat{\beta}_1 = \Phi^{-1}(0.7) = 0.524$$

$$\hat{\beta}_1 = 0.524 - (-0.842) = 1.366$$

$\Phi^{-1}(0.2)$ は下側 20% 点で、上側 20% 点の符号を変えた値です。$\Phi^{-1}(0.7)$ は上側 30% 点です。

### ポイント

- 同じデータにロジスティック回帰を当てはめると、$\hat{\beta}_1 = \log\dfrac{0.7}{0.3} - \log\dfrac{0.2}{0.8} \approx 0.847 + 1.386 = 2.234$ で、プロビットの約 1.6 倍になる。ロジスティック分布の標準偏差は $\pi/\sqrt{3} \approx 1.81$ なので、係数の比はおおむね 1.6〜1.8 になる。
- プロビットモデルは潜在変数 $Y^* = \beta_0 + \beta_1 x + \varepsilon$、$\varepsilon \sim N(0, 1)$ が 0 を超えたとき $Y = 1$ となるモデルとして解釈できる。誤差の分散を 1 に固定しているため、係数の大きさは潜在変数の標準偏差を単位として読む。
- よくある誤り：$\Phi^{-1}(0.2) = +0.842$ として $0.524 - 0.842 = -0.318$ とする。確率の差 $0.7 - 0.2 = 0.5$ を係数とする。
