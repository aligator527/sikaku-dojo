  非負の整数値をとる確率変数 $X$ の確率母関数が

  $$G_X(s) = E\left[s^X\right] = (0.2 + 0.8s)^5\, e^{3(s - 1)}$$

  で与えられている。$X$ の期待値 $E[X]$ と分散 $V[X]$ の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - '$E[X] = 4,\ V[X] = 3.8$'
  - '$E[X] = 7,\ V[X] = 2.4$'
  - '$E[X] = 7,\ V[X] = 3.8$'
  - '$E[X] = 7,\ V[X] = 7$'
  - '$E[X] = 7,\ V[X] = 45.8$'
answer: 3

確率母関数の積は、独立な確率変数の和の確率母関数です。$(0.2 + 0.8s)^5$ は二項分布 $B(5,\ 0.8)$、$e^{3(s-1)}$ はポアソン分布 $Po(3)$ の確率母関数なので、$X$ は独立な $Y \sim B(5,\ 0.8)$ と $Z \sim Po(3)$ の和 $Y + Z$ と同じ分布に従います。よって $E[X] = 4 + 3 = 7$、$V[X] = 0.8 + 3 = 3.8$ です。

### 計算

母関数を微分しても求められます。$G_X'(1) = E[X]$、$G_X''(1) = E[X(X-1)]$ です。積の微分を避けるため、対数 $H(s) = \log G_X(s)$ を使います。

$$H(s) = 5\log(0.2 + 0.8s) + 3(s - 1)$$

$$H'(s) = \frac{4}{0.2 + 0.8s} + 3,\qquad H''(s) = -\frac{3.2}{(0.2 + 0.8s)^2}$$

$G_X(1) = 1$ なので $H'(1) = G_X'(1) = E[X]$、$H''(1) = G_X''(1) - G_X'(1)^2 = V[X] - E[X]$ が成り立ちます。

$$E[X] = H'(1) = 4 + 3 = 7,\qquad V[X] = H''(1) + H'(1) = -3.2 + 7 = 3.8$$

なお $G_X''(1) = E[X(X-1)] = V[X] + E[X]^2 - E[X] = 3.8 + 49 - 7 = 45.8$ です。

### 各選択肢の検討

- ①：二項分布の成功確率を $0.2$ と読み違え、$E[X] = 5 \times 0.2 + 3 = 4$ としています。$(1 - p + ps)^n$ では $s$ の係数が成功確率 $p$ です（分散 $np(1-p)$ は $p$ と $1-p$ を入れ替えても変わらないので $3.8$ のままです）。
- ②：母関数が積なので分散も積 $0.8 \times 3 = 2.4$ になると考えています。独立な和では母関数が積になり、分散は和になります。
- ③：正しい。
- ④：全体をポアソン分布とみなし、分散を期待値と同じ 7 としています。二項分布の部分は分散 $0.8$ が期待値 $4$ より小さくなります。
- ⑤：$G_X''(1) = E[X(X-1)] = 45.8$ を分散としています。分散は $G_X''(1) + G_X'(1) - G_X'(1)^2$ です。

### ポイント

- $G_X'(1) = E[X]$、$G_X''(1) = E[X(X-1)]$（2 次の階乗モーメント）、$V[X] = G_X''(1) + G_X'(1) - G_X'(1)^2$。
- 確率母関数からは確率そのものも $P(X = k) = G_X^{(k)}(0)/k!$ で得られる。例えば $P(X = 0) = G_X(0) = 0.2^5 e^{-3}$。
- 主な確率母関数：二項分布 $(1 - p + ps)^n$、ポアソン分布 $e^{\lambda(s-1)}$、幾何分布（初めて成功するまでの試行回数）$ps/\{1 - (1-p)s\}$。
