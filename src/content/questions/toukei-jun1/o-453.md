ルービンのルールでは、統合した推定値の分散を「補完内分散の平均 $\bar{W}$」と「補完間分散 $B$ に $(1 + 1/m)$ を掛けたもの」の和 $T = \bar{W} + (1 + 1/m)B$ とします。$\bar{W} = 0.30$、$B = 0.125$ なので $T = 0.30 + 1.2 \times 0.125 = 0.45$、標準誤差は $\sqrt{0.45} \approx 0.67$ です。

### 計算

$$\bar{Q} = \frac{10.2 + 10.8 + 9.9 + 10.5 + 10.6}{5} = 10.4,\qquad \bar{W} = \frac{0.30 + 0.28 + 0.32 + 0.29 + 0.31}{5} = 0.30$$

$$B = \frac{1}{m - 1}\sum_{l=1}^{m}(\hat{Q}_l - \bar{Q})^2 = \frac{0.04 + 0.16 + 0.25 + 0.01 + 0.04}{4} = \frac{0.50}{4} = 0.125$$

$$T = \bar{W} + \left(1 + \frac{1}{m}\right)B = 0.30 + 1.2 \times 0.125 = 0.45,\qquad \sqrt{T} \approx 0.671$$

### ポイント

- 補完間分散 $B$ は、欠測値が分からないことによる不確かさを表す。単一代入ではこの部分が無視され、標準誤差を過小に評価する。
- $(1 + 1/m)B/T = 0.15/0.45 \approx 0.33$ は欠測による情報の損失の大きさの目安（欠測情報の割合の近似）。区間推定には自由度 $\nu = (m - 1)\{1 + \bar{W}/((1 + 1/m)B)\}^2 = 4 \times (1 + 0.30/0.15)^2 = 36$ の $t$ 分布を用いる。
- よくある誤り：$\sqrt{\bar{W}} \approx 0.55$（補完間の変動を無視）、$\sqrt{\bar{W} + B} \approx 0.65$（$1/m$ の補正を忘れる）、$B$ を $m$ で割って求める。
