二段抽出の分散は、条件付き分散の分解 $V[\bar{y}] = V_1[E_2(\bar{y})] + E_1[V_2(\bar{y})]$ により、「どの村が選ばれるか」による第 1 段の分散と、「村の中でどの世帯が選ばれるか」による第 2 段の分散の和になります。それぞれに有限母集団修正が付き、$V[\bar{y}] = 0.9 \times 36/20 + 0.8 \times 400/200 = 1.62 + 1.60 = 3.22$ です。

### 計算

第 1 段の抽出率 $f_1 = n/N = 0.1$、第 2 段の抽出率 $f_2 = m/M = 0.2$ です。

選ばれた村を固定すると $E_2(\bar{y}) = \frac{1}{n}\sum_i \bar{Y}_i$ で、これは村の平均を単純無作為非復元抽出したときの標本平均なので

$$V_1[E_2(\bar{y})] = (1 - f_1)\frac{S_1^2}{n} = 0.9 \times \frac{36}{20} = 1.62$$

選ばれた村を固定したときの分散は $V_2(\bar{y}) = \frac{1}{n^2}\sum_i (1 - f_2)\frac{S_{2i}^2}{m}$ で、その期待値は（各村が選ばれる確率 $n/N$ を使って）

$$E_1[V_2(\bar{y})] = (1 - f_2)\frac{S_2^2}{nm} = 0.8 \times \frac{400}{200} = 1.60$$

$$V[\bar{y}] = 1.62 + 1.60 = 3.22$$

### ポイント

- 公式：$V[\bar{y}] = (1 - f_1)\dfrac{S_1^2}{n} + (1 - f_2)\dfrac{S_2^2}{nm}$。
- よくある誤り：有限母集団修正を両方とも忘れると $1.8 + 2.0 = 3.80$。分散の推定量の式 $v(\bar{y}) = (1 - f_1)\dfrac{s_1^2}{n} + f_1(1 - f_2)\dfrac{s_2^2}{nm}$ の第 2 項の $f_1$ を母分散の式に持ち込むと $1.62 + 0.16 = 1.78$ となる（推定量の式では、標本の村平均の分散 $s_1^2$ に第 2 段の変動も含まれるため $f_1$ が付く）。
- 費用が一定なら、村間の分散 $S_1^2$ が大きいほど多くの村から少しずつ選ぶ方が有利になる。
