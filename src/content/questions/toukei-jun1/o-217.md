観測された件数 0 より「さらに極端な結果」はないので、上限 $p_U$ は $P(X \le 0 \mid p_U) = (1 - p_U)^{150} = 0.05$ を解いて求めます。両辺の対数をとると $150\log(1 - p_U) = -2.996$ で、$\log(1 - p_U) \approx -p_U$ より $p_U \approx 2.996/150 \approx 0.0200$ です。

### 計算

片側 95% 信頼上限は、「$p$ がこれより大きければ $X = 0$ となる確率が 5% 未満になる」境界の $p$ です。

$$(1 - p_U)^{150} = 0.05 \iff 150\log(1 - p_U) = \log 0.05 = -2.996$$

$$p_U \approx \frac{2.996}{150} \approx 0.01997$$

（近似を使わない値は $1 - 0.05^{1/150} \approx 0.0198$ です。）したがって、信頼度 95% で $p \le 0.020$ といえます。

### 各選択肢の検討

- ①：正規近似（ワルド型）の上限 $\hat p + 1.645\sqrt{\hat p(1 - \hat p)/n}$ に $\hat p = 0$ を入れると、幅が 0 になり上限も 0 になります。事象が観察されないとき、ワルド型の区間は使えません。
- ②：$1/n$ は「1 件起きた場合の点推定値」で、信頼上限ではありません。
- ③：$\log 0.10$ を使った片側 90% 信頼上限です。
- ④：正しい。
- ⑤：$\log 0.025$ を使っています。これは両側 95% 区間（両側に 2.5% ずつ）の上限で、片側 95% の上限ではありません。

### ポイント

- 3 の法則：$n$ 回の試行で事象が 0 回なら、$p$ の片側 95% 信頼上限は約 $3/n$（$-\log 0.05 \approx 3$）。
- 二項分布の正確な（クロッパー・ピアソン型の）信頼限界は、累積確率が $\alpha$ となる $p$ を求めて構成する。$\hat p$ が 0 や 1 に近いとき、正規近似の区間は被覆確率が名目値を大きく下回る。
