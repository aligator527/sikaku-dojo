  成功確率 $0.4$ の独立なベルヌーイ試行を、3 回目の成功が起こるまで繰り返す。3 回目の成功が起こるまでに要した試行回数（3 回目の成功の試行を含む）を $N$ とする。$N$ の期待値 $E[N]$ と分散 $V[N]$ の組合せとして、正しいものを次のうちから一つ選べ。
choices:
  - '$E[N] = 2.5,\ V[N] = 3.75$'
  - '$E[N] = 4.5,\ V[N] = 11.25$'
  - '$E[N] = 7.5,\ V[N] = 4.5$'
  - '$E[N] = 7.5,\ V[N] = 11.25$'
  - '$E[N] = 7.5,\ V[N] = 18.75$'
answer: 4

$N$ は「1 回の成功が起こるまでの試行回数」$G_1, G_2, G_3$ の和で、$G_i$ は互いに独立に同じ幾何分布に従います（成功した直後から試行を数え直すと、それ以前の結果と独立に同じ状況が繰り返されるため）。幾何分布の期待値 $1/p$、分散 $(1-p)/p^2$ を 3 倍して、$E[N] = 7.5$、$V[N] = 11.25$ です。

### 計算

$$E[G_i] = \frac{1}{p} = \frac{1}{0.4} = 2.5,\qquad V[G_i] = \frac{1-p}{p^2} = \frac{0.6}{0.16} = 3.75$$

$$E[N] = 3 \times 2.5 = 7.5,\qquad V[N] = 3 \times 3.75 = 11.25$$

$N$ の確率関数は、$n$ 回目が 3 回目の成功で、それまでの $n - 1$ 回に成功がちょうど 2 回あることから

$$P(N = n) = {}_{n-1}\mathrm{C}_2\, 0.4^3\, 0.6^{n-3}\qquad (n = 3, 4, 5, \ldots)$$

です（負の二項分布）。

### 各選択肢の検討

- ①：成功 1 回までの試行回数（幾何分布）の期待値と分散です。3 回分の和なので 3 倍する必要があります。
- ②：失敗回数 $Y = N - 3$ の期待値 $r(1-p)/p = 4.5$ です。分散は $N$ と $Y$ で同じ $11.25$ ですが、期待値は試行回数で数えると 3 だけ大きくなります。
- ③：分散を $r(1-p)/p$ とし、$p$ で 1 回しか割っていません。
- ④：正しい。
- ⑤：分散を $r/p^2 = 3/0.16$ とし、$1 - p$ を掛け忘れています。

### ポイント

- 負の二項分布には「$r$ 回目の成功までの試行回数」で定義する流儀と「それまでの失敗回数」で定義する流儀がある。期待値は $r/p$ と $r(1-p)/p$ で異なるが、分散はどちらも $r(1-p)/p^2$。
- 負の二項分布はポアソン分布の平均がガンマ分布に従ってばらつくときの周辺分布としても現れ、分散が平均より大きい（過分散の）カウントデータのモデルになる。
