  確率変数 $X_n$（$n = 1, 2, \ldots$）が

  $$P(X_n = n^2) = \frac{1}{n},\qquad P(X_n = 0) = 1 - \frac{1}{n}$$

  を満たすとする。$n \to \infty$ のときの $X_n$ の振る舞いとして、正しいものを次のうちから一つ選べ。
choices:
  - '$X_n$ は 0 に確率収束し、$E[X_n]$ も 0 に収束する。'
  - '$X_n$ は 0 に確率収束し、$E[X_n]$ は 1 に収束する。'
  - '$X_n$ は 0 に確率収束するが、$E[X_n]$ は発散する。'
  - '$X_n$ は 0 に確率収束せず、$E[X_n]$ は発散する。'
  - '$X_n$ は 0 に確率収束せず、$E[X_n]$ は 0 に収束する。'
answer: 3

確率収束は「0 から離れる確率」が 0 に近づくかどうかで判定し、その確率は $1/n \to 0$ なので $X_n$ は 0 に確率収束します。一方、期待値は $n^2 \times 1/n = n$ で発散します。まれに起こる非常に大きな値が期待値を支配するためで、確率収束しても期待値が収束するとは限りません。

### 計算

任意の $\varepsilon > 0$ に対し、$n^2 > \varepsilon$ となる $n$ では

$$P(|X_n - 0| > \varepsilon) = P(X_n = n^2) = \frac{1}{n} \to 0$$

$$E[X_n] = n^2 \times \frac{1}{n} = n \to \infty,\qquad V[X_n] = E[X_n^2] - E[X_n]^2 = n^3 - n^2 \to \infty$$

### 各選択肢の検討

- ①：確率収束から期待値の収束は導けません。$E[X_n] = n$ です。
- ②：$P(X_n = n) = 1/n$ の場合なら $E[X_n] = 1$ ですが、ここでの値は $n^2$ です。
- ③：正しい。
- ④：確率収束するかどうかは、とる値の大きさではなく、0 から離れる確率で決まります。
- ⑤：確率収束の判定も期待値の計算も誤っています。

### ポイント

- 確率収束に加えて $X_n$ が一様に有界（より一般には一様可積分）であれば、期待値も収束する。
- 推定量について、平均二乗誤差 $\to 0$ ならばマルコフ（チェビシェフ）の不等式により一致性（確率収束）が従うが、逆は成り立たない。この例のように、一致推定量でも平均二乗誤差が発散することがある。
