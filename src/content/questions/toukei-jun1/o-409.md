共通性は共通因子部分 $0.70 f_1 + 0.20 f_2$ の分散です。斜交回転では因子どうしが相関するので、共分散の項 $2 \times 0.70 \times 0.20 \times 0.50$ を加える必要があり、$0.49 + 0.04 + 0.14 = 0.67$ となります。

### 計算

$V[f_1] = V[f_2] = 1$、$\mathrm{Cov}(f_1, f_2) = 0.5$ なので

$$V[0.70 f_1 + 0.20 f_2] = 0.70^2 + 0.20^2 + 2 \times 0.70 \times 0.20 \times 0.50 = 0.49 + 0.04 + 0.14 = 0.67$$

行列で書くと、パターン行列の行 $\boldsymbol{p} = (0.70,\ 0.20)$ と因子間相関行列 $\Phi$ を用いて $h^2 = \boldsymbol{p}\,\Phi\,\boldsymbol{p}^\top$ です。

検算：構造行列（変数と因子の相関）$\boldsymbol{s} = \boldsymbol{p}\,\Phi = (0.70 + 0.5 \times 0.20,\ 0.5 \times 0.70 + 0.20) = (0.80,\ 0.55)$ を用いると $h^2 = \boldsymbol{p}\,\boldsymbol{s}^\top = 0.70 \times 0.80 + 0.20 \times 0.55 = 0.67$ です。

### 各選択肢の検討

- ①：$0.49 + 0.04 = 0.53$ は直交解の公式です。因子間相関を無視しています。
- ②：共分散の項を $0.70 \times 0.20 \times 0.50 = 0.07$ と 1 倍しか加えていません。
- ③：正しい。
- ④：$(0.70 + 0.20)^2 = 0.81$ は因子間相関を 1 としたときの値です。
- ⑤：構造行列の要素の 2 乗和 $0.80^2 + 0.55^2 \approx 0.94$ です。構造行列の値には他の因子を経由した相関が含まれるので、2 乗和は共通性になりません。

### ポイント

- 斜交解では「パターン行列（係数）」と「構造行列（相関）」が異なり、$S = P\Phi$ の関係がある。直交解（$\Phi = I$）では両者が一致する。
- 斜交解の共通性は $\operatorname{diag}(P\Phi P^\top)$。パターン行列の 2 乗和では求まらない。
