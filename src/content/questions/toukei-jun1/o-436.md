ARMA モデルを MA($\infty$) 表現 $X_t = \sum_{j \geq 0}\psi_j\varepsilon_{t-j}$ に直すと、$h$ 期先の予測誤差は将来の誤差 $\varepsilon_{n+1}, \ldots, \varepsilon_{n+h}$ の部分 $\sum_{j=0}^{h-1}\psi_j\varepsilon_{n+h-j}$ になります。ARMA(1,1) では $\psi_1 = \phi + \theta = 1.1$、$\psi_2 = \phi\psi_1 = 0.88$ なので、分散は $2 \times (1 + 1.21 + 0.7744) \approx 5.97$ です。

### 計算

$(1 - 0.8B)X_t = (1 + 0.3B)\varepsilon_t$ より、$\psi(B) = (1 + 0.3B)/(1 - 0.8B)$ の係数を比べると

$$\psi_0 = 1,\qquad \psi_1 = \phi + \theta = 1.1,\qquad \psi_j = \phi\,\psi_{j-1}\ (j \geq 2) \ \Rightarrow\ \psi_2 = 0.88$$

$$V[X_{n+3} - \hat{X}_{n+3}] = \sigma^2(\psi_0^2 + \psi_1^2 + \psi_2^2) = 2 \times (1 + 1.21 + 0.7744) = 2 \times 2.9844 = 5.9688$$

$h \to \infty$ では、予測誤差の分散は $X_t$ の分散

$$\gamma(0) = \frac{1 + 2\phi\theta + \theta^2}{1 - \phi^2}\sigma^2 = \frac{1.57}{0.36} \times 2 \approx 8.72$$

に近づきます。

### ポイント

- $h$ 期先予測誤差の分散 $= \sigma^2\sum_{j=0}^{h-1}\psi_j^2$。1 期先は $\sigma^2$ そのもの。
- よくある誤り：AR 部分だけの重み $1, \phi, \phi^2$ を使う（$2 \times 2.0496 \approx 4.10$）、$\psi_2 = \phi^2$ とする（約 5.24）、$\sigma^2 = 2$ を掛け忘れる（約 2.98）。
