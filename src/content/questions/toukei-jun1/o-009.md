推移確率行列のすべての成分が正なので、この連鎖は既約かつ非周期的で、定常分布 $\pi = (\pi_S, \pi_C, \pi_R)$ がただ一つ存在します。$\pi P = \pi$ と $\pi_S + \pi_C + \pi_R = 1$ を連立して解くと $\pi = (24/61,\ 22/61,\ 15/61)$ となり、雨の確率は $15/61 \approx 0.246$ です。

### 計算

$\pi P = \pi$ の各列から次の式が得られます。

$$\pi_S = 0.6\pi_S + 0.3\pi_C + 0.2\pi_R \quad\Rightarrow\quad 0.4\pi_S = 0.3\pi_C + 0.2\pi_R \quad (1)$$

$$\pi_R = 0.1\pi_S + 0.3\pi_C + 0.4\pi_R \quad\Rightarrow\quad 0.6\pi_R = 0.1\pi_S + 0.3\pi_C \quad (2)$$

(1) から $\pi_S = 0.75\pi_C + 0.5\pi_R$。これを (2) に代入すると

$$0.6\pi_R = 0.075\pi_C + 0.05\pi_R + 0.3\pi_C \ \Rightarrow\ 0.55\pi_R = 0.375\pi_C \ \Rightarrow\ \pi_C = \frac{22}{15}\pi_R$$

$$\pi_S = 0.75 \times \frac{22}{15}\pi_R + 0.5\pi_R = 1.1\pi_R + 0.5\pi_R = \frac{24}{15}\pi_R$$

和が 1 なので $\pi_R\left(\dfrac{24}{15} + \dfrac{22}{15} + 1\right) = \pi_R \cdot \dfrac{61}{15} = 1$、よって

$$\pi_R = \frac{15}{61} \approx 0.2459,\qquad \pi_S = \frac{24}{61} \approx 0.393,\qquad \pi_C = \frac{22}{61} \approx 0.361$$

検算：$\pi_C = 0.3\pi_S + 0.4\pi_C + 0.4\pi_R$ に代入すると $(7.2 + 8.8 + 6.0)/61 = 22/61$ で成り立ちます。

### ポイント

- 定常分布は「$\pi P = \pi$（行ベクトルを左から掛ける）」で求める。$P\pi = \pi$（列ベクトル）と取り違えない。$\pi P = \pi$ の 3 本の式は 1 本が従属なので、和が 1 の条件を必ず加える。
- エルゴード的な連鎖では、長期的に各状態に滞在する時間の割合が定常分布に収束する。初期状態にはよらない。
