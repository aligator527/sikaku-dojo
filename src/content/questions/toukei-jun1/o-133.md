一般に、4 次モーメントが有限な母集団では $\sqrt{n}(S_n^2 - \sigma^2) \xrightarrow{d} N(0,\ \mu_4 - \sigma^4)$ です（$\mu_4 = E[(X - \mu)^4]$）。指数分布では $\sigma^2 = \theta^2$、$\mu_4 = 9\theta^4$ なので、$\tau^2 = 9\theta^4 - \theta^4 = 8\theta^4$ です。正規母集団の値 $2\sigma^4$ の 4 倍になります。

### 計算

$\mu = \theta$ として、$S_n^2$ を次のように分解します。

$$S_n^2 = \frac{n}{n-1}\left\{\frac{1}{n}\sum_{i=1}^{n}(X_i - \mu)^2 - (\bar{X}_n - \mu)^2\right\}$$

$\sqrt{n}(\bar{X}_n - \mu)^2 = \{\sqrt{n}(\bar{X}_n - \mu)\}^2/\sqrt{n} \xrightarrow{p} 0$、$n/(n-1) \to 1$ なので、スルツキーの補題により $\sqrt{n}(S_n^2 - \sigma^2)$ は $Y_i = (X_i - \mu)^2$ の標本平均についての $\sqrt{n}(\bar{Y}_n - \sigma^2)$ と同じ極限分布をもちます。$E[Y_i] = \sigma^2$、$V[Y_i] = \mu_4 - \sigma^4$ なので、中心極限定理により

$$\sqrt{n}(S_n^2 - \sigma^2) \xrightarrow{d} N(0,\ \mu_4 - \sigma^4)$$

指数分布のキュムラントは $\kappa_r = (r-1)!\,\theta^r$ なので、$\kappa_2 = \theta^2$、$\kappa_4 = 6\theta^4$、$\mu_4 = \kappa_4 + 3\kappa_2^2 = 9\theta^4$ です。

$$\tau^2 = 9\theta^4 - \theta^4 = 8\theta^4$$

### 各選択肢の検討

- ①：正規母集団での値（$\mu_4 = 3\sigma^4$ なので $2\sigma^4$）です。母集団の尖度を無視しています。
- ②：正しい。
- ③：$\mu_4$ そのもので、$\sigma^4$ を引いていません。
- ④：原点まわりのモーメントで $E[X^4] - (E[X^2])^2 = 24\theta^4 - 4\theta^4$ としています。$(X_i - \mu)^2$ の分散は中心モーメントで計算します。
- ⑤：原点まわりの 4 次モーメント $E[X^4] = 4!\,\theta^4$ です。

### ポイント

- $\tau^2 = \sigma^4(\kappa + 2)$（$\kappa$ は尖度 $\mu_4/\sigma^4 - 3$）。正規分布 $\kappa = 0$ では $2\sigma^4$、指数分布 $\kappa = 6$ では $8\sigma^4$。
- 母分散のカイ二乗検定や信頼区間は母集団の正規性からのずれ（尖度）に敏感で、大標本でも正しくならない。母平均の $t$ 検定が大標本で頑健なのとは対照的である。
