ファジー RDD の推定値は、閾値 $X = 60$ での結果 $Y$ の跳びを、受給率の跳びで割ったものです。回帰直線を $X = 60$ で評価すると、$Y$ の跳びは $51.6 - 48.0 = 3.6$、受給率の跳びは $0.70 - 0.10 = 0.60$ なので、効果は $3.6/0.60 = 6.0$ 単位です。

### 計算

閾値 $X = 60$ での予測値：

| | 左側の極限 | 右側の極限 | 跳び |
| --- | --- | --- | --- |
| $Y$ | $18.0 + 0.50 \times 60 = 48.0$ | $27.6 + 0.40 \times 60 = 51.6$ | $3.6$ |
| 受給率 | $-0.02 + 0.002 \times 60 = 0.10$ | $0.64 + 0.001 \times 60 = 0.70$ | $0.60$ |

$$\hat{\tau}_{\mathrm{FRD}} = \frac{\lim_{x \downarrow 60}E[Y \mid X = x] - \lim_{x \uparrow 60}E[Y \mid X = x]}{\lim_{x \downarrow 60}P(T = 1 \mid X = x) - \lim_{x \uparrow 60}P(T = 1 \mid X = x)} = \frac{3.6}{0.60} = 6.0$$

これは「閾値を越えたか」を操作変数とした操作変数推定量（ワルド推定量）を、閾値の近くで計算したものにあたります。

### ポイント

- よくある誤り：切片どうしの差をとって $(27.6 - 18.0)/(0.64 + 0.02) \approx 14.5$ とする（$X = 0$ での比較になり、閾値での跳びではない）、$Y$ の跳び $3.6$ をそのまま効果とする（受給率が 0 から 1 に跳ぶシャープ RDD の場合にのみ正しい）。
- 推定されるのは閾値付近の complier（資格によって受給が変わる学生）についての局所的な効果で、閾値から離れた学生や、資格によらず受給する（しない）学生への一般化には追加の仮定が必要。
- 回帰直線の当てはめに使う範囲（バンド幅）を変えて結果が安定しているかを確認する。
