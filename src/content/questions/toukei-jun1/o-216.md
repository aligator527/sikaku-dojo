フィッシャー情報量は、パラメータの付け替え $\theta = \theta(\eta)$ で $I(\eta) = I(\theta)\left(\dfrac{d\theta}{d\eta}\right)^2$ と変換されます。平均での $I(\theta) = 1/\theta^2$ から、$\theta = 1/\lambda$ では $I(\lambda) = \lambda^2 \cdot (1/\lambda^2)^2 = 1/\lambda^2$、$\theta = e^\psi$ では $I(\psi) = \theta^{-2}\cdot\theta^2 = 1$ となります。

### 計算

平均 $\theta$ の場合：

$$\log f = -\log\theta - \frac{x}{\theta},\qquad \frac{\partial^2}{\partial\theta^2}\log f = \frac{1}{\theta^2} - \frac{2x}{\theta^3},\qquad I(\theta) = -\frac{1}{\theta^2} + \frac{2\theta}{\theta^3} = \frac{1}{\theta^2}$$

率 $\lambda$ の場合：

$$\log f = \log\lambda - \lambda x,\qquad \frac{\partial^2}{\partial\lambda^2}\log f = -\frac{1}{\lambda^2},\qquad I(\lambda) = \frac{1}{\lambda^2}$$

変換公式でも、$d\theta/d\lambda = -1/\lambda^2$ より $I(\lambda) = I(\theta)\cdot\lambda^{-4} = \lambda^2\cdot\lambda^{-4} = 1/\lambda^2$ と一致します。

対数平均 $\psi$ の場合：$d\theta/d\psi = e^\psi = \theta$ より

$$I(\psi) = \frac{1}{\theta^2}\cdot\theta^2 = 1$$

### 各選択肢の検討

- ①：正しい。
- ②：$I(\theta) = 1/\theta^2$ に $\theta = 1/\lambda$ を代入しただけで、$(d\theta/d\lambda)^2$ を掛け忘れています。
- ③：$I(\psi)$ で $(d\theta/d\psi)^2 = \theta^2$ を掛け忘れています。
- ④：ポアソン分布のフィッシャー情報量 $1/\lambda$ と混同しています。
- ⑤：フィッシャー情報量とその逆数（最尤推定量の漸近分散の $n$ 倍）を取り違えています。

### ポイント

- $\psi = \log\theta$ では情報量が $\theta$ によらず一定になり、$V[\log\hat\theta] \approx 1/n$ となる（分散安定化変換）。$\theta$ の信頼区間を $\exp(\log\hat\theta \pm 1.96/\sqrt n)$ と作ると、区間が正の範囲に収まる。
- 最尤推定量は変換に対して $\hat\lambda = 1/\hat\theta$ のように素直に対応する（不変性）が、フィッシャー情報量は $(d\theta/d\eta)^2$ 倍される。
