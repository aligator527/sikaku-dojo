推移確率は $p_{k,k-1} = k/4$、$p_{k,k+1} = (4-k)/4$ です。詳細つり合い条件から定常分布は二項分布 $B(4,\ 1/2)$、すなわち $\pi = (1, 4, 6, 4, 1)/16$ で、$\pi_2 = 3/8$ です。既約なので平均再帰時間は $1/\pi_2 = 8/3$ です。ただし 1 ステップごとに $X_n$ の偶奇が入れ替わるので周期は 2 で、$P(X_n = 2)$ そのものは収束しません。

### 計算

詳細つり合い条件 $\pi_k\,p_{k,k+1} = \pi_{k+1}\,p_{k+1,k}$ より

$$\frac{\pi_{k+1}}{\pi_k} = \frac{(4-k)/4}{(k+1)/4} = \frac{4-k}{k+1}$$

$$\pi_1 = 4\pi_0,\quad \pi_2 = \frac{3}{2}\pi_1 = 6\pi_0,\quad \pi_3 = \frac{2}{3}\pi_2 = 4\pi_0,\quad \pi_4 = \frac{1}{4}\pi_3 = \pi_0$$

和が 1 なので $\pi_0 = 1/16$、$\pi = \dfrac{1}{16}(1,\ 4,\ 6,\ 4,\ 1)$ です。平均再帰時間は $1/\pi_2 = 16/6 = 8/3$、$1/\pi_0 = 16$ です。

### 各選択肢の検討

- ①：誤り。中央の状態ほど行き来しやすく、定常分布は二項分布になります。
- ②：誤り。周期 2 のため、$X_0 = 2$ なら奇数の $n$ で $P(X_n = 2) = 0$ です。偶数の $n$ では $2\pi_2 = 3/4$ に近づき、$3/8$ には収束しません。
- ③：正しい。平均再帰時間 $= 1/\pi_i$ は周期的な連鎖でも成り立ちます。
- ④：誤り。$\pi_0 = 1/16$ は正しいものの、平均再帰時間は $1/\pi_0 = 16$ です。
- ⑤：誤り。$0 \leftrightarrow 1 \leftrightarrow 2 \leftrightarrow 3 \leftrightarrow 4$ とすべての状態が行き来できるので既約で、有限既約な連鎖の定常分布はただ一つです。

### ポイント

- 定常分布の存在と一意性には（有限なら）既約性で十分だが、$P^n$ が定常分布に収束するにはさらに非周期性が必要。
- 平均再帰時間 $1/\pi_i$ は、長期的な滞在割合 $\pi_i$ の逆数という直観的な関係。
- 玉が $N$ 個なら、全部が箱 I にある状態の平均再帰時間は $2^N$ で、$N$ が大きいと事実上戻ってこない（熱力学の不可逆性の説明に使われたモデル）。
