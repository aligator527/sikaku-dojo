  4 つの 2 水準因子 A, B, C, D について、定義関係 $I = ABCD$ による $2^{4-1}$ 一部実施要因計画（8 回の実験）を行う。3 因子以上の交互作用は無視できるとする。この計画についての記述として、正しいものを次のうちから一つ選べ。
choices:
  - '主効果 A は 2 因子交互作用 BC と別名（交絡）の関係にあるので、A の効果は BC と区別できない。'
  - '主効果どうしは互いに別名にならず、2 因子交互作用とも別名にならないが、2 因子交互作用 AB は CD と別名の関係にあり、両者は区別できない。'
  - '8 回の実験で、4 つの主効果と 6 つの 2 因子交互作用をすべて互いに区別して推定できる。'
  - '2 因子交互作用 AB と AC は別名の関係にある。'
  - 'この計画の分解能（レゾリューション）は III である。'
answer: 2

別名は、効果に定義関係の語 $ABCD$ を掛けて（同じ文字の 2 乗は 1）求めます。主効果は $A = BCD$ のように 3 因子交互作用と、2 因子交互作用は $AB = CD$ のように別の 2 因子交互作用と別名になります。3 因子交互作用を無視すれば主効果は推定できますが、AB と CD は区別できないので、② が正しい記述です。

### 計算

定義関係 $I = ABCD$ を掛けると、別名関係は次のとおりです。

| 効果 | 別名 |
| --- | --- |
| A | BCD |
| B | ACD |
| C | ABD |
| D | ABC |
| AB | CD |
| AC | BD |
| AD | BC |

8 回の実験では、平均を除いて 7 個の対比しか推定できず、上の 7 組がそれぞれ 1 つの対比にあたります。

### 各選択肢の検討

- ①：誤り。A と BC が別名になるのは、$I = ABC$ のような 3 文字の定義関係の場合です。ここでは A の別名は BCD です。
- ②：正しい。
- ③：誤り。推定できる対比は 7 個なので、主効果 4 個と 2 因子交互作用 6 個の計 10 個を区別することはできません。2 因子交互作用は 2 つずつ組になって別名になります。
- ④：誤り。$AB \times ABCD = CD$ なので、AB の別名は CD です。
- ⑤：誤り。分解能は定義関係の最も短い語の長さで、ここでは 4（レゾリューション IV）です。

### ポイント

- 分解能 III：主効果が 2 因子交互作用と別名。分解能 IV：主効果は 2 因子交互作用と別名にならないが、2 因子交互作用どうしが別名。分解能 V：2 因子交互作用も互いに別名にならない。
- この計画は、$L_8$ 直交表の第 1, 2, 4 列に A, B, C、第 7 列に D を割り付けたものと同じ構造である。
