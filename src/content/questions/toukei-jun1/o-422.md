  平均 0 の時系列データの標本分散は $2.5$、ラグ 1 の標本自己相関係数は $r(1) = 0.4$ で、ラグ 2 以降の標本自己相関係数はほぼ 0 であった。そこで MA(1) モデル

  $$X_t = \varepsilon_t + \theta\,\varepsilon_{t-1},\qquad V[\varepsilon_t] = \sigma^2$$

  をモーメント法（理論的な分散と自己相関係数を標本の値に一致させる方法）で当てはめる。反転可能な解として得られる $(\theta, \sigma^2)$ の推定値として正しいものを、次のうちから一つ選べ。

MA(1) の自己相関係数は $\rho(1) = \theta/(1 + \theta^2)$ です。これを $0.4$ とおくと $0.4\theta^2 - \theta + 0.4 = 0$ となり、$\theta = 0.5$ と $\theta = 2$ の 2 つの解が得られます。反転可能なのは $|\theta| < 1$ の $\theta = 0.5$ で、$\sigma^2 = 2.5/(1 + 0.25) = 2.0$ です。

### 計算

$$\frac{\theta}{1 + \theta^2} = 0.4 \ \Longrightarrow\ 0.4\theta^2 - \theta + 0.4 = 0 \ \Longrightarrow\ \theta = \frac{1 \pm \sqrt{1 - 0.64}}{0.8} = \frac{1 \pm 0.6}{0.8} = 2,\ 0.5$$

2 つの解は互いに逆数で、どちらも同じ自己相関構造を与えます。反転可能性（$\varepsilon_t$ を現在と過去の $X$ で表せること）の条件 $|\theta| < 1$ を満たすのは $\theta = 0.5$ です。

分散 $\gamma(0) = (1 + \theta^2)\sigma^2$ を標本分散に一致させると

$$\sigma^2 = \frac{2.5}{1 + 0.5^2} = 2.0$$

### 各選択肢の検討

- ①：自己相関係数 0.4 をそのまま $\theta$ としています（AR(1) の $\rho(1) = \phi$ との混同）。
- ②：$\theta = 2$ も同じ自己相関を与えますが、反転可能ではありません。
- ③：$\sigma^2$ を $X_t$ の分散 2.5 のままにしています。
- ④：符号が逆です。$\theta < 0$ なら $\rho(1) < 0$ になります。
- ⑤：正しい。

### ポイント

- MA(1) では $|\rho(1)| \leq 0.5$。標本自己相関が 0.5 を超えるなら、モーメント法の解は存在せず、MA(1) 以外のモデルを考える。
- 反転可能な表現を選ぶことで、モデルが一意に定まり、AR($\infty$) 表現 $\varepsilon_t = X_t - \theta X_{t-1} + \theta^2 X_{t-2} - \cdots$ による予測ができる。
