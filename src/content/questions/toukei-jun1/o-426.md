ARMA(1,1) では、MA 部分の影響はラグ 1 までにしか及ばないので、ラグ 2 以降は AR(1) と同じ漸化式 $\rho(h) = \phi\,\rho(h-1)$ が成り立ちます。ただし出発点の $\rho(1)$ は $\phi$ ではなく $\dfrac{(1 + \phi\theta)(\phi + \theta)}{1 + 2\phi\theta + \theta^2} \approx 0.692$ なので、$\rho(2) = 0.5 \times 0.692 \approx 0.35$ です。

### 計算

モデル式の両辺に $X_t$、$X_{t-1}$ を掛けて期待値をとります。$E[X_t\varepsilon_t] = \sigma^2$、$E[X_t\varepsilon_{t-1}] = (\phi + \theta)\sigma^2$ を用いると

$$\gamma(0) = \phi\gamma(1) + \sigma^2 + \theta(\phi + \theta)\sigma^2,\qquad \gamma(1) = \phi\gamma(0) + \theta\sigma^2$$

これを解くと

$$\gamma(0) = \frac{1 + 2\phi\theta + \theta^2}{1 - \phi^2}\sigma^2 = \frac{1 + 0.4 + 0.16}{0.75}\sigma^2 = 2.08\sigma^2$$

$$\gamma(1) = 0.5 \times 2.08\sigma^2 + 0.4\sigma^2 = 1.44\sigma^2,\qquad \rho(1) = \frac{1.44}{2.08} \approx 0.6923$$

$h \geq 2$ では $\varepsilon_t, \varepsilon_{t-1}$ が $X_{t-h}$ と無相関なので $\gamma(h) = \phi\gamma(h-1)$ となり

$$\rho(2) = 0.5 \times 0.6923 \approx 0.3462$$

### ポイント

- ARMA($p, q$) の自己相関は、ラグ $q$ を超えると AR 部分の漸化式に従って減衰する。自己相関も偏自己相関も打ち切られないのが ARMA の特徴。
- よくある誤り：AR(1) の公式で $\rho(2) = \phi^2 = 0.25$ とする、$\rho(1) = \phi + \theta = 0.9$ として $0.45$ とする、MA(1) と同様にラグ 2 で 0 とする。
