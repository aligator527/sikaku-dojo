  ある選挙区で候補者 A, B, C の支持率はそれぞれ 0.5, 0.3, 0.2 である。有権者 20 人を無作為に（復元抽出で）選び、A, B, C の支持者数をそれぞれ $N_A$、$N_B$、$N_C$ とする（$N_A + N_B + N_C = 20$）。

$(N_A,\ N_B,\ N_C)$ は多項分布に従い、合計が 20 に固定されているので $N_A$ と $N_B$ は負の相関をもちます（$\mathrm{Cov}(N_A,\ N_B) = -np_Ap_B = -3$）。差の分散は $V[N_A] + V[N_B] - 2\,\mathrm{Cov}(N_A,\ N_B) = 5 + 4.2 + 6 = 15.2$ です。

### 計算

$$V[N_A] = 20 \times 0.5 \times 0.5 = 5,\qquad V[N_B] = 20 \times 0.3 \times 0.7 = 4.2$$

$$\mathrm{Cov}(N_A,\ N_B) = -20 \times 0.5 \times 0.3 = -3$$

$$V[D] = 5 + 4.2 - 2 \times (-3) = 15.2$$

**別解**：$i$ 番目の有権者について、A 支持なら $+1$、B 支持なら $-1$、C 支持なら $0$ をとる $D_i$ を考えると、$D = \sum_{i=1}^{20} D_i$ で $D_i$ は独立です。

$$E[D_i] = 0.5 - 0.3 = 0.2,\qquad E[D_i^2] = 0.5 + 0.3 = 0.8,\qquad V[D_i] = 0.8 - 0.04 = 0.76$$

$$V[D] = 20 \times 0.76 = 15.2$$

### ポイント

- 多項分布：$V[N_i] = np_i(1 - p_i)$、$\mathrm{Cov}(N_i,\ N_j) = -np_ip_j$（$i \neq j$）。
- よくある誤り：共分散を無視して $5 + 4.2 = 9.2$ とする、共分散の符号を誤って $9.2 - 6 = 3.2$ とする。
- 同じ標本から求めた支持率の差 $\hat{p}_A - \hat{p}_B$ の分散は $\{p_A + p_B - (p_A - p_B)^2\}/n$ で、独立な 2 標本の場合の公式とは異なる。
