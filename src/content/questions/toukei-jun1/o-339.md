群間平方和は「群の大きさ × 群平均と全体平均の差の 2 乗」の和、群内平方和は「（群の大きさ − 1）× 不偏分散」の和で求まります。群間平方和 192（自由度 2）、群内平方和 300（自由度 15）より、$F = (192/2)/(300/15) = 96/20 = 4.80$ です。

### 計算

全体平均は各群の大きさが等しいので $(52 + 56 + 60)/3 = 56$ です。

$$S_A = 6\left\{(52 - 56)^2 + (56 - 56)^2 + (60 - 56)^2\right\} = 6 \times 32 = 192,\qquad \text{自由度 } 3 - 1 = 2$$

$$S_E = (6 - 1)(16 + 20 + 24) = 300,\qquad \text{自由度 } 18 - 3 = 15$$

| 要因 | 平方和 | 自由度 | 平均平方 | $F$ |
| --- | --- | --- | --- | --- |
| 肥料 | 192 | 2 | 96 | 4.80 |
| 残差 | 300 | 15 | 20 | |
| 計 | 492 | 17 | | |

$F_{0.05}(2, 15) = 3.682 < 4.80 < F_{0.01}(2, 15) = 6.359$ なので、有意水準 5% で肥料の効果は有意、1% では有意ではありません。

### ポイント

- よくある誤り：不偏分散に $n_i - 1$ ではなく $n_i$ を掛けると $S_E = 360$、$F = 4.0$。群間平方和で群の大きさ 6 を掛け忘れると $F = 0.8$。
- 群内の平均平方 $20$ は、3 群の不偏分散の（自由度で重み付けした）平均で、プールした分散にあたる。
- 一元配置分散分析の前提：各群の誤差が独立に、等しい分散の正規分布に従うこと。
