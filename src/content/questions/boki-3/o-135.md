まず売掛金勘定の増減から期末残高を求め、電子記録債権と合わせて設定額を計算します。次に、期中の貸倒れで貸倒引当金がいくら取り崩されたかを調べ、決算整理前の残高を確定させてから差額を求めます。

### 計算

**1. 売掛金の期末残高**

| 項目 | 金額 |
| --- | ---: |
| 期首残高 | 600,000 |
| ＋ 掛け売上 | 3,200,000 |
| − 返品 | 20,000 |
| − 普通預金による回収 | 2,750,000 |
| − 電子記録債権への振替 | 240,000 |
| − 貸倒れ | 30,000 |
| 期末残高 | 760,000 |

**2. 貸倒引当金の設定額**：（760,000 ＋ 340,000）× 2％ ＝ 22,000円

**3. 決算整理前の貸倒引当金残高**

前期販売分の貸倒れ 30,000円 に対して貸倒引当金 18,000円 を全額取り崩し、不足の 12,000円 は貸倒損失とします。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 貸倒引当金 | 18,000 | 売掛金 | 30,000 |
| 貸倒損失 | 12,000 | | |

決算整理前の残高：18,000 − 18,000 ＝ 0円

**4. 貸倒引当金繰入**：22,000 − 0 ＝ **22,000円**

### ポイント

- 期中の貸倒れで引当金を取り崩したことを忘れ、期首残高 18,000円 を差し引くと、繰入額を 4,000円 と誤ります。
- 貸倒れた売掛金 30,000円 も売掛金の減少です。期末残高の計算から漏らすと設定額が 600円 大きくなります。
- 電子記録債権への振替は売掛金の減少ですが、電子記録債権として期末に残っている分は設定対象です。
