収益の勘定は貸方に残高があるので、借方に同額を記入して残高をゼロにし、相手勘定の損益勘定の貸方に集めます。

### 計算

- 損益勘定への振替額：7,850,000円 ＋ 126,000円 ＋ 4,000円 ＝ 7,980,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 売上 | 7,850,000 | 損益 | 7,980,000 |
| 受取手数料 | 126,000 |  |  |
| 受取利息 | 4,000 |  |  |

### ポイント

- 収益は「（借）収益の各勘定 （貸）損益」、費用は「（借）損益 （貸）費用の各勘定」です。貸借を逆にしないよう注意します。
- 損益勘定に収益と費用を集めた後、その差額（当期純利益または当期純損失）を繰越利益剰余金に振り替えます。
- 収益を直接、繰越利益剰余金に振り替えるのは誤りです。必ず損益勘定を経由します。
