試算表の租税公課 266,000円 には、本来は仮払法人税等とすべき中間納付額と、未使用の収入印紙が含まれています。この2つを除いた額が当期の租税公課です。

### 計算

| 項目 | 金額 |
| --- | ---: |
| 試算表の租税公課 | 266,000 |
| 整理事項1：法人税等の中間納付額を仮払法人税等へ訂正 | −120,000 |
| 整理事項5：未使用の収入印紙を貯蔵品へ振替 | −8,000 |
| 損益計算書の租税公課 | **138,000** |

| 借方科目 | 金額 | 貸方科目 | 金額 |

### ポイント

- 法人税、住民税及び事業税は利益にかかる税金なので、租税公課とは区別します。中間納付額は仮払法人税等で処理し、決算で確定額を計上するときに取り崩します。
- 未使用の郵便切手 3,000円 は通信費から差し引くもので、租税公課とは関係ありません。
- 消費税（税抜方式）も租税公課には含めません。
