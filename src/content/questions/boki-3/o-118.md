まず仕訳を書き、仕訳に出てくる勘定ごとに対応する補助簿を当てはめます。商品の受入れがあるので、仕訳に商品勘定が出てこなくても商品有高帳に記入します。

### 各選択肢の検討

仕訳：

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 仕入 | 304,000 | 前払金 | 60,000 |
| | | 買掛金 | 240,000 |
| | | 現金 | 4,000 |

- 仕入 → **仕入帳**、商品の受入れ → **商品有高帳**（引取運賃を含めた原価で記入）
- 買掛金 → **買掛金元帳**（南商店の口座）
- 現金 → **現金出納帳**
- 前払金 → 対応する補助簿は使用していない

以上から、記入する補助簿は現金出納帳・仕入帳・商品有高帳・買掛金元帳の4つです。

- **ア** 誤り。引取運賃を現金で支払っているので、現金出納帳が必要です。
- **イ** 誤り。商品有高帳が抜けています。
- **ウ** 誤り。売掛金元帳は得意先に対する債権の明細なので、仕入取引では使いません。
- **エ** 誤り。当座預金は動いていません。また、商品有高帳が抜けています。
- **オ** 正しい。

### ポイント

- 商品有高帳には仕入原価 304,000円（単価は引取運賃を含めて計算）で受入れを記入します。
- 前払金は手付金の支払時にすでに記帳されています。本問の取引で使う補助簿はありません。
- 2027年度からの出題区分表では手形が出題範囲から削除されるため、受取手形記入帳・支払手形記入帳は補助簿の選択肢に出てこなくなります。
