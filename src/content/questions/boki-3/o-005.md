給料は差し引き前の **総額** が費用です。源泉徴収した所得税や従業員負担分の社会保険料は、会社が従業員に代わって後日納付するために一時的に預かっているお金なので、それぞれ預り金（負債）として処理します。

### 計算

- 給料（費用）：総額 450,000円
- 所得税預り金：18,000円
- 社会保険料預り金：27,000円
- 普通預金からの支払額：450,000円 − 18,000円 − 27,000円 ＝ 405,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 給料 | 450,000 | 所得税預り金 | 18,000 |
| | | 社会保険料預り金 | 27,000 |
| | | 普通預金 | 405,000 |

### ポイント

- 給料を手取額の 405,000円 で計上するのは誤りです。費用は総額で計上します。
- 後日、社会保険料を納付するときは、従業員負担分（社会保険料預り金）と **会社負担分（法定福利費）** を合わせて支払います。
- 所得税の源泉徴収分は租税公課ではありません。会社の税金ではなく、従業員から預かった税金だからです。
