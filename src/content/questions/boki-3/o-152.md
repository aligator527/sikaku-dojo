移動平均法では、仕入のたびに「残高の金額 ÷ 残高の数量」で平均単価を計算し直し、払出しはその時点の平均単価で記入します。引取運賃は仕入原価に含めるので、7月15日の受入単価は運賃を加えて計算します。

### 計算

| 日付 | 受入 | 払出 | 残高（数量・金額・単価） |
| --- | --- | --- | --- |
| 7月1日 | 50個 40,000 | | 50個 40,000（@800） |
| 7月6日 | 150個 126,000 | | 200個 166,000（@830） |
| 7月10日 | | 120個 × 830 ＝ 99,600 | 80個 66,400（@830） |
| 7月15日 | 120個 105,600（@880） | | 200個 172,000（@860） |
| 7月22日 | | 150個 × 860 ＝ 129,000 | 50個 43,000（@860） |
| 7月28日 | 100個 89,000 | | 150個 132,000（@880） |

- 7月15日の受入金額：120個 × 870 ＋ 引取運賃 1,200 ＝ 105,600円（単価 880円）
- 売上原価：99,600 ＋ 129,000 ＝ **228,600円**

7月28日の仕入は7月22日より後なので、7月の払出単価には影響しません。

### ポイント

- 引取運賃を受入金額に含め忘れると、7月15日以降の平均単価が 854円 となり、売上原価を 227,700円 と誤ります。
- 売上の売価（1,300円・1,350円）は商品有高帳には記入しません。商品有高帳は受入・払出・残高のすべてを原価で記録する帳簿です。
- 月末に仕入れた商品は月末在庫（132,000円）に含まれ、当月の売上原価には含まれません。
