給料は差し引く前の総額 380,000円 が費用です。差し引いた金額のうち、源泉徴収した所得税は会社が後日納付するために預かったお金（所得税預り金・負債）、立替金の回収分は会社の債権（従業員立替金・資産）の減少です。

### 計算

立替え時の仕訳（参考）：（借）従業員立替金 12,000 （貸）現金など 12,000

- 給料：380,000円
- 所得税預り金：14,200円
- 従業員立替金の回収：12,000円
- 振込額：380,000 − 14,200 − 12,000 ＝ 353,800円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 給料 | 380,000 | 所得税預り金 | 14,200 |
| | | 従業員立替金 | 12,000 |
| | | 普通預金 | 353,800 |

### ポイント

- 立て替えた保険料は従業員個人の負担なので、会社の保険料（費用）ではありません。給料から差し引いて回収したら、従業員立替金を減らします。
- 差し引いた金額をまとめて預り金にするのは誤りです。預り金は「後で他者（税務署など）に支払うために預かったお金」、立替金の回収は「会社が貸していたお金が戻ってきた」もので、性質が異なります。
- 給料を手取額 353,800円 で計上するのも典型的な誤りです。
