訂正仕訳は「誤った仕訳の逆仕訳」と「正しい仕訳」を合わせて作ります。配当の決議時点ではまだ支払っていないので、普通預金ではなく未払配当金（負債）を計上し、利益準備金の積立ても記録する必要があります。

### 計算

1. 誤った仕訳を取り消す（逆仕訳）

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 普通預金 | 550,000 | 繰越利益剰余金 | 550,000 |

2. 正しい仕訳

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 繰越利益剰余金 | 550,000 | 未払配当金 | 500,000 |
| | | 利益準備金 | 50,000 |

3. 1と2をまとめると、繰越利益剰余金 550,000円 が貸借で相殺され、次の訂正仕訳になります。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 普通預金 | 550,000 | 未払配当金 | 500,000 |
|  |  | 利益準備金 | 50,000 |

### ポイント

- 繰越利益剰余金を減らす金額（550,000円）は誤った仕訳でも正しかったので、訂正仕訳には現れません。
- 配当金の未払分は、一般の未払金ではなく **未払配当金** です。後日支払ったときに「（借）未払配当金 （貸）普通預金」とします。
- 最小限の仕訳で答える指示があるときは、同じ勘定科目を借方と貸方の両方に書かないようにします。
