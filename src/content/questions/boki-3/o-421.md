入金伝票は「（借）現金」、出金伝票は「（貸）現金」の仕訳です。伝票に書かれた科目は、入金伝票なら貸方、出金伝票なら借方に集計します。振替伝票はそのまま借方・貸方に集計します。

| 勘定科目 | 借方の内訳 | 貸方の内訳 |
| --- | --- | --- |
| 現金 | 入金伝票の合計 65,000 + 8,000 + 24,000 | 出金伝票の合計 48,000 + 5,600 + 30,000 |
| 売掛金 | No.302 150,000、No.303 90,000 | No.101 65,000、No.304 70,000 |
| 買掛金 | No.201 48,000、No.305 10,000 | No.301 120,000 |
| 売上 | | No.103 24,000、No.302 150,000、No.303 90,000 |
| 仕入 | No.203 30,000、No.301 120,000 | No.305 10,000（返品） |

借方合計・貸方合計はともに 620,600円で一致します。

- 現金勘定：$180{,}000 + 97{,}000 - 83{,}600 = 193{,}400$円
- 山口商店：$210{,}000 + 90{,}000 - 65{,}000 = 235{,}000$円
- 広島商店：$160{,}000 + 150{,}000 - 70{,}000 = 240{,}000$円

### ポイント

- 入金伝票の売掛金を借方に集計するのは典型的な誤りです。入金伝票の科目は、現金の相手科目として必ず貸方になります。
- 仕訳日計表の合計は、その日の全伝票の金額の合計（入金伝票＋出金伝票＋振替伝票）と一致します。
