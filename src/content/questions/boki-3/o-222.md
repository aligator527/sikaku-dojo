仕入れた商品を返品したときは、仕入時の仕訳の一部を取り消します。仕入時に計上した仮払消費税も、返品した分だけ取り消します。

### 計算

- 返品した商品の本体価格：45,000円 → 仕入の取消し
- 消費税：45,000円 × 10％ ＝ 4,500円 → 仮払消費税の取消し
- 買掛金の減少：45,000円 ＋ 4,500円 ＝ 49,500円

仕入時の仕訳（返品分、参考）：

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 仕入 | 45,000 | 買掛金 | 49,500 |
| 仮払消費税 | 4,500 | | |

返品の仕訳（上の逆）：

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 買掛金 | 49,500 | 仕入 | 45,000 |
|  |  | 仮払消費税 | 4,500 |

### ポイント

- 返品の消費税を仮受消費税とするのは誤りです。仕入側の消費税は仮払消費税なので、それを取り消します。
- 買掛金は消費税込みの金額で記録されているので、減らす額も税込みの 49,500円 です。
- 売上の返品なら「（借）売上・仮受消費税 （貸）売掛金」となります。
