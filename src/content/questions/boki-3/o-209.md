仮受金で処理していた売却代金を、正しい売却の仕訳に置き換えます。期中の売却なので、期首から売却日までの減価償却費を月割で計上してから帳簿価額を求めます。

### 計算

1. 1年分の減価償却費：1,200,000 ÷ 5年 ＝ 240,000円
2. 当期分（X8年4月〜10月の7か月）：240,000 × 7/12 ＝ 140,000円
3. 売却時の帳簿価額：1,200,000 − 720,000 − 140,000 ＝ 340,000円
4. 売却損益：450,000 − 340,000 ＝ 110,000円（売却益）

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 車両運搬具減価償却累計額 | 720,000 | 車両運搬具 | 1,200,000 |
| 減価償却費 | 140,000 | 固定資産売却益 | 110,000 |
| 仮受金 | 450,000 | | |

### ポイント

- 代金はすでに普通預金に入金され、仮受金として処理されています。売却の仕訳では、普通預金ではなく **仮受金** を借方に記入して消去します。
- 当期分の減価償却費を計上し忘れると、帳簿価額 480,000円 と比べて 30,000円 の売却損と誤ります。
