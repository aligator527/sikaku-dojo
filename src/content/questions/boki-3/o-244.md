  **決算整理事項**

  1. 現金過不足 ￥9,000 は現金の不足額を記録したものである。原因を調査したところ、￥6,300 は郵便切手の購入（通信費）の記入漏れであることが判明したが、残額は原因が判明しなかった。

通信費には、現金過不足の原因として判明した記入漏れが加わり、決算日に未使用の郵便切手が貯蔵品へ振り替えられて差し引かれます。

### 計算

| 項目 | 金額 |
| --- | ---: |
| 試算表の通信費 | 74,000 |
| 整理事項1：郵便切手の購入の記入漏れ | ＋6,300 |
| 整理事項7：未使用の郵便切手を貯蔵品へ振替 | −2,800 |
| 損益計算書の通信費 | **77,500** |

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 通信費 | 6,300 | 現金過不足 | 9,000 |
| 雑損 | 2,700 | | |
| 貯蔵品 | 8,800 | 通信費 | 2,800 |
| | | 租税公課 | 6,000 |

### ポイント

- 現金過不足 9,000円 のうち原因不明の 2,700円 は雑損です。全額を通信費にすると 80,200円 と誤ります。
- 未使用の収入印紙 6,000円 は租税公課から差し引くもので、通信費とは関係ありません。
- 現金は不足が判明した時点で修正済みなので、決算で現金勘定は動かしません。
