期中に廃棄するときは、期首から廃棄日までの減価償却費を月割で計上し、そのうえで残った帳簿価額を損失とします。廃棄は売却と違って代金が入らず、廃棄のための費用もかかるので、帳簿価額と廃棄費用の合計が損失になります。

### 計算

1. 1年分の減価償却費：360,000円 ÷ 6年 ＝ 60,000円
2. 期首の減価償却累計額：X2年4月1日〜X6年3月31日の4年分　60,000円 × 4年 ＝ 240,000円
3. 当期分（X6年4月〜11月の8か月）：60,000円 × 8/12 ＝ 40,000円
4. 廃棄時の帳簿価額：360,000円 − 240,000円 − 40,000円 ＝ 80,000円
5. 固定資産除却損：80,000円 ＋ 廃棄費用 8,000円 ＝ 88,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 備品減価償却累計額 | 240,000 | 備品 | 360,000 |
| 減価償却費 | 40,000 | 現金 | 8,000 |
| 固定資産除却損 | 88,000 |  |  |

借方合計・貸方合計はともに 368,000円 です。

### ポイント

- 廃棄は2027年度から3級の範囲に加わった論点です。勘定科目表では廃棄による損失も **固定資産除却損** が標準とされ、「固定資産廃棄損」は採点上許容される科目として示されています。本問は問題文の指示に従います。
- 期首の累計額は、X2年度からX5年度までの4年分です。当期（X6年度）を含めて5年分とする数え間違いに注意します。
- 廃棄費用を支払手数料として別に計上するのは誤りです。廃棄にかかった費用は損失に含めます。
- 当期分の減価償却費 40,000円 を計上し忘れると、損失を 128,000円 と誤ります。
