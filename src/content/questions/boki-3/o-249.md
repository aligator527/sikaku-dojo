決算整理事項をすべて反映して税引前当期純利益を求め、そこから法人税、住民税及び事業税（税引前当期純利益の30％）を差し引いて当期純利益を求めます。

### 計算

| 整理事項 | 処理 | 損益への影響 |
| --- | --- | --- |
| 1. 中間納付の訂正 | 租税公課 120,000 を仮払法人税等へ | 租税公課 −120,000 |
| 2. 売上原価 | 284,000 ＋ 5,120,000 − 302,000 | 売上原価 5,102,000 |
| 3. 貸倒引当金 | 950,000 × 2％ − 7,000 | 貸倒引当金繰入 12,000 |
| 4. 減価償却 | 960,000 ÷ 8年 | 減価償却費 120,000 |
| 5. 貯蔵品 | 切手 3,000・印紙 8,000 | 通信費 −3,000、租税公課 −8,000 |
| 6. 消費税 | 836,000 − 512,000 ＝ 324,000 を未払消費税へ | 影響なし |
| 7. 法人税等 | 税引前当期純利益 × 30％ | 下で計算 |

損益計算書：

| 給料 | 1,380,000 | 受取手数料 | 94,000 |
| 支払家賃 | 840,000 | | |
| 水道光熱費 | 124,000 | | |
| 通信費 | 60,000 | | |

| 貸倒引当金繰入 | 12,000 | | |

| 合計 | 8,454,000 | 合計 | 8,454,000 |

1. 税引前当期純利益：8,454,000 − 7,794,000（法人税等を除く費用合計）＝ 660,000円
2. 法人税、住民税及び事業税：660,000 × 30％ ＝ 198,000円
3. 当期純利益：660,000 − 198,000 ＝ **462,000円**

### ポイント

- 税引前当期純利益 660,000円 を答えるのは誤りです。損益計算書の当期純利益は法人税等を差し引いた後の金額です。
- 法人税等の中間納付額を租税公課に含めたままにすると、税引前当期純利益が 540,000円 となり、当期純利益を 378,000円 と誤ります。
- 消費税は税抜方式なので損益に影響しません。
