郵便切手や収入印紙は、未使用であれば次期に使えるうえ換金性も高いので、決算で未使用分を費用から差し引き、貯蔵品（資産）に振り替えます。

### 計算

- 郵便切手 4,200円：通信費から貯蔵品へ
- 収入印紙 12,000円：租税公課から貯蔵品へ
- 貯蔵品：4,200円 ＋ 12,000円 ＝ 16,200円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 貯蔵品 | 16,200 | 通信費 | 4,200 |
|  |  | 租税公課 | 12,000 |

### ポイント

- 郵便切手は通信費、収入印紙は租税公課から差し引きます。取り違えに注意します。
- 翌期首には再振替仕訳「（借）通信費 4,200・租税公課 12,000 （貸）貯蔵品 16,200」を行います。
- 3級の勘定科目表に「消耗品」（資産）の勘定はなく、事務用品などは購入時に消耗品費で処理します。
