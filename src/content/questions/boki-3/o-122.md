支払報告を受けた時点で費用を計上して小口現金を減らし、補給によって小口現金を同額増やします。報告と補給が同時なので、小口現金の増減は相殺され、費用と普通預金だけが残ります。

### 計算

1. 支払報告：（借）通信費 4,600・旅費交通費 7,800・消耗品費 3,200・雑費 1,500 （貸）小口現金 17,100
2. 補給：（借）小口現金 17,100 （貸）普通預金 17,100
3. 1と2をまとめると小口現金が消えます。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 通信費 | 4,600 | 普通預金 | 17,100 |
| 旅費交通費 | 7,800 | | |

### ポイント

- 郵便切手は通信費、電車・バス代は旅費交通費、文房具は消耗品費、お茶菓子代は雑費が定番の勘定です。切手代を租税公課（収入印紙など）にしないよう注意します。
- 報告を週末に受け、補給を翌週に行う場合は、報告時に「（借）各費用 （貸）小口現金」、補給時に「（借）小口現金 （貸）普通預金など」と2回に分けて仕訳します。
- 2027年度からの出題区分表では小切手が出題範囲から外れるため、補給は普通預金からの引出しなどで出題されることになります。
