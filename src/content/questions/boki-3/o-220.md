収入印紙は印紙税を納めるために使うものなので租税公課、郵便切手は郵便料金の支払いに使うものなので通信費として、購入時に費用処理します。

### 計算

- 収入印紙：30,000円 → 租税公課
- 郵便切手：6,800円 → 通信費
- 現金の支払額：30,000円 ＋ 6,800円 ＝ 36,800円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 租税公課 | 30,000 | 現金 | 36,800 |
| 通信費 | 6,800 |  |  |

### ポイント

- 購入時に貯蔵品（資産）とするのは誤りです。決算の時点で未使用のものがあれば、その分だけを貯蔵品に振り替えます。
- 収入印紙を通信費、郵便切手を租税公課とする取り違えに注意します。
- 決算で貯蔵品に振り替えた分は、翌期首に再振替仕訳で租税公課・通信費に戻します。
