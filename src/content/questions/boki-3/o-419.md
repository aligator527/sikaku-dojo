先入先出法では、先に受け入れた商品から順に払い出したと考えます。払出のたびに、古い単価の在庫から数量を割り当てます。

- **9/6**：残高は単価の異なる2口（40個 @500 と 60個 @520）になるので、2行に分けて書きます。
- **9/12 売上 70個**：先に受け入れた 40個 @500（20,000円）を全部払い出し、残り 30個を @520（15,600円）から払い出します。払出は2行、残高は 30個 @520 の 15,600円です。
- **9/18**：残高は 30個 @520 と 50個 @530 の2口です。
- **9/24 売上 60個**：30個 @520（15,600円）と 30個 @530（15,900円）を払い出し、残高は 20個 @530 の 10,600円です。
- **9/30 次月繰越**：残高 20個 @530 を払出欄に書いて締め切ると、受入欄と払出欄の合計が数量 150個、金額 77,700円で一致します。

| 項目 | 計算 | 金額 |
| --- | --- | ---: |
| 売上高 | $70 \times 800 + 60 \times 820$| 105,200 |
| 売上原価 | $20{,}000 + 15{,}600 + 15{,}600 + 15{,}900$| 67,100 |
| 売上総利益 | 売上高 − 売上原価 | 38,100 |

### ポイント

- 商品有高帳の単価・金額はすべて原価です。売価は売上高の計算にだけ使います。
- 売上原価は払出欄の金額の合計（次月繰越を除く）です。$77{,}700 - 10{,}600 = 67{,}100$円と、受入合計から期末在庫を引いても求められます。
