給料から差し引いた金額は、会社が従業員に代わって納付するために預かったお金（預り金）です。納付時には預り金を取り崩しますが、社会保険料は会社負担分も同時に納付するため、従業員負担分の2倍の金額が支払われます。

### 計算

**7月10日**

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 所得税預り金 | 54,000 | 普通預金 | 126,000 |
| 住民税預り金 | 72,000 | | |

**7月31日**

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 社会保険料預り金 | 261,000 | 普通預金 | 522,000 |
| 法定福利費 | 261,000 | | |

**普通預金の減少額の合計**：126,000 ＋ 522,000 ＝ **648,000円**

### ポイント

- 社会保険料の会社負担分を忘れると、387,000円 と誤ります。会社負担分は納付時に **法定福利費**（費用）として計上します。
- 6月25日の給料支払いによる普通預金の減少（1,800,000 − 54,000 − 72,000 − 261,000 ＝ 1,413,000円）は6月の取引なので含めません。
- 住民税の特別徴収額は、所得税と同じく預り金（住民税預り金）で処理します。
