帳簿の体系と決算手続きの基本用語です。

| 空欄 | 語句 | 補足 |
| --- | --- | --- |
| ア | 主要簿 | 仕訳帳と総勘定元帳。すべての取引が記録されます。 |
| イ | 補助簿 | 主要簿の記録を補う明細の帳簿です。 |
| ウ | 補助元帳 | 売掛金元帳・買掛金元帳・商品有高帳・固定資産台帳など、勘定ごとの明細です。 |
| エ | 補助記入帳 | 現金出納帳・当座預金出納帳・仕入帳・売上帳など、取引ごとの明細です。 |
| オ | 試算表 | 合計試算表・残高試算表・合計残高試算表があります。 |
| カ | 転記 | 仕訳から総勘定元帳への書き移しです。貸借の一致で転記の誤りの一部を発見できます。 |
| キ | 損益 | 収益・費用を集める決算用の勘定です。 |
| ク | 繰越利益剰余金 | 株式会社では当期純利益を繰越利益剰余金勘定に振り替えます。 |
| ケ | 次期繰越 | 期末の締切りで使います（月次の締切りでは「次月繰越」）。 |
| コ | 前期繰越 | 翌期首に開始記入として書きます。 |
| サ | 間接法 | 固定資産の勘定を直接減らす方法は直接法です。 |
| シ | 先入先出法 | 仕入のたびに平均単価を計算し直す方法は移動平均法です。 |
| ス | 繰延べ | 前払費用・前受収益が生じます。 |
| セ | 見越し | 未払費用・未収収益が生じます。 |
| ソ | 精算表 | 残高試算表・修正記入・損益計算書・貸借対照表の欄を持つ一覧表です。 |

### ポイント

- 補助簿のうち、「〜元帳」「〜台帳」は勘定ごとの明細（補助元帳）、「〜出納帳」と仕入帳・売上帳は取引の明細（補助記入帳）です。商品有高帳は名前に「元帳」がありませんが、商品の種類ごとの明細なので補助元帳に入ります。
- 試算表の貸借が一致しても、仕訳そのものの誤りや、同じ金額の貸借両方の転記漏れは発見できません。
