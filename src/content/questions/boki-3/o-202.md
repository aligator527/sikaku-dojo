除却とは、使用をやめた有形固定資産を帳簿から取り除くことです。取得原価と減価償却累計額を消去し、処分価値（スクラップなどとして売れる見込み額）は貯蔵品（資産）として残し、帳簿価額のうち残りを固定資産除却損とします。期首の除却なので、当期の減価償却費は発生しません。

### 計算

1. 除却時の帳簿価額：480,000円 − 432,000円 ＝ 48,000円
2. 処分価値の見積額：15,000円 → 貯蔵品
3. 固定資産除却損：48,000円 − 15,000円 ＝ 33,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 備品減価償却累計額 | 432,000 | 備品 | 480,000 |
| 貯蔵品 | 15,000 |  |  |
| 固定資産除却損 | 33,000 |  |  |

### ポイント

- 有形固定資産の除却・廃棄は、2027年度から適用される出題区分表で2級から3級に移された論点です。勘定科目表では **固定資産除却損** が標準の勘定科目とされています。
- 処分価値の見積額は、まだ売却していないので未収入金ではなく **貯蔵品** です。後日、実際に売却したときに貯蔵品を減らします。
- 処分価値を考えずに 48,000円 全額を除却損とするのは誤りです。また、売却ではないので固定資産売却損は使いません。
