敷金は、契約が終わったときに原則として返還されるお金なので、費用ではなく差入保証金（資産）とします。仲介手数料は返ってこない支出なので支払手数料、家賃は支払家賃として、それぞれ費用処理します。

### 計算

- 差入保証金：400,000円
- 支払手数料：200,000円
- 支払家賃：200,000円
- 普通預金の減少：400,000円 ＋ 200,000円 ＋ 200,000円 ＝ 800,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 差入保証金 | 400,000 | 普通預金 | 800,000 |
| 支払手数料 | 200,000 |  |  |
| 支払家賃 | 200,000 |  |  |

### ポイント

- 敷金を支払家賃や支払手数料に含めるのは誤りです。返還されることが前提の支出は資産として計上します。
- 店舗を借りただけなので、建物（資産）は計上しません。
- 2027年度からの出題区分表の改定説明では、3級の不動産の賃借は従来どおり賃貸借処理（支払家賃・支払地代勘定）で出題されるとされています。2級以上では、賃貸借処理をする場合も支払リース料勘定を用いる点が異なります。
