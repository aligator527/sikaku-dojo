売掛金元帳には、その得意先に対する売掛金の増減だけを記入します。増加（掛売上）は借方、減少（返品・回収・電子記録債権への振替）は貸方です。残高欄には記入のたびに残高を書き、借方残高なので「借/貸」欄は「借」です。

| 日付 | 内容 | 借方 | 貸方 | 残高 |
| --- | --- | ---: | ---: | ---: |
| 10/1 | 前月繰越 | 240,000 | | 240,000 |
| 10/5 | 掛売上 | 150,000 |  | 390,000 |
| 10/8 | 返品 |  | 10,000 | 380,000 |
| 10/18 | 普通預金に入金 |  | 220,000 | 160,000 |
| 10/25 | 掛売上 | 130,000 |  | 290,000 |
| 10/28 | 電子記録債権の発生 |  | 100,000 | 190,000 |

- **10/12・10/20**：富士商店との取引なので、大和商店の元帳には記入しません。
- **10/25**：発送費は当社が現金で支払った費用で、売掛金は増えません。売掛金元帳に記入するのは売上の 130,000円だけです。
- **10/31 締切り**：残高 190,000円を貸方に「次月繰越」と記入すると、借方・貸方の合計が 520,000円で一致します。11/1 には同額を借方に「前月繰越」と記入します。

富士商店の残高は $180{,}000 + 200{,}000 - 150{,}000 = 230{,}000$円です。売掛金勘定（総勘定元帳）の残高は、得意先元帳の残高の合計 420,000円と一致します。

### ポイント

- 売掛金勘定は統制勘定で、売掛金元帳の各得意先の残高の合計と必ず一致します。
- 電子記録債権の発生記録により、売掛金は減少して電子記録債権に変わります。売掛金元帳では貸方に記入します。
