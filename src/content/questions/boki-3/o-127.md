当座預金出納帳の残高欄を1行ずつ計算し、「借」「貸」のどちらの残高かを確認します。残高が貸方（マイナス）になっている間は当座借越の状態で、その金額が借越額です。

### 計算

| 日付 | 預入 | 引出 | 借／貸 | 残高 |
| --- | ---: | ---: | --- | ---: |
| 6月1日 | 120,000 | | 借 | 120,000 |
| 6月5日 | 85,000 | | 借 | 205,000 |
| 6月10日 | | 260,000 | 貸 | 55,000 |
| 6月18日 | | 90,000 | 貸 | 145,000 |
| 6月25日 | 150,000 | | 借 | 5,000 |
| 6月28日 | | 18,400 | 貸 | 13,400 |

当座借越が最も大きくなったのは6月18日の電子記録債務の決済後で、借越額は **145,000円** です。

### ポイント

- 最終残高（6月28日の貸方残高 13,400円）を答える誤りに注意します。問われているのは期間中の最大の借越額です。
- 借越額は限度額 300,000円 の範囲内なので、引落しはすべて実行されています。
- 決算日に当座預金勘定が貸方残高なら、決算整理でその金額を当座借越勘定（負債）へ振り替えます。月末が決算日なら「（借）当座預金 13,400 （貸）当座借越 13,400」です。
- 2027年度からは小切手の振出しが出題範囲から外れるため、当座預金の引出しは振込み・口座引落し・電子記録債務の決済として出題されます。
