売掛金 350,000円 は、振込みによる回収分 200,000円 と電子記録債権への振替分 150,000円 に分かれ、全額が消滅します。振込手数料は当社負担なので、入金額が少なくなった分を支払手数料（費用）として計上します。

### 計算

1. 振込みによる回収分 200,000円
   - 普通預金の増加：200,000 − 660 ＝ 199,340円
   - 支払手数料：660円
2. 電子記録債権の発生分：350,000 − 200,000 ＝ 150,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 普通預金 | 199,340 | 売掛金 | 350,000 |
| 支払手数料 | 660 | | |
| 電子記録債権 | 150,000 | | |

借方合計・貸方合計はともに 350,000円 で一致します。

### ポイント

- 手数料が差し引かれていても、消滅する売掛金は 200,000円 です。売掛金を 199,340円 だけ減らすと、660円 が売掛金として残ってしまいます。
- 手数料を **当社が負担** する場合は支払手数料です。受取手数料と取り違えないようにします。
- 振込手数料を得意先が負担する場合は、200,000円 がそのまま入金され、当社の仕訳に手数料は出てきません。
