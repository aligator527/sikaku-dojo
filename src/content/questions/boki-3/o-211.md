社会保険料は、従業員と会社がそれぞれ負担します。従業員負担分は給料の支払時に差し引いて社会保険料預り金（負債）としているので、納付時にはこれを取り崩します。会社負担分は会社の費用なので、法定福利費として処理します。

### 計算

- 従業員負担分：社会保険料預り金の取崩し 54,000円
- 会社負担分：法定福利費 54,000円
- 普通預金からの納付額：54,000円 ＋ 54,000円 ＝ 108,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 社会保険料預り金 | 54,000 | 普通預金 | 108,000 |
| 法定福利費 | 54,000 |  |  |

### ポイント

- 納付額 108,000円 の全額を法定福利費とするのは誤りです。従業員負担分は預り金の返済にあたり、会社の費用ではありません。
- 会社負担分を給料や租税公課とするのも誤りです。社会保険料の会社負担分は **法定福利費** で処理します。
- 所得税の源泉徴収分を納付するときは、所得税預り金を取り崩します（会社負担分はありません）。
