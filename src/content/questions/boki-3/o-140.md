内容不明の入金は、内容が判明するまで仮受金（負債）で処理します。内容が判明したら仮受金を借方に記入して取り崩し、本来の勘定に振り替えます。

### 計算

振込み時の仕訳（参考）：（借）普通預金 150,000 （貸）仮受金 150,000

- 売掛金の回収：110,000円 → 売掛金の減少（貸方）
- 注文の手付金：40,000円 → 前受金の増加（貸方）

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 仮受金 | 150,000 | 売掛金 | 110,000 |
| | | 前受金 | 40,000 |

### ポイント

- 普通預金は振込み時にすでに増加させているので、判明時に普通預金を動かすのは誤りです。
- 注文の手付金はまだ商品を引き渡していないので、売上ではなく前受金です。
- 内容不明の **入金** は仮受金（負債）、内容や金額が確定していない **支払い** は仮払金（資産）です。
