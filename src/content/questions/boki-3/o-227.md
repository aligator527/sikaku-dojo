未払法人税等を求めるには、まず税引前当期純利益を計算して法人税等の金額を決め、そこから中間納付額（仮払法人税等）を差し引きます。中間納付額は誤って租税公課に含まれているので、整理事項1で仮払法人税等に振り替えてから計算します。

### 計算

決算整理後の収益・費用（法人税等を除く）：

| 費用 | 金額 | 収益 | 金額 |
| --- | ---: | --- | ---: |
| 売上原価 | 5,102,000 | 売上高 | 8,360,000 |
| 給料 | 1,380,000 | 受取手数料 | 94,000 |
| 支払家賃 | 840,000 | | |
| 水道光熱費 | 124,000 | | |
| 通信費 | 60,000 | | |
| 租税公課 | 138,000 | | |
| 貸倒引当金繰入 | 12,000 | | |
| 減価償却費 | 120,000 | | |
| 支払利息 | 18,000 | | |
| 費用合計 | 7,794,000 | 収益合計 | 8,454,000 |

- 売上原価：284,000 ＋ 5,120,000 − 302,000 ＝ 5,102,000円
- 貸倒引当金繰入：950,000 × 2％ − 7,000 ＝ 12,000円
- 減価償却費：960,000 ÷ 8年 ＝ 120,000円
- 通信費：63,000 − 3,000 ＝ 60,000円、租税公課：266,000 − 120,000 − 8,000 ＝ 138,000円

1. 税引前当期純利益：8,454,000 − 7,794,000 ＝ 660,000円
2. 法人税、住民税及び事業税：660,000 × 30％ ＝ 198,000円
3. 未払法人税等：198,000 − 中間納付額 120,000 ＝ **78,000円**

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 法人税、住民税及び事業税 | 198,000 | 仮払法人税等 | 120,000 |
| | | 未払法人税等 | 78,000 |

### ポイント

- 整理事項1の訂正を忘れると、租税公課が 120,000円 過大となって税引前当期純利益が 540,000円、法人税等が 162,000円 になり、仮払法人税等もないので未払法人税等を 162,000円 と誤ります。
- 消費税（税抜方式）は損益に影響しないので、税引前当期純利益の計算には含めません。
