税抜方式では、売上時に受け取った消費税を仮受消費税、仕入時などに支払った消費税を仮払消費税として処理しています。決算では両者を相殺し、受け取った額が多い分を国に納める義務として未払消費税（負債）に計上します。

### 計算

- 納付額：仮受消費税 683,000円 − 仮払消費税 426,000円 ＝ 257,000円

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 仮受消費税 | 683,000 | 仮払消費税 | 426,000 |
|  |  | 未払消費税 | 257,000 |

### ポイント

- 税抜方式では消費税は損益に影響しません。納付額を租税公課として費用にするのは誤りです。
- 後日納付したときは「（借）未払消費税 257,000 （貸）普通預金 257,000」です。
- 仮払消費税が仮受消費税より多い場合（還付）の処理は2級の範囲です。
