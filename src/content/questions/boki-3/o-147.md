商品を引き渡したので、売上を総額 420,000円 で計上します。注文時に受け取った手付金は前受金（負債）として計上済みなので、これを取り崩して代金に充て、残額を売掛金とします。当社負担の発送運賃は発送費（費用）です。

### 計算

手付金受取時の仕訳（参考）：（借）現金など 80,000 （貸）前受金 80,000

- 売上：420,000円
- 前受金の取崩し：80,000円
- 売掛金：420,000 − 80,000 ＝ 340,000円
- 発送費：6,500円（現金で支払い）

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 前受金 | 80,000 | 売上 | 420,000 |
| 売掛金 | 340,000 | 現金 | 6,500 |
| 発送費 | 6,500 | | |

借方合計・貸方合計はともに 426,500円 で一致します。

### ポイント

- 手付金を **受け取った** 側の勘定は前受金です。前払金を選ぶ誤りに注意します。
- 当社負担の運賃は発送費です。顧客負担の送料を代金に含めて請求する場合は、送料を含めた金額を売上とし、実際の支払額を発送費とします。
- 売上を手付金を差し引いた 340,000円 で計上するのは誤りです。
