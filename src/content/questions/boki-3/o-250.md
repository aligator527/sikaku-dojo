貸借対照表の資産は、決算整理後の残高で示し、貸倒引当金と減価償却累計額は対応する資産から控除します。仮受金・仮払金を正しい勘定に振り替え、売却した車両運搬具は帳簿から取り除きます。

### 計算

1. 決算整理（資産に関係するもの）
   - 車両運搬具の売却：車両運搬具 1,200,000円 と減価償却累計額を消去（当期分の減価償却費 140,000円、売却益 110,000円）
   - 仮払金 480,000円 を備品へ振替 → 備品 2,080,000円
   - 期末商品：214,000円
   - 貸倒引当金：720,000 × 2％ ＝ 14,400円
   - 建物減価償却累計額：1,350,000 ＋ 150,000 ＝ 1,500,000円
   - 備品減価償却累計額：576,000 ＋ (1,600,000 − 576,000) × 20％ ＋ 480,000 × 20％ × 4/12 ＝ 576,000 ＋ 204,800 ＋ 32,000 ＝ 812,800円
2. 貸借対照表（資産の部）

| 資産 | 金額 | 控除額 | 貸借対照表価額 |
| --- | ---: | ---: | ---: |
| 現金 | 128,000 | | 128,000 |
| 普通預金 | 2,346,000 | | 2,346,000 |
| 売掛金 | 720,000 | 貸倒引当金 14,400 | 705,600 |
| 商品 | 214,000 | | 214,000 |
| 建物 | 4,500,000 | 減価償却累計額 1,500,000 | 3,000,000 |
| 備品 | 2,080,000 | 減価償却累計額 812,800 | 1,267,200 |
| 土地 | 3,000,000 | | 3,000,000 |
| 資産合計 | | | **10,660,800** |

検算：負債 586,000円（買掛金）＋ 純資産 10,074,800円（資本金 8,000,000円 ＋ 繰越利益剰余金 1,929,000円 ＋ 当期純利益 145,800円）＝ 10,660,800円

### ポイント

- 売却代金はすでに普通預金に入金されているので、普通預金を増やす必要はありません。仮受金を消去するだけです。
- 仮払金・仮受金は内容が判明したら正しい勘定に振り替えるので、貸借対照表には残りません。
- 減価償却累計額を控除せずに取得原価で合計すると、資産を過大に計算してしまいます。
