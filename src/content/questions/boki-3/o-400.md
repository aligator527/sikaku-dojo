決算整理仕訳を先に書き、修正記入欄に転記してから、各行を損益計算書欄（収益・費用）と貸借対照表欄（資産・負債・純資産）に振り分けます。

| 決算整理事項 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 1. 売上原価 | 仕入 | 80,000 | 繰越商品 | 80,000 |
| | 繰越商品 | 100,000 | 仕入 | 100,000 |
| 2. 貸倒引当金 | 貸倒引当金繰入 | 5,000 | 貸倒引当金 | 5,000 |
| 3. 減価償却 | 減価償却費 | 100,000 | 備品減価償却累計額 | 100,000 |
| 4. 未払給料 | 給料 | 20,000 | 未払給料 | 20,000 |

- 貸倒引当金：$400{,}000 \times 2\% = 8{,}000$円。残高 3,000円との差額 5,000円を繰り入れます。
- 減価償却費：$600{,}000 \div 6 = 100{,}000$円。
- 仕入（売上原価）：$1{,}000{,}000 + 80{,}000 - 100{,}000 = 980{,}000$円。

損益計算書欄の貸方合計（収益）1,500,000円から借方合計（費用）1,405,000円を引いた 95,000円が当期純利益です。損益計算書欄では借方に、貸借対照表欄では貸方に記入すると、それぞれの欄の貸借が一致します（損益計算書 1,500,000円、貸借対照表 1,250,000円）。

### ポイント

- 当期純利益は「損益計算書欄の借方」と「貸借対照表欄の貸方」に同じ金額を書きます。純損失なら逆になります。
- 修正記入欄の合計は、決算整理仕訳の借方合計・貸方合計（305,000円）と一致します。
