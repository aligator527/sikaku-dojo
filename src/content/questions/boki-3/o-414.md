期首の残高を求めてから、期中の取引と決算整理を順に転記します。

- **期首の残高**：備品勘定は A と B の取得原価の合計 960,000円です。減価償却累計額は、A が3年分 $600{,}000 \div 5 \times 3 = 360{,}000$円、B が6か月分 $360{,}000 \div 4 \times \dfrac{6}{12} = 45{,}000$円で、合計 405,000円です。

| 取引 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 9/30 売却 | 備品減価償却累計額 | 360,000 | 備品 | 600,000 |
|  | 減価償却費 | 60,000 |  |  |
|  | 未収入金 | 150,000 |  |  |
|  | 固定資産売却損 | 30,000 |  |  |
| 12/1 購入 | 備品 | 480,000 | 普通預金 | 480,000 |
| 3/31 決算 | 減価償却費 | 130,000 | 備品減価償却累計額 | 130,000 |

- **売却**：当期分（4月〜9月の6か月）の減価償却費は $600{,}000 \div 5 \times \dfrac{6}{12} = 60{,}000$円。帳簿価額 $600{,}000 - 360{,}000 - 60{,}000 = 180{,}000$円と売却額 150,000円の差額 30,000円が売却損です。備品勘定の貸方は相手科目が複数あるので摘要は「諸口」、累計額勘定の借方の摘要は「備品」です。
- **決算**：B は1年分 90,000円、C は12月〜3月の4か月分 $480{,}000 \div 4 \times \dfrac{4}{12} = 40{,}000$円、合計 130,000円を累計額勘定の貸方に記入します。
- **締切り**：備品は 840,000円（B と C）、累計額は 175,000円を「次期繰越」として締め切ります。

損益計算書の減価償却費は、売却時に計上した 60,000円を含めて 190,000円になります。

### ポイント

- 売却時の減価償却費は減価償却累計額を通さず、直接「減価償却費」として計上します。累計額勘定に入るのは決算の 130,000円だけです。
- 固定資産の売却代金の未収分は、売掛金ではなく未収入金です。
