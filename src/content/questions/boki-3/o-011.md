受取家賃勘定の動きを「期首の再振替 → 期中の受取り → 期末の前受計上」の順に追えば、損益計算書の金額（当期に属する家賃）が求まります。月ごとに数えて検算できるのもこの論点の特徴です。

### 計算

受取家賃勘定の記入（貸方が収益の増加、借方が減少）：

| 日付 | 摘要 | 借方 | 貸方 |
| --- | --- | ---: | ---: |
| 4月1日 | 前受家賃（再振替） | | 180,000 |
| 6月1日 | 6か月分受取（6月〜11月、月額90,000） | | 540,000 |
| 12月1日 | 6か月分受取（12月〜5月、月額100,000） | | 600,000 |
| 3月31日 | 前受家賃（翌期4月・5月分） | 200,000 | |
| 3月31日 | 損益 | 1,120,000 | |

- 期末の前受家賃：100,000円 × 2か月 ＝ 200,000円
- 受取家賃（損益）：180,000 ＋ 540,000 ＋ 600,000 − 200,000 ＝ **1,120,000円**

検算（当期12か月分を月ごとに集計）：4月・5月 90,000 × 2 ＋ 6月〜11月 90,000 × 6 ＋ 12月〜3月 100,000 × 4 ＝ 1,120,000円

### ポイント

- 期首の再振替仕訳は「（借）前受家賃 180,000 （貸）受取家賃 180,000」です。前期に受け取った4月・5月分を当期の収益に戻す処理なので、忘れると収益が過少になります。
- 期末の前受額は改定後の月額 100,000円 で計算します。改定前の 90,000円 を使う誤りが多い箇所です。
- 前受収益は負債、前払費用・未収収益は資産、未払費用は負債です。
