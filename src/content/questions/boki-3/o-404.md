未記帳の取引（1.〜3.）を処理したあとの残高で決算整理を行い、最後に税引前当期純利益を求めてから法人税等を計算します。

| 決算整理事項 | 借方 | | 貸方 | |

| 1. 現金過不足 | 現金過不足 | 7,000 | 受取手数料 | 5,000 |
|  |  |  | 雑益 | 2,000 |
| 2. 貸倒れ | 貸倒引当金 | 30,000 | 売掛金 | 30,000 |
| 3. 定期預金 | 定期預金 | 500,000 | 普通預金 | 500,000 |

- 貸倒引当金：前期販売分の貸倒れは引当金を取り崩すので、残高は $36{,}000 - 30{,}000 = 6{,}000$円になります。設定額 $(830{,}000 - 30{,}000) \times 2\% = 16{,}000$円との差額 10,000円を繰り入れます。
- 車両運搬具（定率法）：$(1{,}500{,}000 - 600{,}000) \times 40\% = 360{,}000$円。建物は $5{,}400{,}000 \div 30 = 180{,}000$円。
- 前受家賃：試算表の受取家賃 475,000円は、期首の再振替分7か月（4月〜10月）と11月に受け取った12か月の合計19か月分です。前受分は X9年4月〜10月の7か月で、$25{,}000 \times 7 = 175{,}000$円です。
- 未払利息：1年分の利息は $1{,}000{,}000 \times 2.4\% = 24{,}000$円。12月〜3月の4か月分 8,000円を計上すると、当期の支払利息は 24,000円（12か月分）になります。
- 法人税等：税引前当期純利益 926,000円 × 30% ＝ 277,800円。仮払法人税等 120,000円を差し引いた 157,800円が未払法人税等です。

当期純利益は $926{,}000 - 277{,}800 = 648{,}200$円です。

### ポイント

- 前期に販売した分の貸倒れは貸倒引当金で、当期に販売した分の貸倒れは貸倒損失で処理します。引当金を取り崩したあとの残高を使って差額補充します。
- 毎年同じ月に1年分を受け取る家賃は、試算表に「再振替分＋1年分」が入っています。月数を数えて前受分を求めます。
- 法人税等を30%で計算するときは、法人税等以外の整理をすべて終えた税引前当期純利益を使います。
