決算整理仕訳を修正記入欄に書き、各行の金額を損益計算書欄（収益・費用）と貸借対照表欄（資産・負債・純資産）に移します。整理の結果、残高がゼロになる現金過不足の行は、損益計算書欄にも貸借対照表欄にも記入しません。

| 決算整理事項 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 1. 現金過不足 | 通信費 | 2,600 | 現金過不足 | 4,000 |
|  | 雑損 | 1,400 |  |  |
| 2. 売上原価 | 仕入 | 238,000 | 繰越商品 | 238,000 |

| 3. 貸倒引当金 | 貸倒引当金繰入 | 6,400 | 貸倒引当金 | 6,400 |
| 4. 減価償却 | 減価償却費 | 270,000 | 建物減価償却累計額 | 120,000 |
|  |  |  | 備品減価償却累計額 | 150,000 |
| 5. 前払保険料 | 前払保険料 | 64,000 | 保険料 | 64,000 |

- 雑損：$4{,}000 - 2{,}600 = 1{,}400$円（借方残高の現金過不足は現金の不足なので、残額は雑損です）。
- 貸倒引当金：$620{,}000 \times 2\% = 12{,}400$円。残高 6,000円との差額 6,400円を繰り入れます。
- 減価償却費：建物 $3{,}600{,}000 \div 30 = 120{,}000$円、備品 $900{,}000 \div 6 = 150{,}000$円。
- 前払保険料：X9年4月〜11月の8か月分。$96{,}000 \times \dfrac{8}{12} = 64{,}000$円。
- 未収利息：X8年11月〜X9年3月の5か月分。$400{,}000 \times 3\% \times \dfrac{5}{12} = 5{,}000$円。
- 未払利息：11月末に6月〜11月分を支払っているので、未払は12月〜3月の4か月分。$800{,}000 \times 3\% \times \dfrac{4}{12} = 8{,}000$円。

損益計算書欄の貸方合計（収益）から借方合計（費用）を引くと、当期純利益は 398,600円です。これを損益計算書欄の借方と貸借対照表欄の貸方に記入すると、両欄とも貸借が一致します（損益計算書 5,951,000円、貸借対照表 8,785,000円）。修正記入欄の合計 857,400円は、決算整理仕訳の借方合計と一致します。

### ポイント

- 現金過不足は借方残高なら現金の不足（雑損）、貸方残高なら現金の過剰（雑益）です。原因が判明した分を先に振り替え、残額を雑損・雑益にします。
- 経過勘定は「いつからいつまでの分か」を月単位で数えます。利息の後払いでは、最後の支払日の翌月から決算日までが未払です。
- 未使用の収入印紙は「貯蔵品」として資産に計上し、租税公課から差し引きます。
