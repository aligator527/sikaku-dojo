仕入帳は、仕入取引を発生順に記録する補助記入帳です。月末に締め切るときは、返品以外の仕入の合計を総仕入高とし、返品（仕入戻し）の合計を差し引いて純仕入高を求めます。代金の決済方法（掛け・手付金・電子記録債務）は仕入金額に影響しません。

### 計算

| 日付 | 内容 | 総仕入高 | 仕入戻し高 |
| --- | --- | ---: | ---: |
| 9月3日 | 東商店：A 45,000 ＋ B 42,000 ＋ 引取運賃 2,400 | 89,400 | |
| 9月7日 | 東商店：A 10個 × 450 | | 4,500 |
| 9月15日 | 西商店：C 80個 × 1,250 | 100,000 | |
| 9月22日 | 南商店：D 40個 × 900 | 36,000 | |
| 9月26日 | 西商店：C 4個 × 1,250 | | 5,000 |
| 合計 | | 225,400 | 9,500 |

純仕入高：225,400 − 9,500 ＝ **215,900円**

### ポイント

- 当社負担の引取運賃は仕入原価に含めるので、仕入帳にも内訳として記入し、総仕入高に含めます。
- 手付金と相殺した 20,000円 を差し引いて 80,000円 とするのは誤りです。仕入金額は商品の代金 100,000円 です。
- 仕入帳では返品を赤字で記入します。総仕入高に返品を加えてしまわないよう、締切りの際に区別して集計します。
