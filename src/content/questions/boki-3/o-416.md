まず取引を仕訳にし、仕訳に出てくる勘定科目から補助簿を決めます。現金・当座預金は出納帳、売掛金・買掛金は得意先別・仕入先別の元帳、仕入・売上は仕入帳・売上帳と商品有高帳、有形固定資産は固定資産台帳に記入します。

| 取引 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 6月3日 | 仕入 | 300,000 | 当座預金 | 100,000 |
|  |  |  | 買掛金 | 200,000 |
| 6月8日 | 前受金 | 50,000 | 売上 | 450,000 |
|  | 売掛金 | 400,000 | 現金 | 6,000 |
|  | 発送費 | 6,000 |  |  |
| 6月12日 | 買掛金 | 20,000 | 仕入 | 20,000 |
| 6月20日 | 備品 | 255,000 | 未払金 | 250,000 |
|  |  |  | 現金 | 5,000 |
| 6月25日 | 当座預金 | 180,000 | 売掛金 | 180,000 |
| 6月28日 | 現金 | 40,000 | 前受金 | 40,000 |

| 日付 | 記入する補助簿 |
| --- | --- |
| 6月3日 | 当座預金出納帳、商品有高帳、買掛金元帳、仕入帳 |
| 6月8日 | 現金出納帳、商品有高帳、売掛金元帳、売上帳 |
| 6月12日 | 商品有高帳、買掛金元帳、仕入帳 |
| 6月20日 | 現金出納帳、固定資産台帳 |
| 6月25日 | 当座預金出納帳、売掛金元帳 |
| 6月28日 | 現金出納帳 |

- **6月8日**：内金（前受金）と相殺した分も含めて売上 450,000円を売上帳に記入します。売掛金元帳には掛けの 400,000円だけが記入されます。発送費は現金で支払ったので現金出納帳に記入します。
- **6月12日**：返品は仕入の取消しなので、仕入帳と商品有高帳（払出欄）と買掛金元帳に記入します。
- **6月20日**：備品の代金の未払分は商品の仕入ではないので未払金で、買掛金元帳には記入しません。引取運賃は備品の取得原価に含めます。
- **6月28日**：内金を受け取っただけで、商品はまだ引き渡していないので、売上帳・商品有高帳には記入しません。

### ポイント

- 補助簿は「勘定科目ごとの明細（補助元帳）」と「取引ごとの明細（補助記入帳）」に分かれます。仕訳の勘定科目を手がかりに判定すると迷いません。
- 商品の受入・払出が生じる取引（仕入・売上とその返品）は、必ず商品有高帳にも記入します。
