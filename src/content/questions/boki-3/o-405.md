決算整理仕訳を行ってから、収益・費用を損益計算書に、資産・負債・純資産を貸借対照表に表示します。表示科目が勘定科目と違うもの（売上高・売上原価・商品・前払費用・未払費用）に注意します。

| 決算整理事項 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 1. 売上原価 | 仕入 | 264,000 | 繰越商品 | 264,000 |
|  | 繰越商品 | 288,000 | 仕入 | 288,000 |
| 2. 貸倒引当金 | 貸倒引当金繰入 | 16,000 | 貸倒引当金 | 16,000 |
| 3. 減価償却 | 減価償却費 | 270,000 | 建物減価償却累計額 | 120,000 |
|  |  |  | 備品減価償却累計額 | 150,000 |
| 4. 前払保険料 | 前払保険料 | 27,000 | 保険料 | 27,000 |
| 5. 未払利息 | 支払利息 | 9,000 | 未払利息 | 9,000 |
| 6. 貯蔵品 | 貯蔵品 | 3,000 | 通信費 | 3,000 |

| 8. 法人税等 | 法人税等 | 252,600 | 仮払法人税等 | 110,000 |
|  |  |  | 未払法人税等 | 142,600 |

- 売上原価：$264{,}000 + 4{,}120{,}000 - 288{,}000 = 4{,}096{,}000$円。
- 貸倒引当金：売掛金 $720{,}000 \times 2\% = 14{,}400$円、電子記録債権 $480{,}000 \times 2\% = 9{,}600$円。合計 24,000円と残高 8,000円の差額 16,000円を繰り入れます。貸借対照表では債権ごとに控除します。
- 前払保険料：X9年4月〜6月の3か月分。$108{,}000 \times \dfrac{3}{12} = 27{,}000$円。
- 未払利息：12月末に7月〜12月分を支払っているので、未払は1月〜3月の3か月分。$1{,}200{,}000 \times 3\% \times \dfrac{3}{12} = 9{,}000$円。試算表の 27,000円は期首の再振替（△9,000円）を含むので、計上後の支払利息は1年分の 36,000円になります。
- 未払消費税：$680{,}000 - 412{,}000 = 268{,}000$円。

当期純利益は 589,400円です。貸借対照表の繰越利益剰余金は、試算表の 468,000円に当期純利益を加えた 1,057,400円になります（資産合計・負債純資産合計 8,237,000円）。

### ポイント

- 繰越利益剰余金を試算表の金額のまま書くと、貸借対照表の貸借が当期純利益の分だけ一致しません。
- 前払保険料は「前払費用」、未払利息は「未払費用」として表示します。郵便切手の未使用分は「貯蔵品」です。
- 減価償却累計額・貸倒引当金は、対応する資産の下に控除形式で書き、差引後の金額を右の欄に書きます。
