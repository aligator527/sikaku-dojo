売上原価対立法では、商品を販売するたびに原価を商品勘定から売上原価勘定へ振り替えています。そのため、決算で「仕入・繰越商品」による売上原価の計算は行いません。試算表の売上原価がそのまま当期の売上原価になり、商品勘定の残高が期末の商品です。

| 決算整理事項 | 借方 | | 貸方 | |
| --- | --- | ---: | --- | ---: |
| 1. 返品 | 売上 | 40,000 | 売掛金 | 40,000 |
|  | 商品 | 28,000 | 売上原価 | 28,000 |
| 2. 貸倒引当金 | 貸倒引当金繰入 | 17,600 | 貸倒引当金 | 17,600 |
| 3. 減価償却 | 減価償却費 | 182,400 | 建物減価償却累計額 | 80,000 |
|  |  |  | 備品減価償却累計額 | 102,400 |
| 4. 前払地代 | 前払地代 | 112,000 | 支払地代 | 112,000 |
| 5. 未払利息 | 支払利息 | 6,000 | 未払利息 | 6,000 |
| 6. 法人税等 | 法人税等 | 246,000 | 仮払法人税等 | 80,000 |
|  |  |  | 未払法人税等 | 166,000 |

- 返品：売上と売掛金を売価で取り消し、戻ってきた商品を原価で商品勘定に戻して、売上原価を減らします。売上高は 6,480,000円、売上原価は $3{,}964{,}000 - 28{,}000 = 3{,}936{,}000$円、商品は $348{,}000 + 28{,}000 = 376{,}000$円です。
- 貸倒引当金：返品後の売掛金 720,000円 × 3% ＝ 21,600円。差額 17,600円を繰り入れます。
- 備品（定率法）：$(800{,}000 - 288{,}000) \times 20\% = 102{,}400$円。建物は $2{,}400{,}000 \div 30 = 80{,}000$円。
- 前払地代：X9年4月〜11月の8か月分。$168{,}000 \times \dfrac{8}{12} = 112{,}000$円。
- 未払利息：1月〜3月の3か月分。$600{,}000 \times 4\% \times \dfrac{3}{12} = 6{,}000$円。

当期純利益は 574,000円、繰越利益剰余金は 1,704,000円です。

### ポイント

- 売上原価対立法では、返品のときも売価の仕訳（売上・売掛金）と原価の仕訳（商品・売上原価）の2本が必要です。
- 決算整理で「（借）仕入（貸）繰越商品」などの売上原価の振替を行うと二重計上になります。
- 前払地代は「前払費用」、未払利息は「未払費用」として表示します。
