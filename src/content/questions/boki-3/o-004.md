期中に固定資産を売却するときは、期首から売却日までの減価償却費を月割で計上したうえで、売却時点の帳簿価額と売却価額を比べて売却損益を求めます。商品以外の物品の売却代金を後で受け取る権利は、売掛金ではなく未収入金です。

### 計算

1. 1年分の減価償却費：600,000円 ÷ 5年 ＝ 120,000円
2. 当期分（4月〜8月の5か月）：120,000円 × 5/12 ＝ 50,000円
3. 売却時の帳簿価額：600,000円 − 360,000円 − 50,000円 ＝ 190,000円
4. 売却損益：売却価額 180,000円 − 帳簿価額 190,000円 ＝ △10,000円（売却損）

| --- | ---: | --- | ---: |
| 備品減価償却累計額 | 360,000 | 備品 | 600,000 |
| 減価償却費 | 50,000 | | |
| 未収入金 | 180,000 | | |
| 固定資産売却損 | 10,000 | | |

### ポイント

- 間接法では、備品は **取得原価で** 貸方に、減価償却累計額は **期首残高で** 借方に記入して両方を消去します。
- 当期分の減価償却費を計上し忘れると、帳簿価額が 240,000円 となり売却損を 60,000円 と誤ります。
- 本業の商品以外の売却代金の未収分は **未収入金**、商品代金の未収分は **売掛金** です。
