## 定義

さいころの目、製品の寿命、くじの賞金のように、偶然によって値が決まり、各値（や各範囲）をとる確率が定められている変数を確率変数といいます。大文字 $X$ で確率変数を、小文字 $x$ でその実現値（観測された値）を表すのが慣例です。

## 離散型と連続型

| | 離散型 | 連続型 |
| --- | --- | --- |
| とる値 | 飛び飛びの値（0, 1, 2, … など） | ある区間のすべての実数 |
| 分布の表し方 | 確率関数 $p(x) = P(X = x)$ | 確率密度関数 $f(x)$ |
| 確率 | $P(a \leq X \leq b) = \sum_{a \leq x \leq b} p(x)$ | $P(a \leq X \leq b) = \int_a^b f(x)\,dx$ |
| 1 点の確率 | 正の値をとりうる | 常に $P(X = a) = 0$ |
| 代表例 | 二項分布、ポアソン分布、幾何分布 | 正規分布、一様分布、指数分布 |

どちらの型でも、分布関数 $F(x) = P(X \leq x)$ で分布を表すことができます。

## 確率変数の関数

確率変数 $X$ の関数 $Y = g(X)$ もまた確率変数です。期待値・分散は $E[aX + b] = aE[X] + b$、$V[aX + b] = a^2V[X]$ のように変換され、分布そのものは変数変換によって求めます。統計量（標本平均や不偏分散など）は、データ $X_1, \ldots, X_n$ という確率変数の関数なので、それ自体が確率変数であり、標本分布をもちます。

## 試験での問われ方

統計検定2級では、確率分布表から期待値・分散を求める問題、確率変数の和や 1 次変換の期待値と分散、独立な確率変数の和の分布が出題されます。準1級・1級では、同時分布・条件付き分布・変数変換を使って新しい確率変数の分布を導く問題が中心です。

## よくある誤り

- 連続型の確率変数で $P(X = a)$ を密度の値 $f(a)$ と考える。連続型では 1 点の確率は 0 で、$f(a)$ は確率ではない（1 を超えることもある）。
- 実現値 $\bar{x}$（定数）と確率変数 $\bar{X}$ を区別せずに「$\bar{x}$ の分散」を考える。
- 同じ分布に従う独立な確率変数の和 $X_1 + X_2$ と、1 つの確率変数の 2 倍 $2X_1$ を同一視する。期待値は等しいが、分散は $2\sigma^2$ と $4\sigma^2$ で異なる。
