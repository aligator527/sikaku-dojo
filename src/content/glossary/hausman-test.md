## 一般的な考え方

2 つの推定量 $\hat{\beta}_0$、$\hat{\beta}_1$ があり、

- 帰無仮説 $H_0$ のもとでは、両方とも一致推定量で、$\hat{\beta}_0$ は有効（漸近分散が最小）
- 対立仮説 $H_1$ のもとでは、$\hat{\beta}_1$ だけが一致推定量

という関係にあるとします。$H_0$ が正しければ両者の差 $q = \hat{\beta}_1 - \hat{\beta}_0$ は 0 に近く、$H_1$ のもとでは差が残るので、$q$ の大きさで検定します。ベクトルの場合は

$$H = \hat{q}^{\top}\left(\hat{V}[\hat{\beta}_1] - \hat{V}[\hat{\beta}_0]\right)^{-1}\hat{q}$$

が $H_0$ のもとで漸近的に、比べる係数の個数を自由度とするカイ二乗分布に従います。

## 分母が分散の差になる理由

$H_0$ のもとで $\hat{\beta}_0$ が有効なら、$\mathrm{Cov}(\hat{\beta}_0, q) = 0$ です（もし共分散が 0 でなければ、$\hat{\beta}_0 + cq$ の形で $\hat{\beta}_0$ より分散の小さい一致推定量が作れて矛盾します）。したがって $V[\hat{\beta}_1] = V[\hat{\beta}_0 + q] = V[\hat{\beta}_0] + V[q]$ となり、$V[q] = V[\hat{\beta}_1] - V[\hat{\beta}_0]$ です。

## パネルデータでの使い方

帰無仮説は「個体効果 $\alpha_i$ と説明変数が無相関」です。$H_0$ のもとでは変量効果推定量 $\hat{\beta}_{RE}$（GLS、有効）と固定効果推定量 $\hat{\beta}_{FE}$ はどちらも一致し、$H_1$ のもとでは $\hat{\beta}_{FE}$ だけが一致します。

例えば $\hat{\beta}_{FE} = 0.120$（標準誤差 0.020）、$\hat{\beta}_{RE} = 0.150$（標準誤差 0.015）なら

$$H = \frac{(0.120 - 0.150)^2}{0.020^2 - 0.015^2} = \frac{0.0009}{0.000175} \approx 5.14 > 3.841$$

で、5% 水準で帰無仮説を棄却し、固定効果モデルを採用します。

## 試験での問われ方

統計検定1級（社会科学）では、検定統計量の計算と結論の選択、分母が分散の和ではなく差になる理由の説明、帰無仮説・対立仮説のもとでの各推定量の性質が問われます。操作変数法と最小二乗法を比べる内生性の検定（ダービン・ウー・ハウスマン検定）も同じ構造です。

## よくある誤り

- 分母を分散の和 $\hat{V}_{FE} + \hat{V}_{RE}$ にする。
- 帰無仮説が棄却されたら変量効果モデルを選ぶ、と逆に覚える。棄却されたら一致性を保つ固定効果モデルを選びます。
- 棄却されないことを、帰無仮説が正しいことの証明とみなす。
- 有限標本では分散の差が負になり、統計量が計算できない場合があることを見落とす。
