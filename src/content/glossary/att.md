## 定義

処置群（$T = 1$）の中での潜在結果の差の平均です。$E[Y(1) \mid T = 1]$ は処置群の観測値の平均そのものなので、推定の課題は「処置群が処置を受けなかったら」という反実仮想の平均 $E[Y(0) \mid T = 1]$ をどう求めるかに集約されます。対照群（$T = 0$）に限った効果 $E[Y(1) - Y(0) \mid T = 0]$ は ATU（ATC）と呼ばれ、

$$\mathrm{ATE} = P(T = 1)\,\mathrm{ATT} + P(T = 0)\,\mathrm{ATU}$$

の関係があります。

## ATE と食い違うとき

効果が個体によって異なり、しかも効果の大きい人ほど処置を受けやすい（あるいは受けにくい）とき、ATT と ATE は異なります。たとえば職業訓練に、訓練から得るものが大きい人ほど自発的に参加するなら、ATT は ATE より大きくなります。無作為化比較試験では処置群が集団全体の縮図なので、ATT = ATE です。

## 識別と推定

ATT に必要なのは $E[Y(0) \mid T = 1]$ だけなので、ATE より弱い仮定で済みます。

- **条件**：$Y(0) \perp T \mid X$（処置なしの結果についての無視可能性）と、処置群の $X$ の範囲で対照群が存在すること（$P(T = 1 \mid X) < 1$）。
- **マッチング**：処置群の各個体に、$X$（または傾向スコア）が近い対照群の個体を組み合わせ、差を平均する。
- **重み付け**：処置群には重み 1、対照群には $e(X)/\{1 - e(X)\}$（$e(X)$ は傾向スコア）を与え、対照群の共変量の分布を処置群に合わせる。
- **差の差法**：平行トレンドの仮定のもとで、処置群の変化から対照群の変化を引いた値は ATT を推定する。
- **層別**：層ごとの差を、処置群の層の構成比で重み付けして平均する。

## 試験での問われ方

統計検定準1級では、潜在結果の表や層別の集計から ATT と ATE を計算し分ける問題、重み付けの式（ATT 用と ATE 用の違い）、差の差法が推定する効果が ATT であることを問う問題が出ます。データサイエンスエキスパートでは、施策を受けた顧客での効果の評価として出題されます。

## よくある誤り

- ATT と ATE は常に等しいと考える。
- ATT の推定に、対照群の層の構成や集団全体の構成で重み付けする。
- 重み付けで、ATT を求めるのに ATE 用の重み $1/e(X)$、$1/\{1 - e(X)\}$ を使う。
