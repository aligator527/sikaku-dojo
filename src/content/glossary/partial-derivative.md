## 定義

2 変数関数 $f(x, y)$ について、$y$ を固定して $x$ で微分した

$$f_x(a, b) = \frac{\partial f}{\partial x}(a, b) = \lim_{h\to0}\frac{f(a + h, b) - f(a, b)}{h}$$

を $x$ についての**偏微分係数**、$(a, b)$ を動かして得られる関数 $f_x$ を**偏導関数**といいます。例えば $f = x^2y + y^3$ なら $f_x = 2xy$、$f_y = x^2 + 3y^2$、$f_{xy} = (f_x)_y = 2x$ です。

## 全微分可能性との違い

偏微分可能であっても、その点で連続とは限りません。$f(x, y) = \dfrac{xy}{x^2 + y^2}$（原点では 0）は、原点で $f_x = f_y = 0$ ですが、直線 $y = x$ に沿うと値は $\frac{1}{2}$ に近づくので連続ではありません。

接平面で近似できる性質（**全微分可能**）は、偏微分可能より強い条件です。

$$f(a + h, b + k) = f(a, b) + f_x h + f_y k + o\bigl(\sqrt{h^2 + k^2}\bigr)$$

偏導関数が存在して連続（$C^1$ 級）なら全微分可能です。全微分可能なら連鎖律 $\frac{d}{dt}f(x(t), y(t)) = f_x x'(t) + f_y y'(t)$ が使えます。

## 2 階偏導関数

$f_{xx}, f_{xy}, f_{yx}, f_{yy}$ を並べたものがヘッセ行列です。$f_{xy}$ と $f_{yx}$ が連続なら $f_{xy} = f_{yx}$（シュワルツの定理）が成り立つので、通常ヘッセ行列は対称になります。

## 機械学習・統計での使い方

損失関数を各パラメータで偏微分したものを並べたのが勾配で、勾配降下法や誤差逆伝播法の基礎です。最尤推定では、対数尤度を各母数で偏微分して 0 とおいた連立方程式（尤度方程式）を解きます。最小二乗法の正規方程式も、残差平方和の偏微分から得られます。

## 試験での問われ方

数検1級では、偏導関数・高階偏導関数の計算、原点で定義が異なる関数の偏微分可能性・全微分可能性・連続性の判定、2 変数のテイラー展開が出題されます。E資格や統計検定では、損失関数や対数尤度の偏微分の計算として頻出です。

## よくある誤り

- 偏微分可能なら連続、あるいは全微分可能だと考える。
- 偏微分するとき、固定すべき変数を含む項まで定数扱いせずに微分する（または逆に、変数を含む項を消してしまう）。
- $f_{xy} = f_{yx}$ をいつでも成り立つと考える。連続性の仮定がないと成り立たない例があります。
