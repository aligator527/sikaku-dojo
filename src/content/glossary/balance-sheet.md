## 定義

貸借対照表は、決算日時点で企業がどのような資産を持ち（資金の運用）、それをどのような負債と純資産でまかなっているか（資金の調達）を示します。左側（借方）に資産、右側（貸方）に負債と純資産を記載し、左右の合計は必ず一致します。

## 区分と配列

| 区分 | 主な項目 |
| --- | --- |
| 流動資産 | 現金預金、売掛金、商品、短期の貸付金、前払費用 |
| 固定資産 | 有形固定資産（建物・備品・土地）、無形固定資産（のれん・ソフトウェア）、投資その他の資産 |
| 繰延資産 | 創立費、開業費、株式交付費など |
| 流動負債 | 買掛金、短期借入金、未払金、未払費用、未払法人税等 |
| 固定負債 | 長期借入金、社債、退職給付引当金 |
| 純資産 | 株主資本、評価・換算差額等、株式引受権、新株予約権 |

流動と固定の区分は、まず正常な営業の循環（仕入 → 販売 → 回収）の中にある項目を流動とし（正常営業循環基準）、それ以外は決算日の翌日から1年以内に現金化・支払期限が来るかどうかで分けます（一年基準）。一般の企業は、流動性の高い項目から順に並べる流動性配列法を使います。

## 3級で注意する表示

| 帳簿上の勘定 | 貸借対照表の表示 |
| --- | --- |
| 繰越商品 | 商品 |
| 前払保険料・前払家賃など | 前払費用 |
| 未払利息・未払給料など | 未払費用 |
| 貸倒引当金 | 売掛金などから控除する形で表示 |
| 減価償却累計額 | 各固定資産から控除する形で表示 |
| 繰越利益剰余金 | 当期純利益を加えた金額 |

## 試験での問われ方

日商簿記3級・2級の第3問で、決算整理後の金額から貸借対照表を作成する問題が出ます。1級では表示区分（一年基準の適用、投資その他の資産の範囲など）が理論でも問われます。中小企業診断士の財務・会計では、流動・固定の分類や、流動比率・自己資本比率などの安全性分析の基礎として出題されます。

## よくある誤り

- 繰越利益剰余金に当期純利益を加え忘れ、左右の合計が一致しない。
- 貸付金・借入金など営業循環の外にある債権・債務で、回収・返済が1年を超えて行われるものを流動項目に含める（売掛金・買掛金などの営業債権・債務は期間にかかわらず流動）。
- 帳簿上の勘定科目名（繰越商品など）をそのまま表示科目として書く。
