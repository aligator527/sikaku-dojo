## 定義

1 階差分 $\Delta X_t = (1 - B)X_t = X_t - X_{t-1}$ を $d$ 回とった系列が ARMA($p, q$) に従うとき、$X_t$ は ARIMA($p, d, q$) に従うといいます。I は和分（integrated）の意味で、差分の逆の操作（累積和）で元の系列に戻ることを表します。

| モデル | 内容 |
|---|---|
| ARIMA(0,1,0) | $X_t = X_{t-1} + \varepsilon_t$：ランダムウォーク |
| ARIMA(0,1,1) | $\Delta X_t = \varepsilon_t + \theta\varepsilon_{t-1}$：単純指数平滑法と同じ予測を与える |
| ARIMA(1,1,0) | $\Delta X_t = \phi\Delta X_{t-1} + \varepsilon_t$ |

ARIMA(1,1,0) を元の系列で書くと、たとえば $\phi = 0.5$ なら $(1 - 0.5B)(1 - B)X_t = \varepsilon_t$ から $X_t = 1.5X_{t-1} - 0.5X_{t-2} + \varepsilon_t$ です。AR(2) の形ですが、特性方程式 $(1 - 0.5z)(1 - z) = 0$ が $z = 1$ を根にもつので非定常です。

## 季節 ARIMA

月次データなどの周期 $s$ の季節性には、季節差分 $(1 - B^s)$ と季節ラグの AR・MA 項を加えた SARIMA$(p, d, q)(P, D, Q)_s$ を使います。航空旅客数のモデルとして有名な SARIMA$(0,1,1)(0,1,1)_{12}$ は

$$(1 - B)(1 - B^{12})X_t = (1 + \theta B)(1 + \Theta B^{12})\varepsilon_t$$

で、差分後の系列の自己相関はラグ 1、11、12、13 だけが 0 でなくなります。

## 差分の回数の決め方

- 単位根検定（ADF 検定など）や、コレログラムがゆっくり減衰するかどうかで判断する。
- 差分のしすぎ（過剰差分）に注意：定常な系列、たとえばホワイトノイズを差分すると $\varepsilon_t - \varepsilon_{t-1}$ となり、反転可能でない MA(1)（$\theta = -1$、ラグ 1 の自己相関 $-0.5$）が生じる。差分後のラグ 1 の自己相関が $-0.5$ に近ければ、過剰差分を疑う。
- 対数をとってから差分すると、変化率（成長率）に近い系列になる。

## 予測の特徴

$d \geq 1$ の ARIMA では、予測誤差の分散が予測期間とともに際限なく大きくなり、予測区間は先へ行くほど広がり続けます（定常な ARMA では一定の幅に落ち着く）。

## 試験での問われ方

統計検定準1級・1級では、ARIMA を元の系列の式に書き直す問題、差分後の系列の自己相関（季節 ARIMA を含む）、過剰差分の影響、予測区間の広がり方が問われます。データサイエンスエキスパートでは、売上などの予測モデルの選択として登場します。

## よくある誤り

- ARIMA($p, d, q$) の $d$ を、AR の次数やラグの数と取り違える。
- 季節差分 $1 - B^{12}$ と 12 回差分 $(1 - B)^{12}$ を混同する。
- 差分は多めにとっておけば安全だと考える（過剰差分は反転可能性を失わせ、予測を悪くする）。
