## 現象

独立に生成した 2 本のランダムウォーク $X_t = X_{t-1} + u_t$、$Y_t = Y_{t-1} + v_t$ について、回帰式 $Y_t = \alpha + \beta X_t + e_t$ を最小二乗法で推定すると、真の $\beta$ は 0 なのに

- $\hat{\beta}$ の $t$ 検定が名目の有意水準をはるかに超える頻度で有意になる、
- 決定係数 $R^2$ が大きくなりやすい、
- 残差に強い正の自己相関が残り、ダービン・ワトソン比が 0 に近い、

という結果がよく出ます。グレンジャーとニューボルド（1974）がシミュレーションで示し、その後、標本サイズを増やしても $t$ 統計量が発散し、有意になる確率が 1 に近づくことが理論的に示されました。

## なぜ起こるか

通常の回帰の $t$ 検定は、誤差が定常で独立に近いことを前提にしています。ランダムウォークは長い期間にわたって同じ方向へ漂う（確率的トレンドをもつ）ので、たまたま同じ時期に上昇・下降した 2 本の系列は、無関係でも強く相関して見えます。残差も単位根をもつ非定常な系列になり、標準誤差が大幅に過小評価されます。目安として「$R^2$ がダービン・ワトソン比より大きければ見せかけの回帰を疑え」と言われます。

## 対策

| 方法 | 内容 |
|---|---|
| 単位根検定 | 回帰の前に各系列が単位根をもつか（ADF 検定など）を確かめる |
| 差分をとる | $\Delta Y_t = \beta\Delta X_t + e_t$ のように変化量どうしを回帰する |
| 共和分の検定 | 水準どうしの線形結合 $Y_t - \beta X_t$ が定常なら（共和分）、水準の回帰にも意味がある。残差に単位根検定を行う（エングル・グレンジャー法） |
| 誤差修正モデル | 共和分があるとき、短期の変化と長期の均衡からのずれを同時にモデル化する |

## 関連する話題

2級の範囲では、時間とともに増える 2 つの量（たとえば年ごとのある商品の売上と別の無関係な指標）に強い相関が見られても、共通のトレンドによる見かけの相関である可能性がある、という形で注意が促されます。

## 試験での問われ方

統計検定準1級では、独立なランダムウォークどうしの回帰の結果の解釈（$R^2$ や $t$ 値が大きくても関係は示されない）、対策としての差分や単位根検定を選ぶ問題が出ます。1級・データサイエンスエキスパートでは、共和分やダービン・ワトソン比と合わせて問われます。

## よくある誤り

- $t$ 値や $R^2$ が十分大きければ、非定常な系列どうしでも関係があると判断する。
- 標本サイズを増やせば見せかけの有意性は消えると考える（むしろ有意になりやすくなる）。
- 非定常な系列の回帰はすべて見せかけだと考える（共和分があれば意味のある長期関係を表す）。
