## 考え方

表現力の高いモデルは訓練データの偶然の変動まで覚えてしまい（過学習）、新しいデータでの性能が下がります。正則化は、訓練データへの当てはまりを多少犠牲にしてもバリアンスを減らし、汎化誤差を小さくすることを狙います。バイアスとバリアンスのトレードオフの中で、モデルの実効的な複雑さを調整する手段と言えます。

## 主な方法

| 分類 | 例 |
| --- | --- |
| パラメータノルムペナルティー | L2 正則化（重み減衰、リッジ）、L1 正則化（ラッソ、スパースな解） |
| 確率的な削除 | ドロップアウト、ドロップコネクト |
| データ | データ拡張、ノイズ付与、MixUp |
| 目標 | ラベル平滑化 |
| 学習の手続き（陰的正則化） | 早期終了、バッチサイズ・学習率の調整 |
| 構造 | 重み共有（CNN）、パラメータ共有、マルチタスク学習 |
| 複数モデル | アンサンブル（バギングなど） |

罰則項を使う方法では、目的関数 $J(\boldsymbol\theta) = L(\boldsymbol\theta) + \lambda\Omega(\boldsymbol\theta)$ を最小化します。$\lambda$（正則化係数）が大きいほど制約が強くなり、大きすぎると過少適合になります。$\lambda$ は訓練データではなく検証データで選ぶハイパーパラメータです。

## ベイズ的な解釈

L2 正則化は重みに正規分布の事前分布を、L1 正則化はラプラス分布の事前分布を置いたときの MAP 推定にあたります。正則化項は「パラメータはあまり大きくないはずだ」という事前の知識を表していると解釈できます。

## 陰的正則化

明示的な罰則項がなくても、学習の手続きそのものが汎化に影響します。早期終了は 2 次近似のもとで L2 正則化と似た効果を持ち、SGD の勾配ノイズ（小さいバッチ、大きい学習率）は平坦な最小点に落ち着きやすくすると考えられています。E資格のシラバス 2026 では、早期終了・バッチサイズ・学習率の調整が「陰的正則化」の項目に入っています。

## 試験での問われ方

E資格では、正則化の種類の分類、L1 と L2 の解の違い（スパース性）、正則化係数の効果、MAP 推定との対応、陰的正則化の考え方が出題されます。統計検定データサイエンスエキスパートや準1級では、リッジ回帰・ラッソと交差検証による $\lambda$ の選択として登場します。

## よくある誤り

- 正則化を強めるほど汎化性能が上がると考える（強すぎるとバイアスが増えて過少適合）。
- 正則化係数を訓練誤差が最小になるように選ぶ（訓練誤差は $\lambda = 0$ が最小）。
- バッチ正規化などの「正規化」と「正則化」を混同する（正規化は入力や中間表現のスケールをそろえる操作）。
- バイアス項にも同じ罰則をかけるのが標準だと考える（通常は重みにだけかける）。
