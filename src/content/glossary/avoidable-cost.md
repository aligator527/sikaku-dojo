## 定義

製品の製造をやめる、部門を閉鎖する、部品の内製をやめるといった判断では、「やめると何が減るか」が重要です。やめれば発生しなくなる原価が回避可能原価、やめても発生し続ける原価が回避不能原価です。

| 原価の例 | 区分 |
| --- | --- |
| 直接材料費・変動製造間接費などの変動費 | 回避可能 |
| その製品専用の設備の賃借料（解約できる場合） | 回避可能 |
| その製品のためだけに雇っている臨時工の賃金 | 回避可能 |
| 既存設備の減価償却費 | 回避不能（埋没原価） |
| 本社費など共通固定費の配賦額 | 回避不能 |
| 他の部署に配置転換する監督者の給料 | 回避不能 |

## 計算例：製品の廃止

製品Xの損益が、売上高5,000,000円、変動費3,200,000円、個別固定費1,000,000円（うち廃止すれば回避できるのは600,000円）、共通固定費の配賦額1,200,000円で、営業損益は −400,000円 だったとします。

廃止すると、貢献利益1,800,000円を失う一方、回避できる原価は600,000円だけです。会社全体の利益は 1,800,000 − 600,000 ＝ 1,200,000円 減るので、赤字に見えても製品Xは続けたほうが有利です。共通固定費の配賦額は、廃止しても他の製品に付け替えられるだけで、会社全体では減りません。

## 試験での問われ方

日商簿記1級では、内製か購入かの意思決定で「購入に切り替えると回避できる固定費はどれか」を判断する問題や、製品・事業部の廃止の判断が出題されます。原価概念の理論問題でも、回避可能原価の定義が問われます。

## よくある誤り

- 共通固定費の配賦額を、廃止すれば減る原価とみなす。
- 個別固定費（直接固定費）をすべて回避可能と考える。資料で「回避できる」と明記された部分だけを使います。
- 配賦後の営業損益が赤字というだけで廃止を選ぶ。
