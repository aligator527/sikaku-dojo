## 定義

期中の仕訳は取引のつど行いますが、それだけでは「売れた商品の原価」「建物の価値の減少」「来期分の保険料」などが反映されていません。決算整理は、こうした期末時点の修正をまとめて行う手続きで、そのための仕訳を決算整理仕訳、問題で与えられる修正内容を決算整理事項といいます。

決算の流れは、①決算整理前残高試算表の作成 → ②決算整理 → ③決算整理後残高試算表 → ④決算振替と帳簿の締切 → ⑤財務諸表の作成、です。

## 3級の主な決算整理事項

| 項目 | 決算整理仕訳の例 |
| --- | --- |
| 現金過不足の整理 | （借）雑損 （貸）現金過不足 |
| 当座借越の振替 | （借）当座預金 （貸）当座借越 |
| 売上原価の算定（三分法） | （借）仕入 （貸）繰越商品、（借）繰越商品 （貸）仕入 |
| 貸倒引当金の設定 | （借）貸倒引当金繰入 （貸）貸倒引当金 |
| 減価償却 | （借）減価償却費 （貸）備品減価償却累計額 |
| 貯蔵品への振替 | （借）貯蔵品 （貸）通信費・租税公課 |
| 経過勘定 | （借）前払保険料 （貸）保険料 など |
| 消費税の整理 | （借）仮受消費税 （貸）仮払消費税・未払消費税 |
| 法人税等の計上 | （借）法人税、住民税及び事業税 （貸）仮払法人税等・未払法人税等 |

2級ではこれに、棚卸減耗損・商品評価損、売買目的有価証券・その他有価証券の評価替え、満期保有目的債券の償却原価法、外貨建項目の換算、各種引当金、税効果会計などが加わります。

## 試験での問われ方

3級の第3問（35点）は、決算整理事項にもとづいて財務諸表・精算表・決算整理後残高試算表を作る問題です。2級の第3問でも同様の総合問題が出ます。整理事項の中に「期中の未処理事項」（売掛金の回収の未記帳など）が混ざっているのが普通で、それを先に修正してから引当金などを計算させるのが典型的なひっかけです。

## よくある誤り

- 未処理事項を修正する前の残高で、貸倒引当金や減価償却費を計算する。
- 法人税等を、ほかの決算整理をすべて反映する前の利益から計算してしまう（税引前当期純利益は全項目を整理した後の金額）。
- 決算整理後残高試算表に当期純利益を含めてしまう。決算振替の前なので、繰越利益剰余金は期首の残高のままです。
