## 定義

「企業結合に関する会計基準」では、企業結合のうち、いずれかの企業が他の企業の支配を獲得するものを **取得** とし、支配を獲得した側（取得企業）の立場で処理します（パーチェス法）。同じ親会社の下にある会社どうしの結合（共通支配下の取引）は、帳簿価額で処理します。

取得の処理の要点は次のとおりです。

1. **取得原価**：交付した対価（株式なら交付日の時価）で測定する。
2. **配分**：受け入れた資産・負債を、企業結合日の時価で計上する。
3. **差額**：取得原価が受け入れた純資産（時価）を上回ればのれん、下回れば負ののれん発生益（特別利益）とする。
4. **取得関連費用**：外部のアドバイザーへの報酬などは、取得原価に含めず発生した期の費用とする。

## 仕訳例（吸収合併）

P社（取得企業）はT社を吸収合併し、T社の株主にP社株式1,000株（時価 1株 ￥5,600）を交付した。T社の資産の時価は ￥8,000,000、負債の時価は ￥3,000,000 である。増加する資本のうち ￥3,000,000 を資本金とし、残りをその他資本剰余金とする。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 諸資産 | 8,000,000 | 諸負債 | 3,000,000 |
| のれん | 600,000 | 資本金 | 3,000,000 |
| | | その他資本剰余金 | 2,600,000 |

取得原価は 1,000株 × 5,600 ＝ 5,600,000円、受け入れた純資産は 8,000,000 − 3,000,000 ＝ 5,000,000円 で、差額 600,000円 がのれんです。

## 結合の形

| 形 | 内容 |
| --- | --- |
| 吸収合併 | 一方の会社が存続し、他方の会社の資産・負債を引き継ぐ |
| 新設合併 | 新しい会社を設立し、両社の資産・負債を引き継ぐ |
| 株式交換 | 相手会社の株主から株式を取得して、完全子会社にする |
| 株式移転 | 新しく設立した親会社に、既存会社の株式をすべて取得させる |
| 会社分割・事業譲受 | 事業の一部を引き継ぐ |

株式交換では、完全親会社は子会社株式を取得するだけで、個別財務諸表にはのれんは生じません（のれんは連結で計算します）。

## 試験での問われ方

日商簿記2級では吸収合併の仕訳（のれんの計算と増加資本の内訳）が出題されます。1級では、株式交換・株式移転、取得原価の算定、取得関連費用の扱い（合併では費用、株式交換による子会社株式の個別上の取得原価には含めるなど）、段階取得、逆取得、負ののれんが計算・理論の両方で問われます。

## よくある誤り

- 被合併会社の資産・負債を帳簿価額で受け入れる（取得では時価）。
- のれんを「交付した株式の時価 − 被合併会社の帳簿上の純資産」で計算する。
- 合併の取得関連費用をのれんに含める。
