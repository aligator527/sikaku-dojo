## 定義

離散型の確率変数では $E[X] = \sum_x x\,P(X = x)$、連続型では $E[X] = \int x f(x)\,dx$ を期待値といいます。関数 $g(X)$ の期待値は $E[g(X)] = \sum_x g(x)P(X = x)$（連続なら $\int g(x)f(x)\,dx$）で、$g(X)$ の分布を求め直す必要はありません。

## 性質

- 線形性：$E[aX + bY + c] = aE[X] + bE[Y] + c$。**独立でなくても** 成り立つ。
- 積：$X, Y$ が独立なら $E[XY] = E[X]E[Y]$。一般には $E[XY] = E[X]E[Y] + \mathrm{Cov}(X, Y)$。
- 非負の整数値をとる $X$ では $E[X] = \sum_{k \geq 1} P(X \geq k)$、非負の連続型では $E[X] = \int_0^\infty P(X > x)\,dx$。
- 一般に $E[g(X)] \neq g(E[X])$。たとえば $E[X^2] \geq (E[X])^2$ で、差が分散。

## 計算例

公正なさいころの目 $X$ では $E[X] = (1 + 2 + \cdots + 6)/6 = 3.5$、$E[X^2] = 91/6$ なので $V[X] = 91/6 - 3.5^2 = 35/12$ です。さいころを 10 回投げた目の合計の期待値は、線形性から $10 \times 3.5 = 35$ になります。

### 指示変数による計算

「$n$ 人が無作為に席に着くとき、自分の席に座る人数」の期待値は、$i$ 番目の人が自分の席に座れば 1、そうでなければ 0 をとる変数 $I_i$ の和と考えると、$E[I_i] = 1/n$ なので $n \times 1/n = 1$ です。$I_i$ どうしは独立ではありませんが、線形性は独立性を必要としません。

## 試験での問われ方

統計検定2級では、確率分布表からの期待値と分散の計算、線形性を使った和や平均の期待値、くじ・ゲームの期待値が出題されます。準1級・1級では、条件付き期待値の繰り返し $E[X] = E[E[X \mid Y]]$、裾確率の積分による計算、モーメント母関数からの導出、期待値が存在しない分布（コーシー分布）が問われます。

## よくある誤り

- 独立性を確かめずに $E[XY] = E[X]E[Y]$ を使う。
- $E[1/X] = 1/E[X]$ や $E[X^2] = (E[X])^2$ のように、非線形な関数を期待値の外に出す。
- 期待値を「最もよく起きる値」と解釈する。それは最頻値であり、期待値は実際にとりえない値（3.5 など）にもなる。
