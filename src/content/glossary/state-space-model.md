## 構造

時系列 $y_t$ の背後に、直接は観測できない状態 $\alpha_t$（真の水準、トレンド、季節成分など）があると考えます。

- 観測方程式：$y_t = Z_t\alpha_t + \varepsilon_t$、$\varepsilon_t \sim N(0, H_t)$
- 状態方程式：$\alpha_{t+1} = T_t\alpha_t + \eta_t$、$\eta_t \sim N(0, Q_t)$

最も簡単なローカルレベルモデルは $y_t = \mu_t + \varepsilon_t$、$\mu_{t+1} = \mu_t + \eta_t$ で、ランダムウォークする水準に観測誤差が加わったものです。トレンドや季節成分、回帰項を状態に組み込めば、柔軟なモデルを組み立てられます。ARIMA モデルも状態空間モデルとして書き直せます。

## カルマンフィルタ

観測値が得られるたびに、状態の条件付き分布（正規分布なので平均と分散）を更新する計算手順です。ローカルレベルモデルでは、$a_{t|t-1},\ P_{t|t-1}$ を「時点 $t-1$ までの情報による $\mu_t$ の予測の平均と分散」として

1. 更新（フィルタリング）：カルマンゲイン $K_t = \dfrac{P_{t|t-1}}{P_{t|t-1} + \sigma_\varepsilon^2}$、$a_{t|t} = a_{t|t-1} + K_t(y_t - a_{t|t-1})$、$P_{t|t} = (1 - K_t)P_{t|t-1}$
2. 予測：$a_{t+1|t} = a_{t|t}$、$P_{t+1|t} = P_{t|t} + \sigma_\eta^2$

を繰り返します。更新式は、予測と観測値を精度（分散の逆数）で重み付けした平均で、正規分布の条件付き分布の公式そのものです。

**計算例**：$\sigma_\varepsilon^2 = 1,\ \sigma_\eta^2 = 0.5$、$a_{1|0} = 0,\ P_{1|0} = 1$ で $y_1 = 2$ を観測すると、$K_1 = 0.5$、$a_{1|1} = 1$、$P_{1|1} = 0.5$、次の予測は $a_{2|1} = 1$、$P_{2|1} = 1.0$ です。

## 性質と使いみち

- $P_{t|t-1}$ は一定値に収束し、そのときのゲインで更新するローカルレベルモデルのフィルタは、単純指数平滑法と同じ形になる（ARIMA(0,1,1) とも同等）。信号対雑音比 $q = \sigma_\eta^2/\sigma_\varepsilon^2$ が大きいほどゲインが大きく、新しい観測に敏感になる。
- 欠測があっても、その時点は更新を飛ばして予測だけ行えばよい。
- 1 期先予測誤差とその分散から尤度が計算でき（予測誤差分解）、未知の分散パラメータを最尤法で推定できる。
- 全データを使って過去の状態を推定し直す操作を平滑化という。

## 試験での問われ方

統計検定1級では、ローカルレベルモデルのカルマンフィルタの導出、数値を使った更新・予測の計算、定常ゲインと指数平滑法との関係が記述式で問われます。データサイエンスエキスパートでは、時系列の成分分解や欠測を含むデータの予測手法として登場します。

## よくある誤り

- 予測のステップで状態の分散に $\sigma_\eta^2$ を加え忘れる。
- カルマンゲインの分母に $\sigma_\eta^2$ を使う（分母は予測分散 $+$ 観測誤差の分散 $\sigma_\varepsilon^2$）。
- 状態空間の「状態」をマルコフ連鎖の状態空間（取りうる値の集合）と混同する。
