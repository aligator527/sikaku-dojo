## 定義

予定配賦率は「製造間接費予算 ÷ 基準操業度」で計算します。基準操業度を大きく取るほど固定費率が小さくなり、製品原価に含まれる固定費が少なくなります。どの水準を基準にするかは、原価管理の目的や製品原価の安定性を考えて選びます。

| 種類 | 内容 |
| --- | --- |
| 理論的生産能力 | 機械の故障や作業の中断がまったくない理想的な状態での最大操業度。実現できないため、通常は基準にしない |
| 実際的生産能力 | 理論的生産能力から、機械の修繕・段取・休日など避けられない作業休止を差し引いた操業度 |
| 平均操業度（正常操業度） | 販売面も考慮し、景気の1循環（数年）の需要を平均した操業度 |
| 期待実際操業度（予算操業度） | 次の1年間に実際に見込まれる操業度 |

原価計算基準は、予定配賦率の計算に使う操業度を、技術的に達成できる最大の操業度ではなく、その期間の生産・販売の事情を考慮して予期される操業度とすることを原則としています。

## 操業度差異への影響

年間の固定費予算が24,000,000円で、実際操業度が48,000時間だったとします。

| 基準操業度 | 固定費率 | 操業度差異 |
| --- | ---: | ---: |
| 実際的生産能力 60,000時間 | 400円 | −4,800,000円 |
| 平均操業度 50,000時間 | 480円 | −960,000円 |
| 期待実際操業度 48,000時間 | 500円 | 0円 |

実際的生産能力を基準にすると、使われなかった生産能力のコストが操業度差異として大きく表れます。期待実際操業度を基準にすると、見込みどおりなら差異は出ませんが、その年の需要の見込みによって製品原価が変わります。

## 試験での問われ方

日商簿記2級では、基準操業度と固定費予算から固定費率・予定配賦率を求め、操業度差異を計算するのが基本です。1級では、上の表のように基準操業度の候補ごとに予定配賦率や操業度差異を比較する問題や、活動基準原価計算で実際的生産能力にもとづく活動ドライバー率から未利用キャパシティのコストを求める問題が出ます。

## よくある誤り

- 理論的生産能力と実際的生産能力を取り違える。
- 年間の基準操業度と月間の実際操業度をそのまま比べる。
- 基準操業度を大きくすると操業度差異が小さくなると考える。固定費率は小さくなりますが、実際操業度との差が広がるため、不利差異は通常大きくなります。
