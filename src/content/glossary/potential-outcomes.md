## 定義

個体 $i$ が処置を受けた場合（$T_i = 1$）の結果を $Y_i(1)$、受けなかった場合（$T_i = 0$）の結果を $Y_i(0)$ とし、これらを潜在結果と呼びます。個体 $i$ の因果効果は $\tau_i = Y_i(1) - Y_i(0)$ です。ネイマンが実験の文脈で導入し、ルービンが観察研究にまで広げたので、ルービンの因果モデルとも呼ばれます。

実際に観測されるのは、受けた処置に対応する一方 $Y_i = T_iY_i(1) + (1 - T_i)Y_i(0)$ だけで、もう一方は「もし別の処置を受けていたら」という反実仮想の値です。個体ごとの効果は決して直接観測できない、というのが因果推論の根本問題で、そのため集団の平均で効果を定義します。

| 推定対象 | 定義 |
|---|---|
| 平均処置効果（ATE） | $E[Y(1) - Y(0)]$ |
| 処置群における平均処置効果（ATT） | $E[Y(1) - Y(0) \mid T = 1]$ |
| 条件付き平均処置効果（CATE） | $E[Y(1) - Y(0) \mid X = x]$ |

## 単純な比較と選択バイアス

処置群と対照群の平均の差は

$$E[Y \mid T = 1] - E[Y \mid T = 0] = \underbrace{E[Y(1) - Y(0) \mid T = 1]}_{\text{ATT}} + \underbrace{E[Y(0) \mid T = 1] - E[Y(0) \mid T = 0]}_{\text{選択バイアス}}$$

と分解できます。処置を受ける人と受けない人で、処置がなかった場合の結果 $Y(0)$ がもともと違えば、単純な差は因果効果になりません。無作為割り付けでは $T$ が潜在結果と独立になるので選択バイアスは 0 になり、単純な差が ATE（= ATT）の不偏推定量になります。観察研究では、強く無視できる割り付けなどの仮定のもとで、傾向スコアや回帰による調整を行います。

## SUTVA

潜在結果を $Y_i(1), Y_i(0)$ の 2 つで書けるためには、SUTVA（stable unit treatment value assumption）が必要です。

1. **干渉がない**：個体 $i$ の結果は、他の個体がどの処置を受けたかに影響されない（感染症のワクチンや、同じ教室の生徒への介入では崩れやすい）。
2. **処置のばらつきがない**：「処置を受ける」の中身が個体によって違わない（同じ薬でも用量が違えば別の処置）。

## 試験での問われ方

統計検定準1級（2027 年の範囲表で大項目「統計的因果推論」に追加）では、潜在結果の表から ATE・ATT を計算する問題、単純比較の差が因果効果にならない理由（選択バイアスの分解）、SUTVA の意味を問う問題が出ます。データサイエンスエキスパート・1級では、施策効果の評価や観察研究の調整の前提として登場します。

## よくある誤り

- 観測された $Y_i$ を両方の潜在結果とみなし、個体ごとの効果が計算できると考える。
- 処置群と対照群の平均の差が、常に ATE になると考える。
- 干渉がある状況（友人どうしへの介入など）でも、SUTVA を気にせずに個体ごとの潜在結果を 2 つで書く。
