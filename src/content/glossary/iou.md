## 定義

領域 $A$（予測）と $B$（正解）について、共通部分の面積を和集合の面積で割ります。完全に一致すれば 1、まったく重ならなければ 0 です。集合の類似度としてはジャッカード係数と同じ式です。

## 計算

ボックスを左上 $(x_1, y_1)$・右下 $(x_2, y_2)$ で表すと、共通部分は

$$w = \max\bigl(0,\ \min(x_2^A, x_2^B) - \max(x_1^A, x_1^B)\bigr),\qquad h = \max\bigl(0,\ \min(y_2^A, y_2^B) - \max(y_1^A, y_1^B)\bigr)$$

で、面積は $wh$ です。和集合の面積は 2 つの面積の和から共通部分を引きます。

例：$A = (0, 0, 4, 4)$、$B = (2, 0, 6, 4)$ なら、共通部分は $2 \times 4 = 8$、和集合は $16 + 16 - 8 = 24$ で $\mathrm{IoU} = 1/3$ です。$B = (2, 2, 6, 6)$ にずらすと、共通部分 $4$、和集合 $28$ で $\mathrm{IoU} = 1/7 \approx 0.143$ になります。

## 使われる場面

- **検出の正誤判定**：予測ボックスと正解ボックスの IoU が閾値（PASCAL VOC では 0.5）以上なら TP とします。COCO の mAP は閾値 0.50〜0.95 を 0.05 刻みで変えた平均です。
- **NMS**：信頼度の高いボックスと IoU が閾値を超える他のボックスを重複として除きます。
- **アンカーの割り当て**：正解ボックスとの IoU が高いアンカーを正例、低いアンカーを負例として学習します。
- **セグメンテーション**：画素の集合として IoU を計算し、クラスごとの平均（mIoU）で評価します。
- **損失関数**：$1 - \mathrm{IoU}$ やその改良（重ならない場合も勾配が出る GIoU など）を位置の損失に使うことがあります。

## 関連する指標

ダイス係数 $2|A \cap B|/(|A| + |B|)$ とは $\mathrm{Dice} = 2\,\mathrm{IoU}/(1 + \mathrm{IoU})$ の関係にあります（IoU $= 1/3$ なら Dice $= 0.5$）。順位は一致しますが、値は Dice の方が大きくなります。

## 試験での問われ方

E資格（シラバス 2026 の性能指標のキーワード）では、2 つのボックスの IoU の計算、IoU を計算する関数の実装（共通部分の幅・高さを 0 で切ること）、閾値による TP / FP の判定、セグメンテーションでの mIoU が出題されます。

## よくある誤り

- 分母を 2 つの面積の和にして、共通部分を二重に数える。
- 重ならない場合に共通部分の幅や高さが負になるのを 0 で切り忘れる。
- 座標の表し方（左上・右下か、中心・幅・高さか）を確かめずに計算する。
