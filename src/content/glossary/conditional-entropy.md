## 定義

$X = x$ が分かったときの $Y$ のエントロピーを $H(Y \mid X = x) = -\sum_y p(y \mid x)\log p(y \mid x)$ とし、それを $X$ の分布で平均したものが条件付きエントロピーです。

$$H(Y \mid X) = \sum_x p(x)\,H(Y \mid X = x) = -\sum_{x, y} p(x, y)\log p(y \mid x)$$

## 結合エントロピーと連鎖律

$X$ と $Y$ を組にした確率変数のエントロピーを結合エントロピー $H(X, Y) = -\sum_{x, y}p(x, y)\log p(x, y)$ といいます。$p(x, y) = p(x)p(y \mid x)$ から、次の連鎖律が成り立ちます。

$$H(X, Y) = H(X) + H(Y \mid X) = H(Y) + H(X \mid Y)$$

「まず $X$ を知り、次に $X$ を知ったうえで $Y$ を知る」と情報量が足し算になる、という意味です。

## 性質

- $0 \le H(Y \mid X) \le H(Y)$。条件付けると平均としてのエントロピーは増えません。
- $H(Y) - H(Y \mid X) = I(X; Y)$（相互情報量）。
- $X, Y$ が独立なら $H(Y \mid X) = H(Y)$、$Y$ が $X$ の関数なら $H(Y \mid X) = 0$。
- 一般に $H(Y \mid X) \ne H(X \mid Y)$ です。

## 計算例

$p(0,0) = p(1,1) = 0.4$、$p(0,1) = p(1,0) = 0.1$ とします。$X = 0$ のとき $Y$ の条件付き分布は $(0.8, 0.2)$、$X = 1$ のときは $(0.2, 0.8)$ で、どちらのエントロピーも約 $0.722$ ビットです。よって $H(Y \mid X) \approx 0.722$ ビットで、$H(X) = 1$ と合わせて $H(X, Y) \approx 1.722$ ビットになります。

## 試験での問われ方

E資格（シラバス 2026 の情報理論のキーワード）では、条件付き分布ごとのエントロピーを平均する計算、連鎖律による結合エントロピーの計算、相互情報量との関係が出題されます。決定木の情報利得（分割後のエントロピーの加重平均を引いたもの）の計算も同じ考え方です。

## よくある誤り

- $X$ の特定の値 $x$ での $H(Y \mid X = x)$ だけを答え、$p(x)$ による平均をとり忘れる。
- 結合エントロピーを、独立でないのに $H(X) + H(Y)$ と計算する。
- $H(Y \mid X)$ と $H(X \mid Y)$ を取り違える。
- 特定の $x$ では $H(Y \mid X = x) > H(Y)$ になりうることと、平均の $H(Y \mid X) \le H(Y)$ を混同する。
