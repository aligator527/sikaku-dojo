## 定義

スコアの高い順にデータを並べ、上位 $k$ 件を陽性と判定するときの（再現率, 適合率）を $k = 1, 2, \ldots$ について結んだものです。閾値を下げるほど再現率は増え、適合率は上下しながら陽性の割合に近づきます。

曲線の要約には、曲線の下側の面積（PR-AUC）や平均適合率（AP）を使います。AP は、陽性が現れる順位ごとの上位 $k$ 件の適合率 $\mathrm{Precision}@k$ を平均したものです。

## 計算例

スコアの高い順に 6 件のラベルが 1, 0, 1, 1, 0, 0（陽性 3 件）のとき、陽性が現れるのは 1・3・4 位で、そのときの適合率は $1$、$2/3$、$3/4$ です。AP は $(1 + 2/3 + 3/4)/3 \approx 0.806$ です。

## ROC 曲線との違い

- ROC 曲線の軸（真陽性率・偽陽性率）は陽性の割合に左右されませんが、PR 曲線の適合率は陽性の割合に強く左右されます。
- 陽性が非常に少ないと、偽陽性が数十件増えても偽陽性率はほとんど動きませんが、適合率は大きく下がります。そのため不正検知や異常検知のような不均衡データでは、PR 曲線の方がモデルの差がはっきり表れます。
- でたらめな判別の基準線は、ROC 曲線では対角線ですが、PR 曲線では「適合率 $=$ 陽性の割合」の水平線です。

## 試験での問われ方

統計検定データサイエンスエキスパートでは、順位つきのラベルから AP を計算する問題や、不均衡データで ROC 曲線と PR 曲線のどちらが適切かを選ぶ問題が出ます。E資格でも軸の定義と使い分けが問われます。

## よくある誤り

- PR 曲線の基準線を対角線だと考える。
- 陽性の割合が違うデータセット間で、PR 曲線や AP の値をそのまま比べる。
- 適合率が閾値に対して単調に変わると考える（上下に振れる）。
