## 定義

クロスサイトスクリプティング（XSS）は、掲示板や検索結果の表示のように、入力された文字列を Web ページに埋め込んで出力する処理の不備を突く攻撃です。攻撃者が仕込んだスクリプトが、脆弱なサイトのページの一部として閲覧者のブラウザで実行されるため、そのサイトの Cookie（セッション ID）を盗まれてなりすましをされたり、偽の入力フォームを表示されたりします。

## 種類

| 種類 | 仕組み |
| --- | --- |
| 反射型（Reflected XSS） | スクリプトを含むリクエストを送る罠のリンクを利用者にクリックさせ、その応答に埋め込まれたスクリプトを実行させる |
| 格納型（Stored XSS、Persistent XSS） | 掲示板などにスクリプトを含む書込みを保存させておき、後からページを閲覧した利用者のブラウザで実行させる |
| DOM ベース XSS | サーバを経由せず、ブラウザ上の JavaScript の処理の不備だけで発生する |

格納型は、罠のリンクを踏ませなくても、ページを見ただけの多数の利用者が被害を受ける点が特徴です。

## 対策

- **根本的な対策**：Web ページに出力するすべての値について、HTML の特殊文字（`<`、`>`、`&`、`"` など）をエスケープする。URL を出力するときは「http://」「https://」で始まるものだけを許可する。
- **保険的な対策**：入力値の検査、Cookie に HttpOnly 属性を付ける、CSP（Content Security Policy）でスクリプトの読込み元を制限する。

## 試験での問われ方

- **ITストラテジスト試験**：科目A-2 で、格納型 XSS に該当する事例を、反射型 XSS・DDoS 攻撃・DNS リフレクション攻撃の事例と見分ける問題が出題されています。ほかの攻撃（ファイルレス攻撃、OS コマンドインジェクション）を問う問題でも、選択肢として並びます。

## よくある誤り

- 格納型と反射型を取り違える。スクリプトがサーバに保存されるのが格納型です。
- 入力値の検査だけで十分だと考える。出力時のエスケープが根本的な対策です。
- 利用者に意図しないリクエストを送信させるクロスサイトリクエストフォージェリ（CSRF）と混同する。XSS はスクリプトを利用者のブラウザで実行させる攻撃です。
