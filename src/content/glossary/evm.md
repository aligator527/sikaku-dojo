## 定義

EVM（アーンドバリューマネジメント）は、「どれだけ作業が終わったか」を予算の金額で表し、それを計画や実際の支出と同じ尺度で比べる進捗管理の手法です。

| 値 | 意味 |
| --- | --- |
| PV（計画価値） | 現時点までに完了している予定だった作業の予算 |
| EV（出来高、アーンドバリュー） | 現時点までに実際に完了した作業の、予算上の価値 |
| AC（実コスト） | 現時点までに実際にかかったコスト |
| BAC（完成時総予算） | プロジェクト全体の予算 |

## 主な指標

| 指標 | 式 | 読み方 |
| --- | --- | --- |
| コスト差異 CV | $\mathrm{EV} - \mathrm{AC}$ | 負ならコスト超過 |
| スケジュール差異 SV | $\mathrm{EV} - \mathrm{PV}$ | 負なら遅れ |
| コスト効率指数 CPI | $\mathrm{EV} / \mathrm{AC}$ | 1 未満ならコスト超過 |
| スケジュール効率指数 SPI | $\mathrm{EV} / \mathrm{PV}$ | 1 未満なら遅れ |
| 完成時総コスト見積り EAC | $\mathrm{BAC} / \mathrm{CPI}$ | 今のコスト効率が続く場合の見通し |
| 残作業効率指数 TCPI | $(\mathrm{BAC} - \mathrm{EV}) / (\mathrm{BAC} - \mathrm{AC})$ | 1 より大きいほど、予算内に収めるには残作業の効率を上げる必要がある |

残りの作業が当初の計画どおりのコスト効率で進むと見込める場合は、$\mathrm{EAC} = \mathrm{AC} + (\mathrm{BAC} - \mathrm{EV})$ で見積もります。

## 計算例

BAC 1,000 万円、現時点で PV 500 万円、EV 400 万円、AC 500 万円とします。CV ＝ −100 万円、SV ＝ −100 万円、CPI ＝ 0.8、SPI ＝ 0.8 で、コスト超過かつ遅れです。このコスト効率が続くと EAC ＝ 1,000 ÷ 0.8 ＝ 1,250 万円となり、予算を 250 万円超える見通しです。TCPI は $(1{,}000 - 400) / (1{,}000 - 500) = 1.2$ で、予算内に収めるには残作業を計画より 2 割高い効率で進める必要があります。

## 試験での問われ方

- **ITストラテジスト試験**：科目A-1 で、PV・AC・EV のグラフの位置関係からコストと完了時期の見通しを読み取る問題や、CPI・SPI・TCPI の値から適切な評価と対策を選ぶ問題が出題されています。
- **中小企業診断士試験**：経営情報システムで、PV・EV・AC から SPI・CPI と EAC を計算する問題が出題されています。

## よくある誤り

- CPI を AC ÷ EV、SPI を PV ÷ EV と分子・分母を逆にする。どちらも EV が分子です。
- 進捗の評価で、EV ではなく AC と PV を直接比べる。お金を計画どおり使っていても、作業が進んでいるとは限りません。
- SPI だけで最終的な遅れを判断する。作業がすべて終われば EV は BAC に達するので、遅れていてもプロジェクトの終盤では SPI が 1 に近づきます。
