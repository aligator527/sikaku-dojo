## 定義

標本が母集団を代表しない形で選ばれたり、比較する群に入る人が結果と関係する理由で決まったりすると、標本の大きさをいくら増やしても消えない偏りが生じます。これを選択バイアスといいます。偶然による標本誤差と違い、系統的なずれ（非標本誤差）です。

## 代表的な例

| 名称 | 内容 |
| --- | --- |
| 自己選択（ボランティア）バイアス | ウェブアンケートや健康講座の参加者など、自分から参加した人は関心や健康状態が一般の人と異なる |
| 無回答バイアス | 回答しなかった人の意見や性質が、回答者と異なる |
| カバレッジの偏り | 名簿や調査の方法から、特定の人（電話を持たない人など）が漏れる |
| 生存者バイアス | 存続した企業や生き残った人だけを調べ、脱落したものを見落とす |
| 健康労働者効果 | 働いている人は一般集団より健康なので、職業上の曝露の害が過小に見える |
| 脱落による偏り | 追跡中に、効果がなかった人や副作用の出た人が多く脱落する |
| 対照の選び方の偏り | 症例対照研究で、対照を曝露と関係する集団（病院の他の患者など）から選ぶ |

## 交絡との違い

交絡は「処置と結果の両方に影響する第 3 の変数」による偏りで、母集団の全員を調べても生じます。選択バイアスは「誰が分析の対象になったか」による偏りで、処置と結果の両方の影響を受けて決まる変数（合流点）で対象を絞ったときにも起こります。因果グラフでは、合流点で条件付けることで、もともと無関係な変数の間に見かけの関連が生じる現象として説明されます。

## 防ぎ方

- 標本調査では、確率抽出を使い、無回答を減らす工夫と、ウエイト調整などの補正を行う。
- 比較研究では、処置の無作為割り付け、脱落を含めた ITT 解析、対照の慎重な選定を行う。
- 対象の選ばれ方（組み入れ基準・回答率・脱落の理由）を記録し、結果の解釈で考慮する。

## 試験での問われ方

統計検定2級では、調査の方法の説明から偏りの原因（自己選択・無回答・名簿の漏れ）を見抜く問題が出ます。準1級・1級・データサイエンスエキスパートでは、合流点での条件付けによる偏り、欠測の仕組み（MCAR・MAR・MNAR）との関係、観察データや Web のログデータを使った分析での選択バイアスが問われます。

## よくある誤り

- 標本を大きくすれば選択バイアスも小さくなると考える。
- 選択バイアスと交絡を同じものと考え、共変量の調整で常に除けると考える。
- 回答者数が多いことを、代表性が高いことの根拠にする。
