## 定義

損益計算書の利益は、売掛金のように代金を回収していない売上や、減価償却費のように支出を伴わない費用を含むため、実際の資金の増減とは一致しません。キャッシュ・フロー計算書は、資金の動きそのものを3つの区分で示します。ここでいう資金は、現金（手許現金・要求払預金）と、容易に換金でき価値の変動リスクが小さい短期投資（取得日から3か月以内に満期となる定期預金など）を合わせた **現金及び現金同等物** です。

| 区分 | 主な内容 |
| --- | --- |
| 営業活動 | 商品の販売・仕入、給料・経費の支払い、法人税等の支払額 |
| 投資活動 | 有形固定資産・有価証券の取得と売却、貸付けと回収 |
| 財務活動 | 借入れと返済、社債の発行と償還、株式の発行、配当金の支払額 |

利息と配当金の受取額・利息の支払額は、営業活動の区分に記載する方法と、受取額を投資活動、支払額を財務活動に記載する方法のどちらかを選び、継続して適用します。配当金の支払額は財務活動に記載します。

## 間接法による営業活動の計算例

営業活動によるキャッシュ・フローの表示には、取引ごとの収入・支出を示す直接法と、税引前当期純利益から調整する間接法があります。

| 項目 | 金額 |
| --- | ---: |
| 税引前当期純利益 | 500 |
| 減価償却費（支出を伴わない費用） | ＋120 |
| 貸倒引当金の増加額 | ＋10 |
| 売上債権の増加額 | −80 |
| 棚卸資産の減少額 | ＋30 |
| 仕入債務の増加額 | ＋40 |
| 法人税等の支払額 | −150 |
| 営業活動によるキャッシュ・フロー | 470 |

資産（売上債権・棚卸資産）の増加は資金の減少、負債（仕入債務）の増加は資金の増加として調整します。実際の間接法では、受取利息・支払利息などをいったん利益から除き、「小計」の後に利息の受払額を記載します。

## 試験での問われ方

中小企業診断士の財務・会計では、間接法による営業活動によるキャッシュ・フローの計算と、各取引がどの区分に入るかの正誤問題が繰り返し出題されます。日商簿記1級でも、連結キャッシュ・フロー計算書や、表示区分に関する理論が問われます。

## よくある誤り

- 売上債権の増加額を利益に加算してしまう（資金が回収されていないので減算）。
- 配当金の支払額を営業活動の区分に記載する（財務活動）。
- 有形固定資産の売却による収入を営業活動に含める（投資活動。間接法では売却損益を営業活動の区分で調整する）。
