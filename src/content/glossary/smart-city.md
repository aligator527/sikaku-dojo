## 定義

スマートシティは、都市に関わるさまざまなデータを集めて分野を越えて連携させ、行政・企業・住民が協力して地域の課題を解決していく取組です。技術の導入そのものではなく、住民の生活の質（ウェルビーイング）を高めることが目的とされます。

## 都市 OS（データ連携基盤）

スマートシティでは、分野ごとにサービスを作り込むと、データやシステムが縦割りになり、他の地域への展開もしにくくなります。そこで、共通の機能をまとめた**都市 OS**（データ連携基盤）の上に、各分野のサービスを載せる構成がとられます。

| 層 | 主な機能の例 |
| --- | --- |
| サービス | 観光、交通、防災、医療・健康、子育て支援などのアプリケーション |
| 都市 OS | 認証・ID 管理、API による公開、データの管理と連携、本人同意（オプトイン）の管理 |
| データ・アセット | センサ、行政データ、企業のデータ、オープンデータ |

API とデータの形式を標準化しておくと、サービス事業者が参入しやすくなり、他の自治体との相互運用も容易になります。

## 推進上の検討点

- 個人データを扱うサービスでは、本人の同意を得る仕組みとプライバシー保護が不可欠です。
- 実証実験（PoC）で終わらせず、事業として継続できる運営主体と費用負担の仕組みを作る必要があります。
- 住民や地域の企業など、多様な関係者の合意形成が重要です。

## 試験での問われ方

- **ITストラテジスト試験**：午後の事例でスマートシティ構想が題材になり、共通機能層（認証・ID 管理、API 管理、オプトイン管理など）を設ける目的や、PoC の実効性を評価する観点が問われました。

## よくある誤り

- 最新技術の導入を目的として計画し、どの地域課題をどう解決するかを示さない。
- 分野ごとに個別のシステムを作り、データ連携や横展開を考えない。
