## 定義

事前分布 $\pi(\theta)$ とデータ $x$ の尤度 $f(x \mid \theta)$ から、ベイズの定理で

$$\pi(\theta \mid x) = \frac{f(x \mid \theta)\,\pi(\theta)}{m(x)},\qquad m(x) = \int f(x \mid \theta)\,\pi(\theta)\,d\theta$$

と求めた分布です。分母の $m(x)$ は周辺尤度で、$\theta$ を含まない正規化定数です。

## 求め方のこつ

実際の計算では「事後分布 ∝ 尤度 × 事前分布」の $\theta$ を含む部分（核）だけを残し、それがどの分布の形かを見抜きます。たとえば成功確率 $p$ の事前分布が $\mathrm{Beta}(a, b)$ で、$n$ 回中 $x$ 回成功したなら

$$\pi(p \mid x) \propto p^{x}(1 - p)^{n - x}\cdot p^{a - 1}(1 - p)^{b - 1} = p^{a + x - 1}(1 - p)^{b + n - x - 1}$$

なので、事後分布は $\mathrm{Beta}(a + x,\ b + n - x)$ です。

## 事後分布の要約

| 要約 | 内容 |
|---|---|
| 事後平均 | 二乗誤差損失のもとでのベイズ推定量 |
| 事後中央値 | 絶対誤差損失のもとでのベイズ推定量 |
| 事後モード | MAP 推定値 |
| 信用区間 | 事後確率 $1 - \alpha$ で $\theta$ を含む区間 |

正規分布（分散 $\sigma^2$ 既知）の平均 $\mu$ に $N(\mu_0, \tau_0^2)$ を置くと、$n$ 個の観測の平均 $\bar{x}$ のもとで事後分布も正規分布になり、精度（分散の逆数）は足し算 $1/\tau_n^2 = 1/\tau_0^2 + n/\sigma^2$、事後平均は精度による加重平均になります。例：$\mu_0 = 50,\ \tau_0 = 10,\ \sigma = 10,\ n = 4,\ \bar{x} = 60$ なら事後分布は $N(58,\ 20)$ です。

## 性質

- 逐次更新：データを 2 回に分けて更新しても、まとめて更新しても同じ事後分布になる（前回の事後分布が次の事前分布になる）。
- 大標本：$n$ が大きいと、事後分布は最尤推定値を中心とし分散が $n$ 個分のフィッシャー情報量の逆数 $1/\{nI(\hat{\theta})\}$ の正規分布に近づき、事前分布の影響は消えていく。

## 試験での問われ方

統計検定準1級では、共役事前分布を使った事後分布の特定と事後平均・事後分散の計算、事後分布が事前平均と標本平均の間に来ること（縮小）を問う問題が定番です。1級では導出を記述させ、事後予測分布や損失関数とベイズ推定量の関係まで問われます。データサイエンスエキスパート・E資格では、MCMC で事後分布からサンプルを得る目的として登場します。

## よくある誤り

- 事後分布を「データの分布」と取り違える（事後分布はパラメータ $\theta$ の分布）。
- 核を見抜く際に、$\theta$ を含む因子を定数として落としてしまう。
- 事後分布の分散が事前分布の分散より必ず小さいと思い込む（平均的には小さくなるが、個々のデータでは大きくなる場合もある）。
