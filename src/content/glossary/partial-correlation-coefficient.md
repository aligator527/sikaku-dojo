## 定義

$x$ と $y$ のそれぞれを $z$ に回帰（単回帰）し、その残差どうしの相関係数を、$z$ を固定したときの $x$ と $y$ の偏相関係数 $r_{xy \cdot z}$ といいます。3 変数の相関係数だけから、上の公式で計算できます。

## 直感的な意味

$x$ と $y$ の相関には、「$z$ が $x$ と $y$ の両方に影響している」ことによる部分が含まれているかもしれません。各変数から $z$ で説明できる部分を差し引いた残りどうしの相関を見ることで、$z$ を介さない関係の強さを測ります。

## 計算例

$r_{xy} = 0.6$、$r_{xz} = 0.8$、$r_{yz} = 0.7$ なら

$$r_{xy\cdot z} = \frac{0.6 - 0.8 \times 0.7}{\sqrt{(1 - 0.64)(1 - 0.49)}} = \frac{0.04}{\sqrt{0.1836}} \approx 0.093$$

です。もとの相関 0.6 のほとんどが、$z$ を通じた見かけの相関だったと解釈できます。分子の符号で偏相関係数の符号が決まる点も確認しておきます。

## 性質

- $-1 \leq r_{xy\cdot z} \leq 1$。
- $r_{xz} = 0$ かつ $r_{yz} = 0$ なら、偏相関係数はもとの相関係数に一致する。
- もとの相関が正でも、偏相関が 0 に近くなったり、負になったりすることがある。
- 変数が多い場合は、相関行列の逆行列 $R^{-1} = (r^{ij})$ から $r_{ij\cdot\text{残り}} = -r^{ij}/\sqrt{r^{ii}r^{jj}}$ で求まる。
- 重回帰の偏回帰係数の t 検定は、対応する偏相関係数が 0 かどうかの検定と同等。

## 試験での問われ方

統計検定2級では、3 つの相関係数を与えて偏相関係数を計算し、その解釈（見かけの相関かどうか）を選ぶ問題が出題されます。統計検定1級・データサイエンスエキスパートでは、相関行列の逆行列との関係、グラフィカルモデル（偏相関が 0 の変数の組は条件付き独立）、重回帰との関係が問われます。

## よくある誤り

- 偏相関係数ともとの相関係数を同じものと考える。
- 分母の平方根をとり忘れる、または分子で $r_{xz}r_{yz}$ を足してしまう。
- 偏相関係数が 0 に近いことから、$x$ と $y$ の間に因果関係がないと断定する。取り除いた変数が中間変数（$x \to z \to y$）なら、因果の経路を消してしまったことになる。
