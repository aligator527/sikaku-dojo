## 定義

上澄み吸収価格戦略（スキミング・プライシング）は、牛乳の上澄み（クリーム）をすくい取るように、まず高くても買いたいという顧客層から利益を得る戦略です。その後、需要が一巡したら段階的に価格を下げ、より価格に敏感な顧客層へと販売を広げていきます。

## 適した条件

| 条件 | 理由 |
| --- | --- |
| 需要の価格弾力性が低い（価格に敏感でない顧客層が一定数いる） | 高価格でも販売量が大きく落ちない |
| 製品に独自性があり、特許やブランドで模倣・参入が難しい | 高価格のままでも競合に顧客を奪われにくい |
| 規模の経済や経験曲線効果が小さい | 大量販売によるコスト低下の利点が小さい |
| 開発費が大きく、早期に回収したい | 導入期から高い利幅を確保できる |
| 品質の高さを価格で示したい | 高価格が品質のシグナルになる |

## 市場浸透価格戦略との比較

| | 上澄み吸収価格戦略 | 市場浸透価格戦略 |
| --- | --- | --- |
| 導入期の価格 | 高い | 低い |
| 狙い | 早期の利益確保・投資回収 | 早期のシェア獲得 |
| 適した需要 | 価格弾力性が低い | 価格弾力性が高い |
| 参入障壁 | 高い（模倣されにくい）ことが前提 | 低価格自体が参入を思いとどまらせる |
| コスト構造 | 規模の経済・経験曲線効果が小さい | 規模の経済・経験曲線効果が大きい |

## 試験での問われ方

- **中小企業診断士試験**：企業経営理論のマーケティング論で、新製品の価格戦略の適用条件を入れ替えた正誤問題が出題されます。
- **ITストラテジスト試験**：価格戦略の説明として、上澄み吸収価格戦略と市場浸透価格戦略を区別させる問題が出ます。

## よくある誤り

- 競合の参入が容易で、需要の価格弾力性が高い市場で有効だとする（そのような市場では市場浸透価格戦略が向いています）。
- 上澄み吸収価格戦略と市場浸透価格戦略の説明を入れ替える。
