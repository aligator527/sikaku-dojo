## 定義

株主資本等変動計算書は、純資産の変動を明らかにするための財務諸表です。会社法上の計算書類の一つで、貸借対照表・損益計算書と並んで作成されます。純資産の部の項目ごとに列を設け、次の行で構成します。

- **当期首残高**：前期末の貸借対照表の金額
- **当期変動額**：新株の発行、剰余金の配当、当期純利益、自己株式の取得・処分などの変動事由ごとの金額
- **当期末残高**：当期末の貸借対照表の金額

株主資本の各項目は変動事由ごとに記載しますが、評価・換算差額等などの株主資本以外の項目は「株主資本以外の項目の当期変動額（純額）」として純額でまとめて記載できます。

## 作成例

資本金 ￥10,000,000、利益準備金 ￥800,000、繰越利益剰余金 ￥3,000,000 の会社が、当期に配当 ￥1,000,000（利益準備金の積立て ￥100,000）を行い、当期純利益 ￥1,500,000 を計上した。

| | 資本金 | 利益準備金 | 繰越利益剰余金 | 株主資本合計 |
| --- | ---: | ---: | ---: | ---: |
| 当期首残高 | 10,000,000 | 800,000 | 3,000,000 | 13,800,000 |
| 剰余金の配当 | | 100,000 | △1,100,000 | △1,000,000 |
| 当期純利益 | | | 1,500,000 | 1,500,000 |
| 当期末残高 | 10,000,000 | 900,000 | 3,400,000 | 14,300,000 |

利益準備金の積立ては純資産の内部の振替なので、株主資本合計は配当で社外に出ていく 1,000,000円 だけ減ります。

## 試験での問われ方

日商簿記2級の第2問で、期中の純資産に関する取引（増資、配当と準備金の積立て、任意積立金、合併、当期純利益、その他有価証券の評価差額）から計算書を完成させる問題が出ます。1級では、自己株式の取得・処分・消却や新株予約権の変動を含む問題が理論・計算の両方で出題されます。

## よくある誤り

- 利益準備金の積立額を、繰越利益剰余金の減少額に含め忘れる（配当額＋積立額が減少）。
- 当期末残高を、前期末の貸借対照表の金額のまま記入する。
- その他有価証券評価差額金の変動を「当期純利益」の行に記入する（株主資本以外の項目の純額の行）。
