## 定義

DNS は、「www.example.jp」のようなドメイン名から、通信に必要な IP アドレスを調べる（名前解決する）ための分散型のデータベースです。

- **権威 DNS サーバ**：自分が管理するドメインの情報（ゾーン情報）をもち、問合せに答える。
- **キャッシュ DNS サーバ（フルリゾルバ）**：利用者の端末からの問合せを受け、ルート → トップレベルドメイン → 各ドメインの権威 DNS サーバと順にたどって答えを得る。得た答えは一定時間（TTL）キャッシュに保存して再利用する。

## DNS を狙う主な攻撃

| 攻撃 | 内容 |
| --- | --- |
| DNS キャッシュポイズニング | キャッシュ DNS サーバに偽の応答を受け入れさせ、利用者を偽のサイトへ誘導する。存在しないサブドメインへの問合せを繰り返して偽の応答を紛れ込ませる手法がカミンスキー攻撃 |
| DNS 水責め攻撃（ランダムサブドメイン攻撃） | ランダムに作った存在しないサブドメイン名を大量に問い合わせる。キャッシュが効かないため、問合せが標的の権威 DNS サーバに集中し、サービスが妨害される |
| DNS リフレクション攻撃（DNS アンプ攻撃） | 送信元を標的に偽装した問合せを多数の DNS サーバに送り、大きな応答を標的に集中させる DDoS 攻撃 |

## 主な対策

- DNSSEC で応答に署名し、受け取った応答が正当なものか検証する（キャッシュポイズニング対策）。
- 問合せに使う送信元ポート番号をランダムにする。
- キャッシュ DNS サーバを、組織外の誰からの問合せにも答える状態（オープンリゾルバ）にしない。問合せの頻度を制限する。

## 試験での問われ方

- **ITストラテジスト試験**：科目A-2 のセキュリティ分野で、DNS 水責め攻撃の説明を、キャッシュポイズニングや DNS リフレクション攻撃の説明と見分ける問題が出題されています。ほかの攻撃を問う問題でも、選択肢としてこれらの DNS への攻撃がよく並びます。

## よくある誤り

- 水責め攻撃をキャッシュポイズニングと混同する。水責め攻撃の目的は偽情報の注入ではなく、権威 DNS サーバへの負荷によるサービス妨害です。
- 水責め攻撃は大量の DNS 応答を送り付ける攻撃だと考える。大量の「問合せ」を使う点がリフレクション攻撃との違いです。
