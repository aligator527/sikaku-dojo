## 定義

事業部制組織では、本社（トップ・マネジメントとスタッフ部門）の下に、製品別・地域別・顧客別の事業部を置きます。各事業部は開発・生産・販売などの機能を内部に持ち、独立した利益責任単位（プロフィット・センター）として運営されます。

## 長所と短所

| 長所 | 短所 |
| --- | --- |
| 市場の変化に迅速に対応できる | 事業部間で経営資源（設備・人員・研究開発）が重複しやすい |
| 事業ごとの業績が明確で、評価しやすい | 事業部の短期的な利益が優先され、長期的な投資や全社最適が軽視されやすい |
| トップが日常業務から解放され、全社戦略に専念できる | 事業部間の協力や資源の共有が進みにくく、セクショナリズムが生じやすい |
| 事業部長が一つの事業全体を運営する経験を積み、次世代の経営者として育つ | 事業部の数が増えると、本社の調整・管理の負担が大きい |

## 関連する組織形態

| 形態 | 特徴 |
| --- | --- |
| カンパニー制 | 事業部をさらに独立した「社内カンパニー」とし、投資の意思決定や資本の配分まで大幅な権限を与える。事業部制より権限委譲の程度が大きい |
| 持株会社 | 事業を子会社として法的に分離し、持株会社がグループ全体を統括する |
| マトリックス組織 | 機能別と事業部別（製品別・地域別など）の二つの軸を組み合わせる。メンバーは二人の上司（ツーボス）を持つため、命令一元化の原則が崩れ、権限や責任をめぐる対立が起こりやすい |
| SBU（戦略事業単位） | 事業部の枠を超えて、戦略を立てる単位として事業をまとめ直す |

## 試験での問われ方

**中小企業診断士試験**の企業経営理論で、事業部制組織・カンパニー制・マトリックス組織の特徴を比べる正誤問題が繰り返し出題されます。第 2 次試験の事例 I では、事業の多角化に合わせた組織体制の見直しとして記述することがあります。

## よくある誤り

- カンパニー制は事業部制より権限委譲の程度が小さいとする（大きくなります）。
- マトリックス組織は命令一元化の原則が最も徹底されるとする（二人の上司から命令を受けるので、命令一元化は崩れます）。
- 事業部制では経営資源の重複が起こりにくいとする。
