## 表現

IEEE 754 の倍精度（64 ビット、Python の `float`、NumPy の `float64`）は、符号 1 ビット、指数 11 ビット、仮数 52 ビットで、先頭の 1 を省略するので有効桁は 2 進 53 桁（10 進で約 15〜16 桁）です。1 と、その次に表せる数との差（計算機イプシロン）は $2^{-52} \approx 2.2 \times 10^{-16}$ です。単精度（32 ビット）は 10 進で約 7 桁、深層学習で使う半精度（16 ビット）は約 3 桁しかありません。

## 典型的な誤差

- **丸め誤差**：0.1 は 2 進数では循環小数になり、正確に表せません。そのため `0.1 + 0.2 == 0.3` は偽になります（左辺は 0.30000000000000004）。浮動小数点数どうしは `==` ではなく、差が許容誤差以下かで比べます。
- **桁落ち**：ほぼ等しい 2 数の引き算で、上位の桁が打ち消し合い、有効桁が大きく減ります。
- **情報落ち**：絶対値が大きく違う数の足し算で、小さい方の数が丸めで消えます。$10^{16} + 1$ は $10^{16}$ と同じ値になります。多数の値を足すときは、小さい値から足す、カハンの加算アルゴリズムを使う、などで誤差を抑えます。
- **オーバーフロー・アンダーフロー**：表せる範囲を超えると無限大や 0 になります。確率の積は対数をとって和で計算し、softmax は最大値を引いてから指数をとります。

## 分散の計算での桁落ち

分散を $\frac{1}{n}\sum x_i^2 - \bar{x}^2$ で計算すると、値が大きく散らばりの小さいデータでは、ほぼ等しい 2 つの大きな数の差をとることになり、桁落ちが起こります。たとえば $10^9 + 1, 10^9 + 2, 10^9 + 3, 10^9 + 4$ の分散（真の値 1.25）を倍精度でこの式で計算すると、2 乗が約 $10^{18}$ になって 1 の位の情報が丸めで失われ、結果は 0 になってしまいます。先に平均を求めて偏差の 2 乗和をとる 2 パスの方法、適当な定数を引いてから計算する方法、ウェルフォードの逐次更新法を使えば正しく求まります。

## 試験での問われ方

統計検定データサイエンスエキスパートでは、大きな値をもつデータの分散を 2 通りの式で計算する Python のコードの結果、`0.1 + 0.2 == 0.3` の真偽、桁落ちの起こる計算を選ぶ問題が出ます。E資格では、半精度・単精度の有効桁と混合精度学習、log-sum-exp などの数値安定化が問われます。

## よくある誤り

- 数学的に同じ式なら、コンピュータでも同じ結果になると考える。
- 倍精度なら有効桁は無限に近いと考え、$10^{9}$ 程度の値の 2 乗で精度が失われることを見落とす。
