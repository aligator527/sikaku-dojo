## 解の構造

$y'' + p(x)y' + q(x)y = r(x)$ について、$r = 0$ の**同次方程式**の解全体は 2 次元の線形空間になります。一次独立な 2 つの解 $y_1, y_2$（基本解）をとると、同次方程式の一般解は $C_1y_1 + C_2y_2$ です。一次独立性はロンスキアン $W = y_1y_2' - y_1'y_2 \ne 0$ で確かめます。

非同次方程式の一般解は、1 つの特殊解 $y_p$ を見つけて

$$y = C_1y_1 + C_2y_2 + y_p$$

と書けます。初期条件 $y(x_0), y'(x_0)$ を与えれば $C_1, C_2$ が決まり、解がただ 1 つに定まります。$n$ 階でも同様で、任意定数は $n$ 個です。

## 定数係数の場合

$y'' + ay' + by = r(x)$（$a, b$ は定数）では、同次方程式の解は特性方程式 $\lambda^2 + a\lambda + b = 0$ の根で決まります。

| 根 | 基本解 |
| --- | --- |
| 相異なる実根 $\lambda_1, \lambda_2$ | $e^{\lambda_1x},\ e^{\lambda_2x}$ |
| 重根 $\lambda$ | $e^{\lambda x},\ xe^{\lambda x}$ |
| 複素根 $\alpha \pm \beta i$ | $e^{\alpha x}\cos\beta x,\ e^{\alpha x}\sin\beta x$ |

特殊解は、右辺が多項式・指数関数・三角関数なら未定係数法で、一般の右辺なら定数変化法

$$y_p = -y_1\int\frac{y_2\,r}{W}\,dx + y_2\int\frac{y_1\,r}{W}\,dx$$

で求めます。例えば $y'' - 3y' + 2y = 4x$ は、特性根 1, 2 と特殊解 $2x + 3$ から $y = C_1e^x + C_2e^{2x} + 2x + 3$ です。

## 変数係数で解ける例

- オイラーの微分方程式 $x^2y'' + axy' + by = 0$：$x = e^t$ と置くと定数係数になり、$y = x^m$ を代入した $m(m-1) + am + b = 0$ で解が決まります。
- 1 つの解 $y_1$ が分かれば、$y = y_1u$ と置いて階数を下げられます。
- 解析的な係数なら、べき級数解を仮定して係数の漸化式を作れます。

## 応用

ばね・振り子・電気回路の方程式 $mx'' + cx' + kx = F(t)$ が典型で、特性根の種類が過減衰・臨界減衰・減衰振動に対応します。外力の振動数が固有振動数に一致すると、特殊解に $t\sin\omega t$ の形が現れて振幅が増大します（共鳴）。

## 試験での問われ方

数検1級では、定数係数の 2 階・高階線形微分方程式の一般解と初期値問題、未定係数法や定数変化法による特殊解、オイラーの微分方程式、連立線形微分方程式への応用が頻出です。

## よくある誤り

- 重根のとき基本解を $e^{\lambda x}$ だけにする（$xe^{\lambda x}$ が必要）。
- 非同次方程式で、特殊解だけを答えて同次方程式の一般解を加え忘れる。
- 初期条件を、特殊解を加える前の同次解だけに当てはめて $C_1, C_2$ を決める。
