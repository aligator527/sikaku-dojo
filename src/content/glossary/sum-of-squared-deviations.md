## 定義

$S_{xx} = \sum (x_i - \bar{x})^2$ を偏差平方和といいます。2 変数の場合の $S_{xy} = \sum (x_i - \bar{x})(y_i - \bar{y})$ は偏差積和と呼ばれます。

- $S_{xx}/n$ が分散、$S_{xx}/(n-1)$ が不偏分散、$S_{xy}/n$ が共分散。
- 計算公式：$S_{xx} = \sum x_i^2 - n\bar{x}^2$、$S_{xy} = \sum x_i y_i - n\bar{x}\bar{y}$。
- 平均 $\bar{x}$ は $\sum (x_i - a)^2$ を最小にする $a$ で、$\sum (x_i - a)^2 = S_{xx} + n(\bar{x} - a)^2$ が成り立つ。

## 計算例

データ $3, 5, 6, 8, 8$ では $\sum x_i = 30$、$\sum x_i^2 = 198$ なので、$S_{xx} = 198 - 30^2/5 = 198 - 180 = 18$ です。偏差 $-3, -1, 0, 2, 2$ を 2 乗して足しても $9 + 1 + 0 + 4 + 4 = 18$ になります。

## 使われる場面

| 場面 | 偏差平方和の使い方 |
| --- | --- |
| 単回帰 | 傾き $\hat{\beta} = S_{xy}/S_{xx}$、傾きの標準誤差 $\hat{\sigma}/\sqrt{S_{xx}}$、相関係数 $r = S_{xy}/\sqrt{S_{xx}S_{yy}}$ |
| 回帰の平方和分解 | 全平方和 $S_{yy}$ = 回帰平方和 + 残差平方和 |
| 分散分析 | 全平方和 = 群間平方和 + 群内平方和、それぞれを自由度で割って平均平方を作る |
| 母分散の推測 | 正規母集団では $S_{xx}/\sigma^2 \sim \chi^2(n-1)$ |

## 試験での問われ方

統計検定2級では、集計値（$\sum x_i$、$\sum x_i^2$ など）から偏差平方和を求め、回帰係数・決定係数・分散分析表を完成させる計算が頻出です。単回帰の傾きの標準誤差が $1/\sqrt{S_{xx}}$ に比例すること（説明変数の値を広く散らばらせると推定が精密になること）も問われます。準1級・1級では、平方和の分解と各平方和の分布（カイ二乗分布、コクランの定理）が範囲です。

## よくある誤り

- $\sum x_i^2 - (\sum x_i)^2$ のように、$n$ で割り忘れる。
- 偏差平方和をそのまま分散として使う。
- 分散分析で、平方和を自由度で割らずに F 値を計算する。
