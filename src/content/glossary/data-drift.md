## 種類

学習時と運用時で同時分布 $P(\boldsymbol x, y) = P(y \mid \boldsymbol x)P(\boldsymbol x)$ のどこが変わるかで分けます。

- **共変量シフト（狭い意味のデータドリフト）**：入力の分布 $P(\boldsymbol x)$ が変わり、$P(y \mid \boldsymbol x)$ は変わらない。例：新しい客層の顧客が増える。学習データに少なかった領域での予測が不安定になる。
- **事前確率シフト（ラベルシフト）**：目的変数の割合 $P(y)$ が変わり、各クラス内の入力の分布 $P(\boldsymbol x \mid y)$ は変わらない。例：不良品率が上がる。予測確率はオッズの補正で直せる。
- **コンセプトドリフト**：入力と目的変数の関係 $P(y \mid \boldsymbol x)$ そのものが変わる。例：制度改正や景気の変化で、同じ属性の人の返済行動が変わる。入力の分布だけを見ていても気づけないことがあり、正解ラベルが得られてからの性能の監視が必要。

変化の仕方には、急な変化、徐々に進む変化、季節のように繰り返す変化があります。

## 検知の方法

- **入力・出力の分布の比較**：学習時と直近の運用データについて、各特徴量やモデルの出力スコアの分布を比べる。区間に分けた割合の差を表す PSI（Population Stability Index、上の式）、コルモゴロフ・スミルノフ検定、カイ二乗検定、KL ダイバージェンスなどを使う。PSI はおおよそ 0.1 未満で安定、0.25 を超えると大きな変化とみなす目安が使われる。
- **性能の監視**：正解ラベルが遅れて得られる場合は、その時点で正解率・AUC・較正などを計算して推移を見る。
- **区別のための分類器**：学習時のデータと運用時のデータを見分ける分類器を作り、よく見分けられるなら分布が変わっていると判断する。

### PSI の計算例

3 区間の学習時の割合が $(0.5, 0.3, 0.2)$、運用時が $(0.4, 0.3, 0.3)$ なら、$\mathrm{PSI} = (-0.1)\log 0.8 + 0 + 0.1\log 1.5 \approx 0.022 + 0.041 = 0.063$ です。

## 対処

新しいデータでの再学習（定期的、または検知をきっかけに）、特徴量の見直し、学習データの重み付け（共変量シフトでは密度比で重み付けする）、閾値や較正のやり直しを行います。どの対処をとるかは、変化の種類と、正解ラベルがいつ得られるかによります。

## 試験での問われ方

統計検定データサイエンスエキスパートでは、区間ごとの件数の表から PSI を計算する問題や、共変量シフト・コンセプトドリフトの違い、監視と再学習の考え方を問う選択肢が出ます。

## よくある誤り

- 入力の分布が変わっていなければ、モデルの性能も保たれていると考える（コンセプトドリフトは入力の分布だけでは検知できない）。
- 件数ではなく割合に直さずに PSI を計算する。
