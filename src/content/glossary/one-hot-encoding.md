## 定義

血液型（A, B, O, AB）なら、A $= (1, 0, 0, 0)$、B $= (0, 1, 0, 0)$、O $= (0, 0, 1, 0)$、AB $= (0, 0, 0, 1)$ と表します。どの 2 つのカテゴリーの間のユークリッド距離も $\sqrt{2}$ で等しく、内積は 0 です。

カテゴリーに 1, 2, 3, 4 と番号を振って数値として入れる（ラベルエンコーディング）と、「A と O の差は A と B の差の 2 倍」のような、本来ない順序や間隔をモデルに持ち込んでしまいます。順序のある変数（満足度の 5 段階など）を除き、名義尺度の変数には one-hot 表現を使います。

## 回帰モデルでの注意

切片のある線形回帰で $K$ 個の列をすべて入れると、各行の和が常に 1 で切片の列と一致し、完全な多重共線性が生じて係数が一意に定まりません（ダミー変数の罠）。1 つのカテゴリーを基準として除き、$K - 1$ 個のダミー変数にします。その係数は基準カテゴリーとの差を表します。正則化を加えるモデルや決定木では、$K$ 列すべてを使うこともあります。

## 深層学習での使い方

- **正解ラベル**：多クラス分類の正解を one-hot ベクトル $\boldsymbol t$ で表すと、交差エントロピー損失は $-\sum_k t_k \log y_k = -\log y_{\text{正解}}$ となり、正解クラスの予測確率だけが残ります。ラベル平滑化では、1 と 0 の代わりに $1 - \varepsilon$ と $\varepsilon/(K - 1)$ などを使います。
- **単語の入力**：語彙数 $V$ の one-hot ベクトルに埋め込み行列（$V \times d$）を掛けることは、その単語の行を取り出すことと同じです。実装では行列積をせずに表引きで計算します。

## 欠点と代替

カテゴリーの種類が多い（郵便番号、商品 ID など）と、次元が大きく疎なデータになります。頻度の低いカテゴリーをまとめる、目的変数の平均で置き換えるターゲットエンコーディング（交差検証の中で計算しないとリークする）、学習による埋め込みベクトルなどを使います。また、学習時になかったカテゴリーが本番で現れたときの扱いも決めておきます。

## 試験での問われ方

統計検定データサイエンスエキスパートでは、カテゴリー変数の数値化として適切な方法、切片のある回帰で 1 列を除く理由が問われます。E資格では、one-hot の正解ラベルと交差エントロピー、埋め込み層との関係、NumPy での one-hot の作り方が出ます。

## よくある誤り

- 名義尺度のカテゴリー番号をそのまま数値の特徴量として使う。
- 切片のある線形回帰に $K$ 個の列をすべて入れる。
