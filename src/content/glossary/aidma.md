## 定義

AIDMA は、広告やプロモーションが消費者の心理にどう働きかけるかを考えるための、購買行動のプロセスモデルです。

| 段階 | 消費者の状態 | 企業の課題の例 |
| --- | --- | --- |
| Attention（注意） | 商品の存在を知る | 認知度を高める（広告・露出の増加） |
| Interest（関心） | 商品に興味を持つ | 特徴や便益を伝える |
| Desire（欲求） | 欲しいと思う | 自分に必要だと感じさせる、試用の機会 |
| Memory（記憶） | 欲求を記憶にとどめる | ブランド名を覚えてもらう、想起させる |
| Action（行動） | 購買する | 店頭での入手しやすさ、購入のきっかけ |

段階は認知段階（A）、感情段階（I・D・M）、行動段階（A）に分けられます。消費者がどの段階でつまずいているかを調べて、施策を選ぶのに使います。例えば、「名前は知られているが買われない」なら、関心や欲求の段階に課題があると考えます。

## AISAS

インターネットの普及を背景に、電通が提唱したモデルです。

| AIDMA | AISAS |
| --- | --- |
| Attention（注意） | Attention（注意） |
| Interest（関心） | Interest（関心） |
| Desire（欲求） | Search（検索） |
| Memory（記憶） | Action（行動） |
| Action（行動） | Share（共有） |

関心を持った消費者が自ら情報を検索し、購入後には SNS や口コミサイトで評価を共有する点が特徴で、共有された情報が他の消費者の検索・購買につながります。

## 試験での問われ方

- **中小企業診断士試験**：企業経営理論のマーケティング論で、AIDMA と AISAS の各段階の内容を入れ替えた選択肢の正誤問題が出題されます。
- **ITストラテジスト試験**：AIDMA モデルの活用方法（どの段階の課題に対してどの施策をとるか）を選ぶ問題が出ています。

## よくある誤り

- AIDMA に Search（検索）や Share（共有）の段階が含まれるとする（AISAS の段階です）。
- AIDMA の M を Motive（動機）とする（Memory（記憶）です）。
