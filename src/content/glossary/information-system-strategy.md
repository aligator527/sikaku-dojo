## 定義

情報システム戦略（IT 戦略）は、経営戦略を受けて「どの業務を、どの情報システムで、どの順序で、どれだけの投資で変えていくか」を定めるものです。個々のシステム開発の計画ではなく、組織全体を対象に、全体最適の視点で方向性を示す点が特徴です。

## 主な内容

| 項目 | 内容の例 |
| --- | --- |
| 経営戦略との整合 | 経営目標・事業課題と、IT で実現する施策の対応 |
| 情報システム全体体系 | 業務とシステムの全体像（あるべき姿）、EA による整理 |
| IT 投資方針 | 投資枠、案件の評価基準、優先順位の付け方 |
| 推進体制 | CIO・IT 部門・事業部門の役割、ガバナンスの仕組み |
| 標準・方針 | 技術標準、データ活用やセキュリティの基本方針 |

情報システム戦略を基に**全体システム化計画**を作り、さらに個々の案件ごとに**個別システム化構想・計画**を立てる、という順序で具体化していきます。

## 試験での問われ方

- **ITストラテジスト試験**：午後の出題範囲「情報システム戦略と全体システム化計画の策定」の中心となる概念です。論述では、経営戦略のどの目標を受けて、どの業務課題をどの施策で解決するのかという因果のつながりと、経営層の承認を得るための説明が評価されます。

## よくある誤り

- 新しい技術の導入計画を書くだけで、経営戦略・事業課題との結び付きを示さない。
- 部門ごとの要望を積み上げただけの計画にし、全体最適の視点（重複投資の排除、データの共通化など）を欠く。
- 一度策定すれば終わりと考え、経営環境の変化に応じた見直しや実行状況のモニタリングを考えない。
