## 更新式

$$h_t = h_{t-1} + g_t^2,\qquad w_t = w_{t-1} - \frac{\eta}{\sqrt{h_t} + \varepsilon}\,g_t$$

$h$ はパラメータと同じ形の配列で、要素ごとに勾配の 2 乗を足し続けます。$\varepsilon$ は 0 除算を防ぐ小さな定数です。

## 性質

- **パラメータごとの学習率**：実効的な学習率 $\eta/\sqrt{h_t}$ はパラメータごとに異なります。勾配が大きかった（よく更新された）パラメータは学習率が小さく、勾配がまれにしか来ないパラメータは学習率が大きいままです。出現頻度の低い特徴量（疎なデータ）の学習に向きます。
- **学習率の単調減少**：$h_t$ は減ることがないので、実効的な学習率は単調に小さくなります。凸な問題では理論的に好ましい性質ですが、深層学習のように長く学習すると、途中で更新がほとんど止まってしまうことがあります。
- 最初の更新は $h_1 = g_1^2$ なので、勾配の大きさによらず更新量は（$\varepsilon$ を無視して）$\eta$ になります。

## 計算例

$w_0 = 0$、$\eta = 0.1$、勾配が $g_1 = 3$、$g_2 = 4$ のとき、

$$h_1 = 9,\quad w_1 = 0 - 0.1 \times \frac{3}{3} = -0.1,\qquad h_2 = 9 + 16 = 25,\quad w_2 = -0.1 - 0.1 \times \frac45 = -0.18$$

2 回目の勾配は 1 回目より大きいのに、更新量は $0.1$ から $0.08$ に減っています。

## 改良

- **RMSProp**：累積和の代わりに指数移動平均を使い、古い勾配を忘れる。
- **AdaDelta**：学習率 $\eta$ そのものも更新量の移動平均から決める。
- **Adam**：RMSProp にモーメンタムとバイアス補正を加える。

## 試験での問われ方

E資格では、数ステップの更新の計算、NumPy による実装の穴埋め（`h += grad * grad`）、RMSProp との違い（累積和と指数移動平均）、学習が進むと更新が止まる理由が出題されます。

## よくある誤り

- 学習が進むほど実効的な学習率が大きくなると逆に考える。
- 累積せずに直前の勾配の 2 乗だけで割る（それは減衰率 0 の RMSProp）。
- AdaGrad はすべてのパラメータに共通の学習率を使うと考える。
- 平方根をとらずに $h_t$ で割る。
