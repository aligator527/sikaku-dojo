## モデル

因子 A（$a$ 水準）と因子 B（$b$ 水準）のすべての組で $r$ 回ずつ繰り返し測定したデータに、

$$y_{ijk} = \mu + \alpha_i + \beta_j + (\alpha\beta)_{ij} + \varepsilon_{ijk},\qquad \varepsilon_{ijk} \sim N(0, \sigma^2)$$

を当てはめます。$\alpha_i, \beta_j$ が主効果、$(\alpha\beta)_{ij}$ が交互作用効果です。

## 分散分析表（繰り返しあり）

| 要因 | 自由度 | 平均平方 | F 値 |
| --- | --- | --- | --- |
| A | $a - 1$ | $V_A = S_A/(a-1)$ | $V_A/V_E$ |
| B | $b - 1$ | $V_B = S_B/(b-1)$ | $V_B/V_E$ |
| A × B | $(a-1)(b-1)$ | $V_{AB}$ | $V_{AB}/V_E$ |
| 誤差 | $ab(r-1)$ | $V_E$ | |
| 計 | $abr - 1$ | | |

## 計算例

$a = 3$、$b = 2$、$r = 4$（$N = 24$）で、$S_A = 40$、$S_B = 30$、$S_{AB} = 12$、$S_E = 36$ のとき、自由度は $2, 1, 2, 18$ で、$V_A = 20$、$V_B = 30$、$V_{AB} = 6$、$V_E = 2$ です。F 値は $F_A = 10$、$F_B = 15$、$F_{AB} = 3$ で、5% 点 $F_{0.05}(2, 18) \approx 3.55$、$F_{0.05}(1, 18) \approx 4.41$ と比べると、主効果 A・B は有意、交互作用は有意ではありません。

## 繰り返しがない場合

各組で 1 回しか測定しない（$r = 1$）と誤差の自由度が 0 になるので、交互作用がないと仮定し、交互作用の平方和を誤差として使います（誤差の自由度 $(a-1)(b-1)$）。乱塊法の分散分析は、ブロックを因子 B とみた繰り返しのない二元配置と同じ形です。

## 発展

- 交互作用が有意でなく小さいときは、誤差にプールして主効果の検定の自由度を増やすことがある。
- 因子が変量（ロットや測定者など）なら、期待平均平方が変わり、主効果の F 検定の分母が誤差ではなく交互作用の平均平方になることがある。
- 各組のデータ数が異なる（不釣り合い）と平方和の分解が一意でなくなり、タイプ I・II・III の平方和を区別する必要がある。

## 試験での問われ方

統計検定準1級・1級では、分散分析表の空欄を自由度・平方和から埋めて F 値を判定する問題、繰り返しの有無による違い、交互作用のプーリング、変量模型での期待平均平方が問われます。

## よくある誤り

- 繰り返しのない二元配置で、交互作用を検定しようとする。
- 誤差の自由度を $abr - ab$ でなく $abr - 1$ や $(a-1)(b-1)$ とする（繰り返しありの場合）。
- 交互作用が有意なのに、主効果の大小だけで最適な水準を決める。
