## 定義

フィンテックは、スマートフォン、クラウド、AI、ブロックチェーンなどの技術を使って、従来は銀行・証券会社・保険会社が提供してきた金融サービスを、より便利で安価なものに変える動きです。新興企業だけでなく、既存の金融機関や、小売・通信など金融以外の事業者も担い手になっています。

## 主な分野

| 分野 | 例 |
| --- | --- |
| 決済・送金 | スマートフォンのコード決済、個人間送金 |
| 家計・会計管理 | 複数の口座やカードの情報を集約する家計簿アプリ、クラウド会計 |
| 融資 | 取引データを使った与信審査、クラウドファンディング |
| 資産運用 | ロボアドバイザー |
| 保険 | 運転データに基づく保険料の設定（インシュアテック） |
| 規制対応 | 規制対応業務の効率化（レグテック） |

## 制度面の動き

- 2017 年の銀行法改正で、口座情報の取得などを行う**電子決済等代行業**の登録制度ができ、銀行にはオープン API の体制整備が求められました。
- 2021 年には、一つの登録で銀行・証券・保険のサービスを横断的に仲介できる**金融サービス仲介業**が創設されました。
- 金融以外の事業者が自社サービスに金融機能を組み込む組込型金融（エンベデッドファイナンス）も広がっています。

## 試験での問われ方

- **ITストラテジスト試験**：午後の論述で、フィンテックを活用して顧客満足度と収益の向上を図る事業戦略が題材となりました。午後の記述式では、金融サービスのアプリ開発や勘定系システムとの連携が問われています。

## よくある誤り

- フィンテックを、金融機関の社内システムの IT 化（勘定系システムの更新など）だけのことと考える。顧客に新しい金融サービスを提供することが中心です。
