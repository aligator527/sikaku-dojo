## 定義

直接原価計算の損益計算書は、変動費と固定費を分けて段階的に利益を示します。その最初の段階が変動製造マージンです。

| 区分 | 金額の例 |
| --- | ---: |
| 売上高 | 10,000,000円 |
| 変動売上原価 | 4,000,000円 |
| **変動製造マージン** | 6,000,000円 |
| 変動販売費 | 1,000,000円 |
| 貢献利益 | 5,000,000円 |
| 固定費（固定製造原価 3,000,000円、固定販売費及び一般管理費 1,000,000円） | 4,000,000円 |
| 営業利益 | 1,000,000円 |

（販売単価5,000円、変動製造原価1個2,000円、変動販売費1個500円、販売量2,000個の例）

## 変動売上原価の計算

変動売上原価は、販売した製品の変動製造原価です。直接原価計算では製品を変動製造原価だけで評価するので、

変動売上原価 ＝ 期首製品（変動製造原価）＋ 当期の変動製造原価 − 期末製品（変動製造原価）

で求めます。固定製造原価は期間原価として全額を当期の費用とし、売上原価には含めません。標準直接原価計算では、標準変動売上原価に変動費の原価差異を加減します。

## 売上総利益との違い

全部原価計算の売上総利益は、売上高から固定製造原価を含む売上原価を差し引いた利益です。変動製造マージンは変動製造原価だけを差し引くので、通常は売上総利益より大きくなります。

## 試験での問われ方

日商簿記2級の第5問では、直接原価計算の損益計算書の空欄（変動売上原価・変動製造マージン・貢献利益など）を埋める問題が出ます。期首・期末に製品在庫がある場合の変動売上原価の計算がポイントです。1級では先入先出法や仕掛品を含めた変動売上原価の計算が問われます。

## よくある誤り

- 変動販売費を変動売上原価に含めてしまう。
- 変動売上原価を、販売量ではなく生産量にもとづいて計算する。
- 変動製造マージンを貢献利益と同じものとして扱う。
