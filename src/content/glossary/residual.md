## 定義

回帰モデル $y_i = \mathbf{x}_i^{\top}\boldsymbol{\beta} + \varepsilon_i$ を推定したとき、$e_i = y_i - \hat{y}_i$ を残差といいます。誤差 $\varepsilon_i$ は真の係数からのずれで観測できませんが、残差は推定した係数からのずれで、データから計算できます。

## 性質（最小二乗法、定数項ありのとき）

- 残差の和は 0。
- 残差と各説明変数、残差と当てはめ値は無相関（直交）。
- 残差平方和 $S_e = \sum e_i^2$ を自由度 $n - p - 1$ で割ると、誤差分散の不偏推定量になる。
- 残差の分散は $(1 - h_{ii})\sigma^2$ で、点ごとに異なる。$h_{ii}$ はてこ比で、説明変数の値が平均から離れた点ほど残差は小さくなりやすい。

そのため、大きさを比べるときは残差を標準偏差の推定値で割った標準化残差やスチューデント化残差を使います。

## 残差プロットによる診断

| 残差プロットの様子 | 疑われること |
| --- | --- |
| 当てはめ値に対して曲線状のパターン | 線形性の不足（2 乗項や変換が必要） |
| 当てはめ値とともにばらつきが広がる（漏斗形） | 不均一分散 |
| 時間順に並べると正負が続く | 誤差の自己相関（ダービン・ワトソン比で確認） |
| 一部の点だけ極端に大きい | 外れ値 |
| Q-Q プロットが直線から外れる | 誤差の非正規性 |

## 試験での問われ方

統計検定2級では、回帰式から特定の点の予測値と残差を計算する問題や、残差プロットの図から仮定の崩れを読み取る問題が出ます。準1級・1級では、ハット行列による残差の分散の導出、スチューデント化残差、クックの距離などの影響診断が問われます。

## よくある誤り

- 残差と誤差を同じものと考える（残差は互いに独立ではなく、和が 0 という制約がある）。
- 残差の符号を逆にする（「予測値 − 観測値」ではなく「観測値 − 予測値」）。
- 残差の大きさをそのまま比べて外れ値を判定する（てこ比の大きい点の残差は小さく出る）。
