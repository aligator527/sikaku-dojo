## 基本の要素

- **エージェント**と**環境**：エージェントは状態 $s_t$ を観測して行動 $a_t$ を選び、環境は報酬 $r_{t+1}$ と次の状態 $s_{t+1}$ を返す。
- **方策** $\pi(a \mid s)$：状態に応じた行動の選び方。
- **収益** $G_t$：将来の報酬の割引和。割引率 $\gamma \in [0, 1)$ が小さいほど目先の報酬を重視します。
- **価値関数**：状態価値 $V^\pi(s)$ と行動価値 $Q^\pi(s, a)$ は、その状態（と行動）から方策 $\pi$ に従ったときの収益の期待値です。

次の状態と報酬が現在の状態と行動だけで決まるという仮定のもとでの定式化を、マルコフ決定過程（MDP）といいます。

収益は「すぐの報酬 + 割り引いた次の時点からの収益」と再帰的に書けるので、価値関数はベルマン方程式 $V^\pi(s) = E_\pi\left[r_{t+1} + \gamma V^\pi(s_{t+1}) \mid s_t = s\right]$ を満たします。最適な方策の価値は、行動について最大をとるベルマン最適方程式 $V^\ast(s) = \max_a E\left[r_{t+1} + \gamma V^\ast(s_{t+1}) \mid s_t = s,\ a_t = a\right]$ を満たします。

例：報酬が $2, 0, 1, 3$ の順に得られ、$\gamma = 0.5$ なら、$G_1 = 2 + 0.5 \times 0 + 0.25 \times 1 + 0.125 \times 3 = 2.625$ です。

## 教師あり学習との違い

- 正解の行動は与えられず、報酬という評価だけが返ってきます。
- 報酬が遅れて得られることがあり、どの行動が良かったのかを過去にさかのぼって割り当てる必要があります。
- 自分の行動によって集まるデータが変わります。

## 探索と活用

今わかっている最善の行動を選ぶ（活用）だけでは、より良い行動を見つけられません。ときには別の行動も試す（探索）必要があり、この兼ね合いを探索と活用のジレンマといいます。代表的な方法が **ε-greedy 方策** で、確率 $1 - \varepsilon$ で推定価値が最大の行動を、確率 $\varepsilon$ で全行動から一様に無作為に選びます。行動が 5 種類で $\varepsilon = 0.2$ なら、価値最大の行動が選ばれる確率は、無作為に選んだときに当たる分も含めて $0.8 + 0.2/5 = 0.84$ です。学習が進むにつれて $\varepsilon$ を小さくするのが一般的です。

## 手法の分類

| 分類 | 考え方 | 例 |
| --- | --- | --- |
| 価値ベース | 行動価値を学習し、価値の高い行動を選ぶ | Q 学習、SARSA、DQN |
| 方策ベース | 方策を直接パラメータで表して最適化する | 方策勾配法（REINFORCE） |
| 両者の組み合わせ | 方策（Actor）と価値（Critic）を同時に学習する | Actor-Critic、A3C、PPO |

深層強化学習は、価値関数や方策をニューラルネットワークで表すもので、画像を入力に Atari のゲームを学習した DQN や、囲碁の AlphaGo が知られています。大規模言語モデルを人間の好みに合わせる RLHF にも使われています。

## 試験での問われ方

E資格（シラバス 2026 の深層強化学習：DQN、A3C）では、価値関数・方策の定義、Q 学習の更新の計算、価値ベースと方策ベースの違いが出題されます。統計検定データサイエンスエキスパートでは、割引報酬和や ε-greedy 方策の確率の計算、報酬の設計の注意点が問われます。

## よくある誤り

- ε-greedy で価値最大の行動が選ばれる確率を $1 - \varepsilon$ とする（無作為に選んだときに当たる $\varepsilon/K$ を足し忘れる）。
- 割引率を大きくすると目先の報酬を重視すると逆に考える。
- 強化学習でも各状態での正解の行動が与えられると考える。
