## 定義

**事象の独立**：$P(A \cap B) = P(A)P(B)$ のとき、事象 $A$ と $B$ は独立であるといいます。$P(B) > 0$ なら、これは $P(A \mid B) = P(A)$（$B$ が起きたと知っても $A$ の確率が変わらない）と同じです。

**確率変数の独立**：すべての $x, y$ で同時分布が周辺分布の積に分解できる、つまり $P(X \leq x,\ Y \leq y) = P(X \leq x)P(Y \leq y)$（密度や確率関数でいえば $f(x, y) = f_X(x)f_Y(y)$）のとき、$X$ と $Y$ は独立です。

## 性質

- $X, Y$ が独立なら $E[XY] = E[X]E[Y]$、$\mathrm{Cov}(X, Y) = 0$、$V[X + Y] = V[X] + V[Y]$。
- 独立なら、それぞれの関数 $g(X)$ と $h(Y)$ も独立。
- 独立なら無相関だが、無相関でも独立とは限らない。同時分布が多変量正規分布のときは、無相関と独立が同値になる。
- 3 つ以上では「互いに独立」（すべての組合せで積の公式が成り立つ）と「どの 2 つも独立」（対ごとの独立）を区別する。

## 例：対ごとに独立でも互いに独立ではない

公正な硬貨を 2 回投げ、$A$ を「1 回目が表」、$B$ を「2 回目が表」、$C$ を「2 回の結果が同じ」とします。$P(A) = P(B) = P(C) = 1/2$ で、$P(A \cap B) = P(A \cap C) = P(B \cap C) = 1/4$ なのでどの 2 つも独立ですが、$P(A \cap B \cap C) = 1/4 \neq 1/8$ なので 3 つは互いに独立ではありません。

## 試験での問われ方

統計検定2級では、事象の独立の判定、独立な試行の確率計算、独立な確率変数の和の期待値と分散、「排反」と「独立」の区別が問われます。準1級・1級では、同時密度が積に分解できるかによる独立性の判定、正規母集団での $\bar{X}$ と不偏分散の独立性、無相関だが独立でない例が出題されます。分割表の独立性の検定も、この定義を期待度数の計算に使っています。

## よくある誤り

- 排反と独立を同じものと考える。確率が正の 2 つの事象が排反なら $P(A \cap B) = 0 \neq P(A)P(B)$ なので、むしろ独立ではない。
- 共分散が 0 であることから独立を結論する。
- 対ごとの独立から、3 つ以上の事象が互いに独立であると結論する。
