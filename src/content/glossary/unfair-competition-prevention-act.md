## 定義

不正競争防止法は、特許権や商標権のような権利を登録によって与えるのではなく、一定の**行為**を「不正競争」と定めて禁止する法律です。そのため、商標登録をしていない商品名や、特許出願していないノウハウなども、要件を満たせば保護されます。

## 主な不正競争の類型

| 類型 | 内容 |
| --- | --- |
| 周知表示混同惹起行為 | 需要者の間に広く知られた他人の商品等表示（商品名、ロゴなど）と同一・類似の表示を使い、混同を生じさせる |
| 著名表示冒用行為 | 全国的に著名な他人の表示を、自己の商品等表示として使う（混同がなくても対象） |
| 商品形態模倣行為 | 他人の商品の形態をまねた商品を譲渡などする（日本国内で最初に販売された日から 3 年間）。2024 年施行の改正で、デジタル空間での提供も対象であることが明確化された |
| 営業秘密の侵害 | 営業秘密を不正に取得・使用・開示する |
| 限定提供データの不正取得等 | 特定の者に提供するために蓄積・管理されたデータを不正に取得・使用・開示する |
| 技術的制限手段の無効化 | コピーガードなどを無効にする装置やプログラムの提供 |
| ドメイン名の不正取得等 | 不正の利益を得る目的又は他人に損害を加える目的で、他人の商品等表示と同一・類似のドメイン名を取得・保有・使用する |
| 誤認惹起行為・信用毀損行為 | 原産地や品質を誤認させる表示、競争相手の信用を害する虚偽の事実の告知・流布 |

不正競争によって営業上の利益を侵害された者は、差止請求や損害賠償請求ができます。営業秘密の侵害など悪質な行為には刑事罰もあります。

## 試験での問われ方

- **ITストラテジスト試験**：午前I で、ドメイン名の不正取得に当たる行為（他人の商品名を使ったドメイン名でコピー商品を販売して利益を得る）が問われました。偶然に類似のドメイン名を取得しただけの場合や、表示が周知でない地域での販売は不正競争に当たりません。
- **中小企業診断士試験**：経営法務で、営業秘密の三要件や、商標法との違いが問われます。

## よくある誤り

- 不正競争防止法による保護にも登録が必要だと考える。
- 周知表示混同惹起行為は、その表示が知られていない地域でも成立すると考える。周知であることが要件です。
