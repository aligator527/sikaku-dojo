## 定義

離散確率変数 $X, Y$ の同時分布を $p(x, y)$、周辺分布を $p(x), p(y)$ とすると

$$I(X; Y) = \sum_{x, y} p(x, y)\log\frac{p(x, y)}{p(x)\,p(y)}$$

です。これは同時分布と「独立だとした場合の分布」$p(x)p(y)$ との KL ダイバージェンス $D_{\mathrm{KL}}\left(p(x, y) \parallel p(x)p(y)\right)$ にあたります。

## エントロピーとの関係

$$I(X; Y) = H(X) - H(X \mid Y) = H(Y) - H(Y \mid X) = H(X) + H(Y) - H(X, Y)$$

ベン図で表すと、$H(X)$ と $H(Y)$ の円の重なりが $I(X; Y)$、和集合全体が結合エントロピー $H(X, Y)$、重ならない部分が条件付きエントロピーです。

## 性質

- $I(X; Y) \ge 0$ で、$I(X; Y) = 0$ と $X, Y$ の独立は同値です。
- 対称：$I(X; Y) = I(Y; X)$。
- $I(X; X) = H(X)$（自分自身との相互情報量はエントロピー）。
- 相関係数は線形の関係しか捉えませんが、相互情報量は非線形の依存も捉えます。相関係数が 0 でも相互情報量が正のことがあります。

## 計算例

$p(0,0) = p(1,1) = 0.4$、$p(0,1) = p(1,0) = 0.1$ のとき、周辺分布はどちらも $\left(\tfrac12, \tfrac12\right)$ で $H(X) = H(Y) = 1$ ビットです。結合エントロピーは

$$H(X, Y) = -2 \times 0.4\log_2 0.4 - 2 \times 0.1\log_2 0.1 \approx 1.722$$

なので、$I(X; Y) = 1 + 1 - 1.722 \approx 0.278$ ビットです。

## 機械学習での使われ方

- **決定木の情報利得**：分割に使う特徴 $X$ と目的変数 $Y$ について $H(Y) - H(Y \mid X)$ を計算するもので、相互情報量そのものです。
- **特徴選択**：目的変数との相互情報量が大きい特徴を選びます。
- **表現学習**：対照学習の InfoNCE 損失は、2 つのビューの表現の間の相互情報量の下界を大きくするものと解釈されます。

## 試験での問われ方

E資格では、同時分布の表からの計算、エントロピー・条件付きエントロピーとの関係式、独立や相関との関係を問う正誤問題が出ます。$H(X, Y) = H(X) + H(Y)$ が独立のときにしか成り立たないことに注意します。

## よくある誤り

- 相関係数が 0 なら相互情報量も 0 だとする。
- 相互情報量を結合エントロピー $H(X, Y)$ と取り違える。
- 計算で $p(x, y)$ ではなく $p(x)p(y)$ で重み付けしてしまう。
