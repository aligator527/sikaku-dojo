## 定義

伝票会計では、取引ごとに伝票を起こし、これを仕訳帳の代わりにして総勘定元帳へ転記します。三伝票制では、取引を現金の動きによって3種類の伝票に分けます。

| 伝票 | 記入する取引 | 省略される側 |
| --- | --- | --- |
| 入金伝票 | 現金が増える取引 | 借方「現金」（相手科目だけを書く） |
| 出金伝票 | 現金が減る取引 | 貸方「現金」 |
| 振替伝票 | 現金が動かない取引 | なし（通常の仕訳と同じ） |

1日分の伝票を勘定科目ごとに集計した表を **仕訳日計表** といい、これを使って総勘定元帳へまとめて転記します。

## 一部現金取引の起票

商品 ￥100,000 を売り上げ、代金のうち ￥30,000 は現金で受け取り、残額は掛けとした。このように一部だけ現金が動く取引には、2通りの起票方法があります。

**取引を分解する方法**

| 伝票 | 内容 |
| --- | --- |
| 入金伝票 | 売上 30,000 |
| 振替伝票 | （借）売掛金 70,000 （貸）売上 70,000 |

**いったん全額を掛け取引とみなす方法**

| 伝票 | 内容 |
| --- | --- |
| 振替伝票 | （借）売掛金 100,000 （貸）売上 100,000 |
| 入金伝票 | 売掛金 30,000 |

どちらの方法でも、合わせた仕訳は同じになります。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 現金 | 30,000 | 売上 | 100,000 |
| 売掛金 | 70,000 | | |

## 試験での問われ方

3級の第2問で、伝票の空欄補充、一部現金取引の起票方法の判定、仕訳日計表の作成と元帳への転記が出題されます。すでに起票された片方の伝票から、もう片方の伝票の内容を推定させる形が定番です。

## よくある誤り

- 入金伝票の科目欄に「現金」と書く（相手科目を書く）。
- 一部現金取引で、2つの起票方法を混ぜてしまい、売上を二重に計上する。
- 仕訳日計表の借方・貸方の合計が一致することを確認せずに転記する。
