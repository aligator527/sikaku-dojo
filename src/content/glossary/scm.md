## 定義

SCM は、サプライチェーンに関わる取引先（部品メーカー、製造業者、卸売業者、小売業者、物流業者など）が需要や在庫の情報を共有し、モノの流れを全体として最適化する考え方です。各社がそれぞれ自社に都合よく発注・在庫管理をすると、全体として過剰在庫や欠品が起こりやすくなります。

## 情報共有の効果

小売店の小さな需要の変動が、卸売業者、メーカー、部品メーカーへとさかのぼるにつれて大きな発注の変動になる現象（ブルウィップ効果）は、各段階が下流の発注だけを見て判断することで起こります。販売時点の需要情報（POS データなど）をサプライチェーン全体で共有すると、この増幅を抑えられます。

## SCOR

SCOR（Supply Chain Operations Reference model）は、サプライチェーンの業務プロセスを標準的に記述するための参照モデルです。従来の版では、最上位のプロセスを次の六つで定義していました（Source・Make・Deliver・Return が実行プロセス）。

| プロセス | 内容 |
| --- | --- |
| Plan（計画） | 需要と供給のバランスをとる計画 |
| Source（調達） | 資材などの購入 |
| Make（生産） | 製品の生産、サービスの実施 |
| Deliver（配送） | 受注と納入 |
| Return（返品） | 納入後に発生する返品などの作業 |
| Enable（支援） | 各プロセスを支える管理（ルール、データ、リスク管理など） |

共通の用語と指標で自社と取引先のプロセスを比較できるため、ベンチマーキングや改善の検討に使われます（2022 年以降は、Orchestrate・Order・Transform・Fulfill などを含む構成に改められています）。

## 試験での問われ方

- **ITストラテジスト試験**：午前II で、SCOR の実行プロセスのうち Source に当たるもの（資材などの購入）や、SCM から発展した S&OP の説明が問われました。
- **中小企業診断士試験**：運営管理の物流と SCM で、ブルウィップ効果や情報共有の効果が問われます。

## よくある誤り

- SCM を自社内の在庫管理や物流の効率化だけのことと考える。企業の枠を越えた全体最適が要点です。
- SCOR の Source を「受注」、Deliver を「調達」と取り違える。
