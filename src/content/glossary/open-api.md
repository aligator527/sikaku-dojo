## 定義

API（Application Programming Interface）は、ソフトウェアの機能を別のソフトウェアから呼び出すための取決めです。オープン API は、その API を社外に公開し、契約した他社や一般の開発者が自社の機能・データを自分のサービスに組み込めるようにすることを指します。

## API エコノミー

複数の企業が API を公開し合い、互いの機能を組み合わせることで、一社では作れないサービスや新しい市場が生まれる状態を **API エコノミー** と呼びます。

- ホテル事業者が、他社が公開しているタクシー配車アプリの API を自社アプリに組み込み、宿泊客に配車サービスを提供する。
- 銀行が口座情報の照会や振込の API を電子決済等代行業者などに公開し、家計簿アプリや会計ソフトから口座を利用できるようにする（2017 年の銀行法改正で、銀行にオープン API の体制整備の努力義務が課されました）。

## 公開するときの検討事項

- **ビジネス面**：API の利用料、利用者の拡大による自社サービスの価値向上、提携先の審査。
- **技術面**：API ゲートウェイによる認証・認可（OAuth など）、流量制限、監視、バージョン管理。
- **リスク面**：個人データの提供に関する本人同意、障害時の責任分担、契約条件。

## 試験での問われ方

- **ITストラテジスト試験**：午前II で API エコノミーの事例を選ぶ問題が出題されました（社内だけで使う API や、API を使った単なるツール連携は該当しません）。午後の事例では、物流や金融のサービスをオープン API で外部企業に提供する戦略が登場します。

## よくある誤り

- 社内の他部署に API を提供することや、社内システムの再構築に API を使うことを API エコノミーと考える。社外の企業とサービスをつなぎ合わせて価値を生むことが要点です。
- API を公開すれば利用が自然に広がると考え、利用者の獲得や開発者への支援を計画しない。
