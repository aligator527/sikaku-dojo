## 定義

未収入金は、本業の商品売買以外の取引から生じた、受け取る金額が確定している債権です。商品の掛売上で生じる売掛金とは区別します。未収金と書かれることもあります。

| 取引 | 使う勘定 |
| --- | --- |
| 商品を掛けで販売した | 売掛金 |
| 不用の備品・土地などを売却し、代金は後日受け取る | 未収入金 |
| 決算で、受取家賃などの未収分を見越計上する | 未収収益（未収家賃など） |

## 仕訳例

不用になった備品（取得原価 ￥200,000、減価償却累計額 ￥150,000、間接法）を ￥40,000 で売却し、代金は月末に受け取ることにした。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 備品減価償却累計額 | 150,000 | 備品 | 200,000 |
| 未収入金 | 40,000 | | |
| 固定資産売却損 | 10,000 | | |

月末、上記の代金が普通預金口座に振り込まれた。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 普通預金 | 40,000 | 未収入金 | 40,000 |

帳簿価額は 200,000 − 150,000 ＝ 50,000円 で、売却価額 40,000円 との差 10,000円 が固定資産売却損になります。

## 試験での問われ方

3級の第1問では、固定資産の売却取引の相手科目として登場します。2級では、有価証券の売却代金の未収分も未収入金で処理します。売掛金・未収収益など、名前や働きの似た勘定との区別がよく問われます。

## よくある誤り

- 固定資産の売却代金の未収分を売掛金で処理する。
- 未収入金（確定した債権）と未収収益（経過勘定）を混同する。
- 期中に売却したのに、当期分の減価償却費を計上しないまま売却損益を計算する。
