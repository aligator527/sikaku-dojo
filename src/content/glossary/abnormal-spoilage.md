## 定義

機械の故障、作業ミスの多発、災害など、通常の生産では起こらない原因で発生した仕損・減損が異常仕損・異常減損です。正常仕損費は良品を作るのに避けられない原価として良品に負担させますが、異常仕損費は原価の本質（正常的なもの）を満たさないので、非原価項目として製品原価から除きます（原価計算基準5）。

## 計算の考え方

異常仕損費を製品原価から除くには、まず異常仕損品にも原価を按分し、その額を把握する必要があります。そのため、異常仕損品の数量（加工費は換算量）も按分の分母に含めて計算します。仕損品に処分価額があれば、それを差し引いた額が異常仕損費です。

## 計算例（平均法、原料は始点投入）

| 項目 | 数量（進捗度） | 原料費 | 加工費 |
| --- | --- | ---: | ---: |
| 月初仕掛品 | 200個（50％） | 90,000円 | 40,000円 |
| 当月投入 | 1,800個 | 810,000円 | 1,052,000円 |
| 完成品 | 1,600個 | | |
| 異常仕損（終点で発生） | 100個 | | |
| 月末仕掛品 | 300個（40％） | | |

- 原料費の単価：900,000 ÷（1,600 ＋ 100 ＋ 300）＝ 450円
- 加工費の単価：1,092,000 ÷（1,600 ＋ 100 ＋ 120）＝ 600円
- 異常仕損費：100 ×（450 ＋ 600）＝ 105,000円
- 月末仕掛品原価：300 × 450 ＋ 120 × 600 ＝ 207,000円
- 完成品総合原価：1,600 ×（450 ＋ 600）＝ 1,680,000円

仕訳は（借）製品 1,680,000・異常仕損費 105,000（貸）仕掛品 1,785,000 です。

## 試験での問われ方

日商簿記1級では、異常仕損費の金額と仕訳、正常仕損と異常仕損が同時に発生する場合の処理が出題されます。正常仕損の発生点より後で異常仕損が生じた場合は、異常仕損品も正常仕損の発生点を通過しているので、正常仕損費の一部を負担させます。原価計算基準の理論問題でも、異常な仕損が非原価項目であることが問われます。

## よくある誤り

- 異常仕損費を完成品原価に含めてしまう。
- 度外視法と混同し、異常仕損品の数量を分母から除いて按分する。
- 正常仕損の発生点を通過した異常仕損品に、正常仕損費を負担させ忘れる。
