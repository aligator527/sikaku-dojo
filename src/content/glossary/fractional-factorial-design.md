## 考え方

2 水準の因子が $k$ 個あると、全ての組合せを試す要因配置実験には $2^k$ 回が必要です。$k$ が大きいと現実的でないので、そのうち $2^{k-p}$ 回だけを選んで実験するのが一部実施要因計画です。その代償として、いくつかの効果どうしが区別できなくなります（別名、交絡）。実務では 3 因子以上の交互作用は小さいことが多いので、主効果や 2 因子交互作用を高次の交互作用と交絡させます。

## 例：$2^{4-1}$ 計画

因子 A, B, C の $2^3 = 8$ 通りの組合せについて、D の水準を $D = ABC$（$\pm 1$ の符号の積）で決めると、8 回の実験で 4 因子を調べられます。このとき定義関係は $I = ABCD$ で、各効果の別名は定義関係を掛けて求めます（$A^2 = I$ を使う）。

| 効果 | 別名 |
| --- | --- |
| A | BCD |
| B | ACD |
| C | ABD |
| D | ABC |
| AB | CD |
| AC | BD |
| AD | BC |

主効果は 3 因子交互作用と交絡するだけなので、3 因子交互作用が無視できれば主効果を推定できます。一方、2 因子交互作用どうし（AB と CD など）は区別できません。

## 分解能

定義関係に現れる最も短い語の長さを分解能といいます。

- 分解能 III（例 $2^{3-1}$, $C = AB$）：主効果が 2 因子交互作用と交絡する。
- 分解能 IV（例 $2^{4-1}$, $D = ABC$）：主効果は 3 因子交互作用とだけ交絡し、2 因子交互作用どうしは交絡する。
- 分解能 V：主効果も 2 因子交互作用も、3 因子以上の交互作用とだけ交絡する。

同じ実験回数なら、分解能の高い計画が望ましいとされます。直交表への割り付けは、一部実施要因計画を表の形で実現したものです。

## 試験での問われ方

統計検定準1級・1級では、生成元から定義関係と別名関係を求める問題、ある効果がどの交互作用と交絡するかを答える問題、分解能の判定、主効果の推定値の計算が出題されます。

## よくある誤り

- 別名関係を求めるとき、同じ文字の 2 乗を消し忘れる（$A \times ABCD = A^2BCD = BCD$）。
- 一部実施でも、全ての 2 因子交互作用を主効果と別に推定できると考える。
- 生成元の符号（$D = -ABC$ など）によって、別名の符号が変わることを見落とす。
