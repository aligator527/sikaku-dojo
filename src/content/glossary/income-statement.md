## 定義

損益計算書は、1年間などの会計期間に、どれだけの収益を上げ、どれだけの費用がかかり、その結果いくらの利益（または損失）が出たかを示します。報告式の損益計算書では、収益と費用を性質ごとに区分し、段階的に利益を計算します。

| 区分 | 内容の例 | 計算される利益 |
| --- | --- | --- |
| 売上高 − 売上原価 | 商品の販売高と、その原価 | 売上総利益 |
| − 販売費及び一般管理費 | 給料、広告宣伝費、発送費、減価償却費、貸倒引当金繰入（営業債権分） | 営業利益（本業のもうけ） |
| ＋ 営業外収益 − 営業外費用 | 受取利息・受取配当金、支払利息、有価証券評価損益 | 経常利益（経常的なもうけ） |
| ＋ 特別利益 − 特別損失 | 固定資産売却損益、災害損失、国庫補助金受贈益 | 税引前当期純利益 |
| − 法人税、住民税及び事業税 ± 法人税等調整額 | 税金費用 | 当期純利益 |

## 計算例

| 項目 | 金額 |
| --- | ---: |
| 売上高 | 1,000,000 |
| 売上原価 | 600,000 |
| 売上総利益 | 400,000 |
| 販売費及び一般管理費 | 250,000 |
| 営業利益 | 150,000 |
| 営業外収益 | 20,000 |
| 営業外費用 | 30,000 |
| 経常利益 | 140,000 |
| 特別利益 | 10,000 |
| 特別損失 | 40,000 |
| 税引前当期純利益 | 110,000 |
| 法人税、住民税及び事業税 | 33,000 |
| 当期純利益 | 77,000 |

## 試験での問われ方

日商簿記3級では勘定式に近い簡単な損益計算書、2級では報告式の損益計算書を作成させ、各費用・収益をどの区分に表示するかが問われます。1級では特別損益の範囲や表示方法が理論でも出題されます。中小企業診断士の財務・会計では、段階利益の意味や、売上高営業利益率などの収益性分析の基礎として問われます。

## よくある誤り

- 支払利息や有価証券評価損を販売費及び一般管理費に含める（営業外費用）。
- 営業外の貸付金に対する貸倒引当金繰入を販売費及び一般管理費に含める（営業外費用）。
- 固定資産売却損益を営業外損益にする（臨時的なものは特別損益）。
- 損益計算書に「仕入」と表示する（表示科目は売上原価）。
