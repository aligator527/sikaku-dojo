## 定義

郵便切手やはがき、収入印紙は、購入したときに通信費・租税公課（費用）として処理するのが通常です。しかし決算日に使わずに残っている分は当期の費用ではなく、翌期以降に使える資産です。そこで決算整理で、未使用分を費用から貯蔵品（資産）に振り替えます。

## 仕訳例

決算にあたり、郵便切手 ￥2,000 と収入印紙 ￥3,000 が未使用で残っていた。購入時にそれぞれ通信費・租税公課で処理している。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 貯蔵品 | 5,000 | 通信費 | 2,000 |
| | | 租税公課 | 3,000 |

翌期首に、上記の振替を元に戻す再振替仕訳を行った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 通信費 | 2,000 | 貯蔵品 | 5,000 |
| 租税公課 | 3,000 | | |

再振替によって、翌期に切手・印紙を使ったときに改めて仕訳をしなくても、使った分が翌期の費用として扱われます。

## 消耗品との違い

事務用品などの消耗品も購入時に消耗品費で処理しますが、日商簿記3級では、期末の未使用分を資産に振り替える処理は求められていません。貯蔵品に振り替える対象として問われるのは、主に郵便切手・はがき・収入印紙です。2級以上では、固定資産を除却したときの処分見込額を貯蔵品として計上する場面にも登場します。

## 試験での問われ方

3級の第3問の決算整理事項で定番の項目です。精算表や財務諸表の作成問題では、貸借対照表に「貯蔵品」が表示されるかどうか、通信費・租税公課の金額が正しく減っているかで得点が分かれます。第2問の勘定記入では、翌期首の再振替も含めて問われます。

## よくある誤り

- 未使用の切手・印紙を「現金」として扱う。
- 決算整理で、通信費・租税公課を借方、貯蔵品を貸方にしてしまう（貯蔵品が増えるので借方）。
- 翌期首の再振替仕訳を忘れる。
