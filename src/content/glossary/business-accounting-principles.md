## 定義

企業会計原則は、1949年に公表された日本の会計基準の基礎となる文書です。その後、多くの論点は企業会計基準委員会の個別の会計基準に置き換えられていますが、一般原則は今も会計の基本的な考え方として試験で問われます。

## 一般原則（7つ）

| 原則 | 内容 |
| --- | --- |
| 真実性の原則 | 企業の財政状態と経営成績について真実な報告を提供すること。見積りや方法の選択が入るため、求められるのは相対的な真実 |
| 正規の簿記の原則 | すべての取引を、網羅的・検証可能・秩序ある正確な会計帳簿に記録し、それにもとづいて財務諸表を作ること |
| 資本取引・損益取引区分の原則 | 資本取引と損益取引を明確に区別し、特に資本剰余金と利益剰余金を混同しないこと |
| 明瞭性の原則 | 財務諸表によって、利害関係者に必要な会計事実を明瞭に表示し、判断を誤らせないようにすること |
| 継続性の原則 | いったん採用した会計処理の原則・手続は、正当な理由がない限り毎期継続して適用すること |
| 保守主義の原則 | 予測される将来の危険に備えて、慎重な判断にもとづく会計処理を行うこと（ただし過度の保守主義は認めない） |
| 単一性の原則 | 目的に応じて形式の異なる財務諸表を作る場合でも、もとになる会計記録は一つであること（形式多元・実質一元） |

## 重要性の原則

注解では、重要性の乏しいものについて本来の厳密な方法によらず簡便な方法を認めています（消耗品の購入時費用処理、引当金の不計上など）。その結果、簿外資産・簿外負債が生じても、正規の簿記の原則に従った処理として認められます。

## 継続性の原則が必要な理由

一つの会計事実について複数の処理方法が認められている場合、方法を自由に変更できると、利益を操作できてしまい、期間比較もできなくなります。そのため、変更には正当な理由が必要です。

## 試験での問われ方

中小企業診断士の財務・会計では、一般原則の内容に関する正誤問題が出題されます。日商簿記1級の会計学でも、各原則の意味や、重要性の原則との関係、概念フレームワークとの違いが問われます。

## よくある誤り

- 真実性の原則が求めるのは絶対的な真実だと考える（相対的な真実）。
- 継続性の原則は会計処理の変更を一切認めないと考える（正当な理由があれば変更できる）。
- 保守主義の原則を、利益を少なく見せるためならどのような処理も許されるものと考える。
