## 七つの手法

| 手法 | 内容 | 主な用途 |
| --- | --- | --- |
| 親和図法 | 混沌とした事実・意見・発想を言語データとしてカードに書き、内容の近いもの（親和性の高いもの）同士をまとめて図にする | 問題の全体像や本質をつかむ（KJ 法と同じ考え方） |
| 連関図法 | 原因と結果、目的と手段が複雑に絡み合った問題について、要因同士の因果関係を矢印で結ぶ | 複雑な問題の主要因を見つける |
| 系統図法 | 目的を達成する手段を、目的 → 手段 → さらにその手段と、樹形図状に展開する | 具体的な実施策を体系的に洗い出す |
| マトリックス図法 | 行と列に要素を並べ、交点で関係の有無や強さを表す | 要素間の関係を整理する（品質機能展開など） |
| PDPC 法 | 計画の実行過程で起こりうる事態を予測し、対応策を含めた過程を図にする（過程決定計画図） | 不測の事態に備えて計画を立てる |
| アロー・ダイアグラム法 | 作業の順序関係を矢線で結んだ日程計画の図 | 日程管理、クリティカルパスの把握 |
| マトリックス・データ解析法 | 数値データを主成分分析などで解析し、要素の関係を整理する | 七つの中で唯一、数値データを扱う |

## QC 七つ道具との違い

| | QC 七つ道具 | 新 QC 七つ道具 |
| --- | --- | --- |
| 扱う情報 | 主に数値データ | 主に言語データ（定性的な情報） |
| 主な目的 | 現状の分析、原因の特定、工程の管理 | 問題の構造化、方策の立案、計画の策定 |
| 主な利用者 | 現場の改善活動 | 管理者・スタッフの企画や方針管理 |

## 試験での問われ方

- **中小企業診断士試験**：運営管理の品質管理で、各手法の説明を入れ替えた選択肢の正誤問題や、QC 七つ道具との区別が出題されます。
- **ITストラテジスト試験**：「親和図の特徴はどれか」のように、個別の手法の説明を選ぶ問題が出ています。

## よくある誤り

- 親和図法と連関図法を取り違える（似た内容をまとめるのが親和図法、因果関係を矢印で結ぶのが連関図法）。
- 特性要因図やパレート図を新 QC 七つ道具に含める（QC 七つ道具です）。
- 新 QC 七つ道具はすべて言語データを扱うとする（マトリックス・データ解析法は数値データを扱います）。
