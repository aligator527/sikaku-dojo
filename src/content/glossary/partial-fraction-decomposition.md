## 方法

有理式 $P(x)/Q(x)$ で分子の次数が分母以上なら、まず割り算をして多項式部分を取り出します。残りの真分数は、分母の因数分解に応じて次の形の和に分けられます。

- 1 次因数 $(x - a)$：$\dfrac{A}{x - a}$
- 重複する 1 次因数 $(x - a)^k$：$\dfrac{A_1}{x - a} + \dfrac{A_2}{(x - a)^2} + \cdots + \dfrac{A_k}{(x - a)^k}$
- 既約な 2 次因数 $(x^2 + px + q)$：$\dfrac{Bx + C}{x^2 + px + q}$

係数は、両辺に分母を掛けて恒等式として比較するか、根を代入して求めます。1 次因数 $(x - a)$ の係数は「分母から $(x - a)$ を除いた式に $x = a$ を代入する」（ヘヴィサイドの方法）と速く求まります。

## 計算例

$\dfrac{1}{(x-1)(x+1)^2} = \dfrac{A}{x-1} + \dfrac{B}{x+1} + \dfrac{C}{(x+1)^2}$ とおきます。$x = 1$ の代入から $A = \frac{1}{4}$、$(x + 1)^2$ を掛けて $x = -1$ を代入すると $C = -\frac{1}{2}$、$x^2$ の係数比較 $A + B = 0$ から $B = -\frac{1}{4}$ です。

## 主な用途

- 有理関数の積分：各項は $\log|x - a|$、$\dfrac{1}{x-a}$ のべき、$\log(x^2 + px + q)$ と $\arctan$ で積分できます。
- 級数の和（望遠鏡和）：$\dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}$ より $\sum_{n=1}^\infty \dfrac{1}{n(n+1)} = 1$ です。
- 高次導関数：$\dfrac{1}{x - a}$ の $n$ 階導関数は $\dfrac{(-1)^n n!}{(x - a)^{n+1}}$ なので、分解してから微分すると簡単です。
- べき級数・ローラン展開：各項を等比級数に展開します。
- ラプラス変換の逆変換や、母関数から数列の一般項を求める計算にも使います。

## 試験での問われ方

数検1級では、有理関数の不定積分・広義積分、級数の和、$n$ 階導関数、ローラン展開の計算の途中で使う基本技術として頻繁に現れます。1次では計算の速さと正確さが問われます。

## よくある誤り

- 重複因数 $(x + 1)^2$ に対して $\dfrac{C}{(x+1)^2}$ だけを置き、$\dfrac{B}{x+1}$ を置き忘れる。
- 既約な 2 次因数の分子を定数だけにする（$Bx + C$ が必要）。
- 分子の次数が分母以上のまま分解しようとする。
