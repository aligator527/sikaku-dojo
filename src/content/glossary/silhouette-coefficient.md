## 定義

点 $i$ について、

- $a(i)$：同じクラスターの他の点との距離の平均
- $b(i)$：他のクラスターそれぞれについて、そのクラスターの点との距離の平均を求め、その最小値（最も近い隣のクラスターまでの平均距離）

として、$s(i) = (b(i) - a(i))/\max\{a(i), b(i)\}$ と定めます。

- $s(i)$ が 1 に近い：自分のクラスターにしっかり属している
- 0 に近い：2 つのクラスターの境目にある
- 負：隣のクラスターの方が近く、割り当てが不適切な可能性がある

1 点だけのクラスターの点は $s(i) = 0$ と定めるのが普通です。

## 計算例

点 $i$ のクラスターに他の点が 2 つあり、点 $i$ からの距離が 1.0 と 3.0 なら $a = 2.0$ です。他のクラスター B の 2 点との距離が 4.0 と 6.0（平均 5.0）、クラスター C の 2 点との距離が 3.0 と 4.0（平均 3.5）なら $b = 3.5$ で、$s = (3.5 - 2.0)/3.5 \approx 0.43$ です。

## クラスター数の選び方

- **平均シルエット係数**：全点の $s(i)$ の平均が最大になるクラスター数 $k$ を選ぶ。点ごと・クラスターごとの値を並べた図（シルエット図）で、まとまりの悪いクラスターも確認できる。
- **エルボー法**：$k$ に対してクラスター内平方和を描き、減り方が急に鈍る「肘」の $k$ を選ぶ。クラスター内平方和は $k$ を増やせば必ず減るので、最小値では選べない。肘がはっきりしないことも多い。
- ほかに、ギャップ統計量や、混合ガウスモデルなら BIC も使われます。

## 試験での問われ方

統計検定データサイエンスエキスパートでは、距離の表から特定の点のシルエット係数を計算する問題や、平均シルエット係数・エルボー法によるクラスター数の選び方に関する選択肢が出ます。

## よくある誤り

- $b(i)$ を「他のクラスターのすべての点との距離の平均」とする（クラスターごとに平均をとり、その最小値を使う）。
- 分母を $a(i)$ や $b(i)$ に固定する（大きい方で割る）。
- クラスター内平方和が最小の $k$ を最適とする。
