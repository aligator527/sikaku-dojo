## 定義

$A \cap B = \emptyset$（共通部分がない）のとき、事象 $A$ と $B$ は排反であるといいます。3 つ以上の事象では、どの 2 つも排反なとき「互いに排反」といいます。

## 加法定理

一般には

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

で、重なりの分を引く必要があります。$A, B$ が排反なら $P(A \cap B) = 0$ なので、単純な足し算 $P(A) + P(B)$ になります。互いに排反な $A_1, A_2, \ldots$ についても $P(\bigcup A_i) = \sum P(A_i)$ が成り立ちます。

## 排反と独立の違い

| | 排反 | 独立 |
| --- | --- | --- |
| 意味 | 同時に起こらない | 一方が起きても他方の確率が変わらない |
| 式 | $P(A \cap B) = 0$ | $P(A \cap B) = P(A)P(B)$ |
| 簡単になる公式 | 和の確率（加法定理） | 積の確率（乗法定理） |

$P(A) > 0$、$P(B) > 0$ の事象が排反なら、$A$ が起きたと分かった時点で $B$ は起こりえない（$P(B \mid A) = 0 \neq P(B)$）ので、独立ではありません。

**例**：さいころ 1 回で $A$ = 「偶数の目」、$B$ = 「1 の目」は排反で、$P(A \cup B) = 1/2 + 1/6 = 2/3$ です。$P(A \cap B) = 0 \neq P(A)P(B) = 1/12$ なので独立ではありません。

## 試験での問われ方

統計検定2級では、場合分けした事象の確率を足し合わせてよいかの判断、加法定理の適用、排反と独立の区別を問う記述の正誤問題が出題されます。全確率の公式やベイズの定理も、標本空間を互いに排反な事象に分割することが前提になっています。

## よくある誤り

- 排反でない事象の確率をそのまま足して、重なりを二重に数える。
- 「排反なら独立」「独立なら排反」と考える。
- 互いに排反でない場合分けをして全確率の公式を使う。
