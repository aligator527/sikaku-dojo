## CPU との違い

| | CPU | GPU |
| --- | --- | --- |
| コア | 少数（数〜数十）の高性能なコア | 数千の単純なコア |
| 得意な処理 | 複雑な分岐を含む逐次処理 | 同じ演算を大量のデータに適用する並列処理 |
| メモリ | 大容量・低帯域 | 比較的小容量・高帯域（HBM など） |

深層学習の計算の大部分は行列積と要素ごとの演算なので、GPU の並列性を生かせます。NVIDIA の GPU は CUDA というプログラミング環境を持ち、PyTorch などのライブラリが利用しています。低精度の行列積に特化した Tensor コアを使うと、混合精度学習でさらに速くなります。

## 並列処理の分類

- **SIMD**（Single Instruction Multiple Data）：1 つの命令で複数のデータを同時に処理する（CPU のベクトル命令など）。
- **SIMT**（Single Instruction Multiple Thread）：多数のスレッドが同じ命令を同時に実行する GPU の方式。NVIDIA の GPU では 32 スレッド（ワープ）が単位です。スレッドごとに分岐できますが、分岐が分かれると両方を順に実行するので効率が落ちます。
- **MIMD**（Multiple Instruction Multiple Data）：複数のプロセッサがそれぞれ別の命令を別のデータに実行する（マルチコア CPU、複数台のクラスタ）。

## TPU などのアクセラレータ

- **TPU**（Tensor Processing Unit）：Google が開発した深層学習専用のプロセッサ。多数の乗算器を格子状に並べたシストリックアレイで行列積を効率よく行い、BF16 を活用します。主にクラウドで使われます。
- そのほか、推論向けの専用チップ（NPU）や、回路を書き換えられる FPGA もあります。

## 実務上の注意

- GPU のメモリには、パラメータのほか、勾配・最適化手法の状態・逆伝播のための活性が載ります。FP32 で Adam を使うと、パラメータ 1 個あたり重み・勾配・2 つのモーメントで 16 バイト程度が必要で、5 億パラメータなら約 8 GB です（活性は別）。
- 実際の性能は、演算性能だけでなくメモリ帯域や GPU 間の通信速度で決まることも多くあります。

## 試験での問われ方

E資格（シラバス 2026 のアクセラレータ：SIMD、SIMT、MIMD、GPU、TPU）では、並列処理の分類と GPU・TPU の対応、CPU との違い、学習時のメモリ量の見積もりが出題されます。統計検定データサイエンスエキスパートでは、GPU の台数と性能から学習時間を見積もる計算が問われます。

## よくある誤り

- GPU は 1 つ 1 つのコアが CPU より高性能だと考える（単純なコアを大量に持つ）。
- SIMT と MIMD を同じものだと考える（SIMT は同じ命令をそろえて実行する）。
- 学習時の GPU メモリをパラメータの分だけで見積もる（勾配・最適化手法の状態・活性も必要）。
