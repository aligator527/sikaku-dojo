## 役割

線形予測子 $\eta = \mathbf{x}^\top\boldsymbol{\beta}$ は実数全体の値をとりますが、平均 $\mu$ は分布によって範囲が限られます（確率なら $0 < \mu < 1$、件数なら $\mu > 0$）。リンク関数 $g$ は両者を結びつけ、逆関数 $g^{-1}$ で戻したときに $\mu$ が許される範囲に収まるようにします。

| リンク | $g(\mu)$ | 逆関数 $\mu = g^{-1}(\eta)$ | 主な用途 |
|---|---|---|---|
| 恒等 | $\mu$ | $\eta$ | 正規分布 |
| 対数 | $\log\mu$ | $e^{\eta}$ | ポアソン分布、ガンマ分布 |
| ロジット | $\log\dfrac{\mu}{1-\mu}$ | $\dfrac{1}{1 + e^{-\eta}}$ | 二項分布 |
| プロビット | $\Phi^{-1}(\mu)$ | $\Phi(\eta)$ | 二項分布 |
| 補 2 重対数（cloglog） | $\log\{-\log(1-\mu)\}$ | $1 - \exp(-e^{\eta})$ | 二項分布（非対称な反応） |
| 逆数 | $1/\mu$ | $1/\eta$ | ガンマ分布 |

## 正準リンク

指数型分布族の密度を $f(y;\theta) = \exp\{(y\theta - b(\theta))/\phi + c(y, \phi)\}$ と書いたとき、自然母数 $\theta$ を平均 $\mu = b'(\theta)$ で表した関数 $g(\mu) = \theta(\mu)$ を正準リンクといいます。

| 分布 | 正準リンク |
|---|---|
| 正規分布 | 恒等 $\mu$ |
| ポアソン分布 | 対数 $\log\mu$ |
| 二項分布 | ロジット |
| ガンマ分布 | 逆数 $-1/\mu$（符号を除けば $1/\mu$） |
| 逆ガウス分布 | $-1/(2\mu^2)$ |

例：ポアソン分布 $e^{-\mu}\mu^y/y! = \exp\{y\log\mu - \mu - \log y!\}$ で、$y$ に掛かる $\log\mu$ が自然母数なので、正準リンクは対数リンクです。

正準リンクを使うと、$\sum_i x_{ij}y_i$ が十分統計量になり、スコア方程式が $X^\top(\mathbf{y} - \boldsymbol{\mu}) = \mathbf{0}$ と簡単になります（切片があれば $\sum\hat{\mu}_i = \sum y_i$）。また、ニュートン・ラフソン法とフィッシャーのスコア法が一致します。ただし、正準リンクを使わなければならないわけではなく、解釈やデータへの当てはまりで選びます（ガンマ回帰では対数リンクがよく使われます）。

## 係数の解釈

- 恒等リンク：$x_j$ が 1 増えると平均が $\beta_j$ 増える。
- 対数リンク：平均が $e^{\beta_j}$ 倍になる（率比）。
- ロジットリンク：オッズが $e^{\beta_j}$ 倍になる（オッズ比）。
- プロビットリンク：潜在変数の標準偏差単位の変化で、確率への効果は $x$ の値によって変わる。

## 試験での問われ方

統計検定準1級では、分布と正準リンクの組合せを選ぶ問題、指数型分布族の形から正準リンクを導く問題、リンクに応じた係数の解釈が出ます。1級では、正準リンクのもとでのスコア方程式や十分統計量の導出が記述式で問われます。

## よくある誤り

- リンク関数を目的変数 $y$ に適用する変換と考える（変換するのは平均 $\mu$）。
- ガンマ分布の正準リンクを対数リンクとする（正準リンクは逆数。対数リンクもよく使われるが正準ではない）。
- 正準リンク以外は使えないと考える。
