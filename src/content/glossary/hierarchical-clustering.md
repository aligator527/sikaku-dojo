## 手順（凝集型）

1. データ間の距離（非類似度）の行列を作る。
2. 各データを 1 つのクラスターとする。
3. 最も距離の近い 2 つのクラスターを併合する。
4. 併合したクラスターと他のクラスターとの距離を、決めた方法（下記）で計算し直す。
5. クラスターが 1 つになるまで 3・4 を繰り返す。

## クラスター間の距離の定め方

| 方法 | クラスター $A$ と $B$ の距離 |
| --- | --- |
| 最短距離法（単連結法） | 2 つのクラスターの点の組の距離の最小値 |
| 最長距離法（完全連結法） | 点の組の距離の最大値 |
| 群平均法 | 点の組の距離の平均 |
| 重心法 | 重心間の距離 |
| ウォード法 | 併合によるクラスター内平方和の増加量 |

最短距離法は鎖のように細長くつながったクラスターを作りやすく（連鎖効果）、最長距離法やウォード法はまとまった大きさのクラスターを作りやすい傾向があります。重心法では、併合の高さが前の段階より低くなる「逆転」が起こることがあります。

## 計算例

4 点の距離が $d(A, B) = 1$、$d(A, C) = 4$、$d(B, C) = 3$、$d(A, D) = 6$、$d(B, D) = 5$、$d(C, D) = 2$ のとき、まず高さ 1 で $A$ と $B$、次に高さ 2 で $C$ と $D$ が併合されます。最後の併合の高さは、最短距離法では $\min(4, 3, 6, 5) = 3$、最長距離法では 6、群平均法では $(4 + 3 + 6 + 5)/4 = 4.5$ です。

## デンドログラムの読み方

縦軸（または横軸）は併合したときの距離（高さ）です。ある高さで水平に切ると、その高さより下でつながった点の集まりがクラスターになります。2 つの点がどの高さで初めて同じクラスターになるかを表す距離をコーフェン距離といいます。葉の並ぶ順序には任意性があり、横に隣り合っていても近いとは限りません。

## 試験での問われ方

統計検定データサイエンスエキスパートでは、距離行列から併合の順序と高さを求める問題、併合の記録やデンドログラムから指定した数のクラスターを読み取る問題、クラスター間距離の定め方による違いが出ます。統計検定準1級・1級でも、多変量解析の手法として同様の計算が問われます。

## よくある誤り

- デンドログラムの葉の左右の並びを、データの近さと解釈する。
- 一度併合したクラスターが後で分かれることがあると考える（凝集型では分かれない）。
- 大規模なデータにもそのまま使えると考える（距離行列だけで $O(n^2)$ の記憶が必要で、$k$ 平均法より計算量が大きい）。
