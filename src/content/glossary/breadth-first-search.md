## 手順

```python
from collections import deque

def bfs(graph, s):
    dist = {s: 0}
    q = deque([s])
    while q:
        u = q.popleft()
        for v in graph[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```

先に入れたものから先に取り出す（FIFO）キューを使うので、距離 0 の頂点、距離 1 の頂点、距離 2 の頂点……の順に訪問されます。各頂点に初めて到達したときの値が、出発点からの最短の辺の数です。

## 計算量

各頂点を 1 回だけキューに入れ、各辺を 1 回（無向グラフでは 2 回）調べるので、隣接リストで表したグラフでは $O(V + E)$ です（$V$ は頂点数、$E$ は辺の数）。隣接行列で表すと $O(V^2)$ になります。Python のリストの `pop(0)` は $O(n)$ なので、キューには `collections.deque` を使います。

## 深さ優先探索との違い

深さ優先探索（DFS）は、スタック（あるいは再帰）を使って、行けるところまで進んでから戻る探索です。到達可能性の判定、連結成分の数え上げ、閉路の検出、トポロジカルソートなどに使いますが、最初に到達したときの経路が最短とは限りません。

## 重み付きグラフ

辺に正の重み（所要時間など）があるときは、辺の数が少ない経路が最短とは限らないので、ダイクストラ法を使います。重みがすべて 1 のとき、ダイクストラ法は距離の小さい順に頂点を確定するので、幅優先探索と同じ最短距離が得られます（同じ距離の頂点どうしの順序は実装によります）。

## 応用

ウェブページのリンク構造で、トップページから各ページに何回のクリックで行けるかを求める、SNS で「友達の友達」までの範囲を求める、迷路の最短手数を求める、といった問題に使われます。

## 試験での問われ方

統計検定データサイエンスエキスパートでは、出題範囲表のアルゴリズムに幅優先探索・深さ優先探索が挙がっています。グラフと BFS のコードを示して、各頂点の距離や訪問の順序、キューの中身をたどらせる形が考えられます。

## よくある誤り

- 訪問済みの印を付けずに探索し、同じ頂点を何度もキューに入れる（閉路があると終わらない）。
- 重み付きグラフの最短経路を幅優先探索で求める。
