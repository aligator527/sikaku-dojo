## 定義

ハミング符号は、通信や記憶の途中でビットが反転する誤りに備えて、情報ビットに検査ビットを付け加える符号です。受信側で検査の式を計算すると、誤りがあるかどうかだけでなく、**どのビットが誤っているか**まで分かるので、そのビットを反転すれば訂正できます。

(7, 4) ハミング符号では、7 ビットの符号語のうち 1・2・4 ビット目（2 のべき乗の位置）を検査ビット、3・5・6・7 ビット目を情報ビットとし、次の検査値（mod 2 の和）がすべて 0 になるように検査ビットを決めます。

$$
c_0 = x_1 + x_3 + x_5 + x_7,\quad c_1 = x_2 + x_3 + x_6 + x_7,\quad c_2 = x_4 + x_5 + x_6 + x_7
$$

受信語で $c_2 c_1 c_0$ を計算し、2 進数として読んだ値 $i = c_0 + 2c_1 + 4c_2$ が 0 でなければ、$i$ ビット目が誤りです。

## 計算例

符号語 0110011 を送ったところ、6 ビット目が反転して 0110001 を受信したとします。受信語で計算すると $c_0 = 0 + 1 + 0 + 1 \equiv 0$、$c_1 = 1 + 1 + 0 + 1 \equiv 1$、$c_2 = 0 + 0 + 0 + 1 = 1$ なので $i = 0 + 2 + 4 = 6$ です。6 ビット目を反転すると、元の 0110011 に戻ります。

## パリティとの違い

1 ビットのパリティ（全体の 1 の個数を偶数または奇数にそろえる）は、1 ビットの誤りを**検出**できますが、位置が分からないので訂正はできず、2 ビットの誤りは検出もできません。ハミング符号は符号語どうしの最小ハミング距離が 3 なので、1 ビットの誤りを訂正できます。検査ビットをもう 1 つ加えると、1 ビット訂正と 2 ビット検出を同時に行えます（ECC メモリなどで利用）。

## 試験での問われ方

- **ITストラテジスト試験**：科目A-1 で、検査の式と訂正の手順を示したうえで、受信した符号語を訂正した結果を求める問題が出題されています。式に当てはめて mod 2 で計算するだけなので、ビットの位置を数え間違えないことが大切です。

## よくある誤り

- 2 ビットの誤りも訂正できると考える。(7, 4) ハミング符号で訂正できるのは 1 ビットまでです。
- $i$ を求めるとき、$c_0$ と $c_2$ の重み（1 と 4）を逆にする。
- 「左から $i$ ビット目」を右から数える。
