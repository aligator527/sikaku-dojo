## 原因

誤差逆伝播法では、入力側の層の勾配は各層の局所勾配（活性化関数の微分と重み行列）の積になります。各因子の大きさが 1 より小さいと積は指数的に 0 に近づき（勾配消失）、1 より大きいと指数的に大きくなります（勾配爆発）。

- **シグモイド関数**の微分は最大でも $0.25$（$x = 0$ のとき）なので、何層も重ねると勾配が急速に小さくなります。$\tanh$ の微分は最大 $1$ ですが、飽和領域では 0 に近くなります。
- **RNN** では同じ重み行列 $W$ が時刻ごとに掛かるため、$W$ の最大特異値（固有値）が 1 より小さいか大きいかで、勾配消失・爆発が起こりやすくなります。

## 主な対策

| 対策 | 仕組み |
| --- | --- |
| ReLU 系の活性化関数 | 正の領域で微分が 1 なので勾配が縮まない |
| 重みの初期化（Xavier / He） | 各層の出力と勾配の分散が層を通じて保たれるようにする |
| バッチ正規化など | 各層の入力分布を整え、飽和領域に入りにくくする |
| 残差接続（skip connection） | 恒等写像の経路で勾配がそのまま伝わる |
| LSTM / GRU | ゲート付きの加法的なセル状態の更新で、長い時間にわたって勾配を保つ |
| 勾配クリッピング | 勾配のノルムが閾値を超えたら縮める（勾配爆発の対策） |

## 試験での問われ方

E資格では、シグモイド関数の微分の最大値、各対策の仕組み、LSTM のゲートの役割、勾配クリッピングの式 $\boldsymbol g \leftarrow \dfrac{c}{\|\boldsymbol g\|}\boldsymbol g\ (\|\boldsymbol g\| > c)$ が問われます。

## よくある誤り

- 勾配クリッピングを勾配消失の対策と誤解する（クリッピングは勾配爆発の対策）。
- ReLU にも、負の領域で勾配が 0 になりユニットが学習しなくなる問題（dying ReLU）がある。Leaky ReLU などで緩和します。
