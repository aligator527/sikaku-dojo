## 定義

標本調査では、どの個体が標本に選ばれるかによって推定値が変わります。この「たまたま選ばれた標本による」ずれを標本誤差といいます。確率抽出なら、標本誤差の大きさを標準誤差や信頼区間で表せます。標本の大きさを $n$ とすると、おおよそ $1/\sqrt{n}$ に比例して小さくなり、全数調査では 0 です。

## 非標本誤差との区別

標本誤差以外の、調査の過程で生じる誤差をまとめて非標本誤差といいます。

| 種類 | 例 |
| --- | --- |
| カバレッジ誤差 | 名簿（抽出枠）に載っていない人がいる（固定電話の名簿で携帯電話のみの世帯が漏れる） |
| 無回答誤差 | 回答しなかった人の性質が回答者と異なる |
| 測定誤差 | 質問文の言い回しや調査員の影響、記憶違い、社会的に望ましい回答への偏り |
| 処理誤差 | 入力や集計の誤り |

| | 標本誤差 | 非標本誤差 |
| --- | --- | --- |
| 原因 | 一部だけを調べたこと | 調査の設計・実施・集計の不備 |
| 全数調査 | 生じない | 生じる |
| 標本を大きくすると | 小さくなる | 小さくならない（増えることもある） |
| 評価 | 標準誤差で確率的に評価できる | 評価が難しく、偏りとして現れやすい |

## 試験での問われ方

統計検定2級では、具体的な誤差の例（名簿の漏れ、無回答、聞き方の影響、標本の偶然のばらつき）が標本誤差と非標本誤差のどちらにあたるかを判定する問題が定番です。準1級・1級では、無回答による偏りの補正（ウエイト調整・多重代入）や、総合的な誤差（平均二乗誤差 = 分散 + 偏りの 2 乗）としての評価が問われます。

## よくある誤り

- 標本を大きくすれば、すべての誤差が小さくなると考える。
- 全数調査なら誤差はないと考える（非標本誤差は残る）。
- 回答率が低いことによる偏りを、標本誤差に含める（非標本誤差である）。
