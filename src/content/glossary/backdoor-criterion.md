## 定義

因果ダイアグラムで、処置 $X$ に入る矢印（$X \leftarrow \cdots$）から始まる $X$ と $Y$ の間の経路をバックドアパス（裏口の経路）といいます。交絡による見かけの関連は、この経路を通って伝わります。変数の組 $Z$ が次の 2 条件を満たすとき、$Z$ は $(X, Y)$ についてバックドア基準を満たすといいます。

1. $Z$ のどの変数も $X$ の子孫ではない。
2. $Z$ が、$X$ と $Y$ の間のすべてのバックドアパスを遮断する（d 分離の意味で）。

このとき、介入した場合の分布は冒頭の調整公式（バックドア調整）で観測データから計算できます。線形の構造方程式モデルなら、$Y$ を $X$ と $Z$ に回帰したときの $X$ の係数が因果効果です。

## 判定のこつ

| $Z$ に入れる候補 | 判断 |
|---|---|
| 共通原因（$X \leftarrow C \to Y$） | 入れる（バックドアパスを遮断する） |
| 中間変数（$X \to M \to Y$） | 入れない（$X$ の子孫。効果の一部を消す） |
| 合流点（$X \to S \leftarrow Y$ や $A \to S \leftarrow B$） | 入れない。入れるならその経路を他の変数で遮断する |
| 処置の原因だけ（$W \to X$） | 入れなくてよい（入れても偏りは生じないが精度が落ちることがある） |
| 結果の原因だけ（$V \to Y$） | 入れなくてよい（入れると精度が上がることが多い） |

基準を満たす組は一つとは限らず、未観測の変数を含まない組が一つでもあれば効果を推定できます。合流点を調整するとかえってバックドアパスが開く例（M バイアス：$X \leftarrow A \to S \leftarrow B \to Y$ で $S$ を調整する）にも注意します。

## 計算例

2 値の $Z$ が $X$ と $Y$ の共通原因で、$P(Z = 1) = 0.4$、$P(Y = 1 \mid X, Z)$ が次の表のとき

| | $Z = 0$ | $Z = 1$ |
|---|---|---|
| $X = 1$ | 0.3 | 0.6 |
| $X = 0$ | 0.2 | 0.5 |

$P(Y = 1 \mid do(X = 1)) = 0.6 \times 0.3 + 0.4 \times 0.6 = 0.42$、$P(Y = 1 \mid do(X = 0)) = 0.6 \times 0.2 + 0.4 \times 0.5 = 0.32$ で、因果効果（リスク差）は 0.10 です。$Z = 1$ の人ほど $X = 1$ になりやすい（たとえば $P(X = 1 \mid Z = 1) = 0.8$、$P(X = 1 \mid Z = 0) = 0.25$）と、調整しない単純な比較 $P(Y = 1 \mid X = 1) - P(Y = 1 \mid X = 0)$ は約 0.26 と大きく出ます。

## 試験での問われ方

統計検定準1級では、因果ダイアグラムからバックドア基準を満たす変数の組を選ぶ問題、調整公式による介入効果の計算、調整してはいけない変数（中間変数・合流点）の判断が出ます。データサイエンスエキスパートでも、観察データからの施策効果の推定で調整変数を選ぶ問題が出題されます。

## よくある誤り

- 調整公式で $P(z)$ の代わりに $P(z \mid x)$ を使う（それは単純な条件付き確率 $P(y \mid x)$ に戻ってしまう）。
- $X$ の後に起きた変数（中間変数や結果の子孫）を調整変数に含める。
- 共変量は多く調整するほど偏りが減ると考える（合流点を調整すると偏りが生じる）。
