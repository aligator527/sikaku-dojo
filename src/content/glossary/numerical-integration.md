## 台形公式

区間 $[a, b]$ を幅 $h = (b - a)/n$ の小区間に分け、$f_k = f(a + kh)$ とします。各小区間で $f$ を直線で近似すると**台形公式**

$$T_h = \frac{h}{2}\Bigl(f_0 + 2f_1 + 2f_2 + \cdots + 2f_{n-1} + f_n\Bigr)$$

が得られます。誤差は、ある $\xi \in (a, b)$ を用いて

$$\int_a^b f\,dx - T_h = -\frac{(b - a)h^2}{12}f''(\xi)$$

と表せ、$h$ を半分にすると誤差はおよそ $\frac{1}{4}$ になります。$f'' > 0$（下に凸）なら台形公式は真の値より大きくなります。

## シンプソンの公式

小区間を 2 つずつ組にして（$n$ は偶数）、3 点を通る 2 次式で近似すると**シンプソンの公式**

$$S_h = \frac{h}{3}\bigl(f_0 + 4f_1 + 2f_2 + 4f_3 + \cdots + 2f_{n-2} + 4f_{n-1} + f_n\bigr)$$

になります。誤差は $-\dfrac{(b - a)h^4}{180}f^{(4)}(\xi)$ で、3 次式までは正確に積分できます。

## 計算例

$\int_0^1 x^2\,dx = \frac{1}{3}$ を $h = \frac{1}{2}$ で近似すると、

- 台形公式：$\frac{1}{4}\left(0 + 2\cdot\frac{1}{4} + 1\right) = 0.375$。誤差 $-\frac{1}{24}$ は公式 $-\frac{1\cdot(1/2)^2}{12}\cdot 2$ と一致します。
- シンプソンの公式：$\frac{1}{6}\left(0 + 4\cdot\frac{1}{4} + 1\right) = \frac{1}{3}$（2 次式なので正確）

## その他の方法

- 中点公式：小区間の中点の値を使う。誤差は台形公式の約半分で符号が逆です。
- リチャードソン補外：$h$ と $h/2$ の台形公式から $\frac{4T_{h/2} - T_h}{3}$ を作ると誤差の主要項が消え、シンプソンの公式と一致します（ロンバーグ積分）。
- ガウス求積：分点も最適に選び、$n$ 点で $2n - 1$ 次式まで正確に積分します。
- モンテカルロ積分：乱数で期待値として近似する方法で、誤差は $O(1/\sqrt{N})$ と遅いものの、次元が高くても使えます。

## 試験での問われ方

数検1級では、台形公式・シンプソンの公式で近似値を計算し、誤差の評価式を証明または利用する問題（必要な分割数の見積もりなど）が出ます。統計検定データサイエンスエキスパートでは、数値積分の公式の計算や、精度の次数を比較する問題があります。

## よくある誤り

- 台形公式で、両端以外の値に係数 2 を掛け忘れる。
- シンプソンの公式で、係数 $4, 2, 4, \ldots$ の並びや、分割数が偶数であることを守らない。
- 誤差の次数を取り違え、$h$ を半分にしたときの誤差の減り方を誤る（台形 $\frac{1}{4}$、シンプソン $\frac{1}{16}$）。
