## 主な評価エラー

| エラー | 内容 |
| --- | --- |
| ハロー効果 | 特に優れた点（または劣った点）に引きずられて、他の評価項目まで同じ方向に評価してしまう |
| 寛大化傾向 | 部下との摩擦を避けたい、自信がないなどの理由で、評価が全体に甘くなる（その逆が厳格化傾向） |
| 中心化傾向 | 優劣の判断を避けて、評価が評価尺度の中央（「普通」）に集中する |
| 対比誤差 | 評価者自身の能力や価値観を基準にしてしまう。自分の得意分野では厳しく、不得意分野では甘くなる |
| 期末誤差（近接誤差） | 評価期間の終わり近くの出来事が強く印象に残り、期間全体の評価に過大な影響を与える |
| 論理的誤差 | 評価項目の間に論理的な関連があると思い込み、関連する項目を同じように評価してしまう（「企画力が高いから判断力も高いはずだ」） |

## 防止策

- 評価基準・着眼点を具体的に定め、評価者と被評価者で共有する。
- 評価期間を通じて、具体的な行動や事実を記録する（期末誤差の防止）。
- 評価者訓練（考課者訓練）を行い、陥りやすい誤りを理解させる。
- 一次評価・二次評価の複数段階での評価、多面評価（360 度評価）を取り入れる。
- 評価結果をフィードバックし、面談を通じて納得性を高める。

## 試験での問われ方

**中小企業診断士試験**の企業経営理論の人的資源管理で、各エラーの説明を入れ替えた選択肢の正誤問題が出題されます。第 2 次試験の事例 I では、評価制度の公平性・納得性を高める施策（評価基準の明確化、評価者訓練、フィードバック）として記述する場面があります。

## よくある誤り

- 寛大化傾向と中心化傾向を取り違える（評価が甘くなるのが寛大化、中央に集まるのが中心化です）。
- 対比誤差を、項目間の論理的な関連の思い込みとする（それは論理的誤差です）。
- 期末誤差を、評価期間の初めの出来事が強く印象に残ることとする（期間の終わり近くの出来事です）。
