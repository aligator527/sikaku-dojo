## オーダー記法

基本操作の回数 $f(n)$ について、定数倍と低次の項を無視し、最も速く増える項で表します。$3n^2 + 5n + 2 = O(n^2)$ です。

| オーダー | 例 |
| --- | --- |
| $O(1)$ | 配列の添字による参照、ハッシュ表の検索（平均） |
| $O(\log n)$ | 二分探索、ヒープへの追加・取り出し |
| $O(n)$ | 線形探索、合計の計算 |
| $O(n \log n)$ | マージソート、ヒープソート、クイックソート（平均） |
| $O(n^2)$ | バブルソート、二重ループで全ての組を調べる処理 |
| $O(2^n)$ | 部分集合の全列挙、素朴な再帰によるフィボナッチ数の計算（正確には $\Theta(\varphi^n)$、$\varphi \approx 1.618$） |

$n = 10^6$ のとき、$n\log_2 n$ は約 $2 \times 10^7$ ですが、$n^2$ は $10^{12}$ で、実用上の差は決定的です。最悪の場合の計算量のほか、平均計算量や、操作を繰り返したときの 1 回あたりの償却計算量も使います。

## ループと再帰の数え方

- 二重ループ `for i in range(n): for j in range(i):` の内側は $n(n-1)/2$ 回で $O(n^2)$。
- 変数を毎回半分にするループ（`while n > 1: n //= 2`）は $O(\log n)$。
- リストに対する `x in list` は $O(n)$、集合や辞書に対する `x in set` は平均 $O(1)$。ループの中で `in list` を使うと全体が $O(n^2)$ になります。

## マスター定理

分割統治法の漸化式 $T(n) = aT(n/b) + \Theta(n^d)$（$a \geq 1$、$b > 1$）は、

- $d > \log_b a$ なら $T(n) = \Theta(n^d)$
- $d = \log_b a$ なら $T(n) = \Theta(n^d \log n)$
- $d < \log_b a$ なら $T(n) = \Theta(n^{\log_b a})$

と解けます。マージソート（$a = 2, b = 2, d = 1$）は $\Theta(n \log n)$、二分探索（$a = 1, b = 2, d = 0$）は $\Theta(\log n)$、カラツバ法（$a = 3, b = 2, d = 1$）は $\Theta(n^{\log_2 3}) \approx \Theta(n^{1.585})$ です。

## 試験での問われ方

統計検定データサイエンスエキスパートでは、Python のコードの実行回数のオーダーを答える問題、分割統治の漸化式の解、リストと集合の検索の違いなどが出ます。E資格では、行列積・畳み込み・自己注意（系列長の 2 乗）などの計算量やパラメータ数が問われます。

## よくある誤り

- 定数倍の大きい $O(n)$ と $O(n \log n)$ の比較で、オーダーだけを根拠に小さい $n$ でも速さが決まると考える。
- `x in list` を $O(1)$ と見積もる。
