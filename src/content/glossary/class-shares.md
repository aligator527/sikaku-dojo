## 定義

株式会社は、原則としてすべての株式を同じ内容で扱います（株主平等の原則）。ただし、定款で定めれば、次の事項について内容の異なる株式（種類株式）を発行できます。種類株式を発行する会社を種類株式発行会社といいます。

| 事項（第 108 条第 1 項） | 例と使い道 |
| --- | --- |
| 剰余金の配当 | 優先株式（配当を優先して受ける）、劣後株式 |
| 残余財産の分配 | 解散時の分配を優先・劣後させる |
| 議決権制限 | 株主総会の全部または一部の事項で議決権がない株式（無議決権株式） |
| 譲渡制限 | 譲渡に会社の承認を要する株式 |
| 取得請求権付 | 株主が会社に取得を請求できる株式 |
| 取得条項付 | 一定の事由が生じたときに会社が取得できる株式 |
| 全部取得条項付 | 株主総会の特別決議で、その種類の株式の全部を会社が取得できる株式 |
| 拒否権付（黄金株） | 一定の事項について、株主総会の決議のほかに、その種類株主総会の決議を必要とする株式 |
| 取締役・監査役の選任権付 | その種類株主総会で取締役・監査役を選任できる株式（公開会社・指名委員会等設置会社は発行できない） |

## 中小企業での活用

- **事業承継**：後継者に議決権のある株式を集め、他の相続人には無議決権株式や配当優先株式を渡すことで、経営権を安定させつつ財産の分配のバランスをとります。
- **拒否権付種類株式**：先代経営者が一定期間、重要事項への拒否権を持ち、後継者の経営を見守る使い方があります。
- **資金調達**：議決権のない配当優先株式を投資家に発行し、経営への関与を抑えながら資金を集めます。

## 属人的定めとの違い

非公開会社は、種類株式を使わなくても、定款で「株主ごとに」配当・残余財産・議決権について異なる取扱いを定めることができます（属人的定め、第 109 条第 2 項）。これは株式の内容ではなく株主個人に着目した定めで、公開会社では認められません。

## 試験での問われ方

**中小企業診断士試験**の経営法務で、種類株式の内容、公開会社が発行できない種類株式、議決権制限株式の発行限度（公開会社は発行済株式総数の 2 分の 1 まで）、属人的定めとの違い、事業承継での活用が問われます。

## よくある誤り

- 公開会社も取締役・監査役の選任権付種類株式を発行できるとする（非公開会社だけです）。
- 属人的定めを公開会社でも定められるとする。
- 公開会社で議決権制限株式が発行済株式総数の 2 分の 1 を超えても、是正の措置は不要とする（直ちに 2 分の 1 以下にする措置が必要です）。
