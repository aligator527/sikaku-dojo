## 定義

離散型では $p(x, y) = P(X = x,\ Y = y)$（同時確率関数）、連続型では $P((X, Y) \in A) = \iint_A f(x, y)\,dx\,dy$ を満たす $f(x, y) \geq 0$（同時密度関数）で、$X$ と $Y$ の同時分布を表します。離散型の 2 変数なら、行と列に $X$ と $Y$ の値をとった同時確率の表になります。

## 同時分布から分かること

- **周辺分布**：もう一方の変数について足し合わせる（積分する）。$f_X(x) = \int f(x, y)\,dy$。
- **条件付き分布**：$f(y \mid x) = f(x, y)/f_X(x)$。
- **独立性**：すべての $x, y$ で $f(x, y) = f_X(x)f_Y(y)$ なら独立。
- **期待値・共分散**：$E[g(X, Y)] = \iint g(x, y)f(x, y)\,dx\,dy$。

周辺分布だけからは同時分布は決まりません。同じ周辺分布をもつ同時分布は無数にあり、その違いが 2 変数の関係（相関や従属性）です。

## 計算例

$f(x, y) = x + y$（$0 \leq x, y \leq 1$）とします。

- 全体の積分は $1/2 + 1/2 = 1$ で、密度関数の条件を満たす。
- 周辺密度：$f_X(x) = \int_0^1 (x + y)\,dy = x + 1/2$。$Y$ も同じ形。
- $f_X(x)f_Y(y) = (x + 1/2)(y + 1/2) \neq x + y$ なので、$X$ と $Y$ は独立ではない。
- $E[X] = 7/12$、$E[XY] = 1/3$ から $\mathrm{Cov}(X, Y) = 1/3 - (7/12)^2 = -1/144$。
- 対称性から $P(Y < X) = 1/2$。

## 試験での問われ方

統計検定2級では、同時確率の表から周辺確率・条件付き確率・期待値・共分散を求め、独立かどうかを判定する問題が出題されます。準1級・1級では、同時密度関数の定数の決定、領域を指定した確率の重積分、周辺密度・条件付き密度の導出、変数変換による新しい同時密度の計算（ヤコビアンを使う）が中心になります。

## よくある誤り

- 積分範囲を誤る。$0 < x < y < 1$ のように領域が三角形のときは、内側の積分の範囲が外側の変数に依存する。
- 周辺分布だけを見て独立かどうかを判断する。調べるべきは、同時分布が周辺分布の積に等しいかどうか。
- 台（密度が正の領域）が長方形でない場合（例：$0 < x < y$）は、式が積の形に見えても独立ではないことを見落とす。
