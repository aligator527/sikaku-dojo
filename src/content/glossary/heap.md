## 構造

最小ヒープでは、どの節点の値もその子の値以下です。根が全体の最小値になります。完全二分木なので配列に詰めて格納でき、添字を 0 から振ると、

- 添字 $i$ の子：$2i + 1$ と $2i + 2$
- 添字 $i$ の親：$\lfloor (i - 1)/2 \rfloor$

です。木の高さは $\lfloor \log_2 n \rfloor$ です。兄弟の間には大小関係がないので、配列全体が整列しているわけではありません。

## 操作

| 操作 | 方法 | 計算量 |
| --- | --- | --- |
| 最小値の参照 | 根（添字 0）を見る | $O(1)$ |
| 追加 | 末尾に置き、親より小さい間は親と交換して上へ移す | $O(\log n)$ |
| 最小値の取り出し | 根を取り出し、末尾の要素を根に移して、小さい方の子と交換しながら下へ移す | $O(\log n)$ |
| 配列からの構築 | 後ろの節点から順に下へ移す処理を行う | $O(n)$ |

Python の `heapq` モジュールはリストを最小ヒープとして扱い、`heappush`・`heappop` などを提供します。最大ヒープが必要なら、値の符号を反転して入れます。

## 例

空のヒープに 5, 3, 8, 1 の順に追加すると、配列は $[5] \to [3, 5] \to [3, 5, 8] \to [1, 3, 8, 5]$ となります（1 を末尾に置くと親 5 より小さいので交換、さらに親 3 より小さいので交換）。ここで最小値を取り出すと 1 が返り、配列は $[3, 5, 8]$ になります。

## 使い道

- **優先度付きキュー**：処理待ちのジョブを優先度の高い順に取り出す。ダイクストラ法で、暫定距離が最小の頂点を取り出す。
- **ヒープソート**：全要素を入れて順に取り出すと $O(n \log n)$ で整列できる。
- **上位 $k$ 件**：大きさ $k$ の最小ヒープに保持しながら走査すると、$O(n \log k)$ で上位 $k$ 件が求まる。

## 試験での問われ方

統計検定データサイエンスエキスパートでは、`heapq` で要素を追加・取り出ししたあとのリストの中身や、取り出される順序をたどる問題、各操作の計算量が出ます。

## よくある誤り

- ヒープの配列が昇順に整列していると考える（保証されるのは親子の大小だけ）。
- 最小値の取り出しが $O(1)$ だと考える（参照は $O(1)$、取り出しは並べ直しが必要で $O(\log n)$）。
