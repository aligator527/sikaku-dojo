## 定義と性質

無差別曲線は、横軸に財 X、縦軸に財 Y の消費量をとり、効用が等しくなる組合せを結んだ曲線です。通常の選好のもとでは次の性質をもちます。

1. 右下がり（一方を減らしたら他方を増やさないと同じ満足を保てない）。
2. 原点から遠いほど効用が高い。
3. 互いに交わらない。
4. 原点に対して凸（限界代替率が逓減する）。

無差別曲線の傾きの絶対値を **限界代替率（MRS）** といい、X を 1 単位増やすときに同じ効用を保つために諦めてもよい Y の量を表します。これは X と Y の限界効用の比 $MU_x/MU_y$ に等しくなります。

## 効用最大化

所得 $I$ をすべて 2 財に使うときの **予算制約線** は $p_x x + p_y y = I$ で、傾きの絶対値は価格比 $p_x/p_y$ です。効用が最大になるのは、予算制約線と無差別曲線が接する点で、

$$
MRS_{xy} = \frac{MU_x}{MU_y} = \frac{p_x}{p_y}
$$

が成り立ちます（加重限界効用均等の法則 $MU_x/p_x = MU_y/p_y$ と同じ意味です）。

### 計算例

効用関数 $u = xy$、所得 200、$p_x = 5$、$p_y = 2$ のとき、$MRS = y/x$ なので $y/x = 5/2$。これを予算制約 $5x + 2y = 200$ に代入すると $x = 20$、$y = 50$ です。$u = xy$ の形では、所得の半分ずつを各財に使う（$x = I/(2p_x)$、$y = I/(2p_y)$）ことになります。

## 価格・所得の変化

- **所得の変化**：予算制約線が平行移動します。最適点の軌跡が所得消費曲線で、財が上級財か下級財かで向きが変わります。
- **価格の変化**：予算制約線の傾きが変わります。最適点の変化は代替効果と所得効果に分けて考えます。

## 試験での問われ方

**中小企業診断士試験**の経済学・経済政策で、効用関数と予算から最適な消費量を求める計算、無差別曲線の形（完全代替財・完全補完財など）と最適点、価格変化の効果の分解がグラフで問われます。

## よくある誤り

- 限界代替率を価格比の逆数と等しくしてしまう（$MRS = p_x/p_y$ です）。
- 無差別曲線同士が交わる図を正しいとする。
- 予算制約線の傾きを $p_y/p_x$ とする。
