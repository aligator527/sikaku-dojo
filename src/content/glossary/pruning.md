## 手順

1. モデルを通常どおり学習する。
2. 重要度の低い重み（またはチャネル・層）を選んで 0 にする（削除する）。最も簡単な基準は重みの絶対値の小ささです。
3. 残った重みで再学習（ファインチューニング）し、精度を回復させる。
4. 必要なら 2〜3 を繰り返し、少しずつ削除する割合を増やす（反復的プルーニング）。

一度に大量に削ると精度が大きく落ちるので、少しずつ削っては再学習する方が高い圧縮率を達成しやすくなります。

## 非構造化と構造化

| | 非構造化プルーニング | 構造化プルーニング |
| --- | --- | --- |
| 単位 | 個々の重み | チャネル（フィルタ）、ヘッド、層など |
| 結果 | 疎な（0 の多い）重み行列 | 小さな密な行列 |
| 圧縮率 | 高くしやすい | 比較的低い |
| 実際の高速化 | 疎行列演算の対応がないと出にくい | 通常の GPU・CPU でそのまま速くなる |

非構造化プルーニングで重みの 90% を 0 にしても、行列の形は変わらないので、疎行列を効率よく扱える仕組みがなければ計算時間はあまり減りません。チャネル単位で削れば、層の形そのものが小さくなります。チャネルの重要度には、フィルタの重みのノルムや Batch Normalization のスケール $\gamma$ の大きさが使われます。

## 宝くじ仮説

大きなネットワークの中には、最初の初期値のまま単独で学習しても同程度の精度に達する小さな部分ネットワーク（当たりくじ）が含まれている、という仮説（lottery ticket hypothesis）があります。プルーニングで見つけた構造を元の初期値に戻して学習し直すことで、その存在が実験的に示されました。

## 正則化との関係

L1 正則化は重みを 0 に近づけて疎にするので、プルーニングしやすいモデルを作るのに役立ちます。ドロップアウトは学習中に一時的にユニットを無効にするだけで、推論時のモデルは小さくならない点がプルーニングと異なります。

## 試験での問われ方

E資格（シラバス 2026 のモデルの軽量化：プルーニング（枝刈り）、蒸留、量子化）では、手順と再学習の必要性、非構造化と構造化の違い（実際に速くなるかどうか）、重要度の基準、ほかの軽量化手法との違いが出題されます。

## よくある誤り

- 非構造化プルーニングで 0 にした重みの割合だけ、推論時間が必ず短くなると考える。
- 削除した後は再学習しなくても精度が保たれると考える。
- ドロップアウトとプルーニングを同じものだと考える（ドロップアウトは学習時だけの一時的な無効化）。
