## 保全活動の体系

| 区分 | 保全の方式 | 内容 |
| --- | --- | --- |
| 維持活動 | 予防保全 | 故障する前に、計画的に点検・整備・交換を行う |
| | 　時間基準保全（定期保全） | 稼働時間や期間などをもとに、一定周期で行う |
| | 　状態基準保全（予知保全） | 振動・温度などのデータで劣化の状態を監視し、故障の兆候が現れたときに行う |
| | 事後保全 | 故障してから修理する。故障しても影響が小さい設備では、こちらの方が経済的なことがある |
| 改善活動 | 改良保全 | 今使っている設備の弱点を改良して、故障しにくく、保全しやすくし、寿命を延ばす |
| | 保全予防 | 新しい設備の計画・設計の段階から、故障しにくく保全しやすい設備にする |

## 方式の選び方

- 故障すると生産全体が止まる、安全や品質への影響が大きい設備は、予防保全を重視します。
- 交換部品が安く、故障の影響が小さい設備は、事後保全（計画的な事後保全）の方が費用を抑えられます。
- IoT センサーで設備の状態をリアルタイムに監視できるようになり、必要なときだけ保全を行う予知保全の活用が広がっています。

## TPM との関係

TPM（全員参加の生産保全）は、設備総合効率を最大にすることを目標に、オペレーターによる自主保全を含めて全員で設備の保全に取り組む活動です。設備総合効率を低下させる故障・段取り調整・速度低下・不良などのロスを洗い出して減らします。

## 試験での問われ方

- **中小企業診断士試験**：運営管理の設備管理で、改良保全と保全予防、時間基準保全と状態基準保全の説明を入れ替えた正誤問題が出題されます。
- **ITストラテジスト試験**：IoT を活用した予知保全（設備の稼働データを使った故障の予兆検知）が、事例の題材として登場します。

## よくある誤り

- 保全予防と改良保全を取り違える（今ある設備を改良するのが改良保全、設計段階から故障しにくくするのが保全予防）。
- 予知保全を、一定周期で部品を交換する方式とする（それは時間基準保全です）。
- 事後保全はどんな設備でも予防保全より劣るとする。
