## 定義

真のモデルが $y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + u$（$E[u \mid x_1, x_2] = 0$）なのに、$x_2$ を除いて $y$ を $x_1$ だけに回帰すると、$x_2$ の影響が誤差に入り、$x_1$ と誤差が相関します。そのときの係数の確率極限は上の式で、$\beta_2\,\mathrm{Cov}(x_1, x_2)/V[x_1]$ が偏りです。これは「$x_2$ を $x_1$ に回帰したときの傾き $\delta$」を使って $\beta_1 + \beta_2\delta$ とも書けます。

## 偏りの向き

偏りの符号は、欠落変数の係数 $\beta_2$ の符号と、$x_1$ と $x_2$ の相関の符号の積で決まります。

| | $\mathrm{Corr}(x_1, x_2) > 0$ | $\mathrm{Corr}(x_1, x_2) < 0$ |
| --- | --- | --- |
| $\beta_2 > 0$ | 上向き（過大） | 下向き（過小） |
| $\beta_2 < 0$ | 下向き（過小） | 上向き（過大） |

偏りが生じないのは、$\beta_2 = 0$（$x_2$ が $y$ に影響しない）か、$x_1$ と $x_2$ が無相関の場合だけです。

## 計算例

賃金の対数 $y$ を教育年数 $x_1$ と能力 $x_2$ で説明する式で $\beta_1 = 0.10$、$\beta_2 = 0.04$、$V[x_1] = 4$、$\mathrm{Cov}(x_1, x_2) = 0.8$ とします。能力を観測できず教育年数だけで回帰すると

$$\operatorname*{plim}\hat{\beta}_1 = 0.10 + 0.04 \times \frac{0.8}{4} = 0.108$$

となり、教育の効果を 8% 過大に見積もります（能力バイアス）。

## 対処法

- 欠落変数（またはその代理変数）を観測してモデルに加える。
- パネルデータで、時間によらない欠落変数を固定効果推定や一階差分で取り除く。
- 操作変数法、ランダム化実験、差の差法などで識別する。

統計的因果推論の言葉では、欠落変数が $x_1$ と $y$ の両方に影響するとき、それは交絡因子であり、欠落変数バイアスは交絡による偏りの回帰モデルでの表現です。

## 試験での問われ方

統計検定1級（社会科学）では、確率極限の式の導出と数値計算、偏りの向きの判断、パネルデータの固定効果推定で偏りが消える理由が問われます。準1級・2級では、重回帰と単回帰で係数が変わる理由や、交絡の例として出題されます。

## よくある誤り

- 説明変数を増やせば偏りが必ず減ると考える。結果変数の影響を受ける変数（中間変数や合流点）を入れると、かえって偏りが生じます。
- 偏りの式の分母を $V[x_2]$ にする（分母は残した変数 $x_1$ の分散）。
- 標本サイズを大きくすれば偏りが消えると考える（一致性の問題なので消えません）。
