## 定義

方策 $\pi$ のもとで

- **状態価値関数**：$V^\pi(s) = E_\pi[G_t \mid s_t = s]$（状態 $s$ からの収益の期待値）
- **行動価値関数**：$Q^\pi(s, a) = E_\pi[G_t \mid s_t = s,\ a_t = a]$（状態 $s$ で行動 $a$ をとってからの収益の期待値）

です。両者は $V^\pi(s) = \sum_a \pi(a \mid s)\,Q^\pi(s, a)$ の関係にあります。たとえば 2 つの行動の Q 値が $1$ と $2$ で、方策がそれぞれを確率 $0.3$、$0.7$ で選ぶなら、$V^\pi(s) = 0.3 \times 1 + 0.7 \times 2 = 1.7$ です。差 $A(s, a) = Q(s, a) - V(s)$ をアドバンテージといい、この例では $-0.7$ と $0.3$ になります。

## ベルマン方程式

収益は「すぐの報酬 + 割り引いた次の時点からの収益」と再帰的に書けるので、価値関数は次の関係を満たします。

$$Q^\pi(s, a) = E\left[r + \gamma\,V^\pi(s') \mid s, a\right]$$

最適な方策のもとでの行動価値 $Q^\ast$ は、次のベルマン最適方程式を満たします。

$$Q^\ast(s, a) = E\left[r + \gamma\max_{a'}Q^\ast(s', a') \,\middle|\, s, a\right]$$

$Q^\ast$ が分かれば、各状態で $Q^\ast(s, a)$ が最大の行動を選ぶことが最適な方策になります。Q 学習や DQN は、この方程式を満たすように $Q$ を近似していく方法です。

## 表現のしかた

- **Q テーブル**：状態と行動が少ないときは、すべての組の値を表に持ちます。
- **関数近似**：状態が画像のように膨大・連続な場合は、ニューラルネットワーク $Q(s, a; \theta)$ で近似します（DQN）。DQN は状態を入力して全行動の Q 値をまとめて出力します。

## 試験での問われ方

E資格（シラバス 2026 の DQN のキーワード：行動価値関数）や統計検定データサイエンスエキスパートでは、状態価値と行動価値の関係、ベルマン方程式による価値の計算、最適な行動の選び方、アドバンテージの意味が出題されます。

## よくある誤り

- 状態価値関数と行動価値関数を混同する（行動価値は最初の行動を固定する）。
- 価値関数を、その時点の報酬 $r$ だけの期待値と考える（将来の割引報酬の和の期待値）。
- 方策を確率的にとるときも、$V(s)$ を Q 値の最大値で計算する（$V^\pi$ は方策による加重平均。最大値になるのは最適な方策のとき）。
