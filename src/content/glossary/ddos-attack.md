## 定義

DoS 攻撃（サービス妨害攻撃）は、処理能力や回線の容量を超える通信を標的に送り付けたり、処理に時間のかかる要求を繰り返したりして、正規の利用者がサービスを使えない状態にする攻撃です。これを多数の機器から同時に行うものを DDoS 攻撃（分散型サービス妨害攻撃）といいます。情報セキュリティの 3 要素のうち、主に**可用性**を損なう攻撃です。

## 主な手口

| 手口 | 内容 |
| --- | --- |
| ボットネットによる攻撃 | マルウェアに感染して遠隔操作される多数の機器（ボット）から、一斉に大量の通信を送る。初期設定のパスワードのままの IoT 機器が乗っ取られやすい |
| リフレクション攻撃（アンプ攻撃） | 送信元のアドレスを標的に偽装した問合せを、DNS などのサーバに多数送り、増幅された大きな応答を標的に集中させる |
| DNS 水責め攻撃 | 存在しないサブドメイン名を大量に問い合わせて、権威 DNS サーバに負荷をかける |
| アプリケーション層への攻撃 | Web ページの要求など、正常に見える要求を大量に送る |

## 主な対策

- 通信事業者や CDN 事業者が提供する DDoS 対策サービスを使い、攻撃の通信を手前で吸収・遮断する。
- 単位時間当たりの要求数を制限する。サーバやネットワークに余裕をもたせる。
- 自組織の DNS サーバをオープンリゾルバにしない、送信元を偽装したパケットを外へ出さないなど、踏み台にされないようにする。
- IoT 機器の初期パスワードを変更する。国の取組 NOTICE では、推測されやすいパスワードの IoT 機器を調べ、ISP を通じて利用者に注意を促しています。

## 試験での問われ方

- **ITストラテジスト試験**：科目A-2 で、ボットネットによる攻撃や DNS リフレクション攻撃が、XSS や DNS 水責め攻撃を問う問題の選択肢として出てきます。IoT 機器の悪用を防ぐ NOTICE の取組も出題されています。

## よくある誤り

- DDoS 攻撃を、情報を盗み出す攻撃だと考える。主な目的はサービスの妨害（可用性の侵害）です。
- 攻撃元の IP アドレスを遮断すれば防げると考える。攻撃元は多数で、送信元が偽装されていることもあります。
