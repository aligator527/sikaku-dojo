## 定義

データでは、標準化得点 $z_i = (x_i - \bar{x})/s$ の 3 乗の平均を歪度といいます（$s$ は $n$ で割る標準偏差。標本サイズによる補正を加えた定義もあります）。確率分布では、平均まわりの 3 次モーメントを $\sigma^3$ で割った $\gamma_1 = E[(X - \mu)^3]/\sigma^3$ です。

## 直感的な意味

偏差を 3 乗すると符号が残り、大きな偏差ほど強調されます。右側に平均から大きく離れた値があると正の項が支配的になり、歪度は正になります。

| 歪度 | 分布の形 | 代表値の並びの傾向 |
| --- | --- | --- |
| 正 | 右に裾が長い（所得、待ち時間など） | 最頻値 < 中央値 < 平均値 |
| 0 | 左右対称（正規分布、一様分布など） | ほぼ等しい |
| 負 | 左に裾が長い（易しい試験の得点など） | 平均値 < 中央値 < 最頻値 |

## 分布の例

- 正規分布：0
- 指数分布：2（率 $\lambda$ によらず一定）
- ポアソン分布 $Po(\lambda)$：$1/\sqrt{\lambda}$（$\lambda$ が大きいほど対称に近づく）
- 二項分布 $B(n, p)$：$(1 - 2p)/\sqrt{np(1-p)}$（$p = 0.5$ で 0）

## 性質

- 1 次変換 $y = a + bx$ で、$b > 0$ なら歪度は変わらず、$b < 0$ なら符号が反転する。
- 分布の形そのものの指標なので、標準化しても変わらない。
- 歪度が 0 でも左右対称とは限らない（3 次モーメントがたまたま打ち消し合う非対称分布もある）。

## 試験での問われ方

統計検定2級では、定義式を与えたうえで、ヒストグラムと歪度の符号の対応、1 次変換による変化、平均値・中央値との関係を問う記述の正誤問題が出題されます。準1級・1級では、モーメント母関数やキュムラントから分布の歪度を求める計算、正規近似の精度との関係が問われます。

## よくある誤り

- 「右に裾が長い」を「山が右に寄っている」と取り違え、符号を逆にする。右に裾が長い分布では山は左寄りで、歪度は正。
- 符号を反転させる 1 次変換（$b < 0$）で歪度が変わらないと考える。
- 歪度が 0 であることから正規分布であると結論する。
