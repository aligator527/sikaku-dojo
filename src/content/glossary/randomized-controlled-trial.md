## 仕組み

対象者を乱数などで処置群（新しい治療・施策）と対照群（標準治療・プラセボ・現状のまま）に割り付け、一定期間後の結果を比べます。割り付けが偶然で決まるので、年齢や重症度など、観測しているかどうかにかかわらず全ての背景因子が両群で平均的に等しくなります。したがって、群間の結果の差を処置の効果とみなせます。観察研究に比べて交絡の影響を排除できる点が最大の強みで、医薬品の承認や政策評価で最も信頼性の高い証拠とされます。

## 偏りを防ぐ工夫

| 工夫 | 防ぐもの |
| --- | --- |
| 無作為割り付け | 処置の選ばれ方による交絡 |
| 割り付けの隠蔽 | 割り付けを予想した登録の操作 |
| 盲検化（二重盲検） | 期待による反応の違い（プラセボ効果）、評価の偏り |
| 層別・ブロック無作為化 | 重要な背景因子の偶然の偏り、群の人数の偏り |
| ITT 解析 | 脱落や治療の変更による群の比較可能性の崩れ |
| 事前の計画（主要評価項目・サンプルサイズ・解析法） | 多重性、結果を見てからの解析の選択 |

## 限界

- 費用と時間がかかり、倫理的に割り付けられない要因（喫煙など）には使えない。
- 参加者が限られた条件の人だけだと、結果を一般の人に当てはめられるか（外的妥当性）が問題になる。
- 割り付け後の脱落や不遵守があると、無作為化の利点が一部失われる。

データサイエンスの分野では、ウェブサイトの 2 つの案を利用者に無作為に表示して比べる A/B テストも、同じ考え方に基づくランダム化実験です。

## 試験での問われ方

統計検定2級では、研究デザインの説明からランダム化比較試験を見分け、無作為化の目的（交絡の除去）や観察研究との違いを問う問題が出ます。1級の医薬生物学分野では、サンプルサイズの設計、ITT 解析と PP 解析の違い、非劣性試験、層別無作為化、中間解析の多重性が問われます。データサイエンスエキスパートでは A/B テストの設計と解釈が出題されます。

## よくある誤り

- 対象者を母集団から無作為に抽出することと、処置を無作為に割り付けることを混同する。
- 無作為化すれば、個々の試験で両群の背景因子が必ず一致すると考える。
- 割り付け後に、実際に治療を受けた人だけで比べても偏りはないと考える。
