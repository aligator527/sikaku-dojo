## 定義

ビジネスモデルキャンバスは、A. オスターワルダーと Y. ピニュールが示した、ビジネスモデルを可視化するための枠組みです。次の九つのブロックを 1 枚のキャンバスに配置し、要素どうしのつながりを確かめながら検討します。

| ブロック | 問い |
| --- | --- |
| 顧客セグメント | 誰に価値を提供するか |
| 価値提案 | 顧客のどの課題を解決し、どんな価値を提供するか |
| チャネル | どの経路で価値を届けるか |
| 顧客との関係 | 顧客とどのような関係を築き、維持するか |
| 収益の流れ | 顧客は何に対して、どのように支払うか |
| リソース | 価値提案に必要な主要な経営資源は何か |
| 主要活動 | 価値を生み出すために行う重要な活動は何か |
| パートナー | 外部の誰と協力するか |
| コスト構造 | 主なコストは何か |

中央の価値提案と右側の四つ（顧客セグメント・チャネル・顧客との関係・収益の流れ）が価値と収益の側、左側の四つ（リソース・主要活動・パートナー・コスト構造）が効率とコストの側を表します。

## 使いどころ

- 既存事業のビジネスモデルを整理し、デジタル技術で変えられる要素を探す。
- 新規事業やプラットフォーム型ビジネスの構想で、複数の顧客セグメント（例：利用者と出店者）ごとの価値提案と収益の流れを検討する。

## 試験での問われ方

- **ITストラテジスト試験**：午前II で、システム化構想の段階でビジネスモデルを整理・分析するフレームワークとして出題されました。選択肢には、バリューチェーン分析（主活動と支援活動）、SWOT 分析、バランススコアカード（四つの視点）の説明が並び、ブロックの数と内容で見分けます。

## よくある誤り

- 主活動・支援活動で業務を分類するバリューチェーンと混同する。
- 九つのブロックを個別に埋めるだけで、価値提案と顧客セグメント、収益の流れとコスト構造の整合を確かめない。
