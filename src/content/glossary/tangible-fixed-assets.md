## 定義

有形固定資産は、販売目的ではなく、長期間にわたって営業に使うために保有する、形のある資産です。主な勘定科目は次のとおりです。

| 勘定 | 例 | 減価償却 |
| --- | --- | --- |
| 建物 | 店舗・事務所・倉庫 | する |
| 構築物 | 塀・舗装・看板の支柱など | する |
| 機械装置 | 製造用の機械 | する |
| 車両運搬具 | トラック・営業用の自動車 | する |
| 備品 | 机・パソコン・陳列棚など | する |
| 土地 | 店舗の敷地など | しない |
| 建設仮勘定 | 建設中の建物への支払額 | しない（完成後に振り替える） |

## 取得から処分まで

- **取得**：取得原価 ＝ 購入代価 ＋ 付随費用（仲介手数料、登記料、引取運賃、据付費など）。
- **使用中**：決算ごとに減価償却を行い、取得原価を耐用年数にわたって費用配分します。
- **処分**：売却したときは帳簿価額との差額を固定資産売却損益、使用をやめたときは除却・廃棄として処理します。

## 資本的支出と収益的支出（2級）

取得後に支出した工事代などは、資産の価値を高めたり耐用年数を延ばしたりする部分（資本的支出）を固定資産の取得原価に加え、現状を維持するための部分（収益的支出）を修繕費とします。

建物の改修工事に ￥1,000,000 を支払い、うち ￥700,000 は耐用年数を延長させる改良と判断された。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 建物 | 700,000 | 普通預金 | 1,000,000 |
| 修繕費 | 300,000 | | |

## 試験での問われ方

日商簿記では、3級から1級まで取得・減価償却・売却の流れが繰り返し出題されます。2級では割賦購入、圧縮記帳、建設仮勘定、資本的支出、1級では減損会計や資産除去債務が加わります。中小企業診断士の財務・会計では、貸借対照表の区分や、キャッシュ・フロー計算書の投資活動の区分（有形固定資産の取得・売却による支出・収入）として問われます。

## よくある誤り

- 土地を減価償却してしまう。
- 付随費用を取得原価に含めず、支払手数料などの費用にする。
- 改良（資本的支出）にあたる支出まで修繕費として処理する。
