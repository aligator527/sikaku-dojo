## 定義

輸出入などで外国通貨建ての取引を行った場合、帳簿は円で記録するため、為替相場で円に換算します（「外貨建取引等会計処理基準」）。

| 時点 | 換算に使う相場 |
| --- | --- |
| 取引発生時 | 取引発生時の為替相場（HR） |
| 決算時：貨幣項目（外国通貨、外貨預金、外貨建ての売掛金・買掛金・貸付金・借入金など） | 決算時の為替相場（CR）で換算し直す |
| 決算時：非貨幣項目（前払金・前受金、商品、固定資産など） | 換算し直さない（取得時の円額のまま） |
| 決済時 | 決済時の為替相場 |

換算によって生じた差額は為替差損益とし、損益計算書では差益と差損を相殺した純額を営業外収益または営業外費用に表示します。

## 仕訳例

商品 1,000ドルを掛けで輸入した。取引時の為替相場は 1ドル ＝ ￥140 である。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 仕入 | 140,000 | 買掛金 | 140,000 |

決算日の為替相場は 1ドル ＝ ￥145 である。買掛金を換算し直す。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 為替差損益 | 5,000 | 買掛金 | 5,000 |

翌期、1ドル ＝ ￥143 のときに普通預金口座から決済した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 買掛金 | 145,000 | 普通預金 | 143,000 |
| | | 為替差損益 | 2,000 |

## 前払金がある場合

輸入の前に手付金 200ドルを 1ドル ＝ ￥138 で支払っていた（前払金 27,600円）場合、商品 1,000ドルを受け取ったとき（1ドル ＝ ￥140）の仕入額は、前払金部分は支払時の円額のまま、残額 800ドルは受取時の相場で換算します。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 仕入 | 139,600 | 前払金 | 27,600 |
| | | 買掛金 | 112,000 |

## 試験での問われ方

日商簿記2級の第1問や決算整理で、取引時・決算時・決済時の換算が出題されます。1級では外貨建有価証券の換算、在外支店・在外子会社の財務諸表の換算、為替予約のヘッジ会計まで扱います。

## よくある誤り

- 決算時に前払金・商品などの非貨幣項目まで換算し直す。
- 決済時に、決算で換算替えした後の帳簿価額ではなく取引時の金額を取り崩す。
- 為替差益と為替差損を両建てで表示する（純額で表示）。
