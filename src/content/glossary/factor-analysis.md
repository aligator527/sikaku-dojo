## モデル

$p$ 個の観測変数 $\mathbf{x}$ が、$m\ (< p)$ 個の共通因子 $\mathbf{f}$ と独自因子 $\boldsymbol{\varepsilon}$ で

$$x_j = \mu_j + \lambda_{j1}f_1 + \cdots + \lambda_{jm}f_m + \varepsilon_j\qquad (j = 1, \ldots, p)$$

と表されるとします。$\lambda_{jk}$ が因子負荷量で、$\mathbf{f}$ は平均 0・分散共分散行列 $I$（直交因子）、$\varepsilon_j$ は互いに無相関で $\mathbf{f}$ とも無相関、分散 $\psi_j$ とします。このとき分散共分散行列は

$$\Sigma = \Lambda\Lambda^\top + \Psi,\qquad \Psi = \mathrm{diag}(\psi_1, \ldots, \psi_p)$$

となり、変数どうしの共分散はすべて共通因子だけで説明されます。標準化した変数では $1 = h_j^2 + \psi_j$（共通性 + 独自分散）です。

## 1 因子モデルの例

標準化した 3 変数の相関が $r_{12} = 0.48$、$r_{13} = 0.42$、$r_{23} = 0.56$ で 1 因子モデルが成り立つなら、$r_{jk} = \lambda_j\lambda_k$ なので

$$\lambda_1^2 = \frac{r_{12}r_{13}}{r_{23}} = 0.36\ \Rightarrow\ \lambda_1 = 0.6,\qquad \lambda_2 = 0.8,\qquad \lambda_3 = 0.7$$

で、共通性は 0.36、0.64、0.49、独自分散は 0.64、0.36、0.51 です。

## 推定と因子数の決め方

- **推定法**：主因子法（共通性の初期値を入れた相関行列の固有値分解を繰り返す）、最尤法（正規分布を仮定）、最小二乗法。
- **因子数**：相関行列の固有値が 1 を超える数（カイザー基準）、スクリープロットで固有値の減り方が緩やかになる手前、最尤法での適合度の尤度比検定、AIC・BIC。
- **適合度検定の自由度**：$\{(p - m)^2 - (p + m)\}/2$。例：$p = 6,\ m = 2$ なら $(16 - 8)/2 = 4$。自由度が正でないと、モデルはデータに制約を課さない。

## 回転の不定性

任意の直交行列 $T$ について $\Lambda T$ も同じ $\Sigma$ を与えるので、因子負荷量は回転の分だけ一意に決まりません。そこで解釈しやすい単純構造になるように因子回転（バリマックス、プロマックスなど）を行います。

## 主成分分析との違い

| | 主成分分析 | 因子分析 |
|---|---|---|
| 目的 | 変数の情報を少数の合成変数に要約する | 変数の相関の背後にある潜在因子を想定する |
| モデル | 誤差の項をもたない（変数の線形結合） | 変数を因子の線形結合 + 独自因子で表す |
| 分解するもの | 分散全体 | 共通の部分（共通性）だけ |

探索的因子分析は因子の構造を探るもの、確認的因子分析は仮説として決めた構造（どの変数がどの因子に負荷するか）をデータで検証するもので、後者は構造方程式モデリングの一部です。

## 試験での問われ方

統計検定準1級では、因子負荷量から共通性・独自分散・因子の寄与を計算する問題、1 因子モデルで相関から負荷量を求める問題、適合度検定の自由度、回転の性質が出ます。1級（人文）では、因子数の決め方や確認的因子分析、尺度の信頼性と組み合わせた記述問題が出題されます。

## よくある誤り

- 主成分分析と因子分析を同じものとして扱う。
- 回転によって共通性や適合度が変わると考える（回転しても $\Sigma$ の再現は同じなので変わらない）。
- 因子の意味（名前）がデータから自動的に決まると考える（負荷量のパターンを見て分析者が解釈する）。
