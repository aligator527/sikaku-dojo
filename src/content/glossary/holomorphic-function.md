## 定義とコーシー・リーマンの関係式

複素関数 $f(z)$ が領域 $D$ の各点で

$$f'(z) = \lim_{h\to0}\frac{f(z + h) - f(z)}{h}\quad(h \text{ は複素数})$$

をもつとき、$f$ は $D$ で**正則**であるといいます。複素平面全体で正則な関数を**整関数**といいます。

$f = u + iv$（$z = x + iy$）と書くと、正則であることは、$u, v$ が全微分可能で**コーシー・リーマンの関係式**

$$u_x = v_y,\qquad u_y = -v_x$$

を満たすことと同値です。このとき $f'(z) = u_x + iv_x$ です。例えば $z^2 = (x^2 - y^2) + i\,2xy$ は満たし、$\bar{z} = x - iy$ は $u_x = 1 \ne v_y = -1$ で満たしません。

## 正則関数の性質

- **調和性**：$u, v$ はラプラス方程式 $u_{xx} + u_{yy} = 0$ を満たします（調和関数）。$v$ を $u$ の共役調和関数といい、$u$ から関係式を積分して求められます。
- **コーシーの積分定理**：単連結な領域内の閉曲線 $C$ について $\oint_C f(z)\,dz = 0$。
- **コーシーの積分公式**：$C$ の内部の点 $a$ で $f(a) = \dfrac{1}{2\pi i}\oint_C\dfrac{f(z)}{z - a}dz$、さらに $f^{(n)}(a) = \dfrac{n!}{2\pi i}\oint_C\dfrac{f(z)}{(z - a)^{n+1}}dz$。したがって正則関数は何回でも微分でき、各点のまわりでテイラー展開できます。
- **リウヴィルの定理**：有界な整関数は定数。ここから代数学の基本定理が導かれます。
- **一致の定理**・**最大値の原理**：領域内の集積点をもつ集合で一致する 2 つの正則関数は全体で一致し、$|f|$ は領域の内部で最大値をとりません（定数関数を除く）。

## 計算例

$\displaystyle\oint_{|z|=2}\frac{e^z}{z - 1}\,dz$ は、$e^z$ が正則で $z = 1$ が円の内部にあるので、積分公式から $2\pi i\,e$ です。

## 試験での問われ方

数検1級では、コーシー・リーマンの関係式から正則性を判定する、調和関数 $u$ から共役調和関数 $v$ と $f$ を求める、リウヴィルの定理やその応用を証明する、コーシーの積分公式で積分を計算する問題が出ます。

## よくある誤り

- コーシー・リーマンの関係式の第 2 式の符号を逆にする（$u_y = -v_x$）。
- 一点で関係式を満たすだけで、その点の近くで正則だと考える。$|z|^2$ は原点でだけ複素微分可能で、どこでも正則ではありません。
- 被積分関数が曲線の内部に特異点をもつのに、コーシーの積分定理で 0 とする。
