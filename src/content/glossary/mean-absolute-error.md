## 定義

MAE は誤差の大きさを目的変数と同じ単位で表す指標です。誤差を 2 乗しないので、1 件の大きな誤差が全体を支配しにくくなります。

相対的な誤差を見る指標として MAPE（平均絶対パーセント誤差）もあり、売上や需要の予測でよく使われます。

## 計算例

5 件の予測誤差が $1, -2, 0, 3, -2$ のとき、$\mathrm{MAE} = (1 + 2 + 0 + 3 + 2)/5 = 1.6$ です。同じデータの RMSE は約 1.90 です。

## MSE・RMSE との比較

- 常に $\mathrm{MAE} \leq \mathrm{RMSE}$ で、誤差の大きさがそろっているほど両者は近づきます。RMSE が MAE よりずっと大きいときは、一部に大きな誤差があります。
- 予測値を定数にする場合、MAE を最小にするのは中央値、MSE を最小にするのは平均値です。分布の裾が重いデータや外れ値の多いデータでは MAE が向きます。
- MAE を損失関数として学習する（最小絶対偏差回帰）と、条件付き中央値を推定することになります。絶対値は 0 で微分できないため、勾配法では劣勾配や滑らかな近似（Huber 損失など）を使います。

## MAPE の注意

MAPE は実測値で割るので、実測値が 0 のデータでは定義できず、0 に近い値があると極端に大きくなります。また、実測値を下回る予測の誤差は（予測値が 0 以上なら）最大でも 100% にとどまる一方、上回る予測の誤差には上限がないため、MAPE を最小にしようとすると過小な予測に偏りやすくなります。

## 試験での問われ方

統計検定データサイエンスエキスパートとE資格では、予測結果の表から MAE・RMSE を計算し、外れ値があるときにどちらが大きく変わるかを比べる問題、どの統計量が各損失を最小にするかを問う問題が出ます。

## よくある誤り

- MAE を最小にする定数予測を平均値と答える（中央値が正しい）。
- 実測値に 0 を含むデータで MAPE を使う。
