## 定義

待ち行列理論は、銀行の ATM、コールセンター、サーバへの処理要求などのように、客が不規則に到着し、窓口でサービスを受けるまで並んで待つ状況を確率モデルで表す理論です。モデルは「到着の分布 / サービス時間の分布 / 窓口の数」の記号（ケンドール記号）で表します。

**M/M/1** は、到着がランダム（ポアソン到着、到着間隔が指数分布）、サービス時間が指数分布、窓口が 1 つのモデルです。

## M/M/1 の公式

平均到着率を $\lambda$、平均サービス時間を $T_s$ とします。

| 量 | 式 |
| --- | --- |
| 利用率 | $\rho = \lambda T_s$（$\rho < 1$ が前提） |
| 平均待ち時間（サービス時間を含まない） | $W_q = \dfrac{\rho}{1-\rho}\,T_s$ |
| 平均応答時間（待ち時間＋サービス時間） | $W = \dfrac{1}{1-\rho}\,T_s$ |
| 系内の平均人数 | $L = \dfrac{\rho}{1-\rho}$ |

## 計算例

平均 4 分に 1 人（$\lambda = 0.25$ 人/分）が到着し、平均サービス時間が 3 分なら、$\rho = 0.75$、$W_q = 0.75 / 0.25 \times 3 = 9$ 分、$W = 3 / 0.25 = 12$ 分です。到着が増えて $\rho = 0.9$ になると、$W_q = 0.9 / 0.1 \times 3 = 27$ 分と 3 倍になります。利用率が 1 に近づくと、待ち時間は急激に長くなります。

## 試験での問われ方

- **ITストラテジスト試験**：科目A-1 で、2 台の ATM を 1 台に統合したときの平均待ち時間の式を選ぶ問題が出題されています。利用者数（到着率）が 2 倍になると利用率も $2\rho$ になり、それを公式の分子と分母の両方に当てはめます。
- **統計検定準1級**：ポアソン過程の応用として、待ち行列のモデルで系内の人数の分布を求める問題が出てきます。

## よくある誤り

- 平均待ち時間 $W_q$ と、サービス時間を含む平均応答時間 $W$ を取り違える。問題文が「サービス時間を含まない」かどうかを確認します。
- 窓口を統合したとき、分子か分母の一方だけの利用率を変える。
- 利用率が 1 以上（処理能力を超える到着）でも公式が使えると考える。その場合、行列は限りなく長くなります。
