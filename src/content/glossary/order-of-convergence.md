## 定義

反復法で得られる近似値の列 $x_n$ が解 $\alpha$ に収束するとき、誤差 $e_n = x_n - \alpha$ について

$$\lim_{n\to\infty}\frac{|e_{n+1}|}{|e_n|^p} = C\quad(0 < C < \infty)$$

となる $p$ を**収束次数**といいます。

- $p = 1$（$0 < C < 1$）：**1 次収束**。誤差は毎回ほぼ $C$ 倍になり、正しい桁数は一定のペースで増えます。$C$ を収束率といいます。
- $p = 2$：**2 次収束**。誤差がほぼ 2 乗になり、正しい桁数がおよそ倍々に増えます。

## 代表的な反復法の収束次数

| 方法 | 収束次数 |
| --- | --- |
| 二分法 | 1 次（誤差の上限が毎回 $\frac{1}{2}$） |
| 不動点反復 $x_{n+1} = g(x_n)$ | 1 次（$C = \lvert g'(\alpha)\rvert < 1$ のとき） |
| ニュートン法（単純解） | 2 次 |
| ニュートン法（$m$ 重解） | 1 次（$C = \frac{m-1}{m}$） |
| 割線法 | 約 1.618 次（黄金比） |
| 勾配降下法（強凸な二次関数） | 1 次（収束率は条件数で決まる） |

不動点反復の場合は、$e_{n+1} = g(x_n) - g(\alpha) = g'(\xi)e_n$ と平均値の定理で書けることから 1 次収束が分かります。$g'(\alpha) = 0$ なら、テイラー展開の次の項が効いて 2 次以上になり、ニュートン法はまさにこの場合です。

## 計算例

$f(x) = (x - 1)^2$ にニュートン法を適用すると $x_{n+1} = x_n - \frac{x_n - 1}{2}$ で、誤差は $0.5, 0.25, 0.125, \ldots$ と毎回半分になります（重解なので 1 次収束、$C = \frac{1}{2}$）。単純解 $\sqrt{2}$ を求める $x_{n+1} = \frac{1}{2}\left(x_n + \frac{2}{x_n}\right)$ では、誤差が $10^{-1}, 10^{-3}, 10^{-6}, 10^{-12}$ 程度と 2 次的に減ります。

## 試験での問われ方

数検1級では、反復法の誤差の漸化式を導いて収束次数や収束率を求める問題、ニュートン法が重解で 1 次収束に落ちることを示す問題、ヤコビ法などの反復法の収束条件（反復行列のスペクトル半径が 1 未満）を扱う問題が出ます。統計検定データサイエンスエキスパートでは、最適化手法の収束の速さの比較として問われます。

## よくある誤り

- 誤差の比 $|e_{n+1}/e_n|$ が 1 未満であれば 2 次収束だと考える。比が一定値に近づくなら 1 次収束です。
- 「2 次収束は 1 次収束の 2 倍速い」と考える。2 次収束では反復ごとに正しい桁数が倍になり、差はずっと大きくなります。
- 収束次数は初期値によらず成り立つと考える。解の十分近くでの性質です。
