## 定義

仮想記憶は、プログラムが使うアドレス（仮想アドレス）と、主記憶上の実際の番地（実アドレス）を切り離し、補助記憶装置（ディスクなど）も使って、主記憶の容量より大きなプログラムを実行できるようにする仕組みです。

代表的な**ページング方式**では、プログラムを一定の大きさのページに分け、必要なページだけを主記憶のページ枠に読み込みます。参照したページが主記憶にないことを**ページフォールト**といい、そのときは補助記憶から読み込み（ページイン）、ページ枠が空いていなければどれかのページを追い出し（ページアウト）ます。

## ページ置換えアルゴリズム

| 方式 | 追い出すページ |
| --- | --- |
| FIFO | 主記憶に読み込まれた時刻が最も古いページ |
| LRU（Least Recently Used） | 最後に参照されてから最も長い時間がたったページ |
| LFU（Least Frequently Used） | 参照された回数が最も少ないページ |

LRU では、すでに主記憶にあるページが参照される（ヒットする）たびに、そのページの「最終参照時刻」が新しくなります。FIFO では、ヒットしても順位は変わりません。

## 計算例

ページ枠が 3 つで、ページを 1 → 2 → 3 → 1 → 4 の順に参照するとします。4 番目の参照（1）はヒットです。5 番目でページ 4 を読み込むとき、

- **FIFO**：最初に読み込んだページ 1 を追い出し、主記憶は 4・2・3 になる。
- **LRU**：最終参照は 1 が 4 番目、2 が 2 番目、3 が 3 番目なので、最も古いページ 2 を追い出し、主記憶は 1・4・3 になる。

## 試験での問われ方

- **ITストラテジスト試験**：科目A-1 で、ページ枠の番地と参照するページの順序を与え、LRU 方式で最後に参照したページがどのページ枠に入るかを求める問題が出題されています。表を作り、ページフォールトのたびに各ページの最終参照の位置を確かめるのが確実です。

## よくある誤り

- LRU と FIFO を取り違える。LRU は「最後に参照された時刻」、FIFO は「読み込まれた時刻」で判断します。
- LRU で、ヒットしたページの最終参照時刻を更新し忘れる。
- 主記憶が不足してページの入替えが頻発し、処理効率が極端に落ちる状態（スラッシング）を、CPU を高速にすれば解消できると考える。原因はページの入替えの多さなので、主記憶の増設や、同時に動かすプログラムの数を減らすことが対策です。
