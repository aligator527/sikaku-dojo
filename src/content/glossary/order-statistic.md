## 定義

$X_1, \ldots, X_n$ を小さい順に並べたものを $X_{(1)} \leq X_{(2)} \leq \cdots \leq X_{(n)}$ と書き、$X_{(k)}$ を第 $k$ 順序統計量といいます。$X_{(1)}$ が最小値、$X_{(n)}$ が最大値、$X_{(n)} - X_{(1)}$ が範囲です。

## 分布（独立に密度 $f$、分布関数 $F$ に従うとき）

- 最大値：$P(X_{(n)} \leq x) = F(x)^n$、密度 $nF(x)^{n-1}f(x)$。
- 最小値：$P(X_{(1)} > x) = \{1 - F(x)\}^n$、密度 $n\{1 - F(x)\}^{n-1}f(x)$。
- 第 $k$ 順序統計量：上の式。「$k - 1$ 個が $x$ より小さく、1 個が $x$ の近くにあり、$n - k$ 個が $x$ より大きい」場合の数と確率を掛けたものと読める。
- 全体の同時密度：$n!\prod_{i=1}^n f(x_{(i)})$（$x_{(1)} < \cdots < x_{(n)}$）。

## 代表的な結果

| 母集団 | 結果 |
| --- | --- |
| $U(0, 1)$ | $X_{(k)} \sim \mathrm{Beta}(k,\ n - k + 1)$、$E[X_{(k)}] = k/(n + 1)$ |
| $U(0, \theta)$ | 最大値 $X_{(n)}$ は十分統計量で最尤推定量。$\frac{n+1}{n}X_{(n)}$ は不偏 |
| $\mathrm{Exp}(\lambda)$ | 最小値は $\mathrm{Exp}(n\lambda)$。間隔 $X_{(k+1)} - X_{(k)}$（$X_{(0)} = 0$）は独立に $\mathrm{Exp}((n - k)\lambda)$ |

**例**：独立に $\mathrm{Exp}(1)$ に従う 3 つの寿命の最大値（並列系の寿命）の期待値は、間隔の性質から $1/3 + 1/2 + 1 = 11/6$ です。最小値（直列系の寿命）の期待値は $1/3$ です。

## 試験での問われ方

統計検定準1級・1級では、最大値・最小値の分布と期待値、一様分布の順序統計量とベータ分布の関係、$U(0, \theta)$ の推定（最尤推定量・不偏化・信頼区間）、指数分布の間隔の性質、標本中央値の漸近分布、直列系・並列系の信頼性の計算が出題されます。

## よくある誤り

- 最小値の分布を $F(x)^n$ とする（それは最大値の分布）。最小値は余事象 $\{1 - F(x)\}^n$ から求める。
- 順序統計量どうしを独立と考える（並べ替えたことで従属になる）。
- 一般の密度で第 $k$ 順序統計量の係数 $\dfrac{n!}{(k-1)!(n-k)!}$ を落とす。
