## 定義

$X$ と $Y$ が独立に同じ種類の分布に従い、その和 $X + Y$ も同じ種類の分布に従うとき、その分布族は再生性をもつといいます。

## 再生性をもつ主な分布

| 分布（独立とする） | 和の分布 | 条件 |
| --- | --- | --- |
| $N(\mu_1, \sigma_1^2) + N(\mu_2, \sigma_2^2)$ | $N(\mu_1 + \mu_2,\ \sigma_1^2 + \sigma_2^2)$ | なし |
| $Po(\lambda_1) + Po(\lambda_2)$ | $Po(\lambda_1 + \lambda_2)$ | なし |
| $B(n_1, p) + B(n_2, p)$ | $B(n_1 + n_2, p)$ | 成功確率が同じ |
| $\mathrm{Ga}(\alpha_1, \lambda) + \mathrm{Ga}(\alpha_2, \lambda)$ | $\mathrm{Ga}(\alpha_1 + \alpha_2, \lambda)$ | 率（尺度）が同じ |
| $\chi^2(k_1) + \chi^2(k_2)$ | $\chi^2(k_1 + k_2)$ | なし |
| 負の二項分布 | 成功回数 $r$ が足される | 成功確率が同じ |

一様分布や指数分布には再生性がありません（指数分布の和はガンマ分布になる）。

## 証明の方法

モーメント母関数を使うのが標準的です。独立なら $M_{X+Y}(t) = M_X(t)M_Y(t)$ なので、ポアソン分布では

$$e^{\lambda_1(e^t - 1)} \cdot e^{\lambda_2(e^t - 1)} = e^{(\lambda_1 + \lambda_2)(e^t - 1)}$$

となり、これは $Po(\lambda_1 + \lambda_2)$ のモーメント母関数です。モーメント母関数が分布を一意に決めることから結論が得られます。離散分布なら確率母関数、または畳み込みの和 $P(X + Y = k) = \sum_j P(X = j)P(Y = k - j)$ を直接計算しても示せます。

## 計算例

窓口 A と窓口 B に来る 1 時間あたりの客数が独立に $Po(3)$、$Po(5)$ に従うとき、合計の客数は $Po(8)$ に従い、1 時間に合計 10 人以上来る確率などをポアソン分布の表から直接求められます。

## 試験での問われ方

統計検定2級では、独立な正規分布・二項分布・ポアソン分布の和の分布を答える問題、合計に関する確率の計算が出題されます。準1級・1級では、モーメント母関数・確率母関数による再生性の証明、条件（成功確率や率が等しいこと）を満たさない場合の扱い、和を条件としたときの条件付き分布（例：$X \mid X + Y = n$ が二項分布になる）が問われます。

## よくある誤り

- 成功確率の異なる二項分布の和を二項分布とする。
- 正規分布の和の分散で、標準偏差を足してしまう（足すのは分散）。
- 独立でない場合にも再生性を使う。
- 差 $X - Y$ にもポアソン分布の再生性を適用する（差は負の値をとりうるのでポアソン分布ではない。正規分布なら差も正規分布）。
