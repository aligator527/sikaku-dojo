## 定義

$$\mathrm{ReLU}(x) = \max(0, x)$$

正の入力はそのまま通し、負の入力は 0 にします。微分は $x > 0$ で 1、$x < 0$ で 0 です。$x = 0$ では微分できませんが、実装では 0（ライブラリによっては 1）として扱います。

## 利点

- **勾配が消えにくい**：正の領域では微分が常に 1 なので、層を重ねても勾配が縮みません。シグモイド関数（微分の最大値 0.25）と比べて深いネットワークを学習しやすくなりました。
- **計算が軽い**：比較と 0 への置き換えだけで済み、指数関数を計算しません。
- **疎な活性**：負の入力に 0 を出すので、多くのユニットの出力が 0 になり、表現がスパースになります。

## 欠点と派生

- **dying ReLU**：あるユニットへの入力がどのデータでも負になると、出力も勾配も 0 のままになり、そのユニットの重みが更新されなくなります。大きすぎる学習率や負に偏ったバイアスで起きやすくなります。
- **Leaky ReLU**：$\max(\alpha x, x)$（$\alpha = 0.01$ など）として、負の側にも小さな勾配を残します。$\alpha$ を学習するものを PReLU といいます。
- **GELU**：$x\,\Phi(x)$（$\Phi$ は標準正規分布の分布関数）。0 付近で滑らかで、Transformer 系のモデルでよく使われます。
- 負の入力を 0 にするので出力の 2 乗平均が入力の分散の半分になり、それを補うため、重みの初期化では分散を $2/n_{\mathrm{in}}$ とする He の初期化を組み合わせます。

## 実装（逆伝播）

順伝播で $x \le 0$ の位置を表すマスクを保存しておき、逆伝播では上流から来た勾配のうちマスクが真の位置を 0 にするだけです。

```python
mask = x <= 0
out = x.copy(); out[mask] = 0      # 順伝播
dx = dout.copy(); dx[mask] = 0     # 逆伝播
```

## 試験での問われ方

E資格では、ReLU レイヤの順伝播・逆伝播の実装、勾配消失との関係、dying ReLU と Leaky ReLU、He の初期化との組み合わせ、具体的な入力に対する順伝播の計算が出題されます。統計検定データサイエンスエキスパートでも、活性化関数の比較の正誤問題で登場します。

## よくある誤り

- 逆伝播で、出力ではなく勾配そのものに ReLU をかける（判定に使うのは順伝播の入力の符号）。
- ReLU は勾配消失を完全になくすと考える（負の領域では勾配は 0）。
- ReLU を使うネットワークに、シグモイド関数向けの Xavier の初期化をそのまま使うと、深い層で出力の分散が小さくなっていく。
