## 定義

連続型の確率変数 $X$ について、任意の $a \leq b$ で $P(a \leq X \leq b) = \int_a^b f(x)\,dx$ となる関数 $f$ を確率密度関数（密度関数）といいます。分布関数 $F$ とは $F(x) = \int_{-\infty}^x f(t)\,dt$、$F'(x) = f(x)$ の関係にあります。

## 性質

- $f(x) \geq 0$ かつ全体の積分が 1。この 2 条件から、式に含まれる定数を決める問題がよく出る。
- $f(x)$ そのものは確率ではない。1 点の確率は $P(X = a) = 0$ で、$f(a)\,\Delta x$ が「$a$ の近くの幅 $\Delta x$ の区間に入る確率」の近似になる。
- $f(x)$ は 1 を超えてもよい（例：$U(0, 0.5)$ の密度は 2）。
- 期待値は $E[X] = \int x f(x)\,dx$、関数の期待値は $E[g(X)] = \int g(x)f(x)\,dx$。

## 計算例

$f(x) = c\,x(1 - x)$（$0 \leq x \leq 1$）とします。

- $\int_0^1 x(1-x)\,dx = 1/6$ なので $c = 6$。
- 分布関数は $F(x) = 3x^2 - 2x^3$、$P(X \leq 1/2) = 1/2$（$x = 1/2$ について対称）。
- $E[X] = 1/2$、$E[X^2] = 3/10$ より $V[X] = 3/10 - 1/4 = 1/20$。
- 最頻値は $x = 1/2$ で、そこでの密度の値は $3/2$（1 を超えている）。

これはベータ分布 $\mathrm{Beta}(2, 2)$ の密度です。

## 変数変換との関係

$Y = g(X)$（$g$ は単調）の密度は $f_Y(y) = f_X(g^{-1}(y))\left|\dfrac{d}{dy}g^{-1}(y)\right|$ で求めます。密度の値をそのまま代入するだけでは足りず、微分の係数（ヤコビアン）がかかる点が、確率関数（離散型）との大きな違いです。

## 試験での問われ方

統計検定2級では、一様分布や簡単な多項式の密度から確率・期待値を求める問題が出題されます。準1級・1級では、定数の決定、分布関数との相互変換、変数変換による密度の導出、同時密度から周辺密度・条件付き密度を求める計算が中心です。

## よくある誤り

- $f(a)$ を「$X = a$ となる確率」と考える。
- 密度の値が 1 を超えていることを理由に、密度関数ではないと判断する。
- 変数変換で $f_X(g^{-1}(y))$ だけを書き、微分の係数を掛け忘れる。
