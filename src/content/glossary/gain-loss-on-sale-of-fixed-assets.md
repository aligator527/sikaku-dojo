## 定義

固定資産の帳簿価額は「取得原価 − 減価償却累計額」です。期中に売却する場合は、期首から売却日までの当期分の減価償却費も計上し、それを差し引いた売却時点の帳簿価額と売却価額を比べます。差額は臨時的な損益なので、損益計算書では特別利益・特別損失に表示するのが一般的です。

## 仕訳例（間接法、期中売却）

当期首から6か月が経過した日に、備品（取得原価 ￥600,000、期首の減価償却累計額 ￥240,000、耐用年数5年、残存価額ゼロ、定額法）を ￥250,000 で売却し、代金は翌月末に受け取ることとした。

1. 当期分の減価償却費：600,000 ÷ 5年 × 6／12 ＝ 60,000円
2. 売却時の帳簿価額：600,000 − 240,000 − 60,000 ＝ 300,000円
3. 売却損益：250,000 − 300,000 ＝ −50,000円（売却損）

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 備品減価償却累計額 | 240,000 | 備品 | 600,000 |
| 減価償却費 | 60,000 | | |
| 未収入金 | 250,000 | | |
| 固定資産売却損 | 50,000 | | |

商品ではない固定資産の売却なので、代金の未収分は売掛金ではなく未収入金です。

## 記帳方法による違い

直接法（減価償却累計額を使わず、資産の金額を直接減らす方法）で記帳している場合は、貸方の備品の金額がすでに帳簿価額になっているので、減価償却累計額の行は現れません。

## 試験での問われ方

3級・2級の第1問で毎回のように出題される論点です。期首売却か期中売却か、月割の月数、間接法か直接法かの3点を問題文から読み取ります。2級では、定率法や生産高比例法で償却している資産の売却、1級では減損処理後の資産の売却も扱います。

## よくある誤り

- 期中売却で、当期分の減価償却費を計上し忘れる。
- 売却損益を「売却価額 − 取得原価」で計算する。
- 代金の未収分を売掛金で処理する。
