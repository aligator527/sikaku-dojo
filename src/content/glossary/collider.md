## 定義と性質

経路 $X \to C \leftarrow Y$ の $C$ のように、経路上の前後の両方から矢印が向かってくる頂点を、その経路の合流点といいます。合流点は経路を「閉じて」いるので、$X$ と $Y$ の間に他の経路がなければ $X$ と $Y$ は独立です。ところが $C$（または $C$ の子孫）で条件付けると経路が開き、$X$ と $Y$ の間に関連が生じます。これを合流点バイアス（選択バイアスの一種）といいます。

交絡因子（分岐 $X \leftarrow C \to Y$ の $C$）とは逆で、交絡因子は調整すべき変数、合流点は調整してはいけない変数です。

## 計算例

$X$ と $Y$ が独立にそれぞれ確率 1/2 で 1 をとり、$C = 1$ を「$X = 1$ または $Y = 1$」と定めます。全体では $X$ と $Y$ は無関係ですが、$C = 1$ の人だけを見ると

$$P(X = 1 \mid C = 1, Y = 1) = \frac{1}{2},\qquad P(X = 1 \mid C = 1, Y = 0) = 1$$

となり、$Y = 0$ であることが分かると $X = 1$ が確定します。$C = 1$ の集団の中では $X$ と $Y$ に負の関連が現れます。

## 典型的な例

- **バークソンのバイアス**：入院の理由になる 2 つの病気 $A, B$ は一般集団では独立でも、入院患者（入院 = 合流点）だけを調べると負の関連が見える。
- **選抜による関連**：才能と容姿が独立でも、両方の合計で選ばれた芸能人の中では、一方が高い人ほど他方が低く見える。
- **生存者に限った分析**：処置と未観測の健康状態がともに生存に影響するとき、生存者だけで処置の効果を比べると偏る。
- **M バイアス**：$X \leftarrow A \to S \leftarrow B \to Y$ の $S$ は処置より前に測った共変量でも合流点で、$S$ を調整するとバックドアパスが開いてしまう。

## 試験での問われ方

統計検定準1級では、因果ダイアグラムから合流点を見つけて調整してはいけない変数を選ぶ問題、合流点で条件付けたときに生じる関連の向き、d 分離の規則（合流点とその子孫の扱い）が問われます。データサイエンスエキスパートでは、データの抽出条件（選ばれた顧客だけのデータなど）が合流点になって分析を偏らせる例として出ます。

## よくある誤り

- 結果より前に測った変数なら、調整しても問題ないと考える（処置前の変数でも合流点になりうる）。
- 合流点そのものでなく、その子孫で条件付けるなら問題ないと考える（子孫でも経路は開く）。
- 合流点で条件付けたときに生じた相関を、因果関係の証拠と解釈する。
