## 定義

預り金は、いずれ第三者に支払う（または本人に返す）ために一時的に預かったお金を記録する負債です。簿記の試験で最も多いのは、給料の支払時に差し引いた従業員の所得税（源泉所得税）と社会保険料です。内容ごとに所得税預り金・社会保険料預り金のような勘定に分けて記録します。

## 仕訳例

従業員の給料総額 ￥300,000 から、源泉所得税 ￥20,000 と社会保険料の従業員負担分 ￥30,000 を差し引き、残額を普通預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 給料 | 300,000 | 所得税預り金 | 20,000 |
| | | 社会保険料預り金 | 30,000 |
| | | 普通預金 | 250,000 |

社会保険料を、従業員負担分 ￥30,000 と会社負担分 ￥30,000 を合わせて普通預金口座から納付した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 社会保険料預り金 | 30,000 | 普通預金 | 60,000 |
| 法定福利費 | 30,000 | | |

源泉所得税 ￥20,000 を税務署に現金で納付した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 所得税預り金 | 20,000 | 現金 | 20,000 |

## ポイント

- 給料は差引前の総額で費用計上し、差し引いた分を預り金にします。
- 社会保険料の会社負担分は会社の費用なので、法定福利費で処理します。
- 従業員が負担すべき支出を会社が一時的に立て替えたときは、預り金ではなく立替金（従業員立替金）という資産を使います。給料の支払時にその分を差し引いて精算します。

## 試験での問われ方

3級の第1問で、給料の支払いと、税金・社会保険料の納付が出題されます。2級では賞与の支給とあわせて出題されることもあります。

## よくある誤り

- 給料を手取額で計上する（給料は総額）。
- 社会保険料の納付時に、会社負担分まで預り金の減少とする。
- 預り金（負債）と立替金（資産）を取り違える。
