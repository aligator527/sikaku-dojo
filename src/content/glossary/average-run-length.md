## 定義

各群の打点が独立に確率 $p$ で管理限界外に出るとき、最初に限界外に出るまでの群の数（ランレングス）は幾何分布に従い、その期待値が $\mathrm{ARL} = 1/p$ です。標準偏差も $\sqrt{1 - p}/p$ と大きく、ランレングスのばらつきは大きいことに注意が必要です。

## $\bar{X}$ 管理図の ARL

管理限界が $\mu_0 \pm 3\sigma/\sqrt{n}$ で、工程平均が $\mu_0 + \delta\sigma$ にずれたとすると、$\bar{X}$ が限界外に出る確率は

$$p = P\left(Z > 3 - \delta\sqrt{n}\right) + P\left(Z < -3 - \delta\sqrt{n}\right)$$

です。

| 状況（$n = 4$） | $p$ | ARL |
| --- | --- | --- |
| ずれなし（$\delta = 0$） | 0.0027 | 約 370 |
| $\delta = 0.5$ | 0.0228 | 約 44 |
| $\delta = 1$ | 0.1587 | 約 6.3 |
| $\delta = 2$ | 0.8413 | 約 1.2 |

管理状態での ARL（$\mathrm{ARL}_0$）は大きいほど誤警報が少なく、工程が変化したときの ARL（$\mathrm{ARL}_1$）は小さいほど変化を早く検出できます。検定の言葉では、$1/\mathrm{ARL}_0$ が第 1 種の過誤確率、$1/\mathrm{ARL}_1$ が 1 回の打点での検出力にあたります。

## 管理図の比較

シューハート管理図は大きな変化（$2\sigma$ 以上）の検出に強い一方、$0.5\sigma \sim 1\sigma$ 程度の小さな持続的変化の検出には時間がかかります。同じ $\mathrm{ARL}_0$ にそろえたうえで $\mathrm{ARL}_1$ を比べると、累積和（CUSUM）管理図や EWMA 管理図の方が小さな変化を早く検出できます。群の大きさ $n$ を増やすと $\delta\sqrt{n}$ が大きくなるので、ARL は短くなります。

## 試験での問われ方

統計検定1級（理工学）では、平均がずれたときの検出確率と ARL の計算、ARL が幾何分布の期待値になる理由、群の大きさや管理限界の幅を変えたときの ARL の変化が問われます。

## よくある誤り

- 片側の確率だけで $p$ を計算する（ずれと反対側の確率は小さいが、厳密には両側を足します）。
- ARL を、変化が起きてから必ずその群数で検出できる値と考える（あくまで期待値です）。
- 個々の値の標準偏差 $\sigma$ と、平均の標準偏差 $\sigma/\sqrt{n}$ を混同する。
