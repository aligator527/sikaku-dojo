## 定義

フェアユースは、米国の著作権法第107条に定められた一般的な権利制限の規定です。著作物の利用が公正な利用（フェアユース）に当たるかどうかを、次の四つの要素を総合的に考慮して、裁判所が個別に判断します。

1. 利用の目的と性格（商業的な利用か、非営利の教育目的かなど）
2. 著作物の性質
3. 利用された部分の量と、著作物全体に占める重要性
4. 利用が著作物の潜在的な市場や価値に与える影響

規定が包括的なため、新しい技術やサービスによる利用にも柔軟に対応できる一方、事前に適法かどうかを判断しにくいという面があります。

## 日本の著作権法との違い

日本の著作権法には、フェアユースのような一般的な規定はありません。その代わりに、権利を制限する場面を**個別に**定めています。

| 規定 | 内容の例 |
| --- | --- |
| 私的使用のための複製（第30条） | 個人や家庭内で使うための複製 |
| 引用（第32条） | 公正な慣行に合致し、正当な範囲内での引用 |
| 学校その他の教育機関での複製等（第35条） | 授業の過程での利用 |
| 享受を目的としない利用（第30条の4） | AI の学習などの情報解析 |
| 電子計算機での付随的な利用など（第47条の4、第47条の5） | キャッシュ、所在検索サービスなどでの軽微な利用 |

2018 年の改正（2019 年施行）で、第30条の4 などの比較的柔軟な権利制限規定が設けられましたが、これも米国型の一般規定ではありません。

## 試験での問われ方

- **ITストラテジスト試験**：午前II で、フェアユースの説明を選ぶ問題が出題されました。紛らわしい選択肢として、公的機関による使用料の免除、著作権管理団体による使用料の徴収、著作者の意に反する改変の禁止（同一性保持権）の説明が並びます。

## よくある誤り

- 日本の著作権法にもフェアユースの一般規定があると考える。
- 著作者の意に反する改変を禁止する考え方（同一性保持権）と混同する。
