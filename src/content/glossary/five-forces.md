## 定義

ファイブフォース分析は、業界の構造が収益性をどう左右するかを、次の五つの力で分析する手法です。どの力も「強いほど業界の収益性は下がる」と考えます。

| 競争要因 | 力が強くなる条件の例 |
| --- | --- |
| 既存企業間の競争 | 同規模の競合が多い、成長が鈍い、固定費が高い、撤退障壁が高い |
| 新規参入の脅威 | 参入障壁（規模の経済、必要資本、流通チャネル、ブランドなど）が低い |
| 代替品の脅威 | 同じニーズを満たす、価格性能比の高い代替品がある |
| 買い手の交渉力 | 買い手が少数で大量購入、製品が標準化、スイッチングコストが低い |
| 売り手（供給業者）の交渉力 | 供給業者が少数、供給品が差別化されている、代替の調達先がない |

## 試験での問われ方

- **中小企業診断士試験**：企業経営理論で、各要因を強める（弱める）条件の正誤が繰り返し問われます。
- **ITストラテジスト試験**：事業環境分析の手法として出題されます。

## よくある誤り

- 「参入障壁が高い」ことを収益性の低下要因とする（逆です）。
- 業界内の個別企業の強み・弱みの分析（SWOT や VRIO）と、業界構造の分析を混同する。
