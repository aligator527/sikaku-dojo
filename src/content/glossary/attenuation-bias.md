## 定義

真のモデル $Y = \alpha + \beta X + \varepsilon$ の説明変数 $X$ が直接観測できず、誤差を含む $W = X + U$（$U$ は $X$、$\varepsilon$ と独立、平均 0、分散 $\sigma_U^2$）だけが観測されるとします（古典的測定誤差、変数誤差モデル）。$Y$ を $W$ に回帰した最小二乗推定量は

$$\operatorname*{plim}\hat{\beta} = \frac{\mathrm{Cov}(W, Y)}{V[W]} = \frac{\beta\sigma_X^2}{\sigma_X^2 + \sigma_U^2}$$

に収束し、一致推定量になりません。$\lambda = \sigma_X^2/(\sigma_X^2 + \sigma_U^2)$ は信頼性比（テスト理論の信頼性係数と同じ考え方）で、$0 < \lambda \leq 1$ なので推定値は 0 に向かって縮みます。

## 性質

- 測定誤差が目的変数 $Y$ の側だけにある場合は、誤差分散が増えるだけで、傾きの推定量は不偏のままです。偏りが生じるのは説明変数の誤差です。
- 重回帰では、誤差のある変数の係数が縮むだけでなく、それと相関する他の変数の係数にも偏りが波及します。
- パネルデータで固定効果推定や一階差分をすると、真の値の個体内変動は小さくなる一方、測定誤差は残るので、$\lambda$ が下がって減衰バイアスが大きくなりやすくなります。

## 計算例

$\sigma_X^2 = 4$、$\sigma_U^2 = 1$、$\beta = 0.5$ なら $\lambda = 0.8$ で、$\hat{\beta}$ は約 $0.40$ に収束します。$\lambda$ が既知（または繰り返し測定から推定可能）なら、$\hat{\beta}/\lambda$ で補正できます。

## 対処法

- 同じ量を独立に 2 回測った値の一方を、もう一方の操作変数として使う（操作変数法）。
- 繰り返し測定や妥当性研究から $\sigma_U^2$ を推定して補正する。
- 誤差分散の比が既知なら、デミング回帰（直交回帰）を使う。

## 試験での問われ方

統計検定1級（社会科学）では、自己申告の所得などを例に確率極限を導いて一致性がないことを示し、偏りの向き、操作変数による一致推定を論じる記述問題が典型です。人文科学では、相関係数が信頼性によって薄まる「希薄化」と同じ現象として扱われます。

## よくある誤り

- 測定誤差があっても、標本サイズを大きくすれば偏りは消えると考える。
- 目的変数の測定誤差でも傾きが縮むと考える。
- 測定誤差による偏りは常に推定値を大きくすると考える（古典的測定誤差では 0 に向かって縮みます）。
