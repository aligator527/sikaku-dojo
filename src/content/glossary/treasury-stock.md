## 定義

自己株式の取得は、株主に払い込まれた資本を払い戻すのと同じ効果を持つので、資産としては扱わず、株主資本のマイナスとして表示します（「自己株式及び準備金の額の減少等に関する会計基準」）。

| 取引 | 処理 |
| --- | --- |
| 取得 | 取得原価で自己株式を計上。取得の手数料（付随費用）は営業外費用 |
| 処分（売却・交付） | 処分の対価と帳簿価額の差額を自己株式処分差益・差損とし、その他資本剰余金に加減する |
| 消却 | 帳簿価額をその他資本剰余金から減額する |

その他資本剰余金が期末にマイナスになった場合は、ゼロとしてその負の額を繰越利益剰余金から減額します。

## 仕訳例

自己株式1,000株を1株 ￥500 で取得し、手数料 ￥10,000 とともに普通預金口座から支払った。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 自己株式 | 500,000 | 普通預金 | 510,000 |
| 支払手数料 | 10,000 | | |

このうち600株を1株 ￥600 で処分し、代金は普通預金口座に入金された。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| 普通預金 | 360,000 | 自己株式 | 300,000 |
| | | その他資本剰余金 | 60,000 |

残りの400株を消却した。

| 借方科目 | 金額 | 貸方科目 | 金額 |
| --- | ---: | --- | ---: |
| その他資本剰余金 | 200,000 | 自己株式 | 200,000 |

## 試験での問われ方

日商簿記1級では、取得・処分・消却の仕訳、複数回取得した場合の帳簿価額（平均単価など）、新株予約権の行使や合併の対価に自己株式を交付する場合の処理が出題されます。純資産の部の表示や株主資本等変動計算書の問題でも登場します。中小企業診断士では、会社法の自己株式の取得規制や、財務諸表の表示が問われることがあります。

## よくある誤り

- 自己株式を有価証券などの資産に計上する。
- 自己株式処分差益を損益計算書の収益にする（その他資本剰余金に計上）。
- 取得時の手数料を取得原価に含める（営業外費用）。
