## 定義

原価差異は「標準原価（予定原価・予算許容額）− 実際原価」で計算するのが一般的です。結果がプラスなら実際原価が少なくて済んだので **有利差異**、マイナスなら余計にかかったので **不利差異** です。

不利差異は、原価が標準より多くかかった分なので、費用と同じく借方に残高が生じます。このため不利差異を **借方差異**、有利差異を **貸方差異** とも呼びます。

| 差異 | 有利差異になる場合 |
| --- | --- |
| 価格差異・材料消費価格差異 | 実際単価が標準（予定）単価より低い |
| 数量差異 | 実際消費量が標準消費量より少ない |
| 賃率差異 | 実際賃率が標準（予定）賃率より低い |
| 作業時間差異・能率差異 | 実際作業時間が標準作業時間より短い |
| 予算差異 | 実際発生額が予算許容額より少ない |
| 操業度差異 | 実際操業度が基準操業度より大きい |

売上高のような収益の差異では逆に、実際が予算を上回るときが有利差異です。退職給付会計の数理計算上の差異でも、同じ考え方で、将来の費用を減らす方向の差異を有利差異、増やす方向の差異を不利差異（借方差異）と呼びます。

## 計算例と仕訳

価格差異が ＋20,000円（有利）、数量差異が −35,000円（不利）なら、総差異は −15,000円（不利）です。パーシャル・プランでは、仕掛品勘定で把握した差異を次のように振り替えます。

- 不利差異：（借）数量差異 35,000（貸）仕掛品 35,000
- 有利差異：（借）仕掛品 20,000（貸）価格差異 20,000

不利差異は差異勘定の借方に、有利差異は貸方に残ります。年度末に売上原価に賦課すると、不利差異は売上原価を増やし、有利差異は売上原価を減らします。

## 試験での問われ方

日商簿記の工業簿記では、差異の金額とともに「有利・不利」や「借方・貸方」を答えさせる問題がほとんどです。差異分析図では、内側に標準、外側に実際を書けば、内側から外側を引いた結果の符号で有利・不利がそのまま判定できます。中小企業診断士でも、価格差異・数量差異の組合せを有利・不利つきで選ぶ問題が出題されます。

## よくある誤り

- 「実際 − 標準」で計算し、有利・不利を逆にしてしまう。
- 操業度差異で、実際操業度が基準操業度を上回った場合を不利と判断する。
- 不利差異を貸方差異と覚えてしまう（不利差異は借方差異）。
