## 定義

仮説検定では、主張したいこと（差がある、効果がある）を対立仮説 $H_1$ に置き、その否定を帰無仮説 $H_0$ とします。帰無仮説が正しいと仮定したときに、観測データが十分に起こりにくい（p 値が有意水準以下）なら、帰無仮説を棄却して対立仮説を採ります。

帰無仮説には通常「$\mu = \mu_0$」「$p_1 = p_2$」「2 つの変数は独立」のような等号の形の仮説を置きます。等号で値を 1 つに決めると、検定統計量の分布が定まり、棄却域や p 値を計算できるからです。

## 代表的な帰無仮説

| 検定 | 帰無仮説 |
| --- | --- |
| 母平均の検定 | $\mu = \mu_0$ |
| 2 群の平均の比較 | $\mu_1 = \mu_2$ |
| 回帰係数の t 検定 | $\beta_j = 0$ |
| 一元配置分散分析 | すべての群の母平均が等しい |
| 独立性のカイ二乗検定 | 2 つの変数は独立 |
| 等分散の F 検定 | $\sigma_1^2 = \sigma_2^2$ |

## 単純仮説と複合仮説

母数の値を 1 点に決める仮説（$\mu = \mu_0$）を単純仮説、範囲で表す仮説（$\mu \leq \mu_0$）を複合仮説といいます。片側検定で帰無仮説を $\mu \leq \mu_0$ とした場合も、棄却確率が最大になる境界 $\mu = \mu_0$ で棄却域を決めます。

## 試験での問われ方

統計検定2級では、問題文の状況から帰無仮説と対立仮説を正しく立てる問題、検定結果の正しい解釈を選ぶ問題が頻出です。準1級・1級では、ネイマン・ピアソンの補題や尤度比検定で、単純仮説・複合仮説に応じた検定の構成が問われます。

## よくある誤り

- 「帰無仮説が棄却されなかった」ことを「帰無仮説が正しいと証明された」と解釈する（データが否定するに足りなかっただけ）。
- p 値を「帰無仮説が正しい確率」と解釈する。
- 主張したいこと（効果がある）を帰無仮説に置いてしまう。
- データを見てから、有意になる向きの仮説を立てる。
