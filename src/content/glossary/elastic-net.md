## 定義

罰則の強さ $\lambda$ と、L1 と L2 の混合比 $\alpha \in [0, 1]$ の 2 つのハイパーパラメータをもちます。$\alpha = 1$ ならラッソ、$\alpha = 0$ ならリッジ回帰です（ソフトウェアによって L2 の項に $1/2$ を付けるなど、書き方が少しずつ異なります）。

## ラッソの弱点との関係

ラッソには次の弱点があります。

- 強く相関する変数の組から 1 つだけを選び、どれが選ばれるかがデータの小さな変化で入れ替わる。
- $p > n$ のとき、選べる変数が $n$ 個までに限られる。

L2 の罰則を加えると目的関数が狭義凸になり、相関の強い変数には似た大きさの係数が付く「グループ化効果」が生まれます。そのうえで L1 の罰則により不要な変数は 0 になるので、遺伝子発現データのように変数が非常に多く、互いに相関する変数の群があるデータに向きます。

## 使い方

説明変数を標準化してから当てはめ、$\lambda$ と $\alpha$ を交差検証で選びます。$\alpha$ の候補を数通りに絞り、それぞれで $\lambda$ の経路を計算するのが一般的です。

## 試験での問われ方

統計検定データサイエンスエキスパートや準1級では、ラッソ・リッジ回帰と並べて罰則の形と性質（0 になる係数が生じるか、相関する変数をどう扱うか）を比べる選択肢として出ます。E資格のシラバス 2026 では線形回帰の正則化は前提知識（グレー網掛けで出題対象外）ですが、出題対象の L1・L2 正則化を組み合わせたものとして理解しておくと役立ちます。

## よくある誤り

- エラスティックネットでは係数が 0 にならないと考える（L1 の項があるので 0 になりうる）。
- $\alpha$ の向き（どちらが L1 の割合か）を確かめずに解釈する。
