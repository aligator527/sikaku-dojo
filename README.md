# 資格道場

統計・数学・IT・AI・簿記・経営分野の資格試験に向けた学習サイトです。
問題演習（解答・解説つき）、用語集、模擬試験、対策方法、参考リンクを資格ごとにまとめています。

| 分野                   | 資格                                                      |
| ---------------------- | --------------------------------------------------------- |
| 統計・データサイエンス | 統計検定 2級 / 準1級 / 1級 / データサイエンスエキスパート |
| 数学                   | 実用数学技能検定 1級                                      |
| IT・情報処理           | ITストラテジスト試験                                      |
| AI・ディープラーニング | JDLA E資格                                                |
| 会計・簿記             | 日商簿記検定 3級 / 2級 / 1級                              |
| 経営・コンサルティング | 中小企業診断士                                            |

## 機能

- **問題一覧・問題ページ** — 選択式・複数選択・数値入力・仕訳入力と表の記入（簿記の精算表・財務諸表・勘定記入など。欄ごとの部分点）・記述式（自己採点）。KaTeX で数式を表示。
- **分野別演習** — 分野・未解答・間違えた問題・ブックマーク・今日の復習で絞り込んで一問ずつ解く。キーボード操作（数字キーで選択、Enter で解答・次へ）に対応。
- **問題の復習** — 間違えた問題は翌日、正解するたびに 3・7・14・30 日後に再出題（間隔反復）。
- **模擬試験** — 制限時間・問題パレット・見直しフラグつき。終了後に合否と分野別得点を表示。条件を指定したカスタム模試も作れる。
- **用語集** — 50音索引、資格別フィルタ、関連用語・関連問題。間隔反復の用語カード。
- **公式集** — 資格ごとの公式一覧。印刷すると A4 2段組。
- **学習ツール** — 統計数値表（標準正規・t・χ²・F 分布、すべてサイト内で計算）、確率分布の計算機、記述統計・回帰の計算機。統計系の演習・模試からは「付表」ボタンで開ける。
- **資格ロードマップ** — 資格を分野と難易度で並べ、次のステップと出題範囲の重なりを図示。
- **学習記録** — 正答率・定着度・弱点分野・模試履歴・受験日カウントダウン・学習カレンダー（連続学習日数）。ブラウザ内（localStorage）に保存し、JSON で書き出し・読み込みできる。
- **オフライン対応（PWA）** — ホーム画面に追加でき、資格ごとに「オフライン用に保存」すると通信なしで演習・模試ができる。
- **サイト内検索** — Pagefind による全文検索（資格・種類で絞り込み）。
- ライト / ダークテーマ、スマートフォン対応。

## 開発

Node.js 22.12 以上と pnpm が必要です。

```bash
pnpm install
pnpm dev          # http://localhost:4321
pnpm test         # ドメインロジックの単体テスト
pnpm check        # 型チェック
pnpm validate     # 教材の検査（KaTeX・YAML・正解番号・重複など。数秒で終わる）
pnpm build        # 本番ビルド（教材の整合性チェック + 検索インデックス生成）
pnpm preview      # ビルド結果の確認（検索はここで動く）
```

技術構成: [Astro](https://astro.build/)（静的サイト生成）+ React（インタラクティブ部分のみ）+ TypeScript、
nanostores、KaTeX、Pagefind、Lucide アイコン。詳しくは [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 教材の追加・修正

教材はすべて `src/content/` 以下の YAML / Markdown ファイルです。書式・著作権のルールは
[docs/CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md) を参照してください。`pnpm validate` が数式・書式を、
`pnpm build` がスキーマとファイル間の参照（分野 ID、正解番号、仕訳の貸借一致など）を検証します。
大量の問題を書き足している最中に UI を触るときは、`CONTENT_WATCH=off pnpm dev` で問題ファイルの
変更による再読み込みを止められます。

## 公開（GitHub Pages）

1. GitHub にリポジトリを作成して push する。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
3. `main` への push ごとに `.github/workflows/deploy.yml` がビルドと公開を行う。
   サイトの URL とベースパス（`/<リポジトリ名>/`）は自動で設定される。

### 検索エンジンへの登録（任意）

各ページには canonical・OGP・構造化データ（JSON-LD）が入り、`sitemap-index.xml` が生成されます。
GitHub Pages のプロジェクトサイト（`https://<user>.github.io/<repo>/`）ではドメイン直下の
`robots.txt` を置けないため、サイトマップは検索エンジンの管理ツールから登録します。

1. [Google Search Console](https://search.google.com/search-console) で **URL プレフィックス** プロパティ
   （`https://<user>.github.io/<repo>/`）を追加し、確認方法に「HTML タグ」を選ぶ。
2. タグの `content` の値を、リポジトリの **Settings → Secrets and variables → Actions → Variables** に
   `GOOGLE_SITE_VERIFICATION` として登録し、再デプロイしてから確認する。
3. 確認後、「サイトマップ」に `sitemap-index.xml` を送信する。
4. Bing Webmaster Tools も同様に `BING_SITE_VERIFICATION`（`msvalidate.01` の値）を登録する。
5. Bing・Yandex などに更新を通知したい場合は、英数字 32 文字程度の任意の文字列を `INDEXNOW_KEY` に登録する。
   デプロイのたびにサイトマップの URL が IndexNow に送信される（変数がなければ何も送信しない）。

共有用画像（`public/og/*.png`）は `pnpm og` で生成します。資格を追加・改名したら実行してコミットしてください
（Noto CJK フォントが必要）。

そのほかのワークフロー:

- `ci.yml` — プルリクエストで教材検査・テスト・型チェック・ビルドを実行。
- `links.yml` — 毎週、教材内の外部リンク切れを確認し、あれば Issue を作成。

## 著作権について

IPA（情報処理技術者試験）の過去問題は、IPA の定める条件に従い出典を明記して掲載しています。
そのほかの試験の過去問題は主催者の著作物のため転載せず、オリジナル問題・改題と公式資料へのリンクで構成しています。
